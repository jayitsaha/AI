Locally Linear Embedding (LLE)

Nonlinear dimensionality reduction by preserving local reconstruction weights
Advanced Unsupervised Learning Manifold Learning O(DN·k²) + eigenproblem
1
Understanding the Concept
▾

Imagine you have a Swiss roll — a flat sheet of paper rolled into a spiral. In 3D, points that are geometrically close on the paper surface look close, but so do points from completely different parts of the roll. A regular PCA would flatten this into a messy blob. LLE instead unrolls the paper, preserving which points were actually neighbors on the sheet.

LLE's key insight: even on a curved, nonlinear manifold, every point can be approximately reconstructed as a linear combination of its nearest neighbors. If you're on the surface of a sphere, your immediate neighborhood looks flat — that's the "locally linear" part. LLE finds those reconstruction weights in high-dimensional space, then finds a low-dimensional layout where the same weights still work as well as possible.

Core Insight

LLE asks: "If point \(x_i\) is a weighted average of its neighbors in high-D, find low-D coordinates where it's the same weighted average of the same neighbors." The weights are invariant to rotation, scaling, and translation — making them geometry-preserving fingerprints.

This gives LLE two clean phases: (1) solve a small local regression per point to find neighbor weights, (2) solve one global eigenproblem to find the embedding that honors all those weights simultaneously.

One-Line Summary

LLE unfolds nonlinear manifolds by freezing local reconstruction weights and finding the globally consistent low-dimensional layout — no distance metric needed, just local linearity.

2
How It Works — The Two-Phase Algorithm
▾

Phase 1: Find Reconstruction Weights

For each point \(x_i \in \mathbb{R}^D\), find its \(k\) nearest neighbors \(\{x_j\}_{j \in \mathcal{N}(i)}\). Then solve for weights \(W_{ij}\) that minimize the reconstruction error:

$$\varepsilon(W) = \sum_{i=1}^{N} \left\| x_i - \sum_{j \in \mathcal{N}(i)} W_{ij}\, x_j \right\|^2 \quad \text{subject to} \quad \sum_j W_{ij} = 1,\; W_{ij} = 0 \text{ if } j \notin \mathcal{N}(i)$$

This is a constrained least-squares problem. Define the local Gram matrix \(G_{jk} = (x_i - x_j)^\top (x_i - x_k)\). The optimal weights are:

$$W_{ij} = \frac{\sum_k G^{-1}_{jk}}{\sum_{lm} G^{-1}_{lm}}$$

The weights encode local geometry. If neighbors are collinear, the weights can be large and oscillatory — this is the key fragility of LLE.

Phase 2: Find the Embedding (Eigenproblem)

Now find low-D coordinates \(y_i \in \mathbb{R}^d\) (with \(d \ll D\)) that minimize the same reconstruction error using the frozen weights \(W_{ij}\):

$$\Phi(Y) = \sum_{i=1}^{N} \left\| y_i - \sum_j W_{ij}\, y_j \right\|^2 = Y^\top M Y$$

where the sparse cost matrix \(M = (I - W)^\top(I - W)\). Minimizing \(Y^\top M Y\) subject to \(Y^\top Y = I\) and \(\mathbf{1}^\top Y = 0\) (zero-centered) gives the eigenvectors of \(M\) corresponding to eigenvalues \(\lambda_2 \le \lambda_3 \le \dots \le \lambda_{d+1}\) (skip \(\lambda_1 = 0\)).

Why Skip the Smallest Eigenvector?

The smallest eigenvalue of \(M\) is always 0, with eigenvector \(\mathbf{1}/\sqrt{N}\) (the trivial constant solution — all points at the same location). We skip it and take eigenvectors 2 through \(d+1\).

Numerical Trace (N=4, k=2, d=1)

Consider 4 points on a 2D curve: \(x_1 = [0,0]\), \(x_2 = [1,0.1]\), \(x_3 = [2,0.4]\), \(x_4 = [3,0.9]\). For \(x_2\), neighbors are \(x_1, x_3\). Local Gram: \(G_{11} = (x_2-x_1)^\top(x_2-x_1) = 1.01\), \(G_{22} = (x_2-x_3)^\top(x_2-x_3) = 1.09\), \(G_{12} = (x_2-x_1)^\top(x_2-x_3) = -1.04\). Weights: \(w_1 \approx 0.512, w_2 \approx 0.488\). The embedding minimizes \(M = (I-W)^\top(I-W)\) and the second eigenvector gives 1D positions roughly \([-0.67, -0.22, 0.22, 0.67]\) — equal spacing reflecting the roughly linear spacing of the original.

Design Decision: Why Eigenvectors?

The cost \(Y^\top M Y\) is a quadratic form. Minimizing it with orthonormality constraint is exactly the Rayleigh quotient problem — solved by eigenvectors. This is not a heuristic; it's the provably optimal solution given the weight constraints.

3
The Mathematics — Full Derivation
▾

Phase 1 Derivation: Constrained Least Squares

For point \(x_i\), let \(\mathbf{w}_i = (W_{i,j_1}, \dots, W_{i,j_k})^\top\) be the weight vector over its \(k\) neighbors. Define the centered neighbor matrix \(\tilde{X}_i \in \mathbb{R}^{D \times k}\) where column \(j\) is \(x_i - x_j\). The reconstruction error is:

$$\varepsilon_i = \|\tilde{X}_i \mathbf{w}_i\|^2 = \mathbf{w}_i^\top G_i \mathbf{w}_i, \quad G_i = \tilde{X}_i^\top \tilde{X}_i \in \mathbb{R}^{k \times k}$$

Using Lagrange multiplier \(\lambda\) for the sum-to-one constraint \(\mathbf{1}^\top \mathbf{w}_i = 1\):

$$\mathcal{L} = \mathbf{w}_i^\top G_i \mathbf{w}_i - \lambda(\mathbf{1}^\top \mathbf{w}_i - 1)$$
$$\frac{\partial \mathcal{L}}{\partial \mathbf{w}_i} = 2 G_i \mathbf{w}_i - \lambda \mathbf{1} = 0 \implies \mathbf{w}_i = \frac{\lambda}{2} G_i^{-1} \mathbf{1}$$

Applying the constraint \(\mathbf{1}^\top \mathbf{w}_i = 1\) to find \(\lambda\):

$$\mathbf{w}_i^* = \frac{G_i^{-1} \mathbf{1}}{\mathbf{1}^\top G_i^{-1} \mathbf{1}}$$

This is the exact closed-form solution. Note: if \(G_i\) is singular (when \(k > D\) or neighbors are collinear), add regularization: \(G_i \leftarrow G_i + \epsilon I\).

Phase 2 Derivation: The Cost Matrix M

Expand \(\Phi(Y) = \sum_i \|y_i - \sum_j W_{ij} y_j\|^2\). Let \(Y \in \mathbb{R}^{N \times d}\). Then:

$$\Phi(Y) = \sum_i \|(I_i - W_i)Y\|^2 = \text{tr}(Y^\top (I-W)^\top (I-W) Y) = \text{tr}(Y^\top M Y)$$

where \(M_{ij} = \delta_{ij} - W_{ij} - W_{ji} + \sum_k W_{ki}W_{kj}\). The matrix \(M\) is symmetric, positive semi-definite, with the null vector \(\mathbf{1}\).

To avoid the trivial solution \(Y = 0\) and degenerate solutions, impose constraints: \(\frac{1}{N}Y^\top Y = I_d\) (unit covariance) and \(\sum_i y_i = 0\) (zero mean). The solution is the bottom \(d+1\) eigenvectors of \(M\), discarding the smallest (\(\lambda_1 = 0\)):

$$M v = \lambda v, \quad y_i^{(l)} = v_{\lambda_{l+1}}(i), \quad l = 1, \dots, d$$
Invariance Properties of the Weights

The optimal weights \(W_{ij}\) are invariant to: (1) rotation of the data, (2) global rescaling, (3) global translation. This is because the constraint \(\sum_j W_{ij} = 1\) makes the reconstruction affine-invariant. These invariances are exactly what you want for embedding: they ensure global geometry doesn't corrupt local relationships.

Comparisons, Trade-offs & When to Use
▾

LLE vs. Other Manifold Methods

Method Preserves Complexity Best For Weakness
LLE Local linear reconstruction O(N·k³ + N³) Smooth, well-sampled manifolds Sensitive to k, sparse graphs
Isomap Geodesic distances O(N²·k + N³) Convex manifolds Short-circuit paths, non-convex
t-SNE Local neighborhood structure O(N log N) Visualization (2D/3D) Global structure lost, non-parametric
UMAP Local + some global topology O(N log N) General visualization Hyperparameter sensitive
PCA Global variance (linear) O(N·D²) Linear structure, interpretability Fails on nonlinear manifolds
When to Use LLE

Use LLE when: the data lies on a smooth, well-sampled manifold; you care about local geometric structure; the manifold is not severely curved or noisy. Avoid when: data is sparse/noisy; you need out-of-sample extension; the manifold has holes or strong curvature (use Isomap or t-SNE instead).

Key Takeaways

LLE's elegance comes from reducing a nonlinear global problem into many small local linear regressions plus one sparse eigenproblem. The weight matrix \(W\) is the invariant "fingerprint" of local geometry. The embedding is unique (up to rotation/reflection) and globally consistent. Its main limitation — sensitivity to \(k\) and non-convex manifolds — led to variants like Modified LLE (MLLE) and HLLE (Hessian LLE) that add regularization and use higher-order local geometry.

From-Scratch Implementation
▾

LLE from scratch in NumPy — each step corresponds directly to the math above:

import numpy as np
from sklearn.neighbors import NearestNeighbors
def lle(X, n_components=2, k=12, reg=1e-3):
N, D = X.shape
# ── Phase 1: Find k nearest neighbors ──
nbrs = NearestNeighbors(n_neighbors=k+1).fit(X)
_, indices = nbrs.kneighbors(X) # (N, k+1); col 0 is self
indices = indices[:, 1:] # drop self-neighbor
# ── Phase 1: Compute reconstruction weights ──
W = np.zeros((N, N))
for i in range(N):
Z = X[indices[i]] - X[i] # (k, D): centered neighbors
G = Z @ Z.T # (k, k): local Gram matrix
G += reg * np.trace(G) * np.eye(k) # regularize
w = np.linalg.solve(G, np.ones(k)) # solve G w = 1
W[i, indices[i]] = w / w.sum() # normalize to sum=1
# ── Phase 2: Build cost matrix M = (I-W)^T (I-W) ──
IW = np.eye(N) - W
M = IW.T @ IW # (N, N), symmetric PSD
# ── Phase 2: Eigenproblem — bottom d+1 eigenvectors ──
eigvals, eigvecs = np.linalg.eigh(M) # sorted ascending
Y = eigvecs[:, 1:n_components+1] # skip λ₁≈0 (trivial)
return Y * np.sqrt(N) # scale by √N (sklearn convention)
Common Gotcha

The regularization reg * trace(G) is proportional to the data scale — this is better than a fixed \(\epsilon\) because it adapts to the local neighborhood size. Without regularization, \(G\) is often rank-deficient when \(k \ge D\), causing wildly incorrect weights.
