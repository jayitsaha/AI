Calibration in Multi-Class Settings

One-vs-Rest, Matrix/Vector/Temperature Scaling, Dirichlet Calibration & Classwise-ECE

Advanced Classical ML Calibration Complexity: O(K·B)
1

The Core Problem

A neural network trained with cross-entropy loss typically produces overconfident softmax outputs in the multi-class setting. Binary calibration methods (Platt scaling, isotonic regression) extend naturally to One-vs-Rest (OvR), but this ignores cross-class correlations — a key limitation when classes compete through a shared softmax denominator.

Two distinct calibration metrics expose different failure modes:

Confidence-ECE
Groups predictions by \(\hat{p}_{\max}\) (the predicted max probability). Checks whether the highest predicted probability matches empirical accuracy across all classes.
$$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{n} \left|\overline{\text{conf}}(B_m) - \overline{\text{acc}}(B_m)\right|$$
Classwise-ECE
For each class \(k\), groups by \(\hat{p}_k\) independently. Checks if \(\hat{p}_k \approx \text{freq}(k)\). Reveals miscalibration of minority classes hidden by confidence-ECE.
$$\text{cwECE} = \frac{1}{K}\sum_{k=1}^K \sum_{m=1}^M \frac{|B_{km}|}{n} |\text{conf}(B_{km}) - \text{acc}_k(B_{km})|$$
Key Insight: A model can have low confidence-ECE (well-calibrated on the dominant class) yet high classwise-ECE for minority classes. Classwise-ECE is strictly more informative.
2

Calibration Methods Hierarchy

Methods are ordered by expressiveness (and overfitting risk). All are fitted post-hoc on a held-out validation set using negative log-likelihood.

1 param
Temperature Scaling Scalar \(T > 0\) applied uniformly: \(W = \tfrac{1}{T}I\). Divides all logits by \(T\) — softens (T > 1) or sharpens (T < 1) the distribution uniformly. Cannot fix per-class miscalibration.
K params
Vector Scaling Per-class weights \(w_k\) and biases \(b_k\) applied element-wise: \(\hat{p} = \text{softmax}(w \odot z + b)\). Can correct different overconfidence levels per class. No cross-class interaction.
K² params
Matrix Scaling Full \(K \times K\) matrix \(W\) on logits: \(\hat{p} = \text{softmax}(Wz + b)\). Captures cross-class correlations. Risk of overfitting with small validation sets.
K² params
Dirichlet Calibration Works in log-probability space: \(\hat{p} = \text{softmax}(W \log p + b)\) where \(\log p = \text{log-softmax}(z)\). Naturally parameterizes a Dirichlet distribution over the simplex. Handles inter-class dependencies via log-probability correlations.
2K params
OvR Platt Scaling Per-class sigmoid: \(\sigma(a_k z_k + b_k)\), then renormalize. Simple but calibrated marginals may not compose to a valid joint. Works well when classes are nearly independent.
3

The Mathematics

All calibration methods transform raw logits \(z \in \mathbb{R}^K\) before the final softmax. Here \(K\) is the number of classes, \(T\) is temperature, \(W\) is a weight matrix, and \(b\) is a bias vector.

Standard Softmax
$$p_k = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}$$
Temperature Scaling
$$\hat{p}_k = \frac{e^{z_k/T}}{\sum_{j=1}^K e^{z_j/T}}$$
Vector Scaling (\(w, b \in \mathbb{R}^K\))
$$\hat{p}_k = \text{softmax}(w \odot z + b)_k$$
Matrix Scaling (\(W \in \mathbb{R}^{K \times K}\))
$$\hat{p} = \text{softmax}(Wz + b)$$
Dirichlet Calibration (\(\log p = \text{log-softmax}(z)\))
$$\hat{p} = \text{softmax}(W \log p + b)$$
Classwise-ECE
$$\text{cwECE} = \frac{1}{K}\sum_{k=1}^K \sum_{m=1}^M \frac{|B_{km}|}{n} |\text{conf}(B_{km}) - \text{acc}_k(B_{km})|$$
Confidence-ECE
$$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{n} \left|\overline{\text{conf}}(B_m) - \overline{\text{acc}}(B_m)\right|$$
4

OvR Per-Class Calibration

One-vs-Rest extends binary calibration to \(K\) classes. For each class \(k\), we treat the problem as binary (is this class \(k\)?) and apply Platt scaling independently:

$$\hat{q}_k = \sigma(a_k \cdot z_k + b_k)$$

The per-class calibrated probabilities are then renormalized to form a valid probability distribution:

$$\hat{p}_k = \frac{\hat{q}_k}{\sum_{j=1}^K \hat{q}_j} = \frac{\sigma(a_k z_k + b_k)}{\sum_j \sigma(a_j z_j + b_j)}$$

Parameters \((a_k, b_k)\) are fitted per class by minimizing binary cross-entropy on the validation set. This requires fitting \(K\) separate logistic regression models, each on the one-vs-rest labels.

Limitation: Each class is calibrated in isolation. The calibrated marginals \(\hat{q}_k\) do not naturally sum to 1, so renormalization is required. This can introduce distortion — particularly when class difficulties are unequal. The method ignores correlations between logits \(z_k\) across classes.

Use NLL loss on the validation set to fit \((a_k, b_k)\) for each class. A well-calibrated OvR model satisfies \(P(Y=k \mid \hat{p}_k = v) \approx v\) for each \(k\) separately.

When to Use Which Method

Method Parameters Cross-class Overfits small val Best for
Temperature Scaling 1 No Never Default choice; overconfident deep nets
Vector Scaling 2K No Rarely Classes with different confidence levels
Matrix Scaling K² + K Yes Often Large val set; strong cross-class correlations
Dirichlet K² + K Yes Often Log-probability space; Dirichlet-structured data
OvR Platt 2K No Rarely Near-independent classes; per-class ECE priority
Occam's Razor: Temperature scaling is the first thing to try. It has one parameter, never overfits, and often corrects >80% of calibration error from overconfident deep networks. Move to vector or matrix scaling only if classwise-ECE shows per-class discrepancies.

Step 6: Dirichlet Calibration
Dirichlet calibration operates in log-probability space. We first compute \(\log p = \text{log-softmax}(z)\), then apply a linear layer, then softmax. This parameterization respects the simplex geometry and naturally captures log-probability correlations between classes.
Step 1 — log-softmax(z):
log p₀ = log(0.8717) = −0.137
log p₁ = log(0.1067) = −2.238
log p₂ = log(0.0216) = −3.834

Result: \([{-0.137},\ {-2.238},\ {-3.834}]\) → same as starting probabilities at T=1

Evaluation
Step 7: Classwise-ECE vs Confidence-ECE
Two metrics evaluate calibration differently. Confidence-ECE uses one reliability diagram for max-probability predictions. Classwise-ECE builds a separate diagram per class. A model can look well-calibrated by confidence-ECE while being severely miscalibrated for minority classes.
Confidence-ECE (single diagram)
Classwise-ECE: Cat class
Classwise-ECE: Bird class (minority)
The Cat (dominant) class appears well-calibrated on its own diagram. The Bird (minority) class is severely miscalibrated — visible only via classwise-ECE. Confidence-ECE masks this because Bird predictions rarely "win" the max-probability competition.
$$\text{cwECE} = \frac{1}{K}\sum_{k=1}^K \text{ECE}_k \quad \text{vs} \quad \text{ECE} = \sum_m \frac{|B_m|}{n}|\overline{\text{conf}}(B_m) - \overline{\text{acc}}(B_m)|$$
