Understanding Random Graph Models
▼

What is this? Real networks — the internet, social circles, protein interactions, neural connectomes — are neither perfectly regular (where every node has the same connections) nor purely random. Three probabilistic models capture different structural regimes: Erdős–Rényi (binomial randomness), Barabási–Albert (rich-get-richer hubs), and Watts–Strogatz (high clustering + short paths).

Analogy: Think of building a city's road system. ER is like a planner who flips a coin to decide whether each pair of intersections gets a direct road — perfectly democratic but unrealistic. BA is like organic growth where new roads always connect to already-busy intersections (highways join airports, not cornfields). WS is like a neighborhood where you know your neighbors well (clustering) but a few long-distance shortcuts (rewired edges) let you reach anyone in the city in just a few hops.

💡 If you remember one thing

ER gives Poisson degree distributions and a sharp phase transition to a giant connected component at \(p = 1/n\); BA gives power-law degree distributions \(P(k) \sim k^{-3}\) via preferential attachment; WS interpolates between high clustering and short path length — capturing the "small-world" property observed in most real networks.

2
How Each Model Generates Networks
▼

Erdős–Rényi \(G(n,p)\)

Start with \(n\) isolated nodes. For every pair \((i,j)\), add edge \(i\!-\!j\) independently with probability \(p\). The number of edges is binomial with mean \(\binom{n}{2}p\). Each node's degree \(d_i \sim \text{Bin}(n-1, p)\), which converges to \(\text{Poisson}((n-1)p)\) as \(n \to \infty\) with \((n-1)p = \lambda\) fixed. The critical insight is the phase transition: set \(p = c/n\). For \(c < 1\), all components are tiny (order \(\log n\)). At \(c = 1\), a giant component of order \(n^{2/3}\) emerges. For \(c > 1\), a unique giant component of fraction \(S\) of all nodes appears, where \(S\) satisfies the implicit equation \(S = 1 - e^{-cS}\).

Barabási–Albert Preferential Attachment

Start with a small seed graph (\(m_0\) nodes, fully connected). At each time step, add one new node with \(m\) edges. Each edge connects to an existing node \(i\) with probability proportional to its current degree \(k_i\): \(\Pi(i) = k_i / \sum_j k_j\). This "rich get richer" rule generates a stationary power-law degree distribution \(P(k) \sim k^{-3}\) regardless of \(m\). Nodes added early accumulate many edges (hubs); late arrivals stay small. The exponent \(-3\) is universal for this attachment rule.

Watts–Strogatz Small-World

Start with a ring lattice of \(n\) nodes each connected to \(k\) nearest neighbors (\(k/2\) on each side). With probability \(\beta\), rewire each edge to a random target (avoiding self-loops and duplicates). At \(\beta = 0\): regular ring (high clustering, long paths). At \(\beta = 1\): Erdős–Rényi-like random graph (low clustering, short paths). The remarkable small-world regime at intermediate \(\beta\) (\(0.01 \lesssim \beta \lesssim 0.1\)) preserves high clustering \(C \approx C_0\) while collapsing path length to \(L \approx L_{\text{random}}\).

🔑 Key Structural Properties

Three defining metrics distinguish the models: (1) Degree distribution \(P(k)\) — Poisson (ER), power-law (BA), Binomial/Poisson (WS). (2) Clustering coefficient \(C = \frac{\text{closed triangles}}{\text{all triples}}\) — low in ER, low in BA, high in WS. (3) Average path length \(L\) — \(O(\ln n / \ln \langle k \rangle)\) in ER and BA, \(O(n/k)\) in regular ring but \(O(\ln n)\) in WS with small \(\beta\).

3
The Mathematics
▼

ER Phase Transition

For \(G(n, c/n)\), define \(S\) as the fraction of nodes in the giant component. By a branching-process argument, \(S\) satisfies:

$$S = 1 - e^{-cS}, \quad c = (n-1)p$$

This has no positive solution for \(c \leq 1\) (subcritical). For \(c > 1\), the unique positive root gives the giant component size. For example: \(c=2 \Rightarrow S \approx 0.797\), \(c=3 \Rightarrow S \approx 0.941\). Near the critical point, \(S \approx 2(c-1)/c^2\) for \(c \to 1^+\).

BA Power-Law Degree Distribution

Let \(P(k,t)\) be the fraction of nodes with degree \(k\) at time \(t\). The master equation (mean-field) for the degree distribution is:

$$\frac{\partial (t \cdot P(k,t))}{\partial t} = m \cdot \frac{(k-1)P(k-1,t) - kP(k,t)}{2t} + \delta_{k,m}$$

At stationarity (\(P(k,t) \to P(k)\) as \(t \to \infty\)), this gives:

$$P(k) = \frac{2m(m+1)}{k(k+1)(k+2)} \approx \frac{2m^2}{k^3} \text{ for large } k$$

The exponent is exactly \(\gamma = 3\) for any \(m \geq 1\). Hubs of degree \(k_{\max} \approx \sqrt{n}\) appear.

Watts–Strogatz Clustering

For the ring lattice (\(\beta = 0\)) with each node connected to \(k\) nearest neighbors, the clustering coefficient is:

$$C_0 = \frac{3(k/2 - 1)}{2(k - 1)} \xrightarrow{k \gg 1} \frac{3}{4}$$

After rewiring with probability \(\beta\), clustering decays as \(C(\beta) \approx C_0 \cdot f(\beta)\) where \(f(\beta) \approx (1 - \beta)^3\). Average path length transitions from \(L_{\text{ring}} \approx n/(2k)\) at \(\beta = 0\) to \(L_{\text{random}} \approx \ln(n)/\ln(k)\) at \(\beta = 1\). The key feature: \(L\) drops much faster than \(C\) as \(\beta\) increases — the small-world window.

⚠️ Common Pitfalls

The ER phase transition is at \(p = 1/n\) (\(c=1\)), NOT \(p = 1/2\) or any other value. The BA exponent \(\gamma=3\) is only exact for the linear preferential attachment rule; non-linear rules change the exponent. The WS model does NOT generate a power-law degree distribution — that confusion is common. Finally, "small-world" refers to short paths AND high clustering simultaneously — short paths alone (ER) are not small-world.

Key Takeaways & Comparisons
▼

When to use each model:

  • ER — null model / baseline; studying percolation, epidemics, random connectivity. Use when you want maximum-entropy random graphs with no structural bias.
  • BA — modeling the internet, citation networks, protein-protein interactions, social follower graphs. Use when hub structure and power-law degrees are expected.
  • WS — neural networks, power grids, collaboration networks. Use when you need high transitivity (friend-of-a-friend is often a friend) AND short paths simultaneously.
💡 Hierarchy of Realism

ER (pure random, Poisson degrees) → WS (adds clustering, no hubs) → BA (adds power-law hubs, no clustering mechanism). Real networks often combine features of WS (clustering) AND BA (power-law), motivating hybrid models like the Holme–Kim or Configuration Model.

Code Trace
▼
import networkx as nx, numpy as np
# 1. Erdős–Rényi G(n,p) — phase transition
n = 500
G_sub = nx.erdos_renyi_graph(n, p=0.5/n) # subcritical
G_crit = nx.erdos_renyi_graph(n, p=1.0/n) # critical
G_sup = nx.erdos_renyi_graph(n, p=3.0/n) # supercritical
print(max(len(c) for c in nx.connected_components(G_sup))/n) # ≈ 0.94
# 2. Barabási–Albert preferential attachment
G_ba = nx.barabasi_albert_graph(n, m=2) # m=2 edges per new node
degrees = sorted([d for _, d in G_ba.degree()], reverse=True)
print(degrees[:5]) # hubs: top degrees
# Verify power-law: loglog slope ≈ -3
from collections import Counter
deg_count = Counter(degrees)
# 3. Watts–Strogatz small-world
G_ws = nx.watts_strogatz_graph(n, k=6, p=0.05) # 6 neighbors, 5% rewire
C = nx.average_clustering(G_ws)
L = nx.average_shortest_path_length(G_ws)
print(f"C={C:.3f}, L={L:.3f}") # high C, low L
# Compare: ER with same avg degree k=6
G_er = nx.erdos_renyi_graph(n, p=6/(n-1))
print(f"ER: C={nx.average_clustering(G_er):.3f}") # ≈ k/n ≪ WS
