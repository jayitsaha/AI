1
Understanding Catastrophic Forgetting
▼

What is it? Catastrophic Forgetting is a fundamental problem in neural networks: when a model is sequentially trained on new tasks, its performance on previously learned tasks rapidly degrades. This prevents models from learning continuously like humans do, where new knowledge is integrated without erasing old skills.

Analogy: Imagine a chef who learns to bake a complex cake (Task A). Then, they learn to prepare an elaborate sushi platter (Task B). If they completely forget how to bake the cake after mastering sushi, that's catastrophic forgetting. Continual learning methods aim to teach the chef sushi without making them forget cake, perhaps by reminding them of important cake-baking steps while learning sushi, or by making them aware of which skills are critical for cake-baking and trying not to alter those too much.

💡 If you remember one thing

Continual Learning (Lifelong Learning) aims to overcome catastrophic forgetting by enabling models to learn new tasks sequentially while retaining performance on previous ones. EWC, SI, and LwF are three prominent regularization-based strategies that achieve this by either protecting important weights or distilling old knowledge.

2
How These Methods Work
▼

The Common Goal: Stabilize Past Knowledge

All three methods tackle catastrophic forgetting by adding a regularization term to the standard loss function when learning a new task (Task B). This term discourages the model from drastically changing parameters that were important for previous tasks (Task A). The key difference lies in *how* importance is defined and *what* knowledge is being preserved.

Elastic Weight Consolidation (EWC)

Inspired by neuroscience, EWC (Kirkpatrick et al., 2017) treats important weights for Task A as "elastic springs" that resist moving too far from their Task A optimal values. The stiffness of each spring is determined by its Fisher Information, which measures how sensitive the Task A loss was to small changes in that weight. High Fisher values mean the weight is crucial and should be protected; low values mean it can change more freely.

Synaptic Intelligence (SI)

SI (Zenke et al., 2017) is an online, local alternative to EWC. Instead of computing Fisher Information (which requires access to Task A data or a separate pass), SI tracks the "path integral" of a weight's contribution to the loss change during Task A training. Essentially, it accumulates a measure of how much a weight *moved* and *contributed* to the loss reduction for Task A. Weights that moved a lot and significantly reduced the loss are deemed important.

Learning without Forgetting (LwF)

LwF (Li & Hoiem, 2017) takes a different approach: knowledge distillation. When training on Task B, it simultaneously tries to maintain the *output behavior* (logits or probabilities) of the model on Task A. This is done by using a distillation loss, where the current model's predictions for Task A inputs are encouraged to match the predictions of the model *before* Task B training. This doesn't directly protect weights, but indirectly preserves the model's function for old tasks.

🔑 Key Property

EWC and SI are parameter regularization methods: they add a penalty to the loss that depends on how much individual weights deviate from their previous optimal values, weighted by importance. LwF is an output regularization (distillation-based) method: it adds a penalty that depends on how much the model's output for old tasks changes.

3
Why It Works — The Math
▼

The General Continual Learning Objective

When learning a new task B, the goal is to minimize the loss \(L_B(\theta)\) for Task B, while also keeping the loss for previous Task A, \(L_A(\theta)\), small. This is often framed as minimizing:

$$\mathcal{L}(\theta) = L_B(\theta) + \lambda \mathcal{R}(\theta, \theta_A^*)$$

where \(\theta\) are the current model parameters, \(\theta_A^*\) are the parameters after training on Task A, \(\lambda\) is a hyperparameter controlling the regularization strength, and \(\mathcal{R}(\cdot)\) is the task-specific regularization term.

EWC: Fisher Information as Importance

EWC approximates the importance of each parameter \(\theta_i\) by its diagonal Fisher Information \(F_i\), computed after training on Task A. The regularization term is then a quadratic penalty:

$$\mathcal{R}_{EWC}(\theta, \theta_A^*) = \sum_i \frac{1}{2} F_i (\theta_i - \theta_{A,i}^*)^2$$

The total loss for Task B becomes: $$ \mathcal{L}_{EWC}(\theta) = L_B(\theta) + \sum_i \frac{\lambda}{2} F_i (\theta_i - \theta_{A,i}^*)^2 $$ This penalizes changes to \(\theta_i\) proportionally to \(F_i\). The Fisher Information is defined as \(F_i = \mathbb{E}_{x \sim D_A} \left[ \left( \frac{\partial \log p(y|x, \theta)}{\partial \theta_i} \right)^2 \right]\).

SI: Path Integral of Synaptic Importance

SI uses an online estimate of importance \(\omega_i\). When training on Task A, for each weight \(\theta_i\), it accumulates a measure of how much it changed and contributed to the loss. A simplified view of the accumulated importance for Task A is:

$$\omega_i = \sum_{t \in \text{Task A updates}} \frac{g_i^2}{(\Delta \theta_i^t)^2 + \epsilon}$$

where \(g_i\) is the gradient and \(\Delta \theta_i^t\) is the parameter change at step \(t\). The regularization term for Task B is then similar to EWC:

$$\mathcal{L}_{SI}(\theta) = L_B(\theta) + \sum_i \frac{\lambda}{2} \omega_i (\theta_i - \theta_{A,i}^*)^2$$

This allows for a local, online computation of importance, avoiding a separate Fisher pass.

LwF: Knowledge Distillation

LwF adds a distillation loss. Let \(f_A(\cdot, \theta_A^*)\) be the model trained on Task A, and \(f(\cdot, \theta)\) be the current model being trained on Task B. For a given input \(x\), \(f_A(x, \theta_A^*)\) produces logits \(z_A\), and \(f(x, \theta)\) produces logits \(z\). The distillation loss encourages \(z\) to be close to \(z_A\) for Task A examples:

$$\mathcal{L}_{distill}(\theta) = \sum_{x \sim D_A} \text{KL}( \text{softmax}(z_A/T) \parallel \text{softmax}(z/T) )$$

where KL is Kullback-Leibler divergence and \(T\) is a temperature parameter. The total loss for Task B is: $$ \mathcal{L}_{LwF}(\theta) = L_B(\theta) + \lambda \mathcal{L}_{distill}(\theta) $$ This preserves the *functional behavior* of the old model, rather than specific weights.

⚠️ Common Pitfall

The choice of \(\lambda\) (regularization strength) is critical. Too low, and forgetting still occurs. Too high, and the model struggles to learn the new task, leading to "backward transfer" (negative impact on new task performance). Finding the right balance is often problem-specific and requires careful hyperparameter tuning.

Key Takeaways
▼

When to use EWC, SI, or LwF:

  • When your model needs to learn new tasks sequentially without access to old task data (or only limited access).
  • In scenarios where a single model must maintain proficiency across a growing set of skills or domains (e.g., robotics, personal assistants).
  • As a baseline for more complex continual learning strategies, or when computational resources for replay/memory-based methods are limited.

Limitations and Considerations:

  • **Scalability:** EWC and SI require storing importance weights for each parameter for each task, which can grow with the number of tasks.
  • **Hyperparameter tuning:** The regularization strength \(\lambda\) is crucial and often task-dependent.
  • **Task Similarity:** These methods work best when tasks are somewhat related or share common features. For very dissimilar tasks, preventing forgetting might severely hinder new task learning.
  • **Performance vs. Forgetting Trade-off:** There's always a trade-off. Extreme regularization might prevent new learning, while too little will still lead to forgetting.
💡 Beyond Regularization

While EWC, SI, and LwF are regularization-based, other continual learning approaches exist: Replay-based methods store and re-train on a small subset of old data; Architecture-based methods dynamically expand the model for new tasks; and Meta-Learning approaches train models to learn how to learn sequentially.
