1
Understanding Bits-Back Coding
▼

What is it? Bits-back coding is a clever trick that lets you use a latent-variable generative model (like a VAE) as a lossless data compressor. Normally, latent variables seem like overhead — you have to communicate them to the decoder. Bits-back coding shows that you can recover those bits for free by drawing the latent from the posterior rather than some fixed code.

Analogy: Suppose you and a friend share a secret codebook (the generative model). To compress a message \(x\), you don't just describe \(x\) directly — instead you think: "which scenario \(z\) most naturally explains \(x\)?" You transmit \(z\) (cheaply, under the prior) and then \(x\) given \(z\) (cheaply, under the likelihood). But you also "get back" the bits you used to choose \(z\) from your private coin flips, because your friend can figure out those same coin flips from the received message. That "getting back" is the bits-back.

💡 If you remember one thing

The net bits per datum in bits-back coding equals the negative ELBO: $$\text{bits}(x) = -\frac{\mathcal{L}(x)}{\ln 2} = \frac{1}{\ln 2}\bigl[\underbrace{D_{\mathrm{KL}}(q_\phi(z|x)\,\|\,p(z))}_{\text{overhead}} - \underbrace{\mathbb{E}_{q_\phi}[\ln p_\theta(x|z)]}_{\text{savings}}\bigr]$$ A better density model \(\Rightarrow\) higher ELBO \(\Rightarrow\) fewer bits.

2
The BB-ANS Cycle — How It Works Internally
▼

Arithmetic / ANS Coding Background

Modern lossless compressors use Asymmetric Numeral Systems (ANS), which maintains a single large integer (the "ANS state") that encodes a stack of symbols. Each push of symbol \(s\) under distribution \(P\) increases the state size by \(-\log_2 P(s)\) bits. Each pop recovers \(-\log_2 P(s)\) bits. Bits-back coding exploits this reversibility.

The Three-Phase BB-ANS Encode Cycle

To encode datum \(x\) with latent-variable model \(p(z)\,p_\theta(x|z)\) and inference network \(q_\phi(z|x)\):

  • Phase 1 — Bits-Back Pop: Pop \(z \sim q_\phi(z|x)\) from the ANS tail using the posterior as the decode distribution. This removes \(-\log_2 q_\phi(z|x)\) bits from the state (bits received).
  • Phase 2 — Encode x|z: Push \(x\) under \(p_\theta(x|z)\). Adds \(-\log_2 p_\theta(x|z)\) bits.
  • Phase 3 — Encode z: Push \(z\) under prior \(p(z)\). Adds \(-\log_2 p(z)\) bits.

Net bits added to the ANS state for this datum:

$$\Delta\text{bits}(x,z) = \underbrace{-\log_2 p_\theta(x|z)}_{\text{push }x|z} \underbrace{-\log_2 p(z)}_{\text{push }z} \underbrace{+\log_2 q_\phi(z|x)}_{\text{pop z (bits back)}}$$

Taking the expectation over \(z\sim q_\phi(z|x)\):

$$\mathbb{E}_{q}[\Delta\text{bits}] = \mathbb{E}_q[-\log_2 p(x,z) + \log_2 q(z|x)] = -\frac{\mathcal{L}(x)}{\ln 2}$$

Decoding (Reverse Cycle)

Decoding runs the three phases in reverse: pop \(z\) under \(p(z)\), pop \(x\) under \(p_\theta(x|z)\), then push noise bits under \(q_\phi(z|x)\) to restore the ANS state. This perfectly inverts encoding.

🔑 Key Property

BB-ANS is lossless: after encoding all \(n\) data points, the ANS state can be decoded back to exactly the original sequence. The net compression ratio approaches the ELBO as \(n \to \infty\). The expected bits-back gain per datum equals \(\mathbb{E}_q[-\log_2 q_\phi(z|x)]\), the entropy of the posterior.

⚠️ Initial Bits Requirement

To pop \(z \sim q_\phi(z|x)\) in Phase 1, the ANS state must already contain at least \(-\log_2 q_\phi(z|x)\) bits. This means you need an initial "seed" of random bits before encoding the first datum. For large \(n\), this overhead is amortized and negligible.

3
The Math — ELBO as Compression Bound
▼

The ELBO Decomposition

The Evidence Lower BOund (ELBO) for latent-variable model \(p_\theta(x) = \int p(z)p_\theta(x|z)\,dz\) is:

$$\mathcal{L}(x;\,\phi,\theta) = \underbrace{\mathbb{E}_{q_\phi(z|x)}[\ln p_\theta(x|z)]}_{\text{reconstruction term}} - \underbrace{D_{\mathrm{KL}}\!\bigl(q_\phi(z|x)\,\big\|\,p(z)\bigr)}_{\text{KL penalty}}$$

This equals \(\ln p_\theta(x) - D_{\mathrm{KL}}(q_\phi(z|x)\,\|\,p_\theta(z|x))\), so \(\mathcal{L}(x) \le \ln p_\theta(x)\). Equality holds when \(q_\phi = p_\theta(\cdot|x)\) exactly.

Compression Interpretation

Shannon's source coding theorem says lossless compression of \(x\) drawn from \(P_{\text{data}}\) requires at least \(H(P_{\text{data}})\) bits per symbol. Under model \(p_\theta\), the cross-entropy cost is:

$$H(P_{\text{data}}, p_\theta) = \mathbb{E}_{x \sim P_{\text{data}}}\!\left[-\log_2 p_\theta(x)\right] = H(P_{\text{data}}) + D_{\mathrm{KL}}(P_{\text{data}}\,\|\,p_\theta)$$

Since \(-\log_2 p_\theta(x) \ge -\mathcal{L}(x)/\ln 2\), bits-back coding achieves:

$$\text{bits/datum} = \underbrace{-\frac{\mathcal{L}(x)}{\ln 2}}_{\text{ELBO bound}} \xrightarrow{q_\phi\to p_\theta(\cdot|x)} -\log_2 p_\theta(x)$$

Why Better Models = Better Compressors

The ELBO is a lower bound to \(\ln p_\theta(x)\). Both increase as the model improves. Specifically:

  • Higher \(\mathbb{E}[\ln p_\theta(x|z)]\) ⟹ better reconstruction ⟹ fewer bits for \(x|z\).
  • Tighter posterior \(q_\phi \approx p_\theta(\cdot|x)\) ⟹ \(\mathcal{L}\to\ln p_\theta(x)\) ⟹ fewer wasted bits.
  • Stronger prior \(p(z)\) (e.g., learned flow prior) ⟹ lower KL ⟹ cheaper to transmit \(z\).
📐 Numerical Example

Bernoulli \(x=1\), \(p(z)=\mathcal{N}(0,1)\), \(q_\phi(z|x)=\mathcal{N}(0.5,\,0.64)\), \(p_\theta(x|z)=\sigma(z)\).
\(\bullet\) KL \(=0.168\) nats \(=0.243\) bits   (overhead)
\(\bullet\) \(\mathbb{E}[\ln p(x|z)] \approx -0.474\) nats \(= -0.684\) bits   (reconstruction)
\(\bullet\) ELBO \(= -0.642\) nats   \(\Rightarrow\) net \(\mathbf{0.927}\) bits/datum

⚠️ Common Misconception

Bits-back coding is not lossy compression. The latent \(z\) is fully transmitted (under prior \(p(z)\)). The "bits back" refers only to the bits used to select which \(z\) to use, which are recovered from the ANS tail — the decoder sees the same \(z\) and reconstructs \(x\) exactly (for discrete \(x\)).

Key Takeaways & Comparison
▼

When bits-back coding applies:

  • You have a trained latent-variable model (VAE, flow-VAE, VQ-VAE, diffusion with encoder).
  • You need lossless compression and the model is a good fit to the data distribution.
  • Data volume is large enough to amortize the initial seed bits overhead.

Comparison of compression methods:

Huffman / gzipHistogram / LZ77~8 (natural images)YesNo latent structure

💡 The ML-Compression Duality

Every lossless compressor defines an implicit probability model over data (via the Kraft inequality). Every density estimator defines a lossless compressor. Minimizing bits/datum \(\equiv\) maximizing log-likelihood. The ELBO is simultaneously a training objective for VAEs and a compression rate guarantee for bits-back coding.

Code Trace
▼
import numpy as np, math
# Model parameters (trained VAE-like setup)
mu_q, sigma2_q = 0.5, 0.64 # posterior q(z|x) = N(0.5, 0.64)
x = 1 # Bernoulli observation
# Sample z ~ q(z|x) [in ANS: pop z using q as decode dist]
z = np.random.normal(mu_q, np.sqrt(sigma2_q))
log_q_z = -0.5*((z-mu_q)**2/sigma2_q) - 0.5*math.log(2*math.pi*sigma2_q)
bits_back = -log_q_z / math.log(2) # bits recovered from tail
# Cost to encode x under p(x|z) [in ANS: push x under likelihood]
sigmoid = lambda z: 1/(1+math.exp(-z))
log_p_xz = math.log(sigmoid(z)) if x==1 else math.log(1-sigmoid(z))
cost_xz = -log_p_xz / math.log(2) # bits spent
# Cost to encode z under prior p(z)=N(0,1) [in ANS: push z under prior]
log_p_z = -0.5*z**2 - 0.5*math.log(2*math.pi)
cost_z = -log_p_z / math.log(2) # bits spent
# Net bits = cost_xz + cost_z - bits_back = -ELBO/log2
net_bits = cost_xz + cost_z - bits_back
# Cross-check: compute ELBO directly
kl = 0.5*(sigma2_q + mu_q**2 - 1 - math.log(sigma2_q))
recon = math.log(sigmoid(mu_q)) # E_q[log p(x|z)] approx at mean
elbo = recon - kl
print(f"Net bits (sample): {net_bits:.3f}")
print(f"-ELBO/log2 (expected): {-elbo/math.log(2):.3f}")
# >> Net bits (sample): ~1.1 (varies by z sample)
# >> -ELBO/log2 (expected): 0.927
