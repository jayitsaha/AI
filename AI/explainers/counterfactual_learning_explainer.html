Understanding Counterfactual Learning
▼

What is it? Counterfactual learning is about answering "what if?" questions. Given a set of observed actions (treatments) and their outcomes, it aims to estimate what the outcome *would have been* if a different action had been taken. This is crucial when we only have observational data, not randomized controlled trials, and we want to understand the true causal effect of an action (e.g., an ad, a medical treatment, a policy change).

Analogy: Imagine you're a marketing manager. You run an ad campaign (Treatment A=1) but only show it to younger, tech-savvy users (Covariate X). Older users (Covariate X) don't see the ad (Treatment A=0). You observe that users who saw the ad (A=1) clicked more (Outcome Y). Is this because the ad is effective, or because younger, tech-savvy users click more regardless of the ad? Counterfactual learning tries to disentangle this by asking: "What would the click rate have been for older users *if they had seen the ad*?"

💡 If you remember one thing

Counterfactual learning addresses selection bias in observational data. When treatment assignment isn't random (e.g., doctors recommend treatment to sicker patients), simply comparing outcomes between treated and untreated groups gives a biased estimate of the treatment's true effect. Methods like Inverse Propensity Weighting (IPW) re-weight observations to simulate a randomized experiment.

How It Works: Inverse Propensity Weighting (IPW)
▼

The Problem: Selection Bias

In a randomized controlled trial (RCT), treatment assignment is independent of covariates \(X\). Thus, comparing outcomes of treated (\(A=1\)) and control (\(A=0\)) groups directly gives an unbiased estimate of the Average Treatment Effect (ATE). In observational data, however, treatment assignment \(A\) is often correlated with covariates \(X\). For example, a loan officer might only offer loans (treatment) to customers with good credit scores (covariate). If we then compare repayment rates, we'd wrongly conclude the "loan offer" itself causes good repayment, when it's really the underlying credit score.

The Solution: Propensity Scores

The core idea of IPW is to re-weight the observed data so that the treated and control groups become comparable with respect to their covariates. This is achieved using the propensity score, defined as the probability of receiving a particular treatment given the observed covariates:

$$e(X) = P(A=1 \mid X)$$

This score is typically estimated using a logistic regression or a more sophisticated machine learning model, where \(X\) are features and \(A\) is the target variable. A high propensity score means a unit was very likely to receive treatment; a low score means it was unlikely.

Inverse Propensity Weighting (IPW)

Once we have the propensity scores, we assign a weight to each observation. For a treated unit (\(A=1\)), its weight is \(1/e(X)\). For an untreated unit (\(A=0\)), its weight is \(1/(1-e(X))\). The intuition:

  • Units that received treatment (\(A=1\)) but were *unlikely* to receive it (low \(e(X)\)) get a *high* weight. They are "surprising" treated units, helping us understand what would happen if more units like them were treated.
  • Units that did *not* receive treatment (\(A=0\)) but were *likely* to receive it (high \(e(X)\)) also get a *high* weight. They are "surprising" control units, helping us understand what would happen if more units like them were *not* treated.

These weights balance the covariate distributions between the treated and control groups, effectively creating a synthetic randomized experiment where direct comparison of outcomes becomes unbiased.

🔑 Key Property

IPW relies on two crucial assumptions: Conditional Independence (or Unconfoundedness), meaning all confounders (covariates affecting both treatment and outcome) are observed and included in \(X\); and Overlap, meaning \(0 < e(X) < 1\) for all \(X\), so there's a non-zero probability of observing both treatment and control for every covariate combination.

3
Why It Works: The Math Behind IPW
▼

Defining the Average Treatment Effect (ATE)

The goal is to estimate the Average Treatment Effect (ATE), which is the expected difference in outcomes if everyone received treatment versus if everyone received no treatment:

$$\text{ATE} = \mathbb{E}[Y(A=1) - Y(A=0)]$$

where \(Y(A=1)\) and \(Y(A=0)\) are the potential outcomes under treatment and control, respectively. We only observe one of these for each individual.

The IPW Estimator for ATE

The IPW estimator for the ATE is constructed by taking the weighted average of outcomes for the treated and control groups. For a dataset with \(N\) observations, this can be written as:

Inside the inner expectation, we use the definition of conditional expectation \(\mathbb{E}[A Y \mid X] = \sum_a \sum_y (ay) P(A=a, Y=y \mid X)\). Since \(A\) is binary and \(Y\) is observed only for the assigned \(A\), we have \(A Y = A Y(A)\). Given \(X\), \(A\) is either 0 or 1. If \(A=1\), the term is \(Y(A=1)/e(X)\). If \(A=0\), it's 0. So, $$\mathbb{E}\left[\frac{A Y}{e(X)} \mid X\right] = \frac{1 \cdot Y(A=1) \cdot P(A=1 \mid X)}{e(X)} + \frac{0 \cdot Y(A=0) \cdot P(A=0 \mid X)}{e(X)}$$ Since \(P(A=1 \mid X) = e(X)\), this simplifies to: $$\mathbb{E}\left[\frac{A Y}{e(X)} \mid X\right] = \frac{Y(A=1) \cdot e(X)}{e(X)} = Y(A=1)$$ Taking the outer expectation, we get \(\mathbb{E}[Y(A=1)]\). A similar derivation holds for the control term. Thus, the IPW estimator provides an unbiased estimate of the ATE under the unconfoundedness and overlap assumptions.

⚠️ Common Pitfall

Extreme propensity scores: If \(e(X)\) is very close to 0 or 1 for some observations, the IPW weights \(1/e(X)\) or \(1/(1-e(X))\) can become extremely large. This leads to high variance in the ATE estimate. Truncating extreme weights or using more robust estimators (like Augmented IPW, A-IPW) can mitigate this, but it often signals a violation of the overlap assumption.

Key Takeaways
▼

When to use Counterfactual Learning / IPW:

  • You have observational data (not an RCT) and suspect selection bias.
  • You want to estimate the causal effect of a treatment or intervention.
  • You have measured all relevant confounders (covariates that affect both treatment assignment and outcome).
  • There is sufficient overlap: for most covariate values, both treated and control units are observed.

When NOT to use / Limitations:

  • Unmeasured Confounders: If important confounders are not observed, IPW cannot correct for the bias they introduce (violates unconfoundedness). This is the biggest Achilles' heel of observational causal inference.
  • Lack of Overlap: If some \(X\) values only appear in the treated group (or only in the control group), propensity scores will be near 0 or 1, leading to extreme weights and high variance.
  • Model Misspecification: If the propensity score model \(e(X)\) is poorly specified (e.g., using linear regression when the relationship is nonlinear), the weights will be inaccurate, and the bias will persist.
💡 Beyond IPW

IPW is one of many methods in counterfactual learning. Others include: Matching (pairing similar treated and control units), Regression Adjustment (modeling outcomes directly), and Doubly Robust Estimators (which combine IPW and regression adjustment, being consistent if *either* the propensity score model *or* the outcome model is correctly specified, hence "doubly robust"). Modern approaches often leverage deep learning for more flexible modeling of propensity scores and outcome functions.

Code Trace (Python)

import numpy as np
from sklearn.linear_model import LogisticRegression
# 1. Generate synthetic data with selection bias
def generate_data(N=200, bias_strength=1.5, true_effect=0.5):
X = np.random.uniform(0, 10, N) # Covariate (e.g., age)
# Selection bias: higher X -> more likely to get treatment A=1
prop_A_given_X = 1 / (1 + np.exp(-bias_strength * (X - 5)))
A = (np.random.rand(N) < prop_A_given_X).astype(int) # Treatment (0 or 1)
# Outcome Y depends on X and A, with some noise
Y = 0.5 * X + true_effect * A + np.random.normal(0, 0.5, N)
return X, A, Y, prop_A_given_X # prop_A_given_X is the true propensity
X, A, Y, true_propensity = generate_data()
# 2. Naive ATE (biased)
naive_mean_treated = Y[A == 1].mean()
naive_mean_control = Y[A == 0].mean()
naive_ate = naive_mean_treated - naive_mean_control
# 3. Estimate Propensity Scores e(X)
# Use Logistic Regression to predict A from X
propensity_model = LogisticRegression(solver='liblinear')
propensity_model.fit(X.reshape(-1, 1), A)
e_X = propensity_model.predict_proba(X.reshape(-1, 1))[:, 1]
# Ensure propensity scores are not too close to 0 or 1 (for stability)
e_X = np.clip(e_X, 0.05, 0.95)
# 4. Calculate IPW weights
weights = np.zeros_like(A, dtype=float)
weights[A == 1] = 1 / e_X[A == 1]
weights[A == 0] = 1 / (1 - e_X[A == 0])
# 5. IPW-corrected ATE
# Weighted sum of outcomes for treated group
weighted_sum_treated = np.sum(Y[A == 1] * weights[A == 1])
weighted_sum_weights_treated = np.sum(weights[A == 1])
ipw_mean_treated = weighted_sum_treated / weighted_sum_weights_treated
# Weighted sum of outcomes for control group
weighted_sum_control = np.sum(Y[A == 0] * weights[A == 0])
weighted_sum_weights_control = np.sum(weights[A == 0])
ipw_mean_control = weighted_sum_control / weighted_sum_weights_control
ipw_ate = ipw_mean_treated - ipw_mean_control
print(f"Naive ATE: {naive_ate:.2f}")
print(f"IPW ATE: {ipw_ate:.2f}")
