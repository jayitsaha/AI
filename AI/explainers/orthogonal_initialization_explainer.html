Orthogonal Initialization

Initializing weights as isometries — so deep and recurrent networks neither explode nor vanish
Advanced Deep Learning Initialization O(n³) via QR
1
Understanding Orthogonal Initialization
▼

What is it? When you initialize a neural network's weight matrix, you have to pick some starting numbers. The obvious choice — independent random Gaussian entries — has a hidden flaw: multiplying by it doesn't just rotate and shuffle your data, it also stretches it unevenly in different directions. Orthogonal initialization instead sets the weight matrix \(W\) so that \(W^\top W = I\): a matrix that only rotates/reflects and never stretches. Every vector keeps exactly the same length after multiplication.

Analogy: Think of passing a photograph through a stack of mirrors versus a stack of funhouse-mirror lenses. A flat mirror (orthogonal transform) reflects the image perfectly — same size, same proportions, just flipped or rotated. A funhouse lens (random matrix) stretches some parts and squashes others. Pass the photo through ten flat mirrors and it still looks identical. Pass it through ten funhouse lenses and it becomes an unrecognizable smear — some regions blown up to infinity, others crushed to a point. That's exactly what happens to activations and gradients in a 50-layer network.

💡 If you remember one thing

An orthogonal matrix is an isometry — it preserves vector norms and angles exactly: \(\|Qx\| = \|x\|\) for every \(x\). Random Gaussian matrices only preserve norm on average; individual directions get stretched or crushed, and that distortion compounds multiplicatively with every extra layer.

How It Works Internally
▼

Step 1 — Sample a random matrix

Draw \(A \in \mathbb{R}^{n\times n}\) with i.i.d. entries \(A_{ij} \sim \mathcal{N}(0,1)\). This is the same starting point as ordinary random init — the difference is what we do with it next.

Step 2 — Orthogonalize via QR decomposition

Factor \(A = QR\), where \(Q\) has orthonormal columns (\(Q^\top Q = I\)) and \(R\) is upper-triangular. In practice this is done with the Gram–Schmidt process or Householder reflections: each new column of \(A\) has the projection onto all previous \(Q\)-columns subtracted off, then is rescaled to unit length. The result \(Q\) is a genuine rotation/reflection matrix — its rows and columns are mutually orthonormal by construction, not by luck.

Step 3 — Fix the sign ambiguity

QR decomposition is only unique up to the signs of \(R\)'s diagonal. Saxe et al. (2014) fix this by multiplying each column of \(Q\) by \(\operatorname{sign}(\operatorname{diag}(R))\), so the sampling distribution is the uniform (Haar) measure over the orthogonal group \(O(n)\) rather than a biased subset of it.

Step 4 — Reshape for conv layers / apply a gain

For non-square weight tensors (e.g. a Conv2d kernel), the matrix is generated on the flattened \((\text{fan\_out}, \text{fan\_in} \times k_h \times k_w)\) shape, then reshaped back. A scalar gain \(g\) is multiplied in, \(W = g\cdot Q\), to compensate for the nonlinearity that follows (e.g. \(g=\sqrt{2}\) for ReLU, matching He-style variance).

Design decision: why QR and not Gram-Schmidt by hand, or SVD?

Any factorization that yields orthonormal columns works — QR (via Householder, numerically stable) and SVD (\(A = U\Sigma V^\top\), then use \(U\) or \(V\)) both give a uniformly random orthogonal matrix. QR is preferred in practice (torch.nn.init.orthogonal_, tf.orthogonal_initializer) because it's roughly 2–3× cheaper than a full SVD for the same \(n\times n\) matrix, and Householder QR is backward-stable, so the resulting \(Q\) is orthogonal to within machine epsilon even for large \(n\).

🔑 Key Property

Every singular value of an orthogonal matrix is exactly 1. Since a linear map's maximum and minimum stretch factors over all directions are its largest and smallest singular values, an orthogonal \(Q\) stretches every direction by precisely the same amount — no direction is amplified, none is attenuated. This is the property random Gaussian matrices lack.

3
Why It Works — The Math
▼

Norm preservation (the isometry property)

By definition, \(Q\) is orthogonal iff \(Q^\top Q = QQ^\top = I\). Then for any vector \(x\):

$$\|Qx\|_2^2 = (Qx)^\top(Qx) = x^\top Q^\top Q x = x^\top I x = \|x\|_2^2$$

So \(\|Qx\| = \|x\|\) exactly, for every \(x\) — not just on average. This is what makes \(Q\) an isometry of \(\mathbb{R}^n\).

Eigenvalues live on the unit circle

If \(Qv = \lambda v\) for eigenvector \(v \neq 0\), taking norms on both sides and using the isometry property gives \(\|v\| = \|Qv\| = |\lambda|\,\|v\|\), so \(|\lambda| = 1\). Every eigenvalue of an orthogonal matrix (real or complex) has magnitude exactly 1 — geometrically, they sit on the unit circle in the complex plane. Composing \(L\) layers multiplies eigenvalues: \(|\lambda^L| = |\lambda|^L = 1^L = 1\) for all \(L\), so depth never causes blow-up or collapse.

Why random Gaussian matrices fail at depth

Let \(W\) have i.i.d. \(\mathcal{N}(0, 1/n)\) entries (variance-preserving scale, matching \(\mathbb{E}[\|Wx\|^2]=\|x\|^2\)). Individually, \(W\) preserves norm in expectation, but its singular values \(\sigma_1 \geq \dots \geq \sigma_n\) are spread around 1 (Marchenko–Pastur law), not equal to 1. After composing \(L\) independent layers \(W_L \cdots W_1\), the top singular value of the product grows like \(\sigma_{\max}^L\) and the bottom shrinks like \(\sigma_{\min}^L\) — an exponential-in-depth condition number:

$$\kappa(W_L \cdots W_1) \approx \left(\frac{\sigma_{\max}}{\sigma_{\min}}\right)^{L} \to \infty \text{ as } L \to \infty$$

This is precisely the vanishing/exploding gradient problem, viewed as a statement about singular-value spread rather than just scalar magnitude.

Dynamical isometry

Pennington, Schoenholz & Ganguli (2017) define dynamical isometry: the input-output Jacobian of the whole network has singular values concentrated near 1. Orthogonal init gives this exactly at initialization for linear layers, and — combined with the right nonlinearity (e.g. scaled tanh) — approximately for nonlinear deep nets, enabling stable training at depths of 10,000+ layers where Gaussian init fails past a few dozen.

⚠️ Common Misconception

"Orthogonal init means the weights don't need to be learned." False — \(Q\) is only the starting point. Gradient descent immediately moves \(W\) away from the orthogonal manifold as training proceeds. The benefit is purely about giving optimization a numerically well-conditioned starting point, not about staying orthogonal forever (though some methods, e.g. orthogonal RNNs, do enforce it throughout training via constrained optimization).

Key Takeaways
▼

When to use orthogonal init:

  • Vanilla RNNs / LSTMs, where the same recurrent matrix is applied hundreds or thousands of times (dynamical isometry directly attacks vanishing/exploding gradients over time)
  • Very deep plain (non-residual) networks, or deep linear/near-linear sub-networks
  • Reinforcement learning policy/value networks, where good gradient conditioning at init noticeably speeds up early learning
  • Any layer followed by a near-linear activation (tanh, linear, leaky-ReLU with small slope) where the gain factor can be tuned precisely

When NOT to bother:

  • Networks with residual connections and normalization layers (ResNets, Transformers) — skip connections and LayerNorm/BatchNorm already stabilize signal propagation, so He/Xavier (Gaussian) init is standard and orthogonal init gives little extra benefit
  • Very wide, shallow networks — singular-value spread barely compounds with only 1–3 layers
  • Embedding tables / sparse lookup layers — orthogonality has no clear meaning for row-wise lookups
💡 One-line summary

Orthogonal init replaces "roughly the right variance" (Xavier/He) with "exactly norm-preserving in every direction," which is what actually prevents compounding blow-up/collapse across many composed layers.

Code Trace

import numpy as np
# --- From-scratch orthogonal init (Saxe et al., 2014) ---
def orthogonal_init(shape, gain=1.0):
rows, cols = shape[0], np.prod(shape[1:])
flat = np.random.normal(0.0, 1.0, size=(max(rows, cols), min(rows, cols)))
# QR decomposition -> Q has orthonormal columns
Q, R = np.linalg.qr(flat)
# Fix sign ambiguity so Q is Haar-uniform over O(n)
Q = Q * np.sign(np.diag(R))
if rows < cols:
Q = Q.T
W = gain * Q.reshape(shape)
return W
# sanity check: columns are orthonormal -> W^T W ~= gain^2 * I
W = orthogonal_init((256, 256), gain=np.sqrt(2))
print(np.allclose(W.T @ W / 2.0, np.eye(256), atol=1e-6)) # True
# --- Production usage ---
import torch, torch.nn as nn
rnn = nn.RNN(input_size=128, hidden_size=256, num_layers=1)
nn.init.orthogonal_(rnn.weight_hh_l0, gain=1.0) # recurrent weight matrix
nn.init.xavier_uniform_(rnn.weight_ih_l0) # input weight, unrelated
