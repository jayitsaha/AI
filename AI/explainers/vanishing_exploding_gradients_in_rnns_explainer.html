Vanishing & Exploding Gradients in RNNs

Why backpropagation through time breaks down over long sequences — and how orthogonal init, clipping, and gating fix it
Advanced Deep Learning Sequence Models O(T) backward pass
1
Understanding the Problem
▼

What is it? A recurrent neural network (RNN) reuses the same weight matrix \(W\) at every time step, so training it means backpropagating an error signal through a chain that is as deep as the sequence is long. When that chain has 50 or 100 links, the gradient gets multiplied by (roughly) the same factor 50 or 100 times in a row. If that factor is even slightly below 1, the gradient shrinks toward zero — vanishing. If it's even slightly above 1, the gradient blows up toward infinity — exploding.

Analogy: Imagine whispering a message down a line of 100 people (a game of telephone), except each person also has to multiply the message's "volume" by a fixed factor before passing it on. If that factor is 0.9, by the 100th person the message is inaudible (\(0.9^{100} \approx 2.7\times10^{-5}\)). If it's 1.1, by the 100th person everyone is screaming (\(1.1^{100}\approx 13{,}781\)). Neither extreme lets useful information travel end-to-end — only a factor extremely close to 1 keeps the signal intact.

💡 If you remember one thing

Backprop-through-time (BPTT) computes gradients as a product of \(T\) Jacobians, one per time step. A product of many numbers less than 1 shrinks geometrically toward 0; a product of many numbers greater than 1 grows geometrically toward \(\infty\). RNNs are exponentially sensitive to the spectral radius of \(W\) and the saturation of the activation function.

2
How It Works Internally
▼

Unrolling the Recurrence

An RNN computes \(h_t = \tanh(Wh_{t-1} + Ux_t + b)\). Unrolled across \(T\) steps this is exactly a \(T\)-layer feedforward network — except every layer shares the same weight matrix \(W\). Training with backpropagation-through-time (BPTT) means the chain rule must walk backward across all \(T\) shared-weight layers to compute \(\partial L/\partial W\).

The Jacobian Chain

To get the gradient of the loss with respect to an early hidden state \(h_k\), the chain rule forces us to multiply together every intermediate Jacobian between step \(k\) and the final step \(T\):

$$\frac{\partial L}{\partial h_k} = \frac{\partial L}{\partial h_T}\prod_{t=k+1}^{T}\frac{\partial h_t}{\partial h_{t-1}}, \qquad \frac{\partial h_t}{\partial h_{t-1}} = \operatorname{diag}\big(\tanh'(z_t)\big)\,W$$

Each factor \(\operatorname{diag}(\tanh'(z_t))\,W\) is an \(n\times n\) matrix. \(\tanh'(z) = 1-\tanh^2(z) \in (0,1]\), so every factor shrinks the signal along the activation dimension, and \(W\) can shrink or grow it along the weight dimension depending on its spectral radius.

Design Decision: Why Shared Weights?

Sharing \(W\) across time is what makes an RNN generalize to sequences of any length with a fixed parameter count — the alternative (a separate matrix per position) would not generalize and would not respect the sequence's translation symmetry. But this same design choice is exactly what causes the vanishing/exploding problem: the same matrix is applied over and over, so its eigenvalues compound geometrically instead of averaging out as they might with independent random matrices.

🔑 Key Property

The gradient magnitude after \(n = T-k\) steps behaves like \((\lambda\gamma)^n\), where \(\lambda\) is the largest singular value of \(W\) and \(\gamma = \sup|\tanh'(z)| \le 1\). This is an exponential function of sequence length — small deviations of \(\lambda\gamma\) from 1 have an enormous effect once \(n\) grows past a few dozen steps.

3
Why It Works — The Math
▼

Bounding the Jacobian Product

Using the sub-multiplicativity of the operator norm, \(\|AB\|\le\|A\|\|B\|\), the norm of the full backward product is bounded by:

$$\left\|\frac{\partial h_T}{\partial h_k}\right\| = \left\|\prod_{t=k+1}^{T}\operatorname{diag}(\tanh'(z_t))\,W\right\| \le \prod_{t=k+1}^{T}\|\operatorname{diag}(\tanh'(z_t))\|\,\|W\| \le (\gamma\lambda)^{T-k}$$

where \(\lambda = \|W\|_2\) (largest singular value) and \(\gamma=\sup_z|\tanh'(z)|=1\), attained only at \(z=0\). In practice pre-activations drift away from 0 as training proceeds, so \(\gamma\) is typically well below 1 — which is why vanishing is the generic outcome unless \(W\) is specifically scaled to compensate.

Proof Sketch (Vanishing Case)

If \(\lambda < 1/\gamma\), every factor in the product has operator norm strictly less than 1, say \(\le \rho < 1\). Then \(\|\partial h_T/\partial h_k\| \le \rho^{T-k} \to 0\) as \(T-k\to\infty\) — geometric decay to zero. The exploding case is the mirror image: Pascanu, Mikolov & Bengio (2013) show that \(\lambda > 1/\gamma\) is a necessary condition for exploding gradients to be possible (not sufficient — it depends on the actual trajectory of activations), which is why exploding gradients tend to appear as sudden, input-dependent spikes rather than the smooth monotonic decay seen with vanishing.

⚠️ Common Misconception

"Vanishing gradients mean the RNN stops learning." Not quite — the gradient with respect to recent steps stays healthy; only the long-range component vanishes. The network still trains, but it becomes effectively blind to dependencies more than a handful of steps in the past, even though nothing in the loss curve looks obviously broken.

Key Takeaways
▼

What causes it:

  • Shared weight matrix \(W\) applied \(T\) times → gradient scales like \((\lambda\gamma)^{T-k}\), exponential in sequence length
  • Saturating activations (\(\tanh\), sigmoid) push \(\gamma \ll 1\) once units are confidently on/off
  • Poor weight initialization (too small → vanish, too large → explode)

How to fix it in practice:

  • Gradient clipping (Pascanu et al. 2013) — rescale the gradient norm if it exceeds a threshold; cheap, effective against exploding gradients, does nothing for vanishing
  • Orthogonal / identity initialization — keep \(\lambda \approx 1\) at the start of training (IRNN, Le et al. 2015; orthogonal init for tanh RNNs)
  • Gated architectures (LSTM, GRU) — an additive, gated cell-state path keeps the effective multiplier close to the forget gate value (\(\approx 1\)) instead of \(\lambda\gamma\)
  • Skip/residual connections, truncated BPTT, layer normalization — shorten or stabilize the effective gradient path
💡 Big Picture

Vanishing and exploding gradients are two faces of the same phenomenon: repeated multiplication by roughly the same matrix. Every practical fix — clipping, careful init, gating, attention, residual paths — works by either bounding the product's growth or replacing the multiplicative path with an additive one.

Code Trace

import numpy as np
# 2x2 "weight" W = r * rotation(theta): spectral norm is exactly r
def rot_scale(theta, r):
c, s = np.cos(theta), np.sin(theta)
return r * np.array([[c, -s], [s, c]])
# Per-step Jacobian: diag(tanh'(z_t)) @ W ~= gamma * W (isotropic gamma)
def gradient_norm_over_time(r, gamma, theta, T):
J = rot_scale(theta, r * gamma)
P = np.eye(2)
norms = [1.0]
for _ in range(T):
P = J @ P # accumulate one more Jacobian
norms.append(np.linalg.norm(P, 2)) # spectral norm
return norms
# Vanishing: saturated tanh (gamma=0.25) even with orthogonal W (r=1)
vanish = gradient_norm_over_time(r=1.0, gamma=0.25, theta=0.35, T=12)
print(vanish[-1]) # ~5.96e-08
# Exploding: r*gamma > 1
explode = gradient_norm_over_time(r=1.5, gamma=0.9, theta=0.35, T=12)
print(explode[-1]) # ~36.7
# Gradient clipping: rescale ONLY if norm exceeds threshold
def clip_grad_norm(g, max_norm=5.0):
n = np.linalg.norm(g)
return g * (max_norm / n) if n > max_norm else g
# LSTM cell path: additive update, multiplier = forget gate (close to 1)
forget_gates = np.array([0.96,0.94,0.97,0.93,0.95,0.92,0.96,0.94,0.93,0.97,0.95,0.94])
lstm_norm_T = np.prod(forget_gates) # ~0.52, decays MUCH slower than tanh RNN
