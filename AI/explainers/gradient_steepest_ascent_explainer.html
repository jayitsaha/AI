Gradient: Direction of Steepest Ascent

Gradient fields, contour geometry, and why \(\nabla f\) always points uphill fastest
Intermediate Calculus & Analysis Multivariable Calculus O(n) computation
1
Understanding the Gradient
▼

What is it? The gradient is the multivariable generalisation of the derivative. For a scalar function \(f(x,y)\) — imagine a hilly landscape where height is \(f\) — the gradient \(\nabla f\) is a 2D arrow that always points in the direction you would walk to climb the hill as steeply as possible. No matter where you stand on the landscape, that arrow tells you: step this way and you gain altitude the fastest.

Analogy: Stand on a hillside with a compass. The gradient is the arrow on that compass that points directly uphill — not to the side, not diagonally — but perpendicular to the elevation contour lines you see on a topographic map. Water flowing downhill follows the negative gradient: it always takes the steepest downhill path.

Why it matters for ML: Nearly every deep learning algorithm — gradient descent, Adam, SGD, backpropagation — relies on computing \(\nabla_\theta \mathcal{L}\), the gradient of the loss with respect to parameters. The gradient tells the optimizer which direction to move to increase the loss; by following the negative gradient we decrease it.

💡 If you remember one thing

The gradient \(\nabla f(\mathbf{x})\) is the unique vector such that the directional derivative in direction \(\mathbf{u}\) equals \(\nabla f \cdot \mathbf{u}\). The dot product is maximised when \(\mathbf{u}\) points in the same direction as \(\nabla f\), making \(\nabla f\) the direction of steepest ascent. Its magnitude \(\|\nabla f\|\) is the steepness of that climb.

2
How the Gradient Works Internally
▼

Definition

For a differentiable function \(f : \mathbb{R}^n \to \mathbb{R}\), the gradient at point \(\mathbf{x} \in \mathbb{R}^n\) is the vector of all partial derivatives:

$$\nabla f(\mathbf{x}) = \left(\frac{\partial f}{\partial x_1},\; \frac{\partial f}{\partial x_2},\; \ldots,\; \frac{\partial f}{\partial x_n}\right)^\top \in \mathbb{R}^n$$

Each component \(\partial f / \partial x_i\) tells you how fast \(f\) changes if you move along the \(i\)-th axis alone, holding all others fixed. The gradient bundles these \(n\) "slope readings" into one vector.

The Directional Derivative Connection

The directional derivative of \(f\) at \(\mathbf{x}\) in direction \(\mathbf{u}\) (where \(\|\mathbf{u}\| = 1\)) is:

$$D_{\mathbf{u}} f(\mathbf{x}) = \nabla f(\mathbf{x}) \cdot \mathbf{u} = \|\nabla f(\mathbf{x})\|\, \cos\theta$$

where \(\theta\) is the angle between \(\nabla f\) and \(\mathbf{u}\). This is the rate of change of \(f\) when you walk from \(\mathbf{x}\) in direction \(\mathbf{u}\). The cosine factor is the key: it is maximised at \(\theta = 0\), i.e. when \(\mathbf{u}\) aligns with \(\nabla f\). Hence \(\nabla f\) is the steepest-ascent direction.

Gradient Fields

At every point in the domain, the gradient defines an arrow. The collection of all these arrows — one per location — forms the gradient field \(\mathbf{F}(\mathbf{x}) = \nabla f(\mathbf{x})\). It is a vector field that "flows" from lower to higher values of \(f\). The gradient field is always conservative: it has zero curl, and is path-independent.

Perpendicularity to Level Sets

A level set (or contour) of \(f\) at value \(c\) is the set \(\{\mathbf{x} : f(\mathbf{x}) = c\}\). The gradient \(\nabla f(\mathbf{x})\) is always perpendicular (normal) to the level set passing through \(\mathbf{x}\). Proof: if \(\mathbf{v}\) is any tangent vector to the level set at \(\mathbf{x}\), then \(f(\mathbf{x} + t\mathbf{v}) = c\) for all small \(t\), so \(\frac{d}{dt}f(\mathbf{x}+t\mathbf{v})|_{t=0} = \nabla f \cdot \mathbf{v} = 0\). Hence \(\nabla f \perp \mathbf{v}\) for all tangent directions, i.e. \(\nabla f\) is the outward normal.

🔑 Key Property

The gradient has three equivalent characterisations: (1) the vector of partial derivatives \((\partial f/\partial x_1, \ldots, \partial f/\partial x_n)^\top\), (2) the direction of steepest ascent (max directional derivative), and (3) the outward normal to level sets. All three are the same object.

3
Why \(\nabla f\) is Steepest Ascent — The Proof
▼

Optimise the Directional Derivative over Unit Directions

We want to find the unit vector \(\mathbf{u}^*\) that maximises the rate of increase of \(f\):

$$\mathbf{u}^* = \underset{\|\mathbf{u}\|=1}{\operatorname{argmax}}\; D_{\mathbf{u}} f(\mathbf{x}) = \underset{\|\mathbf{u}\|=1}{\operatorname{argmax}}\;\nabla f(\mathbf{x}) \cdot \mathbf{u}$$

By the Cauchy-Schwarz inequality:

$$\nabla f \cdot \mathbf{u} \;\leq\; \|\nabla f\|\,\|\mathbf{u}\| = \|\nabla f\|$$

with equality if and only if \(\mathbf{u} = \nabla f / \|\nabla f\|\). Therefore:

$$\mathbf{u}^* = \frac{\nabla f(\mathbf{x})}{\|\nabla f(\mathbf{x})\|}, \qquad \max_{\|\mathbf{u}\|=1} D_{\mathbf{u}} f = \|\nabla f(\mathbf{x})\|$$

The steepest descent direction is \(-\mathbf{u}^*\), giving \(D_{-\mathbf{u}^*}f = -\|\nabla f\|\) (the most negative directional derivative).

Numerical Example: \(f(x,y) = e^{-(x^2 + 2y^2)/4}\)

At the point \(\mathbf{x} = (1, 0.5)\):

$$\nabla f(1, 0.5) = \left(-\frac{x}{2}e^{-(x^2+2y^2)/4},\; -y\,e^{-(x^2+2y^2)/4}\right)\bigg|_{(1,\,0.5)}$$

Computing step by step: \(e^{-(1 + 0.5)/4} = e^{-0.375} \approx 0.687\)

$$\nabla f(1, 0.5) = \left(-0.5 \times 0.687,\; -0.5 \times 0.687\right) = (-0.344,\; -0.344)$$

This gradient points toward the origin (the maximum of \(f\)), which is the steepest-ascent direction.

Proof that \(\nabla f \perp\) Level Sets (Implicit Differentiation)

Let \(\gamma(t)\) be any curve lying on the level set \(\{f = c\}\), so \(f(\gamma(t)) = c\) for all \(t\). Differentiating both sides:

$$\frac{d}{dt}f(\gamma(t)) = \nabla f(\gamma(t)) \cdot \gamma'(t) = 0$$

The tangent vector \(\gamma'(t)\) to the level set is always orthogonal to \(\nabla f\). Since this holds for all tangent directions, \(\nabla f\) is the normal to the level set. QED.

⚠️ Common Misconception

The gradient depends on the coordinate system. In Cartesian coordinates it is simply \((\partial f/\partial x, \partial f/\partial y)\), but in polar or spherical coordinates the formula involves metric factors. Also: the gradient is zero at critical points (maxima, minima, saddle points) — it is NOT undefined, it is zero. The steepest-ascent characterisation breaks down when \(\|\nabla f\| = 0\) (you are already at a stationary point).

Key Takeaways & ML Connections
▼

Core gradient facts:

  • The gradient \(\nabla f\) is the steepest-ascent direction; its negative \(-\nabla f\) is steepest descent.
  • The gradient is perpendicular to every level set (contour) of \(f\).
  • The magnitude \(\|\nabla f\|\) is the steepness: large = steep slope, 0 = flat (stationary point).
  • The directional derivative in direction \(\mathbf{u}\) is \(\nabla f \cdot \mathbf{u}\), which Cauchy-Schwarz bounds by \(\pm\|\nabla f\|\).

In ML and optimisation:

  • Gradient descent: \(\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}\) moves parameters in the direction that decreases the loss most rapidly.
  • Backpropagation: efficiently computes \(\nabla_\theta \mathcal{L}\) for all parameters via the chain rule.
  • Saddle points: where \(\nabla f = 0\) but neither a max nor a min — gradient methods stall here.
  • Natural gradient: instead of Euclidean gradient, uses the Fisher information metric to account for the geometry of the parameter space.
💡 Hierarchy of Derivatives

Gradient \(\nabla f\) (vector, first order) → Jacobian \(J\) (matrix, first order, vector-valued \(f\)) → Hessian \(H = \nabla^2 f\) (matrix, second order). The Hessian governs local curvature and distinguishes maxima (\(H \prec 0\)) from minima (\(H \succ 0\)) at critical points.

Code Trace — Gradient Ascent from Scratch
▼
import numpy as np
# Scalar field: Gaussian hill (max at origin)
def f(x, y): # f: R² → R
return np.exp(-(x**2 + 2*y**2) / 4)
def grad_f(x, y): # ∇f: R² → R²
e = np.exp(-(x**2 + 2*y**2) / 4) # shared exponential
return np.array([-x/2 * e, -y * e]) # (∂f/∂x, ∂f/∂y)
def directional_deriv(x, y, u): # D_u f(x,y)
u_hat = u / np.linalg.norm(u) # ensure unit vector
return np.dot(grad_f(x, y), u_hat) # = ∇f · û
# ── Gradient Ascent ───────────────────────────────────
x, y = -2.0, -1.0 # starting point
lr = 0.5 # step size (learning rate)
path = [(x, y, f(x, y))] # record trajectory
for step in range(14): # iterate
g = grad_f(x, y) # current gradient
x += lr * g[0] # step in ∇f direction
y += lr * g[1]
path.append((x, y, f(x, y)))
if np.linalg.norm(g) < 1e-4: break # converged
print("Gradient ascent path (x, y, f):")
for pt in path[:6]:
print(f" ({pt[0]:6.3f}, {pt[1]:6.3f}), f={pt[2]:.4f}")
# → (-2.000, -1.000), f=0.2231
# → (-1.888, -0.888), f=0.2763
# → (-1.758, -0.766), f=0.3438
# → (-1.607, -0.634), f=0.4285
# → (-1.434, -0.498), f=0.5280 ← crosses contour 0.5
# → (-1.245, -0.366), f=0.6347
