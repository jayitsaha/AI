Convex Optimization: Global Optima Guarantee

Why any local minimum of a convex objective is the global minimum — and why this makes ML training reliable
Foundational Calculus & Optimization Math Foundations O(1) guarantee check
1
Understanding the Guarantee
▼

What is it? When you train an ML model you are minimizing a loss function. The scary question is: "Did gradient descent find the best possible solution, or just a local ditch?" Convexity gives you a complete answer: if the loss function is convex and the feasible set is convex, every local minimum is automatically the global minimum. There are no hidden better solutions.

Analogy: Imagine rolling a marble down a bowl (convex) versus a mountain range (non-convex). In the bowl, wherever the marble stops, it is at the lowest point — there is nowhere lower. In the mountain range, the marble might stop in a valley that is not the lowest valley. Convexity is the mathematical condition that guarantees you have a bowl, not a mountain range.

If you remember one thing

For a convex objective \(f\) over a convex set \(\mathcal{C}\): any point where \(\nabla f = 0\) (or the KKT conditions hold) is the global minimum. Local optima do not exist — the local is always global. This is why logistic regression, linear regression, and SVM training are reliable: they are convex problems.

The Chord Argument — Why Local = Global
▼

The Formal Definition

A function \(f: \mathbb{R}^n \to \mathbb{R}\) is convex if for all \(a, b\) in its domain and all \(\lambda \in [0,1]\):

$$f(\lambda a + (1-\lambda)b) \;\leq\; \lambda f(a) + (1-\lambda) f(b)$$

Geometrically: the function lies at or below any chord connecting two of its points. This is Jensen's inequality. For \(f(x) = x^2 + 1\) with \(a = -1.8, b = 1.8\): the chord has value \(4.24\) everywhere between them, while the maximum function value along this segment is only \(4.24\) at the endpoints — everywhere in between, \(f\) is strictly less.

The Core Proof (by Contradiction)

Suppose \(x_{\text{local}}\) is a local minimum but NOT the global minimum, so \(\exists\, x^*\) with \(f(x^*) < f(x_{\text{local}})\). By convexity, for any \(\lambda \in (0,1)\):

$$f(\lambda x^* + (1-\lambda)x_{\text{local}}) \;\leq\; \lambda f(x^*) + (1-\lambda) f(x_{\text{local}}) \;<\; f(x_{\text{local}})$$

For small enough \(\lambda\), the point \(\lambda x^* + (1-\lambda)x_{\text{local}}\) is arbitrarily close to \(x_{\text{local}}\) yet has a strictly smaller function value — contradicting the assumption that \(x_{\text{local}}\) is a local minimum. Therefore no such \(x_{\text{local}}\) can exist.

Key Invariant

In a convex function, every lower point is continuously reachable along the descending chord. You can always walk downhill. This makes local = global an inescapable consequence of the geometry.

The Math — Convexity, KKT & Sufficiency
▼

Checking Convexity via the Hessian

For twice-differentiable \(f\): \(f\) is convex if and only if its Hessian \(\nabla^2 f(x) \succeq 0\) (positive semi-definite) for all \(x\) in the domain. For \(f(x) = x^2+1\): \(\nabla^2 f = 2 > 0\) — strictly convex.

For logistic regression with \(n\) examples and weight vector \(w \in \mathbb{R}^d\):

$$\mathcal{L}(w) = \sum_{i=1}^n \log\!\left(1 + e^{-y_i w^\top x_i}\right)$$

The Hessian is \(H = X^\top D X\) where \(D_{ii} = \sigma_i(1-\sigma_i)\) and \(\sigma_i = 1/(1+e^{-y_i w^\top x_i})\). Since \(D_{ii} \in [0, \tfrac{1}{4}]\) for all \(w\), we have \(D \succeq 0\), so \(H \succeq 0\) — logistic regression is convex.

KKT Conditions: Necessary AND Sufficient

For a convex problem \(\min f(x)\) s.t. \(g_i(x) \leq 0\) (convex constraints), the KKT conditions are both necessary AND sufficient for global optimality:

$$\nabla f(x^*) + \sum_i \mu_i^* \nabla g_i(x^*) = 0, \quad \mu_i^* \geq 0, \quad \mu_i^* g_i(x^*) = 0$$
Common Misconception

KKT sufficiency requires both the objective and all constraints to be convex. For a non-convex problem, KKT conditions are only necessary — a KKT point might be a saddle or local minimum, not global. The convexity assumption is what elevates KKT from necessary to sufficient.

Example: SVM as a Convex QP

SVM solves \(\min_{w,b} \tfrac{1}{2}\|w\|^2\) subject to \(y_i(w^\top x_i + b) \geq 1\). The objective \(\tfrac{1}{2}\|w\|^2\) is strictly convex; the constraints are linear (hence convex). Any solver that finds KKT conditions certifies the global optimum.

Key Takeaways & ML Connections
▼

Convex ML models — always converge to the global optimum:

  • Linear regression — MSE loss \(\|Xw - y\|^2\) is a convex quadratic; unique global min via normal equations
  • Logistic regression — log-loss is convex; gradient descent finds global optimum
  • SVM — convex QP; guaranteed global solution via dual
  • Ridge/Lasso regression — convex (quadratic + convex penalty)

Non-convex models (deep networks, GMMs) — no global guarantee:

  • Multiple local minima and saddle points exist
  • Different random seeds may converge to different solutions
  • In practice, for overparameterized nets, local minima are nearly as good as global (empirical finding, not theoretical)
Decision Guide

Need a guaranteed global optimum? Choose a convex model (logistic regression, SVM, linear regression). Need maximum expressiveness at the cost of optimization guarantees? Use deep networks — and rely on good initialization, learning rate schedules, and empirical validation.

Code: Verifying Convexity & Checking KKT
▼
import numpy as np
from scipy.optimize import minimize
# ── 1. Verify convexity via Hessian ──────────────────────────────────────
def f_convex(x): # f(x) = x^2 + 1
return x**2 + 1
def hessian_1d(f, x, h=1e-5): # finite-difference second derivative
return (f(x+h) - 2*f(x) + f(x-h)) / h**2
for x in [-2, -1, 0, 1, 2]:
H = hessian_1d(f_convex, x)
print(f"x={x:+.0f} H={H:.3f} convex={H >= 0}") # all True
# ── 2. Logistic regression: check PSD Hessian ────────────────────────────
X = np.array([[1,-1],[1,0.5],[1,2],[-1,1]]) # design matrix
y = np.array([1, 1, -1, -1]) # labels
def logistic_loss(w): # convex logistic loss
return np.sum(np.log1p(np.exp(-y * (X @ w))))
def logistic_hessian(w): # H = X^T D X, D_ii = sigma_i(1-sigma_i)
s = 1 / (1 + np.exp(-y * (X @ w)))
D = np.diag(s * (1 - s))
return X.T @ D @ X # guaranteed PSD
w0 = np.zeros(2)
H = logistic_hessian(w0)
eigs = np.linalg.eigvalsh(H) # eigenvalues of Hessian
print(f"Hessian eigenvalues: {eigs}") # both >= 0 -> convex
print(f"PSD? {np.all(eigs >= -1e-10)}") # True
# ── 3. Gradient descent finds global optimum ─────────────────────────────
result = minimize(logistic_loss, np.zeros(2), method='BFGS',
jac=lambda w: X.T @ (1/(1+np.exp(y*(X@w)))*(-y)))
print(f"Optimal w: {result.x}") # global optimum guaranteed
print(f"Loss: {result.fun:.6f}") # same from any start point
# ── 4. KKT check for SVM ─────────────────────────────────────────────────
# min x^2 s.t. x >= 1 => KKT: 2x - mu = 0, mu*(x-1)=0, x>=1, mu>=0
# Solution: x*=1, mu*=2 (active constraint)
x_star, mu_star = 1.0, 2.0
stationarity = 2*x_star - mu_star # should be 0
comp_slack = mu_star * (x_star - 1) # should be 0
print(f"Stationarity: {stationarity}") # 0.0
print(f"Comp. slack: {comp_slack}") # 0.0 → global optimum
