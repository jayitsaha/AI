Understanding Fixup Initialization
▼

What is it? Residual networks (ResNets) are normally trained with BatchNorm or LayerNorm sitting inside every block — without it, deep nets simply fail to train because activation variance explodes with depth. Fixup Initialization (Zhang, Dauphin & Ma, ICLR 2019) is a way to set the initial weights so that a residual network trains stably from scratch with zero normalization layers, matching normalized-network accuracy on ImageNet and machine translation.

Analogy: Stacking L residual blocks is like L people each whispering a small correction into a message as it passes down a line. If everyone whispers at "normal volume," the message gets louder and louder exponentially and becomes noise by block 50. Fixup tells each whisperer, in advance, exactly how quietly to speak — proportional to how many people are in the line — so the final message stays at a sane volume without needing a "volume control" (normalization) at every step.

💡 If you remember one thing

Fixup rescales every residual branch's weights by \(L^{-\frac{1}{2m-2}}\) (L = number of residual blocks, m = layers per branch), zero-initializes the last layer of every branch, and adds learnable scalar multipliers + biases. This keeps forward activation variance and the SGD update magnitude at \(\Theta(1)\) regardless of depth — no BatchNorm required.

How Fixup Works Internally
▼

Why BatchNorm Was Load-Bearing

In a plain residual block \(x_{l+1} = x_l + F_l(x_l)\), He/Kaiming initialization makes each layer inside \(F_l\) variance-preserving: \(\operatorname{Var}[F_l(x_l)] \approx \operatorname{Var}[x_l]\). That sounds fine — until you realize the skip connection adds this branch output back onto \(x_l\) itself, so the block's output variance roughly doubles at every block. BatchNorm was silently fixing this by renormalizing activations back to unit variance after every block, masking the real problem: uncontrolled initialization.

The Two-Part Fixup Recipe

For a network with L residual blocks, each containing m layers in its branch, Fixup applies four rules:

  • Scale down: initialize the first m−1 layers of each residual branch with the standard method (e.g. He), then multiply those weights by \(L^{-\frac{1}{2m-2}}\).
  • Zero the last layer: initialize the final layer of each residual branch (e.g. the last conv, or the classifier weights of a block) to exactly zero, so \(F_l(x_l) = 0\) at step 0 — the block starts as a pure identity map.
  • Add scalars: insert a learnable scalar multiplier before each conv/linear layer inside a branch, initialized to 1.
  • Add biases: insert a learnable scalar bias before every conv, linear, and nonlinear layer, initialized to 0.

The scalars and biases replace the affine \((\gamma,\beta)\) parameters that BatchNorm used to provide, restoring the network's ability to learn per-channel scale/shift without needing batch statistics.

Design Decision: Why This Exact Exponent?

The exponent \(-\frac{1}{2m-2}\) is derived, not guessed: it is exactly the scaling factor that makes each block's contributed variance shrink by \(1/L\), so that summing the contributions of all L blocks lands back at \(\Theta(1)\) instead of exploding — see Card 3 for the full derivation.

🔑 Key Property

Fixup makes the network compute the identity function at initialization (because the last branch layer is zero), while the scaled early layers guarantee the SGD update to the network's output after one step is also \(\Theta(1)\) in depth — both the forward pass AND the first gradient step are depth-independent.

3
Why It Works — The Variance Derivation
▼

Step 1 — The Uncontrolled Recurrence

Let \(x_l\) be the input to residual block \(l\), and \(F_l\) its m-layer branch. The block computes:

$$x_{l+1} = x_l + F_l(x_l)$$

Taking variance of both sides (treating \(x_l\) and \(F_l(x_l)\) as roughly uncorrelated at init):

$$\operatorname{Var}[x_{l+1}] \approx \operatorname{Var}[x_l] + \operatorname{Var}[F_l(x_l)]$$

With standard variance-preserving init (He/Kaiming, unscaled), each layer inside the branch preserves incoming variance, so \(\operatorname{Var}[F_l(x_l)] \approx \operatorname{Var}[x_l]\). Substituting:

$$\operatorname{Var}[x_{l+1}] \approx 2\operatorname{Var}[x_l] \implies \operatorname{Var}[x_L] \approx 2^{L}\operatorname{Var}[x_0]$$

This is exponential blow-up in depth — at L = 50 that's a factor of \(2^{50}\approx 10^{15}\), which overflows activations and produces vanishing/exploding gradients long before training starts.

Step 2 — Scaling One Branch to Shrink Its Contribution

Suppose we scale the weights of the m−1 non-final layers of branch \(F_l\) by a factor \(s\). Since a linear layer's output variance scales with the square of its weight scale, and the branch composes m−1 such scaled layers:

$$\operatorname{Var}[F_l(x_l)] \approx s^{2(m-1)}\operatorname{Var}[x_l]$$

We want each block to contribute only \(\frac{1}{L}\) of the running variance, so that L blocks summed together contribute \(\Theta(1)\) total — not \(\Theta(L)\) or \(\Theta(2^L)\). Setting \(s^{2(m-1)} = \frac{1}{L}\) and solving for s:

$$s^{2(m-1)} = L^{-1} \implies s = L^{-\frac{1}{2(m-1)}} = L^{-\frac{1}{2m-2}}$$

This is exactly the Fixup scaling factor.

Step 3 — The Bounded Recurrence

With this scaling, each block now satisfies:

$$\operatorname{Var}[x_{l+1}] \approx \operatorname{Var}[x_l]\left(1+\frac{1}{L}\right)$$

Unrolling across all L blocks:

$$\operatorname{Var}[x_L] \approx \operatorname{Var}[x_0]\left(1+\frac{1}{L}\right)^{L} \xrightarrow{L\to\infty} e\cdot\operatorname{Var}[x_0]$$

Regardless of how deep the network is, the output variance stays within a constant factor (≈ e ≈ 2.72) of the input variance — Θ(1) in depth. The zero-initialized last layer additionally makes the network compute the exact identity at step 0, and Zhang et al. further show the SGD update norm after one training step is also \(\Theta(1)\) under this scaling.

⚠️ Common Misconception

Fixup is not "just remove BatchNorm." Removing BatchNorm without rescaling reproduces the \(2^L\) blow-up above and the network won't train at all. Fixup replaces normalization's stabilizing effect with a principled, data-independent initialization — it does not remove the need for careful learning-rate warmup in some setups, and networks trained this way can still slightly underperform BatchNorm variants without extra regularization (Fixup's paper adds Mixup/label smoothing to close the last gap).

Key Takeaways
▼

When Fixup helps:

  • Very deep residual nets where BatchNorm's batch-size dependence hurts (small-batch / per-example training, RL, meta-learning)
  • Settings needing exact per-example determinism (BatchNorm couples examples within a batch)
  • Sequence models / low-latency inference where normalization's runtime statistics overhead is undesirable
  • Research into what normalization layers actually contribute to trainability

When NOT to reach for it:

  • Standard large-batch image classification — BatchNorm is simpler, well-understood, and already fast
  • You need Fixup's accuracy gap closed without extra regularization (Mixup/label smoothing) tuning effort
  • Non-residual architectures — Fixup's derivation specifically targets summed residual branches
💡 Big Picture

Fixup shows that normalization layers were solving an initialization problem, not a fundamentally architectural one. Get the initial variance and update scale right analytically, and a residual network trains without ever computing a running mean or variance. This inspired later normalization-free architectures (e.g. NFNets).

Code Trace — Fixup Init in PyTorch
▼
import torch, torch.nn as nn
# L = total number of residual blocks in the network
# m = number of conv/linear layers inside each branch
def fixup_init_branch(branch_layers, L, m):
scale = L ** (-1.0 / (2 * m - 2))
# (1) scale down the first m-1 layers after standard He init
for layer in branch_layers[:-1]:
nn.init.kaiming_normal_(layer.weight, mode='fan_out',
nonlinearity='relu')
layer.weight.data.mul_(scale)
# (2) zero-init the LAST layer of the branch
nn.init.zeros_(branch_layers[-1].weight)
class FixupBlock(nn.Module):
def __init__(self, dim, L, m=2):
super().__init__()
self.conv1 = nn.Conv2d(dim, dim, 3, padding=1, bias=False)
self.conv2 = nn.Conv2d(dim, dim, 3, padding=1, bias=False)
fixup_init_branch([self.conv1, self.conv2], L, m)
# (3)+(4) learnable scalars & biases replace BatchNorm's affine
self.bias1a = nn.Parameter(torch.zeros(1))
self.bias1b = nn.Parameter(torch.zeros(1))
self.bias2a = nn.Parameter(torch.zeros(1))
self.bias2b = nn.Parameter(torch.zeros(1))
self.scale = nn.Parameter(torch.ones(1))
self.relu = nn.ReLU(inplace=True)
def forward(self, x):
out = self.relu(self.conv1(x + self.bias1a) + self.bias1b)
out = self.conv2(out + self.bias2a) * self.scale + self.bias2b
return self.relu(x + out) # no BatchNorm anywhere
