Understanding the Rayleigh Quotient
▼

What is it? For a symmetric matrix \(A\) and any nonzero vector \(x\), the Rayleigh quotient is the scalar \(R(x) = \frac{x^\top A x}{x^\top x}\). It measures how much \(A\) "stretches" the direction of \(x\) — answering the question: "If I shoot an arrow in direction \(x\), how much does \(A\) amplify it?"

Analogy: Imagine pressing clay with your hands. Every direction you push has a different resistance — some directions are hard to compress, others very easy. The Rayleigh quotient measures that resistance for each direction. The directions of maximum and minimum resistance are exactly the eigenvectors of the matrix, and the resistances are exactly the eigenvalues.

Why normalise by \(x^\top x\)? Without dividing, making \(x\) longer would grow \(x^\top A x\) without bound. Dividing by \(\|x\|^2\) makes \(R(x)\) depend only on the direction of \(x\), not its magnitude. On the unit sphere (\(\|x\|=1\)) the Rayleigh quotient and the numerator coincide.

💡 If you remember one thing

For a real symmetric matrix \(A\) with eigenvalues \(\lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\), $$\lambda_{\min}(A) \;\leq\; R(x) = \frac{x^\top A x}{x^\top x} \;\leq\; \lambda_{\max}(A)$$ with equality at the corresponding eigenvectors. Every eigenvalue is a stationary point of \(R\).

How the Rayleigh Quotient Works Internally
▼

The Spectral Decomposition Perspective

Because \(A\) is real symmetric, the Spectral Theorem gives \(A = Q\Lambda Q^\top\) where \(Q = [q_1 | q_2 | \cdots | q_n]\) is orthonormal and \(\Lambda = \operatorname{diag}(\lambda_1,\ldots,\lambda_n)\). Write any unit vector \(x\) in the eigenbasis: \(x = \sum_i c_i q_i\) with \(\sum_i c_i^2 = 1\). Then:

$$R(x) = x^\top A x = \left(\sum_i c_i q_i\right)^\top A \left(\sum_j c_j q_j\right) = \sum_i c_i^2 \lambda_i$$

This is a convex combination of the eigenvalues (coefficients \(c_i^2 \geq 0\), sum to 1). So \(R(x)\) is a weighted average of all eigenvalues, and its range is exactly \([\lambda_{\min}, \lambda_{\max}]\).

Stationarity at Eigenvectors

The gradient of \(R(x)\) with respect to \(x\) (computed via the quotient rule) is:

$$\nabla_x R(x) = \frac{2}{x^\top x}\bigl(Ax - R(x)\,x\bigr)$$

Setting \(\nabla R = 0\) gives \(Ax = R(x)\,x\), i.e., \(x\) must be an eigenvector and \(R(x)\) its eigenvalue. Thus the critical points of \(R\) are exactly the eigenvectors, and the critical values are the eigenvalues.

Connection to PCA and Power Iteration

PCA seeks directions of maximum variance: \(\max_{\|x\|=1} x^\top \Sigma x = R_\Sigma(x)\), which is exactly the Rayleigh quotient of the sample covariance \(\Sigma\). The first PC is the top eigenvector. Power iteration approximates this maximum by repeatedly applying \(A\) to a random start, since \(A^k x\) aligns with the dominant eigenvector exponentially fast — each iteration climbs the Rayleigh quotient toward \(\lambda_{\max}\).

🔑 Key Property — Minimax Theorem

The \(k\)-th smallest eigenvalue satisfies the Courant–Fischer minimax characterisation: $$\lambda_k = \min_{\dim(S)=k}\;\max_{x \in S,\,x\neq 0} R(x)$$ This generalises the min/max to intermediate eigenvalues and underpins Lanczos iteration and interlacing theorems.

3
Why It Works — The Math
▼

Proof of the Min-Max Bounds

Let \(A\) be \(n\times n\) real symmetric with eigenpairs \((\lambda_i, q_i)\), \(\lambda_1 \leq \cdots \leq \lambda_n\). For unit \(x = \sum c_i q_i\) (\(\sum c_i^2=1\)):

$$R(x) = \sum_{i=1}^n c_i^2 \lambda_i \;\geq\; \lambda_1 \sum_{i=1}^n c_i^2 = \lambda_1$$

with equality when \(x = q_1\) (so \(c_1=1\), all others zero). Similarly \(R(x) \leq \lambda_n\) with equality at \(q_n\). This proves:

$$\lambda_{\min} = \min_{\|x\|=1} R(x), \qquad \lambda_{\max} = \max_{\|x\|=1} R(x)$$

Derivation of the Gradient

Write \(f(x) = x^\top A x\) and \(g(x) = x^\top x\). By the quotient rule:

$$\nabla R = \frac{g \nabla f - f \nabla g}{g^2} = \frac{(x^\top x)(2Ax) - (x^\top Ax)(2x)}{(x^\top x)^2} = \frac{2}{x^\top x}(Ax - R(x)\,x)$$

At a critical point \(\nabla R = 0\): \(Ax = R(x)\,x\), so \(x\) is an eigenvector and \(R(x)\) is its eigenvalue.

Generalised Rayleigh Quotient

For the generalised eigenproblem \(Ax = \lambda B x\) with \(B\) symmetric positive-definite:

$$R_{A,B}(x) = \frac{x^\top A x}{x^\top B x}$$

The extrema are the generalised eigenvalues. This appears in Fisher's Linear Discriminant Analysis (LDA) where \(A = S_B\) (between-class scatter) and \(B = S_W\) (within-class scatter).

⚠️ Common Pitfall

The Rayleigh quotient bounds \(\lambda_{\min} \leq R(x) \leq \lambda_{\max}\) require \(A\) to be real symmetric (or complex Hermitian). For non-symmetric matrices, \(x^\top A x\) can be complex or the bounds can fail — use the symmetrised form \(\frac{x^\top(A + A^\top)x/2}{x^\top x}\) instead.

Key Takeaways & Applications
▼

Where the Rayleigh Quotient appears in ML:

  • PCA: First principal component = \(\arg\max_{\|x\|=1} R_\Sigma(x)\). Each subsequent PC = next largest eigenvector direction.
  • LDA (Fisher): Maximise \(R_{S_B, S_W}(w)\) for optimal linear discriminant direction.
  • Power Iteration: Repeatedly compute \(v \leftarrow Av/\|Av\|\); the Rayleigh quotient \(v^\top A v\) converges to \(\lambda_{\max}\) at rate \(|\lambda_{n-1}/\lambda_n|^{2k}\).
  • Lanczos Algorithm: Projects \(A\) onto a Krylov subspace and maximises/minimises the Rayleigh quotient restricted to that subspace, converging fast to extreme eigenvalues.
  • Spectral Clustering: Graph Laplacian eigenvalues found via Rayleigh quotient minimisation, partitioning data into clusters.
  • Generalised Eigenproblems: Linear discriminant analysis, CCA, and kernel methods all involve \(R_{A,B}(x)\) for symmetric positive-definite pairs.
💡 Hierarchy of Insight

Extrema → min/max Rayleigh quotient = smallest/largest eigenvalue. Stationarity → every eigenvector is a critical point. Minimax (Courant–Fischer) → intermediate eigenvalues characterised by constrained max-min. This hierarchy underpins all of spectral theory.

Code Trace — NumPy Implementation
▼
import numpy as np
# Define symmetric 2x2 matrix
A = np.array([[3.0, 1.0],
[1.0, 2.0]])
# Rayleigh quotient function
def rayleigh(A, x):
"""R(x) = x.T @ A @ x / (x.T @ x)"""
return (x @ A @ x) / (x @ x)
# Compute eigenvalues and eigenvectors
eigvals, eigvecs = np.linalg.eigh(A) # eigh for symmetric!
# eigvals = [1.3820, 3.6180] (sorted ascending)
# eigvecs[:,0] ≈ [-0.851, 0.526] (min eigvec)
# eigvecs[:,1] ≈ [ 0.526, 0.851] (max eigvec)
# Verify: R(q_min) = lambda_min
q_min = eigvecs[:, 0]
print(rayleigh(A, q_min)) # → 1.3820 = lambda_min
# Verify: R(q_max) = lambda_max
q_max = eigvecs[:, 1]
print(rayleigh(A, q_max)) # → 3.6180 = lambda_max
# Power iteration: climbs Rayleigh quotient to lambda_max
v = np.random.randn(2)
for _ in range(20):
v = A @ v
v = v / np.linalg.norm(v) # renormalize
print(rayleigh(A, v)) # converges → 3.6180
