The formal language of mathematical reasoning — foundations for neuro-symbolic AI, SAT solvers, and knowledge graphs
Foundational Discrete Mathematics Neuro-Symbolic AI Must Know
1
Understanding the Concept
▼

Propositional logic is the simplest formal logic: it deals with propositions (statements that are either true or false) and connectives (and, or, not, if-then, if-and-only-if) that combine them. Think of it as the algebra of truth: just as algebra manipulates numbers, propositional logic manipulates truth values.

First-order logic (FOL) — also called predicate logic — goes further by introducing objects, predicates (properties and relations), and quantifiers (\(\forall\) "for all" and \(\exists\) "there exists"). It lets us make statements about entire domains: "All humans are mortal" or "There exists a prime greater than any given prime."

Real-World Analogy

Propositional logic is like a light-switch circuit: each switch is ON (true) or OFF (false), and wiring them in series (AND) or parallel (OR) gives a combined result. FOL adds loops over components: "every switch in this panel" or "some switch in this cabinet."

Key Insight

Logic is the bridge between syntax (symbolic rules) and semantics (meaning in the world). A formula is valid (tautology) if true under every assignment; satisfiable if true under some assignment; unsatisfiable (contradiction) if false under all assignments. SAT solvers decide satisfiability algorithmically — a central tool in neuro-symbolic AI.

Why it matters for AI: Neuro-symbolic AI aims to fuse neural networks (pattern recognition) with symbolic reasoning (logical inference). Differentiable logic layers embed propositional/FOL constraints into neural training; knowledge graphs encode FOL facts; and SAT/SMT solvers verify or guide neural network decisions.

Propositional Logic — Syntax, Semantics & SAT
▼

Syntax: Building Formulas

Propositional formulas are built inductively:

  • Atoms: propositional variables \(P, Q, R, \ldots\) (base truth-bearers)
  • Negation: \(\neg P\) — "not P"
  • Conjunction: \(P \wedge Q\) — "P and Q"
  • Disjunction: \(P \vee Q\) — "P or Q"
  • Implication: \(P \rightarrow Q\) — "if P then Q" (equivalent to \(\neg P \vee Q\))
  • Biconditional: \(P \leftrightarrow Q\) — "P if and only if Q"

Semantics: Truth Assignments

A truth assignment (or valuation) \(v: \text{Vars} \to \{0,1\}\) maps each variable to True/False. The truth value of a formula under \(v\) is computed recursively via the standard truth tables.

$$P \rightarrow Q \;\equiv\; \neg P \vee Q$$
$$P \leftrightarrow Q \;\equiv\; (P \rightarrow Q) \wedge (Q \rightarrow P)$$

Key Classifications

  • Tautology (valid): \(\phi\) is true for every assignment. Example: \(P \vee \neg P\) (Law of Excluded Middle).
  • Satisfiable: \(\phi\) is true for some assignment. Example: \(P \wedge Q\) (satisfied when both true).
  • Contradiction (unsatisfiable): \(\phi\) is false for all assignments. Example: \(P \wedge \neg P\).

Normal Forms & CNF

A formula is in Conjunctive Normal Form (CNF) if it is a conjunction of clauses, each clause being a disjunction of literals (variables or their negations). SAT solvers require CNF input:

$$(P \vee Q) \wedge (\neg P \vee R) \wedge (\neg Q \vee \neg R)$$

Every propositional formula can be converted to CNF (via Tseitin transformation, which may introduce auxiliary variables to avoid exponential blowup).

Common Misconception

\(P \rightarrow Q\) does not mean "P causes Q." It only means: it is not the case that P is true while Q is false. A false premise makes any implication vacuously true: "If the moon is cheese, then 2+2=5" is a true statement in propositional logic.

Resolution & DPLL

The resolution rule is the core of classical automated theorem proving:

$$\frac{C_1 \vee P \quad \neg P \vee C_2}{C_1 \vee C_2}$$

The DPLL algorithm (Davis–Putnam–Logemann–Loveland, 1962) decides SAT efficiently in practice via unit propagation, pure-literal elimination, and backtracking search. Modern CDCL (Conflict-Driven Clause Learning) solvers extend DPLL with learned clauses and can handle millions of variables.

First-Order Logic — Predicates, Quantifiers & Models
▼

Syntax of FOL

First-order logic extends propositional logic with:

  • Terms: constants (\(a, b, c\)), variables (\(x, y, z\)), and function symbols (\(f(x), \text{succ}(n)\))
  • Predicates: \(P(x)\), \(\text{Human}(x)\), \(\text{Loves}(x,y)\) — relations over objects
  • Universal quantifier: \(\forall x\, \phi(x)\) — "for all x in the domain, \(\phi(x)\) holds"
  • Existential quantifier: \(\exists x\, \phi(x)\) — "there exists x in the domain such that \(\phi(x)\) holds"
  • Equality: \(x = y\)

Classic Examples

$$\forall x\,[\text{Human}(x) \rightarrow \text{Mortal}(x)]$$
$$\text{Human}(\text{Socrates}) \vdash \text{Mortal}(\text{Socrates})$$
$$\forall x\,\exists y\,[x < y] \quad \text{(no largest natural number)}$$

Models & Satisfiability

A model \(\mathcal{M} = (D, I)\) consists of a non-empty domain \(D\) and an interpretation \(I\) assigning meaning to constants, functions, and predicates. A formula \(\phi\) is:

  • True in \(\mathcal{M}\) (written \(\mathcal{M} \models \phi\)) if \(\phi\) holds under the interpretation
  • Valid (logically true): true in all models
  • Satisfiable: true in some model

Decidability & Completeness

FOL satisfiability is semi-decidable (not fully decidable — Church–Turing, 1936). However, Gödel's Completeness Theorem (1929) guarantees: if a formula is logically valid, there exists a finite proof in any complete proof system (e.g., resolution, natural deduction).

Key Theorem — Gödel Completeness (1929)

A first-order formula \(\phi\) is logically valid if and only if it is provable in the predicate calculus: \(\models \phi \iff \vdash \phi\). This means the syntactic proof system perfectly captures semantic truth — completeness without gaps.

Prenex Normal Form

Every FOL formula can be converted to Prenex Normal Form (PNF): all quantifiers pulled to the front, followed by a quantifier-free matrix:

$$\forall x_1 \exists x_2 \forall x_3 \cdots \underbrace{[\phi(x_1, x_2, x_3, \ldots)]}_{\text{quantifier-free matrix}}$$

Neuro-Symbolic Connections

Knowledge Graphs encode FOL-style facts as triples \((\text{subject}, \text{predicate}, \text{object})\) — e.g., \((\text{Paris}, \text{capitalOf}, \text{France})\). Querying a KG is essentially FOL inference over an open-world assumption.
Differentiable Logic (LTN, DL2) embeds FOL formulas into loss functions: quantifiers become aggregations (\(\forall \to \min\), \(\exists \to \max\)), and connectives map to t-norms/t-conorms (e.g., product: \(P \wedge Q \mapsto p \cdot q\)).
SAT Solvers in AI Verification: Neural network properties (e.g., robustness bounds) are encoded as SAT/SMT queries and solved to certify or falsify the network's behaviour.

Why Logic Matters for Modern AI

Differentiable Logic: The Math

In Logic Tensor Networks (Serafini & d'Avila Garcez, 2016), truth values are real numbers in \([0,1]\) and connectives become differentiable operators (t-norms):

$$\text{Product t-norm:}\quad P \wedge Q \;\mapsto\; p \cdot q$$
$$\text{Product t-conorm:}\quad P \vee Q \;\mapsto\; p + q - p \cdot q$$
$$\text{Quantifiers:}\quad \forall x\,\phi(x) \;\mapsto\; \prod_{d \in D} \phi(d), \quad \exists x\,\phi(x) \;\mapsto\; \max_{d \in D} \phi(d)$$

These differentiable mappings allow backpropagation through logical constraints, enabling joint learning of neural predicates subject to FOL knowledge.

SAT Complexity

The Cook–Levin Theorem (1971)

SAT (propositional satisfiability) is NP-complete: every problem in NP polynomial-time reduces to SAT. Despite worst-case exponential complexity, modern CDCL solvers (MiniSat, CryptoMiniSat, Glucose) routinely handle industrial instances with \(10^6\)+ variables via learned clauses and VSIDs heuristics.

Key Takeaways

  • Propositional logic: finite alphabet of truth values + connectives. Decidable, NP-complete for SAT.
  • First-order logic: objects + predicates + quantifiers. Complete (Gödel 1929) but only semi-decidable for satisfiability.
  • Neuro-symbolic AI uses logic to constrain, verify, and interpret neural models — the most active frontier in trustworthy AI.
  • SAT solvers and knowledge graphs are the two dominant engineering artifacts of logic in practical AI systems.
If You Remember One Thing

Logic gives AI a formal contract: propositional logic handles truth-functional combinations (AND/OR/NOT), FOL handles quantified statements over objects, and modern neuro-symbolic systems embed both into differentiable learning pipelines — making neural networks both powerful and provably constrained.

Propositional SAT via DPLL (from scratch)

# Represent clauses as frozensets of signed integers (+i = var i, -i = neg var i)
def dpll(clauses, assignment={}):
# Base cases
if not clauses: return assignment # all clauses satisfied
if any(len(c)==0 for c in clauses): return None # empty clause = conflict
# Unit propagation: if clause has single literal, force its truth
units = [next(iter(c)) for c in clauses if len(c)==1]
for lit in units:
clauses = simplify(clauses, lit) # remove satisfied clauses
assignment[abs(lit)] = (lit > 0) # record assignment
# Choose a variable to branch on (VSIDS heuristic in production)
lit = next(iter(next(iter(clauses)))) # pick first literal
# Try lit = True
res = dpll(simplify(clauses, lit), {**assignment, abs(lit): True})
if res: return res
# Backtrack: try lit = False
return dpll(simplify(clauses, -lit), {**assignment, abs(lit): False})
def simplify(clauses, lit):
return [c - {-lit} for c in clauses if lit not in c]
# (P∨Q) ∧ (¬P∨R) ∧ (¬Q∨¬R) — CNF clauses as signed-int frozensets
clauses = [{1,2}, {-1,3}, {-2,-3}] # P=1, Q=2, R=3
result = dpll(clauses)
# result = {1: True, 2: False, 3: True} ← P=T, Q=F, R=T satisfies all clauses

Differentiable Logic (Product t-norm, NumPy)

import numpy as np
# Predicates as neural network outputs in [0,1]
Human = np.array([0.95, 0.02, 0.88]) # truth values for 3 entities
Mortal = np.array([0.91, 0.15, 0.84])
# FOL axiom: forall x. Human(x) -> Mortal(x)
# Implication: p -> q ≈ 1 - p + p*q (Łukasiewicz t-norm)
impl = 1 - Human + Human * Mortal # element-wise over domain
# Universal quantifier: forall = min (fuzzy) or geometric mean
sat_forall = impl.min() # 0.908 — nearly satisfied
# Loss: 1 - satisfaction (maximise axiom truth)
loss = 1 - sat_forall # 0.092
# Backprop through loss adjusts Human/Mortal predictor weights
