Understanding Capacity & Expressiveness
▼

What are they? In machine learning, a model's representation capacity refers to the set of functions it can theoretically represent or approximate. It's about the *potential* complexity of the relationships it can model. Expressiveness is closely related, often used interchangeably, but can emphasize the ability to represent *complex* or *non-linear* functions efficiently.

A simple linear model has low capacity (it can only represent linear functions). A deep neural network has high capacity (it can represent a vast range of complex, non-linear functions). More parameters generally mean more capacity, but the *architecture* (number of layers, type of non-linearities) plays an equally critical role in how that capacity translates into useful expressiveness.

Analogy: Imagine you want to draw a picture. A child with a single crayon (low capacity) can only draw simple lines. A skilled artist with a full box of 100 crayons (high capacity) can draw much more intricate and colorful images. Now, consider the tools: a ruler allows only straight lines (low expressiveness), while a flexible brush allows curves and complex shapes (high expressiveness). A network's capacity is like the number of crayons, and its expressiveness is like the flexibility of its brush — both are needed to create sophisticated "pictures" (functions).

💡 If you remember one thing

A model's capacity is primarily determined by its number of parameters (weights and biases), while its expressiveness (especially for non-linear functions) fundamentally relies on the presence and type of non-linear activation functions and its architectural depth.

2
How Capacity & Expressiveness Arise
▼

Parameters as Degrees of Freedom

Every weight and bias in a neural network is a tunable parameter. Each parameter acts like a "knob" that can be adjusted during training. A network with \(P\) parameters has \(P\) degrees of freedom, allowing it to potentially fit more complex patterns in the data. More parameters mean more unique configurations (functions) the network can represent.

The Crucial Role of Non-linearities

Without non-linear activation functions (like ReLU, sigmoid, or tanh), a stack of multiple linear layers (e.g., \(y = W_2(W_1 x + b_1) + b_2\)) would simply collapse into a single linear transformation (\(y = W_{eff} x + b_{eff}\)). This means a network without non-linearities, no matter how many layers it has, can only learn linear decision boundaries. Non-linearities allow the network to "bend" and "fold" the input space, enabling it to learn arbitrarily complex, non-linear functions.

Width vs. Depth: Different Paths to Expressiveness

Both increasing the number of neurons per layer (width) and increasing the number of layers (depth) contribute to a network's capacity and expressiveness:

  • Width: A wider network (more neurons in a hidden layer) can learn more diverse features in parallel. The Universal Approximation Theorem (discussed in Card 3) states that a sufficiently wide single-hidden-layer network can approximate any continuous function. However, very wide shallow networks can be inefficient, requiring many more parameters than a deep network for the same task.
  • Depth: A deeper network (more hidden layers) can learn hierarchical representations. Early layers might detect simple features (edges, textures), while later layers combine these into more abstract concepts (eyes, noses, faces). This hierarchical composition often allows deep networks to represent very complex functions more efficiently (with fewer total parameters) than shallow, wide networks. They can also capture long-range dependencies more effectively.
🔑 Key Property

Non-linear activation functions are the fundamental enablers of a neural network's ability to learn non-linear relationships. Without them, no amount of width or depth can make a network more expressive than a simple linear model.

3
Why It Works — The Math
▼

Linear Model: A Baseline of Limited Capacity

Consider a simple binary classification problem with input \(x \in \mathbb{R}^d\). A linear model computes an output \(y\) as:

$$y = w^\top x + b$$

where \(w \in \mathbb{R}^d\) is the weight vector and \(b \in \mathbb{R}\) is the bias. The decision boundary is defined by \(w^\top x + b = 0\), which is always a hyperplane (a line in 2D, a plane in 3D). This model has \(d+1\) parameters and can only separate linearly separable data.

The Universal Approximation Theorem (UAT)

The UAT is a cornerstone of neural network theory, stating that a feedforward network with a single hidden layer can approximate any continuous function on a compact subset of \(\mathbb{R}^n\), given enough hidden units and a "squashing" non-linearity. More formally:

Let \(\sigma\) be a non-constant, bounded, and monotonically increasing continuous function (e.g., sigmoid). Let \(I_m\) be the \(m\)-dimensional unit hypercube. Then for any continuous function \(f: I_m \to \mathbb{R}\) and any \(\varepsilon > 0\), there exists an integer \(N\) (number of hidden units), real constants \(v_i, b_i \in \mathbb{R}\), and real vectors \(w_i \in \mathbb{R}^m\) such that

$$F(x) = \sum_{i=1}^N v_i \sigma(w_i^\top x + b_i)$$

satisfies \(|F(x) - f(x)| < \varepsilon\) for all \(x \in I_m\).

This theorem implies that adding just one non-linear hidden layer is sufficient for universal approximation, provided that layer is wide enough. However, it doesn't specify *how wide* that layer needs to be, nor does it guarantee efficient learning or generalization.

Depth for Efficiency and Abstraction

While a single wide layer is theoretically sufficient, deep networks often achieve better performance with fewer parameters in practice. This is because deep networks can learn hierarchical representations, composing simpler features into more complex ones. For example, a 2-layer network with ReLU activations can be represented as:

$$h_1 = \max(0, W_1 x + b_1)$$ $$y = W_2 h_1 + b_2$$

Each neuron in the first hidden layer creates a hyperplane. The ReLU activation makes the region on one side of the hyperplane "active" and the other side "inactive." By combining multiple such activated hyperplanes, the network can form convex polyhedra. Deeper layers can then combine these polyhedra to form even more complex, non-convex decision regions, often more efficiently than a single wide layer trying to do it all at once.

⚠️ Capacity vs. Learning

High capacity is a necessary but not sufficient condition for a model to learn a complex function. A model might have enough capacity, but still fail to learn due to poor optimization, insufficient data, or inadequate regularization (leading to overfitting).

Key Takeaways
▼

When to increase capacity:

  • Your model is underfitting (both training and validation accuracy are low), indicating it's too simple to capture the underlying patterns in the data.
  • The problem involves highly complex, non-linear relationships that a simpler model cannot represent.
  • You have a large amount of high-quality training data that can support a more complex model without immediately overfitting.

When to be cautious with capacity:

  • Your model is overfitting (high training accuracy, low validation accuracy), meaning it's memorizing the training data rather than learning generalizable patterns.
  • Computational resources (memory, processing power) are limited, as larger models require significantly more of both.
  • The problem domain is intrinsically simple, and a simpler model might offer better interpretability and faster inference without sacrificing performance.
💡 Balancing Act

The goal is to find a model with sufficient capacity to learn the true data distribution, but not so much that it overfits to noise or becomes computationally intractable. Regularization techniques (like dropout, weight decay) are crucial tools for managing the *effective* capacity of a high-capacity model during training.

Code Trace (Simple 2-Layer Network)
▼
import numpy as np
def relu(x): return np.maximum(0, x)
def sigmoid(x): return 1 / (1 + np.exp(-x))
def tanh(x): return np.tanh(x)
class TwoLayerNet:
def __init__(self, input_size, h1_size, h2_size, output_size, activation_fn):
# Initialize weights and biases randomly
self.W1 = np.random.randn(input_size, h1_size) * 0.1
self.b1 = np.zeros((1, h1_size))
self.W2 = np.random.randn(h1_size, h2_size) * 0.1 if h2_size > 0 else None
self.b2 = np.zeros((1, h2_size)) if h2_size > 0 else None
self.W_out = np.random.randn(h2_size if h2_size > 0 else h1_size, output_size) * 0.1
self.b_out = np.zeros((1, output_size))
self.activation_fn = activation_fn
def forward(self, X):
# Hidden Layer 1
h1_pre = X @ self.W1 + self.b1
h1_act = self.activation_fn(h1_pre)
# Hidden Layer 2 (optional)
if self.W2 is not None:
h2_pre = h1_act @ self.W2 + self.b2
h2_act = self.activation_fn(h2_pre)
final_hidden_output = h2_act
else:
final_hidden_output = h1_act
# Output Layer (sigmoid for binary classification probability)
output_logits = final_hidden_output @ self.W_out + self.b_out
probabilities = sigmoid(output_logits)
return probabilities
def get_num_params(self):
num_params = self.W1.size + self.b1.size
if self.W2 is not None:
num_params += self.W2.size + self.b2.size
num_params += self.W_out.size + self.b_out.size
return num_params
