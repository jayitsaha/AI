Understanding the Jacobian
▼

What is it? When a function takes in multiple numbers and outputs multiple numbers (a "vector-valued" function), its derivative is not a single number — it is a matrix called the Jacobian. Each entry of the matrix tells you: "If I nudge this input by a tiny bit, how much does that particular output move?"

Analogy: Imagine a weather simulation that takes (temperature, humidity) as inputs and outputs (cloud coverage, rainfall). The Jacobian is like the sensitivity table: "Increasing temperature by 1° changes cloud coverage by A and rainfall by B; increasing humidity by 1% changes cloud coverage by C and rainfall by D." The Jacobian packages all four sensitivities into one 2×2 table.

Geometric meaning: Near any point \(\mathbf{x}_0\), a smooth function \(f\) looks like a linear map — and the Jacobian \(J\) is exactly that linear map. Infinitesimally, \(J\) stretches and rotates space: a tiny circle of inputs becomes an ellipse in output space, with shape determined by \(J\).

💡 If you remember one thing

The Jacobian \(J_f(\mathbf{x})\) is the matrix of all first-order partial derivatives: entry \((i,j)\) is \(\partial f_i / \partial x_j\). It is the "best linear approximation" to \(f\) near \(\mathbf{x}\), and the chain rule for vector functions is just Jacobian matrix multiplication: \(J_{g \circ f}(\mathbf{x}) = J_g(f(\mathbf{x})) \cdot J_f(\mathbf{x})\). This is exactly what happens in backpropagation.

Definition & Internal Mechanics
▼

Formal Definition

Let \(f: \mathbb{R}^n \to \mathbb{R}^m\) be a differentiable function, written component-wise as \(f(\mathbf{x}) = (f_1(\mathbf{x}), \ldots, f_m(\mathbf{x}))^\top\). The Jacobian matrix \(J_f(\mathbf{x}) \in \mathbb{R}^{m \times n}\) is:

$$J_f(\mathbf{x}) = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix}$$

Row \(i\) of \(J_f\) is the gradient of \(f_i\) — how the \(i\)-th output responds to all inputs. Column \(j\) of \(J_f\) shows how all outputs respond to nudging the \(j\)-th input.

Worked Example: \(f(x,y) = (3x + y,\ x + 2y)\)

With \(f_1 = 3x+y\) and \(f_2 = x+2y\), the Jacobian is constant (since \(f\) is linear):

$$J_f = \begin{bmatrix} \partial f_1/\partial x & \partial f_1/\partial y \\ \partial f_2/\partial x & \partial f_2/\partial y \end{bmatrix} = \begin{bmatrix} 3 & 1 \\ 1 & 2 \end{bmatrix}$$

The Local Linear Approximation

For any small displacement \(\Delta\mathbf{x}\) from point \(\mathbf{x}_0\):

$$f(\mathbf{x}_0 + \Delta\mathbf{x}) \approx f(\mathbf{x}_0) + J_f(\mathbf{x}_0)\, \Delta\mathbf{x}$$

This is the multivariable Taylor expansion to first order. The Jacobian is the coefficient that tells you how the output changes linearly in response to any input perturbation.

🔑 Key Property

The Jacobian has shape \(m \times n\) for \(f: \mathbb{R}^n \to \mathbb{R}^m\). Special cases: when \(m=1\), \(J_f\) is a row vector (the gradient \(\nabla f^\top\)); when \(m=n\), \(J_f\) is square and \(|\det J_f|\) gives the local volume scaling factor.

Chain Rule & Determinant — The Math
▼

Chain Rule for Vector Functions

Given \(f: \mathbb{R}^n \to \mathbb{R}^k\) and \(g: \mathbb{R}^k \to \mathbb{R}^m\), the composition \(h = g \circ f: \mathbb{R}^n \to \mathbb{R}^m\) has Jacobian:

$$J_h(\mathbf{x}) = J_g(f(\mathbf{x}))\, J_f(\mathbf{x})$$

This is just matrix multiplication. Each Jacobian maps differentials: \(df = J_f\, dx\), then \(dg = J_g\, df = J_g J_f\, dx\). The chain is the product of matrices evaluated at the appropriate points.

Numerical Trace: Composing \(f\) and \(g\)

Let \(J_f = \begin{bmatrix}2&0\\0.5&1.5\end{bmatrix}\), \(J_g = \begin{bmatrix}1&1\\0&2\end{bmatrix}\). Then:

$$J_{g \circ f} = J_g \cdot J_f = \begin{bmatrix}1&1\\0&2\end{bmatrix}\begin{bmatrix}2&0\\0.5&1.5\end{bmatrix} = \begin{bmatrix}2.5&1.5\\1&3\end{bmatrix}$$

The Determinant: Local Area Scaling

When \(m = n\) (same input and output dimensions), \(|\det J_f(\mathbf{x})|\) measures how much \(f\) locally scales volumes. A unit disk in input space gets mapped to an ellipse in output space with area \(|\det J_f| \cdot \pi r^2\).

$$\text{Area}(f(\text{disk}_r)) \approx |\det J_f(\mathbf{x}_0)| \cdot \pi r^2$$

For our \(J_f = \begin{bmatrix}3&1\\1&2\end{bmatrix}\): \(\det J_f = 3 \cdot 2 - 1 \cdot 1 = 5\). A circle of radius 0.25 (area \(\approx 0.196\)) maps to an ellipse of area \(\approx 5 \times 0.196 = 0.982\). (Verified: semi-axes \(3.618 \times 0.25 = 0.904\) and \(1.382 \times 0.25 = 0.346\), area \(= \pi \times 0.904 \times 0.346 \approx 0.982\) ✓)

Connection to Backpropagation

In a neural network with layers \(\mathbf{a}^{(1)} = f^{(1)}(\mathbf{x})\), \(\mathbf{a}^{(2)} = f^{(2)}(\mathbf{a}^{(1)})\), …, the chain rule gives:

$$\frac{\partial L}{\partial \mathbf{x}} = \left(J_{f^{(1)}}(\mathbf{x})\right)^\top \cdot \left(J_{f^{(2)}}(\mathbf{a}^{(1)})\right)^\top \cdots \left(\frac{\partial L}{\partial \mathbf{a}^{(K)}}\right)$$

Backprop is precisely this: multiply Jacobian transposes from the output layer back to the input. Modern autodiff frameworks compute these products efficiently using the vector-Jacobian product (VJP) — they never form the full Jacobian, just apply \(J^\top \mathbf{v}\) for the upstream gradient vector \(\mathbf{v}\).

⚠️ Common Confusion

Row vs. column convention: Some texts define \(J_f\) as the transpose of what's shown here (a numerator-layout convention where column \(i\) is the gradient of \(f_i\)). Always check: in the denominator-layout (used here and by most ML frameworks), \(J_f \in \mathbb{R}^{m \times n}\) has rows = outputs, columns = inputs.

▼

When does \(|\det J|\) matter?

  • Change of variables in integration: \(\int g(f(\mathbf{x}))|\det J_f(\mathbf{x})|\,d\mathbf{x}\)
  • Normalizing flows: Log-likelihood requires \(\log|\det J|\) for each bijective layer
  • Newton's method (vector): \(\mathbf{x}_{k+1} = \mathbf{x}_k - J_f^{-1}(\mathbf{x}_k) f(\mathbf{x}_k)\) — needs invertible \(J\)
  • Jacobian regularization: Penalizing \(\|J_f\|_F^2\) improves adversarial robustness
💡 Backprop in one line

Backprop = repeated left-multiplication by Jacobian transposes, starting from \(\partial L/\partial \mathbf{output}\) and working backwards. Frameworks call this a VJP (vector-Jacobian product): they compute \(\mathbf{v}^\top J_f\) without ever materializing the full \(m \times n\) Jacobian — keeping memory \(O(n+m)\) instead of \(O(mn)\).

Code Trace — Jacobian & Chain Rule in NumPy
▼
import numpy as np
# f(x,y) = (3x + y, x + 2y) [linear, so J is constant]
def f1(v):
x, y = v
return np.array([3*x + y, x + 2*y])
# Analytical Jacobian of f1
J1 = np.array([[3., 1.],
[1., 2.]]) # shape (2,2): df_i/dx_j
print("det(J1) =", np.linalg.det(J1)) # 5.0
# Singular values → ellipse semi-axes
U, S, Vt = np.linalg.svd(J1)
print("Singular values:", S) # [3.618, 1.382]
# Circle of radius r mapped to ellipse
r = 0.25
thetas = np.linspace(0, 2*np.pi, 200)
circle = np.array([r*np.cos(thetas), r*np.sin(thetas)]) # (2, 200)
ellipse = J1 @ circle # (2, 200) — each column transformed
# Chain rule: g: R^2->R^2 followed by f1
J2 = np.array([[1., 1.],
[0., 2.]]) # Jacobian of g
J_chain = J2 @ J1 # chain rule = matrix product
print("J_chain =\n", J_chain) # [[2.5,1.5],[1.,3.]]
print("det(J_chain) =", np.linalg.det(J_chain)) # 6.0
# Backprop: upstream gradient v, VJP = v^T @ J
v = np.array([1., 0.]) # upstream gradient
vjp = v @ J_chain # vector-Jacobian product
print("VJP:", vjp) # gradient w.r.t. input
