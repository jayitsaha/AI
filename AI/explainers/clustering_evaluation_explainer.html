Clustering Evaluation Metrics

From silhouette scores to ARI — how to measure clustering quality with and without ground truth

Intermediate Unsupervised Learning 6 Metrics No Labels vs Ground Truth

ⓘ Understanding Clustering Evaluation

▼

Evaluating clustering is fundamentally different from evaluating supervised models. In classification, you have ground truth labels and can directly compare predictions. In clustering, you often don't — you're discovering structure, not recovering it.

Internal Metrics

Use only the data and the cluster assignments themselves. No ground truth labels needed. They measure compactness (how tight are clusters?) and separation (how far apart are clusters?). Best for: tuning k, comparing algorithms when you have no labels.

External Metrics

Compare predicted cluster assignments against known ground truth labels. Used when you have labeled data and want to benchmark how well clustering recovers the true structure. Best for: benchmarking algorithms, research evaluation, validating assumptions.

💡
The 6 metrics covered: Silhouette Score, Calinski-Harabasz (CH) Index, Davies-Bouldin (DB) Index (internal) and Adjusted Rand Index (ARI), Normalized Mutual Information (NMI), V-measure (external).

◆ Internal Metrics Deep Dive

▼
Silhouette Score
$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$

\(a(i)\) = mean distance from point \(i\) to all other points in the same cluster (intra-cluster cohesion).
\(b(i)\) = mean distance from point \(i\) to all points in the nearest other cluster (inter-cluster separation).
Range: \([-1, +1]\). Higher is better. Values near +1 mean well-separated clusters; near 0 means overlapping; negative means misassigned.

Calinski-Harabasz Index
$$CH = \frac{SS_B / (k-1)}{SS_W / (n-k)}$$

\(SS_B\) = sum of squared distances between cluster centroids and the global centroid (between-cluster scatter).
\(SS_W\) = sum of squared distances within clusters (within-cluster scatter).
Range: \([0, \infty)\). Higher is better. Not bounded, so only meaningful for comparison across models on the same dataset.

Davies-Bouldin Index
$$DB = \frac{1}{k} \sum_{i=1}^{k} \max_{j \neq i} \frac{s_i + s_j}{d(c_i, c_j)}$$

\(s_i\) = average distance of points in cluster \(i\) to its centroid (average scatter).
\(d(c_i, c_j)\) = distance between centroids of clusters \(i\) and \(j\).
Range: \([0, \infty)\). Lower is better. DB measures the worst-case (max) similarity between each cluster and its most similar neighbor.

a(i) intuition

Think of a(i) as measuring how "tight" the cluster is for point i. Small a(i) means the point is close to its cluster mates — good cohesion. If a(i) is large, the point may be on the cluster's fringe.

b(i) intuition

Think of b(i) as measuring "how far" the point is from the neighboring cluster. Large b(i) means the clusters are well separated. The "nearest cluster" is the one with the smallest mean distance to point i.

CH vs DB trade-off

CH rewards globular, well-separated clusters (ANOVA-style). DB penalises clusters with high intra-scatter relative to centroid distance. They can disagree when clusters are elongated or of unequal size.

◆ External Metrics Deep Dive

▼
Adjusted Rand Index (ARI)
$$ARI = \frac{RI - E[RI]}{\max(RI) - E[RI]}$$

RI (Rand Index) counts the fraction of pairs that are consistently grouped (both in the same cluster or both in different clusters).
The adjustment subtracts the expected value under random label assignment, making ARI = 0 for random clusterings.
Range: \((-1, +1]\). ARI = 1 is perfect; ARI = 0 is random; negative values are worse than random.

Normalized Mutual Information
$$NMI = \frac{2 \cdot I(Y; C)}{H(Y) + H(C)}$$

\(I(Y; C)\) = mutual information between true labels \(Y\) and cluster assignments \(C\).
\(H(Y)\), \(H(C)\) = Shannon entropies of the label and cluster distributions.
Range: \([0, 1]\). NMI = 1 is perfect; NMI = 0 means the clustering provides no information about the labels. Symmetric metric.

V-measure
$$V = \frac{2 \cdot h \cdot c}{h + c}$$

\(h\) = homogeneity: each cluster contains only members of a single class (like precision).
\(c\) = completeness: all members of a class are in the same cluster (like recall).
Range: \([0, 1]\). V-measure is the harmonic mean of h and c — analogous to F1 for clustering. Not chance-corrected.

Why ARI over raw RI?

Raw Rand Index is biased: even random partitions can achieve high values simply because most pairs happen to be in different clusters. ARI corrects for this expectation, giving 0 to random and enabling fair comparison.

NMI information view

NMI asks: "How many bits of information about the true class can I infer from knowing the cluster?" High MI means clusters align well with classes. Normalization puts it in [0,1] regardless of cluster count.

Homogeneity vs Completeness

A clustering is homogeneous if no cluster mixes classes (each predicted cluster = one true class). It is complete if no class spans multiple clusters. V-measure trades off these two goals like precision and recall.

✓ Key Takeaways & When to Use Which

▼

Choosing the right metric depends on whether you have ground truth labels, what scale you're working at, and what aspect of cluster quality matters most to you.

Metric Type Has Labels? Scale Invariant? Range Best For
Silhouette Internal No Yes [-1, +1] Interpretable per-point quality, choosing k
Calinski-Harabasz Internal No No [0, ∞) Dense, well-separated clusters; fast computation
Davies-Bouldin Internal No Yes [0, ∞) Worst-case cluster pair analysis; lower = better
ARI External Yes Yes (-1, +1] Benchmarking; chance-corrected; symmetric clusters
NMI External Yes Yes [0, 1] Information-theoretic view; different cluster counts
V-measure External Yes Yes [0, 1] Diagnosing homogeneity vs completeness trade-off
⚠
Common pitfall: Using only one metric. ARI can be near zero for a reasonable clustering if the number of clusters differs from ground truth. Always report at least one internal and (if labels are available) one external metric. For production without labels, use Silhouette + DB together.
