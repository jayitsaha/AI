Understanding Bijective Transformations
▼

What is it? A bijective transformation (or bijection) is a function that is both injective (one-to-one, distinct inputs map to distinct outputs) and surjective (onto, every possible output is mapped to by at least one input). In simpler terms, it's a mapping that has a well-defined inverse: for every output, there's exactly one input that produced it.

Why is it important? In probability and statistics, we often need to understand how a random variable's distribution changes when we apply a function to it. If that function is bijective, we can precisely relate the original probability density function (PDF) to the new one. In calculus, bijectivity is key for changing variables in integrals, allowing us to simplify complex integration regions or functions.

Analogy: Imagine you have a stretchy rubber sheet with a grid drawn on it, representing one coordinate system (say, \(u\)-space). You stretch, twist, or bend this sheet without tearing it or folding it over itself, creating a new grid (say, \(v\)-space). A bijective transformation is like this stretching: every point on the original sheet corresponds to exactly one point on the stretched sheet, and vice-versa. If you tore the sheet, it wouldn't be surjective; if you folded it, it wouldn't be injective.

💡 If you remember one thing

A bijective transformation \(v = T(u)\) means that for every \(v\), there's a unique \(u = T^{-1}(v)\). This uniqueness is crucial for determining how probability densities or infinitesimal volumes scale when moving from one coordinate system to another. The scaling factor is given by the Jacobian determinant.

2
How Change of Variables Works Internally
▼

The Core Idea: Conserving Probability Mass

When we transform a random variable \(U\) with PDF \(p_U(u)\) into a new random variable \(V = T(U)\), the total probability mass must be conserved. That is, the probability that \(U\) falls into an infinitesimal region \(dU\) around \(u\) must equal the probability that \(V\) falls into the corresponding transformed region \(dV\) around \(v = T(u)\).

$$P(U \in dU) = p_U(u)\,|dU| \quad \text{and} \quad P(V \in dV) = p_V(v)\,|dV|$$

For these to be equal, \(p_U(u)\,|dU| = p_V(v)\,|dV|\). This implies \(p_V(v) = p_U(u) \frac{|dU|}{|dV|}\). The ratio of infinitesimal volumes \(\frac{|dU|}{|dV|}\) is exactly \(\left|\det\left(\frac{\partial u}{\partial v}\right)\right|\), or equivalently, \(\frac{1}{\left|\det\left(\frac{\partial v}{\partial u}\right)\right|}\).

The Jacobian Determinant: The Volume Scaling Factor

For a differentiable transformation \(T: \mathbb{R}^n \to \mathbb{R}^n\) defined by \(v = T(u)\), where \(u = (u_1, \dots, u_n)\) and \(v = (v_1, \dots, v_n)\), the Jacobian matrix \(J_T\) (or \(\frac{\partial v}{\partial u}\)) contains all first-order partial derivatives:

$$J_T = \frac{\partial v}{\partial u} = \begin{pmatrix} \frac{\partial v_1}{\partial u_1} & \cdots & \frac{\partial v_1}{\partial u_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial v_n}{\partial u_1} & \cdots & \frac{\partial v_n}{\partial u_n} \end{pmatrix}$$

The absolute value of its determinant, \(|\det(J_T)|\), tells us how an infinitesimal volume element \(|dU|\) in \(u\)-space is scaled when transformed into \(|dV|\) in \(v\)-space: \(|dV| = |\det(J_T)|\,|dU|\). This is the fundamental link between the two coordinate systems.

Design Decision: Why the Absolute Value?

The determinant of the Jacobian can be negative, indicating that the transformation flips the orientation of the coordinate system (e.g., a reflection). However, probability densities and volumes must always be non-negative. Therefore, we always take the absolute value of the Jacobian determinant to ensure that the scaling factor correctly represents the ratio of volumes.

🔑 Key Property

For a bijective transformation \(v = T(u)\), the probability density function \(p_V(v)\) of the transformed variable \(V\) is given by: $$p_V(v) = p_U(T^{-1}(v)) \left|\det\left(\frac{\partial u}{\partial v}\right)\right| = p_U(T^{-1}(v)) \left|\det\left(\frac{\partial T^{-1}(v)}{\partial v}\right)\right|$$ Using the inverse function theorem, \(\left|\det\left(\frac{\partial T^{-1}(v)}{\partial v}\right)\right| = \frac{1}{\left|\det\left(\frac{\partial T(u)}{\partial u}\right)\right|}\) evaluated at \(u = T^{-1}(v)\). So, the formula is often written as: $$p_V(v) = p_U(T^{-1}(v)) \frac{1}{\left|\det\left(\frac{\partial T(u)}{\partial u}\right)\right|_{u=T^{-1}(v)}}$$

3
Why It Works — The Math
▼

Derivation for Probability Density Functions

Let \(U\) be a continuous random variable with PDF \(p_U(u)\). Let \(V = T(U)\) be a new random variable, where \(T\) is a differentiable bijection. We want to find \(p_V(v)\).

Consider the cumulative distribution function (CDF) for \(V\):

$$F_V(v) = P(V \le v) = P(T(U) \le v)$$

Since \(T\) is a bijection, its inverse \(T^{-1}\) exists. Assuming \(T\) is monotonically increasing (or decreasing, handled by absolute value), we can write:

$$F_V(v) = P(U \le T^{-1}(v)) = F_U(T^{-1}(v))$$

To find the PDF \(p_V(v)\), we differentiate \(F_V(v)\) with respect to \(v\) using the chain rule:

$$p_V(v) = \frac{d}{dv} F_V(v) = \frac{d}{dv} F_U(T^{-1}(v)) = p_U(T^{-1}(v)) \cdot \frac{d}{dv} T^{-1}(v)$$

For multi-dimensional \(u\) and \(v\), the scalar derivative \(\frac{d}{dv} T^{-1}(v)\) is replaced by the absolute value of the determinant of the Jacobian of the inverse transformation, \(\left|\det\left(\frac{\partial T^{-1}(v)}{\partial v}\right)\right|\). Thus, the general formula for PDFs is:

$$p_V(v) = p_U(T^{-1}(v)) \left|\det\left(\frac{\partial T^{-1}(v)}{\partial v}\right)\right|$$

Using the Inverse Function Theorem, we know that \(\det\left(\frac{\partial T^{-1}(v)}{\partial v}\right) = \frac{1}{\det\left(\frac{\partial T(u)}{\partial u}\right)}\) where \(u = T^{-1}(v)\). Therefore, we can write the formula in terms of the Jacobian of \(T\):

$$p_V(v) = p_U(T^{-1}(v)) \frac{1}{\left|\det\left(\frac{\partial T(u)}{\partial u}\right)\right|_{u=T^{-1}(v)}}$$
⚠️ When Bijectivity Fails

If \(T\) is not bijective (e.g., \(V = U^2\), where two \(U\) values map to one \(V\) value), the formula above is insufficient. You must sum over all possible inverse mappings: \(p_V(v) = \sum_{u \in T^{-1}(v)} p_U(u) \left|\det\left(\frac{\partial T^{-1}(v)}{\partial v}\right)\right|\). If \(T\) is not differentiable, the Jacobian is undefined, and other techniques (like convolution for sums of random variables) are needed.

Key Takeaways
▼

When to use change of variables:

  • Probability: To find the PDF of a transformed random variable (e.g., \(Y = \log X\), \(Z = X+Y\)).
  • Integration: To simplify integrals by changing coordinate systems (e.g., Cartesian to polar/spherical, or arbitrary non-linear transformations).
  • Machine Learning: Fundamental to normalizing flows (generative models that learn complex distributions by chaining simple bijective transformations).
  • Physics/Engineering: Transforming coordinate systems in vector calculus, fluid dynamics, electromagnetism.

Important considerations:

  • Bijectivity: The transformation \(T\) must be one-to-one and onto for a unique inverse \(T^{-1}\) to exist. If not, the formula needs modification (summing over multiple inverse branches).
  • Differentiability: \(T\) must be continuously differentiable for the Jacobian to be well-defined.
  • Absolute Value: Always use the absolute value of the Jacobian determinant, as probability densities and volumes cannot be negative.
💡 Big Picture

The change of variables formula is a cornerstone of multivariate calculus and probability theory, allowing us to seamlessly translate concepts and quantities (like volume, area, or probability density) between different coordinate systems, provided the transformation is well-behaved (bijective and differentiable).

Code Trace (Python/NumPy)
▼
import numpy as np
# 1. Define the original PDF (e.g., uniform on [0,1]x[0,1])
def p_U(u_x, u_y):
if 0 <= u_x <= 1 and 0 <= u_y <= 1:
return 1.0
return 0.0
# 2. Define the transformation T: U -> V
# Example: Shear transformation v_x = u_x + k*u_y, v_y = u_y
def T_transform(u_x, u_y, k):
v_x = u_x + k * u_y
v_y = u_y
return v_x, v_y
# 3. Define the inverse transformation T_inv: V -> U
def T_inverse(v_x, v_y, k):
u_y = v_y
u_x = v_x - k * u_y
return u_x, u_y
# 4. Compute the Jacobian matrix of T
# J_T = [[dv_x/du_x, dv_x/du_y],
# [dv_y/du_x, dv_y/du_y]]
def compute_jacobian_T(u_x, u_y, k):
dvx_dux = 1
dvx_duy = k
dvy_dux = 0
dvy_duy = 1
return np.array([[dvx_dux, dvx_duy], [dvy_dux, dvy_duy]])
# 5. Compute the Jacobian determinant of T
def det_jacobian_T(u_x, u_y, k):
jacobian = compute_jacobian_T(u_x, u_y, k)
return np.linalg.det(jacobian)
# 6. Apply the change of variables formula for p_V(v)
def p_V(v_x, v_y, k):
u_x, u_y = T_inverse(v_x, v_y, k)
# Evaluate p_U at the inverse point
pu_at_u = p_U(u_x, u_y)
# Calculate the absolute Jacobian determinant of T at u
abs_det_J_T = np.abs(det_jacobian_T(u_x, u_y, k))
if abs_det_J_T == 0: # Avoid division by zero if transformation is degenerate
return 0.0
return pu_at_u / abs_det_J_T
# Example usage:
shear_factor = 0.5
test_u = (0.2, 0.3)
test_v = T_transform(test_u[0], test_u[1], shear_factor)
print(f"Original point u: {test_u}")
print(f"Transformed point v: {test_v}")
print(f"p_U(u): {p_U(test_u[0], test_u[1])}")
print(f"p_V(v): {p_V(test_v[0], test_v[1], shear_factor)}")
