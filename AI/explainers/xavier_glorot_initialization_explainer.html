Understanding Xavier/Glorot Initialization
▼

What is it? When you build a deep network, every layer's weights get initialized before training starts. If those initial weights are too small, the signal passed forward shrinks to nothing by the last layer. If they're too large, the signal blows up and saturates the activation function. Xavier (a.k.a. Glorot) initialization picks the initial weight variance so that the signal — and, symmetrically, the gradient flowing backward — keeps roughly the same variance at every layer.

Analogy: Think of a long line of people passing a whispered message down a hallway (a "telephone game" relay). If each person whispers too quietly (weights too small), the message is inaudible by the last person. If each person shouts (weights too large), everyone downstream just hears distorted noise (saturation). Xavier initialization tells each person exactly how loudly to speak so the message arrives at the other end at roughly its original volume — no matter how long the hallway (how deep the network) is.

Named after Xavier Glorot, who introduced it with Yoshua Bengio in 2010, this scheme is designed specifically for symmetric, zero-centered activations like tanh and sigmoid, where the function behaves approximately linearly near zero.

💡 If you remember one thing

Xavier/Glorot init draws each weight from a distribution with variance $$\operatorname{Var}(W) = \frac{2}{n_{in} + n_{out}}$$ where \(n_{in}\) and \(n_{out}\) are the layer's fan-in and fan-out. This variance is the "sweet spot" that keeps both the forward activation variance and the backward gradient variance approximately constant across depth.

How It Works Internally
▼

The Problem: Naive Initialization Breaks Deep Nets

Before Glorot & Bengio's 2010 analysis, weights were commonly initialized from a fixed-scale distribution, e.g. \(W \sim \mathcal{N}(0, 0.01^2)\) or \(U[-1,1]\), regardless of layer width. A layer's pre-activation is \(z = Wx\), so \(\operatorname{Var}(z)\) scales with the number of inputs \(n_{in}\) summed. With a fixed small weight variance, \(\operatorname{Var}(z)\) shrinks geometrically with depth — activations collapse toward 0 (the tanh/sigmoid vanishing-signal regime). With a fixed large weight variance, \(\operatorname{Var}(z)\) explodes — activations saturate at \(\pm 1\) (tanh) or \(0/1\) (sigmoid), where the local gradient is nearly 0, killing backprop anyway.

The Insight: Variance Must Depend on Layer Width

Glorot & Bengio's fix: the initialization variance must scale inversely with the number of connections a unit has, so that summing more inputs is compensated by each individual weight contributing less. Two separate requirements emerge:

  • Forward stability: to keep \(\operatorname{Var}(\text{activation})\) constant layer-to-layer, we need \(\operatorname{Var}(W) = 1/n_{in}\).
  • Backward stability: to keep the variance of the gradient signal constant as it flows backward through \(W^\top\), we need \(\operatorname{Var}(W) = 1/n_{out}\).

Since \(n_{in} \neq n_{out}\) in general, both cannot be satisfied exactly with one shared weight matrix. Glorot & Bengio's compromise is the harmonic-mean-style average of the two targets: \(\operatorname{Var}(W) = 2/(n_{in}+n_{out})\) — balancing forward and backward signal preservation simultaneously.

Design Decision: Why Average Instead of Picking One?

Using only \(1/n_{in}\) (this is essentially "LeCun initialization") preserves the forward pass exactly but lets backward gradient variance drift with \(n_{out}/n_{in}\). Using only \(1/n_{out}\) does the reverse. Averaging gives a variance that is exact when \(n_{in}=n_{out}\) (very common in practice — most hidden layers are the same width) and only mildly off otherwise, trading a small approximation error in exchange for controlling both directions of signal flow at once.

🔑 Key Property

Xavier init is a variance-preservation scheme: it is derived so that, under the linear approximation of tanh/sigmoid near zero, \(\operatorname{Var}(\text{activation}_\ell) \approx \operatorname{Var}(\text{activation}_{\ell-1})\) for every layer \(\ell\) — the signal neither vanishes nor explodes as depth grows.

Why It Works — The Math
▼

Setup & Assumptions

Consider a single fully-connected layer: \(z_j = \sum_{i=1}^{n_{in}} w_{ij} x_i\), where weights \(w_{ij}\) are i.i.d. with \(\mathbb{E}[w_{ij}]=0\), and inputs \(x_i\) are i.i.d. with \(\mathbb{E}[x_i]=0\), independent of the weights. Near zero, \(\tanh(z)\approx z\) and \(\sigma(z) \approx \tfrac14 z + \tfrac12\), so activations are treated as approximately linear for this derivation.

Forward Variance Propagation

Because the \(n_{in}\) terms \(w_{ij}x_i\) are independent and zero-mean:

$$\operatorname{Var}(z_j) = \sum_{i=1}^{n_{in}} \operatorname{Var}(w_{ij}x_i) = n_{in}\cdot \operatorname{Var}(w)\cdot \operatorname{Var}(x)$$

using \(\operatorname{Var}(w_{ij}x_i) = \mathbb{E}[w_{ij}^2]\mathbb{E}[x_i^2] - (\mathbb{E}[w_{ij}]\mathbb{E}[x_i])^2 = \operatorname{Var}(w)\operatorname{Var}(x)\) since both means are 0. To make \(\operatorname{Var}(z) = \operatorname{Var}(x)\) — i.e. the signal keeps the same scale after this layer — we need:

$$n_{in}\cdot\operatorname{Var}(w) = 1 \;\;\Longrightarrow\;\; \operatorname{Var}(w) = \frac{1}{n_{in}}$$

Backward Variance Propagation

By an identical argument applied to the backward pass \(\delta_x = W^\top \delta_z\) (each input receives a sum over \(n_{out}\) output gradients), preserving gradient variance requires:

$$\operatorname{Var}(w) = \frac{1}{n_{out}}$$

The Compromise

Averaging the two constraints gives the Glorot variance:

$$\operatorname{Var}(W) = \frac{2}{n_{in}+n_{out}}$$

Uniform form — since \(\operatorname{Var}\big(U[-a,a]\big) = a^2/3\), solve \(a^2/3 = 2/(n_{in}+n_{out})\):

$$W \sim U\!\left[-\sqrt{\dfrac{6}{n_{in}+n_{out}}},\; \sqrt{\dfrac{6}{n_{in}+n_{out}}}\right]$$

Normal form — sample directly with the target variance:

$$W \sim \mathcal{N}\!\left(0,\; \dfrac{2}{n_{in}+n_{out}}\right)$$
⚠️ Common Misconception

Xavier init assumes the activation is linear near 0 (true for tanh/sigmoid close to the origin, and exactly true if there's no nonlinearity at all). ReLU violates this: it zeroes out half the pre-activations, halving the effective variance and shifting the mean away from 0. Using Xavier variance with ReLU networks systematically under-scales the weights — this is precisely why He/Kaiming initialization (\(\operatorname{Var}(W)=2/n_{in}\)) was later derived for ReLU-family activations.

Key Takeaways
▼

When to use Xavier/Glorot:

  • Fully-connected or convolutional layers followed by tanh or sigmoid activations
  • Any architecture relying on the activation being approximately linear/symmetric near 0
  • RNN weight matrices using tanh/sigmoid gates (with care around recurrent weights)

When NOT to use:

  • ReLU / Leaky ReLU / GELU networks — use He (Kaiming) initialization instead (\(\operatorname{Var}(W)=2/n_{in}\))
  • Networks with normalization layers (BatchNorm/LayerNorm) right after each linear layer — init matters much less since normalization re-centers/re-scales activations anyway
  • Networks with residual/skip connections at very large depth — modern schemes (e.g. scaled/He variants, or explicit residual-branch scaling) are typically preferred
💡 Big Picture

Every principled initialization scheme — LeCun, Xavier/Glorot, He/Kaiming — solves the same equation, \(\operatorname{Var}(W)\cdot n = \text{const}\), just tuned for a different activation function's local linear/nonlinear behavior near 0. Understanding Xavier's derivation is the key that unlocks all of them.

Code Trace

import numpy as np
# Fan-in / fan-out for a Linear(64 -> 64) layer
n_in, n_out = 64, 64
# Xavier/Glorot normal initialization
var_xavier = 2.0 / (n_in + n_out)
W = np.random.randn(n_in, n_out) * np.sqrt(var_xavier)
# Equivalent Xavier/Glorot uniform initialization
a = np.sqrt(6.0 / (n_in + n_out))
W_uniform = np.random.uniform(-a, a, size=(n_in, n_out))
# Forward pass through L tanh layers, tracking variance
a_l = np.random.randn(n_in) # unit-variance input
for l in range(8):
W_l = np.random.randn(n_in, n_out) * np.sqrt(var_xavier)
z_l = W_l @ a_l
a_l = np.tanh(z_l)
print(f"layer {l}: Var(activation) = {a_l.var():.4f}")
# PyTorch equivalent (production usage)
import torch.nn as nn
layer = nn.Linear(64, 64)
nn.init.xavier_normal_(layer.weight, gain=nn.init.calculate_gain('tanh'))
nn.init.zeros_(layer.bias)
