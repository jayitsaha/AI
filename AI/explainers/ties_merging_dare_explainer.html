TIES-Merging & DARE

Merging fine-tuned LLMs by trimming, electing, summing, disentangling, and rescaling delta weights
Intermediate Deep Learning LLM Merging O(P) per parameter
1
Understanding TIES-Merging, DARE
▼

What is it? TIES-Merging (Trim, Elect, Sum) and DARE (Disentangling and Rescaling) are techniques to combine multiple fine-tuned Large Language Models (LLMs) into a single, more capable model. Instead of naively averaging model weights (which often leads to "catastrophic forgetting" of individual capabilities), TIES-Merging intelligently selects and combines only the "important" changes (delta weights) from each fine-tuned model. DARE further refines this by randomly pruning and rescaling these selected deltas to prevent saturation and improve generalization.

Analogy: Imagine you have a base "general knowledge" expert, and several "specialist" experts, each fine-tuned on a specific topic (e.g., medical, legal, creative writing). You want to create a new "super-expert" that combines all their specialist knowledge without losing any. Naive averaging is like asking all specialists to mumble their opinions simultaneously — it's often incoherent. TIES-Merging is like having a moderator: first, they filter out irrelevant "noise" (Trim), then identify where specialists largely agree on the "direction" of knowledge change (Elect), and finally aggregate those agreements (Sum). DARE is a final touch, making sure the combined opinions aren't too strong or redundant, encouraging a more robust "super-expert."

💡 If you remember one thing

TIES-Merging focuses on delta weights (\(\Delta W = W_{tuned} - W_{base}\)) rather than absolute weights. It prunes small deltas and only combines those that show strong sign agreement across different fine-tuned models. DARE then randomly prunes a subset of these combined deltas and rescales the survivors to maintain the overall magnitude of the update, which is crucial for performance.

2
How It Works Internally
▼

The Problem: Catastrophic Forgetting in Naive Merging

When you fine-tune a large model on a specific task, it learns new capabilities. If you have several such models, each fine-tuned on a different task, simply averaging their weights often leads to a merged model that performs poorly on all tasks. This is because the "important" changes for one task might be averaged out or contradicted by others, leading to a phenomenon known as catastrophic forgetting or interference.

TIES-Merging: Trim, Elect, Sum

TIES-Merging addresses this by identifying and preserving the most salient changes from each fine-tuned model. It operates on the delta weights, \(\Delta W_k = W_k - W_{base}\), where \(W_k\) is the weights of a fine-tuned model \(k\) and \(W_{base}\) are the weights of the original base model. For each parameter (or group of parameters):

  1. Trim: Small magnitude delta weights are set to zero. These are considered "unimportant" noise or task-specific fine-tuning that might not generalize. A global magnitude threshold is applied.
  2. Elect: For the remaining (non-zero) delta weights, TIES identifies a "dominant sign" for each parameter across all models. Only deltas that agree with this dominant sign are kept; others are set to zero. This ensures that models contributing to a parameter update are pushing in a consistent direction.
  3. Sum: The surviving (trimmed and elected) delta weights from all models are summed up. This forms the final merged delta weight, which is then added to the base model: \(W_{merged} = W_{base} + \Delta W_{merged}\).

DARE: Disentangling and Rescaling

While TIES-Merging significantly improves performance over naive averaging, the summation step can still lead to issues:

  • Saturation: If many models contribute to a parameter, the summed delta can become excessively large, pushing the parameter into saturated regions of activation functions.
  • Redundancy: Over-reliance on a few parameters that many models agree on, potentially limiting generalization.

DARE introduces an additional step to mitigate these:

  1. Random Pruning: After TIES has produced an initial merged delta, DARE randomly prunes a fraction \(p_{DARE}\) of its non-zero elements. This acts as a form of regularization, encouraging the model to rely on a more diverse set of parameters.
  2. Rescaling: To compensate for the reduction in magnitude caused by random pruning, the remaining non-zero elements are rescaled by a factor of \(\frac{1}{1-p_{DARE}}\). This ensures that the expected magnitude of the overall update remains consistent, preventing under-training.
🔑 Key Property

The core idea of TIES-Merging is to focus on sparse, sign-consistent delta weights. DARE complements this by introducing a controlled amount of randomness and magnitude preservation to prevent over-optimization on highly-agreed-upon parameters, leading to more robust and generalizable merged models.

3
Why It Works — The Math
▼

Delta Weights and Naive Averaging

Let \(W_{base}\) be the weights of the base model, and \(W_k\) be the weights of the \(k\)-th fine-tuned model. The delta weights are defined as \(\Delta W_k = W_k - W_{base}\). Naive averaging computes the merged weights as:

$$ W_{avg} = \frac{1}{K} \sum_{k=1}^K W_k = W_{base} + \frac{1}{K} \sum_{k=1}^K \Delta W_k $$

This approach often fails because deltas from different fine-tuning tasks can have conflicting signs or magnitudes, leading to destructive interference and catastrophic forgetting.

TIES-Merging: Trim, Elect, Sum

TIES-Merging introduces two masking steps before summation. For each parameter \(p\) and each model \(k\):

  1. Trim: A magnitude mask \(M_{trim, p, k}\) is applied. $$ M_{trim, p, k} = \mathbb{I}(|\Delta W_{p,k}| \ge \tau_{mag}) $$ where \(\tau_{mag}\) is a global magnitude threshold.
  2. Elect: A sign consistency mask \(M_{elect, p, k}\) is applied. $$ M_{elect, p, k} = \mathbb{I}(\operatorname{sign}(\Delta W_{p,k}) = \operatorname{dominantSign}(\{\Delta W_{p,j}\}_{j=1}^K)) $$ The \(\operatorname{dominantSign}\) is determined (e.g., by majority vote or median sign) among all non-trimmed deltas for parameter \(p\).

The effective delta for parameter \(p\) from model \(k\) becomes \(\Delta W'_{p,k} = M_{trim, p, k} \cdot M_{elect, p, k} \cdot \Delta W_{p,k}\). The final merged delta is then:

$$ \Delta W_{merged, p} = \sum_{k=1}^K \Delta W'_{p,k} $$

And \(W_{merged} = W_{base} + \Delta W_{merged}\).

DARE: Disentangling and Rescaling

After computing \(\Delta W_{merged}\) (let's call it \(\Delta_{TIES}\) for clarity), DARE applies a final transformation. It randomly prunes a fraction \(p_{DARE}\) of the elements in \(\Delta_{TIES}\) and rescales the remaining ones. Let \(M_{DARE, p}\) be a Bernoulli mask where \(M_{DARE, p} = 1\) with probability \(1-p_{DARE}\) and \(0\) otherwise. The DARE-processed delta is:

$$ \Delta W_{DARE, p} = \frac{M_{DARE, p}}{1 - p_{DARE}} \cdot \Delta_{TIES, p} $$

The crucial part is the \(\frac{1}{1 - p_{DARE}}\) rescaling. This ensures that the expected value of the DARE-processed delta remains the same as the original TIES delta: \(\mathbb{E}[\Delta W_{DARE, p}] = \Delta_{TIES, p}\). This prevents under-training while introducing sparsity and robustness, similar to how inverted dropout works. The final merged weights are \(W_{merged} = W_{base} + \Delta W_{DARE}\).

⚠️ Practical Considerations

The choice of \(\tau_{mag}\) for trimming and \(p_{DARE}\) for DARE's random pruning are hyper-parameters. Too aggressive trimming or pruning can remove important information, while too lenient can reintroduce noise or saturation. These values often require tuning on a validation set for optimal performance.

Key Takeaways
▼

When to use TIES-Merging & DARE:

  • When you have multiple fine-tuned LLMs (or other neural networks) for different tasks and want to combine their capabilities into a single model.
  • To mitigate catastrophic forgetting and interference that occurs with naive weight averaging.
  • To create a "mixture of experts" or multi-task model without the overhead of training from scratch or complex routing mechanisms.
  • When you need a more robust and generalizable merged model, as DARE's random pruning and rescaling act as a form of regularization.

When NOT to use / be cautious:

  • If the fine-tuned models are extremely divergent or trained on completely orthogonal tasks with no shared feature space, TIES might struggle to find consistent signals.
  • For very small models or tasks where naive averaging already performs well (e.g., merging models trained on highly similar datasets), the added complexity might not be necessary.
  • The hyper-parameters (\(\tau_{mag}\) and \(p_{DARE}\)) require careful tuning, which can add overhead.
💡 Big Picture

TIES-Merging with DARE provides a principled, lightweight, and surprisingly effective method for parameter merging in deep learning. It leverages the observation that fine-tuning often results in sparse, directionally consistent changes, and that selectively combining these changes, with careful regularization (DARE), can yield a powerful composite model superior to simple averaging.

Code Trace (Simplified)
▼
import torch
def ties_merge_and_dare(base_model, fine_tuned_models,
magnitude_threshold=0.01, dare_pruning_ratio=0.5):
# 1. Compute Deltas for each fine-tuned model
deltas = [] # List of delta-weight dictionaries {param_name: delta_tensor}
for ft_model in fine_tuned_models:
delta = {name: ft_model.state_dict()[name] - base_model.state_dict()[name]
for name in base_model.state_dict()}
deltas.append(delta)
merged_delta = {name: torch.zeros_like(base_model.state_dict()[name])
for name in base_model.state_dict()}
for name in base_model.state_dict():
all_param_deltas = torch.stack([d[name] for d in deltas]) # (K, ...)
# TIES Step 1: Trim (magnitude pruning)
# Zero out small deltas. Note: threshold applied to each element.
trimmed_deltas = all_param_deltas.clone()
trimmed_deltas[trimmed_deltas.abs() < magnitude_threshold] = 0
# TIES Step 2: Elect (sign consistency)
# Calculate dominant sign for each element across models
# Here, a simple majority vote for non-zero trimmed deltas
dominant_signs = torch.sign(trimmed_deltas.sum(dim=0))
# Keep only deltas that agree with the dominant sign
elected_deltas = trimmed_deltas.clone()
mask_inconsistent = (torch.sign(elected_deltas) != dominant_signs) & (elected_deltas != 0)
elected_deltas[mask_inconsistent] = 0
# TIES Step 3: Sum (aggregate remaining deltas)
ties_delta = elected_deltas.sum(dim=0)
# DARE: Disentangling and Rescaling
if dare_pruning_ratio > 0:
# Randomly prune elements from the TIES delta
mask_dare_keep = (torch.rand_like(ties_delta) > dare_pruning_ratio)
dare_delta = ties_delta * mask_dare_keep
# Rescale remaining elements to preserve expected magnitude
if (1 - dare_pruning_ratio) > 1e-6: # Avoid division by zero
dare_delta /= (1 - dare_pruning_ratio)
merged_delta[name] = dare_delta
else:
merged_delta[name] = ties_delta
# Apply the final merged delta to the base model
merged_model_state_dict = {name: base_model.state_dict()[name] + merged_delta[name]
for name in base_model.state_dict()}
# Create a new model with merged weights (or load into existing)
new_merged_model = type(base_model)() # Assumes same class for simplicity
new_merged_model.load_state_dict(merged_model_state_dict)
return new_merged_model
