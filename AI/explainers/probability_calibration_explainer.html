1
Understanding Calibration
▼

What is it? When a classifier outputs a score of 0.8 for "this email is spam," does that actually mean there is an 80% chance it is spam? For most models — SVMs, gradient boosted trees, and even neural networks — the answer is no. The score is a ranking signal, not a true probability. Calibration is the post-hoc process of transforming raw model scores into reliable probabilities that match observed frequencies.

Analogy: Think of a weather forecaster. A well-calibrated forecaster who says "70% chance of rain" should be right about 70% of the time when they make that prediction — not 95% of the time (overconfident) or 50% of the time (underconfident). An overconfident model outputs 0.95 for cases where only 70% are truly positive. An underconfident model hedges near 0.5 even when it is very sure.

The Reliability Diagram: The canonical diagnostic tool. Divide test predictions into bins by confidence (0–0.1, 0.1–0.2, …) and for each bin plot the observed positive rate on the y-axis against the mean predicted probability on the x-axis. A perfectly calibrated model lies exactly on the diagonal \(y = x\). Points below the diagonal indicate overconfidence; points above indicate underconfidence.

💡 If you remember one thing

A model that outputs \(\hat{p}(x) = 0.8\) is calibrated if, among all test examples where it predicts 0.8, exactly 80% are truly positive. Calibration methods (Platt scaling, isotonic regression) fit a second model on top of raw scores to bend the reliability curve onto the diagonal. The ECE (Expected Calibration Error) quantifies how far from the diagonal you are — lower is better, zero is perfect.

2
Platt Scaling & Isotonic Regression
▼

Platt Scaling (1999)

Proposed by John Platt for calibrating SVMs. It fits a logistic (sigmoid) function on top of the raw scores \(f(x)\):

$$\hat{p}(x) = \sigma(A \cdot f(x) + B) = \frac{1}{1 + e^{-(A f(x) + B)}}$$

Parameters \(A\) and \(B\) are found by minimizing the binary cross-entropy on a held-out calibration set — never the training set. For SVMs, Platt typically finds \(A < 0\) (large positive margin → high probability) and \(B \approx 0\). Only 2 parameters, so it generalises well even with a few hundred calibration examples.

Isotonic Regression (Zadrozny & Elkan, 2002)

A non-parametric approach. It fits a piecewise-constant monotone increasing function \(g: \mathbb{R} \to [0,1]\) mapping scores to calibrated probabilities. The only constraint is monotonicity: if score \(s_1 > s_2\) then \(g(s_1) \geq g(s_2)\). This is solved exactly by the Pool Adjacent Violators (PAV) algorithm in \(O(n)\) time after sorting.

Because isotonic regression can fit arbitrary shapes, it requires more calibration data. Rule of thumb: Platt for <1 000 calibration samples, isotonic for >5 000. For moderate sizes (1 000–5 000), compare both with cross-validation.

Expected Calibration Error (ECE)

Partition \(n\) predictions into \(M\) equal-width bins. For each bin, measure the weighted gap between mean prediction and mean observed frequency:

$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{n} \left| \overline{\hat{p}}_m - \overline{y}_m \right|$$

Numerically (from our simulation, test set, \(n=1000\), \(M=10\) bins):

Raw: ECE = 0.144 Platt: ECE = 0.061 Isotonic: ECE = 0.047
🔑 Key Design Decision: Always Use a Held-Out Calibration Set

Fitting Platt or isotonic regression on training data causes severe overfitting — especially isotonic, which can memorise labels exactly. Use 5-fold cross-validation (sklearn's CalibratedClassifierCV(cv=5)) or a dedicated 20% hold-out split. On the calibration set, isotonic ECE may be near zero; on test it will be nonzero — that is the real number to report.

⚠️ ECE Pitfall: Bin Count Sensitivity

ECE with \(M = 15\) bins on a small test set can produce noisy estimates because some bins have very few samples. Complement ECE with the Brier Score \(\frac{1}{n}\sum_i (\hat{p}_i - y_i)^2\), which is a proper scoring rule, needs no binning, and measures both discrimination and calibration jointly.

3
The Math Behind Calibration
▼

Formal Definition

A classifier \(h: \mathcal{X} \to [0,1]\) is perfectly calibrated if for all \(p \in [0,1]\):

$$\Pr(Y = 1 \mid h(X) = p) = p$$

In practice we verify this condition in finite bins and measure the violation with ECE.

Platt Scaling Derivation

Given raw scores \(\{(f_i, y_i)\}_{i=1}^n\) on the calibration set, maximise the log-likelihood of the Bernoulli model \(y_i \mid f_i \sim \text{Bern}(\sigma(A f_i + B))\):

$$\ell(A, B) = \sum_{i=1}^n \bigl[ y_i \log \sigma(A f_i + B) + (1 - y_i) \log(1 - \sigma(A f_i + B)) \bigr]$$

Platt recommended label-smoothed targets \(t_+ = \frac{N_+ + 1}{N_+ + 2}\) and \(t_- = \frac{1}{N_- + 2}\) to avoid degenerate solutions when the model is highly confident. The objective is convex in \(A, B\), so L-BFGS converges reliably.

Isotonic Regression via Pool Adjacent Violators (PAV)

Sort predictions: \(f_{(1)} \le f_{(2)} \le \cdots \le f_{(n)}\). Find non-decreasing \(\hat{p}_1 \le \cdots \le \hat{p}_n\) minimising the weighted squared error:

$$\min_{\hat{p}_1 \le \cdots \le \hat{p}_n} \sum_{i=1}^n w_i (y_{(i)} - \hat{p}_i)^2$$

PAV scans left-to-right: whenever a monotonicity violation occurs (i.e., the next label would decrease the running average), it merges the violating block with its left neighbour and replaces all values with the block mean. Each merge is \(O(1)\) amortised, giving \(O(n \log n)\) total (dominated by the initial sort).

📐 Key Equations Summary

Platt: \(\hat{p} = \sigma(A f + B)\), parameters \(A, B\) fit by MLE on calibration set

Isotonic PAV: \(\hat{p}_i = \bar{y}_{\text{block}(i)}\), piecewise-constant step function

Temperature scaling (neural nets): \(\hat{p}_k = \text{softmax}(z_k / T)\)

ECE: \(\sum_m \frac{|B_m|}{n}|\bar{\hat{p}}_m - \bar{y}_m|\) — lower is better, 0 is perfect

Temperature Scaling for Neural Networks

For deep classifiers, divide all logits by a scalar \(T > 0\) before softmax. Finding the optimal \(T\) is a 1D search on the validation NLL — extremely fast. Guo et al. (2017) showed that modern neural networks are systematically overconfident and that \(T > 1\) reliably fixes this, matching more complex methods.

$$\hat{p}_k = \frac{\exp(z_k / T)}{\sum_j \exp(z_j / T)}, \quad T = \underset{T}{\operatorname{argmin}} \; \text{NLL}_{\text{val}}$$

Code Implementation
▼

From Scratch — Platt Scaling

import numpy as np
from scipy.special import expit     # numerically stable sigmoid
from scipy.optimize import minimize
 
def platt_calibrate(s_cal, y_cal, s_test):
    """Platt scaling: fit sigmoid A*s+B on calibration set, apply to test."""
    # Label smoothing (Platt 1999): avoids degenerate log(0)
    n_pos = y_cal.sum(); n_neg = len(y_cal) - n_pos
    t_pos = (n_pos + 1) / (n_pos + 2)  # smoothed +1 target
    t_neg = 1.0 / (n_neg + 2)           # smoothed -1 target
    targets = np.where(y_cal == 1, t_pos, t_neg)
 
    def nll(params):
        A, B = params
        p = np.clip(expit(A * s_cal + B), 1e-12, 1 - 1e-12)
        return -np.mean(targets * np.log(p) + (1-targets) * np.log(1-p))
 
    res = minimize(nll, x0=[1.0, 0.0], method='L-BFGS-B')
    A, B = res.x                         # A typically negative for SVMs
    return expit(A * s_test + B)         # calibrated probabilities
 
def isotonic_calibrate(s_cal, y_cal, s_test):
    """Isotonic regression via PAV: monotone step function."""
    from sklearn.isotonic import IsotonicRegression
    iso = IsotonicRegression(out_of_bounds='clip')
    iso.fit(s_cal, y_cal)                # fits PAV on training scores
    return iso.predict(s_test)           # step function lookup
 
def ece(probs, labels, n_bins=10):
    """Expected Calibration Error."""
    bins = np.linspace(0, 1, n_bins + 1)
    total = 0.0
    for i in range(n_bins):
        mask = (probs >= bins[i]) & (probs < bins[i+1])
        if mask.sum() > 0:
            total += mask.sum() / len(probs) * abs(probs[mask].mean() - labels[mask].mean())
    return total

Production Usage (scikit-learn)

from sklearn.calibration import CalibratedClassifierCV, calibration_curve
from sklearn.svm import SVC
 
# Platt scaling via 5-fold CV (avoids data leakage)
cal_platt = CalibratedClassifierCV(SVC(), cv=5, method='sigmoid')
cal_platt.fit(X_train, y_train)
 
# Isotonic via 5-fold CV
cal_iso = CalibratedClassifierCV(SVC(), cv=5, method='isotonic')
cal_iso.fit(X_train, y_train)
 
# Reliability diagram
for name, clf in [('Platt', cal_platt), ('Isotonic', cal_iso)]:
    frac, mean_pred = calibration_curve(y_test, clf.predict_proba(X_test)[:,1], n_bins=10)
    plt.plot(mean_pred, frac, marker='o', label=name)
 
# For pre-trained models (manual split)
base = SVC().fit(X_train, y_train)         # train on train
cal = CalibratedClassifierCV(base, cv='prefit', method='sigmoid')
cal.fit(X_cal, y_cal)                      # calibrate on separate split
probs = cal.predict_proba(X_test)[:,1]     # calibrated probabilities
⚠️ Gotcha: cv='prefit' vs cv=5

With cv='prefit', you must hold out a calibration set before fitting the base model — it must never have seen the calibration examples. With cv=5, sklearn internally trains 5 base models and calibrates each on its held-out fold, then averages predictions. The latter is safer and more data-efficient but trains the base model 5× times.

Key Takeaways & When to Use
▼

When calibration matters:

  • Decision thresholds based on probabilities (e.g., "alert if P(fraud) > 0.3")
  • Downstream risk estimation or cost-sensitive decision making
  • Ensembles that combine probability estimates from multiple models
  • Any context where "I am 80% sure" must mean 80%, not 95%

When it matters less:

  • Pure ranking tasks (AUC only) where relative order matters, not absolute values
  • Models already outputting probabilities via a well-specified generative model (e.g., naive Bayes with correct priors)

Method selection:

  • Platt scaling — SVM, boosting, linear models; <1 000 calibration samples; fast, low variance
  • Isotonic regression — any model; >5 000 calibration samples; flexible, can fix non-monotone miscalibration
  • Temperature scaling — neural networks; single parameter, preserves top-1 accuracy and ranking
  • Beta calibration — when sigmoid is too rigid but isotonic overfits; 3-parameter family
💡 Design Decision Guide

Start by plotting the reliability diagram — if the miscalibration is roughly monotone and smooth, Platt scaling usually suffices. If the curve has complex non-monotone shape (possible in boosting with class imbalance), isotonic regression or beta calibration will do better. Always evaluate ECE on a dedicated test set, not the calibration set itself.
