Repeated K-Fold Cross-Validation

Run standard K-fold multiple times with different random partitions — average the scores for a tighter, lower-variance estimate of generalisation performance.
Intermediate Model Selection Classical ML O(R·K·train)
1
🎯 The 30-Second Version
▼

What is this? Normal cross-validation (CV) splits your data into K groups (folds), trains on K−1 of them, tests on the held-out one, repeats K times, and averages the test scores. The trouble is one particular random split might be lucky — or unlucky — making your score estimate noisy.

Repeated K-fold fixes this by running the whole K-fold process R times, each time re-shuffling the data into fresh folds, then averaging all R × K scores. More repetitions → smaller variance on the estimate → you can be more confident the score reflects true model quality, not split luck.

Real-World Analogy

Imagine judging a chef by having them cook the same dish once — the result depends heavily on that one day's mood, ingredient freshness, etc. Repeated K-fold is like having the chef cook the dish across 30 different sessions with different fresh ingredients each time, then averaging the judges' scores. One bad day can't skew the result.

💡 If you remember one thing

Repeated K-fold with R repeats and K folds produces R×K hold-out scores. Averaging them reduces the variance of the CV estimate by approximately a factor of 1/R, at the cost of R× the compute.

⚙️ How It Works — Mechanism & Math
▼

Let \(n\) be the dataset size, \(K\) the number of folds, and \(R\) the number of repeats. At repeat \(r\) a fresh random permutation \(\pi_r\) of \(\{1,\ldots,n\}\) is drawn, and the dataset is partitioned into K non-overlapping folds of size \(\approx n/K\). Each fold \(j\) serves as the test set once, yielding score \(s_{r,j}\). The final estimate is:

$$\bar{s} = \frac{1}{RK}\sum_{r=1}^{R}\sum_{j=1}^{K} s_{r,j}$$

Variance Reduction

Let \(\sigma^2_{\rm cv}\) be the variance of a single K-fold estimate. Scores within the same repeat are correlated (they share training data), so the variance of \(\bar{s}\) is not \(\sigma^2_{\rm cv}/(RK)\) but rather:

$$\operatorname{Var}(\bar{s}) \approx \frac{\sigma^2_{\rm cv}}{R}$$

Each new repeat uses an independent partition \(\pi_r\), breaking the within-repeat correlation. Adding a second repeat roughly halves the variance; a 5-repeat 5-fold run has variance ~5× lower than a single 5-fold run.

Numerical Trace (10 samples, K=5, R=3)

Suppose 10 data points are scored by a decision-tree classifier. Each cell is the accuracy on that fold's hold-out set:

Key Formula

Standard error of the repeated-CV estimate: \(\operatorname{SE}(\bar{s}) = \sqrt{\operatorname{Var}(\bar{s})/R} \approx \hat{\sigma}_{\rm cv}/\sqrt{R}\), where \(\hat{\sigma}_{\rm cv}\) is estimated from the spread of repeat-level means.

3
📜 Historical Context & Why It Exists
▼

Cross-validation traces back to Mosteller & Tukey (1968) and Stone (1974), with leave-one-out CV being the earliest formalisation. K-fold CV became popular through Geisser (1975) and Kohavi (1995), who showed K=10 achieves a good bias–variance trade-off. However, Bengio & Grandvalet (2004) proved formally that no unbiased estimator of the CV variance exists — the within-fold correlations make exact variance estimation impossible.

Repeated K-fold emerged as the practical answer: rather than correcting the variance estimate analytically, just collect more independent estimates. Dietterich (1998) studied statistical tests for comparing classifiers under CV, and Bouckaert (2003) showed that repeated CV gives far more reliable model comparisons than single runs. The procedure was formalised in software (e.g., scikit-learn's RepeatedKFold, 2013) and is now the default recommendation in many modern ML textbooks.

⚠️ The Correlation Trap

Within a single repeat, the K fold scores are not independent — they share ~(K−1)/K of their training data. Naive \(\sigma^2/K\) underestimates the true variance. The bias can be severe on small datasets. Repeating with fresh partitions creates inter-repeat independence that standard statistics can exploit.

💻 Code — From Scratch & Production
▼

From Scratch (NumPy only)

import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.tree import DecisionTreeClassifier
def repeated_kfold_scratch(X, y, model, K=5, R=3, seed=0):
"""Manual repeated K-fold. Returns all R*K scores."""
n = len(y)
all_scores = []
rng = np.random.default_rng(seed)
for r in range(R): # outer: each repeat
perm = rng.permutation(n) # fresh random permutation
fold_sizes = np.full(K, n // K)
fold_sizes[:n % K] += 1 # distribute remainder
fold_starts = np.concatenate([[0], np.cumsum(fold_sizes)])
for j in range(K): # inner: each fold
test_idx = perm[fold_starts[j]:fold_starts[j+1]]
train_idx = np.concatenate([perm[:fold_starts[j]],
perm[fold_starts[j+1]:]])
model.fit(X[train_idx], y[train_idx])
acc = (model.predict(X[test_idx]) == y[test_idx]).mean()
all_scores.append(acc)
scores = np.array(all_scores).reshape(R, K)
repeat_means = scores.mean(axis=1) # one mean per repeat
grand_mean = repeat_means.mean()
se = repeat_means.std(ddof=1) / np.sqrt(R) # SE from repeat means
return grand_mean, se, scores
X, y = load_breast_cancer(return_X_y=True)
clf = DecisionTreeClassifier(max_depth=4, random_state=0)
mean, se, scores = repeated_kfold_scratch(X, y, clf, K=5, R=10)
print(f"Accuracy: {mean:.4f} ± {se:.4f}") # e.g. 0.9086 ± 0.0031

Production (scikit-learn)

from sklearn.model_selection import RepeatedKFold, cross_val_score
import numpy as np
rkf = RepeatedKFold(n_splits=5, n_repeats=10, random_state=42)
# n_splits=K, n_repeats=R
scores = cross_val_score(clf, X, y, cv=rkf, scoring='accuracy', n_jobs=-1)
print(f"n scores: {len(scores)}") # 50 (10 repeats × 5 folds)
print(f"Mean: {scores.mean():.4f}") # grand mean
print(f"Std: {scores.std():.4f}") # std of all 50 scores
# SE from repeat-level means (more principled):
repeat_means = scores.reshape(10, 5).mean(axis=1)
se = repeat_means.std(ddof=1) / np.sqrt(10)
print(f"SE (repeat-based): {se:.4f}")
⚠️ Common Gotcha

scores.std() from scikit-learn's cross_val_score mixes within-repeat and between-repeat variance. For a principled SE, reshape into (R, K), take row means, then compute std(ddof=1)/√R. The naïve std is an overestimate.

Decision Guide

n > 10,000: single 5-fold is fine (compute beats variance reduction). n = 100–10,000: 10-fold or repeated 5-fold (R=5). n < 100: repeated 10-fold (R=10) or LOOCV. Whenever you want a confidence interval or are running a statistical test between two models, always repeat.

Interview Q&A

Q1 (Easy): What does repeated K-fold fix compared to standard K-fold?
A: It reduces the variance of the CV score estimate by averaging R independent partitions, each producing K fold scores. Variance drops roughly as 1/R.

Q2 (Medium): Why can't you just use the 95% CI from the K fold scores within a single run?
A: The K scores share (K−1)/K of their training data → they are positively correlated → the naive SE = std/√K underestimates the true uncertainty. Repeated CV breaks this by introducing independent partitions.

Q3 (Hard): You're comparing model A vs model B with repeated 10-fold CV. How would you test for a significant difference?
A: Use the corrected paired t-test (Nadeau–Bengio, 2003). Let \(d_{r,j} = s^A_{r,j} - s^B_{r,j}\). Compute \(\bar{d} = \frac{1}{RK}\sum d_{r,j}\) and the corrected variance \(\hat{\sigma}^2_d = \left(\frac{1}{RK} + \frac{n_{\rm test}}{n_{\rm train}}\right)\hat{\sigma}^2\), where the second term accounts for the training–test overlap. Test statistic: \(t = \bar{d}/\sqrt{\hat{\sigma}^2_d}\) under \(t_{RK-1}\).

Q4 (Expert): Does more repeats always help?
A: Asymptotically yes, but with diminishing returns (variance ∝ 1/R). In practice, R=10 is almost always sufficient. More R doesn't reduce bias — if the model class has high structural bias vs the true function, no amount of CV averaging fixes it.

Red Flags (wrong answers in interviews)

"Repeated K-fold uses more data for training" — False, same data, different splits. "It reduces overfitting" — False, it reduces estimation variance, not model overfitting. "K=5 and R=5 gives 25 independent scores" — False, the 5 scores within a repeat are correlated.
