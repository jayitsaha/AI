Understanding LU & LDLᵀ
▼

What is it? LU decomposition splits any square matrix \(A\) into a product of a lower-triangular matrix \(L\) and an upper-triangular matrix \(U\), so \(A = LU\). Triangular systems are trivially solvable by substitution, turning the hard problem \(Ax = b\) into two easy ones. LDLᵀ is a variant for symmetric matrices that saves memory and work by storing only half the data: \(A = LDL^\top\) where \(D\) is diagonal.

Analogy: Imagine solving a tangled equation by first peeling it into two nested layers, like Russian dolls. The outer layer \(U\) is solved top-to-bottom (back-substitution) and the inner layer \(L\) is solved bottom-to-top (forward substitution). Once you have \(L\) and \(U\), solving for any right-hand side costs almost nothing — you just peel the dolls again.

💡 If you remember one thing

LU decomposition IS Gaussian elimination, written in matrix form. The multipliers you compute during elimination fill \(L\); the remaining upper triangle is \(U\). Solving \(Ax = b\) becomes: forward-substitute \(Ly = b\), then back-substitute \(Ux = y\). LDLᵀ does the same for symmetric \(A\) using only \(\frac{n(n+1)}{2}\) entries instead of \(n^2\).

How Gaussian Elimination Becomes LU
▼

Step-by-step: Eliminating below column 1

Start with \(A\). To zero out entry \(a_{i1}\) below the pivot \(a_{11}\), subtract \(\ell_{i1} = a_{i1}/a_{11}\) times row 1 from row \(i\). This multiplier \(\ell_{i1}\) is recorded in the corresponding slot of \(L\). After all eliminations in column 1, the subdiagonal is zero and \(L\) has been partially filled.

Repeat for column 2 (with the updated submatrix), then column 3, and so on. The unit lower-triangular matrix \(L\) accumulates all multipliers; \(U\) is the final upper triangle.

The Concrete 3×3 Example Used Throughout

$$A = \begin{bmatrix} 2 & 1 & -1 \\ -3 & -1 & 2 \\ -2 & 1 & 2 \end{bmatrix}$$

Step 1: Pivot = \(a_{11} = 2\). Multipliers: \(\ell_{21} = -3/2 = -1.5\), \(\ell_{31} = -2/2 = -1\).

Eliminate column 1 below pivot. Updated matrix after step 1:

$$\begin{bmatrix} 2 & 1 & -1 \\ 0 & 0.5 & 0.5 \\ 0 & 2 & 1 \end{bmatrix}$$

Step 2: Pivot = \(u_{22} = 0.5\). Multiplier: \(\ell_{32} = 2/0.5 = 4\). Final U row 3 update: \([0, 0, 1 - 4\cdot0.5] = [0, 0, -1]\).

Result:

$$L = \begin{bmatrix} 1 & 0 & 0 \\ -1.5 & 1 & 0 \\ -1 & 4 & 1 \end{bmatrix}, \quad U = \begin{bmatrix} 2 & 1 & -1 \\ 0 & 0.5 & 0.5 \\ 0 & 0 & -1 \end{bmatrix}$$

LDLᵀ for Symmetric A

When \(A = A^\top\) is symmetric positive definite, we exploit symmetry: factor \(A = LDL^\top\) where \(L\) is unit lower-triangular and \(D\) is diagonal. Extract the diagonal of \(U\) into \(D\), then scale \(U\)'s rows: \(L^\top = D^{-1}U\). This avoids storing both \(L\) and \(U\) — \(U\) is simply \(D L^\top\). The Cholesky factorization \(A = LL^\top\) is the special case with \(D = I\).

🔑 Key Property

LU decomposition exists and is unique when \(A\) is nonsingular and all leading principal submatrices are nonsingular (no zero pivots without pivoting). With partial pivoting — swapping rows to put the largest magnitude element on the diagonal — we get \(PA = LU\) where \(P\) is a permutation matrix, and the algorithm is numerically stable.

3
Why It Works — The Math
▼

LU from Elementary Matrices

Each elimination step can be encoded as a unit lower-triangular elementary matrix \(E_k\). Eliminating column \(k\) below the pivot multiplies by \(E_k = I - \ell_k e_k^\top\), where \(\ell_k\) holds the multipliers and \(e_k\) is the \(k\)-th standard basis vector. After \(n-1\) steps:

$$E_{n-1} \cdots E_2 E_1 A = U \implies A = E_1^{-1} E_2^{-1} \cdots E_{n-1}^{-1} U = LU$$

The beautiful fact is that \(L = E_1^{-1} E_2^{-1} \cdots E_{n-1}^{-1}\) is unit lower-triangular, and the inverses of elementary matrices just negate the multipliers — so \(L\) is trivially computed by placing the multipliers in their column positions.

Solving Ax = b in Two Triangle Solves

Given \(A = LU\), substitute: \(LUx = b\). Let \(y = Ux\). Then:

$$\underbrace{Ly = b}_{\text{forward substitution}}, \quad \underbrace{Ux = y}_{\text{back substitution}}$$

Forward substitution (L unit lower-triangular, so \(\ell_{ii}=1\)):

$$y_i = b_i - \sum_{j=1}^{i-1} \ell_{ij} y_j, \quad i = 1, 2, \ldots, n$$

Back substitution:

$$x_i = \frac{1}{u_{ii}} \left( y_i - \sum_{j=i+1}^{n} u_{ij} x_j \right), \quad i = n, n-1, \ldots, 1$$

LDLᵀ Derivation

For symmetric \(A\), write the LU factors: \(U = DL^\top\) where \(D = \operatorname{diag}(u_{11}, u_{22}, \ldots, u_{nn})\). Then:

$$A = LU = L \cdot D L^\top$$

The entries of \(L\) and \(D\) satisfy:

$$d_j = a_{jj} - \sum_{k=1}^{j-1} \ell_{jk}^2 d_k, \qquad \ell_{ij} = \frac{1}{d_j}\left(a_{ij} - \sum_{k=1}^{j-1} \ell_{ik} \ell_{jk} d_k\right), \quad i > j$$
⚠️ Numerical Pitfall: Zero or Tiny Pivots

If a pivot \(u_{kk} = 0\), the algorithm fails (division by zero). If it's merely tiny, large multipliers amplify round-off error catastrophically. Partial pivoting (always choosing the largest-magnitude element in the column as pivot) cures both: gives \(PA = LU\) with all \(|\ell_{ij}| \leq 1\), bounding growth.

Complexity

$$\text{LU factor: } \tfrac{2n^3}{3} \text{ flops} \quad\quad \text{Each Ax=b solve: } 2n^2 \text{ flops} \quad\quad \text{LDL}^\top \text{ factor: } \tfrac{n^3}{3} \text{ flops}$$

The key insight: factor \(A\) once in \(O(n^3)\), then solve for any number of right-hand sides \(b\) in \(O(n^2)\) each. For large \(n\) and many right-hand sides, this is transformative.

Key Takeaways — When to Use What
▼

LU vs alternatives:

Method Requirement Cost Use When
LU Any nonsingular 2n³/3 + 2n²/solve General square systems, many RHS
LDLᵀ Symmetric (indef OK) n³/3 + n²/solve Symmetric systems (FEM, covariance)
Cholesky Symmetric PD n³/3 + n²/solve SPD systems (Kalman, Gaussian process)
QR Any (even rect.) 2n³/3 – 4n³/3 Least squares, better stability
Iterative (CG) Sparse SPD O(kn) per iter Large sparse systems (PDE solvers)
💡 Decision Rule

Use LU for general \(n \times n\) systems or matrix inversion. Use LDLᵀ when \(A\) is symmetric (halves memory and flops). Use Cholesky when \(A\) is also positive definite (numerically nicest, no pivoting needed). Never use explicit matrix inverse in practice — A\b (MATLAB/numpy solve) does LU internally and is more stable.

Numerical stability hierarchy: Cholesky > LDLᵀ with pivoting > LU with partial pivoting > LU without pivoting > direct inverse.

Code Trace — From Scratch
▼
import numpy as np
# Our 3x3 matrix A and rhs b
A = np.array([[ 2, 1, -1],
[-3, -1, 2],
[-2, 1, 2]], dtype=float)
b = np.array([4., -10., -3.])
# ── LU Decomposition (no pivoting) ──────────────────
n = A.shape[0]
L = np.eye(n) # Start with identity (unit lower tri)
U = A.copy() # U starts as A, we modify in place
for k in range(n - 1): # k = 0, 1 (columns 0..n-2)
for i in range(k + 1, n): # rows below pivot
L[i, k] = U[i, k] / U[k, k] # multiplier → L
U[i, :] -= L[i, k] * U[k, :] # eliminate row i
# L = [[ 1, 0, 0], U = [[ 2, 1, -1],
# [-1.5, 1, 0], [ 0, 0.5, 0.5],
# [-1, 4, 1]] [ 0, 0, -1]]
# ── Forward substitution: Ly = b ─────────────────────
y = np.zeros(n)
for i in range(n):
y[i] = b[i] - L[i, :i] @ y[:i] # sum of known L*y terms
# y = [4, -4, -1]
# ── Back substitution: Ux = y ────────────────────────
x = np.zeros(n)
for i in range(n - 1, -1, -1):
x[i] = (y[i] - U[i, i+1:] @ x[i+1:]) / U[i, i]
# x = [2, -1, 1] ← solution to Ax = b
print(np.allclose(A @ x, b)) # True
# ── Production (scipy) ───────────────────────────────
from scipy.linalg import lu_factor, lu_solve
lu, piv = lu_factor(A) # LU + pivot record
x_prod = lu_solve((lu, piv), b) # O(n²) per RHS
