Bayesian vs Frequentist Inference

Two philosophies of probability — parameters fixed or random, and what that means for statistics
Intermediate Probability & Statistics Inference Part I · Section 0.3
1
Understanding the Two Paradigms
▼

What is this? When you collect data to learn about the world, you need a philosophy: what does probability even mean? The frequentist says probability is about long-run frequencies of repeatable experiments — the unknown parameter (say, the bias of a coin) is a fixed, true number; the data is what's random. The Bayesian says probability encodes degrees of belief — both data and parameters are treated as random variables, and you update your beliefs using Bayes' theorem.

Analogy: Imagine you find an unfamiliar coin. A frequentist flips it many times and says "I estimate the heads probability is 0.7, and if I repeated this whole experiment many times, 95% of my confidence intervals would trap the true value." A Bayesian starts with a personal belief ("probably fair"), then updates that belief as they see each flip. After 10 heads in 14 flips, their updated belief is a whole distribution over possible biases — not just a number.

💡 If you remember one thing

Frequentist: parameters are fixed, data is random — inference is about what data you'd see if you repeated the experiment. Bayesian: parameters are random with a prior — inference updates the prior with the likelihood to get a posterior: \(\underbrace{p(\theta | x)}_{\text{posterior}} \propto \underbrace{p(x | \theta)}_{\text{likelihood}} \cdot \underbrace{p(\theta)}_{\text{prior}}\).

🔴 Frequentist Paradigm

Parameter \(\theta\) is fixed but unknown

Data \(x\) is random (repeated samples)

Use MLE: \(\hat{\theta} = \arg\max_\theta \, p(x|\theta)\)

Uncertainty via confidence intervals, p-values

🔵 Bayesian Paradigm

Parameter \(\theta\) is random with a prior \(p(\theta)\)

Data \(x\) conditions the belief

Use Bayes' theorem: posterior \(p(\theta|x)\)

Uncertainty via credible intervals

Historical Context & Core Concepts
▼

Historical Origins

1763: Thomas Bayes' posthumous paper "An Essay towards solving a Problem in the Doctrine of Chances" introduced the first statement of Bayes' theorem. Pierre-Simon Laplace independently developed it extensively in the 1770s–1820s, calling it the "principle of inverse probability."

Early 20th century: Ronald Fisher (1922) introduced Maximum Likelihood Estimation and the modern framework of frequentist inference. Jerzy Neyman and Egon Pearson (1933) formalized hypothesis testing and confidence intervals. This became the dominant statistical paradigm for decades, partly due to its objectivity — no prior needed.

Bayesian revival: Harold Jeffreys (1939) and later Leonard Savage (1954) defended Bayesian methods philosophically. The MCMC revolution of the 1990s (Gelfand & Smith 1990, Gelman et al. 1995) made Bayesian computation practical for complex models, triggering the modern "Bayes resurgence."

⚠️ The Confidence Interval Trap

A 95% confidence interval does NOT mean "there's a 95% probability the parameter is in this interval." The parameter is fixed — it either is or isn't in the interval. The correct interpretation: "If I repeated this procedure many times, 95% of the resulting intervals would contain the true \(\theta\)." A Bayesian credible interval does have the intuitive probability interpretation.

The Math — Bayes' Theorem & MLE
▼

Bayes' Theorem for Inference

Given observed data \(x = (x_1, \ldots, x_n)\) and parameter \(\theta\):

$$p(\theta \mid x) = \frac{p(x \mid \theta)\, p(\theta)}{p(x)} = \frac{p(x \mid \theta)\, p(\theta)}{\int p(x \mid \theta') p(\theta')\, d\theta'}$$

The normalizing constant \(p(x)\) is often intractable for complex models, motivating MCMC. We write the proportional form: \(p(\theta|x) \propto p(x|\theta)\,p(\theta)\).

Coin Example — Beta-Binomial Model

Let \(\theta\) = probability of heads. Observe \(n\) flips, \(k\) heads. Choose prior \(\theta \sim \text{Beta}(\alpha_0, \beta_0)\):

$$p(\theta) = \frac{\theta^{\alpha_0-1}(1-\theta)^{\beta_0-1}}{B(\alpha_0,\beta_0)}, \qquad \theta \in [0,1]$$

The likelihood (Binomial) is \(p(k|n,\theta) = \binom{n}{k}\theta^k(1-\theta)^{n-k}\). The posterior is:

$$p(\theta \mid k, n) \propto \theta^k(1-\theta)^{n-k} \cdot \theta^{\alpha_0-1}(1-\theta)^{\beta_0-1} = \theta^{(\alpha_0+k)-1}(1-\theta)^{(\beta_0+n-k)-1}$$

This is \(\text{Beta}(\alpha_0 + k,\; \beta_0 + (n-k))\) — the Beta prior is conjugate to the Binomial likelihood. Posterior mean: \(\frac{\alpha_0 + k}{\alpha_0 + \beta_0 + n}\). This is a weighted blend of prior mean \(\frac{\alpha_0}{\alpha_0+\beta_0}\) and MLE \(\frac{k}{n}\), with prior weight shrinking as \(n \to \infty\).

Frequentist MLE

Maximize \(\log p(k|n,\theta) = k\log\theta + (n-k)\log(1-\theta)\) + const. Setting derivative to zero:

$$\frac{d}{d\theta}\log L(\theta) = \frac{k}{\theta} - \frac{n-k}{1-\theta} = 0 \implies \hat{\theta}_{MLE} = \frac{k}{n}$$

Wald 95% confidence interval (large-\(n\) approximation): \(\hat{\theta}_{MLE} \pm 1.96 \sqrt{\hat{\theta}(1-\hat{\theta})/n}\).

📐 Convergence with Data

As \(n \to \infty\), both the Bayesian posterior and the frequentist MLE converge to the same value — the true \(\theta\). The prior is "washed out." Mathematically: \(p(\theta | x_1,\ldots,x_n) \to \delta(\theta - \theta_{\text{true}})\). This is the Bernstein–von Mises theorem.

When to Use Each & Key Takeaways
▼

Use Frequentist when:

  • Large samples where prior is irrelevant (MLE ≈ posterior mean)
  • You need objective, prior-free analysis (regulatory settings)
  • A/B testing, clinical trials with pre-specified hypotheses and power
  • Classical ML: logistic regression, SVM, most sklearn models

Use Bayesian when:

  • Small samples where regularization from a prior helps
  • You want a full uncertainty distribution (not just a point estimate)
  • Sequential updating: incorporate new data online without storing old data
  • Hierarchical / multilevel models (partial pooling)
  • Decision-making under uncertainty where posterior directly informs action
💡 The Modern View

Most practitioners are pragmatic — use whatever works for the task. L2 regularization in logistic regression is a Gaussian prior (MAP estimate). Ridge regression is Bayesian. Many frequentist estimators correspond to Bayesian posteriors with specific priors. The dichotomy is philosophically real but practically often blurred.

Code — From Scratch & Production

import numpy as np
from scipy import stats
# ── BAYESIAN: Beta-Binomial conjugate model ──
alpha0, beta0 = 2.0, 2.0 # prior: Beta(2,2) — weakly fair
n, k = 20, 14 # 20 flips, 14 heads
# Posterior update (closed form for conjugate prior)
alpha_post = alpha0 + k # = 16
beta_post = beta0 + (n - k) # = 8
post_dist = stats.beta(alpha_post, beta_post)
post_mean = alpha_post / (alpha_post + beta_post) # 0.6667
credible_interval = post_dist.interval(0.95) # [0.471, 0.836]
# ── FREQUENTIST: MLE + Wald CI ──
theta_mle = k / n # = 0.7
se = np.sqrt(theta_mle * (1-theta_mle) / n) # = 0.1025
conf_interval = (theta_mle - 1.96*se, # = (0.499, 0.901)
theta_mle + 1.96*se)
# p-value for H₀: θ = 0.5 (is coin fair?)
z = (theta_mle - 0.5) / se # = 1.951
p_value = 2 * (1 - stats.norm.cdf(abs(z))) # = 0.051 — barely fails α=0.05
# ── PRODUCTION: PyMC Bayesian model ──
import pymc as pm
with pm.Model() as coin_model:
theta = pm.Beta('theta', alpha=2, beta=2) # prior
obs = pm.Binomial('obs', n=n, p=theta, observed=k)
trace = pm.sample(2000, return_inferencedata=True)
pm.plot_posterior(trace, var_names=['theta'])
