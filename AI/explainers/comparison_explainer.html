1
Understanding LLM Architectures
▼

What is this? Modern Large Language Models all descend from the Transformer architecture introduced in 2017, yet each family makes distinct engineering choices about how attention works, how positions are encoded, how layers are normalized, and what activation functions are used. These seemingly small differences profoundly affect model quality, training stability, inference speed, and maximum context length.

Analogy: Think of LLMs like car engines. They all run on the same fundamental principle (internal combustion / self-attention), but a Ferrari V12, a Toyota hybrid, and a Tesla electric motor differ in cylinder count, fuel injection, turbocharging, and cooling. Similarly, GPT-4, LLaMA, and Mistral all use attention but differ in head configuration, position encoding, normalization placement, and gating strategies.

If you remember one thing

The evolution from GPT-2 to modern LLMs follows a clear trajectory: Multi-Head Attention gave way to Grouped-Query Attention for KV-cache efficiency; learned positional embeddings were replaced by RoPE for length generalization; Post-LayerNorm shifted to Pre-RMSNorm for training stability; and GELU was superseded by SwiGLU for improved gradient flow.

2
Attention Mechanism Variants
▼

Multi-Head Attention (MHA)

The original Transformer uses MHA with \(h\) independent heads, each computing separate \(Q, K, V\) projections. For a model with dimension \(d_{model}\) and \(h\) heads, each head operates on \(d_k = d_{model}/h\) dimensions. During autoregressive inference, every head stores its own KV cache, requiring \(2 \times L \times h \times d_k\) memory per layer, where \(L\) is sequence length.

$$\text{MHA}(Q,K,V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)W^O, \quad \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

Multi-Query Attention (MQA)

MQA shares a single set of K and V projections across all heads while keeping separate Q projections. This reduces KV-cache from \(O(h \cdot d_k)\) to \(O(d_k)\) per position per layer -- an \(h\times\) reduction. PaLM (540B) uses MQA, achieving ~1.7x faster inference with minimal quality loss.

Grouped-Query Attention (GQA)

GQA is the compromise: heads are divided into \(G\) groups, each group sharing one KV pair. When \(G=1\) it is MQA; when \(G=h\) it is MHA. LLaMA 2 (70B) uses \(G=8\) groups with \(h=64\) heads, so 8 query heads share each KV pair. This cuts KV-cache by \(h/G = 8\times\) while preserving most of MHA's expressiveness.

$$\text{KV-cache per layer} = 2 \times L \times G \times d_k \quad \text{where } G \in \{1, \ldots, h\}$$
Key Trade-off

MHA maximizes model expressiveness (each head learns independent attention patterns). MQA maximizes inference speed (minimal KV-cache). GQA occupies the Pareto-optimal middle ground, and has become the de facto standard for models above 13B parameters.

3
Position Encoding & Normalization
▼

Positional Encoding Strategies

Learned Absolute (GPT-2/3): A learnable embedding matrix \(E_{pos} \in \mathbb{R}^{L_{max} \times d}\) is added to token embeddings. Simple but cannot generalize beyond \(L_{max}\) positions seen during training.

RoPE -- Rotary Position Embedding (LLaMA, Mistral, Qwen): Encodes position by rotating Q and K vectors in 2D subspaces. For position \(m\), the rotation matrix applies \(e^{im\theta_j}\) where \(\theta_j = 10000^{-2j/d}\). The attention dot product \(q_m^\top k_n\) then depends only on relative distance \(m-n\), enabling length extrapolation via NTK-aware scaling or YaRN.

$$\text{RoPE}(x_m, \theta) = \begin{pmatrix} x_1 \cos m\theta_1 - x_2 \sin m\theta_1 \\ x_1 \sin m\theta_1 + x_2 \cos m\theta_1 \\ \vdots \end{pmatrix}$$

ALiBi -- Attention with Linear Biases (BLOOM, MPT): Instead of modifying embeddings, ALiBi adds a linear penalty \(-m|i-j|\) to attention logits, where \(m\) is a head-specific slope. No learnable parameters, strong length generalization.

Normalization Strategies

Post-LayerNorm (original Transformer, GPT-2): Normalization is applied after the residual addition: \(\text{LN}(x + \text{Sublayer}(x))\). Can cause gradient instability in deep networks because the residual path passes through normalization.

Pre-LayerNorm (GPT-3, PaLM): Normalization is applied before the sublayer: \(x + \text{Sublayer}(\text{LN}(x))\). The residual path is clean (no normalization), enabling more stable gradient flow. Nearly universal in modern LLMs.

RMSNorm (LLaMA, Mistral, Gemma): A simplified Pre-LN that omits mean subtraction: \(\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum x_i^2 + \epsilon}} \cdot \gamma\). Approximately 10-15% faster than LayerNorm with equivalent quality. Mathematically, it only normalizes variance, not mean.

$$\text{RMSNorm}(x) = \frac{x}{\text{RMS}(x)} \cdot \gamma, \quad \text{RMS}(x) = \sqrt{\frac{1}{d}\sum_{i=1}^d x_i^2}$$
Common Misconception

Pre-LN does not mean "better" unconditionally. Post-LN can actually produce better final quality if training is carefully managed (warmup, gradient clipping). Pre-LN's advantage is stability -- it converges reliably without extensive hyperparameter tuning, which matters more at scale.

4
Activation Functions & Training Strategies
▼

FFN Activation Functions

GELU (GPT-2/3, BERT): The Gaussian Error Linear Unit computes \(\text{GELU}(x) = x \cdot \Phi(x)\), where \(\Phi\) is the Gaussian CDF. It provides a smooth, non-monotonic approximation to ReLU that helps gradient flow in deep networks.

SwiGLU (LLaMA, PaLM, Mistral): Combines Swish activation with a Gated Linear Unit. The FFN computes \(\text{SwiGLU}(x) = (\text{Swish}(xW_1)) \odot (xW_3)\) followed by \(W_2\). This introduces a third weight matrix but empirically improves quality by ~1-2% on benchmarks at matched compute. The gating mechanism lets the network learn what information to pass through.

$$\text{SwiGLU}(x, W_1, W_2, W_3) = (\sigma(xW_1) \odot xW_1) \cdot (xW_3) \cdot W_2$$

where \(\sigma(x) = x \cdot \text{sigmoid}(\beta x)\) is Swish. Most implementations use \(\beta = 1\).

Training Strategy Differences

Context Length Scaling: GPT-3 trained at 2K context. LLaMA 2 uses 4K. Mistral introduces Sliding Window Attention (SWA) at 4K window size for efficient 32K context. LLaMA 3 reaches 128K via progressive training: start at 8K, then extend with RoPE frequency scaling.

Optimizer Choices: Most LLMs use AdamW with cosine learning rate decay. LLaMA pioneered using a higher \(\beta_2 = 0.95\) (vs. standard 0.999) for stability. Chinchilla scaling laws (Hoffmann et al., 2022) showed that training tokens should scale linearly with model parameters: a 70B model needs ~1.4T tokens.

Data Mix: The quality and composition of pretraining data matters as much as architecture. LLaMA's key insight was that a smaller model trained on more data (1T+ tokens) outperforms a larger model trained on less. Mistral and Qwen further refine data filtering and curriculum strategies.

Design Insight

SwiGLU's third projection matrix means the FFN hidden dimension must shrink to maintain parameter parity. LLaMA uses \(d_{ff} = \frac{8}{3} d_{model}\) (rounded to nearest multiple of 256) instead of the standard \(4 \times d_{model}\), so total FFN parameters remain comparable despite the extra matrix.

Evolution Pattern

Notice the convergence: post-2022 models nearly universally adopt Pre-RMSNorm + RoPE + SwiGLU + GQA + no bias terms. The primary differentiators are now training data quality, context length strategy, and fine-tuning approach rather than architecture.

6
Key Takeaways
▼

Architecture choices have converged. The "LLaMA recipe" (Pre-RMSNorm, RoPE, SwiGLU, GQA) has become the default for new open models. Divergence now occurs in context-length engineering, MoE routing, and data strategies.

KV-cache efficiency is the inference bottleneck. GQA reduced KV-cache by 8x in LLaMA 2-70B. Sliding Window Attention (Mistral) bounds cache to window size. These are not just academic improvements -- they determine whether a model fits on consumer hardware.

RoPE unlocked length extrapolation. Unlike learned positional embeddings, RoPE's rotary structure allows extending context at inference time via frequency scaling (NTK-aware, YaRN, Dynamic NTK). This is why modern models can go from 4K training to 128K+ inference.

Training strategy matters as much as architecture. Chinchilla showed that GPT-3 was undertrained. LLaMA proved that smaller models with more data win. The field has shifted from "bigger model" to "better data + longer training + smart curriculum."
