Policy Evaluation & Policy Improvement

The core cycle of Reinforcement Learning: understanding and optimizing behavior
Foundational Reinforcement Learning O(S²A) per iteration
1
Understanding the Core Cycle
▼

What is it? In Reinforcement Learning (RL), an agent learns to make decisions in an environment to maximize cumulative reward. The agent's decision-making strategy is called a policy (\(\pi\)). To know if a policy is good, we need to quantify its expected future reward, which is its value function (\(V^\pi\)). The cycle of "Policy Evaluation" (calculating \(V^\pi\)) and "Policy Improvement" (making a better \(\pi'\) based on \(V^\pi\)) forms the backbone of many RL algorithms like Policy Iteration.

Analogy: Imagine you're trying to find the best route through a city (your "policy") to get to work.

  • Policy Evaluation: You drive your current route for a week, measuring travel times, fuel costs, and stress levels. You calculate the "value" of this route (e.g., average 45 minutes, $20 fuel, 3 stress points).
  • Policy Improvement: Based on this evaluation, you realize a specific turn consistently leads to a bad traffic jam. You decide to try a different turn at that intersection, hoping to improve your overall commute. This new route is your "improved policy."
You repeat: evaluate the new route, then improve it further, until you find the optimal commute.

💡 If you remember one thing

Policy Evaluation answers "How good is the current strategy?" by computing expected returns. Policy Improvement answers "Can I find a better strategy?" by greedily choosing actions that maximize those expected returns. This iterative dance leads to optimal behavior.

2
How It Works Internally
▼

Formalizing the Problem

We consider a Markov Decision Process (MDP) defined by:

  • A set of states \(\mathcal{S}\)
  • A set of actions \(\mathcal{A}\)
  • Transition probabilities \(P(s'|s,a)\): probability of reaching state \(s'\) from \(s\) after taking action \(a\)
  • Reward function \(R(s,a,s')\): immediate reward for transition \(s \xrightarrow{a} s'\)
  • Discount factor \(\gamma \in [0,1]\): how much future rewards are valued
A policy \(\pi(a|s)\) is a probability distribution over actions for each state. The goal is to find an optimal policy \(\pi^*\) that maximizes the expected cumulative discounted reward.

1. Policy Evaluation: The Bellman Expectation Equation

Given a policy \(\pi\), the value function \(V^\pi(s)\) for state \(s\) is the expected return starting from \(s\) and following \(\pi\):

$$V^\pi(s) = \mathbb{E}_\pi \left[ \sum_{k=0}^\infty \gamma^k R_{t+k+1} \middle| S_t = s \right]$$

This can be broken down into the immediate reward plus the discounted value of the next state, known as the Bellman Expectation Equation:

$$V^\pi(s) = \sum_{a} \pi(a|s) \sum_{s', r} P(s', r|s, a) \left[ r + \gamma V^\pi(s') \right]$$

We solve this system of linear equations iteratively. Starting with an arbitrary \(V_0(s)\) (e.g., all zeros), we compute \(V_{k+1}(s)\) from \(V_k(s)\) until convergence:

$$V_{k+1}(s) = \sum_{a} \pi(a|s) \sum_{s', r} P(s', r|s, a) \left[ r + \gamma V_k(s') \right]$$

2. Policy Improvement: Greedy Action Selection

Once we have \(V^\pi(s)\), we can find a better policy \(\pi'\). For each state \(s\), we choose the action \(a\) that maximizes the expected \(Q^\pi(s,a)\) value (the value of taking action \(a\) in state \(s\) and then following \(\pi\)):

$$Q^\pi(s,a) = \sum_{s', r} P(s', r|s, a) \left[ r + \gamma V^\pi(s') \right]$$

The new policy \(\pi'(s)\) is then defined as taking the greedy action:

$$\pi'(s) = \arg\max_{a \in \mathcal{A}} Q^\pi(s,a)$$

The Policy Improvement Theorem states that if \(\pi'\) is constructed this way, then \(V^{\pi'}(s) \ge V^\pi(s)\) for all \(s \in \mathcal{S}\). The process repeats until the policy no longer changes, at which point it must be optimal.

🔑 Key Property

Policy Iteration alternates between fully evaluating the current policy (\(V^\pi\)) and then making it greedy with respect to that value function (\(\pi'\)). This cycle is guaranteed to converge to the optimal policy \(\pi^*\) and optimal value function \(V^*\).

3
Why It Works — Convergence Proof Sketch
▼

The Policy Improvement Theorem

Let \(\pi\) and \(\pi'\) be any two deterministic policies. If for all states \(s \in \mathcal{S}\), \(Q^\pi(s, \pi'(s)) \ge V^\pi(s)\), then the new policy \(\pi'\) is better than or equal to \(\pi\), i.e., \(V^{\pi'}(s) \ge V^\pi(s)\) for all \(s \in \mathcal{S}\).

Proof Sketch:

1. By definition of \(V^{\pi'}(s)\) and the greedy improvement step:

$$V^{\pi'}(s) = Q^{\pi'}(s, \pi'(s)) \quad \text{and} \quad Q^{\pi'}(s, \pi'(s)) \ge Q^{\pi}(s, \pi'(s))$$

2. We can expand \(Q^{\pi}(s, \pi'(s))\) using the Bellman expectation equation:

$$Q^{\pi}(s, \pi'(s)) = \sum_{s', r} P(s', r|s, \pi'(s)) \left[ r + \gamma V^{\pi}(s') \right]$$

3. Substitute the inequality from the theorem's premise \(Q^\pi(s, \pi'(s)) \ge V^\pi(s)\) into the expanded Bellman equation, and repeatedly apply it for successive states:

\begin{align*} V^{\pi'}(s) &\ge Q^\pi(s, \pi'(s)) \\ &= \sum_{s', r} P(s', r|s, \pi'(s)) \left[ r + \gamma V^\pi(s') \right] \\ &\le \sum_{s', r} P(s', r|s, \pi'(s)) \left[ r + \gamma Q^\pi(s', \pi'(s')) \right] \\ &\le \sum_{s', r} P(s', r|s, \pi'(s)) \left[ r + \gamma \sum_{s'', r'} P(s'', r'|s', \pi'(s')) [r' + \gamma Q^\pi(s'', \pi'(s''))] \right] \\ &\dots \end{align*}

This expansion shows that at each step, the value under \(\pi'\) is greater than or equal to the value under \(\pi\), propagating through future states. Since \(\gamma < 1\), the geometric series converges, leading to \(V^{\pi'}(s) \ge V^\pi(s)\).

Convergence to Optimality

Since the state space is finite, there are a finite number of deterministic policies. Policy Improvement guarantees that \(V^{\pi'}(s) \ge V^\pi(s)\) for all \(s\), and if \(V^{\pi'}(s) = V^\pi(s)\) for all \(s\), then \(\pi\) must be an optimal policy. Thus, Policy Iteration must converge to an optimal policy in a finite number of steps.

⚠️ Common Pitfall

Policy Iteration requires a complete model of the environment (transition probabilities \(P(s'|s,a)\) and rewards \(R(s,a,s')\)). In many real-world scenarios, this model is unknown. Model-free algorithms like Q-learning or SARSA learn directly from interactions without needing to explicitly compute \(P\) or \(R\), but they still implicitly perform evaluation and improvement steps.

Key Takeaways
▼

When Policy Iteration is suitable:

  • When a complete model of the environment (transition probabilities and rewards) is known.
  • For problems with small to medium-sized state and action spaces, where the computational cost of iterating over all states and actions is manageable.
  • As a foundational algorithm to understand the principles of dynamic programming in RL before moving to more complex model-free methods.

Limitations and Alternatives:

  • Computational Cost: Each policy evaluation step can be computationally expensive, requiring solving a system of linear equations or many iterations. This becomes prohibitive for large state spaces.
  • Model Dependence: The biggest limitation is the requirement for a known MDP model. In most practical applications, this model is unknown and must be learned or approximated.
  • Value Iteration: A related dynamic programming algorithm that combines evaluation and improvement into a single update step, directly solving the Bellman Optimality Equation. It often converges faster in practice but implicitly performs policy improvement at every step.
  • Model-Free RL: For unknown models, Q-learning, SARSA, and policy gradient methods learn directly from experience, avoiding explicit evaluation and improvement loops on the full state space. However, the underlying principles of estimating values and improving policies remain.
💡 Big Picture

Policy Evaluation and Policy Improvement are two fundamental components present in almost all Reinforcement Learning algorithms. Whether explicitly separated (as in Policy Iteration) or blended (as in Value Iteration or Q-learning), the core idea of estimating "how good" a strategy is and then making it "better" drives all of RL.

# Assume `env` provides:
# env.states, env.actions
# env.P(s, a) -> list of (prob, next_s, reward) tuples
# env.is_terminal(s) -> bool
def policy_evaluation(policy, V, gamma, theta=1e-6):
while True:
delta = 0
for s in env.states:
if env.is_terminal(s):
V[s] = 0
continue
v_old = V[s]
v_new = 0
for a_prob, a in policy[s]: # policy[s] might be [(1.0, 'up')] or [(0.25, 'up'), ...]
for prob, next_s, reward in env.P(s, a):
v_new += a_prob * prob * (reward + gamma * V[next_s])
V[s] = v_new
delta = max(delta, abs(v_old - V[s]))
if delta < theta:
break
return V
def policy_improvement(V, gamma):
new_policy = {}
for s in env.states:
if env.is_terminal(s):
new_policy[s] = [(1.0, None)] # No action in terminal state
continue
q_values = {}
for a in env.actions:
q_sa = 0
for prob, next_s, reward in env.P(s, a):
q_sa += prob * (reward + gamma * V[next_s])
q_values[a] = q_sa
best_action = max(q_values, key=q_values.get)
new_policy[s] = [(1.0, best_action)] # Deterministic greedy policy
return new_policy
def policy_iteration(env, gamma):
V = {s: 0 for s in env.states}
# Initialize with a random policy (e.g., uniform over actions)
policy = {s: [(1.0/len(env.actions), a) for a in env.actions] for s in env.states}
for s in env.terminal_states: policy[s] = [(1.0, None)]
while True:
V = policy_evaluation(policy, V, gamma)
new_policy = policy_improvement(V, gamma)
if new_policy == policy: # Check for policy stability
break
policy = new_policy
return V, policy
