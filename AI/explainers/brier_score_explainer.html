Understanding the Brier Score
💡 The 30-Second Version

Your weather app says 80% chance of rain. It doesn't rain. How wrong was it? The Brier score measures exactly this — the squared error between a predicted probability and the actual binary outcome. Lower is better; 0 is perfect.

Real-world analogy: Imagine a doctor says "this patient has a 90% chance of diabetes." If the patient does have diabetes, the prediction was excellent (small error). If not, the error is \((0.9 - 0)^2 = 0.81\) — very high. The Brier score averages these squared errors across all patients.

What makes it special: the Brier score is a proper scoring rule. That means the only way to minimize your expected score is to report your true beliefs — you cannot game it by inflating or deflating your stated probability.

Key Concept

The Brier score = MSE in probability space. It rewards calibration (correct probabilities) AND resolution (spreading predictions away from the base rate). A proper scoring rule — the unique minimizer is honest probability reporting.

Formula (binary case):

$$BS = \frac{1}{N}\sum_{i=1}^{N}(f_i - o_i)^2$$

where \(f_i \in [0,1]\) is the predicted probability and \(o_i \in \{0,1\}\) is the observed outcome.

Range: \([0, 2]\) in general; \([0, 1]\) for binary outcomes. Climatological baseline (always predict the base rate \(\bar{o}\)) gives \(BS_{ref} = \bar{o}(1-\bar{o})\).

2
How It Works — The Murphy Decomposition

The deepest insight about the Brier score comes from the Murphy (1973) decomposition, which splits it into three interpretable components:

$$BS = \underbrace{\text{REL}}_{\text{reliability}} - \underbrace{\text{RES}}_{\text{resolution}} + \underbrace{\text{UNC}}_{\text{uncertainty}}$$

Group predictions into \(K\) forecast bins. Let \(n_k\) = number of forecasts in bin \(k\), \(f_k\) = the forecast probability for that bin, \(o_k\) = observed relative frequency in bin \(k\), \(\bar{o}\) = overall base rate, \(N\) = total predictions.

$$\text{REL} = \frac{1}{N}\sum_{k=1}^{K} n_k(f_k - o_k)^2$$
$$\text{RES} = \frac{1}{N}\sum_{k=1}^{K} n_k(o_k - \bar{o})^2$$
$$\text{UNC} = \bar{o}(1-\bar{o})$$
Murphy Decomposition Interpretation

REL (Reliability): How far are stated probabilities from observed frequencies? Lower is better.
RES (Resolution): How much do forecasts differ from the base rate? Higher is better.
UNC (Uncertainty): Irreducible variability in the data — fixed by nature, not the model.

A good model has low REL (is calibrated) and high RES (is informative). They trade off: saying "50% always" has perfect REL on balanced data but zero RES.

⚠️ Common Misconception

The Brier score is NOT the same as accuracy. A model that always predicts 0.5 achieves Brier = 0.25 on balanced data — worse than a calibrated, confident model, but better than an overconfident wrong model. Lower Brier ≠ higher AUC.

3
Why It Works — Propriety Proof Sketch

A scoring rule \(S(f, o)\) is strictly proper if for a forecaster whose true belief is \(p\):

$$\mathbb{E}[S(p, O)] < \mathbb{E}[S(f, O)] \quad \forall f \neq p$$

For the Brier score, the expected score when reporting \(f\) but truth is \(p\):

$$\mathbb{E}[BS] = p(f-1)^2 + (1-p)(f-0)^2 = pf^2 - 2pf + p + f^2 - pf^2$$

Taking the derivative with respect to \(f\) and setting to zero:

$$\frac{d}{df}\mathbb{E}[BS] = 2f - 2p = 0 \implies f^* = p$$

The second derivative is \(+2 > 0\), so this is a strict minimum. Reporting your true belief \(p\) uniquely minimizes your expected Brier score. This is what "proper scoring rule" means.

Brier Skill Score (BSS)

To compare against a climatological baseline, use:

$$BSS = 1 - \frac{BS}{BS_{ref}} = 1 - \frac{BS}{\bar{o}(1-\bar{o})}$$

BSS = 1 is perfect. BSS = 0 means no better than always predicting the base rate. BSS < 0 means worse than climatology.

Key Takeaways & When to Use

Use the Brier score when:

  • You need to evaluate probabilistic predictions (not just class labels)
  • Calibration matters (medical risk scores, weather forecasting, finance)
  • You want a single number that rewards both calibration and resolution
  • You want incentive-compatible evaluation (can't be gamed by hedging)

Decision Guide

Brier score when you want an intuitive, bounded (0–1) metric that rewards honest probabilities.
Log loss when you want to penalise overconfident wrong predictions more aggressively (log loss → ∞ as \(f \to 0\) for \(o=1\)).
BSS when comparing against a non-trivial baseline (imbalanced classes).
