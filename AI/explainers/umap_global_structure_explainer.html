Advanced Unsupervised Learning Manifold Learning O(n log n)

Understanding UMAP
▼

What is it? UMAP (Uniform Manifold Approximation and Projection) takes high-dimensional data (e.g. 784-pixel images, 768-dim sentence embeddings) and squashes it into 2 or 3 dimensions you can actually plot — while trying hard to keep points that were "neighbors" in the original space still neighbors in the picture, and keep the rough distances between distant clusters honest.

Analogy: Imagine flattening a crumpled paper ball onto a table without tearing it. You can't do this perfectly (that's topology for you), but you can be smart: keep every local patch of paper looking like it did before crumpling (local neighborhoods preserved), and try not to fold far-apart regions on top of each other (global structure preserved). t-SNE is like flattening with a heavy hammer that only cares about local patches; UMAP is more careful about the whole sheet.

💡 If you remember one thing

UMAP builds a weighted graph of "how confidently is point B a neighbor of point A" (a fuzzy simplicial set) in high-dim space, builds the same kind of graph in a low-dim layout, and then nudges the low-dim points until the two graphs match as closely as possible — measured by cross-entropy, not squared error.

How UMAP Works Internally
▼

Phase 1 — Build a fuzzy topological representation (high-dim)

For each point i, find its k nearest neighbors (n_neighbors, typically 15). Compute two local statistics: ρᵢ — the distance to the single nearest neighbor (this enforces the assumption that the manifold is locally uniform, i.e. every point should have at least one neighbor at distance ≈ 0) — and σᵢ, found by binary search so that the local fuzzy neighborhood has an effective size of log₂(k). This gives each point its own adaptive notion of "close," which is exactly what makes UMAP robust to varying density.

Phase 2 — Symmetrize into one global graph

Neighborliness computed this way is directional (A can consider B a neighbor without B reciprocating). UMAP combines the two directed weights using a fuzzy set union (probabilistic t-conorm) rather than a plain average — so if either point considers the other close, the edge stays strong.

Phase 3 — Optimize a low-dimensional layout

Initialize low-dim coordinates (UMAP defaults to a spectral embedding of the graph Laplacian; we use random init here for transparency). Then run stochastic gradient descent that treats the layout as a physics simulation: connected points attract each other along the smooth curve family 1/(1+a·d^{2b}), and randomly sampled non-neighbor pairs repel each other. Both forces run every epoch, simultaneously — the layout is a real-time balance, not sequential phases.

Design Decision — why negative sampling instead of computing all repulsions?

Computing exact repulsion for every non-edge pair is O(n²) per epoch. UMAP instead samples a handful of random "negative" pairs per node per epoch — an approximation borrowed from word2vec — cutting cost to roughly O(n) per epoch and making UMAP dramatically faster than t-SNE's O(n²) (or O(n log n) with Barnes-Hut) on large datasets.

🔑 Key Property

UMAP has a theoretical foundation in Riemannian geometry and algebraic topology: it treats the data as sampled from a manifold with a locally-varying metric, approximates that manifold as a fuzzy simplicial set (a weighted graph, in practice), and finds the low-dim layout minimizing cross-entropy against that fuzzy set — not a heuristic, but the fuzzy-set analogue of minimizing a topological "difference."

Why It Works — The Math
▼

Local fuzzy membership

For point \(i\) with sorted neighbor distances \(d_{i1} \le d_{i2} \le \dots \le d_{ik}\), set \(\rho_i = d_{i1}\). Find \(\sigma_i\) solving:

$$\sum_{j=1}^{k} \exp\!\left(-\frac{\max(0,\, d_{ij}-\rho_i)}{\sigma_i}\right) = \log_2(k)$$

via binary search (monotonic in \(\sigma_i\)). The directed membership strength of \(j\) as a neighbor of \(i\) is then:

$$v_{j|i} = \exp\!\left(-\frac{\max(0,\, d_{ij}-\rho_i)}{\sigma_i}\right)$$

Symmetrization (fuzzy set union)

Treating \(v_{j|i}\) as the probability of an edge existing, the union of two fuzzy sets (this direction and the reverse) is the probabilistic t-conorm:

$$w_{ij} = v_{j|i} + v_{i|j} - v_{j|i}\cdot v_{i|j}$$

Cross-entropy layout loss

Low-dim similarity uses a smooth curve fit to match a Laplace-like kernel: \(\displaystyle \phi(d) = \frac{1}{1+a\,d^{2b}}\), with \(a\!\approx\!1.929,\ b\!\approx\!0.7915\) for the default min_dist=0.1. UMAP minimizes the fuzzy-set cross-entropy between high-dim weights \(w_{ij}\) and low-dim weights \(\phi(d_{ij})\) over all pairs:

$$C = \sum_{i\ne j}\Big[\, w_{ij}\log\frac{w_{ij}}{\phi(d_{ij})} \;+\; (1-w_{ij})\log\frac{1-w_{ij}}{1-\phi(d_{ij})} \Big]$$

The first term is attractive (pulls \(\phi(d_{ij})\) up toward \(w_{ij}\) when the pair is a true neighbor); the second is repulsive (pushes \(\phi(d_{ij})\) down for non-neighbor pairs). Differentiating w.r.t. the low-dim positions gives the SGD update used every epoch:

$$\frac{\partial C}{\partial y_i} \propto \underbrace{-\frac{2ab\,d^{2(b-1)}}{1+a\,d^{2b}}(y_i-y_j)}_{\text{attractive, edges}} \;+\; \underbrace{\frac{2b}{(\epsilon+d^2)(1+a\,d^{2b})}(y_i-y_j)}_{\text{repulsive, negative samples}}$$

where \(d = \|y_i-y_j\|\) and \(\epsilon\) avoids division by zero. Because the same \(\phi(d)\) curve family with the SAME \(a,b\) is used everywhere, distances between well-separated clusters are not artificially rescaled the way t-SNE's per-point normalized Gaussian/Student-t construction rescales them — this is the mathematical root of UMAP's better global-distance preservation.

⚠️ Common Misconception

"UMAP embedding distances are meaningful in an absolute sense." They are not — only relative ordering of distances is (approximately) preserved; UMAP is not a metric-preserving isometry. Cluster sizes and inter-cluster gaps in a UMAP plot should be read qualitatively, never as exact quantities (this is a frequent single-cell genomics pitfall).

▼

When to use UMAP: large datasets, when you need reasonable global structure (e.g. comparing cluster sizes/distances), when you'll need to embed new points later, or as a general-purpose nonlinear reduction step before clustering/visualization.

When NOT to use UMAP (or any 2D projection): when you need exact distance/density estimates, or rigorous statistical inference — treat the 2D plot as a qualitative map, not a metric space. For linear, interpretable, or variance-maximizing structure, prefer PCA.

🎯 Decision Rule

Need a fast, general-purpose exploratory 2D/3D map with decent global fidelity → UMAP. Need maximum local cluster separation for a single static figure and dataset is small → t-SNE is fine. Need interpretable linear axes / need to explain variance → PCA. Need both speed AND to embed brand-new points later → UMAP (or Parametric UMAP with a neural encoder).
