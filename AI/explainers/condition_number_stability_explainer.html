Condition Number & Numerical Stability

How sensitive is \(Ax = b\) to small perturbations? The condition number tells you.
Intermediate Linear Algebra Numerical Methods Must Know for ML
1
Understanding the Condition Number
▼

What is it? When you solve a system of equations \(Ax = b\), tiny errors in \(b\) (measurement noise, floating-point rounding) get amplified into errors in the solution \(x\). The condition number \(\kappa(A)\) measures exactly how bad this amplification can be. A small condition number (near 1) is good — the problem is well-conditioned. A large condition number (like \(10^{10}\)) is bad — the problem is ill-conditioned, and even microscopic errors in input can produce completely wrong output.

Analogy: Imagine two nearly-parallel streets intersecting at a very shallow angle. Their "intersection point" is where you live. Now someone gives you directions that are off by just one meter — but because the streets are nearly parallel, that tiny directional error moves the intersection point by a kilometer. The condition number is how shallow that angle is: a right-angle intersection (κ = 1) is robust to misdirection; a nearly-parallel intersection (κ huge) is catastrophically sensitive.

💡 If you remember one thing

The condition number \(\kappa(A) = \sigma_{\max}/\sigma_{\min}\) (ratio of largest to smallest singular value) bounds the relative error amplification: $$\frac{\|\delta x\|}{\|x\|} \leq \kappa(A) \cdot \frac{\|\delta b\|}{\|b\|}$$ Forming the normal equations \(A^\top A x = A^\top b\) squares the condition number: \(\kappa(A^\top A) = \kappa(A)^2\). This is why direct matrix inversion is dangerous for ill-conditioned systems.

2
Geometric Interpretation via SVD
▼

The Unit Circle Under a Linear Map

The Singular Value Decomposition (SVD) reveals the geometry of what a matrix \(A\) does to space. Write \(A = U \Sigma V^\top\). The matrix \(A\) maps the unit sphere \(\{x : \|x\| = 1\}\) to an ellipsoid whose semi-axis lengths are exactly the singular values \(\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_n\).

  • \(\sigma_{\max}\) = length of the longest axis of the output ellipsoid
  • \(\sigma_{\min}\) = length of the shortest axis of the output ellipsoid
  • \(\kappa(A) = \sigma_{\max}/\sigma_{\min}\) = the eccentricity ratio

A perfectly conditioned matrix (\(\kappa=1\)) maps the circle to another circle. An ill-conditioned matrix maps it to a very thin, elongated ellipse — almost a line segment. Directions along the short axis are nearly wiped out: the matrix barely "sees" them. When you invert, those nearly-zero directions get enormously amplified.

Connection to Near-Parallel Lines

In 2D, solving \(Ax=b\) geometrically means finding the intersection of two lines (the rows of \(A\)). If the rows are nearly parallel, the intersection is poorly localized — moving \(b\) by a hair shifts the intersection massively. The angle \(\theta\) between the rows satisfies \(\sin\theta \approx \sigma_{\min}/\sigma_{\max} = 1/\kappa(A)\). Large \(\kappa\) → small angle → near-parallel rows → catastrophic sensitivity.

🔑 Key Property

For a matrix \(A \in \mathbb{R}^{m \times n}\) with SVD \(A = U\Sigma V^\top\), the condition number with respect to the 2-norm is \(\kappa_2(A) = \sigma_1 / \sigma_n\). It equals the ratio of the largest to smallest singular value. For square nonsingular \(A\): \(\kappa(A) = \|A\|_2 \cdot \|A^{-1}\|_2\).

Why Normal Equations Square the Condition Number

When solving the least-squares problem \(\min_x \|Ax - b\|^2\), the classical approach forms the normal equations \(A^\top A x = A^\top b\). But \(A^\top A\) has singular values \(\sigma_i^2\), so \(\kappa(A^\top A) = \sigma_{\max}^2 / \sigma_{\min}^2 = \kappa(A)^2\). If \(\kappa(A) = 10^6\), working with \(A^\top A\) gives condition \(10^{12}\) — double-precision floating point only has about 15-16 significant digits, so you lose 12 digits of precision. QR decomposition or the SVD solve the same problem without this squaring.

⚠️ Practical Warning

Never form \(A^\top A\) explicitly to solve least squares. Use np.linalg.lstsq (which uses QR/SVD internally) or scipy.linalg.lstsq. Both avoid squaring the condition number. The MATLAB backslash operator (\) does the same.

3
The Math — Error Bound Derivation
▼

The Perturbation Bound

Suppose \(Ax = b\) and \(A(x + \delta x) = b + \delta b\). Since \(A\) is fixed: \(A \,\delta x = \delta b\), so \(\delta x = A^{-1}\delta b\).

$$\|\delta x\| \leq \|A^{-1}\| \cdot \|\delta b\|$$

From the original system \(b = Ax\), we get \(\|b\| \leq \|A\| \cdot \|x\|\), i.e., \(1/\|x\| \leq \|A\|/\|b\|\). Combining:

$$\frac{\|\delta x\|}{\|x\|} \leq \|A\| \cdot \|A^{-1}\| \cdot \frac{\|\delta b\|}{\|b\|} = \kappa(A) \cdot \frac{\|\delta b\|}{\|b\|}$$

This is tight — there exist perturbations \(\delta b\) that actually achieve the bound. The condition number is not pessimistic; it is the exact worst-case amplification factor.

Condition Number via SVD — Formal Definition

$$\kappa_p(A) = \|A\|_p \cdot \|A^{-1}\|_p$$

For the 2-norm (spectral norm), \(\|A\|_2 = \sigma_{\max}\) and \(\|A^{-1}\|_2 = 1/\sigma_{\min}\), giving:

$$\kappa_2(A) = \frac{\sigma_{\max}}{\sigma_{\min}}$$

Matrix Perturbation (Perturbation in A)

If both \(A\) and \(b\) are perturbed by \(\delta A\) and \(\delta b\) simultaneously:

$$\frac{\|\delta x\|}{\|x\|} \leq \frac{\kappa(A)}{1 - \kappa(A)\frac{\|\delta A\|}{\|A\|}} \left(\frac{\|\delta A\|}{\|A\|} + \frac{\|\delta b\|}{\|b\|}\right)$$

This blows up when \(\kappa(A) \cdot \|\delta A\|/\|A\| \to 1\), i.e., when the perturbation is large enough to make \(A + \delta A\) singular.

Loss of Significant Digits

A rule of thumb: if \(\kappa(A) \approx 10^k\) and you have \(d\) decimal digits of precision (for float64, \(d \approx 16\)), then the solution \(x\) has approximately \(d - k\) correct digits. So \(\kappa = 10^{12}\) with float64 leaves only ~4 correct digits.

$$\text{correct digits in } x \approx d - \log_{10}\kappa(A)$$
📐 Normal Equations — Squaring Proof

If \(A = U\Sigma V^\top\), then \(A^\top A = V\Sigma^\top U^\top U\Sigma V^\top = V\Sigma^2 V^\top\). The singular values of \(A^\top A\) are \(\sigma_i^2\), so \(\kappa(A^\top A) = \sigma_{\max}^2/\sigma_{\min}^2 = \kappa(A)^2\). ∎

Key Takeaways & Practical Rules
▼
Condition NumberInterpretationFloat64 Digits LostRecommended Solver
\(\kappa \approx 1\)Perfectly conditioned, isometric0Any (Gaussian elim. fine)
\(\kappa \sim 10^3\)Well-conditioned~3LU / QR
\(\kappa \sim 10^6\)Moderately ill-conditioned~6QR with pivoting
\(\kappa \sim 10^{10}\)Severely ill-conditioned~10SVD with truncation
\(\kappa \gtrsim 10^{15}\)Effectively singular in float6415+Regularization (Tikhonov/ridge)

Why This Matters for ML

  • Normal equations for linear regression: squaring κ — use QR (sklearn's default) not explicit inversion
  • Feature scaling: StandardScaler reduces condition number by equalizing column norms, which directly improves gradient descent conditioning
  • Ridge regression: adds \(\lambda I\) to \(A^\top A\), making κ(A^TA + λI) = (σ_max² + λ)/(σ_min² + λ) ≪ κ(A)²
  • Deep learning: weight matrices with high condition numbers lead to vanishing/exploding gradients; spectral normalization clips σ_max
  • Gram matrices in kernel methods: RBF kernels can produce nearly singular Gram matrices for clustered data; add nugget term ε·I
💡 Hierarchy of Stability

Most stable → least stable for solving \(\min_x\|Ax-b\|^2\):
SVD ≥ QR with pivoting > QR > LU > Normal equations \(A^\top A\). The normal equations square the condition number and should be avoided when \(\kappa(A)\) is large.

Code Trace — Numerical Demonstration
▼
import numpy as np
# Ill-conditioned 2x2 system (near-parallel rows)
A = np.array([[1.0, 1.0],
[1.0, 1.001]]) # rows differ by 0.001 in second column
b = np.array([2.0, 2.001])
b_perturbed = np.array([2.0, 2.002]) # b₂ perturbed by 0.001
# Compute condition number
kappa = np.linalg.cond(A) # ≈ 4001 (2-norm condition number)
sigma = np.linalg.svd(A, compute_uv=False) # [2.0005, 0.0005]
kappa_manual = sigma[0] / sigma[-1] # = 4001 ✓
# Solve both systems
x_true = np.linalg.solve(A, b) # [1.0, 1.0]
x_pert = np.linalg.solve(A, b_perturbed) # [1.0 - 1.0, 1.0 + 1.0] ≈ [0.0, 2.0]
# Relative errors confirm κ bound
rel_b = np.linalg.norm(b_perturbed - b) / np.linalg.norm(b)
rel_x = np.linalg.norm(x_pert - x_true) / np.linalg.norm(x_true)
amplification = rel_x / rel_b # ≈ kappa(A) at worst case
# Normal equations squaring κ
AtA = A.T @ A
kappa_AtA = np.linalg.cond(AtA) # ≈ 16,008,001 = 4001² ✓
# Safe: use QR (lstsq) not normal equations
x_safe = np.linalg.lstsq(A, b, rcond=None)[0] # Uses QR/SVD internally
x_unsafe = np.linalg.solve(AtA, A.T @ b) # Avoidable squaring!
