Decompose large optimization into small, parallelizable sub-problems via alternating updates
Advanced Optimization Theory Non-Smooth & Constrained O(k·n) per iter
1
Understanding ADMM
▼

What is it? ADMM is an algorithm for solving optimization problems that have two groups of variables with a coupling constraint between them. Rather than tackling the whole problem at once (which might be impossible or very slow), ADMM alternates: it optimizes over one group while holding the other fixed, then switches — repeating until both agree. A "multiplier" (Lagrange dual variable) is updated after each round to enforce the coupling constraint.

Analogy: Imagine two departments (Sales and Engineering) must agree on a shared product spec \(x = z\). Sales minimizes its own cost \(f(x)\) alone, Engineering minimizes its own cost \(g(z)\) alone, then a mediator (the dual variable) adjusts the "price" of disagreement. After a few rounds of negotiation, both departments converge to the same spec that minimizes the total cost.

If you remember one thing

ADMM splits \(\min_x\; f(x) + g(z)\;\text{s.t.}\;Ax + Bz = c\) into three cheap alternating steps — an \(x\)-update (solve a smooth sub-problem), a \(z\)-update (apply a proximal operator), and a dual variable update (gradient ascent on the Lagrangian). Each step is often closed-form.

ADMM shines in distributed / large-scale settings: each sub-problem can run on a separate machine, making it the workhorse behind modern distributed LASSO, consensus optimization, model-parallel training, and network flow problems.

How ADMM Works Internally
▼

The General Problem

ADMM solves the consensus form:

$$\underset{x,\,z}{\text{minimize}}\;\; f(x) + g(z) \quad\text{subject to}\;\; Ax + Bz = c$$

where \(f\) and \(g\) are convex (possibly non-smooth). The augmented Lagrangian adds a quadratic penalty \(\tfrac{\rho}{2}\|Ax+Bz-c\|^2\) that makes the objective strongly convex in each variable:

$$L_\rho(x,z,y) = f(x) + g(z) + y^\top(Ax+Bz-c) + \tfrac{\rho}{2}\|Ax+Bz-c\|^2$$

The Three Update Steps (Scaled Form)

Using the scaled dual variable \(u = y/\rho\), the three steps per iteration \(k\) are:

$$\underbrace{x^{k+1} \;=\; \underset{x}{\operatorname{argmin}}\left[f(x) + \tfrac{\rho}{2}\|Ax + Bz^k - c + u^k\|^2\right]}_{\textbf{x-update: smooth quadratic sub-problem}}$$
$$\underbrace{z^{k+1} \;=\; \underset{z}{\operatorname{argmin}}\left[g(z) + \tfrac{\rho}{2}\|Ax^{k+1} + Bz - c + u^k\|^2\right]}_{\textbf{z-update: proximal operator of } g}$$
$$\underbrace{u^{k+1} \;=\; u^k + Ax^{k+1} + Bz^{k+1} - c}_{\textbf{dual update: gradient ascent on constraint violation}}$$

LASSO as a Special Case

For LASSO \(\min_x \tfrac{1}{2}\|Ax-b\|^2 + \lambda\|x\|_1\), set \(f(x)=\tfrac{1}{2}\|Ax-b\|^2\), \(g(z)=\lambda\|z\|_1\), and add constraint \(x=z\). Then:

  • x-update: solve \((A^\top A + \rho I)x = A^\top b + \rho(z^k - u^k)\) — a linear system, one Cholesky once.
  • z-update: soft threshold \(z = \mathcal{S}_{\lambda/\rho}(x^{k+1}+u^k)\) — closed-form, component-wise.
  • u-update: \(u \mathrel{+}= x - z\) — trivial accumulation.
Key Property — Convergence

Under mild convexity, ADMM converges to a primal-dual optimal pair. The primal residual \(\|Ax^k+Bz^k-c\|\to 0\) measures constraint satisfaction; the dual residual \(\rho\|B(z^k-z^{k-1})\|\to 0\) measures optimality. Both must vanish at convergence.

3
The Math Behind ADMM
▼

Proximal Operator — The z-Update in General

The z-update is always the proximal operator of \(g\) evaluated at \(v = c - Ax^{k+1} - Bu^k\):

$$\mathbf{prox}_{g/\rho}(v) = \underset{z}{\operatorname{argmin}}\left[g(z) + \tfrac{\rho}{2}\|z - v\|^2\right]$$

For \(g(z)=\lambda\|z\|_1\), the prox is the soft-threshold (component-wise):

$$\mathcal{S}_\kappa(v_i) = \operatorname{sign}(v_i)\cdot\max(|v_i|-\kappa,\; 0), \quad \kappa = \lambda/\rho$$

KKT Optimality Conditions

At a solution \((x^\star, z^\star, y^\star)\), the KKT conditions are:

$$0 \in \partial f(x^\star) + A^\top y^\star, \quad 0 \in \partial g(z^\star) + B^\top y^\star, \quad Ax^\star + Bz^\star = c$$

The dual residual \(\rho A^\top B(z^k - z^{k-1})\) is the gap from satisfying the first condition, which vanishes as \(z\) stops changing.

Stopping Criteria

Stop when both residuals fall below tolerances \(\epsilon_\text{abs}, \epsilon_\text{rel}\):

$$\|Ax^k + Bz^k - c\|_2 \leq \epsilon_\text{pri}, \quad \rho\|A^\top B(z^k - z^{k-1})\|_2 \leq \epsilon_\text{dual}$$
Common Pitfall — Choosing \(\rho\)

The penalty parameter \(\rho > 0\) controls the trade-off between primal and dual convergence speed. Too small: dual convergence is slow. Too large: primal convergence is slow. Adaptive schemes update \(\rho\) to balance the two residuals. The convergence rate is \(O(1/k)\) for general convex problems, linear for strongly convex ones.

Connection to Dual Decomposition & Proximal Point

ADMM generalizes dual decomposition (which has convergence issues without augmentation) and the proximal point algorithm (which needs full joint minimization). ADMM's genius is to alternate between the two variables rather than minimizing jointly, making each sub-problem easy while retaining convergence.

Key Takeaways & When to Use ADMM
▼

Use ADMM when:

  • The objective naturally splits into two groups \(f(x)+g(z)\) with a coupling constraint
  • Each sub-problem has an efficient closed-form solution (e.g., linear systems, soft-threshold)
  • The problem is too large for interior-point methods (millions of variables)
  • Distributed computation is available — each node solves its own \(f_i(x_i)\)

Do NOT use ADMM when:

  • High-accuracy solutions are needed — ADMM converges to \(\epsilon\) accuracy in \(O(1/\epsilon)\) iters, not the \(O(\log(1/\epsilon))\) of interior-point methods
  • The sub-problems have no closed form and need iterative solves themselves
  • The problem is unconstrained and smooth — use L-BFGS or conjugate gradient instead
Hierarchy of Related Methods

Gradient Descent (differentiable \(f\)) ⊂ Proximal Gradient (smooth \(f\) + non-smooth \(g\)) ⊂ ADMM (structured \(f+g\) with coupling constraint) ⊂ Interior-Point (general convex, high accuracy). ADMM occupies the sweet spot between speed-per-iteration and generality.

Key applications: consensus LASSO/ridge, distributed SVM, network utility maximization, image restoration (TV regularization), basis pursuit, portfolio optimization, model-parallel deep learning.
