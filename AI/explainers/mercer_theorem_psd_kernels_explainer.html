Mercer's Theorem & PSD Kernels

Why a valid kernel must have a non-negative Gram matrix — and what that buys you
Advanced Classical ML · SVM Functional Analysis · Linear Algebra
1
Understanding the Concept
▾

What is a kernel? A kernel \(K(x, x')\) is a similarity function between two inputs. Think of it as: "how alike are these two points?" The RBF kernel \(K(x,x') = e^{-\|x-x'\|^2/2\sigma^2}\) returns 1 when \(x = x'\) and decays toward 0 as they diverge.

The key question: not all symmetric functions are kernels. For an SVM to work, the kernel must secretly be computing a dot product in some feature space — i.e. \(K(x, x') = \langle \phi(x), \phi(x') \rangle\) for some (possibly infinite-dimensional) feature map \(\phi\). Mercer's theorem tells you exactly when this is true.

💡 The One-Sentence Version

A function \(K\) is a valid kernel if and only if its Gram matrix is positive semi-definite for every finite set of input points — equivalently, \(K\) admits a spectral decomposition with non-negative eigenvalues.

Real-world analogy: Imagine you're scoring how similar pairs of documents are. If you use a bad similarity function, you could end up in a contradictory world where a document is simultaneously "very similar" and "very different" to a set of others — the math collapses. Mercer's condition is the consistency check: it guarantees your similarity function has a coherent geometric interpretation.

🔑 Key Property

\(K\) is a valid Mercer kernel \(\Leftrightarrow\) for any \(n\) points \(\{x_1,\ldots,x_n\}\), the \(n \times n\) Gram matrix \(G_{ij} = K(x_i, x_j)\) is positive semi-definite (all eigenvalues \(\geq 0\)).

2
How It Works — The Mercer Decomposition
▾

From Gram matrix to feature map

Given a positive semi-definite Gram matrix \(G\), eigendecompose it: \(G = V \Lambda V^\top\) where \(\Lambda = \text{diag}(\lambda_1, \ldots, \lambda_n)\) with \(\lambda_i \geq 0\). The feature map is then \(\phi(x_i) = [\sqrt{\lambda_1} V_{i1},\, \ldots,\, \sqrt{\lambda_n} V_{in}]^\top\), and \(\langle \phi(x_i), \phi(x_j) \rangle = K(x_i, x_j)\). This always works because \(\sqrt{\lambda_i}\) is real when \(\lambda_i \geq 0\).

$$K(x, x') = \sum_{i=1}^{\infty} \lambda_i \,\phi_i(x)\,\phi_i(x'), \quad \lambda_i \geq 0$$

The continuous version of Mercer's theorem (for \(L^2\) kernels on compact domains) says the kernel has an eigenfunction expansion. For practical finite datasets, we work with the \(n \times n\) Gram matrix and its eigendecomposition.

Why negative eigenvalues break everything

If \(G\) has a negative eigenvalue \(\lambda_k < 0\), the corresponding "feature map" component would require \(\sqrt{\lambda_k} \in \mathbb{C}\) — an imaginary number. The inner product in feature space becomes complex, not a real geometric similarity. Optimization in SVM (which maximizes a margin in feature space) breaks down.

⚠️ Common Misconception

Symmetry (\(K(x,y)=K(y,x)\)) is necessary but NOT sufficient. The function \(K(x,y) = xy - 1\) is symmetric but its Gram matrix on \(\{0,1,2,3\}\) has eigenvalue \(\approx -1.71\) — it is NOT a valid kernel.

Closure properties

K₁+K₂=Valid
K₁×K₂=Valid
α·Kα≥0,=Valid
K−K'=Not guaranteed

These follow from eigenvalue linearity: if \(G_1, G_2 \succeq 0\), then \(\alpha G_1 + \beta G_2 \succeq 0\) for \(\alpha,\beta \geq 0\); and the Hadamard product \(G_1 \circ G_2 \succeq 0\) (Schur product theorem).

3
The Mathematics — PSD, Mercer, and Feature Maps
▾

Positive Semi-Definiteness

A symmetric matrix \(G \in \mathbb{R}^{n \times n}\) is positive semi-definite (PSD) if:

$$\mathbf{c}^\top G\, \mathbf{c} \geq 0 \quad \forall \mathbf{c} \in \mathbb{R}^n$$

Equivalently: all eigenvalues \(\lambda_i(G) \geq 0\). For kernels, replace \(G_{ij} = K(x_i, x_j)\) and require this for every finite set of points and every coefficient vector \(\mathbf{c}\).

Mercer's Theorem (1909)

Let \(\mathcal{X}\) be a compact metric space. A continuous, symmetric function \(K: \mathcal{X} \times \mathcal{X} \to \mathbb{R}\) is a Mercer kernel iff:

$$\int_{\mathcal{X}\times\mathcal{X}} K(x,x')\,f(x)\,f(x')\,dx\,dx' \geq 0 \quad \forall f \in L^2(\mathcal{X})$$

This is the functional-analytic version of PSD. Mercer proved that such \(K\) has an eigenfunction expansion:

$$K(x, x') = \sum_{i=1}^{\infty} \lambda_i\,\phi_i(x)\,\phi_i(x')$$

where \(\{\phi_i\}\) are orthonormal eigenfunctions of the integral operator \(T_K[f](x) = \int K(x,x')f(x')dx'\), and \(\lambda_i \geq 0\) are the corresponding eigenvalues. The series converges absolutely and uniformly.

Feature Map Construction

The feature map is \(\phi: \mathcal{X} \to \ell^2\) defined by:

$$\phi(x) = \left(\sqrt{\lambda_1}\,\phi_1(x),\; \sqrt{\lambda_2}\,\phi_2(x),\; \ldots\right)$$

Then \(\langle \phi(x), \phi(x') \rangle_{\ell^2} = \sum_{i=1}^\infty \sqrt{\lambda_i}\phi_i(x)\cdot\sqrt{\lambda_i}\phi_i(x') = \sum_{i=1}^\infty \lambda_i\phi_i(x)\phi_i(x') = K(x,x')\). The feature space is the Reproducing Kernel Hilbert Space (RKHS) \(\mathcal{H}_K\).

Numerical Example: RBF on 4 Points

Let \(X = \{0, 1, 2, 3\}\), \(K(x,x') = e^{-(x-x')^2/2}\). The Gram matrix:

$$G = \begin{bmatrix}1.0000 & 0.6065 & 0.1353 & 0.0111 \\ 0.6065 & 1.0000 & 0.6065 & 0.1353 \\ 0.1353 & 0.6065 & 1.0000 & 0.6065 \\ 0.0111 & 0.1353 & 0.6065 & 1.0000\end{bmatrix}$$

Eigenvalues: \(\lambda_1 \approx 0.1338\), \(\lambda_2 \approx 0.5094\), \(\lambda_3 \approx 1.2485\), \(\lambda_4 \approx 2.1082\). All non-negative — RBF is a valid kernel.

Invalid Kernel: \(K(x,y) = xy - 1\)

On the same points, the Gram matrix has eigenvalues \(\approx \{-1.71, 0, 0, 11.71\}\). The negative eigenvalue means no real feature map exists — this function cannot be used as an SVM kernel.

📐 Proof Sketch: PSD ⟺ Feature Map

(⇒) If \(K(x,x') = \langle\phi(x),\phi(x')\rangle\), then \(\sum_{i,j} c_i c_j K(x_i,x_j) = \|\sum_i c_i \phi(x_i)\|^2 \geq 0\).
(⟸) If \(K\) is PSD, construct the pre-RKHS as formal linear combinations \(f = \sum_i \alpha_i K(\cdot, x_i)\) with inner product \(\langle f, g \rangle = \sum_{i,j}\alpha_i\beta_j K(x_i, x_j)\). Complete this space → RKHS \(\mathcal{H}_K\). Then \(\phi(x) = K(\cdot, x)\) satisfies \(\langle\phi(x),\phi(x')\rangle = K(x,x')\) by the reproducing property. ∎

Code — Checking & Building Valid Kernels
▾

From-Scratch: Kernel Validation (NumPy)

import numpy as np
def gram_matrix(kernel_fn, X):
"""Build the n×n Gram matrix G[i,j] = K(x_i, x_j)."""
n = len(X)
G = np.zeros((n, n))
for i in range(n):
for j in range(n):
G[i, j] = kernel_fn(X[i], X[j])
return G
def is_valid_kernel(kernel_fn, X, tol=1e-8):
"""Mercer check: Gram matrix must be PSD (all eigenvalues >= -tol)."""
G = gram_matrix(kernel_fn, X)
# G must be symmetric (sanity check)
assert np.allclose(G, G.T), "Kernel not symmetric!"
eigenvalues = np.linalg.eigvalsh(G) # eigvalsh for symmetric matrices
return np.all(eigenvalues >= -tol), eigenvalues
# --- Examples ---
X = np.array([0., 1., 2., 3.])
rbf = lambda x, y: np.exp(-(x-y)**2 / 2)
ok, eigs = is_valid_kernel(rbf, X)
print(f"RBF valid: {ok}, eigs: {eigs.round(4)}")
# RBF valid: True, eigs: [0.1338, 0.5094, 1.2485, 2.1082]
bad = lambda x, y: x*y - 1
ok, eigs = is_valid_kernel(bad, X)
print(f"K=xy-1 valid: {ok}, eigs: {eigs.round(4)}")
# K=xy-1 valid: False, eigs: [-1.7082, 0., 0., 11.7082]

Production: scikit-learn Precomputed Kernel

from sklearn.svm import SVC
import numpy as np
def rbf_gram(X1, X2, sigma=1.0):
"""Vectorized RBF Gram matrix: K[i,j] = exp(-||x_i - x_j||^2 / 2σ²)"""
dists = np.sum(X1**2, 1)[:,None] + np.sum(X2**2,1)[None,:] - 2*X1@X2.T
return np.exp(-dists / (2 * sigma**2))
# SVC with precomputed kernel (must be PSD!)
X_train, y_train = ... # your data
K_train = rbf_gram(X_train, X_train)
K_test = rbf_gram(X_test, X_train) # test vs train
clf = SVC(kernel='precomputed')
clf.fit(K_train, y_train) # ← pass Gram matrix, not X
pred = clf.predict(K_test) # ← test row = K(x_test, x_train_i)
# ⚠️ Gotcha: if K is not PSD, the dual QP may have no solution or
# converge to a meaningless local minimum. Always validate first!

Key Takeaways & Related Topics
▾
✅ Summary

1. Mercer's condition: \(K\) is valid iff its Gram matrix is PSD for all finite input sets.
2. PSD ↔ feature map: \(K(x,x') = \langle\phi(x),\phi(x')\rangle_\mathcal{H}\) in some Hilbert space.
3. Eigendecomposition: \(K(x,y)=\sum_i\lambda_i\phi_i(x)\phi_i(y)\) with \(\lambda_i \geq 0\).
4. Closure: sums, products, and non-negative scalings of kernels are kernels.
5. How to check: compute Gram matrix on sample points; verify \(\min\lambda_i \geq 0\).
