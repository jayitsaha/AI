Text Summarization: Extractive vs. Abstractive

Understanding the two main paradigms of automatic text summarization
Foundational NLP Machine Learning Intermediate
1
Understanding Text Summarization
▼

What is it? Text summarization is the task of creating a concise and coherent summary of a longer document while retaining its core meaning. It's crucial for information overload, allowing users to quickly grasp the essence of large texts.

There are two primary approaches:

  • Extractive Summarization: Identifies and extracts the most important sentences or phrases directly from the source document to form a summary. It's like highlighting key parts of a text.
  • Abstractive Summarization: Generates new sentences and phrases that capture the main ideas of the source document. This often involves paraphrasing, generalization, and synthesis, similar to how a human summarizes.

Analogy: Imagine you're asked to summarize a book. An extractive approach would be to copy-paste the most impactful sentences or paragraphs. An abstractive approach would be to read the book, understand it, and then write a brand new, shorter text describing its plot and themes in your own words.

💡 Key Difference

Extractive summaries are always composed of sentences that exist in the original text. Abstractive summaries can contain novel words and phrases, allowing for greater fluency and conciseness, but also posing a higher risk of factual inaccuracies (hallucinations).

2
How Extractive Summarization Works (TextRank)
▼

Extractive summarization algorithms typically follow a pipeline:

  1. Preprocessing: Segment the document into sentences and tokenize words.
  2. Feature Extraction: Represent each sentence using features like TF-IDF vectors, word embeddings (e.g., Word2Vec, BERT), or lexical overlap.
  3. Similarity Graph Construction: Build a graph where sentences are nodes, and edges connect sentences based on their similarity. Edge weights reflect the degree of similarity.
  4. Sentence Scoring: Apply a graph-based ranking algorithm (like PageRank) to score each sentence. Sentences with more connections to other important sentences receive higher scores.
  5. Summary Generation: Select the top-N highest-scoring sentences, typically maintaining their original order in the document, until the desired summary length is reached.

TextRank: A Classic Example

TextRank is a popular unsupervised extractive summarization algorithm. It adapts Google's PageRank algorithm to text. Instead of web pages, TextRank operates on a graph of sentences. The "importance" of a sentence is determined by how many other sentences it is similar to, and how important those similar sentences are.

🔑 Key Property

TextRank is unsupervised, meaning it doesn't require labeled training data. Its effectiveness relies on the assumption that important sentences in a document will share significant content overlap with many other sentences in that same document.

Modern Extractive Methods (BertSumExt)

More recent approaches like BertSumExt leverage pre-trained language models (BERT) to generate high-quality sentence embeddings. Similarity is then calculated using cosine similarity between these embeddings. A classifier can then be trained on these embeddings to predict which sentences should be included in the summary, often with additional features like sentence position.

3
How Abstractive Summarization Works (Seq2Seq & Transformers)
▼

Abstractive summarization is a more challenging task as it requires natural language generation (NLG) capabilities. It's typically tackled using sequence-to-sequence (Seq2Seq) models, often built upon the Transformer architecture.

Seq2Seq Architecture

A standard Seq2Seq model consists of two main components:

  1. Encoder: Reads the source document and converts it into a fixed-size contextual representation (a "thought vector" or "context vector").
  2. Decoder: Takes this context vector and generates the summary word by word, conditioned on the previously generated words.

The crucial innovation for these models is the attention mechanism, which allows the decoder to "look back" at different parts of the source document (encoder outputs) when generating each word of the summary, rather than relying solely on a single fixed context vector.

Training Objective

Abstractive models are trained on large datasets of (document, summary) pairs. The objective is to maximize the probability of generating the target summary given the source document. This is typically done by minimizing the negative log-likelihood of the target sequence:

$$L(\theta) = - \sum_{t=1}^{T_s} \log P(y_t | y_1, \dots, y_{t-1}, X; \theta)$$

where \(X\) is the source document, \(Y = (y_1, \dots, y_{T_s})\) is the target summary, and \(\theta\) are the model parameters.

The generation process involves predicting the next word \(y_t\) based on the document \(X\) and all previously generated words \(y_1, \dots, y_{t-1}\). This is a conditional probability:

$$P(Y|X) = \prod_{t=1}^{T_s} P(y_t | y_1, \dots, y_{t-1}, X)$$

During inference, techniques like beam search are used to find the most probable sequence of words for the summary.

Modern Abstractive Models (BART, Pegasus, T5)

These are large-scale pre-trained Transformer-based models. They are trained on massive text corpora using self-supervised objectives (e.g., denoising for BART, gap-filling for T5) and then fine-tuned on summarization datasets. Their ability to understand context and generate coherent text makes them highly effective for abstractive summarization.

⚠️ Hallucination Risk

A major challenge with abstractive models is "hallucination," where the model generates content that is fluent and grammatically correct but factually inconsistent with the source document. This is a critical concern in applications requiring high factual accuracy.

Key Takeaways
▼

Extractive Summarization:

  • Pros: Guaranteed factual accuracy (sentences are from original text), simpler to implement (e.g., TextRank), less prone to grammar errors.
  • Cons: Can be less fluent or coherent than human summaries, may include redundant information, cannot synthesize new ideas.
  • Use Cases: Legal documents, scientific papers, news articles where factual integrity is paramount.

Abstractive Summarization:

  • Pros: More human-like, fluent, and concise summaries; can paraphrase and synthesize information; potentially better at capturing overall meaning.
  • Cons: Prone to "hallucinations" (generating factually incorrect information), requires large training datasets, computationally expensive, more complex model architectures.
  • Use Cases: General news, creative content, dialogue summarization where fluency is highly valued and some factual deviation might be acceptable (or can be mitigated).
💡 Hybrid Approaches

Some advanced systems combine both. They might first identify key sentences (extractive step) and then use an abstractive model to paraphrase and condense those selected sentences, aiming for both accuracy and fluency.

Code Trace: Simplified TextRank
▼
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity
def textrank_summarize(document, num_sentences=2, damping_factor=0.85, iterations=100):
# 1. Sentence Tokenization (simplified here)
sentences = [s.strip() for s in document.split('.') if s.strip()]
if len(sentences) <= num_sentences: return sentences
# 2. Feature Extraction (TF-IDF)
vectorizer = TfidfVectorizer(stop_words='english')
tfidf_matrix = vectorizer.fit_transform(sentences)
# 3. Similarity Graph Construction (Cosine Similarity)
similarity_matrix = cosine_similarity(tfidf_matrix, tfidf_matrix)
np.fill_diagonal(similarity_matrix, 0) # No self-loops
# Normalize similarity matrix for PageRank (sum of rows to 1)
row_sums = similarity_matrix.sum(axis=1, keepdims=True)
normalized_matrix = np.where(row_sums == 0, 0, similarity_matrix / row_sums)
# 4. Sentence Scoring (PageRank-like iteration)
scores = np.ones(len(sentences)) / len(sentences) # Initial uniform scores
for _ in range(iterations):
new_scores = (1 - damping_factor) + damping_factor * np.dot(normalized_matrix.T, scores)
if np.allclose(new_scores, scores, atol=1e-6): break # Convergence check
scores = new_scores
# 5. Summary Generation
ranked_sentence_indices = np.argsort(scores)[::-1] # Sort in descending order
summary_indices = sorted(ranked_sentence_indices[:num_sentences]) # Get top N, maintain original order
return [sentences[i] for i in summary_indices]
# Example Usage:
document = "Text summarization is a crucial NLP task. It aims to create a concise and coherent summary of a longer document. There are two main approaches: extractive and abstractive. Extractive summarization identifies and extracts key sentences directly from the source text. TextRank is a popular graph-based algorithm for extractive summarization. Abstractive summarization generates new sentences to capture the core meaning. Large language models like BART and T5 are widely used for abstractive summarization."
summary = textrank_summarize(document, num_sentences=2)
print("Summary:", " ".join(summary))
