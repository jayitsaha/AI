Understanding Vanilla RNNs
▼

What is it? A Recurrent Neural Network (RNN) is a type of neural network designed to handle sequential data, such as text, speech, or time series. Unlike traditional feedforward networks that treat inputs independently, an RNN maintains an internal "hidden state" that captures information about previous elements in the sequence. This state is updated at each step, allowing the network to exhibit a form of memory.

Analogy: Imagine you're reading a sentence. To understand the current word, you need to remember the words that came before it. A vanilla RNN works similarly: at each word, it processes the current word (input) and combines it with its "memory" of the previous words (hidden state) to update its understanding and potentially predict the next word. The same "brain" (weights) is used for every word, just like you use the same language processing skills for each word in a sentence.

💡 If you remember one thing

The core idea of an RNN is to apply the same set of weights repeatedly to each element in a sequence, updating a hidden state that serves as a summary of all past information. This hidden state is the network's "memory."

How It Works Internally
▼

The Basic RNN Cell

At its core, a vanilla RNN operates through a simple recurrent cell. For each time step \(t\), it takes two main inputs:

  1. The current input from the sequence, \(x_t\).
  2. The hidden state from the previous time step, \(h_{t-1}\).

It then computes a new hidden state, \(h_t\), and optionally an output, \(y_t\), for the current time step. The magic lies in using the same weight matrices and biases across all time steps. This parameter sharing is what makes RNNs powerful for sequences of arbitrary length.

The Hidden State: Network's Memory

The hidden state \(h_t\) is a vector that encapsulates information about the entire sequence processed up to time \(t\). It acts as a compressed summary or "memory" of all past inputs. This memory allows the network to make decisions at the current time step that are informed by context from earlier in the sequence.

The update rule for \(h_t\) typically involves a non-linear activation function (like \(\tanh\)) applied to a linear combination of the current input \(x_t\) and the previous hidden state \(h_{t-1}\).

Unfolding in Time

While we conceptually think of a single RNN cell, it's often helpful to visualize the network as "unfolded" or "rolled out" across the entire sequence. This means creating a copy of the RNN cell for each time step, with the hidden state from one step flowing into the next. This unfolded view clearly shows the chain-like structure and how information propagates through time, which is crucial for understanding how gradients are computed during training (Backpropagation Through Time, BPTT).

🔑 Key Property

Vanilla RNNs are characterized by parameter sharing across time and the maintenance of a recurrent hidden state. This enables them to process sequences by iteratively updating their internal memory, making them suitable for tasks like language modeling and machine translation.

Why It Works — The Math
▼

The Recurrence Relations

Let \(x_t\) be the input vector at time step \(t\), \(h_t\) be the hidden state vector, and \(y_t\) be the output vector. The core computations for a vanilla RNN at each time step \(t\) are defined by:

$$h_t = \tanh(W_{xh}x_t + W_{hh}h_{t-1} + b_h)$$

Here, \(W_{xh}\) is the weight matrix for input to hidden, \(W_{hh}\) is the weight matrix for hidden to hidden (the recurrent connection), and \(b_h\) is the bias vector for the hidden layer. The \(\tanh\) activation function is commonly used to introduce non-linearity and keep hidden state values bounded between -1 and 1. For the initial time step (\(t=0\)), \(h_{-1}\) is typically initialized to a zero vector.

The output \(y_t\) is then computed based on the current hidden state \(h_t\):

$$y_t = W_{hy}h_t + b_y$$

Where \(W_{hy}\) is the weight matrix for hidden to output, and \(b_y\) is the bias vector for the output layer. For classification tasks (e.g., predicting the next word), a softmax activation function is often applied to \(y_t\) to obtain a probability distribution over the vocabulary:

$$\hat{y}_t = \text{softmax}(y_t)$$

Notice that \(W_{xh}, W_{hh}, W_{hy}, b_h, b_y\) are shared across all time steps. This means the same parameters are used to process \(x_1, x_2, \dots, x_T\), making the model efficient and capable of learning patterns that generalize across different positions in a sequence.

⚠️ Common Pitfall: Vanishing/Exploding Gradients

The repeated multiplication by \(W_{hh}\) during backpropagation (Backpropagation Through Time, BPTT) can cause gradients to either shrink exponentially (vanishing gradients) or grow exponentially (exploding gradients). Vanishing gradients make it hard for vanilla RNNs to learn long-range dependencies, as information from early time steps effectively "fades out" before reaching later ones. This limitation led to the development of more sophisticated architectures like LSTMs and GRUs.

Key Takeaways
▼

When to use Vanilla RNNs:

  • Short sequences: For tasks where dependencies are mostly local and don't span many time steps.
  • Small datasets: When you need a simple recurrent model and don't have enough data to train more complex architectures like LSTMs or Transformers.
  • Conceptual understanding: As a foundational building block for understanding more advanced recurrent architectures.
  • Simple sequence generation: For generating short sequences where long-term coherence isn't critical.

When NOT to use Vanilla RNNs:

  • Long-range dependencies: The vanishing gradient problem makes it very difficult for vanilla RNNs to learn relationships between elements far apart in a sequence. This is their primary weakness.
  • Complex tasks: For sophisticated natural language processing (e.g., machine translation, sentiment analysis on long documents) or complex time series forecasting, LSTMs, GRUs, or Transformers are almost always preferred.
  • Parallel processing is critical: While the unfolded view helps conceptualize, the inherent sequential nature of RNN computations (waiting for \(h_{t-1}\) to compute \(h_t\)) limits parallelization during inference, unlike feedforward layers or attention mechanisms in Transformers.
💡 What came next?

The limitations of vanilla RNNs, particularly with long-range dependencies, spurred the development of more advanced recurrent architectures. Long Short-Term Memory (LSTM) networks and Gated Recurrent Units (GRUs) introduce "gates" that regulate the flow of information into and out of the hidden state, effectively solving the vanishing gradient problem and allowing them to learn much longer dependencies. These are the workhorses of classical sequence modeling.

Code Trace (Python from Scratch)
▼
import numpy as np
# Define network dimensions
vocab_size = 5 # e.g., H, E, L, O, <PAD>
hidden_size = 4
# Initialize weights and biases (randomly for training)
W_xh = np.random.randn(vocab_size, hidden_size) * 0.1 # Input to hidden
W_hh = np.random.randn(hidden_size, hidden_size) * 0.1 # Hidden to hidden
W_hy = np.random.randn(hidden_size, vocab_size) * 0.1 # Hidden to output
b_h = np.zeros((1, hidden_size)) # Hidden bias
b_y = np.zeros((1, vocab_size)) # Output bias
def tanh(x): return np.tanh(x)
def softmax(x):
e_x = np.exp(x - np.max(x)) # Stable softmax
return e_x / e_x.sum(axis=-1, keepdims=True)
def rnn_forward(inputs, h_prev):
hs, ys, ps = {}, {}, {}
hs[-1] = np.copy(h_prev) # Initial hidden state
for t in range(len(inputs)):
# Hidden state update
h_t_pre_act = np.dot(inputs[t], W_xh) + np.dot(hs[t-1], W_hh) + b_h
hs[t] = tanh(h_t_pre_act)
# Output calculation
y_t = np.dot(hs[t], W_hy) + b_y
ys[t] = y_t
ps[t] = softmax(y_t) # Probabilities
return hs, ys, ps
# Example sequence: "HELLO" (one-hot encoded)
char_to_idx = {'H':0, 'E':1, 'L':2, 'O':3, '<PAD>':4}
idx_to_char = {v:k for k,v in char_to_idx.items()}
inputs = []
for char_idx in [char_to_idx['H'], char_to_idx['E'], char_to_idx['L'], char_to_idx['L'], char_to_idx['O']]:
vec = np.zeros((1, vocab_size))
vec[0, char_idx] = 1
inputs.append(vec)
h0 = np.zeros((1, hidden_size)) # Initial hidden state
hidden_states, outputs, probabilities = rnn_forward(inputs, h0)
# Print predictions for each time step
for t in range(len(inputs)):
predicted_idx = np.argmax(probabilities[t])
print(f"Time {t}: Input '{idx_to_char[np.argmax(inputs[t])]}', Predicted next char: '{idx_to_char[predicted_idx]}'")
