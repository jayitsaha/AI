SSL Assumptions

Smoothness · Cluster · Manifold · Low-Density Separation — when unlabeled data helps (and when it doesn't)

1
Understanding the Assumptions

In semi-supervised learning (SSL) you have a small labeled set \(\mathcal{L} = \{(x_i, y_i)\}_{i=1}^l\) and a large unlabeled set \(\mathcal{U} = \{x_j\}_{j=l+1}^{l+u}\) with \(u \gg l\). The central question is: can the geometry of \(p(x)\) tell us anything about \(p(y|x)\)?

The answer is yes — but only if certain assumptions connect the marginal \(p(x)\) to the conditional \(p(y|x)\). These are the four classical SSL assumptions. Violating any one of them makes unlabeled data useless or actively harmful.

💡 If You Remember One Thing

Unlabeled data is useful only when the structure of \(p(x)\) (density, clusters, manifolds) is informative about \(p(y|x)\). All four SSL assumptions formalise exactly what "structure of \(p(x)\) is informative" means — and each fails in a different way when that coupling breaks.

2
The Four Assumptions — Theory & Math

1. Smoothness Assumption

If two inputs \(x, x'\) are close in input space, their labels are also close (or identical for classification):

$$\|x - x'\| \text{ small} \;\Rightarrow\; p(y|x) \approx p(y|x')$$

Formally: the Bayes-optimal decision function \(f^*\) is Lipschitz on the support of \(p(x)\), i.e. \(\exists L: |f^*(x)-f^*(x')| \le L\|x-x'\|\). This lets us propagate labels from labeled to nearby unlabeled points. Fails when the true boundary oscillates rapidly or when the metric is wrong (e.g., pixel distance for images).

2. Cluster Assumption

The data forms well-separated clusters in input space, and each cluster is predominantly one class:

$$x, x' \text{ in same cluster} \;\Rightarrow\; y = y'$$

Equivalently: the decision boundary should lie in a region of low density — not through the interior of any cluster. This directly motivates methods like S3VM (the boundary is pushed to low-density gaps) and label propagation (spread labels within clusters). Fails when classes genuinely overlap in a single dense cluster (e.g., two species with identical morphology).

3. Manifold Assumption

The high-dimensional input \(x \in \mathbb{R}^d\) actually lies near a low-dimensional manifold \(\mathcal{M}\) of intrinsic dimension \(m \ll d\):

$$x \approx \phi(z), \quad z \in \mathbb{R}^m,\; m \ll d$$

where \(\phi: \mathbb{R}^m \to \mathbb{R}^d\) is the manifold embedding. The smoothness assumption should hold along the manifold, not in the ambient space. Unlabeled data reveals the manifold geometry, enabling geodesic-distance label propagation (Laplacian Eigenmaps, TSNE, graph-based methods). Fails when the true manifold is not smooth (fractal-like) or when the data is intrinsically high-dimensional (uniformly fills \(\mathbb{R}^d\)).

4. Low-Density Separation Assumption

The decision boundary passes through regions of low marginal density \(p(x)\):

$$f^*(x) = 0 \;\Rightarrow\; p(x) \text{ is small}$$

This is the dual view of the cluster assumption: instead of "same cluster → same class", we say "the boundary avoids dense regions". Operationalised by Transductive SVMs: the margin is placed in low-density gaps by maximising it simultaneously on labeled and unlabeled data. Fails when classes are interleaved in density (e.g., concentric rings of alternating class with no low-density gap between them).

3
Why They Work — Invariants & Proof Sketches

Smoothness → Label Propagation Convergence

Under the smoothness assumption, label propagation on a graph \(G=(V,E)\) with weights \(w_{ij} = \exp(-\|x_i-x_j\|^2/2\sigma^2)\) finds the minimum-energy (harmonic) extension of the labeled function. The solution satisfies the discrete Laplace equation \(\Delta f(u) = 0\) for all unlabeled nodes \(u\), where \(\Delta\) is the graph Laplacian. This is optimal under smoothness because it minimises \(\sum_{ij} w_{ij}(f_i-f_j)^2\).

$$\hat{f} = \arg\min_{f: f|_{\mathcal{L}} = y} \sum_{i,j} w_{ij}(f_i - f_j)^2 = (I - \alpha S)^{-1} y$$

Cluster → S3VM Objective

The Transductive SVM adds unlabeled-data margin terms to the SVM objective. Maximising the margin while assigning pseudo-labels \(\tilde{y}_j \in \{-1,+1\}\) to unlabeled points forces the hyperplane to avoid dense regions:

$$\min_{w,b,\tilde{y}} \tfrac{1}{2}\|w\|^2 + C\!\sum_{i \in \mathcal{L}} \xi_i + C^*\!\sum_{j \in \mathcal{U}} \tilde{\xi}_j \quad \text{s.t. both label constraints}$$
Key Invariant

All four assumptions share one meta-structure: they assert that \(p(x)\) and \(p(y|x)\) are coupled via the geometry of the support. When this coupling is absent — i.e., the input density is uninformative about the class conditional — SSL cannot help and may hurt (by adding noise to the decision boundary).

⚠️ Common Misconception

More unlabeled data is not always better. If the assumptions fail, adding unlabeled data shifts the decision boundary away from the true optimum. This is known as negative transfer in SSL and is well-documented empirically in adversarial/out-of-distribution settings.

Key Insight

The cluster assumption and the low-density separation assumption are dual views of the same idea: clusters = connected components of the high-density set, and the boundary = the low-density separator between them. They differ only in which side of the picture you look at.

6
Key Takeaways
  • Smoothness: nearby points share labels → enables local propagation of the few labeled examples.
  • Cluster: intra-cluster label homogeneity → enables self-training and cluster-driven boundary placement.
  • Manifold: data lives near a low-dim surface → enables geodesic label spreading and manifold regularisation.
  • Low-density separation: boundaries avoid dense regions → enables margin maximisation in low-density gaps (TSVM).
  • All four can be violated simultaneously; always verify empirically (e.g., run labeled-only vs. SSL baseline).
  • Deep self-supervised pre-training implicitly enforces all four via data augmentation — which is why it dominates modern SSL.
