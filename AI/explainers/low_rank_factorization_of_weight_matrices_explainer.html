Low-Rank Factorization of Weight Matrices

Compressing neural network layers by replacing one big matrix with two thin ones
Advanced Model Compression Linear Algebra O(mn·min(m,n))
1
Understanding Low-Rank Factorization
▼

What is it? Every layer of a neural network stores a weight matrix \(W\) with \(m \times n\) numbers. Low-rank factorization asks: does this matrix really need all \(mn\) independent numbers, or can it be approximated as the product of two much smaller matrices? If so, we can replace one fat layer with two thin layers that use far fewer parameters and multiplications, while barely changing what the network computes.

Analogy: Imagine a giant lookup table that maps every combination of ingredients to a dish rating. If most of that table's behavior is really explained by just a handful of underlying "flavor axes" (sweet, salty, spicy...), you don't need to store every cell — you can store a small set of axis scores per ingredient and per dish, then multiply them back together. That's exactly what truncating a singular value decomposition does to a weight matrix.

💡 If you remember one thing

Every matrix \(W \in \mathbb{R}^{m\times n}\) can be written exactly as \(W = U\Sigma V^\top\). Keeping only the top \(r\) singular values gives the best possible rank-\(r\) approximation \(W_r = U_r\Sigma_r V_r^\top\), turning \(mn\) parameters into \(r(m+n)\) parameters — and that reconstruction is provably optimal in squared error (the Eckart–Young theorem).

How It Works Internally
▼

From One Fat Layer to Two Thin Ones

A linear layer computes \(y = Wx\) where \(W\) is \(m \times n\), \(x\) is the \(n\)-dimensional input, and \(y\) is the \(m\)-dimensional output. If we truncate the SVD of \(W\) to rank \(r\), we get \(W \approx U_r \Sigma_r V_r^\top\). Define \(B = \Sigma_r V_r^\top\) (shape \(r \times n\)) and \(A = U_r\) (shape \(m \times r\)). Then \(y \approx A(Bx)\): the input is first projected down to an \(r\)-dimensional "bottleneck" \(h = Bx\), then expanded back up to \(y = Ah\). One matrix multiply becomes two, but each one is thin.

Where the Savings Come From

The original layer stores \(mn\) numbers and costs \(mn\) multiply-adds per forward pass. The factored layer stores \(r(m+n)\) numbers and costs \(r(m+n)\) multiply-adds. Whenever \(r \ll \frac{mn}{m+n}\), the factored form is dramatically cheaper in both memory and compute — this is precisely why SVD-based compression is applied to huge embedding tables, fully-connected classifier heads, and attention projection matrices in production models.

Design Decision: Why the SVD and not some other split?

You could factor \(W \approx AB\) for many choices of \(A, B\) — that's what optimization-based methods like LoRA fine-tuning or learned low-rank layers do. But if you want the factorization that minimizes reconstruction error for a given, already-trained \(W\) with no retraining, the SVD is not just convenient, it is mathematically optimal: no other rank-\(r\) matrix gets closer to \(W\) in Frobenius norm than the truncated SVD does.

🔑 Key Property

The singular values \(\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_{\min(m,n)} \ge 0\) measure how much "energy" each rank-1 direction of \(W\) contributes. In real trained networks these decay quickly — a handful of large singular values explain most of the layer's behavior, which is exactly the redundancy low-rank compression exploits.

3
Why It Works — The Math
▼

The Singular Value Decomposition

Any real matrix \(W \in \mathbb{R}^{m\times n}\) decomposes as:

$$W = U \Sigma V^\top, \qquad U^\top U = I,\ \ V^\top V = I,\ \ \Sigma = \operatorname{diag}(\sigma_1,\dots,\sigma_{\min(m,n)})$$

Truncating to the top \(r\) components gives \(W_r = \sum_{k=1}^r \sigma_k\, u_k v_k^\top\), a sum of \(r\) rank-1 "layers."

The Eckart–Young–Mirsky Theorem

Among all matrices of rank \(\le r\), \(W_r\) is the closest to \(W\) in both Frobenius and spectral norm:

$$\|W - W_r\|_F = \min_{\operatorname{rank}(B)\le r} \|W - B\|_F = \sqrt{\sigma_{r+1}^2 + \sigma_{r+2}^2 + \dots + \sigma_{\min(m,n)}^2}$$

Dividing by \(\|W\|_F = \sqrt{\sum_k \sigma_k^2}\) gives the relative reconstruction error, the single number that tells you how much information rank-\(r\) truncation throws away:

$$\text{rel. error}(r) = \frac{\|W-W_r\|_F}{\|W\|_F} = \sqrt{\dfrac{\sum_{k>r}\sigma_k^2}{\sum_k \sigma_k^2}}$$

Proof Sketch

Write \(W\) in its SVD basis. Any rank-\(r\) matrix \(B\) can be represented in a rotated coordinate system where the squared error decomposes as a sum over singular directions. Zeroing out the smallest \(\sigma_k\) contributes the least possible squared error to the total, since they are already sorted by magnitude — so keeping the largest \(r\) and discarding the rest is optimal by a simple exchange argument (swapping any kept small \(\sigma_i\) for a discarded larger \(\sigma_j\) strictly reduces error).

⚠️ Common Pitfall

SVD truncation is optimal for approximating the given matrix, not necessarily for preserving downstream task accuracy. A weight matrix's singular values reflect variance in its own entries, not how sensitive the loss is to each direction — that's why compression is usually followed by a short fine-tuning ("distillation") pass to recover accuracy that pure numerical approximation doesn't guarantee.

Key Takeaways
▼

When to use low-rank factorization:

  • Large fully-connected or embedding layers whose singular value spectrum decays quickly
  • Post-training compression when retraining from scratch is too expensive
  • As the parameterization of a trainable update, e.g. LoRA's \(\Delta W = BA\) for cheap fine-tuning
  • Speeding up inference on memory- or bandwidth-bound deployments (mobile, edge)

When NOT to use it:

  • The spectrum is nearly flat (all singular values similar) — truncation buys little compression for a given error budget
  • The layer is already small — the two-matrix overhead (extra memory access, kernel launch) can outweigh the FLOP savings
  • Extreme accuracy sensitivity without a fine-tuning budget to recover lost performance
💡 Hierarchy

Full matrix (rank \(\min(m,n)\)) ⊃ SVD truncation (fixed, optimal, no retraining) ⊃ Learned low-rank / LoRA (rank fixed by design, trained directly) ⊃ Pruning + quantization (complementary, often stacked on top of low-rank compression for further savings).

Code Trace
▼
import numpy as np
# W: trained weight matrix, shape (m, n)
m, n = W.shape
# Full SVD: W = U @ diag(S) @ Vt
U, S, Vt = np.linalg.svd(W, full_matrices=False)
# Keep only the top-r singular directions
r = 4
U_r, S_r, Vt_r = U[:, :r], S[:r], Vt[:r, :]
# Two thin layers replacing one fat layer
A = U_r # shape (m, r)
B = np.diag(S_r) @ Vt_r # shape (r, n)
# Forward pass: y = W @ x ==> y = A @ (B @ x)
def forward_factored(x):
h = B @ x # (r, n) @ (n,) -> (r,)
y = A @ h # (m, r) @ (r,) -> (m,)
return y
# Reconstruction error (Eckart-Young)
W_r = A @ B
rel_error = np.linalg.norm(W - W_r, 'fro') / np.linalg.norm(W, 'fro')
rel_error_closed_form = np.sqrt(np.sum(S[r:]**2) / np.sum(S**2))
print(f"params: {m*n} -> {r*(m+n)} ({m*n/(r*(m+n)):.2f}x smaller)")
print(f"relative error: {rel_error:.4f}")
