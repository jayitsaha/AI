Understanding the EM Algorithm
▼

What is it? The Expectation-Maximization (EM) algorithm is a general recipe for finding maximum likelihood estimates when some data is hidden or missing. Imagine trying to learn about a population by observing only part of it — EM iterates between "guessing" the hidden parts and "improving" the model to explain what you see.

Analogy: You walk into a room with two groups of people speaking quietly. You cannot tell which group each person belongs to, but you can hear each person's voice pitch. EM says: "Guess which group each voice belongs to (E-step), then recompute what each group sounds like (M-step)." Repeat until the groupings stabilize. The algorithm never makes the overall fit worse — each iteration either improves the model or leaves it exactly the same.

Canonical application: Gaussian Mixture Models (GMMs) — fitting \(K\) Gaussian clusters to unlabeled data. The cluster assignments are the "missing" latent variables \(Z\).

💡 If you remember one thing

EM maximizes a lower bound on the log-likelihood called the ELBO. The E-step tightens the bound (makes it touch the log-likelihood); the M-step lifts it. This coordinate-ascent structure guarantees monotone non-decrease of \(\log p(X \mid \theta)\) at every iteration — EM can never hurt you.

2
E-step and M-step — Internal Mechanics
▼

The Setup — Incomplete Data

We observe data \(X = \{x_1, \ldots, x_N\}\). Each point has an unobserved latent variable \(z_i\) (e.g., which cluster it came from). The complete-data log-likelihood \(\log p(X, Z \mid \theta)\) would be easy to maximize if we knew \(Z\). Since we do not, EM uses the expected complete-data log-likelihood.

E-Step — Compute Responsibilities (Posterior over Z)

Given the current parameters \(\theta^{(t)}\), compute the posterior distribution over the hidden variables:

$$Q(\theta \mid \theta^{(t)}) = \mathbb{E}_{Z \mid X, \theta^{(t)}}\!\left[\log p(X, Z \mid \theta)\right]$$

For a GMM with \(K\) components, this means computing the responsibility of each component \(k\) for data point \(x_i\):

$$r_{ik} = \frac{\pi_k \,\mathcal{N}(x_i \mid \mu_k, \Sigma_k)}{\sum_{j=1}^K \pi_j \,\mathcal{N}(x_i \mid \mu_j, \Sigma_j)}$$

Each \(r_{ik} \in [0,1]\) is a soft assignment: "How much does component \(k\) 'own' point \(x_i\)?" The E-step does no parameter update — it only refreshes the distribution over \(Z\).

M-Step — Re-estimate Parameters

Now maximize \(Q\) with respect to \(\theta\), treating the responsibilities as fixed weights. For GMM, the updates have closed form:

$$N_k = \sum_{i=1}^N r_{ik}, \quad \hat{\pi}_k = \frac{N_k}{N}, \quad \hat{\mu}_k = \frac{\sum_i r_{ik}\, x_i}{N_k}, \quad \hat{\Sigma}_k = \frac{\sum_i r_{ik}(x_i - \hat{\mu}_k)(x_i - \hat{\mu}_k)^\top}{N_k}$$

Each formula is a weighted MLE — the weight of point \(i\) for component \(k\) is exactly its responsibility \(r_{ik}\).

🔑 Key Property — Monotone Convergence

Every EM iteration satisfies \(\log p(X \mid \theta^{(t+1)}) \geq \log p(X \mid \theta^{(t)})\). The observed log-likelihood never decreases. This follows directly from Jensen's inequality applied to the ELBO construction (see Card 3).

Numerical Trace — One EM Iteration on a 2-component GMM

Data: 20 points drawn from \(0.4 \cdot \mathcal{N}(-2, 0.64) + 0.6 \cdot \mathcal{N}(3, 1.44)\). Initialize: \(\mu_1 = -1.0, \mu_2 = 1.5, \sigma_1 = \sigma_2 = 1.0, \pi_1 = \pi_2 = 0.5\).

E-step: For \(x = 1.305\): \(r_{1} = \frac{0.5 \cdot \mathcal{N}(1.305 \mid -1.0, 1.0)}{0.5\cdot\mathcal{N}(-1.0)+0.5\cdot\mathcal{N}(1.5)} = \frac{0.5 \times 0.046}{0.5 \times 0.046 + 0.5 \times 0.358} \approx 0.114\). Point 1.305 is mostly assigned to component 2 (the right cluster).

M-step after iter 1: \(\hat{\mu}_1 = -1.414, \hat{\mu}_2 = 2.218, \hat{\sigma}_1 = 0.822, \hat{\sigma}_2 = 0.966, \hat{\pi}_1 = 0.416\).

Log-likelihood jumps from \(-\infty\) (initial) to \(-41.89\) after iter 1, then \(-36.84 \to -35.91 \to -35.79 \to \text{converged at } -35.79\) after 5 iterations.

Why EM Never Decreases the Likelihood — The Math
▼

EM as Coordinate Ascent on the ELBO

The key identity underlying EM comes from introducing any distribution \(q(Z)\) and writing:

$$\log p(X \mid \theta) = \underbrace{\mathbb{E}_{q}\!\left[\log \frac{p(X,Z \mid \theta)}{q(Z)}\right]}_{\mathcal{L}(q,\theta) \;\text{(ELBO)}} + \underbrace{KL(q(Z) \,\|\, p(Z \mid X, \theta))}_{\geq\, 0}$$

Since \(KL \geq 0\), the ELBO is always a lower bound on the log-likelihood. EM alternates:

E-step: Set \(q(Z) = p(Z \mid X, \theta^{(t)})\). This makes \(KL = 0\), so \(\mathcal{L}(q, \theta^{(t)}) = \log p(X \mid \theta^{(t)})\). The bound touches the log-likelihood — it's tight.

M-step: Maximize \(\mathcal{L}(q, \theta)\) over \(\theta\) with \(q\) fixed. This finds \(\theta^{(t+1)}\) with a higher ELBO. Since \(\log p(X \mid \theta^{(t+1)}) \geq \mathcal{L}(q, \theta^{(t+1)}) \geq \mathcal{L}(q, \theta^{(t)}) = \log p(X \mid \theta^{(t)})\), the log-likelihood cannot decrease.

Proof of Monotone Convergence

$$\log p(X \mid \theta^{(t+1)}) \;\geq\; \mathcal{L}(q^{(t)}, \theta^{(t+1)}) \;\geq\; \mathcal{L}(q^{(t)}, \theta^{(t)}) \;=\; \log p(X \mid \theta^{(t)})$$

The first inequality holds because \(KL \geq 0\). The second holds because the M-step maximizes \(\mathcal{L}\) over \(\theta\). The equality holds because the E-step sets \(KL = 0\). QED.

Convergence — What EM Guarantees and What It Does Not

EM converges to a stationary point of the log-likelihood (usually a local maximum). It does not guarantee finding the global maximum — the objective is generally non-convex. The ELBO being bounded above (by the true log-likelihood) ensures convergence, but the fixed point may be a local maximum or even a saddle point.

⚠️ Common Misconceptions

1. "EM finds the MLE." It finds a local MLE (stationary point). For GMMs, multiple restarts are standard practice.
2. "The M-step always has a closed form." Only for exponential-family complete-data models. In general, the M-step requires numerical optimization (Generalized EM / GEM).
3. "EM is slow." Near convergence, EM has linear convergence rate governed by the fraction of missing information. Many missing variables → slow convergence. Use mini-batch or stochastic EM for large datasets.

Connection to Variational Inference

Variational Inference (VI) generalizes EM: instead of setting \(q = p(Z \mid X, \theta)\) exactly (which may be intractable), VI restricts \(q\) to a family \(\mathcal{Q}\) and maximizes the ELBO jointly. EM is exact VI — it is VI where the E-step is tractable (exact posterior computation).

From-Scratch Implementation
▼

Fully annotated from-scratch NumPy implementation of EM for a Gaussian Mixture Model:

import numpy as np
def gauss_pdf(x, mu, sigma):
"""Univariate Gaussian pdf. Numerically stable for small sigma."""
return np.exp(-0.5 * ((x - mu) / sigma)**2) / (sigma * np.sqrt(2 * np.pi))
def em_gmm(X, K=2, max_iter=100, tol=1e-6, seed=42):
np.random.seed(seed)
N = len(X)
# ── Initialise parameters ─────────────────────────────────────────
idx = np.random.choice(N, K, replace=False)
mu = X[idx].copy() # K means, picked at random data points
sigma = np.ones(K) # equal initial variances
pi = np.ones(K) / K # uniform mixing coefficients
log_likes = []
for it in range(max_iter):
# ── E-step: compute responsibilities r[i,k] ───────────────────
R = np.zeros((N, K))
for k in range(K):
R[:, k] = pi[k] * gauss_pdf(X, mu[k], sigma[k])
# Marginal likelihood p(x_i) = sum_k pi_k * N(x_i | mu_k, sig_k)
pX = R.sum(axis=1, keepdims=True) # shape (N, 1)
R /= pX # normalise: r[i,k] in [0,1], sum_k = 1
# ── Log-likelihood ────────────────────────────────────────────
ll = np.sum(np.log(pX))
log_likes.append(ll)
# ── M-step: update parameters ─────────────────────────────────
Nk = R.sum(axis=0) # effective count for each component
mu = (R * X[:, None]).sum(axis=0) / Nk # weighted mean
sigma = np.sqrt( # weighted std dev
(R * (X[:, None] - mu)**2).sum(axis=0) / Nk
)
pi = Nk / N # updated mixing proportions
# ── Convergence check ────────────────────────────────────────
if it > 0 and abs(log_likes[-1] - log_likes[-2]) < tol:
break
return mu, sigma, pi, R, log_likes
⚠️ Production Gotchas

1. Degenerate components: A component can collapse onto a single point (\(\sigma_k \to 0\)), causing \(-\infty\) log-likelihood. Fix: add a small regularization \(\sigma_k \leftarrow \max(\sigma_k, \epsilon)\) or use a Dirichlet/Wishart prior (Bayesian GMM).
2. Label switching: EM components have no canonical ordering. Sort by \(\mu_k\) after convergence for reproducible output.
3. Initialization: Use K-means++ initialization for means — much more reliable than random. sklearn's GaussianMixture does this by default.
4. sklearn one-liner: from sklearn.mixture import GaussianMixture; gm = GaussianMixture(n_components=K, n_init=10).fit(X)

Key Takeaways & Applications
▼

When to Use EM

GMMs / soft clustering: When you need probabilistic cluster assignments, not hard labels. EM is the standard algorithm for training GMMs. Missing data: When data is missing at random (MAR), EM treats the missing values as latent variables and produces the exact MLE. Hidden Markov Models (HMMs): The Baum-Welch algorithm is EM — the E-step runs the forward-backward algorithm; the M-step updates transition/emission matrices. Factor Analysis & PCA with missing data: EM recovers principal components even when observations have missing entries.
