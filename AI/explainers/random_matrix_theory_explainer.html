How eigenvalues of large sample covariance matrices behave — and what it means for PCA

1
Understanding Random Matrix Theory
▼

What is it? When you collect data with many features (say, 500 gene expressions from 1000 patients), the sample covariance matrix you compute is a random matrix — because the data is random. Random Matrix Theory (RMT) asks: what do the eigenvalues of this matrix look like, even when there is no real signal? The Marchenko-Pastur law gives the exact answer.

The core surprise: Even if your data columns are completely independent and normally distributed (pure noise!), the eigenvalues of the sample covariance matrix do NOT all equal 1.0. They spread out into a smooth, curved distribution. This spread is entirely due to finite-sample estimation error — it is pure mathematical artifact, not signal.

Analogy: Imagine flipping 500 fair coins 1000 times and computing the correlation between every pair. Even though the coins are independent, some pairs will look correlated by chance. If you do PCA on the resulting correlation matrix, you'll see "principal components" that capture this spurious structure. The Marchenko-Pastur law tells you exactly how large these spurious eigenvalues can get, so you know which PCA components are real signal versus noise.

💡 If you remember one thing

For a \(p \times n\) data matrix of i.i.d. entries (pure noise), as \(p,n\to\infty\) with \(\gamma = p/n\) fixed, the eigenvalues of the sample covariance matrix follow the Marchenko-Pastur distribution with support \([\lambda_-, \lambda_+]\) where $$\lambda_{\pm} = \sigma^2(1 \pm \sqrt{\gamma})^2.$$ Any eigenvalue above \(\lambda_+\) is a genuine signal, not noise.

2
How the MP Distribution Arises
▼

Setup: The Sample Covariance Matrix

Let \(\mathbf{X}\) be a \(p \times n\) matrix whose entries are i.i.d. with mean 0 and variance \(\sigma^2\). The sample covariance matrix is

$$\hat{\Sigma} = \frac{1}{n} \mathbf{X} \mathbf{X}^\top \in \mathbb{R}^{p \times p}$$

This matrix has \(p\) eigenvalues \(\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_p \geq 0\). The key question: what is the distribution of these eigenvalues as \(p, n \to \infty\)?

The Aspect Ratio \(\gamma = p/n\)

The single most important parameter is the aspect ratio \(\gamma = p/n\):

  • \(\gamma \ll 1\) (many more samples than features): bulk is narrow, well-concentrated around \(\sigma^2\)
  • \(\gamma = 1\) (square matrix): bulk spreads from 0 to \(4\sigma^2\), the smallest eigenvalues touch zero
  • \(\gamma > 1\) (more features than samples): \(p - n\) eigenvalues are exactly 0; remaining \(n\) eigenvalues follow MP

The Marchenko-Pastur Density

The empirical spectral distribution converges (weakly, almost surely) to the MP density:

$$f_\gamma(\lambda) = \frac{\sqrt{(\lambda_+ - \lambda)(\lambda - \lambda_-)}}{2\pi \gamma \sigma^2 \lambda} \cdot \mathbf{1}_{[\lambda_-, \lambda_+]}(\lambda) + \max(1 - 1/\gamma, 0)\cdot\delta(\lambda)$$

where the bulk edges are \(\lambda_{\pm} = \sigma^2(1 \pm \sqrt{\gamma})^2\) and \(\delta(\lambda)\) is a point mass at zero when \(\gamma > 1\).

🔑 Key Property

The MP law is a free probability result. It describes the spectral measure of \(\frac{1}{n}\mathbf{X}\mathbf{X}^\top\) exactly in the limit, with no approximation error — a remarkable exact result about an ensemble of random matrices.

Connection to Wishart Matrices

When the entries of \(\mathbf{X}\) are Gaussian, \(\hat{\Sigma}\) is a Wishart matrix \(W_p(\sigma^2 I, n)\). The MP law was originally proved for this Gaussian case by Marchenko and Pastur (1967) using the Stieltjes transform, then extended to non-Gaussian entries via universality results.

3
The Math — Derivation Sketch
▼

Stieltjes Transform Approach

The key tool is the Stieltjes transform of the empirical spectral distribution \(\mu_n\):

$$m(z) = \int \frac{1}{\lambda - z} \, d\mu_n(\lambda) = \frac{1}{p} \operatorname{tr}\!\left((\hat{\Sigma} - zI)^{-1}\right), \quad z \in \mathbb{C}^+$$

By the resolvent identity and concentration inequalities, as \(p, n \to \infty\), \(m(z)\) converges a.s. to the unique solution of the self-consistency equation:

$$m = \frac{1}{-z + \sigma^2/(1 + \gamma m \sigma^2)}$$

Solving this quadratic in \(m\) and inverting via the Stieltjes inversion formula \(f(\lambda) = \frac{1}{\pi}\lim_{\eta\to 0^+} \operatorname{Im}\, m(\lambda + i\eta)\) yields the MP density.

Bulk Edges from the Self-Consistency Equation

The edges \(\lambda_\pm\) occur where the imaginary part of \(m(z)\) vanishes for real \(z\). Setting \(z = \lambda\) real and requiring a double root of the quadratic:

$$\lambda_{\pm} = \sigma^2(1 \pm \sqrt{\gamma})^2$$

For \(\gamma = 1\): \(\lambda_- = 0\), \(\lambda_+ = 4\sigma^2\). For \(\gamma = 0.25\): \(\lambda_- = 0.25\sigma^2\), \(\lambda_+ = 2.25\sigma^2\).

Spiked Model: Signal Above the Bulk

In the spiked covariance model (Johnstone 2001), the population covariance is \(\Sigma = I + \sum_{k=1}^r \ell_k \mathbf{u}_k \mathbf{u}_k^\top\) with \(r \ll p\) spikes of strength \(\ell_k\). The BBP phase transition (Baik-Ben Arous-Péché 2005) states:

$$\hat{\lambda}_k \xrightarrow{a.s.} \begin{cases} \sigma^2\!\left(1 + \ell_k\right)\!\left(1 + \dfrac{\gamma}{\ell_k}\right) & \text{if } \ell_k > \sigma^2\sqrt{\gamma} \text{ (signal detectable)}\\ \lambda_+ & \text{if } \ell_k \leq \sigma^2\sqrt{\gamma} \text{ (signal buried in noise)} \end{cases}$$

This is the PCA noise threshold: a population spike must exceed \(\sigma^2\sqrt{\gamma}\) to be detectable in finite samples.

⚠️ Common Pitfall

In high-dimensional data (\(p\) comparable to \(n\)), the largest sample eigenvalue is systematically biased upward: \(\hat{\lambda}_1 \approx \sigma^2(1+\sqrt{\gamma})^2\) even when there is no signal. Treating the top PCA component as signal is incorrect unless \(\hat{\lambda}_1\) significantly exceeds \(\lambda_+\).

The Inverse Marchenko-Pastur Problem

Given the sample eigenvalues \(\hat{\lambda}_i\), one can estimate the population eigenvalues via the Oracle approximating shrinkage estimator (Ledoit-Wolf). The key formula relates sample and population eigenvalues through the MP equation:

$$\hat{\ell}_k = \frac{\hat{\lambda}_k}{\left|1 + \gamma \, \hat{m}(\hat{\lambda}_k)\right|^2}$$

where \(\hat{m}(\lambda) = \frac{1}{p}\sum_{j \neq k} \frac{1}{\hat{\lambda}_j - \lambda}\) is the empirical Stieltjes transform excluding eigenvalue \(k\).

PCA Implications & Key Takeaways
▼

The PCA Noise Threshold

In standard PCA, we pick the top \(k\) eigenvalues as "signal." But in high dimensions, many of these may be noise. The correct test: a sample eigenvalue \(\hat{\lambda}\) represents genuine signal only if \(\hat{\lambda} > \lambda_+ = \sigma^2(1+\sqrt{\gamma})^2\). Below this threshold, you cannot distinguish signal from noise — the BBP transition shows information is irretrievably lost.

Practical Rule of Thumb

Estimate \(\sigma^2\) as the median sample eigenvalue (the bulk center is \(\approx\sigma^2\)). Compute \(\lambda_+ = \hat{\sigma}^2(1+\sqrt{\gamma})^2\). Discard all principal components whose eigenvalue is below \(\lambda_+\).

📐 Numerical Example

With \(p = 100\), \(n = 400\), \(\gamma = 0.25\), \(\sigma^2 = 1\): the bulk occupies \([0.25, 2.25]\). A sample eigenvalue of 2.5 is above \(\lambda_+ = 2.25\) — barely significant. An eigenvalue of 4.0 is strongly above the bulk — genuine signal. An eigenvalue of 2.0 — pure noise, despite looking large.

Tracy-Widom Fluctuations at the Edge

The largest eigenvalue \(\hat{\lambda}_1\) (when there is no spike) fluctuates around \(\lambda_+\) on scale \(n^{-2/3}\) following the Tracy-Widom distribution (GOE class). This gives precise finite-sample hypothesis tests: whether the observed \(\hat{\lambda}_1\) is consistent with pure noise under the MP law.

When to Apply RMT

  • High-dimensional PCA: Genomics, finance, imaging — whenever \(p/n\) is not negligible
  • Covariance estimation: Ledoit-Wolf shrinkage and its nonlinear variants use MP to correct eigenvalues
  • Neural network weights: Empirical spectra of weight matrices often follow MP — deviations signal learning
  • Noise estimation: The bulk median gives a consistent estimator of \(\sigma^2\)
🔑 Bottom Line

The Marchenko-Pastur law is the null distribution for high-dimensional PCA. It plays the same role as the chi-squared distribution in classical hypothesis testing — it tells you what to expect from pure noise, so you can identify genuine structure.

From-Scratch Implementation
▼

A numerically correct implementation of the MP density and eigenvalue simulation in Python + NumPy.

import numpy as np
import matplotlib.pyplot as plt
def marchenko_pastur_density(lam, gamma, sigma2=1.0):
"""Marchenko-Pastur PDF at eigenvalue lam."""
lam_plus = sigma2 * (1 + np.sqrt(gamma))**2
lam_minus = sigma2 * (1 - np.sqrt(gamma))**2
# Support check
mask = (lam >= lam_minus) & (lam <= lam_plus)
f = np.zeros_like(lam, dtype=float)
l = lam[mask]
num = np.sqrt((lam_plus - l) * (l - lam_minus))
f[mask] = num / (2 * np.pi * gamma * sigma2 * l)
return f
def sample_eigenvalues(p, n, sigma2=1.0):
"""Eigenvalues of (1/n) X X^T, X ~ N(0, sigma^2)."""
X = np.random.randn(p, n) * np.sqrt(sigma2)
S = X @ X.T / n # sample covariance (mean already 0)
eigvals = np.linalg.eigvalsh(S) # symmetric — use eigvalsh
return np.sort(eigvals)[::-1] # descending
def bbp_threshold(gamma, sigma2=1.0):
"""BBP transition: minimum signal strength detectable."""
return sigma2 * np.sqrt(gamma)
def spiked_sample_eigenvalue(ell, gamma, sigma2=1.0):
"""Limiting sample eigenvalue for a population spike ell."""
lam_plus = sigma2 * (1 + np.sqrt(gamma))**2
threshold = bbp_threshold(gamma, sigma2)
if ell <= threshold:
return lam_plus # spike buried in bulk
return sigma2 * (1 + ell) * (1 + gamma / ell)
# --- Example usage ---
gamma, n = 0.25, 400
p = int(gamma * n) # p = 100
eigvals = sample_eigenvalues(p, n)
lam_plus = (1 + np.sqrt(gamma))**2 # = 2.25
lam_minus = (1 - np.sqrt(gamma))**2 # = 0.25
print(f"Largest eigenvalue: {eigvals[0]:.3f} (MP upper edge: {lam_plus:.3f})")
print(f"Smallest eigenvalue: {eigvals[-1]:.3f} (MP lower edge: {lam_minus:.3f})")
