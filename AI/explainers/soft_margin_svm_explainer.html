Understanding Soft-Margin SVM
▼

What is it? A hard-margin SVM draws the widest possible straight-line boundary between two classes — but only when the data is perfectly separable. Real data rarely is: classes overlap, outliers exist, noise corrupts labels. Soft-margin SVM relaxes the separability requirement by introducing slack variables \(\xi_i \geq 0\), one per training point. These variables absorb violations of the margin constraint. The scalar \(C > 0\) controls how severely violations are penalised.

Analogy: Imagine enforcing a security perimeter at an event. Hard-margin says: "No one may step inside the barrier — ever." Impossible if the crowd is dense. Soft-margin says: "People may cross, but each crosser costs you a penalty proportional to how far they've trespassed. C controls the fine rate — high C means strict enforcement and a narrow perimeter; low C means relaxed enforcement and a wide, comfortable zone."

If you remember one thing

Soft-margin SVM minimises $$\frac{1}{2}\|w\|^2 + C\sum_{i=1}^{n}\xi_i$$ subject to \(y_i(w^\top x_i + b) \geq 1 - \xi_i\), \(\xi_i \geq 0\). Small \(C\) = wide soft margin (many tolerated violations). Large \(C\) = narrow hard-ish margin (near-zero violations). The per-point penalty \(\xi_i^* = \max(0,\, 1 - y_i f(x_i))\) is exactly the hinge loss.

How Soft-Margin SVM Works Internally
▼

From Hard to Soft: Introducing Slack Variables

The hard-margin constraint for each training point \(i\) is \(y_i(w^\top x_i + b) \geq 1\) — every point must sit at least one unit (in \(w\)-normalised space) from the hyperplane. Soft-margin relaxes this:

$$y_i(w^\top x_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0 \quad \forall\, i$$

Geometrically, the slack \(\xi_i\) measures the violation:

  • \(\xi_i = 0\): point is on or outside its class's margin boundary — fully satisfied.
  • \(0 < \xi_i < 1\): point is inside the margin but still on the correct side of the hyperplane.
  • \(\xi_i \geq 1\): point is misclassified — it crossed to the wrong side.

The Primal Optimisation Problem

$$\min_{w,\, b,\, \xi}\;\; \frac{1}{2}\|w\|^2 + C\sum_{i=1}^{n} \xi_i \quad \text{s.t.}\; y_i(w^\top x_i + b) \geq 1 - \xi_i,\;\; \xi_i \geq 0$$

The two competing terms are: \(\frac{1}{2}\|w\|^2\) — pushes toward a wide margin (small \(\|w\|\)); and \(C\sum\xi_i\) — penalises violations. The scalar \(C > 0\) arbitrates:

  • Small C: violations are cheap. The solver chooses a wide margin even at the cost of many violators. Effectively stronger regularisation.
  • Large C: violations are expensive. The solver shrinks the margin to eliminate them. As \(C \to \infty\), approaches hard-margin SVM.
Key Invariant: Support Vectors Only

At the optimum, \(w = \sum_i \alpha_i y_i x_i\) where \(\alpha_i > 0\) only for support vectors — points satisfying \(y_i f(x_i) \leq 1\). All other points contribute nothing to the boundary. Smaller C typically yields more support vectors; larger C fewer (only the closest boundary points).

The Dual Formulation

Via Lagrangian duality, the primal reduces to a quadratic program in the multipliers \(\alpha_i\):

$$\max_{\alpha}\;\sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j x_i^\top x_j \quad \text{s.t.}\;\; 0 \leq \alpha_i \leq C,\;\; \sum_i \alpha_i y_i = 0$$

The only difference from the hard-margin dual is the box constraint \(\alpha_i \leq C\), which prevents outliers from contributing an unbounded amount to the decision boundary. The kernel trick replaces \(x_i^\top x_j\) with any positive-definite kernel \(k(x_i, x_j)\) — enabling nonlinear boundaries without computing explicit features.

Common Pitfall: C direction is counter-intuitive

C is an inverse regularisation strength. Larger C = less regularisation = tighter (potentially overfit) boundary. This is opposite to the convention in ridge regression where \(\lambda\) (regularisation strength) gives \(\lambda\|w\|^2\), and \(\lambda = \frac{1}{2C}\).

Why It Works — Hinge Loss and Regularisation
▼

Equivalence to Hinge Loss + L2 Regularisation

At the optimum, the value of each slack variable is \(\xi_i^* = \max(0,\, 1 - y_i f(x_i))\). This is exactly the hinge loss:

$$\ell_{\text{hinge}}(y_i, f(x_i)) = \max(0,\; 1 - y_i f(x_i))$$

Substituting back, the soft-margin objective equals:

$$\underbrace{\frac{1}{2}\|w\|^2}_{\text{L2 regularisation}} + C\underbrace{\sum_{i=1}^n \max(0,\; 1 - y_i f(x_i))}_{\text{total hinge loss}}$$

Comparing with the standard regularised ERM form \(\lambda R(w) + \frac{1}{n}\sum_i \ell_i\), we see that \(C = \frac{1}{2n\lambda}\). The SVM thus belongs to the broader family of regularised risk minimisation, with hinge loss playing the role of the empirical risk.

KKT Conditions at Optimum

For each point, the complementary slackness conditions of the Lagrangian give a clean trichotomy:

  • \(\alpha_i = 0\): outside margin, \(\xi_i = 0\) — not a support vector. Removing it wouldn't change \(w\).
  • \(0 < \alpha_i < C\): on the margin boundary (\(y_i f(x_i) = 1\)), \(\xi_i = 0\).
  • \(\alpha_i = C\): inside the margin or misclassified (\(y_i f(x_i) < 1\)), \(\xi_i = 1 - y_i f(x_i) > 0\).

Why Hinge Loss vs. Logistic Loss?

Hinge loss is exactly zero for correctly classified points outside the margin (\(u = y_i f(x_i) > 1\)). This sparsity is the source of the support vector property — most training points have no influence on the boundary. Logistic loss \(\log(1 + e^{-u})\) is always positive, meaning every training point influences the logistic regression weights, making the solution dense.

Margin Width Formula

The geometric margin (distance between the two supporting hyperplanes \(w^\top x + b = \pm 1\)) is \(\frac{2}{\|w\|}\). Minimising \(\frac{1}{2}\|w\|^2\) maximises the margin squared. A wider margin \(\Leftrightarrow\) smaller \(\|w\|\) \(\Leftrightarrow\) stronger effective regularisation (smaller C).

Key Takeaways
▼

When to use soft-margin SVM:

  • Binary classification with overlapping classes or noisy labels
  • Moderate dimensions (text classification with TF-IDF is a classic use)
  • Kernel trick needed — replace \(x_i^\top x_j\) with RBF/poly kernel for nonlinear boundaries
  • Interpretability: support vectors are the "hardest" training examples

When NOT to use:

  • Very large \(n\) (>100 k) — QP solver is \(O(n^2)\) to \(O(n^3)\) in general
  • Multi-class out-of-the-box — requires OvO or OvR wrapper
  • Calibrated probabilities needed — Platt scaling required as a post-hoc step
C tuning heuristic

Grid-search C on a log scale: \(\{0.001, 0.01, 0.1, 1, 10, 100, 1000\}\) with cross-validation. Start with \(C=1\). Too many support vectors (nearly all training points) → C too small. Near-zero training error with poor validation → C too large (overfitting).

From Scratch: Subgradient Descent on Hinge + L2

import numpy as np
def svm_subgradient(X, y, C=1.0, lr=0.01, epochs=1000):
"""Soft-margin SVM via subgradient on 1/2||w||^2 + C * sum max(0, 1-y_i f(x_i))."""
n, d = X.shape
w = np.zeros(d) # weight vector (no bias trick: augment X with 1s)
for t in range(1, epochs + 1):
eta = lr / t # decreasing step for convergence guarantee
for i in range(n):
u = y[i] * (X[i] @ w) # functional margin for point i
if u < 1: # inside margin or misclassified
# Subgradient of hinge: -y_i * x_i (w.r.t. w)
w = (1 - eta) * w + eta * C * y[i] * X[i]
else: # correctly outside margin
w = (1 - eta) * w # only L2 regularisation gradient
return w
def soft_svm_objective(w, b, X, y, C):
"""Compute primal objective: 1/2||w||^2 + C * sum_i max(0, 1-y_i*f(x_i))."""
margins = y * (X @ w + b) # shape (n,)
xi = np.maximum(0, 1 - margins) # slack / hinge loss per point
return 0.5 * np.dot(w, w) + C * xi.sum()
