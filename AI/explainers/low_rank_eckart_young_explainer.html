Understanding Low-Rank Approximation
▼

What is it? Any matrix \(A\) can be factored into a sum of simple "rank-1 pieces." Each piece is just an outer product of two vectors — extremely compact. Low-rank approximation keeps only the k most important pieces, discarding the rest. The result \(A_k\) is a matrix that looks as much like \(A\) as possible using only \(k\) pieces.

Analogy: Think of a photograph. You can represent it as a stack of transparent overlays — the first overlay captures the big-picture light/dark pattern, the next adds coarser colour regions, then finer details. Low-rank approximation keeps only the first \(k\) overlays. The Eckart–Young theorem says: of all possible \(k\)-overlay representations you could construct, the SVD gives you the one with the smallest total error. You cannot do better.

One-sentence summary: The rank-\(k\) truncated SVD is the uniquely optimal rank-\(k\) approximation to any matrix, in both spectral and Frobenius norm.

💡 If you remember one thing

Build \(A_k = \sum_{i=1}^k \sigma_i \mathbf{u}_i \mathbf{v}_i^\top\) by adding rank-1 layers in decreasing singular-value order. The spectral error is exactly \(\sigma_{k+1}\) and the Frobenius error is \(\sqrt{\sigma_{k+1}^2 + \cdots + \sigma_r^2}\). No other rank-\(k\) matrix achieves smaller error in either norm.

How It Works — SVD & Rank-1 Layers
▼

Step 1: SVD Gives You the Pieces

Every real matrix \(A \in \mathbb{R}^{m \times n}\) of rank \(r\) has a Singular Value Decomposition:

$$A = U \Sigma V^\top = \sum_{i=1}^{r} \sigma_i \mathbf{u}_i \mathbf{v}_i^\top$$

where \(\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_r > 0\) are the singular values, \(\mathbf{u}_i \in \mathbb{R}^m\) are left singular vectors (orthonormal), and \(\mathbf{v}_i \in \mathbb{R}^n\) are right singular vectors (orthonormal). Each term \(\sigma_i \mathbf{u}_i \mathbf{v}_i^\top\) is a rank-1 matrix scaled by \(\sigma_i\).

Step 2: Truncate to Rank k

The rank-\(k\) approximation simply drops the last \(r - k\) terms:

$$A_k = \sum_{i=1}^{k} \sigma_i \mathbf{u}_i \mathbf{v}_i^\top = U_k \Sigma_k V_k^\top$$

where \(U_k\) holds the first \(k\) columns of \(U\), \(\Sigma_k = \operatorname{diag}(\sigma_1, \ldots, \sigma_k)\), and \(V_k\) holds the first \(k\) columns of \(V\). This is all you need — no other rank-\(k\) matrix is closer to \(A\).

Step 3: The Errors Are Exact and Known

The error of the rank-\(k\) approximation has a beautiful closed form in two norms:

$$\|A - A_k\|_2 = \sigma_{k+1}, \qquad \|A - A_k\|_F = \sqrt{\sum_{i=k+1}^{r} \sigma_i^2}$$

The spectral norm error equals the very next singular value. The Frobenius error equals the Euclidean norm of the discarded singular values. Both are the smallest achievable for any rank-\(k\) matrix.

🔑 Key Property — Eckart–Young–Mirsky Theorem (1936/1960)

For any matrix \(B\) of rank at most \(k\):

$$\|A - A_k\|_2 \leq \|A - B\|_2 \quad \text{and} \quad \|A - A_k\|_F \leq \|A - B\|_F$$

Optimality holds simultaneously for both norms, and for all unitarily invariant norms.

3
Why It Works — Proof Sketch & Key Math
▼

Error Formulas — Derivation

Write the residual \(E = A - A_k = \sum_{i=k+1}^r \sigma_i \mathbf{u}_i \mathbf{v}_i^\top\). Since the \(\mathbf{u}_i\) and \(\mathbf{v}_i\) are orthonormal:

$$\|A - A_k\|_2 = \max_{\|\mathbf{x}\|=1} \|E\mathbf{x}\|_2 = \sigma_{k+1}$$

The maximum is achieved by \(\mathbf{x} = \mathbf{v}_{k+1}\), giving \(E\mathbf{v}_{k+1} = \sigma_{k+1}\mathbf{u}_{k+1}\).

$$\|A - A_k\|_F^2 = \|E\|_F^2 = \sum_{i=k+1}^r \sigma_i^2$$

This follows because \(\|\cdot\|_F^2 = \operatorname{tr}(E^\top E)\) and the singular values of \(E\) are exactly \(\sigma_{k+1}, \ldots, \sigma_r\).

Optimality — Proof Sketch (Frobenius Case)

Suppose \(B\) has rank at most \(k\). Its null space has dimension at least \(n - k\). The span of \(\{\mathbf{v}_1, \ldots, \mathbf{v}_{k+1}\}\) is \((k+1)\)-dimensional, so by a dimension argument it contains a unit vector \(\mathbf{w}\) in the null space of \(B\). Then:

$$\|A - B\|_F \geq \|(A-B)\mathbf{w}\| = \|A\mathbf{w}\| \geq \sigma_{k+1} = \|A - A_k\|_2 \leq \|A - A_k\|_F$$

Since any competitor \(B\) achieves error \(\geq \sigma_{k+1}\) and \(A_k\) achieves exactly \(\sigma_{k+1}\) in spectral norm, \(A_k\) wins. The Frobenius case requires an additional step using the Courant-Fischer min-max principle.

Compression Ratio

Storing \(A \in \mathbb{R}^{m \times n}\) costs \(mn\) numbers. Storing \(A_k = U_k \Sigma_k V_k^\top\) costs \(mk + k + nk = k(m + n + 1)\) numbers. The compression is worthwhile when:

$$k < \frac{mn}{m + n + 1} \approx \frac{mn}{m+n}$$
⚠️ Common Misconception

Eckart–Young proves optimality over the Frobenius norm AND the spectral (operator) norm AND all unitarily invariant norms. It does NOT hold for entry-wise norms like \(\ell^\infty\) or \(\ell^1\). For example, minimizing the max entry-wise error is a different (much harder) problem.

Code — From Scratch & Numerically Correct
▼

From Scratch with NumPy

import numpy as np
# ── Build the matrix used in the visualisation ──
np.random.seed(42)
A = np.array([[4.5,1.2,-0.8,2.1,0.3],
[1.2,3.8, 0.5,-1.1,1.7],
[-0.8,0.5,2.9,0.7,-0.4],
[2.1,-1.1,0.7,3.3,0.9],
[0.3,1.7,-0.4,0.9,2.1]])
# ── Full SVD ──
U, s, Vt = np.linalg.svd(A, full_matrices=True)
# s = singular values in descending order
print("Singular values:", np.round(s, 3))
# → [6.453 4.965 3.436 2.206 0.460]
# ── Build rank-k approximation iteratively ──
for k in range(1, 6):
# Select first k singular values / vectors
Ak = (U[:, :k] * s[:k]) @ Vt[:k, :]
# Spectral norm error = next singular value
err_spec = s[k] if k < len(s) else 0.0
# Frobenius norm error = sqrt(sum of dropped sigma^2)
err_frob = np.sqrt(np.sum(s[k:]**2))
# Verify against direct computation
assert np.isclose(np.linalg.norm(A - Ak, 2), err_spec, atol=1e-8)
assert np.isclose(np.linalg.norm(A - Ak, 'fro'), err_frob, atol=1e-8)
print(f"k={k} spec={err_spec:.4f} frob={err_frob:.4f}")
# ── Eckart–Young optimality check ──
k = 2
Ak = (U[:, :k] * s[:k]) @ Vt[:k, :]
best_frob = np.linalg.norm(A - Ak, 'fro') # 2.009 (optimal)
# Any OTHER rank-2 matrix B will have ≥ this error
B_random = np.random.randn(5,2) @ np.random.randn(2,5) # rank 2
assert np.linalg.norm(A - B_random, 'fro') >= best_frob - 1e-8

Production Usage (scikit-learn / PyTorch)

# ── scikit-learn: TruncatedSVD (memory-efficient for sparse matrices) ──
from sklearn.decomposition import TruncatedSVD
svd = TruncatedSVD(n_components=2, random_state=42)
A_reduced = svd.fit_transform(A) # shape (5, 2)
A_reconstructed = A_reduced @ svd.components_ # shape (5, 5)
# ── PyTorch (GPU-accelerated) ──
import torch
A_t = torch.tensor(A, dtype=torch.float64)
U_t, s_t, Vh_t = torch.linalg.svd(A_t, full_matrices=False)
k = 2
Ak_t = (U_t[:, :k] * s_t[:k]) @ Vh_t[:k, :]
# ⚠️ Gotcha: torch.linalg.svd returns Vh (conjugate transpose of V),
# not V. So use Vh[:k, :], NOT V[:, :k].T
# ── LoRA (Low-Rank Adaptation for LLMs) ──
# LoRA initialises two matrices A (m×r) and B (r×n) with r << min(m,n)
# Δ W = B @ A (rank-r update). Eckart-Young tells us the best such Δ W
# is exactly the rank-r SVD truncation of the full weight update.

Key Takeaways & When to Use
▼

Comparison: Low-Rank Methods

MethodOptimalityCostUse case
Truncated SVD (Eckart–Young)Optimal (all unitarily invariant norms)O(min(m,n)·mn)Dense matrices, exact optimality needed
Randomised SVDNear-optimal with high probabilityO(k·mn) + O(k²n)Large-scale, approximate; e.g., PCA on 10⁶ rows
NMF (Non-negative MF)Not generally optimalIterativeWhen non-negativity matters (topic models, images)
CUR DecompositionNear-optimalO(k·mn)Need interpretable rows/columns
Sparse PCANot optimal (sparse constraint)IterativeWhen loadings must be sparse for interpretation

When to use truncated SVD (Eckart–Young):

  • Image compression — keep top-\(k\) singular values, reconstruct
  • Principal Component Analysis — columns of \(U_k\) are the top-\(k\) PCs
  • Latent Semantic Analysis (LSA) — reduce term-document matrix to \(k\) topics
  • Collaborative filtering — low-rank matrix completion (Netflix Prize)
  • LoRA fine-tuning — approximate weight updates as rank-\(r\) outer products
  • Noise reduction — small singular values often correspond to noise
💡 The Energy Interpretation

The fraction of "information" (Frobenius norm squared) captured by \(A_k\) is \(\displaystyle\frac{\sum_{i=1}^k \sigma_i^2}{\sum_{i=1}^r \sigma_i^2}\). Choose \(k\) to retain, say, 99% of the total energy. This is the standard "explained variance" criterion in PCA.
