Non-Maximum Suppression (NMS) & Variants

Selecting the best bounding boxes for object detection
Foundational Deep Learning Computer Vision O(N log N) / O(N²)
1
Understanding NMS
▼

What is it? Object detection models often predict many overlapping bounding boxes for the same object, especially when multiple anchor boxes or different scales/aspect ratios are used. Non-Maximum Suppression (NMS) is a post-processing algorithm that aims to eliminate these redundant detections, keeping only the most confident and representative box for each distinct object.

Analogy: Imagine a crowd of photographers all trying to take a picture of the same celebrity. Each photographer (detection) has a different angle (bounding box) and a different level of confidence (score) that their shot is the best. NMS is like an editor who looks at all the photos, picks the absolute best one, and then discards all other photos that are "too similar" (i.e., too much overlap) to the chosen best one. This process repeats until only unique, high-quality photos remain.

💡 If you remember one thing

NMS is a greedy algorithm that iteratively selects the detection with the highest confidence score and suppresses (removes or re-scores) all other detections that significantly overlap with it. It's essential for producing clean, interpretable object detection results.

How NMS Works Internally
▼

The Standard NMS Procedure

Given a list of bounding boxes, each with a confidence score, standard NMS follows these steps:

  1. Sort: Order all candidate bounding boxes in descending order of their confidence scores.
  2. Select Best: Pick the box with the highest score from the sorted list. Add this box to the final list of detections.
  3. Suppress Overlaps: For all remaining candidate boxes, calculate their Intersection over Union (IoU) with the selected box. If the IoU is greater than a predefined threshold (e.g., 0.5), remove that candidate box from the list.
  4. Repeat: Go back to step 2 with the remaining (unprocessed and un-suppressed) boxes until no candidate boxes are left.

This greedy approach ensures that for any cluster of overlapping boxes, only the most confident one survives.

Beyond Hard Suppression: Soft-NMS

A limitation of standard NMS is its "hard thresholding": if two objects are genuinely close (e.g., two people hugging), and their bounding boxes significantly overlap, standard NMS might suppress one of them even if both are valid detections. Soft-NMS addresses this by reducing the confidence score of overlapping boxes instead of outright removing them. This allows slightly less confident but still valid detections to potentially survive if they don't overlap too much with subsequent selections.

Considering Geometry: DIoU-NMS

Standard IoU only considers the area of overlap. However, two boxes can have the same IoU but different spatial arrangements (e.g., one box perfectly centered within another, versus two boxes barely touching at an edge). DIoU (Distance-IoU) is a metric that incorporates the distance between the center points of bounding boxes into the IoU calculation. DIoU-NMS uses this more sophisticated metric for suppression, leading to more robust results, especially when dealing with nested or highly overlapping objects that represent the same entity. It penalizes detections that are far from the center of the chosen box, even if their IoU is high.

🔑 Key Property

All NMS variants share the core idea of iterating through detections by confidence. They primarily differ in (1) how overlap is measured (IoU, DIoU, etc.) and (2) how overlapping boxes are handled (hard removal, score re-weighting, etc.).

3
Why It Works — The Math
▼

1. Intersection over Union (IoU)

The fundamental metric for measuring overlap between two bounding boxes \(B_1\) and \(B_2\) is IoU. It's the ratio of the area of their intersection to the area of their union:

$$IoU(B_1, B_2) = \frac{Area(B_1 \cap B_2)}{Area(B_1 \cup B_2)}$$

An IoU of 0 means no overlap, and an IoU of 1 means perfect overlap. Standard NMS uses this metric directly.

2. Soft-NMS Re-weighting Function

Instead of setting \(s_i = 0\) for overlapping boxes, Soft-NMS applies a score reduction. A common non-linear (Gaussian) re-weighting function is:

$$s_i = s_i \cdot e^{-\frac{IoU(M, B_i)^2}{\sigma}}$$

Here, \(M\) is the currently selected box, \(B_i\) is a candidate box, \(s_i\) is its original score, and \(\sigma\) is a hyperparameter (typically around 0.5) that controls the decay rate. A higher IoU leads to a greater score reduction, but never to zero unless the IoU is extremely high or \(\sigma\) is very small.

3. Distance-IoU (DIoU)

DIoU (Zheng et al., 2020) improves upon IoU by considering the normalized distance between the center points of the bounding boxes. Let \(b^M\) and \(b^i\) be the center points of box \(M\) and \(B_i\) respectively, and \(c\) be the diagonal length of the smallest enclosing box covering both \(M\) and \(B_i\). The penalty term \(R_{DIoU}\) is:

$$R_{DIoU}(M, B_i) = \frac{\rho^2(b^M, b^i)}{c^2}$$

where \(\rho^2(b^M, b^i)\) is the squared Euclidean distance between the center points. The DIoU metric is then:

$$DIoU(M, B_i) = IoU(M, B_i) - R_{DIoU}(M, B_i)$$

DIoU-NMS then uses this \(DIoU(M, B_i)\) value in place of \(IoU(M, B_i)\) for its suppression or re-weighting logic. This encourages selecting boxes that are better aligned with the ground truth and suppresses boxes that are far from the center of a strong detection, even if they have high IoU.

⚠️ Common Pitfall

A major challenge with NMS (especially standard NMS) is handling occluded or very close objects. If two distinct objects are very close and their true bounding boxes significantly overlap, NMS might incorrectly suppress one of them, treating it as a redundant detection for the other. This is often called the "over-suppression" problem.

When to use NMS (or a variant):

  • Almost always, as a post-processing step in any object detection pipeline (e.g., Faster R-CNN, SSD, YOLO).
  • When your model outputs many redundant, overlapping bounding boxes for the same object.
  • To improve the precision and interpretability of your detection results.

When to be cautious / consider alternatives:

  • When dealing with extremely dense scenes where true objects genuinely overlap significantly (e.g., a stack of coins). Standard NMS might over-suppress. Soft-NMS or NMS-free methods (like CenterNet, FCOS) might be better.
  • If computational speed is absolutely critical and you have a very large number of detections (NMS can be \(O(N^2)\) in worst case, though often \(O(N \log N)\) with spatial indexing).
💡 One-Line Summary

NMS is a critical heuristic that transforms raw, messy object detector outputs into a clean, sparse set of final predictions. Its variants offer trade-offs between speed, simplicity, and performance in challenging scenarios.

import numpy as np
def compute_iou(box1, box2):
# box: [x1, y1, x2, y2]
x1, y1, x2, y2 = box1
_x1, _y1, _x2, _y2 = box2
# Intersection area
inter_x1 = max(x1, _x1)
inter_y1 = max(y1, _y1)
inter_x2 = min(x2, _x2)
inter_y2 = min(y2, _y2)
inter_w = max(0, inter_x2 - inter_x1)
inter_h = max(0, inter_y2 - inter_y1)
inter_area = inter_w * inter_h
# Union area
box1_area = (x2 - x1) * (y2 - y1)
box2_area = (_x2 - _x1) * (_y2 - _y1)
union_area = box1_area + box2_area - inter_area
return inter_area / (union_area + 1e-6) # Add epsilon to prevent division by zero
def compute_diou(box1, box2):
iou = compute_iou(box1, box2)
# Center points
b1_cx, b1_cy = (box1[0] + box1[2]) / 2, (box1[1] + box1[3]) / 2
b2_cx, b2_cy = (box2[0] + box2[2]) / 2, (box2[1] + box2[3]) / 2
# Distance between center points squared
center_dist_sq = (b1_cx - b2_cx)**2 + (b1_cy - b2_cy)**2
# Smallest enclosing box (diagonal squared)
c_x1 = min(box1[0], box2[0]); c_y1 = min(box1[1], box2[1])
c_x2 = max(box1[2], box2[2]); c_y2 = max(box1[3], box2[3])
c_diag_sq = (c_x2 - c_x1)**2 + (c_y2 - c_y1)**2
# DIoU penalty term
diou_penalty = center_dist_sq / (c_diag_sq + 1e-6)
return iou - diou_penalty
def standard_nms(boxes, scores, iou_threshold):
# Prepare data for processing (track original indices)
detections = [(scores[i], boxes[i], i) for i in range(len(boxes))]
detections.sort(key=lambda x: x[0], reverse=True) # Sort by score (descending)
final_boxes_indices = []
while detections:
best_score, best_box, best_idx = detections.pop(0) # Pick highest score box
final_boxes_indices.append(best_idx)
# Filter out boxes with high IoU from remaining detections
remaining_detections = []
for score, box, idx in detections:
if compute_iou(best_box, box) < iou_threshold:
remaining_detections.append((score, box, idx))
detections = remaining_detections
return final_boxes_indices
def soft_nms(boxes, scores, iou_threshold, sigma=0.5):
current_scores = np.array(scores) # Scores will be modified
active_indices = list(range(len(boxes))) # All boxes initially active
final_boxes_indices = []
while active_indices:
# Find box with max score among active ones
max_score = -1
best_active_idx = -1
for idx in active_indices:
if current_scores[idx] > max_score:
max_score = current_scores[idx]
best_active_idx = idx
if max_score < 1e-3: break # Effectively removed
final_boxes_indices.append(best_active_idx)
active_indices.remove(best_active_idx) # Remove from consideration for next best
best_box = boxes[best_active_idx]
for idx in active_indices:
iou = compute_iou(best_box, boxes[idx])
if iou >= iou_threshold: # Only apply penalty if IoU is high
current_scores[idx] *= np.exp(-(iou * iou) / sigma)
return final_boxes_indices, current_scores # Return final scores too
def diou_nms(boxes, scores, diou_threshold):
detections = [(scores[i], boxes[i], i) for i in range(len(boxes))]
detections.sort(key=lambda x: x[0], reverse=True)
final_boxes_indices = []
while detections:
best_score, best_box, best_idx = detections.pop(0)
final_boxes_indices.append(best_idx)
remaining_detections = []
for score, box, idx in detections:
if compute_diou(best_box, box) < diou_threshold:
remaining_detections.append((score, box, idx))
detections = remaining_detections
return final_boxes_indices
