Lagrangian Duality

Weak duality, strong duality, and Slater's constraint qualification
Advanced Optimization Theory Convex Analysis Part I · Section 5.3
1
Understanding Lagrangian Duality
▼

What is it? When you want to minimize a function subject to constraints, duality gives you a second, "mirror-image" problem whose optimal value can never exceed the original. Under benign conditions (convexity + Slater's condition), the two problems have exactly the same optimal value — and solving the easier dual can solve the hard primal.

Analogy: Imagine bidding on a contract. The primal problem is the buyer asking: "What's the cheapest way to fulfill these requirements?" The dual is the seller asking: "What prices should I charge for each resource so that my total profit is as large as possible without over-pricing?" Weak duality says the seller can never extract more money than the buyer must spend. Strong duality says that in fair markets (convex, Slater conditions hold), the two match exactly.

💡 If you remember one thing

The dual function \(g(\lambda, \nu) = \inf_x \mathcal{L}(x, \lambda, \nu)\) is always concave (even if the primal is non-convex), and always lower-bounds the primal optimal \(p^\star\). This is weak duality. When the gap \(p^\star - d^\star = 0\), we have strong duality — guaranteed for convex problems satisfying Slater's condition.

2
The Lagrangian and Dual Function
▼

Primal Problem

Consider the standard form optimization problem:

$$\min_{x} \; f_0(x) \quad \text{s.t.} \quad f_i(x) \le 0, \; i=1,\ldots,m \quad h_j(x) = 0, \; j=1,\ldots,p$$

The Lagrangian absorbs constraints into the objective by attaching multipliers \(\lambda_i \ge 0\) (for inequalities) and \(\nu_j \in \mathbb{R}\) (for equalities):

$$\mathcal{L}(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{j=1}^p \nu_j h_j(x)$$

The Dual Function

The Lagrange dual function is the pointwise infimum of \(\mathcal{L}\) over all \(x\):

$$g(\lambda, \nu) = \inf_{x \in \mathcal{D}} \mathcal{L}(x, \lambda, \nu)$$

For any dual-feasible \((\lambda \ge 0, \nu)\), \(g(\lambda, \nu) \le p^\star\). This is the fundamental inequality of weak duality. The dual function is concave in \((\lambda, \nu)\) as the pointwise infimum of affine functions of \((\lambda, \nu)\) — regardless of the convexity of the primal.

🔑 Why the Dual Function Is Always Concave

For any fixed \(x\), \(\mathcal{L}(x, \lambda, \nu)\) is affine (hence concave) in \((\lambda, \nu)\). The infimum of any collection of concave functions is concave. Therefore \(g = \inf_x \mathcal{L}(x,\cdot,\cdot)\) is always concave, making the dual problem \(\max_{\lambda \ge 0} g(\lambda, \nu)\) always a convex optimization problem — even when the primal is non-convex.

The Dual Problem

The Lagrange dual problem maximizes the dual function subject to dual feasibility:

$$\max_{\lambda \ge 0,\, \nu} \; g(\lambda, \nu) \qquad \text{optimal value: } d^\star$$

The duality gap is \(p^\star - d^\star \ge 0\). Strong duality holds when the gap is zero: \(p^\star = d^\star\).

3
Weak Duality, Strong Duality, and Slater's Condition
▼

Weak Duality (always holds)

Theorem: For any dual-feasible \((\lambda, \nu)\) with \(\lambda \ge 0\), and any primal-feasible \(\tilde{x}\) (i.e., \(f_i(\tilde{x}) \le 0\), \(h_j(\tilde{x}) = 0\)):

$$g(\lambda, \nu) \le p^\star$$

Proof sketch: For any primal-feasible \(\tilde{x}\):

$$g(\lambda,\nu) = \inf_x \mathcal{L}(x,\lambda,\nu) \le \mathcal{L}(\tilde{x},\lambda,\nu) = f_0(\tilde{x}) + \underbrace{\sum_i \lambda_i f_i(\tilde{x})}_{\le\, 0} + \underbrace{\sum_j \nu_j h_j(\tilde{x})}_{=\, 0} \le f_0(\tilde{x})$$

Since this holds for all primal-feasible \(\tilde{x}\), taking the infimum gives \(g(\lambda,\nu) \le p^\star\). Taking the supremum over dual-feasible \((\lambda,\nu)\) gives \(d^\star \le p^\star\).

Slater's Condition (Guarantees Strong Duality)

Slater's condition: For a convex problem (\(f_0, f_1, \ldots, f_m\) convex, \(h_j\) affine), there exists a strictly feasible point \(\tilde{x} \in \operatorname{relint}(\mathcal{D})\) such that:

$$f_i(\tilde{x}) < 0 \;\; \forall i=1,\ldots,m \qquad \text{and} \qquad h_j(\tilde{x}) = 0 \;\; \forall j$$

If Slater's condition holds, then strong duality holds: \(p^\star = d^\star\), and the dual optimum \(d^\star\) is attained.

Strong Duality and KKT Conditions

When strong duality holds and primal/dual optima are attained, the KKT conditions are both necessary and sufficient for optimality. The complementary slackness condition \(\lambda_i^\star f_i(x^\star) = 0\) for all \(i\) is especially important: either the constraint is tight (\(f_i(x^\star) = 0\)) or the multiplier is zero (\(\lambda_i^\star = 0\)).

⚠️ Common Misconception

Slater's condition is sufficient for strong duality in convex problems — it is not necessary. Strong duality can hold even when no strictly feasible point exists (e.g., linear programs always have strong duality when both are feasible, even when no strict interior point exists). Non-convex problems can also sometimes exhibit strong duality (see quadratic problems with QCQP and S-procedure).

From Scratch — Computing the Dual Function
▼

Below is a numerically correct computation of the dual function for a convex QP, demonstrating weak duality and verifying strong duality via Slater's condition.

import numpy as np
from scipy.optimize import minimize_scalar
# Primal: min (x-1)^2 + 2 s.t. x >= 2 (i.e., 2 - x <= 0)
f0 = lambda x: (x - 1)**2 + 2 # objective
f1 = lambda x: 2 - x # inequality constraint (<= 0)
# Primal optimum: x* = 2 (constraint active), p* = 3
p_star = f0(2.0) # = 3.0
def lagrangian(x, lam):
"""L(x, lambda) = f0(x) + lambda * f1(x)"""
return f0(x) + lam * f1(x)
def dual_function(lam):
"""g(lambda) = inf_x L(x, lambda) [closed-form for this QP]"""
# Analytical: x*(lam) = 1 + lam/2, g(lam) = -lam^2/4 + lam + 2
return -lam**2 / 4 + lam + 2
# Verify weak duality: g(lam) <= p_star for all lam >= 0
lambdas = np.linspace(0, 6, 1000)
assert np.all(dual_function(lambdas) <= p_star + 1e-9), "Weak duality violated!"
# Dual optimum: maximize g(lam) over lam >= 0
lam_star = 2.0 # d/dlam g = -lam/2 + 1 = 0 => lam* = 2
d_star = dual_function(lam_star) # = 3.0
print(f"p* = {p_star:.4f}, d* = {d_star:.4f}, gap = {p_star - d_star:.4f}")
# Output: p* = 3.0000, d* = 3.0000, gap = 0.0000 (strong duality!)
# Slater's condition: find strictly feasible x_tilde
x_tilde = 3.0 # f1(3) = 2-3 = -1 < 0 (strictly feasible)
print(f"Slater point: x_tilde={x_tilde}, f1(x_tilde)={f1(x_tilde)}")
# => Strong duality is guaranteed by Slater's condition

The dual function is computed in closed form for this quadratic program (QP) using the analytical minimizer. For more complex problems, scipy.optimize.minimize computes \(\inf_x \mathcal{L}(x,\lambda)\) numerically for each \(\lambda\).

6
Key Takeaways & When to Use
▼

Summary

Weak duality is a free lunch: it always holds and gives a certificate lower bound on \(p^\star\). Strong duality (gap = 0) is the prize: it lets you solve the primal via the dual, which is always convex regardless of the primal. Slater's condition is the most common and practical sufficient condition — for a convex problem, if you can find one strictly feasible interior point, strong duality is guaranteed.

Why this matters for ML: SVMs exploit strong duality to move from a constrained primal (hard to solve) to a dual (solvable via QP, enables kernel trick). Interior-point methods rely on duality gaps as optimality certificates. ADMM and Lagrangian relaxation use dual variables to decompose large optimization problems.

📐 Three-Line Summary

Weak duality: \(g(\lambda,\nu) \le p^\star\) always.
Strong duality: \(d^\star = p^\star\) when Slater holds (convex + strict interior).
Slater check: Find \(\tilde{x}\) with \(f_i(\tilde{x}) < 0\) for all inequality constraints.
