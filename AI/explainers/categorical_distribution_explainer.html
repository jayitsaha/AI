Categorical Distribution

The fundamental distribution for multi-class outcomes — backbone of softmax, cross-entropy, and language model next-token prediction.
Foundational Probability & Statistics Part I · Section 0.3 K-outcome draw
1
Understanding the Concept
▾

A Categorical distribution describes a single random experiment with exactly K mutually exclusive outcomes (categories), each with its own probability. You roll once and land on exactly one face — that's it.

Think of it as a loaded K-sided die. Before you roll, each face \(k \in \{1,\dots,K\}\) has probability \(p_k\), with all probabilities non-negative and summing to one: \(\sum_{k=1}^{K} p_k = 1\). After you roll, you observe exactly one face — a one-hot vector with a 1 in position \(k\) and 0s everywhere else.

Key Insight

The Categorical is the generalization of the Bernoulli from 2 outcomes to K. When K = 2, with \(p_1 = p\) and \(p_2 = 1-p\), you recover the Bernoulli exactly. Every softmax output in a neural network is implicitly producing the parameters of a Categorical distribution over the vocabulary/class set.

Real-World Analogy

Imagine a spinner divided into K coloured sectors, where each sector's arc length is proportional to its probability. Spin it once — you get exactly one colour. Language models do exactly this at each generation step: the softmax layer produces sector sizes (probabilities), and sampling picks one token.

If You Remember One Thing

A Categorical draw produces a one-hot vector \(\mathbf{e}_k\) with probability \(p_k\). The softmax function converts raw logits into valid Categorical parameters, and the negative log-likelihood of the true class is the cross-entropy loss.

2
How It Works — Parameters, PMF & Sampling
▾

Probability Mass Function

Let \(X \sim \text{Categorical}(\mathbf{p})\) where \(\mathbf{p} = (p_1,\dots,p_K)\) with \(p_k \ge 0\) and \(\sum_k p_k = 1\). The PMF is:

$$P(X = k) = p_k, \qquad k = 1, \dots, K$$

Equivalently, encoding the outcome as a one-hot vector \(\mathbf{x} = \mathbf{e}_k\) (1 at position \(k\), 0 elsewhere):

$$P(\mathbf{x}) = \prod_{k=1}^{K} p_k^{x_k}$$

Moments

For the one-hot representation \(\mathbf{x} = \mathbf{e}_K\):

$$\mathbb{E}[x_k] = p_k, \qquad \operatorname{Var}(x_k) = p_k(1 - p_k), \qquad \operatorname{Cov}(x_j, x_k) = -p_j p_k \text{ for } j \ne k$$

Softmax — Turning Logits into Categorical Parameters

Neural networks output unconstrained logits \(\mathbf{z} \in \mathbb{R}^K\). The softmax function maps them to valid Categorical probabilities:

$$p_k = \text{softmax}(\mathbf{z})_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$$

For numerical stability, subtract the max logit before exponentiating (the result is identical because the constant cancels in numerator and denominator):

$$p_k = \frac{e^{z_k - z_{\max}}}{\sum_{j=1}^{K} e^{z_j - z_{\max}}}$$
Common Mistake

Softmax outputs are not calibrated probabilities unless the model is calibrated. A softmax value of 0.95 does not mean "95% chance of being correct" — it only means "outcome \(k\) is the modal prediction under this distribution." Always pair with temperature scaling or Platt calibration for reliable confidence estimates.

Gumbel-Max Trick — Differentiable Sampling

Drawing from \(\text{Categorical}(\mathbf{p})\) is equivalent to:

$$k^* = \underset{k}{\operatorname{argmax}}\;\bigl(z_k + g_k\bigr), \qquad g_k \overset{\text{i.i.d.}}{\sim} \text{Gumbel}(0, 1)$$

where \(g_k = -\log(-\log u_k)\) and \(u_k \sim \text{Uniform}(0,1)\). This enables the Gumbel-Softmax (Concrete) reparameterisation for gradient-based training through discrete choices.

Cross-Entropy Loss Connection

Given true class \(y\) (a one-hot vector) and model probabilities \(\mathbf{q}\), the negative log-likelihood of the Categorical is exactly the cross-entropy:

$$\mathcal{L} = -\log q_y = -\sum_{k=1}^{K} y_k \log q_k = H(y, \mathbf{q})$$

Minimising cross-entropy loss is equivalent to maximising the log-likelihood of the Categorical model. This is the standard loss for every classification network and language model.

Why It Works — Exponential Family & Maximum Entropy
▾

Exponential Family Form

The Categorical belongs to the exponential family. Writing the PMF in canonical form (using the first \(K-1\) categories with \(p_K = 1 - \sum_{k<K} p_k\)):

$$P(\mathbf{x}\,|\,\boldsymbol{\eta}) = \exp\!\Bigl(\boldsymbol{\eta}^\top \mathbf{x} - A(\boldsymbol{\eta})\Bigr), \quad \eta_k = \log\frac{p_k}{p_K}, \quad A(\boldsymbol{\eta}) = \log\!\Bigl(1 + \sum_{k=1}^{K-1} e^{\eta_k}\Bigr)$$

Here \(\boldsymbol{\eta}\) are the natural parameters (log-odds relative to the reference class), \(A(\boldsymbol{\eta})\) is the log-partition function, and \(\mathbf{x}\) is the sufficient statistic. The mean parameter is \(\mu_k = \mathbb{E}[x_k] = p_k = \nabla_{\eta_k} A\).

Maximum Entropy Justification

Among all distributions over \(K\) outcomes with fixed mean \(\mathbb{E}[x_k] = p_k\), the Categorical is the maximum-entropy distribution. No other distribution with those marginals is less informative. Its entropy is:

$$H(\mathbf{p}) = -\sum_{k=1}^{K} p_k \log p_k$$

Entropy is 0 when all mass is on one outcome (certainty), and \(\log K\) nats (bits: \(\log_2 K\)) for the uniform distribution (maximum uncertainty). This justifies using it as the default prior when only outcome probabilities are known.

KL Divergence between Two Categoricals

$$D_{\mathrm{KL}}(P \| Q) = \sum_{k=1}^{K} p_k \log \frac{p_k}{q_k}$$ This is the extra expected bits needed to encode samples from \(P\) using the code optimal for \(Q\). Cross-entropy decomposes as \(H(P,Q) = H(P) + D_{\mathrm{KL}}(P\|Q)\).

Key Takeaways & When to Use
▾

Summary

The Categorical distribution is the simplest multi-outcome probability model. Its parameters are a probability vector \(\mathbf{p}\) on the \((K-1)\)-simplex. It generalises Bernoulli (K=2), is parameterised by softmax in neural networks, and its negative log-likelihood gives cross-entropy loss. Sampling can be done naively via CDF inversion or elegantly via the Gumbel-max trick — the latter enables differentiable relaxations.

When to Use

  • Multi-class classification (single correct label per example) — final layer outputs \(\text{softmax}(\mathbf{z})\) gives Categorical parameters.
  • Language modelling — every next-token prediction is a Categorical draw over the vocabulary.
  • Reinforcement learning — policy distributions over discrete action spaces.
  • Generative models — discrete latent variables (VQ-VAE, dVAE, discrete diffusion).

When NOT to Use

  • Multi-label problems (multiple correct labels) — use independent Bernoullis or Sigmoid instead of Softmax.
  • Continuous outputs — use Gaussian, Laplace, or mixture models.
  • Ordinal outcomes — Categorical ignores ordering; use ordered logit or Poisson instead.
