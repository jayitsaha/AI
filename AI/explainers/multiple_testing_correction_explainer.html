Understanding Multiple Testing
▼

What is the problem? A single hypothesis test at significance level \(\alpha = 0.05\) has a 5% chance of wrongly rejecting a true null hypothesis. But if you run m independent tests, each at the same threshold, the chance of making at least one false rejection explodes. With \(m = 20\) tests you would expect roughly one false positive by chance alone, even if all null hypotheses are true.

Analogy: Imagine flipping a fair coin once — a 5% "event" (five heads in a row) is rare. But flip it a thousand times and you will almost certainly see that event somewhere. Running 100 statistical tests at \(\alpha = 0.05\) is like flipping the coin 100 times and declaring the coin "magic" when any run of heads appears.

If you remember one thing

When testing \(m\) hypotheses simultaneously, the Family-Wise Error Rate (FWER) is \(1-(1-\alpha)^m\), which rapidly approaches 1. Bonferroni controls FWER by using threshold \(\alpha/m\) per test (conservative). Benjamini–Hochberg (BH) controls the less stringent False Discovery Rate (FDR) by comparing sorted p-values to a staircase: reject \(H_{(i)}\) if \(p_{(i)} \le \frac{i}{m}\alpha\).

2
How Each Correction Works
▼

The Problem: Family-Wise Error Rate (FWER)

Suppose we test \(m\) null hypotheses \(H_1, \ldots, H_m\), each independently at level \(\alpha\). If all are true, the probability that at least one is falsely rejected is:

$$\text{FWER} = 1 - (1-\alpha)^m$$

For \(m = 20, \alpha = 0.05\): FWER \(\approx 0.64\). For \(m = 100\): FWER \(\approx 0.994\). We are almost guaranteed a false positive.

Bonferroni Correction: Control FWER

The simplest fix. Reject \(H_i\) only when \(p_i \le \alpha/m\). By a union bound:

$$\text{FWER} \le m \cdot \frac{\alpha}{m} = \alpha$$

This is valid under any dependence structure, but it is conservative. With many truly non-null hypotheses, power is low — real effects can be missed.

False Discovery Rate (FDR) — A Weaker but More Powerful Goal

Instead of controlling the probability of any false positive, FDR controls the expected proportion of rejections that are false:

$$\text{FDR} = \mathbb{E}\!\left[\frac{V}{\max(R,1)}\right]$$

where \(V\) = number of false discoveries, \(R\) = total rejections. FDR \(\le\) FWER, so FDR control is weaker — but allows far more statistical power when many true effects exist.

Benjamini–Hochberg (BH) Procedure: Control FDR

Sort the \(m\) p-values: \(p_{(1)} \le p_{(2)} \le \cdots \le p_{(m)}\). Find the largest rank \(k\) such that:

$$p_{(k)} \le \frac{k}{m}\,\alpha$$

Reject hypotheses \(H_{(1)}, \ldots, H_{(k)}\). The BH procedure guarantees \(\text{FDR} \le \alpha\) when tests are independent (or PRDS — positive regression dependence on a subset).

Key Insight: Staircase vs Horizontal Line

Bonferroni uses a flat threshold \(\alpha/m\) for all tests — the same bar for the weakest and strongest signal. BH uses a staircase threshold \((i/m)\alpha\) that rises with rank, giving the procedure room to accept more discoveries when evidence accumulates.

Common Pitfall

BH controls FDR at level \(\alpha\) under independence. Under arbitrary dependence, use Benjamini–Yekutieli (BY), which replaces \(\alpha\) with \(\alpha / \sum_{i=1}^{m} 1/i \approx \alpha / \ln m\) — much more conservative.

3
Why BH Works — Proof Sketch
▼

Setup

Let \(m_0\) be the number of true nulls (unknown), \(m_1 = m - m_0\) the true alternatives. Under the null, p-values are Uniform\([0,1]\). The BH step-up rule rejects \(H_{(1)}, \ldots, H_{(k)}\) where \(k = \max\{i : p_{(i)} \le (i/m)\alpha\}\).

FDR Control Derivation (Benjamini & Hochberg 1995)

The key identity links the false discovery proportion to individual null p-values:

$$\text{FDR} = \sum_{i \in \mathcal{H}_0} \mathbb{E}\!\left[\frac{\mathbf{1}(p_i \le (k/m)\alpha)}{k}\right]$$

Under independence, each true-null p-value \(p_i \sim U[0,1]\), so \(\Pr(p_i \le t) = t\). Summing over \(m_0\) true nulls and bounding \(k \ge R \ge 1\):

$$\text{FDR} \le \frac{m_0}{m}\,\alpha \le \alpha$$

The ratio \(m_0/m\) is the fraction of truly null hypotheses. When all nulls are true (\(m_0 = m\)), FDR = FWER; when many alternatives exist (\(m_0 \ll m\)), FDR \(\ll\) FWER and BH is dramatically more powerful.

Power Comparison

With \(m = 100\) tests, \(\alpha = 0.05\), and 20 truly non-null effects:

  • Bonferroni threshold: \(0.05/100 = 0.0005\) — misses weak effects
  • BH threshold at rank 20: \((20/100) \times 0.05 = 0.01\) — 20× more lenient for the 20th hypothesis
BH Step-Up Algorithm (Exact)

1. Sort p-values: \(p_{(1)} \le \cdots \le p_{(m)}\).
2. Find \(k^\star = \max\left\{i : p_{(i)} \le \dfrac{i}{m}\alpha\right\}\).
3. Reject \(H_{(1)}, \ldots, H_{(k^\star)}\). If no such \(i\) exists, reject nothing.
Guaranteed: \(\text{FDR} \le \dfrac{m_0}{m}\,\alpha \le \alpha\).

Key Takeaways & When to Use Each
▼

Use Bonferroni when:

  • Few tests (\(m \le 20\)) and FWER control is mandatory
  • A single false positive is catastrophic (e.g., clinical drug approval)
  • Tests are positively correlated (Bonferroni is still valid)

Use BH when:

  • Many tests (\(m \gg 100\)) — genomics, neuroimaging, A/B multivariate
  • You can tolerate some false discoveries in exchange for more power
  • Tests are independent or positively correlated (PRDS)

Hierarchy of Error Control

FWER control (Bonferroni) \(\Rightarrow\) FDR control (BH), but not vice versa. BH controlling FDR at \(\alpha\) does NOT guarantee FWER \(\le \alpha\). Choose based on consequences: confirmatory trials → FWER; exploratory discovery → FDR.

import numpy as np
from scipy import stats
# m = 10 p-values (sorted for illustration)
p_vals = [0.0012, 0.0032, 0.0089, 0.0241, 0.0324,
0.0510, 0.0642, 0.1540, 0.2314, 0.4820]
m, alpha = len(p_vals), 0.05
# ── Bonferroni ──────────────────────────────────
bonf_thresh = alpha / m # 0.005
bonf_reject = [p <= bonf_thresh for p in p_vals]
# Rejects: [True, True, False, ...] (2 rejections)
# ── Benjamini–Hochberg ──────────────────────────
bh_thresh = [(i+1)/m * alpha for i in range(m)]
# = [0.005, 0.010, 0.015, 0.020, ...]
k_star = -1
for i in range(m-1, -1, -1): # scan from largest rank
if p_vals[i] <= bh_thresh[i]:
k_star = i; break
bh_reject = list(range(k_star + 1)) # reject ranks 0..k_star
# k_star = 2, so reject hypotheses (1), (2), (3)
# ── scipy shortcut ──────────────────────────────
from statsmodels.stats.multitest import multipletests
reject_bh, pvals_corrected, _, _ = multipletests(
p_vals, alpha=0.05, method='fdr_bh')
reject_bonf, _, _, _ = multipletests(
p_vals, alpha=0.05, method='bonferroni')
