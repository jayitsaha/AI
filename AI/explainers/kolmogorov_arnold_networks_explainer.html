Understanding KANs
▼

What is it? Kolmogorov-Arnold Networks (KANs) are a new type of neural network architecture inspired by the Kolmogorov-Arnold representation theorem. Unlike traditional Multi-Layer Perceptrons (MLPs) which apply a fixed activation function (like ReLU) after a linear transformation, KANs place *learnable univariate functions* on the edges (connections) between neurons. This makes KANs potentially more interpretable, efficient, and accurate for certain tasks, especially those involving symbolic reasoning or discovering underlying mathematical formulas.

Analogy: Imagine a complex orchestral piece. In an MLP, each musician plays a fixed note (activation) after a fixed instruction (linear weight). In a KAN, each connection between musicians is a soloist, playing a unique, adaptable melody (univariate function) that changes to best contribute to the overall harmony. This allows the orchestra to learn much more nuanced and complex relationships, sometimes with fewer musicians, and makes it easier to understand *why* a particular harmony is produced by listening to individual melodies.

💡 If you remember one thing

KANs replace the fixed non-linearity + linear weight in MLPs with a single, learnable, univariate function \(\phi(x)\) on each edge. This allows KANs to directly learn and represent complex interactions between features, leading to higher interpretability and potential for better performance on tasks like symbolic regression.

How KANs Work Internally
▼

The Core Idea: Kolmogorov-Arnold Representation Theorem

The Kolmogorov-Arnold Representation Theorem states that any continuous multivariate function \(f(x_1, \dots, x_n)\) can be written as a finite composition of continuous univariate functions and addition: $$f(\mathbf{x}) = \sum_{q=0}^{2n} \Phi_q \left( \sum_{p=1}^n \psi_{q,p}(x_p) \right)$$ This theorem theoretically shows that any complex function can be decomposed into simpler 1D functions. KANs are inspired by this idea, constructing a neural network where each "edge" between neurons learns one of these univariate functions.

KAN Architecture: Layers of Univariate Functions

A KAN consists of layers of neurons, much like an MLP. However, instead of linear transformations followed by fixed activations, the connections *between* neurons \(i\) in layer \(l\) and neuron \(j\) in layer \(l+1\) are associated with a learnable univariate function \(\phi_{j,i}^{(l)}(x)\). The output of a neuron in layer \(l+1\) is then the sum of the outputs of these functions from the previous layer:

$$x_j^{(l+1)} = \sum_{i=1}^{N_l} \phi_{j,i}^{(l)}(x_i^{(l)})$$

This structure means that KANs are essentially "MLPs of functions," where each "weight" is replaced by a function, and each "neuron" performs a summation.

Spline Basis Functions: Representing the Univariate Functions

Each univariate function \(\phi_{j,i}^{(l)}(x)\) in a KAN is represented as a spline. A spline is a piecewise polynomial function, defined by a set of control points (or grid points) and basis functions. This allows \(\phi(x)\) to be flexible and locally adaptable. During training, the coefficients of these splines (and optionally the grid points themselves) are optimized. This means the *shape* of the activation function on each edge is learned, rather than being fixed.

Design Decision: Why Splines?

Splines are chosen for several reasons:

  • Flexibility: They can approximate a wide variety of continuous functions.
  • Local Support: Changes to one control point only affect the spline locally, aiding stability.
  • Differentiability: Splines are smooth and differentiable, allowing for standard gradient-based optimization.
  • Interpretability: The learned shape of a spline can often reveal simple mathematical relationships (e.g., a linear slope, a quadratic curve, a step function).
🔑 Key Property

KANs maintain universal approximation capabilities, similar to MLPs, but often achieve better accuracy with fewer parameters on tasks where the underlying function has a sparse or interpretable structure. The learnable splines allow the network to adapt its "activation functions" directly to the data.

Why It Works — The Math
▼

The KAN Architecture Equation

Consider a KAN with \(L\) layers. Let \(x^{(0)}\) be the input vector. For each layer \(l \in \{0, \dots, L-1\}\), the activation of neuron \(j\) in layer \(l+1\) is given by:

$$x_j^{(l+1)} = \sum_{i=1}^{N_l} \phi_{j,i}^{(l)}(x_i^{(l)})$$

where \(N_l\) is the number of neurons in layer \(l\), and \(\phi_{j,i}^{(l)}\) is the learnable univariate function connecting neuron \(i\) in layer \(l\) to neuron \(j\) in layer \(l+1\). The final output is \(x^{(L)}\).

Representing \(\phi\) with B-Splines

Each \(\phi_{j,i}^{(l)}(x)\) is composed of a basis function expansion. A common choice is a B-spline basis. For a given input \(x\), the spline function can be written as:

$$\phi(x) = w \cdot B(x) = \sum_{k=1}^G c_k B_k(x)$$

Here, \(B_k(x)\) are the B-spline basis functions (determined by a fixed grid of \(G\) points), and \(c_k\) are the learnable coefficients (weights) for each basis function. The grid points themselves can also be learned, or fixed to be uniform. This formulation ensures smoothness and local control over the function's shape.

Training Objective

Training a KAN involves minimizing a loss function (e.g., Mean Squared Error for regression, Cross-Entropy for classification) with respect to the spline coefficients \(c_k\) (and potentially grid points). Additionally, KANs often incorporate regularization terms to encourage sparsity and smoothness, which enhances interpretability:

$$\mathcal{L} = \text{Loss}(\text{KAN}(\mathbf{x}), \mathbf{y}) + \lambda_1 \sum_{l,j,i} \| \phi_{j,i}^{(l)} \|_1 + \lambda_2 \sum_{l,j,i} \| \phi_{j,i}^{(l)''} \|_2^2$$

The \(L_1\) regularization promotes sparsity (driving some \(\phi\) functions to be constant zero), aiding interpretability. The second-derivative regularization \(\| \phi'' \|_2^2\) encourages smoothness. These terms help KANs discover simpler, more interpretable underlying functions.

⚠️ Common Pitfall

While KANs are inspired by the Kolmogorov-Arnold theorem, they are not a direct, exact implementation. The theorem requires specific properties (e.g., finite sum of \(2n+1\) functions), whereas KANs use a neural network approximation with variable layer sizes. This distinction is important for understanding their practical application vs. theoretical purity.

Key Takeaways
▼

When to use KANs:

  • Interpretability: When understanding the "why" behind predictions is crucial. The learned spline shapes can often be directly interpreted as mathematical functions.
  • Symbolic Regression: For tasks where the goal is to discover a simple underlying mathematical formula from data. KANs have shown promise in identifying such relationships.
  • Improved Accuracy/Efficiency: On certain tabular datasets or tasks with sparse functional dependencies, KANs can achieve comparable or better accuracy than MLPs with fewer parameters.
  • Scientific Discovery: Potentially useful in scientific domains where discovering underlying physical laws or relationships from experimental data is a goal.

When NOT to use:

  • Large-scale Vision/Language: For tasks like image recognition or natural language processing, where the benefits of highly optimized linear algebra operations and dense representations (e.g., in Transformers, CNNs) currently outweigh KANs' advantages.
  • Computational Cost: While efficient for smaller models, KANs can be more computationally intensive than MLPs of similar capacity due to spline evaluation and gradient computation for many univariate functions.
  • Lack of Optimized Libraries: KANs are newer, so highly optimized, production-ready libraries are still evolving compared to the mature ecosystems for MLPs/Transformers.
💡 Big Picture

KANs represent a fascinating bridge between classical symbolic AI and modern neural networks. By embedding learnable functions directly into the network structure, they offer a path towards more transparent, interpretable, and potentially more "scientific" machine learning models, capable of not just predicting but also explaining their predictions in human-understandable terms.

import torch
import torch.nn as nn
import torch.nn.functional as F
class KANLayer(nn.Module):
def __init__(self, in_features, out_features, grid_size=5, k=3):
super().__init__()
self.in_features = in_features
self.out_features = out_features
# For each input-output pair, store spline coefficients
self.spline_weights = nn.Parameter(torch.randn(out_features, in_features, grid_size + k))
self.grid = torch.linspace(-1, 1, grid_size + 2*k + 1) # Fixed grid for simplicity
self.k = k # spline order
def forward(self, x):
# x: (batch_size, in_features)
batch_size = x.shape[0]
# Expand x to (batch_size, out_features, in_features) for broadcasting
x_expanded = x.unsqueeze(1).expand(batch_size, self.out_features, self.in_features)
# Compute B-spline basis functions for each x_i
# (Simplified: in reality, this would involve a proper B-spline evaluation)
# For demo, let's just use a placeholder `evaluate_spline_basis`
basis_outputs = torch.zeros(batch_size, self.out_features, self.in_features, self.grid.shape[0] - 1 - self.k)
for i in range(self.in_features):
for j in range(self.out_features):
# Simulate spline evaluation: sum of basis functions * weights
# This is the core phi_j,i(x_i) computation
# A real implementation would use `torch_spline_conv.basis_funcs`
current_x = x[:, i] # input for this phi_j,i
# Simplified: map input to an index for spline_weights
# In reality, this is a smooth, differentiable spline eval.
phi_output = torch.sum(self.spline_weights[j, i, :grid_size] * (current_x.unsqueeze(-1) ** torch.arange(grid_size).float()), dim=-1)
basis_outputs[:, j, i] = phi_output # Store phi_j,i(x_i)
# Sum up the contributions for each output neuron
output = torch.sum(basis_outputs, dim=2) # x_j^(l+1) = sum_i phi_j,i(x_i^l)
return output
