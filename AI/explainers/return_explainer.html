Return: Discounted Cumulative Reward

Evaluating future value in Reinforcement Learning
Foundational Reinforcement Learning Control Theory O(T) calculation
1
Understanding Return
▼

What is it? In Reinforcement Learning (RL), an agent interacts with an environment, taking actions and receiving "rewards" — numerical feedback on how good or bad its actions were. The agent's ultimate goal is to maximize the total amount of reward it receives over time. This total, future reward is called the Return (\(G_t\)). However, future rewards are often worth less than immediate ones, so they are typically "discounted" by a factor \(\gamma\).

Analogy: Imagine you're offered \$100 today or \$100 a year from now. You'd almost certainly take it today. Why? Because of interest (you could invest it), inflation (money loses value), and uncertainty (what if the person disappears?). The "discount factor" \(\gamma\) in RL captures this same intuition: a reward of \(R\) received \(k\) steps in the future is only worth \(\gamma^k R\) today. Agents learn to optimize for this "present value" of future rewards.

💡 If you remember one thing

The Return \(G_t\) is the sum of all future rewards, starting from time \(t+1\), where each reward is discounted by how far into the future it occurs. The discount factor \(\gamma \in [0,1)\) determines how much the agent values immediate rewards versus long-term rewards. $$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^\infty \gamma^k R_{t+k+1}$$

2
How It Works Internally
▼

The Accumulation Process

At any given time step \(t\), an agent wants to know the total value of following a particular policy from that point onwards. This value is \(G_t\). The calculation proceeds by summing up rewards, each weighted by a power of \(\gamma\):

  • The immediate reward \(R_{t+1}\) (received at the next step) is weighted by \(\gamma^0 = 1\).
  • The reward \(R_{t+2}\) (two steps away) is weighted by \(\gamma^1 = \gamma\).
  • The reward \(R_{t+3}\) (three steps away) is weighted by \(\gamma^2\).
  • And so on, with \(R_{t+k+1}\) weighted by \(\gamma^k\).

This exponential decay means rewards far in the future contribute very little to the current return, especially for small \(\gamma\).

The Role of the Discount Factor \(\gamma\)

The choice of \(\gamma\) is crucial and reflects the agent's "horizon":

  • \(\gamma = 0\): The agent is "myopic" and only cares about the immediate reward \(R_{t+1}\). All future rewards are zeroed out.
  • \(\gamma \to 1\): The agent is "farsighted" and considers future rewards almost as important as immediate ones. This can lead to more complex, long-term planning.
  • Typical values (e.g., 0.9, 0.99): A balance, acknowledging that immediate rewards are generally more certain and impactful.

A key mathematical property is that if \(\gamma < 1\), the infinite sum defining \(G_t\) is guaranteed to converge to a finite value, assuming rewards are bounded. This makes calculations tractable.

Recursive Relationship (Bellman Equation)

The return can also be expressed recursively, which is fundamental to many RL algorithms:

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots$$ $$G_t = R_{t+1} + \gamma (R_{t+2} + \gamma R_{t+3} + \dots)$$ $$G_t = R_{t+1} + \gamma G_{t+1}$$

This means the return at time \(t\) is the immediate reward plus the discounted return from the next time step. This recursive structure forms the basis for Bellman equations, which are central to dynamic programming and temporal-difference learning methods in RL.

🔑 Key Property

The Return \(G_t\) is the objective function that an RL agent implicitly or explicitly tries to maximize. By maximizing \(G_t\), the agent learns a policy that leads to the greatest cumulative discounted reward over its lifetime in the environment.

3
Why It Works — The Mathematical Foundation
▼

The Geometric Series Connection

The sum for \(G_t\) is a variation of a geometric series. For a standard geometric series \(\sum_{k=0}^\infty ar^k = a + ar + ar^2 + \dots\), if \(|r| < 1\), the sum converges to \(\frac{a}{1-r}\). In our case, each term is \(\gamma^k R_{t+k+1}\). While the rewards \(R\) can vary, the discount factor \(\gamma\) acts like the common ratio \(r\).

The convergence for \(\gamma < 1\) is critical. If \(\gamma = 1\), the sum \(\sum R_{t+k+1}\) might diverge to infinity (or negative infinity) if the rewards don't eventually go to zero. This makes it impossible to define a clear objective for continuing tasks (tasks without a natural end). Discounting ensures that even in an infinitely long task, the total return remains finite and well-defined.

Impact on Policy Optimization

The return \(G_t\) directly informs how an agent updates its policy. In algorithms like Policy Gradient, the gradient of the expected return with respect to policy parameters is computed and used to adjust the policy. The discount factor shapes this gradient, influencing whether the agent prioritizes actions that yield immediate rewards or those that set up larger, but more distant, future rewards.

$$\nabla J(\theta) = \mathbb{E}_{\pi_\theta}\left[ \sum_{t=0}^T \nabla \log \pi_\theta(A_t | S_t) G_t \right]$$

Here, \(J(\theta)\) is the objective function (expected return), and \(\nabla J(\theta)\) is its gradient. The term \(G_t\) directly scales the policy updates, making actions that lead to high return more probable.

⚠️ Common Pitfall

Choosing \(\gamma\) too close to 1 (e.g., 0.9999) for very long horizons can introduce numerical instability. The sum of discounted rewards might become very large, and the agent might struggle to learn because it's trying to optimize for a distant future with many uncertain steps. Conversely, a \(\gamma\) too small (e.g., 0.1) makes the agent excessively short-sighted, potentially missing out on optimal long-term strategies.

Key Takeaways
▼

When to use and tune \(\gamma\):

  • Task Horizon: For episodic tasks (with a clear end), \(\gamma\) can be 1 (undiscounted) if all episodes are guaranteed to terminate. For continuing tasks (infinite horizon), \(\gamma < 1\) is essential for convergence.
  • Agent Behavior: A higher \(\gamma\) encourages farsighted behavior, making the agent consider long-term consequences. A lower \(\gamma\) makes the agent more myopic, prioritizing immediate gains.
  • Domain Knowledge: The choice of \(\gamma\) often requires domain expertise. In financial applications, \(\gamma\) might reflect real-world interest rates. In games, it might reflect the importance of winning quickly vs. accumulating points over time.

Impact on RL algorithms:

  • Value Functions: Return is directly used to define state-value function \(V(s) = \mathbb{E}[G_t | S_t=s]\) and action-value function \(Q(s,a) = \mathbb{E}[G_t | S_t=s, A_t=a]\).
  • Policy Gradient Methods: \(G_t\) serves as the "score" or "advantage" for an action, guiding policy updates.
  • Temporal Difference Learning: The recursive relationship \(G_t = R_{t+1} + \gamma G_{t+1}\) is leveraged by TD methods (like Q-learning and SARSA) to learn from bootstrapped estimates of future returns.
💡 Big Picture

The concept of discounted cumulative reward is not just a mathematical convenience; it's a fundamental statement about how an intelligent agent should evaluate its actions to achieve long-term goals in an uncertain world. It bridges immediate feedback with a strategic, forward-looking perspective.

Code Trace (Python)
▼
import numpy as np
def calculate_return(rewards, gamma, start_time_idx):
"""
Calculates the discounted cumulative return G_t for a given start_time_idx.
Args:
rewards (list or np.array): Sequence of rewards [R1, R2, ..., RT].
gamma (float): Discount factor (0 <= gamma <= 1).
start_time_idx (int): The index t from which to calculate the return.
G_t uses rewards from index t+1 onwards.
Returns:
float: The discounted cumulative return G_t.
"""
G_t = 0.0
# Loop through rewards from t+1 onwards
for k in range(len(rewards) - (start_time_idx + 1)):
# R_t+k+1 is rewards[start_time_idx + k]
reward_val = rewards[start_time_idx + k]
discount_term = (gamma ** k)
G_t += discount_term * reward_val
return G_t
# Example Usage:
rewards_sequence = [10, -5, 20, 0, 15, -10, 5, 25, 30, 0] # R1 to R10
gamma_val = 0.9
t_val = 0
return_g0 = calculate_return(rewards_sequence, gamma_val, t_val)
print(f"G_{t_val} with gamma={gamma_val}: {return_g0:.2f}")
t_val_2 = 3
return_g3 = calculate_return(rewards_sequence, gamma_val, t_val_2)
print(f"G_{t_val_2} with gamma={gamma_val}: {return_g3:.2f}")
