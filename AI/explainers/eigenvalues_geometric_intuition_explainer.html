Eigenvalues & Eigenvectors

Geometric intuition: invariant directions of a linear transformation
Foundational Linear Algebra Math Foundations Part I Review
1
The Geometric Picture
▼

What is this? Every matrix \(A\) is a recipe for transforming space. Apply it to any vector \(\mathbf{v}\) and you get a new vector \(A\mathbf{v}\) that has (typically) both a different length and a different direction. But for every non-degenerate matrix there are special directions — eigenvectors — where the output is exactly parallel to the input. The transformation only stretches or flips the vector; it never tilts it off its line.

Analogy — The North Star directions. Imagine poking sticks into the ground in all directions from a central point. Now you apply a strong wind that bends most sticks sideways. But two sticks, pointing northeast and northwest, happen to align exactly with the wind lines and merely grow or shrink in length. Those two are the eigenvectors; how much they grow is the eigenvalue.

If You Remember One Thing

Eigenvectors are the invariant directions of a linear map. Under \(A\), they stay on their own line: $$A\mathbf{v} = \lambda\mathbf{v}$$ where \(\lambda\) (the eigenvalue) says how much the vector scales — \(\lambda > 1\) stretches, \(0 < \lambda < 1\) shrinks, \(\lambda < 0\) flips, \(\lambda = 1\) leaves unchanged.

2
The Formal Definition
▼

Eigenvector & Eigenvalue — Precise Definition

Given a square matrix \(A \in \mathbb{R}^{n \times n}\), a non-zero vector \(\mathbf{v} \in \mathbb{R}^n\) is an eigenvector of \(A\) if there exists a scalar \(\lambda \in \mathbb{R}\) (or \(\mathbb{C}\)) such that:

$$A\mathbf{v} = \lambda\mathbf{v}$$

The scalar \(\lambda\) is the corresponding eigenvalue. The pair \((\lambda, \mathbf{v})\) is called an eigenpair. The set of all eigenvectors for a given \(\lambda\) (plus the zero vector) forms the eigenspace — a subspace of \(\mathbb{R}^n\).

Worked Example

Take \(A = \begin{pmatrix}2 & 1 \\ 1 & 2\end{pmatrix}\) and \(\mathbf{v}_1 = \tfrac{1}{\sqrt{2}}\begin{pmatrix}1\\1\end{pmatrix}\):

$$A\mathbf{v}_1 = \begin{pmatrix}2&1\\1&2\end{pmatrix}\frac{1}{\sqrt{2}}\begin{pmatrix}1\\1\end{pmatrix} = \frac{1}{\sqrt{2}}\begin{pmatrix}3\\3\end{pmatrix} = 3 \cdot \frac{1}{\sqrt{2}}\begin{pmatrix}1\\1\end{pmatrix} = 3\mathbf{v}_1$$

So \(\lambda_1 = 3\). For \(\mathbf{v}_2 = \tfrac{1}{\sqrt{2}}\begin{pmatrix}-1\\1\end{pmatrix}\):

$$A\mathbf{v}_2 = \frac{1}{\sqrt{2}}\begin{pmatrix}-1\\1\end{pmatrix} = 1 \cdot \mathbf{v}_2$$

So \(\lambda_2 = 1\). Notice \(\mathbf{v}_1 \perp \mathbf{v}_2\) — this always happens for symmetric matrices (spectral theorem).

Key Property — Eigenvalue Sign and Magnitude

\(\lambda > 1\): vector stretched (grows) along its direction
\(0 < \lambda < 1\): vector compressed (shrinks) along its direction
\(\lambda = 1\): vector is fixed — the transformation leaves it exactly as-is
\(\lambda < 0\): vector is flipped and possibly scaled (points the opposite way)
\(\lambda = 0\): vector is mapped to the zero vector (indicates singularity of \(A\))

3
Finding Eigenvalues & Eigenvectors
▼

Step 1 — The Characteristic Polynomial

Rearrange \(A\mathbf{v} = \lambda\mathbf{v}\) as \((A - \lambda I)\mathbf{v} = \mathbf{0}\). For a non-zero solution \(\mathbf{v}\) to exist, \((A - \lambda I)\) must be singular:

$$\det(A - \lambda I) = 0$$

This is the characteristic equation. Its roots are the eigenvalues. For our \(2 \times 2\) example:

$$\det\begin{pmatrix}2-\lambda & 1 \\ 1 & 2-\lambda\end{pmatrix} = (2-\lambda)^2 - 1 = \lambda^2 - 4\lambda + 3 = (\lambda-3)(\lambda-1) = 0$$

So \(\lambda_1 = 3\) and \(\lambda_2 = 1\).

Step 2 — Recover Eigenvectors (Null Space)

For each eigenvalue, solve \((A - \lambda_i I)\mathbf{v} = \mathbf{0}\) for \(\mathbf{v}\):

For \(\lambda_1 = 3\): \(\begin{pmatrix}-1&1\\1&-1\end{pmatrix}\mathbf{v} = \mathbf{0} \Rightarrow v_1 = v_2\). Normalising: \(\mathbf{v}_1 = \frac{1}{\sqrt{2}}\begin{pmatrix}1\\1\end{pmatrix}\).

For \(\lambda_2 = 1\): \(\begin{pmatrix}1&1\\1&1\end{pmatrix}\mathbf{v} = \mathbf{0} \Rightarrow v_1 = -v_2\). Normalising: \(\mathbf{v}_2 = \frac{1}{\sqrt{2}}\begin{pmatrix}-1\\1\end{pmatrix}\).

Eigendecomposition

If \(A\) has \(n\) linearly independent eigenvectors, we can factor it:

$$A = V \Lambda V^{-1}$$

where \(V\) has eigenvectors as columns and \(\Lambda = \operatorname{diag}(\lambda_1, \ldots, \lambda_n)\). For symmetric matrices, \(V\) is orthogonal so \(A = V \Lambda V^\top\) (spectral decomposition).

Common Pitfalls

Eigenvectors are directions, not unique vectors. Any non-zero scalar multiple \(c\mathbf{v}\) is also an eigenvector for the same \(\lambda\). Always specify normalization convention.
Complex eigenvalues: Real matrices can have complex conjugate pairs — this corresponds to rotations in the transformation. Symmetric (and more generally, Hermitian) matrices always have real eigenvalues.
Repeated eigenvalues: When \(\lambda_i = \lambda_j\), any linear combination of their eigenvectors is also an eigenvector — the eigenspace has dimension > 1.

Key Takeaways & Why It Matters in ML
▼

Why eigenvectors matter in ML:

  • PCA — principal components are eigenvectors of the data covariance matrix \(\Sigma\); eigenvalues give the variance captured per component
  • Spectral clustering — uses eigenvectors of the graph Laplacian to embed nodes
  • Neural network optimization — the curvature of the loss landscape is described by eigenvalues of the Hessian; large \(\lambda\) = steep curvature = hard to train
  • SVD — singular values are square roots of eigenvalues of \(A^\top A\); right singular vectors are its eigenvectors
  • PageRank — the rank vector is the dominant eigenvector of the web's transition matrix
The One-Line Summary

Eigendecomposition reveals the natural axes of a linear transformation — the directions along which the transform acts by pure scaling. These axes are the backbone of PCA, SVD, spectral methods, and much of numerical linear algebra in ML.

Code Trace — NumPy
▼
import numpy as np
# Define a symmetric 2x2 matrix
A = np.array([[2.0, 1.0],
[1.0, 2.0]])
# Compute eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eig(A)
# eigenvalues = [3., 1.]
# eigenvectors[:, 0] = [0.707, 0.707] (45-degree direction)
# eigenvectors[:, 1] = [-0.707, 0.707] (135-degree direction)
# Verify: A @ v == lambda * v
v1 = eigenvectors[:, 0] # [0.707, 0.707]
print(A @ v1) # [2.121, 2.121]
print(eigenvalues[0] * v1) # [2.121, 2.121] ✓
# Characteristic polynomial: det(A - lambda*I) = 0
# (2-lambda)^2 - 1 = 0 => lambda = 3 or 1
# For PCA: use eigh (symmetric/Hermitian) — faster & always real
vals, vecs = np.linalg.eigh(A) # Returns sorted ascending
# vals = [1., 3.], vecs sorted accordingly
