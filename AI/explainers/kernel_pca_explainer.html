Kernel PCA
Non-linear dimensionality reduction via the kernel trick — eigendecompose the Gram matrix to find principal components in implicit feature space
Advanced Unsupervised Learning Dimensionality Reduction Part III · Section 12
1
Understanding the Concept
▾

The core problem with standard PCA: Regular PCA finds directions of maximum variance in your data, but those directions are always straight lines through the original input space. When your data lies on a curved surface — think concentric circles, a Swiss roll, or an interleaved spiral — the "most informative" directions simply don't exist as linear projections.

Key Insight

Kernel PCA solves this by first mapping data into a (possibly infinite-dimensional) feature space \(\mathcal{F}\) via a function \(\phi: \mathbb{R}^d \to \mathcal{F}\), then running standard PCA there — but without ever computing \(\phi\) explicitly. Only the pairwise inner products \(k(x_i, x_j) = \langle \phi(x_i), \phi(x_j) \rangle\) are needed, and those can be computed directly via the kernel function.

Analogy: Imagine two concentric rings of points lying on a flat table. You can't separate them with a straight cut on the table. But if you roll the table into a cylinder (a non-linear transformation), the inner ring ends up at a different height than the outer ring — and now a flat horizontal cut separates them perfectly. Kernel PCA performs exactly this kind of implicit "lifting" and then does standard PCA in the lifted space.

One-sentence summary: Kernel PCA replaces the sample covariance matrix with the kernel (Gram) matrix \(K_{ij} = k(x_i, x_j)\), centers it, then extracts the top eigenvectors as nonlinear principal components.

If You Remember One Thing

You never need to compute \(\phi(x)\) — only the kernel matrix \(K\). The kernel trick lets you do PCA in a potentially infinite-dimensional feature space using only \(n \times n\) matrix operations on your \(n\) data points.

2
How It Works Internally
▾

The Three-Step Algorithm

Step 1 — Build the Gram matrix. Compute the \(n \times n\) kernel matrix where entry \((i,j)\) is \(k(x_i, x_j)\). Popular choices: RBF/Gaussian \(k(x,y)=\exp(-\|x-y\|^2/(2\sigma^2))\), polynomial \(k(x,y)=(x^\top y + c)^p\), Laplacian.

Step 2 — Center in feature space. Standard PCA centers the data first. In feature space we can't do this explicitly, but we can center the Gram matrix:

$$\tilde{K} = K - \mathbf{1}_n K - K \mathbf{1}_n + \mathbf{1}_n K \mathbf{1}_n$$

where \(\mathbf{1}_n = \frac{1}{n}\mathbf{1}\mathbf{1}^\top\) is the \(n\times n\) matrix of \(1/n\). This subtracts the row mean, column mean, and adds back the grand mean — exactly what centering does.

Step 3 — Eigendecompose \(\tilde{K}\). Solve \(\tilde{K} \alpha = \lambda n \alpha\). The eigenvectors \(\alpha^{(l)}\) are the expansion coefficients of the \(l\)-th principal component in feature space. To project a training point \(x_i\) onto the \(l\)-th kernel-PC:

$$z_i^{(l)} = \sum_{j=1}^n \alpha_j^{(l)} k(x_j, x_i)$$

Normalize each \(\alpha^{(l)}\) so that \(\lambda_l (\alpha^{(l)})^\top \alpha^{(l)} = 1\).

Common Gotcha

Projecting a new point \(x^*\) requires centering its kernel vector using the training means: \(\tilde{k}_i^* = k(x_i, x^*) - \frac{1}{n}\sum_j k(x_j, x^*) - \frac{1}{n}\sum_j k(x_i, x_j) + \frac{1}{n^2}\sum_{j,l}k(x_j, x_l)\). Forgetting this centering correction is the #1 implementation mistake.

Kernel Selection Guide

  • RBF / Gaussian: \(k(x,y) = \exp(-\gamma\|x-y\|^2)\). Universal approximator — works for almost any smooth non-linearity. Bandwidth \(\gamma\) controls how local the comparison is. Default choice.
  • Polynomial: \(k(x,y) = (x^\top y + c)^p\). Natural for data with multiplicative feature interactions. Degree \(p\) controls the complexity of the implicit feature space.
  • Laplacian: \(k(x,y) = \exp(-\gamma\|x-y\|_1)\). More robust to outliers than RBF due to the L1 norm; less smooth.
  • Sigmoid: \(k(x,y) = \tanh(\alpha x^\top y + c)\). Mimics a two-layer neural network; not always positive semi-definite — use with care.
3
The Mathematical Derivation
▾

Let \(x_1,\ldots,x_n \in \mathbb{R}^d\) and let \(\phi: \mathbb{R}^d \to \mathcal{F}\) be the implicit feature map. Define the centered images \(\tilde{\phi}(x_i) = \phi(x_i) - \frac{1}{n}\sum_j \phi(x_j)\).

Standard PCA in \(\mathcal{F}\) seeks directions \(v \in \mathcal{F}\) maximizing variance. By the representer theorem, any solution lies in the span of the data:

$$v = \sum_{i=1}^n \alpha_i \tilde{\phi}(x_i)$$

The variance along \(v\) (with \(\|v\|=1\)) is:

$$\text{Var}(v) = \frac{1}{n}\sum_{i=1}^n \langle v, \tilde{\phi}(x_i)\rangle^2 = \frac{1}{n}\|\tilde{K}\alpha\|^2$$

Subject to \(\|v\|^2 = \alpha^\top \tilde{K} \alpha = 1\). Using a Lagrange multiplier, maximizing variance is equivalent to solving:

$$\tilde{K}\alpha = \lambda n \cdot \alpha$$

So the kernel-PCs are the eigenvectors of the centered Gram matrix \(\tilde{K}\), scaled by \(n\). The \(l\)-th principal component score for point \(x_i\) is:

$$z_i^{(l)} = \langle v^{(l)}, \tilde{\phi}(x_i)\rangle = \sum_{j=1}^n \alpha_j^{(l)} \tilde{k}(x_j, x_i)$$

Centering the Gram matrix explicitly: Define \(\mathbf{1}_n = \tfrac{1}{n}\mathbf{11}^\top\). Then:

$$\tilde{K} = (I - \mathbf{1}_n)\, K\, (I - \mathbf{1}_n)$$

This is equivalent to double-centering \(K\): subtract row means, subtract column means, add global mean.

Normalization Condition

The \(l\)-th eigenvector \(\alpha^{(l)}\) must satisfy \(\lambda_l \|\alpha^{(l)}\|^2 = 1\), so we normalize: \(\hat{\alpha}^{(l)} = \alpha^{(l)} / \sqrt{\lambda_l}\). This ensures the projection directions in \(\mathcal{F}\) have unit norm.

Warning — Reconstruction

Unlike linear PCA, Kernel PCA has no closed-form pre-image. Reconstructing the original space \(\mathbb{R}^d\) from kernel-PC coordinates requires solving a pre-image problem (e.g., gradient descent in input space), which is non-trivial and often approximate.

From-Scratch Implementation
▾

Complete Kernel PCA from scratch in NumPy. All math is explicit — no sklearn calls:

import numpy as np
def rbf_kernel(X, Y, gamma=1.0):
"""Gaussian / RBF kernel: k(x,y) = exp(-gamma * ||x-y||^2)"""
# Compute pairwise squared distances via broadcasting
sq_dists = np.sum(X**2, axis=1)[:,None] + np.sum(Y**2, axis=1)[None,:] - 2*X@Y.T
return np.exp(-gamma * sq_dists)
def center_kernel(K):
"""Double-center the Gram matrix: K_c = (I-1n)K(I-1n)"""
n = K.shape[0]
one_n = np.ones((n, n)) / n # n×n matrix of 1/n
return K - one_n @ K - K @ one_n + one_n @ K @ one_n
def kernel_pca(X, n_components=2, gamma=1.0):
n = X.shape[0]
K = rbf_kernel(X, X, gamma) # Step 1: build Gram matrix
K_c = center_kernel(K) # Step 2: center it
# Step 3: eigen-decompose
eigvals, eigvecs = np.linalg.eigh(K_c) # ascending order
idx = np.argsort(eigvals)[::-1] # sort descending
eigvals, eigvecs = eigvals[idx], eigvecs[:, idx]
# Normalize eigenvectors so ||v^l||=1 in feature space
alphas = eigvecs[:, :n_components] / np.sqrt(eigvals[:n_components])
# Project: Z = K_c @ alphas (n x n_components)
Z = K_c @ alphas
return Z, eigvals, alphas, K_c
def project_new(x_new, X_train, alphas, K_train_means,
K_grand_mean, gamma=1.0):
"""Project an unseen point — must apply the same centering."""
k_vec = rbf_kernel(x_new.reshape(1,-1), X_train, gamma).squeeze()
# Centering correction using training statistics
k_c = k_vec - K_train_means - k_vec.mean() + K_grand_mean
return k_c @ alphas
Production Usage (sklearn)

from sklearn.decomposition import KernelPCA
kpca = KernelPCA(n_components=2, kernel='rbf', gamma=1.0, fit_inverse_transform=True)
Z_train = kpca.fit_transform(X_train) # builds K, centers, eigendecomposes
Z_test = kpca.transform(X_test) # applies saved centering correction
X_approx = kpca.inverse_transform(Z_train) # pre-image (approximate)

Decision Rule

Use Kernel PCA when: data lies on a curved manifold, you need a linear-analysis-compatible representation, or downstream is a linear classifier. Use linear PCA when data is approximately Gaussian or n is very large. Use UMAP/t-SNE purely for visualization without downstream tasks.

Key Takeaways

  • The kernel trick allows PCA in infinite-dimensional feature spaces via only \(n \times n\) Gram matrix operations.
  • Centering the Gram matrix (double-centering) is not optional — it corresponds to mean-centering in feature space.
  • RBF kernel bandwidth \(\gamma\) is the most critical hyperparameter; cross-validate it.
  • Complexity is \(\mathcal{O}(n^3)\) (eigendecomposition of \(n\times n\) matrix); Nyström approximation reduces this to \(\mathcal{O}(nm^2)\) with \(m\) landmark points.
  • Related techniques: Spectral Embedding (Laplacian Eigenmaps) uses the graph Laplacian similarly; KPCA with the diffusion kernel recovers diffusion maps.
