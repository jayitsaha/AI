Quantile Loss (Pinball Loss)

An asymmetric loss that targets any quantile of the conditional distribution — the engine of prediction intervals.
Intermediate Classical ML · Evaluation Probabilistic Forecasting Asymmetric · τ-Quantile
1
Understanding the Concept
▲

What is this? When you predict a single number (like "tomorrow's sales will be 500 units"), you get a point estimate. But real decisions need ranges: "sales will be between 300 and 700." Quantile loss — also called pinball loss — is a special scoring rule that trains models to predict any specific percentile of the outcome, not just the average. Stack several quantile predictions together and you get a complete prediction interval.

Real-World Analogy. Imagine a judge scoring an archery contest where hitting too far left costs differently from hitting too far right. For a target at the 90th percentile (\(\tau = 0.9\)): missing by shooting too low costs 0.9 points per unit of miss, while shooting too high costs only 0.1 points per unit. To minimise your score, you naturally aim high — right at the 90th percentile of where arrows land. That asymmetric penalty is pinball loss.

💡 If You Remember One Thing

The pinball loss for quantile \(\tau\) penalises under-predictions by \(\tau\) and over-predictions by \(1-\tau\). The prediction that minimises expected pinball loss is exactly the \(\tau\)-quantile of the true distribution — provably, by calculus.

One-sentence summary. Pinball loss is an asymmetric absolute-error loss whose asymmetry ratio equals \(\tau\), making the optimal prediction the \(\tau\)-th conditional quantile rather than the conditional mean.

2
How It Works Internally
▲

The Piecewise Formula

Given a target value \(y\) and a model prediction \(\hat{y}\), the pinball loss for quantile level \(\tau \in (0,1)\) is:

$$L_\tau(y, \hat{y}) = \begin{cases} \tau\,(y - \hat{y}) & \text{if } y \geq \hat{y} \quad (\text{under-prediction}) \\ (1-\tau)\,(\hat{y} - y) & \text{if } y < \hat{y} \quad (\text{over-prediction}) \end{cases}$$

This can be written compactly using the check function (also called the tilted absolute value):

$$L_\tau(y, \hat{y}) = (y - \hat{y})\,\bigl[\tau - \mathbf{1}(y < \hat{y})\bigr]$$

where \(\mathbf{1}(\cdot)\) is the indicator function (1 if the condition holds, else 0).

What Each Branch Does — Numerically

Take \(\tau = 0.9\), true value \(y = 10\), and three predictions:

  • Perfect: \(\hat{y}=10\) → \(L_{0.9} = 0\)
  • Under by 3: \(\hat{y}=7\) → under-pred branch → \(0.9 \times (10-7) = 2.7\)
  • Over by 3: \(\hat{y}=13\) → over-pred branch → \(0.1 \times (13-10) = 0.3\)

The same 3-unit error costs 9× more when it's an under-prediction than an over-prediction. That asymmetry forces the learned prediction to sit at the 90th percentile.

Key Invariant

At the optimum, the fraction of training residuals where \(y > \hat{y}\) equals exactly \(\tau\). The model calibrates itself so \(\tau \times 100\)% of actuals lie above the prediction.

Prediction Intervals by Stacking Quantiles

Train two models with \(\tau = 0.05\) and \(\tau = 0.95\). Their predictions bound a 90% prediction interval. The interval need not be symmetric — the model learns the actual shape of the conditional distribution from data. This is conformal to the data, unlike parametric confidence intervals that assume normality.

⚠ Quantile Crossing

If quantile models are trained independently, the 90th-percentile prediction may occasionally be lower than the 10th-percentile prediction — a logical impossibility called quantile crossing. Fixes: joint training with non-crossing constraints (Chernozhukov et al.), isotonic regression post-processing, or conformal quantile regression.

3
The Math — Why It Works
▲

Optimality Proof: Why the Quantile is the Minimiser

Let \(F\) be the true CDF of \(Y\). We want the scalar prediction \(q\) minimising the expected pinball loss:

$$R(q) = \mathbb{E}\bigl[L_\tau(Y,q)\bigr] = \tau\int_q^{\infty}(y-q)\,dF(y) + (1-\tau)\int_{-\infty}^{q}(q-y)\,dF(y)$$

Differentiate with respect to \(q\) and set to zero:

$$\frac{dR}{dq} = -\tau\bigl(1-F(q)\bigr) + (1-\tau)\,F(q) = 0$$

Solving:

$$-\tau + \tau F(q) + (1-\tau)F(q) = 0 \implies F(q) = \tau$$

So \(q^* = F^{-1}(\tau)\), the \(\tau\)-quantile. QED. The gradient of the expected pinball loss is zero precisely when exactly a fraction \(\tau\) of probability mass lies below the prediction.

Gradient for SGD

The subgradient of \(L_\tau\) with respect to \(\hat{y}\) (the model output) is:

$$\frac{\partial L_\tau}{\partial \hat{y}} = \begin{cases} -\tau & \text{if } y > \hat{y} \\ 1-\tau & \text{if } y < \hat{y} \\ \text{undefined} & \text{if } y = \hat{y} \end{cases}$$

In practice the undefined case is measure-zero; libraries use 0 there. The gradient is a constant (unlike MSE's linear gradient), which means pinball loss is more robust to outliers — a 100× larger residual does not produce a 100× larger gradient update.

Connection to MAE

Setting \(\tau = 0.5\) gives symmetric weights \(0.5\) on both sides — identical to the Mean Absolute Error scaled by \(0.5\). This is consistent with the fact that MAE's minimiser is the median (50th percentile).

$$L_{0.5}(y,\hat{y}) = \tfrac{1}{2}\,|y - \hat{y}| \qquad \Longrightarrow \qquad q^* = \text{median}(Y)$$
∑ Check Function View

The loss \(\rho_\tau(u) = u(\tau - \mathbf{1}_{u<0})\) is called the check function or tilted \(L_1\). Quantile regression minimises \(\sum_i \rho_\tau(y_i - \mathbf{x}_i^\top \boldsymbol{\beta})\) over \(\boldsymbol{\beta}\), which can be solved by linear programming (Koenker & Bassett 1978).

Code Implementation
▲

From Scratch — NumPy

import numpy as np

def pinball_loss(y_true, y_pred, tau):
    """
    Compute pinball (quantile) loss.
    Args:
        y_true : array-like, shape (n,)  — observed values
        y_pred : array-like, shape (n,)  — predicted quantile values
        tau    : float in (0, 1)         — quantile level
    Returns:
        scalar mean pinball loss
    """
    y_true = np.asarray(y_true, dtype=float)
    y_pred = np.asarray(y_pred, dtype=float)
    residual = y_true - y_pred           # positive = under-prediction
    # tau weights the positive side; (1-tau) weights the negative side
    loss = np.where(residual >= 0,
                    tau * residual,
                    (1.0 - tau) * (-residual))
    return loss.mean()

# ── Numerical example ──
y      = np.array([10.0, 15.0, 8.0, 20.0, 12.0])
q_pred = np.array([12.0, 12.0, 12.0, 12.0, 12.0])  # constant prediction
for tau in [0.1, 0.5, 0.9]:
    print(f"  tau={tau:.1f}  loss={pinball_loss(y, q_pred, tau):.3f}")
# tau=0.1  loss=0.360   ← mostly over-predicting → heavy right penalty
# tau=0.5  loss=1.200   ← symmetric = MAE/2
# tau=0.9  loss=1.440   ← mostly under-predicting → heavy left penalty

Gradient for PyTorch Autograd

import torch

def pinball_loss_torch(y_true, y_pred, tau):
    """Differentiable pinball loss for gradient-based training."""
    residual = y_true - y_pred
    loss = torch.where(residual >= 0,
                       tau * residual,
                       (1.0 - tau) * (-residual))
    return loss.mean()

# ── Usage in training loop ──
model = MyQuantileModel()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
tau = 0.9   # train the 90th-percentile predictor

for X_batch, y_batch in dataloader:
    pred = model(X_batch).squeeze()
    loss = pinball_loss_torch(y_batch, pred, tau)
    optimizer.zero_grad()
    loss.backward()   # subgradient flows correctly through torch.where
    optimizer.step()

Production — sklearn & LightGBM

# sklearn QuantileRegressor (uses interior-point LP solver)
from sklearn.linear_model import QuantileRegressor
model = QuantileRegressor(quantile=0.9, alpha=0.0)   # alpha=L1 regulariser
model.fit(X_train, y_train)
q90 = model.predict(X_test)

# LightGBM (gradient-boosted quantile regression)
import lightgbm as lgb
params = {
    "objective": "quantile",
    "alpha": 0.9,           # alpha = tau in LightGBM's convention
    "n_estimators": 500,
    "learning_rate": 0.05,
}
gbm = lgb.LGBMRegressor(**params)
gbm.fit(X_train, y_train)
q90_gbm = gbm.predict(X_test)

# Build 80% prediction interval
q10 = lgb.LGBMRegressor(**{**params,"alpha":0.1}).fit(X_train,y_train).predict(X_test)
# Coverage check: should be ~80%
coverage = ((y_test >= q10) & (y_test <= q90_gbm)).mean()
print(f"Empirical coverage: {coverage:.1%}")   # target: 80%
⚠ Common Gotcha

Different libraries name the quantile level differently: quantile in sklearn, alpha in LightGBM, q in XGBoost. Always verify which parameter controls \(\tau\). Also, alpha in sklearn's QuantileRegressor is the L1 regularisation strength, not the quantile level.

Key Takeaways & When to Use
▲

When to Use Pinball Loss

  • You need a prediction interval, not just a point estimate.
  • Errors are asymmetric in cost (e.g., understocking vs overstocking inventory).
  • The outcome distribution is skewed or heavy-tailed — the mean is misleading.
  • Building risk-sensitive forecasts (energy demand, financial VaR).

✓ Decision Rule

Use MSE when the mean is the right target. Use MAE / τ=0.5 for robustness. Use pinball at τ ≠ 0.5 when the cost of under-prediction differs from over-prediction, or when you need calibrated prediction intervals. Use CRPS when you want to evaluate the full predictive distribution.
