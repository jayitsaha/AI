1
Understanding VCR
▼

What is it? Visual Commonsense Reasoning (VCR) is a benchmark and task family that asks a model not just to recognize what is in an image, but to explain why. Given an image and a question — with noun phrases grounded to specific detected regions, e.g. "why is person2 upset with person1?" — the model must pick the correct answer from 4 candidates (Q→A), and then pick the correct rationale that justifies that answer from 4 more candidates (QA→R).

Analogy: A detective doesn't just say "the butler did it." A good detective points at the muddy footprint, the broken lock, and the alibi that doesn't add up, and connects them into a story. Object detectors are like a rookie who lists everything in the room. VCR forces the model to be the detective — to ground its claim in specific visual evidence and chain that evidence into a plausible commonsense explanation.

💡 If you remember one thing

VCR is hard by design: distractor answers are recognition-plausible (they mention real objects in the scene) but commonsense-implausible. Getting the answer right for the wrong reason doesn't count — the model must also justify itself, which is why the holistic metric requires both \(Q\to A\) and \(QA \to R\) to be correct.

2
How VCR Works Internally
▼

Grounded Language: Tags, not just Words

Every question, answer, and rationale in VCR is written with explicit references to detected image regions — e.g. "person1" is not a free-floating noun phrase, it is literally tag [1] pointing at a bounding box produced by an object detector (classically Faster R-CNN / Mask R-CNN). This grounding is what lets a model connect a claim in language to actual pixels — "person1 is holding glass1" can be checked against the region features of both boxes.

Two Chained Tasks: Q→A and QA→R

VCR splits "explain what's happening" into two multiple-choice sub-problems. Q→A: given the question and 4 candidate answers, pick the correct one. QA→R: given the question plus the (now known) correct answer, pick the correct rationale from 4 candidates that best justifies it. The reference architecture (Zellers et al.'s R2C, "Recognition to Cognition Networks") processes each (query, response) pair — where query is Q or [Q;A], and response is a candidate A or R — through three stages: grounding (attend from text tokens to detected regions), contextualization (fuse grounded visual features with a language encoder over query and response), and reasoning (a bidirectional LSTM/attention module that pools everything into one plausibility score per candidate).

Design Decision: Why Two Separate Multiple-Choice Tasks Instead of One?

An alternative would be free-form answer generation, but that is hard to grade automatically and lets models get credit for vague, ungrounded guesses. Multiple-choice keeps evaluation exact, while chaining Q→A into QA→R forces the explanation to be checked independently — a model that answer-hacks (matches surface patterns without reasoning) is very unlikely to also rationale-hack, because the four rationale distractors are adversarially mined to be plausible-sounding but visually or logically wrong.

🔑 Key Property

VCR distractors are mined to defeat recognition-only shortcuts: every wrong answer/rationale mentions real, correctly-detected objects from the scene. The only way to reliably win is commonsense grounding — combining what is seen with what is plausible.

Why It Works — The Math
▼

Grounding Attention

Let \(v_1,\dots,v_M\) be region (RoI) feature vectors from the detector, and \(q_1,\dots,q_T\) be contextualized token embeddings of the query (question, or question+answer). Grounding computes, for each token \(t\), an attention distribution over the \(M\) regions:

$$\alpha_{t,i} = \frac{\exp\!\big(v_i^\top W\, q_t\big)}{\sum_{j=1}^{M}\exp\!\big(v_j^\top W\, q_t\big)} \qquad \tilde v_t = \sum_{i=1}^{M}\alpha_{t,i}\,v_i$$

\(\tilde v_t\) is the visually-grounded representation of token \(t\) — a soft pointer from language directly into pixel evidence.

Contextualization & Reasoning

The grounded vectors \(\tilde v_t\) are concatenated with the token embeddings and passed through a contextualizing encoder (BiLSTM or Transformer) to get \(h_Q\) (query) and \(h_{a_k}\) (candidate response \(k\)). A reasoning module — itself another BiLSTM with attention over \([h_Q; h_{a_k}]\) — pools these into a single scalar plausibility score:

$$s_k = \operatorname{MLP}\big([\,h_Q \,;\, h_{a_k} \,;\, \tilde v\,]\big)$$

Scoring the 4 Candidates

The four scores \(s_1,\dots,s_4\) (one per candidate answer, or per candidate rationale) are turned into a probability distribution with softmax, and trained with cross-entropy against the human-annotated correct index \(k^*\):

$$P(a_k \mid Q, I) = \frac{\exp(s_k)}{\sum_{k'=1}^{4}\exp(s_{k'})} \qquad \mathcal{L} = -\log P(a_{k^*} \mid Q, I)$$

The same scoring machinery is reused for QA→R, just with the query redefined as \([Q\,;\,\hat a]\) (question concatenated with the chosen answer) and candidates being the 4 rationales.

The Holistic Metric

$$\text{Acc}_{Q\to AR} \;=\; \frac{1}{N}\sum_{n=1}^{N} \mathbb{1}\!\left[\hat a_n = a_n^{*}\right]\cdot \mathbb{1}\!\left[\hat r_n = r_n^{*}\right]$$
⚠️ Common Pitfall

A high \(Q\to A\) accuracy alone is misleading. A model can pick the right answer via superficial language priors (e.g. "sad" answers are statistically likelier when a question contains "upset") while completely failing \(QA\to R\). Always report the joint \(Q\to AR\) score — it's what separates genuine grounded reasoning from pattern matching.

Key Takeaways
▼

When VCR-style grounded reasoning matters:

  • Any task where "what" is not enough and the system must justify "why" (accident/incident analysis, visual dialog, embodied agents explaining plans)
  • Evaluating whether a multimodal model is truly reasoning vs. exploiting language priors / dataset bias
  • Building interpretable VQA systems where the rationale doubles as an explanation for a human

Limitations to keep in mind:

  • Multiple-choice framing caps ambition — the model never has to generate a rationale from scratch
  • Region detectors bottleneck grounding quality; a missed or bad box propagates errors downstream
  • Large pretrained vision-language transformers (VisualBERT, LXMERT, UNITER, and later end-to-end ViT-based VLMs) now largely subsume the R2C-style pipeline, folding grounding, contextualization and reasoning into unified attention layers
💡 The Big Idea

VCR reframed "visual understanding" from labeling pixels to justifying inferences. The Q→A / QA→R split and adversarial distractor mining became a template later reused across visual entailment, visual dialog, and multimodal chain-of-thought benchmarks.

# Region features from a detector: [agitation, broken, gaze, holding]
regions = {
"person1": np.array([0.2, 0.1, 0.8, 0.9]),
"person2": np.array([0.9, 0.0, 0.9, 0.1]),
"glass1": np.array([0.0, 0.9, 0.0, 0.0]),
"bottle1": np.array([0.0, 0.1, 0.0, 0.0]),
"table1": np.array([0.0, 0.0, 0.0, 0.0]),
}
def cosine(a, b):
return a @ b / (np.linalg.norm(a) * np.linalg.norm(b) + 1e-9)
def ground(tags): # avg region feature = grounded evidence
return np.mean([regions[t] for t in tags], axis=0)
# Q -> A: score each candidate answer against its grounded evidence
def score_candidates(candidates):
s = np.array([cosine(ground(c["tags"]), c["claim"]) for c in candidates])
p = np.exp(s) / np.exp(s).sum() # softmax -> probability
return p
