1
Understanding Factor Analysis
▼

What is it? Factor Analysis (FA) is a statistical method that explains correlations among many observed variables (like test scores, survey answers, or gene expression levels) by positing that a small number of latent factors — hidden, unobservable quantities — drive all the observed variation. Each observed variable is assumed to be a weighted linear combination of these latent factors plus its own unique noise.

Analogy: Imagine you measure 20 student abilities: arithmetic, geometry, algebra, reading speed, vocabulary, grammar, spelling... You notice math scores are correlated with each other, and language scores are correlated with each other. Factor Analysis reveals the hidden drivers: "mathematical aptitude" and "verbal aptitude" — two latent factors that explain why groups of tests move together. You never directly observe these aptitudes, but FA recovers them from the pattern of correlations.

The generative model: For \(p\) observed variables \(\mathbf{x} \in \mathbb{R}^p\) and \(k\) latent factors \(\mathbf{f} \in \mathbb{R}^k\) (with \(k \ll p\)):

$$\mathbf{x} = \boldsymbol{\mu} + \Lambda \mathbf{f} + \boldsymbol{\varepsilon}$$

where \(\Lambda \in \mathbb{R}^{p \times k}\) is the factor loading matrix, \(\mathbf{f} \sim \mathcal{N}(\mathbf{0}, I_k)\) are the common factors, and \(\boldsymbol{\varepsilon} \sim \mathcal{N}(\mathbf{0}, \Psi)\) is unique noise with \(\Psi = \text{diag}(\psi_1, \ldots, \psi_p)\) diagonal.

💡 If you remember one thing

FA decomposes the covariance of observed variables as \(\Sigma = \Lambda\Lambda^\top + \Psi\), splitting variance into shared (common) variance explained by factors, and unique variance (\(\Psi\)) specific to each variable. PCA doesn't separate these — it mixes unique and common variance indiscriminately.

2
How Factor Analysis Works Internally
▼

The Covariance Decomposition

Under the FA model, the implied covariance of \(\mathbf{x}\) is:

$$\operatorname{Cov}(\mathbf{x}) = \Lambda \operatorname{Cov}(\mathbf{f}) \Lambda^\top + \Psi = \Lambda I_k \Lambda^\top + \Psi = \Lambda\Lambda^\top + \Psi$$

The \((i,j)\) entry of \(\Lambda\Lambda^\top\) equals \(\sum_{m=1}^k \lambda_{im}\lambda_{jm}\) — the correlation between variables \(i\) and \(j\) is explained entirely by their shared loadings on the \(k\) common factors. The diagonal of \(\Psi\) captures leftover per-variable noise.

Identification: The Rotation Problem

FA has a fundamental ambiguity: for any orthogonal matrix \(R\) (with \(RR^\top = I\)), the loading matrix \(\Lambda^* = \Lambda R\) produces the same covariance structure:

$$\Lambda^* (\Lambda^*)^\top = \Lambda R R^\top \Lambda^\top = \Lambda \Lambda^\top$$

This means infinitely many loading matrices fit the data equally well. Rotation is the technique for choosing a particular solution that maximizes interpretability. Varimax (orthogonal) maximizes the variance of squared loadings within each factor — pushing loadings toward 0 or ±1. Promax (oblique) allows correlated factors and often gives even cleaner structure when factors are naturally correlated.

Estimation: EM Algorithm

Maximum likelihood estimation for FA iterates the EM algorithm. In the E-step, compute the posterior expectation of the latent factors given data:

$$\mathbb{E}[\mathbf{f}_i \mid \mathbf{x}_i] = \Lambda^\top (\Lambda\Lambda^\top + \Psi)^{-1} (\mathbf{x}_i - \boldsymbol{\mu})$$

In the M-step, update \(\Lambda\) and \(\Psi\) to maximize the expected log-likelihood. This alternates until convergence (typically dozens of iterations).

🔑 Key Property: Communality vs Uniqueness

The communality of variable \(i\) is \(h_i^2 = \sum_{m=1}^k \lambda_{im}^2\) — the proportion of its variance explained by all common factors. The uniqueness is \(\psi_i = 1 - h_i^2\) (assuming standardized variables). High communality means the variable is well-explained by the factor structure; high uniqueness means it's mostly idiosyncratic.

FA vs PCA: The Critical Distinction

PCA finds directions of maximum total variance. It does not distinguish between variance shared among variables and unique per-variable noise. FA explicitly models this separation: \(\Sigma = \Lambda\Lambda^\top + \Psi\). The practical consequence: with substantial unique variance, PCA and FA can give very different loading patterns. FA is preferred when the goal is to uncover latent constructs; PCA when the goal is dimensionality reduction or compression.

⚠️ Common Misconception

Factor Analysis does not determine the number of factors \(k\) automatically. You must choose \(k\) via scree plots, parallel analysis, BIC/AIC, or domain theory. Choosing too few factors leaves shared variance unexplained; too many leads to Heywood cases (negative unique variances) or near-zero communalities.

3
The Math: Rotation Criteria
▼

Varimax Criterion (Kaiser, 1958)

Varimax finds an orthogonal rotation matrix \(R\) that maximizes the sum of variances of squared (normalized) loadings within each factor. Define normalized loadings \(\tilde{\lambda}_{im} = \lambda_{im} / h_i\). The varimax criterion is:

$$V = \sum_{m=1}^k \left[ \frac{1}{p} \sum_{i=1}^p \tilde{\lambda}_{im}^4 - \left(\frac{1}{p} \sum_{i=1}^p \tilde{\lambda}_{im}^2\right)^2 \right]$$

This is maximized iteratively by rotating pairs of factors (Jacobi rotations). Each pairwise rotation is a simple rotation by angle \(\theta\) applied to columns \(m\) and \(m'\) of \(\Lambda\), where \(\theta\) is chosen to maximize \(V\).

Promax Criterion (Hendrickson & White, 1964)

Promax first applies varimax to get orthogonal loadings \(\hat{\Lambda}\), then raises each loading to a power \(p\) (typically \(p = 3\)) — preserving sign but shrinking small loadings toward zero — and finds the oblique transformation that best approximates the powered matrix:

$$\min_{P} \| \hat{\Lambda} P - \hat{\Lambda}^{(3)} \|_F^2 \quad \text{subject to oblique } P$$

The result is factors that are allowed to correlate. The factor correlation matrix \(\Phi = (P^\top P)^{-1}$ reports inter-factor correlations.

Factor Scores

After fitting, each observation's factor scores — the estimated values of the latent factors — are computed via the regression method (Thomson, 1951):

$$\hat{\mathbf{f}}_i = \Lambda^\top \Sigma^{-1} (\mathbf{x}_i - \boldsymbol{\mu}) = \Lambda^\top (\Lambda\Lambda^\top + \Psi)^{-1} (\mathbf{x}_i - \boldsymbol{\mu})$$

This is identical to the E-step equation — factor scores are the posterior means of the latent factors. Note they are only estimates, not observed values.

FA vs PCA: When to Use Each
▼

Factor Analysis and PCA both reduce dimensions, but their goals and assumptions differ fundamentally:

Dimension Factor Analysis PCA
GoalExplain correlations via latent constructsMaximize explained total variance
Variance modeledShared (common) variance onlyAll variance (shared + unique + error)
Model\(\mathbf{x} = \Lambda\mathbf{f} + \boldsymbol{\varepsilon}\), \(\Psi\) diagonalRotation of axes, no noise model
Solution uniquenessRotation-indeterminate (need rotation)Unique (by variance ordering)
Components interpretable?Yes (after rotation, sparse loadings)Often not (dense, all variables load)
Factor correlationAllowed (oblique rotation)Orthogonal by definition
Typical usePsychometrics, survey scales, gene modulesCompression, visualization, preprocessing
Sklearn classFactorAnalysis()PCA()
🎯 Decision Rule

Use FA when you believe observed variables are caused by latent constructs and want to identify those constructs (e.g., intelligence testing, personality scales, topic modeling). Use PCA when you want to compress data into orthogonal directions that capture most variance, or when you have no prior belief in latent factors.

⚠️ Common Pitfall: Factor Naming

After rotation, researchers name factors based on which variables load highly — e.g., "Factor 1 = Verbal Intelligence." But factor names are interpretive labels, not statistical results. The same loadings can often support multiple narratives. Always report the actual loadings, not just the labels.

Key Takeaways & Code
▼

Summary

Factor Analysis assumes observed variables \(\mathbf{x} = \Lambda\mathbf{f} + \boldsymbol{\varepsilon}\) where \(\mathbf{f}\) are \(k\) latent factors and \(\boldsymbol{\varepsilon}\) is unique noise. It decomposes the covariance as \(\Sigma = \Lambda\Lambda^\top + \Psi\). Rotation (varimax/promax) resolves the identification ambiguity and produces sparse, interpretable loadings.

From-Scratch EM in NumPy

import numpy as np
from numpy.linalg import inv, svd
def factor_analysis_em(X, k, max_iter=500, tol=1e-6):
"""EM for Factor Analysis. X: (n, p) standardized data, k: n_factors."""
n, p = X.shape
# Init: Lambda from top-k PCA, Psi from residual variance
U, S, Vt = svd(X, full_matrices=False)
Lambda = Vt[:k].T * (S[:k] / np.sqrt(n)) # (p, k)
Psi = np.ones(p) # unique variances, diagonal of Psi
ll_prev = -np.inf
for _ in range(max_iter):
# E-step: compute posterior stats of f given x
Psi_inv = 1.0 / Psi # diagonal inverse
# beta = Lambda^T Sigma^{-1} via Woodbury: (I + Lambda^T Psi^-1 Lambda)^-1 Lambda^T Psi^-1
M = np.eye(k) + (Lambda.T * Psi_inv) @ Lambda # (k,k)
M_inv = inv(M)
beta = M_inv @ (Lambda.T * Psi_inv) # (k, p) factor score coefficients
Ezz = M_inv + (beta @ X.T) @ (X @ beta.T) / n # E[ff^T]
Ez = X @ beta.T # (n, k) = E[f | x] for each observation
# M-step: update Lambda and Psi
Lambda = (X.T @ Ez) @ inv(n * Ezz) # (p, k)
Psi = np.clip(np.diag(X.T @ X / n) - np.diag(Lambda @ (Ez.T @ X) / n), 1e-6, None)
return Lambda, Psi
