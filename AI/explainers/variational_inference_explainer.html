Understanding Variational Inference
▼

What is it? Variational Inference (VI) is a technique used to approximate intractable probability distributions, typically the posterior distribution \(p(z|x)\) of latent variables \(z\) given observed data \(x\). Instead of directly computing this complex posterior, VI posits a simpler, tractable *variational distribution* \(q(z)\) and then optimizes its parameters to make \(q(z)\) as close as possible to \(p(z|x)\).

Analogy: Imagine you're trying to perfectly illuminate a complex, irregularly shaped sculpture (the true posterior \(p(z|x)\)) in a dark room. You only have a simple flashlight with a fixed beam shape (your variational distribution \(q(z)\), e.g., a simple Gaussian) and you can only adjust its position and focus (optimize \(q\)'s parameters). You move the flashlight around until its beam best covers the sculpture, even if it can't perfectly match every nook and cranny. The goal is to find the best possible approximation given your flashlight's limitations.

💡 If you remember one thing

The core idea of VI is to transform a difficult integration problem (computing the posterior) into an easier optimization problem. We minimize the Kullback-Leibler (KL) divergence \(KL(q(z) || p(z|x))\) which is equivalent to maximizing the Evidence Lower Bound (ELBO), \(\mathcal{L}(q)\).

2
How Variational Inference Works Internally
▼

The Intractability Problem

In Bayesian modeling, we often want to compute the posterior distribution \(p(z|x) = \frac{p(x,z)}{p(x)}\), where \(p(x,z)\) is the joint probability of data and latents, and \(p(x) = \int p(x,z) dz\) is the model evidence (or marginal likelihood). For many interesting models, this integral \(p(x)\) is intractable, making \(p(z|x)\) impossible to compute directly.

The ELBO Objective

Instead of computing \(p(z|x)\) directly, VI introduces a family of simpler distributions \(q(z; \phi)\) (e.g., Gaussians), parametrized by \(\phi\). The goal is to find \(\phi^*\) such that \(q(z; \phi^*)\) is the best approximation to \(p(z|x)\). "Best" is defined by minimizing \(KL(q(z) || p(z|x))\). However, this KL divergence still depends on \(p(z|x)\) (specifically, on \(p(x)\)), so it's also intractable. The trick is to rewrite it:

$$\log p(x) = \mathcal{L}(q) + KL(q(z) || p(z|x))$$

where \(\mathcal{L}(q) = \mathbb{E}_{q(z)}[\log p(x,z)] - \mathbb{E}_{q(z)}[\log q(z)]\) is the ELBO. Since \(\log p(x)\) is a constant (for a given \(x\)) and \(KL(q(z) || p(z|x)) \ge 0\), maximizing the ELBO \(\mathcal{L}(q)\) is equivalent to minimizing the KL divergence. This is tractable because ELBO only requires expectations with respect to \(q(z)\), which we know how to compute.

Mean-Field Approximation

A common choice for \(q(z)\) is the mean-field approximation, where the latent variables \(z = \{z_1, \dots, z_M\}\) are assumed to be independent under \(q\): \(q(z) = \prod_{j=1}^M q_j(z_j)\). Each \(q_j(z_j)\) is typically chosen from a simple family (e.g., Gaussian). This simplifies the optimization problem significantly, often leading to coordinate ascent updates (CAVI) where each \(q_j(z_j)\) is updated in turn while holding others fixed.

Amortized Variational Inference

For large datasets, optimizing \(\phi\) for each data point \(x\) can be slow. Amortized VI addresses this by training an "inference network" \(q_\phi(z|x)\) (e.g., a neural network) that takes \(x\) as input and directly outputs the optimal parameters \(\phi\) for \(q(z)\). Once trained, this network can quickly infer the posterior approximation for new data points in a single forward pass, "amortizing" the cost of inference across many examples.

🔑 Key Property

ELBO can be seen as the expected log-likelihood \(\mathbb{E}_{q(z)}[\log p(x|z)]\) minus the KL divergence between \(q(z)\) and the prior \(p(z)\): \(\mathcal{L}(q) = \mathbb{E}_{q(z)}[\log p(x|z)] - KL(q(z) || p(z))\). This makes intuitive sense: maximize how well \(q\) explains the data, while keeping \(q\) close to the prior.

3
Why It Works — The Math Behind ELBO
▼

Deriving the Evidence Lower Bound (ELBO)

We start with the logarithm of the model evidence, \(\log p(x)\), which is difficult to compute due to the integral over latent variables. We introduce our variational distribution \(q(z)\) into the integral:

$$\log p(x) = \log \int p(x,z) dz = \log \int q(z) \frac{p(x,z)}{q(z)} dz$$

Now, we can apply Jensen's inequality, which states that for a concave function \(f\) (like \(\log\)), \(f(\mathbb{E}[X]) \ge \mathbb{E}[f(X)]\). Here, \(\mathbb{E}_{q(z)}[\cdot]\) is the expectation operator. Treating \(\frac{p(x,z)}{q(z)}\) as our random variable:

$$\log p(x) \ge \mathbb{E}_{q(z)}\left[\log \frac{p(x,z)}{q(z)}\right]$$

This lower bound is precisely the ELBO, \(\mathcal{L}(q)\). We can further decompose it:

$$\mathcal{L}(q) = \mathbb{E}_{q(z)}[\log p(x,z)] - \mathbb{E}_{q(z)}[\log q(z)]$$

This form shows that the ELBO is the expected log-joint probability minus the entropy of \(q(z)\). Maximizing this encourages \(q(z)\) to assign high probability to regions where \(p(x,z)\) is high, while also keeping \(q(z)\) "spread out" (high entropy) to explore the space.

Relationship to KL Divergence

The difference between the true log evidence and the ELBO is exactly the KL divergence between \(q(z)\) and the true posterior \(p(z|x)\):

$$\log p(x) - \mathcal{L}(q) = KL(q(z) || p(z|x))$$

Since \(KL(q(z) || p(z|x)) \ge 0\), it follows that \(\log p(x) \ge \mathcal{L}(q)\) (hence "Lower Bound"). Maximizing \(\mathcal{L}(q)\) therefore pushes \(q(z)\) closer to \(p(z|x)\) by minimizing their KL divergence. This is the fundamental mathematical justification for Variational Inference.

⚠️ Common Pitfall

The mean-field approximation assumes independence between latent variables. This means it cannot capture correlations in the true posterior. For example, if \(p(z_1, z_2|x)\) is a banana-shaped or highly correlated distribution, a mean-field Gaussian \(q(z_1)q(z_2)\) (which is always axis-aligned) will struggle to approximate it well, often underestimating variance or getting stuck in a single mode of a multimodal posterior.

Key Takeaways
▼

When to use Variational Inference:

  • When the true posterior distribution \(p(z|x)\) is intractable (e.g., due to complex likelihoods or priors).
  • When you need a fast approximation to the posterior, especially for large datasets (amortized VI).
  • In generative models (e.g., Variational Autoencoders - VAEs), where it provides a principled way to learn latent representations.
  • When you need uncertainty estimates in deep learning models (Bayesian Neural Networks).

When NOT to use:

  • When exact inference (e.g., conjugacy, simple integration) or accurate sampling (e.g., MCMC for small models) is feasible.
  • When the true posterior is highly multimodal and you need to capture all modes (mean-field can struggle and collapse to one mode).
  • When the true posterior has strong correlations that a mean-field approximation cannot capture, leading to underestimation of variance.
💡 Big Picture

Variational Inference is a cornerstone of modern probabilistic machine learning, enabling Bayesian methods to scale to complex models and large datasets where traditional MCMC methods would be too slow. While approximations like mean-field have limitations, more flexible \(q(z)\) families (e.g., normalizing flows) continue to push the boundaries of what VI can achieve.

import torch
import torch.nn as nn
import torch.optim as optim
# Define the Encoder (Inference Network) q_phi(z|x)
class Encoder(nn.Module):
def __init__(self, input_dim, latent_dim):
super().__init__()
self.fc1 = nn.Linear(input_dim, 256)
self.fc_mu = nn.Linear(256, latent_dim)
self.fc_logvar = nn.Linear(256, latent_dim)
def forward(self, x):
h = torch.relu(self.fc1(x))
mu = self.fc_mu(h)
logvar = self.fc_logvar(h)
return mu, logvar # Parameters for q(z|x) = N(z|mu, exp(logvar))
# Define the Decoder (Generative Model) p_theta(x|z)
class Decoder(nn.Module):
def __init__(self, latent_dim, output_dim):
super().__init__()
self.fc1 = nn.Linear(latent_dim, 256)
self.fc2 = nn.Linear(256, output_dim)
def forward(self, z):
h = torch.relu(self.fc1(z))
return torch.sigmoid(self.fc2(h)) # p(x|z) is Bernoulli for images
# VAE Loss (ELBO) - for a single data point x
def vae_loss(x, x_recon, mu, logvar):
# Reconstruction loss: E_q(z|x)[log p(x|z)]
recon_loss = nn.functional.binary_cross_entropy(x_recon, x, reduction='sum')
# KL Divergence: KL(q(z|x) || p(z)) where p(z) = N(0,1)
# -0.5 * sum(1 + logvar - mu^2 - exp(logvar))
kl_div = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
return recon_loss + kl_div # Maximize ELBO (minimize -ELBO)
