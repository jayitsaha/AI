Certified Robustness: Randomized Smoothing & Interval Bound Propagation

Mathematically provable guarantees against adversarial perturbations
Intermediate Deep Learning Robustness O(N_samples) or O(layers)
1
Understanding Certified Robustness
▼

What is it? Certified robustness provides a mathematical guarantee that a machine learning model's prediction for a given input will remain unchanged, even if that input is perturbed by any small amount within a specified region (e.g., an L2 or L_infinity ball). This goes beyond empirical robustness (which tests against specific attacks) by offering a provable guarantee for an entire perturbation set.

Why do we need it? Modern neural networks are vulnerable to "adversarial examples" — inputs crafted with tiny, imperceptible perturbations that cause the model to misclassify. These pose a serious threat in safety-critical applications like autonomous driving or medical diagnosis. Certified robustness aims to provide trust in these systems by proving that they are immune to such attacks within a defined boundary.

Analogy: Imagine a digital lock that recognizes your fingerprint. A standard lock might be robust to a few smudges (empirical robustness). A *certified robust* lock, however, guarantees that even if a small patch of your fingerprint (within a certain size and pattern deviation) is altered in *any* way, the lock will still correctly identify you. Randomized Smoothing (RS) is like having many noisy sensors and taking a majority vote. Interval Bound Propagation (IBP) is like precisely calculating the minimum and maximum possible values at each processing step to see if the final decision can ever flip.

💡 If you remember one thing

Randomized Smoothing (RS) provides probabilistic L2 certificates by classifying the mode of predictions over noisy inputs. Interval Bound Propagation (IBP) provides deterministic L_infinity certificates by tracking activation bounds through the network. Both aim to prove a model's prediction is stable within an adversarial region.

2
How It Works Internally
▼

Randomized Smoothing (RS)

RS (Cohen et al., 2019) works by taking a standard, non-robust base classifier \(f\) and "smoothing" its predictions. To classify an input \(x\):

  1. A fixed amount of Gaussian noise \(\delta \sim \mathcal{N}(0, \sigma^2 I)\) is added to the input: \(\tilde{x} = x + \delta\).
  2. The base classifier \(f\) predicts on this noisy input: \(f(\tilde{x})\).
  3. This process is repeated \(N\) times, and the final prediction of the *smoothed classifier* \(g(x)\) is the class that receives the majority vote.

The core idea is that if the original input \(x\) is correctly classified, and a small perturbation \(x'\) still lies mostly within the noisy region that \(x\) occupies, then \(x'\) will also likely be correctly classified by the majority vote. The certification provides an L2 radius \(R\) around \(x\) within which \(g(x')\) is guaranteed to be the same as \(g(x)\) with high probability. This radius depends on the noise level \(\sigma\) and the probabilities of the top two classes from the noisy samples.

Design Decision: Why L2 noise? Gaussian noise is mathematically convenient for deriving probabilistic bounds in L2 norms. Other noise distributions (e.g., uniform) can also be used, but Gaussian is standard for RS due to its analytical tractability and connection to L2 balls.

Interval Bound Propagation (IBP)

IBP (Gowal et al., 2019; Mirman et al., 2018) is a technique to provide *deterministic* certificates, typically for L_infinity perturbations. It works by propagating symbolic interval bounds through the network:

  1. Given an input \(x\) and an L_infinity perturbation radius \(\epsilon\), define the input interval \([L_0, U_0]\) such that for each pixel \(i\), \(x_i \in [x_i - \epsilon, x_i + \epsilon]\).
  2. For each layer in the neural network, propagate these lower and upper bounds. For example, a linear layer \(z = Wx + b\) maps input intervals \([L_i, U_i]\) to output intervals \([L_j^z, U_j^z]\). A ReLU activation \(y = \max(0, x)\) maps \([L_i, U_i]\) to \([\max(0, L_i), \max(0, U_i)]\).
  3. After propagating through all layers, the final layer outputs intervals \([L_c, U_c]\) for each class \(c\). If for a class \(c_A\), \(L_{c_A} > U_k\) for all other classes \(k \neq c_A\), then the model is deterministically certified to predict \(c_A\) for any perturbation within the \(\epsilon\)-ball.

IBP can be applied during training (adversarial training with IBP bounds) to make the network itself robust to these bounds, or as a post-hoc verification method.

Design Decision: Why L_infinity? L_infinity perturbations are often considered the "strongest" or most restrictive type of attack, as they allow individual pixel values to change independently up to \(\epsilon\). IBP is well-suited for L_infinity bounds because interval arithmetic naturally handles independent bounds on each dimension.

🔑 Key Property

The core trade-off is between the type of certificate (probabilistic L2 vs. deterministic L_infinity), computational cost (RS requires many forward passes, IBP involves complex symbolic propagation or specialized layers), and tightness of the resulting bounds.

3
Why It Works — The Math
▼

Randomized Smoothing: Probabilistic L2 Certificate

Let \(f\) be a base classifier and \(g\) be the smoothed classifier defined as \(g(x) = \operatorname{argmax}_c \mathbb{P}(f(x+\delta)=c)\) where \(\delta \sim \mathcal{N}(0, \sigma^2 I)\). The core theorem states:

If \(g(x) = c_A\) and \(\mathbb{P}(f(x+\delta)=c_A) \ge p_A\) and \(\mathbb{P}(f(x+\delta)=c_B) \le p_B\) for any \(c_B \neq c_A\), then for any \(x'\) such that \(\|x - x'\|_2 \le R\), we have \(g(x') = c_A\).

The certified radius \(R\) is given by:

$$R = \frac{\sigma}{2} \left( \Phi^{-1}(p_A) - \Phi^{-1}(p_B) \right)$$

Here, \(\Phi^{-1}\) is the inverse cumulative distribution function of the standard normal distribution. This means we need to estimate \(p_A\) (the probability of the top class) and \(p_B\) (the probability of the second-best class) by sampling many noisy versions of \(x\). The larger the gap between \(p_A\) and \(p_B\), the larger the certified radius \(R\).

Interval Bound Propagation: Deterministic L_infinity Certificate

IBP relies on propagating lower and upper bounds through each network operation. For an input \(x \in [L, U]\) (where the interval is element-wise for a box perturbation):

  1. Linear Layer: For \(z = Wx + b\), where \(x \in [L_x, U_x]\):
    $$L_z = W^+ L_x + W^- U_x + b \\ U_z = W^+ U_x + W^- L_x + b$$
    where \(W^+\) contains the positive elements of \(W\) and \(W^-\) contains the negative elements of \(W\).
  2. ReLU Activation: For \(y = \max(0, x)\), where \(x \in [L_x, U_x]\):
    $$L_y = \max(0, L_x) \\ U_y = \max(0, U_x)$$

By applying these rules layer by layer, we obtain the final output bounds \([L_c, U_c]\) for each class \(c\). If there exists a class \(c_A\) such that \(L_{c_A} > U_k\) for all \(k \neq c_A\), then the prediction for \(x\) is certified to be \(c_A\) within the \(\epsilon\)-L_infinity ball.

⚠️ Common Pitfall

IBP can suffer from bound looseness, especially in deep networks or with complex activations, leading to underestimation of robustness. The propagated intervals can become much wider than the true reachable set of activations. Randomized Smoothing, while providing probabilistic guarantees, requires a large number of samples to accurately estimate \(p_A\) and \(p_B\), making it computationally expensive during certification.

Key Takeaways
▼

When to use Randomized Smoothing:

  • When L2 robustness certificates are desired.
  • For large models where exact symbolic propagation (like IBP) is computationally intractable.
  • When you can afford many forward passes for sampling (e.g., during certification, not necessarily training).
  • It can turn *any* base classifier into a robust one, even if the base classifier itself isn't robustly trained.

When to use Interval Bound Propagation:

  • When deterministic L_infinity robustness certificates are critical.
  • For smaller or medium-sized networks where the overhead of interval arithmetic is manageable.
  • When you need to train a network to be robust *during* optimization (IBP can be incorporated into the loss function).
  • It provides tighter bounds than some other deterministic methods for shallow networks, but can loosen for deep ones.

General Considerations for Certified Robustness:

  • Computational Cost: Both methods are significantly more expensive than standard training and inference.
  • Certified Radius: The achieved certified radii are often small compared to the magnitude of real-world noise.
  • Trade-off with Accuracy: Robust models often exhibit a drop in clean accuracy compared to their non-robust counterparts.
💡 Big Picture

Certified robustness is a crucial step towards building trustworthy AI systems. Randomized Smoothing and Interval Bound Propagation represent two distinct but complementary approaches, each with its own strengths and limitations, pushing the frontier of provably secure machine learning.

▼
import torch
import numpy as np
from scipy.stats import norm
# --- Randomized Smoothing (Certification) ---
def certify_rs(x: torch.Tensor, model, sigma: float, num_samples: int, alpha: float = 0.001):
"""Certifies the robustness of a point x using Randomized Smoothing."""
counts = torch.zeros(model.num_classes, dtype=torch.int)
for _ in range(num_samples):
noise = torch.randn_like(x) * sigma
prediction = model(x + noise).argmax()
counts[prediction] += 1
(top1_count, top1_class) = counts.max(dim=0)
counts[top1_class] = -1 # Temporarily remove top1_class to find second best
(top2_count, _) = counts.max(dim=0)
# Lower bound for pA, upper bound for pB (using Clopper-Pearson or similar)
p_A_lower = top1_count / num_samples # Simplified for explainer
p_B_upper = top2_count / num_samples # Simplified for explainer
if p_A_lower > p_B_upper: # Check if a certificate can be issued
# Calculate certified radius R using inverse CDF of normal
# R = sigma/2 * (norm.ppf(p_A_lower) - norm.ppf(p_B_upper))
# Simplified formula when p_A_lower and p_B_upper are just counts/num_samples
R = sigma * (norm.ppf(p_A_lower) - norm.ppf(p_B_upper)) / 2
return top1_class, R
else:
return None, 0.0 # No certificate issued
# --- Interval Bound Propagation (Forward Pass) ---
def propagate_ibp(lower_bound: torch.Tensor, upper_bound: torch.Tensor, layer):
"""Propagates interval bounds through a single layer."""
if isinstance(layer, torch.nn.Linear):
# W+ * L + W- * U + b for lower bound
# W+ * U + W- * L + b for upper bound
pos_W = torch.clamp(layer.weight, min=0)
neg_W = torch.clamp(layer.weight, max=0)
new_lower = torch.matmul(lower_bound, pos_W.T) + torch.matmul(upper_bound, neg_W.T) + layer.bias
new_upper = torch.matmul(upper_bound, pos_W.T) + torch.matmul(lower_bound, neg_W.T) + layer.bias
return new_lower, new_upper
elif isinstance(layer, torch.nn.ReLU):
# max(0, L) for lower, max(0, U) for upper
return torch.clamp(lower_bound, min=0), torch.clamp(upper_bound, min=0)
else:
raise NotImplementedError("Layer type not supported for IBP")
