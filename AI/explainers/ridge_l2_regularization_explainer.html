Understanding Ridge Regression
▼

What is it? When you fit a linear model, the coefficients can blow up to huge values if your features are correlated or you have more features than data points. Ridge regression adds a penalty term that keeps the coefficients small by shrinking them toward zero — preventing overfitting while retaining all features.

Analogy: Imagine fitting a rubber band between data points. OLS lets the band stretch as tight as possible, which can create wild swings. Ridge adds a spring attached to the origin that constantly pulls the band back. The stronger the spring (larger \(\lambda\)), the more constrained the fit. You lose some training accuracy but gain generalization.

💡 If you remember one thing

Ridge adds \(\lambda \|\beta\|_2^2\) to the OLS loss and has a beautiful closed form: $$\hat{\beta}_{Ridge} = (X^\top X + \lambda I)^{-1} X^\top y$$ The \(\lambda I\) term "ridges" the diagonal of \(X^\top X\), making it invertible even when singular, and shrinks all coefficients toward zero as \(\lambda\) grows.

Key distinction from Lasso: Ridge (L2) shrinks all coefficients proportionally but never to exactly zero — it keeps all features but small. Lasso (L1) can zero out features entirely, doing selection. Ridge is preferred when all features are expected to contribute.

2
How Ridge Works Internally
▼

From OLS to Ridge: Adding the Penalty

OLS minimizes \(\|y - X\beta\|_2^2\). Ridge adds an L2 penalty:

$$\hat{\beta}_{Ridge} = \underset{\beta}{\operatorname{argmin}} \|y - X\beta\|_2^2 + \lambda\|\beta\|_2^2$$

Setting the gradient to zero gives the closed-form solution directly — no iterative optimization needed:

$$\hat{\beta}_{Ridge} = (X^\top X + \lambda I)^{-1} X^\top y$$

The SVD Perspective (Most Illuminating)

Let \(X = U D V^\top\) be the thin SVD where \(D = \operatorname{diag}(d_1, \ldots, d_p)\) holds singular values. The Ridge solution becomes:

$$\hat{\beta}_{Ridge} = V \operatorname{diag}\!\left(\frac{d_j}{d_j^2 + \lambda}\right) U^\top y$$

Compare to OLS: \(\hat{\beta}_{OLS} = V \operatorname{diag}(1/d_j) U^\top y\). Ridge replaces each \(1/d_j\) with \(d_j/(d_j^2+\lambda)\). This shrinkage factor \(d_j^2/(d_j^2+\lambda)\) is always \(\in (0,1)\) — Ridge shrinks each principal-direction coefficient by this factor.

🔑 SVD Shrinkage Factor

For singular value \(d_j\) and penalty \(\lambda\), the shrinkage factor is: \(\frac{d_j^2}{d_j^2 + \lambda}\). Small singular values (near-collinear directions) get shrunk the most. Large singular values (dominant directions) are barely affected. This is Ridge's key stability mechanism.

The Regularization Path

As \(\lambda\) sweeps from 0 to \(\infty\): at \(\lambda=0\), Ridge = OLS (no regularization); as \(\lambda \to \infty\), all \(\hat{\beta}_j \to 0\). The trace of coefficients vs. \(\lambda\) is the ridge path — a smooth, continuous shrinkage of all coefficients simultaneously.

⚠️ Common Pitfall

The intercept should NOT be penalized. In practice, center \(y\) and standardize \(X\) before applying Ridge, then recover the intercept as \(\hat{\beta}_0 = \bar{y} - \bar{X}^\top \hat{\beta}_{Ridge}\). Sklearn's Ridge handles this automatically with fit_intercept=True.

Why It Works — The Math
▼

Derivation of the Closed Form

Start with the penalized objective \(L(\beta) = \|y - X\beta\|_2^2 + \lambda\|\beta\|_2^2\). Expand:

$$L(\beta) = y^\top y - 2\beta^\top X^\top y + \beta^\top X^\top X \beta + \lambda \beta^\top \beta$$

Take the gradient with respect to \(\beta\) and set to zero:

$$\nabla_\beta L = -2X^\top y + 2X^\top X \beta + 2\lambda \beta = 0$$
$$(X^\top X + \lambda I)\hat{\beta} = X^\top y \implies \hat{\beta}_{Ridge} = (X^\top X + \lambda I)^{-1} X^\top y$$

The matrix \((X^\top X + \lambda I)\) is always positive definite for \(\lambda > 0\) even if \(X^\top X\) is singular — this is why Ridge solves the ill-conditioned case.

Bias-Variance Decomposition

Ridge trades unbiasedness for lower variance. The bias and variance are:

$$\operatorname{Bias}(\hat{\beta}_{Ridge}) = -\lambda (X^\top X + \lambda I)^{-1}\beta^*$$
$$\operatorname{Var}(\hat{\beta}_{Ridge}) = \sigma^2 (X^\top X + \lambda I)^{-1} X^\top X (X^\top X + \lambda I)^{-1}$$

As \(\lambda\) increases: bias grows (away from true \(\beta^*\)), variance shrinks. The optimal \(\lambda\) minimizes total MSE = bias² + variance. This is always found by cross-validation in practice.

Geometric View: Constrained Optimization

Ridge is equivalent to constrained OLS:

$$\min_\beta \|y - X\beta\|_2^2 \quad \text{subject to} \quad \|\beta\|_2^2 \le t$$

The OLS solution moves outward along contours; the L2 constraint set is a sphere. The Ridge solution is where the first OLS contour touches the sphere — always at a non-corner point, hence no exact zeros.

📐 Key Identity

Using SVD \(X = UDV^\top\): the fitted values \(\hat{y}_{Ridge} = X\hat{\beta}_{Ridge} = \sum_j \frac{d_j^2}{d_j^2+\lambda} u_j u_j^\top y\). Each principal component of \(y\) is shrunk by factor \(d_j^2/(d_j^2+\lambda)\). The effective degrees of freedom is \(\text{df}(\lambda) = \sum_j \frac{d_j^2}{d_j^2+\lambda}\), which decreases from \(p\) (at \(\lambda=0\)) to \(0\) (as \(\lambda\to\infty\)).

Key Takeaways & When to Use
▼

When to Use Ridge

Use Ridge when: you expect all features to contribute (no true sparsity), features are correlated (multicollinearity), or \(p \approx n\) or \(p > n\). The closed form is fast and exact — prefer it over Lasso when interpretability via selection isn't needed.

Avoid Ridge when: you need automatic feature selection (use Lasso), or you expect sparse true coefficients. Also avoid when features are on vastly different scales without standardization.

Comparison with Key Alternatives

OLS: Unbiased but high variance with correlated features; fails when \(p > n\).

Lasso (L1): Sparse solutions (exact zeros); not differentiable at 0; no closed form; better when true model is sparse.

Elastic Net: Combines L1+L2; best of both; handles correlated features while doing selection.

PCR (Principal Component Regression): Hard drops low-variance components; Ridge is smoother — it soft-shrinks all components proportional to \(d_j^2/(d_j^2+\lambda)\).

💡 Interview Anchor

Ridge solves multicollinearity by adding \(\lambda I\) to \(X^\top X\) before inverting — this condition number improvement is the numerical reason Ridge works. The SVD view makes this precise: Ridge shrinks along directions with small singular values (the multicollinear directions) the most.
