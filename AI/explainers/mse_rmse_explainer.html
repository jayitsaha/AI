Mean Squared Error (MSE) & RMSE
The canonical regression loss — squaring residuals, penalising outliers hard, and returning to interpretable units
Foundational Classical ML Evaluation Metrics Must Know
1
Understanding the Concept

What is this? When a model predicts a number (like a house price or tomorrow's temperature), it makes errors. MSE measures how bad those errors are by squaring each error and averaging them. RMSE just takes the square root so the answer is back in the original units.

Real-World Analogy

Imagine a dart player throwing at a bullseye. Each dart misses by some distance — that's the error. MSE is like measuring every miss, squaring it (so a 10 cm miss counts 100×, not 10×, versus a 1 cm miss), then averaging. RMSE converts that back so the answer is in centimetres again.

If You Remember One Thing

MSE squares residuals, so large errors hurt disproportionately — a single 10-unit miss contributes 100× the penalty of a 1-unit miss. RMSE simply takes the square root so the metric is interpretable in the same units as your target variable \(y\).

Formal definitions:

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2 \qquad \text{RMSE} = \sqrt{\text{MSE}}$$

where \(y_i\) is the true value, \(\hat{y}_i\) is the predicted value, and \(n\) is the number of samples.

The quadratic growth means the model is heavily penalised for large mistakes — which is often desirable (e.g., predicting load in a power grid, where a 10× error is catastrophically worse than a 1× error), but becomes problematic when your data contains genuine outliers.

Mathematical Identity

MSE decomposes cleanly: \(\text{MSE} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Noise}\). This bias-variance decomposition is why MSE is the natural loss for OLS regression — minimising MSE is equivalent to minimising squared bias plus variance simultaneously.

Why not absolute error (MAE)? |residual| is not differentiable at zero, making gradient-based optimisation harder. The squared function \(r^2\) is smooth everywhere and its gradient \(2r\) is linear — giving clean closed-form solutions (OLS) and stable gradient descent.

RMSE back in target units: MSE is in squared units (e.g., dollars²). That's uninterpretable. \(\sqrt{\text{MSE}}\) restores the original unit scale, making RMSE directly comparable to mean absolute error and to the spread of \(y\).

Common Trap

MSE and RMSE are scale-dependent. An MSE of 100 is excellent if \(y \in [0, 10000]\) but catastrophic if \(y \in [0, 5]\). Always normalise or compare relative to target variance: \(R^2 = 1 - \text{MSE}/\text{Var}(y)\).

Outlier Sensitivity Rule of Thumb

If one observation has error \(k\) times the typical error, it contributes \(k^2\) times as much to MSE but only \(k\) times as much to MAE. A single 10× outlier inflates MSE by 100×; it only inflates MAE by 10×.

Decision Guide

Use MSE/RMSE when: large errors are catastrophically worse than small ones; you need a differentiable, convex loss for gradient descent; outliers are genuine signal (not noise).
Use MAE when: the target has genuine outliers (e.g., income, clickthrough); you care about average absolute deviation; you want robustness.
Use Huber when: you want the best of both worlds with a tunable threshold \(\delta\).

4
Key Takeaways
  • MSE = average squared residual. Squaring makes it convex, differentiable, and analytically tractable (OLS has a closed-form solution).
  • RMSE = √MSE, restoring interpretability in the original unit of \(y\). Always report RMSE (not MSE) to stakeholders.
  • Quadratic penalty: a 10-unit error contributes 100× the penalty of a 1-unit error — MSE is sensitive to outliers by design.
  • Minimising MSE → predicting the conditional mean \(\mathbb{E}[y|x]\). Minimising MAE → conditional median.
  • Bias-variance: MSE = Bias² + Variance + Irreducible Noise — the canonical decomposition of generalisation error.
  • Scale-dependent: always normalise (e.g., use \(R^2\), MAPE, or normalised RMSE) before comparing across different targets.
