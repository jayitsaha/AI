Understanding Rate-Distortion Theory
▼

What is it? Every time you compress an image, stream a video, or save an audio file, a trade-off is made: smaller file (fewer bits) means lower quality. Rate-distortion theory, developed by Claude Shannon in 1959, answers the fundamental question: what is the minimum number of bits you must spend to keep the quality loss below a specified threshold?

Analogy: Imagine summarising a novel. If you write a one-word summary ("adventure"), you lose almost everything — high distortion, very few bits. A full copy is zero distortion but costs all the bits. Every intermediate length summary is a point on the rate-distortion curve. Shannon proved that no summariser — however brilliant — can break through this curve: it is a hard theoretical wall.

💡 If you remember one thing

The rate-distortion function \(R(D)\) is the minimum mutual information between source and reconstruction: $$R(D) = \min_{p(\hat{x}|x):\,\mathbb{E}[d(X,\hat{X})]\leq D} I(X;\hat{X})$$ For a Gaussian source \(X\sim\mathcal{N}(0,\sigma^2)\) with squared-error distortion: \(R(D) = \tfrac{1}{2}\log_2(\sigma^2/D)\) bits, \(0 \leq D \leq \sigma^2\).

Practical impact: JPEG, MP3, H.264, and modern neural codecs are all attempts to approach (but never beat) the Shannon limit. Rate-distortion theory also underpins the β-VAE, a cornerstone of modern generative modelling.

2
The Math — Derivation for a Gaussian Source
▼

Setup

Let \(X \sim \mathcal{N}(0, \sigma^2)\) be the source. A lossy compressor chooses a reconstruction \(\hat{X}\) subject to mean squared error (MSE) distortion: \(D = \mathbb{E}[(X-\hat{X})^2] \leq D_0\). The rate-distortion function is:

$$R(D) = \min_{p(\hat{x}|x):\,\mathbb{E}[(X-\hat{X})^2]\leq D} I(X;\hat{X})$$

Why Mutual Information = Bits?

Shannon's channel coding theorem says you need \(I(X;\hat{X})\) bits per sample to reliably transmit the index of the reconstruction. The optimisation finds the cheapest (minimum \(I\)) reconstruction channel that keeps MSE below \(D\).

Solving the Gaussian Case

For a Gaussian source, the optimal reconstruction is also Gaussian. Model: \(\hat{X} = X + N\) where \(N \sim \mathcal{N}(0, D)\) is independent noise (the "lossy channel"). Then:

$$I(X;\hat{X}) = h(\hat{X}) - h(\hat{X}|X) = \tfrac{1}{2}\log_2(2\pi e(\sigma^2 + D)) - \tfrac{1}{2}\log_2(2\pi e\,D)$$

Wait — that's the reverse channel. The correct formulation uses the fact that \(X = \hat{X} + N'\) (reconstruction adds noise of variance \(D\)). The entropy power inequality shows the Gaussian maximises \(h(X|\hat{X})\) for fixed \(\mathbb{E}[d]\), so:

$$I(X;\hat{X}) = h(X) - h(X|\hat{X}) = \tfrac{1}{2}\log_2(2\pi e\,\sigma^2) - \tfrac{1}{2}\log_2(2\pi e\,D) = \tfrac{1}{2}\log_2\!\left(\frac{\sigma^2}{D}\right)$$

This is achieved with equality when the reconstruction channel is Gaussian. For \(D \geq \sigma^2\), transmit nothing — predict the mean, achieving \(\mathbb{E}[X^2]=\sigma^2\) at zero rate. Hence:

$$\boxed{R(D) = \max\!\left(0,\; \tfrac{1}{2}\log_2\!\left(\frac{\sigma^2}{D}\right)\right)} \quad 0 \leq D \leq \sigma^2$$

🔑 Key Property: R(D) is Convex and Decreasing

The R-D function is always convex (the curve bends upward) and non-increasing. Convexity means: halving the distortion always costs more bits than halving it again (diminishing returns on quality). This holds for any source, not just Gaussian.

⚠️ Common Misconception

R(D) is not the performance of any specific codec — it is the Shannon limit. Practical codecs like JPEG or MP3 operate above the R-D curve (higher rate for the same distortion). Modern neural codecs are getting within 10-20% of the limit for natural images.

Connection to β-VAE and Neural Compression
▼

The β-VAE as a Lagrangian Relaxation

The rate-distortion problem $$\min_{p(\hat{x}|x)} I(X;\hat{X}) \quad \text{s.t.} \quad \mathbb{E}[d(X,\hat{X})] \leq D$$ has a Lagrangian dual: $$\mathcal{L}_\beta = \mathbb{E}[d(X,\hat{X})] + \beta \cdot I(X;\hat{X})$$

Minimising this for different \(\beta \geq 0\) traces the entire convex R-D curve. Now look at the β-VAE objective: $$\mathcal{L}_{\text{VAE}} = \underbrace{-\mathbb{E}_{q(z|x)}[\log p(x|z)]}_{\text{Distortion}} + \beta\, \underbrace{KL(q(z|x) \| p(z))}_{\text{Rate}}$$

This is exactly the Lagrangian! The KL divergence \(KL(q(z|x)\|p(z))\) upper-bounds the mutual information \(I(X;Z)\) (the rate), and the reconstruction term is the distortion. Hence:

$$\beta = 1 \text{ (standard VAE): balanced rate-distortion} \quad \beta > 1 \text{: high compression, more distortion}$$

💡 Why High β Causes Disentanglement

With high \(\beta\), the model is forced to use very few bits to represent the input. The most efficient Gaussian code uses independent latent dimensions each capturing a single factor of variation. This pressure toward efficient coding naturally produces disentangled representations (Higgins et al., 2017).

Code: Computing & Visualising R(D)
▼

From Scratch — Gaussian R-D Curve

import numpy as np
import matplotlib.pyplot as plt
def rd_gaussian(sigma2: float, D_vals: np.ndarray) -> np.ndarray:
"""Rate-distortion function for Gaussian source with MSE distortion.
R(D) = max(0, 0.5 * log2(sigma^2 / D)) for D in [0, sigma^2]
"""
# Clip: below 0 is undefined, above sigma^2 costs 0 bits
return np.maximum(0.0, 0.5 * np.log2(sigma2 / np.clip(D_vals, 1e-10, None)))
sigma2 = 1.0
D = np.linspace(0.005, sigma2, 500)
R = rd_gaussian(sigma2, D)
# Key operating points
for d in [0.01, 0.10, 0.25, 0.50, 1.00]:
r = rd_gaussian(sigma2, np.array([d]))[0]
print(f"D={d:.2f} R(D)={r:.4f} bits")
# D=0.01 R(D)=3.3219 bits
# D=0.25 R(D)=1.0000 bits ← exactly 1 bit at D=sigma²/4
# D=1.00 R(D)=0.0000 bits ← zero rate at max distortion

β-VAE R-D Operating Points

import torch, torch.nn as nn
class BetaVAE(nn.Module):
def __init__(self, latent_dim=16, beta=1.0):
super().__init__()
self.beta = beta # β trades rate vs distortion
# encoder, decoder: omitted for brevity
def elbo(self, x, x_hat, mu, log_var):
# Distortion: pixel-level reconstruction loss
recon = nn.functional.mse_loss(x_hat, x, reduction='sum')
# Rate: KL divergence = upper bound on I(X;Z)
kl = -0.5 * torch.sum(1 + log_var - mu**2 - log_var.exp())
# β scales the rate penalty ↔ operates on R-D curve
return recon + self.beta * kl
# beta=1: standard VAE (balanced)
# beta=4: compressed latents, blurrier reconstruction
# beta=0.5: high fidelity, less disentangled
⚠️ Gotcha: KL ≠ Exact Mutual Information

The KL term \(\mathbb{E}_{p(x)}[KL(q(z|x)\|p(z))]\) equals \(I(X;Z) + KL(q(z)\|p(z))\). It upper-bounds \(I(X;Z)\) only when \(q(z) \approx p(z)\). If the aggregate posterior \(q(z)\) deviates from the prior \(p(z)\), the KL overestimates the actual rate.

Key Takeaways & Related Topics
▼

Summary

Rate-distortion theory provides the theoretical floor for lossy compression. The R-D function \(R(D)\) is always convex and non-increasing. For a Gaussian source with MSE: \(R(D) = \frac{1}{2}\log_2(\sigma^2/D)\). No compressor — classical or neural — can achieve a rate below this curve for a given distortion.

🔑 When to Apply R-D Theory

Use when designing or evaluating codecs, neural compression, or generative models (β-VAE). Ask: "How far is my codec from the Shannon limit?" The gap is your engineering headroom. Do not use as a direct design algorithm — R-D is a lower bound, not a construction method.

Related Topics to Explore

Prerequisites: Shannon entropy, mutual information, channel capacity (Shannon's source coding theorem), Gaussian distribution properties, KL divergence.

Build on this with: Vector quantisation (VQ-VAE), neural image compression (BPG, WebP), β-VAE and disentanglement, information bottleneck principle, Kolmogorov complexity.
