Understanding Matrix Factorization
▼

What is it? Picture a giant spreadsheet: rows are users, columns are movies, cells are 1–5 star ratings. Almost every cell is empty — nobody has watched everything. Matrix factorization guesses the missing cells by assuming a small number of hidden "taste dimensions" (maybe "loves sci-fi," "prefers slow dramas") explain most of the pattern, so both users and items can be described by short vectors in that hidden space.

Analogy: Imagine describing every restaurant by how spicy, how expensive, and how fast-food-ish it is (3 numbers), and every diner by how much they like spicy, expensive, and fast food (3 matching numbers). A diner's predicted rating for a restaurant is just how well those two short lists line up — the dot product. You never listed every possible dish; you compressed both sides into a handful of coordinates.

💡 If you remember one thing

Every algorithm on this page solves one equation: approximate a sparse rating matrix \(R\) as the product of two skinny matrices, $$R \approx P\,Q^\top$$ where \(P\) holds one short vector per user and \(Q\) holds one short vector per item. SVD, ALS, SVD++ and NMF are just different ways to find \(P\) and \(Q\) — with different assumptions about missing data, constraints, and extra signal.

2
How the Family Works Internally
▼

SVD — the exact, complete-matrix baseline

Singular Value Decomposition factors ANY complete matrix as \(M = U\Sigma V^\top\), where the singular values in \(\Sigma\) are sorted by how much variance each hidden dimension explains. Keeping only the top \(k\) singular values/vectors gives the mathematically best possible rank-\(k\) approximation of \(M\) (Eckart–Young theorem). The catch: SVD needs every cell filled in — real rating matrices are 95%+ empty, so classic SVD can't be applied directly.

ALS — Alternating Least Squares

ALS only ever looks at the ratings that actually exist. It alternates: freeze the item vectors \(Q\) and solve for the best user vectors \(P\) (a plain ridge regression per user, closed-form), then freeze \(P\) and solve for \(Q\) the same way. Each half-step is a convex least-squares problem with an exact solution — no gradient descent, no learning rate to tune — and it naturally ignores missing entries because they simply never enter the sum.

SVD++ — adding implicit feedback

Even the fact that a user rated an item at all (regardless of the score) is informative. SVD++ adds a second set of "implicit" item vectors \(y_j\) and folds them into the user representation: a user is described not just by their own learned vector but by the average of the implicit vectors of everything they've touched.

NMF — Non-negative Matrix Factorization

NMF keeps the same \(R \approx WH\) structure but forces every entry of \(W\) and \(H\) to be \(\ge 0\). Ratings, word counts, and pixel intensities are naturally non-negative, and this constraint produces "parts-based" factors — you can only ADD hidden components together, never cancel one out with a negative one — which is often more interpretable than SVD's signed factors.

🔑 Key Property

All four methods minimize essentially the same reconstruction error \(\sum (r_{ij} - \hat r_{ij})^2\). What differs is which entries count (all vs. observed-only), what constraints apply to the factors (none vs. non-negative), and what extra signal is folded in (explicit ratings only vs. + implicit interactions).

3
Why It Works — The Math
▼

ALS objective and closed-form update

ALS minimizes a regularized sum over only the OBSERVED index set \(\Omega\):

$$\min_{P,Q}\; \sum_{(i,j)\in\Omega}\big(r_{ij} - p_i^\top q_j\big)^2 \;+\; \lambda\Big(\sum_i \lVert p_i\rVert^2 + \sum_j \lVert q_j\rVert^2\Big)$$

This is non-convex jointly in \((P,Q)\), but holding \(Q\) fixed makes it convex and separable per user. Taking the gradient with respect to \(p_i\) and setting it to zero gives a ridge-regression normal equation:

$$p_i = \Big(\sum_{j \in \Omega_i} q_j q_j^\top + \lambda I\Big)^{-1} \sum_{j\in\Omega_i} r_{ij}\,q_j$$

where \(\Omega_i\) is the set of items user \(i\) rated. The symmetric update solves for every \(q_j\) with \(P\) fixed. Alternating between these two exact solves is guaranteed to never increase the regularized objective.

SVD++ prediction rule

$$\hat r_{ij} = \mu + b_i + b_j + q_j^\top\Big(p_i + |N(i)|^{-1/2}\!\!\sum_{k\in N(i)} y_k\Big)$$

\(N(i)\) is the set of items user \(i\) has interacted with at all (rated or not), \(\mu\) is the global mean rating, and \(b_i, b_j\) are learned user/item bias terms. The \(|N(i)|^{-1/2}\) normalizer keeps the implicit sum on a comparable scale regardless of how many items a user has touched.

NMF multiplicative updates

Because \(W,H \ge 0\) is a constraint rather than a penalty, NMF cannot use the ALS closed form directly (it could produce negative entries). Instead it uses multiplicative updates that provably never decrease non-negativity and provably never increase reconstruction error:

$$H \leftarrow H \odot \frac{W^\top R}{W^\top W H} \qquad\qquad W \leftarrow W \odot \frac{R H^\top}{W H H^\top}$$
⚠️ Common Pitfall

ALS is convex in EACH block but not jointly — different random initializations can converge to different local optima. It's also silent about brand-new users/items with zero observed ratings (the "cold-start" problem): with no rows in \(\Omega_i\), the ridge solve just returns \(p_i = 0\).

Key Takeaways
▼

When to use which:

  • SVD — dense, complete matrices (images, complete surveys); need the mathematically optimal low-rank approximation
  • ALS — sparse recommender data at scale; embarrassingly parallel across users/items, industry default (Spark MLlib, early Netflix Prize solutions)
  • SVD++ — implicit signals (views, clicks, add-to-cart) are available alongside explicit ratings and cold-start matters
  • NMF — interpretability matters (topic modeling, image parts, gene expression) and the data is naturally non-negative

When NOT to use matrix factorization at all:

  • Brand-new users/items with zero interactions — need content-based or hybrid methods instead
  • Ratings depend heavily on context (time of day, device, session) — factorization treats each user/item as static
  • Extremely large catalogs where even \(k\) small dot products per candidate are too slow — approximate nearest-neighbor retrieval is layered on top in practice
💡 Hierarchy

All four share one skeleton, \(R \approx P Q^\top\). SVD solves it exactly but needs a complete matrix. ALS relaxes that to handle sparsity. SVD++ extends ALS's objective with implicit feedback terms. NMF adds a non-negativity constraint on top of the same skeleton. They are variations on one idea, not four unrelated algorithms.
