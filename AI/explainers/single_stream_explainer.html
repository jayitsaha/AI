Concatenate image and text tokens into ONE shared self-attention stack — VisualBERT / UNITER-style early fusion

1
Understanding Single-Stream Fusion
▼

What is it? Imagine you have a photo and a caption. A "single-stream" vision-language model like VisualBERT or UNITER doesn't process the picture and the sentence separately and then combine them later — it throws every image piece (region/patch tokens) and every word (text tokens) into one long sequence and feeds that whole sequence through one Transformer stack. There is no dedicated "image branch" or "text branch" — just one shared self-attention mechanism that sees everything at once.

Analogy: Picture a single roundtable meeting where photographers and writers sit together, mixed in one row, instead of two separate rooms (image room, text room) that occasionally send messages to each other. Every seat can freely turn and listen to any other seat, whether it holds a picture piece or a word. Nothing is off-limits — that's early, unrestricted fusion.

💡 If you remember one thing

Single-stream models concatenate visual tokens and text tokens into one sequence \(H^0 = [e_{CLS}; e_{img,1..N_i}; e_{SEP}; e_{txt,1..N_t}; e_{SEP}]\) and run it through a single, shared multi-head self-attention Transformer — cross-modal attention isn't a special module, it just falls out of ordinary self-attention over the joint sequence.

2
How It Works Internally
▼

From Pixels and Words to One Sequence

An object detector (e.g. Faster R-CNN, frozen) proposes \(N_i\) image regions and outputs a pooled feature vector per region (e.g. 2048-d). A tokenizer (e.g. WordPiece) splits the caption into \(N_t\) sub-word tokens. Each of these — region features AND word tokens — is projected into the same model dimension \(d\) and given three additive embeddings: a content embedding (region feature / word embedding), a position embedding (spatial box coordinates for regions, sequence index for words), and a segment / modality-type embedding (0 = image, 1 = text) so the model can still tell which side a token came from even after concatenation.

$$H^0 = \big[\, e_{CLS},\; e_{r_1},\dots,e_{r_{N_i}},\; e_{SEP},\; e_{w_1},\dots,e_{w_{N_t}},\; e_{SEP} \,\big] \in \mathbb{R}^{N\times d}, \quad N = N_i+N_t+3$$

One Shared Self-Attention Stack

All \(N\) tokens — image and text mixed — are stacked into a single matrix and pushed through \(L\) identical Transformer layers. Each layer computes ONE set of query/key/value projections \(Q=H W_Q,\ K=H W_K,\ V=H W_V\) shared across the entire sequence, then full (unmasked) self-attention: every token attends to every other token, image-to-image, text-to-text, AND image-to-text, all with the exact same softmax mechanism. There is no separate cross-attention block — grounding between "the word dog" and "the region containing the dog" emerges implicitly, purely because both tokens live in the same attention matrix.

Design Decision: Why Concatenate Instead of Two Towers?

The alternative — dual-stream models (ViLBERT, LXMERT) — process image and text in separate Transformer towers first, then bolt on explicit cross-attention layers to exchange information. Single-stream skips that architectural split entirely: fewer unique parameter groups, deeper cross-modal mixing per layer, and a simpler implementation (it's "just BERT" with extra visual tokens). The cost is that the model can't easily allocate different capacity/depth to each modality, and the joint attention is \(O(N^2)\) over the combined length rather than smaller per-modality attentions plus lighter cross-attention.

🔑 Key Property

In single-stream fusion, cross-modal interaction is not a distinct module — it is a byproduct of ordinary self-attention applied to a sequence that happens to contain two modalities. Modality-type embeddings are the ONLY thing that distinguishes an image token from a text token inside the attention computation.

3
Why It Works — The Math
▼

Scaled Dot-Product Self-Attention Over the Joint Sequence

For the joint hidden states \(H \in \mathbb{R}^{N\times d}\), one attention head computes:

$$Q = HW_Q,\quad K = HW_K,\quad V = HW_V, \qquad \operatorname{Attn}(Q,K,V) = \operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

The crucial point: the softmax runs over all \(N\) columns at once. For a text query \(q_i\) (say the word "dog") and an image key \(k_j\) (say the region containing a dog), the weight is:

$$a_{ij} = \frac{\exp(q_i\cdot k_j/\sqrt{d_k})}{\sum_{m=1}^{N}\exp(q_i\cdot k_m/\sqrt{d_k})}$$

Nothing in this formula treats image keys differently from text keys — grounding (word attending to the matching region) is learned purely from data through ordinary backpropagation on this single softmax, with no modality-specific parameters in the attention itself.

Stacking Layers

Multi-head attention runs \(h\) heads in parallel (each with its own \(W_Q,W_K,W_V \in \mathbb{R}^{d\times d/h}\)), concatenates outputs, and applies a feed-forward network with residual connections and LayerNorm:

$$H^{(l+1)} = \operatorname{LN}\big(H^{(l)} + \operatorname{MHA}(H^{(l)})\big), \qquad H^{(l+1)} = \operatorname{LN}\big(H^{(l+1)} + \operatorname{FFN}(H^{(l+1)})\big)$$

Because the same \(H^{(l)}\) contains both modalities, each layer re-mixes image and text representations together — by layer \(L\), a text token's representation can depend on visual evidence several "hops" away, and vice versa.

Complexity

Self-attention over the joint sequence costs \(O(N^2 d)\) where \(N = N_i + N_t + 3\). Compare this to dual-stream: \(O(N_i^2 d) + O(N_t^2 d) + O(N_iN_t d)\) for a comparable amount of cross-attention — asymptotically similar, but single-stream pays the full \(N^2\) cost at every layer since fusion is not decoupled from within-modality processing.

⚠️ Common Pitfall

Modality-type embeddings are additive, not a masking mechanism. If you forget to add them (or initialize them to zero), the model literally cannot tell an image token from a text token from position alone once several self-attention layers have mixed everything together — a subtle bug that silently degrades grounding without throwing any error.

Key Takeaways
▼

When single-stream shines:

  • Tasks needing fine-grained word-region grounding (VQA, referring expressions, NLVR2)
  • When you want a minimal architecture — essentially BERT + visual tokens, easy to pretrain with masked-language / masked-region / image-text-matching objectives
  • Moderate sequence lengths, where paying full \(O(N^2)\) joint attention every layer is affordable

When to prefer dual-stream / contrastive instead:

  • Large-scale retrieval where you need independently-cacheable image/text embeddings (→ CLIP-style dual encoders)
  • Very long modality-specific inputs (long documents + many regions) where per-modality depth control matters (→ ViLBERT, LXMERT)
  • Latency-critical serving where separating towers lets you pre-compute one side offline

💡 One-line summary

Single-stream = "throw everything into one Transformer and let self-attention figure out the cross-modal relationships" — simple, deep fusion, at the price of quadratic cost over the combined sequence.

Code Trace

# 1. Extract region features (frozen Faster R-CNN) & tokenize text
region_feats = faster_rcnn(image) # (Ni, 2048)
region_boxes = detector.boxes(image) # (Ni, 4)
tokens = tokenizer(caption) # ['[CLS]','a','dog','runs','[SEP]']
# 2. Project + position + modality-type embeddings
img_embed = Linear(2048, d)(region_feats) + pos_embed(region_boxes) + seg_embed(IMG=0)
txt_embed = word_embed(tokens) + pos_embed(range(Nt)) + seg_embed(TXT=1)
# 3. Concatenate into ONE joint sequence
H0 = concat([cls_embed, img_embed, sep_embed, txt_embed, sep_embed], dim=0) # (N, d)
# 4. Shared multi-head self-attention over the FULL sequence, L layers
H = H0
for l in range(L):
Q, K, V = H @ Wq, H @ Wk, H @ Wv # one weight set, no modality split
A = softmax(Q @ K.T / sqrt(d_head)) # cross-modal attention included, unmasked
H = layer_norm(H + A @ V)
H = layer_norm(H + ffn(H))
# 5. Pooled [CLS] -> joint multimodal representation
joint_repr = H[0] # used for VQA head / ITM head / etc.
