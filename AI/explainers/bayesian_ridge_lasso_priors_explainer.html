Bayesian Interpretation: Ridge = Gaussian Prior, Lasso = Laplace Prior

MAP estimation as penalized MLE — how prior shape determines the penalty term
Intermediate Classical ML · Regression Part III · Section 9.2
1
Understanding the Concept
▾

You've probably heard that Ridge regression adds an L2 penalty and Lasso adds an L1 penalty to the loss function. But why those specific penalties? Bayesian statistics gives the answer: they're not arbitrary — they arise naturally from different beliefs about the size of the model coefficients before seeing any data.

In Bayesian regression, you combine two things: the likelihood (how well the model fits the data) and the prior (what you believed about the parameters before seeing data). The MAP (Maximum A Posteriori) estimate is the parameter value that maximises the product of likelihood and prior. Taking the negative log turns this multiplication into addition — and the negative log of the prior becomes your regularisation penalty.

Key Concept

MAP = penalized MLE. MAP estimation is equivalent to Maximum Likelihood Estimation (MLE) with an added regularisation term. The shape of the prior determines the shape of the penalty:

Gaussian prior \(\beta_j \sim \mathcal{N}(0, \tau^2)\) → \(-\log p(\beta) \propto \beta^2\) → Ridge (L2) penalty

Laplace prior \(\beta_j \sim \text{Laplace}(0, b)\) → \(-\log p(\beta) \propto |\beta|\) → Lasso (L1) penalty

Real-world analogy. Imagine you're guessing a student's exam score before seeing any data. A Gaussian prior says: "I think the score is probably near zero, and I assign exponentially less belief to scores further away — symmetrically and smoothly." A Laplace prior says: "I think it's most likely exactly zero, with a sharp peak there." The Laplace prior's sharp spike at zero is why it produces sparse estimates (exact zeros), while the Gaussian prior's smooth shape produces smooth shrinkage toward zero.

💡 If you remember one thing

The Laplace prior has a non-differentiable sharp peak at zero. This kink is precisely why Lasso produces exact zeros: the subdifferential of \(|\beta|\) at \(\beta=0\) includes 0, so the MAP solution is pinned there when the likelihood gradient is small enough.

The Math: From Prior to Penalty
▾

Setup: Bayesian Linear Regression

Assume the linear model \(y = X\beta + \varepsilon\) with \(\varepsilon \sim \mathcal{N}(0, \sigma^2 I)\). The likelihood for \(n\) observations is:

$$p(y \mid \beta) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(y_i - x_i^\top \beta)^2}{2\sigma^2}\right)$$

The negative log-likelihood (up to constants) is the familiar MSE loss:

$$-\log p(y \mid \beta) \propto \frac{1}{2\sigma^2} \|y - X\beta\|_2^2$$

Ridge: Gaussian Prior

Place an independent Gaussian prior on each coefficient: \(\beta_j \sim \mathcal{N}(0, \tau^2)\). The joint prior is:

$$p(\beta) = \prod_{j=1}^p \frac{1}{\sqrt{2\pi\tau^2}} \exp\!\left(-\frac{\beta_j^2}{2\tau^2}\right)$$

Taking the negative log:

$$-\log p(\beta) = \frac{p}{2}\log(2\pi\tau^2) + \frac{1}{2\tau^2}\sum_{j=1}^p \beta_j^2 = \text{const} + \frac{1}{2\tau^2}\|\beta\|_2^2$$

The MAP objective \(-\log p(\beta \mid y) = -\log p(y \mid \beta) - \log p(\beta)\) becomes:

$$\hat{\beta}_{\text{Ridge}} = \underset{\beta}{\operatorname{argmin}} \; \|y - X\beta\|_2^2 + \lambda\|\beta\|_2^2, \quad \lambda = \frac{\sigma^2}{\tau^2}$$

The closed-form solution is \(\hat{\beta}_{\text{Ridge}} = (X^\top X + \lambda I)^{-1} X^\top y\). The posterior is Gaussian:

$$p(\beta \mid y) = \mathcal{N}\!\left(\hat{\beta}_{\text{Ridge}},\; \sigma^2(X^\top X + \lambda I)^{-1}\right)$$

Lasso: Laplace Prior

Place an independent Laplace prior: \(\beta_j \sim \text{Laplace}(0, b)\). The density is:

$$p(\beta_j) = \frac{1}{2b}\exp\!\left(-\frac{|\beta_j|}{b}\right)$$

Taking the negative log:

$$-\log p(\beta) = p\log(2b) + \frac{1}{b}\sum_{j=1}^p |\beta_j| = \text{const} + \frac{1}{b}\|\beta\|_1$$

The MAP objective becomes:

$$\hat{\beta}_{\text{Lasso}} = \underset{\beta}{\operatorname{argmin}} \; \|y - X\beta\|_2^2 + \lambda\|\beta\|_1, \quad \lambda = \frac{2\sigma^2}{b}$$

For a single predictor \((X^\top X = 1)\), the MAP solution is the soft-thresholding operator:

$$\hat{\beta}_{\text{Lasso}} = \operatorname{sign}(\hat{\beta}_{\text{OLS}}) \cdot \max\!\left(|\hat{\beta}_{\text{OLS}}| - \frac{\lambda}{2}, \; 0\right)$$
⚠️ Common Misconception

MAP is not full Bayesian inference — it gives a point estimate, not a posterior distribution. For Ridge, the full posterior is tractable (it's Gaussian). For Lasso, the posterior with a Laplace prior has no simple closed form — Lasso gives the MAP but not the full posterior uncertainty.

Numerical Trace (y = 2.0, σ² = 1.0, τ² = 1.0, b = 1.0)

For a single coefficient with OLS estimate \(\hat{\beta}_{\text{OLS}} = y = 2.0\):

Ridge MAP: \(\hat{\beta} = y \cdot \tau^2 / (\sigma^2 + \tau^2) = 2.0 \times 1.0 / (1.0 + 1.0) = 1.0\)

Lasso MAP: \(\hat{\beta} = \max(|y| - \sigma^2/b, 0) = \max(2.0 - 1.0, 0) = 1.0\)

Both shrink the OLS estimate of 2.0 down to 1.0, but via different mechanisms. With a smaller OLS estimate (e.g., y = 0.8, b = 0.5): Lasso gives \(\max(0.8 - 2.0, 0) = 0\) — exact zero! Ridge gives \(0.8 \times 1.0 / (1.0 + 1.0) = 0.4\) — always nonzero.

3
Why the Prior Shape Determines Sparsity
▾

The Geometry of Sparsity

The MAP estimate is a compromise between where the likelihood peaks (the OLS estimate) and where the prior is concentrated. The shape of the prior's density at \(\beta = 0\) is everything:

Key Insight: Differentiability at Zero

Gaussian prior: \(-\log p(\beta) = \frac{\beta^2}{2\tau^2}\) is smooth and differentiable at \(\beta = 0\). The gradient is exactly 0 at \(\beta = 0\), so the prior weakly pulls toward zero but never pins exactly there unless the data perfectly cancels.

Laplace prior: \(-\log p(\beta) = \frac{|\beta|}{b}\) is non-differentiable at \(\beta = 0\) — it has a kink. The subdifferential is the interval \([-1/b, 1/b]\). The KKT conditions for optimality are satisfied at \(\beta = 0\) whenever the likelihood gradient is small enough, giving exact zeros.

Penalty Function Comparison

Minimize the objective \(f(\beta) = \text{loss}(\beta) + \text{penalty}(\beta)\). At the optimum, the gradient of the loss must cancel the subdifferential of the penalty:

Ridge: The penalty gradient \(\lambda \cdot 2\beta\) → 0 as \(\beta\) → 0. For small coefficients, the penalty gradient is tiny, so the likelihood gradient dominates. Exact zero requires the likelihood gradient to also be exactly zero — rare.

Lasso: The penalty has a subgradient range of \([-\lambda, \lambda]\) at \(\beta = 0\). If the likelihood gradient satisfies \(|{-\nabla_\beta \text{loss}|_{\beta=0}}| \leq \lambda\), the subgradient condition is met with \(\beta^* = 0\). This is common for weak predictors.

Scale Relationship: λ, σ², τ², b

The regularisation strength \(\lambda\) has a direct Bayesian interpretation:

$$\lambda_{\text{Ridge}} = \frac{\sigma^2}{\tau^2}, \quad \lambda_{\text{Lasso}} = \frac{2\sigma^2}{b}$$

Larger noise \(\sigma^2\) → stronger regularisation. Wider prior (large \(\tau^2\) or \(b\)) → weaker regularisation (more trust in data). As \(\tau^2 \to \infty\) (flat Gaussian prior) or \(b \to \infty\) (flat Laplace prior), the MAP converges to OLS.

🔑 Design Decision: Why Gaussian?

The Gaussian prior is conjugate to the Gaussian likelihood — the posterior is also Gaussian, enabling exact closed-form inference. This makes Ridge computationally and analytically beautiful. The Laplace prior lacks conjugacy, so full Bayesian inference requires sampling or approximation — but the MAP (Lasso) remains convex and efficiently solvable.

Interview Deep-Dive
▾
Easy What is the Bayesian interpretation of Ridge regression? ▾
Ridge regression is equivalent to MAP estimation with a Gaussian prior on the coefficients. Specifically, if \(\beta_j \sim \mathcal{N}(0, \tau^2)\) independently, then the MAP estimate maximises \(p(\beta \mid y) \propto p(y \mid \beta) \cdot p(\beta)\), which is equivalent to minimising \(\|y - X\beta\|^2 + \lambda\|\beta\|^2_2\) with \(\lambda = \sigma^2/\tau^2\). The L2 penalty term is the negative log of the Gaussian prior.
Easy What prior corresponds to Lasso? Why does it produce sparse solutions? ▾
Lasso corresponds to a Laplace (double-exponential) prior \(\beta_j \sim \text{Laplace}(0, b)\). Its density has a sharp, non-differentiable peak at zero. This kink means the subdifferential of \(|\beta|\) at zero spans \([-1/b, 1/b]\), allowing the optimality conditions to be satisfied with \(\beta^* = 0\) whenever the gradient of the loss function is small — i.e., for weak predictors. The Gaussian prior's smooth quadratic penalty has gradient 0 at zero, so it can never force exact zeros.
Medium What is the relationship between λ in Ridge/Lasso and the prior hyperparameters? ▾
For Ridge: \(\lambda = \sigma^2 / \tau^2\). Larger noise \(\sigma^2\) → stronger regularisation (trust the prior more). Larger prior variance \(\tau^2\) (diffuse prior) → weaker regularisation. As \(\tau^2 \to \infty\), \(\lambda \to 0\) and Ridge converges to OLS. For Lasso: \(\lambda = 2\sigma^2 / b\). Larger scale \(b\) (more spread out Laplace) → weaker regularisation. Cross-validating \(\lambda\) is equivalent to estimating the ratio of noise to prior variance.
Medium Is MAP the same as full Bayesian inference? What's the difference? ▾
No. MAP gives a single point estimate — the mode of the posterior. Full Bayesian inference characterises the entire posterior distribution \(p(\beta \mid y)\), capturing uncertainty about \(\beta\). For Ridge (Gaussian prior + Gaussian likelihood), the full posterior is tractable: \(p(\beta \mid y) = \mathcal{N}(\hat{\beta}_{\text{Ridge}}, \sigma^2(X^\top X + \lambda I)^{-1})\). For Lasso, the Laplace prior doesn't give a closed-form posterior — MAP gives the point estimate but full posterior inference requires MCMC or variational methods.
Hard Explain geometrically why Lasso produces exact zeros but Ridge doesn't. ▾
The constraint set of Ridge is a smooth hypersphere \(\|\beta\|^2_2 \leq t\); the constraint set of Lasso is an L1 ball (a diamond in 2D) with sharp corners at the axes. When the elliptical contours of the OLS loss function are tangent to the constraint boundary, they're most likely to touch the L1 ball at a corner (where one or more coordinates are exactly 0) because corners have the highest "surface-to-volume" ratio. The L2 ball has no corners — tangency can occur anywhere on the smooth surface. Equivalently, in unconstrained form: the Laplace penalty's kink at zero allows the subdifferential optimality condition to be satisfied with \(\beta = 0\); the smooth quadratic cannot.
Hard What prior corresponds to Elastic Net? What about group regularisation? ▾
Elastic Net (\(\alpha\|\beta\|_1 + (1-\alpha)\|\beta\|^2_2\)) corresponds to a prior that is the product of a Laplace and a Gaussian: \(p(\beta) \propto \exp(-\alpha|\beta|/c_1 - \beta^2/c_2)\) — sometimes called a "normal-exponential-gamma" or convex combination of priors. Group Lasso corresponds to a multivariate Laplace (or a spherical Cauchy-like prior) applied to groups of coefficients jointly, inducing group-level sparsity. The Horseshoe prior (slab-and-spike with a Cauchy-tailed shrinkage) achieves near-unbiased estimation for strong signals while driving small coefficients to zero — it doesn't correspond to a simple penalty form.

From Scratch: Bayesian Linear Regression (Ridge MAP)

import numpy as np
def ridge_map(X, y, tau2=1.0, sigma2=1.0):
"""MAP estimate with Gaussian prior N(0, tau2*I).
Equivalent to Ridge regression with lambda = sigma2 / tau2."""
lam = sigma2 / tau2 # regularisation strength
n, p = X.shape
# Closed form: (X'X + lambda*I)^{-1} X'y
A = X.T @ X + lam * np.eye(p) # p x p augmented matrix
b = X.T @ y # p-vector
return np.linalg.solve(A, b) # numerically stable solve
def lasso_map_1d(y_ols, sigma2=1.0, b_scale=1.0):
"""Soft-threshold: MAP with Laplace prior Laplace(0, b_scale)."""
threshold = sigma2 / b_scale # lambda/2 in standard notation
return np.sign(y_ols) * np.maximum(np.abs(y_ols) - threshold, 0)
# Numerical trace: y=2.0, sigma2=1.0, tau2=1.0, b=1.0
beta_ridge = ridge_map(np.array([[1.]]), np.array([2.]), tau2=1.0, sigma2=1.0)
beta_lasso = lasso_map_1d(y_ols=2.0, sigma2=1.0, b_scale=1.0)
print(f"Ridge MAP: {beta_ridge[0]:.4f}") # 1.0000
print(f"Lasso MAP: {beta_lasso:.4f}") # 1.0000
beta_lasso_sparse = lasso_map_1d(y_ols=0.8, sigma2=1.0, b_scale=0.5)
print(f"Lasso sparse: {beta_lasso_sparse:.4f}") # 0.0000 (exact zero!)

Production Usage (sklearn)

from sklearn.linear_model import Ridge, Lasso, BayesianRidge
from sklearn.model_selection import cross_val_score
# Ridge: alpha here = lambda = sigma2/tau2
ridge = Ridge(alpha=1.0) # sklearn uses 'alpha' not 'lambda'
ridge.fit(X_train, y_train)
# Lasso: alpha here = lambda/2 in our notation
lasso = Lasso(alpha=0.5, max_iter=10000)
lasso.fit(X_train, y_train)
print(lasso.coef_) # many will be exactly 0.0
# Full Bayesian Ridge (tractable because Gaussian-Gaussian conjugacy)
bayes_ridge = BayesianRidge() # learns lambda and sigma2 from data
bayes_ridge.fit(X_train, y_train)
y_pred, y_std = bayes_ridge.predict(X_test, return_std=True) # posterior uncertainty!
# ⚠️ sklearn Lasso alpha != our lambda. Relationship: sklearn_alpha = lambda/(2*n)

Decision Guide

Use Ridge when all predictors likely matter (e.g., genomics with dense effects). Use Lasso when you expect many irrelevant features and want automatic selection. Use Elastic Net when predictors come in correlated groups. Use BayesianRidge (sklearn) when you want posterior uncertainty estimates with Gaussian prior.
