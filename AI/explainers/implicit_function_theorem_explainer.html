Implicit Function Theorem

When does \(F(x,y)=0\) locally define \(y\) as a function of \(x\)?
Advanced Multivariable Calculus Analysis ∂F/∂y ≠ 0
1
Understanding the Theorem
▼

What is it? Given an equation \(F(x,y)=0\) that defines a curve in the plane, the Implicit Function Theorem (IFT) answers: can we locally "solve" for \(y\) as a smooth function of \(x\)? The answer is yes — at any point where the curve isn't "vertical" — and in that case we can differentiate implicitly without ever writing \(y\) explicitly.

Analogy: Imagine a road on a hilly map drawn by the equation \(F(\text{longitude}, \text{altitude}) = 0\). At most points the altitude is a smooth function of longitude — small steps east or west give a well-defined altitude. But at a cliff face the road becomes vertical: one longitude has infinitely many altitudes. The IFT says the road is locally altitude-as-a-function-of-longitude precisely when the cliff isn't vertical, i.e., when the altitude partial derivative \(\partial F / \partial y \ne 0\).

💡 If you remember one thing

If \(F(x_0,y_0)=0\) and \(\partial F/\partial y \big|_{(x_0,y_0)} \ne 0\), then near \((x_0,y_0)\) the level set \(\{F=0\}\) is the graph of a smooth function \(g\), and the slope is $$\frac{dy}{dx} = -\frac{F_x}{F_y}$$

Why it matters in ML: The IFT is the theoretical backbone behind implicit differentiation of optimality conditions — the key tool in differentiable optimization layers, bilevel optimization, and meta-learning where the "inner" solution is implicitly defined by \(\nabla_y \mathcal{L}(x,y)=0\).

2
How It Works — Local Solvability
▼

Setup

Let \(F: \mathbb{R}^2 \to \mathbb{R}\) be continuously differentiable (\(C^1\)). Fix a point \((x_0, y_0)\) on the level set, i.e. \(F(x_0, y_0) = 0\). The gradient of \(F\) is \(\nabla F = (F_x, F_y)\). The level curve \(F = 0\) is the set of points where \(F\) equals zero — a curve in the plane.

The Key Condition

The tangent line to \(F(x,y)=0\) at \((x_0,y_0)\) has gradient vector \((F_x, F_y)\) as its normal. For the tangent to be non-vertical (i.e., for the curve to locally look like a graph \(y = g(x)\)), we need \(F_y \ne 0\). When \(F_y = 0\), the tangent is vertical — the curve folds back on itself at that point, and \(y\) cannot be written as a function of \(x\) near there.

🔑 The Theorem Statement

If \(F \in C^1\) near \((x_0,y_0)\), \(F(x_0,y_0)=0\), and \(F_y(x_0,y_0) \ne 0\), then there exist open intervals \(I \ni x_0\) and \(J \ni y_0\) and a unique \(C^1\) function \(g: I \to J\) such that for all \(x \in I\): $$F(x,\, g(x)) = 0 \quad \text{and} \quad g'(x) = -\frac{F_x(x,\,g(x))}{F_y(x,\,g(x))}$$

Worked Example: The Unit Circle

Take \(F(x,y) = x^2 + y^2 - 1\). Then \(F_x = 2x\), \(F_y = 2y\). At \((0, 1)\): \(F_y = 2 \ne 0\), so near this point we can write \(y = g(x) = \sqrt{1-x^2}\). The slope is \(g'(x) = -\frac{2x}{2y} = -\frac{x}{y}\). At the "east pole" \((1,0)\): \(F_y = 0\) — the tangent is vertical, and no smooth \(y=g(x)\) exists locally.

⚠️ Only Local

The IFT is a local result. Globally, \(x^2+y^2=1\) cannot be written as a single function \(y=g(x)\) — it has two branches. The theorem only guarantees existence in a small neighborhood of the base point.

3
The Mathematics — Derivation & Implicit Differentiation
▼

Deriving the Slope Formula

Suppose \(g\) exists and \(F(x,g(x))=0\) identically. Differentiate both sides with respect to \(x\) using the chain rule:

$$\frac{d}{dx} F(x,\,g(x)) = F_x(x,g(x))\cdot 1 + F_y(x,g(x))\cdot g'(x) = 0$$

Solving for \(g'(x)\), assuming \(F_y \ne 0\):

$$g'(x) = -\frac{F_x(x,\,g(x))}{F_y(x,\,g(x))}$$

This is the implicit differentiation formula. Note it gives the slope of the level curve directly in terms of the partial derivatives of \(F\) — no need to ever solve for \(y\) explicitly.

Proof Sketch of Existence (Contraction Mapping)

The standard proof uses the Contraction Mapping Theorem (Banach fixed-point theorem). Near \((x_0,y_0)\), define the iteration \(T_x(y) = y - \frac{F(x,y)}{F_y(x_0,y_0)}\). Since \(F_y(x_0,y_0) \ne 0\) and \(F\) is \(C^1\), for \(x\) near \(x_0\) the map \(T_x\) is a contraction on a small ball, so it has a unique fixed point \(g(x)\) satisfying \(F(x,g(x))=0\). Smoothness of \(g\) follows from the formula for \(g'\).

The n-Dimensional Version

More generally: \(F: \mathbb{R}^m \times \mathbb{R}^n \to \mathbb{R}^n\), with \(F(\mathbf{x}_0,\mathbf{y}_0)=\mathbf{0}\). If the Jacobian \(D_{\mathbf{y}} F(\mathbf{x}_0,\mathbf{y}_0)\) is invertible (an \(n\times n\) matrix), then near \(\mathbf{x}_0\) there is a unique \(C^1\) function \(\mathbf{g}(\mathbf{x})\) with \(F(\mathbf{x},\mathbf{g}(\mathbf{x}))=\mathbf{0}\) and:

$$D\mathbf{g}(\mathbf{x}) = -\bigl[D_{\mathbf{y}}F(\mathbf{x},\mathbf{g}(\mathbf{x}))\bigr]^{-1}\, D_{\mathbf{x}}F(\mathbf{x},\mathbf{g}(\mathbf{x}))$$

Connection to Bilevel Optimization

In meta-learning and bilevel optimization, the inner problem \(\min_y \mathcal{L}(x,y)\) defines \(y^*(x)\) implicitly via the stationarity condition \(\nabla_y \mathcal{L}(x, y^*(x)) = \mathbf{0}\). Setting \(F(x,y) = \nabla_y \mathcal{L}(x,y)\), the IFT yields:

$$\frac{dy^*}{dx} = -\bigl[\nabla_{yy}^2 \mathcal{L}\bigr]^{-1}\, \nabla_{xy}^2 \mathcal{L}$$

This is the formula used in MAML, DEQ (Deep Equilibrium Models), and OptNet to differentiate through a constrained or equilibrium layer without unrolling.

📐 Key Formulas at a Glance

2D: \(\;g'(x) = -F_x/F_y\)
nD: \(\;D\mathbf{g} = -[D_y F]^{-1} D_x F\)
ML: \(\;dy^*/dx = -[\nabla_{yy}^2 \mathcal{L}]^{-1} \nabla_{xy}^2 \mathcal{L}\)

Key Takeaways & ML Connections
▼

When IFT applies (local solvability)

  • \(F\) is \(C^1\) (continuously differentiable) in a neighborhood of the base point
  • \(F(x_0, y_0) = 0\) — we are on the level set
  • \(\partial F/\partial y \ne 0\) at the base point — the Jacobian condition

When IFT fails

  • \(F_y = 0\): tangent is vertical, curve folds back — no local graph
  • \(F\) not differentiable (e.g., corners or cusps)
  • Even when IFT holds locally, the global function may be multi-valued
💡 ML Application: Differentiable Optimization Layers

In OptNet (Amos & Kolter 2017) and DEQ (Bai et al. 2019), the network output is defined implicitly as the solution to an inner problem. The IFT guarantees this solution is differentiable with respect to network parameters whenever the inner Hessian \(\nabla^2_{yy}\mathcal{L}\) is invertible — and gives the exact gradient formula without unrolling the optimization loop.

🔑 Hierarchy of Related Theorems

Inverse Function Theorem ⊂ Implicit Function Theorem ⊂ Constant Rank Theorem. The Inverse Function Theorem is actually a special case of the IFT (set \(F(x,y)=f(y)-x\)).

Code Trace — Implicit Differentiation & Optimization Layer
▼

Implicit differentiation from scratch and a minimal differentiable optimization layer using the IFT gradient formula.

import numpy as np
# ── Example 1: Unit circle F(x,y) = x² + y² - 1 ──
def F(x, y): return x**2 + y**2 - 1
def Fx(x, y): return 2*x # ∂F/∂x
def Fy(x, y): return 2*y # ∂F/∂y
# At (x0,y0) = (0.6, 0.8): F_y = 1.6 ≠ 0 → IFT holds
x0, y0 = 0.6, 0.8
assert abs(F(x0, y0)) < 1e-10 # on the curve
slope = -Fx(x0,y0) / Fy(x0,y0) # = -0.6/0.8 = -0.75
print(f"dy/dx at (0.6, 0.8) = {slope}") # -0.75
# Verify: g(x) = sqrt(1 - x²) → g'(x) = -x/sqrt(1-x²)
g_prime = -x0 / np.sqrt(1 - x0**2) # -0.6/0.8 = -0.75 ✓
# At "east pole" (1, 0): F_y = 0 → IFT FAILS
print(f"F_y at (1,0) = {Fy(1.0, 0.0)}") # 0 → failure
# ── Example 2: IFT in bilevel opt ──
# Inner problem: y*(x) = argmin_y ½y² - xy → y*(x) = x
# Stationarity: F(x,y) = ∇_y L = y - x = 0
def L(x, y): return 0.5*y**2 - x*y
def Lyy(x,y): return 1.0 # ∇²_yy L = 1 (invertible)
def Lxy(x,y): return -1.0 # ∇²_xy L = -1
# IFT gradient: dy*/dx = -(∇²_yy)⁻¹ ∇²_xy
dy_star_dx = -(1.0/Lyy(0,0)) * Lxy(0,0) # = -(-1)/1 = 1
print(f"dy*/dx = {dy_star_dx}") # 1.0 ✓ (y*=x)
