Z-score Standardization

Transform any feature to mean 0, standard deviation 1 via \(\frac{x - \mu}{\sigma}\)

Foundational Feature Engineering Classical ML Must Know
1
Understanding the Concept

What is this? Z-score standardization rescales a numeric feature so that it has a mean of zero and a standard deviation of one. Every value is replaced by "how many standard deviations it is above or below the mean." The rule is simple: subtract the mean, then divide by the standard deviation.

$$z = \frac{x - \mu}{\sigma}$$

Real-world analogy. Imagine comparing exam scores across different subjects. A score of 80 in History (class mean 60, SD 10) is very different from a score of 80 in Maths (class mean 78, SD 2). After standardizing, History gives \(z = 2.0\) ("2 standard deviations above average — excellent!") and Maths gives \(z = 1.0\) ("just one SD above — good, but not exceptional"). Now scores are on the same scale and directly comparable.

💡 If you remember one thing
Z-score standardization subtracts the training-set mean and divides by the training-set standard deviation. Always fit on train, then apply the same \(\mu\) and \(\sigma\) to test/inference — never recompute on test data.
Key Property
After standardization: \(\mathbb{E}[z] = 0\) and \(\text{Var}(z) = 1\). The distribution shape (skewness, kurtosis) is unchanged — only location and scale shift.
2
How It Works Internally

The transform is a two-parameter affine map. Given a feature column \(x_1, x_2, \ldots, x_n\):

$$\mu = \frac{1}{n}\sum_{i=1}^{n} x_i \qquad \sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \mu)^2}$$
$$z_i = \frac{x_i - \mu}{\sigma}$$

The subtraction centres the distribution at zero. The division normalises the spread. The result is a dimensionless "standard score." The inverse is \(x_i = z_i \cdot \sigma + \mu\), so no information is lost — standardization is fully invertible.

Why gradient-based methods benefit. Gradient descent updates \(\theta \leftarrow \theta - \alpha \nabla L\). When features have vastly different scales, the loss surface becomes a narrow ravine: gradients in the high-scale direction are enormous while those in the low-scale direction are tiny. The optimizer oscillates or requires a tiny learning rate. After standardization every feature contributes on an equal footing, the loss surface becomes more bowl-shaped, and a single learning rate works well across all dimensions.

Why distance methods benefit. k-NN and SVM kernels compute Euclidean distances. A 1-unit change in a feature measured in millimetres contributes the same distance as a 1-unit change in a feature measured in kilometres — which is absurd. Standardization makes 1 unit = 1 standard deviation for every feature, so distances reflect genuine similarity.

⚠ Outlier Sensitivity
The sample standard deviation \(\sigma\) is non-robust: a single extreme outlier inflates \(\sigma\), compressing all non-outlier z-scores toward zero. For data with genuine heavy tails, consider Robust Scaling (median + IQR) instead.

Design decision — why divide by σ and not range or IQR? Dividing by \(\sigma\) is the unique choice that guarantees unit variance. It also maximises compatibility with the normal distribution assumption, which underlies PCA, LDA, and Gaussian process models. The range \((\max - \min)\) is highly non-robust; IQR is robust but gives variance \(\neq 1\).

3
The Math Behind It

Proof: z has mean 0, variance 1.

Let \(z_i = (x_i - \mu)/\sigma\). Compute the mean of \(z\):

$$\bar{z} = \frac{1}{n}\sum_{i=1}^n z_i = \frac{1}{n}\sum_{i=1}^n \frac{x_i - \mu}{\sigma} = \frac{1}{\sigma}\left(\frac{1}{n}\sum_{i=1}^n x_i - \mu\right) = \frac{\mu - \mu}{\sigma} = 0 \checkmark$$

Compute the variance of \(z\):

$$\text{Var}(z) = \frac{1}{n}\sum_{i=1}^n z_i^2 = \frac{1}{n}\sum_{i=1}^n \frac{(x_i-\mu)^2}{\sigma^2} = \frac{\sigma^2}{\sigma^2} = 1 \checkmark$$

Connection to the standard normal. If \(X \sim \mathcal{N}(\mu, \sigma^2)\) then \(Z = (X - \mu)/\sigma \sim \mathcal{N}(0, 1)\). Standardization is the sample analogue of this population transform. With finite samples, the standardized column has exactly mean 0 and variance 1, but is only approximately standard-normal (depending on the underlying distribution).

Effect on distance. Euclidean distance between two points \(\mathbf{x}\) and \(\mathbf{y}\) in the original space:

$$d(\mathbf{x}, \mathbf{y}) = \sqrt{\sum_{j=1}^{p}(x_j - y_j)^2}$$

After standardizing each feature by its own \(\mu_j, \sigma_j\):

$$d_{\text{std}}(\mathbf{x}, \mathbf{y}) = \sqrt{\sum_{j=1}^{p}\frac{(x_j - y_j)^2}{\sigma_j^2}}$$

This is the Mahalanobis distance with a diagonal covariance matrix — each feature contributes proportionally to its variability.

Key Formulas

\(\displaystyle z_i = \frac{x_i - \hat{\mu}}{\hat{\sigma}} \qquad\) (standardization)

\(\displaystyle \hat{\mu} = \frac{1}{n}\sum_{i=1}^n x_i \qquad \hat{\sigma} = \sqrt{\frac{1}{n-1}\sum_{i=1}^n (x_i - \hat{\mu})^2}\qquad\) (sklearn uses n−1 by default)

\(\displaystyle x_i = z_i \cdot \hat{\sigma} + \hat{\mu} \qquad\) (inverse)

🚨 Common Mistake — n vs n−1
Population variance divides by \(n\); sample variance (Bessel correction) divides by \(n-1\). sklearn.StandardScaler divides by \(n\) (population) by default when computing \(\sigma\) for scaling — this is intentional: it gives exact unit variance on the training set. numpy.std(ddof=1) uses \(n-1\). For large \(n\) the difference is negligible.

Key Takeaways & When to Use
✅ Use Z-score When
  • • Gradient descent (LR, SVM, NN)
  • • Distance methods (k-NN, k-means)
  • • PCA / dimensionality reduction
  • • Regularized models (Lasso, Ridge)
  • • Gaussian-assumption models (LDA)
  • • Feature importance is comparable
❌ Skip Z-score When
  • • Tree models (GBDT, RF) — scale-invariant
  • • Naive Bayes — assumptions differ
  • • Heavy outliers dominate → use Robust Scaler
  • • Fixed known range needed → Min-Max
  • • Sparse features → MaxAbs Scaler
ScalerFormulaOutput RangeOutlier Robust?Best For
Z-score (Standard) \(\frac{x-\mu}{\sigma}\) ≈ [−3, 3] No Gradients, distances, PCA
Min-Max \(\frac{x-\min}{\max-\min}\) [0, 1] No (worst) Neural net inputs, image pixels
Robust \(\frac{x-\text{median}}{\text{IQR}}\) Varies Yes Data with outliers
MaxAbs \(x / |x|_{\max}\) [−1, 1] No Sparse matrices

Code — From Scratch & Production

From scratch (NumPy):

import numpy as np
class StandardScaler:
def fit(self, X): # X: shape (n_samples, n_features)
self.mu_ = X.mean(axis=0) # per-feature mean
self.sigma_ = X.std(axis=0) # per-feature std (ddof=0)
return self
def transform(self, X):
return (X - self.mu_) / self.sigma_ # broadcast: (n, p) - (p,) / (p,)
def inverse_transform(self, Z):
return Z * self.sigma_ + self.mu_
def fit_transform(self, X): # convenience
return self.fit(X).transform(X)

Production (sklearn) — correct pipeline usage:

from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression
# X_train, X_test already split — NEVER fit scaler on test data
pipe = Pipeline([
("scaler", StandardScaler()), # fit on train, transform both
("clf", LogisticRegression()),
])
pipe.fit(X_train, y_train) # scaler.fit_transform(X_train) internally
pipe.predict(X_test) # scaler.transform(X_test) — uses train μ, σ
# Gotcha: StandardScaler(with_mean=False) for sparse matrices
# Gotcha: StandardScaler(with_std=False) to only centre, not scale
