Understanding Bayes by Backprop
▼

What is it? Traditional neural networks (NNs) learn fixed, "point estimate" weights. Bayes by Backprop (BBB) takes a Bayesian approach: it learns *probability distributions* over the weights instead. This allows the network to express its uncertainty about its predictions, rather than just giving a single answer. It achieves this by using variational inference, which approximates the true (intractable) posterior distribution of weights with a simpler, tractable distribution.

Analogy: Imagine you're asking a committee of experts for advice. A traditional NN is like asking a single, highly confident expert who always gives one answer. A Bayesian NN is like asking a committee where each member has slightly different knowledge and confidence. When they all agree, the committee is confident; when they disagree, the committee expresses high uncertainty. Bayes by Backprop is the process of training this committee by adjusting a shared "blueprint" for how each expert is formed.

💡 If you remember one thing

Bayes by Backprop (BBB) transforms the problem of finding weight distributions into a standard gradient-based optimization. Instead of learning weights \(w\), it learns the parameters (mean \(\mu\) and variance \(\sigma^2\)) of a simple distribution \(q(w|\phi)\) over each weight, using the reparameterization trick to make it differentiable. The objective function is the Evidence Lower Bound (ELBO).

2
How It Works Internally
▼

Bayesian Neural Networks (BNNs)

In a BNN, every weight \(w_{ij}\) and bias \(b_i\) is treated as a random variable. We don't learn a single value for \(w_{ij}\), but rather a probability distribution \(p(w_{ij}|D)\) — the posterior distribution of the weight given the training data \(D\). This posterior is often complex and impossible to compute directly.

Variational Inference (VI)

VI approximates the true posterior \(p(w|D)\) with a simpler, tractable distribution \(q(w|\phi)\), where \(\phi\) are the *variational parameters* we optimize. For BBB, \(q\) is typically chosen as a factorized Gaussian distribution: \(q(w|\phi) = \prod_i q(w_i|\phi_i)\), where each \(q(w_i|\phi_i) = \mathcal{N}(\mu_i, \sigma_i^2)\). So, for each weight, we learn two parameters: its mean \(\mu_i\) and its standard deviation \(\sigma_i\) (often parameterized as \(\rho_i\) where \(\sigma_i = \log(1+\exp(\rho_i))\) to ensure positivity).

The Reparameterization Trick

To optimize \(\phi = \{\mu, \rho\}\) using gradient descent, we need to compute gradients of the ELBO objective with respect to \(\phi\). This involves taking expectations over \(q(w|\phi)\). The reparameterization trick allows us to sample \(w\) in a way that is differentiable with respect to \(\phi\):

$$w = \mu + \sigma \cdot \epsilon \quad \text{where } \epsilon \sim \mathcal{N}(0, 1)$$

Now, the randomness is factored out into \(\epsilon\), which is independent of \(\phi\). We can compute gradients of the ELBO using Monte Carlo samples of \(\epsilon\).

ELBO as the Objective Function

The core idea is to maximize the Evidence Lower Bound (ELBO), which is a lower bound on the marginal log-likelihood of the data \(\log p(D)\). Maximizing the ELBO is equivalent to minimizing the Kullback-Leibler (KL) divergence between \(q(w|\phi)\) and the true posterior \(p(w|D)\). The ELBO has two terms:

  1. Likelihood Term: \(\mathbb{E}_{q(w|\phi)}[\log p(D|w)]\). This encourages the sampled networks to fit the data well.
  2. Complexity Term: \(-D_{KL}(q(w|\phi) || p(w))\). This acts as a regularizer, pushing \(q(w|\phi)\) towards a chosen prior distribution \(p(w)\) (e.g., a simple Gaussian).

By optimizing \(\phi\) to maximize the ELBO, we find a \(q(w|\phi)\) that best approximates the posterior while balancing data fit and regularization.

🔑 Key Property

BBB effectively trains an ensemble of networks where each member's weights are sampled from \(q(w|\phi)\). The ELBO objective ensures that this ensemble (1) fits the data well on average, and (2) doesn't stray too far from prior beliefs about the weights, preventing overfitting and encouraging robust uncertainty estimates.

3
Why It Works — The Math
▼

The Evidence Lower Bound (ELBO)

Our goal in Bayesian inference is to compute the posterior distribution \(p(w|D) = \frac{p(D|w)p(w)}{p(D)}\) and use it to make predictions. However, the marginal likelihood \(p(D) = \int p(D|w)p(w)dw\) is often intractable. Variational inference sidesteps this by instead optimizing a tractable lower bound on \(\log p(D)\).

Starting from \(\log p(D)\) and introducing the variational distribution \(q(w|\phi)\):

$$\log p(D) = \log \int p(D|w) p(w) dw = \log \int q(w|\phi) \frac{p(D|w) p(w)}{q(w|\phi)} dw$$

By Jensen's inequality (\(\log \mathbb{E}[X] \ge \mathbb{E}[\log X]\)), we get:

$$\log p(D) \ge \mathbb{E}_{q(w|\phi)}\left[\log \frac{p(D|w) p(w)}{q(w|\phi)}\right]$$

This expectation can be decomposed into two terms, forming the ELBO, \(\mathcal{L}(\phi)\):

$$\mathcal{L}(\phi) = \mathbb{E}_{q(w|\phi)}[\log p(D|w)] - D_{KL}(q(w|\phi) || p(w))$$

Here, the first term is the expected log-likelihood (how well the data fits sampled weights), and the second term is the Kullback-Leibler (KL) divergence between our variational posterior \(q(w|\phi)\) and the prior \(p(w)\). Maximizing \(\mathcal{L}(\phi)\) drives \(q(w|\phi)\) to be close to the true posterior \(p(w|D)\).

Gradients via Reparameterization

To optimize \(\mathcal{L}(\phi)\) using stochastic gradient descent, we need \(\nabla_\phi \mathcal{L}(\phi)\). Using the reparameterization trick \(w = \mu + \sigma \cdot \epsilon\) with \(\epsilon \sim \mathcal{N}(0,1)\), we can write the gradient of the likelihood term as:

$$\nabla_\phi \mathbb{E}_{q(w|\phi)}[\log p(D|w)] = \mathbb{E}_{\epsilon}[\nabla_\phi \log p(D|w(\phi, \epsilon))]$$

This allows us to estimate the gradient by sampling \(\epsilon\) and performing standard backpropagation through the network, where the "weights" are now functions of \(\phi\) and \(\epsilon\). The KL divergence term also has a closed form for Gaussian distributions and is easily differentiable.

⚠️ Common Pitfall

The choice of prior \(p(w)\) for the KL divergence term is crucial. A common choice is a simple Gaussian (e.g., \(\mathcal{N}(0, I)\)). If the prior is too strong or ill-chosen, it can pull the variational posterior \(q(w|\phi)\) away from the true posterior, leading to poor performance or miscalibrated uncertainty. Also, the Monte Carlo estimate of the ELBO gradient can have high variance, requiring many samples or specific gradient estimators.

Key Takeaways
▼

When to use Bayes by Backprop:

  • Quantifying Uncertainty: When predictions need to come with confidence intervals (e.g., medical diagnosis, financial forecasting, autonomous driving). BNNs naturally provide both aleatoric (data inherent noise) and epistemic (model uncertainty) uncertainty.
  • Small Datasets: BNNs can be less prone to overfitting than traditional NNs on small datasets due to the regularization effect of the KL divergence term and the implicit ensemble averaging.
  • Active Learning: Uncertainty estimates can guide data acquisition, helping to select new data points where the model is most uncertain.
  • Robustness: The ensemble-like nature of BNNs can lead to more robust models, less sensitive to adversarial attacks.

When NOT to use:

  • Computational Cost: BNNs are significantly more expensive to train and run than traditional NNs. Each weight has two parameters (\(\mu\) and \(\rho\)), doubling the parameter count. Additionally, predictions require multiple forward passes (sampling) to estimate uncertainty.
  • Large-Scale Problems: The increased computational burden often makes BBB impractical for very large models or datasets where training time is already a bottleneck.
  • Simpler Alternatives Suffice: For some applications, simpler methods like Monte Carlo Dropout can provide reasonable uncertainty estimates with less overhead.
💡 Big Picture

BBB is a foundational method that bridges Bayesian inference and deep learning, enabling NNs to express uncertainty. While computationally intensive, it provides a principled way to incorporate probabilistic reasoning into complex models, opening doors to more robust and trustworthy AI systems.

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.distributions import Normal, Categorical
# Define a variational linear layer for BNNs
class LinearVariational(nn.Module):
def __init__(self, in_features, out_features, prior_sigma=1.0):
super().__init__()
self.in_features = in_features
self.out_features = out_features
# Variational parameters for weights (mu, rho)
self.w_mu = nn.Parameter(torch.Tensor(out_features, in_features))
self.w_rho = nn.Parameter(torch.Tensor(out_features, in_features))
# Variational parameters for biases (mu, rho)
self.b_mu = nn.Parameter(torch.Tensor(out_features))
self.b_rho = nn.Parameter(torch.Tensor(out_features))
# Initialize parameters (e.g., Kaiming uniform)
nn.init.kaiming_uniform_(self.w_mu, a=math.sqrt(5))
nn.init.zeros_(self.b_mu)
# Initialize rho to small negative for small initial sigma
nn.init.constant_(self.w_rho, -3.0)
nn.init.constant_(self.b_rho, -3.0)
# Prior distributions for KL divergence term
self.prior_w = Normal(0, prior_sigma)
self.prior_b = Normal(0, prior_sigma)
def forward(self, x):
# Compute standard deviations from rho (softplus ensures positivity)
w_sigma = F.softplus(self.w_rho)
b_sigma = F.softplus(self.b_rho)
# Reparameterization trick: sample weights from variational posterior
epsilon_w = Normal(0, 1).sample(self.w_mu.shape)
epsilon_b = Normal(0, 1).sample(self.b_mu.shape)
weight = self.w_mu + w_sigma * epsilon_w
bias = self.b_mu + b_sigma * epsilon_b
# Standard linear layer operation with sampled weights
return F.linear(x, weight, bias)
def kl_divergence(self):
# Variational posteriors for weights and biases
q_w = Normal(self.w_mu, F.softplus(self.w_rho))
q_b = Normal(self.b_mu, F.softplus(self.b_rho))
# Compute KL divergence for all parameters and sum
kl_w = torch.sum(torch.distributions.kl_divergence(q_w, self.prior_w))
kl_b = torch.sum(torch.distributions.kl_divergence(q_b, self.prior_b))
return kl_w + kl_b
# Main BNN model
class BNN(nn.Module):
def __init__(self, hidden_features=1, prior_sigma=1.0):
super().__init__()
self.l1 = LinearVariational(1, hidden_features, prior_sigma) # Input to Hidden
self.l2 = LinearVariational(hidden_features, 1, prior_sigma) # Hidden to Output
self.activation = nn.Tanh()
def forward(self, x):
x = self.l1(x)
x = self.activation(x)
x = self.l2(x)
return x
def elbo_loss(self, x, y, num_samples=1, beta=1.0):
# Monte Carlo estimate of expected log-likelihood
log_likelihood = 0
for _ in range(num_samples):
y_pred = self.forward(x)
# Assuming Gaussian likelihood: -MSE loss
log_likelihood += -F.mse_loss(y_pred, y, reduction='sum')
log_likelihood /= num_samples
# KL divergence term
kl = self.l1.kl_divergence() + self.l2.kl_divergence()
# ELBO objective (to be maximized, so we minimize -ELBO)
return -(log_likelihood - beta * kl) # beta is often 1/num_batches or 1
