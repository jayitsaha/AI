Label Propagation & Label Spreading

Graph-Based Semi-Supervised Learning — Diffusing labels through a similarity graph
Intermediate Classical ML Semi-Supervised Graph Methods O(n²) — n nodes
1
Understanding the Concept

What is this?

Imagine you have 1000 data points but only 10 of them are labeled. Label propagation builds a graph where similar data points are connected by edges. Labels then diffuse outward from the labeled nodes — like ink dropped into water — until every unlabeled node absorbs a label from its neighbors. The algorithm stops when the labels stop changing.

💡 If you remember one thing

Labels flow from labeled nodes to unlabeled ones via the graph's transition matrix (row-normalized adjacency). Label Spreading adds a soft clamp \(\alpha\) that prevents labeled nodes from drifting — Label Propagation hard-clamps them back every iteration.

Real-World Analogy

Think of a rumor spreading through a social network. A few people know the truth (labeled nodes). Each person tells their friends, who tell their friends. After a few rounds, even people who never heard the original message have been "influenced" by it. Similarity in feature space = friendship in the network.

The Two Variants at a Glance

Label Propagation (LP) — hard clamp: after each propagation step, the labels of the original labeled nodes are reset back to their true values. This guarantees that labeled nodes never change.

Label Spreading (LS) — soft clamp: labeled nodes are allowed to drift slightly. A hyperparameter \(\alpha \in (0,1)\) controls how much weight to give to neighbor influence vs. the original label. This is more robust to label noise.

🔑 Key Invariant

Both algorithms converge to a unique fixed point because the iteration matrix's spectral radius is < 1 (for spreading) or the clamped system is a contraction (for propagation). Convergence is guaranteed.

How It Works Internally

Step 1 — Build the Similarity Graph

Given \(n\) data points \(x_1, \ldots, x_n\), construct a weight matrix \(W \in \mathbb{R}^{n \times n}\) where each entry \(W_{ij}\) measures the similarity between \(x_i\) and \(x_j\). A common choice is the RBF kernel:

$$W_{ij} = \exp\!\left(-\frac{\|x_i - x_j\|^2}{2\sigma^2}\right)$$

You can also use a \(k\)-nearest-neighbour graph (connect each node to its \(k\) closest neighbours, set non-edges to 0). This sparsifies the graph and speeds up computation.

Step 2 — Build the Transition / Normalized-Laplacian Matrix

Label Propagation uses the row-normalized transition matrix \(T\):

$$T = D^{-1}W, \qquad D_{ii} = \sum_j W_{ij}$$

\(T_{ij}\) is the probability of "jumping" from node \(i\) to node \(j\), so each row sums to 1.

Label Spreading uses the symmetric normalized Laplacian form:

$$S = D^{-1/2}W D^{-1/2}$$

This preserves symmetry. The spreading update uses \(S\) with a clamping term.

Step 3 — Propagate Iteratively

Label Propagation update rule (per iteration \(t\)):

$$F^{(t+1)} = T \cdot F^{(t)}$$

Then clamp: for every labeled node \(i \in \mathcal{L}\), reset \(F_i^{(t+1)} \leftarrow Y_i\). Repeat until \(\|F^{(t+1)} - F^{(t)}\|_\infty < \epsilon\).

Label Spreading update rule:

$$F^{(t+1)} = \alpha \, S \cdot F^{(t)} + (1-\alpha)\, Y$$

Here \(Y\) is the initial label matrix (zeros for unlabeled). No hard reset — instead \((1-\alpha)Y\) continuously pulls each node toward its original label (or zero for unlabeled). The closed-form solution is:

$$F^* = (I - \alpha S)^{-1}(1-\alpha)\,Y$$
⚠️ Common Confusion

Label Propagation uses \(T = D^{-1}W\) (asymmetric, row-stochastic). Label Spreading uses \(S = D^{-1/2}W D^{-1/2}\) (symmetric). They are not the same matrix. Sklearn's LabelSpreading uses \(S\) and a clamping \(\alpha\); sklearn's LabelPropagation uses \(T\) with hard clamping and \(\alpha=1\).

Why It Works — Mathematical Guarantee

Label Propagation Closed Form

Partition nodes into labeled \(\mathcal{L}\) and unlabeled \(\mathcal{U}\), and partition \(T\) accordingly:

$$T = \begin{bmatrix} T_{LL} & T_{LU} \\ T_{UL} & T_{UU} \end{bmatrix}$$

Since labeled nodes are clamped each iteration, only \(F_{\mathcal{U}}\) changes. At convergence:

$$F_{\mathcal{U}}^* = (I - T_{UU})^{-1} T_{UL}\, Y_{\mathcal{L}}$$

This inverse exists because \(T_{UU}\) is a sub-stochastic matrix (rows sum to less than 1 when \(T_{UL} \neq 0\)), so all eigenvalues of \(T_{UU}\) have magnitude strictly less than 1, and \((I - T_{UU})\) is invertible.

Label Spreading Convergence

The spreading iteration \(F^{(t+1)} = \alpha S F^{(t)} + (1-\alpha)Y\) is a linear contraction with operator norm \(\alpha \|S\|_2 = \alpha \leq \alpha < 1\) (since \(S\) has spectral radius 1). By Banach fixed-point theorem, the iteration converges to a unique fixed point \(F^*\) for any \(\alpha \in (0,1)\).

∑ Harmonic Energy Interpretation

Label Propagation's fixed point minimises the graph quadratic energy \(\frac{1}{2}\sum_{ij}W_{ij}(f_i - f_j)^2\) subject to \(f_i = y_i\) for labeled nodes. The unlabeled labels are harmonic functions on the graph — no local maxima or minima, only smooth interpolation.

🎯 Decision Guide

Use Label Spreading when labels may be noisy or you want smooth uncertainty propagation. Use Label Propagation when labeled data is trusted completely. Avoid both when \(n > 50\text{k}\) without sparse kNN graphs — the full RBF matrix is \(O(n^2)\) memory.

6
Key Takeaways
  • Graph construction is the critical hyperparameter — kernel width \(\sigma\) or \(k\) in kNN determines whether the algorithm works at all.
  • Label Propagation = transition matrix \(T = D^{-1}W\) + hard clamp after each step. Exact labels preserved.
  • Label Spreading = symmetric matrix \(S = D^{-1/2}WD^{-1/2}\) + soft clamp \(\alpha\). Robust to label noise.
  • Closed-form convergence is guaranteed for both — LP because \(T_{UU}\) is sub-stochastic, LS because \(\alpha < 1\) is a contraction.
  • The fixed point is harmonic — it minimises the total variation (smoothness energy) over the graph, subject to the label constraints.
  • Sklearn: sklearn.semi_supervised.LabelPropagation and LabelSpreading implement both. Key params: kernel, gamma (σ), n_neighbors, alpha.
