Understanding Eigenvalues & Eigenvectors
▼

What is it? When you multiply a matrix \(A\) by most vectors, the result points in a completely different direction. But there are special vectors — eigenvectors — that only get scaled (stretched or shrunk), never rotated. The scaling factor is the eigenvalue.

Analogy: Imagine a funhouse mirror that stretches everything. Most shapes get distorted beyond recognition, but a perfectly vertical stripe stays vertical — it just gets taller or shorter. That stripe is an eigenvector; how much taller it gets is its eigenvalue.

💡 If you remember one thing

For a square matrix \(A\), a nonzero vector \(\mathbf{v}\) is an eigenvector with eigenvalue \(\lambda\) if \(A\mathbf{v} = \lambda\mathbf{v}\). The eigenvalue \(\lambda\) satisfies the characteristic polynomial \(\det(A - \lambda I) = 0\). Eigenvectors point in the directions a transformation only scales — they reveal the "skeleton" of a matrix.

Why it matters in ML: PCA finds eigenvectors of the covariance matrix to discover principal components. SVD is built on eigendecomposition. PageRank computes the dominant eigenvector of the web link graph. Neural network training dynamics depend on eigenvalues of the Hessian.

Core Concepts & Definitions
▼

The Fundamental Definition

Let \(A \in \mathbb{R}^{n \times n}\). A scalar \(\lambda \in \mathbb{C}\) is an eigenvalue of \(A\), and a nonzero vector \(\mathbf{v} \in \mathbb{C}^n\) is the corresponding eigenvector, if:

$$A\mathbf{v} = \lambda\mathbf{v}, \quad \mathbf{v} \neq \mathbf{0}$$

Geometrically: \(A\) maps \(\mathbf{v}\) to a scalar multiple of itself. The direction is preserved; only the magnitude (and possibly sign) changes.

The Characteristic Polynomial

Rearrange the definition: \(A\mathbf{v} = \lambda\mathbf{v} \Rightarrow (A - \lambda I)\mathbf{v} = \mathbf{0}\). For a nonzero \(\mathbf{v}\) to satisfy this, the matrix \((A - \lambda I)\) must be singular — it must have a null space. A matrix is singular iff its determinant is zero:

$$\det(A - \lambda I) = 0$$

Expanding this determinant gives a degree-\(n\) polynomial in \(\lambda\) called the characteristic polynomial \(p(\lambda)\). Its roots are exactly the eigenvalues of \(A\).

Worked 2×2 Example

Take \(A = \begin{bmatrix} 3 & 1 \\ 0 & 2 \end{bmatrix}\). The characteristic polynomial is:

$$\det\!\begin{bmatrix} 3-\lambda & 1 \\ 0 & 2-\lambda \end{bmatrix} = (3-\lambda)(2-\lambda) - 0 = \lambda^2 - 5\lambda + 6 = 0$$

Factoring: \((\lambda-3)(\lambda-2) = 0\), so \(\lambda_1 = 3\) and \(\lambda_2 = 2\).

Eigenvector for \(\lambda_1 = 3\): solve \((A - 3I)\mathbf{v} = \mathbf{0}\): \(\begin{bmatrix}0&1\\0&-1\end{bmatrix}\mathbf{v}=\mathbf{0}\), giving \(\mathbf{v}_1 = \begin{bmatrix}1\\0\end{bmatrix}\). For \(\lambda_2 = 2\): \(\begin{bmatrix}1&1\\0&0\end{bmatrix}\mathbf{v}=\mathbf{0}\), giving \(\mathbf{v}_2 = \begin{bmatrix}-1\\1\end{bmatrix}\).

🔑 Key Property: Eigenspace

All scalar multiples \(c\mathbf{v}\) of an eigenvector are also eigenvectors with the same \(\lambda\). The set \(\{\mathbf{v} : A\mathbf{v} = \lambda\mathbf{v}\} \cup \{\mathbf{0}\}\) forms a subspace called the eigenspace of \(\lambda\). Its dimension is the geometric multiplicity of \(\lambda\).

Why It Works — The Math
▼

Trace, Determinant, and Eigenvalues

For an \(n \times n\) matrix with eigenvalues \(\lambda_1, \ldots, \lambda_n\) (counted with multiplicity), two beautiful invariants hold:

$$\operatorname{tr}(A) = \sum_{i=1}^n \lambda_i, \qquad \det(A) = \prod_{i=1}^n \lambda_i$$

These follow directly from the characteristic polynomial \(p(\lambda) = \det(A - \lambda I)\). For our 2×2 example: \(\operatorname{tr}(A) = 3+2 = 5 = \lambda_1 + \lambda_2\) ✓ and \(\det(A) = 6 = \lambda_1\lambda_2\) ✓.

General 2×2 Characteristic Polynomial

For \(A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}\):

$$p(\lambda) = \lambda^2 - (a+d)\lambda + (ad-bc) = \lambda^2 - \operatorname{tr}(A)\,\lambda + \det(A)$$

The roots via the quadratic formula:

$$\lambda = \frac{\operatorname{tr}(A) \pm \sqrt{\operatorname{tr}(A)^2 - 4\det(A)}}{2}$$

The discriminant \(\Delta = \operatorname{tr}(A)^2 - 4\det(A)\) determines the eigenvalue type: \(\Delta > 0\) gives two real distinct eigenvalues; \(\Delta = 0\) gives a repeated real eigenvalue; \(\Delta < 0\) gives complex conjugate eigenvalues.

Eigendecomposition (Diagonalization)

If \(A\) has \(n\) linearly independent eigenvectors, collect them as columns of a matrix \(P = [\mathbf{v}_1 | \cdots | \mathbf{v}_n]\). Then:

$$A = P \Lambda P^{-1}, \quad \text{where } \Lambda = \operatorname{diag}(\lambda_1, \ldots, \lambda_n)$$

This means \(A^k = P\Lambda^k P^{-1}\) — raising a matrix to a power is trivial once diagonalized. The dominant eigenvector (largest \(|\lambda|\)) governs long-run behavior.

⚠️ Common Misconception

Not every matrix is diagonalizable. A matrix \(A\) is diagonalizable iff its geometric multiplicities match its algebraic multiplicities for each eigenvalue. The matrix \(\begin{bmatrix}1&1\\0&1\end{bmatrix}\) has a repeated eigenvalue \(\lambda=1\) but only one independent eigenvector — it is defective (a Jordan block, not diagonalizable over \(\mathbb{R}\) in the standard sense). For ML in practice, covariance matrices and Gram matrices are symmetric positive semi-definite and are always diagonalizable with real, non-negative eigenvalues (Spectral Theorem).

Key Takeaways & ML Connections
▼

When eigenvalues/eigenvectors appear in ML

  • PCA: Eigenvectors of the covariance matrix \(\Sigma\) are principal components; eigenvalues give explained variance.
  • SVD: \(A = U\Sigma V^\top\) — columns of \(U\) are eigenvectors of \(AA^\top\); columns of \(V\) are eigenvectors of \(A^\top A\).
  • PageRank: The stationary distribution is the dominant eigenvector of the (column-stochastic) link matrix.
  • Hessian analysis: Eigenvalues of the loss Hessian determine optimization: large eigenvalues → sharp curvature → instability; small eigenvalues → flat directions → slow convergence.
  • Spectral clustering: The Fiedler vector (second eigenvector of the graph Laplacian) partitions a graph into two clusters.
💡 Spectrum = Skeleton

The set of all eigenvalues \(\{\lambda_i\}\) is called the spectrum of \(A\). It captures the essential behavior of the linear map: the largest eigenvalue controls long-run growth, the sign pattern controls stability, and the spread controls condition number (sensitivity to perturbations).

Symmetric matrices (most important for ML)

By the Spectral Theorem, every real symmetric matrix \(S = S^\top\) has real eigenvalues and orthonormal eigenvectors. This is why covariance matrices and graph Laplacians behave so cleanly: \(S = Q\Lambda Q^\top\) with \(Q^\top Q = I\).

Code Trace — From Scratch & NumPy
▼
import numpy as np
# Our matrix: A = [[2,1],[1,2]] (symmetric PSD)
A = np.array([[2., 1.], [1., 2.]])
# Step 1: characteristic polynomial det(A - λI) = 0
# p(λ) = λ² - tr(A)λ + det(A) = λ² - 4λ + 3
tr_A = np.trace(A) # 4.0
det_A = np.linalg.det(A) # 3.0
coeffs = [1, -tr_A, det_A] # [1, -4, 3]
lambdas = np.roots(coeffs) # [3., 1.]
# Step 2: eigenvector for λ=3 => (A - 3I)v = 0
lam1 = 3.0
null_mat = A - lam1 * np.eye(2) # [[-1,1],[1,-1]]
# Row reduce: v1 = [1, 1] / sqrt(2)
v1 = np.array([1., 1.]) / np.sqrt(2)
# Step 3: verify Av1 == lam1 * v1
assert np.allclose(A @ v1, lam1 * v1) # True
# Step 4: NumPy built-in (returns sorted ascending)
eigenvalues, eigenvectors = np.linalg.eigh(A) # use eigh for symmetric
# eigenvalues: [1., 3.]
# eigenvectors: [[-0.707, 0.707], (v2)
# [ 0.707, 0.707]] (v1)
# Step 5: diagonalization A = P @ diag(λ) @ P.T
P = eigenvectors # orthonormal columns
Lambda = np.diag(eigenvalues)
A_reconstructed = P @ Lambda @ P.T # should equal A
assert np.allclose(A_reconstructed, A) # True
# Power iteration: find dominant eigenvector
def power_iteration(M, n_iter=20):
v = np.random.randn(M.shape[0])
for _ in range(n_iter):
v = M @ v
v = v / np.linalg.norm(v) # normalize
lam = v @ M @ v # Rayleigh quotient
return v, lam
