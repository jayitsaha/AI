KNN for Regression

Predict by averaging the K nearest neighbors — lazy, non-parametric, locally adaptive
Intermediate Classical ML Supervised Learning O(n·d) inference
1
Understanding KNN Regression
▼

What is it? K-Nearest Neighbors (KNN) regression predicts a continuous output for a new query point by finding the K training points that are closest to it and averaging their target values. There is no model to train — the training data is the model. At prediction time, the algorithm simply looks up the neighborhood and computes a local average.

Analogy: Imagine you want to know the price of a house in a neighborhood you've never visited. You look up the K most similar houses sold nearby and average their prices. You don't fit a global formula — you just consult the local evidence. That's KNN regression. With distance weighting, closer houses count more than farther ones.

💡 If you remember one thing

KNN regression predicts $$\hat{y}(x_q) = \frac{1}{K} \sum_{i \in \mathcal{N}_K(x_q)} y_i$$ where \(\mathcal{N}_K(x_q)\) is the set of K training points closest to the query \(x_q\). K controls the entire bias-variance trade-off: small K → low bias, high variance; large K → high bias, low variance.

Key intuition: KNN produces a piecewise-constant regression function. Each query borrows strength only from its local neighborhood. The fitted curve is step-jagged for K = 1, increasingly smooth as K grows, and eventually flat as K → n (global mean). This local adaptivity is both KNN's superpower and its weakness.

🔑 Lazy Learning

KNN is a lazy learner: it defers all computation to query time. Training cost is \(O(1)\) (just store data). Inference cost is \(O(n \cdot d)\) — scan all n training points in d dimensions to find neighbors. This makes it expensive at scale without spatial indexing (e.g., KD-trees, ball trees).

2
How KNN Regression Works Internally
▼

Algorithm: Step by Step

1. Store training data. KNN memorises all \(n\) training pairs \(\{(x_i, y_i)\}_{i=1}^n\). No parameters are estimated, no optimization is run. The dataset itself is the "model".

2. Compute distances. Given a query point \(x_q\), compute the distance to every training point: $$d(x_q, x_i) = \|x_q - x_i\|_2 \quad (\text{Euclidean, the default})$$ Other choices include L1 (Manhattan), Minkowski, cosine, or Hamming for discrete features.

3. Select K nearest neighbors. Sort distances and pick the K smallest. Let \(\mathcal{N}_K(x_q) = \{i_1, i_2, \ldots, i_K\}\) be their indices (sorted by distance ascending).

4. Aggregate target values.

  • Uniform: $$\hat{y}(x_q) = \frac{1}{K} \sum_{j \in \mathcal{N}_K} y_j$$
  • Distance-weighted: $$\hat{y}(x_q) = \frac{\sum_{j \in \mathcal{N}_K} w_j \, y_j}{\sum_{j \in \mathcal{N}_K} w_j}, \quad w_j = \frac{1}{d(x_q, x_j) + \epsilon}$$

Distance weighting makes closer neighbors contribute more — reducing the discontinuous "jumps" in the piecewise-constant curve and providing a locally-smooth prediction surface.

Design Decision: Why K and Not a Bandwidth?

K-NN fixes the number of neighbors; kernel regression fixes a bandwidth (distance radius). In sparse regions KNN automatically expands its neighborhood (fewer points within any fixed radius), while kernel methods use a constant window that may find zero neighbors. This makes KNN naturally adaptive to local data density — a distinct advantage in irregular point clouds.

⚠️ The Curse of Dimensionality

In high dimensions, "nearest" neighbors are nearly equidistant from the query point. As \(d \to \infty\), all pairwise distances converge to the same value and the K-NN concept breaks down. Rule of thumb: KNN works well when \(d \lesssim 20\). Beyond that, use tree-based methods or dimensionality reduction first.

3
The Math — Why It Works
▼

KNN as a Local Average Estimator

KNN regression is a special case of a Nadaraya-Watson kernel estimator with a uniform kernel whose bandwidth adapts to achieve exactly K neighbors. The KNN predictor can be written as:

$$\hat{f}(x_q) = \sum_{i=1}^{n} w_i(x_q) \, y_i, \qquad w_i(x_q) = \frac{\mathbf{1}[i \in \mathcal{N}_K(x_q)]}{K}$$

where \(\mathbf{1}[\cdot]\) is the indicator function. The weights sum to 1 and are non-negative, so KNN is a locally weighted average.

Bias-Variance Decomposition

Suppose the true model is \(y_i = f(x_i) + \varepsilon_i\) with \(\varepsilon_i \overset{\text{iid}}{\sim} (0, \sigma^2)\). The MSE of the KNN predictor at a fixed query point \(x_q\) decomposes as:

$$\mathrm{MSE}[\hat{f}(x_q)] = \underbrace{\left(\mathbb{E}[\hat{f}(x_q)] - f(x_q)\right)^2}_{\text{Bias}^2} + \underbrace{\mathrm{Var}[\hat{f}(x_q)]}_{\text{Variance}}$$

Variance: Since the K neighbors' y-values are (approximately) independent with variance \(\sigma^2\):

$$\mathrm{Var}[\hat{f}(x_q)] = \frac{\sigma^2}{K}$$

Variance decreases as K increases — larger neighborhoods average out noise.

Bias: If the K-th nearest neighbor is at distance \(r_K(x_q)\) from the query, the bias is approximately:

$$\mathrm{Bias}[\hat{f}(x_q)] \approx \frac{r_K(x_q)^2}{2(d+2)} \nabla^2 f(x_q)$$

where \(d\) is the input dimension and \(\nabla^2 f\) is the Laplacian. Bias grows with K: larger K means the neighborhood radius \(r_K\) grows, averaging over a wider region that may have a different mean from \(f(x_q)\).

Optimal K and Consistency

KNN regression is universally consistent: as \(n \to \infty\) with \(K \to \infty\) and \(K/n \to 0\), the predictor converges to the true regression function \(f\) in \(L_2\). The optimal K (minimizing MSE) scales as:

$$K^* \sim n^{\frac{4}{d+4}}$$

giving MSE rate \(n^{-4/(d+4)}\) — the minimax rate for \(C^2\) regression functions. This rate degrades rapidly with dimension \(d\) (curse of dimensionality).

⚠️ Discontinuities at Voronoi Boundaries

The K=1 KNN fitted curve is exactly piecewise-constant over the Voronoi diagram of the training set: each cell predicts the y-value of its one training point. For K > 1, the boundaries are more complex but discontinuities still occur when the set of K nearest neighbors changes. Distance weighting softens (but does not eliminate) these jumps.

When to Use KNN Regression
▼
MethodTraining CostInference CostParametric?Best For
KNNO(1)O(n·d)NoLow-d, small n, irregular f
Linear RegressionO(n·d²)O(d)YesLinear relationships
Decision TreeO(n·d·log n)O(log n)NoAxis-aligned boundaries
Kernel RegressionO(1)O(n·d)NoSmooth f, bandwidth selection
Gaussian ProcessO(n³)O(n²)NoUncertainty quantification

Use KNN regression when:

  • The function is highly non-linear and local structure dominates
  • You have low-to-moderate dimensions (\(d \lesssim 20\)) and moderate n
  • You want a fast baseline before investing in heavier models
  • Interpretability matters: "prediction = average of similar examples" is easy to explain

Avoid KNN regression when:

  • High-dimensional features (d > 50) — curse of dimensionality kills performance
  • Large datasets (n > 1M) — brute-force inference is prohibitive without indexing
  • Features have very different scales — always normalise features first
  • You need probabilistic predictions or uncertainty estimates — KNN gives point estimates only
💡 Practical Tips

1. Always normalise (StandardScaler or MinMaxScaler) — distances are scale-sensitive.
2. Use cross-validation to select K; odd K avoids ties in classification, but for regression any K works.
3. KD-trees or Ball-trees reduce inference to \(O(\log n)\) in low dimensions — use sklearn's algorithm='auto'.
4. Distance weighting (weights='distance') almost always helps vs. uniform.

Code Trace

import numpy as np
# Training data (15 noisy sine points)
x_train = np.array([0.1,0.4,0.7,1.2,1.8,2.3,2.9,3.5,4.0,4.6,5.1,5.7,6.0,6.5,7.0])
y_train = np.array([0.174,0.369,0.741,1.161,0.939,0.711,0.476,-0.236,-0.827,-0.912,-0.995,-0.621,-0.243,-0.072,0.398])
def knn_predict(x_query, x_train, y_train, k=3, weighted=False):
# Step 1: compute distances to all training points
dists = np.abs(x_train - x_query) # L1 in 1D = |x_i - x_q|
idx = np.argsort(dists)[:k] # indices of K smallest distances
neighbors_y = y_train[idx] # y values of K neighbors
if not weighted:
return np.mean(neighbors_y) # uniform average
else:
w = 1.0 / (dists[idx] + 1e-10) # inverse-distance weights
return np.dot(w, neighbors_y) / w.sum() # weighted average
# Predict at query x = 3.0, K=3 (uniform)
pred = knn_predict(3.0, x_train, y_train, k=3)
print(f"Prediction: {pred:.4f}") # → 0.3170
# Production: sklearn
from sklearn.neighbors import KNeighborsRegressor
knn = KNeighborsRegressor(n_neighbors=3, weights='distance')
knn.fit(x_train.reshape(-1,1), y_train)
pred_sk = knn.predict([[3.0]])
