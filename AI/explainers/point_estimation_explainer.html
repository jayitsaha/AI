Understanding Point Estimation
▼

What is it? When you don't know some property of a population — say, the average height of all adults — you take a sample and compute a single number as your best guess. That single number is a point estimate, and the formula for computing it (e.g., "take the sample mean") is an estimator. Point estimation is the study of how good those guesses are.

Analogy: Imagine you're trying to guess the weight of a bag by weighing it on a cheap kitchen scale. The scale might be slightly off (bias), and every time you weigh it you get a slightly different reading (variance). A good scale is accurate on average (unbiased) and gives consistent readings (low variance). The mean squared error captures the total error: it combines how far off the average is AND how jumpy the readings are.

💡 If You Remember One Thing

Every estimator has a bias-variance trade-off. The MSE decomposes as $$\text{MSE}(\hat{\theta}) = \text{Bias}(\hat{\theta})^2 + \text{Var}(\hat{\theta})$$ — and this is the exact same decomposition as the machine learning bias-variance tradeoff. An estimator is "efficient" when its variance hits the theoretical floor: the Cramér-Rao Lower Bound.

The five properties covered here:

  • Bias — does the estimator aim at the right target on average?
  • Variance — how much does the estimator jump around from sample to sample?
  • MSE — the total quadratic cost = bias² + variance
  • Consistency — does the estimator converge to the truth as the sample grows?
  • Efficiency — does the estimator achieve the minimum possible variance (the CRLB)?

Historical Context & Motivation
▼

The problem: Before the 20th century, statisticians computed estimates (sample mean, proportion) but had no unified framework for evaluating how good an estimator was. Why use the sample mean to estimate the population mean? Could something else do better?

Key milestones

  • 1920s — R.A. Fisher introduced the concepts of sufficiency, efficiency, and the information inequality. He defined the maximum likelihood estimator and showed it achieves minimum variance asymptotically.
  • 1945 — Cramér & Rao independently derived the lower bound on estimator variance: \(\text{Var}(\hat{\theta}) \geq \frac{1}{I(\theta)}\), where \(I(\theta)\) is the Fisher information. This gave the first definitive answer to "how good can you possibly get?"
  • 1950 — Rao-Blackwell theorem — Given any unbiased estimator, you can always improve it (or match it) by conditioning on a sufficient statistic. This gave a constructive route to efficient estimators.
  • 1956–60 — James-Stein shrinkage — Showed that for estimating a multivariate mean, biased estimators can have lower total MSE than the unbiased sample mean. Introduced the idea of deliberately accepting bias to reduce variance.

Before vs After

EraApproachLimitation

🔑 Connection to Machine Learning

Ridge regression and LASSO introduce bias into linear model coefficients. Dropout in neural networks adds noise (effectively increasing variance during training but reducing test variance). Every regularization method is an application of the bias-variance trade-off, rooted in the statistical theory of point estimation.

The Mathematics of Estimator Quality
▼

Setup

Let \(\theta\) be an unknown parameter of a population. We observe an i.i.d. sample \(X_1, X_2, \ldots, X_n \sim f(x;\theta)\). An estimator \(\hat{\theta}_n = T(X_1,\ldots,X_n)\) is any statistic used to guess \(\theta\).

Bias

$$\text{Bias}(\hat{\theta}) = \mathbb{E}[\hat{\theta}] - \theta$$

An estimator is unbiased if \(\text{Bias}(\hat{\theta}) = 0\) for all \(\theta\). Example: \(\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i\) is unbiased for \(\mu = \mathbb{E}[X]\) because \(\mathbb{E}[\bar{X}] = \mu\). By contrast, the biased sample variance \(\tilde{s}^2 = \frac{1}{n}\sum_{i=1}^n(X_i - \bar{X})^2\) satisfies \(\mathbb{E}[\tilde{s}^2] = \frac{n-1}{n}\sigma^2\), giving bias \(= -\frac{\sigma^2}{n}\).

Variance

$$\text{Var}(\hat{\theta}) = \mathbb{E}\!\left[(\hat{\theta} - \mathbb{E}[\hat{\theta}])^2\right]$$

For the sample mean from a population with variance \(\sigma^2\): $$\text{Var}(\bar{X}) = \frac{\sigma^2}{n}$$. This shrinks as \(n\) grows, making the estimator more precise with more data.

MSE Decomposition (the central identity)

$$\text{MSE}(\hat{\theta}) = \mathbb{E}\!\left[(\hat{\theta} - \theta)^2\right] = \text{Bias}(\hat{\theta})^2 + \text{Var}(\hat{\theta})$$

Proof: Let \(b = \mathbb{E}[\hat{\theta}] - \theta\). Then:

$$\mathbb{E}[(\hat{\theta}-\theta)^2] = \mathbb{E}[(\hat{\theta}-\mathbb{E}[\hat{\theta}]+b)^2] = \mathbb{E}[(\hat{\theta}-\mathbb{E}[\hat{\theta}])^2] + 2b\underbrace{\mathbb{E}[\hat{\theta}-\mathbb{E}[\hat{\theta}]]}_{=0} + b^2 = \text{Var}(\hat{\theta}) + b^2$$

At \(c=1\) (unbiased), MSE equals pure variance \(\sigma^2/n=0.4\). Any deviation in \(c\) adds a quadratic bias penalty.

Consistency

An estimator is consistent if it converges in probability to the true value:

$$\hat{\theta}_n \xrightarrow{p} \theta \quad \Leftrightarrow \quad \forall \varepsilon > 0,\; P(|\hat{\theta}_n - \theta| > \varepsilon) \to 0 \text{ as } n \to \infty$$

Chebyshev's inequality gives a concrete bound: \(P(|\bar{X}_n - \mu| > \varepsilon) \leq \frac{\text{Var}(\bar{X}_n)}{\varepsilon^2} = \frac{\sigma^2}{n\varepsilon^2} \to 0\). With \(\sigma=2\), \(\varepsilon=0.5\): for \(n=100\) the bound is 0.16; for \(n=10{,}000\) it is 0.0016.

⚠️ Unbiased ≠ Consistent

The estimator \(\hat{\theta} = X_1\) (just the first observation, ignoring all others) is unbiased (\(\mathbb{E}[X_1]=\mu\)) but NOT consistent — its variance \(\sigma^2\) never shrinks. Conversely, the biased \(\tilde{s}^2\) IS consistent because its bias \(-\sigma^2/n \to 0\).

Efficiency & the Cramér-Rao Lower Bound

The Fisher information \(I_n(\theta)\) measures how much information a sample of size \(n\) carries about \(\theta\):

$$I_n(\theta) = \mathbb{E}\!\left[\left(\frac{\partial}{\partial\theta}\log f(X;\theta)\right)^2\right] = -\mathbb{E}\!\left[\frac{\partial^2}{\partial\theta^2}\log f(X;\theta)\right]$$

For i.i.d. samples: \(I_n(\theta) = n \cdot I_1(\theta)\). The Cramér-Rao Lower Bound (CRLB) states: for any unbiased estimator \(\hat{\theta}\),

$$\text{Var}(\hat{\theta}) \geq \frac{1}{I_n(\theta)}$$

An estimator achieving this bound is called efficient. Example: for \(X_i \sim \mathcal{N}(\mu,\sigma^2)\), \(I_n(\mu) = n/\sigma^2\), so CRLB \(= \sigma^2/n\). The sample mean \(\bar{X}\) achieves exactly this, so it is efficient.

📐 Fisher Information for Normal Mean

Log-likelihood: \(\ell(\mu) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum(x_i-\mu)^2\). Score: \(\frac{\partial\ell}{\partial\mu} = \frac{1}{\sigma^2}\sum(x_i-\mu)\). Fisher info: \(I_n(\mu)=\mathbb{E}[\text{score}^2]=n/\sigma^2\). So CRLB \(=\sigma^2/n\) — matched exactly by \(\bar{X}\).

Key Takeaways & ML Connection
▼

Summary of properties

PropertyDefinitionML Analogue
Bias\(\mathbb{E}[\hat{\theta}]-\theta\)Underfitting (systematic error)
Variance\(\mathbb{E}[(\hat{\theta}-\mathbb{E}[\hat{\theta}])^2]\)Overfitting (sensitivity to training data)
MSEBias² + VarianceGeneralization error decomposition
Consistency\(\hat{\theta}_n \xrightarrow{p} \theta\)More data → better model (the deep learning scaling law)
EfficiencyVar = CRLB = 1/INo "free lunch" — optimal use of data

The ML bias-variance trade-off is literally this

For a regression model with fixed training set of size \(n\), the expected test MSE decomposes as:

$$\mathbb{E}\!\left[(y - \hat{f}(x))^2\right] = \text{Bias}[\hat{f}(x)]^2 + \text{Var}[\hat{f}(x)] + \sigma^2_\varepsilon$$

The \(\sigma^2_\varepsilon\) term is irreducible noise. Regularization (Ridge, LASSO, dropout, weight decay) reduces variance at the cost of increased bias — exactly the James-Stein idea from 1956.

💡 Efficient Estimators in Practice

MLE is asymptotically efficient: as \(n\to\infty\), \(\sqrt{n}(\hat{\theta}_{MLE}-\theta) \xrightarrow{d} \mathcal{N}(0, I_1(\theta)^{-1})\). This means MLE extracts the maximum information from data in the large-sample limit. In deep learning, while models are not estimating a scalar \(\theta\), the CRLB intuition survives: more expressive models trained on more data approach the data-generating process.

Code Trace
▼
import numpy as np
# True parameter: population mean mu=5, variance sigma^2=4
np.random.seed(42); mu=5.0; sigma2=4.0; sigma=2.0
# --- BIAS ---
# Unbiased estimator: sample mean
n = 10; samples = np.random.normal(mu, sigma, (10000, n))
xbar = samples.mean(axis=1) # shape (10000,)
print(f"E[X_bar] = {xbar.mean():.4f}") # ≈ 5.0 (unbiased)
# Biased estimator: 1/n * sum(Xi^2 - sample_var) ... simpler: c*X_bar
c = 0.9; biased_est = c * xbar
print(f"Bias(0.9*X_bar) = {biased_est.mean()-mu:.4f}") # ≈ -0.5
# --- MSE DECOMPOSITION ---
def mse_decompose(estimates, theta):
bias = estimates.mean() - theta
variance = estimates.var()
mse = ((estimates - theta)**2).mean()
return bias, variance, mse
b, v, m = mse_decompose(xbar, mu)
print(f"X_bar: bias={b:.4f}, var={v:.4f}, mse={m:.4f}") # 0, 0.4, 0.4
print(f"Check: bias^2+var = {b**2+v:.4f}") # 0.4
# --- CONSISTENCY ---
for n in [10, 100, 1000, 10000]:
samp = np.random.normal(mu, sigma, (5000, n))
xb = samp.mean(axis=1)
prob = (np.abs(xb - mu) > 0.5).mean()
print(f"n={n:5d}: P(|X_bar-mu|>0.5) ≈ {prob:.4f}")
# --- CRAMER-RAO LOWER BOUND ---
# Fisher info for Normal(mu, sigma^2): I_n(mu) = n/sigma^2
n = 50
fisher_info = n / sigma2 # = 12.5
crlb = 1 / fisher_info # = 0.08
actual_var = sigma2 / n # = 0.08 (X_bar is efficient)
print(f"CRLB={crlb:.4f}, Var(X_bar)={actual_var:.4f}")
print(f"Efficient: {actual_var <= crlb + 1e-9}")
