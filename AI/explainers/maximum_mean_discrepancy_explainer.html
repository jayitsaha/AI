Understanding Maximum Mean Discrepancy (MMD)
▼

What is it? Maximum Mean Discrepancy (MMD) is a powerful statistical test and metric used to determine if two sets of samples come from the same underlying probability distribution. Unlike traditional methods that require estimating densities (which is hard in high dimensions), MMD works by mapping the samples into a high-dimensional feature space (a Reproducing Kernel Hilbert Space, RKHS) and then simply comparing the means of these mapped samples.

Analogy: Imagine you have two piles of sand, one red and one blue. You want to know if they came from the same beach. Instead of trying to count every grain or draw a perfect outline of each pile (density estimation), MMD suggests: "Let's take a scoop from the center of mass of each pile. If the two scoops (the 'mean embeddings' in RKHS) are different enough, then the piles likely came from different beaches." The magic is that this 'scoop' can capture very complex differences between the piles.

💡 If you remember one thing

MMD measures the distance between two distributions \(\mathcal{P}\) and \(\mathcal{Q}\) by comparing the means of their samples after mapping them into a high-dimensional feature space \(\mathcal{H}\) defined by a kernel function \(k\). Importantly, \(MMD(\mathcal{P}, \mathcal{Q}) = 0\) if and only if \(\mathcal{P} = \mathcal{Q}\) (when using a suitable "characteristic" kernel).

2
How MMD Works Internally
▼

The Core Idea: Embedding into an RKHS

At its heart, MMD leverages the "kernel trick." Instead of directly comparing distributions \(\mathcal{P}\) and \(\mathcal{Q}\) in their original data space, MMD maps each data point \(x\) into a high (possibly infinite) dimensional feature space \(\mathcal{H}\) using a feature map \(\phi: \mathcal{X} \to \mathcal{H}\). The key is that we don't need to explicitly know \(\phi(x)\); all we need is a kernel function \(k(x, y) = \langle \phi(x), \phi(y) \rangle_{\mathcal{H}}\) which computes the inner product between two points in this feature space.

In this RKHS, each distribution \(\mathcal{P}\) is represented by its "mean embedding" \(\mu_{\mathcal{P}} = \mathbb{E}_{x \sim \mathcal{P}}[\phi(x)]\). The MMD is then simply the distance between these mean embeddings in the RKHS:

$$MMD(\mathcal{P}, \mathcal{Q}) = \|\mu_{\mathcal{P}} - \mu_{\mathcal{Q}}\|_{\mathcal{H}}$$

This distance can be computed using only kernel evaluations, avoiding explicit high-dimensional mappings.

Empirical Estimation from Samples

In practice, we don't have access to the true distributions \(\mathcal{P}\) and \(\mathcal{Q}\), but rather finite samples \(X = \{x_1, \dots, x_n\}\) from \(\mathcal{P}\) and \(Y = \{y_1, \dots, y_m\}\) from \(\mathcal{Q}\). We can estimate the mean embeddings empirically:

$$\hat{\mu}_{\mathcal{P}} = \frac{1}{n} \sum_{i=1}^n \phi(x_i) \quad \text{and} \quad \hat{\mu}_{\mathcal{Q}} = \frac{1}{m} \sum_{j=1}^m \phi(y_j)$$

The empirical MMD is then calculated using these sample means. The beauty is that the squared MMD can be expressed purely in terms of kernel function evaluations between samples, without ever needing to compute \(\phi(x)\) explicitly. This is computationally efficient and avoids the "curse of dimensionality" that plagues density estimation.

Design Decision: Why RKHS and Kernels?

The RKHS framework allows MMD to compare highly complex distributions. A carefully chosen kernel (like the Gaussian kernel) can map data into a space where even non-linear relationships become linearly separable. This means MMD can detect subtle differences between distributions that simpler metrics might miss. The kernel trick makes this computationally feasible, turning potentially infinite-dimensional calculations into sums over pairwise similarities in the original data space.

🔑 Key Property

The MMD is a distance between functions (the mean embeddings) in a Reproducing Kernel Hilbert Space, not directly between probability densities. This allows it to detect differences even when densities are hard to estimate, and it's easily differentiable, making it suitable for optimization in machine learning tasks.

3
Why It Works — The Math
▼

Formal Definition and The Supremum Form

The MMD between two distributions \(\mathcal{P}\) and \(\mathcal{Q}\) is formally defined as the supremum (the least upper bound) over a class of functions \(f\) in the unit ball of the RKHS \(\mathcal{H}\):

$$MMD(\mathcal{P}, \mathcal{Q}) = \sup_{\|f\|_{\mathcal{H}} \le 1} \left( \mathbb{E}_{x \sim \mathcal{P}}[f(x)] - \mathbb{E}_{y \sim \mathcal{Q}}[f(y)] \right)$$

This means MMD finds the function \(f\) (from a specific class) that maximizes the difference between the expected values under \(\mathcal{P}\) and \(\mathcal{Q}\). If such a function can find a large difference, the distributions are far apart. If no such function can find a significant difference, they are close.

The Kernel Trick Derivation

Using properties of RKHS and the kernel trick, the squared MMD can be elegantly expressed without explicit feature maps \(\phi(x)\). For distributions \(\mathcal{P}\) and \(\mathcal{Q}\), the squared MMD is:

$$MMD^2(\mathcal{P}, \mathcal{Q}) = \mathbb{E}_{x,x' \sim \mathcal{P}}[k(x,x')] + \mathbb{E}_{y,y' \sim \mathcal{Q}}[k(y,y')] - 2\mathbb{E}_{x \sim \mathcal{P}, y \sim \mathcal{Q}}[k(x,y)]$$

Here, \(x, x'\) are independent samples from \(\mathcal{P}\), and \(y, y'\) are independent samples from \(\mathcal{Q}\). This form breaks MMD down into three intuitive terms: the average similarity within samples from \(\mathcal{P}\), the average similarity within samples from \(\mathcal{Q}\), and the average similarity between samples from \(\mathcal{P}\) and \(\mathcal{Q}\). If the distributions are identical, the within-distribution similarities will balance out the cross-distribution similarities, leading to MMD = 0.

Empirical MMD from Samples

Given finite samples \(X = \{x_1, \dots, x_n\}\) and \(Y = \{y_1, \dots, y_m\}\), we can estimate the expectations using sample averages. The unbiased empirical MMD estimator (often used in practice, though a biased version is simpler for visualization) is:

$$\widehat{MMD}^2(X, Y) = \frac{1}{n(n-1)} \sum_{i \ne j} k(x_i, x_j) + \frac{1}{m(m-1)} \sum_{i \ne j} k(y_i, y_j) - \frac{2}{nm} \sum_{i=1}^n \sum_{j=1}^m k(x_i, y_j)$$

A simpler, biased estimator (which we'll use in the interactive section for clarity, as it includes diagonal terms `k(x_i, x_i)`) is:

$$\widehat{MMD}^2(X, Y) = \frac{1}{n^2} \sum_{i=1}^n \sum_{j=1}^n k(x_i, x_j) + \frac{1}{m^2} \sum_{i=1}^m \sum_{j=1}^m k(y_i, y_j) - \frac{2}{nm} \sum_{i=1}^n \sum_{j=1}^m k(x_i, y_j)$$

The choice of kernel \(k\) is crucial. A common choice is the Gaussian (RBF) kernel: \(k(x,y) = \exp\left(-\frac{\|x-y\|^2}{2\sigma^2}\right)\), where \(\sigma\) is the bandwidth parameter. This kernel is "characteristic," meaning MMD=0 if and only if the distributions are identical.

⚠️ Common Pitfall

The choice of kernel and its bandwidth (\(\sigma\)) is critical. A too-small \(\sigma\) makes the kernel too localized, only seeing nearest neighbors, and MMD will be large even for slightly overlapping distributions. A too-large \(\sigma\) makes the kernel too smooth, making everything look similar, and MMD will be small even for distinct distributions. Often, \(\sigma\) is chosen via median heuristic or cross-validation.

Key Takeaways
▼

When to use MMD:

  • Generative Models: As a loss function for Generative Adversarial Networks (GANs) or Variational Autoencoders (VAEs) to encourage generated samples to match real data distribution.
  • Domain Adaptation: To align feature distributions between a source domain (with labels) and a target domain (unlabeled) so a classifier trained on source data generalizes better.
  • Two-Sample Testing: To statistically test whether two finite samples \(X\) and \(Y\) are drawn from the same distribution.
  • Unsupervised Representation Learning: To learn representations that are invariant to certain nuisance factors by minimizing MMD between distributions conditioned on different factors.

When NOT to use:

  • High-Dimensional Data with Limited Samples: The empirical estimate of MMD can be noisy, and kernel computations become sparse or computationally expensive.
  • When Explicit Density Estimation is Required: MMD gives a distance, but not an interpretable density function. If you need to know *what* the densities are, MMD won't directly provide it.
  • When Interpretability of Individual Features is Paramount: The kernel trick maps data into an abstract feature space, making it harder to interpret which specific features contribute to the discrepancy.
💡 MMD vs. Other Divergences

MMD offers a compelling alternative to metrics like KL-divergence or Wasserstein distance. It's computationally efficient (no density estimation needed), easily differentiable (good for gradient-based optimization), and can be computed directly from samples. Unlike KL-divergence, it's symmetric and well-defined even when distributions have disjoint support.

import numpy as np
def gaussian_kernel(X, Y, sigma=1.0):
"""Computes the Gaussian (RBF) kernel matrix."""
# Squared Euclidean distance matrix
diff = X[:, np.newaxis, :] - Y[np.newaxis, :, :]
sq_dist = np.sum(diff**2, axis=-1)
return np.exp(-sq_dist / (2 * sigma**2))
def mmd_squared(X, Y, kernel_fn, sigma=1.0):
"""Computes the biased empirical MMD^2."""
n, m = X.shape[0], Y.shape[0]
# Compute kernel matrices
K_XX = kernel_fn(X, X, sigma=sigma)
K_YY = kernel_fn(Y, Y, sigma=sigma)
K_XY = kernel_fn(X, Y, sigma=sigma)
# Sum terms
term_xx = np.sum(K_XX) / (n * n)
term_yy = np.sum(K_YY) / (m * m)
term_xy = np.sum(K_XY) / (n * m)
return term_xx + term_yy - 2 * term_xy
