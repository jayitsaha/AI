1
Understanding Recurrent Networks
▼

What are they? Recurrent Neural Networks (RNNs), Long Short-Term Memory (LSTMs), and Gated Recurrent Units (GRUs) are specialized neural network architectures designed to process sequential data. Unlike traditional feedforward networks that treat inputs independently, recurrent networks maintain an internal "hidden state" that captures information from previous steps in the sequence, allowing them to model temporal dependencies.

Why are they needed? Many real-world problems involve sequences: time series data (stock prices, weather), natural language (words in a sentence), audio, and video. For these, the order of data points matters, and information from earlier points is crucial for understanding later ones. Standard neural networks lack this "memory" mechanism.

Analogy: Imagine reading a story. To understand the current sentence, you need to remember characters, plot points, and context from previous sentences. An RNN is like a reader who keeps a small, evolving summary of the story in their head, constantly updating it as they read new sentences. This summary (the hidden state) is then used to interpret the next part of the story.

💡 If you remember one thing

Recurrent networks process sequences one element at a time, updating an internal hidden state that acts as a memory of past inputs. This hidden state is then passed to the next step, closing a feedback loop. LSTMs and GRUs are advanced versions that solve the "short-term memory" problem of simple RNNs using sophisticated gating mechanisms.

2
How RNNs Work (and Why They Fail)
▼

The Basic RNN Cell

A vanilla RNN processes an input \(x_t\) at time step \(t\) by combining it with the hidden state \(h_{t-1}\) from the previous time step. The new hidden state \(h_t\) is computed, and an output \(\hat{y}_t\) is often derived from \(h_t\). The same set of weights is reused across all time steps — this is the "recurrent" part.

$$h_t = \tanh(W_{hh}h_{t-1} + W_{xh}x_t + b_h)$$
$$\hat{y}_t = W_{hy}h_t + b_y$$

Here, \(W_{hh}\) transforms the previous hidden state, \(W_{xh}\) transforms the current input, and \(b_h\) is a bias. \(\tanh\) is a common activation function. The output \(\hat{y}_t\) is typically a linear transformation of \(h_t\), possibly followed by another activation (e.g., softmax for classification).

The Problem: Vanishing/Exploding Gradients

While elegant, simple RNNs struggle with long-term dependencies. During backpropagation through time (BPTT), gradients are repeatedly multiplied by the weight matrices. If these weights are small, gradients can shrink exponentially (vanishing gradients), making it hard for the network to learn connections between distant inputs and outputs. If weights are large, gradients can grow exponentially (exploding gradients), leading to unstable training. This effectively gives simple RNNs a very "short memory."

The Solution: LSTMs and GRUs

To overcome this, LSTMs (Long Short-Term Memory) and GRUs (Gated Recurrent Units) were invented. They introduce "gates" — special neural networks within the recurrent cell that learn to control the flow of information. These gates decide what information to store, what to forget, and what to pass on, allowing them to maintain a more stable "memory" over longer sequences.

🔑 Key Property

LSTMs and GRUs solve the vanishing gradient problem by using additive updates to a special "cell state" (LSTM) or "candidate hidden state" (GRU) controlled by multiplicative gates. This allows gradients to flow more easily through time without vanishing.

3
Why It Works — The Gating Mechanisms
▼

LSTM: The Three Gates and Cell State

LSTMs introduce a cell state \(C_t\) which runs straight through the cell, only modified by element-wise multiplication with gates. This "conveyor belt" allows information to flow largely unchanged. There are three main gates, all using a sigmoid activation \(\sigma\) to output values between 0 and 1, controlling how much of a signal gets through:

  1. Forget Gate (\(f_t\)): Decides what information to throw away from the previous cell state \(C_{t-1}\).
  2. Input Gate (\(i_t\)) & Candidate Cell State (\(\tilde{C}_t\)): Decides what new information from \(x_t\) and \(h_{t-1}\) to store in the cell state.
  3. Output Gate (\(o_t\)): Decides what parts of the cell state to output as the new hidden state \(h_t\).

The equations for an LSTM cell are:

$$ \begin{aligned} f_t &= \sigma(W_f[h_{t-1}, x_t] + b_f) \\ i_t &= \sigma(W_i[h_{t-1}, x_t] + b_i) \\ \tilde{C}_t &= \tanh(W_C[h_{t-1}, x_t] + b_C) \\ C_t &= f_t \odot C_{t-1} + i_t \odot \tilde{C}_t \\ o_t &= \sigma(W_o[h_{t-1}, x_t] + b_o) \\ h_t &= o_t \odot \tanh(C_t) \end{aligned} $$

Here, \([h_{t-1}, x_t]\) denotes concatenation of the previous hidden state and current input, and \(\odot\) is element-wise multiplication.

GRU: Simplified Gating

GRUs are a simplified version of LSTMs, combining the cell state and hidden state into a single hidden state \(h_t\), and reducing the number of gates to two:

  1. Update Gate (\(z_t\)): Controls how much of the previous hidden state \(h_{t-1}\) to carry over to the current hidden state.
  2. Reset Gate (\(r_t\)): Decides how much of the previous hidden state to "forget" when computing the new candidate hidden state \(\tilde{h}_t\).

The equations for a GRU cell are:

$$ \begin{aligned} z_t &= \sigma(W_z[h_{t-1}, x_t] + b_z) \\ r_t &= \sigma(W_r[h_{t-1}, x_t] + b_r) \\ \tilde{h}_t &= \tanh(W_h[r_t \odot h_{t-1}, x_t] + b_h) \\ h_t &= (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t \end{aligned} $$

GRUs are computationally less expensive than LSTMs and often perform similarly, especially on large datasets.

⚠️ Common Pitfall

The choice between LSTM and GRU often comes down to empirical performance and computational budget. LSTMs are generally more powerful for very complex, long-range dependencies due to the explicit cell state, but GRUs can be faster to train and generalize well, especially on smaller datasets or when model size is critical.

When to use RNN/LSTM/GRU:

  • Time Series Forecasting: Predicting future stock prices, weather, sensor readings.
  • Natural Language Processing (NLP): Machine translation, sentiment analysis, text generation, speech recognition.
  • Sequence Generation: Generating music, video frames, code.
  • Any data where temporal order and context are important.

When NOT to use:

  • Independent Data: For tabular data or images where order doesn't matter, feedforward or convolutional networks are more appropriate.
  • Very Long Sequences with Global Dependencies: For extremely long sequences (e.g., thousands of tokens in NLP), Transformers with their attention mechanisms often outperform RNNs/LSTMs/GRUs due to parallelization and direct modeling of long-range interactions.
  • Simple Tasks: If a simpler model (e.g., ARIMA for time series) performs adequately, the complexity of RNNs might be overkill.
💡 Big Picture

The evolution from simple RNNs to LSTMs and GRUs represents a crucial breakthrough in deep learning, enabling models to effectively learn from and generate complex sequential data. While Transformers have taken over many state-of-the-art applications, LSTMs/GRUs remain foundational and highly efficient choices for many sequence modeling tasks.

Code Trace — PyTorch Example
▼
import torch
import torch.nn as nn
input_size = 10 # e.g., 10 features per time step
hidden_size = 20 # size of the hidden state
output_size = 1 # e.g., predicting a single scalar
num_layers = 1 # number of stacked recurrent layers
batch_size = 32
seq_len = 50 # length of the input sequence
# 1. Define the RNN/LSTM/GRU layer
# model = nn.RNN(input_size, hidden_size, num_layers, batch_first=True)
model = nn.LSTM(input_size, hidden_size, num_layers, batch_first=True)
# model = nn.GRU(input_size, hidden_size, num_layers, batch_first=True)
# A linear layer to map the hidden state to the desired output size
output_layer = nn.Linear(hidden_size, output_size)
# 2. Prepare dummy input data
# Input: (batch_size, seq_len, input_size)
input_data = torch.randn(batch_size, seq_len, input_size)
# 3. Forward pass
# For RNN/GRU: output, hidden_state = model(input_data)
# For LSTM: output, (hidden_state, cell_state) = model(input_data)
lstm_output, (final_h, final_c) = model(input_data)
# lstm_output: (batch_size, seq_len, hidden_size) - hidden state for each time step
# final_h: (num_layers, batch_size, hidden_size) - final hidden state across layers
# final_c: (num_layers, batch_size, hidden_size) - final cell state across layers
# 4. Get the prediction for the last time step (common for sequence prediction)
last_hidden_state = lstm_output[:, -1, :] # Take hidden state from last time step
prediction = output_layer(last_hidden_state)
print(f"Input shape: {input_data.shape}")
print(f"LSTM output shape: {lstm_output.shape}")
print(f"Final hidden state shape: {final_h.shape}")
print(f"Prediction shape: {prediction.shape}")
