1
Understanding State-Space Models
▼

What is it? A state-space model (SSM) is a sequence model built from classical control theory: it keeps a small "hidden state" vector that acts like a running summary of everything seen so far, updates that summary with each new input via a linear rule, and reads a prediction off the summary. S4 (Structured State Space) made this trainable at scale with a clever fixed-matrix parameterization; Mamba then let the update rule itself change based on the input, giving the model the ability to "choose" what to remember.

Analogy: Picture a detective keeping a running case notebook. A plain RNN scribbles a new note on top of the old one every time, no matter how trivial the new clue is. A state-space model is a detective who has learned a smooth, principled way to blend old notes with new evidence — like a Kalman filter's belief update. Mamba's twist: the detective now decides, clue by clue, how strongly to update the notebook — a shocking confession rewrites pages, "um" and "uh" leave it untouched.

💡 If you remember one thing

An SSM is a linear recurrence \(h_t = \bar{A} h_{t-1} + \bar{B} x_t\), \(y_t = C h_t\) — exactly like an RNN, but derived from a continuous-time ODE and (in S4) parameterized so it can be computed as a global convolution. Mamba's key idea: make \(\bar{A}, \bar{B}, C\) depend on \(x_t\) itself, so the recurrence becomes selective — content-aware, not just position-aware.

How It Works Internally
▼

The Continuous-Time Origin

An SSM starts from a linear ODE borrowed from control theory: \(h'(t) = A h(t) + B x(t)\), \(y(t) = C h(t)\), where \(h(t) \in \mathbb{R}^N\) is the latent state, \(A \in \mathbb{R}^{N\times N}\) governs how the state evolves on its own, and \(B, C\) read the input in and the output out. To run this on discrete tokens, we discretize with a step size \(\Delta\) (zero-order hold), producing discrete matrices \(\bar{A} = e^{\Delta A}\) and \(\bar{B} = A^{-1}(\bar{A}-I)B\), and the familiar recurrence \(h_t = \bar{A}h_{t-1} + \bar{B}x_t\).

S4: Structure Makes It Trainable

Naively, this recurrence is just a linear RNN — slow to train (sequential) and, with a random \(A\), forgets everything almost immediately. S4's contributions were: (1) initialize \(A\) with the HiPPO matrix, which is mathematically derived to optimally compress a streaming signal's history into a fixed-size state; (2) constrain \(A\) to a structured form (diagonal or diagonal-plus-low-rank) so the discretization and the equivalent convolution kernel \(K = (C\bar{B}, C\bar{A}\bar{B}, C\bar{A}^2\bar{B}, \dots)\) can be computed in \(O(N\log L)\) via FFT — turning training into one big parallel convolution instead of a slow sequential loop.

Mamba: From Time-Invariant to Selective

S4's \(\bar{A}, \bar{B}, C\) are fixed once trained — the same filter is applied everywhere, regardless of token content. Mamba (2023) removes this restriction: \(\Delta_t, B_t, C_t\) become linear projections of the current input token \(x_t\). The system is no longer linear time-invariant (LTI) — it is linear time-varying (LTV), sometimes called "S6". This breaks the convolution trick (the kernel is no longer fixed), so Mamba instead computes the recurrence with a hardware-aware parallel associative scan, fusing the discretization and recurrence into a single GPU kernel that never materializes the full state in slow memory.

🔑 Key Property

Selectivity means \(\Delta_t\) acts as a learned gate: small \(\Delta_t \Rightarrow \bar{A}_t \approx I, \bar{B}_t \approx 0\) (the token is ignored, state persists); large \(\Delta_t \Rightarrow \bar{A}_t \approx 0\) (the state "resets" and is dominated by the new input). This gives Mamba the ability to skip filler tokens and latch onto salient ones — something a fixed-kernel S4/CNN fundamentally cannot do.

Why It Works — The Math
▼

Exact Discretization (Zero-Order Hold)

Holding \(x(t)=x_k\) constant over \([k\Delta,(k+1)\Delta]\), the ODE \(h'(t)=Ah(t)+Bx(t)\) has the integrating-factor solution \(\frac{d}{dt}\big[e^{-At}h(t)\big] = e^{-At}Bx(t)\). Integrating over one step and simplifying:

$$\bar{A} = e^{\Delta A}, \qquad \bar{B} = A^{-1}\left(e^{\Delta A} - I\right) B$$

giving the exact discrete update \(h_k = \bar{A}h_{k-1} + \bar{B}x_k\), \(y_k = Ch_k\). When \(A\) is diagonal (as in S4D and Mamba) this is elementwise — no matrix exponential needed, just \(N\) scalar exponentials.

The Convolutional View (S4, LTI only)

Unrolling the recurrence shows \(y_k = \sum_{i=0}^{k} \left(C\bar{A}^{i}\bar{B}\right) x_{k-i}\), i.e. \(y = K * x\) with kernel \(K_i = C\bar{A}^i\bar{B}\). Because \(\bar A,\bar B,C\) don't change with \(t\), \(K\) can be precomputed once — this is what makes S4 trainable as a single global convolution (parallel over the sequence, unlike an RNN).

$$y_k = (K * x)_k, \qquad K = \big(C\bar{B},\; C\bar{A}\bar{B},\; C\bar{A}^2\bar{B},\; \dots\big)$$

Selectivity Breaks — and Rescues — Efficiency

Mamba defines \(\Delta_t = \text{softplus}(W_\Delta x_t + b_\Delta)\), \(B_t = W_B x_t\), \(C_t = W_C x_t\). Because \(\bar A_t, \bar B_t\) now depend on \(t\), there is no single fixed kernel \(K\) — the sum \(y_k=\sum_i C_k\big(\prod_{j} \bar A_{k-j}\big)\bar B_{k-i}x_{k-i}\) must, in principle, be evaluated recurrently. The saving grace: the recurrence's combination operator is associative, \((\bar A_i,\bar B_i x_i)\otimes(\bar A_j,\bar B_j x_j)=(\bar A_i\bar A_j,\ \bar A_j \bar B_i x_i+\bar B_j x_j)\), which is exactly the structure a parallel prefix scan exploits: \(O(L)\) work but only \(O(\log L)\) sequential depth, versus attention's \(O(L^2)\) work and \(O(1)\) depth but quadratic memory.

⚠️ Common Pitfall

Treating \(A\) as a free, unconstrained matrix is a trap: an untrained/randomly-initialized \(A\) makes the recurrence forget almost instantly (eigenvalues of \(\bar A\) near 0) or blow up (eigenvalues \(>1\)). This is exactly the vanishing/exploding gradient problem that plagued vanilla RNNs — HiPPO-style initialization and diagonal, negative-real-part \(A\) are what make SSMs trainable at all.

Key Takeaways
▼

When to reach for SSMs (S4/Mamba):

  • Very long sequences (audio, genomics, high-res pixels) where attention's \(O(L^2)\) memory is prohibitive
  • Streaming / online inference — SSMs run as an \(O(1)\)-per-step recurrence at inference, no growing KV cache
  • Tasks needing content-based selective memory (selective copying, induction) — use Mamba, not plain S4

When NOT to use them:

  • Short sequences where attention's quadratic cost is a non-issue and its in-context flexibility wins
  • Tasks requiring precise, exact random-access retrieval across the whole context — attention's explicit pairwise scores still have an edge over a fixed-size compressed state
  • When you need the mature tooling/interpretability ecosystem built around Transformers
💡 Hierarchy

Vanilla RNN (unconstrained, unstable \(A\)) ⊂ Linear RNN / S4 (structured, HiPPO-initialized, LTI, convolution-trainable) ⊂ Mamba / S6 (LTV, input-dependent \(\Delta,B,C\), parallel-scan-trainable). Each layer relaxes an assumption of the previous one — S4 fixes RNN instability; Mamba fixes S4's lack of content-awareness.

Code Trace
▼
import numpy as np
def softplus(x):
return np.log1p(np.exp(x))
# Zero-order-hold discretization (A diagonal -> elementwise)
def discretize(A, B, delta):
Abar = np.exp(delta * A) # e^{Delta A}
Bbar = (Abar - 1) / A * B # A^-1 (Abar - I) B
return Abar, Bbar
# Fixed, structured state matrix (HiPPO-style: negative, diagonal)
A = np.array([-0.5, -1.0, -0.2])
B_base = np.array([1.0, 0.5, 0.8])
C_base = np.array([0.6, -0.3, 0.9])
# --- S4 / LTI: fixed Delta, one discretization for the whole sequence ---
Abar_lti, Bbar_lti = discretize(A, B_base, delta=0.5)
h = np.zeros(3)
for x_t in tokens:
h = Abar_lti * h + Bbar_lti * x_t # same filter every step
y_t = C_base @ h
# --- Mamba / S6: selection -- Delta, B, C depend on x_t ---
def selective_ssm_step(h_prev, x_t, A, W_delta, b_delta, W_B, W_C, C_base):
delta_t = softplus(W_delta * x_t + b_delta) # input-dependent gate
B_t = B_base + W_B * x_t # input-dependent B
C_t = C_base + W_C * x_t # input-dependent C
Abar_t, Bbar_t = discretize(A, B_t, delta_t) # per-token discretization
h_t = Abar_t * h_prev + Bbar_t * x_t # the scan's recurrence step
y_t = C_t @ h_t
return h_t, y_t
# Parallel associative scan replaces this python loop on real hardware,
# giving O(L) work with O(log L) sequential depth instead of O(L) depth.
