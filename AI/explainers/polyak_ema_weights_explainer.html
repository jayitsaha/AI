Understanding Polyak / EMA Averaging
▼

What is it? When you train a neural network, gradient descent bounces around — each step lands in a slightly different part of the loss landscape due to noise (mini-batch gradients aren't perfect). Instead of keeping only the last parameter vector, Polyak–Ruppert averaging keeps a running average of all the parameter vectors visited during training. The average is much smoother and sits closer to the true minimum.

Analogy: Imagine a drunk person walking toward a destination. Any single step lands them somewhere random, but the average position over many steps stays reliably close to the true path. The average "smooths out" the randomness and gets you closer to where you actually want to go.

Two flavors: Polyak–Ruppert averaging takes the uniform mean of all past iterates. Exponential Moving Average (EMA) gives exponentially more weight to recent iterates using a decay coefficient \(\beta \in (0,1)\), so the model can adapt as training progresses. Both share the same core insight: averaging reduces variance.

If you remember one thing

Averaging SGD iterates reduces the variance of the estimator without increasing bias (under standard conditions), giving you a better final model for free — just keep a running average of weights alongside your optimizer, at zero extra gradient computation cost.

How It Works Internally
▼

The Two Averaging Schemes

Polyak–Ruppert averaging (1992) maintains the uniform running mean of all iterates produced by SGD:

$$\bar{\theta}_T = \frac{1}{T}\sum_{t=1}^{T} \theta_t$$

Updated online at each step via: \(\bar{\theta}_t = \bar{\theta}_{t-1} + \frac{1}{t}(\theta_t - \bar{\theta}_{t-1})\). Note this is exact — no approximation — but all past iterates equally weighted.

Exponential Moving Average (EMA) generalizes this by letting recent iterates matter more, controlled by a decay coefficient \(\beta \in (0,1)\):

$$\bar{\theta}_t = \beta\,\bar{\theta}_{t-1} + (1 - \beta)\,\theta_t$$

The effective memory (half-life in steps) is \(t_{1/2} = \log(0.5)/\log(\beta)\). With \(\beta=0.999\), half-life \(\approx 693\) steps; with \(\beta=0.99\), half-life \(\approx 69\) steps.

What Actually Happens to the Weights

The EMA model is a second copy of the network weights maintained alongside the optimizer. On every gradient step, you first update \(\theta_t\) via SGD/Adam, then update the shadow copy with the EMA formula above. The EMA model is never gradient-updated directly — it only absorbs new information through the running average.

Design Decision: Why not just run SGD longer?

Running SGD longer shrinks the gradient but also requires a smaller learning rate, which slows progress. Averaging at a fixed learning rate lets you keep fast progress (high LR) and reduce variance simultaneously. This decouples exploration (SGD) from exploitation (EMA).

Bias Correction (Important Early in Training)

EMA initialized at \(\bar{\theta}_0 = \theta_0\) is unbiased. But if initialized at zero (common in Adam's moment estimates), the early values are biased toward zero. The bias-corrected estimate is:

$$\hat{\theta}_t = \frac{\bar{\theta}_t}{1 - \beta^t}$$

At \(t=1\) with \(\beta=0.999\): divisor \(= 1-0.999 = 0.001\), so the correction factor is ×1000. By \(t=5000\) the correction factor is \(\approx 1.007\) — negligible. This is exactly the Adam bias correction applied to the first and second moment estimates.

Why It Works — The Math
▼

Variance Reduction — The Core Guarantee

Consider the stochastic gradient iterates \(\theta_t = \theta_{t-1} - \eta\,g_t\) where \(g_t = \nabla L(\theta_{t-1}) + \xi_t\) with zero-mean noise \(\mathbb{E}[\xi_t]=0\) and variance \(\operatorname{Var}(\xi_t)=\sigma^2\). The iterate after \(T\) steps starting from some \(\theta_0\) decomposes as:

$$\theta_T - \theta^* = \underbrace{(I - \eta H)^T(\theta_0 - \theta^*)}_{\text{bias}} - \eta\sum_{t=0}^{T-1}(I-\eta H)^{T-1-t}\xi_t$$

where \(H = \nabla^2 L(\theta^*)\) is the Hessian at the minimum. The noise terms accumulate. The variance of \(\theta_T\) is proportional to \(\eta^2 \sigma^2 / (1-(1-\eta\lambda_{\min})^2) \approx \eta\sigma^2/(2\lambda_{\min})\).

Polyak–Ruppert Convergence Rate

The Polyak–Ruppert average \(\bar{\theta}_T\) satisfies the central limit theorem:

$$\sqrt{T}\,(\bar{\theta}_T - \theta^*) \xrightarrow{d} \mathcal{N}\!\left(0,\; H^{-1} C\, H^{-1}\right)$$

where \(C = \operatorname{Var}(\nabla L(\theta^*))\) is the gradient noise covariance. Crucially, the asymptotic covariance \(H^{-1}CH^{-1}\) is the Cramér–Rao optimal covariance for any unbiased estimator based on stochastic gradients — Polyak–Ruppert averaging achieves statistical efficiency. The individual iterates converge at rate \(\mathcal{O}(1/\sqrt{T})\) but with worse constant; the averaged iterate matches the optimal rate AND constant.

EMA as a Low-Pass Filter

The EMA \(\bar{\theta}_t = (1-\beta)\sum_{k=0}^{t}\beta^{t-k}\theta_k\) is a first-order IIR (infinite impulse response) filter. In the frequency domain, with the discrete-time frequency \(\omega\), the EMA magnitude response is:

$$|H(e^{j\omega})| = \frac{1-\beta}{\sqrt{1 + \beta^2 - 2\beta\cos\omega}}$$

This is a low-pass filter with cutoff frequency \(\omega_c \approx 1-\beta\). High-frequency components (rapid mini-batch noise) are attenuated; low-frequency components (the true gradient direction) pass through. Choosing large \(\beta \approx 0.999\) gives a very narrow passband — only very slow changes pass through, yielding a highly stable model.

Key Formula: EMA as Weighted Sum

Unrolling the recurrence: \(\bar{\theta}_t = (1-\beta)\sum_{k=0}^{t}\beta^{t-k}\,\theta_k\). The weights sum to \((1-\beta)\sum_{k=0}^{t}\beta^{t-k} = 1-\beta^{t+1} \approx 1\) for large \(t\). Each weight decays geometrically: iterate \(k\) steps ago has weight \((1-\beta)\beta^{t-k}\).

Common Pitfall: Using EMA at Too-Small Beta Early in Training

If \(\beta\) is too small (e.g., 0.9), the EMA tracks the SGD iterate closely but provides minimal smoothing. If \(\beta\) is too large (e.g., 0.9999), the EMA lags far behind during the rapid early descent phase. A common fix: use a warm-up schedule \(\beta_t = \min(\beta, (1+t)/(10+t))\) that starts \(\beta\) near 0 and ramps it up.

Applications & Key Takeaways
▼

When to Use EMA Averaging

  • Always at inference: In diffusion models (DDPM, Stable Diffusion, EDM), the EMA copy of the score/denoiser network is used at test time — consistently better sample quality and FID scores.
  • Self-supervised learning (Mean Teacher, DINO, BYOL): EMA teacher generates stable pseudo-labels or targets for the student model, preventing training collapse without negative pairs.
  • SWA for generalization: Stochastic Weight Averaging averages late-phase SGD checkpoints at a high/cyclic learning rate, finding flat minima that generalize better on out-of-distribution data.
  • LLM fine-tuning: EMA can reduce variance in reward model signal during RLHF; used in some DPO implementations.

Comparison: EMA vs SWA vs Polyak

Method Weights Memory Best For
Polyak–Ruppert Uniform \(\tfrac{1}{T}\) O(d) Convex theory, long runs
EMA (\(\beta\)) Exponential decay O(d) Continuous training, teacher
SWA Uniform over last k O(d) Flat minima, generalization
Bottom Line

EMA of weights costs one extra copy of the model (O(d) memory) and zero extra gradient computation. For essentially any neural network training run, keeping an EMA shadow model and using it at inference is a free performance boost.

# EMA of model weights (e.g. for Mean Teacher / SWA)
class EMAModel:
def __init__(self, model, decay=0.999):
self.decay = decay
self.shadow = copy.deepcopy(model) # EMA weights
self.shadow.eval()
for p in self.shadow.parameters():
p.requires_grad_(False)
def update(self, model, step):
# Bias-corrected decay ramps up from 0 to self.decay
d = min(self.decay, (1 + step) / (10 + step))
with torch.no_grad():
for s_p, m_p in zip(self.shadow.parameters(),
model.parameters()):
# theta_ema = d * theta_ema + (1-d) * theta_sgd
s_p.data.mul_(d).add_(m_p.data, alpha=1-d)
