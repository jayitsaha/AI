He / Kaiming Initialization

Variance-preserving weight init for ReLU networks — \(\operatorname{Var}(W) = 2/\text{fan\_in}\)
Foundational Deep Learning Optimization O(1) per layer
1
Understanding He / Kaiming Initialization
▼

What is it? He (Kaiming) initialization is a rule for randomly setting a neural network's initial weights so that the variance of activations stays roughly constant as signal passes through many layers. It was designed specifically for networks using ReLU-family activations, which zero out roughly half of their inputs and therefore shrink signal variance at every layer unless the weights compensate.

Analogy: Think of a chain of audio amplifiers, each followed by a noise gate that mutes any signal below zero volume (that's ReLU). Each gate throws away about half the waveform's energy. If every amplifier's gain is set the same as you'd use without a gate, the signal fades to silence after a dozen stages. He initialization doubles each amplifier's gain to exactly cancel out what the gate removes, so the signal's loudness stays constant all the way through the chain.

💡 If you remember one thing

ReLU zeroes out half the pre-activations, which halves their variance. He init compensates by doubling the weight variance: $$\operatorname{Var}(W) = \frac{2}{\text{fan\_in}}$$ so that activation variance neither vanishes nor explodes as depth grows.

How It Works Internally
▼

The Signal-Propagation Problem

Consider a plain feedforward layer \(z = Wx\), followed by an activation \(a = \phi(z)\), stacked \(L\) times. If each layer's weights are drawn independently with zero mean and variance \(\sigma_W^2\), and the fan-in (number of incoming connections) is \(n\), then the pre-activation variance obeys \(\operatorname{Var}(z) \approx n\,\sigma_W^2\,\operatorname{Var}(x)\). Whatever multiplicative factor this introduces gets applied again and again, layer after layer — any deviation from 1.0 compounds exponentially with depth, causing activations to vanish toward zero or explode toward infinity.

Where ReLU Breaks the Xavier Assumption

Xavier/Glorot initialization (2010) sets \(\sigma_W^2 = 1/n\) (or \(2/(n_{in}+n_{out})\)) so the multiplicative factor is exactly 1 — but its derivation assumes a linear or symmetric activation like tanh, where the activation doesn't change the variance. ReLU is different: \(\text{ReLU}(z) = \max(0, z)\) discards the entire negative half of the distribution. For a zero-mean symmetric \(z\), that means the surviving activation carries only half the variance of \(z\). Xavier weights, unmodified, leave a ReLU network's activation variance shrinking by ~2× at every single layer.

Design Decision: Why Multiply by Exactly 2?

He et al. (2015) derived the exact correction: since ReLU removes precisely half of a symmetric distribution's second moment, scaling the weight variance up by a factor of 2 exactly cancels that loss, restoring a per-layer multiplicative factor of 1. This is not a heuristic fudge factor — it falls directly out of the algebra of a rectified Gaussian (see Card 3).

🔑 Key Property

He initialization is variance-preserving through the forward pass of ReLU networks: \(\operatorname{Var}(a^{(l)}) \approx \operatorname{Var}(a^{(l-1)})\) for every layer \(l\), regardless of depth — which is exactly what lets very deep ReLU / ResNet-style networks train stably from a random start.

3
Why It Works — The Derivation
▼

Setup

Let layer \(l\) compute \(z^{(l)} = W^{(l)} a^{(l-1)}\), then \(a^{(l)} = \max(0, z^{(l)})\). Assume weight entries \(W_{ij}\) are i.i.d., zero-mean, independent of the input \(a^{(l-1)}\), with variance \(\sigma_W^2\), and fan-in \(n_l\). Because \(W\) is zero-mean and independent of \(a^{(l-1)}\), the pre-activation \(z^{(l)}\) is itself zero-mean and (by the CLT, for reasonably large \(n_l\)) approximately symmetric — regardless of the sign structure of \(a^{(l-1)}\).

Step 1 — Pre-activation variance

$$\operatorname{Var}(z^{(l)}) = n_l\, \sigma_W^2 \, \mathbb{E}\big[(a^{(l-1)})^2\big] = n_l\, \sigma_W^2 \, \operatorname{Var}(z^{(l-1)}_{+})$$

where \(\operatorname{Var}(z^{(l-1)}_+)\) denotes the second moment of the previous layer's activations (mean-squared, since ReLU outputs are non-negative and not zero-mean).

Step 2 — Effect of ReLU on a symmetric, zero-mean variable

If \(z \sim \) any distribution symmetric about 0 with variance \(\sigma_z^2\), split the expectation at 0:

$$\mathbb{E}[\max(0,z)^2] = \int_0^\infty z^2 f(z)\,dz = \tfrac{1}{2}\int_{-\infty}^{\infty} z^2 f(z)\,dz = \tfrac{1}{2}\,\sigma_z^2$$

using symmetry: the positive half contributes exactly half of the total second moment. So each ReLU exactly halves the propagated variance.

Step 3 — The recursion and the fix

$$\operatorname{Var}(a^{(l)}_{\text{2nd moment}}) = \tfrac{1}{2}\,n_l\,\sigma_W^2 \cdot \operatorname{Var}(a^{(l-1)}_{\text{2nd moment}})$$

For the variance to be preserved layer-to-layer, the multiplier must equal 1:

$$\tfrac{1}{2}\,n_l\,\sigma_W^2 = 1 \quad\Longrightarrow\quad \sigma_W^2 = \frac{2}{n_l} = \frac{2}{\text{fan\_in}}$$

This is exactly the He/Kaiming rule. Without the factor of 2 (i.e. Xavier's \(1/n\)), the multiplier is \(0.5\) per layer, so after \(L\) layers the variance shrinks by \(0.5^L\) — at \(L=20\) that's a factor of roughly \(10^{-6}\), effectively dead activations.

⚠️ Subtlety

The derivation never requires the activations \(a^{(l-1)}\) to be symmetric — only the pre-activation \(z^{(l)} = W^{(l)}a^{(l-1)}\) needs to be approximately zero-mean symmetric, which holds because \(W^{(l)}\) is zero-mean and independent of its input. This is why the argument applies recursively at every layer, even though ReLU outputs themselves are never symmetric or zero-mean.

Key Takeaways
▼
SchemeWeight varianceDesigned forUnder ReLU depth
LeCun\(1/\text{fan\_in}\)Linear / sigmoid (unit gain)Decays ~2× per layer
Xavier / Glorot\(2/(\text{fan\_in}+\text{fan\_out})\)tanh / symmetric activationsDecays ~2× per layer
He / Kaiming\(2/\text{fan\_in}\)ReLU, Leaky ReLU, PReLU, GELU-ishStable, ≈ constant

fan_in vs fan_out mode: mode='fan_in' (PyTorch default) preserves activation variance on the forward pass; mode='fan_out' preserves gradient variance on the backward pass. For square layers (fan_in = fan_out) they're identical; they diverge for bottleneck/expansion layers such as convolutions with changing channel counts.

When to use He: any network dominated by ReLU-family activations — CNNs, ResNets, plain MLPs. When not: networks using tanh/sigmoid (prefer Xavier), or architectures with normalization + residual scaling where init matters less (still a reasonable default, just less critical).

💡 Hierarchy

All three schemes solve the same equation — "keep the per-layer variance multiplier at 1" — under different activation assumptions. He = Xavier's equation × the ReLU correction factor of 2.

import numpy as np
# From scratch: He/Kaiming normal init for a Linear(fan_in -> fan_out) layer
def kaiming_normal_(fan_in, fan_out, mode='fan_in', nonlinearity='relu'):
gain = np.sqrt(2.0) # gain for ReLU family
fan = fan_in if mode == 'fan_in' else fan_out
std = gain / np.sqrt(fan) # sqrt(2 / fan)
return np.random.randn(fan_in, fan_out) * std
# Forward pass through L ReLU layers, tracking activation variance
def simulate(widths, init='he', n_samples=200):
x = np.random.randn(n_samples, widths[0])
variances = [x.var()]
for fan_in, fan_out in zip(widths[:-1], widths[1:]):
if init == 'he':
W = kaiming_normal_(fan_in, fan_out) # Var = 2/fan_in
else: # xavier
std = np.sqrt(2.0 / (fan_in + fan_out)) # Var = 2/(fan_in+fan_out)
W = np.random.randn(fan_in, fan_out) * std
x = np.maximum(0, x @ W) # linear + ReLU
variances.append(x.var())
return variances
# Production usage (PyTorch)
import torch.nn as nn
layer = nn.Linear(256, 256)
nn.init.kaiming_normal_(layer.weight, mode='fan_in', nonlinearity='relu')
nn.init.zeros_(layer.bias)
# Gotcha: nonlinearity must match your actual activation — 'relu' uses gain
# sqrt(2); 'leaky_relu' scales gain by the negative slope automatically.
