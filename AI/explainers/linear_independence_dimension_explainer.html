Linear Independence & Dimension

The geometry of non-redundant directions and the foundations of vector spaces
Foundational Linear Algebra Must Know
1
Understanding Linear Independence
▼

What is it? A set of vectors \(\{\mathbf{v}_1, \mathbf{v}_2, \ldots, \mathbf{v}_n\}\) is linearly independent if no vector in the set can be written as a linear combination of the others. Equivalently, the only solution to the homogeneous equation is the trivial one: all scalars must be zero.

Analogy — GPS coordinates: To precisely locate any point on Earth, you need latitude, longitude, and altitude. Each piece of information tells you something genuinely new that you cannot derive from the other two. Remove any one of them and you lose an irreplaceable dimension of information. That is exactly what linear independence means: each vector contributes a direction that cannot be reconstructed from the remaining vectors, no matter how you scale and combine them.

Contrast with dependence: If you include a fourth GPS coordinate that is always equal to latitude minus longitude, it is redundant — it tells you nothing new. Mathematically, it lies in the span of the first two coordinates. Dependent vectors are exactly like this: wasteful, redundant, carrying no new directional information.

$$c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_n\mathbf{v}_n = \mathbf{0} \implies c_i = 0 \;\forall i$$

This condition is the definition of linear independence. To test it, form the matrix \(A = [\mathbf{v}_1 \mid \mathbf{v}_2 \mid \cdots \mid \mathbf{v}_n]\) and ask: does \(A\mathbf{c} = \mathbf{0}\) have only the trivial solution \(\mathbf{c} = \mathbf{0}\)? If yes, the columns (your vectors) are independent. If the system has non-trivial solutions, the vectors are dependent — and you can read off the dependency relationship directly from those non-trivial coefficients.

Geometric Intuition

In 2D, two vectors are independent if they point in genuinely different directions — not along the same line. In 3D, three vectors are independent if they do not all lie in the same plane. Each independent vector "escapes" the subspace spanned by the previous ones, adding a truly new dimension to the space you can reach.

If you remember one thing

Linearly independent = non-redundant directions. Each vector in the set adds a dimension that none of the others can cover. If you can write any one vector as a combination of the rest, you have a redundancy — and that redundancy shows up as a zero determinant, a rank drop, and a non-trivial null space.

Why This Definition is Natural

The equation \(c_1\mathbf{v}_1 + \cdots + c_n\mathbf{v}_n = \mathbf{0}\) with \(\mathbf{c} \neq \mathbf{0}\) is saying: "I can reach the zero vector by combining these vectors with non-zero weights." That means at least one vector can be isolated on one side: \(\mathbf{v}_k = -\frac{1}{c_k}\sum_{i \neq k} c_i\mathbf{v}_i\). The vector \(\mathbf{v}_k\) is redundant — it lives in the span of the others.

Span, Basis, and Dimension
▼

Span: Everything You Can Reach

The span of a set of vectors is the collection of all possible linear combinations. It answers the question: "If I can scale and add these vectors in any way, what set of points can I reach?" Formally:

$$\text{span}(\mathbf{v}_1,\ldots,\mathbf{v}_k) = \{ c_1\mathbf{v}_1 + \cdots + c_k\mathbf{v}_k : c_i \in \mathbb{R} \}$$

The span of a single nonzero vector is a line through the origin. The span of two non-collinear vectors is a plane through the origin. The span of \(k\) linearly independent vectors in \(\mathbb{R}^n\) is a \(k\)-dimensional subspace of \(\mathbb{R}^n\). Crucially, adding more dependent vectors to your set does not enlarge the span — it is already covered.

Basis: The Most Efficient Spanning Set

A basis for a vector space \(V\) is a set of vectors that simultaneously (1) spans \(V\) — you can reach every point in \(V\) — and (2) is linearly independent — there is no redundancy. A basis is the most economical description of a space: you cannot remove any vector without losing coverage, and you cannot add any vector without introducing dependence.

Examples: The standard basis \(\{\mathbf{e}_1 = [1,0], \mathbf{e}_2 = [0,1]\}\) for \(\mathbb{R}^2\) is the canonical choice, but \(\{[2,1], [1,2]\}\) is equally valid. Both span all of \(\mathbb{R}^2\) and are independent. Even \(\{[3,-1], [0,4]\}\) works. What is remarkable is that despite their apparent diversity, all these bases share something fundamental: they all have exactly 2 vectors.

Dimension: A Theorem, Not a Definition

The dimension of a vector space \(V\) is the number of vectors in any basis of \(V\). The remarkable fact — which requires proof — is that every basis of \(V\) has exactly the same number of vectors. You cannot have two bases of \(\mathbb{R}^2\) where one has 2 vectors and another has 3. This invariance is what makes dimension a well-defined concept.

Key Fact: Basis Cardinality is an Invariant

Any two bases of the same vector space contain the same number of vectors. This common number is the dimension. For \(\mathbb{R}^n\), the dimension is \(n\). For the column space of a matrix \(A\), the dimension is the rank of \(A\). For the solution set of \(A\mathbf{x} = \mathbf{0}\), it is the nullity.

Key Relationships

  • A set of more than \(\dim(V)\) vectors in \(V\) is always linearly dependent
  • A set of fewer than \(\dim(V)\) vectors cannot span \(V\)
  • A linearly independent spanning set is exactly a basis — no more, no less
  • If you have \(\dim(V)\) linearly independent vectors, they automatically span \(V\)
  • If you have \(\dim(V)\) vectors that span \(V\), they are automatically independent
Intuition: Dimension as Degrees of Freedom

Dimension counts the number of truly independent choices you have when moving around in a space. On a line, you have one degree of freedom (how far along). On a plane, two. In 3D, three. The dimension of the column space of a matrix tells you how many independent output directions the matrix can produce.

3
Why It Matters — The Math
▼

Rank: Counting Independent Directions

The rank of a matrix \(A\) is the dimension of its column space — equivalently, the maximum number of linearly independent columns (which equals the maximum number of linearly independent rows). Rank measures how much information \(A\) actually contains. A rank-deficient matrix compresses information: multiple input directions get collapsed to the same output.

Null Space and Nullity

The null space (or kernel) of \(A\) is the set of all vectors \(\mathbf{x}\) such that \(A\mathbf{x} = \mathbf{0}\). It is always a subspace of \(\mathbb{R}^n\). Its dimension is the nullity. Geometrically, null space vectors are the directions that \(A\) crushes to zero — the "lost" directions. If \(A\mathbf{x} = A\mathbf{y}\), then \(\mathbf{x} - \mathbf{y}\) lies in the null space, which is why you cannot distinguish \(\mathbf{x}\) from \(\mathbf{y}\) from \(A\)'s output alone.

The Rank-Nullity Theorem

Perhaps the most elegant theorem in elementary linear algebra connects rank and nullity through a simple conservation law:

$$\text{rank}(A) + \text{nullity}(A) = n$$

where \(n\) is the number of columns of \(A\). Every input dimension either contributes to the output (rank) or gets killed (nullity). The total must equal \(n\). There is no third option. This is the Fundamental Theorem of Linear Algebra.

Determinant Test for Independence

For a square matrix formed by stacking your vectors as columns, the determinant provides an instant independence test:

$$\det[\mathbf{v}_1 \mid \cdots \mid \mathbf{v}_n] \neq 0 \iff \text{the vectors are linearly independent}$$

Geometrically, the absolute value of the determinant is the volume of the parallelepiped spanned by the vectors. Dependent vectors lie in a lower-dimensional subspace, so they enclose zero volume — and the determinant is exactly zero. This is not a coincidence; it is the geometric meaning of the determinant.

Solving \(A\mathbf{x} = \mathbf{b}\): The Full Picture

  • Unique solution: \(A\) has full column rank (all columns independent), so \(\text{nullity}(A) = 0\). The solution is \(\mathbf{x} = A^{-1}\mathbf{b}\) if \(A\) is square.
  • No solution: \(\mathbf{b}\) is not in the column space of \(A\) — the system is inconsistent.
  • Infinite solutions: \(A\) has linearly dependent columns, so there exist non-trivial null space vectors; you can add any multiple of them to a particular solution.
Common Pitfall: Confusing Span with Independence

More vectors does not mean more span. The vectors \(\{[1,0],[2,0],[0,1]\}\) have three elements, but they only span \(\mathbb{R}^2\) (not \(\mathbb{R}^3\)) because two of them are collinear and thus dependent. The span is determined by the number of independent vectors, not the total count. Adding dependent vectors is like adding duplicates to a list — they bloat your set without expanding what it can represent.

The SVD Connection

The Singular Value Decomposition reveals the rank exactly: \(\text{rank}(A)\) equals the number of nonzero singular values. Small singular values indicate near-dependence — directions that are almost redundant. This is why SVD is used for low-rank approximation, PCA, and computing the pseudo-inverse robustly.

Key Takeaways & Applications
▼

Principal Component Analysis (PCA)

PCA finds the linearly independent directions of maximum variance in your data. The principal components are orthogonal (automatically independent) vectors that form a basis for the directions along which your data varies the most. By keeping only the top \(k\) components, you retain the most informative subspace while discarding near-zero directions (near-dependent dimensions that add noise rather than signal). The rank of the data's covariance matrix tells you the intrinsic dimensionality.

Solving \(A\mathbf{x} = \mathbf{b}\): Unique Solutions Require Full Rank

A linear system \(A\mathbf{x} = \mathbf{b}\) has a unique solution if and only if the columns of \(A\) are linearly independent — equivalently, \(A\) has full column rank. This is why, before inverting a matrix, you should always verify that it is full rank. Near-rank-deficiency (very small but nonzero singular values) causes numerical instability: the solution exists in theory but is astronomically sensitive to small perturbations in \(\mathbf{b}\).

Neural Networks: Weight Matrix Rank and Expressivity

A neural network layer computes \(\mathbf{y} = W\mathbf{x} + \mathbf{b}\) where \(W\) is the weight matrix. If the columns of \(W\) are linearly dependent — if \(\text{rank}(W) \lt \min(d_\text{in}, d_\text{out})\) — the layer can only produce outputs in a lower-dimensional subspace. This bottlenecks expressivity: no matter how complex the input, the output is confined to the column space of \(W\). Modern techniques like LoRA explicitly exploit this by representing weight updates as low-rank perturbations, compressing large fine-tuning tasks into a small independent-direction basis.

Multicollinearity in Regression

When predictor variables in a regression are nearly linearly dependent (multicollinear), the design matrix \(X\) becomes nearly rank-deficient. The matrix \(X^\top X\) becomes nearly singular, and its inverse — which appears in the OLS formula \(\hat{\beta} = (X^\top X)^{-1} X^\top \mathbf{y}\) — becomes extremely sensitive to small data perturbations. Coefficient estimates become unreliable and high-variance. Variance Inflation Factors (VIF) and condition numbers of \(X^\top X\) quantify how close to dependence your predictors are.

When to Check Independence

  • Before regression: detect multicollinearity; use VIF or check condition number
  • Before matrix inversion: verify full rank to avoid numerical disasters
  • Before dimensionality reduction: understand the intrinsic dimension of your data
  • During model design: ensure feature engineering does not introduce redundant features
  • When debugging: a rank drop in a transformation matrix often signals a bug or degenerate case
The Big Picture

Linear independence and dimension are the vocabulary of information in linear algebra. Rank tells you how much information a matrix carries. Nullity tells you how much is lost. Dimension tells you the intrinsic complexity of a space. Together they form the Rank-Nullity Theorem: \(\text{rank}(A) + \text{nullity}(A) = n\). Every linear map you will ever encounter obeys this law — it is conservation of dimension.

import numpy as np
# ─── Step 1: Two vectors ───────────────────────────────────────
v1 = np.array([2, 1])
v2 = np.array([1, 2])
# Stack as columns of a matrix
A = np.column_stack([v1, v2]) # shape (2, 2)
# ─── Steps 3–4: Determinant and rank test ──────────────────────
det = np.linalg.det(A)
print(f"det = {det:.3f}") # 3.000 — nonzero → independent
# Method 2: Rank
rank = np.linalg.matrix_rank(A)
print(f"rank = {rank}") # 2 — full rank → independent
# ─── Step 5–6: Dependent example ──────────────────────────────
v3 = 2 * v1 # v3 = [4, 2]
B = np.column_stack([v1, v3])
print(f"det(B) = {np.linalg.det(B):.3f}") # 0.000 — dependent
print(f"rank(B) = {np.linalg.matrix_rank(B)}") # 1 — rank drops
# ─── Step 7: Standard basis for comparison ─────────────────────
e1 = np.array([1, 0])
e2 = np.array([0, 1])
# ─── Step 8: Null space via SVD ────────────────────────────────
U, S, Vt = np.linalg.svd(B)
null_mask = S < 1e-10
null_space = Vt[null_mask].T # columns spanning null space
print(f"Null space of B:\n{null_space}") # [2, -1] direction
# ─── Step 9: Rank-Nullity check ────────────────────────────────
n_cols = B.shape[1]
rank_B = np.linalg.matrix_rank(B)
nullity_B = n_cols - rank_B
print(f"rank + nullity = {rank_B} + {nullity_B} = {rank_B + nullity_B}") # 2
