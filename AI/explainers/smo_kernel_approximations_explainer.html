SVM Scalability: SMO, RFF & Nyström

From O(n³) kernel SVM → analytic pairwise updates → linear-time kernel approximations
Advanced Classical ML SVM O(n²–n³) → O(nD)
1
The Scaling Wall: Why Kernel SVM Breaks at Large n
▼

The kernel trick is elegant but expensive. A kernel SVM with RBF kernel solves the dual QP over \(n\) training samples. The dual objective involves the \(n \times n\) Gram matrix \(K_{ij} = k(x_i, x_j)\), which costs \(O(n^2)\) to store and \(O(n^2 d)\) to compute. Solving the resulting QP takes \(O(n^3)\) with interior-point methods.

For \(n = 10{,}000\): the Gram matrix alone needs ~800 MB (float64). For \(n = 100{,}000\): ~80 GB — completely infeasible. Two orthogonal solutions break this wall:

  • SMO — keeps the kernel SVM intact but replaces the QP solver with a decomposition that updates only 2 \(\alpha_i\) at a time analytically, never materializing the full Gram matrix at once.
  • Kernel Approximations (RFF, Nyström) — approximate the kernel function with an explicit low-dimensional feature map \(\phi(x)\), converting the problem to a linear SVM on \(\phi(x)\) which trains in \(O(nD)\) time and \(O(D)\) memory.
If you remember one thing

The dual SVM objective is $$\max_\alpha \sum_i \alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i \alpha_j y_i y_j k(x_i,x_j)$$ subject to \(0 \le \alpha_i \le C\) and \(\sum_i \alpha_i y_i = 0\). SMO exploits the 2-variable analytic solution; RFF/Nyström approximate \(k\) so the sum never needs to be computed in kernel space.

2
SMO: Sequential Minimal Optimization
▼

Platt (1998) observed that the smallest feasible QP subproblem is over two variables — the equality constraint \(\sum_i \alpha_i y_i = 0\) couples any two \(\alpha\)s together. Given a pair \((\alpha_i, \alpha_j)\), the constraint fixes \(\alpha_i = \gamma - s\,\alpha_j\) where \(s = y_i y_j\) and \(\gamma = \alpha_i^{\rm old} y_i + \alpha_j^{\rm old} y_j\). This reduces the 2-variable problem to a 1-variable clipped quadratic, solvable in closed form.

The Two-Variable Update

Define the error \(E_k = f(x_k) - y_k\) where \(f(x) = \sum_i \alpha_i y_i k(x_i, x) + b\). The unconstrained optimum for \(\alpha_j\) is:

$$\alpha_j^{\rm new,\rm unclipped} = \alpha_j^{\rm old} + \frac{y_j(E_i - E_j)}{\eta}, \qquad \eta = K_{ii} + K_{jj} - 2K_{ij} \ge 0$$

Since \(\eta \ge 0\) is the second derivative of the objective w.r.t. \(\alpha_j\), the optimum is a maximum. Clip to the box \([L, H]\) where the bounds depend on \(y_i y_j\):

$$L,H = \begin{cases} \max(0,\alpha_i+\alpha_j-C),\; \min(C,\alpha_i+\alpha_j) & y_i = y_j \\ \max(0,\alpha_j-\alpha_i),\; \min(C,C+\alpha_j-\alpha_i) & y_i \ne y_j \end{cases}$$

Then \(\alpha_j^{\rm new} = \text{clip}(\alpha_j^{\rm new,\rm unclipped},L,H)\) and \(\alpha_i^{\rm new} = \alpha_i^{\rm old} + y_i y_j(\alpha_j^{\rm old} - \alpha_j^{\rm new})\). The bias \(b\) is updated to maintain KKT conditions.

Heuristic Pair Selection (KKT Violation)

Outer loop: find \(\alpha_i\) violating KKT — either not on margin (\(0 < \alpha_i < C\) but \(y_i f(x_i) \ne 1\)) or misclassified. Inner loop: pick \(\alpha_j\) to maximize \(|E_i - E_j|\). This greedy heuristic makes large steps. Convergence is guaranteed when all KKT conditions are satisfied to tolerance \(\varepsilon\).

Complexity

Each SMO iteration updates 2 variables in \(O(n)\) time (computing \(E_i, E_j\) requires evaluating \(f\) at two points). In practice, with the heuristic, total iterations are \(O(n)\) to \(O(n^2)\), giving overall \(O(n^2)\) to \(O(n^3)\) — but with a much smaller constant than naive QP solvers. Critically, memory is \(O(n)\): only errors \(E_k\) and alphas are kept; the Gram matrix is computed on-the-fly (or cached partially).

3
Kernel Approximations: RFF and Nyström
▼

Random Fourier Features (Rahimi & Recht, 2007)

Any shift-invariant kernel \(k(x,z) = k(x-z)\) that is positive definite is, by Bochner's theorem, the Fourier transform of a non-negative spectral measure \(p(\omega)\):

$$k(x-z) = \int p(\omega)\,e^{j\omega^\top(x-z)}\,d\omega = \mathbb{E}_\omega\!\left[e^{j\omega^\top x}\overline{e^{j\omega^\top z}}\right]$$

For the RBF kernel \(k(x,z) = \exp(-\gamma\|x-z\|^2)\), the spectral density is \(p(\omega) = \mathcal{N}(0, 2\gamma I)\). Drawing \(D\) i.i.d. samples \(\omega_1,\ldots,\omega_D \sim p(\omega)\) and \(b_1,\ldots,b_D \sim \mathrm{Uniform}[0,2\pi]\), define the random feature map:

$$\phi(x) = \sqrt{\tfrac{2}{D}}\bigl[\cos(\omega_1^\top x + b_1),\ldots,\cos(\omega_D^\top x + b_D)\bigr]^\top \in \mathbb{R}^D$$

Then \(\mathbb{E}[\phi(x)^\top \phi(z)] = k(x,z)\). By the law of large numbers, \(\phi(x)^\top\phi(z) \xrightarrow{D\to\infty} k(x,z)\) uniformly over compact sets. In practice, \(D = 500\)–\(10{,}000\) suffices. After computing \(\Phi \in \mathbb{R}^{n\times D}\), train a linear SVM on \(\Phi\): cost \(O(nD)\) vs \(O(n^2 d)\) for the kernel.

Nyström Method

Instead of random sampling from the spectral measure, Nyström approximates the Gram matrix using a small set of \(m \ll n\) landmark points \(\{x_{l_1},\ldots,x_{l_m}\}\). Partition the full Gram matrix as:

$$K = \begin{pmatrix} K_{mm} & K_{mn} \\ K_{nm} & K_{nn} \end{pmatrix}$$

The Nyström approximation uses only \(K_{mm}\) and \(K_{nm} \in \mathbb{R}^{n\times m}\):

$$\tilde{K} = K_{nm}\, K_{mm}^{-1}\, K_{nm}^\top$$

This is a rank-\(m\) approximation. Equivalently, the feature map is \(\tilde{\phi}(x) = K_{mm}^{-1/2} k_m(x)\) where \(k_m(x) = [k(x,x_{l_1}),\ldots,k(x,x_{l_m})]^\top\). Computing \(\tilde{\Phi} \in \mathbb{R}^{n\times m}\) costs \(O(nm^2)\); training linear SVM costs \(O(nm)\).

RFF vs Nyström: When to Choose Which

RFF: fast, embarrassingly parallel, works online. Error \(O(1/\sqrt{D})\) uniform over all \(x\). Good when data is large and diverse. Nyström: deterministic given landmarks, lower error per feature if landmarks are chosen well (e.g., k-means centers), but requires \(O(m^2)\) for \(K_{mm}^{-1}\). Better when data lies on a low-dimensional manifold. Both give \(\epsilon\)-approximation with \(D = O(\log(1/\delta)/\epsilon^2)\) features.

Error Bounds

For RFF with \(D\) features, by the McDiarmid inequality:

$$P\!\left(\sup_{x,z}\left|\phi(x)^\top\phi(z) - k(x,z)\right| > \varepsilon\right) \le 2^8\left(\tfrac{\sigma_p}{\varepsilon}\right)^2 \exp\!\left(-\tfrac{D\varepsilon^2}{4(d+2)}\right)$$

where \(\sigma_p^2\) is the second moment of the spectral distribution. For Nyström, the spectral error satisfies \(\|K - \tilde{K}\|_F \le \sum_{i>m}\lambda_i\) where \(\lambda_i\) are eigenvalues of \(K\) — the truncation error depends on the spectral decay rate of the kernel.

Practical Advice

For \(n < 10^4\): use SMO (scikit-learn's LibSVM). For \(n \sim 10^4\)–\(10^6\): RFF + SGD linear SVM (scikit-learn's RBFSampler + SGDClassifier). For structured data on a low-dim manifold: Nyström with k-means landmarks often outperforms RFF at the same \(D = m\). Always tune \(D\) or \(m\) via cross-validation — the approximation quality directly impacts accuracy.

import numpy as np
from sklearn.svm import SVC
# ── SMO core (simplified, full impl in libsvm) ──────────────────────────
def smo_step(alpha, b, X, y, i, j, C, K):
"""Analytically optimize the (alpha_i, alpha_j) pair."""
n = len(y)
f = lambda k: sum(alpha[l]*y[l]*K[l,k] for l in range(n)) + b
E_i, E_j = f(i) - y[i], f(j) - y[j]
eta = K[i,i] + K[j,j] - 2*K[i,j] # second derivative
if eta <= 0: return alpha, b # degenerate case
# Bounds (from equality constraint sum(alpha*y) = 0)
if y[i] == y[j]:
L = max(0, alpha[i]+alpha[j]-C); H = min(C, alpha[i]+alpha[j])
else:
L = max(0, alpha[j]-alpha[i]); H = min(C, C+alpha[j]-alpha[i])
if abs(H - L) < 1e-8: return alpha, b
aj_old, ai_old = alpha[j], alpha[i]
alpha[j] = np.clip(alpha[j] + y[j]*(E_i-E_j)/eta, L, H) # closed form!
alpha[i] += y[i]*y[j]*(aj_old - alpha[j])
# Update bias b
b1 = b - E_i - y[i]*(alpha[i]-ai_old)*K[i,i] - y[j]*(alpha[j]-aj_old)*K[i,j]
b2 = b - E_j - y[i]*(alpha[i]-ai_old)*K[i,j] - y[j]*(alpha[j]-aj_old)*K[j,j]
b = b1 if 0 < alpha[i] < C else (b2 if 0 < alpha[j] < C else (b1+b2)/2)
return alpha, b
# ── Random Fourier Features (RBF kernel, gamma=0.5) ─────────────────────
def rff_features(X, D=1000, gamma=0.5, seed=42):
rng = np.random.default_rng(seed)
d = X.shape[1]
# Bochner: k(x-z)=exp(-gamma||x-z||^2) => omega ~ N(0, 2*gamma*I)
omega = rng.normal(0, np.sqrt(2*gamma), (d, D))
b = rng.uniform(0, 2*np.pi, D)
return np.sqrt(2/D) * np.cos(X @ omega + b) # shape (n, D)
# ── Nyström Approximation ────────────────────────────────────────────────
def nystrom_features(X, m=100, gamma=0.5, seed=42):
rng = np.random.default_rng(seed)
idx = rng.choice(len(X), m, replace=False) # random landmarks
X_m = X[idx]
def rbf(A, B): return np.exp(-gamma * ((A[:,None]-B[None])**2).sum(-1))
K_mm = rbf(X_m, X_m) # (m, m) landmark gram matrix
K_nm = rbf(X, X_m) # (n, m) cross gram
# Low-rank Cholesky: K_mm = U S U^T, feature = K_nm @ U @ diag(1/sqrt(S))
S, U = np.linalg.eigh(K_mm)
S = np.maximum(S, 1e-12) # numerical stability
return K_nm @ U @ np.diag(1/np.sqrt(S)) # shape (n, m)
# ── Pipeline: kernel SVM → RFF linear SVM ───────────────────────────────
from sklearn.pipeline import Pipeline
from sklearn.kernel_approximation import RBFSampler, Nystroem
from sklearn.svm import LinearSVC
rff_svm = Pipeline([
('rff', RBFSampler(gamma=0.5, n_components=1000, random_state=42)),
('svm', LinearSVC(C=1.0, max_iter=2000))
]) # O(nD) time, O(D) memory
nys_svm = Pipeline([
('nys', Nystroem(kernel='rbf', gamma=0.5, n_components=100, random_state=42)),
('svm', LinearSVC(C=1.0, max_iter=2000))
]) # O(nm²) time, landmark gram computed once
