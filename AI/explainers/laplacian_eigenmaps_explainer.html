Understanding Laplacian Eigenmaps
▼

What is it? High-dimensional data often lies on a curved, low-dimensional surface (a manifold) embedded in a high-dimensional space — think of a rolled-up sheet of paper inside 3D space. Laplacian Eigenmaps (LE) finds coordinates for each data point in that low-dimensional space by asking one question: keep nearby points nearby. It does this using graph theory and linear algebra, making it one of the cleanest manifold learning algorithms.

Analogy: Imagine a city map rolled into a cylinder. Two neighborhoods might be close on the map but far apart in 3D (across the cylinder). Laplacian Eigenmaps "unrolls" the data by connecting each neighborhood to its true neighbors (via a graph), then finds coordinates that honor those local adjacencies — without needing to know the global shape upfront.

Three steps: (1) Build a weighted k-NN graph encoding local geometry. (2) Form the graph Laplacian \(L = D - W\). (3) Embed using the smallest nontrivial eigenvectors of \(L\) — these eigenvectors are the smoothest functions on the graph, naturally separating the manifold's structure.

💡 If you remember one thing

The embedding minimizes \(\sum_{ij} W_{ij}\|y_i - y_j\|^2 = y^\top L y\) subject to \(y^\top D y = 1\). This objective forces connected (similar) points to map to nearby coordinates. The solution is the generalized eigenproblem \(L v = \lambda D v\), and you take the \(d\) eigenvectors with smallest nonzero eigenvalues.

How It Works Internally
▼

Step 1 — Build the Weighted k-NN Graph

For \(n\) data points \(x_1,\ldots,x_n \in \mathbb{R}^D\), connect each point to its \(k\) nearest neighbors (by Euclidean distance). The weight \(W_{ij}\) encodes similarity — two common choices are the heat kernel \(W_{ij} = \exp(-\|x_i - x_j\|^2 / t)\) (smooth, all pairs have weight; \(t\) controls neighborhood scale) or \(W_{ij} = 1\) if \(j\) is a k-NN neighbor (binary). The graph must be connected; if not, each connected component embeds separately.

Step 2 — Form the Graph Laplacian

Define the degree matrix \(D_{ii} = \sum_j W_{ij}\) (diagonal). The unnormalized graph Laplacian is \(L = D - W\). Key properties: \(L\) is symmetric positive semi-definite, \(L\mathbf{1} = 0\) (the constant vector is always an eigenvector with eigenvalue 0), and for any vector \(f\):

$$f^\top L f = \frac{1}{2} \sum_{i,j} W_{ij}(f_i - f_j)^2 \geq 0$$

This quadratic form is exactly the objective to minimize — it sums the squared differences of embedding coordinates over all edges, weighted by edge strength.

Step 3 — Solve the Generalized Eigenproblem

We want embedding coordinates \(Y \in \mathbb{R}^{n \times d}\) (each row is a point's low-dim coordinate). To prevent the trivial all-zero solution, we impose \(Y^\top D Y = I\). The problem becomes:

$$\min_Y \operatorname{tr}(Y^\top L Y) \quad \text{s.t.} \quad Y^\top D Y = I$$

Via Lagrange multipliers, this reduces to the generalized eigenvalue problem \(Lv = \lambda Dv\). We discard the eigenvector for \(\lambda_0 = 0\) (the trivial constant embedding) and take the next \(d\) eigenvectors \(v_1,\ldots,v_d\) corresponding to the \(d\) smallest nonzero eigenvalues \(\lambda_1 \leq \ldots \leq \lambda_d\).

🔑 Spectral Geometry Insight

The Fiedler vector \(v_1\) (smallest nonzero eigenvalue) is the smoothest nonconstant function on the graph — it varies as slowly as possible across edges. Higher eigenvectors capture progressively finer structure. Together they form a coordinate system faithful to the graph's topology — the manifold's intrinsic geometry.

Design Decision: Normalized vs Unnormalized Laplacian

The normalized Laplacian \(\mathcal{L} = D^{-1/2}LD^{-1/2} = I - D^{-1/2}WD^{-1/2}\) has eigenvalues in \([0,2]\) and leads to the random-walk interpretation (spectral clustering). Belkin & Niyogi's original LE uses the unnormalized form with generalized eigenproblem \(Lv = \lambda Dv\), which is equivalent to \(D^{-1}L v = \lambda v\) (random-walk Laplacian). Both are closely related; the normalized form is preferred when degree varies widely.

The Mathematics Behind It
▼

Full Derivation

Given weighted adjacency matrix \(W \in \mathbb{R}^{n\times n}\) (symmetric, non-negative), degree matrix \(D_{ii} = \sum_j W_{ij}\), Laplacian \(L = D - W\).

Objective: find \(y \in \mathbb{R}^n\) minimizing neighbor disagreement:

$$\min_y \; y^\top L y = \min_y \frac{1}{2}\sum_{i,j}W_{ij}(y_i-y_j)^2$$

Constraint: normalize via degree matrix to prevent scale collapse:

$$y^\top D y = 1, \quad y^\top D \mathbf{1} = 0 \quad \text{(orthogonal to trivial solution)}$$

Lagrangian: \(\mathcal{L}(y,\lambda) = y^\top Ly - \lambda(y^\top Dy - 1)\). Setting \(\partial\mathcal{L}/\partial y = 0\):

$$2Ly - 2\lambda Dy = 0 \implies Ly = \lambda Dy$$

This is the generalized eigenproblem. If \(D\) is invertible (all degrees \(> 0\)), it reduces to \(D^{-1}Ly = \lambda y\), a standard eigenvalue problem of the random-walk Laplacian.

Solution: Eigenvalues \(0 = \lambda_0 \leq \lambda_1 \leq \ldots \leq \lambda_{n-1}\). For \(d\)-dimensional embedding, use columns of the matrix formed by eigenvectors \(v_1,\ldots,v_d\) (skipping \(v_0\)):

$$x_i \mapsto \bigl(v_1(i),\; v_2(i),\; \ldots,\; v_d(i)\bigr) \in \mathbb{R}^d$$

Spectral gap: A well-separated manifold has \(\lambda_1 \ll \lambda_{d+1}\) (spectral gap after the \(d\)-th nonzero eigenvalue), confirming the embedding dimension.

∑ Key Identities

\(L = D - W\)  |  \(L\mathbf{1}=0\)  |  \(f^\top Lf = \tfrac12\sum_{ij}W_{ij}(f_i-f_j)^2\)  |  \(\lambda_0=0\) always  |  Multiplicity of 0 = # connected components

⚠️ Common Pitfall

Laplacian Eigenmaps does NOT preserve global distances — only local topology. Points far apart on the manifold may appear anywhere in the embedding. This is a feature (it "unfolds" curved manifolds) but also a limitation (no meaningful inter-cluster distances). Contrast with PCA, which preserves global variance.

From-Scratch Implementation
▼

A minimal NumPy implementation illustrating every step of Laplacian Eigenmaps. No sklearn, no scipy sparse — raw matrix operations only.

import numpy as np
from sklearn.neighbors import kneighbors_graph # only for k-NN graph
def laplacian_eigenmaps(X, k=5, t=1.0, d=2):
"""Laplacian Eigenmaps from scratch.
X: (n, D) input data; k: neighbors; t: heat kernel scale; d: embed dim."""
n = X.shape[0]
# Step 1: k-NN graph (heat kernel weights)
A = kneighbors_graph(X, k, mode='distance', include_self=False)
A = A.toarray() # dense for clarity
# Symmetrize and apply heat kernel
dist_sq = A ** 2
W = np.where(dist_sq > 0, np.exp(-dist_sq / t), 0.0)
W = np.maximum(W, W.T) # symmetrize
# Step 2: Graph Laplacian L = D - W
D = np.diag(W.sum(axis=1)) # degree matrix
L = D - W # unnormalized Laplacian
# Step 3: Generalized eigenproblem Lv = λDv
# scipy.linalg.eigh solves A v = λ B v for symmetric A, pos-def B
from scipy.linalg import eigh
vals, vecs = eigh(L, D) # eigenvalues in ascending order
# Skip λ₀ = 0 (trivial); take next d eigenvectors
embedding = vecs[:, 1:d+1] # shape (n, d)
return embedding, vals, vecs

Highlighted lines correspond to the active visualization step above. The code trace reinforces that each conceptual step maps to 2–4 lines of NumPy/SciPy.

Key Takeaways & Comparisons
▼

When to Use Laplacian Eigenmaps

Use LE when: your data lies on a curved manifold; you care about preserving local neighborhood structure; you want a principled spectral method with theoretical guarantees; the downstream task is clustering or visualization on nonlinear data.

Avoid LE when: you need global distance preservation (use PCA or MDS); data is out-of-sample (LE has no natural extension for new points — use Isomap+Nyström or UMAP); the graph is disconnected and you cannot merge components; \(n\) is very large (\(> 10^5\)) — the dense Laplacian is \(O(n^2)\) memory.

Spectral Manifold Methods Comparison

Isomap vs LE vs LLE vs UMAP:

  • Isomap: preserves geodesic (manifold) distances globally. Sensitive to noise & holes. MDS on graph shortest paths.
  • LE: preserves local geometry via graph Laplacian spectrum. No global distance guarantee. Spectral, principled, fast for small \(n\).
  • LLE: preserves local linear reconstruction weights. No graph Laplacian; instead solves \((I-W)^\top(I-W)v = \lambda v\). Very sensitive to \(k\).
  • UMAP: fuzzy topological approach. Preserves both local and some global structure. Scales to large \(n\). State-of-the-art for visualization.
🔗 Spectral Clustering Connection

Spectral clustering = Laplacian Eigenmaps + k-means. Run LE to get \(d\)-dimensional embedding, then cluster with k-means. The graph Laplacian's eigenvectors naturally separate graph-connected components — cluster boundaries appear as gaps in embedding coordinates.
