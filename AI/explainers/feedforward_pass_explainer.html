Understanding the Feedforward Pass
▼

What is it? The feedforward pass (a.k.a. forward pass) is how a neural network turns an input vector into an output vector: push the numbers through layer after layer, where each layer does exactly two things — an affine transform (multiply by a weight matrix, add a bias) and a nonlinearity (squash the result through an activation function). Repeat for every layer and whatever comes out the end is the network's prediction.

Analogy: Think of an assembly line of translators. Each translator (layer) takes the message handed to them, re-weighs which words matter (the matrix multiply), adds their own personal spin (the bias), and then rephrases it through their own "style filter" (the activation function) before passing it to the next translator. By the time the message reaches the last translator, it has been reshaped into something the final reader (the output layer) can act on.

💡 If you remember one thing

Every layer does the same two-step recipe: $$z = Wa + b, \qquad a' = \sigma(z)$$ where \(a\) is the previous layer's output (or the raw input for layer 1), \(W\) and \(b\) are that layer's learned parameters, and \(\sigma\) is the activation function. Stack this recipe \(L\) times and you have a full forward pass.

How It Works Internally
▼

The General Recipe

Let \(a^{(0)} = x \in \mathbb{R}^{n_0}\) be the input. For each layer \(l = 1, \dots, L\):

$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}, \qquad a^{(l)} = \sigma^{(l)}\!\left(z^{(l)}\right)$$

Here \(W^{(l)} \in \mathbb{R}^{n_l \times n_{l-1}}\) is the weight matrix (rows = neurons in layer \(l\), columns = inputs from layer \(l-1\)), \(b^{(l)} \in \mathbb{R}^{n_l}\) is the bias vector, and \(z^{(l)}\) is the "pre-activation." The network's output is \(\hat{y} = a^{(L)}\), and it is exactly the composition of \(L\) affine-then-nonlinear maps.

Matrix Shapes — the part everyone gets wrong

If layer \(l\) has \(n_l\) neurons and receives \(n_{l-1}\) numbers from the previous layer, then \(W^{(l)}\) must be \(n_l \times n_{l-1}\) so that \(W^{(l)} a^{(l-1)}\) (a matrix-vector product) produces a vector of length \(n_l\) — one pre-activation per neuron. Get the shape wrong and the matrix multiply simply cannot be computed.

Design Decision: Why Affine then Nonlinear?

The affine step \(Wa+b\) can only rotate, scale, and shift — it is a linear operation. If you stacked affine maps directly (no nonlinearity between them), the composition of any number of affine maps is itself a single affine map: an MLP with no activations, however deep, collapses to one linear model in disguise. The nonlinearity \(\sigma\) is what breaks that collapse and lets depth actually buy you expressive power.

🔑 Key Property

The feedforward pass is a pure function of the input and the current parameters — no randomness, no memory of previous calls. Given the same \(x\) and the same weights, it always produces the same \(\hat{y}\). This determinism is exactly what backpropagation exploits: every \(z^{(l)}\) and \(a^{(l)}\) computed here gets cached and reused to compute gradients on the way back.

3
Why It Works — The Math
▼

The Full Composition

Unrolling the recursion for an \(L\)-layer network gives one nested expression:

$$\hat{y} = \sigma^{(L)}\Big(W^{(L)}\,\sigma^{(L-1)}\big(\cdots \sigma^{(1)}(W^{(1)}x + b^{(1)}) \cdots\big) + b^{(L)}\Big)$$

Each \(\sigma^{(l)}\) can be a different function — ReLU in hidden layers, sigmoid or softmax at the output — but the shape of the computation is identical at every layer.

Proof Sketch: Why Depth Needs Nonlinearity

Suppose every \(\sigma^{(l)} = \text{identity}\). Then \(a^{(l)} = W^{(l)}a^{(l-1)} + b^{(l)}\) for all \(l\). Substituting recursively:

$$\hat{y} = \underbrace{W^{(L)}W^{(L-1)}\cdots W^{(1)}}_{\tilde{W}} x + \tilde{b}$$

The product of matrices \(\tilde{W}\) is itself just one matrix, and the accumulated bias terms collapse into one vector \(\tilde{b}\). So \(\hat{y} = \tilde{W}x + \tilde{b}\) — a single affine map, no matter how many layers \(L\) you stacked. This is why every hidden layer needs a non-polynomial nonlinearity between the affine steps.

Cost of One Forward Pass

Each layer's matrix-vector product \(W^{(l)}a^{(l-1)}\) costs \(O(n_l \cdot n_{l-1})\) multiply-adds. Summed across layers, the whole forward pass costs \(O\!\left(\sum_{l=1}^{L} n_l n_{l-1}\right)\) — dominated by whichever layer has the most parameters. Batched over \(m\) examples this becomes matrix-matrix products, which is exactly why GPUs (built for dense matrix multiplication) accelerate this so well.

⚠️ Common Misconception

"The forward pass computes the loss." It doesn't — the forward pass only produces \(\hat{y} = a^{(L)}\). Comparing \(\hat{y}\) to a target \(y\) via a loss function \(\mathcal{L}(\hat{y}, y)\) is a separate step that happens after the forward pass, and only during training (at inference time there may be no target at all).

Key Takeaways
▼

What the forward pass gives you:

  • The network's prediction \(\hat{y} = a^{(L)}\) — used directly at inference time
  • Every intermediate \(z^{(l)}\) and \(a^{(l)}\), cached for backpropagation to reuse (the chain rule needs them)
  • The number of arithmetic operations to budget for: \(O(\sum_l n_l n_{l-1})\), the basis for FLOP-counting a model

What it does NOT do:

  • Compute a loss (needs a target and a separate loss function)
  • Update any weights (that's gradient descent, after backprop)
  • Guarantee a good prediction — a forward pass through randomly initialized weights is just as well-defined as one through trained weights
💡 The One-Layer Recipe, Repeated

Every architecture you'll meet — MLPs, CNNs (convolution instead of dense matmul), Transformers (attention instead of a plain matmul) — still ends every layer with "affine-ish transform, then nonlinearity." The MLP forward pass is the purest, simplest version of that pattern, which is why it's the right place to build intuition before tackling anything fancier.

Code Trace
▼
import numpy as np
# Input vector (n0 = 3)
x = np.array([1.0, -0.5, 0.8])
# Layer 1 params: W1 is (4,3), b1 is (4,)
W1 = np.array([[ 0.6,-0.3, 0.9],
[ 0.2, 0.8,-0.5],
[-0.7, 0.4, 0.1],
[ 0.5, 0.5, 0.5]])
b1 = np.array([0.1, -0.2, 0.05, 0.0])
def relu(v): return np.maximum(0, v)
def sigmoid(v): return 1 / (1 + np.exp(-v))
# z1 = W1 @ x + b1 (affine)
z1 = W1 @ x + b1
# a1 = ReLU(z1) (nonlinearity)
a1 = relu(z1)
# Layer 2 params: W2 is (3,4), b2 is (3,)
W2 = np.array([[ 0.4,-0.6, 0.3, 0.7],
[-0.2, 0.5, 0.8,-0.4],
[ 0.9, 0.1,-0.3, 0.6]])
b2 = np.array([0.0, 0.15, -0.1])
z2 = W2 @ a1 + b2
a2 = relu(z2)
# Output layer params: W3 is (2,3), b3 is (2,)
W3 = np.array([[ 0.5, 0.7,-0.4],
[-0.6, 0.3, 0.9]])
b3 = np.array([0.2, -0.1])
z3 = W3 @ a2 + b3
y_hat = sigmoid(z3) # final prediction
print(y_hat) # e.g. [0.62, 0.35]
