Viterbi Algorithm (Decoding)

Dynamic-programming decoding of the most likely hidden-state sequence in an HMM via δ-recursion, backpointers, and trellis backtracking.

Advanced Part III · Classical ML Hidden Markov Models Dynamic Programming O(N²T)
1
Understanding the Concept

What is it? Given a sequence of observations (things we can see), and a Hidden Markov Model that describes how hidden states generate those observations and transition between each other, the Viterbi algorithm finds the single most probable hidden-state path — the sequence of hidden states most likely to have produced the observed data.

Analogy: Imagine you're tracking a hiker crossing a mountain range in fog. You can't see them directly (hidden states = location), but you can hear occasional sounds — birdsong, wind, running water (observations). You have a map with transition probabilities (how likely is the hiker to move from ridge → valley?) and emission probabilities (how likely is running water at ridge?). Viterbi finds the most likely route the hiker walked, given all the sounds you heard.

💡 If You Remember One Thing

Viterbi is just dynamic programming on a trellis: at each time step, for each state, keep only the best predecessor (max over all incoming paths), and remember which predecessor gave that max (the backpointer). After processing all observations, backtrack from the best final state to recover the full optimal path.

2
How It Works Internally — Three Phases

The Trellis Structure

Build a grid: rows = hidden states \(s_1 \ldots s_N\), columns = time steps \(t = 1 \ldots T\). Each cell \((i, t)\) stores \(\delta_t(i)\), the probability of the best path ending in state \(i\) at time \(t\) that produced observations \(o_1 \ldots o_t\).

Phase 1 — Initialisation (t = 1)

$$\delta_1(i) = \pi_i \cdot B(i, o_1)$$

where \(\pi_i\) is the initial-state probability and \(B(i, o_1)\) is the emission probability of observation \(o_1\) from state \(i\). No backpointer needed for \(t=1\).

Phase 2 — Recursion (t = 2 … T)

$$\delta_t(j) = \max_{i} \bigl[\delta_{t-1}(i) \cdot A(i \to j)\bigr] \cdot B(j, o_t)$$

For each state \(j\) at time \(t\): look back at every predecessor state \(i\), score the best path arriving at \(j\) from \(i\), then multiply by the emission of observation \(o_t\) from \(j\).

Store the backpointer: \(\psi_t(j) = \arg\max_i [\delta_{t-1}(i) \cdot A(i \to j)]\).

Phase 3 — Termination & Backtrack

$$q^*_T = \arg\max_i \delta_T(i)$$

Then follow backpointers: \(q^*_t = \psi_{t+1}(q^*_{t+1})\) for \(t = T-1, \ldots, 1\). This recovers the full optimal state sequence.

🔑 Key Invariant

\(\delta_t(j)\) stores the probability of the single most probable path through the trellis that ends in state \(j\) at time \(t\), having generated \(o_1, \ldots, o_t\). This is the Viterbi path probability — distinct from the forward variable \(\alpha_t(j)\) which sums over all paths.

⚠️ Numerical Stability

In practice, products of many small probabilities underflow to zero. Always work in log space: \(\log \delta_t(j) = \max_i [\log \delta_{t-1}(i) + \log A(i,j)] + \log B(j, o_t)\). The \(\arg\max\) is unchanged, and addition replaces multiplication — no underflow.

3
The Mathematics — Why It Is Optimal

An HMM is defined by \(\lambda = (\pi, A, B)\):

  • \(\pi_i = P(q_1 = s_i)\) — initial-state distribution, \(\sum_i \pi_i = 1\)
  • \(A_{ij} = P(q_t = s_j \mid q_{t-1} = s_i)\) — transition matrix, rows sum to 1
  • \(B(i, o) = P(o_t = o \mid q_t = s_i)\) — emission distribution

We seek the state sequence \(\mathbf{q}^* = \arg\max_{\mathbf{q}} P(\mathbf{q} \mid \mathbf{o}, \lambda)\). By Bayes' theorem and since \(P(\mathbf{o} \mid \lambda)\) is constant w.r.t. \(\mathbf{q}\):

$$\mathbf{q}^* = \arg\max_{\mathbf{q}} P(\mathbf{q}, \mathbf{o} \mid \lambda)$$

The joint probability factorises (Markov property + conditional independence of emissions):

$$P(\mathbf{q}, \mathbf{o} \mid \lambda) = \pi_{q_1} \prod_{t=2}^T A_{q_{t-1}, q_t} \prod_{t=1}^T B(q_t, o_t)$$

Viterbi exploits Bellman's optimality principle: the best path to any state \(j\) at time \(t\) must pass through the best predecessor. This allows breaking the global \(\max\) over \(N^T\) paths into \(T\) independent per-step \(\max\) operations, each over only \(N\) predecessors — reducing complexity from exponential to \(\mathcal{O}(N^2 T)\).

📐 Log-Space Recursion (Numerically Stable)

Let \(\tilde{\delta}_t(j) = \log \delta_t(j)\). Then:

Init: \(\tilde{\delta}_1(i) = \log \pi_i + \log B(i, o_1)\)

Recurse: \(\tilde{\delta}_t(j) = \max_i [\tilde{\delta}_{t-1}(i) + \log A_{ij}] + \log B(j, o_t)\)

The \(\arg\max\) for the backpointer is identical in both spaces.

Key Takeaways & When to Use
  • Finds the MAP state sequence — not the individually most likely state at each step (that's the Forward-Backward algorithm).
  • Complexity: \(\mathcal{O}(N^2 T)\) time, \(\mathcal{O}(NT)\) space for the δ table and backpointer matrix.
  • Always work in log space in practice — probability products underflow for \(T > 30\) even with 64-bit floats.
  • Beam search is an approximation of Viterbi that prunes low-probability paths to reduce \(\mathcal{O}(N^2)\) per step — widely used in NLP decoders.
  • Applications: speech recognition (phone sequence decoding), POS tagging, gene finding, network sequence alignment, CRF decoding.
Forward vs. Viterbi

The Forward algorithm computes \(\alpha_t(j) = \sum_i \alpha_{t-1}(i) A_{ij} B(j,o_t)\) (sum over predecessors) to get \(P(\mathbf{o} \mid \lambda)\). Viterbi replaces sum with max and adds backpointers. Same trellis structure, different aggregation — max gives the best path, sum gives total observation likelihood.
