1
Understanding Neural TTS
▼

What is it? Neural text-to-speech converts written text into a natural-sounding waveform using two learned models chained together. The first model — an attention-based encoder-decoder (Tacotron / Tacotron 2) — reads the text and produces a mel-spectrogram: a time-frequency "musical score" describing how loud each frequency band should be at each moment. The second model — a neural vocoder (WaveNet, WaveGlow, HiFi-GAN) — turns that score into actual audio samples.

Analogy: Think of a play being staged. The encoder-decoder is the director annotating the script — deciding the rhythm, pauses, and emphasis for every word, and writing it down as sheet music (the mel-spectrogram). The vocoder is the orchestra performing that sheet music — turning symbols on a page into sound pressure waves your ears can hear. Neither stage alone produces speech; you need both.

💡 If you remember one thing

Tacotron 2 factors TTS into two independently-trainable problems: (1) an attention mechanism that learns to align text characters with output time steps and predicts a mel-spectrogram frame-by-frame, and (2) a vocoder that inverts that spectrogram into a waveform. Splitting text→acoustics from acoustics→audio was the key architectural insight that made end-to-end neural TTS both trainable and high quality.

How It Works Internally
▼

Encoder: Characters → Contextual Representations

Each input character (or phoneme) is mapped to a learned embedding vector. Tacotron 2's encoder passes these embeddings through 3 convolutional layers (capturing local context like "th" or "ing") followed by a single bidirectional LSTM, producing one contextual hidden vector \(h_i\) per input position — informed by neighbors on both sides.

Location-Sensitive Attention: Aligning Text and Time

The decoder must decide, at every output time step \(t\), which characters are currently being "spoken." Vanilla content-based attention can jump around unpredictably. Tacotron 2 uses location-sensitive attention: it augments the content score with a term computed by convolving the cumulative attention weights from all previous steps. This gives the model a memory of what it already attended to, strongly biasing it toward moving forward monotonically rather than skipping or repeating words.

Decoder: Autoregressive Mel-Frame Prediction

At each step, a small "pre-net" (2 FC layers with dropout kept on even at inference, for regularization) processes the previous predicted mel frame. This is concatenated with the attention context vector \(c_t\) (a weighted sum of encoder states) and fed into 2 stacked LSTM layers. A linear projection produces the next mel frame, and a separate projection produces a "stop token" probability that tells the model when the utterance is finished.

Postnet + Vocoder

After the full mel sequence is generated, a 5-layer convolutional Postnet predicts a residual correction added back to the coarse mel spectrogram, sharpening formant details a frame-by-frame RNN tends to blur. Finally, a separately-trained vocoder converts the mel spectrogram into a raw waveform — the original paper used WaveNet (autoregressive, one audio sample at a time); modern systems use parallel flow-based (WaveGlow) or GAN-based (HiFi-GAN) vocoders for real-time synthesis.

🔑 Design Decision: Why location-sensitive attention, not vanilla attention?

Speech is produced by reading text left-to-right without skipping or repeating. Tacotron 1's content-only attention occasionally attended to the wrong words on long or repetitive utterances. By convolving the history of past alignments into the score, Tacotron 2's attention is explicitly biased toward the next unvisited position — trading some flexibility for robustness, a huge quality win for production TTS.

Why It Works — The Math
▼

Location-Sensitive Attention Score

At decoder step \(t\), with previous decoder state \(s_{t-1}\) and encoder states \(h_i\), the model computes cumulative attention features \(f_{t,i} = F * \sum_{\tau

$$e_{t,i} = w^\top \tanh\!\big(W s_{t-1} + V h_i + U f_{t,i} + b\big), \qquad \alpha_{t,i} = \frac{\exp(e_{t,i})}{\sum_{j} \exp(e_{t,j})}$$

The context vector is the attention-weighted sum of encoder states, \(c_t = \sum_i \alpha_{t,i} h_i\), which is what the decoder actually "reads" at step \(t\).

Training Objective

Both the pre-Postnet and post-Postnet mel predictions are supervised against the ground-truth mel-spectrogram (teacher forcing feeds true previous frames during training, not the model's own predictions):

$$\mathcal{L} = \underbrace{\lVert \hat{y}_{\text{mel}} - y_{\text{mel}} \rVert_2^2}_{\text{before Postnet}} + \underbrace{\lVert \hat{y}_{\text{mel}} + r - y_{\text{mel}} \rVert_2^2}_{\text{after Postnet residual } r} + \underbrace{\text{BCE}(\hat{p}_{\text{stop}}, p_{\text{stop}})}_{\text{stop token}}$$

Why Monotonic Alignment Emerges (Proof Sketch)

The cumulative feature \(f_{t,i}\) grows large for positions \(i\) already attended to in earlier steps, and the learned convolution kernel \(F\) is trained to suppress the score \(e_{t,i}\) there — an implicit "already visited, move on" signal. Combined with content similarity peaking near the position where the acoustic realization of character \(i\) naturally occurs, the joint score is maximized by a roughly diagonal band that shifts monotonically from \(i=0\) to \(i=T_{\text{enc}}-1\) as \(t\) increases.

⚠️ Common Misconception

"Attention guarantees a monotonic, one-to-one alignment." It does not — it is only biased toward monotonicity, not constrained to it. On long, repetitive, or out-of-distribution text, Tacotron-style models can still skip words, stutter (repeat), or fail to emit a stop token. This exact failure mode motivated later non-autoregressive, duration-based models (FastSpeech, FastSpeech 2) that predict an explicit phoneme duration and hard-align mel frames — trading some attention flexibility for guaranteed robustness and much faster, parallel inference.

Key Takeaways
▼

When to use Tacotron-style attention-based TTS:

  • You need expressive, natural prosody and have a large, clean single/few-speaker corpus
  • Offline / batch synthesis where autoregressive latency (one frame at a time) is acceptable
  • Research or fine-tuning where flexible, learned alignment beats hand-engineered duration models

When NOT to use / prefer alternatives:

  • Real-time, low-latency serving — prefer non-autoregressive models (FastSpeech 2) with a parallel duration predictor
  • Very long or unusual text where attention can skip/repeat — duration-based alignment is far more robust
  • Need for fast vocoding — swap WaveNet for a parallel vocoder (WaveGlow, HiFi-GAN) which is 100-1000x faster
💡 Evolution

Tacotron (2017) → predicted linear spectrograms + Griffin-Lim phase reconstruction (robotic-sounding). Tacotron 2 (2018) → predicts mel-spectrograms + a learned WaveNet vocoder (near-human MOS scores). FastSpeech / FastSpeech 2 → replace attention with an explicit duration predictor for parallel, robust inference. HiFi-GAN / WaveGlow → replace the slow autoregressive vocoder with a fast parallel one, closing the loop on real-time neural TTS.

Code Trace (PyTorch-style pseudocode)
▼
class Tacotron2(nn.Module):
def forward(self, text):
# 1. Character embedding
embedded = self.char_embedding(text) # (T_enc, 512)
# 2. Encoder: 3x Conv1D + BiLSTM -> contextual states
enc_out = self.encoder(embedded) # (T_enc, 512)
mel_frames, cum_attn = [], torch.zeros(T_enc)
prev_mel = torch.zeros(1, n_mels)
dec_state = self.init_decoder_state()
for t in range(max_decoder_steps):
prenet_out = self.prenet(prev_mel) # dropout always on
# 3. Location-sensitive attention
loc_feats = self.loc_conv(cum_attn)
attn_w = self.attention(dec_state, enc_out, loc_feats)
context = (attn_w.unsqueeze(-1) * enc_out).sum(0)
cum_attn = cum_attn + attn_w
# 4. Autoregressive decoder LSTMs -> mel + stop token
dec_state = self.decoder_rnn(torch.cat([prenet_out, context]), dec_state)
mel_t = self.mel_proj(dec_state)
stop_t = torch.sigmoid(self.stop_proj(dec_state))
mel_frames.append(mel_t); prev_mel = mel_t
if stop_t > 0.5: break
mel_out = torch.stack(mel_frames) # (T_dec, n_mels)
# 5. Postnet residual refinement (non-causal, whole sequence)
mel_post = mel_out + self.postnet(mel_out)
# 6. Vocoder: mel -> raw waveform
waveform = self.vocoder(mel_post) # WaveNet / WaveGlow / HiFi-GAN
return waveform
