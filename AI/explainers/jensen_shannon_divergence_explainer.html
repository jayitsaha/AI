Understanding Jensen-Shannon Divergence
▼

What is this? When you have two probability distributions — say, the distribution of words used in English news articles vs. scientific papers — you often want a single number that quantifies "how different are these two distributions?" Jensen-Shannon Divergence (JSD) is one of the best such numbers: it's symmetric (swapping p and q gives the same answer), always finite (unlike KL divergence, which can blow up to infinity), and bounded between 0 and 1 bit.

Real-world analogy. Imagine you're a DJ mixing two songs. You average them into a "blend track" M = (Song_A + Song_B) / 2. JSD asks: on average, how surprised would a listener expecting the blend be when they hear Song_A or Song_B? If both songs are identical, no surprise: JSD = 0. If they're completely different genres, maximum surprise: JSD = 1 bit. The "blend" trick is what makes JSD symmetric and bounded — you never compare the songs directly to each other, only each to the blend.

💡 If You Remember One Thing

JSD symmetrises KL divergence by routing both distributions through their average mixture \(m = (p+q)/2\):
JSD(p,q) = ½ KL(p‖m) + ½ KL(q‖m)

JSD appears in three major ML contexts: (1) as a divergence measure for comparing distributions during training, (2) as the loss function of the original GAN — GANs literally minimise JSD between real and generated data, and (3) as √JSD, which is a proper metric (triangle inequality satisfied).

Prerequisites you should know: Shannon entropy \(H(p) = -\sum_x p(x)\log p(x)\), KL divergence \(D_{\mathrm{KL}}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}\), and basic probability distributions.

The Formula & Its Properties
▼

Core Definition

Given distributions \(p\) and \(q\) over the same space \(\mathcal{X}\), let \(m = \tfrac{1}{2}(p + q)\) be their mixture. Then:

$$\mathrm{JSD}(p \| q) = \frac{1}{2} D_{\mathrm{KL}}(p \| m) + \frac{1}{2} D_{\mathrm{KL}}(q \| m)$$

where \(D_{\mathrm{KL}}(p \| m) = \sum_x p(x) \log_2 \frac{p(x)}{m(x)}\) is KL divergence measured in bits (using log base 2). Using natural logs gives JSD in nats, bounded by \(\ln 2 \approx 0.693\).

Four Key Properties (with proofs)

Key Property 1: Symmetry — JSD(p,q) = JSD(q,p)

The mixture \(m = (p+q)/2\) is symmetric in p and q. Swapping the roles gives the same m, so each KL term is also swapped — but the ½ weighting means the total is unchanged. ∎

Key Property 2: Bounded — 0 ≤ JSD(p,q) ≤ 1 bit

Lower bound: If p = q then m = p, so KL(p‖m) = 0 and KL(q‖m) = 0 → JSD = 0.
Upper bound: By Gibbs' inequality, \(D_{\mathrm{KL}}(p\|m) \leq \log_2(1/\min_x m(x)/p(x))\). The tightest bound is 1 bit when p and q have disjoint support (e.g., one-hot on different outcomes): each KL term equals \(\log_2(1/0.5) = 1\) bit, so JSD = ½·1 + ½·1 = 1 bit. ∎

Key Property 3: √JSD is a metric (satisfies triangle inequality)

Endres & Schindele (2003) proved that \(d(p,q) = \sqrt{\mathrm{JSD}(p,q)}\) satisfies identity, symmetry, and the triangle inequality — making it a proper distance function on the space of distributions. JSD alone is NOT a metric (triangle inequality can fail for the squared root of a non-metric).

Key Property 4: Relation to Shannon entropy

There is an elegant entropy decomposition:
\(\mathrm{JSD}(p,q) = H\!\left(\frac{p+q}{2}\right) - \frac{1}{2}H(p) - \frac{1}{2}H(q)\)
JSD equals the entropy of the mixture minus the average entropy of the components — a "mixture gains information" perspective.

$$\mathrm{JSD}(p,q) = H\!\left(\frac{p+q}{2}\right) - \frac{H(p)+H(q)}{2}$$
⚠️ JSD vs KL divergence — critical differences

KL divergence \(D_{\mathrm{KL}}(p\|q)\) is asymmetric and can be infinite when q(x)=0 but p(x)>0 — a major problem when comparing neural network outputs to empirical data with zero counts. JSD never blows up because m = (p+q)/2 always assigns positive weight wherever either distribution does, so the log ratio is always finite.

Numerical trace with our example distributions

With \(p = [0.05, 0.15, 0.55, 0.20, 0.05]\), \(q = [0.05, 0.05, 0.20, 0.45, 0.25]\):

$$m = \tfrac{p+q}{2} = [0.050,\; 0.100,\; 0.375,\; 0.325,\; 0.150]$$
$$D_{\mathrm{KL}}(p\|m) = 0.1723 \text{ bits},\quad D_{\mathrm{KL}}(q\|m) = 0.1641 \text{ bits}$$
$$\mathrm{JSD}(p,q) = \tfrac{1}{2}(0.1723 + 0.1641) = \mathbf{0.1682}\text{ bits},\quad \sqrt{\mathrm{JSD}} = 0.4101$$
3
The GAN Connection
▼

The Original GAN Objective (Goodfellow et al., 2014)

In the original GAN framework, a generator G produces fake samples and a discriminator D tries to distinguish real from fake. Goodfellow showed that at the optimal discriminator \(D^* = \frac{p_{\mathrm{data}}(x)}{p_{\mathrm{data}}(x) + p_G(x)}\), the generator's training objective simplifies to:

$$C(G) = -\log 4 + 2 \cdot \mathrm{JSD}(p_{\mathrm{data}} \| p_G)$$

Minimising the generator loss is therefore exactly minimising the Jensen-Shannon Divergence between the real data distribution and the generator's output distribution. The global minimum \(C^* = -\log 4\) is achieved when and only when \(p_G = p_{\mathrm{data}}\), i.e. JSD = 0.

🔴 Why JSD Causes Mode Collapse in GANs

JSD is bounded at 1 bit even when distributions are completely disjoint. In early GAN training, real and generated distributions barely overlap, so JSD ≈ 1 bit and its gradient vanishes — the generator receives no useful signal about which direction to improve. This "gradient saturation" is the root cause of training instability and mode collapse in vanilla GANs. Wasserstein GANs (Arjovsky et al., 2017) replaced JSD with the Wasserstein-1 distance, which provides meaningful gradients even when distributions don't overlap.

Entropy decomposition — a deeper insight

The entropy formula \(\mathrm{JSD}(p,q) = H(m) - \tfrac{1}{2}H(p) - \tfrac{1}{2}H(q)\) reveals JSD as the information gain from mixing. The mixture distribution is always at least as uncertain as the average of its components — and how much more uncertain it is exactly measures how different p and q are. If p and q are identical, mixing adds zero uncertainty; if they're orthogonal, mixing creates maximum additional uncertainty.

💡 Generalisation to Multiple Distributions

JSD generalises to \(k\) distributions with weights \(\pi_1,\ldots,\pi_k\): \(\mathrm{JSD}_\pi(p_1,\ldots,p_k) = H\!\left(\sum_i \pi_i p_i\right) - \sum_i \pi_i H(p_i)\). This multi-distribution form is used in mixture model training and diversity measurement.

From-Scratch Implementation & Code Trace
▼

From-scratch NumPy implementation (with line-by-line trace)

import numpy as np
def kl_divergence(p, q, base=2):
"""KL divergence D_KL(p||q) in bits (base=2) or nats (base=e)."""
p, q = np.asarray(p, float), np.asarray(q, float)
mask = (p > 0) # avoid log(0); 0*log(0) = 0 by convention
log_fn = np.log2 if base == 2 else np.log
return float(np.sum(p[mask] * log_fn(p[mask] / q[mask])))
def jsd(p, q, base=2):
"""Jensen-Shannon Divergence. Symmetric, bounded in [0, 1] (base=2)."""
p, q = np.asarray(p, float), np.asarray(q, float)
m = (p + q) / 2 # mixture midpoint
return 0.5 * kl_divergence(p, m, base) + 0.5 * kl_divergence(q, m, base)
def jsd_metric(p, q):
"""√JSD — a proper metric (triangle inequality holds)."""
return np.sqrt(jsd(p, q))
# ── Trace ─────────────────────────────────────────────────────────────────
p = np.array([0.05, 0.15, 0.55, 0.20, 0.05])
q = np.array([0.05, 0.05, 0.20, 0.45, 0.25])
m = (p + q) / 2 # [0.050, 0.100, 0.375, 0.325, 0.150]
kl_pm = kl_divergence(p, m) # 0.1723 bits
kl_qm = kl_divergence(q, m) # 0.1641 bits
jsd_val = 0.5 * kl_pm + 0.5 * kl_qm # 0.1682 bits
metric = np.sqrt(jsd_val) # 0.4101

Production usage — SciPy

from scipy.spatial.distance import jensenshannon
import numpy as np
p = np.array([0.05, 0.15, 0.55, 0.20, 0.05])
q = np.array([0.05, 0.05, 0.20, 0.45, 0.25])
# scipy.spatial.distance.jensenshannon returns √JSD (the metric)
dist = jensenshannon(p, q, base=2) # 0.4101 (√JSD, NOT JSD!)
jsd_val = dist ** 2 # 0.1682 (JSD in bits)
# ⚠️ Common gotcha: scipy returns the SQUARE ROOT by default.
# Always square it if you want the raw JSD value.
⚠️ Common Gotcha: scipy returns √JSD, not JSD

scipy.spatial.distance.jensenshannon(p, q) returns the square root of JSD (the Jensen-Shannon distance, not the divergence). If you need the divergence value itself, square the output. This has tripped up many practitioners comparing numerical results.

Key Takeaways & When to Use JSD
▼

Use JSD when:

  • You need a symmetric measure — neither distribution is the "reference"
  • Distributions may have non-overlapping support (KL would be ∞)
  • You want a bounded score for easy interpretation (e.g., model evaluation dashboards)
  • You need a proper metric — use √JSD for clustering or nearest-neighbour search on distributions
  • You're debugging a GAN — JSD directly measures how far generator is from data distribution

Do NOT use JSD when:

  • Distributions are far apart and you need informative gradients for a generative model → use Wasserstein distance (WGAN) instead
  • You explicitly need asymmetry (e.g., forward vs. reverse KL has different mode-covering/mode-seeking behaviour)
  • You're computing cross-entropy loss in classification → that's forward KL implicitly
