1
Understanding the Concept
▼

What is a linear transformation? A linear transformation is a function that moves every point in space according to a fixed rule — like stretching a rubber sheet, spinning it, or flipping it — while always keeping the origin fixed and never bending straight lines into curves. Every such transformation on 2D space can be represented by a 2×2 matrix.

Analogy: Think of space as a grid of graph paper. A linear transformation is like printing that grid on a thin rubber sheet and then stretching, rotating, or flipping the sheet. Straight lines stay straight, parallel lines stay parallel, and the origin (where the axes cross) never moves.

There are four canonical "pure" transforms you should master. They appear constantly in graphics, robotics, PCA, and ML:

  • Rotation — spin the plane by angle \(\theta\). Area preserved (det = 1).
  • Reflection — flip across a line through the origin. Area preserved, but orientation flips (det = −1).
  • Orthogonal projection — collapse everything onto a subspace (a line through origin). Area lost (det = 0).
  • Shear — slide one axis while holding the other fixed. Area preserved (det = 1), but angles change.
💡 If you remember one thing

The determinant tells you everything about area change and orientation: \(|\det(A)|\) = area scaling factor; \(\text{sign}(\det(A)) > 0\) = orientation preserved; \(\text{sign}(\det(A)) < 0\) = orientation flipped; \(\det(A) = 0\) = dimension collapsed.

2
How Each Transform Works
▼

Rotation by angle \(\theta\)

The rotation matrix sends the standard basis vectors \(\mathbf{e}_1 = (1,0)\) to \((\cos\theta, \sin\theta)\) and \(\mathbf{e}_2 = (0,1)\) to \((-\sin\theta, \cos\theta)\). Writing these as columns gives:

$$R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}, \quad \det(R) = \cos^2\theta + \sin^2\theta = 1$$

Key properties: \(R(\theta)^{-1} = R(-\theta) = R(\theta)^\top\) — rotation matrices are orthogonal (\(R^\top R = I\)). Eigenvectors are complex: \(e^{\pm i\theta}\) — no real fixed directions (except \(\theta = 0, \pi\)).

Reflection across the line at angle \(\alpha\)

Reflecting across the line \(y = x\tan\alpha\) (which makes angle \(\alpha\) with the x-axis):

$$M(\alpha) = \begin{bmatrix} \cos 2\alpha & \sin 2\alpha \\ \sin 2\alpha & -\cos 2\alpha \end{bmatrix}, \quad \det(M) = -1$$

The determinant is always \(-1\): reflections flip orientation. The eigenvectors are the line of reflection (eigenvalue \(+1\)) and the perpendicular line (eigenvalue \(-1\)).

Orthogonal projection onto the line at angle \(\alpha\)

Every point is projected perpendicularly onto the line \(\mathbf{u} = (\cos\alpha, \sin\alpha)^\top\). This is \(P = \mathbf{u}\mathbf{u}^\top\):

$$P(\alpha) = \begin{bmatrix} \cos^2\alpha & \cos\alpha\sin\alpha \\ \cos\alpha\sin\alpha & \sin^2\alpha \end{bmatrix}, \quad \det(P) = 0$$

The determinant is 0 because the plane collapses onto a line (dimension drops). Eigenvalues: 1 (along the projection line) and 0 (perpendicular direction — everything in that direction maps to zero).

Horizontal shear by factor \(k\)

A shear slides points horizontally proportional to their height. The y-axis tilts but the x-axis is fixed:

$$S(k) = \begin{bmatrix} 1 & k \\ 0 & 1 \end{bmatrix}, \quad \det(S) = 1$$

Area is preserved (det = 1). The only eigenvector is the x-axis direction \((1, 0)^\top\) with eigenvalue 1 — a shear has a repeated eigenvalue with only one eigenvector, making it non-diagonalizable (defective).

Key Concept: Column Interpretation

The columns of any transformation matrix \(A\) are the images of the standard basis vectors. Column 1 = where \((1,0)\) lands; column 2 = where \((0,1)\) lands. This is the fastest way to read any 2×2 matrix geometrically.

3
The Math — Derivations & Properties
▼

Linearity conditions

A function \(T: \mathbb{R}^2 \to \mathbb{R}^2\) is linear if and only if for all \(\mathbf{u}, \mathbf{v} \in \mathbb{R}^2\) and \(c \in \mathbb{R}\):

$$T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v}) \quad \text{and} \quad T(c\mathbf{u}) = cT(\mathbf{u})$$

Every linear map on \(\mathbb{R}^2\) can be written as \(T(\mathbf{x}) = A\mathbf{x}\) for a unique 2×2 matrix \(A\).

Deriving the rotation matrix

We want \(T\) to rotate vectors by angle \(\theta\). A vector \(\mathbf{x} = (r\cos\phi, r\sin\phi)\) should map to \((r\cos(\phi+\theta), r\sin(\phi+\theta))\). Using angle-addition formulas:

$$x' = r\cos\phi\cos\theta - r\sin\phi\sin\theta = x\cos\theta - y\sin\theta$$
$$y' = r\cos\phi\sin\theta + r\sin\phi\cos\theta = x\sin\theta + y\cos\theta$$

In matrix form: \((x', y')^\top = R(\theta)(x, y)^\top\), giving the rotation matrix above. The determinant equals \(\cos^2\theta + \sin^2\theta = 1\) by the Pythagorean identity.

Composition of transforms

Transforms compose by matrix multiplication. Order matters: rotating then reflecting \(\neq\) reflecting then rotating. But:

$$R(\theta_2) \cdot R(\theta_1) = R(\theta_1 + \theta_2) \quad \text{(rotations commute with each other)}$$
$$P(\alpha)^2 = P(\alpha) \quad \text{(projection is idempotent)}$$
$$M(\alpha)^2 = I \quad \text{(reflecting twice = identity)}$$

⚠️ Common Misconception

A projection matrix has \(\det = 0\), which means it is NOT invertible — information is permanently lost. You cannot recover the original vector from its projection. This is why principal components (which project high-dimensional data) discard variance.

From-Scratch Code (NumPy)
▼

All four transforms implemented from first principles, with a numerical trace for \(\theta = 45°\), \(\alpha = 30°\), \(k = 0.8\):

import numpy as np
def rotation(theta_deg): # R(θ)
t = np.radians(theta_deg) # 45° → 0.7854 rad
return np.array([[np.cos(t), -np.sin(t)],
[np.sin(t), np.cos(t)]]) # det = cos²+sin² = 1
def reflection(alpha_deg): # M(α)
a = np.radians(2 * alpha_deg) # use double angle
return np.array([[np.cos(a), np.sin(a)],
[np.sin(a), -np.cos(a)]]) # det = -1 always
def projection(alpha_deg): # P(α) = uuᵀ
a = np.radians(alpha_deg)
u = np.array([np.cos(a), np.sin(a)]) # unit vector
return np.outer(u, u) # det = 0 always
def shear(k): # S(k)
return np.array([[1, k], [0, 1]]) # det = 1 always
# --- Numerical trace (θ=45°, α=30°, k=0.8) ---
R = rotation(45) # [[0.707, -0.707], [0.707, 0.707]]
M = reflection(30) # [[0.5, 0.866], [0.866, -0.5]]
P = projection(30) # [[0.75, 0.433], [0.433, 0.25]]
Sh = shear(0.8) # [[1, 0.8], [0, 1]]
v = np.array([1, 1]) # test vector
print(R @ v) # [0.000, 1.414] — rotated 45°
print(M @ v) # [1.366, 0.366] — reflected across 30° line
print(P @ v) # [1.183, 0.683] — projected onto 30° line
print(Sh @ v) # [1.8, 1.0] — sheared by k=0.8
# Verify determinants
np.linalg.det(R) # ≈ 1.0 ✓
np.linalg.det(M) # ≈ -1.0 ✓
np.linalg.det(P) # ≈ 0.0 ✓
np.linalg.det(Sh) # ≈ 1.0 ✓

🔗 ML Connections

PCA projects data onto eigenvectors of the covariance matrix — a composition of rotation (to eigenbasis) and projection (onto top-k directions). Attention computes query-key dot products then normalizes — geometrically this is a sequence of rotations and projections in a high-dimensional space. Householder reflections are the workhorse behind numerically stable QR decomposition (used in backprop, least squares, and SVD computation).

⚠️ Orthogonal vs Orthonormal

An orthogonal matrix has \(Q^\top Q = I\), meaning its columns are orthonormal. Both rotation and reflection matrices are orthogonal. "Orthogonal transform" preserves lengths and angles. Projection matrices are NOT orthogonal (they are symmetric: \(P^\top = P\) and idempotent: \(P^2 = P\)).
