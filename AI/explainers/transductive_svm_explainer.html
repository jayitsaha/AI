Transductive SVM (TSVM)

Semi-supervised classification via margin maximisation over labeled + unlabeled data
Advanced Classical ML Semi-Supervised Non-Convex Optimisation
1
Understanding the Concept

The core idea: A standard SVM only uses labeled training points to find a decision boundary. A TSVM says: "I also have a pile of unlabeled points — let me assign them labels, and then find the boundary that gives the biggest margin over all points."

Analogy. Imagine two villages (positive class, negative class) separated by a valley. You know which village a few houses belong to. There are many houses of unknown allegiance scattered across the valley. TSVM finds the widest no-man's land (margin) that avoids placing the boundary through any cluster of houses — known or unknown. The boundary prefers to cut through the sparsely populated valley floor, not through a dense neighbourhood.

💡 If you remember one thing

TSVM simultaneously assigns pseudo-labels to unlabeled data and maximises the margin. The boundary is forced to pass through low-density regions (the cluster assumption). This makes the objective non-convex — a major challenge.

One-sentence summary: TSVM extends the SVM maximum-margin principle to semi-supervised learning by treating the labels of unlabeled points as discrete latent variables and jointly optimising over all of them, exploiting the cluster and low-density separation assumptions.

2
How It Works — Architecture & Mechanism

Let \(\mathcal{L} = \{(x_i, y_i)\}_{i=1}^l\) be labeled points with \(y_i \in \{-1,+1\}\), and \(\mathcal{U} = \{x_j^*\}_{j=1}^u\) be unlabeled points. A TSVM seeks a hyperplane \((w, b)\) and pseudo-labels \(\hat{y}_j \in \{-1,+1\}\) that solve:

$$\min_{w,b,\hat{y},\xi,\xi^*} \; \frac{1}{2}\|w\|^2 + C_l \sum_{i=1}^l \xi_i + C_u \sum_{j=1}^u \xi_j^*$$ $$\text{subject to:} \quad y_i(w^\top x_i + b) \geq 1 - \xi_i, \; \xi_i \geq 0 \quad \forall i \in \mathcal{L}$$ $$\hat{y}_j(w^\top x_j^* + b) \geq 1 - \xi_j^*, \; \xi_j^* \geq 0 \quad \forall j \in \mathcal{U}$$ $$\hat{y}_j \in \{-1,+1\}, \quad \xi_j^* \geq 0$$

The parameters \(C_l\) and \(C_u\) control how much labeled vs unlabeled points are penalised for margin violations. A class-balance constraint is often added: \(\sum_j \hat{y}_j = \lfloor u \cdot r \rfloor\) where \(r\) is the expected fraction of positives.

Key Concept — Why Non-Convex?

The integer constraint \(\hat{y}_j \in \{-1,+1\}\) makes the feasible set discrete and non-convex. Even if we relax to \(\hat{y}_j \in [-1,+1]\), the product \(\hat{y}_j(w^\top x_j^*+b)\) is bilinear (product of two optimisation variables), which is non-convex. There are exponentially many \(2^u\) label assignments to consider.

Practical algorithms to handle non-convexity:

  • Local search / label-switching (Joachims 1999): Start from an inductive SVM prediction; greedily swap pairs of unlabeled labels if the objective improves. \(O(u^2)\) per outer iteration.
  • Continuation / annealing (CCCP): Start with small \(C_u\), gradually increase it. Each step is a convex QP. The sequence of solutions "anneals" toward a good local minimum.
  • Concave-Convex Procedure (CCCP): The non-convex loss is split into convex + concave parts; at each step the concave part is linearised, yielding a convex sub-problem.
  • SVM-light T: Joachims' practical implementation using the label-switching strategy.
⚠️ Design Decision — C_u Scheduling

If \(C_u\) starts too large, the algorithm gets stuck in bad local optima driven by the unlabeled data. Standard practice: start \(C_u \ll C_l\) (e.g. 0.001×\(C_l\)) and double it repeatedly until \(C_u = C_l\). This schedule ensures that labeled data "anchors" the solution first.

3
The Math — Non-Convex Objective & CCCP

Define the hinge loss \(\ell(z) = \max(0, 1-z)\). The TSVM objective can be written as:

$$\mathcal{J}(w,b,\hat{y}) = \frac{1}{2}\|w\|^2 + C_l \sum_{i=1}^l \ell\bigl(y_i f(x_i)\bigr) + C_u \sum_{j=1}^u \ell\bigl(\hat{y}_j f(x_j^*)\bigr)$$

where \(f(x) = w^\top x + b\).

An alternative viewpoint uses the symmetric hinge loss (hat loss) on unlabeled points:

$$\ell^{\text{sym}}(z) = \max(0, 1 - |z|) = \max(0, 1-z) + \max(0, 1+z) - 1$$

This treats an unlabeled point that lies near the boundary (small \(|f(x_j^*)|\)) as costly regardless of sign, directly implementing the low-density separation assumption.

📐 CCCP Decomposition

Write \(\ell^{\text{sym}}(z) = \underbrace{\max(0,1-z)}_{\text{convex}} + \underbrace{\max(0,1+z) - 1}_{\text{concave in } z \text{ for } z \leq 0}\). At iteration \(t\): linearise the concave part around \(f^{(t)}(x_j^*)\), yielding a convex QP solvable by any SVM solver. Iterate until convergence. Each iteration strictly decreases the objective (descent property of CCCP).

Convergence guarantee: CCCP converges to a local minimum or a stationary point of the original non-convex problem. Global optimality is not guaranteed; multiple initialisations help.

VC-theory perspective: With \(l\) labeled and \(u\) unlabeled points, the effective margin on the entire data pool is larger, which can reduce the generalisation bound compared to using only labeled data. Specifically, the leave-one-out error bound on unlabeled points scales as \(O\!\left(\frac{R^2 / \gamma^2 + 1}{u}\right)\) where \(\gamma\) is the margin on unlabeled data and \(R\) is the radius of the data ball (Vapnik & Sterin 1977; Joachims 1999).

From-Scratch NumPy Implementation

Simplified TSVM using the label-switching heuristic (Joachims 1999). Assumes a linear kernel for clarity; production code uses quadratic programming for arbitrary kernels.

import numpy as np
from sklearn.svm import SVC
def tsvm_label_switching(X_l, y_l, X_u, C_l=1.0, C_u_max=1.0, n_steps=10):
"""Transductive SVM via C_u annealing + greedy label-switching."""
n_u = len(X_u)
# Step 1: Inductive SVM on labeled data only
svm = SVC(C=C_l, kernel='rbf').fit(X_l, y_l)
y_hat = svm.predict(X_u).astype(float) # initial pseudo-labels
# Step 2: Anneal C_u from small to C_u_max
C_u = C_u_max * 1e-3 # start very small
X_all = np.vstack([X_l, X_u])
while C_u <= C_u_max:
y_all = np.concatenate([y_l, y_hat])
w_all = np.concatenate([np.full(len(y_l), C_l), np.full(n_u, C_u)])
svm = SVC(C=1.0, kernel='rbf').fit(X_all, y_all, sample_weight=w_all)
# Step 3: Label-switching until stable
changed = True
while changed:
changed = False
scores = svm.decision_function(X_u) # f(x_j*)
for j in range(n_u):
for k in range(j+1, n_u):
# Swap if both margin violations improve
if y_hat[j] != y_hat[k]: # opposite labels
if scores[j]*y_hat[j] < 0 and scores[k]*y_hat[k] < 0:
y_hat[j], y_hat[k] = y_hat[k], y_hat[j]
changed = True
if changed:
y_all = np.concatenate([y_l, y_hat])
svm.fit(X_all, y_all, sample_weight=w_all)
C_u = min(C_u * 2, C_u_max) # double C_u
return svm, y_hat # final SVM + pseudo-labels

🎯 When to Use TSVM

Use TSVM when: you have a fixed, known unlabeled test set; clusters are well-separated; labeled data is very scarce (<1% of total); and you can afford the quadratic-in-\(u\) compute cost.

Do NOT use TSVM when: you need online/streaming predictions on new points; unlabeled data is massive (>10 k points); or the cluster assumption is violated (classes overlap).

  • Advantages: principled margin maximisation; transductive VC bound; handles very small labeled sets; kernel trick applies naturally.
  • Disadvantages: non-convex optimisation with many local optima; does not generalise to new test points (truly transductive); slow (\(O(u^2)\) label-switching); sensitive to class-balance hyperparameter; can hurt if cluster assumption violated.
