Visual Reasoning: NLVR, Winoground

Benchmarking multimodal models beyond superficial correlations
Foundational Deep Learning Vision-Language Evaluation
1
Understanding Visual Reasoning
▼

What is it? Visual reasoning refers to a model's ability to understand complex relationships between elements in an image and a given text. This goes beyond simple object recognition or captioning, requiring capabilities like counting, spatial understanding, negation, attribute binding, and logical inference. For instance, a model might correctly identify a "red block" but fail to verify "there are more red blocks than blue blocks."

Analogy: Imagine a child learning to read and understand the world. Initially, they might learn to identify "dog" in a picture and "dog" in text. This is basic recognition. True visual reasoning is when they can answer questions like "Is the dog sitting on the mat?" or "Are there two dogs and one cat?" — requiring a deeper, compositional understanding of both modalities and their interaction.

💡 If you remember one thing

Visual reasoning benchmarks (like NLVR and Winoground) are designed to test if multimodal models genuinely understand the semantic alignment between vision and language, or if they are merely exploiting superficial correlations or unimodal biases (e.g., guessing answers based only on the text, or only on the image, without true cross-modal understanding).

How NLVR & Winoground Work Internally
▼

The Limitations of Early VQA

Many early Visual Question Answering (VQA) datasets were found to contain "language priors" or "shortcut learning." For example, if 80% of questions starting with "What color is the" had "red" as an answer, models could achieve high accuracy by guessing "red" without looking at the image. NLVR2 and Winoground were developed to combat these issues by demanding more robust, grounded reasoning.

NLVR2: Natural Language for Visual Reasoning 2

NLVR2 (Suhr et al., 2018) is a binary classification task. Given a natural language sentence and two related images, the model must determine if the sentence is true for both images simultaneously. This design forces models to perform explicit comparisons, spatial reasoning, counting, and negation across multiple visual inputs guided by a single linguistic query.

  • Input: A sentence \(T\) and two images \(I_1, I_2\).
  • Output: Binary (True/False).
  • Challenge: Requires joint reasoning over two visual contexts and their relation to the text. For example, "There is a red block to the left of a blue block in both images."

Winoground: Adversarial Contrastive Evaluation

Winoground (Mu et al., 2022) is an adversarial benchmark designed to expose unimodal biases and spurious correlations. It presents a "winograd schema" for vision-language models: given two images and two captions, the model must correctly match each image to its corresponding caption. The key is that the *distractor* image and caption are highly plausible but incorrect, making it hard for models to cheat.

  • Input: Two images \(I_1, I_2\) and two captions \(T_1, T_2\).
  • Goal: Correctly identify that \((I_1, T_1)\) and \((I_2, T_2)\) are the true pairs.
  • Challenge: Each image is plausible with either caption, and each caption is plausible with either image. A model must understand the subtle differences to pass. For example, \(I_1\) is "dog chases cat", \(I_2\) is "cat chases dog"; \(T_1\) is "dog chases cat", \(T_2\) is "cat chases dog".
🔑 Key Property

Both NLVR2 and Winoground push models beyond simple correlation. NLVR2 demands compositional reasoning over multiple images, while Winoground specifically targets unimodal biases by creating highly competitive distractor examples that test true cross-modal understanding rather than reliance on image-only or text-only cues.

3
Why It Works — The Math
▼

NLVR2: Joint Embedding and Classification

For NLVR2, models typically encode the sentence and both images into a shared embedding space. A common approach concatenates these embeddings and passes them through a Multi-Layer Perceptron (MLP) for binary classification:

$$ \mathbf{v}_1 = \text{Enc}_V(I_1), \quad \mathbf{v}_2 = \text{Enc}_V(I_2), \quad \mathbf{t} = \text{Enc}_L(T) $$ $$ \mathbf{h} = \text{concat}(\mathbf{v}_1, \mathbf{v}_2, \mathbf{t}) $$ $$ s = \text{MLP}(\mathbf{h}) $$ $$ P(\text{True} \mid T, I_1, I_2) = \text{sigmoid}(s) $$

The model must learn to extract and compare relevant features from both images based on the textual query, rather than just processing each image-sentence pair independently.

Winoground: Contrastive Scoring for Robustness

Winoground's evaluation is designed to be highly sensitive to unimodal biases. Given two images \((I_1, I_2)\) and two captions \((T_1, T_2)\), where \((I_1, T_1)\) and \((I_2, T_2)\) are the correct pairs, a model computes similarity scores \(S(I_i, T_j)\) for all four combinations. To pass, a model must satisfy four strict contrastive conditions:

$$ \text{score}(I, T) = \text{similarity}(\text{Enc}_V(I), \text{Enc}_L(T)) $$ $$ \text{WinogroundPass} \iff \quad \begin{aligned} & \big(S(I_1, T_1) > S(I_1, T_2)\big) \quad (\text{Image } I_1 \text{ matches } T_1 \text{ better than } T_2) \\ \land\ & \big(S(I_2, T_2) > S(I_2, T_1)\big) \quad (\text{Image } I_2 \text{ matches } T_2 \text{ better than } T_1) \\ \land\ & \big(S(I_1, T_1) > S(I_2, T_1)\big) \quad (\text{Caption } T_1 \text{ matches } I_1 \text{ better than } I_2) \\ \land\ & \big(S(I_2, T_2) > S(I_1, T_2)\big) \quad (\text{Caption } T_2 \text{ matches } I_2 \text{ better than } I_1) \end{aligned} $$

This rigorous evaluation ensures that the model correctly associates both the image and the text with their true counterpart, and that this association is stronger than any spurious association with the distractor. The conditions are symmetric for both image and text modalities.

⚠️ Common Pitfall

Many models perform well on traditional VQA but fail Winoground. This often reveals a unimodal bias: the model might be excellent at image captioning (so \(S(I_1, T_1)\) is high), but if it also scores \(S(I_1, T_2)\) high because \(I_1\) is just a "good image," it fails. Winoground demands true cross-modal grounding, not just high individual scores.

Key Takeaways
▼

When to use NLVR/Winoground:

  • When evaluating the true multimodal understanding of Vision-Language Models (VLMs), especially for compositional reasoning.
  • To detect and mitigate unimodal biases (e.g., models relying too heavily on text priors or image features alone).
  • For tasks requiring fine-grained comparisons, spatial relationships, counting, or negation across visual inputs.
  • To push the boundaries of VLM capabilities beyond simple object recognition or generic captioning.

When NOT to use:

  • For basic VQA tasks where simpler datasets suffice and computational resources are limited.
  • If your primary goal is only object detection or image classification, as these benchmarks target more complex reasoning.
  • If your model is not designed for multimodal input (e.g., purely vision or purely language models).
💡 Hierarchy of VLM Evaluation

The evolution of VLM benchmarks reflects increasing demands on reasoning:
Image Captioning / VQA (basic recognition, language priors)
   ↓
NLVR2 (multi-image comparison, compositional reasoning)
   ↓
Winoground (adversarial contrastive evaluation, unimodal bias detection)
Each step adds complexity, pushing models towards more robust, human-like understanding.

Code Trace (Python-like Pseudocode)
▼
# Assume Enc_V(image) -> vector, Enc_L(text) -> vector
# Assume similarity(v1, v2) -> scalar (e.g., cosine similarity)
# --- NLVR2 Evaluation Logic ---
def evaluate_nlvr2(sentence, image1, image2, mlp_classifier, threshold=0.5):
v1_embed = Enc_V(image1)
v2_embed = Enc_V(image2)
t_embed = Enc_L(sentence)
# Concatenate embeddings and classify
joint_embed = concatenate([v1_embed, v2_embed, t_embed])
raw_score = mlp_classifier(joint_embed) # e.g., logits
confidence = sigmoid(raw_score) # P(True | S, I1, I2)
return confidence > threshold, confidence
# --- Winoground Evaluation Logic ---
def evaluate_winoground(image1, image2, text1, text2):
# Encode all inputs
e_I1, e_I2 = Enc_V(image1), Enc_V(image2)
e_T1, e_T2 = Enc_L(text1), Enc_L(text2)
# Compute all 4 similarity scores
S_I1T1 = similarity(e_I1, e_T1)
S_I1T2 = similarity(e_I1, e_T2)
S_I2T1 = similarity(e_I2, e_T1)
S_I2T2 = similarity(e_I2, e_T2)
# Check the four contrastive conditions
cond1 = (S_I1T1 > S_I1T2) # I1 matches T1 better than T2
cond2 = (S_I2T2 > S_I2T1) # I2 matches T2 better than T1
cond3 = (S_I1T1 > S_I2T1) # T1 matches I1 better than I2
cond4 = (S_I2T2 > S_I1T2) # T2 matches I2 better than I1
return all([cond1, cond2, cond3, cond4]), {
'S_I1T1': S_I1T1, 'S_I1T2': S_I1T2,
'S_I2T1': S_I2T1, 'S_I2T2': S_I2T2,
'cond1': cond1, 'cond2': cond2, 'cond3': cond3, 'cond4': cond4
}
