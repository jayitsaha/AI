Guiding Reinforcement Learning agents with auxiliary rewards without changing optimal policy
Intermediate Reinforcement Learning Algorithms O(1) extra cost
1
Understanding Reward Shaping
▼

What is it? In Reinforcement Learning (RL), agents learn by maximizing cumulative reward. However, environments often provide sparse rewards (e.g., only a +100 at the goal, 0 everywhere else), making learning very slow. Reward shaping adds auxiliary rewards to intermediate states to guide the agent, making the reward signal denser and learning faster.

Analogy: Imagine teaching a dog to fetch a specific toy. Sparse reward: only giving a treat when it brings *that exact toy* back. Learning is hard. Shaped reward: giving small treats for moving towards the toy, for picking up *any* toy, then bigger treats for picking up *the right toy*, and finally the big treat for bringing it back. The small, frequent treats guide the dog more efficiently without changing the ultimate goal (getting the specific toy).

💡 If you remember one thing

Potential-based reward shaping adds an auxiliary reward \(F(s,a,s')\) to the environment's true reward \(R(s,a,s')\) such that the optimal policy of the original Markov Decision Process (MDP) remains unchanged. The shaped reward is \(R'(s,a,s') = R(s,a,s') + F(s,a,s')\), where \(F(s,a,s') = \gamma \Phi(s') - \Phi(s)\) for some potential function \(\Phi(s)\) and discount factor \(\gamma\).

2
How Potential-Based Shaping Works
▼

The Problem: Sparse Rewards

Many real-world RL tasks suffer from sparse rewards. For example, in a maze, the agent might only get a reward when it reaches the exit, and zero otherwise. Until the agent stumbles upon the goal by pure chance, it receives no signal about whether its actions are good or bad. This makes exploration inefficient and learning extremely slow, especially in large state spaces.

The Solution: Adding a Potential Function

Potential-based reward shaping addresses this by defining a potential function \(\Phi(s)\) that assigns a scalar value to each state \(s\). This function typically reflects how "close" or "desirable" a state is to the goal. For instance, in a navigation task, \(\Phi(s)\) could be the negative distance to the goal, so states closer to the goal have a higher potential (less negative).

The auxiliary reward \(F(s,a,s')\) is then calculated as the difference in potential between the next state \(s'\) and the current state \(s\), scaled by the discount factor \(\gamma\):

$$F(s,a,s') = \gamma \Phi(s') - \Phi(s)$$

This \(F(s,a,s')\) is added to the original environment reward \(R(s,a,s')\) to form the shaped reward \(R'(s,a,s')\). The agent then learns using \(R'(s,a,s')\).

Design Decision: Why is \(\gamma \Phi(s') - \Phi(s)\) "Safe"?

The crucial property of potential-based shaping is that it guarantees policy invariance. This means that any optimal policy in the original MDP (with rewards \(R\)) is also an optimal policy in the shaped MDP (with rewards \(R'\)), and vice-versa. This is not true for arbitrary reward functions! The specific form \(\gamma \Phi(s') - \Phi(s)\) ensures that the relative values between states are preserved, only shifting the absolute value of the Q-function, which doesn't affect the optimal action choice.

🔑 Key Property

Potential-based reward shaping is policy invariant. It changes the absolute values of states and actions (the Q-values and V-values) but preserves their relative ordering, meaning the optimal policy remains the same. This allows faster learning without the risk of steering the agent towards a suboptimal goal.

3
Why It Works — The Policy Invariance Proof
▼

The Bellman Optimality Equation

In a standard MDP, the optimal Q-value function \(Q^*(s,a)\) satisfies the Bellman optimality equation:

$$Q^*(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \max_{a'} Q^*(s',a')$$

where \(R(s,a)\) is the immediate reward, \(\gamma\) is the discount factor, and \(P(s'|s,a)\) is the transition probability. The optimal policy \(\pi^*(s)\) chooses actions that maximize \(Q^*(s,a)\).

Shaped Bellman Equation

Now, let's consider an MDP with shaped rewards \(R'(s,a,s') = R(s,a,s') + \gamma \Phi(s') - \Phi(s)\). The Bellman equation for the shaped Q-function \(Q^{'*}(s,a)\) becomes:

$$Q^{'*}(s,a) = R(s,a) + \gamma \Phi(s') - \Phi(s) + \gamma \sum_{s'} P(s'|s,a) \max_{a'} Q^{'*}(s',a')$$

The key insight is that the optimal Q-function of the shaped MDP, \(Q^{'*}(s,a)\), relates to the original optimal Q-function, \(Q^*(s,a)\), by a simple additive shift:

$$Q^{'*}(s,a) = Q^*(s,a) + \Phi(s)$$

Let's prove this by substituting \(Q^*(s,a) + \Phi(s)\) into the shaped Bellman equation:

Substitute \(\Phi(s') + Q^*(s',a')\) for \(Q^{'*}(s',a')\):

\begin{align*} Q^{'*}(s,a) &= R(s,a) + \gamma \Phi(s') - \Phi(s) + \gamma \sum_{s'} P(s'|s,a) \max_{a'} (Q^*(s',a') + \Phi(s')) \\ &= R(s,a) - \Phi(s) + \gamma \sum_{s'} P(s'|s,a) \left( \Phi(s') + \max_{a'} Q^*(s',a') \right) \\ &= R(s,a) - \Phi(s) + \gamma \sum_{s'} P(s'|s,a) \Phi(s') + \gamma \sum_{s'} P(s'|s,a) \max_{a'} Q^*(s',a') \\ &= R(s,a) - \Phi(s) + \gamma \mathbb{E}_{s' \sim P(\cdot|s,a)}[\Phi(s')] + \gamma \mathbb{E}_{s' \sim P(\cdot|s,a)}[\max_{a'} Q^*(s',a')] \end{align*}

This derivation shows that the term \(\gamma \Phi(s')\) cancels out with the \(\Phi(s)\) terms when considering the expected future values. More precisely, the relationship \(Q^{'*}(s,a) = Q^*(s,a) + \Phi(s)\) holds for all \(s,a\). The addition of \(\Phi(s)\) to the Q-value doesn't change the action that maximizes it, since \(\Phi(s)\) is constant for a given state \(s\). Therefore, \(\max_{a'} Q^{'*}(s,a') = \max_{a'} (Q^*(s,a') + \Phi(s))\) implies that the optimal action \(a^*\) is the same in both cases.

⚠️ Common Pitfall

Not all reward shaping is policy invariant! If \(F(s,a,s')\) does not take the specific potential-based form \(\gamma \Phi(s') - \Phi(s)\), then adding it to the reward can change the optimal policy. This means the agent might learn to optimize for the shaped rewards, but end up with a suboptimal (or even disastrous) policy for the original problem. Always use potential-based shaping if policy invariance is critical.

Key Takeaways
▼

When to use potential-based shaping:

  • When rewards are sparse and the agent struggles with exploration (e.g., mazes, complex environments with delayed feedback).
  • When you have domain knowledge that can be encoded into a potential function (e.g., distance to goal, number of items collected, health remaining).
  • When you want to accelerate learning without altering the optimal policy of the original problem.
  • In continuous state spaces, if a differentiable potential function can be defined, it can be seamlessly integrated.

When NOT to use or be careful:

  • If the potential function \(\Phi(s)\) is poorly designed or provides misleading guidance, it can still slow down learning, even if the optimal policy is theoretically preserved.
  • If the environment already provides dense and informative rewards, shaping might add unnecessary complexity.
  • If the problem requires learning a completely novel behavior where domain knowledge is absent or incorrect.
  • The computational cost of evaluating \(\Phi(s)\) for every state transition must be negligible.
💡 Big Picture

Reward shaping is a powerful technique for injecting domain knowledge into RL. Potential-based shaping is particularly elegant because it provides a mathematical guarantee of policy invariance, making it a "safe" way to guide exploration and accelerate convergence to the true optimal policy. It transforms a sparse reward landscape into a helpful gradient, allowing algorithms to find solutions faster.

import numpy as np
class ShapedEnv:
def __init__(self, env, potential_fn, gamma):
self.env = env
self.potential_fn = potential_fn
self.gamma = gamma
self.last_state_potential = None
def reset(self):
obs, info = self.env.reset()
self.last_state_potential = self.potential_fn(obs)
return obs, info
def step(self, action):
next_obs, reward, terminated, truncated, info = self.env.step(action)
current_potential = self.last_state_potential
next_potential = self.potential_fn(next_obs)
# Calculate the shaping reward F(s,a,s')
shaping_reward = self.gamma * next_potential - current_potential
shaped_reward = reward + shaping_reward
self.last_state_potential = next_potential # Update for next step
return next_obs, shaped_reward, terminated, truncated, info
# Example Usage (simplified grid world)
class GridEnv:
def __init__(self, size=5, goal=(4,4)):
self.size = size; self.goal = goal
self.agent_pos = (0,0)
def reset(self):
self.agent_pos = (0,0); return self.agent_pos, {}
def step(self, action):
# 0:up, 1:down, 2:left, 3:right
r, c = self.agent_pos
if action == 0: r = max(0, r-1)
elif action == 1: r = min(self.size-1, r+1)
elif action == 2: c = max(0, c-1)
elif action == 3: c = min(self.size-1, c+1)
self.agent_pos = (r, c)
reward = 100 if self.agent_pos == self.goal else -1
terminated = (self.agent_pos == self.goal); truncated = False
return self.agent_pos, reward, terminated, truncated, {}
# Define a potential function (negative Manhattan distance to goal)
def manhattan_potential(state, goal_pos=(4,4), scale_k=1.0):
return -scale_k * (abs(state[0] - goal_pos[0]) + abs(state[1] - goal_pos[1]))
# Setup environment and shaped environment
raw_env = GridEnv()
shaped_env = ShapedEnv(raw_env, lambda s: manhattan_potential(s, scale_k=1.0), gamma=0.9)
# Simulate a step
obs, info = shaped_env.reset() # (0,0)
next_obs, shaped_r, term, trunc, info = shaped_env.step(3) # Move right to (0,1)
print(f"Shaped reward for (0,0)->(0,1): {shaped_r:.2f}")
