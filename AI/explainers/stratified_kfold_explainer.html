Stratified K-Fold Cross-Validation

Preserving class proportions across every fold — the right way to evaluate classifiers
Intermediate Model Selection Classical ML K folds · O(n)
1
Understanding the Concept

What is it? Stratified K-Fold splits your dataset into K validation folds while guaranteeing that each fold mirrors the overall class distribution of the full dataset. If 10 % of your data is class "fraud", every fold will also be ~10 % fraud — both in the held-out validation slice and in the training slice.

Analogy. Imagine you have a bag of 100 marbles: 80 blue, 15 red, 5 yellow. Plain K-Fold randomly scoops handfuls — some scoops might contain zero yellow marbles, skewing what the model learns. Stratified K-Fold carefully deals the marbles into K piles so each pile has ~80 blue, ~15 red, ~5 yellow — exactly preserving the recipe.

💡 If you remember one thing

Stratified K-Fold sorts samples by class and distributes them in round-robin order across folds, so each fold's class ratio matches the full dataset. For imbalanced data it is not optional — plain K-Fold can produce folds with zero minority-class samples, making evaluation meaningless.

One-sentence summary. Stratified K-Fold is K-Fold with the constraint that every fold maintains the original label distribution, producing unbiased, low-variance performance estimates especially under class imbalance.

2
How It Works — Numerical Example

Consider 20 samples, 3 classes: Class A (10 samples, 50 %), Class B (6 samples, 30 %), Class C (4 samples, 20 %). We want K = 5 folds, so each fold holds 4 samples.

📐 Allocation Formula

For class \(c\) with \(n_c\) samples and K folds, fold \(k\) receives \(\lfloor n_c/K \rfloor\) or \(\lceil n_c/K \rceil\) samples of that class, distributing the remainder round-robin:

$$n_{c,k} = \left\lfloor \frac{n_c}{K} \right\rfloor + \mathbf{1}\!\left[k < n_c \bmod K\right]$$

Global proportion preserved: \(\;\hat{p}_c = n_c/n\;\) — the same in every fold's validation set.

Exact allocation for our example:

ClassTotal%Per fold (exact)Fold allocation
A (●)1050%10/5 = 2.02 per fold, every fold
B (■)630%6/5 = 1.22 in folds 0–1, 1 in folds 2–4
C (▲)420%4/5 = 0.81 in folds 0–3, 0 in fold 4
⚠️ vs. Plain K-Fold

Plain K-Fold shuffles and cuts; fold 4 could accidentally contain 0 samples of Class C. For a minority class at 5 % or less this is almost guaranteed to happen in some fold, and the validation metric on that fold is measuring the wrong distribution.

3
Why It Matters for Imbalanced Data

Suppose 95 % of samples are class 0 and 5 % are class 1 (fraud, disease, rare event). With plain K-Fold some folds may contain no class-1 samples in the validation set. When you compute ROC-AUC, F1, or precision-recall on that fold:

Plain K-Fold (danger zone)

• Some folds: 0 minority samples → undefined F1, degenerate AUC
• Accuracy looks perfect (classifier predicts majority always)
• Variance across fold metrics explodes
• Model sees different class ratios per training fold → inconsistent threshold calibration

Stratified K-Fold (correct)

• Every fold: exactly ~5 % minority samples → well-defined metrics
• F1/AUC estimates have low variance across folds
• Training folds all see the same imbalance → model calibrates consistently
• Honest estimate of production performance

Mathematically, the expected validation error is unbiased only when the validation distribution matches the deployment distribution. Stratification enforces this match within each fold.

📌 Key Property

Stratified K-Fold is the unique fold assignment that minimises the KL divergence between each fold's label distribution and the full dataset's label distribution, given the constraint of non-overlapping folds.

Key Takeaways & When to Use

Always use Stratified K-Fold for classification — it is the default in scikit-learn's cross_val_score for classifiers for exactly this reason.

SituationRecommendation
Binary or multiclass classificationStratified K-Fold (default K=5 or K=10)
Heavily imbalanced classes (<10% minority)Stratified K-Fold + ROC-AUC / F1 metrics
Regression tasksPlain K-Fold (no class labels to stratify)
Very small datasets (<50 samples)Stratified Leave-One-Out CV
Time-series dataTimeSeriesSplit (ordering must be preserved)
Production snippet

from sklearn.model_selection import StratifiedKFold
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for train_idx, val_idx in skf.split(X, y): ...
