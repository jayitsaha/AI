Understanding Expected SARSA
▼

What is it? Expected SARSA is a model-free reinforcement learning algorithm used to learn the optimal action-value function \(Q(s,a)\) for a given policy \(\pi\). It's a Temporal Difference (TD) control method, meaning it learns from experience without a model of the environment's dynamics. Unlike standard SARSA, which samples a single next action, Expected SARSA computes an expected value over all possible next actions, weighted by their probabilities under the current policy.

Analogy: Imagine a cautious navigator trying to find the best route.

  • A SARSA navigator picks a path, takes a step, and learns from that single experience.
  • A Q-learning navigator imagines the *absolute best* path from their current location, even if they don't actually intend to take it, and learns from that optimal (but hypothetical) outcome.
  • An Expected SARSA navigator, however, considers all possible paths from their current location, weighs them by how likely they are to take each (based on their current habits/policy), and learns from the *average* expected outcome. This makes their updates more stable and less prone to being swayed by a single lucky or unlucky roll of the dice.

💡 If you remember one thing

Expected SARSA calculates its TD target using the expected Q-value of the next state, averaged over all actions according to the current policy \(\pi\): $$\text{TD Target} = R_{t+1} + \gamma \sum_{a'} \pi(a'|S_{t+1}) Q(S_{t+1}, a')$$ This significantly reduces the variance of the target compared to sampling a single action, leading to more stable learning.

2
How It Works Internally
▼

The Core Idea: Temporal Difference Learning

All SARSA-family algorithms are based on Temporal Difference (TD) learning. They update an estimate of the value function based on another estimate (bootstrapping). The general update rule is:

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ \text{TD Target} - Q(S_t, A_t) \right]$$

The key difference between SARSA, Q-learning, and Expected SARSA lies in how they construct the "TD Target":

  • SARSA (On-policy): The TD Target is based on the *next action actually taken* by the agent. If the agent takes action \(A_{t+1}\) in state \(S_{t+1}\), the target is \(R_{t+1} + \gamma Q(S_{t+1}, A_{t+1})\). This makes SARSA learn the value of the policy it is currently following (on-policy).
  • Q-learning (Off-policy): The TD Target is based on the *maximum possible Q-value* in the next state. The target is \(R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a')\). This allows Q-learning to learn the optimal policy's values directly, regardless of the exploration policy (off-policy).
  • Expected SARSA (Off-policy): The TD Target is based on the *expected Q-value* of the next state, considering all possible actions \(a'\) and their probabilities under the current policy \(\pi\). The target is \(R_{t+1} + \gamma \sum_{a'} \pi(a'|S_{t+1}) Q(S_{t+1}, a')\). It is off-policy because it learns about the target policy (often greedy) while following an exploratory behavior policy.

Design Decision: Why the Expectation?

The primary benefit of using the expectation \(\sum_{a'} \pi(a'|S_{t+1}) Q(S_{t+1}, a')\) is variance reduction.

  • SARSA's target is a single sample, which can be noisy, especially in stochastic environments.
  • Q-learning uses a maximum, which can also be a high-variance estimate if the max action's Q-value is unstable.
  • By averaging over all possible next actions, Expected SARSA smooths out the target, leading to more stable and often faster convergence, especially when the environment is deterministic or the policy is near-deterministic.
The trade-off is computational cost: summing over all actions can be expensive for environments with large action spaces, whereas SARSA and Q-learning only require looking up or maximizing over actions.

🔑 Key Property

Expected SARSA is an off-policy algorithm, meaning it can learn the optimal Q-function while following an exploratory behavior policy (e.g., \(\epsilon\)-greedy). The expectation term \(\sum_{a'} \pi(a'|S') Q(S', a')\) represents the true value of state \(S'\) under policy \(\pi\), i.e., \(V^{\pi}(S')\). So the TD target is effectively \(R_{t+1} + \gamma V^{\pi}(S_{t+1})\).

3
Why It Works — The Math
▼

The Bellman Expectation Equation for Q-values

The true action-value function \(Q^{\pi}(s,a)\) for a policy \(\pi\) satisfies the Bellman Expectation Equation:

$$Q^{\pi}(s,a) = \mathbb{E}_{\pi}\left[R_{t+1} + \gamma Q^{\pi}(S_{t+1}, A_{t+1}) \mid S_t=s, A_t=a\right]$$

This expectation can be expanded by marginalizing over the next state \(S'\) and next action \(A'\):

$$Q^{\pi}(s,a) = \sum_{s', r} p(s', r \mid s,a) \left[ r + \gamma \sum_{a'} \pi(a' \mid s') Q^{\pi}(s', a') \right]$$

Expected SARSA uses this structure. The term \(\sum_{a'} \pi(a' \mid s') Q^{\pi}(s', a')\) is precisely the expected value of the next state \(s'\) under policy \(\pi\), denoted \(V^{\pi}(s')\). So, the target effectively becomes \(R_{t+1} + \gamma V^{\pi}(S_{t+1})\).

Expected SARSA Update Rule

Given a transition \((S_t, A_t, R_{t+1}, S_{t+1})\), the update for \(Q(S_t, A_t)\) is:

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \left( \sum_{a'} \pi(a'|S_{t+1}) Q(S_{t+1}, a') \right) - Q(S_t, A_t) \right]$$

Here, \(\alpha\) is the learning rate, \(\gamma\) is the discount factor, and \(\pi(a'|S_{t+1})\) is the probability of taking action \(a'\) in state \(S_{t+1}\) according to the agent's current policy. This policy \(\pi\) is typically derived from the current Q-values, e.g., an \(\epsilon\)-greedy policy where the greedy action is chosen with probability \(1-\epsilon+\epsilon/|A|\) and other actions with probability \(\epsilon/|A|\).

Convergence Properties

Expected SARSA is guaranteed to converge to the optimal action-value function \(Q^*\) under conditions similar to Q-learning:

  • All state-action pairs are visited infinitely often (ensured by sufficient exploration, e.g., an \(\epsilon\)-greedy behavior policy with \(\epsilon > 0\)).
  • The learning rate \(\alpha\) decays appropriately (e.g., \(\sum \alpha_t = \infty\) and \(\sum \alpha_t^2 < \infty\)).
Its off-policy nature (target derived from policy \(\pi\) which can be different from the behavior policy) and use of expectation make it a robust and stable learner.

⚠️ Common Pitfall

The computational cost of Expected SARSA can be a bottleneck for environments with very large action spaces. The sum \(\sum_{a'} \pi(a'|S') Q(S', a')\) requires evaluating the Q-value for *every* possible action in the next state. In contrast, Q-learning only requires finding the maximum (which can be done efficiently in some cases), and SARSA only requires evaluating the Q-value for *one* sampled action.

Key Takeaways
▼

When to use Expected SARSA:

  • When you need stable and low-variance updates. The expectation over next actions smooths out the learning process, making it less sensitive to individual noisy samples.
  • In deterministic or near-deterministic environments, where the expectation often provides a very accurate estimate of the true value.
  • When policy evaluation (learning \(Q^{\pi}\) for a given \(\pi\)) is a primary concern, or as part of a policy iteration scheme.
  • When the action space is small, making the summation over all actions computationally feasible.

When NOT to use:

  • For environments with very large or continuous action spaces. The \(\sum_{a'}\) operation becomes computationally prohibitive. Q-learning's \(\max_{a'}\) is often faster to compute in such cases (e.g., if a function approximator can directly output the max).
  • If computational efficiency per update is paramount and a slightly higher variance is acceptable (e.g., standard SARSA or Q-learning might be faster per step in some scenarios).
  • When the goal is strictly to learn \(Q^*\) and Q-learning is simpler to implement for your specific problem.
💡 Variance-Bias Trade-off

Expected SARSA sits in an interesting spot in the RL algorithm landscape. It's off-policy like Q-learning, allowing it to learn \(Q^*\) while exploring, but it constructs its target using an expectation like a policy evaluation method. This gives it lower variance than SARSA (no sampling noise in the target) and can be more robust than Q-learning (max operator can be unstable), at the cost of higher computational complexity per update for large action spaces.

Code Trace (Python-like Pseudocode)
▼
import numpy as np
class ExpectedSarsaAgent:
def __init__(self, num_states, num_actions, alpha=0.1, gamma=0.9, epsilon=0.1):
self.Q = np.zeros((num_states, num_actions)) # Q-table initialization
self.alpha = alpha # Learning rate
self.gamma = gamma # Discount factor
self.epsilon = epsilon # Exploration rate for epsilon-greedy
self.num_actions = num_actions
def get_action_probabilities(self, state):
# Epsilon-greedy policy based on current Q-values
action_probs = np.ones(self.num_actions) * (self.epsilon / self.num_actions)
greedy_actions = np.argwhere(self.Q[state] == np.max(self.Q[state])).flatten()
prob_greedy = (1 - self.epsilon) / len(greedy_actions)
for a in greedy_actions:
action_probs[a] += prob_greedy
return action_probs
def choose_action(self, state):
action_probs = self.get_action_probabilities(state)
return np.random.choice(self.num_actions, p=action_probs)
def update(self, state, action, reward, next_state):
# Calculate action probabilities for next_state
next_action_probs = self.get_action_probabilities(next_state)
# Calculate expected Q-value for the next state
expected_q_s_prime = np.sum(next_action_probs * self.Q[next_state])
# Calculate TD Target
td_target = reward + self.gamma * expected_q_s_prime
# Calculate TD Error
td_error = td_target - self.Q[state, action]
# Update Q-value for (state, action)
self.Q[state, action] += self.alpha * td_error
