1
Understanding Confidence Intervals
▼

What is it? A confidence interval (CI) is a range of values computed from sample data that, under the correct frequentist interpretation, has a specified long-run probability of containing the true population parameter. It is not a probability statement about where the parameter is — it is a statement about the reliability of the procedure used to compute the interval.

Analogy: Imagine a robot fishing for the exact temperature of a lake with a thermometer that reads slightly differently each time. A 95% confidence interval is like a net with a guaranteed 95% catch rate — if the robot casts that net over and over, 95% of casts will land on the true temperature. On any single cast you can't say "95% chance the true temp is in this net." The net either has the fish or it doesn't. The 95% is about the net's long-run reliability, not about this particular cast.

💡 If you remember one thing

A 95% CI means: the procedure produces intervals that cover the true parameter in 95% of repeated experiments. It does NOT mean "there is a 95% probability the parameter lies in this specific interval." The parameter is fixed (frequentist view); the interval is the random object.

⚠️ The Most Common Misconception

"There is a 95% probability that \(\mu\) lies between 3.88 and 5.46." WRONG. The true mean \(\mu\) is a fixed (unknown) constant, not a random variable. It either is or isn't in the interval. The probability statement applies to the random interval, not to \(\mu\). (Bayesian credible intervals do give the probabilistic-parameter interpretation — but they require a prior.)

2
Construction: Exact, Asymptotic & Bootstrap
▼

Step 1 — Choose a Pivotal Quantity

A pivot is a function of data and the unknown parameter whose distribution is known and parameter-free. For the mean with unknown variance, the pivot is the t-statistic:

$$T = \frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t_{n-1}$$

Step 2 — Invert the Pivot

For confidence level \(1-\alpha\), we find the critical value \(t_{\alpha/2, n-1}\) such that \(P(-t_{\alpha/2} \le T \le t_{\alpha/2}) = 1-\alpha\), then rearrange to isolate \(\mu\):

$$\bar{X} - t_{\alpha/2,\,n-1}\frac{S}{\sqrt{n}} \;\le\; \mu \;\le\; \bar{X} + t_{\alpha/2,\,n-1}\frac{S}{\sqrt{n}}$$

Numerical Trace (n=25, seed=42, true μ=5)

Sample: \(\bar{x} = 4.673,\; s = 1.913,\; \text{SE} = s/\sqrt{25} = 0.383\)

Critical value: \(t_{0.025, 24} = 2.064\)

Margin: \(2.064 \times 0.383 = 0.790\)

$$\text{95% CI} = [4.673 - 0.790,\;\; 4.673 + 0.790] = [3.883,\; 5.463]$$

This interval does contain \(\mu = 5.0\). But one single CI cannot be said to have "95% probability" of containing \(\mu\) — that 95% is earned across many such experiments.

Bootstrap CI — No Distributional Assumption

When the sampling distribution is unknown or the pivot is unavailable, bootstrap resampling approximates the sampling distribution empirically. The percentile bootstrap CI is:

$$\text{CI}_{\text{boot}} = \left[\hat{\theta}^*_{(\alpha/2)},\; \hat{\theta}^*_{(1-\alpha/2)}\right]$$

where \(\hat{\theta}^*_{(p)}\) is the \(p\)-th percentile of \(B\) bootstrap replicate statistics. With \(B = 5000\) resamples from the same sample: Bootstrap 95% CI = [3.954, 5.401] — very close to the t-interval [3.883, 5.463] since data are approximately normal.

🔑 Three Types of CI

Exact (Clopper-Pearson for proportions, t-CI for means): finite-sample guarantee. Asymptotic (Wald, likelihood-ratio): valid as \(n\to\infty\), faster to compute. Bootstrap (percentile, BCa): no distributional assumption, works for any statistic, requires \(B\gg100\) resamples.

3
The Math — Derivation & Properties
▼

Coverage Probability (the formal definition)

Let \(\hat{\theta}_L(X), \hat{\theta}_U(X)\) be functions of the sample. The interval \([\hat{\theta}_L, \hat{\theta}_U]\) is a \(1-\alpha\) CI for \(\theta\) if:

$$P_\theta\!\left(\hat{\theta}_L(X) \le \theta \le \hat{\theta}_U(X)\right) \ge 1 - \alpha \quad \forall\, \theta \in \Theta$$

The subscript \(\theta\) on \(P_\theta\) is critical: the probability is over repeated samples \(X\), not over the parameter.

Why the t-distribution, not Normal?

When \(X_1,\ldots,X_n \overset{\text{iid}}{\sim} \mathcal{N}(\mu, \sigma^2)\) with \(\sigma^2\) unknown, replace \(\sigma\) with \(S\). The extra uncertainty from estimating \(\sigma\) inflates the tails: \(T = (\bar{X}-\mu)/(S/\sqrt{n}) \sim t_{n-1}\), not \(\mathcal{N}(0,1)\). As \(n\to\infty\), \(t_{n-1}\to\mathcal{N}(0,1)\).

Factors Controlling Width

$$\text{Width} = 2 \cdot t_{\alpha/2,\,n-1} \cdot \frac{S}{\sqrt{n}}$$

Width shrinks as \(\sqrt{n}\) (quadruple \(n\) to halve width). Width grows with confidence level (larger \(t_{\alpha/2}\)). Width grows with population spread \(S\).

BCa Bootstrap (Bias-Corrected and Accelerated)

The simple percentile bootstrap has bias when \(\hat{\theta}\) is a nonlinear statistic. BCa corrects for both median bias (\(\hat{z}_0\)) and acceleration (\(\hat{a}\), the rate at which standard error changes with \(\theta\)):

$$\alpha_1 = \Phi\!\left(\hat{z}_0 + \frac{\hat{z}_0 + z_{\alpha/2}}{1 - \hat{a}(\hat{z}_0 + z_{\alpha/2})}\right), \quad \alpha_2 = \Phi\!\left(\hat{z}_0 + \frac{\hat{z}_0 + z_{1-\alpha/2}}{1 - \hat{a}(\hat{z}_0 + z_{1-\alpha/2})}\right)$$

The CI is then \([\hat{\theta}^*_{(\alpha_1)}, \hat{\theta}^*_{(\alpha_2)}]\). BCa is second-order accurate (error \(O(n^{-1})\) vs basic percentile's \(O(n^{-1/2})\)).

∑ Key Quantities

\(\bar{X}\) — sample mean (the point estimate). \(S\) — sample standard deviation (ddof=1). \(\text{SE} = S/\sqrt{n}\) — standard error of the mean. \(t_{\alpha/2,n-1}\) — upper \(\alpha/2\) critical value of \(t_{n-1}\). Margin of error \(= t_{\alpha/2,n-1} \cdot \text{SE}\).

Interview Deep-Dive
▼

Q1 (Easy) — What does a 95% CI mean?

Model answer: A 95% CI is a random interval — because it is computed from random data — constructed by a procedure that covers the true parameter in 95% of repeated experiments. On any specific interval computed, the parameter is either inside or not; there is no probability attached to that specific instance. The 95% describes the long-run frequency of the procedure, not a belief about the parameter.

🚨 Instant Rejection Answer

"There is a 95% probability that the true mean is in this interval." This conflates a probability statement about a fixed constant with a statement about the random procedure. The correct probabilistic-parameter interpretation belongs to Bayesian credible intervals, not frequentist CIs.

Q2 (Medium) — How does sample size affect CI width?

Answer: Width \(\propto 1/\sqrt{n}\). Quadrupling sample size halves the CI width. More subtly, the critical value \(t_{\alpha/2, n-1}\) also shrinks toward the z-critical as df grows — but this effect is small for \(n > 30\).

Q3 (Medium) — When do you use bootstrap instead of t-CI?

Answer: Use bootstrap when: (1) the statistic of interest has no known closed-form pivot (e.g., median, ratio of means, correlation); (2) the normality assumption fails and \(n\) is small; (3) you want a distribution-free CI. The t-CI is preferable when assumptions hold — it has exact finite-sample coverage, while bootstrap is only asymptotically correct. For means with \(n \ge 30\) and no extreme skew, both give nearly identical results.

Q4 (Hard) — Explain to a PhD Researcher

The frequentist CI is a region estimator with guaranteed coverage under the sampling model. It is dual to a hypothesis test: \(\theta_0\) is in the 95% CI if and only if the two-sided size-\(\alpha\) test of \(H_0: \theta = \theta_0\) fails to reject. The Neyman construction inverts the acceptance region of this test. BCa bootstrap achieves second-order accuracy by adjusting for skewness in the bootstrap distribution via the bias-correction \(\hat{z}_0\) and acceleration \(\hat{a}\), estimated by jackknife.

Q5 (Hard) — CI vs Prediction Interval vs Credible Interval

CI: covers the unknown parameter \(\mu\) with probability \(1-\alpha\). Prediction interval: covers a single future observation \(X_{n+1}\); it is wider because it includes both estimation uncertainty and observation noise: \(\bar{X} \pm t_{\alpha/2, n-1} \cdot S\sqrt{1 + 1/n}\). Credible interval: a Bayesian posterior interval; here the parameter is treated as a random variable and the interval has probability \(1-\alpha\) of containing \(\theta\) given the observed data — a genuine probability statement about \(\theta\).

Key Takeaways & Related Topics
▼

Decision Guide

Use t-CI when data are approximately normal and you need a mean. Use z-CI (Wald) when \(n\) is large or \(\sigma\) is known. Use bootstrap percentile CI for any statistic with unknown sampling distribution. Use BCa bootstrap when the statistic is nonlinear (median, ratio, correlation) and bias matters. Use Bayesian credible interval when you have a meaningful prior and want a probability statement about the parameter.

💡 Practical Rules

n < 30, normal data: t-CI with df = n-1. n ≥ 30: z-CI is adequate. Any statistic, n ≥ 20: bootstrap percentile CI. Skewed or heavy-tailed: BCa bootstrap. Wider CI = more uncertainty, not a failure.
