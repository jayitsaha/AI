Typical, Eta, & Mirostat Sampling

Beyond Top-K/P: Controlling text generation diversity and coherence with advanced methods
Intermediate Deep Learning NLP Generative AI
1
Understanding Advanced Sampling
▼

What is it? When a Large Language Model (LLM) generates text, it outputs a probability distribution over the entire vocabulary for the next token. Simple sampling methods like greedy search (always pick the most probable) or pure random sampling (weighted by probabilities) often lead to repetitive or incoherent text. Advanced sampling techniques like Typical, Eta, and Mirostat aim to produce more human-like, diverse, and coherent outputs by intelligently filtering or adjusting these probabilities before a token is chosen.

Analogy: Imagine you're picking a word to continue a sentence.

  • Greedy: You always pick the most obvious word. (e.g., "The cat sat on the mat.") Very predictable.
  • Pure Random: You might pick a very rare, nonsensical word. (e.g., "The cat sat on the quantum-fluctuation.") Too random.
  • Top-K/P: You only consider the top K most probable words, or words whose cumulative probability sums to P. (e.g., "The cat sat on the rug," or "sofa.") Better, but still might miss good options.
  • Typical/Eta: You consider words that are "typical" or "not too surprising" given the context, filtering out both extremely common and extremely rare words. (e.g., "The cat sat on the window sill.") More natural.
  • Mirostat: You dynamically adjust your "pickiness" (temperature) to maintain a desired level of text perplexity/entropy, ensuring the generated text doesn't become too repetitive or too chaotic over time. (e.g., You start picking common words, but if the text gets boring, you become more adventurous.)

💡 If you remember one thing

These methods don't change the underlying model, but rather how we interpret and sample from its output probabilities. They apply a filter or dynamic adjustment to the raw softmax distribution to steer the generation towards desired qualities like diversity, coherence, and naturalness.

2
How It Works Internally
▼

The Baseline: Softmax, Temperature, Top-K/P

All sampling starts with the model's raw logits \(z\). These are converted to probabilities \(P(x_i)\) via softmax, often with a temperature \(T\):

$$P(x_i) = \frac{e^{z_i/T}}{\sum_j e^{z_j/T}}$$

A low \(T\) sharpens the distribution (more confident, less diverse), high \(T\) flattens it (more diverse, less coherent). Top-K truncates the vocabulary to the \(K\) most probable tokens. Top-P (nucleus) truncates to the smallest set of tokens whose cumulative probability exceeds \(P\).

Typical Sampling: Information Content Filtering

Typical sampling (Y. Li et al., 2022) aims to select tokens from the "typical set" of the distribution, avoiding both very high-probability (boring) and very low-probability (irrelevant) tokens. It does this by filtering tokens based on their information content (surprisal) relative to the distribution's entropy. Tokens \(i\) are kept if: $$|(-\log P(x_i)) - H(P)| < \tau$$ where \(H(P) = -\sum_j P(x_j) \log P(x_j)\) is the Shannon entropy of the distribution, and \(\tau\) (often called `typical_p` or `min_p`) is a threshold. This ensures chosen tokens are neither too predictable nor too surprising.

Eta Sampling: Surprisal Thresholding

Eta sampling (J. Li et al., 2023) is a simpler variant that focuses purely on filtering out highly surprising tokens. It defines a threshold \(\alpha\) (often `eta_alpha`) on the negative log-probability (surprisal). Only tokens \(i\) where \(-\log P(x_i) < \alpha\) are considered. This prevents the model from generating extremely rare or "out-of-distribution" tokens, keeping the output grounded while allowing for more diversity than greedy or low-temperature sampling.

Mirostat: Dynamic Temperature for Perplexity Control

Mirostat (M. W. F. Weng et al., 2023) is a more advanced, adaptive method that dynamically adjusts the sampling temperature \(T\) at each generation step to maintain a target perplexity (or target entropy) for the generated text. It uses a PID-like controller:

  1. Define a target entropy \( \tau \) (mirostat_tau).
  2. At each step, calculate the current distribution's entropy \(H(P)\).
  3. If \(H(P) < \tau\), the model is too confident/predictable; increase \(T\).
  4. If \(H(P) > \tau\), the model is too diverse/random; decrease \(T\).
  5. The adjustment is proportional to \((\tau - H(P))\), with a learning rate for \(T\).
This creates a self-regulating system that balances creativity and coherence over longer sequences, making the model "aware" of its own output's predictability. The actual sampling is then done using Top-K or Top-P on the distribution scaled by the adjusted \(T\).

🔑 Key Property

While Top-K/P filter based on rank or cumulative probability, Typical and Eta sampling filter based on information-theoretic properties of individual tokens. Mirostat goes further by adapting the temperature itself based on the global property (entropy) of the distribution, creating a feedback loop.

3
Why It Works — The Math
▼

Softmax with Temperature

Given logits \(z = [z_1, \dots, z_V]\) for a vocabulary of size \(V\), and a temperature \(T > 0\), the probabilities are:

$$P(x_i \mid z, T) = \frac{\exp(z_i / T)}{\sum_{j=1}^V \exp(z_j / T)}$$

As \(T \to 0\), \(P(x_i)\) approaches a one-hot distribution (argmax). As \(T \to \infty\), \(P(x_i)\) approaches a uniform distribution. \(T=1\) is standard softmax.

Shannon Entropy and Surprisal

The surprisal of a token \(x_i\) is \(-\log P(x_i)\). The Shannon entropy of the entire distribution \(P\) is the expected surprisal:

$$H(P) = \mathbb{E}[-\log P(x)] = -\sum_{i=1}^V P(x_i) \log P(x_i)$$

Entropy measures the "unpredictability" or "diversity" of the distribution. A high entropy means many tokens have similar probabilities; low entropy means a few tokens dominate.

Typical Sampling Criterion

Typical sampling filters tokens \(x_i\) based on a deviation from the distribution's entropy. A token is considered "typical" if its surprisal is close to the average surprisal (entropy):

$$|(-\log P(x_i)) - H(P)| < \tau_{\text{typical}}$$

The parameter \(\tau_{\text{typical}}\) (often `typical_p`) controls the size of the typical set. A smaller \(\tau_{\text{typical}}\) leads to a smaller, more focused set of tokens, while a larger \(\tau_{\text{typical}}\) includes more diverse (but still typical) options.

All these methods introduce hyperparameters (temperature, \(\tau_{\text{typical}}\), \(\alpha_{\text{eta}}\), \(\tau_{\text{mirostat}}\)). Choosing optimal values is crucial and often requires empirical tuning. Incorrectly chosen parameters can lead to either overly conservative (repetitive) or overly aggressive (incoherent) generation, defeating the purpose of these advanced techniques.

5
Key Takeaways
▼

When to use these methods:

  • Typical Sampling: When you want a balance of coherence and diversity. It's often preferred over Top-P for open-ended generation tasks where you want to avoid both generic and truly bizarre outputs.
  • Eta Sampling: For robust, coherent generation where preventing "hallucinations" or very rare tokens is paramount, but you still desire more diversity than greedy or low-temperature sampling. Useful in factual generation or summarization.
  • Mirostat: When generating long sequences and you need consistent control over the output's "creativity" or "predictability" (perplexity). It's excellent for maintaining a desired stylistic or informational density over time without constant manual tuning of temperature.
  • Top-K/P: Still excellent baselines. Top-P is a good general-purpose choice for many tasks, offering a dynamic vocabulary size.

When to be cautious:

  • Over-filtering: Too strict parameters (e.g., very low Typical P, very low Eta Alpha) can lead to repetitive text, as the model is forced to pick from a very small set of tokens.
  • Under-filtering: Too lenient parameters can allow for incoherent or irrelevant text, especially with high temperatures.
  • Computational Cost: While generally efficient, these methods add a small overhead compared to simple greedy sampling. Mirostat's dynamic adjustment adds a bit more complexity to the sampling loop.
  • Parameter Tuning: Finding the optimal parameters for each method (e.g., `typical_p`, `eta_alpha`, `mirostat_tau`) is often task-specific and requires experimentation.
💡 Big Picture

The evolution of sampling methods reflects a deeper understanding of what makes human language "good." It's not just about picking the most likely word, but about selecting words that are plausible within context, not too surprising, and which collectively maintain a desired level of information density over time. These techniques are crucial for making LLMs truly useful and engaging.

Code Trace (Python Pseudocode)
▼
import numpy as np
def softmax(logits, temperature=1.0):
scaled_logits = np.asarray(logits) / temperature
exp_logits = np.exp(scaled_logits - np.max(scaled_logits)) # Stable softmax
return exp_logits / np.sum(exp_logits)
def calculate_entropy(probs):
return -np.sum(p * np.log(p) for p in probs if p > 1e-10)
def typical_sampling(logits, temperature, typical_p_tau):
probs = softmax(logits, temperature)
entropy = calculate_entropy(probs)
neg_log_probs = -np.log(probs)
# Filter tokens where |surprisal - entropy| < typical_p_tau
mask = np.abs(neg_log_probs - entropy) < typical_p_tau
filtered_probs = probs * mask
if np.sum(filtered_probs) == 0: # Fallback to original if all filtered
return np.random.choice(len(probs), p=probs / np.sum(probs))
return np.random.choice(len(probs), p=filtered_probs / np.sum(filtered_probs))
def eta_sampling(logits, temperature, eta_alpha):
probs = softmax(logits, temperature)
neg_log_probs = -np.log(probs)
# Filter tokens where surprisal < eta_alpha
mask = neg_log_probs < eta_alpha
filtered_probs = probs * mask
if np.sum(filtered_probs) == 0: # Fallback
return np.random.choice(len(probs), p=probs / np.sum(probs))
return np.random.choice(len(probs), p=filtered_probs / np.sum(filtered_probs))
# Mirostat requires state (current_temperature, Kp, target_tau)
class MirostatSampler:
def __init__(self, target_tau, Kp=0.1, initial_temp=1.0):
self.target_tau = target_tau
self.Kp = Kp
self.current_temperature = initial_temp
def sample(self, logits):
probs = softmax(logits, self.current_temperature)
current_entropy = calculate_entropy(probs)
# Adjust temperature based on error (target_tau - current_entropy)
error = self.target_tau - current_entropy
self.current_temperature = max(0.01, self.current_temperature + self.Kp * error)
# Sample from the adjusted distribution (often with Top-K/P too)
return np.random.choice(len(probs), p=probs / np.sum(probs))
