Visualizing heterogeneous feature effects for individual predictions
Intermediate Explainable AI (XAI) Model Interpretability O(N × M)

Understanding ICE Plots
▼

What is it? Individual Conditional Expectation (ICE) plots visualize how a machine learning model's prediction for a single instance changes as one feature varies, while holding all other features constant at their original values for that specific instance. This allows us to see how the model responds to a feature for different individuals, revealing heterogeneous effects and interactions that might be hidden by global average-effect plots.

Analogy: Imagine you're trying to understand how a car's price (predicted by a complex model) changes based on its mileage. A standard plot (like a Partial Dependence Plot) might show the average price trend across all cars as mileage changes. An ICE plot would instead show, for your specific car (e.g., a 2018 Honda Civic in good condition), how its predicted price would change if its mileage were different, while keeping all other specs of your car (make, model, year, condition) exactly the same. Then, it does this for *every single car* in your dataset, drawing a separate line for each. This way, you can see if the impact of mileage on price is different for a Honda Civic versus, say, a Ferrari.

💡 If you remember one thing

ICE plots reveal heterogeneous effects and interactions by showing how a model's prediction changes for specific instances. Each line on an ICE plot is a "what-if" scenario for one data point, answering: "If only this one feature changed for this specific instance, how would the prediction change?"

2
How ICE Plots Work Internally
▼

The Mechanism: Perturb, Predict, Plot

To generate an ICE plot for a feature \(X_j\) given a trained model \(f\), the process is as follows:

  1. Select Feature: Choose the feature \(X_j\) you want to analyze.
  2. Define Grid: Create a grid of values \(\{v_1, v_2, \dots, v_M\}\) spanning the observed range of \(X_j\) in your dataset. These are the values \(X_j\) will be set to.
  3. Iterate Instances: For each instance \(x^{(i)}\) in your dataset (or a representative sample):
    1. Create Synthetic Data: Generate \(M\) new "synthetic" data points. For each \(k \in \{1, \dots, M\}\), construct a new instance \(x'^{(i,k)}\) where the \(j\)-th feature is set to \(v_k\), and all other features \(X_{-j}\) are kept at their original values from \(x^{(i)}\). Formally: \(x'^{(i,k)} = (v_k, x_{-j}^{(i)})\).
    2. Predict: Obtain the model's prediction \(\hat{y}'^{(i,k)} = f(x'^{(i,k)})\) for each of these \(M\) synthetic points.
  4. Plot: Plot the pairs \((v_k, \hat{y}'^{(i,k)})\) for all \(k\). This forms a single line, the ICE curve for instance \(x^{(i)}\). Repeat for all selected instances.

The collection of these individual lines forms the complete ICE plot.

Contrast with Partial Dependence Plots (PDPs)

Partial Dependence Plots (PDPs) show the average effect of a feature on the prediction. A PDP is essentially the average of all ICE curves. While PDPs provide a clear global trend, they can mask important interactions. For example, if a feature has a positive effect for some instances and a negative effect for others, a PDP might show a flat line, suggesting no effect, while ICE plots would show two distinct groups of lines. This makes ICE plots invaluable for uncovering complex, instance-specific model behaviors.

🔑 Key Property

Each ICE curve is a unique "slice" of the model's prediction function, conditional on a specific instance's feature values. It reveals how the model's output changes for that instance's unique context, making it a powerful tool for understanding local model behavior and identifying feature interactions.

3
Why It Works — The Mathematical Basis
▼

Formal Definition of an ICE Curve

Let \(\hat{y} = f(x)\) be the prediction function of our machine learning model, where \(x\) is a vector of features. We can partition \(x\) into the feature of interest \(x_j\) and all other features \(x_{-j}\). An ICE curve for a specific instance \(x^{(i)}\) shows the prediction \(\hat{y}\) as a function of \(x_j\), holding \(x_{-j}\) constant at \(x_{-j}^{(i)}\):

$$f_{\text{ICE}}^{(i)}(x_j) = f(x_j, x_{-j}^{(i)})$$

Here, \(x_{-j}^{(i)}\) represents the vector of all feature values for instance \(i\) except for \(x_j\).

Relationship to Partial Dependence Plots (PDPs)

The Partial Dependence Plot (PDP) for a feature \(x_j\) is defined as the marginal expectation of the prediction function \(f\) over the marginal distribution of \(x_{-j}\):

$$\operatorname{PDP}(x_j) = \mathbb{E}_{x_{-j}}[f(x_j, x_{-j})]$$

In practice, this expectation is approximated by averaging over the observed instances in the dataset:

$$\operatorname{PDP}(x_j) \approx \frac{1}{N} \sum_{i=1}^N f(x_j, x_{-j}^{(i)}) = \frac{1}{N} \sum_{i=1}^N f_{\text{ICE}}^{(i)}(x_j)$$

This equation clearly shows that the PDP is simply the average of all individual ICE curves. This mathematical relationship highlights why ICE plots can reveal details that PDPs might obscure: averaging can smooth out or cancel out heterogeneous effects present in individual curves.

Detecting Interactions

The shape of ICE curves provides direct insight into feature interactions. If all ICE curves for a feature \(X_j\) are approximately parallel, it suggests that \(X_j\) does not interact with other features in its effect on the prediction. That is, the effect of changing \(X_j\) is roughly the same regardless of the values of other features \(X_{-j}\). However, if the ICE curves cross each other, fan out, or have significantly different slopes, it strongly indicates an interaction between \(X_j\) and at least one other feature \(X_k \in X_{-j}\).

⚠️ Common Pitfall & Limitations

ICE plots can suffer from extrapolation issues. When we vary \(X_j\) for an instance \(x^{(i)}\), we might create synthetic feature combinations \((x_j, x_{-j}^{(i)})\) that are unrealistic or do not exist in the training data. The model's predictions for such out-of-distribution points might be unreliable. Also, for datasets with many instances, plotting all ICE curves can result in an overplotted "spaghetti plot" that is hard to interpret; sampling or using centered ICE plots (where each curve starts at 0 by subtracting \(f(x_j^{(i)}, x_{-j}^{(i)})\)) can help.

Key Takeaways
▼

When to use ICE plots:

  • When you suspect heterogeneous effects or feature interactions, and a global average (like PDP) might obscure them.
  • To understand how a model behaves for specific individual instances, answering "what-if" questions for a particular data point.
  • For debugging and auditing model behavior, especially if the model makes unexpected predictions for certain types of inputs.
  • As a complement to PDPs, providing a more detailed, instance-level view after a global trend has been observed.

When NOT to use or use with caution:

  • With a very large number of instances, as plotting all curves can lead to an unreadable "spaghetti plot". Consider sampling or using centered ICE plots.
  • When the feature space is high-dimensional and varying one feature might create unrealistic or out-of-distribution instances for which the model's predictions are unreliable (extrapolation risk).
  • If a simple, global understanding of feature effects is sufficient, as PDPs are less cluttered and easier to digest.
💡 Centered ICE Plots

To reduce clutter and make comparisons easier, especially when the baseline prediction for each instance varies widely, you can plot Centered ICE (c-ICE) plots. Each c-ICE curve is defined as \(f_{\text{c-ICE}}^{(i)}(x_j) = f(x_j, x_{-j}^{(i)}) - f(x_j^{(i)}, x_{-j}^{(i)})\). This shifts each curve so that it passes through zero at its original feature value \(x_j^{(i)}\), emphasizing the change in prediction rather than the absolute value.

Code Trace (Python-like Pseudocode)
▼
import numpy as np
# Assume 'model' is a trained ML model with a .predict() method
# Assume 'data' is a pandas DataFrame with features X1, X2
def generate_ice_curves(model, data, feature_of_interest, num_grid_points=100):
feature_values = data[feature_of_interest].values
grid_points = np.linspace(feature_values.min(), feature_values.max(), num_grid_points)
ice_curves = [] # List to store individual ICE curve predictions
for i in range(len(data)):
instance = data.iloc[i].copy()
instance_predictions = []
for val in grid_points:
temp_instance = instance.copy()
temp_instance[feature_of_interest] = val # Vary the feature of interest
# Keep other features fixed at their original values for this instance
prediction = model.predict(temp_instance.to_frame().T)[0]
instance_predictions.append(prediction)
ice_curves.append(instance_predictions)
return grid_points, np.array(ice_curves)
def calculate_pdp(ice_curves):
# PDP is simply the average of all ICE curves
return np.mean(ice_curves, axis=0)
