Concatenation & Linear Projection

Combining and transforming features in machine learning
Foundational Deep Learning Linear Algebra O(D_out × D_in)
1
Understanding the Concepts
▼

What are they? In machine learning, especially deep learning, we often deal with multiple sources of information or different types of features. Concatenation is the process of joining these features together into a single, larger feature vector. This increases the dimensionality of our data.

Once features are combined, a linear projection (also known as a dense or fully-connected layer without an activation function) is typically applied. This operation transforms the concatenated feature vector into a new space, often reducing its dimensionality or preparing it for a subsequent task like classification or regression.

Analogy: Imagine you're building a dish. You might have a "flavor profile" vector (e.g., sweet, sour, salty) and a "texture profile" vector (e.g., crunchy, creamy, chewy). Concatenation is like putting all these individual flavor and texture scores into one long list. Then, a linear projection is like a chef's special blending technique that takes this long list and transforms it into a concise "dish rating" vector (e.g., how appealing, how complex, how balanced).

💡 If you remember one thing

Concatenation combines information by increasing dimensionality. Linear Projection then learns to distill this combined information into a more useful or compact representation, effectively transforming the feature space.

How It Works Internally
▼

Concatenation: Stacking Vectors

When you concatenate two vectors, say \(v_1\) of dimension \(d_1\) and \(v_2\) of dimension \(d_2\), you simply stack them end-to-end to form a new vector \(v_{cat}\) of dimension \(d_1 + d_2\). This is often done along a specific axis (e.g., axis 1 for feature vectors in a batch) in tensor operations. No information is lost; rather, it's organized into a single, comprehensive representation.

For example, if \(v_1 = [a, b, c]^\top\) and \(v_2 = [x, y]^\top\), then \(v_{cat} = [a, b, c, x, y]^\top\). This allows downstream layers to process all features simultaneously.

Linear Projection: Matrix Multiplication

A linear projection is a matrix multiplication. Given a concatenated feature vector \(v_{cat}\) of dimension \(D_{in}\), we multiply it by a weight matrix \(W\) and typically add a bias vector \(b\). The weight matrix \(W\) has dimensions \(D_{out} \times D_{in}\), where \(D_{out}\) is the desired output dimension. The bias vector \(b\) has dimension \(D_{out}\).

The operation is \(z = W v_{cat} + b\). Each row of \(W\) can be thought of as learning a specific linear combination of the input features in \(v_{cat}\) to produce one component of the output vector \(z\). This allows the model to learn complex relationships between the combined features and project them into a space that is optimal for the next task.

🔑 Key Property

A linear projection is the core operation of a dense (or fully-connected) layer in a neural network, before any non-linear activation function is applied. It allows the network to learn a weighted combination of its inputs.

Why It Works — The Math
▼

Mathematical Definition of Concatenation

Let's consider two column vectors \(v_1 \in \mathbb{R}^{d_1}\) and \(v_2 \in \mathbb{R}^{d_2}\). Their concatenation, denoted as \(v_{cat}\), is a new column vector formed by stacking them vertically:

$$v_{cat} = \begin{pmatrix} v_1 \\ v_2 \end{pmatrix} \in \mathbb{R}^{d_1+d_2}$$

If \(v_1 = [v_{1,1}, \dots, v_{1,d_1}]^\top\) and \(v_2 = [v_{2,1}, \dots, v_{2,d_2}]^\top\), then \(v_{cat}\) is simply \([v_{1,1}, \dots, v_{1,d_1}, v_{2,1}, \dots, v_{2,d_2}]^\top\). This operation is straightforward and reversible (you can always split the vector back into its original components).

Mathematical Definition of Linear Projection

Given the concatenated vector \(v_{cat} \in \mathbb{R}^{D_{in}}\), a linear projection transforms it into an output vector \(z \in \mathbb{R}^{D_{out}}\) using a weight matrix \(W \in \mathbb{R}^{D_{out} \times D_{in}}\) and a bias vector \(b \in \mathbb{R}^{D_{out}}\):

$$z = W v_{cat} + b$$

Each component \(z_j\) of the output vector \(z\) is a weighted sum of all components of \(v_{cat}\), plus a bias term:

$$z_j = \sum_{i=1}^{D_{in}} W_{j,i} v_{cat,i} + b_j \quad \text{for } j=1, \dots, D_{out}$$

The weights \(W_{j,i}\) determine how much each input feature \(v_{cat,i}\) contributes to each output feature \(z_j\). During training, these weights \(W\) and biases \(b\) are learned to optimize a specific objective, allowing the model to extract and combine relevant information from the concatenated features.

⚠️ Information Loss vs. Feature Extraction

If \(D_{out} < D_{in}\), the linear projection performs dimensionality reduction. While this can lead to information loss, the goal is to learn a projection that retains the most salient information for the task, effectively acting as a learned feature extractor. If \(D_{out} > D_{in}\), it expands the feature space, which can be useful for increasing model capacity or preparing for subsequent non-linear transformations.

Key Takeaways
▼

When to use Concatenation:

  • Multimodal Inputs: Combining features from different data types (e.g., image embeddings, text embeddings, tabular data).
  • Hierarchical Features: Merging features from different layers or stages of a neural network (e.g., skip connections in U-Nets, combining local and global features).
  • Contextual Information: Adding auxiliary information to a primary feature set.
  • Feature Engineering: Explicitly combining features that might interact in complex ways.

When to use Linear Projection:

  • Dimensionality Transformation: Adjusting the feature dimension to match the requirements of subsequent layers or tasks.
  • Feature Learning: Allowing the model to learn optimal linear combinations of input features.
  • Bottlenecks: Creating a compact, low-dimensional representation (bottleneck layer) to force the model to learn efficient encodings.
  • Output Layers: The final layer before a softmax (for classification) or direct output (for regression) is often a linear projection.
💡 Practical Applications

These operations are ubiquitous in modern neural architectures. Think of combining image features with textual captions for a visual question answering system, or merging various sensor readings before feeding them into a control system. Concatenation provides the raw combined input, and linear projection provides the learned interpretation.

Code Trace

import numpy as np
# 1. Define two input feature vectors
# v1: e.g., features from an image encoder (3D)
# v2: e.g., features from a text encoder (2D)
v1 = np.array([0.8, 0.2, 0.5])
v2 = np.array([0.6, 0.9])
# 2. Concatenate the feature vectors
# Resulting vector will have dimension 3 + 2 = 5
v_cat = np.concatenate((v1, v2))
print(f"Concatenated vector (v_cat): {v_cat}")
print(f"Dimension of v_cat: {v_cat.shape[0]}")
# 3. Define the desired output dimension (D_out)
D_out = 2 # e.g., project to 2D for a simple classifier
D_in = v_cat.shape[0] # Input dimension for projection
# 4. Initialize the projection weight matrix (W) and bias (b)
# W has shape (D_out, D_in)
# b has shape (D_out,)
W = np.random.randn(D_out, D_in) * 0.1 # Small random weights
b = np.random.randn(D_out) * 0.01 # Small random biases
print(f"Projection matrix (W) shape: {W.shape}")
# 5. Perform the linear projection
# z = W @ v_cat + b
v_proj = W @ v_cat + b
print(f"Projected vector (v_proj): {v_proj}")
print(f"Dimension of v_proj: {v_proj.shape[0]}")
