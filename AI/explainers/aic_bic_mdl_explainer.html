AIC, BIC & MDL
Model Selection Criteria — Balancing Fit & Complexity
Intermediate Classical ML Statistics Model Selection O(k) per model
1
Understanding the Concept

The problem: You have two models that both fit your data — a simple line and a wavy 10-degree polynomial. The polynomial always fits better (lower training error), but is it actually better? Model selection criteria answer this by adding a complexity penalty to the fit score.

The core insight: Every criterion has the same structure:

$$\text{Criterion} = \underbrace{-2\ell(\hat{\theta})}_{\text{badness of fit}} + \underbrace{\text{penalty}(k, n)}_{\text{complexity cost}}$$

where \(\ell(\hat{\theta})\) is the maximized log-likelihood, \(k\) is the number of free parameters, and \(n\) is the sample size. Pick the model with the smallest criterion value.

Key Concept

AIC = 2k − 2ℓ (penalises each parameter equally). BIC = k ln n − 2ℓ (penalty grows with sample size, so it favours simpler models more aggressively for large n). MDL = codelength of model + codelength of data given model.

Analogy: Imagine explaining a noisy graph to a friend. AIC asks: "How many words did you need?" BIC asks: "How many words, knowing your friend has heard thousands of explanations?" MDL asks: "What is the shortest total message that encodes both your model and the data it explains?"

💡 If you remember one thing

All three criteria penalise overfitting by charging for model complexity, but BIC's penalty grows as \(k\ln n\) while AIC's is just \(2k\) — so BIC selects sparser models as \(n \to \infty\).

2
How Each Criterion Works

All three criteria are derived from fundamentally different theoretical frameworks, yet converge on the same intuition:

CriterionFull NameFormulaTheoretical RootBest For
AIC Akaike Information Criterion \(2k - 2\ell\) KL divergence minimisation (Kullback-Leibler) Prediction; true model may not be in candidate set
AICc Corrected AIC \(2k - 2\ell + \frac{2k(k+1)}{n-k-1}\) Small-sample bias correction to AIC Small \(n\) or when \(n/k < 40\)
BIC Bayesian Information Criterion \(k\ln n - 2\ell\) Laplace approximation to Bayesian model evidence Consistency; identifying true model when it exists
MDL Minimum Description Length \(-\ell + \frac{k}{2}\ln\frac{n}{2\pi}\) (NML variant) Kolmogorov complexity / two-part code Principled compression view; robust to prior misspecification

Information flow: Given \(m\) candidate models \(\mathcal{M}_1, \ldots, \mathcal{M}_m\):

  • Fit each model by MLE, obtaining \(\hat{\theta}_j\) and log-likelihood \(\ell_j\)
  • Compute \(-2\ell_j\) (deviance) and parameter count \(k_j\)
  • Add penalty: \(\text{AIC}_j = 2k_j - 2\ell_j\), \(\text{BIC}_j = k_j \ln n - 2\ell_j\)
  • Select \(\hat{j} = \arg\min_j \text{Criterion}_j\)
⚠ Design Decision: Why −2ℓ not −ℓ?

The factor of 2 is historical convention: −2ℓ matches the χ² distribution for likelihood-ratio tests, making AIC/BIC directly comparable to LRT p-values and interpretable as "deviance."

3
The Math Behind It

AIC derivation (Akaike 1974): The goal is to find the model minimising the expected KL divergence from the true density \(f\) to the fitted model \(g_{\hat{\theta}}\):

$$\text{KL}(f \| g_{\hat{\theta}}) = \int f(x) \ln \frac{f(x)}{g(x;\hat{\theta})}\,dx$$

Since \(\int f \ln f\) is a constant independent of the model, we only need to maximise \(\mathbb{E}_f[\ln g(x;\hat{\theta})]\). The MLE \(\hat{\theta}\) gives \(\frac{1}{n}\sum_i \ln g(x_i; \hat{\theta}) = \frac{\ell(\hat{\theta})}{n}\) as an estimator, but this is optimistically biased by \(k/n\) due to fitting the same data used for evaluation. Correcting:

$$\widehat{\mathbb{E}_f[\ln g(x;\hat{\theta})]} = \frac{\ell(\hat{\theta})}{n} - \frac{k}{n}$$

Multiply by \(-2n\): \(\text{AIC} = -2\ell + 2k\). ✓

BIC derivation (Schwarz 1978): From the Bayesian perspective, we want the model with highest posterior probability \(P(\mathcal{M}_j | \mathbf{x})\). With equal priors \(P(\mathcal{M}_j) \propto 1\) and Laplace approximation to the marginal likelihood:

$$\ln P(\mathbf{x} | \mathcal{M}_j) \approx \ell(\hat{\theta}_j) - \frac{k_j}{2}\ln n + C$$

Multiplying by \(-2\) gives \(\text{BIC}_j = k_j \ln n - 2\ell_j\). The dominant \(-\frac{k}{2}\ln n\) term means BIC grows faster than AIC's \(2k\) whenever \(\ln n > 2\), i.e., \(n \geq 8\).

MDL (two-part code, Rissanen 1978): The total codelength is:

$$L(\mathcal{M}, \mathbf{x}) = L(\hat{\theta}) + L(\mathbf{x} | \hat{\theta})$$

With \(k\) parameters each quantised at resolution \(\epsilon = 1/\sqrt{n}\) (since finer precision is unrecoverable from \(n\) observations), coding each parameter takes \(\frac{1}{2}\ln n\) bits. Using Shannon entropy for the data term:

$$L_{\text{MDL}} \approx -\ell(\hat{\theta}) + \frac{k}{2}\ln n$$

This equals \(\frac{1}{2}\text{BIC}\)! So BIC and simple MDL select the same model. The modern normalised maximum likelihood (NML) version of MDL is more principled but complex.

🧮 Penalty Comparison at a Glance

For each additional parameter \(k\): AIC charges \(2\) bits. BIC charges \(\ln n\) bits. For \(n = 100\): BIC charges \(\ln 100 \approx 4.6\) — more than twice AIC. For \(n = 1000\): BIC charges \(\approx 6.9\). BIC becomes dramatically harsher as \(n\) grows.

⚠ Common Misconception

AIC is not a consistent model selector — even with infinite data it may not recover the true model. BIC is consistent (selects true model with probability → 1 as n → ∞) but assumes the true model is in the candidate set. When that assumption fails, AIC often has lower prediction error.

Key Takeaways & When to Use
SituationPreferReason
Prediction accuracy on new dataAIC / AICcMinimises expected KL to true distribution
Identifying true model structureBICConsistent selection as n → ∞
Small sample (n/k < 40)AICcAIC overfits at small n; AICc has second-order correction
Coding/compression framingMDLPrincipled minimum description length
GLMs, time series, survival modelsAICLikelihood-based; widely implemented in software
Mixture models (# components)BICPenalises extra components more strongly
🎯 Decision Rule

Use AIC when your goal is prediction and you suspect the true model is not in your candidate set. Use BIC when your goal is model identification and you have enough data. Use AICc always when sample size is small. BIC and MDL select the same model asymptotically.
