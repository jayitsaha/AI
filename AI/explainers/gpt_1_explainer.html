Understanding GPT-1
▼

What is it? GPT-1 ("Improving Language Understanding by Generative Pre-Training", Radford et al., OpenAI, June 2018) is a 12-layer decoder-only Transformer trained in two stages: first it reads huge amounts of unlabeled text and learns to predict the next word (generative pre-training), then it is lightly adapted with a small labeled dataset for a specific task like classification or entailment (discriminative fine-tuning). It was the first paper to show this recipe works across many NLP tasks with almost no task-specific architecture.

Analogy: Imagine hiring someone who has read millions of books (pre-training gives broad language intuition) and then giving them a one-afternoon crash course on your specific job — grading essays, sorting emails, whatever (fine-tuning). Because they already understand language deeply, the crash course is short and cheap, yet the results are excellent.

💡 If you remember one thing

GPT-1 = unsupervised pre-training (predict the next token over raw text with a causal Transformer decoder) + supervised fine-tuning (reuse the same weights, add one linear head, train on a small labeled dataset). $$L_1(\mathcal{U}) = \sum_i \log P(u_i \mid u_{i-k},\dots,u_{i-1};\Theta)$$

How GPT-1 Works Internally
▼

The Problem Before GPT-1

In 2018, labeled data was scarce for most NLP tasks, and models like ELMo used shallow, task-specific architectures (BiLSTMs) on top of frozen or lightly-used embeddings — every new task needed a bespoke network. GPT-1's insight: pre-train ONE deep language model on unlabeled text (cheap, abundant), then reuse almost the entire network for any downstream task by adding just an output layer.

Architecture: Decoder-Only Transformer

GPT-1 stacks 12 identical decoder blocks, each with: (1) masked multi-head self-attention (768-dim, 12 heads) so a token can only attend to itself and earlier tokens, (2) a position-wise feed-forward network (3072-dim hidden, GELU activation), (3) residual connections and layer normalization around each sub-block. Token embeddings are summed with learned positional embeddings before the first block — there is no encoder, no cross-attention, just a strictly causal stack.

Stage 1 — Generative Pre-training

Given an unlabeled token sequence \(\mathcal{U} = \{u_1,\dots,u_n\}\), the model is trained with the standard language-modeling objective: maximize the log-likelihood of each token given the \(k\) previous tokens (context window \(k=512\)). This forces the network to build genuinely useful representations of syntax, coreference, and world knowledge with zero labels.

Stage 2 — Discriminative Fine-tuning

For a labeled dataset \(\mathcal{C}\) of (input sequence, label) pairs, the final token's hidden state \(h_l^m\) is fed into a new linear layer with weights \(W_y\) to predict the label: \(P(y\mid x) = \text{softmax}(h_l^m W_y)\). Crucially, the pre-trained weights are NOT frozen — the whole network is fine-tuned jointly, and the original LM loss is kept as an auxiliary term to prevent catastrophic forgetting.

🔑 Design Decision: Why keep the LM loss during fine-tuning?

Radford et al. found that auxiliary language-modeling loss during fine-tuning (\(L_3 = L_2(\mathcal{C}) + \lambda \cdot L_1(\mathcal{C})\)) improved generalization and sped up convergence — the model doesn't "forget" its pre-trained language ability while specializing to the task.

Why It Works — The Math
▼

Masked Self-Attention

Each attention head projects the input \(X\) into queries, keys, and values with learned matrices \(W_Q, W_K, W_V\), then computes scaled dot-product attention with a causal mask \(M\) (upper-triangular \(-\infty\)) so future tokens contribute zero weight:

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}} + M\right)V$$

Multiple heads run this in parallel on different learned subspaces and are concatenated, letting the model track several relationships (e.g. syntax vs. coreference) simultaneously.

The Pre-training Objective, Derived

Pre-training maximizes the joint log-likelihood of the corpus factorized autoregressively (chain rule of probability):

$$L_1(\mathcal{U}) = \sum_{i} \log P(u_i \mid u_{i-k}, \dots, u_{i-1}; \Theta)$$

Each conditional \(P(u_i \mid \dots)\) is produced by running the Transformer decoder up to position \(i-1\) and applying a softmax over the vocabulary to the final hidden state — exactly the mechanism shown in the interactive walkthrough below.

Gradient Flow & Why Residuals Matter

With 12 stacked blocks, gradients must travel through many nonlinear layers. Residual connections \(x_{l+1} = x_l + \text{Sublayer}(\text{LN}(x_l))\) give an additive path so \(\partial L/\partial x_l\) always contains an identity term, preventing vanishing gradients even at this depth — the same trick that makes ResNets trainable.

⚠️ Common Pitfall

The causal mask is not optional decoration — without it, pre-training would leak the answer (the model would just copy the next token from its own future context), making the language-modeling loss trivially near-zero and useless for learning real structure.

Key Takeaways
▼

Why GPT-1 mattered:

  • First demonstration that a single generic causal Transformer, pre-trained once, could be fine-tuned to beat task-specific architectures across 9 of 12 GLUE-era NLP benchmarks.
  • Established the "pre-train then fine-tune" paradigm with minimal task-specific structure — inputs for different tasks (entailment, similarity, QA) were just reformatted into a single token sequence with delimiter tokens, no new architecture.
  • Direct ancestor of GPT-2 (scale up, zero-shot), GPT-3 (in-context learning replaces fine-tuning), and ultimately instruction-tuned / RLHF models.

Limitations at the time:

  • Only 117M parameters and a 512-token context — tiny by modern standards.
  • Still needed labeled fine-tuning data per task; true zero-shot/few-shot generalization arrived only with GPT-2/3.
  • Unidirectional context (left-to-right only) is weaker than BERT's bidirectional pre-training for pure understanding tasks — this is the trade-off GPT-1 accepted in exchange for a natural generative/autoregressive objective.
💡 The Recipe That Stuck

Decoder-only Transformer + next-token prediction at scale + light task adaptation is still, seven years later, the dominant recipe for large language models — GPT-1 is where it was first shown to work.

import numpy as np
# Toy 1-layer causal self-attention (GPT-1 building block)
def causal_attention(X, Wq, Wk, Wv, d_k):
Q, K, V = X @ Wq, X @ Wk, X @ Wv # project
scores = Q @ K.T / np.sqrt(d_k) # QK^T / sqrt(d_k)
mask = np.triu(np.ones_like(scores), k=1) * -1e9
weights = softmax(scores + mask, axis=-1) # causal softmax
return weights @ V # context vectors
# Stage 1: pre-training objective (next-token prediction)
def lm_loss(hidden, W_vocab, target_id):
logits = hidden @ W_vocab # project to vocab
probs = softmax(logits)
return -np.log(probs[target_id]) # cross-entropy
# Stage 2: fine-tuning head (swap LM head for task head)
def finetune_head(h_last_token, W_y):
return softmax(h_last_token @ W_y) # P(label | x)
# Fine-tune loss keeps LM loss as auxiliary term
L3 = L2_task_loss + lam * L1_lm_loss # lam ~ 0.5
