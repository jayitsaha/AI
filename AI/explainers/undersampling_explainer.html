Understanding Undersampling
▼

What is it? Undersampling is a technique used in machine learning to address imbalanced datasets, where one class (the "majority" class) significantly outnumbers another (the "minority" class). It involves reducing the number of samples in the majority class to balance the class distribution, thereby preventing models from becoming biased towards the majority class and neglecting the minority class.

Analogy: Imagine you're training a dog to identify rare birds from photos. If 99% of your photos are of pigeons and 1% are of rare eagles, the dog might learn to just say "pigeon" for everything. Undersampling is like taking out many of the pigeon photos, so the dog has a more balanced set of examples and is forced to pay closer attention to the unique features of the eagles (the minority class), rather than just the overwhelming presence of pigeons (the majority class).

💡 If you remember one thing

Undersampling aims to alleviate class imbalance by removing samples from the majority class. While it can improve model performance on the minority class, it risks discarding potentially valuable information from the majority class, which might lead to overfitting on the now smaller dataset.

2
How Undersampling Works Internally
▼

The Problem with Imbalance

In many real-world scenarios (e.g., fraud detection, disease diagnosis), the event of interest (minority class) is rare. Standard classification algorithms often assume balanced class distributions. When faced with imbalance, they tend to classify new observations as the majority class, achieving high overall accuracy but poor performance (low recall/precision) on the minority class.

General Strategy: Reduce the Majority

Undersampling techniques select a subset of the majority class samples to retain, effectively shrinking the dataset size. The core challenge is deciding which majority samples to keep. Different methods employ various heuristics to achieve this:

  • Random Undersampling: The simplest approach, it randomly removes instances from the majority class until the desired class ratio is achieved. It's fast but can discard important information.
  • Tomek Links: Identifies pairs of instances from different classes that are each other's nearest neighbors. Removing the majority class instance from such a pair helps to clean up the decision boundary and remove noisy/overlapping samples.
  • Edited Nearest Neighbours (ENN): For each instance, it finds its k-nearest neighbors. If an instance's class differs from the majority class of its k-NN, that instance is removed. This method is effective at removing noisy or borderline instances.
  • NearMiss: A family of methods that select majority class samples based on their proximity to minority class samples. NearMiss-1, for example, selects majority samples whose average distance to the k-nearest minority samples is smallest, effectively keeping majority samples that are closest to the minority class boundary.

Design Decision: When to Undersample vs. Oversample?

Undersampling reduces dataset size, which can speed up training but risks information loss. Oversampling (e.g., SMOTE) increases dataset size, which preserves information but can lead to overfitting on the synthesized minority samples. The choice often depends on dataset size, computational resources, and the specific characteristics of the imbalance. Hybrid methods (like SMOTE-Tomek) combine both for better results.

🔑 Key Property

The effectiveness of an undersampling method hinges on its ability to remove redundant or noisy majority samples while preserving those that are crucial for defining the decision boundary. Random undersampling is naive; heuristic methods like Tomek Links or NearMiss aim for more informed removal.

3
Why It Works — The Math
▼

Class Imbalance Ratio

Let \(N_{maj}\) be the number of samples in the majority class and \(N_{min}\) be the number of samples in the minority class. The imbalance ratio is typically defined as:

$$\text{Ratio} = \frac{N_{maj}}{N_{min}}$$

Undersampling aims to reduce \(N_{maj}\) to achieve a target ratio, often 1:1. The number of majority samples to keep, \(N'_{maj}\), is determined by a desired ratio \(\rho\) (e.g., \(\rho=1\) for 1:1 balance): \(N'_{maj} = \rho \cdot N_{min}\).

Euclidean Distance

Many undersampling methods rely on proximity. For two points \(x_a = (x_{a1}, \dots, x_{ad})\) and \(x_b = (x_{b1}, \dots, x_{bd})\) in \(d\)-dimensional space, the Euclidean distance is:

$$d(x_a, x_b) = \sqrt{\sum_{j=1}^d (x_{aj} - x_{bj})^2}$$

Tomek Links Condition

A pair of instances \((x_i, x_j)\) forms a Tomek Link if they belong to different classes (\(y_i \neq y_j\)), and \(x_i\) is the nearest neighbor of \(x_j\), and \(x_j\) is the nearest neighbor of \(x_i\). Formally:

$$\forall k \neq i, d(x_i, x_j) < d(x_i, x_k) \quad \text{and} \quad \forall l \neq j, d(x_j, x_i) < d(x_j, x_l)$$

After identifying Tomek Links, the majority class instance from each link is removed. This removes noisy majority samples that are deep within the minority region or very close to the decision boundary, effectively increasing the separation between classes.

Edited Nearest Neighbours (ENN)

For each instance \(x_i\), find its \(k\)-nearest neighbors. Let \(C(x_i)\) be the class of \(x_i\), and \(C_{NN}(x_i)\) be the set of classes of its \(k\)-nearest neighbors. If the majority class among \(C_{NN}(x_i)\) is different from \(C(x_i)\), then \(x_i\) is considered "misclassified" by its neighbors and is removed. This cleans the dataset by removing instances that appear to be noise or outliers.

NearMiss-1 (Example of NearMiss Family)

To select \(N'_{maj}\) majority samples, NearMiss-1 calculates for each majority sample \(x_{maj}\) the average distance to its \(k\)-nearest minority neighbors. It then keeps the \(N'_{maj}\) majority samples with the smallest average distances. This ensures that the retained majority samples are those closest to the minority class, helping to preserve the decision boundary.

⚠️ Common Pitfall

Undersampling can dramatically reduce the size of your training data, potentially leading to models that underfit or fail to generalize well to unseen data. Always validate performance on a hold-out set and consider hybrid approaches or oversampling if information loss becomes a problem.

Key Takeaways
▼

When to use Undersampling:

  • When the dataset is very large and reducing its size is computationally beneficial.
  • When the majority class contains many redundant or noisy samples.
  • To improve the performance (especially recall/F1-score) of classifiers on the minority class.
  • As a preprocessing step before applying more complex models.

When to be cautious or avoid:

  • When the majority class samples are all unique and valuable — removing them may lead to significant information loss and underfitting.
  • If the minority class is extremely small, undersampling might make the overall dataset too small to learn effectively.
  • If computational resources are not a concern, oversampling or hybrid methods might be preferred to retain more information.
  • For highly overlapping classes, some undersampling methods might remove too many useful samples, making separation harder.
💡 Rule of Thumb

No single undersampling technique is universally best. Random Undersampling is simple and fast, good for initial exploration. Tomek Links and ENN focus on cleaning the decision boundary and removing noise. NearMiss is aggressive, keeping only majority samples closest to the minority, which can be effective but also risky.

Code Trace (Scikit-learn & Imbalanced-learn)
▼
import numpy as np
from collections import Counter
from imblearn.under_sampling import RandomUnderSampler, TomekLinks, EditedNearestNeighbours, NearMiss
from sklearn.datasets import make_classification
# 1. Generate an imbalanced dataset
X, y = make_classification(n_samples=1000, n_features=2, n_informative=2,
n_redundant=0, n_repeated=0, n_classes=2,
n_clusters_per_class=1, weights=[0.9, 0.1], random_state=42)
print(f"Original dataset shape: {Counter(y)}") # Counter({0: 900, 1: 100})
# 2. Random Undersampling
rus = RandomUnderSampler(sampling_strategy=0.5, random_state=42) # 50% of minority class size
X_rus, y_rus = rus.fit_resample(X, y)
print(f"Random Undersampling: {Counter(y_rus)}") # Counter({0: 200, 1: 100})
# 3. Tomek Links
tl = TomekLinks(sampling_strategy='majority') # removes majority samples that form Tomek links
X_tl, y_tl = tl.fit_resample(X, y)
print(f"Tomek Links: {Counter(y_tl)}") # e.g., Counter({0: 885, 1: 100})
# 4. Edited Nearest Neighbours (ENN)
enn = EditedNearestNeighbours(sampling_strategy='majority', n_neighbors=3) # remove majority if most k-NN are minority
X_enn, y_enn = enn.fit_resample(X, y)
print(f"Edited Nearest Neighbours: {Counter(y_enn)}") # e.g., Counter({0: 850, 1: 100})
# 5. NearMiss-1
nm1 = NearMiss(sampling_strategy=0.5, version=1, n_neighbors=3) # select majority closest to k minority neighbors
X_nm1, y_nm1 = nm1.fit_resample(X, y)
print(f"NearMiss-1: {Counter(y_nm1)}") # Counter({0: 200, 1: 100})
