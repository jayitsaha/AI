Rayleigh-Ritz Method

Eigenvalue approximation via subspace projection — the engine behind Lanczos, Arnoldi, LOBPCG, and PCA power iterations
Advanced Linear Algebra Numerical Methods Subspace Projection
1
Understanding the Concept

What is it? The Rayleigh-Ritz method finds approximate eigenvalues and eigenvectors of a large matrix \(A\) by "zooming in" on a smaller subspace \(\mathcal{V}\). Instead of solving the full \(n \times n\) eigenvalue problem, we project \(A\) onto a \(k\)-dimensional trial subspace \(V \in \mathbb{R}^{n \times k}\) and solve the tiny \(k \times k\) projected problem \(V^\top A V\). The eigenvalues of \(V^\top A V\) — called Ritz values — approximate the true eigenvalues of \(A\).

Analogy
Imagine trying to find the highest peak in a mountain range by flying a drone at very high altitude. The full range is the matrix \(A\) — far too large to scan every centimetre. The Rayleigh-Ritz method says: "Pick a handful of vantage points (your subspace \(V\)), project the terrain onto them, and find the tallest peak in that projection." As you add more vantage points, your projected peak height converges to the true maximum.
Core Invariant
If you remember one thing: The Ritz values are the eigenvalues of the projected matrix \(\tilde{A} = V^\top A V\). They converge to the true eigenvalues of \(A\) as the subspace \(\mathcal{V}\) grows — and the convergence is super-linear once the subspace aligns with the target eigenvector direction.

One-sentence summary: The Rayleigh-Ritz method restricts an eigenvalue problem to a tractable subspace, yielding Ritz pairs that converge to the true eigenpairs as the subspace expands.

2
How It Works — Internal Mechanism

The Four-Step Algorithm

  1. Choose a trial subspace \(\mathcal{V} = \operatorname{span}(V)\), where \(V \in \mathbb{R}^{n \times k}\) has orthonormal columns (i.e., \(V^\top V = I_k\)).
  2. Form the projected matrix \(\tilde{A} = V^\top A V \in \mathbb{R}^{k \times k}\).
  3. Solve the small eigenproblem \(\tilde{A} s_i = \theta_i s_i\), giving Ritz values \(\theta_i\) and Ritz vectors \(\tilde{u}_i = V s_i\).
  4. Enrich the subspace (e.g., add the residual \(r_i = A \tilde{u}_i - \theta_i \tilde{u}_i\) and re-orthogonalise) then repeat.
$$\tilde{A} = V^\top A V, \quad \tilde{A} s = \theta s \implies \text{Ritz pair: } (\theta,\; Vs)$$

Connection to the Rayleigh Quotient

For symmetric \(A\), the Ritz value \(\theta_i\) is the stationary value of the Rayleigh quotient \(\rho(x) = x^\top A x / x^\top x\) restricted to \(\mathcal{V}\). This gives a minimax characterisation and guarantees that the extreme Ritz values bound the true extreme eigenvalues.

Minimax Guarantee
By the Courant-Fischer theorem, the \(k\)-th largest Ritz value \(\theta_k\) satisfies: $$\lambda_k(A) \le \theta_k \le \lambda_1(A)$$ for symmetric \(A\) with \(\lambda_1 \ge \lambda_2 \ge \cdots\). Every Ritz value is an upper bound to the corresponding true eigenvalue from below (for the smallest) and below to the corresponding from above (for the largest) — depending on which end you target.

Why This Works for Large Matrices

When \(n = 10^6\) and \(k = 50\), forming \(\tilde{A}\) requires only \(k\) matrix-vector products (each \(O(n)\) for sparse \(A\)), totalling \(O(nk)\) — vastly cheaper than direct diagonalisation \(O(n^3)\). The subspace \(V\) is kept in memory (\(O(nk)\) storage) and the \(k \times k\) projected system is solved exactly using dense LAPACK routines.

Design Decision: Orthonormality is Critical
The columns of \(V\) must be orthonormal (\(V^\top V = I_k\)). Without this, \(\tilde{A} = V^\top A V\) is not the true projection and the Ritz values carry spurious bias. In practice, Gram-Schmidt re-orthogonalisation (or modified Gram-Schmidt / Householder) is run at every expansion step to prevent numerical column-linear-dependence as \(k\) grows.

The Math Behind It

Variational Derivation (Symmetric Case)

Let \(A = A^\top \in \mathbb{R}^{n \times n}\) with eigenpairs \((\lambda_i, u_i)\) and \(u_i^\top u_j = \delta_{ij}\). Define the trial space \(\mathcal{V} = \operatorname{span}(V)\) with \(V^\top V = I_k\).

We seek \(x \in \mathcal{V}\) that makes the Rayleigh quotient stationary:

$$\min_{x \in \mathcal{V},\, x \neq 0} \rho(x) = \frac{x^\top A x}{x^\top x}$$

Writing \(x = Vs\), \(\|x\|^2 = s^\top V^\top V s = s^\top s\), and:

$$\rho(Vs) = \frac{s^\top (V^\top A V) s}{s^\top s} = \frac{s^\top \tilde{A} s}{s^\top s}$$

Stationarity \(\nabla_s \rho = 0\) gives exactly the \(k \times k\) eigenproblem \(\tilde{A}s = \theta s\). QED — the Ritz values are the eigenvalues of the projected matrix.

Residual and Error Bounds

The residual for Ritz pair \((\theta, \tilde{u})\) is \(r = A\tilde{u} - \theta \tilde{u}\). The eigenvalue error satisfies the Davis-Kahan-type bound:

$$|\lambda_i - \theta_i| \le \frac{\|r\|_2}{\delta}, \quad \delta = \min_{j \neq i}|\lambda_i - \lambda_j|$$

where \(\delta\) is the spectral gap to the nearest other eigenvalue. Larger gap → faster convergence.

Non-Symmetric Generalisation

For non-symmetric \(A\), one uses a Petrov-Galerkin condition: seek \(x \in \mathcal{V}\) such that the residual is orthogonal to a test subspace \(\mathcal{W}\):

$$W^\top(Ax - \theta x) = 0 \implies (W^\top A V)s = \theta (W^\top V)s$$

With \(\mathcal{W} = \mathcal{V}\) (Galerkin condition) this reduces to the standard Ritz method. Arnoldi builds \(\mathcal{W} = A\mathcal{V}\) (rational Krylov / two-sided).

Common Misconception
"Ritz values are always closer to true eigenvalues than the initial guess." False — Ritz values can stagnate or even diverge for non-symmetric matrices when the subspace does not contain enough spectral information. For symmetric positive-definite \(A\), monotone convergence from above is guaranteed; for indefinite or non-symmetric \(A\), spurious Ritz values ("ghost eigenvalues") can appear.

Key Takeaways & Connections
Summary
The Rayleigh-Ritz method is the theoretical core of all practical large-scale eigensolvers. It replaces an intractable \(n \times n\) eigenproblem with a tractable \(k \times k\) one by projecting onto a carefully chosen subspace, then iteratively enriches that subspace to drive the approximation error to zero.

When to Use Rayleigh-Ritz vs Alternatives

  • Use Rayleigh-Ritz when \(A\) is large and sparse, and you need only the \(k \ll n\) extreme eigenpairs.
  • Use LAPACK dsyev when \(A\) is dense and \(n \lesssim 10^4\) — full diagonalisation is exact and fast enough.
  • Use randomised SVD when you need approximate extreme singular values/vectors of a general matrix quickly with controllable error.
