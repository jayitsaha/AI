Understanding Newton & Quasi-Newton Methods
▼

What is it? When you minimize a function (e.g., a neural-network loss), gradient descent only uses first-order information — the slope. Newton's method also uses second-order information — the curvature — encoded in the Hessian matrix \(\nabla^2 f\). This lets it jump directly to the minimum of a quadratic surface in a single step, instead of zig-zagging slowly like gradient descent.

Analogy: Imagine navigating a valley in thick fog. Gradient descent feels the slope underfoot and takes a small step downhill. Newton's method also feels how the slope is changing (the curvature), so it can predict exactly how far the valley floor is and land there in one leap. BFGS is a practical compromise: it builds a curvature map incrementally from the gradient differences it observes along the way, without ever spending the \(O(n^3)\) cost of computing the full Hessian.

If you remember one thing

Newton's update is \(\theta \leftarrow \theta - H^{-1}\nabla f\), where \(H = \nabla^2 f\) is the Hessian. It achieves quadratic convergence near a minimum but costs \(O(n^3)\) per step. BFGS approximates \(H^{-1}\) with a rank-2 update from gradient differences, costing \(O(n^2)\). L-BFGS stores only \(m\) recent vector pairs, reducing cost to \(O(mn)\) — making it the workhorse for large-scale ML.

How Newton & BFGS Work Internally
▼

Newton's Method: Local Quadratic Model

At each iterate \(\theta_k\), Newton builds a second-order (quadratic) Taylor approximation of \(f\):

$$f(\theta) \approx f(\theta_k) + \nabla f(\theta_k)^\top (\theta - \theta_k) + \tfrac{1}{2}(\theta - \theta_k)^\top \nabla^2 f(\theta_k)(\theta - \theta_k)$$

This quadratic is minimized analytically by setting its gradient to zero, giving the Newton step:

$$\theta_{k+1} = \theta_k - \bigl[\nabla^2 f(\theta_k)\bigr]^{-1} \nabla f(\theta_k)$$

For a bowl-shaped (convex quadratic) function, this jumps straight to the global minimum in one step, regardless of the bowl's eccentricity.

The Problem: Hessian is Expensive

For \(n\) parameters, \(\nabla^2 f \in \mathbb{R}^{n \times n}\) has \(O(n^2)\) entries to compute and store, and solving \(H p = -g\) costs \(O(n^3)\). For a neural net with \(n = 10^7\) parameters, this is completely infeasible.

BFGS: Approximate the Inverse Hessian

BFGS (Broyden–Fletcher–Goldfarb–Shanno, 1970) maintains an approximation \(B_k \approx H_k^{-1}\) and updates it after each step using the secant condition: the new approximation must satisfy \(B_{k+1}(g_{k+1} - g_k) = \theta_{k+1} - \theta_k\), i.e., it must agree with the true curvature in the direction just traveled. Defining \(s_k = \theta_{k+1} - \theta_k\) and \(y_k = g_{k+1} - g_k\), the BFGS rank-2 update is:

$$B_{k+1} = \left(I - \rho_k s_k y_k^\top\right) B_k \left(I - \rho_k y_k s_k^\top\right) + \rho_k s_k s_k^\top, \quad \rho_k = \frac{1}{y_k^\top s_k}$$
Key Property — L-BFGS

L-BFGS (Limited-memory BFGS) avoids storing \(B_k\) explicitly. Instead it keeps only the last \(m\) pairs \(\{(s_i, y_i)\}_{i=k-m}^{k}\) and computes the action \(B_k g\) via a two-loop recursion in \(O(mn)\) time and \(O(mn)\) memory. With \(m \in [5, 20]\) this is dramatically cheaper than full BFGS's \(O(n^2)\).

Line Search: Wolfe Conditions

BFGS uses a line search to find a step-size \(\alpha_k\) satisfying the Wolfe conditions: sufficient decrease (\(f(\theta_k + \alpha_k p_k) \le f(\theta_k) + c_1 \alpha_k g_k^\top p_k\)) and curvature (\(|g_{k+1}^\top p_k| \le c_2 |g_k^\top p_k|\)). The curvature condition ensures \(y_k^\top s_k > 0\), which keeps the Hessian approximation positive definite.

3
Why It Works — The Math
▼

Quadratic Convergence of Newton's Method

Near a non-degenerate local minimum \(\theta^*\) (where \(\nabla f(\theta^*) = 0\) and \(\nabla^2 f(\theta^*) \succ 0\)), Newton's method satisfies:

$$\|\theta_{k+1} - \theta^*\| \le C \|\theta_k - \theta^*\|^2$$

This is quadratic convergence: the number of correct decimal places doubles at each step. Gradient descent achieves only linear convergence (\(\|\theta_{k+1} - \theta^*\| \le r \|\theta_k - \theta^*\|\) for \(r < 1\)) at a rate governed by the condition number \(\kappa = \lambda_{\max}/\lambda_{\min}\) of the Hessian.

Derivation: Why the Newton Step Minimizes the Quadratic Model

The local quadratic model \(m_k(p) = f(\theta_k) + g_k^\top p + \frac{1}{2}p^\top H_k p\) is minimized by setting \(\nabla_p m_k = 0\):

$$g_k + H_k p = 0 \implies p^* = -H_k^{-1} g_k$$

When \(H_k \succ 0\), \(p^* = -H_k^{-1}g_k\) is a descent direction. Setting \(\alpha_k = 1\) recovers the classical Newton step.

BFGS Superlinear Convergence

BFGS achieves superlinear convergence — faster than linear but slower than quadratic — because the Hessian approximation \(B_k\) converges to the true \(H^{-1}\) along the optimization path. The convergence rate satisfies:

$$\lim_{k\to\infty} \frac{\|\theta_{k+1} - \theta^*\|}{\|\theta_k - \theta^*\|} = 0$$

The key insight is that BFGS satisfies the quasi-Newton (secant) condition \(B_{k+1} s_k = y_k\) while remaining the closest symmetric positive-definite matrix to \(B_k\) in the weighted Frobenius norm — this is the update's mathematical justification.

Common Pitfall

Newton's method fails if the Hessian is not positive definite (saddle points, negative curvature). Modified Newton methods add a multiple of the identity: \(H_k + \lambda_k I\) to ensure positive definiteness. BFGS automatically maintains \(B_k \succ 0\) if the Wolfe curvature condition is enforced during line search.

Key Takeaways & When to Use
▼

Method Comparison

The hierarchy from slowest (but cheapest) to fastest (but most expensive):

  • Gradient Descent: \(O(n)\) per step, linear convergence, condition-number dependent. Use for huge \(n\).
  • L-BFGS: \(O(mn)\) per step (\(m \approx 10\)), superlinear convergence. Best for large-scale smooth optimization.
  • BFGS: \(O(n^2)\) storage & per-step, superlinear. Feasible for moderate \(n \le 10^4\).
  • Newton: \(O(n^3)\) solve, quadratic convergence. Only for small \(n\) or structured problems (e.g., natural gradient).
Practical Rule

For deep learning: use Adam/SGD (stochastic, handles noise). For classical ML / scientific computing (scipy, sklearn, statsmodels): use L-BFGS — it's method='L-BFGS-B' in scipy.optimize.minimize. For logistic regression / small MLP: L-BFGS often converges in <100 iterations versus thousands for SGD.

When NOT to use quasi-Newton

Stochastic gradients (mini-batch noise) violate the secant condition: \(y_k^\top s_k\) can be negative, destroying positive definiteness. L-BFGS-B requires accurate gradients — it is a full-batch method and does not directly replace Adam in deep learning.

Code Trace
▼
import numpy as np
from scipy.optimize import minimize
# Objective: elongated bowl, condition number kappa=25
def f(x): return 0.5*(x[0]**2 + 25.0*x[1]**2)
def grad(x): return np.array([x[0], 25.0*x[1]])
def hess(x): return np.diag([1.0, 25.0]) # exact Hessian
# --- Newton's method (1 step for quadratic!) ---
x0 = np.array([3.0, 2.0])
H = hess(x0) # [[1, 0],[0, 25]]
g = grad(x0) # [3, 50]
p = -np.linalg.solve(H, g) # Newton step = [-3, -2]
x_newton = x0 + p # [0, 0] — done in 1 step!
# --- L-BFGS-B via scipy (production) ---
result = minimize(f, x0, jac=grad, method='L-BFGS-B',
options={'maxiter': 200, 'ftol': 1e-12})
print(f"L-BFGS: x={result.x}, iters={result.nit}")
# --- Manual BFGS rank-2 update ---
def bfgs_update(B, s, y):
rho = 1.0 / (y @ s) # 1 / (y^T s)
I = np.eye(len(s))
A = I - rho * np.outer(s, y)
return A @ B @ A.T + rho * np.outer(s, s)
# Ensure y^T s > 0 (Wolfe condition) before updating!
if y @ s > 1e-10:
B = bfgs_update(B, s, y) # rank-2 correction
