Huber Loss

Robust regression metric — quadratic near zero, linear in the tails

Intermediate Classical ML Evaluation O(n) per epoch
1
Understanding the Concept

Imagine you're measuring how far off a weather forecast is each day. Most days the error is small — a degree or two. Occasionally there's a wild outlier: you predicted 20 °C and it was 5 °C. MSE squares that big error, letting it dominate everything. MAE treats all errors equally, but its gradient is flat so small errors get ignored. Huber loss is the best of both worlds: act like MSE when the error is small (quadratic precision), act like MAE when the error is large (linear robustness).

💡 If you remember one thing

Huber loss = MSE inside \([-\delta, +\delta]\), MAE outside. The transition point \(\delta\) is the tunable knob between sensitivity and robustness.

The single hyperparameter \(\delta\) sets the boundary: residuals smaller than \(\delta\) are treated quadratically, larger ones linearly. This gives smooth gradients everywhere (unlike MAE at zero) and bounded influence of outliers (unlike MSE).

2
How It Works — The Piecewise Definition

For a residual \(r = y - \hat{y}\), the Huber loss is:

$$L_\delta(r) = \begin{cases} \frac{1}{2}r^2 & |r| \le \delta \\ \delta\!\left(|r| - \frac{\delta}{2}\right) & |r| > \delta \end{cases}$$

The linear piece is chosen so the function and its first derivative are continuous at the join points \(r = \pm\delta\):

  • At \(r = \delta\): quadratic gives \(\tfrac{1}{2}\delta^2\); linear gives \(\delta(\delta - \tfrac{\delta}{2}) = \tfrac{1}{2}\delta^2\) ✓
  • Gradient of quadratic piece: \(r\). Gradient of linear piece: \(\pm\delta\). At the join: both equal \(\delta\) ✓
🔑 Key property

The gradient of Huber loss is clipped at \(\pm\delta\). This is exactly what prevents outliers from exploding gradients during training.

The gradient used for optimization:

$$\frac{\partial L_\delta}{\partial r} = \begin{cases} r & |r| \le \delta \\ \delta \cdot \operatorname{sign}(r) & |r| > \delta \end{cases}$$
⚠️ Common Confusion

Huber loss is not "MSE + clipping." The linear tail is designed so the loss surface is everywhere differentiable. MAE has a non-differentiable kink at zero; Huber loss does not.

Why It Works — MSE vs MAE vs Huber
PropertyMSEMAEHuber (\(\delta\))
Small-error gradientProportional to \(r\)Constant ±1Proportional to \(r\) (like MSE)
Large-error gradientProportional to \(r\) (grows!)Constant ±1Clipped to ±\(\delta\) (like MAE)
Outlier influenceVery high (quadratic)Bounded (linear)Bounded (linear beyond \(\delta\))
Differentiable everywhereYesNo (at 0)Yes
Converges fast near optimumYesNoYes
Robust to outliersNoYesYes (tunable)

Huber loss recovers MSE as \(\delta \to \infty\) (the whole curve becomes quadratic) and recovers MAE as \(\delta \to 0\) (the whole curve becomes linear).

💡 Statistical viewpoint

Minimizing Huber loss corresponds to maximum-likelihood estimation under a Huber distribution — Gaussian in the centre, Laplace (exponential) in the tails. It is the M-estimator proposed by Peter Huber in 1964.

From-Scratch Implementation

NumPy implementation — vectorised, handling batches:

import numpy as np
def huber_loss(y_true, y_pred, delta=1.0):
"""Huber loss, vectorised over a batch."""
r = y_true - y_pred # residuals
abs_r = np.abs(r)
quadratic = 0.5 * r**2 # MSE piece
linear = delta * (abs_r - 0.5*delta) # MAE piece
loss = np.where(abs_r <= delta, quadratic, linear)
return loss.mean() # scalar mean loss
def huber_gradient(y_true, y_pred, delta=1.0):
"""Gradient dL/d(y_pred) for backprop."""
r = y_true - y_pred
grad = np.where(np.abs(r) <= delta, -r, -delta * np.sign(r))
return grad / len(r) # mean gradient
PyTorch one-liner

torch.nn.HuberLoss(delta=1.0)(pred, target) — or torch.nn.SmoothL1Loss(beta=1.0) which is identical for beta=delta.

6
Key Takeaways
  • Use Huber loss when your target variable may have outliers but you still want smooth quadratic gradients for small errors.
  • \(\delta\) is usually set via cross-validation; a common default is \(\delta = 1.0\) (i.e., the scale of a "normal" residual in your units).
  • In deep learning, SmoothL1Loss in PyTorch / Huber in TensorFlow/Keras are production-ready implementations.
  • For regression on raw prices, sensor readings, or any heavy-tailed target — prefer Huber over MSE.
  • Related: Pseudo-Huber loss (differentiable approximation), Quantile loss (asymmetric robustness), Log-cosh loss (similar shape, fully smooth).
🔑 Decision rule

No outliers → MSE. Outliers present, care about large errors → MAE. Want fast convergence near optimum and robustness to outliers → Huber.
