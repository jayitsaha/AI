Transformer Variants for Long-Horizon Forecasting

Informer, Autoformer, FEDformer, PatchTST — adapting attention for time series
Intermediate Deep Learning Time Series O(L log L) to O(L)
1
Understanding the Challenge
▼

What is Long-Horizon Time Series Forecasting (LHTSF)? It's about predicting far into the future given a long history of data. Think predicting electricity demand for the next month based on years of past data, or stock prices for the next quarter. Unlike short-term prediction, LHTSF demands models that can capture complex long-range dependencies, handle distribution shifts, and remain computationally efficient for very long input and output sequences.

Why are standard Transformers not ideal for LHTSF? While Transformers revolutionized sequence modeling, their core self-attention mechanism computes interactions between *every pair* of elements in a sequence. This leads to quadratic complexity, \(O(L^2)\), where \(L\) is the sequence length. For LHTSF, where \(L\) can be hundreds or thousands, this quickly becomes computationally prohibitive and memory-intensive. Furthermore, vanilla attention is "flat" — it doesn't inherently understand temporal patterns like seasonality or trends, nor is it robust to the distribution shifts common in real-world time series.

The variants explored here — Informer, Autoformer, FEDformer, and PatchTST — are specialized Transformer architectures designed to overcome these limitations, making Transformers practical and effective for LHTSF.

💡 If you remember one thing

These Transformer variants primarily tackle two issues for LHTSF: (1) reducing the quadratic \(O(L^2)\) computational and memory cost of self-attention, and (2) making the model's inductive biases more suitable for temporal data (e.g., by incorporating decomposition, frequency analysis, or local patching).

2
How Each Variant Works
▼

1. Informer (2021)

Informer introduced two key mechanisms to address Transformer's efficiency issues:

  • ProbSparse Self-Attention: Instead of computing attention for all \(L^2\) query-key pairs, Informer proposes that only a few query vectors are "active" and truly contribute to the dominant attention patterns. It uses a sparsity measure (based on KL divergence) to identify and select only the top-\(K\) relevant queries, reducing the complexity to \(O(L \log L)\).
  • Self-Attention Distilling: This technique progressively reduces the sequence length (and thus memory footprint) between successive encoder layers by using a convolutional layer to downsample feature maps.

2. Autoformer (2021)

Autoformer focuses on enhancing the Transformer's ability to model time series by explicitly handling periodicity and trends:

  • Series Decomposition Block: Before applying attention, Autoformer uses a moving average kernel to recursively decompose the input series into a trend component and a seasonal-remainder component. These are processed separately and recombined.
  • Auto-correlation Mechanism: This replaces the standard self-attention. Instead of dot products, it computes the auto-correlation of the features to discover inherent periodicities. Attention weights are then derived based on these detected periods, making the mechanism more robust to temporal shifts and local noise while maintaining \(O(L \log L)\) complexity.

3. FEDformer (2022)

FEDformer takes a frequency-domain approach, leveraging the fact that many time series signals are best understood through their spectral components:

  • Frequency Enhanced Block (FEB): It performs the core attention mechanism directly in the frequency domain. After decomposing the series (similar to Autoformer), it applies a Fast Fourier Transform (FFT) to the query, key, and value representations. Self-attention is then computed on these frequency-domain representations, capturing global dependencies more efficiently.
  • Low-rank Frequency Mixing: To further enhance efficiency and robustness, FEDformer uses a small MLP (mixer) to combine a low-rank subset of frequency components, reducing the number of parameters and computational cost. This allows for \(O(L)\) complexity.

4. PatchTST (2023)

PatchTST simplifies the Transformer's interaction with time series by introducing a patching strategy and focusing on channel independence:

  • Patching: Instead of treating each individual time step as a token, PatchTST divides the time series into overlapping "patches" (sub-sequences). The Transformer then processes these patches as its input tokens. This effectively reduces the sequence length for the Transformer, making it more efficient, and allows it to capture local semantic information within each patch.
  • Channel-Independent Modeling: For multivariate time series, PatchTST applies the Transformer encoder independently to each variate (channel). This simplifies the model and prevents cross-channel interaction from dominating, which can be beneficial when individual channels have distinct temporal dynamics.
🔑 Key Property

Each variant introduces a unique inductive bias tailored for time series: Informer uses sparsity, Autoformer uses periodicity, FEDformer uses frequency, and PatchTST uses local temporal segments. These biases guide the Transformer to learn more relevant features for forecasting while improving efficiency.

3
Why They Work — The Core Math
▼

Standard Self-Attention Bottleneck

The core of a Transformer is the scaled dot-product attention:

$$Attention(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

If \(Q, K, V \in \mathbb{R}^{L \times d_k}\), computing \(QK^T\) results in an \(L \times L\) matrix. This matrix multiplication dominates the computation with \(O(L^2 d_k)\) complexity and requires \(O(L^2)\) memory for the attention map, making it infeasible for large \(L\).

Informer: ProbSparse Self-Attention

Informer's key idea is to identify salient queries. For each query \(q_i\), it computes a "sparsity measurement" (e.g., using KL divergence approximation):

$$M(q_i, K) = \max_j \frac{q_i k_j^T}{\sqrt{d_k}} - \frac{1}{L_K} \sum_j \frac{q_i k_j^T}{\sqrt{d_k}}$$

This measures how much \(q_i\) deviates from a uniform attention distribution over \(K\). Only the top-\(u\) queries (where \(u = L \log L\)) with the highest \(M(q_i, K)\) values are selected. The attention computation then becomes sparse:

$$Attention(Q, K, V) = \text{softmax}\left(\frac{\bar{Q}K^T}{\sqrt{d_k}}\right)V$$

where \(\bar{Q}\) contains only the selected sparse queries, reducing complexity to \(O(L \log L)\).

Autoformer: Auto-correlation Mechanism

Autoformer replaces the dot-product attention with an auto-correlation mechanism. It leverages the Wiener-Khinchin theorem, which states that the power spectral density of a signal is the Fourier transform of its auto-correlation function. The auto-correlation of a series \(X\) at lag \(\tau\) is \(\mathcal{R}_X(\tau) = \text{Cov}(X_t, X_{t-\tau})\). The attention mechanism identifies dominant periodicities by computing auto-correlations:

$$\text{AutoCorrelation}(X) = \text{Top-k Periods from } \mathcal{F}^{-1}\left(|\mathcal{F}(X)|^2\right)$$

where \(\mathcal{F}\) is the Fourier Transform. This allows attention to focus on significant temporal dependencies, achieving \(O(L \log L)\) complexity.

⚠️ Efficiency vs. Expressivity

While these methods dramatically improve efficiency, they often do so by introducing stronger inductive biases or approximations. For example, ProbSparse attention might miss subtle but important dependencies if a query's "sparsity measure" is low but its interaction with a key is critical. Patching loses fine-grained temporal information within patches. These trade-offs are acceptable for LHTSF where raw Transformer power is often overkill and computationally infeasible.

Key Takeaways
▼

When to use each variant:

  • Informer: A solid general-purpose choice for LHTSF, particularly when computational resources are a concern and the raw sequence length is very high. Its ProbSparse attention and distilling mechanisms offer good efficiency gains.
  • Autoformer: Excels with highly periodic or seasonal time series data (e.g., electricity load, traffic, weather patterns). Its explicit decomposition and auto-correlation mechanism provide strong inductive biases for capturing such patterns effectively.
  • FEDformer: Ideal for complex time series with rich multi-frequency components, especially when global relationships across the entire sequence are important. Operating in the frequency domain can be more robust to noise and local fluctuations.
  • PatchTST: Highly effective for very long input sequences and multivariate forecasting, especially when local temporal patterns are salient. The patching strategy implicitly handles local semantics and significantly reduces the effective sequence length for the Transformer, leading to strong performance and efficiency.

When NOT to use these specialized Transformers:

  • Small datasets or short horizons: For simpler problems or shorter prediction tasks, traditional methods (ARIMA, Exponential Smoothing) or simpler deep learning models (RNNs, LSTMs) might be more efficient and easier to train without the overhead of complex Transformer architectures.
  • Non-stationary data without preprocessing: While some variants handle trends, highly non-stationary data still benefits from explicit differencing or detrending before model input, regardless of the Transformer variant.
  • Interpreting fine-grained attention: If interpretability of individual time step relationships is paramount, the approximations (ProbSparse, patching) or transformations (frequency domain) might obscure direct attention patterns.
💡 Big Picture

The evolution from vanilla Transformers to these specialized variants showcases a critical trend in ML research: adapting powerful general-purpose architectures with domain-specific inductive biases to excel in particular problem settings. For LHTSF, this means balancing computational efficiency with robust temporal modeling.

import torch
import torch.nn as nn
import torch.nn.functional as F
class ProbSparseAttention(nn.Module):
def __init__(self, mask_flag=True, factor=5, scale=None):
super(ProbSparseAttention, self).__init__()
self.factor = factor # sparsity factor, e.g., 5
self.scale = scale # 1/sqrt(d_k)
self.mask_flag = mask_flag
def _prob_attn(self, queries, keys, values):
L_Q = queries.shape[-2] # Query sequence length
L_K = keys.shape[-2] # Key sequence length
# Calculate sparsity measure M(q_i, K) for each query
# Approx top-u queries (u = L_Q * log(L_K))
scores_top, index_sample = self._get_top_queries(queries, keys, L_Q, L_K)
# Construct sparse query matrix Q_sparse
Q_sparse = queries.index_select(-2, index_sample)
# Compute attention for sparse queries
scores = torch.matmul(Q_sparse, keys.transpose(-1, -2))
if self.scale is not None: scores = scores * self.scale
attn_weights = F.softmax(scores, dim=-1)
output = torch.matmul(attn_weights, values)
# Reconstruct full output by padding with zeros for non-selected queries
# (Simplified: in reality, need to map back to original query positions)
full_output = torch.zeros_like(queries).to(output.device)
full_output.index_copy_(-2, index_sample, output)
return full_output
def _get_top_queries(self, queries, keys, L_Q, L_K):
# Simplified: in real Informer, this involves random sampling and max-pooling
# For illustration, let's just pick queries with high L2 norm difference
query_norms = queries.norm(dim=-1)
key_norms = keys.norm(dim=-1)
# Dummy metric: variance of dot products (higher variance -> more 'active')
# In original Informer: KL divergence from uniform distribution
# Compute a proxy for attention scores (without softmax)
raw_scores = torch.matmul(queries, keys.transpose(-1, -2))
# Measure 'sparsity' by max score minus average score for each query
M = raw_scores.max(dim=-1)[0] - raw_scores.mean(dim=-1)
top_k = int(L_Q * torch.log(torch.tensor(L_K, dtype=torch.float32)).item()) # u = L_Q * log(L_K)
if top_k == 0: top_k = 1 # Ensure at least one query is selected
_, index_sample = torch.topk(M, top_k, dim=-1) # Select top-k queries
return M, index_sample
def forward(self, queries, keys, values):
return self._prob_attn(queries, keys, values)
