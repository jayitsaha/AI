Understanding ELU & SELU
▼

What are they? ELU and SELU are activation functions — the nonlinearity applied after each linear layer in a neural net. ReLU hard-clips every negative input to exactly 0. ELU instead lets negative inputs curve smoothly down toward a floor of \(-\alpha\), never fully flatlining and never fully exploding. SELU takes that same curve and multiplies it by a very specific constant \(\lambda\), fixing \(\alpha\) at another specific constant — together these two numbers give the network a remarkable property: activations converge toward zero mean and unit variance on their own, layer after layer.

Analogy: ReLU is a thermostat that just shuts the heater off below 0°C — the room can drift arbitrarily cold with no correction. ELU is a smarter thermostat: it lets the room dip a little below 0°C but curves gently back, never crashing. SELU is that same thermostat factory-calibrated with exact gain settings so that no matter how many rooms (layers) the heat passes through, every room self-corrects back to a standard comfortable baseline — with no separate climate-control system (BatchNorm) bolted on.

💡 If you remember one thing

SELU \(= \lambda \cdot \text{ELU}_\alpha(x)\) with fixed constants \(\lambda \approx 1.0507\), \(\alpha \approx 1.6733\) chosen so that the mapping (mean, variance) → (mean′, variance′) has a stable, attracting fixed point at (0, 1) — that single fact is the entire self-normalizing property.

How They Work Internally
▼

The Problem with ReLU

ReLU's output is always \(\ge 0\), so the mean activation of any ReLU layer is systematically positive — this "bias shift" pushes the next layer's weighted sums off-center and slows convergence. Worse, any unit whose input is always negative outputs exactly 0 with zero gradient forever — a "dead" unit that can never recover.

ELU's Fix: Smooth, Bounded Negative Branch

$$\text{ELU}_\alpha(x) = \begin{cases} x & x > 0 \\ \alpha(e^{x}-1) & x \le 0 \end{cases}$$

For \(x \le 0\), the output smoothly approaches \(-\alpha\) as \(x \to -\infty\) instead of flatlining at 0. This keeps a non-zero gradient everywhere (no dead units) while still pulling the mean activation down toward zero (faster, more stable training) and bounding the output (robust to large negative noise).

SELU's Fix: Calibrate the Curve to Self-Normalize

SELU scales the entire ELU curve by \(\lambda\) and fixes \(\alpha\) at a specific value — not tunable hyperparameters, but the unique solution of two equations that force \((\mu,\nu)=(0,1)\) to be a fixed point of the per-layer mean/variance recursion (derived in Card 3). Paired with LeCun-normal weight init \(w \sim \mathcal{N}(0, 1/n_{in})\), each SELU layer's output statistics land back near \((0,1)\) — no BatchNorm needed.

🔑 Key Property

A network is self-normalizing if the map \(g(\mu,\nu)=(\mu',\nu')\) taking a layer's input statistics to its output statistics has \((0,1)\) as a stable, attracting fixed point — small deviations shrink back toward \((0,1)\) automatically, with no external normalization step.

3
Why It Works — The Math
▼

Setting Up the Fixed-Point Equation

Assume layer inputs \(x_i\) are i.i.d. with mean \(\mu\), variance \(\nu\). With LeCun-normal weights \(w_i \sim \mathcal{N}(0, 1/n)\), the pre-activation \(z = \sum_i w_i x_i + b\) is approximately Gaussian by the CLT:

$$z \sim \mathcal{N}(\mu_z, \nu_z), \qquad \mu_z \approx 0,\quad \nu_z \approx \nu$$

Propagating through SELU defines a map \(g(\mu,\nu) = (\mu', \nu')\) via \(\mu' = \mathbb{E}[\text{SELU}(z)]\), \(\nu' = \operatorname{Var}[\text{SELU}(z)]\). Self-normalization requires:

$$g(0,1) = (0,1)$$

This gives two nonlinear equations in \(\lambda,\alpha\). Solving numerically (Klambauer et al., 2017) yields the unique positive solution:

$$\alpha \approx 1.6732632423543772,\qquad \lambda \approx 1.0507009873554805$$

Why It's Stable, Not Just a Fixed Point

The paper further shows \(g\) is a contraction mapping near \((0,1)\) — the Jacobian of \(g\) has spectral radius \(<1\) there. By the Banach fixed-point theorem, this makes \((0,1)\) stable and attracting: starting from any \((\mu_0,\nu_0)\) reasonably close (empirically \(\mu\in[-0.1,0.1]\), \(\nu\in[0.8,1.5]\)), repeated application of \(g\) — i.e. stacking more SELU layers — drives statistics toward \((0,1)\):

$$\lim_{k\to\infty} g^{(k)}(\mu_0,\nu_0) = (0,1)$$
⚠️ Common Pitfall

SELU does not force exact statistics like BatchNorm does — it's an asymptotic, assumption-dependent convergence. Wrong init (He/Xavier instead of LeCun-normal), ordinary Dropout, or unscaled skip-connections all break the assumptions and the fixed point can drift.

Key Takeaways
▼

When to use ELU:

  • Deep CNNs where you want faster convergence than ReLU with minimal extra setup
  • You want to reduce dead units without the extra parameter of PReLU
  • Default \(\alpha=1\) keeps the function \(C^1\)-continuous at the kink

When to use SELU:

  • Plain feed-forward MLPs (no skip connections) — tabular data, small/medium nets
  • You want to drop BatchNorm entirely (batch-size-independent inference)
  • You can commit to the full recipe: LeCun-normal init + standardized inputs + AlphaDropout

When NOT to use SELU:

  • Residual/skip-connection architectures (ResNets, Transformers) — variance algebra breaks
  • You're using default framework initializers (Kaiming/Xavier) and won't change them
  • You need ordinary Dropout — must use AlphaDropout instead
💡 Hierarchy

ReLU (hard clip, biased mean) → ELU (smooth clip, closer to zero mean) → SELU (calibrated scale + shape ⇒ provably self-normalizing). Each step trades a little compute (an exp()) for better-behaved statistics.

Code Trace
▼
ALPHA, LAMBDA = 1.6732632423543772, 1.0507009873554805
def selu(x):
pos = np.where(x > 0, x, 0.0)
neg = np.where(x <= 0, ALPHA * (np.expm1(x)), 0.0)
return LAMBDA * (pos + neg)
def lecun_normal(fan_in, fan_out, rng):
std = (1.0 / fan_in) ** 0.5 # REQUIRED: Var(w) = 1/n
return rng.normal(0, std, size=(fan_in, fan_out))
x = rng.normal(0, 1, size=(n_samples, n_units)) # standardized input
for layer in range(n_layers):
W = lecun_normal(n_units, n_units, rng)
z = x @ W
x = selu(z)
print(layer, x.mean(), x.var()) # stays pinned near 0.0 / 1.0
# Contrast: ReLU + He-init, no BatchNorm -> mean/var drift with depth
def relu_he_layer(x, rng):
n = x.shape[1]
W = rng.normal(0, (2.0 / n) ** 0.5, size=(n, n))
return np.maximum(x @ W, 0.0)
