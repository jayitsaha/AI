Linear Attention

Re-associating (QKᵀ)V → Q(KᵀV) with a kernel feature map to trade O(n²d) for O(nd²)
Advanced Efficient Transformers Attention O(n·d²)
1
Understanding Linear Attention
▼

What is it? Standard self-attention computes a full \(n \times n\) grid of "who attends to whom" scores before touching the values \(V\) — that grid costs \(O(n^2 d)\) time and \(O(n^2)\) memory, which becomes brutal at long sequence lengths. Linear attention swaps the softmax similarity for a kernel feature map \(\phi\), which makes the attention formula algebraically re-associable: instead of building the giant \(n\times n\) matrix first, you can multiply the small matrices first and never materialize the big one at all.

Analogy: Imagine tallying votes from \(n\) voters across \(d\) candidates, then cross-referencing every voter against every other voter (\(n^2\) comparisons) before totaling. Linear attention instead just keeps a running \(d \times d\) tally sheet ("how much does feature A of keys correlate with feature B of values") and looks each voter up against that tiny sheet — no voter-vs-voter comparison ever happens.

💡 If you remember one thing

Matrix multiplication is associative: \((AB)C = A(BC)\). Softmax attention is forced to compute \(A=QK^\top\) first because softmax needs row-wise scores. Drop softmax for a kernel feature map \(\phi\), and you're free to compute \(\phi(K)^\top V\) (a \(d\times d\) matrix) first — collapsing the sequence dimension \(n\) out of the expensive matrix entirely.

2
How Linear Attention Works Internally
▼

Why Softmax Attention Is Stuck at O(n²d)

Standard attention is \(\text{softmax}(QK^\top/\sqrt{d})V\). The softmax is applied row-wise over the \(n\times n\) score matrix \(A = QK^\top\), so every entry of \(A\) must exist simultaneously before normalization — you cannot skip building it. Forming \(A\) costs \(O(n^2 d)\) multiply-adds, and \(AV\) costs another \(O(n^2 d)\); the \(n\times n\) matrix also has to live in memory (or be tiled, as FlashAttention does, without reducing the FLOP count).

The Kernel Trick: Replace Softmax with φ(q)·φ(k)

Linear attention (Katharopoulos et al., 2020) approximates the similarity kernel with a feature map \(\phi: \mathbb{R}^d \to \mathbb{R}^r_{+}\) (e.g. \(\phi(x)=\text{elu}(x)+1\)), so \(\text{sim}(q_i,k_j) \approx \phi(q_i)^\top\phi(k_j)\) — a plain dot product, no row-wise normalization required upfront. Because it's just a dot product, the output for token \(i\) becomes:

$$O_i = \frac{\phi(q_i)^\top \sum_j \phi(k_j)v_j^\top}{\phi(q_i)^\top \sum_j \phi(k_j)}$$

The sums \(\sum_j \phi(k_j)v_j^\top\) (a \(d\times d\) matrix \(S=\phi(K)^\top V\)) and \(\sum_j \phi(k_j)\) (a \(d\)-vector \(z\)) do not depend on \(i\) at all — compute them once, then every query just does one small matrix-vector product against them.

Design Decision: Why Compute φ(K)ᵀV Before φ(Q)?

This is pure associativity of matrix multiplication: \((\phi(Q)\phi(K)^\top)V = \phi(Q)(\phi(K)^\top V)\). The left form builds the \(n\times n\) matrix first (expensive, grows with sequence length). The right form builds the \(d\times d\) matrix \(S=\phi(K)^\top V\) first — its size is fixed by the head dimension, completely independent of \(n\). Since \(d \ll n\) in practice (e.g. \(d{=}64\), \(n{=}8192\)), this re-association is the entire efficiency win.

🔑 Key Property

Softmax attention's cost is dominated by the sequence-length-squared term \(n^2 d\). Linear attention's cost is dominated by the feature-dimension-squared term \(nd^2\) — linear in \(n\), because the intermediate \(S\) never grows with sequence length.

3
Why It Works — The Math
▼

From Softmax Attention to a Bilinear Form

Write softmax attention entrywise as a weighted average with kernel similarity \(\text{sim}(q,k)=\exp(q^\top k/\sqrt d)\):

$$O_i = \frac{\sum_{j=1}^n \text{sim}(q_i,k_j)\, v_j}{\sum_{j=1}^n \text{sim}(q_i,k_j)}$$

Any kernel that factorizes as \(\text{sim}(q,k) = \phi(q)^\top\phi(k)\) for some feature map \(\phi\) lets us pull the sum over \(j\) inside, decoupling it from query index \(i\):

$$O_i = \frac{\phi(q_i)^\top\left(\sum_j \phi(k_j)v_j^\top\right)}{\phi(q_i)^\top\left(\sum_j \phi(k_j)\right)} = \frac{\phi(q_i)^\top S}{\phi(q_i)^\top z},\quad S=\phi(K)^\top V \in \mathbb{R}^{d\times d},\ z=\sum_j\phi(k_j)$$

In matrix form for all \(n\) queries at once, this is exactly the associativity rewrite:

$$\big(\phi(Q)\,\phi(K)^\top\big)\,V \;=\; \phi(Q)\,\big(\phi(K)^\top V\big)$$

FLOP Counting

Left side: \(\phi(Q)\phi(K)^\top\) is \((n{\times}d)(d{\times}n) \to n{\times}n\), costing \(O(n^2d)\); then \((n{\times}n)(n{\times}d)\to n{\times}d\) costs another \(O(n^2d)\). Total: \(O(n^2d)\). Right side: \(\phi(K)^\top V\) is \((d{\times}n)(n{\times}d)\to d{\times}d\), costing \(O(nd^2)\); then \((n{\times}d)(d{\times}d)\to n{\times}d\) costs another \(O(nd^2)\). Total: \(O(nd^2)\). The speedup factor is \(n/d\) — for \(n{=}4096, d{=}64\) that's a 64× reduction in FLOPs.

⚠️ Common Misconception

"Linear attention is just an approximation trick." It's really an exact re-association once you accept the kernelized similarity — the only approximation is replacing \(\exp(q^\top k/\sqrt d)\) with \(\phi(q)^\top\phi(k)\) for a tractable, positive, low-rank-friendly \(\phi\) (Performer's random features make this approximation asymptotically unbiased for the true softmax kernel).

Key Takeaways
▼

When to use linear attention:

  • Long sequences where \(n \gg d\) — documents, genomics, audio, high-res image patches
  • Streaming / causal inference where O(1)-per-token recurrent decoding matters (no growing KV cache)
  • Memory-constrained training where the \(O(n^2)\) attention matrix doesn't fit

When NOT to use:

  • Short sequences (\(n \lesssim d\)) — the re-association buys nothing or even hurts
  • Tasks needing sharp, sparse attention patterns — linear kernels tend to produce more diffuse attention than softmax
  • When exact softmax fidelity matters and hardware-aware exact methods (FlashAttention) already fit in memory
💡 The One Reusable Idea

Whenever an operation is a chain of matrix multiplications, check whether it's forced into one associativity order (like softmax forces \(QK^\top\) first) — if you can relax that constraint, re-associating around the smallest dimension is a free lunch. This same trick underlies Performer, RWKV, State Space Models (Mamba's scan), and RNN-style attention.

Code Trace
▼
import numpy as np
def phi(x):
# positive feature map (Katharopoulos et al. 2020)
return np.where(x > 0, x + 1, np.exp(x)) # elu(x) + 1
# ---- Standard attention: O(n^2 d) ----
def standard_attention(Q, K, V):
A = Q @ K.T # (n,d)@(d,n) -> (n,n) O(n^2 d)
A = softmax(A / np.sqrt(Q.shape[-1]), axis=-1)
return A @ V # (n,n)@(n,d) -> (n,d) O(n^2 d)
# ---- Linear attention: O(n d^2) ----
def linear_attention(Q, K, V):
Qp, Kp = phi(Q), phi(K)
S = Kp.T @ V # (d,n)@(n,d) -> (d,d) O(n d^2) <-- shrinking intermediate
z = Kp.sum(axis=0) # (d,) O(n d)
num = Qp @ S # (n,d)@(d,d) -> (n,d) O(n d^2)
den = Qp @ z + 1e-6 # (n,d)@(d,) -> (n,)
return num / den[:, None]
# ---- Recurrent / causal streaming form: O(1) per new token ----
def linear_attention_step(q_t, k_t, v_t, S, z):
S = S + np.outer(phi(k_t), v_t) # (d,d) running state
z = z + phi(k_t) # (d,) running normalizer
o_t = (phi(q_t) @ S) / (phi(q_t) @ z + 1e-6)
return o_t, S, z # O(d^2) work, O(d^2) memory — independent of t!
