The self-gated activation discovered by neural architecture search — smooth, non-monotonic, and the workhorse behind EfficientNet
Intermediate Deep Learning Activation Functions O(1) per element

Understanding Swish
▼

What is it? ReLU decides whether to pass a signal with a hard rule based on the sign of the input. Swish instead multiplies the input \(x\) by \(\sigma(\beta x)\) — the sigmoid of a scaled version of the same input. The signal effectively gates itself: it looks at its own magnitude and decides how much of itself to let through, smoothly, with no hard corner.

Analogy: ReLU is a wall switch — fully on or fully off. Swish is a dimmer that reads its own brightness level and adjusts itself: strongly positive signals get waved through almost untouched, strongly negative signals get dimmed almost to darkness, and signals near zero get a proportional, continuously-adjustable dose. Because the dimmer briefly "overcorrects" for mildly negative inputs, the output can dip slightly below zero before settling — something a plain on/off switch could never do.

💡 If you remember one thing

Swish is self-gated: $$\text{Swish}_\beta(x) = x\cdot\sigma(\beta x), \qquad \sigma(z)=\frac{1}{1+e^{-z}}$$ At \(\beta=1\) this is exactly SiLU (Sigmoid Linear Unit). It was not hand-designed — it was discovered by an automated search over activation functions, and it consistently outperformed ReLU in deep networks like EfficientNet.

How Swish Works Internally
▼

Found by Search, Not by Hand

Ramachandran, Zoph & Le ("Searching for Activation Functions", 2017) ran reinforcement-learning-driven neural architecture search (NAS) over a combinatorial space of unary and binary operators (multiply, sigmoid, tanh, max, exp, ...) composed into candidate scalar activations. Across thousands of trained child networks, the search kept converging on the same shape: \(x\cdot\sigma(\beta x)\). It generalized across image classifiers of varying depth — a strong sign the shape itself, not a lucky coincidence, was doing the work.

Self-Gating vs. Cross-Gating

Gated units like LSTMs or GLUs compute a gate from a separate projection of the input and apply it to another projection of the input — two learned paths. Swish collapses this to one path: the same scalar \(x\) is simultaneously the value being gated and the argument that produces the gate. No extra weight matrix is needed, so Swish costs the same O(1)-per-element budget as ReLU or GELU, just with one extra sigmoid evaluation.

The Role of β

\(\beta\) is either fixed at 1 (giving SiLU, used in EfficientNet's original paper and many diffusion U-Nets) or made a learnable per-channel parameter trained jointly with the network's weights via ordinary backprop. A trained β lets each channel independently choose where on the linear-to-ReLU spectrum it wants to sit — some channels stay nearly linear, others sharpen toward a ReLU-like corner, purely from gradient signal.

Practical Variant: Hard-Swish

MobileNetV3 replaces the sigmoid with a piecewise-linear ReLU6-based approximation, \(\text{h-swish}(x)=x\cdot\frac{\text{ReLU6}(x+3)}{6}\), trading a small accuracy loss for a large latency win on mobile/edge hardware where exponentials are expensive.

🔑 Key Property

Swish is smooth (C∞), non-monotonic, unbounded above and bounded below, and reduces to two familiar limits as \(\beta\) moves: \(\beta\to 0 \Rightarrow \text{Swish}\to x/2\) (linear); \(\beta\to\infty \Rightarrow \text{Swish}\to \text{ReLU}(x)\) (hard gate).

Why It Works — The Math
▼

Definition

$$\text{Swish}_\beta(x) = x\,\sigma(\beta x), \qquad \sigma(z) = \frac{1}{1+e^{-z}}$$

The Gradient

Differentiate with the product rule, using \(\sigma'(z) = \sigma(z)(1-\sigma(z))\):

$$\text{Swish}_\beta'(x) = \sigma(\beta x) + \beta x\,\sigma(\beta x)\big(1-\sigma(\beta x)\big)$$

This is often rewritten in terms of the function's own output, which is how it's implemented efficiently during backprop (the forward value is reused):

$$\text{Swish}_\beta'(x) = \beta\,\text{Swish}_\beta(x) + \sigma(\beta x)\big(1-\beta\,\text{Swish}_\beta(x)\big)$$

At \(x=0\): \(\sigma(0)=0.5\) and the second term vanishes (\(x=0\)), so \(\text{Swish}_\beta'(0)=0.5\) for every value of \(\beta\) — every member of the family passes through the origin with the same slope.

One Curve, Rescaled

Substituting \(u=\beta x\) shows \(\text{Swish}_\beta(x) = \frac{1}{\beta}g(\beta x)\) where \(g(u)=u\,\sigma(u)\) is the fixed \(\beta{=}1\) (SiLU) curve. Its derivative simplifies to \(\text{Swish}_\beta'(x) = g'(\beta x)\) — literally the same universal derivative shape, just horizontally stretched or squeezed by \(1/\beta\). This is exactly why turning the β dial "morphs" the curve: nothing about its shape changes, only how fast \(x\) sweeps through it.

The Non-Monotonic Dip

Setting \(g'(u)=0\) gives a single negative root (solved numerically): \(u^\star \approx -1.27846\), with \(g(u^\star)\approx -0.27846\). Because of the rescaling above, the dip for any \(\beta\) sits at:

$$x^\star = \frac{-1.27846}{\beta}, \qquad \text{Swish}_\beta(x^\star) \approx \frac{-0.27846}{\beta}$$

As \(\beta\to 0\), \(x^\star\to-\infty\) — the dip gets pushed off to the far left and, over any bounded window, the curve looks linear. As \(\beta\to\infty\), \(x^\star\to 0^-\) and the dip's depth shrinks toward 0 — the curve collapses onto ReLU's sharp corner at the origin.

⚠️ Common Pitfall

"Swish is monotonic like ReLU" — false for every finite β: it always dips below zero for some \(x<0\), however small. Also, "Swish = SiLU" is only true at \(\beta=1\); the general family has a tunable (often learned) β, and mixing up a fixed-β checkpoint with a different β will silently change the network's behavior.

Key Takeaways
▼

Summary: \(\text{Swish}_\beta(x)=x\sigma(\beta x)\) is a smooth, non-monotonic, self-gated activation discovered by NAS. It is a one-parameter family that interpolates between a scaled linear function (\(\beta\to0\)) and ReLU (\(\beta\to\infty\)), with \(\beta=1\) (SiLU) as the most common fixed point.

When to use: Default/strong choice for deep CNNs and mobile-efficient architectures — EfficientNet, and SiLU specifically in many diffusion model U-Nets. For extreme latency budgets on edge devices, use hard-swish. For transformer FFN blocks, GELU or gated variants (SwiGLU) are more common defaults, though SiLU is exactly the "Swi" in SwiGLU.

Code Trace
▼
import numpy as np
# Numerically stable sigmoid
def sigmoid(z):
return np.where(z >= 0,
1.0 / (1.0 + np.exp(-z)),
np.exp(z) / (1.0 + np.exp(z)))
# Forward pass: Swish_beta(x) = x * sigmoid(beta * x)
def swish(x, beta=1.0):
return x * sigmoid(beta * x)
# Backward pass, reusing the forward value (as real kernels do)
def swish_grad(x, beta=1.0):
s = sigmoid(beta * x)
swish_x = x * s
return beta * swish_x + s * (1 - beta * swish_x)
# --- Trainable-beta layer (PyTorch-style, per-channel) ---
class Swish(nn.Module):
def __init__(self, num_channels, init_beta=1.0):
super().__init__()
self.beta = nn.Parameter(torch.full((num_channels,), init_beta))
def forward(self, x): # x: (batch, channels, ...)
b = self.beta.view(1, -1, *([1] * (x.dim() - 2)))
return x * torch.sigmoid(b * x)
# beta=1.0 -> nn.SiLU() is the built-in, fused, faster equivalent
x = np.array([-3.0, -1.278, 0.0, 1.0, 2.5])
print(swish(x, beta=1.0)) # [-0.142 -0.278 0.0 0.731 2.310]
print(swish_grad(x, beta=1.0)) # [-0.088 0.0 0.5 0.928 1.099]
