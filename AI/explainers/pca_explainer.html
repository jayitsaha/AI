Principal Component Analysis (PCA)

Variance maximization, reconstruction error, and the explained variance ratio
Intermediate Classical ML Dimensionality Reduction O(min(nd², n²d))
1
Understanding PCA
▼

What is it? PCA rotates your coordinate axes to line up with the directions your data actually spreads out in. The first new axis (PC1) points along the direction of maximum variance; the second (PC2) is perpendicular to the first and captures the next-most variance, and so on. Keeping only the first few axes gives a compressed summary that loses as little spread as mathematically possible.

Analogy: Picture a cloud of fireflies shaped like a cigar, floating in a dark room. Photograph it from the side (along the cigar's long axis) and you capture almost the entire shape in a flat 2D photo. Photograph it from the end and you just see a dim circular blob — most of the structure is invisible. PCA is the algorithm that automatically finds the best "camera angle" — the axis that keeps the most information visible in fewer dimensions.

💡 If you remember one thing

PCA finds the eigenvectors of the covariance matrix. The top eigenvector is the direction of maximum variance — and projecting onto the top-k eigenvectors is simultaneously the variance-maximizing AND the reconstruction-error-minimizing choice of k-dimensional subspace: $$\hat{\beta}: \quad \Sigma v = \lambda v, \qquad \text{EVR}_k = \frac{\lambda_k}{\sum_j \lambda_j}$$

How PCA Works Internally
▼

Two Equivalent Views

Variance maximization (Hotelling, 1933): find the unit direction \(v\) that maximizes \(\operatorname{Var}(Xv) = v^\top \Sigma v\). Reconstruction-error minimization (Pearson, 1901): find the k-dimensional subspace that minimizes the squared distance between each point and its projection back into the original space. These give the identical answer.

The Pipeline

1. Center: subtract the feature-wise mean \(\bar{x}\) from every row. 2. Covariance: form \(\Sigma = X_c^\top X_c / (n-1)\). 3. Eigendecompose: \(\Sigma = V\Lambda V^\top\), sort eigenvalues \(\lambda_1 \ge \lambda_2 \ge \dots\). 4. Project: scores \(Z = X_c V_k\) using the top-k eigenvectors. 5. Reconstruct (optional): \(\hat{X} = ZV_k^\top + \bar{x}\).

$$\Sigma v = \lambda v \quad\Longrightarrow\quad v_1 = \text{top eigenvector} = \text{direction of max variance}$$

Design Decision: Why Eigendecomposition?

The objective \(v^\top \Sigma v\) subject to \(\|v\|=1\) is a quadratic form on the unit sphere. By the spectral theorem, its critical points are exactly the eigenvectors of \(\Sigma\) — no iterative optimizer needed. PCA has a closed-form, globally optimal solution, unlike most ML objectives.

🔑 Key Property

Total variance splits exactly: \(\|x_i\|^2 = \|z_i\|^2_{\text{captured}} + \|x_i - \hat{x}_i\|^2_{\text{lost}}\). Since total is fixed, maximizing captured variance and minimizing lost (reconstruction) variance are the same optimization problem.

3
Why It Works — The Math
▼

Derivation via Lagrange Multipliers

Maximize \(v^\top \Sigma v\) subject to \(v^\top v = 1\). Form the Lagrangian and set its gradient to zero:

$$\mathcal{L}(v,\lambda) = v^\top \Sigma v - \lambda(v^\top v - 1) \;\;\Longrightarrow\;\; \frac{\partial \mathcal{L}}{\partial v} = 2\Sigma v - 2\lambda v = 0$$

So \(\Sigma v = \lambda v\) — stationary points are exactly the eigenvectors. Substituting back, \(v^\top \Sigma v = \lambda\): the captured variance equals the eigenvalue. To maximize, pick the eigenvector with the largest \(\lambda\).

The SVD Route (numerically preferred)

In practice PCA is computed via the SVD of the centered data, never forming \(\Sigma\) directly (which squares the condition number):

$$X_c = USV^\top, \qquad \Sigma = \frac{X_c^\top X_c}{n-1} = V\left(\frac{S^2}{n-1}\right)V^\top, \qquad \lambda_k = \frac{s_k^2}{n-1}$$

Explained Variance Ratio

$$\text{EVR}_k = \frac{\lambda_k}{\sum_{j=1}^d \lambda_j}, \qquad \text{cumulative EVR}(k) = \frac{\sum_{j=1}^k \lambda_j}{\sum_{j=1}^d \lambda_j}$$

Whitening additionally rescales each component to unit variance: \(z_k^{white} = z_k/\sqrt{\lambda_k}\) — producing identity covariance, useful before scale-sensitive algorithms.

⚠️ Common Misconception

"PCA picks the most important features for prediction." False — PCA only ever looks at \(X\), never a target \(y\). A low-variance direction can still be the single most predictive feature; PCA is entirely unsupervised and has no way to know this.

Code Trace
▼
import numpy as np
# 1. Raw data: 10 points, 2 features
X = np.array([[2.5,2.4],[0.5,0.7],[2.2,2.9],[1.9,2.2],[3.1,3.0],
[2.3,2.7],[2.0,1.6],[1.0,1.1],[1.5,1.6],[1.1,0.9]])
# 2. Mean-center
mean = X.mean(axis=0) # [1.81, 1.91]
Xc = X - mean
# 3. Covariance matrix
cov = (Xc.T @ Xc) / (X.shape[0]-1) # [[0.617,0.615],[0.615,0.717]]
# 4. Eigendecomposition (sorted descending)
eigvals, eigvecs = np.linalg.eigh(cov)
order = np.argsort(eigvals)[::-1]
eigvals, eigvecs = eigvals[order], eigvecs[:, order]
# eigvals = [1.284, 0.049] eigvecs[:,0] = [0.678, 0.735]
# 5. Explained variance ratio
evr = eigvals / eigvals.sum() # [0.9632, 0.0368]
# 6. Project onto PC1 and reconstruct
v1 = eigvecs[:, :1] # (2,1)
scores = Xc @ v1 # (10,1) 1D projection
X_hat = scores @ v1.T + mean # reconstruction
sse = np.sum((X - X_hat)**2) # 0.4418 == (n-1)*eigvals[1]

Key Takeaways
▼

When to use PCA:

  • Fast, deterministic, interpretable linear dimensionality reduction
  • Decorrelating / whitening features before another algorithm (k-means, linear regression with multicollinearity)
  • Visualizing dominant axes of variation, with a quantified information loss (explained variance ratio)

When NOT to use:

  • Data lies on a nonlinear manifold — use Kernel PCA, UMAP, or autoencoders
  • You need a projection optimized for classification — use LDA (supervised) instead
  • You need individually-interpretable output dimensions — PCA components are linear mixtures
💡 The Hierarchy of Views

Maximize variance (Hotelling) ≡ minimize reconstruction error (Pearson) ≡ best rank-k approximation under Frobenius norm (Eckart-Young) ≡ MLE of Probabilistic PCA in the zero-noise limit. Four doors, one room.
