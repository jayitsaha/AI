Understanding Markov Decision Processes
▼

What is it? A Markov Decision Process (MDP) is a mathematical framework for modeling sequential decision-making in situations where outcomes are partly random and partly under the control of a decision maker (the "agent"). It's the foundational model for almost all Reinforcement Learning (RL).

An MDP defines an environment by specifying its possible states, the actions an agent can take in each state, the probabilities of transitioning to new states after taking an action, and the rewards received during these transitions. The goal of the agent is to learn a policy — a mapping from states to actions — that maximizes its cumulative reward over time.

Analogy: Imagine you're playing a board game. Each square is a state. Rolling the dice and moving your piece is an action. The dice roll introduces stochasticity (transition probabilities), so you don't always land where you intend. Landing on certain squares gives you rewards (e.g., drawing a "money" card) or penalties (e.g., "go to jail"). You want to play optimally to maximize your score (cumulative reward) by choosing the best move at each turn, considering future outcomes.

💡 If you remember one thing

An MDP captures the essence of an agent-environment interaction: at each step, the agent observes a state, chooses an action, the environment transitions to a new state with some probability, and the agent receives a reward. This loop repeats, and the goal is to maximize the discounted sum of future rewards.

2
How an MDP Works Internally
▼

An MDP is formally defined by a 5-tuple \((S, A, P, R, \gamma)\):

  • \(S\) (States): A finite set of possible states of the environment. E.g., positions on a chessboard, pixels in an image, or "healthy", "sick", "recovered".
  • \(A\) (Actions): A finite set of actions available to the agent in each state. E.g., "move left", "buy", "sell", "attack".
  • \(P\) (Transition Probabilities): A function \(P(s' | s, a)\) that gives the probability of transitioning to state \(s'\) from state \(s\) after taking action \(a\). This captures the stochasticity of the environment. Note the "Markov" property: the next state depends only on the current state and action, not the history of states and actions.
  • \(R\) (Reward Function): A function \(R(s, a, s')\) that specifies the immediate reward an agent receives after transitioning from state \(s\) to \(s'\) via action \(a\). Sometimes simplified to \(R(s, a)\) or even just \(R(s)\).
  • \(\gamma\) (Discount Factor): A scalar, \(\gamma \in [0, 1]\). It determines the present value of future rewards. A reward received \(k\) steps in the future is worth \(\gamma^k\) times what it would be worth if received immediately. \(\gamma=0\) means only immediate rewards matter; \(\gamma=1\) means future rewards are valued equally to immediate ones (if the process terminates).

The Agent's Goal: Maximizing Expected Return

At each time step \(t\), the agent is in state \(S_t\), chooses action \(A_t\), receives reward \(R_{t+1}\), and transitions to state \(S_{t+1}\). The agent aims to find an optimal policy \(\pi(a|s)\) (a strategy mapping states to actions) that maximizes the expected cumulative discounted reward, known as the return:

$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots = \sum_{k=0}^\infty \gamma^k R_{t+k+1}$$
🔑 Key Property

The "Markov" property is crucial: the future is conditionally independent of the past given the present state. Mathematically, \(P(S_{t+1}|S_t, A_t, S_{t-1}, A_{t-1}, \dots) = P(S_{t+1}|S_t, A_t)\). This simplifies the problem significantly, allowing dynamic programming solutions.

3
Why It Works — The Bellman Equations
▼

Value Functions: Quantifying Goodness

To find an optimal policy, we evaluate policies using value functions. A state-value function \(V^\pi(s)\) gives the expected return starting from state \(s\) and following policy \(\pi\). An action-value function \(Q^\pi(s,a)\) gives the expected return starting from state \(s\), taking action \(a\), and then following policy \(\pi\).

The core of MDP theory lies in the Bellman Equations, which decompose the value function into an immediate reward plus the discounted value of the next state:

$$V^\pi(s) = \sum_{a \in A} \pi(a|s) \sum_{s' \in S} P(s'|s,a) \left[ R(s,a,s') + \gamma V^\pi(s') \right]$$

This is the Bellman Expectation Equation for \(V^\pi(s)\). It expresses the value of a state \(s\) under policy \(\pi\) as the sum of the immediate reward from all possible actions (weighted by \(\pi(a|s)\)), plus the discounted value of the next states \(s'\) (weighted by \(P(s'|s,a)\)).

Finding the Optimal Policy

The ultimate goal is to find an optimal policy \(\pi^*\) that achieves the maximum possible value for all states, \(V^*(s) = \max_\pi V^\pi(s)\). The Bellman Equation for the optimal value function is:

$$V^*(s) = \max_{a \in A} \sum_{s' \in S} P(s'|s,a) \left[ R(s,a,s') + \gamma V^*(s') \right]$$

This is the Bellman Optimality Equation for \(V^*(s)\). It states that the value of an optimal state is the maximum over all actions of the expected immediate reward plus the discounted optimal value of the successor state. Once \(V^*(s)\) is known, the optimal policy \(\pi^*(s)\) can be found by simply choosing the action \(a\) that maximizes the quantity inside the brackets.

Similarly, for the optimal action-value function \(Q^*(s,a)\):

$$Q^*(s,a) = \sum_{s' \in S} P(s'|s,a) \left[ R(s,a,s') + \gamma \max_{a'} Q^*(s',a') \right]$$

This equation is often more directly useful for finding optimal policies, as \(\pi^*(s) = \arg\max_a Q^*(s,a)\).

⚠️ Common Pitfall

The Bellman Equations are recursive. Solving them exactly for large state/action spaces (the "curse of dimensionality") is often intractable. This is where approximation methods like Monte Carlo, Temporal Difference Learning, and deep neural networks (Deep Reinforcement Learning) come into play, estimating these values rather than computing them precisely.

Key Takeaways
▼

When to use MDPs:

  • Reinforcement Learning: The fundamental model for training agents to make sequential decisions.
  • Planning & Control: Problems where an agent needs to plan a sequence of actions to achieve a goal, especially under uncertainty (e.g., robotics, autonomous driving, game AI).
  • Operations Research: Optimizing resource allocation, scheduling, inventory management, etc., when future events are uncertain.
  • Economics & Finance: Modeling investment strategies, consumer behavior, or policy decisions over time.

When NOT to use MDPs (or when to use variants):

  • Fully Observable & Deterministic Environments: If there's no uncertainty and you always know the next state, simpler planning algorithms (e.g., A*) might suffice.
  • Continuous State/Action Spaces: While theoretically possible, solving MDPs with continuous spaces is hard. Deep Reinforcement Learning often uses function approximators (neural networks) to handle this.
  • Partial Observability: If the agent doesn't fully know the current state (e.g., only sees partial information), a Partially Observable MDP (POMDP) is a more appropriate, but much harder, model.
  • Non-Markovian Environments: If the future truly depends on the entire history, not just the current state, an MDP is a poor fit. However, careful state engineering can often "Markovianize" such problems.
💡 Big Picture

MDPs provide a powerful, mathematically rigorous framework for thinking about intelligence and decision-making in dynamic, uncertain worlds. They bridge classical AI planning with modern machine learning, laying the groundwork for agents that learn to act optimally through experience.

Code Trace (Python/NumPy)
▼
import numpy as np
# Define a simple 3x3 grid world MDP
# States: 0-8 (row-major order)
# Actions: 0=Up, 1=Down, 2=Left, 3=Right
S = 9 # Number of states
A = 4 # Number of actions
# R(s) - Reward for entering state s
rewards = -0.1 * np.ones(S) # Default step reward
rewards[2] = 10.0 # Goal state (S2)
rewards[5] = -10.0 # Lava state (S5)
# Terminal states
terminal_states = {2, 5}
# P(s' | s, a) - Transition probabilities
# P[s, a, s_prime]
P = np.zeros((S, A, S))
slip_prob = 0.2
intended_prob = 1.0 - 2 * slip_prob
# Helper to get next state for (s, a) in a deterministic grid
def get_next_det(s, action):
row, col = divmod(s, 3)
if action == 0: row = max(0, row - 1) # Up
elif action == 1: row = min(2, row + 1) # Down
elif action == 2: col = max(0, col - 1) # Left
elif action == 3: col = min(2, col + 1) # Right
return row * 3 + col
for s in range(S):
if s in terminal_states: continue # No transitions from terminal states
for a in range(A):
s_intended = get_next_det(s, a)
s_left_slip = get_next_det(s, (a + 2) % 4) # 90 deg left of intended
s_right_slip = get_next_det(s, (a + 1) % 4) # 90 deg right of intended (simplified)
P[s, a, s_intended] += intended_prob
P[s, a, s_left_slip] += slip_prob
P[s, a, s_right_slip] += slip_prob
# Example: Expected immediate reward from state 0, action Right (3)
current_state = 0
chosen_action = 3 # Right
expected_immediate_reward = sum(P[current_state, chosen_action, s_prime] * rewards[s_prime] for s_prime in range(S))
print(f"Expected immediate reward from S{current_state} with action {chosen_action}: {expected_immediate_reward:.2f}")
# Policy Evaluation (one step for V(s))
gamma = 0.9
V = np.zeros(S) # Initial value estimates
policy = np.full(S, chosen_action) # Simple policy: always go Right
new_V = np.zeros(S)
for s in range(S):
if s in terminal_states: continue
a = policy[s]
for s_prime in range(S):
prob = P[s, a, s_prime]
new_V[s] += prob * (rewards[s_prime] + gamma * V[s_prime]) # Bellman Expectation
print(f"Value of S0 after one policy evaluation step (V0=0): {new_V[0]:.2f}")
