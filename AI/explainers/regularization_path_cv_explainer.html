Regularization Path & CV for λ Selection

How coefficient shrinkage unfolds across λ and how cross-validation picks the optimal penalty
Intermediate Classical ML · Regression Part III · Section 9
1
Understanding the Concept
▾

Regularization adds a penalty term to the regression loss function to shrink coefficients toward zero, trading some bias for a large reduction in variance. The key hyperparameter is λ (lambda) — the penalty strength. Too large a λ and the model is too simple (underfitting); too small and it overfits.

Core Intuition

The regularization path is the full set of solutions \(\hat{\beta}(\lambda)\) traced as λ sweeps from ∞ (all zeros) to 0 (OLS). It answers "how do coefficients enter and grow?" in one efficient computation. Cross-validation then picks the λ that minimizes held-out prediction error.

Real-world analogy: Imagine a search committee ranking candidates (predictors). A very strict budget (large λ) means only the single best candidate gets hired. As the budget relaxes (smaller λ), more candidates are brought on board. The CV error curve tells you the optimal budget — the point where adding more employees stops improving performance and just adds noise.

If You Remember One Thing

The Lasso path is piecewise-linear in λ and can be computed for all λ values in a single LARS pass — roughly the same cost as one OLS fit. Cross-validation on this path gives you both λ_min (best accuracy) and λ_1se (best parsimony).

2
The Regularization Path
▾

The Lasso objective is:

$$\hat{\beta}(\lambda) = \underset{\beta}{\operatorname{argmin}} \left\{ \frac{1}{2n}\|y - X\beta\|_2^2 + \lambda\|\beta\|_1 \right\}$$

At \(\lambda_{\max} = \frac{1}{n}\|X^\top y\|_\infty\), all coefficients are exactly zero (the subdifferential condition is just barely not violated). As λ decreases from this value, variables enter the model one at a time — always the one most correlated with the current residual.

LARS: Computing the Full Path Efficiently

The Least Angle Regression Stagewise (LARS) algorithm by Efron et al. (2004) exploits a key structural property: the Lasso path is piecewise-linear. Between "knots" (values of λ where a variable enters or leaves the active set), all active coefficients change at constant rates. LARS finds these knots analytically:

  1. Find the predictor \(X_j\) most correlated with the current residual \(r = y - X\hat{\beta}\).
  2. Move \(\hat{\beta}\) in the equi-angular direction until another predictor becomes equally correlated with \(r\).
  3. Add that predictor; repeat. The path is piecewise-linear between these join points.
Piecewise Linearity

Between consecutive knots \(\lambda_{k+1} < \lambda \leq \lambda_k\), the active set \(\mathcal{A}\) is constant and:

$$\hat{\beta}_{\mathcal{A}}(\lambda) = (X_{\mathcal{A}}^\top X_{\mathcal{A}})^{-1}(X_{\mathcal{A}}^\top y - n\lambda \cdot s_{\mathcal{A}})$$

where \(s_j = \operatorname{sign}(\hat{\beta}_j)\). This is linear in λ — hence the piecewise-linear path.

Warm-Start Coordinate Descent Alternative

For large p, coordinate descent at each λ value on a fine grid, initialized from the previous solution (warm start), is equally efficient and more numerically robust. sklearn's lasso_path() uses this approach. Because each warm-started optimization converges in very few iterations, the total cost across 100 λ values is ≈ 10× a single cold-start fit.

Important: Ridge Has No Exact Path Algorithm

Ridge regression coefficients change smoothly with λ (no zeros until λ=∞), so there are no knots. The "ridge path" is simply the closed-form \(\hat{\beta}_{ridge}(\lambda) = (X^\top X + n\lambda I)^{-1}X^\top y\), evaluated on a grid. The LARS efficiency gain is specific to L1 (Lasso) or L1+L2 (Elastic Net with the LARS-EN variant).

3
Cross-Validation for λ Selection
▾

Once we have the path \(\{\hat{\beta}(\lambda_k)\}_{k=1}^K\) on a grid, we use K-fold cross-validation to estimate prediction error at each λ without a separate test set.

The K-Fold CV Procedure

  1. Partition the n observations into K folds of roughly equal size.
  2. For each fold j and each λ: fit the model on the other K−1 folds, predict on fold j.
  3. Compute hold-out MSE for fold j: \(\text{MSE}_j(\lambda) = \frac{1}{n_j}\sum_{i \in \text{fold}_j}(y_i - \hat{y}_i(\lambda))^2\).
  4. Average: \(\overline{\text{CV}}(\lambda) = \frac{1}{K}\sum_{j=1}^K \text{MSE}_j(\lambda)\).
$$\overline{\text{CV}}(\lambda) = \frac{1}{K}\sum_{j=1}^K \frac{1}{n_j}\sum_{i\in\text{fold}_j}\!\!\left(y_i - x_i^\top \hat{\beta}^{(-j)}(\lambda)\right)^2$$

Two λ Selection Rules

λ_min — the λ that minimizes \(\overline{\text{CV}}(\lambda)\). Best raw predictive accuracy. In our example: λ_min = 0.026, CV-MSE = 0.353.

λ_1se (One-Standard-Error Rule) — select the largest λ whose CV error falls within one standard error of the minimum:

$$\lambda_{1\text{se}} = \max\left\{\lambda : \overline{\text{CV}}(\lambda) \leq \overline{\text{CV}}(\lambda_{\min}) + \frac{\widehat{\text{SD}}\left[\overline{\text{CV}}(\lambda_{\min})\right]}{\sqrt{K}}\right\}$$

In our example: λ_1se = 0.067, which correctly zeros out the three true-zero predictors (β₄, β₅, β₇) while retaining the five signals. The 1-SE rule prefers parsimony over minimal CV error.

U-Shaped CV Curve — Why?

Large λ (left on log scale going right → small): high bias, underfitting — CV error is large.
Optimal λ (middle): bias-variance trade-off balanced — CV error is minimized.
Small λ (right on reverse-log scale): high variance, overfitting — CV error starts increasing again.

Common Gotcha: One-SE Rule Direction

The 1-SE rule picks the largest λ satisfying the threshold — NOT the smallest. Since Lasso has fewer nonzero coefficients at larger λ, the 1-SE rule always yields a sparser model than λ_min. The "largest" here means most regularization, not least.

Key Takeaways
▾
  • Compute once, evaluate everywhere: LARS / warm-start CD computes \(\hat{\beta}(\lambda)\) for all λ in O(np·min(n,p)) time — the same as one OLS fit.
  • Two operating points: λ_min maximises predictive accuracy; λ_1se maximises parsimony. Always report both.
  • K=5 or K=10 folds are standard. Larger K → less bias in CV estimate but more variance and computation.
  • Standardise predictors before Lasso: the L1 penalty is not scale-invariant, so β̂ values depend on units.
  • Elastic Net = L1 + L2 penalty; its path can also be computed via LARS-EN, combining sparsity (Lasso) with grouping (Ridge).
Decision Rule

Use λ_min when prediction accuracy is the priority (e.g., Kaggle competitions). Use λ_1se when you need an interpretable, deployable model (e.g., clinical risk scores, policy models). When in doubt, report both and document the model sizes.
