Robust Scaling (IQR-Based)

Outlier-resistant feature normalization using median & interquartile range

Foundational Classical ML Feature Engineering O(n log n)
1
Understanding the Concept
▾

What is this? Many ML algorithms work best when features are on a similar numerical scale. Robust Scaling shifts each feature so its median becomes 0, then divides by the interquartile range (IQR = Q3 − Q1). Because median and IQR are computed from the middle 50% of data, extreme values (outliers) barely affect the result.

💡 Everyday Analogy

Imagine grading students on a curve. Standard scaling (z-score) uses the class average, so one student who scored 1000/100 would drag the mean up wildly. Robust scaling uses the median grade — if half the class scored 70–80, that range anchors everything, and the one 1000-scorer is just ignored as a curiosity.

The formula:

$$x_{\text{scaled}} = \frac{x - \text{median}(X)}{Q_3(X) - Q_1(X)}$$
🔑 Key Invariant

After robust scaling: the median of the transformed feature = 0, and the IQR = 1. The spread of outliers in the original data does not affect these anchor values.

⚠️ vs. Z-Score (Standard Scaling)

Z-score uses mean & std-dev — both are pulled hard by outliers. If your feature is [1, 2, 3, 4, 1000], the mean is 202 and std is 396. The scaled "normal" values all cluster near −0.5, while the outlier is at +2. Robust scaling keeps 1–4 spread across −1 to +1 where they belong.

How It Works Internally
▾

Robust scaling has two phases: fit (compute statistics from training data) and transform (apply to any dataset).

Phase 1 — Fit (training data only):

  1. Sort the feature vector \(X = [x_1, \ldots, x_n]\) in ascending order.
  2. Compute \(\text{median} = \text{percentile}(X, 50)\)
  3. Compute \(Q_1 = \text{percentile}(X, 25)\) and \(Q_3 = \text{percentile}(X, 75)\)
  4. Store \(\text{center} = \text{median}\), \(\text{scale} = Q_3 - Q_1\)

Phase 2 — Transform:

$$x_i' = \frac{x_i - \text{center}}{\text{scale}}$$

Numerical trace with a contaminated dataset:

Feature (income in $k): \(X = [30, 35, 40, 45, 50, 55, 60, 500]\)

# Q3 = avg(6th, 7th) = (55+60)/2 = 57.5
# IQR = 57.5 - 37.5 = 20.0
# Robust scaled: x' = (x - 47.5) / 20

💡 Design Decision

Why median instead of mean? Median has a breakdown point of 50% — up to half your data can be extreme values before the median is affected. Mean has a breakdown point of 0% (a single outlier can move it arbitrarily).

3
Why It Works — The Statistical Guarantee
▾

Robustness is measured by breakdown point — the fraction of contaminated observations an estimator can tolerate before giving an arbitrarily bad result.

Estimator Center Spread Breakdown point Outlier sensitivity
Standard (Z-score) Mean \(\bar{x}\) Std \(\sigma\) 0% — one outlier breaks it High
Robust (IQR) Median IQR = Q3−Q1 50% — up to half can be junk Low
MinMax Min Max−Min 0% — one outlier collapses range Extreme

Influence function: The influence function measures how much adding one extreme point \(x \to \infty\) changes the estimator. For the mean: influence grows without bound \(\to \infty\). For the median: influence is bounded at \(\frac{1}{2f(m)}\) where \(f\) is the density at median \(m\) — a finite constant.

Similarly, IQR's influence function is bounded (depends only on density at Q1 and Q3), while std-dev's influence grows linearly with the outlier's magnitude.

📐 Influence Function

For the sample mean \(\bar{x}_n\), adding one outlier at \(t\):

$$IF(t; \bar{x}, F) = t - \mu \;\to\; \infty \text{ as } t \to \infty$$

For the median \(m\):

$$IF(t; m, F) = \frac{\text{sgn}(t - m)}{2f(m)} \;\text{ (bounded)}$$

Key Takeaways & When to Use
▾

Use Robust Scaling when:

  • Your feature distribution has heavy tails, known outliers, or you can't clip them
  • You're using distance-based algorithms (KNN, SVM, k-means) sensitive to scale
  • You prefer not to remove outliers from training data (e.g., fraud detection)

Avoid Robust Scaling when:

  • Your data is truly Gaussian — z-score is slightly more efficient (uses all information)
  • You're feeding into tree-based models (Random Forest, XGBoost) — they don't need scaling at all
  • IQR = 0 (e.g., a feature is constant or nearly constant for 50%+ of samples) — division by zero
🎯 Quick Decision Rule

Outliers present & can't remove? → Robust scaling. Clean Gaussian data? → Z-score. Hard known bounds? → MinMax. Tree model? → No scaling needed.

from sklearn.preprocessing import RobustScaler
import numpy as np
X = np.array([[30],[35],[40],[45],[50],[55],[60],[500]])
scaler = RobustScaler(quantile_range=(25.0, 75.0)) # default IQR
X_scaled = scaler.fit_transform(X)
