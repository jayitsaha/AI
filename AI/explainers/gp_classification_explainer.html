GP Classification: Laplace Approximation & Variational Inference

Taming an intractable posterior over a latent Gaussian Process squashed through a sigmoid
Foundational Bayesian ML Gaussian Processes O(n³) per iteration
1
Understanding GP Classification
▼

What is it? Gaussian Process (GP) regression puts a prior directly over functions and gives you exact Gaussian posteriors in closed form. Classification breaks that closed form: instead of observing noisy real-valued y, we observe binary labels. We still place a GP prior over a hidden ("latent") function \(f(x)\), but we squash it through a sigmoid (or probit) link before it produces a probability of class membership, \(p(y=1\mid x) = \sigma(f(x))\).

Analogy: Imagine a smooth, invisible "confidence surface" \(f(x)\) that can be any real number — very negative means "definitely class 0," very positive means "definitely class 1," near zero means "unsure." We never observe this surface directly, only coin-flip outcomes generated by squashing it into a probability. GP classification tries to infer the invisible surface from the coin flips.

💡 If you remember one thing

Because the Bernoulli likelihood is not conjugate to the Gaussian prior, the exact posterior \(p(f\mid y)\) has no closed form. Laplace approximation and variational inference are the two classic recipes for replacing that intractable posterior with a tractable Gaussian: $$p(f\mid y) \;\approx\; \mathcal{N}\!\big(f;\, m,\, S\big)$$ Laplace matches curvature at the mode; VI matches an optimized lower bound on the evidence.

2
How It Works Internally
▼

The Generative Story

Place a GP prior on the latent function: \(f \sim \mathcal{GP}(0, k(\cdot,\cdot))\), so at any finite set of inputs \(f = (f_1,\dots,f_n)\) is jointly Gaussian, \(f \sim \mathcal{N}(0, K)\), with \(K_{ij}=k(x_i,x_j)\). Labels are generated independently given \(f\): \(p(y_i=1\mid f_i) = \sigma(f_i) = 1/(1+e^{-f_i})\). The joint posterior we want is

$$p(f \mid y) = \frac{p(y\mid f)\,p(f)}{p(y)} = \frac{1}{p(y)}\underbrace{\left[\prod_i \sigma(f_i)^{y_i}(1-\sigma(f_i))^{1-y_i}\right]}_{\text{Bernoulli likelihood}}\underbrace{\mathcal{N}(f;0,K)}_{\text{GP prior}}$$

The Gaussian prior and the sigmoid likelihood do not multiply into another Gaussian, and the normalizer \(p(y)=\int p(y\mid f)p(f)\,df\) has no closed form either. We need an approximation.

Route 1 — Laplace Approximation

Find the mode \(\hat f = \arg\max_f \log p(f\mid y)\) with Newton's method, then take a 2nd-order Taylor expansion of \(\log p(f\mid y)\) around \(\hat f\). The quadratic term defines a Gaussian: mean at the mode, covariance equal to the inverse curvature (negative Hessian) there. It is a *local* approximation — cheap, but blind to posterior skew away from the mode.

Route 2 — Variational Inference

Pick a tractable family \(q(f)=\mathcal{N}(m,S)\) and push it as close as possible to the true posterior by maximizing the Evidence Lower Bound (ELBO), $$\mathrm{ELBO}(q) = \mathbb{E}_q[\log p(y\mid f)] - \mathrm{KL}(q(f)\,\|\,p(f)) \;\le\; \log p(y).$$ Unlike Laplace, VI optimizes a *global* objective over the whole distribution, not just curvature at one point — but it needs the expected log-likelihood, which for a sigmoid is itself intractable, so a further trick (a local quadratic bound on the sigmoid) is used to keep every update in closed form.

🔑 Key Property

Both methods return a Gaussian pair \((m, S)\) as a stand-in for \(p(f\mid y)\). Everything downstream — predictive probabilities, decision boundaries, calibrated uncertainty bands — is a deterministic function of this \((m,S)\), which is exactly why the interactive walkthrough below tracks these two numbers at every step.

3
Why It Works — The Math
▼

Laplace: Newton's Method on the Log Posterior

Let \(\Psi(f) = \log p(y\mid f) + \log p(f) = \sum_i \big[y_if_i - \log(1+e^{f_i})\big] - \tfrac12 f^\top K^{-1}f + c\). Its gradient and Hessian are

$$\nabla\Psi = (y-\pi) - K^{-1}f, \qquad \nabla\nabla\Psi = -W - K^{-1}, \quad W=\mathrm{diag}\big(\pi_i(1-\pi_i)\big),\ \ \pi_i=\sigma(f_i)$$

Newton's update \(f^{\text{new}} = f - (\nabla\nabla\Psi)^{-1}\nabla\Psi\) simplifies to

$$f^{\text{new}} = \big(K^{-1}+W\big)^{-1}\Big(Wf + (y-\pi)\Big)$$

Iterating this converges to the mode \(\hat f\). The Laplace covariance is then read straight off the curvature: \(S_{\text{Laplace}} = (K^{-1}+W)^{-1}\big|_{f=\hat f}\) — literally "the inverse of how sharply the log-posterior curves down around its peak."

Variational Inference: The Jaakkola–Jordan Bound

\(\log\sigma(f)\) has no Gaussian-friendly expectation, but it admits a tight local quadratic lower bound at any variational parameter \(\xi\):

$$\log \sigma(f) \ge \log\sigma(\xi) + \frac{f-\xi}{2} - \lambda(\xi)(f^2-\xi^2), \qquad \lambda(\xi)=\frac{1}{4\xi}\tanh\!\Big(\frac{\xi}{2}\Big)$$

Plugging this bound in for every data point turns the expected log-likelihood into a quadratic form in \(f\), so the ELBO becomes analytically maximizable in closed form for fixed \(\xi\), giving coordinate-ascent updates:

$$S^{-1} = K^{-1} + 2\Lambda,\quad \Lambda=\mathrm{diag}(\lambda(\xi_i)) \qquad m = S\,t,\quad t_i = y_i-\tfrac12 \qquad \xi_i^2 = S_{ii}+m_i^2$$

Alternating these three lines is guaranteed to never decrease the ELBO (it is coordinate ascent on a concave-in-each-block objective), so it monotonically climbs toward a local optimum — this is the "optimizing an ELBO" step the walkthrough visualizes directly with real numbers.

⚠️ Common Pitfall

Laplace's covariance comes purely from local curvature — if the true posterior is skewed (common near a mislabeled point), Laplace's symmetric Gaussian can be overconfident or miscentered. VI's bound-based Gaussian is often better calibrated in the tails but can still underestimate variance because it optimizes \(\mathrm{KL}(q\|p)\) — the "mode-seeking," variance-shrinking direction of KL divergence, not the moment-matching direction.

When to reach for GP classification: small-to-medium datasets where calibrated, non-parametric decision boundaries with honest uncertainty matter more than raw speed — e.g. active learning, Bayesian optimization over categorical outcomes, medical risk scoring.

💡 Hierarchy

GP regression (Gaussian likelihood, exact) is the special case where no approximation is needed. GP classification (Bernoulli likelihood) always needs one of: Laplace (local, fast) → Variational (global objective, closed-form updates via the JJ bound, or modern stochastic ELBO with reparameterization) → MCMC / Expectation Propagation (most accurate, most expensive).

d2 = (x1[:, None] - x2[None, :]) ** 2
return sf2 * np.exp(-0.5 * d2 / ls2)

Kinv = np.linalg.inv(K)

for _ in range(5):
pi = sigmoid(f)
W = pi * (1 - pi)
M = Kinv + np.diag(W)
rhs = W * f + (y - pi)
f = np.linalg.solve(M, rhs) # f_new = (Kinv + W)^-1 (Wf + (y - pi))
f_hat = f
Sigma_laplace = np.linalg.inv(Kinv + np.diag(sigmoid(f_hat) * (1 - sigmoid(f_hat))))
# --- Variational inference: Jaakkola-Jordan coordinate ascent ---
xi = np.ones_like(y)
for _ in range(8):
lam = np.tanh(xi / 2) / (4 * xi + 1e-12)
S = np.linalg.inv(Kinv + np.diag(2 * lam))
m = S @ (y - 0.5)
xi = np.sqrt(np.diag(S) + m ** 2) # re-tighten the bound
# --- predictive probability at a new point x* (both methods) ---
def predict(xstar, m, S):
kstar = kernel(np.array([xstar]), x)[0]
a = Kinv @ kstar
mean = kstar @ (Kinv @ m)
var = kernel([xstar],[xstar])[0,0] - kstar@a + kstar@(Kinv@(S@a))
kappa = 1.0 / np.sqrt(1 + np.pi * var / 8)
return sigmoid(kappa * mean) # MacKay's probit-corrected squash
