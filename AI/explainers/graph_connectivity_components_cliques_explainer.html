Understanding Graph Connectivity
▼

What is it? A graph is a set of nodes (vertices) and edges (connections). Connectivity asks: which nodes can reach each other? A connected component is a maximal group of nodes where every pair is reachable. In social networks, components reveal isolated communities. In road maps, a disconnected component means a driver can never reach certain cities.

Analogy: Think of islands and bridges. Each island-cluster reachable from one another (via bridges) is a connected component. If you stand on island A and can walk to island B by crossing bridges, you are in the same component. A lone island with no bridges at all is its own component of size 1.

Directed graphs introduce a subtlety: you can reach B from A but not A from B. A strongly connected component (SCC) requires mutual reachability — you can travel from any node to any other node within the SCC following directed edges. Tarjan's (1972) and Kosaraju's (1978) algorithms find SCCs in linear time \(O(V + E)\).

A clique is a subset of nodes where every pair is connected — the densest possible local structure. The maximum clique problem (find the largest clique) is NP-hard: the best known exact algorithms are exponential in the worst case, though practical branch-and-bound approaches work well on sparse graphs.

The k-core of a graph is the maximal subgraph where every node has degree at least \(k\). Peeling k-cores (progressively removing low-degree nodes) reveals the dense nucleus of a network and is a key tool in community detection and network resilience analysis.

💡 If you remember one thing

Connectivity is the most fundamental graph property. Connected components partition an undirected graph; SCCs partition a directed graph. Cliques capture maximum local density; k-cores capture global cohesion. All four concepts underpin community detection in social networks, circuit analysis, and compiler optimizations (via dominance trees built on SCCs).

Algorithms — How They Work Internally
▼

Connected Components (Undirected) — BFS/DFS in \(O(V+E)\)

Mark every node unvisited. Pick any unvisited node, run BFS/DFS to mark all reachable nodes — these form one component. Repeat for the next unvisited node. The algorithm naturally partitions \(V\) into disjoint sets. Union-Find (Disjoint Set Union, DSU) offers an online alternative: process edges one by one and union endpoints.

Strongly Connected Components — Tarjan's Algorithm

Tarjan's (1972) algorithm uses one DFS pass with a stack and two arrays: disc (discovery time) and low (lowest disc reachable via back/cross edges). A node \(u\) is the root of an SCC when low[u] == disc[u] — at that moment, pop everything on the stack down to (and including) \(u\); those nodes form one SCC.

$$\text{low}[u] = \min\bigl(\text{disc}[u],\; \min_{(u,v) \in E,\, v \in \text{stack}} \text{low}[v]\bigr)$$

Kosaraju's (1978) uses two DFS passes: (1) DFS on the original graph, pushing nodes to a stack in finish order; (2) transpose the graph; (3) DFS on the transposed graph in reverse finish order — each DFS tree in pass 2 is an SCC. Both run in \(O(V+E)\).

Cliques and Maximum Clique

A clique of size \(k\) (a \(K_k\)) requires all \(\binom{k}{2}\) edges present. The Bron–Kerbosch algorithm (1973) finds all maximal cliques by recursive backtracking with pruning. The maximum clique problem is NP-hard; it is equivalent to the maximum independent set on the complement graph. For random Erdős–Rényi graphs \(G(n,1/2)\), the clique number is approximately \(2\log_2 n\).

k-Core Decomposition — Peeling in \(O(V+E)\)

The coreness of node \(v\) is the largest \(k\) such that \(v\) belongs to the \(k\)-core. Compute it by repeatedly removing all nodes with degree below the current threshold:

  1. Compute degrees. Start with \(k=1\).
  2. Remove all nodes with degree \(< k\). Update neighbors' degrees.
  3. Increment \(k\); repeat until no more nodes remain.

The sequence of peeling gives the coreness of every node in \(O(V+E)\) total time.

🔑 Key Invariant

In a directed graph, SCCs partition \(V\) into a directed acyclic graph (DAG) of components — the condensation DAG. This is the master structure for problems like topological sort, 2-SAT, and Kosaraju-based reachability. Each SCC is a maximal set where all nodes are mutually reachable.

The Math Behind It
▼

Graph Connectivity via Adjacency & Laplacian

Let \(G = (V, E)\) with \(|V| = n\). The adjacency matrix \(A \in \{0,1\}^{n \times n}\) has \(A_{ij} = 1\) iff \((i,j) \in E\). The number of walks of length \(\ell\) from \(i\) to \(j\) equals \((A^\ell)_{ij}\). Node \(i\) and \(j\) are connected iff \(\exists \ell \geq 0\) with \((A^\ell)_{ij} > 0\).

The graph Laplacian \(L = D - A\) (where \(D = \operatorname{diag}(\deg(v))\)) has profound connectivity properties:

$$L_{ij} = \begin{cases} \deg(v_i) & i = j \\ -1 & (i,j) \in E \\ 0 & \text{otherwise} \end{cases}$$

By the Matrix-Tree theorem (Kirchhoff 1847), the number of spanning trees of \(G\) equals any cofactor of \(L\), equivalently \(\frac{1}{n} \prod_{i=1}^{n-1} \lambda_i\) where \(\lambda_1 \leq \cdots \leq \lambda_{n-1}\) are the non-zero eigenvalues of \(L\). Most importantly:

📐 Spectral Connectivity

The number of connected components of \(G\) equals the multiplicity of eigenvalue 0 in \(L\). Specifically, \(\lambda_1 = 0\) always; \(\lambda_2 > 0\) iff \(G\) is connected. The second-smallest eigenvalue \(\lambda_2\) is the algebraic connectivity (Fiedler value) — larger means harder to disconnect.

$$\#\text{components}(G) = \dim(\ker(L)) = \text{mult}(0, L)$$

Clique Number and Ramsey Theory

The clique number \(\omega(G)\) satisfies \(\omega(G) \leq \chi(G)\) (chromatic number). The Ramsey number \(R(k, k)\) guarantees that any graph on \(n \geq R(k,k)\) nodes contains a clique or independent set of size \(k\). It grows as \(R(k,k) \leq 4^k\); the exact values are known only for small \(k\) (e.g., \(R(3,3)=6\), \(R(4,4)=18\)).

The expected clique number in \(G(n, 1/2)\):

$$\omega(G(n, 1/2)) \approx 2 \log_2 n - 2 \log_2 \log_2 n + O(1)$$

k-Core and Degeneracy

The degeneracy \(\delta^*(G) = \max_k k\text{-core exists}\) bounds the clique number: \(\omega(G) \leq \delta^*(G) + 1\). This is the basis for efficient branch-and-bound maximum clique algorithms.

⚠️ NP-hardness of Maximum Clique

The decision problem "does \(G\) have a clique of size \(k\)?" is NP-complete (Karp 1972). Moreover, it is hard to approximate within factor \(n^{1-\varepsilon}\) for any \(\varepsilon > 0\) under standard complexity assumptions (Håstad 1999, Zuckerman 2007). In practice, branch-and-bound with k-core pruning (e.g., Bron–Kerbosch with degeneracy ordering) is remarkably fast on real-world sparse graphs.

Applications

  • Community detection: Louvain/Leiden algorithms use modularity over components/cores
  • Compiler design: SCCs of the call graph identify mutually recursive function groups
  • 2-SAT: Build implication graph; solution exists iff no SCC contains both \(x\) and \(\neg x\)
  • Social networks: k-core decomposition reveals influential users (high-coreness hubs)
  • Bioinformatics: Protein interaction networks — cliques suggest functional complexes
  • Web graph: Giant SCC of the web contains ~56% of pages; bow-tie model (Broder et al. 2000)
💡 Interview tip

Connected components → DFS/BFS in \(O(V+E)\). SCCs → Tarjan's (single DFS) or Kosaraju's (two DFS + transpose). Clique → NP-hard, mention Bron–Kerbosch + pruning. k-core → peeling in \(O(V+E)\). Know the Laplacian eigenvalue characterisation of connectivity for ML/spectral interviews.

Connected Components (BFS, Python)

from collections import deque
def connected_components(adj: dict[int, list[int]]) -> list[list[int]]:
"""Return list of connected components (BFS). adj is adjacency list."""
visited = set()
components = []
for start in adj:
if start in visited: continue
comp, queue = [], deque([start])
visited.add(start)
while queue:
u = queue.popleft()
comp.append(u)
for v in adj[u]:
if v not in visited:
visited.add(v); queue.append(v)
components.append(comp)
return components

Tarjan's SCC (Python, iterative)

def tarjan_scc(adj: dict[int, list[int]]) -> list[list[int]]:
"""Tarjan's SCC algorithm — O(V+E). Returns list of SCCs."""
index_counter = [0]
disc, low, on_stack = {}, {}, {}
stack, sccs = [], []
def dfs(v):
disc[v] = low[v] = index_counter[0]
index_counter[0] += 1
stack.append(v); on_stack[v] = True
for w in adj.get(v, []):
if w not in disc: # tree edge
dfs(w)
low[v] = min(low[v], low[w])
elif on_stack.get(w): # back edge
low[v] = min(low[v], disc[w])
if low[v] == disc[v]: # v is SCC root
scc = []
while True:
w = stack.pop(); on_stack[w] = False; scc.append(w)
if w == v: break
sccs.append(scc)
for v in adj:
if v not in disc: dfs(v)
return sccs

k-Core Decomposition (Python)

def k_core_decomposition(adj: dict[int, list[int]]) -> dict[int, int]:
"""Returns coreness (max k such that node is in k-core) for each node."""
deg = {v: len(adj[v]) for v in adj}
coreness = {}
remaining = set(adj.keys())
k = 0
while remaining:
changed = True
while changed:
changed = False
to_remove = [v for v in remaining if deg[v] <= k]
for v in to_remove:
coreness[v] = k
remaining.remove(v)
for u in adj[v]: # update neighbor degrees
if u in remaining: deg[u] -= 1
changed = True
k += 1
return coreness
