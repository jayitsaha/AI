Part III: Classical ML › 1.3.6 Handling Class Imbalance

BalancedBaggingClassifier

Ensemble bagging with per-bag majority-class undersampling — balanced data, no minority signal lost.

Intermediate Classical ML Imbalanced Data Ensemble Methods O(n · T) train
1
Understanding the Concept

What is this? When your dataset has far more examples of one class (majority) than another (minority), most classifiers learn to just predict the majority class — it's the easiest way to get high accuracy. BalancedBaggingClassifier fixes this by building many small models (a "bag" per model), where each bag sees a randomly undersampled version of the majority class so that both classes are equally represented. The final prediction is a vote across all bags.

Real-World Analogy. Imagine you're training 10 fraud-detection inspectors. You have 9,500 legitimate transactions and only 500 fraud cases. Instead of showing all 10 inspectors the same massive pile (where fraud is buried), you give each inspector a balanced mini-deck: 500 fraud cases + 500 randomly selected legitimate ones. Each inspector sees balanced evidence. Their collective vote is smarter than any single inspector trained on the skewed pile.

💡 If You Remember One Thing
Each bootstrap bag draws all minority samples + a random undersample of the majority class, so every base learner trains on class-balanced data — without globally discarding any minority examples.
2
How It Works Internally

Standard bagging draws a bootstrap sample of size \(n\) from the full dataset (with replacement), keeping the original class ratio. With imbalance ratio 19:1, each bag still sees ~95% majority. BalancedBaggingClassifier changes the sampling step:

$$\text{For bag } t = 1, \ldots, T:$$ $$B_t = \text{AllMinority} \;\cup\; \text{Undersample}(\text{Majority}, |\text{Minority}|)$$
  • AllMinority — every minority-class sample is eligible for each bag (sampled with replacement by default).
  • Undersample(Majority, k) — draw exactly \(k = |\text{Minority}|\) majority samples uniformly at random (with or without replacement, controlled by replacement parameter).
  • Each bag \(B_t\) has size \(2k\) and a 50/50 class split.
  • Train base estimator \(h_t\) on \(B_t\).
  • Final prediction: majority vote (classification) or average (probability).
Key Invariant
No minority example is ever globally discarded. Each bag discards a different random subset of majority examples, so across all T bags the model has seen all majority samples multiple times — just not all at once.

The diversity between bags comes from two sources: (1) different random draws of majority samples, and (2) bootstrap resampling of minority samples. This diversity is what makes the ensemble error lower than any single balanced model.

3
Why It Works — The Math

Let \(n^+ = |\text{Minority}|\), \(n^- = |\text{Majority}|\), and imbalance ratio \(\rho = n^- / n^+\). Each bag has size \(m = 2n^+\).

Expected coverage of majority class across T bags. Each bag samples \(n^+\) majority points without replacement from \(n^-\). The probability that a specific majority point is missed by one bag is:

$$P(\text{point missed by bag } t) = 1 - \frac{n^+}{n^-} = 1 - \frac{1}{\rho}$$

Probability it is missed by all T bags:

$$P(\text{missed by all}) = \left(1 - \frac{1}{\rho}\right)^T$$

For \(\rho = 10\), \(T = 10\): \((0.9)^{10} \approx 0.35\). For \(T = 50\): \((0.9)^{50} \approx 0.005\). So with enough estimators, virtually every majority point is seen at least once.

Bias–Variance under balanced sampling. Undersampling reduces the effective training size per learner, increasing variance. Bagging variance reduction formula:

$$\text{Var}(\bar{h}) = \rho_{\text{corr}} \cdot \sigma_h^2 + \frac{1-\rho_{\text{corr}}}{T} \cdot \sigma_h^2$$

where \(\rho_{\text{corr}}\) is pairwise correlation between base learners. The key insight: diversity (low \(\rho_{\text{corr}}\)) from different undersamplings reduces ensemble variance even as each individual learner has higher variance from smaller bags.

Numerical Example
Dataset: 1000 majority (class 0), 100 minority (class 1). \(\rho = 10\), T = 10 bags.
Each bag: 100 minority + 100 randomly drawn majority = 200 samples, 50/50 split.
A plain bagging bag of same size 200: ~182 majority + 18 minority = 91/9 split.

⚠️ Common Gotcha
With replacement=False (default for majority sampling), if \(T\) is too large relative to \(\rho\), the same majority subset is drawn repeatedly — limiting diversity. Increase n_estimators or use replacement=True for large imbalance ratios.
  • Use BalancedBaggingClassifier when: \(\rho > 5\), minority class matters most (fraud, disease, fault detection).
  • Prefer SMOTE when: minority class is tiny (< 50 examples) and you need data augmentation.
  • Key metric: always evaluate with F1-minority, AUC-PR, or MCC — not accuracy.
