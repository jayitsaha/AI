Node Classification: Semi-Supervised Learning

Leveraging graph structure and limited labels for robust classification (Cora, Citeseer, PubMed)
Foundational Graph ML Semi-supervised O(L·E·F)
1
Understanding Node Classification
▼

What is it? Node classification is the task of assigning a category or label to each node in a graph. Unlike typical classification problems where data points are independent, here nodes are connected, and these connections provide crucial information. In a semi-supervised setting, we only have labels for a small subset of nodes, and the goal is to accurately predict the labels for all other (unlabeled) nodes.

Analogy: Imagine a vast network of academic papers (nodes), with citations (edges) linking them. Each paper has a text abstract (features). We want to classify each paper by its research area (label: e.g., "AI", "Databases", "Theory"). We only have the research area for a handful of papers. Semi-supervised node classification uses the text content and the citation patterns to infer the research area for all other papers.

💡 If you remember one thing

The core assumption is homophily: connected nodes tend to share similar properties, including their labels. This means information (like labels or features) can be "smoothed" or "propagated" across the graph to infer labels for unlabeled nodes.

2
How Graph Neural Networks Work
▼

Inputs: Graph, Features, Partial Labels

A typical node classification problem involves three main inputs:

  1. Graph Structure: Represented by an adjacency matrix \(A \in \{0,1\}^{N \times N}\), where \(N\) is the number of nodes. \(A_{ij}=1\) if nodes \(i\) and \(j\) are connected.
  2. Node Features: A feature matrix \(X \in \mathbb{R}^{N \times F}\), where each row \(X_i\) is a \(F\)-dimensional feature vector for node \(i\). (e.g., word embeddings of a paper's abstract).
  3. Partial Labels: A set of known labels \(Y_L\) for a small subset of nodes.

Graph Convolutional Networks (GCNs)

Modern approaches predominantly use Graph Neural Networks (GNNs), especially Graph Convolutional Networks (GCNs). A GCN layer operates on a node's features by aggregating information from its immediate neighbors, then transforming this aggregated information:

$$H^{(l+1)} = \sigma\left(\tilde{A} H^{(l)} W^{(l)}\right)$$

Here, \(H^{(l)}\) is the matrix of node embeddings at layer \(l\) (with \(H^{(0)} = X\)), \(W^{(l)}\) is a learnable weight matrix, and \(\sigma\) is an activation function (like ReLU). The crucial part is \(\tilde{A}\), the symmetrically normalized adjacency matrix, which effectively averages features from a node's neighborhood (including itself).

The Semi-Supervised Training Loop

During training, the GCN predicts labels for all nodes, but the loss function (e.g., cross-entropy) is only computed for the small subset of labeled nodes. This forces the model to learn a representation that correctly classifies known nodes, and due to the graph convolutions, this learned knowledge propagates to unlabeled nodes. The model then generalizes to predict the classes of the unlabeled nodes, implicitly leveraging the homophily principle.

🔑 Key Property

Each GCN layer effectively performs a form of neighborhood aggregation and feature transformation. Stacking multiple layers allows information to propagate further through the graph, enabling nodes to learn representations that incorporate information from their multi-hop neighborhood.

3
Why It Works — The Math
▼

Normalized Adjacency Matrix \(\tilde{A}\)

The aggregation step in GCNs uses a normalized adjacency matrix to prevent exploding or vanishing gradients and to ensure features are properly scaled. It's defined as:

$$\tilde{A} = \hat{D}^{-1/2} \hat{A} \hat{D}^{-1/2}$$

where \(\hat{A} = A + I\) (adjacency matrix with self-loops, to include a node's own features in its aggregation) and \(\hat{D}\) is the diagonal degree matrix of \(\hat{A}\) (\(\hat{D}_{ii} = \sum_j \hat{A}_{ij}\)). This normalization ensures that features are averaged over neighbors, rather than summed, which prevents nodes with many neighbors from dominating the activations.

The Semi-Supervised Loss Function

The objective function for training a GCN in a semi-supervised setting is typically cross-entropy loss, but critically, it's only applied over the labeled nodes:

$$\mathcal{L} = - \sum_{i \in \mathcal{Y}_L} \sum_{c=1}^C Y_{ic} \log(Z_{ic})$$

Here, \(\mathcal{Y}_L\) is the set of indices of labeled nodes, \(C\) is the number of classes, \(Y_{ic}\) is the true one-hot label for node \(i\) and class \(c\), and \(Z_{ic}\) is the predicted probability (after softmax) for node \(i\) belonging to class \(c\). The model learns to classify all nodes, but its parameters are adjusted only based on the errors made on the small labeled subset. The graph structure then "transfers" this learning to the unlabeled nodes.

Connection to Spectral Graph Theory

The form of the GCN layer \(\tilde{A}H^{(l)}W^{(l)}\) can be interpreted as a first-order approximation of spectral convolutions on graphs. In essence, it applies a filter that smooths node features across the graph, similar to how convolutions smooth images. This smoothing helps propagate label information from labeled nodes to their neighbors, then to their neighbors' neighbors, and so on, making the semi-supervised learning effective.

⚠️ Common Pitfall

The effectiveness of GCNs for node classification heavily relies on the homophily assumption. If connected nodes frequently belong to different classes (heterophily), standard GCNs can perform poorly, as the aggregation step will mix conflicting label information. Specialized GNN architectures are needed for heterophilous graphs.

Key Takeaways
▼

When to use semi-supervised node classification:

  • You have graph-structured data (e.g., social networks, citation networks, molecular graphs).
  • Labels are scarce or expensive to acquire for all nodes.
  • The graph exhibits homophily (connected nodes tend to be similar).
  • You need to classify nodes based on both their intrinsic features and their relational context.

When NOT to use / be cautious:

  • If the graph structure is irrelevant or misleading (e.g., random connections).
  • In highly heterophilous graphs, where connected nodes are often dissimilar. Standard GCNs might perform worse than simply ignoring the graph.
  • If node features are extremely strong predictors and the graph adds little information.
💡 Big Picture

Semi-supervised node classification with GNNs is a powerful paradigm that bridges traditional machine learning (feature-based classification) with graph analytics (structure-based inference). It's a cornerstone for understanding and predicting properties in complex relational datasets like Cora, Citeseer, and PubMed, which are widely used benchmarks.

Code Trace — PyTorch Geometric GCN
▼
import torch
import torch.nn.functional as F
from torch_geometric.nn import GCNConv
from torch_geometric.datasets import Planetoid # For Cora, Citeseer, PubMed
# 1. Load Dataset (e.g., Cora)
dataset = Planetoid(root='/tmp/Cora', name='Cora')
data = dataset[0]
# 2. Define a simple 2-layer GCN model
class GCN(torch.nn.Module):
def __init__(self, num_features, hidden_channels, num_classes):
super().__init__()
self.conv1 = GCNConv(num_features, hidden_channels)
self.conv2 = GCNConv(hidden_channels, num_classes)
def forward(self, x, edge_index):
x = self.conv1(x, edge_index) # Aggregate & Transform
x = F.relu(x)
x = F.dropout(x, p=0.5, training=self.training)
x = self.conv2(x, edge_index) # Another layer
return F.log_softmax(x, dim=1) # Log-probabilities (logits)
# 3. Instantiate model, optimizer
model = GCN(dataset.num_features, 16, dataset.num_classes)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01, weight_decay=5e-4)
# 4. Training loop
def train():
model.train()
optimizer.zero_grad()
out = model(data.x, data.edge_index)
# Loss computed ONLY on labeled nodes (train_mask)
loss = F.nll_loss(out[data.train_mask], data.y[data.train_mask])
loss.backward()
optimizer.step()
return loss.item()
# 5. Evaluation (on validation/test set)
@torch.no_grad()
def test():
model.eval()
out = model(data.x, data.edge_index)
pred = out.argmax(dim=1)
# Accuracy on test_mask (unseen labeled nodes)
correct = pred[data.test_mask] == data.y[data.test_mask]
acc = int(correct.sum()) / int(data.test_mask.sum())
return acc
# Run training for 200 epochs
for epoch in range(1, 201):
loss = train()
if epoch % 20 == 0:
test_acc = test()
# print(f'Epoch: {epoch:03d}, Loss: {loss:.4f}, Test Acc: {test_acc:.4f}')
