Understanding Graph Matrices
⌄

A graph \(G = (V, E)\) encodes relationships — social connections, molecular bonds, city road networks. Matrices let us compute with those relationships using linear algebra.

The Four Essential Matrices

Adjacency matrix \(A\): \(A_{ij} = 1\) if edge \((i,j) \in E\), else 0. For undirected graphs, \(A\) is symmetric.

Degree matrix \(D\): diagonal, \(D_{ii} = \deg(v_i) = \sum_j A_{ij}\). Encodes how many neighbours each node has.

Laplacian \(L = D - A\): the graph's differential operator. \(L_{ii} = \deg(v_i)\), \(L_{ij} = -1\) if edge, else 0.

Incidence matrix \(B\): \(n \times m\) (nodes × edges). For directed orientation, column \(e = (i,j)\): \(B_{ie} = +1\), \(B_{je} = -1\). Then \(L = B B^\top\).

Key Insight

If you remember one thing: the Laplacian \(L\) is positive semi-definite (PSD), its number of zero eigenvalues equals the number of connected components, and its second-smallest eigenvector — the Fiedler vector — encodes the best graph cut. This one matrix powers spectral clustering, GNNs, and diffusion on graphs.

Analogy

Think of a graph as a country map. Nodes are cities; edges are roads. The adjacency matrix lists which cities are directly connected. The Laplacian tells you how "central" or "isolated" each city is — its eigenvalues reveal the hidden highway structure of the whole network.

2
Internal Mechanics & Spectral Properties
⌄

Why \(L\) is Positive Semi-Definite

For any vector \(\mathbf{x} \in \mathbb{R}^n\):

$$\mathbf{x}^\top L \mathbf{x} = \sum_{(i,j)\in E}(x_i - x_j)^2 \geq 0$$

This is the graph Dirichlet form. It measures how much signal varies across edges. It can never be negative, so \(L \succeq 0\) (PSD).

Zero Eigenvalues = Connected Components

The all-ones vector \(\mathbf{1}\) is always in the null-space: \(L\mathbf{1} = 0\). More generally, for each connected component there is one zero eigenvalue with eigenvector the indicator of that component. So \(\lambda_1 = 0\) always; \(\lambda_2 > 0\) iff the graph is connected.

The Fiedler Vector (Graph Partitioning)

The eigenvector \(\mathbf{f}\) for \(\lambda_2\) (the Fiedler value) gives the optimal two-way spectral partition: nodes with \(f_i \geq 0\) go to partition A, nodes with \(f_i < 0\) go to partition B. This minimizes the normalised cut and is the backbone of spectral clustering.

Normalised Laplacians

Symmetric: \(\mathcal{L}_{\text{sym}} = D^{-1/2} L D^{-1/2}\), eigenvalues \(\in [0,2]\).

Random-walk: \(\mathcal{L}_{\text{rw}} = D^{-1}L = I - D^{-1}A\), eigenvalues \(\in [0,2]\), used in GNN message passing.

Common Pitfall

The unnormalised Laplacian's eigenvalues depend on node degrees, making them incomparable across graphs. Always normalise when comparing spectra across different graphs or for GNN propagation.

Connection to GNNs

Graph Convolutional Networks (Kipf & Welling 2017) use the propagation rule \(\hat{A} = \tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}\) where \(\tilde{A} = A + I\) (with self-loops). This is exactly \(I - \mathcal{L}_{\text{sym}}\) applied to the self-looped graph — spectral filtering in the graph frequency domain.

3
Complete Mathematical Derivation
⌄

Definitions (undirected graph, \(n\) nodes, \(m\) edges)

$$A_{ij} = \begin{cases}1 & (i,j)\in E \\ 0 & \text{otherwise}\end{cases}, \quad A = A^\top$$
$$D = \operatorname{diag}(d_1,\dots,d_n), \quad d_i = \sum_j A_{ij}$$
$$L = D - A, \quad L_{ij} = \begin{cases}d_i & i=j \\ -1 & (i,j)\in E \\ 0 & \text{otherwise}\end{cases}$$

Proof: \(L \succeq 0\)

Expand the quadratic form using \(L = D - A\):

$$\mathbf{x}^\top L \mathbf{x} = \mathbf{x}^\top D \mathbf{x} - \mathbf{x}^\top A \mathbf{x} = \sum_i d_i x_i^2 - \sum_{(i,j)\in E} 2x_i x_j$$

Since each undirected edge \((i,j)\) contributes \(x_i^2 + x_j^2 - 2x_ix_j = (x_i-x_j)^2\):

$$\mathbf{x}^\top L \mathbf{x} = \sum_{(i,j)\in E}(x_i - x_j)^2 \geq 0 \qquad \forall \mathbf{x}$$

Incidence Matrix Identity: \(L = BB^\top\)

Orient each edge arbitrarily. For edge \(e = (i,j)\): \(B_{ie}=+1\), \(B_{je}=-1\), all other rows 0.

$$(BB^\top)_{ij} = \sum_e B_{ie}B_{je}$$

Diagonal: \(\sum_e B_{ie}^2 = d_i\). Off-diagonal \((i\neq j)\): nonzero only if edge \((i,j)\) exists, contributing \((+1)(-1)=-1\). Hence \(BB^\top = D-A = L\). ■

Spectral Theorem for \(L\)

Since \(L\) is real symmetric PSD, it has eigendecomposition \(L = U\Lambda U^\top\) with \(0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\). The multiplicity of eigenvalue 0 equals the number of connected components \(k\).

$$\lambda_2 > 0 \iff G \text{ is connected}$$

Normalised Variants

$$\mathcal{L}_{\text{sym}} = D^{-1/2}LD^{-1/2} = I - D^{-1/2}AD^{-1/2}$$
$$\mathcal{L}_{\text{rw}} = D^{-1}L = I - D^{-1}A, \quad \text{eigenvalues}\in[0,2]$$
Numerical Example (4-node graph)

Graph: nodes \(\{0,1,2,3\}\), edges \(\{(0,1),(0,2),(1,2),(1,3),(2,3)\}\). Degrees: \(d_0=2,\,d_1=3,\,d_2=3,\,d_3=2\).

Laplacian eigenvalues: \(\lambda = [0,\; 2,\; 4,\; 4]\). One zero eigenvalue — one component. Fiedler value \(\lambda_2=2\). Fiedler vector \(\approx [+0.707, 0, 0, -0.707]\): nodes 0 vs 3 are the natural partition endpoints.

Normalised Laplacian eigenvalues: \([0,\; 1,\; 4/3,\; 5/3]\approx[0,\;1,\;1.333,\;1.667]\), all in \([0,2]\) as required.

Applications & Key Takeaways
⌄

Graph Neural Networks (GNNs)

GCN (Kipf & Welling, 2017) propagates features using \(\hat{A} = \tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}\), a normalised adjacency. Each GNN layer is spectral filtering: \(H^{(l+1)} = \sigma(\hat{A} H^{(l)} W^{(l)})\). The graph Laplacian's spectral decomposition defines the graph Fourier transform that justifies this filtering.

Spectral Clustering

Compute the bottom-\(k\) eigenvectors of \(L\) (or \(\mathcal{L}_\text{sym}\)), stack them as rows of matrix \(U\), then run k-means on the rows of \(U\). The Fiedler vector alone gives the best 2-way cut minimising the normalised cut objective \(N_{\text{cut}}(A,B) = \frac{\text{cut}(A,B)}{\text{vol}(A)} + \frac{\text{cut}(A,B)}{\text{vol}(B)}\).

Diffusion & PageRank

The random-walk Laplacian \(\mathcal{L}_\text{rw} = I - D^{-1}A\) governs diffusion: heat at time \(t\) is \(\mathbf{u}(t) = e^{-t\mathcal{L}_\text{rw}}\mathbf{u}(0)\). PageRank is stationary distribution of the random walk \(D^{-1}A\).

Interview Essentials

Why is L PSD? Quadratic form equals sum of squared edge differences — always non-negative.

What do zero eigenvalues mean? Each connected component contributes exactly one zero eigenvalue.

What is the Fiedler vector? Eigenvector of \(\lambda_2\); its sign gives the best spectral 2-way partition of the graph.

How does A relate to GNNs? Normalised \(\hat{A} = D^{-1/2}AD^{-1/2}\) acts as a low-pass spectral filter; stacking GNN layers applies it repeatedly.

Code: From Scratch in NumPy
⌄

All four matrices computed from scratch; spectral clustering skeleton included.

import numpy as np

# ── Graph definition ───────────────────────────────────────
n = 4
edges = [(0,1), (0,2), (1,2), (1,3), (2,3)]

# Adjacency matrix A
A = np.zeros((n, n), dtype=float)
for i, j in edges:
    A[i, j] = A[j, i] = 1.0            # undirected: symmetric

# Degree matrix D
d = A.sum(axis=1)                       # degree vector
D = np.diag(d)                          # diagonal matrix

# Laplacian L = D - A
L = D - A

# Normalised Laplacian (symmetric form)
D_inv_sqrt = np.diag(1.0 / np.sqrt(d))
L_sym = D_inv_sqrt @ L @ D_inv_sqrt     # I - D^{-1/2} A D^{-1/2}

# Incidence matrix B  (n x m)  arbitrary orientation
m = len(edges)
B = np.zeros((n, m), dtype=float)
for e_idx, (i, j) in enumerate(edges):
    B[i, e_idx] =  1.0                 # source
    B[j, e_idx] = -1.0                 # target

# Verify L = B B^T
assert np.allclose(L, B @ B.T), "Identity violated!"

# ── Spectral decomposition ─────────────────────────────────
vals, vecs = np.linalg.eigh(L)          # eigh: symmetric, real

# Number of connected components = number of ~zero eigenvalues
n_components = np.sum(np.abs(vals) < 1e-10)   # → 1

# Fiedler vector (second eigenvector)
fiedler = vecs[:, 1]
partition = (fiedler >= 0).astype(int)  # 0 or 1

# ── Spectral clustering (k=2) ──────────────────────────────
# Use bottom-k eigenvectors of L_sym as row features
from sklearn.cluster import KMeans

k = 2
U = vecs[:, :k]                         # shape (n, k)
labels = KMeans(n_clusters=k, n_init=10).fit_predict(U)
print("Cluster labels:", labels)        # → [0 1 1 0] or similar
