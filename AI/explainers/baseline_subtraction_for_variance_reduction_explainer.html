Baseline Subtraction for Variance Reduction

Improving Monte Carlo estimates by removing predictable noise
Foundational Monte Carlo Reinforcement Learning O(1) extra cost
1
Understanding Baseline Subtraction
▼

What is it? Baseline subtraction is a variance reduction technique used in Monte Carlo estimation. When we want to estimate the expected value of a random variable \(X\), we can instead estimate the expected value of a modified variable \(X' = X - B\), where \(B\) is a "baseline" random variable with a known expected value \(\mathbb{E}[B]\) (often chosen to be 0). Since \(\mathbb{E}[X - B] = \mathbb{E}[X] - \mathbb{E}[B]\), if \(\mathbb{E}[B]\) is known, we can recover \(\mathbb{E}[X]\) from \(\mathbb{E}[X - B]\) without bias. The trick is that if \(B\) is chosen well (i.e., it's correlated with \(X\)), the variance of \(X'\) can be significantly smaller than the variance of \(X\), leading to more precise estimates with fewer samples.

Analogy: Imagine you're trying to estimate the average weight of apples from a specific orchard. A simple Monte Carlo approach would be to pick a random sample of apples, weigh them, and average the results. This might have high variance due to natural variations in soil quality, sunlight, etc. Now, imagine you also know the average weight of a *standard* apple from a control group (your baseline, \(B\)), and you notice that when apples in your orchard are heavier than average, the control apples are also heavier than average (i.e., they are correlated). Instead of measuring \(X\) (actual apple weight), you measure \(X - B\) (deviation from the control apple). If the local conditions affect both similarly, measuring the *difference* might be less noisy, leading to a more precise estimate of the orchard's average apple weight relative to the control.

💡 If you remember one thing

To reduce the variance of an estimator for \(\mathbb{E}[X]\), you can subtract a random variable \(B\) (the baseline) whose mean \(\mathbb{E}[B]\) is known. The new estimator \(X-B\) is still unbiased for \(\mathbb{E}[X] - \mathbb{E}[B]\). If \(B\) is positively correlated with \(X\), the variance of \(X-B\) will be reduced compared to \(X\).

2
How It Works Internally
▼

The Core Idea: Unbiasedness Preserved, Variance Reduced

Monte Carlo methods often involve estimating an expectation \(\mathbb{E}[X]\) by averaging \(N\) independent samples \(X_1, \dots, X_N\). The precision of this estimate scales with \(1/\sqrt{N}\) and the variance of the underlying random variable \(X\). To get a more precise estimate without taking more samples, we need to reduce \(\operatorname{Var}(X)\).

Baseline subtraction achieves this by constructing a new random variable \(X_c = X - B\), where \(B\) is the baseline. The key requirements for \(B\) are:

  1. Known Expectation: \(\mathbb{E}[B]\) must be known or easily estimable. Often, \(B\) is chosen such that \(\mathbb{E}[B] = 0\), simplifying the math.
  2. Correlation with \(X\): \(B\) should be correlated with \(X\). Ideally, \(B\) captures some of the "noise" or common trends in \(X\), so that subtracting it smooths out the fluctuations.

If these conditions are met, the estimator for \(\mathbb{E}[X]\) becomes \(\frac{1}{N}\sum_{i=1}^N (X_i - B_i) + \mathbb{E}[B]\). This estimator is unbiased, and its variance can be significantly lower.

Common Applications: Reinforcement Learning

A prominent use case for baseline subtraction is in policy gradient methods in Reinforcement Learning. Here, \(X\) represents the "return" or "reward" from a state, and we want to estimate the gradient of the expected return. The gradients are often weighted by the return \(R_t\). However, \(R_t\) can have high variance. A common baseline \(B\) is the state-value function \(V(s_t)\), which estimates the expected return from state \(s_t\). Subtracting \(V(s_t)\) from \(R_t\) gives the "advantage function" \(A_t = R_t - V(s_t)\). Since \(\mathbb{E}[R_t - V(s_t)] = \mathbb{E}[A_t]\) and \(V(s_t)\) is an estimate of \(\mathbb{E}[R_t]\), \(\mathbb{E}[A_t]\) is ideally 0. The advantage function is used to scale gradients, and because \(V(s_t)\) is correlated with \(R_t\), it significantly reduces the variance of the policy gradient estimates.

🔑 Key Property

The effectiveness of baseline subtraction hinges on the covariance between \(X\) and \(B\). A strong positive correlation means \(B\) varies similarly to \(X\), allowing \(X-B\) to "cancel out" common fluctuations and reduce overall variance.

3
Why It Works — The Math
▼

Unbiasedness of the New Estimator

Let our goal be to estimate \(\mu = \mathbb{E}[X]\). We introduce a baseline random variable \(B\) such that its expected value \(\mathbb{E}[B]\) is known. We define a new random variable \(X_c = X - B\).

The expected value of \(X_c\) is:

$$\mathbb{E}[X_c] = \mathbb{E}[X - B] = \mathbb{E}[X] - \mathbb{E}[B]$$

Therefore, if we estimate \(\mathbb{E}[X_c]\) by sampling, our estimate for \(\mu\) would be \(\hat{\mu} = \mathbb{E}[X_c] + \mathbb{E}[B]\). This estimator is clearly unbiased for \(\mathbb{E}[X]\) because \(\mathbb{E}[\hat{\mu}] = \mathbb{E}[\mathbb{E}[X_c] + \mathbb{E}[B]] = \mathbb{E}[X] - \mathbb{E}[B] + \mathbb{E}[B] = \mathbb{E}[X]\).

In many practical scenarios (like RL advantage functions), \(B\) is chosen such that \(\mathbb{E}[B]\) is approximately 0, so the estimate of \(\mathbb{E}[X_c]\) directly approximates \(\mathbb{E}[X]\).

Variance Reduction Condition

Now, let's look at the variance of our new estimator \(X_c\). The variance of the sum/difference of two random variables is given by:

$$\operatorname{Var}(X_c) = \operatorname{Var}(X - B) = \operatorname{Var}(X) + \operatorname{Var}(B) - 2 \operatorname{Cov}(X, B)$$

For baseline subtraction to be effective, we need \(\operatorname{Var}(X_c) < \operatorname{Var}(X)\). Substituting the expression for \(\operatorname{Var}(X_c)\):

$$\operatorname{Var}(X) + \operatorname{Var}(B) - 2 \operatorname{Cov}(X, B) < \operatorname{Var}(X)$$

Subtracting \(\operatorname{Var}(X)\) from both sides, we get the condition for variance reduction:

$$\operatorname{Var}(B) - 2 \operatorname{Cov}(X, B) < 0 \quad \implies \quad 2 \operatorname{Cov}(X, B) > \operatorname{Var}(B)$$

This equation shows that variance reduction occurs when \(B\) is sufficiently positively correlated with \(X\). If \(\operatorname{Cov}(X, B)\) is large and positive, and \(\operatorname{Var}(B)\) is not excessively large, then subtracting \(B\) will indeed reduce variance. If \(B\) is uncorrelated with \(X\) (\(\operatorname{Cov}(X, B) = 0\)), then \(\operatorname{Var}(X_c) = \operatorname{Var}(X) + \operatorname{Var}(B)\), which means variance *increases*. If \(B\) is negatively correlated, it might also increase variance, unless \(\operatorname{Var}(B)\) is very small. The goal is to find a \(B\) that "tracks" \(X\) well.

⚠️ Common Pitfall

Choosing a poor baseline (e.g., one uncorrelated with \(X\), or one with very high variance) can actually increase the variance of your estimator. The assumption that \(\mathbb{E}[B]\) is known is crucial; if \(B\) itself needs to be estimated, its estimation error can introduce bias or additional variance.

Key Takeaways
▼

When to use baseline subtraction:

  • When performing Monte Carlo simulations and the variance of your estimator is high.
  • In Reinforcement Learning, particularly with policy gradient methods (e.g., REINFORCE with baseline, Actor-Critic advantage functions).
  • In A/B testing or experimental design, where a control group or a paired measurement can serve as a baseline to reduce noise.
  • Any situation where you can find a random variable \(B\) that is correlated with your target \(X\) and has a known mean.

When NOT to use:

  • If \(\mathbb{E}[B]\) is unknown or difficult to estimate accurately, as this can introduce bias.
  • If \(B\) is uncorrelated with \(X\), as this will likely increase variance (\(\operatorname{Var}(X-B) = \operatorname{Var}(X) + \operatorname{Var}(B)\)).
  • If \(B\) has extremely high variance compared to its covariance with \(X\), leading to \(\operatorname{Var}(B) - 2 \operatorname{Cov}(X,B) > 0\).
  • If the computational cost of generating or estimating \(B\) outweighs the benefits of variance reduction.
💡 Big Picture

Baseline subtraction is a specific form of control variates, a broader class of variance reduction techniques. Control variates use a variable \(C\) with known mean \(\mathbb{E}[C]\) and subtract \(\beta C\) from \(X\), where \(\beta\) is an optimized coefficient. Baseline subtraction is simply the case where \(\beta=1\) and \(\mathbb{E}[B]=0\).

Code Trace (Python/NumPy)
▼
import numpy as np
# --- Configuration ---
N_SAMPLES = 1000
TRUE_MEAN_X = 10.0
STD_DEV_X = 2.0
TRUE_MEAN_B = 0.0 # Baseline should have known mean
# --- Generate correlated samples ---
def generate_correlated_data(rho, std_dev_b):
# Generate two independent standard normal variables
z1 = np.random.randn(N_SAMPLES)
z2 = np.random.randn(N_SAMPLES)
# Construct X and B with desired mean, std dev, and correlation
X = TRUE_MEAN_X + STD_DEV_X * z1
B = TRUE_MEAN_B + std_dev_b * (rho * z1 + np.sqrt(1 - rho**2) * z2)
return X, B
# --- Perform baseline subtraction ---
rho_val = 0.8 # Example: high positive correlation
std_dev_b_val = 1.0 # Example: moderate baseline noise
X_samples, B_samples = generate_correlated_data(rho_val, std_dev_b_val)
X_minus_B_samples = X_samples - B_samples
# --- Calculate statistics ---
mean_X = np.mean(X_samples)
var_X = np.var(X_samples)
mean_B = np.mean(B_samples)
var_B = np.var(B_samples)
mean_XB = np.mean(X_minus_B_samples)
var_XB = np.var(X_minus_B_samples)
print(f"Original X: Mean={mean_X:.3f}, Variance={var_X:.3f}")
print(f"Baseline B: Mean={mean_B:.3f}, Variance={var_B:.3f}")
print(f"X - B: Mean={mean_XB:.3f}, Variance={var_XB:.3f}")
print(f"Estimated E[X] = Mean(X-B) + E[B] = {mean_XB:.3f} + {TRUE_MEAN_B} = {mean_XB + TRUE_MEAN_B:.3f}")
# Expected variance reduction: Var(X) + Var(B) - 2*Cov(X,B)
# Cov(X,B) = rho * std_dev_X * std_dev_B
expected_cov = rho_val * STD_DEV_X * std_dev_b_val
expected_var_XB = STD_DEV_X**2 + std_dev_b_val**2 - 2 * expected_cov
print(f"Theoretical Var(X-B) = {expected_var_XB:.3f}")
