Intermediate Classical ML Evaluation

Multi-label Metrics

Hamming Loss, Subset Accuracy, and Label-Ranking Average Precision (LRAP) — three complementary ways to measure multi-label classifier performance.

🎭
What is Multi-label Classification?
▼

In multi-label classification each sample can simultaneously belong to multiple classes. Unlike multi-class classification (one label per sample), here a single input maps to a set of labels.

Think of a movie tagged as Action + Comedy + Thriller all at once, or a medical image labelled with multiple findings, or a tweet annotated with several topics.

Formally, given \(N\) samples and \(L\) labels, the true label matrix is \(Y \in \{0,1\}^{N \times L}\), and the prediction matrix is \(\hat{Y} \in \{0,1\}^{N \times L}\).

💡

Because each sample has a set of correct labels, standard accuracy doesn't work. We need metrics that handle partial correctness, label-level errors, and ranking quality differently.

🔥
Hamming Loss — The Lenient Metric
▼

Hamming Loss counts the fraction of individual label decisions (across all samples and all labels) that are wrong. A wrong decision means the prediction XORs with the truth.

$$\text{Hamming Loss} = \frac{1}{N \cdot L} \sum_{i=1}^{N} \sum_{j=1}^{L} \mathbf{1}[\hat{y}_{ij} \neq y_{ij}]$$

Range: \([0, 1]\). Lower is better. With \(N=5\) samples and \(L=5\) labels there are 25 label decisions. Even 3 wrong gives \(3/25 = 0.12\) — only 12% error.

Hamming Loss is lenient because it rewards partial correctness: a sample with 4 out of 5 labels correct contributes only \(1/25\) to the loss, not a full \(1/N\).

⚠

Hamming Loss can be misleading with class imbalance — if 90% of labels are always 0, a classifier that predicts all zeros achieves very low Hamming Loss but is useless.

⚖️
Subset Accuracy — The Strict Judge
▼

Subset Accuracy (also called Exact Match Ratio) requires that the entire predicted label set matches the true label set exactly — every single label must be correct for the sample to count.

$$\text{Subset Accuracy} = \frac{1}{N} \sum_{i=1}^{N} \mathbf{1}[\hat{y}_i = y_i]$$

Range: \([0, 1]\). Higher is better. One wrong label in a row means the whole sample is penalized fully.

This is the strictest multi-label metric. In our example, even though only 3 label decisions are wrong across 25, three different samples are affected, so 3 samples fail and subset accuracy is only \(2/5 = 0.40\).

💡

Subset Accuracy is appropriate when the complete label set matters — e.g., a diagnosis where missing one condition has serious consequences. It is often too strict for many real-world applications.

🎯
LRAP — Rewarding Good Rankings
▼

Label Ranking Average Precision (LRAP) uses the continuous probability scores (not binary predictions) to measure how well the classifier ranks true labels above false labels.

$$\text{LRAP} = \frac{1}{N} \sum_{i=1}^{N} \frac{1}{|Y_i|} \sum_{j:\, y_{ij}=1} \frac{|\{k : \hat{p}_{ik} \geq \hat{p}_{ij},\, y_{ik}=1\}|}{|\{k : \hat{p}_{ik} \geq \hat{p}_{ij}\}|}$$

For each true label \(j\) in sample \(i\): count how many true labels are ranked at least as high as \(j\), divided by how many total labels are ranked at least as high. Average across all true labels and samples.

Range: \([0, 1]\). Higher is better. LRAP = 1.0 means all true labels are ranked at the top with no false labels interspersed. It rewards correct ordering even if binary thresholds are wrong.

💡

A classifier can have low Hamming Loss, low Subset Accuracy, but still achieve LRAP = 1.0 — the ranking is perfect even if some threshold-based predictions are off. This is common when the threshold is miscalibrated.

⚖️
The Trade-off Triangle
▼

The three metrics measure fundamentally different things. Choosing the right one depends on your application requirements.

Metric Strictness Input Best When
Hamming Loss Lenient Binary predictions Each label error has equal cost; partial credit matters
Subset Accuracy Very Strict Binary predictions Complete label sets must be correct; no partial credit
LRAP Ranking-based Probability scores Ranking/retrieval matters; top labels should be returned first
🎯

Always report multiple metrics. A classifier optimized for only one metric can look excellent on that measure while performing poorly on others — as our interactive example demonstrates.
