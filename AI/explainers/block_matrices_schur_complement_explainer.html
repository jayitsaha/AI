1
Understanding Block Matrices
▼

What is a block matrix? Sometimes it's natural to treat a big matrix as a grid of smaller sub-matrices called blocks. A 2×2 block matrix looks like four named sub-matrices \(\begin{pmatrix} A & B \\ C & D \end{pmatrix}\) where each letter is itself a matrix, not a single number. The whole is partitioned so that dimensions line up correctly.

Analogy: Think of a city map divided into four quadrants. Each quadrant has its own internal road network, but roads also cross between quadrants. Block matrices are exactly this — internal structure (the blocks) plus cross-connections (the off-diagonal blocks). When you need to navigate the whole city, you can reason about quadrant interactions without looking at every single street.

💡 If you remember one thing

The Schur complement of \(A\) in \(M = \begin{pmatrix} A & B \\ C & D \end{pmatrix}\) is $$S = D - CA^{-1}B$$ It is what remains of \(D\) after eliminating the influence of the \(A\) block — exactly Gaussian elimination applied to blocks. The Schur complement governs block determinants, inverses, and Gaussian conditional distributions.

Why it matters in ML: Multivariate Gaussian conditioning — the backbone of Gaussian processes, Kalman filters, and Bayesian linear regression — is exactly the Schur complement formula. Efficient sparse solvers and PSD verification also rely on it.

2
Block Operations & the Schur Complement
▼

Block Partitioning

Given an \((m+n) \times (m+n)\) matrix \(M\), partition it as:

$$M = \begin{pmatrix} A & B \\ C & D \end{pmatrix}$$

where \(A \in \mathbb{R}^{m \times m}\), \(B \in \mathbb{R}^{m \times n}\), \(C \in \mathbb{R}^{n \times m}\), \(D \in \mathbb{R}^{n \times n}\). The block structure is not unique — you choose it to exploit sparsity or structure.

Block Gaussian Elimination: Deriving the Schur Complement

Suppose we want to solve \(Mx = b\), i.e. \(Ax_1 + Bx_2 = b_1\) and \(Cx_1 + Dx_2 = b_2\). Eliminate \(x_1\) from the second equation: multiply the first by \(CA^{-1}\) and subtract. The coefficient of \(x_1\) cancels, leaving:

$$(D - CA^{-1}B)\,x_2 = b_2 - CA^{-1}b_1$$

The matrix \(S = D - CA^{-1}B\) is the Schur complement of \(A\) in \(M\). It is the "reduced" system for \(x_2\) after eliminating \(x_1\).

🔑 Key Property

If \(A\) is invertible: \(\det(M) = \det(A)\cdot\det(S)\). And \(M\) is positive definite if and only if both \(A\) and its Schur complement \(S = D - CA^{-1}B\) are positive definite. This gives a recursive PD test — directly used in Cholesky factorisation.

Block Inversion Formula

When \(A\) and \(S\) are both invertible, the block inverse is:

$$M^{-1} = \begin{pmatrix} A^{-1} + A^{-1}B S^{-1} C A^{-1} & -A^{-1}B S^{-1} \\ -S^{-1}CA^{-1} & S^{-1} \end{pmatrix}$$

This is the block matrix inversion lemma. Each entry requires only inverses of \(A\) (size \(m\)) and \(S\) (size \(n\)), never inverting the full \((m+n)\) matrix directly. Huge savings when one block is small.

⚠️ Common Pitfall

Block operations look like scalar algebra but are NOT commutative. \(AB \neq BA\) in general. Always check that matrix dimensions are compatible before applying block formulas. Also: \(S = D - CA^{-1}B\) requires \(A\) invertible; the dual Schur complement \(S' = A - BD^{-1}C\) requires \(D\) invertible — and these are different objects.

The Math — Derivations & Connections
▼

Block Determinant Identity

Factor \(M\) via block elimination (LDU decomposition in blocks):

$$M = \begin{pmatrix} I & 0 \\ CA^{-1} & I \end{pmatrix} \begin{pmatrix} A & 0 \\ 0 & S \end{pmatrix} \begin{pmatrix} I & A^{-1}B \\ 0 & I \end{pmatrix}$$

Taking determinants (each triangular factor has det = 1, middle block-diagonal has det = \(\det A \cdot \det S\)):

$$\det(M) = \det(A)\,\det\!\left(D - CA^{-1}B\right)$$

Woodbury / Sherman–Morrison–Woodbury

Setting \(D = -I\) in the block inversion formula yields the famous Woodbury identity:

$$(A + UCV)^{-1} = A^{-1} - A^{-1}U\left(C^{-1} + VA^{-1}U\right)^{-1}VA^{-1}$$

This converts an \(n \times n\) inverse into one of size \(k \times k\) (rank-\(k\) update), reducing cost from \(O(n^3)\) to \(O(k^2 n)\). It is the Schur complement in disguise.

Gaussian Conditioning (ML Connection)

Let \(\begin{pmatrix} x \\ y \end{pmatrix} \sim \mathcal{N}\!\left(0, \begin{pmatrix} \Sigma_{xx} & \Sigma_{xy} \\ \Sigma_{yx} & \Sigma_{yy} \end{pmatrix}\right)\). The conditional distribution \(x \mid y\) is Gaussian with:

$$x \mid y \sim \mathcal{N}\!\left(\Sigma_{xy}\Sigma_{yy}^{-1}y,\quad \Sigma_{xx} - \Sigma_{xy}\Sigma_{yy}^{-1}\Sigma_{yx}\right)$$

The conditional variance \(\Sigma_{xx} - \Sigma_{xy}\Sigma_{yy}^{-1}\Sigma_{yx}\) is precisely the Schur complement of \(\Sigma_{yy}\) in the joint covariance. Every Gaussian process prediction, Kalman update, and Bayesian linear regression formula is an instance of this.

📐 Numeric Trace (2×2 blocks, each 2×2)

Let \(A = \begin{pmatrix}4&1\\1&3\end{pmatrix}\), \(B = \begin{pmatrix}1\\0\end{pmatrix}\), \(C = \begin{pmatrix}1&0\end{pmatrix}\), \(D = \begin{pmatrix}2\end{pmatrix}\).

\(A^{-1} = \frac{1}{11}\begin{pmatrix}3&-1\\-1&4\end{pmatrix}\), so \(CA^{-1}B = \frac{1}{11}(3\cdot1 + (-1)\cdot0)= \frac{3}{11}\).

\(S = D - CA^{-1}B = 2 - \frac{3}{11} = \frac{19}{11}\). Then \(\det M = \det A \cdot S = 11 \cdot \frac{19}{11} = 19\). ✓

ML Connection — Gaussian Conditioning
▼

Virtually every Gaussian inference algorithm reduces to computing a Schur complement of a covariance matrix. Consider a joint Gaussian with blocks matching the partition:

$$\begin{pmatrix}x\\y\end{pmatrix}\sim\mathcal{N}\!\left(\begin{pmatrix}\mu_x\\\mu_y\end{pmatrix},\begin{pmatrix}\Sigma_{xx}&\Sigma_{xy}\\\Sigma_{yx}&\Sigma_{yy}\end{pmatrix}\right)$$

The posterior mean and variance of \(x\) given observed \(y\):

$$\mu_{x|y} = \mu_x + \Sigma_{xy}\Sigma_{yy}^{-1}(y-\mu_y)$$
$$\Sigma_{x|y} = \Sigma_{xx} - \Sigma_{xy}\Sigma_{yy}^{-1}\Sigma_{yx} = \text{Schur complement of }\Sigma_{yy}$$

This formula appears in:

  • Gaussian Processes: GP prediction mean/variance are Schur complements of the kernel matrix.
  • Kalman Filter: The update step computes \(K = \Sigma_{xy}\Sigma_{yy}^{-1}\) (Kalman gain) and the posterior covariance \(\Sigma_{x|y}\) is the Schur complement.
  • Bayesian Linear Regression: Posterior parameter covariance uses the Woodbury lemma (Schur complement form) for efficient computation.
  • Factor Analysis / PCA: Marginalising over latent variables involves Schur complements of the latent covariance block.
💡 The Deeper Picture

The Schur complement is not just an algebraic trick — it is the unique operator that captures the conditional information in one block given another. Geometrically, \(S = D - CA^{-1}B\) is the variance of the "residual" of \(D\) after projecting onto the \(A\) subspace — a direct analogue of the residual variance in least-squares regression.

Code Trace — From Scratch in NumPy
▼
import numpy as np
# ── Build the full 5x5 matrix ──
A = np.array([[4.,2.,1.],[2.,5.,3.],[1.,3.,6.]]) # 3x3
B = np.array([[1.,0.],[0.,2.],[1.,1.]]) # 3x2
C = B.T # 2x3
D = np.array([[3.,1.],[1.,4.]]) # 2x2
M = np.block([[A, B],[C, D]]) # 5x5
# ── Schur complement of A in M ──
A_inv = np.linalg.inv(A)
S = D - C @ A_inv @ B # 2x2 Schur complement
print("S =", S)
# S = [[2.143, 0.0], [0.0, 2.571]] (approx)
# ── Verify: det(M) = det(A)*det(S) ──
print(np.linalg.det(M)) # e.g. 284.0
print(np.linalg.det(A) * np.linalg.det(S)) # same
# ── Block inversion via Schur ──
S_inv = np.linalg.inv(S)
M11 = A_inv + A_inv @ B @ S_inv @ C @ A_inv
M12 = -A_inv @ B @ S_inv
M21 = -S_inv @ C @ A_inv
M22 = S_inv
M_inv_block = np.block([[M11,M12],[M21,M22]])
print(np.allclose(M_inv_block, np.linalg.inv(M))) # True
# ── Gaussian conditioning example ──
Sigma = M.copy() # treat M as covariance
Sxx, Sxy = A, B # x block (3-dim)
Syx, Syy = C, D # y block (2-dim)
Sigma_x_given_y = Sxx - Sxy @ np.linalg.inv(Syy) @ Syx
print("Conditional variance =", Sigma_x_given_y)
