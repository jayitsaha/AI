The three elementary operations every linear algebra toolkit starts with

1
Understanding the Three Operations
▼

What are these? Every matrix is just a rectangular table of numbers. Three foundational things you can do with matrices: add two same-shaped tables entry by entry, scale every entry by the same number, and transpose — flip a table so rows become columns and columns become rows.

Analogy — the spreadsheet picture: Imagine you have two identical-format budget spreadsheets for January and February. Adding them gives you a combined two-month budget (each cell adds). Scalar multiplication is like giving everyone a 10 % raise — multiply every cell by 1.10. Transposition is rotating the spreadsheet 90° and mirroring it: what was row 1, column 3 is now row 3, column 1.

💡 If you remember one thing

Addition and scalar multiplication work entry-wise; transposition swaps the two indices: \((A^\top)_{ij} = A_{ji}\). Together they make the set of \(m \times n\) real matrices into a vector space. The key identity to know cold: \((AB)^\top = B^\top A^\top\) — note the reversed order.

How Each Operation Works
▼

Matrix Addition — element-by-element

Given \(A, B \in \mathbb{R}^{m \times n}\), their sum \(C = A + B\) is defined by \(C_{ij} = A_{ij} + B_{ij}\) for every row \(i \in \{1,\ldots,m\}\) and column \(j \in \{1,\ldots,n\}\). The shapes must match exactly — you cannot add a \(2 \times 3\) to a \(3 \times 2\).

$$(A + B)_{ij} = A_{ij} + B_{ij}$$

Transposition — swap (i, j) ↔ (j, i)

The transpose \(A^\top\) of an \(m \times n\) matrix \(A\) is an \(n \times m\) matrix whose \((i,j)\)-entry equals \(A_{ji}\). Geometrically: reflect across the main diagonal. A \(2 \times 3\) matrix becomes a \(3 \times 2\) matrix.

$$(A^\top)_{ij} = A_{ji}$$

🔑 Key Property — (AB)ᵀ = BᵀAᵀ

The transpose of a product reverses the order. This is not optional: if \(A\) is \(m \times k\) and \(B\) is \(k \times n\), then \(AB\) is \(m \times n\), so \((AB)^\top\) is \(n \times m\). But \(A^\top\) is \(k \times m\) and \(B^\top\) is \(n \times k\), so \(B^\top A^\top\) is \(n \times m\) — shapes agree. \(A^\top B^\top\) would need \(k \times m\) times \(n \times k\) — shapes clash.$$ (AB)^\top = B^\top A^\top $$

Why It Works — Algebraic Properties
▼

Vector Space Axioms via Addition & Scalar Multiplication

For \(A, B, C \in \mathbb{R}^{m \times n}\) and \(c, d \in \mathbb{R}\), the eight vector space axioms hold. The most useful sub-set:

$$A + B = B + A \quad \text{(commutativity)}$$
$$(A + B) + C = A + (B + C) \quad \text{(associativity)}$$
$$c(A + B) = cA + cB \quad \text{(distributivity over matrix sum)}$$
$$(c + d)A = cA + dA \quad \text{(distributivity over scalar sum)}$$

The zero matrix \(0_{m\times n}\) (all entries zero) is the additive identity: \(A + 0 = A\). The additive inverse is \(-A\) (negate every entry): \(A + (-A) = 0\).

Transpose Properties

$$(A^\top)^\top = A \quad \text{(involution)}$$
$$(A + B)^\top = A^\top + B^\top \quad \text{(linearity)}$$
$$(cA)^\top = c A^\top \quad \text{(scalar passes through)}$$
$$(AB)^\top = B^\top A^\top \quad \text{(reversal — proved below)}$$

Proof of (AB)ᵀ = BᵀAᵀ

Let \(A \in \mathbb{R}^{m \times k}\), \(B \in \mathbb{R}^{k \times n}\). We prove entry-wise. The \((i,j)\)-entry of \((AB)^\top\) is the \((j,i)\)-entry of \(AB\):

$$\bigl[(AB)^\top\bigr]_{ij} = (AB)_{ji} = \sum_{\ell=1}^{k} A_{j\ell}\, B_{\ell i}$$

The \((i,j)\)-entry of \(B^\top A^\top\) is the dot product of row \(i\) of \(B^\top\) with column \(j\) of \(A^\top\). Row \(i\) of \(B^\top\) = column \(i\) of \(B\), so its \(\ell\)-th entry is \(B_{\ell i}\). Column \(j\) of \(A^\top\) = row \(j\) of \(A\), so its \(\ell\)-th entry is \(A_{j\ell}\). Hence:

$$\bigl[B^\top A^\top\bigr]_{ij} = \sum_{\ell=1}^{k} (B^\top)_{i\ell}\,(A^\top)_{\ell j} = \sum_{\ell=1}^{k} B_{\ell i}\, A_{j\ell}$$

Both sums are identical (multiplication of scalars commutes). Therefore \((AB)^\top = B^\top A^\top\). ∎

⚠️ Common Mistake

Students write \((AB)^\top = A^\top B^\top\). This is wrong in general — shapes may not even be compatible. The correct identity is \((AB)^\top = B^\top A^\top\) (reversed order, mirroring how inverses work: \((AB)^{-1} = B^{-1}A^{-1}\)).

Symmetric & Skew-Symmetric Decomposition

Any square matrix \(A\) can be uniquely decomposed:

$$A = \underbrace{\frac{A + A^\top}{2}}_{\text{symmetric}} + \underbrace{\frac{A - A^\top}{2}}_{\text{skew-symmetric}}$$

Symmetric: \(S^\top = S\); skew-symmetric: \(K^\top = -K\). This decomposition underlies many results in spectral theory and physics.

Pure Python (no NumPy), then the NumPy one-liners — understand the internals before reaching for the library.

def mat_add(A, B):
"""Add two matrices of identical shape (m×n)."""
assert len(A)==len(B) and len(A[0])==len(B[0])
return [[A[i][j]+B[i][j] for j in range(len(A[0]))]
for i in range(len(A))]
def scalar_mul(c, A):
"""Multiply every entry of A by scalar c."""
return [[c*A[i][j] for j in range(len(A[0]))]
for i in range(len(A))]
def transpose(A):
"""Transpose: rows become columns. (A^T)_ij = A_ji."""
m, n = len(A), len(A[0])
return [[A[i][j] for i in range(m)] # swap i,j
for j in range(n)]

Key Takeaways
▼

When these operations appear in ML:

  • Addition: residual connections (ResNet), bias addition in linear layers, gradient accumulation
  • Scalar mult: learning-rate scaling of gradients, weight decay (\(W \leftarrow (1-\lambda)W\)), temperature scaling of logits
  • Transpose: computing \(X^\top X\) (Gram matrix), backpropagation weight updates \(\nabla_W = X^\top \delta\), attention score \(QK^\top\)
💡 Interview Must-Know

(AB)ᵀ = BᵀAᵀ. This identity shows up in every derivation involving transposes of products — GLS, backprop, PCA, SVD proofs. Prove it entry-wise in under 60 seconds.

Complexity: All three operations on an \(m \times n\) matrix run in \(O(mn)\) — linear in the number of entries. No fancy algorithms needed.
