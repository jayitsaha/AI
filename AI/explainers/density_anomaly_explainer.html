Density-based Anomaly Detection: DBSCAN

How sparse-neighborhood points become anomalies — automatically, without specifying cluster count.

Intermediate Unsupervised Learning Anomaly Detection ε · minPts · NOISE
1
Understanding the Concept
▼

What is anomaly detection? The goal is to flag observations that deviate so strongly from the majority that they are likely produced by a different, rare process — fraud transactions, sensor malfunctions, network intrusions. Most anomaly detectors need a "normal" reference or must know how many clusters to expect. DBSCAN needs neither.

The DBSCAN insight: A point is normal if its local neighborhood is dense — i.e., at least \(\text{minPts}\) other points fall within radius \(\varepsilon\). A point whose neighborhood is sparse joins no cluster and is automatically labelled NOISE. Those NOISE points are the anomalies.

Key Insight

You never need to say "there are k anomalies." DBSCAN discovers dense regions organically; anything left over is an anomaly by definition. The decision emerges from the data's own geometry.

Analogy: Imagine a city map with dots for people. Clusters are neighbourhoods — many people close together. An anomaly is a lone hiker miles from the nearest town: no dense neighbourhood, no cluster, flagged as NOISE.

Versus distance-only methods (e.g., k-NN distance score, isolation forest): those assign a continuous score and pick a threshold. DBSCAN produces a hard binary NOISE label as a by-product of clustering — no additional thresholding step required.

2
How DBSCAN Works Internally
▼

DBSCAN classifies every point into one of three roles before labelling anomalies:

  • CoreHas ≥ minPts neighbours within ε. Can seed or expand a cluster.
  • BorderWithin ε of a core point but has < minPts own neighbours. Assigned to core's cluster.
  • NOISENot within ε of any core point. → Anomaly.

Algorithm (pseudocode):

for each unvisited point p:
mark p as visited
N = RangeQuery(p, ε) # all points within distance ε
if |N| < minPts:
label p = NOISE # ← anomaly candidate
else:
C = new cluster
expand(p, N, C, ε, minPts) # BFS/DFS flood-fill
for each q in N:
N_q = RangeQuery(q, ε)
if |N_q| ≥ minPts: N += N_q # grow the frontier
if q not yet in a cluster: assign q → C
Complexity

With a spatial index (k-d tree / ball tree) RangeQuery runs in \(\mathcal{O}(\log n)\), giving overall \(\mathcal{O}(n \log n)\). Without indexing: \(\mathcal{O}(n^2)\).

Why ε and minPts matter for anomaly detection: Small ε (tight balls) → more NOISE points flagged. Large minPts → stricter density requirement → more points labelled NOISE. Together they encode the analyst's definition of "normal density."

Design Decision — No Cluster Count

Unlike k-means which needs k, DBSCAN finds clusters implicitly. This is a fundamental advantage for anomaly detection: you don't need to guess how many "normal" modes exist.

3
The Math Behind It
▼

Let \(\mathcal{X} = \{x_1, \dots, x_n\} \subset \mathbb{R}^d\) be the dataset and \(d(\cdot,\cdot)\) a metric (typically Euclidean).

ε-neighbourhood of point \(x_i\):

$$N_\varepsilon(x_i) = \{x_j \in \mathcal{X} : d(x_i, x_j) \le \varepsilon\}$$

Core point condition: \(x_i\) is a core point iff

$$|N_\varepsilon(x_i)| \ge \text{minPts}$$

Direct density-reachability: \(x_j\) is directly density-reachable from \(x_i\) iff \(x_i\) is a core point and \(x_j \in N_\varepsilon(x_i)\).

Density-reachability (transitive closure): \(x_k\) is density-reachable from \(x_i\) if there exists a chain \(x_i = p_1, p_2, \dots, p_m = x_k\) where each \(p_{t+1}\) is directly density-reachable from \(p_t\).

Density-connectivity: \(x_i\) and \(x_j\) are density-connected if there exists a core point \(o\) from which both are density-reachable. A cluster \(C\) is the maximal set of mutually density-connected points.

Anomaly label:

$$\text{label}(x_i) = \begin{cases} \text{NOISE} & \text{if } x_i \notin \text{any cluster} \\ C_k & \text{otherwise} \end{cases}$$

Choosing ε via the k-distance plot: Compute \(d_k(x_i)\), the distance from \(x_i\) to its \(k\)-th nearest neighbour where \(k = \text{minPts}-1\). Sort values in descending order and look for the "elbow" — the sharp rise indicates the natural scale of dense clusters:

$$\varepsilon^* = \arg\max_\varepsilon \; \Delta\bigl(\text{sorted } d_k\bigr)$$
Common Misconception

DBSCAN NOISE ≠ statistical noise. A NOISE point is simply one that fails the density criterion. In low-density but legitimate sub-groups it will be mislabelled as anomalous — ε and minPts must match the data's density scale.

Key Takeaways & When to Use
▼
✓ USE when:
  • Clusters are irregularly shaped
  • You don't know k in advance
  • Anomalies are genuinely sparse outliers
  • Data has meaningful spatial structure
✗ AVOID when:
  • Density varies wildly (HDBSCAN preferred)
  • High-dimensional data (curse of dimensionality)
  • You need calibrated anomaly scores, not labels

Remember One Thing

DBSCAN anomaly detection = points that can't join any dense neighbourhood. ε controls the radius of that neighbourhood; minPts controls what "dense" means. Tune both on a k-distance elbow plot.

6
Code — From Scratch & Production
▼

From scratch (NumPy):

import numpy as np
def dbscan(X, eps, min_pts):
"""Returns array of labels: -1 = NOISE (anomaly), 0,1,... = cluster id."""
n = len(X)
labels = np.full(n, -2) # -2 = unvisited
cluster_id = -1
def range_query(idx):
# Euclidean distance to all other points
dists = np.linalg.norm(X - X[idx], axis=1)
return np.where(dists <= eps)[0].tolist()
for i in range(n):
if labels[i] != -2: continue # already visited
neighbours = range_query(i)
if len(neighbours) < min_pts:
labels[i] = -1 # NOISE → anomaly
continue
cluster_id += 1
labels[i] = cluster_id
seed_set = list(neighbours)
while seed_set:
q = seed_set.pop()
if labels[q] == -1: labels[q] = cluster_id # rescue border
if labels[q] != -2: continue
labels[q] = cluster_id
q_nbrs = range_query(q)
if len(q_nbrs) >= min_pts: seed_set.extend(q_nbrs)
return labels # labels == -1 are anomalies

Production (scikit-learn):

from sklearn.cluster import DBSCAN
from sklearn.neighbors import NearestNeighbors
import numpy as np
# Step 1: choose ε via k-distance elbow (k = minPts - 1)
k = 4
nbrs = NearestNeighbors(n_neighbors=k).fit(X)
dists, _ = nbrs.kneighbors(X)
k_dist = np.sort(dists[:, -1])[::-1] # descending k-dist
# Plot k_dist → pick ε at the elbow
# Step 2: fit DBSCAN
db = DBSCAN(eps=0.5, min_samples=5, algorithm='ball_tree', metric='euclidean')
labels = db.fit_predict(X)
anomalies = X[labels == -1] # NOISE = anomalies
print(f"Anomaly rate: {(labels==-1).mean():.2%}")
# ⚠️ Gotcha: DBSCAN does not scale to millions of rows without approximation.
# Use HDBSCAN (faster, variable density) for large datasets.
