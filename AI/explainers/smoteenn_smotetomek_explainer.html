SMOTEENN & SMOTETomek

Combined Over + Under-Sampling — Cleaner Class Boundaries for Imbalanced Data
Intermediate Classical ML Imbalanced Data Part III
1
Understanding the Concept

When you train a classifier on imbalanced data (e.g., 99% negatives, 1% positives), the model learns to mostly predict the majority class — it's the lazy win. SMOTEENN and SMOTETomek are two-phase data-level fixes: first oversample the minority to balance counts, then clean the resulting dataset to remove noisy and borderline examples that confuse the classifier.

💡 Core Insight

SMOTE creates new minority examples by interpolating between existing ones. Then ENN (or Tomek Links) acts as a surgeon — cutting out overlapping, mislabelled-looking points. The result is a cleaner decision boundary than either technique alone.

Real-World Analogy: Imagine training fraud detection. You only have 100 fraud cases vs 10,000 legit ones. SMOTE is like finding 100 real fraud receipts and carefully generating plausible variants of them to fill the gap. ENN/Tomek-links then look at the combined set and erase any forged receipts that ended up in the legit pile (or vice-versa) — noise that would confuse the detector.

🔑 Key Property

Both methods are hybrid resampling: oversample first (SMOTE), then undersample/clean (ENN or Tomek). Applied to training data only — never the test set.

2
How It Works Internally

Phase 1 — SMOTE (Synthetic Minority Over-sampling Technique)

For each minority sample \(\mathbf{x}_i\), find its \(k\) nearest minority neighbours. Randomly pick one neighbour \(\mathbf{x}_{nn}\) and generate a synthetic point:

$$\mathbf{x}_{syn} = \mathbf{x}_i + \lambda \cdot (\mathbf{x}_{nn} - \mathbf{x}_i), \quad \lambda \sim \text{Uniform}(0,1)$$

Repeat until the desired ratio is reached. This populates minority regions of feature space without pure duplication.

Phase 2a — ENN Cleaning (for SMOTEENN)

Edited Nearest Neighbours (ENN): for every sample in the combined dataset (both classes), find its \(k\) nearest neighbours (typically \(k=3\)). If the majority class label disagrees with the sample's own label, remove that sample. This removes borderline and noisy points from both classes.

Phase 2b — Tomek Links Cleaning (for SMOTETomek)

A Tomek link is a pair \((\mathbf{x}_i, \mathbf{x}_j)\) from opposite classes where no other point is closer to either than they are to each other — i.e., they are mutual nearest neighbours across the class boundary. Removing the majority-class member of each link shaves the boundary clean.

⚠️ Design Difference
  • ENN removes more aggressively — scans all samples, purges based on neighbourhood disagreement. Both majority and minority points can be removed.
  • Tomek Links is conservative — only removes the majority-class member of a link pair. Minority points are never removed.

Why combine? SMOTE alone can create synthetic points in overlapping / noisy regions (where the minority and majority already bleed into each other). The cleaning phase retroactively removes exactly those trouble spots, yielding a cleaner margin.

3
The Math Behind It

SMOTE Interpolation

Let \(\mathcal{M} = \{\mathbf{x}_1,\ldots,\mathbf{x}_m\}\) be minority samples in \(\mathbb{R}^d\). For each \(\mathbf{x}_i\), compute the set of \(k\)-nearest neighbours within \(\mathcal{M}\):

$$\text{KNN}_k(\mathbf{x}_i) = \{\mathbf{x}_{(1)},\ldots,\mathbf{x}_{(k)}\} \subset \mathcal{M}$$

Sample a neighbour \(\mathbf{x}_{nn} \sim \text{Uniform}(\text{KNN}_k(\mathbf{x}_i))\) and a scalar \(\lambda \sim \text{Uniform}(0,1)\). The synthetic sample is the convex combination:

$$\mathbf{x}_{syn} = \mathbf{x}_i + \lambda(\mathbf{x}_{nn} - \mathbf{x}_i) = (1-\lambda)\mathbf{x}_i + \lambda\mathbf{x}_{nn}$$

ENN Removal Rule

After SMOTE, let \(\mathcal{D}' = \mathcal{M}_{syn} \cup \mathcal{M} \cup \mathcal{J}\) (synthetic minority + original minority + majority). For each point \(\mathbf{x} \in \mathcal{D}'\) with label \(y\):

$$\text{Remove } \mathbf{x} \text{ if } \operatorname{mode}\!\left(\{y_j : \mathbf{x}_j \in \text{KNN}_3(\mathbf{x})\}\right) \neq y$$

i.e., if the majority vote of 3-NN disagrees with the sample's own label, it is a borderline/noisy point and is deleted.

Tomek Link Definition

A pair \((\mathbf{x}_i, \mathbf{x}_j)\) with \(y_i \neq y_j\) forms a Tomek link iff:

$$d(\mathbf{x}_i, \mathbf{x}_j) < d(\mathbf{x}_i, \mathbf{x}_k) \text{ and } d(\mathbf{x}_i, \mathbf{x}_j) < d(\mathbf{x}_j, \mathbf{x}_k) \quad \forall \mathbf{x}_k \in \mathcal{D}' \setminus \{\mathbf{x}_i, \mathbf{x}_j\}$$

SMOTETomek removes the majority-class member \(\mathbf{x}_j\) from each such link.

📐 Sampling Ratio

SMOTE typically targets a ratio \(r = |\mathcal{J}| / |\mathcal{M}|\). Number of synthetic samples per minority point: \(\lceil (r-1) \cdot m / m \rceil = r - 1\) on average (when \(k\) neighbours are available). Default is often 1:1 (equal class sizes).

✅ When to Use What
  • SMOTEENN — when classes heavily overlap and you need aggressive cleaning. Produces a much smaller but cleaner training set.
  • SMOTETomek — when classes are mostly separated but the boundary is cluttered; conservative cleaning, retains more data.
  • SMOTE alone — when data is clean and overlap is minimal; noise removal would throw away valuable examples.
⚠️ Critical Gotcha

Apply resampling only on training folds inside cross-validation (use imbalanced-learn's Pipeline). Applying before splitting contaminates the test set with synthetic data — severe data leakage.
