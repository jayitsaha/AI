1
Understanding the Paradigm Shift
▼

The Evolution: Image generation via latent diffusion has undergone a massive architectural and mathematical revolution. We trace this journey through three landmark open-weights models: Stable Diffusion XL (SDXL), Stable Diffusion 3 (SD3), and Black Forest Labs' FLUX.1.

Historically, latent diffusion models relied on a convolutional UNet backbone to predict noise at various resolution scales, using cross-attention mechanisms to inject text prompts. While highly successful, UNets struggle with fine spatial details, text rendering, complex prompt alignment, and scaling efficiency.

To overcome these bottlenecks, modern architectures have transitioned to Diffusion Transformers (DiTs). Rather than using convolutions, DiTs patchify latent representations and process them using standard self-attention blocks. Concurrently, the underlying mathematics shifted from predicting noise vectors (DDPM/DDIM) to predicting straight-line trajectories via Flow Matching.

💡 Core Architecture Shift

SDXL (2023): Convolutional UNet + Standard DDIM/DPMSolver (Noise Prediction).
SD3 (2024): Multimodal Diffusion Transformer (MMDiT) + Rectified Flow Matching.
FLUX (2024): Double & Single Stream DiT + Shifted Flow Matching + Rotary Position Embeddings (RoPE).

2
How It Works Internally
▼

1. Stable Diffusion XL (SDXL)

SDXL represents the pinnacle of UNet-based latent diffusion. It uses a dual text encoder system (CLIP ViT-L and OpenCLIP ViT-bigG) to generate conditioning vectors. To improve generation quality, SDXL introduced micro-conditioning (conditioning the model on original image size and crop coordinates) to prevent the model from cropping out subjects during training.

2. Stable Diffusion 3 (SD3) & MMDiT

SD3 replaces the UNet with a Multimodal Diffusion Transformer (MMDiT). Instead of treating text as a secondary signal injected via cross-attention, MMDiT processes image latents and text embeddings in parallel. It defines two separate sets of weights for the text and image sequences, allowing them to retain domain-specific representations while performing joint attention across modalities. SD3 also scales its text understanding by adding a massive third text encoder: T5-XXL.

3. FLUX.1 (BFL)

FLUX refines the DiT concept into a highly scalable 12-billion parameter model. It utilizes a hybrid block structure consisting of Double Stream Blocks (where text and image sequences maintain separate linear projections but perform joint attention) followed by Single Stream Blocks (where text and image sequences are concatenated along the sequence dimension and processed by unified linear projections). FLUX incorporates Rotary Position Embeddings (RoPE) adapted for 2D spatial grids, allowing it to preserve exact relative positions of image patches, leading to superior text rendering and structural anatomy.

🔑 Joint vs. Cross Attention

In Cross-Attention (SDXL), image features query text features, but text features do not update based on image context. In Joint Attention (SD3/FLUX), both modalities are concatenated into a single sequence, allowing bidirectional information flow: the image adapts to the text, and the text representations are dynamically contextualized by the image layout.

3
The Math: Flow Matching vs. Traditional Diffusion
▼

Traditional Diffusion (SDXL)

Traditional diffusion models define a forward process that gradually adds Gaussian noise to data \(x_1\), producing noisy latents \(x_t\). The neural network is trained to predict either the added noise \(\epsilon\) or the velocity vector \(v\). The trajectories are curved, requiring complex curved-path solvers (like DPMSolver++ or UniPC) to generate images in 20-30 steps.

Rectified Flow Matching (SD3 & FLUX)

Flow Matching simplifies the generative path by constructing a straight-line probability path between the noise distribution \(p_0\) (at \(t=0\)) and the data distribution \(p_1\) (at \(t=1\)). The linear interpolation is defined as:

$$x_t = (1 - t)x_0 + t x_1$$

The true target vector field (velocity) generating this straight line is exactly:

$$u_t(x_t | x_1) = \frac{d}{dt}x_t = x_1 - x_0$$

The neural network \(v_\theta(x_t, t)\) is trained to predict this velocity directly using a simple Mean Squared Error (MSE) loss:

$$\mathcal{L}_{\text{FM}}(\theta) = \mathbb{E}_{t \sim \mathcal{U}(0,1), x_0 \sim \mathcal{N}(0, I), x_1 \sim p_{\text{data}}} \left[ \| v_\theta(x_t, t) - (x_1 - x_0) \|^2 \right]$$

Time-Step Shifting (FLUX)

High-resolution images require finer details that are typically resolved in the middle or early stages of the denoising process. FLUX introduces a Time-Step Shift parameter \(s\) to warp the sampling schedule, concentrating more function evaluations around critical transition phases:

$$t_{\text{shifted}} = \frac{s \cdot t}{1 + (s - 1)t}$$

When \(s > 1\), the time steps are shifted toward \(t=1\) (the noise end), allocating more steps to resolve high-frequency structures.

The architectural shift from UNet to DiT combined with Flow Matching has unlocked unprecedented generation capabilities. Below is a comprehensive comparison of the three systems:

💡 Why FLUX Renders Text So Well

By leveraging RoPE (Rotary Position Embeddings), FLUX preserves exact 2D spatial relationships of patches. Traditional absolute position embeddings lose relative distance metrics when sequences are flattened. RoPE applies a rotation to the Query and Key vectors in the complex plane, ensuring the attention mechanism natively understands "left-of", "right-of", and precise character-level spacing.

Code Trace: Flow Matching DiT Block
▼

This PyTorch-style snippet demonstrates the core execution flow of a joint-modality Double Stream DiT block with RoPE, similar to the layers found in FLUX.

import torch
import torch.nn as nn
class DoubleStreamBlock(nn.Module):
def __init__(self, d_img, d_txt, num_heads):
super().__init__()
self.num_heads = num_heads
# Separate projections for Image and Text sequences
self.qkv_img = nn.Linear(d_img, d_img * 3)
self.qkv_txt = nn.Linear(d_txt, d_txt * 3)
self.proj_img = nn.Linear(d_img, d_img)
self.proj_txt = nn.Linear(d_txt, d_txt)
def apply_rope(self, q, k, rope_embeddings):
# Apply 2D Rotary Position Embeddings to preserve spatial grids
cos, sin = rope_embeddings
return (q * cos) + (self.rotate_half(q) * sin), (k * cos) + (self.rotate_half(k) * sin)
def forward(self, img_x, txt_x, rope):
# 1. Project to Q, K, V
q_i, k_i, v_i = self.qkv_img(img_x).chunk(3, dim=-1)
q_t, k_t, v_t = self.qkv_txt(txt_x).chunk(3, dim=-1)
# 2. Apply Rotary Position Embeddings (RoPE) to Image QK
q_i, k_i = self.apply_rope(q_i, k_i, rope)
# 3. Concatenate sequences for Joint Attention
q = torch.cat([q_i, q_t], dim=1)
k = torch.cat([k_i, k_t], dim=1)
v = torch.cat([v_i, v_t], dim=1)
# 4. Compute scaled dot-product attention
attn = torch.nn.functional.scaled_dot_product_attention(q, k, v)
# 5. Split sequences back to original modalities
out_i, out_t = attn.split([img_x.size(1), txt_x.size(1)], dim=1)
# 6. Apply final linear projections and return residuals
return img_x + self.proj_img(out_i), txt_x + self.proj_txt(out_t)
