Mutual Information \(I(X;Y)\)

The information shared between two random variables — how much knowing Y tells you about X
Intermediate Information Theory Math & Stats O(n²) joint
1
Understanding Mutual Information
▼

What is it? Mutual information \(I(X;Y)\) measures how much information two random variables share. Before you observe \(Y\), you have some uncertainty about \(X\), quantified by \(H(X)\) bits. After observing \(Y\), your uncertainty drops to \(H(X|Y)\) bits. Mutual information is the reduction: \(I(X;Y) = H(X) - H(X|Y)\).

Analogy: Imagine X is whether it actually rains tomorrow, and Y is today's weather forecast. Before checking the forecast, your uncertainty about rain is, say, 1 bit. After seeing the forecast, your uncertainty drops — the difference is the mutual information. A perfect forecast gives \(I = H(X)\) (no uncertainty left). A completely uninformative forecast gives \(I = 0\).

One-sentence summary: Mutual information is the amount of information that one variable contains about another — it is zero if and only if the variables are statistically independent.

If you remember one thing

\(I(X;Y) = H(X) - H(X|Y)\): the uncertainty about X before minus the uncertainty about X after knowing Y. It is symmetric: \(I(X;Y) = I(Y;X)\). It equals zero if and only if \(X\) and \(Y\) are independent.

2
Four Equivalent Formulas
▼

The four equivalent definitions of mutual information are all algebraically equal. Understanding each gives a different geometric or information-theoretic intuition.

Formula 1 — Reduction in Uncertainty

$$I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)$$

How much does knowing \(Y\) reduce uncertainty about \(X\)? By symmetry, the same amount that knowing \(X\) reduces uncertainty about \(Y\).

Formula 2 — Venn Overlap of Entropies

$$I(X;Y) = H(X) + H(Y) - H(X,Y)$$

The joint entropy \(H(X,Y)\) double-counts the shared information. Subtracting it recovers exactly the overlap (the information that "belongs" to both). If X and Y are independent, \(H(X,Y) = H(X)+H(Y)\), so \(I=0\).

Formula 3 — KL Divergence from Independence

$$I(X;Y) = D_{\mathrm{KL}}\!\left(p(x,y)\,\|\,p(x)p(y)\right) = \sum_{x,y} p(x,y)\log\frac{p(x,y)}{p(x)p(y)}$$

MI is the KL divergence from the joint to the product of marginals. Independence means the joint equals the product — so KL = 0. Any dependence makes the distributions differ — KL > 0.

Formula 4 — Expected Pointwise MI

$$I(X;Y) = \mathbb{E}_{p(x,y)}\left[\log\frac{p(x,y)}{p(x)p(y)}\right]$$

The expectation of the pointwise mutual information (PMI) \(\log p(x,y) - \log p(x) - \log p(y)\). PMI is positive when the pair \((x,y)\) co-occurs more than chance; negative when it co-occurs less than chance.

Key Property: Symmetry and Non-Negativity

\(I(X;Y) = I(Y;X) \geq 0\). Non-negativity follows from KL divergence being non-negative (Gibbs' inequality). \(I=0\) if and only if \(X \perp Y\).

3
Why It Works — The Math
▼

Numerical Trace — Noisy Binary Channel

Let \(X \sim \text{Bernoulli}(0.5)\) and \(Y\) be a noisy copy with flip probability 0.2. The joint distribution is:

$$p(0,0)=p(1,1)=0.4,\quad p(0,1)=p(1,0)=0.1$$

Step 1 — Marginals: \(p(X=0)=p(X=1)=0.5\), so \(H(X) = -2(0.5\log_2 0.5) = 1\) bit.

Step 2 — Joint entropy:

$$H(X,Y) = -(2 \cdot 0.4\log_2 0.4 + 2 \cdot 0.1\log_2 0.1) = 1.7219\text{ bits}$$

Step 3 — Mutual information (Formula 2):

$$I(X;Y) = H(X)+H(Y)-H(X,Y) = 1+1-1.7219 = 0.2781\text{ bits}$$

Step 4 — KL verification: \(p(x)p(y) = 0.25\) for all cells. Thus:

$$I(X;Y) = 2\cdot 0.4\log_2\frac{0.4}{0.25} + 2\cdot 0.1\log_2\frac{0.1}{0.25} = 0.2781\text{ bits}\;\checkmark$$

Proof of Non-Negativity (Gibbs' Inequality)

Since \(\ln t \leq t - 1\) for all \(t > 0\) (with equality iff \(t=1\)), we have:

$$-D_{\mathrm{KL}}(p\|q) = \sum_x p(x)\ln\frac{q(x)}{p(x)} \leq \sum_x p(x)\left(\frac{q(x)}{p(x)}-1\right) = \sum_x q(x) - \sum_x p(x) = 0$$

Therefore \(D_{\mathrm{KL}} \geq 0\), which implies \(I(X;Y) \geq 0\), with equality iff \(p(x,y)=p(x)p(y)\) everywhere.

Bounds

$$0 \leq I(X;Y) \leq \min\bigl(H(X),\, H(Y)\bigr)$$

Upper bound reached when one variable is a deterministic function of the other (e.g., \(Y=X\) gives \(I=H(X)\)).

Common Pitfall — MI vs Correlation

Pearson correlation only captures linear dependence. MI captures any statistical dependence, including nonlinear relationships. Two variables can have zero correlation but positive MI (e.g., \(Y = X^2\) with symmetric X).

Key Takeaways & Applications
▼

When \(I(X;Y) = 0\): X and Y are statistically independent — knowing one gives zero information about the other. Always true for independent random variables.

When \(I(X;Y) = H(X)\): Y completely determines X (X is a deterministic function of Y). No residual uncertainty remains.

  • Feature selection: Rank features by \(I(\text{feature}; \text{label})\). High MI features are most predictive. Used in mRMR, MIFS, and sklearn's mutual_info_classif.
  • InfoNCE / contrastive learning: SimCLR and CLIP maximize a lower bound on \(I(\text{image}; \text{augmented view})\) or \(I(\text{image}; \text{caption})\).
  • ICA / disentanglement: Minimize \(I(z_i; z_j)\) to encourage statistically independent latent factors.
  • Channel capacity: Shannon capacity \(C = \max_{p(x)} I(X;Y)\) is the maximum reliable communication rate through a noisy channel.
  • Causal inference: Conditional MI \(I(X;Y|Z) = 0\) tests conditional independence — the basis of constraint-based causal discovery algorithms (PC, FCI).
The Fundamental Identity

All four formulas are identical: \(I(X;Y) = H(X)-H(X|Y) = H(Y)-H(Y|X) = H(X)+H(Y)-H(X,Y) = D_{\mathrm{KL}}(p_{XY}\|p_Xp_Y)\). Choose whichever view is most useful for your problem.

Code Trace

import numpy as np
# Joint distribution: noisy binary channel (flip prob 0.2)
pxy = np.array([[0.4, 0.1], # p(X=0,Y=0), p(X=0,Y=1)
[0.1, 0.4]]) # p(X=1,Y=0), p(X=1,Y=1)
# Marginals
px = pxy.sum(axis=1) # [0.5, 0.5]
py = pxy.sum(axis=0) # [0.5, 0.5]
# Shannon entropies (base-2 bits)
H_X = -np.sum(px * np.log2(px)) # = 1.0 bit
H_Y = -np.sum(py * np.log2(py)) # = 1.0 bit
H_XY = -np.sum(pxy * np.log2(pxy)) # = 1.7219 bits
# Formula 1: H(X) + H(Y) - H(X,Y)
MI_1 = H_X + H_Y - H_XY # = 0.2781 bits
# Formula 2: KL(p(x,y) || p(x)p(y))
prod_xy = np.outer(px, py)
MI_2 = np.sum(pxy * np.log2(pxy / prod_xy)) # = 0.2781 bits
# Feature selection: rank features by MI with label Y
from sklearn.feature_selection import mutual_info_classif

top_features = np.argsort(scores)[::-1][:10]
