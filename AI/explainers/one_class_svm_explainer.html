One-Class SVM

Schölkopf's kernel-based anomaly detector — learns a tight boundary around normal data in feature space

Advanced Anomaly Detection Unsupervised Learning Kernel Methods

Imagine you are a museum security guard who has seen thousands of legitimate visitors. You build an intuition for what "normal" looks like — how people walk, where they linger, their pace. When an unusual person appears, you flag them as suspicious — not because you know what a thief looks like, but because they fall outside your model of normal.

One-Class SVM does exactly this for data. You train it on normal examples only. It learns a compact decision boundary around the normal class in a high-dimensional kernel feature space. Any new point that falls outside this boundary is declared an anomaly. No labeled outliers needed.

Key Insight
Rather than separating two classes, One-Class SVM separates the entire normal dataset from the origin in the Reproducing Kernel Hilbert Space (RKHS). The origin acts as a proxy for "everything else." Points that map close to the origin in feature space are flagged as anomalies.

The algorithm was introduced by Schölkopf et al. (2001) as an extension of Support Vector Machines to the one-class setting. It introduces a hyperparameter \(\nu \in (0, 1]\) that simultaneously controls (a) an upper bound on the fraction of outliers in the training data, and (b) a lower bound on the fraction of training points that will be support vectors.

One-Line Summary
One-Class SVM finds the maximum-margin hyperplane in kernel space that separates all (or most) training points from the origin — everything on the origin's side is an anomaly.

One-Class SVM operates in three conceptual phases:

  1. Kernel embedding — Each input \(\mathbf{x}_i \in \mathbb{R}^d\) is implicitly mapped via \(\phi: \mathbb{R}^d \to \mathcal{H}\) to a (possibly infinite-dimensional) Reproducing Kernel Hilbert Space. With the RBF kernel \(k(\mathbf{x}, \mathbf{x}') = e^{-\gamma\|\mathbf{x}-\mathbf{x}'\|^2}\), this RKHS has infinite dimension.
  2. Hyperplane fitting — Find the hyperplane \(\langle \mathbf{w}, \phi(\mathbf{x}) \rangle = \rho\) that separates the data from the origin with maximum margin \(\rho / \|\mathbf{w}\|\) in \(\mathcal{H}\).
  3. Decision function — Score a new point: \(f(\mathbf{x}) = \text{sign}\!\left(\sum_i \alpha_i k(\mathbf{x}_i, \mathbf{x}) - \rho\right)\). If \(f(\mathbf{x}) = +1\): normal. If \(-1\): anomaly.
Primal Optimization Problem
$$\min_{\mathbf{w},\rho,\xi_i} \;\frac{1}{2}\|\mathbf{w}\|^2 + \frac{1}{\nu n}\sum_{i=1}^n \xi_i - \rho$$

subject to \(\langle \mathbf{w}, \phi(\mathbf{x}_i)\rangle \geq \rho - \xi_i\) and \(\xi_i \geq 0\) for all \(i\).

Here \(\xi_i\) are slack variables; \(\nu\) controls how many points may be on the wrong side.

The dual problem (which is what solvers actually optimize) becomes:

$$\min_{\alpha} \;\frac{1}{2}\sum_{i,j}\alpha_i\alpha_j k(\mathbf{x}_i,\mathbf{x}_j) \quad\text{s.t.}\quad 0\leq\alpha_i\leq\frac{1}{\nu n},\;\sum_i\alpha_i=1$$

The kernel matrix \(K_{ij} = k(\mathbf{x}_i, \mathbf{x}_j)\) is the only thing that touches the data — the explicit \(\phi\) mapping is never computed (kernel trick). After solving, \(\rho\) is recovered from any support vector on the margin boundary, and the decision function is expressed purely via kernel evaluations.

Design Choice: Why the Origin?
The origin \(\mathbf{0} \in \mathcal{H}\) was chosen as the negative exemplar because it always exists, requires no labeled anomalies, and with universal kernels (like RBF) it is infinitely far from any finite dataset in RKHS. This avoids the need for any negative-class examples while still providing a meaningful reference point.

The RBF kernel \(\gamma\) controls the effective radius of influence of each training point. Large \(\gamma\) → narrow, complex boundary hugging each point. Small \(\gamma\) → broad, smooth boundary. Combined with \(\nu\), you get full control over boundary tightness and outlier tolerance.

Starting from the primal, form the Lagrangian with multipliers \(\alpha_i \geq 0\) and \(\beta_i \geq 0\):

$$L = \frac{1}{2}\|\mathbf{w}\|^2 + \frac{1}{\nu n}\sum_i\xi_i - \rho - \sum_i\alpha_i(\langle\mathbf{w},\phi(\mathbf{x}_i)\rangle - \rho + \xi_i) - \sum_i\beta_i\xi_i$$

Taking stationarity conditions:

  • \(\partial L/\partial \mathbf{w} = 0 \Rightarrow \mathbf{w} = \sum_i \alpha_i \phi(\mathbf{x}_i)\)
  • \(\partial L/\partial \rho = 0 \Rightarrow \sum_i \alpha_i = 1\)
  • \(\partial L/\partial \xi_i = 0 \Rightarrow \alpha_i + \beta_i = \frac{1}{\nu n}\)

Substituting back yields the dual:

$$\min_{\boldsymbol{\alpha}} \;\frac{1}{2}\boldsymbol{\alpha}^\top K\boldsymbol{\alpha} \quad\text{s.t.}\quad \boldsymbol{\alpha}^\top\mathbf{1}=1,\;0\leq\alpha_i\leq\frac{1}{\nu n}$$

At optimality, the decision threshold \(\rho\) is recovered from any free support vector (one with \(0 < \alpha_i < \frac{1}{\nu n}\), i.e., exactly on the margin):

$$\rho = \langle \mathbf{w}, \phi(\mathbf{x}_i)\rangle = \sum_j \alpha_j k(\mathbf{x}_j, \mathbf{x}_i)$$

The decision function for any new point \(\mathbf{x}\):

$$f(\mathbf{x}) = \mathrm{sign}\!\left(\sum_{i\in\mathrm{SV}} \alpha_i\, k(\mathbf{x}_i, \mathbf{x}) - \rho\right)$$
The ν Theorem (Schölkopf et al.)

At the solution: (1) \(\nu\) is an upper bound on the fraction of training outliers; (2) \(\nu\) is a lower bound on the fraction of support vectors. If \(\nu = 0.1\), at most 10% of training points can be on the wrong side, and at least 10% will be support vectors.

Common Misconception

\(\nu\) does not directly set the anomaly detection threshold for test data. It controls the trade-off between boundary tightness and training-set tolerance. A model trained with \(\nu=0.05\) may still flag more or fewer than 5% of test points, depending on the distribution shift between train and test.

For the RBF kernel \(k(\mathbf{x},\mathbf{x}') = \exp(-\gamma\|\mathbf{x}-\mathbf{x}'\|^2)\), note that \(k(\mathbf{x},\mathbf{x}) = 1\) always. This means all training points lie on the unit sphere in RKHS. The One-Class SVM therefore finds a spherical cap on this unit sphere that contains most training points, which is equivalent to the Minimum Enclosing Ball formulation (Support Vector Data Description, Tax & Duin 2004).

When to Use One-Class SVM
  • You only have normal-class training data (no labeled anomalies)
  • Dataset is small-to-medium (<50k samples; scales as \(O(n^2)\) to \(O(n^3)\))
  • Non-linear boundary needed (RBF kernel captures complex shapes)
  • Fraud detection, network intrusion, medical monitoring

Pitfalls
  • Curse of dimensionality: With very high-dimensional data (>1000 features), RBF kernel distances concentrate and the boundary degrades. Use PCA first.
  • Quadratic memory: Kernel matrix is \(n \times n\) — infeasible for large \(n\). Use sklearn.linear_model.SGDOneClassSVM for scale.
  • Training contamination: If training data contains anomalies, the model is polluted. \(\nu\) helps absorb some, but keep training data as clean as possible.

From-scratch dual solver (NumPy, QP via CVXOPT concept):

import numpy as np
def rbf_kernel(X, gamma=0.5):
# K[i,j] = exp(-gamma * ||x_i - x_j||^2)
sq_dists = np.sum(X**2,axis=1,keepdims=True) + np.sum(X**2,axis=1) - 2*X@X.T
return np.exp(-gamma * np.maximum(sq_dists, 0))
def decision_scores(X_train, alphas, rho, X_test, gamma=0.5):
# f(x) = sum_i alpha_i * k(x_i, x) - rho
K = np.array([[np.exp(-gamma*np.sum((xi-xj)**2))
for xi in X_train] for xj in X_test]) # (n_test, n_train)
return K @ alphas - rho # positive = normal, negative = anomaly
