Iteratively finding the largest eigenvalue via repeated matrix–vector multiplication
Foundational Lean Intermediate Linear Algebra Numerical Methods O(n²) per iteration
1
Understanding the Power Method
▼

What is this? Every matrix has special directions called eigenvectors — when you multiply the matrix by one of these vectors, it only stretches or flips it, it never rotates it. The stretch factor is called an eigenvalue. The power method is a beautifully simple algorithm that finds the direction with the largest stretch factor by repeatedly applying the matrix and re-normalizing.

Analogy: Imagine a stream of water flowing through rocks. No matter where you drop a leaf, the current (the matrix) will gradually push it toward the dominant flow channel (the dominant eigenvector). Each step the leaf gets a little closer to the main current direction. The power method is like watching that leaf drift — you stop when it stops moving.

💡 If you remember one thing

Repeated multiplication by \(A\) amplifies the dominant eigenvector component exponentially faster than all others. After normalizing each step to stay on the unit sphere, the vector rotates toward \(\mathbf{v}_1\) at a geometric rate of \(\left|\lambda_2 / \lambda_1\right|\). The Rayleigh quotient \(\rho(x) = x^\top A x \,/\, x^\top x\) gives the current best estimate of \(\lambda_1\) — it converges as \(|\lambda_2/\lambda_1|^{2k}\).

How the Power Method Works Internally
▼

The Core Algorithm

Start with an arbitrary nonzero vector \(\mathbf{x}_0\). At each step, multiply by \(A\) and normalize:

$$\mathbf{x}_{k+1} = \frac{A\mathbf{x}_k}{\|A\mathbf{x}_k\|_2}$$

Why Does It Work? — The Eigendecomposition Perspective

Suppose \(A\) has eigenvalues \(|\lambda_1| > |\lambda_2| \geq \cdots \geq |\lambda_n|\) with corresponding eigenvectors \(\mathbf{v}_1, \ldots, \mathbf{v}_n\). Write the starting vector in the eigenbasis:

$$\mathbf{x}_0 = c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \cdots + c_n \mathbf{v}_n \quad (c_1 \neq 0)$$

After \(k\) applications of \(A\) (before normalization):

$$A^k \mathbf{x}_0 = c_1 \lambda_1^k \mathbf{v}_1 + c_2 \lambda_2^k \mathbf{v}_2 + \cdots = \lambda_1^k \!\left( c_1 \mathbf{v}_1 + \sum_{i \geq 2} c_i \left(\tfrac{\lambda_i}{\lambda_1}\right)^k \mathbf{v}_i \right)$$

Because \(|\lambda_i/\lambda_1| < 1\) for \(i \geq 2\), every non-dominant component decays geometrically. After normalization the scalar \(\lambda_1^k\) cancels, and we are left with a vector converging to \(\pm\mathbf{v}_1\).

Extracting the Eigenvalue: Rayleigh Quotient

Once \(\mathbf{x}_k\) is close to \(\mathbf{v}_1\), the best scalar estimate of \(\lambda_1\) is the Rayleigh quotient:

$$\rho(\mathbf{x}_k) = \frac{\mathbf{x}_k^\top A\, \mathbf{x}_k}{\mathbf{x}_k^\top \mathbf{x}_k}$$

For a unit vector this simplifies to \(\mathbf{x}_k^\top A\,\mathbf{x}_k\). Crucially, the error in \(\rho\) is second-order: if the eigenvector error is \(O(\epsilon)\), the eigenvalue error is \(O(\epsilon^2)\). So eigenvalue convergence is twice as fast as eigenvector convergence.

🔑 Key Property — Convergence Rate

The angular error between \(\mathbf{x}_k\) and the true \(\mathbf{v}_1\) decays as \(\left|\lambda_2/\lambda_1\right|^k\). The Rayleigh quotient error decays as \(\left|\lambda_2/\lambda_1\right|^{2k}\). The algorithm converges fast when the spectral gap \(|\lambda_1| - |\lambda_2|\) is large, and slow when the two largest eigenvalues are nearly equal.

3
Why It Works — The Math
▼

Formal Convergence Theorem

Let \(A \in \mathbb{R}^{n \times n}\) be diagonalizable with eigenvalues \(|\lambda_1| > |\lambda_2| \geq \cdots \geq |\lambda_n| \geq 0\) and corresponding eigenvectors \(\{\mathbf{v}_i\}\). If the initial vector \(\mathbf{x}_0\) has nonzero component along \(\mathbf{v}_1\) (i.e., \(c_1 \neq 0\)), then the normalized iterates converge:

$$\left\|\mathbf{x}_k - \pm\mathbf{v}_1\right\|_2 = O\!\left(\left|\frac{\lambda_2}{\lambda_1}\right|^k\right) \quad \text{as } k \to \infty$$

Error Analysis — Exact Bound

Expand \(\mathbf{x}_0 = \sum_i c_i \mathbf{v}_i\) in the orthonormal eigenbasis. After normalization at step \(k\):

$$\sin \angle(\mathbf{x}_k, \mathbf{v}_1) \leq \frac{\sqrt{\sum_{i \geq 2} c_i^2}}{|c_1|} \cdot \left|\frac{\lambda_2}{\lambda_1}\right|^k$$

The prefactor \(\sqrt{\sum_{i\geq 2}c_i^2}/|c_1|\) is the ratio of the non-dominant to dominant component in \(\mathbf{x}_0\). This is why a bad starting vector (small \(|c_1|\)) leads to slower observed convergence in early iterations.

Rayleigh Quotient Convergence (Second Order)

Write \(\mathbf{x}_k = \mathbf{v}_1 + \boldsymbol{\epsilon}_k\) where \(\|\boldsymbol{\epsilon}_k\| = O(r^k)\), \(r = |\lambda_2/\lambda_1|\). Then:

$$\rho(\mathbf{x}_k) = \lambda_1 + O\!\left(\left|\frac{\lambda_2}{\lambda_1}\right|^{2k}\right)$$

because cross terms \(\mathbf{v}_1^\top A\,\boldsymbol{\epsilon}_k = \lambda_1\,\mathbf{v}_1^\top\boldsymbol{\epsilon}_k\) vanish when eigenvectors are orthogonal. Eigenvalue estimates are therefore far more accurate than eigenvector estimates at the same iteration count.

⚠️ Common Pitfall — When Power Method Fails

Equal dominant eigenvalues: if \(|\lambda_1| = |\lambda_2|\) (e.g., complex conjugate pair on a real matrix), the algorithm does not converge to a single vector. Sign issue: if \(\lambda_1 < 0\), the iterates alternate sign; you detect this because \(\|A\mathbf{x}_k\| / \|A\mathbf{x}_{k-1}\|\) converges but the vector alternates. Initial vector: if \(c_1 = 0\) exactly (measure-zero event), the method cannot find \(\lambda_1\) — but floating-point noise makes this essentially impossible in practice.

Relation to PageRank

Google's original PageRank algorithm is exactly the power method applied to a column-stochastic matrix (the web graph). The dominant eigenvalue is 1 by construction (Perron–Frobenius), and the dominant eigenvector is the stationary page-importance distribution.

From-Scratch Implementation
▼

NumPy — Clean Implementation with Convergence Check

# power_method.py — from scratch, no scipy needed
import numpy as np

def power_method(A, tol=1e-10, max_iter=1000, x0=None, seed=42):
    """
    Find the dominant eigenvalue and eigenvector of A using the power method.

    Args:
        A      : (n, n) real symmetric or general matrix
        tol    : convergence threshold on ||x_k - x_{k-1}||
        max_iter: maximum iterations
        x0     : starting vector; random if None
        seed   : RNG seed for reproducibility

    Returns:
        eigenvalue  : float, dominant eigenvalue estimate (Rayleigh quotient)
        eigenvector : (n,) unit vector
        n_iter      : iterations taken
        history     : list of (eigenvector, Rayleigh quotient) per step
    """
    n = A.shape[0]
    rng = np.random.default_rng(seed)

    # --- Step 0: initialize ---
    x = x0 if x0 is not None else rng.standard_normal(n)
    x = x / np.linalg.norm(x)                     # normalize to unit sphere

    history = []

    for k in range(max_iter):
        # --- Step 1: multiply by A ---
        w = A @ x                                  # O(n²) FLOP

        # --- Step 2: detect eigenvalue sign (before normalizing) ---
        norm_w = np.linalg.norm(w)
        if norm_w < 1e-14:
            raise ValueError("Iterate collapsed to zero; A may be singular.")

        # --- Step 3: normalize ---
        x_new = w / norm_w

        # --- Step 4: Rayleigh quotient (best eigenvalue estimate) ---
        rho = x_new @ (A @ x_new)                 # x^T A x (x is already unit)

        history.append((x_new.copy(), rho))

        # --- Step 5: convergence check ---
        if np.linalg.norm(x_new - x) < tol or np.linalg.norm(x_new + x) < tol:
            return rho, x_new, k + 1, history   # +x or -x both valid

        x = x_new

    return rho, x, max_iter, history


# --- Demo ---
if __name__ == "__main__":
    A = np.array([[3., 1.],
                  [1., 2.]])

    lam, v, iters, hist = power_method(A, x0=np.array([1., 0.]))

    print(f"Dominant eigenvalue : {lam:.10f}")
    print(f"Dominant eigenvector: {v}")
    print(f"Converged in        : {iters} iterations")
    print(f"NumPy reference     : {np.linalg.eigvals(A).max():.10f}")
    # Output:
    # Dominant eigenvalue : 3.6180339887
    # Dominant eigenvector: [0.85065081 0.52573111]
    # Converged in        : 52 iterations (tol=1e-10)
⚠️ Production Gotcha

The convergence check must handle sign ambiguity: eigenvectors are defined up to a sign, so both \(\mathbf{x}_k \approx +\mathbf{v}_1\) and \(\mathbf{x}_k \approx -\mathbf{v}_1\) are valid convergence. Check min(‖x_new − x‖, ‖x_new + x‖) < tol, not just one.

Key Takeaways & When to Use
▼

When to use the power method:

  • You only need the dominant eigenvalue/eigenvector (not the full spectrum)
  • Matrix is very large and sparse — each iteration is just one sparse matrix-vector product
  • Examples: PageRank, PCA (first PC via covariance matrix), spectral clustering (first eigenvector of Laplacian), power-flow analysis

When NOT to use:

  • You need all eigenvalues — use QR algorithm or LAPACK eigh
  • Spectral gap is tiny (near-equal dominant eigenvalues) — converges extremely slowly; use Krylov methods (Lanczos, ARPACK)
  • Non-diagonalizable matrices with repeated dominant eigenvalues

💡 Connection to ML

The first principal component in PCA is the dominant eigenvector of the data covariance matrix. Computing it via the power method (on the covariance) is equivalent to repeatedly projecting data onto the current direction and re-normalizing — the foundation of iterative PCA for streaming data. TensorFlow's tf.linalg.eigh and PyTorch's torch.linalg.eigh use LAPACK under the hood for small matrices, but power-method variants appear in distributed settings (e.g., federated PCA).
