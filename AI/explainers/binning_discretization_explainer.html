Understanding Binning / Discretization
▼

What is it? Binning (also called discretization) converts a continuous numerical feature — like age, salary, or temperature — into a set of ordered buckets. Instead of "the customer is 34 years old," you get "the customer is in the 30–40 age group." The feature goes from infinite precision to a small finite set of categories.

Why does this matter? Linear models can only learn straight-line relationships between a feature and the target. If the true relationship is U-shaped or step-like, a linear model will miss it entirely. Binning + one-hot encoding lets a linear model learn a different weight for each bucket, effectively fitting a piecewise-constant function — capturing the nonlinearity without switching to a nonlinear model.

Analogy: Imagine grading exams. Instead of recording every score from 0–100, you assign letter grades A, B, C, D, F. This loses granularity (89 and 91 both become A), but makes the data easier to reason about and can reveal patterns: "students who scored in the B range (80–89) tend to succeed in the follow-up course." Binning does exactly this for ML features.

💡 If you remember one thing

Binning lets linear models learn nonlinear relationships by approximating any smooth function as a piecewise constant — but it trades away within-bin granularity. The three main strategies differ in how they place bin edges: equal-width (uniform range), quantile (equal frequency), and supervised (entropy/tree-based, label-aware).

How Each Strategy Places Bin Edges
▼

Equal-Width Binning

Sort the data. Divide the range \([x_{\min}, x_{\max}]\) into \(k\) intervals of equal width \(w = (x_{\max} - x_{\min})/k\). Edge \(i\) is placed at \(x_{\min} + i \cdot w\). Fast (\(O(n)\) once range is known), but extremely sensitive to outliers — a single extreme value stretches all bins, causing most data to pile into a few bins.

Equal-Frequency (Quantile) Binning

Sort the data (\(O(n \log n)\)). Place edges at quantiles \(q_{i/k}\) for \(i=1,\ldots,k-1\). Each bin contains (approximately) \(\lfloor n/k \rfloor\) samples. This is robust to outliers and gives every bin a meaningful sample size, but two values that are very different in magnitude may land in the same bin if they share the same quantile region.

Supervised (Tree/Entropy-Based) Binning

Fit a decision stump (or shallow tree) on the feature vs. the label. The tree's split points define the bin edges. Splits are chosen to maximise information gain (classification) or variance reduction (regression). This is the only label-aware strategy — it discovers cut-points that are predictive. The cost is \(O(n \log n \cdot k)\) and overfitting risk when labels are noisy.

🔑 Key Invariant

All three strategies are monotone rank-preserving: if \(x_i < x_j\), then \(\text{bin}(x_i) \leq \text{bin}(x_j)\). The ordinal structure of the original feature is always maintained. Only the metric distances between values are discarded.

Downstream Encoding

After binning, the discrete bins are typically one-hot encoded (each bin becomes a binary column) or ordinal-encoded (bins become integers 0, 1, …, k-1). One-hot encoding allows a linear model to assign a completely independent weight to each bin. Ordinal encoding forces a linear model to assume a monotone response across bins.

⚠️ Granularity Loss

Values 34.1 and 39.9 in the same bin are treated as identical — any within-bin variation in the target is silently discarded. More bins → less information loss, but higher model complexity and risk of overfitting. Typical range: \(k \in \{5, 10, 20\}\).

Why It Works — The Math
▼

Piecewise-Constant Approximation

Let \(f: \mathbb{R} \to \mathbb{R}\) be the true conditional mean \(\mathbb{E}[y \mid x]\). After equal-width binning with edges \(t_0 < t_1 < \cdots < t_k\), the binned linear model approximates:

$$\hat{f}(x) = \sum_{j=1}^{k} w_j \cdot \mathbf{1}[t_{j-1} \leq x < t_j]$$

where \(w_j\) is the weight learned for bin \(j\). This is a step function. By the Stone-Weierstrass theorem, as \(k \to \infty\) and bin width \(\to 0\), the approximation converges uniformly to any continuous \(f\) on a compact domain — binning can represent arbitrarily complex relationships, at the cost of more bins.

Equal-Width Edge Formula

$$t_i = x_{\min} + i \cdot \frac{x_{\max} - x_{\min}}{k}, \quad i = 0, 1, \ldots, k$$

Quantile Edge Formula

$$t_i = F^{-1}\!\left(\frac{i}{k}\right), \quad i = 0, 1, \ldots, k$$

where \(F^{-1}\) is the empirical quantile function. The \(i\)-th quantile edge is the value below which \(i/k\) fraction of the data falls.

Information-Gain Split Criterion (Classification)

For a candidate split at threshold \(t\), let \(L = \{x_i \leq t\}\) and \(R = \{x_i > t\}\). The information gain is:

$$\Delta H(t) = H(S) - \frac{|L|}{|S|}H(L) - \frac{|R|}{|S|}H(R)$$

where \(H(S) = -\sum_c p_c \log_2 p_c\) is the Shannon entropy of the label distribution in set \(S\). The optimal split \(t^* = \underset{t}{\operatorname{argmax}}\, \Delta H(t)\) is found by sorting \(x\) and scanning all candidate thresholds — \(O(n \log n)\) per split.

📐 Numerical Example (4 points, 2 bins)

Data: \(x = [1, 5, 7, 20]\), labels binary.
Equal-width: range = 19, width = 9.5. Edges: [1, 10.5, 20]. Bins: {1,5,7} | {20}. Sizes: 3, 1.
Quantile: 50th pct = midpoint of 5 and 7 = 6. Edges: [1, 6, 20]. Bins: {1,5} | {7,20}. Sizes: 2, 2.

Comparison & Key Takeaways
▼

When to use each strategy:

  • Equal-width: Feature is roughly uniformly distributed with no outliers. Fast, interpretable. Good for visualisation and reporting.
  • Quantile (equal-frequency): Feature is skewed or has heavy tails. Guarantees each bin has data. Default choice in most production pipelines (sklearn's KBinsDiscretizer(strategy='quantile')).
  • Supervised (tree-based): Label is available (never in a test-time pipeline!), relationship is known to be nonlinear, and you want label-informed splits. Risk: leakage if not done inside CV folds.

Advantages of binning:

  • Lets linear models capture nonlinear relationships (key for logistic regression, linear SVM)
  • Makes features robust to outliers (single extreme value falls in an edge bin)
  • Handles missing values naturally (add an "Unknown" bin)
  • Fast and interpretable: "customer in 30–40 age group"

Disadvantages / trade-offs:

  • Loses within-bin information — values 34 and 39 become indistinguishable
  • Boundary sensitivity: 40.0 and 40.1 may fall in adjacent bins with very different weights
  • Supervised binning risks target leakage if edges are computed on the full dataset before train/test split
  • Many bins → high-cardinality categorical → sparse one-hot matrix
💡 Decision Guide

Uniform feature + no outliers → equal-width. Skewed feature or outliers → quantile. Known nonlinear label relationship + proper CV → supervised. When in doubt: quantile is the safest default.

Code Trace

import numpy as np
from sklearn.preprocessing import KBinsDiscretizer
# Skewed feature (log-normal), 20 samples
rng = np.random.default_rng(42)
x = rng.lognormal(mean=2.5, sigma=1.0, size=20).reshape(-1, 1)
y = (x.ravel() > 12).astype(int) # nonlinear binary target
# Equal-width binning (k=5)
ew = KBinsDiscretizer(n_bins=5, encode='onehot-dense', strategy='uniform')
X_ew = ew.fit_transform(x) # shape (20, 5)
print("Equal-width edges:", ew.bin_edges_[0].round(1))
# → e.g. [ 1.2, 20.0, 38.8, 57.6, 76.4, 95.2]
# Quantile (equal-frequency) binning (k=5)
qb = KBinsDiscretizer(n_bins=5, encode='onehot-dense', strategy='quantile')
X_qb = qb.fit_transform(x) # shape (20, 5)
print("Quantile edges:", qb.bin_edges_[0].round(1))
# → e.g. [ 1.2, 4.1, 8.3, 14.9, 27.0, 95.2]
# Supervised binning via decision tree
from sklearn.tree import DecisionTreeClassifier
tree = DecisionTreeClassifier(max_depth=2, random_state=0)
tree.fit(x, y)
# Extract split thresholds from the fitted tree
thresholds = sorted(set(tree.tree_.threshold[tree.tree_.threshold > 0]))
print("Supervised edges:", [round(t,1) for t in thresholds])
# → e.g. [12.0, 5.5] (label-informed, fewest needed)
# ⚠️ Always fit discretizer INSIDE cross-validation to prevent leakage!
from sklearn.pipeline import Pipeline
from sklearn.linear_model import LogisticRegression
pipe = Pipeline([
('bin', KBinsDiscretizer(n_bins=5, encode='onehot-dense', strategy='quantile')),
('clf', LogisticRegression()),
])
