Understanding K-Means
▼

What is it? K-Means is a popular unsupervised machine learning algorithm used for partitioning a dataset into a pre-defined number of distinct, non-overlapping subgroups (clusters). Its goal is to group data points such that points within the same cluster are as similar as possible, while points in different clusters are as dissimilar as possible.

How does it define "similarity"? K-Means typically uses Euclidean distance as its measure of similarity. Points are considered "similar" if they are geometrically close to each other in the feature space. The "center" of each cluster is represented by a centroid, which is simply the mean of all data points assigned to that cluster.

Analogy: Imagine you have a large box of assorted LEGO bricks and you want to sort them into 3 piles. K-Means is like repeatedly trying to sort them: first, you randomly pick 3 bricks as "representatives" for your piles. Then, you go through all other bricks, putting each one into the pile of its closest representative. Once all bricks are sorted, you might realize your representatives aren't very central anymore, so you pick a new representative for each pile by finding the average position of all bricks currently in that pile. You repeat this process until the piles stabilize and the representatives no longer move much.

💡 If you remember one thing

K-Means is an iterative algorithm that alternates between two steps: (1) assigning each data point to its closest cluster centroid, and (2) updating each centroid to be the mean of its assigned data points. This process repeats until the centroids no longer move significantly.

How K-Means Works Internally
▼

The Iterative Algorithm

The standard K-Means algorithm proceeds as follows:

  1. Choose \(K\): Decide on the number of clusters, \(K\). This is a hyperparameter and often requires domain knowledge or evaluation metrics (like the elbow method or silhouette score).
  2. Initialization: Place \(K\) initial centroids in the data space. This step is crucial and significantly impacts the final clustering result. Traditionally, this was done randomly, but modern approaches like K-Means++ are preferred.
  3. Assignment Step (E-Step): For each data point, calculate its distance to all \(K\) centroids. Assign the data point to the cluster whose centroid is closest.
  4. Update Step (M-Step): For each cluster, recalculate its centroid by taking the mean (average) of all data points currently assigned to that cluster.
  5. Convergence Check: Repeat steps 3 and 4 until the centroids no longer move significantly between iterations, or a maximum number of iterations is reached.

The Problem with Random Initialization

If the initial centroids are chosen poorly (e.g., all fall into one dense region, or far from any data points), the algorithm can converge to a suboptimal solution, resulting in high within-cluster variance (poor clustering). Since K-Means always converges to a local optimum, a bad start can lead to a bad finish.

The K-Means++ Solution

To address the initialization problem, the K-Means++ algorithm (Arthur & Vassilvitskii, 2007) provides a smart way to select initial centroids:

  1. Pick the first centroid \(c_1\) uniformly at random from the data points.
  2. For each subsequent centroid \(c_i\):
    1. Calculate the squared distance \(D(x)^2\) from each data point \(x\) to its closest already-chosen centroid.
    2. Select the next centroid \(c_i\) from the data points with a probability proportional to \(D(x)^2\). This means points far from existing centroids are more likely to be chosen.
  3. Repeat step 2 until \(K\) centroids have been chosen.

This method tends to spread out the initial centroids, leading to better (and faster) convergence to a good local optimum.

🔑 Key Property

K-Means is a type of Expectation-Maximization (EM) algorithm: the assignment step is the E-step (estimating cluster memberships), and the update step is the M-step (maximizing the likelihood of the data given memberships by updating centroids).

3
Why It Works — The Math
▼

The Objective Function: Within-Cluster Sum of Squares (WCSS)

K-Means aims to minimize the Within-Cluster Sum of Squares (WCSS), also known as inertia. This measures the sum of squared distances between each point and its assigned centroid:

$$J(\mathbf{W}, \mathbf{\mu}) = \sum_{i=1}^N \sum_{k=1}^K w_{ik} \|x_i - \mu_k\|^2$$

Here, \(x_i\) is a data point, \(\mu_k\) is the centroid of cluster \(k\), and \(w_{ik}\) is a binary indicator variable: \(w_{ik}=1\) if point \(x_i\) is assigned to cluster \(k\), and \(w_{ik}=0\) otherwise. The goal is to find optimal cluster assignments \(\mathbf{W}\) and centroids \(\mathbf{\mu}\) that minimize \(J\).

Derivation of the Assignment (E-Step)

Given fixed centroids \(\mu_k\), we want to find the optimal assignments \(w_{ik}\). To minimize \(J\), each point \(x_i\) should be assigned to the centroid \(\mu_k\) that is closest to it. This leads to the assignment rule:

$$w_{ik} = \begin{cases} 1 & \text{if } k = \arg\min_j \|x_i - \mu_j\|^2 \\ 0 & \text{otherwise} \end{cases}$$

This is the "E-step" (Expectation) where we estimate the cluster memberships.

Derivation of the Update (M-Step)

Given fixed assignments \(w_{ik}\), we want to find the optimal centroids \(\mu_k\). To minimize \(J\), we take the derivative with respect to \(\mu_k\) and set it to zero:

$$\frac{\partial J}{\partial \mu_k} = \sum_{i=1}^N w_{ik} \frac{\partial}{\partial \mu_k} \|x_i - \mu_k\|^2 = \sum_{i=1}^N w_{ik} \cdot 2(x_i - \mu_k)(-1) = 0$$

This simplifies to \(\sum_{i=1}^N w_{ik} (x_i - \mu_k) = 0\). Rearranging, we get:

$$\sum_{i=1}^N w_{ik} x_i = \sum_{i=1}^N w_{ik} \mu_k \implies \mu_k = \frac{\sum_{i=1}^N w_{ik} x_i}{\sum_{i=1}^N w_{ik}}$$

This shows that the optimal centroid \(\mu_k\) is simply the mean of all data points assigned to cluster \(k\). This is the "M-step" (Maximization) where we update the centroids.

Convergence Guarantee

Each step of the K-Means algorithm (both assignment and update) either decreases the WCSS objective function \(J\) or leaves it unchanged. Since \(J\) is bounded below (it can never be negative), the algorithm is guaranteed to converge to a local minimum. However, it is not guaranteed to find the global minimum, which is why initialization strategies like K-Means++ are so important.

⚠️ Local Optima

Because K-Means optimizes a non-convex objective function, it can get stuck in local minima. Running the algorithm multiple times with different (e.g., K-Means++) initializations and picking the result with the lowest WCSS is a common practice to mitigate this risk.

Key Takeaways
▼

When to use K-Means:

  • When you have a large dataset and need a fast, scalable clustering algorithm.
  • When you expect clusters to be roughly spherical and of similar size and density.
  • When the number of clusters, \(K\), is known or can be reasonably estimated from domain knowledge.
  • For initial exploration of data structure before applying more complex methods.

When NOT to use K-Means:

  • When clusters have complex geometries (e.g., crescent shapes, intertwined spirals) — K-Means struggles with non-convex boundaries.
  • When clusters have very different densities or sizes, as it tends to split dense clusters and merge sparse ones.
  • When dealing with high-dimensional or sparse data, where distance metrics can become less meaningful (curse of dimensionality).
  • When you need probabilistic cluster assignments (e.g., Gaussian Mixture Models are better for this).
  • When your data contains significant outliers, as centroids can be pulled towards them.

Choosing \(K\): The choice of \(K\) is crucial. Common methods include:

  • Elbow Method: Plot WCSS (inertia) against \(K\). The "elbow" point where the decrease in WCSS starts to slow down suggests an optimal \(K\).
  • Silhouette Score: Measures how similar an object is to its own cluster compared to other clusters. Higher scores indicate better-defined clusters.
  • Domain Knowledge: Often, the number of natural groups is known beforehand (e.g., market segments, species categories).
💡 Extensions & Alternatives

Mini-Batch K-Means uses mini-batches of data to update centroids, making it faster for very large datasets. K-Medoids uses actual data points as cluster centers, making it more robust to outliers. For non-spherical clusters, consider DBSCAN or Spectral Clustering.

Code Trace (Python Pseudocode)
▼
import numpy as np
def euclidean_distance(a, b):
return np.sqrt(np.sum((a - b)**2))
def assign_clusters(data, centroids):
assignments = []
for point in data:
distances = [euclidean_distance(point, c) for c in centroids]
closest_centroid_idx = np.argmin(distances)
assignments.append(closest_centroid_idx)
return np.array(assignments)
def update_centroids(data, assignments, K):
new_centroids = np.zeros((K, data.shape[1]))
for k in range(K):
cluster_points = data[assignments == k]
if len(cluster_points) > 0:
new_centroids[k] = np.mean(cluster_points, axis=0)
return new_centroids
def kmeans_plusplus_init(data, K):
centroids = []
# 1. Choose first centroid uniformly at random
centroids.append(data[np.random.randint(data.shape[0])])
for _ in range(1, K):
# 2a. Calculate D(x)^2 for all points to closest existing centroid
distances_sq = np.array([min(euclidean_distance(p, c)**2 for c in centroids)
for p in data])
# 2b. Select next centroid with probability proportional to D(x)^2
probs = distances_sq / np.sum(distances_sq)
next_centroid_idx = np.random.choice(data.shape[0], p=probs)
centroids.append(data[next_centroid_idx])
return np.array(centroids)
def kmeans(data, K, init_method='kmeans++', max_iters=100):
if init_method == 'random':
centroids = data[np.random.choice(data.shape[0], K, replace=False)]
else: # kmeans++
centroids = kmeans_plusplus_init(data, K)
for i in range(max_iters):
old_centroids = np.copy(centroids)
assignments = assign_clusters(data, centroids)
centroids = update_centroids(data, assignments, K)
if np.allclose(old_centroids, centroids): # Check for convergence
print(f"Converged in {i+1} iterations.")
break
return centroids, assignments
