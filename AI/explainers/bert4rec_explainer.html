Understanding BERT4Rec
▼

What is it? Sequential recommendation predicts the next item a user will interact with, given their ordered history \(s_1, s_2, \dots, s_n\). Earlier neural approaches — GRU4Rec (RNN) and SASRec (causal self-attention) — read the sequence strictly left-to-right, exactly like a language model generating text: position \(i\) can only see positions \(1..i\). BERT4Rec borrows BERT's Masked Language Model (Cloze) trick instead: randomly hide a handful of items in the training sequence with a special [mask] token, and let a fully bidirectional Transformer encoder predict them using context from both sides — past AND future items in the sequence.

Analogy: a causal model is like guessing the next word of a sentence while only seeing what came before it. BERT4Rec is like a fill-in-the-blank exam: "The user bought a phone, ___, and then a phone case." Seeing "phone case" after the blank makes "screen protector" a much easier guess than reading left-to-right alone ever could.

💡 If you remember one thing

BERT4Rec masks random items in a sequence and reconstructs them using bidirectional self-attention over the whole sequence: $$P(s_m \mid s_{1:n}\setminus s_m) = \text{softmax}(h_m E^\top)$$ where \(h_m\) is the Transformer's contextual hidden state at the masked position and \(E\) is the (tied) item embedding matrix.

How BERT4Rec Works Internally
▼

Input Representation

Each item \(s_i\) is embedded and summed with a learned (or sinusoidal) positional embedding \(p_i\): \(x_i = E_{s_i} + p_i\). This gives the model a sense of order, since self-attention itself is permutation-invariant.

The Cloze Task

During training, a random subset (typically \(\rho \approx 15\%\)) of positions in each sequence is replaced with a special [mask] token. The model must reconstruct the original item at every masked position, conditioned on all the unmasked items around it — before and after.

Bidirectional Self-Attention Stack

Stacked Transformer encoder blocks (self-attention + feed-forward, with residuals and LayerNorm) process the whole masked sequence at once. Crucially, there is no causal mask — every position attends to every other position, so information flows freely in both directions.

🔑 Key Property

Because many different positions get masked across training steps (and across epochs), BERT4Rec extracts far more training signal per sequence than a single "predict the next item" example, while fusing context from both directions into every representation.

Design Decision: The Train/Inference Mismatch

At inference there is no natural "hole" to fill — we want to predict the item that comes after the observed history. BERT4Rec's trick: append a [mask] token to the end of the sequence and ask the trained bidirectional model to fill it in, effectively repurposing the Cloze objective for next-item prediction.

⚠️ Common Pitfall

If training never masks the last position, the model rarely practices predicting from an "end-of-sequence" mask, creating a train/inference mismatch. Implementations fix this by occasionally appending an artificial mask at the end during training too.

Why It Works — The Math
▼

Scaled Dot-Product Self-Attention

For a query at masked position \(m\), keys/values at every position \(j\):

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V, \qquad h_m = \sum_j \alpha_{m,j}\, v_j$$

where \(\alpha_{m,j} = \text{softmax}_j(q_m \cdot k_j / \sqrt{d_k})\). A causal model (SASRec/GPT-style) sets \(\alpha_{m,j}=0\) for all \(j > m\) (future positions get \(-\infty\) logits before the softmax). BERT4Rec's bidirectional attention removes that restriction entirely — every \(j \in \{1,\dots,n\}\) is a valid neighbor.

Training Objective

Cross-entropy loss is computed only over the masked positions \(\mathcal{S}_m\) of masked input \(\hat{s}\):

$$\mathcal{L} = -\frac{1}{|\mathcal{S}_m|}\sum_{m \in \mathcal{S}_m} \log P\big(s_m \mid \hat{s}\big), \qquad P(s_m\mid \hat s) = \text{softmax}(h_m E^\top)_{s_m}$$

Complexity

Self-attention costs \(O(n^2 d)\) per layer whether causal or bidirectional — the difference is not compute, it's which entries of the \(n \times n\) attention matrix are allowed to be non-zero. Bidirectional attention keeps the full matrix dense; causal attention zeroes out the upper triangle.

Key Takeaways
▼

When to use BERT4Rec:

  • Offline/batch recommendation where you can afford a full bidirectional encoder pass
  • Sequences where later items give useful disambiguating context for earlier gaps (e.g. session reconstruction, catalog browsing)
  • You want to squeeze more training signal out of limited user history data via Cloze masking

When NOT to use:

  • Strict real-time streaming next-item prediction where a causal/autoregressive model (SASRec, GRU4Rec) is simpler and avoids the train/inference mismatch
  • Very short sequences (few items) — bidirectional context gives little benefit and the extra compute isn't worth it
  • Latency-critical serving where a single append-mask forward pass at inference is still costlier than a cached causal decode
💡 Hierarchy

GRU4Rec (RNN, causal) ⊂ SASRec (causal self-attention) ⊂ BERT4Rec (bidirectional self-attention + Cloze). Each step generalizes how much context a position is allowed to see when forming its representation.

import torch, random
# seq: LongTensor [n] of item ids, MASK = vocab_size (extra id)
def cloze_mask(seq, mask_id, p=0.15):
masked, labels = seq.clone(), torch.full_like(seq, -100)
for i in range(len(seq)):
if random.random() < p:
labels[i] = seq[i] # ground-truth to reconstruct
masked[i] = mask_id # replace with [MASK]
return masked, labels
# bidirectional self-attention: NO causal mask applied
def self_attention(x, Wq, Wk, Wv):
Q, K, V = x @ Wq, x @ Wk, x @ Wv
scores = Q @ K.T / (x.shape[-1] ** 0.5)
attn = torch.softmax(scores, dim=-1) # full n x n, dense
return attn @ V
