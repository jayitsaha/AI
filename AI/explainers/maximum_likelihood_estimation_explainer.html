Understanding MLE
▼

What is it? Maximum Likelihood Estimation answers a simple question: given that I observed this data, what parameter values make that data most probable? You write down the probability of your data as a function of the unknown parameter \(\theta\), then find the \(\theta\) that maximizes it.

Analogy: Imagine you find a bent coin and flip it 10 times, getting 7 heads. You suspect the coin has some unknown bias \(p\). MLE asks: "For which value of \(p\) was getting exactly 7 heads most likely?" The answer turns out to be \(\hat{p} = 7/10 = 0.7\) — your empirical frequency IS the MLE. This generalizes to any model.

Why log-likelihood? Because probabilities multiply for independent observations, but logarithms turn products into sums — easier to differentiate. Since log is monotone, maximizing \(\ell(\theta)\) and \(L(\theta)\) are equivalent.

If you remember one thing

MLE finds the parameter that assigns the highest probability to the data you actually observed: $$\hat{\theta}_{MLE} = \underset{\theta}{\operatorname{argmax}}\; \ell(\theta) = \underset{\theta}{\operatorname{argmax}} \sum_{i=1}^n \log p(x_i \mid \theta)$$ In neural networks, minimizing cross-entropy loss is MLE under a categorical/Bernoulli model.

2
How MLE Works — The Mechanism
▼

The Likelihood Function

Given i.i.d. observations \(x_1, \ldots, x_n\) from a model with parameter \(\theta\), the likelihood is the joint probability of the data viewed as a function of \(\theta\):

$$L(\theta) = \prod_{i=1}^n p(x_i \mid \theta)$$

The log-likelihood (always used in practice) converts the product to a sum:

$$\ell(\theta) = \log L(\theta) = \sum_{i=1}^n \log p(x_i \mid \theta)$$

Bernoulli Example — Numerical Trace

Data: 10 coin flips, 7 heads. Model: \(X_i \sim \text{Bernoulli}(p)\).

Likelihood: \(L(p) = p^7(1-p)^3\). Log-likelihood: \(\ell(p) = 7\log p + 3\log(1-p)\).

Maximizing: set \(\frac{d\ell}{dp} = \frac{7}{p} - \frac{3}{1-p} = 0\) → \(\hat{p} = 7/10 = 0.70\).

At \(p=0.5\): \(\ell = -6.931\); at \(p=0.7\): \(\ell = -6.109\); at \(p=0.9\): \(\ell = -7.645\). The MLE is the peak.

Gaussian Example — Numerical Trace

Data: \(n=10\) observations with sample mean \(\bar{x} = 3.31\), sample variance (biased) \(= 1.063\).

MLE gives \(\hat{\mu} = \bar{x} = 3.31\) and \(\hat{\sigma}^2 = \frac{1}{n}\sum(x_i-\bar{x})^2 = 1.063\).

The Bias Trap

The MLE for \(\sigma^2\) is biased: \(\mathbb{E}[\hat{\sigma}^2_{MLE}] = \frac{n-1}{n}\sigma^2 \neq \sigma^2\). The unbiased estimator divides by \(n-1\) (Bessel's correction). MLE optimality (efficiency) does not imply unbiasedness.

The Score Function

The score is the gradient of the log-likelihood: \(s(\theta) = \frac{\partial \ell(\theta)}{\partial \theta}\). At the MLE, \(s(\hat{\theta}) = 0\). A key identity: \(\mathbb{E}_\theta[s(\theta)] = 0\) — the score has zero expectation under the true model.

Fisher Information

The Fisher information measures the curvature of the log-likelihood surface at \(\theta\): $$\mathcal{I}(\theta) = -\mathbb{E}\!\left[\frac{\partial^2 \ell(\theta)}{\partial \theta^2}\right] = \mathbb{E}\!\left[\left(\frac{\partial \log p(x\mid\theta)}{\partial\theta}\right)^{\!2}\right]$$ High Fisher information = sharp peak = precise MLE. For Bernoulli: \(\mathcal{I}(p) = \frac{1}{p(1-p)}\). At \(p=0.7\): \(\mathcal{I}(0.7) \approx 4.76\).

3
The Math — Derivation and Asymptotic Properties
▼

General MLE Recipe

1. Write the log-likelihood: \(\ell(\theta) = \sum_{i=1}^n \log p(x_i \mid \theta)\).

2. Differentiate and set to zero (score equation): \(\frac{\partial \ell}{\partial \theta} = 0\).

3. Verify it's a maximum: \(\frac{\partial^2 \ell}{\partial \theta^2} < 0\), or equivalently the log-likelihood is concave.

4. If no closed form, use numerical optimization (Newton-Raphson, gradient descent).

Asymptotic Normality (The Central Theorem)

Under regularity conditions, as \(n \to \infty\):

$$\sqrt{n}\,(\hat{\theta}_{MLE} - \theta_0) \xrightarrow{d} \mathcal{N}\!\left(0,\; \mathcal{I}(\theta_0)^{-1}\right)$$

This is one of the deepest results in statistics. It says:

  • The MLE is consistent: \(\hat{\theta}_{MLE} \to \theta_0\) in probability.
  • The estimation error, scaled by \(\sqrt{n}\), converges to a Gaussian.
  • The variance of that Gaussian is \(\mathcal{I}(\theta_0)^{-1}\) — the Cramér-Rao bound.

Proof sketch: Taylor-expand the score around \(\theta_0\): \(0 = s(\hat{\theta}) \approx s(\theta_0) + (\hat{\theta}-\theta_0)s'(\theta_0)\). Rearranging: \(\sqrt{n}(\hat{\theta}-\theta_0) \approx -\frac{\sqrt{n}s(\theta_0)}{s'(\theta_0)/n}\). The numerator is \(\sqrt{n}\) times a sum of mean-zero i.i.d. terms → CLT gives Gaussian. The denominator converges to \(-\mathcal{I}(\theta_0)\) by LLN. Result follows.

Cramér-Rao Lower Bound

For any unbiased estimator \(\tilde{\theta}\) of \(\theta\):

$$\operatorname{Var}(\tilde{\theta}) \geq \frac{1}{n\,\mathcal{I}(\theta)}$$

The MLE achieves this bound asymptotically — it is asymptotically efficient. No consistent unbiased estimator can have lower asymptotic variance.

MLE = Cross-Entropy Minimization

In ML, for a neural network predicting label \(y \in \{0,1\}^K\) with softmax output \(\hat{p}\), the cross-entropy loss is:

$$\mathcal{L}_{CE} = -\frac{1}{n}\sum_{i=1}^n \sum_{k=1}^K y_{ik}\log \hat{p}_{ik} = -\frac{1}{n}\ell(\theta)$$

This is exactly the negative log-likelihood under a categorical model. Minimizing cross-entropy = maximizing likelihood. The MLE framework unifies classical statistics and modern deep learning.

Key Identities Summary

Score: \(\displaystyle s(\theta) = \frac{\partial \ell}{\partial \theta}\), \(\;\mathbb{E}[s(\theta)] = 0\)
Fisher info: \(\mathcal{I}(\theta) = \mathbb{E}[s(\theta)^2] = -\mathbb{E}[\ell''(\theta)]\)
Bernoulli: \(\hat{p} = \bar{x}\), \(\;\mathcal{I}(p) = \tfrac{1}{p(1-p)}\)
Gaussian: \(\hat{\mu} = \bar{x}\), \(\;\hat{\sigma}^2 = \tfrac{1}{n}\sum(x_i-\bar{x})^2\)
Asymp. SE: \(\operatorname{SE}(\hat{\theta}) \approx \frac{1}{\sqrt{n\,\mathcal{I}(\hat{\theta})}}\)

Key Takeaways
▼

MLE properties summary:

  • Consistent: \(\hat{\theta}_{MLE} \xrightarrow{p} \theta_0\) as \(n \to \infty\)
  • Asymptotically normal: \(\sqrt{n}(\hat{\theta}_{MLE} - \theta_0) \xrightarrow{d} \mathcal{N}(0, \mathcal{I}(\theta_0)^{-1})\)
  • Asymptotically efficient: achieves the Cramér-Rao lower bound — no other consistent estimator has lower asymptotic variance
  • Equivariant: if \(\hat{\theta}\) is MLE of \(\theta\), then \(g(\hat{\theta})\) is MLE of \(g(\theta)\)
  • Not necessarily unbiased: the Gaussian variance MLE divides by \(n\), not \(n-1\)

When MLE may fail:

  • Non-identifiable models (multiple \(\theta\) give same distribution)
  • Boundary cases (e.g., all data is heads: \(\hat{p}=1\), meaningless)
  • Heavy-tailed distributions where second moments don't exist (Cauchy)
  • Very small \(n\): asymptotic guarantees may not hold
The Deep Connection

MLE minimizes the KL divergence from the empirical distribution to the model: \(\hat{\theta}_{MLE} = \underset{\theta}{\operatorname{argmin}}\; D_{KL}(\hat{p}_n \| p_\theta)\). This is why MLE is the natural baseline for probabilistic models and why cross-entropy training in deep learning is statistically principled.

Code Trace
▼
import numpy as np
from scipy.optimize import minimize_scalar
# ── Bernoulli MLE ──────────────────────────────────────
n, k = 10, 7 # 10 flips, 7 heads
p_hat = k / n # MLE: closed-form = empirical frequency
print(f"Bernoulli MLE: p_hat = {p_hat}") # 0.7
# Log-likelihood surface
def log_lik(p, k, n):
return k * np.log(p) + (n - k) * np.log(1 - p)
# Fisher information at MLE
I_p = 1 / (p_hat * (1 - p_hat)) # = 4.762
print(f"Fisher info I(p_hat) = {I_p:.3f}")
# ── Gaussian MLE ───────────────────────────────────────
data = np.array([2.1,3.5,4.2,1.8,5.0,2.7,3.9,4.5,2.3,3.1])
mu_hat = np.mean(data) # = 3.31
sigma2_hat = np.var(data) # = 1.063 (biased, MLE)
sigma2_unbiased = np.var(data, ddof=1) # = 1.181 (n-1)
print(f"mu_hat = {mu_hat:.3f}, sigma2_mle = {sigma2_hat:.3f}")
# ── Asymptotic normality: SE of p_hat ──────────────────
n_large = 100
se_p = np.sqrt(1 / (n_large * I_p)) # ≈ 0.0458
print(f"Asymptotic SE(p_hat) for n=100: {se_p:.4f}")
# ── MLE = Cross-entropy minimization ───────────────────
y_true = np.array([1, 0, 1, 1, 0]) # binary labels
p_pred = np.array([0.8, 0.3, 0.7, 0.9, 0.2]) # model output
cross_entropy = -np.mean(y_true*np.log(p_pred) +
(1-y_true)*np.log(1-p_pred))
neg_log_lik = -np.mean(y_true*np.log(p_pred) +
(1-y_true)*np.log(1-p_pred))
print(f"CE = {cross_entropy:.4f} == NLL = {neg_log_lik:.4f}")
