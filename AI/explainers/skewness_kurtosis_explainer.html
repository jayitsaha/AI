Understanding Skewness & Kurtosis
▼

What are they? Once you know a distribution's mean (1st moment) and variance (2nd moment), you still don't fully know its shape. Skewness captures asymmetry — whether the distribution has a longer tail on the left or right — while kurtosis captures tail-heaviness — whether extreme values are rarer or more common than in a Normal distribution.

Skewness analogy: Imagine income distributions. Most people earn modest salaries (the bulk), but a handful of billionaires pull the mean far to the right, creating a long right tail. The distribution is "right-skewed" (positive skewness). Conversely, if a test is too easy, most students score near 100 and a few fail — creating a left-skewed distribution.

Kurtosis analogy: Imagine daily stock returns. A Normal distribution would predict extreme moves (say, ±5%) happening roughly once per century. Real markets have "fat tails" — crashes and rallies of that magnitude happen several times per decade. High excess kurtosis (leptokurtic) says "extreme events are way more likely than Normal predicts." Low kurtosis (platykurtic) says the distribution is flatter, like a uniform distribution — everything is roughly equally likely.

💡 If you remember one thing

Skewness is the 3rd standardized moment (asymmetry) and kurtosis is the 4th standardized moment (tail weight). Excess kurtosis = kurtosis − 3, measuring departure from the Normal distribution. A Normal has skewness = 0 and excess kurtosis = 0 by definition.

2
The Mathematical Definitions
▼

The Standardized Moments

The \(k\)-th central moment of a random variable \(X\) with mean \(\mu\) and standard deviation \(\sigma\) is:

$$\mu_k = \mathbb{E}\!\left[\left(\frac{X - \mu}{\sigma}\right)^k\right]$$

Dividing by \(\sigma^k\) standardizes the moment so it is dimensionless (invariant to location and scale).

Skewness — 3rd Standardized Moment

Skewness \(\gamma_1\) measures the degree and direction of asymmetry:

$$\gamma_1 = \frac{\mu_3}{\sigma^3} = \frac{\mathbb{E}[(X-\mu)^3]}{\left(\mathbb{E}[(X-\mu)^2]\right)^{3/2}}$$

Interpretation: \(\gamma_1 > 0\) means a longer right tail (positive skew); \(\gamma_1 < 0\) means a longer left tail (negative skew); \(\gamma_1 = 0\) means symmetric (but not necessarily Normal).

Kurtosis — 4th Standardized Moment

Kurtosis \(\gamma_2\) measures the weight of the tails relative to the center:

$$\gamma_2 = \frac{\mu_4}{\sigma^4} = \frac{\mathbb{E}[(X-\mu)^4]}{\left(\mathbb{E}[(X-\mu)^2]\right)^{2}}$$

Because the Normal distribution has \(\gamma_2 = 3\), statisticians often report excess kurtosis:

$$\kappa = \gamma_2 - 3$$

So \(\kappa = 0\) for Normal, \(\kappa > 0\) for heavier tails (leptokurtic), and \(\kappa < 0\) for lighter tails (platykurtic).

Reference Values

Normal\(({\mu,\sigma^2})\): skewness \(= 0\), excess kurtosis \(= 0\)
Exponential\((\lambda)\): skewness \(= 2\), excess kurtosis \(= 6\)
Uniform\([a,b]\): skewness \(= 0\), excess kurtosis \(= -1.2\)
t\((v)\) for \(v{>}4\): skewness \(= 0\), excess kurtosis \(= \tfrac{6}{v-4}\)

⚠️ Common Confusion

Many software packages (Python scipy, Excel) report excess kurtosis (kurtosis − 3) by default. Others (moments package, some textbooks) report the raw 4th standardized moment. Always verify which convention is used. scipy.stats.kurtosis uses Fisher's definition (excess = 0 for Normal); set fisher=False to get the raw value of 3 for Normal.

3
Risk, Outliers & Heavy Tails
▼

Why Finance Cares About Skewness

Portfolio returns typically exhibit negative skewness — the left tail is fatter than the right. This means crashes are more extreme than rallies of the same frequency. A strategy that looks profitable by mean and variance may hide a devastating left tail. Mean-variance optimization (Markowitz) ignores this entirely, which is why higher-moment portfolio optimization exists.

Positive skewness is generally preferred by risk-averse investors: most outcomes are below average, but the occasional windfall is large. Lottery tickets and venture capital have extreme positive skew. Bond defaults have extreme negative skew.

Why Excess Kurtosis Matters for Outlier Risk

Under a Normal distribution, values beyond \(\pm 3\sigma\) occur with probability \(\approx 0.27\%\). For a distribution with excess kurtosis \(\kappa = 6\) (e.g., exponential), that probability is dramatically higher. This is the core of tail risk: models assuming Normality will severely underestimate the probability of extreme events.

$$P(|X - \mu| > k\sigma) \;\text{ is much larger when } \kappa > 0$$

The 2008 financial crisis was partly caused by risk models (VaR) assuming Normal returns — they did not account for the heavy tails that fat-tail distributions (Student-t, stable distributions) would have predicted.

🔑 Kurtosis ≠ Peakedness

A persistent myth: "high kurtosis means a sharper peak." Research by Westfall (2014) and others shows this is wrong. Kurtosis is determined entirely by the tails, not the center. Two distributions can have identical peaks but very different kurtosis because one has heavier tails. Think of kurtosis as a tail-weight index, not a peak-sharpness index.

Non-Normality Tests That Use These Moments

The Jarque–Bera test combines skewness and excess kurtosis into a chi-squared statistic to test for Normality:

$$JB = \frac{n}{6}\left(\hat{\gamma}_1^2 + \frac{\hat{\kappa}^2}{4}\right) \sim \chi^2(2) \text{ under } H_0$$

Under the null hypothesis of Normality, both \(\hat{\gamma}_1 = 0\) and \(\hat{\kappa} = 0\), so JB = 0. A large JB rejects Normality.

Worked Example: Computing Moments by Hand

Dataset: \(\{2, 4, 4, 4, 5, 5, 7, 9\}\)  (\(n = 8\))

$$\mu = \frac{2+4+4+4+5+5+7+9}{8} = \frac{40}{8} = 5.0$$
$$\sigma^2 = \frac{\sum(x_i - 5)^2}{8} = \frac{(-3)^2+(-1)^2+(-1)^2+(-1)^2+0^2+0^2+2^2+4^2}{8} = \frac{9+1+1+1+0+0+4+16}{8} = \frac{32}{8} = 4.0$$
$$\sigma = 2.0$$

Standardized deviations \(z_i = (x_i - 5)/2\): \(\{-1.5, -0.5, -0.5, -0.5, 0, 0, 1, 2\}\)

$$\hat{\gamma}_1 = \frac{1}{8}\sum z_i^3 = \frac{(-3.375)+(-0.125)\times3+(0)\times2+(1)+(8)}{8} = \frac{-3.375-0.375+0+1+8}{8} = \frac{5.25}{8} \approx 0.656$$
$$\hat{\gamma}_2 = \frac{1}{8}\sum z_i^4 = \frac{5.0625+0.0625\times3+0\times2+1+16}{8} = \frac{5.0625+0.1875+0+1+16}{8} = \frac{22.25}{8} = 2.781$$
$$\hat{\kappa} = \hat{\gamma}_2 - 3 = 2.781 - 3 = -0.219$$

Slight positive skew (the 9 pulls right); slightly platykurtic (lighter tails than Normal).

From-Scratch Python Implementation

import numpy as np
def skewness(x):
"""Population skewness = 3rd standardized central moment."""
x = np.asarray(x, dtype=float)
mu = x.mean() # 1st moment (mean)
sigma = x.std(ddof=0) # population std (ddof=0)
if sigma == 0:
return 0.0 # degenerate distribution
z = (x - mu) / sigma # standardize
return np.mean(z ** 3) # E[z^3]
def excess_kurtosis(x):
"""Excess kurtosis = 4th standardized moment - 3 (Fisher's definition)."""
x = np.asarray(x, dtype=float)
mu = x.mean()
sigma = x.std(ddof=0)
if sigma == 0:
return 0.0
z = (x - mu) / sigma
return np.mean(z ** 4) - 3 # kurtosis - 3
# Production usage
from scipy import stats
data = np.array([2, 4, 4, 4, 5, 5, 7, 9], dtype=float)
print(stats.skew(data)) # 0.6562 (population, bias=True default)
print(stats.kurtosis(data)) # -0.2188 (excess kurtosis, Fisher=True default)
print(stats.kurtosis(data, fisher=False)) # 2.7812 (raw 4th moment)
# Jarque-Bera normality test
stat, p_value = stats.jarque_bera(data)
print(f"JB={stat:.3f}, p={p_value:.3f}") # small p rejects normality
⚠️ Sample vs Population Formulas

The formulas above use population (biased) estimators. For small samples, use the adjusted Fisher–Pearson estimator for skewness: \(G_1 = \tfrac{\sqrt{n(n-1)}}{n-2}\,\hat{\gamma}_1\). scipy uses this unbiased estimator by default when bias=False. For \(n \geq 100\), the difference is negligible.

When to Check Skewness & Kurtosis

Always check when: applying models that assume Normality (linear regression residuals, t-tests), building risk models (VaR, CVaR), or fitting distributions to empirical data.

Action thresholds: |skewness| > 1 or |excess kurtosis| > 3 suggests significant non-Normality. Consider transformations (log, Box–Cox) or non-parametric methods.
