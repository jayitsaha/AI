Improper Integrals & Convergence

Integrating over infinite domains or unbounded integrands — and knowing when the area is finite
Intermediate Calculus & Analysis Single-Variable Calculus p-Test · Comparison · Limit Comparison
1
The 30-Second Version
▼

What is it? A regular integral measures the area under a curve between two finite endpoints. An improper integral asks: what if one (or both) endpoints are at infinity, or the function blows up inside the interval? Sometimes there's still a finite total area — sometimes not.

Analogy: Imagine filling a bucket from a tap that slows down over time. If the tap slows fast enough (like \(1/t^2\)), you fill only a finite amount of water even as \(t\to\infty\). If it slows barely at all (like \(1/t\)), the bucket overflows — infinite water despite each drop being finite. Convergence means the bucket fills to a fixed level; divergence means it overflows.

One-sentence summary: An improper integral converges when the "area under the curve" over an infinite range (or near a singularity) is still finite, computed by taking a limit of proper integrals.

💡 If you remember one thing

The p-test: \(\int_1^\infty \frac{1}{x^p}\,dx\) converges if and only if \(p > 1\). For \(p \leq 1\) it diverges. This single fact underlies nearly every convergence check in probability and analysis.

2
Core Concepts & Definitions
▼

Type I — Infinite Limits of Integration

When one or both bounds extend to \(\pm\infty\), define the integral as a limit:

$$\int_a^\infty f(x)\,dx = \lim_{b\to\infty} \int_a^b f(x)\,dx$$

If the limit exists and is finite, the integral converges. Otherwise it diverges. Similarly, \(\int_{-\infty}^b\) uses a limit as \(a \to -\infty\), and \(\int_{-\infty}^\infty\) splits into two separate limits that must both converge.

Type II — Unbounded Integrand (Singularity)

If \(f\) blows up at an endpoint or interior point \(c\), approach the singularity via a limit:

$$\int_a^b f(x)\,dx = \lim_{\varepsilon\to 0^+}\int_a^{b-\varepsilon} f(x)\,dx \quad \text{(singularity at } b\text{)}$$

The Fundamental Technique: Antiderivative + Limit

Evaluate \(\int_1^\infty x^{-p}\,dx\) step by step:

$$\int_1^b x^{-p}\,dx = \begin{cases} \dfrac{x^{1-p}}{1-p}\Big|_1^b = \dfrac{b^{1-p}-1}{1-p} & p \neq 1\\[8pt] \ln b & p=1 \end{cases}$$

Taking \(b\to\infty\): if \(p > 1\), then \(b^{1-p}\to 0\), so the limit is \(\frac{1}{p-1}\). If \(p \leq 1\) (including \(p=1\) where \(\ln b \to \infty\)), the limit is \(+\infty\).

🔑 The p-Test (memorize this)

$$\int_1^\infty \frac{1}{x^p}\,dx = \begin{cases} \dfrac{1}{p-1} & p > 1 \quad (\text{converges})\\ +\infty & p \leq 1 \quad (\text{diverges}) \end{cases}$$

Convergence Tests

  • Direct computation: Find antiderivative, take limit. Gold standard when feasible.
  • Comparison Test: If \(0 \leq f(x) \leq g(x)\) and \(\int g\) converges, then \(\int f\) converges. If \(\int f\) diverges and \(f \leq g\), then \(\int g\) diverges.
  • Limit Comparison Test: If \(\lim_{x\to\infty}\frac{f(x)}{g(x)} = L \in (0,\infty)\), then \(\int f\) and \(\int g\) share the same convergence behavior.
  • Absolute Convergence: If \(\int|f|\) converges, then \(\int f\) converges (but not vice versa).

4
Why It Works — Mathematical Derivations
▼

Full Derivation of the p-Test

For \(p \neq 1\):

$$\int_1^B x^{-p}\,dx = \left[\frac{x^{1-p}}{1-p}\right]_1^B = \frac{B^{1-p} - 1}{1-p}$$

As \(B\to\infty\):

  • If \(p > 1\): exponent \(1-p < 0\), so \(B^{1-p} = B^{-(p-1)} \to 0\). Limit \(= \frac{0 - 1}{1-p} = \frac{1}{p-1}\). Converges.
  • If \(p < 1\): exponent \(1-p > 0\), so \(B^{1-p} \to \infty\). Diverges.
  • If \(p = 1\): \(\int_1^B x^{-1}dx = \ln B \to \infty\). Diverges.
$$\int_1^\infty \frac{dx}{x^p} = \frac{1}{p-1} \qquad (p > 1)$$

Type II: Singularity at the Origin — \(\int_0^1 x^{-p}\,dx\)

The roles reverse! Near 0, \(1/x^p\) blows up. We get:

$$\int_0^1 x^{-p}\,dx = \lim_{\varepsilon\to 0^+}\left[\frac{x^{1-p}}{1-p}\right]_\varepsilon^1 = \frac{1}{1-p}\quad (p < 1)$$

This converges when \(p < 1\) and diverges when \(p \geq 1\). Note the reversal: for Type I (\(\infty\) limit) need \(p>1\); for Type II (singularity at 0) need \(p<1\).

Comparison Test — Why It Works

If \(0 \leq f(x) \leq g(x)\) for \(x \geq a\), then the partial integrals satisfy:

$$F(b) = \int_a^b f(x)\,dx \leq \int_a^b g(x)\,dx = G(b)$$

Since \(f \geq 0\), \(F(b)\) is monotone increasing in \(b\). If \(G(b)\) stays bounded (i.e., \(\int g\) converges), then \(F(b)\) is a bounded monotone sequence — by the Monotone Convergence Theorem, it converges. Conversely, if \(F(b)\to\infty\) then \(G(b)\) must too.

Gamma Function — A Famous Converging Improper Integral

The Gamma function is defined by an improper integral of both types (infinite limit + integrand \(\to\infty\) at 0 for small \(s\)):

$$\Gamma(s) = \int_0^\infty t^{s-1} e^{-t}\,dt \qquad (s > 0)$$

At large \(t\), the exponential decay \(e^{-t}\) dominates any polynomial growth, ensuring convergence. At \(t=0\), the integrand \(\sim t^{s-1}\) which is integrable near 0 iff \(s-1 > -1\), i.e., \(s>0\). Key property: \(\Gamma(n) = (n-1)!\)

⚠️ Common Mistake: Cancelling infinities

The Cauchy Principal Value \(\text{P.V.}\int_{-\infty}^{\infty}\frac{x}{1+x^2}dx = 0\) is not the same as the improper integral, which diverges (positive and negative tails don't converge independently). Always split bilateral integrals and check each half.

5
Connection to Probability & Expected Values
▼

Improper integrals are the backbone of continuous probability theory. A probability density function \(f_X(x)\) must satisfy:

$$\int_{-\infty}^{\infty} f_X(x)\,dx = 1$$

This is an improper integral that must converge. Every time you write down a density, you're implicitly using the convergence results from calculus.

Expected Value as an Improper Integral

The expectation of a random variable \(X\) with density \(f\) is:

$$\mathbb{E}[X] = \int_{-\infty}^{\infty} x\,f(x)\,dx$$

This can diverge even when the density itself integrates to 1! The Cauchy distribution \(f(x) = \frac{1}{\pi(1+x^2)}\) is a valid density (integrates to 1), but its mean is undefined — the tails decay only as \(1/x^2\), and \(\int_1^\infty \frac{x}{1+x^2}\approx \int_1^\infty \frac{1}{x}\,dx\) diverges.

The p-Test in Moments

For a power-law tail \(f(x) \approx C/x^{\alpha+1}\) as \(x\to\infty\), the \(k\)-th moment \(\mathbb{E}[X^k]\) exists iff:

$$\int_1^\infty x^k \cdot \frac{C}{x^{\alpha+1}}\,dx = C\int_1^\infty x^{k-\alpha-1}\,dx \text{ converges} \iff k - \alpha - 1 < -1 \iff k < \alpha$$

So a Pareto distribution with tail index \(\alpha\) has a finite mean only if \(\alpha > 1\), finite variance only if \(\alpha > 2\), etc.

Distribution Density tail Mean (\(\mathbb{E}[X]\)) Variance
Exponential(\(\lambda\)) \(\lambda e^{-\lambda x}\) (faster than any power) Finite: \(1/\lambda\) Finite: \(1/\lambda^2\)
Cauchy \(\sim 1/x^2\) (\(\alpha=1\)) Undefined Undefined
Pareto(\(\alpha=2\)) \(\sim 1/x^3\) (\(\alpha=2\)) Finite Undefined
Normal \(\sim e^{-x^2/2}\) (Gaussian) All moments finite Finite: \(\sigma^2\)
📐 Normalization Example

The Laplace distribution has density \(f(x) = \frac{1}{2b}e^{-|x|/b}\). Verify normalization: \(\int_{-\infty}^\infty \frac{1}{2b}e^{-|x|/b}dx = 2\cdot\frac{1}{2b}\int_0^\infty e^{-x/b}dx = \frac{1}{b}\cdot[-be^{-x/b}]_0^\infty = \frac{1}{b}\cdot b = 1\). Converges because exponential decay beats any polynomial.

6
From-Scratch Code & Numerical Checks
▼

Numerically compute improper integrals and verify the p-test using Python.

import numpy as np
from scipy import integrate
# ── Exact formula for p-integral ──────────────────────────────
def p_integral_exact(p):
"""Exact value of ∫₁^∞ x^{-p} dx (None if diverges)"""
if p > 1:
return 1.0 / (p - 1.0) # converges
return None # diverges
# ── Numerical approximation via truncation ────────────────────
def p_integral_numerical(p, B=1e6):
"""Approximate ∫₁^B x^{-p} dx numerically."""
f = lambda x: x**(-p)
val, err = integrate.quad(f, 1, B)
return val, err
# ── Verify p-test for several values ──────────────────────────
for p in [0.5, 1.0, 1.5, 2.0, 3.0]:
exact = p_integral_exact(p)
num, _ = p_integral_numerical(p)
status = "converges" if exact else "DIVERGES"
print(f"p={p:.1f}: {status}, exact={exact}, numerical≈{num:.4f}")
# ── Gamma function (famous improper integral) ─────────────────
from math import gamma, factorial
for n in range(1, 6):
# Γ(n) should equal (n-1)!
print(f"Γ({n}) = {gamma(n):.1f}, (n-1)! = {factorial(n-1)}")
# ── Cauchy distribution — mean is undefined ───────────────────
cauchy_density = lambda x: 1.0 / (np.pi * (1 + x**2))
norm_check, _ = integrate.quad(cauchy_density, -np.inf, np.inf)
print(f"Cauchy integral = {norm_check:.6f}") # = 1.0 ✓
mean_integrand = lambda x: x * cauchy_density(x)
mean_pos, _ = integrate.quad(mean_integrand, 0, np.inf)
print(f"Cauchy E[X+] = {mean_pos:.1f}") # → +inf ✗ no mean
