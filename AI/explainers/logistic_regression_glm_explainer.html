Understanding Logistic Regression as a GLM
▼

What is a GLM? A Generalized Linear Model extends ordinary linear regression to handle response variables that aren't continuous and normally distributed. Instead of forcing everything to be a straight-line prediction of a raw number, a GLM lets you choose the right probability distribution for your outcome and then connects a linear predictor to that distribution through a link function.

Where does logistic regression fit? Logistic regression is the GLM for a binary outcome: yes/no, spam/not-spam, click/no-click. The response variable \(Y_i\) follows a Bernoulli distribution with success probability \(\mu_i = P(Y_i = 1 \mid x_i)\). The logit (log-odds) is the canonical link that maps \(\mu_i \in (0,1)\) to the full real line where the linear predictor lives.

Analogy: Think of a dimmer switch. The linear predictor \(\eta\) is the raw voltage signal — it can go from \(-\infty\) to \(+\infty\). The sigmoid function is the bulb's dimmer circuit: it squashes any voltage into a brightness between 0% and 100% (probability). The logit link is the inverse operation: given observed brightness, recover the underlying voltage. The GLM framework formalises this voltage-to-brightness conversion for binary data.

If you remember one thing

Logistic regression IS a GLM. The log-odds of success is a linear function of the features: $$\log\frac{\mu}{1-\mu} = x^\top\beta$$ Squash both sides through the sigmoid to recover the probability. Every coefficient \(\beta_j\) is a log odds-ratio: a unit increase in \(x_j\) multiplies the odds by \(e^{\beta_j}\).

The GLM Framework Internals
▼

The Three GLM Components

Every GLM has exactly three structural pieces:

  • Random component: the probability distribution of \(Y_i\). For logistic regression this is \(Y_i \sim \operatorname{Bernoulli}(\mu_i)\), meaning \(P(Y_i=1) = \mu_i\) and \(P(Y_i=0) = 1-\mu_i\).
  • Systematic component (linear predictor): \(\eta_i = x_i^\top\beta = \beta_0 + \beta_1 x_{i1} + \cdots + \beta_p x_{ip}\). This is just ordinary linear algebra — no constraints on the range of \(\eta_i\).
  • Link function: \(g(\mu_i) = \eta_i\). For logistic regression the canonical link is the logit: \(g(\mu) = \log\frac{\mu}{1-\mu}\). The inverse link is the sigmoid: \(\mu = g^{-1}(\eta) = \frac{1}{1+e^{-\eta}}\).

Why is the logit the canonical link?

The Bernoulli distribution belongs to the exponential family. In canonical form its natural parameter is \(\theta = \log\frac{\mu}{1-\mu}\) — exactly the logit. When you use the canonical link, the score equations (derivatives of the log-likelihood) take an especially clean form and IRLS (Iteratively Reweighted Least Squares) converges particularly well.

Key Property — Exponential Family Connection

The Bernoulli PMF can be written as $$P(Y=y) = \exp\!\left(y\,\theta - \log(1+e^\theta)\right), \quad \theta = \log\frac{\mu}{1-\mu}$$ where \(\log(1+e^\theta)\) is the log-partition (cumulant) function. Setting \(\theta = x^\top\beta\) is exactly logistic regression. The mean is \(\mu = \dot{b}(\theta)\) where \(b(\theta)=\log(1+e^\theta)\), so \(\mu = e^\theta/(1+e^\theta) = \sigma(\theta)\).

Numerical trace (β₀ = −0.5, β₁ = 1.5, x = 1.0)

1. Linear predictor: \(\eta = -0.5 + 1.5 \times 1.0 = 1.0\)
2. Inverse-link (sigmoid): \(\mu = 1/(1+e^{-1.0}) = 0.731\)
3. Log-odds check: \(\log(0.731/0.269) = \log(2.718) = 1.0\) ✓
4. Odds: \(e^{1.0} = 2.718\) (almost 3:1 in favour of \(Y=1\))
5. One-unit increase in x changes log-odds by \(\beta_1 = 1.5\), multiplying odds by \(e^{1.5} \approx 4.48\).

Common Misconception

\(\beta_j\) is not the change in probability per unit change in \(x_j\) — that change depends on the current value of \(\mu\) and is non-constant. The log-odds changes linearly; the probability changes along the sigmoid curve and is steepest near \(\mu = 0.5\).

Why the Logit Link? — The Math
▼

Maximum Likelihood Estimation

Parameters \(\beta\) are fitted by maximising the log-likelihood. For \(n\) i.i.d. Bernoulli observations the log-likelihood is:

$$\ell(\beta) = \sum_{i=1}^n \left[y_i \log \mu_i + (1-y_i)\log(1-\mu_i)\right] = \sum_{i=1}^n \left[y_i\, x_i^\top\beta - \log(1 + e^{x_i^\top\beta})\right]$$

This is exactly the negative binary cross-entropy used in deep learning. There is no closed form — we optimise iteratively.

Score Equations (Gradient)

The gradient of the log-likelihood with respect to \(\beta\) is:

$$\nabla_\beta\,\ell(\beta) = X^\top(y - \mu) = \sum_{i=1}^n (y_i - \mu_i)\,x_i$$

Setting this to zero gives the score equations. At the MLE, the weighted residuals \(y_i - \mu_i\) are orthogonal to each predictor column. There is no closed form because \(\mu_i\) is a non-linear function of \(\beta\).

Newton–Raphson = IRLS

The Hessian (observed information matrix) is:

$$H(\beta) = -X^\top W X, \quad W = \operatorname{diag}(\mu_i(1-\mu_i))$$

where \(W\) is the diagonal weight matrix with entries equal to the Bernoulli variance \(\mu_i(1-\mu_i)\). One Newton step gives the IRLS update:

$$\beta^{(t+1)} = \beta^{(t)} + (X^\top W X)^{-1} X^\top(y-\mu)$$

This is equivalent to a weighted least squares problem at each iteration: regress the adjusted dependent variable \(z_i = \eta_i + (y_i-\mu_i)/(\mu_i(1-\mu_i))\) on \(x_i\) with weights \(w_i = \mu_i(1-\mu_i)\).

The GLM Canonical Guarantee

When the canonical link is used, the log-likelihood is globally concave (the Hessian is always negative semi-definite), so IRLS converges to the unique global MLE whenever it exists. Existence may fail with complete separation (perfect classification).

Deviance and Model Fit

The GLM analog of RSS is the deviance:

$$D = -2\left[\ell(\hat{\beta}) - \ell(\hat{\beta}_{\text{sat}})\right] = 2\sum_{i=1}^n\left[y_i\log\frac{y_i}{\hat{\mu}_i} + (1-y_i)\log\frac{1-y_i}{1-\hat{\mu}_i}\right]$$

where \(\hat{\beta}_{\text{sat}}\) is the saturated model (one parameter per observation, perfect fit). Smaller deviance = better fit. The difference in deviances between nested models follows an asymptotic \(\chi^2\) distribution — this is the GLM likelihood-ratio test.

Key Takeaways
▼

Logistic regression as a GLM unifies several perspectives:

  • Statistics view: MLE under Bernoulli distribution with logit canonical link; deviance-based inference.
  • ML view: binary cross-entropy loss minimised by gradient descent or IRLS.
  • Odds view: each coefficient is a log odds-ratio; \(e^{\beta_j}\) is the multiplicative change in odds per unit increase in \(x_j\).
  • Geometric view: the decision boundary \(\eta = 0\) is a hyperplane in feature space; logistic regression finds the hyperplane that best separates the two classes.

When to use the GLM framing:

  • You need calibrated probabilities and inference (confidence intervals, likelihood-ratio tests).
  • You want interpretable coefficients with odds-ratio semantics.
  • You have small-to-medium datasets where statistical properties matter more than raw prediction accuracy.
GLM Family Summary

Gaussian + identity link = Linear regression. Bernoulli + logit link = Logistic regression. Poisson + log link = Poisson regression. Gamma + inverse link = Gamma regression. The same IRLS engine fits all of them — only the weight matrix \(W\) and adjusted response \(z\) change.

import numpy as np
from scipy.special import expit # = sigmoid = inverse-logit
# GLM components for logistic regression
beta0, beta1 = -0.5, 1.5 # intercept and slope
x = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])
# Step 1: linear predictor η = β₀ + β₁x
eta = beta0 + beta1 * x # [-3.5, -2.0, -0.5, 1.0, 2.5]
# Step 2: apply inverse-link (sigmoid) → mean μ = P(Y=1|x)
mu = expit(eta) # [0.030, 0.119, 0.378, 0.731, 0.924]
# Step 3: link function maps μ → η (logit = log-odds)
eta_check = np.log(mu / (1 - mu)) # recovers eta
# Coefficient interpretation: β₁ = log odds-ratio
odds_ratio = np.exp(beta1) # 4.48 — each +1 in x multiplies odds by 4.48
# Decision boundary: predict 1 if μ > 0.5 ↔ η > 0 ↔ x > -β₀/β₁
boundary_x = -beta0 / beta1 # = 0.333
