Understanding Active Learning & Query Strategies
▼

What is Active Learning? In many real-world machine learning problems, unlabeled data is abundant, but obtaining high-quality labels is expensive and time-consuming (e.g., medical image annotation, transcribing audio, human review of text). Active learning aims to reduce this labeling cost by intelligently selecting the most informative unlabeled data points for a human expert to label.

What are Query Strategies? These are the "intelligence" algorithms within an active learning system that decide which unlabeled examples, if labeled, would most improve the model's performance. Instead of randomly labeling, or labeling all available data, a good query strategy can achieve comparable model accuracy with significantly fewer labeled examples.

Analogy: Imagine a student learning a new subject. Instead of passively reading every textbook or randomly asking questions, an active learner identifies the specific concepts or problems they are most confused by, or those that seem most crucial for understanding the whole topic. By focusing their questions, they learn more efficiently. In ML, the "student" is the model, and the "questions" are the unlabeled data points it asks the human "teacher" to label.

💡 If you remember one thing

Active learning is about getting "more bang for your buck" from human annotators. Query strategies are the core algorithms that decide which unlabeled data points are most valuable to label next, typically by identifying points where the current model is most uncertain, or where labeling would lead to the biggest improvement.

Key Query Strategy Categories
▼

The Active Learning Loop

Most active learning systems follow an iterative loop:

  1. Train an initial model on a small set of labeled data.
  2. Use the current model and a chosen query strategy to score all unlabeled data points.
  3. Select the top-scoring (most "informative") points.
  4. A human expert labels these selected points.
  5. Add the newly labeled points to the training set.
  6. Go to step 1 (retrain the model). Repeat until budget runs out or performance is satisfactory.

1. Uncertainty Sampling (Most Common)

These strategies select instances about which the current model is least confident or most ambiguous. They are computationally efficient as they only require a single model's predictions.

  • Least Confidence (LC): Selects the instance where the maximum predicted probability for any class is lowest. The model is "least confident" about its best guess.
  • Margin Sampling: Selects instances where the difference between the top two predicted class probabilities is smallest. The model finds it hard to distinguish between its two most likely classes.
  • Entropy Sampling: Selects instances with the highest predictive entropy. Entropy measures the "flatness" of the probability distribution across all classes; a high entropy means the model is unsure across many classes.

2. Query-by-Committee (QBC)

Instead of a single model, QBC trains an ensemble (a "committee") of models. It queries instances where the committee members disagree the most. Disagreement can be measured by vote entropy or Kullback-Leibler divergence between committee members' predictions.

3. Expected Model Change (EMC)

These strategies estimate how much the model's parameters (or predictions on other unlabeled data) would change if a specific unlabeled instance were labeled and added to the training set. This often involves approximating the expected gradient magnitude, making it more computationally intensive.

4. Diversity Sampling

Uncertainty sampling can sometimes select redundant instances (e.g., many similar points in a confused region). Diversity sampling aims to select points that are representative of the overall data distribution, or cover different regions of the feature space, often in combination with uncertainty. This helps avoid "drifting" into local pockets of uncertainty.

5. Bayesian Active Learning by Disagreement (BALD)

A Bayesian approach that queries instances maximizing the mutual information between the model predictions and the model posterior. Essentially, it finds points where labeling would most reduce the uncertainty in the model's parameters, leading to more confident predictions overall.

🔑 Key Property

While Uncertainty Sampling is often the easiest to implement and most widely used, more advanced strategies like QBC, EMC, Diversity, and BALD aim to overcome its limitations (e.g., redundancy, local optima) by considering model disagreement, parameter sensitivity, or global data distribution.

Why It Works — The Math Behind Uncertainty
▼

Formalizing Uncertainty Sampling

Let \(P_{\theta}(y=k|x)\) be the probability that input \(x\) belongs to class \(k\), as predicted by a model with parameters \(\theta\). For a classification problem with \(K\) classes, we typically get a vector of probabilities \([P_1, P_2, \dots, P_K]\) for each unlabeled instance \(x\).

Least Confidence (LC)

This method picks the instance \(x^*\) for which the maximum predicted probability is lowest. This means the model is least confident in its "best guess". A higher score indicates more uncertainty.

$$ \text{score}_{\text{LC}}(x) = 1 - \max_{k \in \{1, \dots, K\}} P_{\theta}(y=k|x) $$

The score ranges from 0 (perfectly confident in one class) to \(1 - 1/K\) (perfectly uncertain, uniform distribution for \(K\) classes).

Margin Sampling

This strategy looks at the difference between the two most probable classes. A smaller margin means the model struggles to differentiate between its top two choices. We want to maximize this "confusion", so a lower margin implies higher informativeness.

$$ \text{score}_{\text{Margin}}(x) = (P_{\theta}(y_1|x) - P_{\theta}(y_2|x)) $$

where \(P_{\theta}(y_1|x)\) is the highest probability and \(P_{\theta}(y_2|x)\) is the second highest. To make it a "higher is better" score for uncertainty, we often use \(1 - \text{score}_{\text{Margin}}(x)\) or simply sort by ascending margin.

Entropy Sampling

Entropy provides a holistic measure of the uncertainty across the entire probability distribution. A uniform distribution across all classes yields the highest entropy, indicating maximum uncertainty. A peaked distribution (one class with very high probability) yields low entropy.

$$ \text{score}_{\text{Entropy}}(x) = -\sum_{k=1}^K P_{\theta}(y=k|x) \log_2 P_{\theta}(y=k|x) $$

The logarithm base (often 2 or \(e\)) affects the scale but not the ranking. Higher entropy directly implies higher uncertainty. This is generally preferred over LC or Margin when there are more than two classes, as it considers the full distribution.

⚠️ Common Pitfall

Uncertainty sampling methods only consider the model's output probabilities, not the underlying feature space. This can lead to querying many redundant points that are similar to each other, but all happen to fall in an uncertain region. Combining with diversity criteria or using more advanced strategies can mitigate this.

Key Takeaways
▼

When to use which strategy:

  • Uncertainty Sampling (LC, Margin, Entropy): Best for initial exploration and when computational resources are limited. Effective for identifying points near the decision boundary. Entropy is generally preferred for multi-class problems.
  • Query-by-Committee (QBC): When you can train an ensemble of models (e.g., bagging, dropout variants, different initializations). Useful for capturing model disagreement.
  • Expected Model Change (EMC): For models where gradients are easily accessible and computing expected change is feasible. Can be more robust but more complex.
  • Diversity Sampling: To prevent redundancy and ensure coverage of the feature space, especially when uncertainty sampling might focus too much on a single region. Often combined with uncertainty.
  • Bayesian Active Learning (BALD): For Bayesian models (e.g., Gaussian Processes, Bayesian Neural Networks) where you can explicitly model uncertainty over parameters. Provides strong theoretical guarantees but can be computationally expensive.

General Considerations:

  • Computational Cost: Simple uncertainty methods are cheap. QBC, EMC, and BALD can be significantly more expensive, requiring multiple model runs or gradient calculations.
  • Data Distribution: If the uncertain region is sparse or contains outliers, uncertainty sampling alone might pick unrepresentative points. Diversity helps.
  • Model Type: Some strategies are naturally suited to certain model types (e.g., ensemble for QBC, Bayesian for BALD).
💡 Rule of Thumb

Start with Entropy Sampling – it's robust, easy to implement, and works well for most classification tasks. If redundancy or local optima become an issue, consider combining it with a diversity criterion or moving to a more sophisticated strategy like QBC or BALD if your model and budget allow.

Code Trace (Python/NumPy)
▼
import numpy as np
# Assume 'model' is a trained classifier with a predict_proba method
# X_unlabeled: (N, D) array of unlabeled data points
# N: number of unlabeled points, D: number of features
# K: number of classes
def get_uncertainty_scores(X_unlabeled, model):
# P_preds: (N, K) array of probabilities for each class
P_preds = model.predict_proba(X_unlabeled)
# 1. Least Confidence (LC)
max_probs = np.max(P_preds, axis=1)
lc_scores = 1 - max_probs
# 2. Margin Sampling
# Sort probabilities for each instance in descending order
sorted_probs = np.sort(P_preds, axis=1)[:, ::-1]
margin_scores = sorted_probs[:, 0] - sorted_probs[:, 1]
# For querying, we want smallest margin, so invert for 'higher is better'
margin_scores_inverted = 1 - margin_scores
# 3. Entropy Sampling
# Handle log(0) by replacing 0s with a small epsilon
P_preds_safe = np.clip(P_preds, 1e-10, 1)
entropy_scores = -np.sum(P_preds_safe * np.log2(P_preds_safe), axis=1)
return {
"least_confidence": lc_scores,
"margin_sampling": margin_scores_inverted,
"entropy_sampling": entropy_scores,
}
