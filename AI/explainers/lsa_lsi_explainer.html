1
Understanding LSA / LSI
▼

What is it? LSA (Latent Semantic Analysis) — called LSI (Latent Semantic Indexing) when applied to search — finds hidden "topics" in a document collection by factorizing the term-document matrix with truncated Singular Value Decomposition (SVD). Instead of comparing documents by literal word overlap, it compares them in a compressed, denoised "latent semantic space."

Analogy: You never learned that "car" and "automobile" are synonyms, but after reading thousands of documents you notice both words keep showing up near "engine" and "garage," never near "hospital." Eventually you'd conclude they mean nearly the same thing — not because anyone told you, but because they keep the same company. LSA formalizes exactly this reasoning with linear algebra.

💡 If you remember one thing

LSA keeps only the top-\(k\) singular values/vectors of the term-document matrix: $$A \approx A_k = U_k \Sigma_k V_k^\top$$ Terms become rows of \(U_k\Sigma_k\), documents become rows of \(V_k\Sigma_k\) — and cosine similarity in that shared \(k\)-dimensional space captures semantic closeness, not just literal overlap.

How LSA Works Internally
▼

The Problem with Raw TF-IDF Cosine Similarity

Classic keyword search represents each document as a sparse TF-IDF vector over the full vocabulary and ranks by cosine similarity to a query. Every word is its own independent axis, so a query for "automobile" gives zero credit to a document that only says "car" — even though they mean the same thing. This is the synonymy problem.

The LSA Fix: Factor, Then Truncate

Build the \(m \times n\) term-document matrix \(A\) (TF-IDF weighted). Compute its full SVD \(A = U\Sigma V^\top\), then keep only the top \(k\) singular values/vectors: \(A_k = U_k \Sigma_k V_k^\top\). The discarded dimensions (small singular values) correspond to idiosyncratic word choice and sampling noise; the retained dimensions capture the dominant, corpus-wide co-occurrence structure.

Design Decision: Why Discard Anything At All?

The full-rank SVD is just a lossless change of basis — no denoising happens until you truncate. It is precisely the act of throwing away the smaller singular triplets that "forces" words like "car" and "automobile" — which individually have weak, sparse evidence of relatedness — to be explained by the same shared, dominant latent direction.

🔑 Key Property

By the Eckart–Young theorem, \(A_k\) is the mathematically optimal rank-\(k\) approximation of \(A\) in Frobenius norm — no other rank-\(k\) matrix reconstructs \(A\) more accurately. Truncation isn't a heuristic; it's provably the best possible compression at that rank.

3
Why It Works — The Math
▼

SVD Factorization

Any real matrix \(A \in \mathbb{R}^{m\times n}\) factors as \(A = U\Sigma V^\top\), with \(U, V\) orthogonal and \(\Sigma = \operatorname{diag}(\sigma_1 \ge \sigma_2 \ge \dots)\). Equivalently, \(A = \sum_i \sigma_i u_i v_i^\top\) — a sum of rank-1 "concept" layers, ranked by importance.

Eckart–Young–Mirsky Optimality

$$A_k = \underset{\operatorname{rank}(B)\le k}{\operatorname{argmin}} \|A-B\|_F, \qquad \|A-A_k\|_F = \sqrt{\textstyle\sum_{i=k+1}^{r}\sigma_i^2}$$

No rank-\(k\) matrix reconstructs \(A\) better than \(A_k\). This is why keeping the top-\(k\) singular values is the provably minimal-error way to compress the co-occurrence structure.

Latent Coordinates & Query Fold-In

Term \(i\)'s latent vector is row \(i\) of \(U_k\Sigma_k\); document \(j\)'s latent vector is row \(j\) of \(V_k\Sigma_k\). A brand-new query \(q\) (never in the original matrix) is projected in with:

$$\hat{q} = q^\top U_k \Sigma_k^{-1}$$
⚠️ Common Pitfall

Optimal reconstruction error (Frobenius norm) is not the same as optimal semantic quality — Eckart-Young guarantees the former, not the latter. LSA's semantic usefulness is an empirically strong but theoretically unguaranteed side-effect.

Key Takeaways
▼

When to use LSA/LSI:

  • Fast, deterministic, CPU-only semantic similarity or search baseline
  • Small-to-medium corpora where full neural pretraining is overkill
  • Exploratory dimensionality reduction before clustering or visualization

When NOT to use:

  • You need polysemy-aware, context-sensitive representations → use contextual embeddings (BERT)
  • You need human-interpretable topic distributions → use LDA or NMF
  • The corpus changes constantly and recomputing SVD is too costly
💡 Lineage

TF-IDF/VSM (no semantics) → LSA/LSI (linear latent semantics via SVD) → pLSA/LDA (probabilistic topic models) → word2vec/GloVe (predictive embeddings) → BERT (contextual embeddings). Each generation relaxes an assumption of the previous one.

Code Trace

import numpy as np
counts = np.array([ # terms x docs
[2,0,0,0,1], # car
[0,1,0,0,1], # auto
[1,1,0,0,0], # engine
[0,0,1,1,0], # doctor
[0,0,1,0,0], # nurse
], dtype=float)
A = build_tfidf(counts) # TF-IDF weighting
U, S, Vt = np.linalg.svd(A, full_matrices=False)
k = 2
U_k, S_k, Vt_k = U[:, :k], S[:k], Vt[:k, :]
term_vecs = U_k @ np.diag(S_k)
doc_vecs = (np.diag(S_k) @ Vt_k).T
cosine(term_vecs[0], term_vecs[1]) # car vs auto -> 1.000
q = np.array([0,1,0,0,0]) # query: "auto"
q_latent = q @ U_k @ np.linalg.inv(np.diag(S_k))
cosine(q_latent, doc_vecs[0]) # query vs D1 -> 1.000
