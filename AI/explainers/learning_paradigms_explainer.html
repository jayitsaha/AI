The Five Learning Paradigms

How a machine knows what "good" looks like — supervised, unsupervised, semi-supervised, self-supervised, and reinforcement learning compared by their training signal.

Foundational Classical ML Part III Must Know
1
The Core Question

Every machine learning algorithm has to answer one question: what signal tells me whether I'm doing well? The answer to that question determines the entire learning paradigm.

Think of learning a sport. A coach yelling "wrong!" after every move is supervised learning. Watching hours of unlabelled footage and discovering patterns yourself is unsupervised learning. Having a coach for 10% of your practice but practising alone the rest of the time is semi-supervised learning. Covering part of the ball and predicting what's hidden is self-supervised learning. Playing a match and only knowing the final score is reinforcement learning.

💡 The One Thing to Remember

All five paradigms are defined by the nature, density, and timing of the training signal — not by the model architecture. The same neural network can be trained under any paradigm.

2
The Mathematics of Training Signals

Every paradigm optimises a loss \(\mathcal{L}\), but where that loss comes from differs fundamentally.

Supervised: The loss compares model output to a human-provided label \(y\).

$$\mathcal{L}_{SL} = \frac{1}{n}\sum_{i=1}^{n} \ell\!\left(f_\theta(x_i),\, y_i\right)$$

Unsupervised: The loss measures how well the model reconstructs or explains the data itself — no \(y\).

$$\mathcal{L}_{UL} = -\frac{1}{n}\sum_{i=1}^{n} \log p_\theta(x_i)$$

Semi-supervised: A weighted combination of labelled and unlabelled losses.

$$\mathcal{L}_{SSL} = \mathcal{L}_{SL}(\mathcal{D}_L) + \lambda\,\mathcal{L}_{UL}(\mathcal{D}_U)$$

Self-supervised: A pretext task \(g\) turns part of \(x\) into a pseudo-label \(\tilde{y}\) automatically.

$$\mathcal{L}_{SelfSL} = \frac{1}{n}\sum_{i=1}^{n} \ell\!\left(f_\theta(x_i^{\text{masked}}),\, x_i^{\text{target}}\right)$$

Reinforcement: The loss (negative expected return) involves the reward signal \(r_t\) delayed over time.

$$\mathcal{L}_{RL} = -\mathbb{E}_\pi\!\left[\sum_{t=0}^{T} \gamma^t r_t\right]$$
Key insight

The closer the training signal is to the desired output — and the denser it is — the more data-efficient training becomes. Supervised \(\gg\) RL in sample efficiency; RL \(\gg\) supervised in generality.

3
Canonical Code Sketch

The same two-layer network \(f_\theta\) trained under each paradigm — notice how only the loss construction changes.

# ── SUPERVISED ────────────────────────────────────────────── loss = cross_entropy(f(x), y) # y is the human label # ── UNSUPERVISED (k-means, VAE) ────────────────────────────── z = encoder(x) x_hat = decoder(z) loss = mse(x_hat, x) # reconstruct x from x # ── SEMI-SUPERVISED ────────────────────────────────────────── loss = cross_entropy(f(x_l), y_l) \ + λ * consistency_loss(f(x_u), f(augment(x_u))) # ── SELF-SUPERVISED (masked prediction) ───────────────────── x_masked, targets = mask_tokens(x) logits = f(x_masked) # no human label needed loss = cross_entropy(logits, targets) # ── REINFORCEMENT ──────────────────────────────────────────── action = policy(state) next_state, reward, done = env.step(action) loss = -advantage * log_prob(action) # REINFORCE gradient
⚠ Common confusion

Self-supervised learning is not the same as unsupervised learning. Self-supervised creates supervised tasks automatically from the data — it still uses cross-entropy against targets. The distinction is that no human labelling is required.

Supervised Learning

Every training example carries a human-assigned label \(y\). The model minimises a loss between its prediction \(\hat{y} = f_\theta(x)\) and that label. This is the richest signal possible — direct, dense, and unambiguous. The cost: labelling requires human effort at scale.

Canonical example: ResNet trained on ImageNet (1.2 M labelled images, 1000 classes). Each image has an expert-assigned class label. The model learns to map pixel tensors to class probabilities via cross-entropy loss.

Decision guide

Abundant labels → Supervised. No labels, need structure → Unsupervised. Rare labels, lots of raw data → Semi-supervised. Large raw corpus, want transferable representations → Self-supervised. Sequential decision-making with env. interaction → Reinforcement.
