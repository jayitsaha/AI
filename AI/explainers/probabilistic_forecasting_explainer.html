Understanding Probabilistic Forecasting
▼

What is it? Most forecasting models output a single "best guess" for a future value, known as a point forecast. While useful, this ignores inherent uncertainty. Probabilistic forecasting goes further, providing a range of possible future outcomes, often with associated probabilities or confidence levels. This range is typically represented as a prediction interval (PI) or a full predictive distribution.

Analogy: Imagine a weather forecast. A point forecast might say "Tomorrow's high temperature will be 20°C." A probabilistic forecast is more like "There's a 90% chance tomorrow's high will be between 18°C and 22°C, and a 5% chance it will be below 17°C." This richer information allows for better decision-making, as it explicitly communicates the risk and potential variability.

💡 If you remember one thing

Probabilistic forecasts quantify the uncertainty around a prediction, providing a range (prediction interval) rather than just a single point. This is crucial for risk management and robust decision-making, as it acknowledges that the future is inherently uncertain.

How Different Methods Work
▼

1. Parametric Prediction Intervals

This is the most common and simplest approach. It typically involves:

  1. Fitting a model (e.g., linear regression, ARIMA) to get a point forecast \(\hat{y}\).
  2. Estimating the variance of the residuals (errors) from this model.
  3. Assuming a specific distribution for these errors (most commonly, a Gaussian/Normal distribution).
  4. Constructing a symmetric interval around \(\hat{y}\) using a critical value (e.g., z-score for normal) and the estimated error standard deviation.

Limitation: Its validity hinges on the distributional assumptions holding true. If errors are non-Gaussian or exhibit heteroscedasticity (non-constant variance), the intervals can be inaccurate, providing misleading coverage.

2. Quantile Regression (QR)

Instead of modeling the conditional mean of \(y\) given \(X\), Quantile Regression directly models the conditional quantiles (e.g., 10th percentile, 50th percentile, 90th percentile). This is achieved by minimizing an asymmetric loss function called the "pinball loss" (or "quantile loss").

Advantage: QR does not assume a specific distribution for the errors and can naturally handle heteroscedasticity, producing intervals that adapt their width depending on the input features. For instance, a forecast might have wider uncertainty when predicting far into the future or for specific conditions.

3. Conformal Prediction (CP)

Conformal Prediction is a powerful, distribution-free framework that can be wrapped around *any* underlying predictive model (e.g., linear regression, neural network, random forest) to provide prediction intervals with rigorous statistical guarantees. It works by:

  1. Splitting data into a training set and a separate calibration set.
  2. Training the base model on the training set.
  3. Computing "non-conformity scores" for each point in the calibration set. A common score for regression is the absolute residual: \(|y_i - \hat{y}_i|\).
  4. Calculating an empirical quantile \(\hat{q}\) from these scores.
  5. For a new prediction, constructing an interval \([\hat{y}^* - \hat{q}, \hat{y}^* + \hat{q}]\) such that the new point's non-conformity score would fall within the calibrated range.

Advantage: CP guarantees that the prediction intervals will contain the true outcome with a user-specified probability (e.g., 90% coverage), without making any assumptions about the underlying data distribution or the model's error distribution. This makes it highly robust.

🔑 Key Property

The choice of method depends on assumptions and desired guarantees. Parametric methods are fast but brittle. Quantile Regression is flexible for heteroscedasticity. Conformal Prediction offers robust, distribution-free coverage guarantees.

3
Why It Works — The Core Math
▼

Parametric Prediction Intervals

Given a regression model \(y_t = f(X_t) + \varepsilon_t\), where \(\varepsilon_t\) are i.i.d. errors, often assumed \(\varepsilon_t \sim \mathcal{N}(0, \sigma^2)\). After fitting the model to obtain \(\hat{f}(X_t)\), the residuals are \(e_t = y_t - \hat{f}(X_t)\). The estimated error variance is:

$$\hat{\sigma}^2 = \frac{1}{N-p} \sum_{t=1}^N (y_t - \hat{f}(X_t))^2$$

For a new input \(X^*\), the \((1-\alpha)\) prediction interval is then constructed as:

$$\left[\hat{f}(X^*) - z_{\alpha/2}\hat{\sigma}, \quad \hat{f}(X^*) + z_{\alpha/2}\hat{\sigma}\right]$$

where \(z_{\alpha/2}\) is the \((1-\alpha/2)\)-th quantile of the standard normal distribution.

Quantile Regression (Pinball Loss)

To estimate the \(\tau\)-th conditional quantile \(Q_y(\tau | X) = f_{\tau}(X)\), Quantile Regression minimizes the following objective function:

$$\min_{\theta_{\tau}} \sum_{i=1}^N \rho_{\tau}(y_i - f(x_i; \theta_{\tau}))$$

where \(\rho_{\tau}(\delta)\) is the pinball loss function, defined as:

$$\rho_{\tau}(\delta) = \delta(\tau - \mathbf{1}_{\delta < 0})$$

This loss function is asymmetric: it penalizes under-prediction more heavily for high quantiles (\(\tau > 0.5\)) and over-prediction more heavily for low quantiles (\(\tau < 0.5\)). For \(\tau=0.5\), it reduces to the absolute error loss, yielding median regression.

Conformal Prediction

Given a training set \(\mathcal{D}_{\text{train}}\) and a calibration set \(\mathcal{D}_{\text{cal}} = \{(x_i, y_i)\}_{i=1}^N\), and a base model \(\hat{f}\) trained on \(\mathcal{D}_{\text{train}}\):

  1. Compute non-conformity scores for each calibration point: \(s_i = |y_i - \hat{f}(x_i)|\).
  2. Sort these scores: \(s_{(1)} \le s_{(2)} \le \dots \le s_{(N)}\).
  3. Compute the empirical quantile \(\hat{q}\). For a desired coverage \(1-\alpha\), \(\hat{q}\) is often chosen as the \(\lceil (N+1)(1-\alpha) \rceil\)-th value in the sorted list of scores (or a similar variant). Specifically, let \(k = \lceil (N+1)(1-\alpha) \rceil\), then \(\hat{q} = s_{(k)}\).
  4. For a new test point \(x^*\), predict \(\hat{f}(x^*)\). The prediction interval is:
$$\left[\hat{f}(x^*) - \hat{q}, \quad \hat{f}(x^*) + \hat{q}\right]$$

This interval has a marginal coverage guarantee: \(P(y^* \in [\hat{f}(x^*) - \hat{q}, \hat{f}(x^*) + \hat{q}]) \ge 1-\alpha\), assuming the data is exchangeable (i.i.d. is a special case).

➕ Notation Note

The notation \(\mathbf{1}_{\delta < 0}\) is an indicator function, which equals 1 if \(\delta < 0\) and 0 otherwise. \(N\) is the number of data points, \(p\) is the number of parameters in the model.

Key Takeaways
▼
MethodAssumptionsInterval TypeGuarantees
Parametric PIKnown error distribution (e.g., Gaussian), homoscedasticitySymmetric, fixed widthApproximate coverage if assumptions hold
Quantile RegressionNone on error distributionAsymmetric, adaptive widthEstimates conditional quantiles, no strict coverage guarantee on finite samples
Conformal PredictionExchangeability of data (e.g., i.i.d. for calibration)Symmetric or asymmetric, adaptive widthGuaranteed coverage (marginal)

When to use each method:

  • Parametric PIs: Ideal for quick baselines, simple models, or when strong domain knowledge suggests Gaussian, homoscedastic errors. Fast to compute.
  • Quantile Regression: When errors are clearly non-Gaussian, asymmetric, or heteroscedastic. Provides a more flexible and realistic representation of uncertainty, crucial for risk-averse applications.
  • Conformal Prediction: When strict, statistically valid coverage guarantees are paramount, especially in high-stakes applications (e.g., medical, financial). It's a robust "wrapper" for any base model.

When to be cautious:

  • Parametric PIs: Blindly trusting intervals when assumptions are violated can lead to under- or over-confidence.
  • Quantile Regression: Can be computationally more intensive (training multiple models). The choice of quantile levels is important.
  • Conformal Prediction: Relies on the exchangeability assumption for calibration data, which can be violated in time series with concept drift. The interval width can be sensitive to the quality of the base model and calibration set size.
💡 Big Picture

The evolution from parametric PIs to Quantile Regression and Conformal Prediction reflects a shift towards more flexible, data-driven, and robust methods for uncertainty quantification, moving away from strong distributional assumptions towards empirical guarantees.

Code Trace (Python / Scikit-learn)
▼
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.ensemble import GradientBoostingRegressor
from scipy.stats import norm
# --- 1. Parametric Prediction Interval ---
def parametric_pi(X_train, y_train, X_test, alpha=0.1):
model = LinearRegression().fit(X_train, y_train)
y_pred_train = model.predict(X_train)
residuals = y_train - y_pred_train
std_dev = np.std(residuals) # Estimate sigma
z_score = norm.ppf(1 - alpha / 2) # Critical value for 1-alpha PI
y_pred_test = model.predict(X_test)
lower_bound = y_pred_test - z_score * std_dev
upper_bound = y_pred_test + z_score * std_dev
return y_pred_test, lower_bound, upper_bound
# --- 2. Quantile Regression ---
def quantile_regression_pi(X_train, y_train, X_test, alpha=0.1):
# Fit separate models for lower and upper quantiles
lower_q = alpha / 2
upper_q = 1 - alpha / 2
model_lower = GradientBoostingRegressor(loss='quantile', alpha=lower_q).fit(X_train, y_train)
model_median = GradientBoostingRegressor(loss='quantile', alpha=0.5).fit(X_train, y_train)
model_upper = GradientBoostingRegressor(loss='quantile', alpha=upper_q).fit(X_train, y_train)
lower_bound = model_lower.predict(X_test)
y_pred_test = model_median.predict(X_test) # Median as point forecast
upper_bound = model_upper.predict(X_test)
return y_pred_test, lower_bound, upper_bound
# --- 3. Conformal Prediction ---
def conformal_pi(X_train, y_train, X_cal, y_cal, X_test, alpha=0.1):
base_model = LinearRegression().fit(X_train, y_train)
y_pred_cal = base_model.predict(X_cal)
non_conformity_scores = np.abs(y_cal - y_pred_cal)
# Calculate empirical quantile q_hat
n_cal = len(non_conformity_scores)
k = int(np.ceil((n_cal + 1) * (1 - alpha)))
q_hat = np.sort(non_conformity_scores)[k-1] # (k-1) for 0-indexed array
y_pred_test = base_model.predict(X_test)
lower_bound = y_pred_test - q_hat
upper_bound = y_pred_test + q_hat
return y_pred_test, lower_bound, upper_bound, non_conformity_scores, q_hat
