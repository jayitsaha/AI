Pre-LN vs Post-LN Transformers

How layer normalization placement determines training stability, gradient flow, and convergence
Architecture Deep Learning Transformers Training Dynamics Stability Critical
1
Understanding Pre-LN vs Post-LN
▼

What is the question? Every transformer block contains a sub-layer (self-attention or feed-forward) and a residual connection. Layer Normalization (LN) must be placed somewhere in this block. The original "Attention Is All You Need" paper placed it after the residual addition (Post-LN). Later work discovered that placing it before the sub-layer (Pre-LN) dramatically improves training stability. This single architectural choice has enormous practical consequences.

Post-LN (original Transformer): The computation flows as: input → sub-layer → add residual → LayerNorm → output. Formally: \(\text{output} = \text{LN}(x + \text{Sublayer}(x))\). The residual is added first, then normalized.

Pre-LN (GPT-2, GPT-3, PaLM, LLaMA, etc.): The computation flows as: input → LayerNorm → sub-layer → add residual → output. Formally: \(\text{output} = x + \text{Sublayer}(\text{LN}(x))\). The input is normalized before entering the sub-layer, and the raw (unnormalized) residual is added back.

⚠ Post-LN (Original Transformer)

Requires careful learning rate warmup. Gradients can explode near initialization. Hard to train deep models without tricks. Achieves slightly better final performance when it converges.

✓ Pre-LN (Modern Standard)

Trains stably without warmup. Gradients flow cleanly through residual path. Scales to very deep models (100+ layers). Slight final performance gap vs Post-LN at same depth.

💡 The Core Intuition

In Pre-LN, the residual stream is never normalized — it accumulates raw activations across all layers. This means the gradient of the loss with respect to early-layer parameters always has a direct, well-scaled path through the residual connections. In Post-LN, every residual addition is followed by normalization, which can distort gradient magnitudes and create instability near initialization when the sub-layer outputs are large relative to the residual.

2
How It Works Internally
▼

Layer Normalization Recap

Layer Normalization normalizes each token's representation across the feature dimension: given a vector \(x \in \mathbb{R}^d\), it computes \(\text{LN}(x) = \gamma \odot \frac{x - \mu}{\sigma + \epsilon} + \beta\) where \(\mu = \frac{1}{d}\sum_i x_i\), \(\sigma^2 = \frac{1}{d}\sum_i (x_i - \mu)^2\), and \(\gamma, \beta\) are learned scale and shift parameters. The key property: the output has zero mean and unit variance (before the affine transform).

The Residual Stream Perspective

Think of a transformer as a residual stream: a vector that flows through all layers, with each layer adding a small update. In Pre-LN, this stream is never touched by normalization — only the input to each sub-layer is normalized before processing. The stream itself grows freely. In Post-LN, the stream is forcibly renormalized after every block, resetting its scale.

Why Post-LN is Unstable at Initialization

At initialization, the sub-layer weights are small (e.g., Xavier init). So \(\text{Sublayer}(x) \approx 0\), meaning \(x + \text{Sublayer}(x) \approx x\). The Post-LN output \(\text{LN}(x + \text{Sublayer}(x)) \approx \text{LN}(x)\) is fine. But as training begins, the sub-layer starts producing non-trivial outputs. The gradient of \(\text{LN}(x + f(x))\) with respect to the parameters of \(f\) involves the Jacobian of LN, which can amplify or suppress gradients depending on the relative magnitudes of \(x\) and \(f(x)\). In deep networks, this compounds across layers.

Why Pre-LN is Stable

In Pre-LN, the gradient of the loss \(\mathcal{L}\) with respect to the input of layer \(\ell\) always passes through the identity residual path: \(\frac{\partial \mathcal{L}}{\partial x_\ell} = \frac{\partial \mathcal{L}}{\partial x_{\ell+1}} \cdot \left(I + \frac{\partial \text{Sublayer}(\text{LN}(x_\ell))}{\partial x_\ell}\right)\). The identity term \(I\) ensures gradients cannot vanish to zero — there is always a direct path. In Post-LN, the LN Jacobian sits between every pair of adjacent layers, potentially distorting this path.

⚠️ The Warmup Requirement

Post-LN transformers famously require a learning rate warmup schedule (starting from near-zero LR and ramping up). This is not a stylistic choice — it is necessary for convergence. Without warmup, gradients in early layers of a deep Post-LN model can be orders of magnitude larger than in later layers, causing divergence. Pre-LN models can often be trained with a constant or cosine-decay schedule from the start.

The Depth Scaling Problem

As the number of layers \(L\) grows, the instability of Post-LN compounds. Empirically, training a 24-layer Post-LN transformer requires much more careful tuning than a 12-layer one. Pre-LN scales more gracefully — GPT-3 (96 layers) and LLaMA-2 (80 layers) both use Pre-LN. Some modern architectures add an additional normalization at the very end of the residual stream (e.g., before the final output projection) to get the best of both worlds.

The Math — Why It Works
▼

Gradient Flow Through L Layers

Consider a simplified transformer with \(L\) identical blocks. Let \(x_\ell\) be the residual stream at layer \(\ell\). Define the sub-layer function as \(F_\ell(\cdot)\) (attention or FFN).

Post-LN forward pass:

$$x_{\ell+1} = \text{LN}(x_\ell + F_\ell(x_\ell))$$

Pre-LN forward pass:

$$x_{\ell+1} = x_\ell + F_\ell(\text{LN}(x_\ell))$$

Now consider backpropagation. The gradient of the loss \(\mathcal{L}\) with respect to \(x_\ell\) in the Pre-LN case is:

$$\frac{\partial \mathcal{L}}{\partial x_\ell} = \frac{\partial \mathcal{L}}{\partial x_{\ell+1}} \cdot \left(I + J_{F_\ell \circ \text{LN}}(x_\ell)\right)$$

where \(J_{F_\ell \circ \text{LN}}\) is the Jacobian of the composed function. The crucial observation: the identity matrix \(I\) is always present in the gradient. Unrolling across all \(L\) layers:

$$\frac{\partial \mathcal{L}}{\partial x_1} = \frac{\partial \mathcal{L}}{\partial x_L} \cdot \prod_{\ell=1}^{L-1}\left(I + J_\ell\right)$$

Each factor \((I + J_\ell)\) has eigenvalues at least 1 (from the identity term), so the gradient cannot collapse to zero. In contrast, Post-LN has:

$$\frac{\partial \mathcal{L}}{\partial x_\ell} = \frac{\partial \mathcal{L}}{\partial x_{\ell+1}} \cdot J_{\text{LN}}(x_\ell + F_\ell(x_\ell)) \cdot \left(I + J_{F_\ell}(x_\ell)\right)$$

The LN Jacobian \(J_{\text{LN}}\) is a projection matrix (it projects onto the subspace orthogonal to the all-ones vector and the input vector). Its eigenvalues are in \([0, 1]\), with two zero eigenvalues. This means Post-LN always loses information in the gradient at each layer — and across \(L\) layers, this compounds multiplicatively.

Expected Gradient Norm at Initialization

Liu et al. (2020) showed that for Post-LN, the expected gradient norm at layer \(\ell\) from the top scales as \(\mathcal{O}(L - \ell)\), meaning early layers receive gradients \(L\) times larger than late layers. For Pre-LN, the gradient norm is approximately constant across layers — \(\mathcal{O}(1)\) — because the residual identity path equalizes the flow.

📐 LN Jacobian Structure

The Jacobian of LayerNorm (ignoring the affine \(\gamma, \beta\)) is: \(J_{\text{LN}} = \frac{1}{\sigma}\left(I - \frac{1}{d}\mathbf{1}\mathbf{1}^\top - \frac{\hat{x}\hat{x}^\top}{d}\right)\) where \(\hat{x} = (x-\mu)/\sigma\). This is a rank-\((d-2)\) projection scaled by \(1/\sigma\). When \(\sigma\) is large (activations spread out), the Jacobian is small — gradients are suppressed. This is the mechanism of Post-LN instability.

🔑 Summary

Pre-LN guarantees a gradient highway through the residual stream with no normalization-induced suppression. Post-LN inserts a potentially rank-deficient, scale-dependent projection at every layer boundary. The practical consequence: Pre-LN trains stably at any depth; Post-LN requires warmup and careful tuning that becomes harder as depth increases.

Key Takeaways
▼

When to use Pre-LN:

  • Training deep transformers (12+ layers) where stability is paramount
  • When you cannot afford extensive hyperparameter tuning or warmup schedules
  • Large-scale language models (GPT-2/3, LLaMA, PaLM all use Pre-LN)
  • When training with large batch sizes or aggressive learning rates
  • Research prototyping where you need reliable convergence

When Post-LN might be preferred:

  • Shallow models (≤6 layers) where instability is manageable
  • When final performance matters more than training ease and you can afford careful tuning
  • Fine-tuning from a pretrained Post-LN checkpoint (BERT, original Transformer)
  • Some evidence Post-LN achieves slightly better perplexity at the same depth when it converges
💡 Modern Practice

The field has largely converged on Pre-LN as the default for new architectures. Some models (e.g., Mistral, Gemma) additionally use RMSNorm instead of LayerNorm (no mean subtraction, only scale normalization), which is faster and equally stable. A few architectures use sandwich normalization (LN both before and after the sub-layer) to get the stability of Pre-LN with some of the representational benefits of Post-LN.

⚠️ The Depth-Performance Tradeoff

Because Pre-LN's residual stream is never reset, representations can drift and become very large in magnitude at deep layers. Some papers report that Pre-LN models need to be slightly wider or have explicit output normalization to match Post-LN quality at the same parameter count. The practical workaround: add a final LayerNorm before the output head (this is standard in GPT-2 and later).

Code Trace

import torch
import torch.nn as nn
# ── POST-LN Block (original Transformer) ──
class PostLNBlock(nn.Module):
def __init__(self, d_model, n_heads, d_ff):
super().__init__()
self.attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
self.ffn = nn.Sequential(nn.Linear(d_model, d_ff), nn.GELU(),
nn.Linear(d_ff, d_model))
self.ln1 = nn.LayerNorm(d_model)
self.ln2 = nn.LayerNorm(d_model)
def forward(self, x):
# Sub-layer 1: attention THEN add THEN norm
attn_out, _ = self.attn(x, x, x)
x = self.ln1(x + attn_out) # POST-LN: norm AFTER residual
# Sub-layer 2: FFN THEN add THEN norm
x = self.ln2(x + self.ffn(x)) # POST-LN: norm AFTER residual
return x
# ── PRE-LN Block (GPT-2 / LLaMA style) ──
class PreLNBlock(nn.Module):
def __init__(self, d_model, n_heads, d_ff):
super().__init__()
self.attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
self.ffn = nn.Sequential(nn.Linear(d_model, d_ff), nn.GELU(),
nn.Linear(d_ff, d_model))
self.ln1 = nn.LayerNorm(d_model)
self.ln2 = nn.LayerNorm(d_model)
def forward(self, x):
# Sub-layer 1: norm THEN attention THEN add residual
attn_out, _ = self.attn(self.ln1(x), self.ln1(x), self.ln1(x))
x = x + attn_out # PRE-LN: raw residual, no norm
# Sub-layer 2: norm THEN FFN THEN add residual
x = x + self.ffn(self.ln2(x)) # PRE-LN: raw residual, no norm
return x
# ── Gradient norm analysis ──
def measure_grad_norms(model, x, y, loss_fn):
loss = loss_fn(model(x), y)
loss.backward()
norms = {}
for name, p in model.named_parameters():
if p.grad is not None:
norms[name] = p.grad.norm().item()
return norms # Post-LN: norms[layer 0] >> norms[layer L-1]
# Pre-LN: norms roughly equal across layers
