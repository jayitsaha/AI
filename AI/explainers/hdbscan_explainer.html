Understanding HDBSCAN
▼

What is it? HDBSCAN (Hierarchical Density-Based Spatial Clustering of Applications with Noise) finds clusters by asking: "which groups of points stay together as a coherent, dense blob across a range of density thresholds?" Rather than committing to a single density cutoff (like DBSCAN), it builds a full hierarchy of clusters and then extracts the ones that are most stable — meaning they persist for the widest range of density levels before fragmenting or dissolving.

The key breakthrough over DBSCAN: DBSCAN needs you to set both \(\varepsilon\) (radius) and min_pts. If your data has clusters of different densities — a tight city-center cluster and a spread-out suburban cluster — no single \(\varepsilon\) works. HDBSCAN only needs min_cluster_size and automatically handles varying density by measuring persistence across all density levels.

💡 If you remember one thing

HDBSCAN converts distance into density via mutual reachability distance, builds a minimum spanning tree, condenses it into a cluster hierarchy, and picks clusters by maximizing cluster stability — the integral of how many points persist in each cluster over the density range it lives. Output: cluster labels + soft membership scores for every point.

How HDBSCAN Works — The 5 Steps
▼

Step 1 — Core Distances

For each point \(p\), compute its core distance \(\mathrm{core}_k(p)\): the distance to its \(k\)-th nearest neighbor (where \(k =\) min_pts). Points in dense regions have small core distances; isolated points have large ones. This regularizes the space so outliers don't distort the distance structure.

$$\mathrm{core}_k(p) = d(p, \, \text{k-th nearest neighbor of } p)$$

Step 2 — Mutual Reachability Distance

Replace raw Euclidean distance with the mutual reachability distance: the true distance lifted to be at least as large as both points' core distances. This makes the distance landscape smoother in dense regions and ensures no cluster has fewer than \(k\) points.

$$d_\mathrm{mreach}(p,q) = \max\!\bigl(\mathrm{core}_k(p),\; \mathrm{core}_k(q),\; d(p,q)\bigr)$$

Step 3 — Minimum Spanning Tree (MST)

Build the MST of the complete graph weighted by mutual reachability distances (Prim's or Kruskal's, \(O(n^2)\) naive or \(O(n \log n)\) with spatial indexing). The MST captures the skeleton of the density structure: short edges connect within-cluster neighbors, long edges span inter-cluster gaps or cross sparse regions.

Step 4 — Condense the Cluster Hierarchy

Sort MST edges by weight and merge them in increasing order. This creates a single-linkage dendrogram. Then condense it: whenever a split produces a branch with fewer than min_cluster_size points, those points are declared noise rather than a new cluster. What remains is a condensed cluster tree where each node represents a cluster that existed for a range of density levels \(\lambda = 1/\varepsilon\).

Step 5 — Select Clusters by Stability

Cluster stability is the sum of how long each point contributes to the cluster in density-space:

$$\mathrm{stability}(C) = \sum_{p \in C}\!\left(\lambda_p^{\text{out}} - \lambda_p^{\text{in}}\right), \quad \lambda = \frac{1}{\varepsilon}$$

where \(\lambda_p^{\text{in}}\) is the density level at which \(p\) joined cluster \(C\) and \(\lambda_p^{\text{out}}\) is when it left (cluster split or dissolved). Use a bottom-up sweep: accept a cluster if its stability exceeds the sum of its children's stabilities; otherwise propagate children up. Points in un-selected clusters become noise or soft members.

🔑 Why This Beats DBSCAN

DBSCAN with a single \(\varepsilon\) either over-merges sparse clusters or fragments dense ones. HDBSCAN runs all \(\varepsilon\) values implicitly via the hierarchy and selects each cluster at the density level where it is most cohesive. Dense and sparse clusters get different effective \(\varepsilon\) values — automatically.

⚠️ Soft Clustering & Outlier Scores

HDBSCAN also produces soft membership probabilities for every point: the ratio of the density at which the point falls off a cluster to the maximum density it ever achieved in that cluster. Outlier scores (GLOSH) measure how far a point is from any cluster core — fully automated noise detection without tuning.

Why It Works — The Math
▼

From Single-Linkage to HDBSCAN

The MST on mutual reachability distances is equivalent to single-linkage clustering in the \(d_\mathrm{mreach}\) space. Single-linkage produces a dendrogram where merge height equals the longest edge in the spanning tree. HDBSCAN is robust single-linkage: the condensation step removes micro-clusters (below min_cluster_size) at each split, making it insensitive to chaining artifacts.

Cluster Stability Derivation

Define \(\lambda = 1/\varepsilon\) (density level; larger \(\lambda\) = higher density threshold). A cluster \(C_k\) is born at density \(\lambda_k^\text{birth}\) and splits or dies at \(\lambda_k^\text{death}\). Point \(p\) leaves \(C_k\) at density \(\lambda_p\) (either at the cluster's death, or earlier if it becomes noise). Then:

$$\mathrm{stability}(C_k) = \sum_{p \in C_k} \bigl(\lambda_p - \lambda_k^{\text{birth}}\bigr)$$

This is the area under the "number of points still in cluster" curve, plotted against density \(\lambda\). A cluster with high stability persists with many points across a large density range — it's a genuine structure.

Optimal Cluster Selection (Leaf-Pruning Algorithm)

The selection algorithm traverses the condensed tree bottom-up. For each cluster \(C\) with children \(\{C_1, C_2, \ldots\}\):

$$\text{select } C \iff \mathrm{stability}(C) \geq \sum_i \mathrm{stability}(C_i)$$

If selecting the parent is better, the children are discarded. If not, children are kept and their stability propagates upward. This is equivalent to finding the set of non-overlapping sub-trees that maximize total stability — a tree-structured optimization problem solvable greedily in \(O(N)\).

Soft Membership Score

For point \(p\) assigned to cluster \(C^*\), the soft membership is:

$$\text{membership}(p, C^*) = \frac{\lambda_p}{\max_{q \in C^*} \lambda_q}$$

A value near 1 means the point was in the cluster at high density (core member); near 0 means it barely made it in (border or potential outlier). Points not assigned to any cluster get membership 0 everywhere.

📐 Key Complexity

Naive: \(O(n^2)\) distance computation + \(O(n^2 \log n)\) MST. With dual-tree algorithms and approximate nearest neighbors: \(O(n \log n)\). The condensation and selection steps are \(O(n)\). Memory: \(O(n^2)\) for dense distance matrix, \(O(n \log n)\) with sparse approximation.

Key Takeaways & When to Use
▼

Use HDBSCAN when:

  • Clusters have varying densities (DBSCAN's single \(\varepsilon\) fails)
  • You want automatic noise detection without tuning an \(\varepsilon\) threshold
  • You need soft membership scores (probabilistic cluster assignment)
  • Clusters are non-convex / non-globular shapes
  • You have a reasonable guess for min_cluster_size but not \(\varepsilon\)

Use K-Means instead when:

  • Clusters are roughly spherical and equally sized
  • You need exact \(k\) clusters and speed is critical (\(O(kn)\) vs \(O(n^2)\))

Use DBSCAN instead when:

  • All clusters have similar density — simpler and faster
  • You need a single \(\varepsilon\) for interpretability
💡 Production Tips

min_cluster_size is the main lever — set it to the smallest cluster you'd care about (e.g., 5 for anomaly detection, 50 for customer segmentation). min_samples (= min_pts for core distances) controls conservatism; default = min_cluster_size. Use UMAP + HDBSCAN as a powerful dimensionality-reduction + clustering pipeline for high-dimensional data.

import numpy as np
from scipy.spatial.distance import cdist
import hdbscan
# Step 1: Core distances (min_pts = 3)
D = cdist(pts, pts) # O(n²) pairwise distances
core_dist = np.sort(D, axis=1)[:, 2] # 3rd nearest neighbor dist
# Step 2: Mutual reachability distance
mrd = np.maximum(core_dist[:,None], # broadcast row core dists
np.maximum(core_dist[None,:], D)) # max(core_i, core_j, d_ij)
# Step 3: MST of mutual reachability graph
from scipy.sparse.csgraph import minimum_spanning_tree
mst = minimum_spanning_tree(mrd) # Kruskal's internally
# Step 4+5: Condense + stability selection
clusterer = hdbscan.HDBSCAN(
min_cluster_size=3,
min_samples=3, # min_pts for core distances
cluster_selection_method='eom') # excess of mass = stability
clusterer.fit(pts)
# Results
labels = clusterer.labels_ # -1 = noise
probs = clusterer.probabilities_ # soft membership [0,1]
scores = clusterer.outlier_scores_ # GLOSH outlier score
# Expected: pts 0-4 → label 0, pts 5-9 → label 1, pts 10-12 → label -1
