Type I & II Errors, Power of a Test

The two ways a hypothesis test can be wrong — and how to balance them
Foundational Lean Intermediate Probability & Statistics Hypothesis Testing Must Know
1
Understanding the Concept
▼

What is it? When you run a statistical test, you can make two kinds of mistakes. A Type I error (false positive) is when you cry "wolf" — you conclude the effect is real when it actually isn't. A Type II error (false negative) is the opposite: you miss the wolf entirely — you conclude nothing is happening when an effect truly exists.

Analogy: Courtroom & Medical Testing. Imagine a court that tries to determine if a drug works. Type I error = sending an innocent drug to market (the drug does nothing, but your test said it works). Type II error = acquitting a guilty drug (the drug really works, but your test missed it). Power is the probability you catch the guilty drug when it is guilty.

If you remember one thing

Every hypothesis test sets a decision threshold. \(\alpha\) = probability of a false alarm (reject \(H_0\) when it's true). \(\beta\) = probability of a miss (fail to reject \(H_0\) when it's false). Power \(= 1 - \beta\) = probability of detecting a real effect. Lowering \(\alpha\) always raises \(\beta\) — you cannot eliminate both errors without more data.

The Decision Table

Every test produces one of four outcomes:

Decision \ Truth \(H_0\) True (no effect) \(H_1\) True (effect exists)
Reject \(H_0\) Type I Error (\(\alpha\)) Correct! (Power = \(1{-}\beta\))
Fail to reject \(H_0\) Correct! (\(1{-}\alpha\)) Type II Error (\(\beta\))

How Errors Arise Internally
▼

The Hypothesis Test Mechanism

A one-sample z-test illustrates the geometry. We want to know if the true mean \(\mu\) equals zero (null) or some positive value \(\delta\) (alternative). We collect \(n\) observations with known variance \(\sigma^2\) and compute the test statistic:

$$Z = \frac{\bar{X}}{\sigma/\sqrt{n}}$$

Under \(H_0\), \(Z \sim \mathcal{N}(0, 1)\). Under \(H_1\) (true mean \(= \delta\)), \(Z \sim \mathcal{N}(\lambda, 1)\) where \(\lambda = \delta\sqrt{n}/\sigma\) is called the non-centrality parameter.

The Critical Value Sets the Threshold

We reject \(H_0\) when \(Z > z_\alpha\), where \(z_\alpha = \Phi^{-1}(1 - \alpha)\) is the upper \(\alpha\)-quantile of the standard normal. For \(\alpha = 0.05\) (one-sided), \(z_{0.05} \approx 1.645\).

  • Type I error rate: \(\alpha = P(Z > z_\alpha \mid H_0) = 1 - \Phi(z_\alpha)\) — by construction, this equals the chosen significance level.
  • Type II error rate: \(\beta = P(Z \leq z_\alpha \mid H_1) = \Phi(z_\alpha - \lambda)\) — probability that even when \(H_1\) is true, the test statistic falls below the threshold.
  • Power: \(1 - \beta = P(Z > z_\alpha \mid H_1) = 1 - \Phi(z_\alpha - \lambda)\)
Key Insight: The Tradeoff Geometry

Both errors arise because the two distributions (\(H_0\) and \(H_1\)) overlap. The threshold cuts through both. Moving it right decreases \(\alpha\) but increases \(\beta\); moving it left decreases \(\beta\) but increases \(\alpha\). The only way to reduce both simultaneously is to increase \(n\) — more data separates the distributions.

What Controls Power?

Power \(= 1 - \Phi(z_\alpha - \lambda)\) increases when:

  • \(\lambda = \delta\sqrt{n}/\sigma\) increases — larger effect size \(\delta\), bigger \(n\), or smaller \(\sigma\)
  • \(\alpha\) increases — raising the significance level (accepting more false positives) raises power

Why It Works — The Math
▼

Formal Definitions

Consider testing \(H_0: \mu = \mu_0\) vs \(H_1: \mu = \mu_1 > \mu_0\) using \(n\) i.i.d. observations from \(\mathcal{N}(\mu, \sigma^2)\).

$$\alpha = P(\text{Reject } H_0 \mid H_0 \text{ true}) = P\!\left(Z > z_\alpha \mid \mu = \mu_0\right)$$
$$\beta = P(\text{Fail to reject } H_0 \mid H_1 \text{ true}) = P\!\left(Z \leq z_\alpha \mid \mu = \mu_1\right)$$
$$\text{Power} = 1 - \beta = P(\text{Reject } H_0 \mid H_1 \text{ true})$$

Closed Form for the Z-Test

Let \(\delta = \mu_1 - \mu_0\) (effect size), \(\lambda = \delta\sqrt{n}/\sigma\) (non-centrality). Then:

$$\beta = \Phi\!\left(z_\alpha - \lambda\right), \qquad \text{Power} = 1 - \Phi\!\left(z_\alpha - \frac{\delta\sqrt{n}}{\sigma}\right)$$

Sample Size Calculation

To guarantee power \(1 - \beta^*\) at effect size \(\delta\) and significance \(\alpha\):

$$n^* = \left\lceil \left(\frac{(z_\alpha + z_{\beta^*})\,\sigma}{\delta}\right)^2 \right\rceil$$

For \(\alpha = 0.05\), power \(= 0.80\) (so \(z_{\beta^*} = 0.842\)), effect size \(\delta = \sigma\) (Cohen's \(d = 1\)): \(n^* = \lceil(1.645 + 0.842)^2\rceil = \lceil 6.19 \rceil = 7\). For \(d = 0.5\): \(n^* = \lceil 4 \times 6.19 \rceil = 25\).

Common Misconception

\(\alpha\) is not the probability that \(H_0\) is true given you rejected it. That would be the false discovery rate (FDR), which also depends on the prior probability that \(H_0\) is true. A p-value \(< 0.05\) does not mean the probability of a false positive is 5%.

Neyman–Pearson Optimality

The Neyman–Pearson Lemma guarantees that for a simple vs simple test (\(H_0: \theta = \theta_0\) vs \(H_1: \theta = \theta_1\)), the likelihood ratio test is the most powerful test at level \(\alpha\). This is why z-tests, t-tests, and F-tests dominate — they are the UMP (uniformly most powerful) tests under their respective models.

Key Takeaways & Interview Tips
▼

The fundamental tradeoff: For a fixed sample size, reducing \(\alpha\) (moving the threshold right) inevitably increases \(\beta\) — there is no free lunch. The only escape is larger \(n\).

When to prioritize \(\alpha\) vs. \(\beta\)

  • Clinical trials (drug approval): Cost of a false positive (approving a useless/harmful drug) is very high → use small \(\alpha = 0.001\) or \(0.005\)
  • Screening tests (cancer detection): Cost of a false negative (missing cancer) is very high → maximize power, accept higher \(\alpha\)
  • Exploratory ML research: Often accept \(\alpha = 0.10\) to avoid missing promising directions

Common Interview Questions

  • Q: "A p-value of 0.03 means there's a 3% chance the null is true." — False. A p-value is \(P(\text{data this extreme} \mid H_0)\), not \(P(H_0 \mid \text{data})\).
  • Q: "We can simultaneously have \(\alpha = 0.01\) and power \(= 0.99\) with \(n = 10\)." — False unless the effect size is enormous.
  • Q: "Increasing \(n\) reduces both errors." — True: more data narrows both distributions, shrinking the overlap region.
Practical rule of thumb

Standard practice sets \(\alpha = 0.05\) and targets power \(= 0.80\). To achieve this for a two-sample t-test with Cohen's \(d = 0.5\) (medium effect), you need \(n \approx 64\) per group. Use the formula: \(n \approx \left(\frac{z_\alpha + z_\beta}{\delta/\sigma}\right)^2\).

Code Trace
▼

Step through the computation of \(\alpha\), \(\beta\), and power for a one-sided z-test. Highlighted lines correspond to the active computation.

import numpy as np
from scipy import stats
# Parameters
alpha = 0.05 # significance level
delta = 0.5 # effect size (mu1 - mu0) / sigma
n = 25 # sample size
sigma = 1.0 # known std dev (normalized)
# Critical value: threshold where we reject H0
z_crit = stats.norm.ppf(1 - alpha) # = 1.6449
# Non-centrality parameter under H1
lam = delta * np.sqrt(n) / sigma # = 2.500
# Type I error (alpha) — by construction
alpha_check = 1 - stats.norm.cdf(z_crit) # = 0.050
# Type II error (beta)
beta = stats.norm.cdf(z_crit - lam) # = 0.196
# Power
power = 1 - beta # = 0.804
# Sample size needed for target power
target_power = 0.80
z_beta = stats.norm.ppf(target_power) # = 0.842
n_star = ((z_crit + z_beta) / delta)**2 # = 24.8 → 25
print(f"n* = {np.ceil(n_star):.0f}") # n* = 25
