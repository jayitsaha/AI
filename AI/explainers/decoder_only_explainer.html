Understanding Decoder-Only Models
▼

What is it? A decoder-only Transformer — the architecture behind GPT-2, GPT-3, GPT-4, LLaMA, and nearly every modern chat assistant — is a language model that reads text left-to-right and predicts one word at a time, feeding each prediction back in as input for the next. It is "decoder-only" because it keeps just the Transformer's decoder stack (masked self-attention + feed-forward layers) and discards the encoder half that the original 2017 Transformer used for translation.

Analogy: Imagine writing a story one word at a time with your hand covering everything you haven't written yet — you can only look backward at what you've already written, never peek ahead. Each new word is chosen by weighing how relevant every previous word is right now, then guessing the most plausible next word. Write it down, slide your hand over one more word, repeat. That sliding, backward-only glance is exactly what "causal" (masked) self-attention enforces.

How GPT Works Internally
▼

The Stack

A GPT model embeds each input token into a vector, adds a positional signal, then pushes the sequence through \(L\) identical blocks. Each block has two sub-layers wrapped in residual connections and LayerNorm: (1) masked multi-head self-attention, and (2) a position-wise MLP (usually 4× wider, GELU activation). A final linear layer ("unembedding") projects the last position's hidden state onto vocabulary-sized logits.

Causal Masking — the defining trick

Self-attention normally lets every position see every other position. A decoder-only model instead computes attention scores \(QK^\top/\sqrt{d}\) and then sets every entry above the diagonal to \(-\infty\) before the softmax, so token \(t\) can only attend to tokens \(1,\dots,t\). This single triangular mask is what turns a general Transformer into an autoregressive generator: training on a whole sequence in parallel still respects "no peeking at the future," so one forward pass yields a correct next-token loss at every position simultaneously.

Inference: one token at a time

At generation time, the model only needs the hidden state of the newest position to produce the next token, but that state's attention still needs the Keys/Values of every earlier position. Recomputing those on every step would be wasteful, so real systems use a KV cache: K and V for each past position are computed once and reused, making each new token cost roughly \(O(nd)\) instead of \(O(n^2 d)\).

🔑 Design Decision: Why decoder-only, not encoder-decoder?

Encoder-decoder Transformers (e.g. the original 2017 model, T5) need paired input/output text and a separate encoder pass. Decoder-only models unify every task — translation, summarization, chat, code — as "predict the next token given everything so far," so one architecture, one objective, and one training pipeline scale to internet-sized corpora without task-specific engineering.

Why It Works — The Math
▼

Causal Self-Attention, precisely

For a sequence of embeddings \(x_1,\dots,x_n \in \mathbb{R}^d\), each position produces a query, key and value via learned projections \(Q = XW_Q,\ K = XW_K,\ V = XW_V\). The attention weights for position \(t\) are:

$$\alpha_{t,i} = \frac{\exp(q_t \cdot k_i / \sqrt{d_k})}{\sum_{j \le t} \exp(q_t \cdot k_j / \sqrt{d_k})} \quad \text{for } i \le t, \qquad \alpha_{t,i} = 0 \text{ for } i > t$$

The output at position \(t\) is the weighted sum \(z_t = \sum_{i \le t} \alpha_{t,i}\, v_i\) — a context vector built only from the past. The \(1/\sqrt{d_k}\) scale keeps dot-product magnitudes (which grow with dimension) from saturating the softmax into near one-hot gradients.

From hidden state to next-token distribution

The final block's output at the last position, \(h_n\), is projected to logits \(\ell = h_n W_{unembed} \in \mathbb{R}^{|V|}\), then converted to a probability distribution with temperature \(T\):

$$p(x_{n+1} = v \mid x_{\le n}) = \frac{\exp(\ell_v / T)}{\sum_{v'} \exp(\ell_{v'} / T)}$$

Training minimizes cross-entropy (equivalently, maximizes likelihood) of the true next token at every position in parallel:

$$\mathcal{L}(\theta) = -\frac{1}{n}\sum_{t=1}^{n} \log p_\theta(x_{t+1} \mid x_{\le t})$$

Gradients flow backward through every masked-attention and MLP sub-layer via the residual stream, exactly as in any deep Transformer — the causal mask only zeroes out illegal attention edges, it does not change how backpropagation works.

⚠️ Common Pitfall

Temperature \(T\) reshapes the distribution but is applied after training — it never changes what the model "believes," only how deterministically it samples. \(T \to 0\) recovers greedy argmax decoding; \(T \to \infty\) approaches uniform random tokens. Many practitioners mistakenly think low temperature makes the model "more accurate" — it only makes it more confident/repetitive, not more correct.

Key Takeaways
▼

When decoder-only shines:

  • Open-ended generation — chat, completion, code, creative writing
  • One model, any task — framed as "predict the next token"
  • Massive unlabeled text corpora — self-supervised, no annotation needed
  • In-context learning — few-shot prompting emerges at scale without gradient updates

Trade-offs vs. other Transformer flavors:

  • No bidirectional context — a token can't be informed by what comes after it (unlike BERT-style encoders)
  • Generation is inherently sequential — one token at a time, mitigated but not eliminated by KV caching
  • Long contexts are expensive — vanilla attention is \(O(n^2)\) in sequence length
💡 Family Tree

GPT-1 (2018, 117M, proved pretrain+finetune) → GPT-2 (2019, 1.5B, zero-shot task transfer) → GPT-3 (2020, 175B, few-shot in-context learning) → InstructGPT/ChatGPT/GPT-4 (RLHF-aligned, multimodal). The same causal decoder block, scaled and refined, powers LLaMA, Mistral, Claude's underlying architecture family, and most modern LLMs.

import numpy as np
# Toy causal self-attention (single head), d=4
def softmax(z):
z = z - np.max(z) # numerical stability
e = np.exp(z)
return e / e.sum()
def causal_attention(X, Wq, Wk, Wv):
n, d = X.shape
Q, K, V = X @ Wq, X @ Wk, X @ Wv
Z = np.zeros_like(V)
for t in range(n):
scores = (Q[t] @ K[:t+1].T) / np.sqrt(d) # only i <= t
weights = softmax(scores) # causal mask
Z[t] = weights @ V[:t+1]
return Z
