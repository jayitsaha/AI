Understanding Dimensionality Reduction
▼

What is it? Dimensionality reduction (DR) is the process of transforming data from a high-dimensional space into a lower-dimensional space such that the lower-dimensional representation retains some meaningful properties of the original data, ideally its intrinsic structure. When used for feature extraction, the goal is to create a new, smaller set of features that are more informative or less redundant than the original ones.

Analogy: Imagine a high-resolution photograph of a landscape. You want to send it quickly over a slow internet connection. You could either crop out parts of the image (feature selection), or compress it into a JPEG file (feature extraction). JPEG compression reduces the number of pixels (dimensions) while trying to keep the most visually important details, generating a new, smaller representation that's still recognizable. That compressed file is your "extracted features."

💡 If you remember one thing

Dimensionality reduction, particularly as feature extraction, aims to find a low-dimensional "essence" of high-dimensional data. This essence (the compressed representation) can then be used as new features for downstream tasks, often improving performance, reducing storage, and speeding up computation.

How It Works Internally: PCA vs. Autoencoders
▼

Principal Component Analysis (PCA)

PCA is a linear dimensionality reduction technique. It works by identifying orthogonal (uncorrelated) directions, called principal components, in the data that capture the maximum variance. The first principal component captures the most variance, the second the second most, and so on. By keeping only the top \(k\) principal components, we project the original data onto these new axes, effectively reducing its dimensionality from \(D\) to \(k\).

  • Centering: Data is first shifted so its mean is at the origin.
  • Covariance Matrix: Computed to understand relationships between features.
  • Eigen-decomposition: The eigenvectors of the covariance matrix are the principal components, and their corresponding eigenvalues indicate the amount of variance captured along each component.
  • Projection: Data points are projected onto the subspace spanned by the chosen \(k\) principal components.

Autoencoders (AE)

Autoencoders are neural networks designed for unsupervised learning of efficient data codings. They consist of two parts: an encoder that maps the input data to a lower-dimensional "latent space" (the bottleneck), and a decoder that maps the latent representation back to the original input space. The network is trained to reconstruct its own input, forcing the latent space to capture the most salient features.

  • Encoder: A neural network that transforms input \(x\) into a latent representation \(z\), where \(\dim(z) < \dim(x)\).
  • Decoder: Another neural network that transforms \(z\) back into a reconstruction \(\hat x\), where \(\dim(\hat x) = \dim(x)\).
  • Reconstruction Loss: The network is trained to minimize the difference between \(x\) and \(\hat x\) (e.g., Mean Squared Error).

Design Decision: When to choose which?

PCA is linear, computationally efficient, and provides interpretable components (directions of maximal variance). It's great for noisy, high-dimensional linear data. However, it cannot capture non-linear relationships. Autoencoders, especially with non-linear activation functions, can learn complex, non-linear mappings. They are more flexible and can extract richer features, but are harder to train, require more data, and their latent features might be less interpretable. For data with strong non-linear structure (e.g., images, text), autoencoders often outperform PCA.

🔑 Key Property

Both PCA and linear autoencoders (with specific architectures) are closely related: a linear autoencoder trained with MSE loss can learn to project data onto the same subspace spanned by PCA's principal components. Autoencoders generalize this idea to non-linear transformations.

3
Why It Works — The Math
▼

PCA: Maximizing Variance

Given a dataset \(X \in \mathbb{R}^{N \times D}\) (N samples, D features), first center the data: \(\tilde X = X - \mu\), where \(\mu\) is the mean of each feature. The covariance matrix is then \(C = \frac{1}{N-1}\tilde X^\top \tilde X\). PCA seeks to find a set of orthogonal vectors \(v_1, \dots, v_k\) (principal components) such that the variance of the projected data is maximized.

This is equivalent to finding the eigenvectors of the covariance matrix \(C\). For each principal component \(v_j\), we have:

$$C v_j = \lambda_j v_j$$

where \(\lambda_j\) is the eigenvalue corresponding to \(v_j\). The eigenvalues represent the variance captured along each principal component. To reduce to \(k\) dimensions, we select the \(k\) eigenvectors corresponding to the largest eigenvalues. The projection \(z_i\) of a data point \(x_i\) onto the first principal component \(v_1\) is simply its dot product:

$$z_i = x_i \cdot v_1$$

And the reconstruction \(\hat x_i\) from this 1D latent space (plus the mean) is:

$$\hat x_i = z_i v_1 + \mu$$

Autoencoders: Minimizing Reconstruction Error

A simple linear autoencoder can be defined as follows:

Encoder: \(z = W_{enc} x + b_{enc}\)

Decoder: \(\hat x = W_{dec} z + b_{dec}\)

The network is trained to minimize a reconstruction loss, typically Mean Squared Error (MSE):

$$\mathcal{L}(x, \hat x) = \|x - \hat x\|^2 = \|x - (W_{dec}(W_{enc} x + b_{enc}) + b_{dec})\|^2$$

If the autoencoder is linear (no activation functions) and trained with MSE loss, and the latent dimension is smaller than the input dimension, it can be shown that the encoder weights \(W_{enc}\) will learn to span the same subspace as the principal components found by PCA (assuming centered data and no biases). This mathematical equivalence highlights their shared goal of finding a compact, informative representation.

⚠️ Common Pitfall

PCA assumes linearity and is sensitive to feature scaling. If features have vastly different scales, those with larger scales might dominate the principal components. Autoencoders, especially deep ones, can overfit if the latent dimension is too large or if regularization is insufficient, leading to a trivial identity mapping rather than true feature extraction.

Key Takeaways
▼

When to use dimensionality reduction as feature extraction:

  • Curse of Dimensionality: When high-dimensional data makes models complex, prone to overfitting, and slow to train.
  • Noise Reduction: By focusing on principal components or learned latent features, noise in less important dimensions can be discarded.
  • Data Visualization: Reducing to 2 or 3 dimensions allows plotting and visual inspection of high-dimensional data.
  • Storage & Speed: Storing and processing lower-dimensional features saves memory and speeds up downstream algorithms.
  • Feature Engineering: Automatically creating new, more abstract features that might be more useful than raw inputs.

When NOT to use or be careful:

  • Interpretability Loss: Reduced features (especially from non-linear autoencoders) can be hard to interpret.
  • Information Loss: Some information is always lost during reduction. If critical information lies in discarded dimensions, performance will suffer.
  • Computational Cost: For very large datasets, PCA's eigenvalue decomposition or autoencoder training can be computationally expensive.
  • Domain Knowledge: Sometimes, hand-crafted features based on domain expertise outperform learned features.
💡 Trade-off

The core challenge in dimensionality reduction is balancing compression (how much you reduce) with information preservation (how much useful signal you retain). This is often controlled by the choice of latent dimension \(k\).

import numpy as np
import torch
import torch.nn as nn
# 1. Generate sample data (e.g., noisy sine wave in 2D)
t = np.linspace(-5, 5, 100)
X_np = np.stack([t + np.random.normal(0, 0.5, 100),
np.sin(t) * 2 + np.random.normal(0, 0.5, 100)], axis=1)
# 2. PCA from scratch (for 2D -> 1D reduction)
mean_X = np.mean(X_np, axis=0)
centered_X = X_np - mean_X
covariance_matrix = np.cov(centered_X, rowvar=False)
eigenvalues, eigenvectors = np.linalg.eig(covariance_matrix)
# Sort by eigenvalue (largest first)
sorted_indices = np.argsort(eigenvalues)[::-1]
pc1 = eigenvectors[:, sorted_indices[0]] # First principal component
# Project data onto PC1 (feature extraction)
X_pca_1d = centered_X @ pc1
# Reconstruct data from 1D (feature reconstruction)
X_pca_reconstructed = (X_pca_1d[:, np.newaxis] @ pc1[np.newaxis, :]) + mean_X
# 3. Simple Linear Autoencoder (2D -> 1D -> 2D)
class LinearAutoencoder(nn.Module):
def __init__(self, input_dim, latent_dim):
super().__init__()
self.encoder = nn.Linear(input_dim, latent_dim)
self.decoder = nn.Linear(latent_dim, input_dim)
def forward(self, x):
latent = self.encoder(x)
reconstructed = self.decoder(latent)
return reconstructed, latent
# Example usage (training omitted for brevity)
ae = LinearAutoencoder(input_dim=2, latent_dim=1)
X_tensor = torch.tensor(X_np, dtype=torch.float32)
reconstructed_X_ae, latent_X_ae = ae(X_tensor)
# After training, reconstructed_X_ae.detach().numpy() would be similar to X_pca_reconstructed
