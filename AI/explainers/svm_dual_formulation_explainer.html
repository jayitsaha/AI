From the max-margin primal to the Lagrangian dual — and the door to kernel methods
Advanced Classical ML Optimization O(n² – n³) solve
1
Understanding SVM Duality
▼

What is it? A Support Vector Machine (SVM) finds the widest possible "corridor" (margin) between two classes of data. The dual formulation is a mathematically equivalent rewriting of that optimization that turns out to be easier to solve and — crucially — exposes a structure that allows SVMs to work in any feature space, including infinite-dimensional ones.

Analogy: Imagine two armies separated by a no-man's land. The primal problem says: "Move the boundary so the corridor is as wide as possible." The dual says: "Station soldiers only at the frontline — a small number of critical soldiers (support vectors) fully define where the boundary sits. Soldiers far behind the lines are irrelevant." The dual formulation identifies exactly which data points matter.

💡 If you remember one thing

The dual objective only involves inner products \(\mathbf{x}_i^\top \mathbf{x}_j\). Replacing those with a kernel function \(k(\mathbf{x}_i, \mathbf{x}_j)\) lets you implicitly work in a high-dimensional feature space without ever computing it — this is the kernel trick. The dual is the gateway to non-linear SVMs.

Key actors: The dual introduces one Lagrange multiplier \(\alpha_i \geq 0\) per training point. Points with \(\alpha_i > 0\) are the support vectors — the only points that determine \(\mathbf{w}\) and \(b\). All other points vanish from the solution.

2
Primal → Lagrangian → Dual
▼

Step 1 — The Primal Problem

Given training data \(\{(\mathbf{x}_i, y_i)\}_{i=1}^n\) with \(y_i \in \{+1, -1\}\), the hard-margin SVM solves:

$$\min_{\mathbf{w},b} \frac{1}{2}\|\mathbf{w}\|^2 \quad \text{subject to} \quad y_i(\mathbf{w}^\top \mathbf{x}_i + b) \geq 1 \quad \forall i$$

The margin width is \(2/\|\mathbf{w}\|\), so minimizing \(\|\mathbf{w}\|^2\) maximizes the margin. There are \(n\) inequality constraints — one per data point.

Step 2 — Form the Lagrangian

Introduce multipliers \(\alpha_i \geq 0\), one per constraint. The Lagrangian is:

$$\mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha}) = \frac{1}{2}\|\mathbf{w}\|^2 - \sum_{i=1}^n \alpha_i \bigl[y_i(\mathbf{w}^\top \mathbf{x}_i + b) - 1\bigr]$$

We want \(\min_{\mathbf{w},b} \max_{\boldsymbol{\alpha} \geq 0} \mathcal{L}\). For a convex QP with linear constraints, strong duality holds (Slater's condition), so this equals \(\max_{\boldsymbol{\alpha} \geq 0} \min_{\mathbf{w},b} \mathcal{L}\).

Step 3 — Eliminate the Primal Variables

Minimizing over \(\mathbf{w}\) and \(b\) by setting gradients to zero:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{w}} = 0 \implies \mathbf{w} = \sum_{i=1}^n \alpha_i y_i \mathbf{x}_i$$
$$\frac{\partial \mathcal{L}}{\partial b} = 0 \implies \sum_{i=1}^n \alpha_i y_i = 0$$

Substituting these back into \(\mathcal{L}\) eliminates \(\mathbf{w}\) and \(b\) completely, yielding the dual problem:

$$\max_{\boldsymbol{\alpha}} \sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \alpha_i \alpha_j y_i y_j \mathbf{x}_i^\top \mathbf{x}_j \quad \text{s.t.} \quad \sum_{i=1}^n \alpha_i y_i = 0, \quad \alpha_i \geq 0$$
🔑 Key Property — Strong Duality

Because the primal is a convex QP and the constraints are linear (Slater's condition: any strictly feasible point suffices), the duality gap is zero. The dual and primal solutions have identical objective values. This is guaranteed by the KKT theorem.

Step 4 — KKT Complementary Slackness

At optimality, the KKT conditions require: \(\alpha_i [y_i(\mathbf{w}^\top \mathbf{x}_i + b) - 1] = 0\) for all \(i\). This means either \(\alpha_i = 0\) (point not a support vector, irrelevant) or \(y_i(\mathbf{w}^\top \mathbf{x}_i + b) = 1\) (point lies exactly on the margin — a support vector). Support vectors are the only points with \(\alpha_i > 0\).

⚠️ Common Confusion

The dual has \(n\) variables (one \(\alpha_i\) per data point) and 1 equality + \(n\) bound constraints. If \(n\) is large (millions), even the dual QP is expensive. In practice, SMO (Sequential Minimal Optimization) solves it analytically for 2-variable sub-problems without forming the full \(n \times n\) Gram matrix explicitly.

Full Mathematical Derivation

Numerical Trace — 4-Point Dataset

Four points: \(\mathbf{x}_1=(1,2)^+\), \(\mathbf{x}_2=(2,3)^+\), \(\mathbf{x}_3=(-1,1)^-\), \(\mathbf{x}_4=(-2,-1)^-\). The Gram matrix \(Q_{ij} = y_iy_j\mathbf{x}_i^\top\mathbf{x}_j\) is:

$$Q = \begin{bmatrix} 5 & 8 & -1 & 4 \\ 8 & 13 & -1 & 7 \\ -1 & -1 & 2 & 1 \\ 4 & 7 & 1 & 5 \end{bmatrix}$$

Solving the dual QP yields \(\alpha_1=0.4,\;\alpha_2=0,\;\alpha_3=0.4,\;\alpha_4=0\). The weight vector:

$$\mathbf{w} = \sum_i \alpha_i y_i \mathbf{x}_i = 0.4(+1)(1,2) + 0.4(-1)(-1,1) = (0.8,\; 0.4)$$

Bias from support vector \(i=1\): \(b = y_1 - \mathbf{w}^\top\mathbf{x}_1 = 1 - (0.8\cdot1 + 0.4\cdot2) = -0.6\). Margin \(= 2/\|\mathbf{w}\| = 2/\sqrt{0.64+0.16} = 2/\sqrt{0.8} \approx 2.236\).

Dual objective value \(= \sum\alpha_i - \frac{1}{2}\boldsymbol{\alpha}^\top Q\boldsymbol{\alpha} = 0.8 - 0.4 = 0.4 = \frac{1}{2}\|\mathbf{w}\|^2\). ✓ Zero duality gap.

📐 Full Dual Derivation (Substitution Step)

Substitute \(\mathbf{w} = \sum_i \alpha_i y_i \mathbf{x}_i\) into \(\mathcal{L}\):

\(\frac{1}{2}\|\mathbf{w}\|^2 = \frac{1}{2}\left(\sum_i \alpha_i y_i \mathbf{x}_i\right)^\top\left(\sum_j \alpha_j y_j \mathbf{x}_j\right) = \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j \mathbf{x}_i^\top\mathbf{x}_j\)

\(\sum_i\alpha_i y_i(\mathbf{w}^\top\mathbf{x}_i) = \sum_{i,j}\alpha_i\alpha_j y_iy_j\mathbf{x}_i^\top\mathbf{x}_j\) and \(\sum_i\alpha_i y_i b = b\sum_i\alpha_i y_i = 0\).

Therefore \(\mathcal{L} = \sum_i\alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_iy_j\mathbf{x}_i^\top\mathbf{x}_j\). QED.

Decision Function at Test Time

To classify a new point \(\mathbf{x}^*\), compute:

$$\hat{y} = \operatorname{sign}\!\left(\sum_{i \in \text{SVs}} \alpha_i y_i \mathbf{x}_i^\top \mathbf{x}^* + b\right)$$

Only support vectors appear (terms with \(\alpha_i=0\) vanish). The prediction depends only on inner products — ready for kernelization.

The Kernel Extension

Replace every inner product \(\mathbf{x}_i^\top \mathbf{x}_j\) with \(k(\mathbf{x}_i,\mathbf{x}_j) = \phi(\mathbf{x}_i)^\top\phi(\mathbf{x}_j)\) for some (possibly infinite-dimensional) feature map \(\phi\). The dual becomes:

$$\max_{\boldsymbol{\alpha}} \sum_i \alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_iy_j k(\mathbf{x}_i,\mathbf{x}_j)$$

Popular kernels: RBF \(k(\mathbf{x},\mathbf{z})=\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2)\), polynomial \((1+\mathbf{x}^\top\mathbf{z})^d\). The kernel must be positive semi-definite (Mercer's theorem) to guarantee a valid inner product in feature space.

Kernel Trick & Takeaways
▼

The Kernel Trick in One Line

Because the dual depends on data only through \(\mathbf{x}_i^\top\mathbf{x}_j\), we can substitute any positive semi-definite kernel \(k(\mathbf{x}_i,\mathbf{x}_j)\) without ever computing the feature map \(\phi\). An RBF kernel implicitly uses an infinite-dimensional feature space but the dual still has only \(n\) variables.

💡 Why Duality Matters Beyond SVMs

The primal-dual derivation pattern — form Lagrangian, take stationarity conditions, substitute back — is a universal tool in constrained convex optimization. It appears in compressed sensing, portfolio optimization, maximum entropy models, and Gaussian process inference. Understanding the SVM dual builds intuition for all of these.

When to Use Which Formulation

Primal is preferred when \(d \gg n\) (very high-dimensional features, e.g., text with TF-IDF). Dual is preferred when \(n \ll d\) or when kernels are needed. For linear SVMs on large datasets, primal SGD (e.g., Pegasos) is faster than solving the dual QP.

Summary of Key Relationships

Primal variables → Dual solution: \(\mathbf{w}^* = \sum_i \alpha_i^* y_i \mathbf{x}_i\). Dual variables → geometry: \(\alpha_i^* > 0\) iff point \(i\) is a support vector. Both give: same decision boundary, same margin, same objective value (zero duality gap).

⚠️ Hard-Margin vs Soft-Margin

The hard-margin dual above requires linear separability. The soft-margin SVM adds slack variables \(\xi_i \geq 0\) to allow misclassifications, controlled by hyperparameter \(C\). The dual is identical except the bound \(\alpha_i \geq 0\) becomes \(0 \leq \alpha_i \leq C\). Support vectors now fall into: on-margin (\(\alpha_i < C\)), on/inside margin (\(\alpha_i = C\)).
