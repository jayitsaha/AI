Understanding TimesNet
▼

What is it? TimesNet (ICLR 2023) is a deep learning architecture for long-term time series forecasting. Unlike traditional models that treat time series as purely 1D sequences, TimesNet recognizes that real-world time series often exhibit multiple seasonalities or periodic patterns (e.g., daily, weekly, yearly cycles). It transforms the 1D series into a collection of 2D tensors, where each tensor captures variations across a specific period, and then applies 2D convolutions to model these "temporal 2D-variations."

Analogy: Imagine analyzing a year's worth of supermarket sales data. A traditional model might look at it as a single, long sequence. But you know there are weekly patterns (e.g., weekend spikes) and monthly patterns (e.g., holiday boosts). TimesNet is like taking that single stream of data and intelligently folding it into multiple spreadsheets: one for weekly sales (rows are weeks, columns are days), another for monthly sales (rows are months, columns are days of month). Then, it uses image-like filters (2D convolutions) to find patterns within and across these "temporal images," capturing how sales evolve over days within a week, and how those weekly patterns change over months.

💡 If you remember one thing

TimesNet's core idea is to leverage the implicit multi-periodicity of time series data. It identifies dominant periods using Fast Fourier Transform (FFT), then reshapes the 1D series into a collection of 2D tensors, each corresponding to a discovered period. These 2D tensors are then processed by 2D convolutional layers, allowing the model to capture complex temporal dependencies both within and across cycles.

How TimesNet Works Internally
▼

The Three Pillars of TimesNet

TimesNet operates through a three-stage process within each TimesBlock (its fundamental building block):

  1. Periodicity Discovery: For an input time series \(X_{1D} \in \mathbb{R}^{L}\) (length \(L\)), TimesNet first applies a Fast Fourier Transform (FFT) to identify a set of \(k\) dominant periods. These periods \(p_1, p_2, \dots, p_k\) correspond to frequencies with the highest amplitudes in the Fourier spectrum. This step effectively extracts the core periodic components of the time series.
  2. Temporal 2D-Variation Modeling: For each discovered period \(p_i\), the 1D time series \(X_{1D}\) is reshaped into a 2D tensor \(X_{2D}^{(i)} \in \mathbb{R}^{p_i \times (L/p_i)}\). This "period-folding" arranges the data such that rows represent time within a cycle (e.g., day of week) and columns represent different cycles (e.g., different weeks). This structure naturally captures both intra-period (vertical) and inter-period (horizontal) dependencies. Multiple such 2D tensors are created, one for each dominant period.
  3. 2D Convolutional Processing: Each 2D tensor \(X_{2D}^{(i)}\) is then fed through a 2D convolutional neural network (CNN). These 2D CNNs can effectively learn local and global patterns within the "temporal image" — for example, how a daily pattern changes from one week to the next, or how specific hours of the day correlate across different days. The outputs from the different 2D CNNs (one for each period) are then fused (e.g., by concatenation or summation) and projected back into a 1D representation for downstream tasks.

Why 2D Convolutions for Time Series?

Traditional 1D convolutions on time series excel at capturing local sequential patterns. However, they struggle with long-range dependencies and multi-periodicity. By transforming the data into 2D, TimesNet allows 2D convolutions to explicitly model:

  • Intra-period variations: Patterns that occur within a single cycle (e.g., how values change from hour 1 to hour 24 within a day).
  • Inter-period variations: How patterns evolve across different cycles (e.g., how the Monday morning peak changes from one week to the next).

This explicit modeling of periodic structure, combined with the efficiency of 2D convolutions, makes TimesNet particularly effective for long-term forecasting tasks where multiple seasonalities are present.

🔑 Key Property

The FFT-based period discovery is crucial. It allows TimesNet to adaptively identify the most relevant periodicities in the data, rather than relying on fixed, predefined seasonalities. This makes the model robust to diverse time series with varying temporal structures.

3
Why It Works — The Math
▼

1. Periodicity Discovery via FFT

Given an input time series \(X_{1D} = \{x_1, x_2, \dots, x_L\} \in \mathbb{R}^L\), we first apply the Fast Fourier Transform to obtain its frequency spectrum. The amplitude of each frequency component reveals its strength in the series:

$$A_j = |\mathcal{F}(\omega_j)| = \left|\sum_{t=0}^{L-1} x_t e^{-i 2\pi \omega_j t / L}\right|$$

We then select the top-\(k\) frequencies \(\{\omega_{j_1}, \dots, \omega_{j_k}\}\) with the largest amplitudes. The corresponding periods are calculated as \(p_i = L / \omega_{j_i}\) (rounded to the nearest integer). These periods define the dimensions for our 2D tensors.

2. Temporal 2D-Variation Reshaping

For each dominant period \(p_i\), the 1D time series \(X_{1D}\) is reshaped into a 2D tensor \(X_{2D}^{(i)}\). This operation is essentially "folding" the 1D series. If \(L\) is not perfectly divisible by \(p_i\), padding or truncation might be applied. The resulting 2D tensor has dimensions \(p_i \times (L/p_i)\):

$$X_{2D}^{(i)} \in \mathbb{R}^{p_i \times \lceil L/p_i \rceil}$$

Each row in \(X_{2D}^{(i)}\) represents a specific phase within the period \(p_i\), and each column represents a full cycle of length \(p_i\). For instance, if \(p_i=24\) (daily period), the first row might be all values at 1 AM, the second at 2 AM, etc., across different days.

3. 2D Convolutional Processing and Aggregation

Each reshaped tensor \(X_{2D}^{(i)}\) is then processed by a dedicated 2D convolutional layer \(Conv2D_i\). The output of these convolutions captures features from both dimensions of the 2D tensor:

$$H^{(i)} = \text{ReLU}(\text{Conv2D}_i(X_{2D}^{(i)}))$$

Finally, the features \(H^{(i)}\) from all \(k\) periods are aggregated. This typically involves concatenating them along a feature dimension and then passing them through a linear projection layer to combine the multi-periodicity information into a unified representation for forecasting.

⚠️ Computational Cost

The FFT step has a complexity of \(O(L \log L)\). The reshaping and 2D convolutions add \(O(k \cdot p_i \cdot (L/p_i) \cdot K^2)\) for \(k\) periods and kernel size \(K\). While effective, this can be more computationally intensive than purely 1D models, especially for very long series or many dominant periods. Efficient implementation of FFT and 2D convolutions is key.

Key Takeaways
▼

When to use TimesNet:

  • Long-term forecasting: Its explicit handling of multi-periodicity makes it robust for predictions far into the future.
  • Data with clear seasonalities: Works best when there are discernible daily, weekly, monthly, or yearly patterns.
  • Complex temporal interactions: When patterns within a cycle interact with patterns across cycles (e.g., how the Monday peak is influenced by the previous Friday's sales).
  • Scalability: 2D convolutions are highly optimized on modern hardware, making it efficient for large datasets.

When to consider alternatives:

  • Non-periodic or chaotic data: If your time series has no discernible periodic patterns, the 2D transformation might not yield significant benefits.
  • Very short time series: FFT requires a sufficient length to identify periods reliably.
  • Extreme real-time constraints: While efficient, the FFT and 2D convolution steps add overhead compared to simpler 1D models.
  • Explainability is paramount: Interpreting features learned by 2D convolutions on reshaped temporal data can be more challenging than 1D models.
💡 Broader Impact

TimesNet's success underscores a growing trend in time series modeling: moving beyond purely sequential thinking. By drawing inspiration from computer vision (2D convolutions) and signal processing (FFT), it demonstrates how cross-domain ideas can unlock powerful new ways to represent and learn from temporal data, especially for complex, multi-scale phenomena.

import numpy as np
from scipy.fft import fft
def get_dominant_periods(series_1d, top_k=3):
L = len(series_1d)
fft_output = fft(series_1d)
magnitudes = np.abs(fft_output[1:L//2+1]) # ignore DC, use half spectrum
frequencies = np.arange(1, L//2+1) / L
# Sort by magnitude and get top-k indices
top_k_indices = np.argsort(magnitudes)[::-1][:top_k]
dominant_periods = np.round(1 / frequencies[top_k_indices]).astype(int)
return dominant_periods
def period_fold_to_2d(series_1d, period):
L = len(series_1d)
num_cycles = int(np.ceil(L / period))
# Pad series if needed to fill full cycles
padded_L = num_cycles * period
padded_series = np.pad(series_1d, (0, padded_L - L), 'constant')
return padded_series.reshape(period, num_cycles)
# Example usage:
# Simulate a time series with a dominant period (e.g., daily)
L = 96 # 4 days of hourly data
time_series = np.sin(np.linspace(0, 4 * 2 * np.pi, L)) + \
0.5 * np.sin(np.linspace(0, 1 * 2 * np.pi, L)) + \
np.random.rand(L) * 0.2
dominant_periods = get_dominant_periods(time_series, top_k=2)
print(f"Dominant periods: {dominant_periods}")
# Create 2D tensors for each period
all_2d_tensors = []
for p in dominant_periods:
if p > 1 and p <= L: # Ensure valid period
folded_2d = period_fold_to_2d(time_series, p)
all_2d_tensors.append(folded_2d)
print(f"2D tensor for period {p} (shape: {folded_2d.shape})")
