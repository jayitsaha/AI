Cocktail party problem · FastICA · Non-Gaussianity maximization

Advanced Unsupervised Learning Signal Processing O(n·d²) per iteration
1
Understanding ICA — The Cocktail Party Intuition

Imagine a cocktail party: multiple people speaking simultaneously, and multiple microphones scattered around the room. Each microphone records a different mixture of all the voices. Can you mathematically recover each individual's speech from the mixed recordings alone?

This is the cocktail party problem, and ICA solves it. ICA finds a linear transformation of your observed mixed signals that produces statistically independent outputs — the original sources — without knowing the mixing process in advance.

Core Insight

The central insight: independent signals can be recovered because mixing makes them more Gaussian (Central Limit Theorem). So to unmix them, we maximize non-Gaussianity. The more "un-Gaussian" each recovered signal is, the more independent it is.

ICA differs fundamentally from PCA. PCA seeks uncorrelated (orthogonal) components ordered by variance. ICA seeks statistically independent components, a strictly stronger condition. Uncorrelated = zero second-order statistics. Independent = zero statistics of ALL orders.

💡 Remember One Thing

Mixing independent non-Gaussian signals makes them look more Gaussian. FastICA reverses this by finding directions that maximize non-Gaussianity — measured by negentropy or kurtosis — thereby recovering the independent sources.

2
How FastICA Works — Step by Step

The ICA generative model: observed mixed signals \(\mathbf{x} \in \mathbb{R}^d\) are linear combinations of independent source signals \(\mathbf{s} \in \mathbb{R}^d\):

$$\mathbf{x} = A\mathbf{s} \quad\Longrightarrow\quad \mathbf{s} = W\mathbf{x}$$

where \(A\) is the unknown \(d \times d\) mixing matrix and \(W = A^{-1}\) is the unmixing matrix we want to find. FastICA finds \(W\) via three stages:

Stage 1 — Center & Whiten. Center: subtract the mean so \(\mathbb{E}[\mathbf{x}] = 0\). Then whiten (sphere) the data so the covariance is the identity matrix \(\mathbb{E}[\mathbf{z}\mathbf{z}^\top] = I\). Whitening is done via eigendecomposition of the covariance: \(\mathbf{z} = ED^{-1/2}E^\top\mathbf{x}\) where \(E\) are eigenvectors and \(D\) eigenvalues. After whitening, the mixing matrix becomes orthogonal — reducing the problem from finding an arbitrary \(A\) to finding a rotation matrix \(R\).

$$\mathbf{z} = \Sigma^{-1/2}(\mathbf{x} - \boldsymbol{\mu}) \quad\text{(whitened data)}$$

Stage 2 — Fixed-Point Iteration (Newton method on negentropy). For each independent component, find a direction \(\mathbf{w}\) (unit vector) such that \(\mathbf{w}^\top\mathbf{z}\) is maximally non-Gaussian. The FastICA update rule:

$$\mathbf{w} \leftarrow \mathbb{E}\bigl[g'(\mathbf{w}^\top\mathbf{z})\bigr]\mathbf{w} - \mathbb{E}\bigl[\mathbf{z}\,g(\mathbf{w}^\top\mathbf{z})\bigr]$$
$$\mathbf{w} \leftarrow \mathbf{w} / \|\mathbf{w}\|$$

where \(g\) is the derivative of a non-quadratic nonlinearity (e.g. \(g(u)=\tanh(u)\) or \(g(u)=u\exp(-u^2/2)\)) and \(g'\) its derivative. This is Newton's method applied to maximize negentropy.

⚠️ ICA Ambiguities

ICA cannot determine: (1) the order of the components, (2) the sign (scale) of each component (you can negate any source without changing independence), (3) the variance of each source (absorbed into the mixing matrix). These are fundamental, not bugs.

3
The Math — Why Non-Gaussianity = Independence

Kurtosis measures how heavy-tailed a distribution is. For a zero-mean, unit-variance variable \(y\):

$$\text{kurt}(y) = \mathbb{E}[y^4] - 3(\mathbb{E}[y^2])^2 = \mathbb{E}[y^4] - 3$$

Gaussian has kurtosis exactly 0. Sub-Gaussian (e.g. uniform): kurtosis < 0. Super-Gaussian (e.g. speech, Laplacian): kurtosis > 0. FastICA maximizes |kurtosis|, but kurtosis is sensitive to outliers.

Negentropy is a more robust measure. For variable \(y\) with the same variance as a Gaussian \(y_{gauss}\):

$$J(y) = H(y_{gauss}) - H(y) \geq 0$$

Negentropy is zero only for a Gaussian and always non-negative (differential entropy \(H\) is maximized by the Gaussian for fixed variance). The Gaussian is the "most disordered" distribution — mixing non-Gaussian sources pushes them toward Gaussian, so unmixing maximizes negentropy.

FastICA approximation of negentropy using a smooth non-quadratic function \(G\):

$$J(y) \approx \bigl[\mathbb{E}[G(y)] - \mathbb{E}[G(\nu)]\bigr]^2$$

where \(\nu \sim \mathcal{N}(0,1)\). Common choices: \(G(u) = \frac{1}{a}\log\cosh(au)\) (robust, good for super-Gaussian) or \(G(u) = -\exp(-u^2/2)\) (good for sub-Gaussian).

The Central Limit Theorem Connection

By the CLT, sums of independent random variables tend toward Gaussian. The mixture \(\mathbf{x} = A\mathbf{s}\) is a sum of independent sources — hence more Gaussian. Any linear combination \(\mathbf{w}^\top\mathbf{x}\) is maximally non-Gaussian when \(\mathbf{w}\) isolates exactly one source. FastICA exploits this: it finds the directions of maximum non-Gaussianity, which correspond precisely to the independent components.

Real-World Applications

EEG / MEG artifact removal: Isolate eye blinks, heart artifacts from brain signals. fMRI brain network discovery: Find spatially independent activation patterns. Financial data: Separate independent market factors. Image processing: Separate mixed image textures. Audio processing: The original cocktail party. Telecommunications: Separate multiplexed signals.

⚠️ When ICA Fails

ICA fails when: (1) sources are Gaussian — CLT means any linear combination looks equally Gaussian, making sources unidentifiable, (2) fewer observations than sources (underdetermined: use sparse ICA), (3) sources are not independent — e.g. speech from one person with reverb. Also, ICA assumes linear mixing; nonlinear mixing requires deep ICA variants.

FastICA from Scratch (NumPy) & Key Takeaways
import numpy as np
def fastica(X, n_components=None, max_iter=200, tol=1e-4):
"""FastICA: find statistically independent components of X (d, n)."""
d, n = X.shape
if n_components is None: n_components = d
# Step 1: Center
X -= X.mean(axis=1, keepdims=True)
# Step 2: Whiten using eigendecomposition of covariance
cov = (X @ X.T) / (n - 1)
eigvals, eigvecs = np.linalg.eigh(cov)
# Sort descending, regularize tiny eigenvalues
idx = np.argsort(eigvals)[::-1]
eigvals, eigvecs = eigvals[idx], eigvecs[:, idx]
W_white = eigvecs[:, :n_components] @ np.diag(1.0 / np.sqrt(eigvals[:n_components] + 1e-10))
Z = W_white.T @ X # whitened data: (n_components, n)
# Step 3: FastICA fixed-point iteration for each component
W = np.random.randn(n_components, n_components) # unmixing matrix
W = np.linalg.qr(W)[0] # initialize orthonormal
for iteration in range(max_iter):
W_old = W.copy()
# g(u) = tanh(u), g'(u) = 1 - tanh²(u)
U = W @ Z # (n_comp, n)
G = np.tanh(U) # g(w^T z)
Gp = 1.0 - G**2 # g'(w^T z)
# Newton step: W = E[z g(w^T z)^T] - E[g'(w^T z)] W
W = (G @ Z.T) / n - Gp.mean(axis=1, keepdims=True) * W
# Symmetric orthogonalization (keep all components simultaneously)
U2, _, Vt = np.linalg.svd(W)
W = U2 @ Vt
# Check convergence: max off-diagonal element of W @ W_old^T
delta = np.max(np.abs(np.abs(np.diag(W @ W_old.T)) - 1.0))
if delta < tol: break
# Full unmixing: W_total = W @ W_white^T
sources = W @ Z # recovered independent components (n_components, n)
return sources, W @ W_white.T

Key Takeaways:

  • ICA = Blind Source Separation via non-Gaussianity maximization
  • FastICA whitens first (makes mixing orthogonal), then applies fixed-point Newton iterations
  • Convergence is quadratic (Newton's method) — typically <50 iterations for large n
  • Ambiguities (order, sign, scale) are inherent; use domain knowledge to resolve them
  • Use sklearn.decomposition.FastICA in production; set fun='logcosh' (robust) or fun='cube' for sub-Gaussian sources
