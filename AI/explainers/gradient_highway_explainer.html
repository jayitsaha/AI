Gradient Highway (LSTM)

How LSTMs solve the vanishing gradient problem in recurrent neural networks
Foundational Deep Learning RNNs Complex Architecture
1
Understanding the Problem
▼

Recurrent Neural Networks (RNNs) are designed to process sequences by maintaining a hidden state that captures information from previous steps. However, standard RNNs struggle with long-term dependencies due to a fundamental issue: the vanishing gradient problem.

What is vanishing gradient? During backpropagation through time (BPTT), gradients are computed by repeatedly multiplying by weight matrices and derivatives of activation functions. If these values are consistently small (e.g., derivatives of sigmoid/tanh in their saturation regions), the gradient can shrink exponentially as it propagates backward through many time steps. This means that weights responsible for capturing long-term dependencies receive tiny updates, making it impossible for the network to learn them.

Imagine trying to remember a detail from a conversation that happened an hour ago. If every new sentence makes you forget a little bit of the previous context, by the time you need that detail, it's gone. Standard RNNs suffer from this "short-term memory" issue.

💡 The Core Problem

In standard RNNs, the hidden state \(h_t\) is the only carrier of information. Its update \(h_t = \tanh(W_{hh}h_{t-1} + W_{xh}x_t)\) involves a non-linear activation. Backpropagating through many such activations causes gradients to vanish, preventing learning of distant relationships.

2
LSTMs: The Gradient Highway
▼

Long Short-Term Memory (LSTM) networks were specifically designed to combat the vanishing gradient problem. They introduce a new component called the cell state (\(C_t\)), which acts as a "highway" for information to flow through time with minimal degradation.

Unlike the hidden state (\(h_t\)) which is heavily transformed by non-linearities at each step, the cell state has a direct, linear connection to itself across time. This allows gradients to flow unimpeded, preserving information over many time steps.

The Three Gates

LSTMs achieve this control through a system of three "gates," which are essentially neural networks (usually sigmoid activated) that regulate the flow of information into and out of the cell state:

  1. Forget Gate (\(f_t\)): Decides what information from the previous cell state (\(C_{t-1}\)) should be thrown away. Output is between 0 and 1.
  2. Input Gate (\(i_t\)): Decides what new information from the current input (\(x_t\)) and previous hidden state (\(h_{t-1}\)) should be stored in the cell state. It works in conjunction with a "candidate" cell state (\(\tilde{C}_t\)).
  3. Output Gate (\(o_t\)): Decides what part of the current cell state (\(C_t\)) should be exposed as the hidden state (\(h_t\)) for the current time step.

The magic for gradient flow lies in how the cell state is updated, primarily through element-wise multiplication with the forget gate, creating a path where gradients can either be preserved or diminished, rather than vanishing completely.

🔑 The Cell State Update

The cell state is updated as: $$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$ The term \(f_t \odot C_{t-1}\) is the "highway." If \(f_t\) is close to 1, information (and its gradient) from \(C_{t-1}\) passes through almost unchanged. The \(\odot\) denotes element-wise multiplication.

3
Why It Works — The Gradient Math
▼

Derivation of Gradient Flow

Let's consider the gradient of the loss function \(L\) with respect to the previous cell state \(C_{t-1}\). We use the chain rule, starting from the current cell state \(C_t\):

$$\frac{\partial L}{\partial C_{t-1}} = \frac{\partial L}{\partial C_t} \frac{\partial C_t}{\partial C_{t-1}}$$

From the cell state update equation \(C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t\), we can find the derivative of \(C_t\) with respect to \(C_{t-1}\):

$$\frac{\partial C_t}{\partial C_{t-1}} = f_t$$

Substituting this back into the chain rule, we get the crucial result:

$$\frac{\partial L}{\partial C_{t-1}} = \frac{\partial L}{\partial C_t} \odot f_t$$

This equation shows that the gradient \(\frac{\partial L}{\partial C_t}\) is multiplied by \(f_t\) (the forget gate's activation) as it propagates backward from \(C_t\) to \(C_{t-1}\). Since \(f_t\) is a sigmoid output, its values are between 0 and 1. If \(f_t\) is consistently close to 1, the gradient is effectively passed through without significant decay. This creates the "gradient highway."

Contrast with Standard RNNs

In a standard RNN, the gradient flow would look like \(\frac{\partial L}{\partial h_{t-1}} = \frac{\partial L}{\partial h_t} \frac{\partial h_t}{\partial h_{t-1}}\). The term \(\frac{\partial h_t}{\partial h_{t-1}}\) involves the derivative of the \(\tanh\) activation and the recurrent weight matrix \(W_{hh}\). This derivative is often small (\(<1\)) and when multiplied repeatedly, leads to vanishing gradients.

The LSTM's cell state, by contrast, has a direct, element-wise multiplication with \(f_t\). If \(f_t\) is learned to be near 1 for important information, the gradient can flow for many time steps without vanishing. This allows LSTMs to learn long-term dependencies effectively.

⚠️ Not a Magic Bullet

While LSTMs mitigate vanishing gradients, they don't eliminate them entirely. Gradients can still vanish if \(f_t\) consistently outputs very small values. Also, exploding gradients can still occur if weights are too large, though LSTMs are less prone to this through their controlled gates. Gradient clipping is often used as a safeguard.

Key Takeaways
▼

When to use LSTMs:

  • Processing sequences with long-term dependencies (e.g., natural language, speech, video).
  • Tasks requiring memory over many time steps (e.g., sentiment analysis, machine translation, time series prediction).
  • When standard RNNs fail to learn due to vanishing gradients.

Alternatives and Considerations:

  • GRU (Gated Recurrent Unit): A simpler variant of LSTM with two gates (reset and update). Often performs similarly to LSTMs with fewer parameters, making it faster to train. It also addresses vanishing gradients.
  • Transformer Networks: For many sequence-to-sequence tasks, Transformers (with their self-attention mechanism) have surpassed RNNs and LSTMs, as they can model long-range dependencies more directly without sequential processing. However, LSTMs still find use in streaming data or when computational resources are limited.
💡 Hierarchy of Sequence Models

Standard RNN (simple, prone to vanishing gradients) < GRU (gated, simpler than LSTM) < LSTM (gated, robust to vanishing gradients). Each step adds complexity to better handle long-term dependencies, with Transformers offering a parallelized alternative.

Code Trace
▼

A simplified Python-like pseudocode for a single LSTM cell's forward pass.

import numpy as np
def sigmoid(x):
return 1 / (1 + np.exp(-x))
def tanh(x):
return np.tanh(x)
def lstm_cell_forward(x_t, h_prev, C_prev, W, U, b):
# W, U, b are weight and bias matrices/vectors for all gates combined
# For simplicity, assume W, U, b are already split for f, i, C_tilde, o
# 1. Forget Gate: Decide what to forget from C_prev
f_t = sigmoid(W['f'] @ h_prev + U['f'] @ x_t + b['f'])
# 2. Input Gate: Decide what new info to store in C_t
i_t = sigmoid(W['i'] @ h_prev + U['i'] @ x_t + b['i'])
C_tilde_t = tanh(W['c'] @ h_prev + U['c'] @ x_t + b['c']) # Candidate cell state
# 3. Update Cell State: The "Gradient Highway"
C_t = f_t * C_prev + i_t * C_tilde_t
# 4. Output Gate: Decide what to output from C_t
o_t = sigmoid(W['o'] @ h_prev + U['o'] @ x_t + b['o'])
h_t = o_t * tanh(C_t) # New hidden state
return h_t, C_t, f_t, i_t, C_tilde_t, o_t

# h_prev_val = 0.5
# C_prev_val = 0.7
# W_params = {'f':0.5, 'i':0.3, 'c':0.6, 'o':0.4}
# U_params = {'f':0.5, 'i':0.4, 'c':0.6, 'o':0.3}
# b_params = {'f':0.5, 'i':0.1, 'c':0.0, 'o':0.0} # b['f'] can be adjusted
