Understanding Concentration Inequalities
▼

What are they? Concentration inequalities are precise mathematical statements that tell you: "the sum (or average) of many independent random variables is very unlikely to be far from its expected value — and the probability of being far away drops exponentially fast." This is the formal machinery behind why averaging data works, why machine learning models generalize, and why randomized algorithms succeed.

Analogy: Imagine flipping 10,000 fair coins. The expected number of heads is 5,000. What's the chance you get 6,000 or more? Intuitively: astronomically small. Concentration inequalities quantify exactly how small — and do so without needing the exact distribution of the sum.

If you remember one thing

Concentration inequalities give upper bounds on \(P(S_n \geq \mu + \delta)\) that decay exponentially in \(\delta^2\) (not just polynomially). The hierarchy from loosest to tightest: Markov → Chebyshev → Hoeffding → Bernstein → Chernoff, with each successive bound using more structure of the distribution.

Why it matters for ML: Every generalization bound in statistical learning theory — PAC learning, VC dimension bounds, Rademacher complexity — is derived using concentration inequalities. McDiarmid's inequality, in particular, is the "Swiss Army knife" of generalization bounds: it applies to any function of independent variables, not just sums.

The Three Key Bounds
▼

Hoeffding's Inequality (1963)

Let \(X_1, \ldots, X_n\) be independent with \(X_i \in [a_i, b_i]\). Then for any \(\delta > 0\):

$$P\!\left(S_n - \mathbb{E}[S_n] \geq \delta\right) \;\leq\; \exp\!\left(\frac{-2\delta^2}{\sum_{i=1}^n (b_i - a_i)^2}\right)$$

For \(X_i \in [0,1]\), this simplifies to \(\exp(-2\delta^2/n)\). Strength: requires only boundedness. Weakness: uses worst-case variance \((b_i-a_i)^2/4\) even when true variance is much smaller.

Bernstein's Inequality (variance-aware)

Let \(X_1, \ldots, X_n\) be independent with \(\mathbb{E}[X_i] = 0\), \(|X_i| \leq c\), and \(\sum \operatorname{Var}(X_i) = \sigma^2\). Then:

$$P\!\left(S_n \geq \delta\right) \;\leq\; \exp\!\left(\frac{-\delta^2/2}{\sigma^2 + c\delta/3}\right)$$

The key insight: the denominator uses the actual variance \(\sigma^2\), not the worst case. When \(\sigma^2 \ll n c^2/4\) (low-variance variables), Bernstein beats Hoeffding by orders of magnitude.

Chernoff Bounds (MGF method — tightest for Bernoulli sums)

For \(S_n = \sum_{i=1}^n X_i\) with \(X_i \sim \text{Bernoulli}(p)\) and \(\mu = np\), the multiplicative Chernoff bound states:

$$P\!\left(S_n \geq (1 + \delta_r)\mu\right) \;\leq\; \left(\frac{e^{\delta_r}}{(1+\delta_r)^{1+\delta_r}}\right)^\mu \;=\; e^{-\mu \cdot h(\delta_r)}$$

where \(h(x) = (1+x)\ln(1+x) - x\) and \(\delta_r = (t - \mu)/\mu\) is the relative deviation. The function \(h(x) \approx x^2/2\) for small \(x\), recovering Bernstein; and \(h(x) \approx x\ln x\) for large \(x\), giving even faster decay.

McDiarmid's Inequality (bounded differences)

Let \(f: \mathcal{X}^n \to \mathbb{R}\) satisfy the bounded differences condition: for all \(i\) and all inputs,

$$\sup_{x_1,\ldots,x_n,\,x_i'} \left|f(x_1,\ldots,x_i,\ldots,x_n) - f(x_1,\ldots,x_i',\ldots,x_n)\right| \leq c_i$$

Then for independent \(X_1, \ldots, X_n\):

$$P\!\left(f(X_1,\ldots,X_n) - \mathbb{E}[f] \geq \delta\right) \;\leq\; \exp\!\left(\frac{-2\delta^2}{\sum_{i=1}^n c_i^2}\right)$$
Key Insight — Why Bernstein Beats Hoeffding When Variance Is Small

For \(n=100\) Bernoulli(\(p=0.05\)) variables: Hoeffding uses worst-case \(\sigma^2_{\max} = n/4 = 25\), while Bernstein uses the actual \(\sigma^2 = np(1-p) = 4.75\). At deviation \(\delta = 10\): Hoeffding gives \(e^{-2} \approx 0.135\); Bernstein gives \(e^{-6.19} \approx 0.002\) — 65 times tighter.

3
Why They Work — Derivations
▼

The Master Trick: Markov + MGF (Chernoff's Method)

All exponential bounds use the same two-step recipe. For any \(s > 0\):

$$P(S_n \geq \mu + \delta) = P(e^{s S_n} \geq e^{s(\mu+\delta)}) \leq \frac{\mathbb{E}[e^{s S_n}]}{e^{s(\mu+\delta)}} = \frac{\prod_{i=1}^n M_{X_i}(s)}{e^{s(\mu+\delta)}}$$

Step 1 uses Markov's inequality on the random variable \(e^{sS_n}\). Step 2 uses independence (MGFs multiply). Then we optimize over \(s > 0\) to get the tightest bound. Different distributions give different MGFs, yielding different bounds.

Hoeffding's Lemma (the core ingredient)

For a zero-mean random variable \(X \in [a, b]\), Hoeffding's lemma states:

$$\mathbb{E}[e^{sX}] \leq \exp\!\left(\frac{s^2(b-a)^2}{8}\right)$$

Proof sketch: By convexity of \(e^{sx}\), we can upper-bound \(e^{sx} \leq \frac{b-x}{b-a}e^{sa} + \frac{x-a}{b-a}e^{sb}\). Taking expectations and using \(\mathbb{E}[X] = 0\): \(\mathbb{E}[e^{sX}] \leq e^{\phi(s)}\) where \(\phi(s) = -su + \ln(1-u+ue^{sv})\) with \(u = -a/(b-a)\), \(v = b-a\). Taylor-expanding at \(s=0\) gives \(\phi(s) \leq s^2(b-a)^2/8\).

Applying Hoeffding's lemma to each \(X_i - \mathbb{E}[X_i]\) and optimizing over \(s\):

$$P(S_n - \mu \geq \delta) \leq \exp\!\left(-s\delta + \sum_{i=1}^n \frac{s^2(b_i-a_i)^2}{8}\right) \xrightarrow{s^* = \frac{4\delta}{\sum(b_i-a_i)^2}} \exp\!\left(\frac{-2\delta^2}{\sum(b_i-a_i)^2}\right)$$

Bernstein's Refinement

Bernstein's approach bounds the MGF more carefully using variance. For \(|X_i| \leq c\), the key bound on the MGF is:

$$\mathbb{E}[e^{sX_i}] \leq \exp\!\left(\frac{s^2 \sigma_i^2/2}{1 - sc/3}\right) \quad \text{for } s < 3/c$$

This follows from the inequality \(e^t \leq 1 + t + t^2/(2(1-t/3))\) for \(t < 3\). Summing over \(i\), substituting \(\sigma^2 = \sum \sigma_i^2\), and optimizing over \(s\) gives Bernstein's bound.

McDiarmid via Doob Martingale

Define the Doob martingale: \(D_k = \mathbb{E}[f \mid X_1,\ldots,X_k] - \mathbb{E}[f \mid X_1,\ldots,X_{k-1}]\). The bounded differences condition implies \(|D_k| \leq c_k\). Applying Azuma's inequality (which uses Hoeffding's lemma on martingale differences):

$$P(f(X_1,\ldots,X_n) - \mathbb{E}[f] \geq \delta) \leq \exp\!\left(\frac{-2\delta^2}{\sum_{k=1}^n c_k^2}\right)$$
Common Pitfall

Bernstein's bound requires knowing the actual variance \(\sigma^2 = \sum \operatorname{Var}(X_i)\). In practice, \(\sigma^2\) may be unknown; you can replace it with an upper bound \(\hat{\sigma}^2\) — but using a loose \(\hat{\sigma}^2 = nc^2/4\) recovers the Hoeffding bound. Also note: McDiarmid gives one-sided and two-sided bounds; the two-sided version doubles the bound.

ML Connections & Key Takeaways
▼

Generalization Bounds (PAC Learning)

The empirical risk \(\hat{R}(h) = \frac{1}{n}\sum_{i=1}^n \ell(h(x_i),y_i)\) is a function of \(n\) i.i.d. samples. Each \(\ell_i \in [0,1]\). Changing one sample changes \(\hat{R}\) by at most \(1/n\). McDiarmid gives: \(P(R(h) - \hat{R}(h) \geq \delta) \leq e^{-2n\delta^2}\). Union-bounding over a hypothesis class of size \(|\mathcal{H}|\): with probability \(\geq 1-\gamma\), uniformly for all \(h \in \mathcal{H}\):

$$R(h) \;\leq\; \hat{R}(h) + \sqrt{\frac{\ln|\mathcal{H}| + \ln(1/\gamma)}{2n}}$$

Rademacher Complexity Tightening

The finite-\(|\mathcal{H}|\) bound is loose for infinite hypothesis classes. Rademacher complexity \(\mathfrak{R}_n(\mathcal{H})\) measures data-dependent complexity. Via McDiarmid applied to the supremum deviation, a tighter generalization bound holds:

$$R(h) \;\leq\; \hat{R}(h) + 2\mathfrak{R}_n(\mathcal{H}) + \sqrt{\frac{\ln(1/\gamma)}{2n}}$$

The \(\mathfrak{R}_n\) term replaces \(\sqrt{\ln|\mathcal{H}|/2n}\) and can be much smaller for structured classes (e.g., linear classifiers with bounded norm).

The Big Picture

Concentration inequalities encode the law of large numbers in finite-sample, non-asymptotic form. They are why machine learning works: given enough data, the empirical distribution concentrates around the true distribution, enabling generalization. The exponential tail decay means you need only \(O(\log(1/\delta)/\varepsilon^2)\) samples for \(\varepsilon\)-accurate estimates with failure probability \(\delta\).

Code Trace

import numpy as np, math
# Problem: n=100 Bernoulli(p=0.05) RVs, mu=5, sigma2=4.75
n, p = 100, 0.05
mu = n * p # = 5.0
sigma2 = n*p*(1-p) # = 4.75 (actual variance)
c = 1.0 # bounded in [0,1], so c_i = 1
delta = 10 # deviation above mean
# --- Hoeffding bound ---
# P(Sn - mu >= delta) <= exp(-2*delta^2 / (n*c^2))
hoeffding = math.exp(-2 * delta**2 / (n * c**2)) # = 0.1353
# --- Bernstein bound ---
# P(Sn - mu >= delta) <= exp(-delta^2 / (2*(sigma2 + c*delta/3)))
bernstein = math.exp(-delta**2 / (2*(sigma2 + c*delta/3))) # = 0.0021
# --- Chernoff bound (Bernoulli, MGF method) ---
# delta_rel = (t - mu) / mu = 10/5 = 2.0
delta_rel = delta / mu # = 2.0
h = (1+delta_rel)*math.log(1+delta_rel) - delta_rel # = 1.296
chernoff = math.exp(-mu * h) # = 0.0015
# --- McDiarmid on sample mean f(X) = mean(X) ---
# c_i = 1/n (changing one variable shifts mean by at most 1/n)
# P(|f(X) - E[f]| >= eps) <= exp(-2*eps^2 / sum(c_i^2))
eps = 0.1 # want sample mean within 0.1 of p
ci_sq_sum = n * (1/n)**2 # = 1/n = 0.01
mcdiarmid = math.exp(-2*eps**2 / ci_sq_sum) # = exp(-2) = 0.1353
print(f"Hoeffding: {hoeffding:.4f}") # 0.1353
print(f"Bernstein: {bernstein:.4f}") # 0.0021 (66x tighter!)
print(f"Chernoff: {chernoff:.4f}") # 0.0015 (90x tighter!)
print(f"McDiarmid: {mcdiarmid:.4f}") # 0.1353 (same as Hoeffding here)
