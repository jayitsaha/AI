Understanding Sparse & Robust PCA
▼

Standard PCA's blind spot: Classical PCA computes directions of maximum variance, but each principal component is a dense linear combination of all original features — making interpretation impossible in high dimensions. Worse, a single corrupted data point can completely distort every component.

Sparse PCA adds an \(\ell_1\) (LASSO) penalty to force each component to use only a few features. The result: components that say "high on features 3 and 7, zero everywhere else" instead of a smeared mix of all 500 genes.

Robust PCA takes a different angle: any data matrix \(X\) can be written as \(X = L + S\) where \(L\) is a low-rank "true signal" and \(S\) is a sparse "outlier" matrix. Recovering \(L\) and \(S\) via Principal Component Pursuit (PCP) gives exact separation under surprisingly mild conditions — even when outliers are large in magnitude.

💡 If you remember one thing

Sparse PCA: \(\ell_1\) penalty → few nonzero loadings → interpretable. Robust PCA: solve \(\min \|L\|_* + \lambda\|S\|_1\) subject to \(L+S=X\) → exact low-rank + sparse decomposition even with gross corruptions.

Internal Mechanisms
▼

Sparse PCA — Elastic Net Regression Loop

The SPCA algorithm (Zou, Hastie & Tibshirani 2006) alternates between two steps. Given current principal directions \(B \in \mathbb{R}^{p \times k}\):

  1. Fix \(B\), update scores \(A = X B (B^\top B)^{-1}\) — standard regression.
  2. Fix \(A\), update each loading \(\beta_j\) via Elastic Net: minimize \(\|XA_j - X\beta_j\|^2 + \lambda_1\|\beta_j\|_1 + \lambda_2\|\beta_j\|^2\). The \(\ell_1\) term soft-thresholds small loadings to exact zero.

Convergence is guaranteed; the \(\ell_1\) penalty controls sparsity (large \(\lambda_1\) → fewer nonzero features per component).

Robust PCA — Principal Component Pursuit

PCP (Candès et al. 2011) solves the convex relaxation:

$$\min_{L,S} \|L\|_* + \lambda\|S\|_1 \quad \text{subject to } L + S = X$$

where \(\|L\|_*\) is the nuclear norm (sum of singular values, the convex proxy for rank) and \(\|S\|_1\) is the entrywise \(\ell_1\) norm (convex proxy for sparsity). The constraint \(L+S=X\) means the two matrices must explain all observations.

Solving PCP: Singular Value Thresholding (SVT) via ADMM

The ADMM updates cycle through:

  1. \(L \leftarrow \mathcal{D}_\tau(X - S)\): soft-threshold singular values of \((X-S)\) at level \(\tau\).
  2. \(S \leftarrow \mathcal{S}_\lambda(X - L)\): soft-threshold entries of \((X-L)\) at level \(\lambda\).

Both operators are closed-form. SVT shrinks small singular values to zero, promoting low-rankness. Entry soft-thresholding zeros out non-outlier residuals, promoting sparsity. ADMM guarantees convergence to the global optimum (the problem is convex).

🔑 Key Theorem (Exact Recovery)

If \(L_0\) has rank \(r \leq c_r \sqrt{n}/\mu\log n\) (incoherence condition) and \(S_0\) has at most \(c_s n\) nonzeros (sparsity condition), then PCP with \(\lambda = 1/\sqrt{\max(n_1,n_2)}\) recovers \((L_0,S_0)\) exactly with high probability. The choice of \(\lambda\) is parameter-free!

3
Why It Works — The Math
▼

Sparse PCA: Penalized Variance Objective

Standard PCA solves \(\max_v v^\top \Sigma v\) subject to \(\|v\|=1\). Sparse PCA adds cardinality control via elastic net:

$$\underset{\alpha,\beta}{\operatorname{argmin}} \sum_{i=1}^n \|x_i - \alpha_i \beta\|^2 + \lambda_1\|\beta\|_1 + \lambda_2\|\beta\|^2 \quad \text{s.t. } \|\alpha\|=1$$

The \(\ell_1\) term induces soft-thresholding. After convergence, the loading \(\hat\beta\) is \(\ell_2\)-normalized. This is equivalent to a penalized SVD.

Soft-Thresholding Operators

The two workhorse operators for PCP are:

$$\mathcal{S}_\lambda(x) = \operatorname{sign}(x)\max(|x|-\lambda,0) \quad \text{(scalar soft-threshold)}$$
$$\mathcal{D}_\tau(M) = U\operatorname{diag}(\mathcal{S}_\tau(\sigma))V^\top \quad \text{(singular value thresholding, } M=U\Sigma V^\top\text{)}$$

Both are the proximal operators of \(\lambda|\cdot|\) and \(\tau\|\cdot\|_*\) respectively. ADMM minimizes the augmented Lagrangian by iterating these closed-form steps.

Incoherence & Why It Matters

A rank-\(r\) matrix \(L_0 = U\Sigma V^\top\) is \(\mu\)-incoherent if its singular vectors are not concentrated on a few entries: \(\|U^\top e_i\|^2 \leq \mu r/n\) for all \(i\). High incoherence means the low-rank component looks like an outlier — impossible to separate. Most real signal matrices (smooth, spread) satisfy the incoherence condition.

⚠️ Common Pitfall

If the outlier matrix \(S\) is also low-rank (e.g., a rank-1 spike), PCP cannot separate it from \(L\) — the problem is identically non-identifiable. PCP requires outliers to be sparse, not structured. For structured corruptions, use Outlier Pursuit or other robust methods.

Convergence Rate

ADMM for PCP converges at rate \(O(1/k)\) in primal residual. In practice, 500–1000 iterations suffice for machine-precision recovery on moderate-scale problems (\(n \lesssim 10^3\)).

# Robust PCA via ADMM (Singular Value Thresholding)
def rpca(X, lam=None, tol=1e-7, max_iter=1000):
m, n = X.shape; lam = lam or 1/np.sqrt(max(m,n))
L, S, Y = np.zeros_like(X), np.zeros_like(X), np.zeros_like(X)
mu = m*n / (4*np.sum(np.abs(X))); rho = 1.5
for it in range(max_iter):
L = svt(X - S + Y/mu, 1/mu) # SVT step: shrink singular values
S = soft_thresh(X - L + Y/mu, lam/mu) # Entry soft-threshold
Y = Y + mu*(X - L - S) # Dual update
if np.linalg.norm(X-L-S,'fro') < tol: break
return L, S

Key Takeaways & When to Use
▼

When to Use Sparse PCA

Use Sparse PCA when interpretability matters: genomics (which genes drive a PC?), finance (which assets load a factor?), neuroimaging (which voxels activate?). The components are sparser and easier to explain than standard PCA, at a cost of no longer being exactly orthogonal. Set \(\lambda_1\) by cross-validation on reconstruction error.

When to Use Robust PCA

Use Robust PCA when your data is contaminated with gross, possibly large-magnitude corruption affecting a small fraction of entries (not entire rows/columns). Applications: background subtraction in video (background = low-rank, moving objects = sparse), collaborative filtering with adversarial ratings, face recognition with occlusions. Works even when outlier magnitude is large — unlike Huber loss, which only handles small contamination.

📐 Quick Parameter Guide

Sparse PCA: \(\lambda_1 \in [0,1]\) controls sparsity (0 = standard PCA). Start at \(\lambda_1 = 0.1\) and increase until the number of nonzero loadings per component equals your desired interpretability target.

Robust PCA: Default \(\lambda = 1/\sqrt{\max(n_1,n_2)}\) works in theory and practice. Only tune if you know the outlier fraction; higher \(\lambda\) → sparser \(S\), lower rank \(L\).

Comparison at a Glance

Standard PCA — fast, orthogonal, no outlier resistance, dense loadings.
Sparse PCA — interpretable loadings, slower (iterative), slightly non-orthogonal, sensitive to outliers.
Robust PCA — resists gross corruptions, globally optimal (convex), decomposes \(X=L+S\), but doesn't give sparse loadings.
Sparse + Robust PCA — research frontier: apply Sparse PCA to the recovered \(L\) for both robustness and interpretability.

From-Scratch Implementation
▼

Sparse PCA (NumPy)

import numpy as np

def soft_thresh(x, lam):
    """Elementwise soft thresholding: sign(x)*max(|x|-lam, 0)"""
    return np.sign(x) * np.maximum(np.abs(x) - lam, 0)

def sparse_pca_1comp(X, lam1=0.1, lam2=0.01, max_iter=200, tol=1e-6):
    """One sparse principal component via elastic-net regression loop."""
    n, p = X.shape
    beta = np.random.randn(p); beta /= np.linalg.norm(beta)
    for _ in range(max_iter):
        # Step 1: update score given current loading
        alpha = X @ beta / (beta @ beta)   # shape (n,)
        # Step 2: update loading via ridge+lasso (elastic net)
        # Normal equations with L2 regularization
        A = X.T @ alpha                     # (p,)
        beta_new = soft_thresh(A, lam1/2) / (alpha @ alpha + lam2)
        if np.linalg.norm(beta_new - beta) < tol:
            break
        beta = beta_new
    return beta / np.linalg.norm(beta)     # normalize

Robust PCA (NumPy)

def svt(M, tau):
    """Singular value thresholding: shrink singular values by tau."""
    U, s, Vt = np.linalg.svd(M, full_matrices=False)
    return U @ np.diag(soft_thresh(s, tau)) @ Vt

def rpca(X, lam=None, tol=1e-7, max_iter=1000):
    """Principal Component Pursuit via ADMM."""
    m, n = X.shape
    lam = lam or 1.0 / np.sqrt(max(m, n))
    mu  = m * n / (4.0 * np.sum(np.abs(X)))  # step size
    L = np.zeros_like(X, dtype=float)
    S = np.zeros_like(X, dtype=float)
    Y = np.zeros_like(X, dtype=float)         # dual variable
    for it in range(max_iter):
        L = svt(X - S + Y / mu, 1.0 / mu)
        S = soft_thresh(X - L + Y / mu, lam / mu)
        Y = Y + mu * (X - L - S)
        err = np.linalg.norm(X - L - S, 'fro') / np.linalg.norm(X, 'fro')
        if err < tol:
            print(f"Converged at iter {it+1}, rel err={err:.2e}")
            break
    return L, S

# Example: video background subtraction
np.random.seed(42)
rows, cols, T = 8, 8, 30
# Low-rank background: rank-2
bg = np.outer(np.sin(np.linspace(0,np.pi,rows*cols)),
              np.cos(np.linspace(0,2*np.pi,T)))
# Sparse foreground: random 5% outliers
fg = np.zeros((rows*cols, T))
oc = np.random.choice(rows*cols*T, int(0.05*rows*cols*T), replace=False)
fg.ravel()[oc] = np.random.randn(len(oc)) * 3
X = bg + fg
L_hat, S_hat = rpca(X)
print("Recovered rank:", np.linalg.matrix_rank(L_hat, tol=1e-3))
