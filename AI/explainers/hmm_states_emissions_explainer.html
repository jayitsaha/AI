1
Understanding the Concept
▾

A Hidden Markov Model (HMM) is a statistical model for sequences where you observe outputs but cannot directly see the underlying process generating them. Think of the weather: you cannot see "today's weather state" directly from a thermometer reading alone — rain, sun, and cloud are hidden states that each produce observable symptoms (umbrella usage, ice cream sales, etc.).

The "Markov" part means the system has short memory: tomorrow's hidden state depends only on today's hidden state, not on anything further in the past. This first-order Markov assumption is what makes the math tractable.

Core Intuition

An HMM has two layers: an invisible Markov chain jumping between hidden states, and a visible layer where each hidden state emits an observable symbol according to its own probability distribution.

Four Components of an HMM

  • Hidden states \(S = \{s_1, s_2, \ldots, s_N\}\) — the unobservable process
  • Initial distribution \(\pi\) — probability of starting in each state
  • Transition matrix \(A\) — probability of moving between states
  • Emission matrix \(B\) — probability of observing each symbol from each state
Key Property

The model \(\lambda = (A, B, \pi)\) fully defines an HMM. Given observations \(O = o_1, o_2, \ldots, o_T\), three classic problems are: Evaluation (Forward algorithm), Decoding (Viterbi), and Learning (Baum-Welch).

The Trellis Structure

To find the most likely hidden state sequence behind an observation sequence (say Walk, Shop, Clean), we unroll all states over all time steps into a trellis. Each node \((i, t)\) holds a score — the probability of being in state \(i\) at time \(t\) having seen \(o_1, \ldots, o_t\) via the most likely path. Arrows in the trellis carry \(a_{ij}\) weights; columns carry \(b_j(o_t)\) emission weights.

Common Misconception

Rows of A must sum to 1 (it is a stochastic matrix over next states), and rows of B must sum to 1 (a distribution over observations). If your matrices don't sum to 1 row-wise, the model is malformed.

Numerical Trace — Viterbi Step 1

Observation sequence: Walk, Shop, Clean. Let \(\delta_t(i)\) = max probability of state sequence ending in state \(i\) at time \(t\).

$$\delta_1(S) = \pi_S \cdot b_S(\text{Walk}) = 0.6 \times 0.6 = 0.36$$
$$\delta_1(R) = \pi_R \cdot b_R(\text{Walk}) = 0.4 \times 0.1 = 0.04$$

At \(t=2\), observation = Shop:

$$\delta_2(S) = \max(0.36 \times 0.7,\; 0.04 \times 0.4) \times 0.3 = \max(0.252, 0.016) \times 0.3 = 0.0756$$
$$\delta_2(R) = \max(0.36 \times 0.3,\; 0.04 \times 0.6) \times 0.4 = \max(0.108, 0.024) \times 0.4 = 0.0432$$

At \(t=3\), observation = Clean:

$$\delta_3(S) = \max(0.0756 \times 0.7,\; 0.0432 \times 0.4) \times 0.1 = \max(0.05292, 0.01728) \times 0.1 = 0.005292$$
$$\delta_3(R) = \max(0.0756 \times 0.3,\; 0.0432 \times 0.6) \times 0.5 = \max(0.02268, 0.02592) \times 0.5 = 0.01296$$

Best final state: \(R\) with 0.01296. Backtrace: Sunny → Sunny → Rainy.

3
The Mathematics
▾

Formal Definitions

An HMM \(\lambda = (A, B, \pi)\) with \(N\) hidden states and \(M\) observation symbols:

$$A = \{a_{ij}\},\quad a_{ij} = P(q_{t+1}=s_j \mid q_t=s_i),\quad \sum_{j=1}^N a_{ij}=1$$
$$B = \{b_j(k)\},\quad b_j(k) = P(o_t=v_k \mid q_t=s_j),\quad \sum_{k=1}^M b_j(k)=1$$
$$\pi = \{\pi_i\},\quad \pi_i = P(q_1=s_i),\quad \sum_{i=1}^N \pi_i=1$$

Joint Probability of a State-Observation Sequence

For hidden path \(Q = q_1, q_2, \ldots, q_T\) and observations \(O = o_1, \ldots, o_T\):

$$P(O, Q \mid \lambda) = \pi_{q_1} \prod_{t=1}^{T-1} a_{q_t q_{t+1}} \prod_{t=1}^{T} b_{q_t}(o_t)$$

Forward Algorithm (Evaluation)

Define forward variable \(\alpha_t(i) = P(o_1, \ldots, o_t, q_t = s_i \mid \lambda)\):

$$\alpha_1(i) = \pi_i \cdot b_i(o_1)$$
$$\alpha_{t+1}(j) = \left[\sum_{i=1}^N \alpha_t(i)\, a_{ij}\right] b_j(o_{t+1})$$
$$P(O \mid \lambda) = \sum_{i=1}^N \alpha_T(i)$$

Viterbi Algorithm (Decoding)

$$\delta_1(i) = \pi_i \cdot b_i(o_1)$$
$$\delta_t(j) = \max_{1 \le i \le N}\left[\delta_{t-1}(i)\, a_{ij}\right] b_j(o_t)$$
$$Q^* = \arg\max_{Q} P(Q, O \mid \lambda)$$
Complexity

Forward/Viterbi: \(\mathcal{O}(N^2 T)\) time, \(\mathcal{O}(NT)\) space. Naïve enumeration of all paths is \(\mathcal{O}(N^T)\) — exponential — which the trellis dynamic programming eliminates.

From-Scratch Implementation
▾

NumPy HMM with Viterbi Decoder

import numpy as np

# Model parameters (Weather HMM)
pi = np.array([0.6, 0.4])          # initial: [Sunny, Rainy]

A = np.array([[0.7, 0.3],          # transition matrix
              [0.4, 0.6]])         # A[i,j] = P(j | i)

B = np.array([[0.6, 0.3, 0.1],    # emission matrix
              [0.1, 0.4, 0.5]])    # B[i,k] = P(obs_k | state_i)
# States: 0=Sunny, 1=Rainy  |  Obs: 0=Walk, 1=Shop, 2=Clean

obs = np.array([0, 1, 2])         # Walk, Shop, Clean

# ── Viterbi Algorithm ─────────────────────────────────────────
T = len(obs)
N = len(pi)
delta = np.zeros((T, N))          # delta[t, i] = max path prob
psi   = np.zeros((T, N), dtype=int) # backpointer

# Initialisation
delta[0] = pi * B[:, obs[0]]      # pi_i * b_i(o_1)

# Recursion
for t in range(1, T):
    for j in range(N):
        # best previous state times transition times emission
        scores = delta[t-1] * A[:, j] * B[j, obs[t]]
        psi[t, j]   = np.argmax(scores)
        delta[t, j] = np.max(scores)

# Traceback
q_star = np.zeros(T, dtype=int)
q_star[-1] = np.argmax(delta[-1])
for t in range(T-2, -1, -1):
    q_star[t] = psi[t+1, q_star[t+1]]

state_names = ['Sunny', 'Rainy']
print("Best path:", [state_names[s] for s in q_star])
# → ['Sunny', 'Sunny', 'Rainy']
print("delta:\n", np.round(delta, 6))
# t=0: [0.36,    0.04   ]
# t=1: [0.0756,  0.0432 ]
# t=2: [0.005292,0.01296]

Production Usage: hmmlearn

from hmmlearn import hmm
import numpy as np

model = hmm.CategoricalHMM(n_components=2, n_features=3)
model.startprob_ = np.array([0.6, 0.4])
model.transmat_  = np.array([[0.7, 0.3],[0.4, 0.6]])
model.emissionprob_ = np.array([[0.6,0.3,0.1],[0.1,0.4,0.5]])

obs_seq = np.array([[0],[1],[2]])   # Walk, Shop, Clean (column vector)
log_prob, states = model.decode(obs_seq, algorithm="viterbi")
print("Log-probability:", log_prob)   # ln(0.01296) ≈ -4.344
print("State sequence:", states)      # [0, 0, 1]  → Sunny, Sunny, Rainy
Gotcha

hmmlearn's decode() expects a 2D array of shape (T, n_features). For discrete observations pass a column vector. Use log-scale internally to avoid underflow for long sequences — the raw product of many small probabilities vanishes to floating-point zero.

6
Key Takeaways
▾
  • Three matrices \(\lambda = (A, B, \pi)\) fully define a discrete HMM.
  • Transition matrix \(A\): row-stochastic, captures state-to-state dynamics.
  • Emission matrix \(B\): row-stochastic, maps each hidden state to observation probabilities.
  • Trellis DP reduces Viterbi from \(\mathcal{O}(N^T)\) exhaustive search to \(\mathcal{O}(N^2 T)\).
  • Use Forward for likelihood evaluation, Viterbi for decoding, Baum-Welch (EM) for learning \(\lambda\).
  • HMMs underlie classical speech recognition, CpG island detection in genomics, POS tagging in NLP, and financial regime detection.
When to Use HMMs

Sequential data with discrete observations and a small, interpretable hidden state space. When you need probabilistic state-path explanations, not just predictions. For continuous observations, switch to Gaussian HMMs; for long-range dependencies, use CRFs or deep sequence models.
