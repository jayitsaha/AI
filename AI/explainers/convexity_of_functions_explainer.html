Convexity of Functions

Definition, first-order & second-order conditions — and why every local min is global
Intermediate Math & Stats Calculus & Analysis Convex Analysis
1
Understanding Convexity
▼

What is it? A function is convex if its graph "cups upward" — like a bowl. More precisely, if you pick any two points on the graph and draw a straight line (chord) between them, the chord lies above the graph everywhere between those points. This single geometric property has enormous consequences for optimization: it guarantees that any locally optimal solution is globally optimal.

Analogy: Imagine you're a hiker in a valley shaped like a bowl (convex terrain). No matter where you stand, the floor is the lowest point — there are no hidden deeper pockets. Any downhill step leads toward the global minimum. Now imagine hilly terrain with multiple valleys (non-convex): you can get stuck in a local dip that's not the deepest. Convexity is the mathematical guarantee that you're in a bowl, not a mountain range.

💡 If you remember one thing

A function \(f\) is convex iff for all \(x, y\) and \(\lambda \in [0,1]\): $$f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)$$ This says the chord lies above (or on) the graph. Three equivalent conditions: (1) the definition above, (2) the gradient underestimates the function (first-order), (3) the Hessian is positive semidefinite (second-order).

Why ML cares: Most loss functions in classical ML are convex (logistic regression loss, SVM hinge loss, L2 regression). Gradient descent is guaranteed to find the global minimum. Deep learning losses are generally non-convex, which is why training is harder and results are not guaranteed to be optimal.

2
Three Equivalent Conditions
▼

Condition 1 — Definition (Chord Test)

A function \(f: \mathbb{R}^n \to \mathbb{R}\) is convex if its domain \(\text{dom}(f)\) is a convex set and for all \(x, y \in \text{dom}(f)\) and all \(\lambda \in [0, 1]\):

$$f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)$$

The left side is the function value at the convex combination (a point between \(x\) and \(y\)). The right side is the corresponding point on the chord from \((x, f(x))\) to \((y, f(y))\). Convexity says: the function is at or below the chord everywhere in between.

Condition 2 — First-Order Condition (Tangent Underestimates)

If \(f\) is differentiable, then \(f\) is convex if and only if for all \(x, y \in \text{dom}(f)\):

$$f(y) \geq f(x) + \nabla f(x)^\top (y - x)$$

The right-hand side is the first-order Taylor approximation of \(f\) at \(x\) — the tangent hyperplane. This condition says: for a convex function, the tangent at any point lies below (or touches) the function everywhere. The tangent is a global underestimate.

🔑 Key Property — Global Underestimator

For a differentiable convex function, the tangent at any point \(x\) is a global lower bound on \(f\). This is why gradient descent works: moving in the direction \(-\nabla f(x)\) always leads to a lower value (until we reach the global minimum where \(\nabla f = 0\)).

Condition 3 — Second-Order Condition (Hessian PSD)

If \(f\) is twice differentiable, then \(f\) is convex if and only if its Hessian matrix is positive semidefinite (PSD) everywhere:

$$\nabla^2 f(x) \succeq 0 \quad \forall x \in \text{dom}(f)$$

In 1D, this simplifies to \(f''(x) \geq 0\) — the function curves upward (or is flat). In multiple dimensions, PSD means all eigenvalues of the Hessian are \(\geq 0\), which means the function curves upward (or is flat) in every direction.

Strict Convexity

Replace \(\leq\) with \(<\) (strict inequality, \(\lambda \in (0,1)\), \(x \neq y\)) to get strict convexity. Equivalently: \(\nabla^2 f(x) \succ 0\) (positive definite Hessian). Strictly convex functions have at most one global minimizer — a unique optimal solution.

📐 Numerical Example

Take \(f(x) = x^2\). Check all three conditions:
Def: \(f(\lambda x + (1-\lambda)y) = (\lambda x + (1-\lambda)y)^2 \leq \lambda x^2 + (1-\lambda)y^2 = \lambda f(x) + (1-\lambda)f(y)\). (This is the weighted power-mean inequality — it holds.) ✓
1st: \(f(y) = y^2 \geq x^2 + 2x(y-x) = 2xy - x^2\). Rearranging: \((y-x)^2 \geq 0\). ✓
2nd: \(f''(x) = 2 \geq 0\). ✓

3
Why Convexity ⇒ Every Local Min is Global
▼

Proof: Local Minimizer is Global (by contradiction)

Let \(f\) be convex. Suppose \(x^*\) is a local minimizer but NOT a global minimizer. Then there exists a point \(z\) with \(f(z) < f(x^*)\). Since \(x^*\) is a local minimizer, there is a ball \(\mathcal{B}(x^*, r)\) where \(f(x^*) \leq f(x)\) for all \(x\) in the ball.

For any \(\lambda \in (0, 1)\), consider \(x_\lambda = \lambda z + (1-\lambda) x^*\). For small enough \(\lambda\), \(x_\lambda \in \mathcal{B}(x^*, r)\), so \(f(x_\lambda) \geq f(x^*)\). But by convexity:

$$f(x_\lambda) = f(\lambda z + (1-\lambda)x^*) \leq \lambda f(z) + (1-\lambda)f(x^*) < \lambda f(x^*) + (1-\lambda)f(x^*) = f(x^*)$$

This gives \(f(x_\lambda) < f(x^*)\), contradicting \(f(x_\lambda) \geq f(x^*)\). Therefore no such \(z\) exists, and \(x^*\) must be a global minimizer. QED.

Jensen's Inequality (Generalization)

The definition of convexity is the \(n=2\) case of Jensen's inequality. For \(n\) points \(x_1, \ldots, x_n\) with weights \(\lambda_i \geq 0\), \(\sum \lambda_i = 1\):

$$f\!\left(\sum_{i=1}^n \lambda_i x_i\right) \leq \sum_{i=1}^n \lambda_i f(x_i)$$

In probabilistic form: for a random variable \(X\) and convex \(f\):

$$f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$$

This single inequality underlies the EM algorithm (the ELBO lower bound), variational inference, information-theoretic inequalities, and the AM-GM inequality.

Optimality Conditions

For a differentiable convex function: \(x^*\) is a global minimizer if and only if \(\nabla f(x^*) = 0\). For a non-differentiable convex function: \(x^*\) is a global minimizer iff \(0 \in \partial f(x^*)\) (subgradient condition).

⚠️ Common Pitfall

Convexity in the function does NOT require a convex domain of inputs (though we do require the domain to be a convex set, i.e., closed under convex combinations). Also: \(f\) convex does NOT mean \(f\) is differentiable — the absolute value \(|x|\) is convex but not differentiable at \(x=0\). The second-order condition only applies when \(f\) is twice differentiable.

Code — Checking Convexity
▼

From Scratch — Numerical Verification

import numpy as np
def check_convexity_definition(f, x_vals, n_tests=500, tol=1e-9):
"""Numerically verify the definition: f(λx+(1-λ)y) ≤ λf(x)+(1-λ)f(y)."""
rng = np.random.default_rng(42)
violations = 0
for _ in range(n_tests):
x, y = rng.choice(x_vals, 2) # Pick two points
lam = rng.uniform(0, 1) # Random λ ∈ [0,1]
lhs = f(lam * x + (1 - lam) * y) # f at midpoint
rhs = lam * f(x) + (1 - lam) * f(y) # chord value
if lhs > rhs + tol: # violation?
violations += 1
return violations == 0
def check_convexity_hessian(f_double_prime, x_vals):
"""Second-order condition: f''(x) ≥ 0 everywhere (1D)."""
return np.all(f_double_prime(x_vals) >= -1e-9)
def is_hessian_psd(H):
"""Check if Hessian matrix H is positive semidefinite."""
eigenvalues = np.linalg.eigvalsh(H) # eigvalsh for symmetric
return np.all(eigenvalues >= -1e-9) # all λ ≥ 0
# --- Test on f(x) = x^2 (convex) ---
x_vals = np.linspace(-3, 3, 200)
f = lambda x: x**2
f2 = lambda x: np.full_like(x, 2.0) # f''(x) = 2
print(check_convexity_definition(f, x_vals)) # True
print(check_convexity_hessian(f2, x_vals)) # True
# --- Test on g(x) = sin(x) (non-convex) ---
g = np.sin
g2 = lambda x: -np.sin(x) # g''(x) = -sin(x), changes sign
print(check_convexity_definition(g, x_vals)) # False
print(check_convexity_hessian(g2, x_vals)) # False
# --- Multivariate: f(x,y) = x^2 + y^2 ---
# Hessian is [[2, 0], [0, 2]] — eigenvalues = [2, 2] > 0 → strictly convex
H = np.array([[2., 0.], [0., 2.]])
print(is_hessian_psd(H)) # True

Production Usage — Convex Optimization with CVXPY

import cvxpy as cp
import numpy as np
# Convex problem: minimize x^2 + y^2 subject to x + y >= 1
x = cp.Variable() # declare variables
y = cp.Variable()
objective = cp.Minimize(x**2 + y**2) # convex objective
constraints = [x + y >= 1] # convex constraint
prob = cp.Problem(objective, constraints)
result = prob.solve() # guaranteed global optimum
print(f"x={x.value:.4f}, y={y.value:.4f}") # x=0.5, y=0.5
# ⚠️ Gotcha: CVXPY enforces DCP rules (Disciplined Convex Programming)
# If you write a non-convex expression, it raises an error at problem creation
# (not at solve time). This is a feature — it catches bugs early.
# Logistic regression loss is convex (used in sklearn LogisticRegression)
from sklearn.linear_model import LogisticRegression
# The solver (lbfgs, liblinear, etc.) is guaranteed to find global optimum
# because the cross-entropy loss is convex in the parameters w.
⚠️ Gotcha — Neural Networks Break Convexity

As soon as you compose a convex loss (cross-entropy) with a non-linear neural network, the overall loss as a function of the network weights is non-convex. Gradient descent can get stuck in local minima, saddle points, or take exponentially long. This is why deep learning training is not guaranteed to converge to the global optimum.

Key Takeaways & Interview Prep
▼

When to use / when matters

  • Logistic regression, SVMs, ridge/lasso regression — all have convex losses: gradient descent is guaranteed to converge to global optimum.
  • Checking convexity is step 1 in any optimization problem analysis.
  • Jensen's inequality appears in ELBO derivations (VAE, EM algorithm), KL divergence bounds, and information theory.

Top Interview Questions

Q1 (Easy): Is \(f(x) = x^2\) convex? Verify two ways.
A: Yes. (1) \(f''(x) = 2 > 0\) everywhere. (2) The chord test: \((\lambda x + (1-\lambda)y)^2 \leq \lambda x^2 + (1-\lambda)y^2\) follows from \((x-y)^2 \geq 0\).

Q2 (Medium): Why does gradient descent converge to the global minimum for logistic regression?
A: The cross-entropy loss is a convex function of the weights \(w\). For convex functions, every local minimum is a global minimum (proved above). Gradient descent on a smooth convex function converges to the global minimum (rate \(O(1/k)\) without strong convexity, linear rate with).

Q3 (Hard): What is Jensen's inequality and where does it appear in ML?
A: For convex \(f\): \(f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]\). In the EM algorithm, the Evidence Lower Bound (ELBO) is derived using Jensen's: \(\log p(x) = \log \mathbb{E}_{z \sim q}[p(x,z)/q(z)] \geq \mathbb{E}_{z \sim q}[\log(p(x,z)/q(z))]\) (applying Jensen with concave \(\log\)). KL divergence is non-negative by the same argument.

Q4 (Hard): How do you check if a multivariate function is convex?
A: Compute the Hessian \(\nabla^2 f(x)\) and check that all its eigenvalues are \(\geq 0\) (PSD) at every point. Alternatively, verify that the function is a composition of convex-preserving operations (CVXPY's DCP ruleset formalizes this).
