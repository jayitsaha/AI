From text or single images to full 3D models via score distillation and view-conditioned diffusion

1
Understanding 3D Generation
▼

What is it? 3D generation is the art and science of creating three-dimensional digital models from simpler inputs like text descriptions or single 2D images. This capability is rapidly transforming fields from gaming and virtual reality to product design and scientific visualization, democratizing 3D content creation.

Why is it hard? Unlike 2D image generation, 3D involves inferring depth, multiple views, and occluded geometry from inherently ambiguous inputs. A single image or text prompt doesn't fully constrain a 3D shape; the generator must "imagine" what the object looks like from other angles, ensuring consistency and plausible structure. This requires sophisticated techniques to bridge the gap between 2D priors and 3D reality.

Analogy: Imagine being given a vague written description of a sculpture, or just one photograph of it. To create a full 3D replica, you'd have to interpret the description, infer hidden details, and imagine how it looks from all sides. If you only have a single photo, you'd need to guess its depth and what's behind it. Modern 3D generative models are doing this at scale, using powerful 2D image models as their "imagination."

💡 If you remember one thing

DreamFusion (text-to-3D) leverages a pre-trained 2D text-to-image diffusion model as a "prior" to guide the optimization of a 3D Neural Radiance Field (NeRF). Zero123 (image-to-3D) trains a 2D diffusion model specifically to generate novel, consistent views of an object from a single input image, enabling 3D reconstruction from these generated views.

2
How DreamFusion & Zero123 Work
▼

DreamFusion: Text-to-3D via Score Distillation Sampling (SDS)

DreamFusion (Poole et al., 2022) aims to synthesize a 3D object (represented as a Neural Radiance Field, or NeRF) directly from a text prompt. It doesn't train a 3D generative model from scratch. Instead, it uses a powerful, pre-trained 2D text-to-image diffusion model (like Google's Imagen) as a "teacher" to guide the optimization of a NeRF.

  1. Initialize NeRF: A 3D Neural Radiance Field is initialized with random parameters. A NeRF is a neural network that, given a 3D coordinate \((x,y,z)\) and a viewing direction \((d_x,d_y,d_z)\), outputs a color and a density value.
  2. Iterative Optimization: For many steps, the following occurs:
    1. Sample Camera Pose: A random camera position and orientation are chosen around the object.
    2. Render 2D Image: The current NeRF is used with volume rendering to produce a 2D image (and optionally a depth map) from the sampled camera pose.
    3. Score Distillation: This rendered 2D image is fed into the pre-trained 2D diffusion model, along with the original text prompt. The diffusion model computes a "score" or gradient, indicating how to modify the 2D image to make it more consistent with the text prompt.
    4. Backpropagate to 3D: Crucially, this 2D gradient is then backpropagated through the volume rendering process to update the parameters of the 3D NeRF. This nudges the 3D object to render more realistic images from that view, guided by the 2D diffusion prior.
  3. Convergence: After thousands of such steps, the NeRF converges to a 3D representation that consistently matches the text prompt across all viewing angles.

Zero123: Image-to-3D via View-Conditioned Diffusion

Zero123 (Liu et al., 2023) tackles the problem of generating novel views of an object from a single input image. This is a critical step for 3D reconstruction from limited input. Instead of an optimization loop, Zero123 directly synthesizes new views.

  1. View-Conditioned Diffusion Model: Zero123 trains a 2D diffusion model on a massive dataset of objects with multiple views (e.g., Objaverse). During training, it learns to generate a target view, conditioned on an input (source) image and the relative camera pose between the source and target views.
  2. Inference: Given a single input 2D image of an object:
    1. Specify Target Pose: A user specifies a desired camera pose relative to the input image (e.g., "rotate 90 degrees left").
    2. Generate Novel View: The Zero123 model takes the input image and the target camera pose as conditions and directly generates a 2D image of the object from that new perspective.
  3. 3D Reconstruction: By generating multiple such consistent novel views from various angles, these images can then be fed into traditional multi-view 3D reconstruction techniques (like NeRF or photogrammetry software) to create a full 3D model.
🔑 Key Difference

DreamFusion uses a 2D diffusion model for guidance in an iterative 3D optimization loop (slow but high quality). Zero123 uses a 2D diffusion model for direct synthesis of new views from a single image (faster per view, enables downstream 3D reconstruction).

3
Why It Works — The Math Behind the Magic
▼

Score Distillation Sampling (SDS) — The DreamFusion Engine

DreamFusion's core innovation is Score Distillation Sampling (SDS), which allows a 2D diffusion model to guide the optimization of a 3D representation. The goal is to optimize the parameters \(\theta\) of a 3D scene representation (like a NeRF) such that images rendered from it, \(x = g(\theta)\), are likely under a text-to-image diffusion model \(p(x|c)\) for a given text prompt \(c\).

The SDS loss function is designed to push the rendered images towards the modes of the diffusion model's distribution. It's defined as:

$$L_{SDS}(\theta) = \mathbb{E}_{t, \epsilon \sim \mathcal{N}(0, I)} \left[ w(t) \left\| \hat{\epsilon}(x_t, t; c) - \epsilon \right\|^2 \right]$

Here, \(x_t\) is a noisy version of the rendered image \(x\), \(\hat{\epsilon}(x_t, t; c)\) is the noise predicted by the 2D diffusion model (conditioned on time \(t\) and text \(c\)), \(\epsilon\) is the actual noise added, and \(w(t)\) is a weighting function. The crucial part is the gradient with respect to the 3D parameters \(\theta\):

$$\nabla_\theta L_{SDS}(\theta) = \mathbb{E}_{t, \epsilon} \left[ w(t) \left( \hat{\epsilon}(x_t, t; c) - \epsilon \right) \frac{\partial x}{\partial \theta} \right]$$

This gradient guides the 3D representation. Effectively, it says: "Adjust the 3D model such that if you render it from a random view, the rendered image, when fed into the 2D diffusion model, produces a noise prediction that aligns with the noise that would be removed to make it more like the text prompt." This is a powerful way to leverage a 2D prior for 3D synthesis. A more simplified form often seen is:

$$\nabla_\theta L_{SDS}(\theta) \propto \mathbb{E}_{t} \left[ w(t) (\hat{\epsilon}(x_t, t; c) - \epsilon) \nabla_\theta g(\theta) \right]$

Where \(\nabla_\theta g(\theta)\) is the gradient of the volume rendering process itself. This iterative process, guided by the 2D diffusion model's "score," allows the NeRF to gradually sculpt itself into the desired 3D object.

Zero123: Learning 3D Consistency in 2D Latent Space

Zero123, on the other hand, is a direct generative model. It's a conditional diffusion model trained to generate a target view \(x_{tgt}\) given a source view \(x_{src}\) and a relative camera pose \(\Delta P\) (which encodes relative rotation and translation). The standard diffusion loss is adapted to this view-conditioned setup:

$$L_{Zero123} = \mathbb{E}_{t, \epsilon, x_{tgt}, x_{src}, \Delta P} \left[ \left\| \epsilon - \hat{\epsilon}(x_t, t, x_{src}, \Delta P) \right\|^2 \right]$

Here, \(x_t\) is a noisy version of \(x_{tgt}\), and the noise prediction network \(\hat{\epsilon}\) is conditioned on both the source image \(x_{src}\) and the relative camera pose \(\Delta P\). The model is trained on large datasets of multi-view images (e.g., Objaverse), where each object provides many pairs of \((x_{src}, x_{tgt}, \Delta P)\). By optimizing this loss, the diffusion model learns the underlying 3D structure and how objects appear from different viewpoints. This allows it to synthesize novel, consistent views directly, without an explicit 3D representation during generation.

⚠️ Computational Cost

DreamFusion's iterative optimization, involving rendering and backpropagating through a diffusion model thousands of times, is computationally very expensive and slow (hours per object). Zero123 generates views in a single forward pass per view, making it much faster for view synthesis, though reconstruction to a full 3D model still requires additional steps.

Key Takeaways
▼

When to use DreamFusion:

  • When generating a 3D asset from a text description is the primary goal.
  • When high fidelity and multi-view consistency are paramount, and computational cost is less of a concern.
  • Leveraging the rich semantic understanding of large 2D text-to-image diffusion models.

When to use Zero123 (or similar view-conditioned models):

  • When starting with a single 2D image and needing to generate novel views for 3D reconstruction.
  • For faster generation of individual views, enabling more interactive workflows.
  • As a component in a larger 3D reconstruction pipeline, where multi-view images are required.

Limitations & Future Directions:

  • DreamFusion: Computationally expensive (hours per object). Can suffer from the "Janus problem" (inconsistent views, like an object having multiple faces) if not carefully regularized.
  • Zero123: Quality of generated views depends heavily on the diversity and quality of the multi-view training data. May struggle with complex occlusions or objects outside its training distribution.
  • Future: Hybrid approaches combining the strengths of both (e.g., Zero123 for initial multi-view generation, then DreamFusion-like SDS fine-tuning). Faster 3D representations and optimization techniques are active research areas.
💡 Big Picture

These methods represent a paradigm shift in 3D content creation, moving from manual modeling to generative AI. They highlight the power of leveraging strong 2D priors (diffusion models) to tackle the complex, ill-posed problem of 3D synthesis, paving the way for ubiquitous 3D digital assets.

import torch
import torch.nn as nn
import numpy as np
from diffusers import DiffusionPipeline # Pre-trained 2D diffusion
from nerf_model import NeRF # A simple NeRF implementation
from zero123_model import Zero123Pipeline # Pre-trained Zero123
# --- DreamFusion (Text-to-3D) ---
def dreamfusion_train(text_prompt, num_steps=5000):
nerf = NeRF().cuda() # Initialize 3D representation
optimizer = torch.optim.Adam(nerf.parameters(), lr=1e-3)
diffusion_model = DiffusionPipeline.from_pretrained("imagen-like").to("cuda")
for step in range(num_steps):
optimizer.zero_grad()
camera_pose = sample_random_camera_pose() # (R, T) matrix
rendered_image = nerf.render(camera_pose) # Render 2D from 3D NeRF
sds_loss = diffusion_model.get_sds_loss(rendered_image, text_prompt)
sds_loss.backward() # Backprop through rendering & NeRF
optimizer.step()
return nerf
# --- Zero123 (Image-to-3D View Synthesis) ---
def zero123_generate_views(input_image, num_views=4):
zero123_model = Zero123Pipeline.from_pretrained("zero123-xl").to("cuda")
generated_views = []
for i in range(num_views):
target_pose = get_relative_camera_pose(i) # e.g., 0, 90, 180, 270 deg
# Model generates target view conditioned on input_image and target_pose
view = zero123_model(input_image, target_pose)
generated_views.append(view)
return generated_views
