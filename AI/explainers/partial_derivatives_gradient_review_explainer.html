Partial Derivatives & Gradient

Section 0.2 — Calculus & Optimization Review  ·  Part I: Math & Stats Foundations
Foundational Calculus Optimization Must Know
1
Understanding the Concept
›

What is a partial derivative? Imagine you're hiking on a mountain. At any point you could ask: "How steep is the slope if I walk exactly east?" or "How steep if I walk exactly north?" A partial derivative answers precisely that — the rate of change of a function in one direction while all other directions are frozen solid.

For a function \(f(x, y)\), the partial derivative \(\frac{\partial f}{\partial x}\) measures how fast \(f\) changes as \(x\) varies, treating \(y\) as a constant. Notationally, \(\partial\) (curly-d) signals "partial" — a derivative with respect to one variable only.

What is the gradient? Collect all partial derivatives into a single vector and you get the gradient. It points in the direction of steepest ascent on the function's surface — the direction you'd run if you wanted to climb as fast as possible from where you're standing.

Key Insight

The gradient \(\nabla f\) packs all slope information into one vector: its direction tells you where the function rises fastest, and its magnitude tells you how steeply.

One-Sentence Definition

A partial derivative is the slope in one coordinate direction (all others fixed); the gradient is the vector of all partial derivatives — the compass needle pointing uphill.

2
How It Works — From Partials to Gradient
›

Computing a partial derivative is exactly like ordinary differentiation — treat every other variable as a numeric constant and differentiate normally.

Example: \(f(x,y) = x^2 + xy + y^2\)

$$\frac{\partial f}{\partial x} = 2x + y \qquad\qquad \frac{\partial f}{\partial y} = x + 2y$$

At the point \((1, 2)\):   \(\frac{\partial f}{\partial x}\big|_{(1,2)} = 4\),   \(\frac{\partial f}{\partial y}\big|_{(1,2)} = 5\).

The gradient vector assembles these into a column vector (or row, depending on convention):

$$\nabla f(x,y) = \begin{bmatrix} \dfrac{\partial f}{\partial x} \\[6pt] \dfrac{\partial f}{\partial y} \end{bmatrix} = \begin{bmatrix} 2x + y \\ x + 2y \end{bmatrix}$$

At \((1, 2)\): \(\nabla f = [4,\, 5]^\top\), with magnitude \(\|\nabla f\| = \sqrt{16+25} \approx 6.40\).

Gradient and level sets are perpendicular. A level set \(\{(x,y): f(x,y) = c\}\) is a contour curve. Moving along it keeps \(f\) constant. The gradient, which maximises the rate of change, must therefore be orthogonal to this "flat" direction. This is the geometric heart of gradient descent.

Formal Definition

For \(f : \mathbb{R}^n \to \mathbb{R}\), the gradient at \(\mathbf{x}\) is $$\nabla f(\mathbf{x}) = \left[\frac{\partial f}{\partial x_1},\;\frac{\partial f}{\partial x_2},\;\ldots,\;\frac{\partial f}{\partial x_n}\right]^\top \in \mathbb{R}^n$$ The directional derivative in direction \(\mathbf{u}\) (unit vector) equals \(\nabla f(\mathbf{x}) \cdot \mathbf{u}\), maximised when \(\mathbf{u} \propto \nabla f\).

Common Pitfall

The gradient points uphill. Gradient descent subtracts it: \(\mathbf{x} \leftarrow \mathbf{x} - \alpha \nabla f(\mathbf{x})\). New learners sometimes add instead of subtract, climbing the loss surface by mistake.

3
The Math — Chain Rule, Jacobian, Gradient Descent
›

Multivariable chain rule. If \(g(t) = f(x(t), y(t))\), then:

$$\frac{dg}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} = \nabla f \cdot \dot{\mathbf{x}}$$

This is the engine of backpropagation: gradients flow backward through composed functions via exactly this dot-product rule.

The Jacobian. When \(f : \mathbb{R}^n \to \mathbb{R}^m\) (vector-valued), each output component has its own gradient. Stacking them gives the Jacobian matrix \(J \in \mathbb{R}^{m \times n}\):

$$J_{ij} = \frac{\partial f_i}{\partial x_j}$$

The gradient is the special case \(m=1\): the Jacobian collapses to a row vector \(\nabla f^\top\).

Gradient descent update. Starting from \(\mathbf{x}_0\), iterate:

$$\mathbf{x}_{t+1} = \mathbf{x}_t - \alpha \,\nabla f(\mathbf{x}_t)$$

Why does this decrease \(f\)? By Taylor expansion to first order: \(f(\mathbf{x}_t - \alpha \nabla f) \approx f(\mathbf{x}_t) - \alpha \|\nabla f\|^2 < f(\mathbf{x}_t)\) for small \(\alpha > 0\).

Numerically traced example. \(f(x,y) = x^2 + xy + y^2\) from \((1,1)\) with \(\alpha=0.1\):

  • \(\nabla f(1,1) = [2(1)+1,\; 1+2(1)] = [3, 3]\)
  • New point: \((1-0.3,\; 1-0.3) = (0.7, 0.7)\)
  • \(f(1,1) = 3\),   \(f(0.7, 0.7) = 0.49 + 0.49 + 0.49 = 1.47\)   ✓ decreased
Why Gradient ⊥ Level Set

Along a level set \(f(\mathbf{x}(t)) = c\), differentiating gives \(\nabla f \cdot \dot{\mathbf{x}} = 0\). The gradient is orthogonal to every tangent of the level curve — it has no "sideways" component, only a "steepest uphill" one.

Key Takeaways & ML Connections
›
  • Partial derivative = ordinary derivative holding all other variables constant. Notation: \(\partial f / \partial x_i\).
  • Gradient = vector of all partials; points in direction of steepest ascent; perpendicular to level sets.
  • Gradient descent subtracts a scaled gradient to minimise a loss function — the core of all deep learning training.
  • Backpropagation is just the multivariable chain rule applied layer-by-layer to compute gradients of a scalar loss w.r.t. millions of parameters.
  • Jacobian generalises gradient to vector-valued functions; arises in layers with vector outputs (linear layers, softmax).
Interview One-Liner

"A partial derivative is the slope in one coordinate direction; the gradient packages all of them into a vector that points uphill, enabling gradient descent to train neural networks."
