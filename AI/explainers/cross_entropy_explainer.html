Understanding Cross-Entropy
▼

What is it? Cross-entropy measures how different two probability distributions are — specifically, how many extra "bits" you'd need if you encoded data using the wrong distribution \(q\) instead of the true distribution \(p\). In machine learning, \(p\) is the true label distribution (often one-hot), and \(q\) is the model's predicted probability distribution. Minimizing cross-entropy means making the model's predictions match the true labels.

Analogy: Imagine you're designing a Morse-code-like system to transmit weather reports. If you know the actual frequencies of each weather type (sunny 70%, cloudy 20%, rainy 10%), you can design short codes for common events and long codes for rare ones — that's Shannon entropy \(H(p)\). But if you design the codes assuming frequencies from another city (distribution \(q\)), you'll use inefficient codes and waste bits — that extra waste is the KL divergence \(D_{KL}(p \| q)\). The total bits you actually use is cross-entropy \(H(p,q) = H(p) + D_{KL}(p \| q)\).

💡 If you remember one thing

For one-hot labels, cross-entropy \(H(p,q) = -\log q_{y}\) — just the negative log probability assigned to the correct class. Minimizing cross-entropy is identical to minimizing the KL divergence from the true label distribution, which is identical to maximum likelihood estimation.

The Decomposition: H(p,q) = H(p) + D_KL(p‖q)
▼

Three Quantities, One Identity

Cross-entropy decomposes cleanly into two information-theoretic quantities:

$$H(p,q) = -\sum_i p_i \log q_i = \underbrace{-\sum_i p_i \log p_i}_{H(p) \text{ (Shannon entropy)}} + \underbrace{\sum_i p_i \log \frac{p_i}{q_i}}_{D_{KL}(p \| q) \text{ (KL divergence)}}$$

Shannon Entropy H(p): The Baseline

\(H(p)\) measures the irreducible uncertainty in the true distribution — the minimum average bits needed regardless of encoding scheme. For a one-hot true label \(p\) (exactly one class is correct), \(H(p) = 0\) because there is zero uncertainty: we always know the correct answer.

KL Divergence D_KL(p‖q): The Gap

\(D_{KL}(p \| q) \geq 0\) always (Gibbs' inequality), with equality iff \(p = q\). It measures the extra inefficiency from using \(q\) instead of \(p\). It is asymmetric: \(D_{KL}(p \| q) \neq D_{KL}(q \| p)\) in general.

Why This Means Minimizing Cross-Entropy = Minimizing KL

Since \(H(p)\) does not depend on the model parameters \(\theta\), we have:

$$\underset{\theta}{\arg\min}\; H(p, q_\theta) = \underset{\theta}{\arg\min}\; D_{KL}(p \| q_\theta)$$

The ground-truth entropy \(H(p)\) is a constant offset. Training with cross-entropy loss is exactly minimizing KL divergence from the true label distribution — pulling the model distribution toward the data distribution.

🔑 Key Property

For one-hot labels (class \(y\)), cross-entropy collapses to negative log-likelihood: \(H(p,q) = -\log q_y\). All non-true-class terms vanish because \(p_i = 0\) for \(i \neq y\). The entire loss is just how much probability the model assigned to the correct class.

3
The Math — Derivation and Gradient
▼

Cross-Entropy Definition

Let \(p\) and \(q\) be probability distributions over \(K\) classes. Cross-entropy is:

$$H(p,q) = -\sum_{k=1}^{K} p_k \log q_k$$

Note: \(\log\) here means natural log (nats) or log base 2 (bits) — in ML, natural log is standard. All gradients below use natural log.

Proof of Decomposition

$$H(p,q) = -\sum_k p_k \log q_k = -\sum_k p_k \log p_k + \sum_k p_k \log \frac{p_k}{q_k} = H(p) + D_{KL}(p \| q)$$

The algebra: add and subtract \(\sum_k p_k \log p_k\). Rearranging yields the identity. Since \(D_{KL}(p\|q) \geq 0\) (Jensen's inequality applied to convex \(-\log\)), we get \(H(p,q) \geq H(p)\) always.

Gradient with Respect to Logits (One-Hot Case)

For classification: \(q_k = \text{softmax}(z)_k = e^{z_k}/\sum_j e^{z_j}\). For one-hot label at class \(y\), the loss is \(\mathcal{L} = -\log q_y\). The gradient with respect to logit \(z_k\) is remarkably clean:

$$\frac{\partial \mathcal{L}}{\partial z_k} = q_k - \mathbb{1}[k = y]$$

This is \(q_k - p_k\) — the difference between predicted and true probability for each class. Derivation: \(\partial(-\log q_y)/\partial z_k = -(1/q_y)\cdot\partial q_y/\partial z_k = -(1/q_y)\cdot q_y(\delta_{ky} - q_k) = q_k - \delta_{ky}\). The gradient is exactly "model prediction minus target."

Connection to Maximum Likelihood

For a dataset \(\{(x_i, y_i)\}_{i=1}^N\), the negative log-likelihood under the model \(q_\theta\) is:

$$-\frac{1}{N}\sum_{i=1}^N \log q_\theta(y_i \mid x_i) = \frac{1}{N}\sum_{i=1}^N H(p_i, q_\theta(x_i)) = \mathbb{E}_{x \sim p_{\text{data}}}[H(p(\cdot|x), q_\theta(\cdot|x))]$$

Minimizing average cross-entropy is identical to maximum likelihood estimation of \(\theta\).

⚠️ Common Misconceptions

1. "Cross-entropy is symmetric." FALSE — \(H(p,q) \neq H(q,p)\) in general. The true distribution always goes in the first slot.

2. "KL divergence is a distance." FALSE — it's not symmetric, so it's not a metric. It's a divergence.

3. "We minimize KL divergence directly." FALSE — we minimize cross-entropy, which equals KL divergence + a constant \(H(p)\). The optimization is equivalent.

Key Takeaways & When to Use
▼

When Cross-Entropy is the Right Loss

  • Classification: Any multi-class problem with softmax output — the standard choice
  • Language modeling: Next-token prediction; average CE loss over tokens
  • Probabilistic outputs: Anywhere you want the model to produce calibrated probabilities
  • Knowledge distillation: Replace one-hot labels with soft teacher distribution — cross-entropy still applies, but \(H(p) \neq 0\)

When NOT to Use

  • Regression: Use MSE, MAE — continuous outputs, not probabilities
  • Severe class imbalance: Vanilla CE can be dominated by majority class — use focal loss or weighted CE
  • Ordinal labels: If classes have order (1-star to 5-stars), ordinal regression losses may be better

💡 The Big Picture

Cross-entropy unifies three perspectives: (1) information-theoretic — minimum bits to encode under wrong distribution; (2) probabilistic — maximum likelihood estimation; (3) geometric — KL divergence from true distribution. All three lead to exactly the same optimization.

Code Trace — From Scratch & PyTorch
▼
import numpy as np
import torch, torch.nn as nn
# ── From Scratch ──────────────────────────────────────
def softmax(logits):
z = logits - logits.max() # numerical stability
e = np.exp(z)
return e / e.sum()
def cross_entropy(p, q):
"""H(p,q) = -sum_k p_k * log(q_k)"""
return -np.sum(p * np.log(q + 1e-15))
logits = np.array([2.0, 1.0, 0.5, -1.0])
q = softmax(logits) # [0.6095, 0.2242, 0.1360, 0.0303]
p = np.array([0., 1., 0., 0.]) # true class = 1 (one-hot)
loss = cross_entropy(p, q) # = -log(0.2242) = 1.4952
assert abs(loss - (-np.log(q[1]))) < 1e-10 # one-hot => single term
# Gradient: dL/dz_k = q_k - p_k
grad = q - p # [0.6095, -0.7758, 0.1360, 0.0303]
# Decomposition: H(p,q) = H(p) + KL(p||q)
Hp = -np.sum(p * np.log(p + 1e-15)) # = 0 (one-hot)
KL = np.sum(p * np.log((p+1e-15)/(q+1e-15))) # = 1.4952
assert abs(Hp + KL - loss) < 1e-10 # identity holds
# ── PyTorch (production) ──────────────────────────────
logits_t = torch.tensor([2.0, 1.0, 0.5, -1.0])
target = torch.tensor(1) # class index (not one-hot)
loss_fn = nn.CrossEntropyLoss() # fused softmax + CE
loss_t = loss_fn(logits_t.unsqueeze(0), target.unsqueeze(0))
# loss_t ≈ 1.4952 (matches manual computation)
# ⚠️ GOTCHA: nn.CrossEntropyLoss takes RAW LOGITS, NOT softmax probs!
# Passing softmax(logits) to CrossEntropyLoss applies softmax TWICE — wrong!
