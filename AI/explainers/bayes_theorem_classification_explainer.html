How prior belief × observed evidence → posterior probability → optimal class decision

1
Understanding Bayes Classification
▾

Imagine you receive an email with the word "buy" in the subject line. Is it spam? To decide, you need two pieces of information: how common is spam in general? (the prior) and how often does spam contain "buy"? (the likelihood). Multiply them together, normalize, and you get the probability the email is spam given what you observed — the posterior.

Bayes' theorem formalises this: \(P(y \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid y)\, P(y)}{P(\mathbf{x})}\). In classification we pick the class \(\hat{y}\) that maximises the posterior — the Maximum A Posteriori (MAP) decision: \(\hat{y} = \underset{y}{\operatorname{argmax}}\; P(\mathbf{x} \mid y)\, P(y)\).

Key Insight

The denominator \(P(\mathbf{x})\) is the same for every class, so MAP classification never needs to compute it — just compare numerators \(P(\mathbf{x} \mid y)\, P(y)\) across classes and pick the largest.

The Three Components

  • Prior \(P(y)\): Our belief about class frequency before seeing any data. If 40 % of emails are spam, \(P(\text{spam}) = 0.4\).
  • Likelihood \(P(\mathbf{x} \mid y)\): How probable is this observation given the class? For a spam email: how often does spam contain "buy"?
  • Posterior \(P(y \mid \mathbf{x})\): Updated belief after observing \(\mathbf{x}\). This is what we classify on.
Core Formula
$$P(y \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid y)\; P(y)}{P(\mathbf{x})}$$

Posterior \(\propto\) Likelihood \(\times\) Prior. The evidence \(P(\mathbf{x})\) is a normalising constant.

2
From Bayes to Naive Bayes Classifier
▾

With \(d\) features the exact likelihood \(P(\mathbf{x} \mid y)\) requires a joint distribution over all \(d\) dimensions — exponentially expensive to estimate. The Naive Bayes classifier escapes this by assuming conditional independence of features given the class label:

$$P(\mathbf{x} \mid y) = \prod_{j=1}^{d} P(x_j \mid y)$$

This converts a single intractable \(d\)-dimensional density into \(d\) independent 1-D densities — each cheap to estimate from data. The "naive" label acknowledges this independence is rarely true in reality, yet the classifier remains surprisingly effective in practice.

The Full MAP Decision Rule

$$\hat{y} = \underset{y \in \mathcal{Y}}{\operatorname{argmax}}\; P(y) \prod_{j=1}^{d} P(x_j \mid y)$$

In practice we work in log-space to avoid underflow:

$$\hat{y} = \underset{y}{\operatorname{argmax}}\; \left[\log P(y) + \sum_{j=1}^{d} \log P(x_j \mid y)\right]$$

Historical Context

Thomas Bayes first described his theorem posthumously in 1763 (published by Richard Price). The rule found its way into text classification in the 1960s via work by Maron & Kuhns on information retrieval. By the 1990s, Paul Graham's spam filters popularised Naive Bayes for email, demonstrating that independence assumptions need not prevent excellent real-world accuracy.

Naivety Trap

When features are strongly correlated, the model double-counts evidence. Use Gaussian NB with caution on highly correlated feature sets; consider LDA or logistic regression instead.

Decision Boundary: Where Posteriors Are Equal

The Bayes-optimal boundary between two classes lies where their posteriors are equal:

$$P(C_0 \mid \mathbf{x}) = P(C_1 \mid \mathbf{x}) \;\Longleftrightarrow\; P(\mathbf{x} \mid C_0)\,P(C_0) = P(\mathbf{x} \mid C_1)\,P(C_1)$$

For Gaussian class-conditionals with equal variances this boundary is a linear hyperplane — equivalent to Linear Discriminant Analysis. With unequal variances the boundary becomes quadratic (QDA).

3
The Math — Complete Derivation
▾

Step 1 — Bayes' Theorem from joint probability

Start from the definition of conditional probability applied to \(y\) and \(\mathbf{x}\):

$$P(y, \mathbf{x}) = P(y \mid \mathbf{x})\,P(\mathbf{x}) = P(\mathbf{x} \mid y)\,P(y)$$

Rearranging for the posterior:

$$P(y \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid y)\,P(y)}{P(\mathbf{x})}$$

Step 2 — Evidence via law of total probability

$$P(\mathbf{x}) = \sum_{k=1}^{K} P(\mathbf{x} \mid y=k)\,P(y=k)$$

This ensures posteriors sum to 1 across all \(K\) classes. Since the denominator is class-independent, MAP ignores it:

$$\hat{y}_{\text{MAP}} = \underset{y}{\operatorname{argmax}}\; P(\mathbf{x} \mid y)\,P(y)$$

Step 3 — Gaussian class-conditional

For a single continuous feature \(x \in \mathbb{R}\) with class \(y=k\):

$$P(x \mid y=k) = \frac{1}{\sigma_k\sqrt{2\pi}}\exp\!\left(-\frac{(x-\mu_k)^2}{2\sigma_k^2}\right)$$

For the multivariate case \(\mathbf{x} \in \mathbb{R}^d\) (full covariance):

$$P(\mathbf{x} \mid y=k) = \frac{1}{(2\pi)^{d/2}|\Sigma_k|^{1/2}}\exp\!\left(-\tfrac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_k)^\top\Sigma_k^{-1}(\mathbf{x}-\boldsymbol{\mu}_k)\right)$$

Step 4 — Log-posterior score

Taking the log (monotone, preserves argmax):

$$\log P(y=k \mid \mathbf{x}) \propto -\tfrac{1}{2}\log|\Sigma_k| - \tfrac{1}{2}(\mathbf{x}-\boldsymbol{\mu}_k)^\top\Sigma_k^{-1}(\mathbf{x}-\boldsymbol{\mu}_k) + \log P(y=k)$$

Step 5 — Decision boundary derivation

Boundary: \(\log P(C_0 \mid \mathbf{x}) = \log P(C_1 \mid \mathbf{x})\). With equal priors and equal \(\Sigma\), this simplifies to:

$$(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^\top \Sigma^{-1} \mathbf{x} = \tfrac{1}{2}(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^\top \Sigma^{-1}(\boldsymbol{\mu}_0 + \boldsymbol{\mu}_1)$$

This is a linear equation in \(\mathbf{x}\) — exactly the LDA discriminant. Unequal \(\Sigma_k\) gives the quadratic discriminant (QDA).

Laplace Smoothing

If a word never appears in training spam, \(P(x \mid \text{spam})=0\) zeros out the entire product. Add pseudocount \(\alpha\):

$$P(x_j = v \mid y=k) = \frac{\text{count}(x_j=v, y=k) + \alpha}{\text{count}(y=k) + \alpha \cdot |V|}$$
Common Misconception

Naive Bayes is a generative model — it models \(P(\mathbf{x},y)\). Despite its simplicity, it is NOT discriminative (it doesn't directly model the boundary). This distinction matters: discriminative models like logistic regression often have lower asymptotic error, while NB converges faster with less data.

From-Scratch Naive Bayes (NumPy)

import numpy as np
class GaussianNaiveBayes:
def fit(self, X, y):
self.classes_ = np.unique(y)
self.priors_ = {} # P(y=k)
self.means_ = {} # mu_{jk}
self.vars_ = {} # sigma^2_{jk}
for k in self.classes_:
Xk = X[y == k]
self.priors_[k] = len(Xk) / len(X) # MLE prior
self.means_[k] = Xk.mean(axis=0) # per-feature mean
self.vars_[k] = Xk.var(axis=0) + 1e-9 # variance + smoothing
def _log_likelihood(self, x, k):
# log N(x; mu_k, sigma^2_k) summed across features
mu, var = self.means_[k], self.vars_[k]
return -0.5 * np.sum(np.log(2*np.pi*var) + (x-mu)**2/var)
def predict(self, X):
preds = []
for x in X:
# log P(y=k) + sum_j log P(x_j | y=k)
scores = {k: np.log(self.priors_[k]) + self._log_likelihood(x,k)
for k in self.classes_}
preds.append(max(scores, key=scores.get)) # argmax = MAP
return np.array(preds)

Key Takeaways

  • MAP = argmax of unnormalised posterior — never compute \(P(\mathbf{x})\) for classification.
  • Log-space arithmetic prevents numerical underflow when multiplying many small likelihoods.
  • Equal-variance Gaussian NB = LDA; unequal variance = QDA; each has a linear/quadratic decision boundary.
  • Laplace smoothing (\(\alpha=1\)) is mandatory for categorical/text features to avoid zero-probability collapse.
  • Calibration matters — NB posteriors are often over-confident; use CalibratedClassifierCV if you need reliable probabilities.
When to Use Naive Bayes
  • High-dimensional sparse features (text, NLP) — features are weakly correlated
  • Small training data — converges faster than discriminative models
  • Real-time prediction — training and inference are \(O(nd)\)
  • Multiclass out-of-the-box — posteriors naturally extend to \(K\) classes
