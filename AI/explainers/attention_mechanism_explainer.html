Bahdanau Attention (Additive Attention)

Learning soft alignment between source and target so the decoder isn't stuck with one fixed-size vector
Intermediate NLP / Seq2Seq Attention O(n·m) alignment
1
Understanding Additive Attention
▼

What is it? When translating a sentence, a plain encoder-decoder RNN squeezes the entire source sentence into one fixed-size vector before the decoder even starts generating. Bahdanau attention (Bahdanau, Cho & Bengio, 2014) lets the decoder instead look back at every encoder hidden state at every generation step, and learns — via a tiny neural network — how much to "look at" each one.

Analogy: Imagine translating a paragraph by only reading it once, closing the book, and writing the translation from memory — that's a vanilla seq2seq bottleneck. Additive attention is like keeping the book open and re-scanning it (with a learned sense of where to look) before writing each new word.

💡 If you remember one thing

At every decoding step \(t\), the decoder computes a compatibility score between its current state and each encoder hidden state, turns those scores into a probability distribution (the alignment weights \(\alpha_{tj}\)) via softmax, and takes their weighted sum as a fresh context vector \(c_t\) — a different, dynamically-built summary for every output word.

2
How It Works Internally
▼

The bottleneck it fixes

A vanilla encoder-decoder runs a BiRNN over the source to produce hidden states \(h_1,\dots,h_n\), keeps only the final state as a "sentence vector," and forces the decoder to reconstruct the whole meaning from it. For long sentences this fixed-size vector becomes a lossy bottleneck — BLEU scores degrade sharply past ~20 tokens.

The additive-attention fix, step by step

  • Encode: a (typically bidirectional) RNN reads the source and keeps all hidden states \(h_1,\dots,h_n\), not just the last one.
  • Score: before emitting target word \(t\), compare the decoder's previous state \(s_{t-1}\) against every \(h_j\) using a small feed-forward network: \(e_{tj} = v^\top \tanh(W_s s_{t-1} + W_h h_j)\). This is called additive (or "concat") attention because the two projected vectors are added before the nonlinearity — as opposed to Luong's multiplicative attention, which takes a dot product.
  • Align: normalize the raw scores across all source positions with softmax: \(\alpha_{tj} = \dfrac{\exp(e_{tj})}{\sum_{k=1}^n \exp(e_{tk})}\). This gives a probability distribution over source positions — the "alignment."
  • Contextualize: build the context vector as the alignment-weighted sum of encoder states: \(c_t = \sum_{j=1}^n \alpha_{tj} h_j\).
  • Decode: feed \(c_t\) (concatenated with the previous output embedding) into the decoder RNN to produce \(s_t\) and the next word.

Design decision: why learn \(W_s, W_h, v\) instead of a fixed similarity?

A fixed metric (like cosine similarity) assumes source and target hidden spaces are already comparable. They're not — they come from different RNNs trained for different roles. The small MLP \((W_s, W_h, v)\) is trained jointly with the rest of the network via backprop, so it learns whatever notion of "relevance" actually helps translation, including reordering (e.g. adjective-noun order flips between French and English).

🔑 Key property

Attention weights are soft and differentiable — every source position contributes something (never a hard 0/1 selection), so gradients flow to all encoder states at every decoding step. This is what actually solves the vanishing-gradient / bottleneck problem, not just the visualization.

3
Why It Works — The Math
▼

Let the encoder produce hidden states \(h_1,\dots,h_n \in \mathbb{R}^d\) and let the decoder's previous hidden state be \(s_{t-1}\in\mathbb{R}^{d'}\). Bahdanau's alignment model is a one-hidden-layer MLP scoring compatibility:

$$e_{tj} = v^\top \tanh\big(W_s s_{t-1} + W_h h_j\big), \qquad j = 1,\dots,n$$

Here \(W_s \in \mathbb{R}^{a\times d'}\), \(W_h \in \mathbb{R}^{a \times d}\) project both states into a shared attention space of dimension \(a\); adding them lets the tanh nonlinearity mix decoder and encoder information before collapsing to a scalar via \(v\in\mathbb{R}^a\).

Scores are turned into a valid probability distribution with softmax:

$$\alpha_{tj} = \frac{\exp(e_{tj})}{\displaystyle\sum_{k=1}^{n}\exp(e_{tk})} \;\;\Rightarrow\;\; \sum_{j=1}^n \alpha_{tj} = 1,\ \ \alpha_{tj} \ge 0$$

and the context vector is the convex combination:

$$c_t = \sum_{j=1}^{n} \alpha_{tj}\, h_j$$

Gradient flow: because \(c_t\) is a differentiable, weighted average, \(\partial \mathcal{L}/\partial h_j\) receives a direct term \(\alpha_{tj}\cdot \partial\mathcal{L}/\partial c_t\) at every decoding step \(t\) — a short path from any output-word loss back to any source-word encoding, regardless of distance. This is exactly what a single fixed context vector could not offer: in the bottleneck architecture, gradient information to early source words has to survive backprop through the entire decoder chain first.

Convergence intuition: \(W_s, W_h, v\) are trained end-to-end with the translation cross-entropy loss — there's no separate alignment supervision. Empirically the learned \(\alpha\) matrix tends to concentrate mass near the true word alignment because that correlates with lower reconstruction loss, but nothing forces it to be sparse or monotonic (see the "the" step in the walkthrough, where two identical source tokens split attention evenly).

⚠️ Common misconception

"Attention weights are interpretable word alignments, like in statistical MT." Not exactly — they're a learned soft relevance signal optimized purely for translation quality. They often correlate with human alignments but are not trained to match them, and can look diffuse or counter-intuitive, especially early in training or for function words.

5
Key Takeaways
▼
  • Additive attention replaces one fixed-size sentence vector with a per-output-step context vector built from all encoder states.
  • Score → softmax → weighted-sum is the reusable three-step recipe behind every later attention variant, including self-attention in Transformers.
  • Bahdanau's scoring function \(v^\top\tanh(W_s s + W_h h)\) is "additive/concat" attention; it's more expressive but slower than Luong's dot-product ("multiplicative") attention, since it needs an extra MLP per score.
  • Use additive attention when hidden dimensions differ between encoder/decoder or query/key dimensionalities don't match cleanly (it doesn't require them to be equal, unlike a plain dot product).
  • This idea directly seeded self-attention and the Transformer's scaled dot-product attention (Vaswani et al., 2017), which scales far better than RNN-based attention.

When to reach for the additive form today: rarely as a production choice (Transformers dominate), but it remains the clearest teaching example of the score → softmax → weighted-sum pattern, and still appears in small RNN-based seq2seq systems, pointer networks, and some low-resource / low-latency models where a full Transformer is overkill.

🎯 Decision rule

Query/key spaces same dimension, need raw speed → Luong dot-product. Different dimensions, more expressive but slower is fine → Bahdanau additive. Need full parallelism and can afford O(n²) → self-attention / Transformer.
