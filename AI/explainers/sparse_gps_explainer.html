Understanding Sparse Gaussian Processes
▼

What is it? Gaussian Processes (GPs) are powerful non-parametric models for regression and classification, providing not just predictions but also uncertainty estimates. The catch: full GPs scale poorly, requiring \(O(N^3)\) computation and \(O(N^2)\) memory for \(N\) data points. Sparse GPs address this by approximating the full GP using a much smaller set of \(M\) "inducing points" (\(M \ll N\)), reducing complexity to \(O(NM^2)\) or \(O(M^3)\).

Analogy: Imagine you're trying to map a huge, complex terrain by taking elevation measurements. A full GP is like measuring every square meter — incredibly precise but impossible for a large area. A sparse GP is like strategically placing a few "survey markers" (inducing points) and using their measurements to infer the terrain everywhere else. If you choose your markers well, you get a good map without the exhaustive effort.

💡 If you remember one thing

Sparse GPs approximate the full GP by introducing a small set of \(M\) "inducing points" (or "pseudo-inputs") \(Z\). These points act as a bottleneck, summarizing the information from the \(N\) training points. The goal is to choose \(Z\) (and the corresponding latent function values \(u = f(Z)\)) such that they capture the essential structure of the data, allowing for faster inference and learning.

How Sparse GPs Work Internally
▼

The Need for Approximation

A standard GP performs inference by inverting the \(N \times N\) covariance matrix of the observed data. This \(O(N^3)\) operation becomes prohibitive for \(N > 10,000\). Sparse GPs sidestep this direct inversion by introducing an auxiliary set of \(M\) inducing points \(Z = \{z_1, \dots, z_M\}\) and their corresponding latent function values \(u = f(Z)\). These inducing points are typically *not* actual data points, but rather locations in the input space chosen to best represent the underlying function.

The Core Idea: Conditional Independence

The key to sparse GP approximations lies in assuming that the observed data \(y\) and the true latent function values \(f(X)\) are conditionally independent given the latent function values at the inducing points, \(u=f(Z)\). Mathematically, this means \(p(y | f(X), u) \approx p(y | u)\). This assumption allows us to factorize the joint distribution and reduce the dimensionality of the critical matrix inversions from \(N \times N\) to \(M \times M\).

Two Main Approaches: FITC and SVGP

There are several ways to implement this sparse approximation:

  • Fully Independent Training Conditional (FITC): This method explicitly factorizes the likelihood, assuming that the data points are independent given the inducing points. It's often seen as a direct approximation of the full GP posterior, where the covariance matrix is approximated as \(K_{NN} \approx Q_{NN} + \Lambda\), where \(Q_{NN} = K_{NZ}K_{ZZ}^{-1}K_{ZN}\) and \(\Lambda\) is a diagonal matrix of residual variances.
  • Stochastic Variational Gaussian Process (SVGP): This is a more flexible and robust approach based on variational inference. Instead of directly approximating the covariance, SVGP defines a variational distribution \(q(f)\) that approximates the true posterior \(p(f|X,y)\). This \(q(f)\) is constructed by first defining a variational posterior over the inducing points \(q(u)\), and then using \(p(f|u)\) to extend it to the entire function space: \(q(f) = \int p(f|u)q(u)du\). The inducing point locations \(Z\) and the parameters of \(q(u)\) are then optimized to minimize the KL divergence between \(q(f)\) and \(p(f|X,y)\).
🔑 Key Property

Inducing points \(Z\) are not fixed training data; they are a set of auxiliary variables (hyperparameters) whose locations can be optimized during training. Their optimal placement often reflects areas of high data density, high uncertainty, or rapid function change, where more "information" is needed to accurately model the GP.

3
Why It Works — The Mathematical Basis
▼

Full GP Prediction

For a full GP, the posterior predictive distribution at a test point \(x^*\) is Gaussian:

$$p(f^*|X,y,x^*) = \mathcal{N}(\mu(x^*), \Sigma(x^*))$$

where \(\mu(x^*) = k(x^*,X)K_{XX}^{-1}y\) and \(\Sigma(x^*) = k(x^*,x^*) - k(x^*,X)K_{XX}^{-1}k(X,x^*)\). The bottleneck is the \(K_{XX}^{-1}\) term, which is \(O(N^3)\) to compute.

FITC Approximation

FITC approximates \(K_{XX}\) using inducing points \(Z\). Let \(u = f(Z)\) be the latent function values at \(Z\). The key idea is to approximate \(p(y|f)\) with \(p(y|u)\), effectively assuming that given \(u\), the data points \(y\) are conditionally independent of each other. This leads to an approximate covariance matrix \(\tilde{K}_{XX}\) given by:

$$\tilde{K}_{XX} = K_{XZ}K_{ZZ}^{-1}K_{ZX} + \text{diag}(K_{XX} - K_{XZ}K_{ZZ}^{-1}K_{ZX})$$

The term \(K_{XZ}K_{ZZ}^{-1}K_{ZX}\) (often denoted \(Q_{XX}\)) captures the covariance between training points mediated through the inducing points. The diagonal term adds back the "local" variance that is lost by assuming conditional independence. With this approximation, the inverse \( \tilde{K}_{XX}^{-1} \) can be computed in \(O(NM^2)\) time, and prediction in \(O(M^2)\).

SVGP: Variational Approach

SVGP takes a different route, aiming to minimize the KL divergence between an approximate posterior \(q(f)\) and the true posterior \(p(f|X,y)\). The variational posterior \(q(f)\) is constructed as \(q(f) = \int p(f|u)q(u)du\), where \(q(u)\) is a simple Gaussian (e.g., \(q(u) = \mathcal{N}(m, S)\)). The objective function, a lower bound on the marginal likelihood (ELBO), is:

$$\mathcal{L} = \sum_{i=1}^N \mathbb{E}_{q(f_i)}[\log p(y_i|f_i)] - \text{KL}[q(u)||p(u)]$$

This ELBO is maximized with respect to the inducing point locations \(Z\), and the variational parameters \((m, S)\) of \(q(u)\). The expectation \(\mathbb{E}_{q(f_i)}[\log p(y_i|f_i)]\) involves \(q(f_i)\), which is derived from \(q(u)\) and \(p(f_i|u)\). This allows for mini-batch optimization, making SVGP highly scalable, typically \(O(M^3)\) for optimization and \(O(M^2)\) for prediction, plus \(O(B M^2)\) for mini-batch likelihood terms (where \(B\) is batch size).

⚠️ Common Pitfall

The quality of sparse GP approximations heavily depends on the choice and optimization of inducing points. Poorly placed inducing points can lead to underfitting or inaccurate uncertainty estimates. For FITC, the diagonal approximation can sometimes lead to overly confident predictions in regions far from inducing points. SVGP, by optimizing \(Z\) and \(q(u)\), generally offers a more robust approximation.

Key Takeaways
▼

When to use Sparse GPs:

  • Large datasets (N > 10,000): When full GP inference is computationally prohibitive.
  • Real-time prediction: Sparse GPs offer faster inference at test time (O(M²) or O(NM) vs O(N²)).
  • Memory constraints: Reduced memory footprint (O(M²) vs O(N²)) for storing covariance matrices.
  • Mini-batch training: SVGP allows for stochastic optimization, making it compatible with deep learning pipelines.

When NOT to use:

  • Small datasets (N < 1,000): The overhead of setting up and optimizing inducing points might outweigh the benefits.
  • If exactness is critical: Sparse approximations inherently trade off some accuracy for speed. If high precision is required everywhere, a full GP is preferred if tractable.
  • Non-stationary data: If the data characteristics change drastically across the input space, a fixed set of inducing points might struggle to capture all nuances.
💡 FITC vs SVGP

FITC is a direct approximation of the covariance matrix, often simpler to implement and faster to train for a fixed set of inducing points. However, its conditional independence assumption can be restrictive. SVGP is a variational method that optimizes both the inducing point locations and a variational posterior, offering greater flexibility and often better performance, especially with large datasets and mini-batching.

import torch
import gpytorch
class SparseGPModel(gpytorch.models.ExactGP):
def __init__(self, train_x, train_y, likelihood, num_inducing_points):
super().__init__(train_x, train_y, likelihood)
self.mean_module = gpytorch.means.ConstantMean()
self.covar_module = gpytorch.kernels.ScaleKernel(gpytorch.kernels.RBFKernel())
# Initialize inducing points (e.g., from subset of data or uniform grid)
inducing_points = train_x[:num_inducing_points, :]
self.variational_strategy = \
gpytorch.variational.VariationalStrategy(
self, inducing_points, gpytorch.variational.CholeskyVariationalDistribution(),
learn_inducing_points=True, quadrature_size=10 # SVGP-like optimization
)
def forward(self, x):
mean_x = self.mean_module(x)
covar_x = self.covar_module(x)
return gpytorch.distributions.MultivariateNormal(mean_x, covar_x)
# Example Usage (assuming train_x, train_y are defined)
likelihood = gpytorch.likelihoods.GaussianLikelihood()
model = SparseGPModel(train_x, train_y, likelihood, num_inducing_points=10)
# Training loop (SVGP optimization)
model.train()
likelihood.train()
optimizer = torch.optim.Adam(model.parameters(), lr=0.1)
mll = gpytorch.mlls.ExactMarginalLogLikelihood(likelihood, model)
for i in range(training_iterations):
optimizer.zero_grad()
output = model(train_x)
loss = -mll(output, train_y) # Maximize ELBO (minimize negative ELBO)
loss.backward()
optimizer.step()
# Prediction
model.eval()
likelihood.eval()
with torch.no_grad(), gpytorch.settings.fast_pred_var():
test_x = torch.linspace(0, 10, 100)
observed_pred = likelihood(model(test_x))
mean = observed_pred.mean
lower, upper = observed_pred.confidence_region()
