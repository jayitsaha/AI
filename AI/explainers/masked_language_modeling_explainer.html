Masked Language Modeling (MLM)

Teaching a model to fill in the blanks — 15% token masking, BERT-style
Foundational NLP / Transformers Self-Supervised Pretraining Objective
1
Understanding Masked Language Modeling
▼

What is it? MLM is the pretraining trick behind BERT: take a sentence, hide ~15% of its tokens, and train a model to guess the hidden words using everything else in the sentence — both left and right context. Because the model can peek in both directions (unlike GPT, which only reads left-to-right), it learns much richer contextual representations of words.

Analogy: Imagine a fill-in-the-blank worksheet: "The cat ___ on the mat." You don't need to be told the answer is "sat" — the surrounding words give it away. MLM turns every sentence in a giant text corpus into millions of these worksheets, and the model gets better and better at using context clues, for free, with no human labels required.

💡 If you remember one thing

MLM randomly masks 15% of input tokens and trains the model to predict the original token at each masked position from bidirectional context: $$\mathcal{L}_{MLM} = -\sum_{i \in \mathcal{M}} \log P(x_i \mid x_{\setminus \mathcal{M}})$$ where \(\mathcal{M}\) is the set of masked positions.

2
How MLM Works Internally
▼

The 15% Masking Recipe (BERT, Devlin et al. 2018)

For every token in a training sequence, an independent coin flip selects it for masking with probability \(p = 0.15\). Once a token is selected, it is not always replaced with a literal [MASK] token — that would create a train/inference mismatch, since [MASK] never appears in real downstream text. Instead, each selected token is routed into one of three buckets:

The 80/10/10 Split

Of the ~15% selected tokens: 80% become the literal [MASK] token, 10% are replaced with a random word from the vocabulary, and 10% are left completely unchanged (the original word, but still counted as a prediction target). In all three cases, the model must output the true original token at that position — it never gets told which bucket a position landed in.

Design Decision: Why not always use [MASK]?

If every masked position were literally [MASK], the encoder would learn to build strong representations only for the artificial [MASK] token, which never occurs at fine-tuning or inference time. By sometimes leaving the true word in place, or swapping in a random word, the model is forced to build good contextual representations for every input token — because it can never be sure which tokens are "trustworthy."

🔑 Key Property

MLM is a denoising autoencoding objective: corrupt the input, reconstruct the original. Because attention is bidirectional and unmasked, every masked position's prediction can draw on context from both sides of the sequence simultaneously — the defining advantage over left-to-right (causal) language modeling.

3
Why It Works — The Math
▼

The Objective

Let \(x = (x_1, \dots, x_n)\) be a token sequence and \(\mathcal{M} \subset \{1,\dots,n\}\) the randomly-chosen masked positions (\(|\mathcal{M}| \approx 0.15n\)). Let \(\tilde{x}\) be the corrupted sequence after applying the 80/10/10 rule. The encoder \(f_\theta\) produces a contextual representation \(h_i = f_\theta(\tilde{x})_i\) for every position, and a softmax classifier over the vocabulary \(V\) predicts the original token:

$$P(x_i = w \mid \tilde{x}) = \frac{\exp(h_i^\top e_w)}{\sum_{w' \in V} \exp(h_i^\top e_{w'})}$$

where \(e_w\) is the output embedding for vocabulary word \(w\). The training loss is the average cross-entropy over only the masked positions:

$$\mathcal{L}_{MLM}(\theta) = -\frac{1}{|\mathcal{M}|}\sum_{i \in \mathcal{M}} \log P(x_i \mid \tilde{x}; \theta)$$

Crucially, the loss is not computed on unmasked positions — gradients flow only from the ~15% of positions the model was asked to reconstruct. This makes each training step statistically efficient (many prediction targets per sequence) while keeping the model honest about needing genuine bidirectional context rather than copying the input.

Gradient Flow

Because self-attention is unmasked (every position attends to every other position, in both directions), \(\partial \mathcal{L}_{MLM} / \partial \theta\) receives contributions that route information from context tokens on both sides back into the shared encoder weights — this is exactly what produces bidirectional representations.

⚠️ Common Pitfall

MLM cannot be used directly for autoregressive text generation — predictions at different masked positions are made independently and conditioned on the corrupted input, not on each other. This is why encoder-only MLM models (BERT) excel at understanding tasks but are awkward for open-ended generation, unlike causal LMs (GPT).

Key Takeaways
▼

Why 15%, specifically?

  • Too low (e.g. 5%) → too few prediction targets per sequence, slow learning, and context is trivially easy to exploit
  • Too high (e.g. 40%+) → too little surviving context to infer the answer, degrading representation quality (later work like SpanBERT / RoBERTa tuned this further)
  • 15% (with the 80/10/10 sub-split) was found empirically by the BERT authors to balance training signal density against context sufficiency

When MLM shines: pretraining bidirectional encoders for classification, NER, extractive QA, sentence embeddings — any task needing deep understanding rather than generation.

When it doesn't fit: open-ended text generation (use causal/autoregressive LMs), or tasks requiring strict left-to-right decoding.

💡 Lineage

BERT (fixed 15%, 80/10/10) → RoBERTa (dynamic masking, no NSP) → SpanBERT (mask contiguous spans, not random tokens) → ELECTRA (replaced-token-detection instead of reconstruction — a more sample-efficient cousin of MLM).

import torch, random
# tokens: LongTensor of shape (seq_len,)
def mask_tokens(tokens, vocab_size, mask_id, p=0.15):
labels = tokens.clone()
prob_matrix = torch.full(tokens.shape, p)
selected = torch.bernoulli(prob_matrix).bool() # ~15% True
labels[~selected] = -100 # ignore in loss
# 80%: replace with [MASK]
mask_80 = torch.bernoulli(torch.full(tokens.shape, 0.8)).bool() & selected
tokens[mask_80] = mask_id
# 10%: replace with random token
rand_10 = torch.bernoulli(torch.full(tokens.shape, 0.5)).bool() & selected & ~mask_80
random_words = torch.randint(vocab_size, tokens.shape)
tokens[rand_10] = random_words[rand_10]
# remaining 10% of `selected`: left unchanged (still a target)
return tokens, labels
