Platt Scaling (Logistic Calibration)

Mapping raw model scores → calibrated probabilities via a two-parameter sigmoid
Intermediate Classical ML Calibration Important for interviews
1
Understanding the Concept
▾

Imagine you train an SVM to detect spam email. The SVM produces a decision score — a number like +3.7 (very spam) or −0.8 (probably not spam). But what does +3.7 mean in probability? The SVM doesn't tell you "90% chance this is spam." That's the calibration problem.

Platt scaling solves this by fitting a tiny logistic model on top of the SVM's raw scores. You collect validation examples with known labels, record their SVM scores, then find two numbers a and b such that:

$$p = \sigma(a \cdot f + b) = \frac{1}{1 + e^{-(a \cdot f + b)}}$$

where \(f\) is the raw score and \(p\) is the calibrated probability. The sigmoid squashes any real number into \((0,1)\), and \(a\) and \(b\) are learned by maximum likelihood on the validation set.

💡 If you remember one thing

Platt scaling fits \(p = \sigma(af+b)\) on a held-out validation set — not the training set — to convert raw scores into calibrated probabilities. The two parameters are found by minimizing log-loss.

Real-world analogy: Think of a doctor interpreting a blood-test value. The raw number (e.g., glucose = 145 mg/dL) means little alone. A calibration table converts it to "~70% probability of pre-diabetes." Platt scaling is that calibration table for ML models.

2
How It Works Internally
▾

Step-by-step procedure

1. Train the base model (e.g., SVM) on a training set. Never touch this set again for calibration.

2. Score the validation set. Run each validation example through the SVM to get decision function values \(f_1, f_2, \ldots, f_n\) and their true labels \(y_i \in \{0,1\}\).

3. Label smoothing (Platt's original trick). To avoid overconfidence, Platt suggested using soft labels:

$$\tilde{y}_+ = \frac{N_+ + 1}{N_+ + 2}, \quad \tilde{y}_- = \frac{1}{N_- + 2}$$

where \(N_+\) is the number of positive examples and \(N_-\) negative. This applies a Laplace smoothing that prevents the calibrated probabilities from hitting 0 or 1 exactly.

4. Optimize \(a\) and \(b\) by minimizing the negative log-likelihood (cross-entropy):

$$\mathcal{L}(a,b) = -\sum_{i=1}^n \left[\tilde{y}_i \log \sigma(a f_i + b) + (1-\tilde{y}_i)\log(1-\sigma(a f_i + b))\right]$$

This is convex in \((a,b)\), so standard L-BFGS or Newton's method converges reliably.

5. Deploy. At inference time, compute the SVM score \(f\), then output \(\hat{p} = \sigma(af+b)\).

⚠️ Critical: Use a separate validation set

If you calibrate on the training set, the SVM's scores are already overfit to those examples — scores cluster near ±∞ and calibration will be terrible. Always use a held-out set (or cross-validated scores).

🔑 Why a = negative is normal

For SVMs, the decision function is defined so that positive scores favor class +1. After fitting, you typically find \(a < 0\) — this inverts the sigmoid so that high positive scores map to high probabilities. The magnitude of \(a\) controls the steepness of the probability transition.

3
The Math — Why It Works
▾

Maximum Likelihood Estimation

The sigmoid \(\sigma(z) = 1/(1+e^{-z})\) is the canonical link function for Bernoulli likelihoods. Given labels \(y_i \in \{0,1\}\), the likelihood of parameters \((a,b)\) is:

$$\mathcal{L}(a,b) = \prod_{i=1}^n p_i^{y_i}(1-p_i)^{1-y_i}, \quad p_i = \sigma(af_i+b)$$

Taking the negative log and substituting the sigmoid identity \(1-\sigma(z)=\sigma(-z)\):

$$-\log\mathcal{L} = \sum_{i=1}^n \left[y_i \log(1+e^{-(af_i+b)}) + (1-y_i)\log(1+e^{af_i+b})\right]$$

The gradient with respect to \(a\) is:

$$\frac{\partial(-\log\mathcal{L})}{\partial a} = \sum_{i=1}^n f_i\bigl(\sigma(af_i+b) - y_i\bigr)$$

Setting both gradients to zero gives the MLE. The Hessian is positive semi-definite because \(\sigma'(z)=\sigma(z)(1-\sigma(z)) \ge 0\), so the loss is convex and the global optimum is unique (assuming the data is not perfectly linearly separable in score space).

Calibration guarantee

After fitting, if the model is well-specified (i.e., the true posterior is indeed a sigmoid of the score), then \(\hat{p}(f)\) satisfies:

$$\mathbb{E}[Y \mid f] \approx \sigma(af+b)$$

meaning that among all examples with score \(f\), the fraction that are truly positive matches the model's output probability. This is the calibration property.

📐 Key identity

The sigmoid satisfies \(\sigma(-z) = 1 - \sigma(z)\), which means that flipping the sign of \(z\) flips the probability about 0.5. This is why the sign of \(a\) determines whether high scores map to high or low probabilities.

Code — From Scratch & Production
▾

From Scratch (NumPy + SciPy)

import numpy as np
from scipy.optimize import minimize
def platt_scale(scores, labels):
"""Fit Platt scaling on (scores, labels) from a held-out val set."""
N_pos = np.sum(labels == 1)
N_neg = np.sum(labels == 0)
# Platt label smoothing — avoids p=0 or p=1
t = np.where(labels == 1,
(N_pos + 1) / (N_pos + 2), # positive target
1.0 / (N_neg + 2)) # negative target
def neg_log_likelihood(params):
a, b = params
z = a * scores + b
# Numerically stable: log(1+exp(-|z|)) + max(z,0)
log_p = -np.logaddexp(0, -z) # log sigmoid
log_1p = -np.logaddexp(0, z) # log(1-sigmoid)
return -np.sum(t * log_p + (1 - t) * log_1p)
res = minimize(neg_log_likelihood, x0=[0.0, 0.0], method='L-BFGS-B')
a_opt, b_opt = res.x
return a_opt, b_opt
def predict_proba(scores, a, b):
return 1.0 / (1.0 + np.exp(-(a * scores + b)))

Production (scikit-learn)

from sklearn.svm import SVC
from sklearn.calibration import CalibratedClassifierCV
from sklearn.model_selection import train_test_split
# Wrap SVC with Platt scaling ('sigmoid' method)
base = SVC(kernel='rbf', C=1.0) # no probability=True needed
calibrated = CalibratedClassifierCV(base, method='sigmoid', cv=5)
calibrated.fit(X_train, y_train)
probs = calibrated.predict_proba(X_test)[:, 1] # calibrated P(y=1|x)
# ⚠️ cv='prefit' lets you calibrate on a separate held-out set:
base.fit(X_train, y_train)
cal2 = CalibratedClassifierCV(base, method='sigmoid', cv='prefit')
cal2.fit(X_val, y_val) # only uses the validation set
⚠️ Gotcha: SVC(probability=True)

When you pass probability=True to sklearn's SVC directly, it uses 5-fold cross-validation internally and applies Platt scaling — but this slows training 5×. Use CalibratedClassifierCV explicitly for more control.

🎯 Decision rule

SVM / linear model + small val set → Platt scaling. Gradient boosting / random forest + large val set → Isotonic regression. Neural network → Temperature scaling (check calibration plot first).

Advantages of Platt scaling:

  • Only 2 parameters — no overfitting risk on small validation sets
  • Closed-form optimization (convex, unique minimum)
  • Works well when the underlying score distribution is roughly linear in log-odds
  • Computationally negligible at inference (one multiply + sigmoid)

Disadvantages:

  • Assumes the calibration mapping is a sigmoid — fails for non-monotone distortions
  • Does not fix ranking (AUROC) — only improves probability estimates
  • Isotonic regression outperforms it when enough data is available
