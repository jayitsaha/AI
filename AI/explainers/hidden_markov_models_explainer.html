Understanding Hidden Markov Models
▼

An HMM models a system where the real state is hidden — you can only see noisy observations emitted by those states. Think of a doctor who cannot directly observe whether you have a cold; she only sees symptoms (runny nose, fever) that the cold emits with some probability.

Formally, an HMM is a tuple \((\mathcal{S}, \mathcal{O}, \pi, A, B)\):

  • \(\mathcal{S}\) — finite set of hidden states \(\{s_1,\ldots,s_N\}\)
  • \(\mathcal{O}\) — finite observation alphabet \(\{o_1,\ldots,o_M\}\)
  • \(\pi\) — initial state distribution, \(\pi_i = P(q_1 = s_i)\)
  • \(A\) — transition matrix, \(a_{ij} = P(q_{t+1}=s_j \mid q_t=s_i)\)
  • \(B\) — emission matrix, \(b_j(k) = P(o_t=k \mid q_t=s_j)\)

Key Concept — The Markov Property

The hidden state \(q_t\) depends only on \(q_{t-1}\) (first-order Markov), and the observation \(o_t\) depends only on \(q_t\) (conditional independence of observations). These two assumptions make exact inference tractable.

The three canonical problems — Evaluation (what is \(P(\mathbf{o} \mid \lambda)\)?), Decoding (what is the best state sequence?), and Learning (how do we fit \(\lambda = (\pi, A, B)\)?) — are solved by the Forward-Backward, Viterbi, and Baum-Welch algorithms respectively.

Intuition

The trellis is an \(N \times T\) grid where each node \((i, t)\) holds a partial probability. The forward pass fills it left-to-right summing over incoming paths; the backward pass fills it right-to-left. Together they give the posterior over every state at every time step without enumerating all \(N^T\) paths.

2
The Three Core Algorithms
▼

Forward Algorithm — \(\alpha_t(i)\)

The forward variable \(\alpha_t(i) = P(o_1,\ldots,o_t,\, q_t=s_i \mid \lambda)\) is the joint probability of all observations up to time \(t\) and being in state \(i\) at time \(t\). The recurrence is:

$$\alpha_t(j) = \left[\sum_{i=1}^{N} \alpha_{t-1}(i)\, a_{ij}\right] b_j(o_t), \quad \alpha_1(i) = \pi_i\, b_i(o_1)$$

Complexity: \(O(N^2 T)\). The total likelihood is \(P(\mathbf{o}\mid\lambda) = \sum_i \alpha_T(i)\).

Backward Algorithm — \(\beta_t(i)\)

The backward variable \(\beta_t(i) = P(o_{t+1},\ldots,o_T \mid q_t=s_i,\lambda)\) is the conditional probability of all future observations given state \(i\) at \(t\):

$$\beta_t(i) = \sum_{j=1}^{N} a_{ij}\, b_j(o_{t+1})\, \beta_{t+1}(j), \quad \beta_T(i) = 1$$

Posterior (Smoothed) Marginals — \(\gamma_t(i)\)

Combining \(\alpha\) and \(\beta\) gives the posterior probability of being in state \(i\) at time \(t\) given all observations:

$$\gamma_t(i) = \frac{\alpha_t(i)\,\beta_t(i)}{\sum_j \alpha_t(j)\,\beta_t(j)} = P(q_t=s_i \mid \mathbf{o},\lambda)$$

Viterbi — Most Probable State Sequence

Viterbi replaces the sum in the forward recurrence with a max, tracking backpointers \(\psi\):

$$\delta_t(j) = \max_{i}\bigl[\delta_{t-1}(i)\,a_{ij}\bigr]\,b_j(o_t), \quad \psi_t(j) = \arg\max_{i}\bigl[\delta_{t-1}(i)\,a_{ij}\bigr]$$

The optimal path is recovered by tracing back \(\psi\) from \(\arg\max_i \delta_T(i)\).

Baum-Welch (EM for HMMs)

We want to find \(\lambda^* = \arg\max_\lambda P(\mathbf{o}\mid\lambda)\). EM alternates: E-step computes expectations using the current \(\lambda\); M-step re-estimates parameters in closed form. The pairwise posterior is:

$$\xi_t(i,j) = \frac{\alpha_t(i)\,a_{ij}\,b_j(o_{t+1})\,\beta_{t+1}(j)}{P(\mathbf{o}\mid\lambda)}$$

M-step updates (closed form):

$$\hat{a}_{ij} = \frac{\sum_{t=1}^{T-1}\xi_t(i,j)}{\sum_{t=1}^{T-1}\gamma_t(i)}, \qquad \hat{b}_j(k) = \frac{\sum_{t:o_t=k}\gamma_t(j)}{\sum_{t=1}^{T}\gamma_t(j)}$$
Warning — Local Optima

Baum-Welch is guaranteed to reach a local maximum of \(P(\mathbf{o}\mid\lambda)\), not the global maximum. Sensitivity to initialisation is a real problem; multiple random restarts or heuristic initialisation (k-means on observations) are standard practice.

Worked Numerical Example (2-State, T=3)
▼

States: Rain (S0), Sun (S1). Observations: Umbrella (O0), No Umbrella (O1). Sequence: [Umbrella, Umbrella, No Umbrella].

Model Parameters
$$\pi = \begin{bmatrix}0.6\\0.4\end{bmatrix}, \quad A = \begin{bmatrix}0.7 & 0.3\\0.4 & 0.6\end{bmatrix}, \quad B = \begin{bmatrix}0.9 & 0.1\\0.2 & 0.8\end{bmatrix}$$

Forward Pass \(\alpha\)

$$\alpha_1(\text{Rain}) = 0.6\times0.9 = 0.54, \quad \alpha_1(\text{Sun}) = 0.4\times0.2 = 0.08$$
$$\alpha_2(\text{Rain}) = (0.54\times0.7 + 0.08\times0.4)\times0.9 = 0.3698\times0.9 \approx 0.3690$$
$$\alpha_2(\text{Sun}) = (0.54\times0.3 + 0.08\times0.6)\times0.2 = 0.210\times0.2 = 0.0420$$
$$\alpha_3(\text{Rain}) = (0.369\times0.7 + 0.042\times0.4)\times0.1 \approx 0.02751$$
$$\alpha_3(\text{Sun}) = (0.369\times0.3 + 0.042\times0.6)\times0.8 \approx 0.10872$$

Total likelihood: \(P(\mathbf{o}\mid\lambda) = 0.02751 + 0.10872 = 0.13623\)

Backward Pass \(\beta\)

$$\beta_3(\text{Rain}) = \beta_3(\text{Sun}) = 1$$
$$\beta_2(\text{Rain}) = 0.7\times0.1\times1 + 0.3\times0.8\times1 = 0.07 + 0.24 = 0.31$$
$$\beta_2(\text{Sun}) = 0.4\times0.1\times1 + 0.6\times0.8\times1 = 0.04 + 0.48 = 0.52$$

Posterior Marginals \(\gamma\)

Time\(\gamma(\text{Rain})\)\(\gamma(\text{Sun})\)Most likely
t=10.89780.1022Rain
t=20.83970.1603Rain
t=30.20190.7981Sun

Viterbi Path

$$\delta_1(\text{Rain})=0.54,\;\delta_1(\text{Sun})=0.08$$
$$\delta_2(\text{Rain})=\max(0.54\times0.7,\,0.08\times0.4)\times0.9=0.378\times0.9=0.3402$$
$$\delta_2(\text{Sun})=\max(0.54\times0.3,\,0.08\times0.6)\times0.2=0.162\times0.2=0.0324$$
$$\delta_3(\text{Rain})=\max(0.3402\times0.7,\,0.0324\times0.4)\times0.1\approx0.023814$$
$$\delta_3(\text{Sun})=\max(0.3402\times0.3,\,0.0324\times0.6)\times0.8\approx0.081648$$

Backtrack: \(\arg\max = \text{Sun}\) at t=3, \(\psi_3(\text{Sun})=\text{Rain}\), \(\psi_2(\text{Rain})=\text{Rain}\).

Optimal Viterbi path: Rain → Rain → Sun (probability ≈ 0.0816)

One Baum-Welch M-step (re-estimated A)

$$\hat{a}_{\text{Rain}\to\text{Rain}} = \frac{\xi_1(\text{R,R})+\xi_2(\text{R,R})}{\gamma_1(\text{R})+\gamma_2(\text{R})} \approx \frac{0.774+0.190}{0.898+0.840} \approx 0.555$$
Sanity Check

The Baum-Welch update yields \(\hat{a}_{\text{Rain}\to\text{Rain}} \approx 0.555\) (down from 0.7) because the third observation "No Umbrella" pulls evidence toward Sun, reducing the estimated Rain→Rain persistence. This is numerically correct per the full EM equations.

Key Takeaways & When to Use HMMs
▼

When to Use HMMs

  • Discrete observations and a known (or estimable) number of states: speech recognition phonemes, POS tagging, gene finding.
  • You need calibrated posterior marginals over states, not just the best path — use forward-backward.
  • You need the single most likely sequence — use Viterbi (faster, no sum over states).
  • Parameters unknown — use Baum-Welch (converges fast in practice, usually <50 iterations).

Limitations vs Modern Alternatives

  • CRFs (Conditional Random Fields) model \(P(\mathbf{q}\mid\mathbf{o})\) directly — globally normalised, more discriminative, better for NLP sequence labelling.
  • RNNs/Transformers replace explicit state spaces with distributed representations; no Markov constraint, but much more parameters.
  • HMMs remain state-of-the-art in speech recognition acoustic modelling hybrids (DNN-HMM), structural biology, and financial regime detection.
The One Thing to Remember

Forward × Backward = Posterior. The elegance of HMMs is that two linear passes over the trellis — each \(O(N^2 T)\) — give exact posterior state probabilities, enable Viterbi decoding via DP, and power the closed-form EM re-estimation in Baum-Welch. Everything flows from \(\alpha_t(i)\cdot\beta_t(i)\).
