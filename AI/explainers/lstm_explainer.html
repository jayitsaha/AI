LSTM: Gates, Cell State & Peephole Connections

How Long Short-Term Memory networks decide what to forget, what to remember, and what to output
Foundational Deep Learning Sequence Models O(1) per step
1
Understanding LSTM
▼

What is it? A vanilla recurrent neural network keeps one hidden state that gets overwritten and squashed through a nonlinearity at every timestep — over long sequences, gradients either vanish or explode and old information gets erased. The Long Short-Term Memory (LSTM) network fixes this by adding a second, protected pathway called the cell state \(c_t\), plus three learned gates — sigmoid-activated vectors in \([0,1]\) — that control exactly how much old memory to erase, how much new information to write, and how much of the memory to expose as output.

Analogy: Think of the cell state as a conveyor belt running through a factory, mostly untouched by machinery. At each station (timestep) there's a forget gate (a worker deciding what to sweep off the belt), an input gate (a worker deciding what new parts to place on), and an output gate (a worker deciding what to read off the belt and report to the next station). Because the belt itself is only ever scaled and added to — never passed through a squashing function — information can ride it for hundreds of steps almost untouched.

Peephole connections are an optional wire that lets each gate look directly at the cell state (not just at the previous hidden state and the current input) before deciding how much to open or close — literally a peephole into the conveyor belt.

💡 If you remember one thing

The cell state update is additive, not multiplicative-through-a-nonlinearity: $$c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t$$ Because \(\partial c_t/\partial c_{t-1} = f_t\) (elementwise, no matrix multiply, no squashing), gradients can flow backward across many timesteps without vanishing — this is the famous constant error carousel.

How LSTM Works Internally
▼

The Four Gates (Vanilla LSTM)

At every timestep \(t\), the cell receives input \(x_t\), the previous hidden state \(h_{t-1}\), and the previous cell state \(c_{t-1}\). It computes four vectors, each a linear combination of \(x_t\) and \(h_{t-1}\) passed through a nonlinearity:

$$f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f) \quad\text{(forget gate)}$$
$$i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i) \quad\text{(input gate)}$$
$$\tilde c_t = \tanh(W_c x_t + U_c h_{t-1} + b_c) \quad\text{(candidate cell content)}$$
$$o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o) \quad\text{(output gate)}$$

The sigmoid \(\sigma\) squashes each gate into \([0,1]\), acting as a per-unit "valve": 0 means fully closed (block everything), 1 means fully open (pass everything). The candidate \(\tilde c_t\) uses \(\tanh\) (range \([-1,1]\)) because it represents actual content, not a gate.

Combining Gates: Cell State and Hidden State

$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t$$
$$h_t = o_t \odot \tanh(c_t)$$

The forget gate decides what fraction of old memory survives; the input gate decides what fraction of the new candidate gets written in; the output gate decides what fraction of the (squashed) cell state becomes the externally visible hidden state \(h_t\), which is also fed back as \(h_{t-1}\) for the next step and typically passed to a downstream layer.

Peephole Connections

In the vanilla LSTM the gates cannot see the cell state directly — they only see \(h_{t-1}\), a lossy, squashed summary of it. Gers & Schmidhuber (2000) introduced peephole connections: extra diagonal weight terms that let the forget and input gates look at \(c_{t-1}\), and the output gate look at the just-updated \(c_t\):

$$f_t = \sigma(W_f x_t + U_f h_{t-1} + P_f \odot c_{t-1} + b_f)$$
$$i_t = \sigma(W_i x_t + U_i h_{t-1} + P_i \odot c_{t-1} + b_i)$$
$$o_t = \sigma(W_o x_t + U_o h_{t-1} + P_o \odot c_t + b_o)$$

\(P_f, P_i, P_o\) are diagonal (elementwise) weight vectors — each cell unit peeps only at its own memory, not at other units'. Note the asymmetry: \(f_t\) and \(i_t\) peep at \(c_{t-1}\) (memory before this step's update, since they help compute the update), while \(o_t\) peeps at \(c_t\) (memory after the update, since output happens last).

Design Decision: Why gates instead of one nonlinearity?

A vanilla RNN computes \(h_t = \tanh(Wx_t + Uh_{t-1})\) — a single squashing operation every step, so information is repeatedly compressed and gradients repeatedly multiplied by \(\tanh'(\cdot) \le 1\) and by \(U\), causing vanishing gradients. LSTM instead separates "how much to remember" (a learned, input-dependent gate) from "what to remember" (the candidate content), and lets the remembering itself be additive. This design was explicitly motivated by Hochreiter's 1991 diagnosis of the vanishing gradient problem.

🔑 Key Property

Every gate is input-dependent and learned — the network decides, per feature and per timestep, how open each valve should be. This is fundamentally different from a fixed decay/leak rate; the same cell can hold information for 3 steps in one context and 300 steps in another.

3
Why It Works — The Math of Gradient Flow
▼

Backpropagation Through the Cell State

Define the loss gradient reaching the cell state at time \(t\) as \(\delta_t = \partial \mathcal{L}/\partial c_t\). From \(c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t\), the derivative with respect to the previous cell state is:

$$\frac{\partial c_t}{\partial c_{t-1}} = f_t \quad\text{(plus small peephole terms if used)}$$

Unrolling across \(k\) steps, the gradient that reaches \(c_{t-k}\) from \(c_t\) is (ignoring the direct \(i_t \odot \tilde c_t\) injection at each step, which contributes its own separate gradient path):

$$\frac{\partial c_t}{\partial c_{t-k}} = \prod_{j=t-k+1}^{t} f_j$$

Compare this to a vanilla RNN, where the analogous term is \(\prod_j U^\top \operatorname{diag}(\tanh'(\cdot))\) — a product of the same weight matrix \(k\) times, each factor bounded by \(\|U\|\cdot\max\tanh'\). If \(\|U\|<1\) the product shrinks geometrically (vanishing gradient); if \(\|U\|>1\) it grows geometrically (exploding gradient) — and the network has no control over this rate. In the LSTM cell-state path, the corresponding factor is just \(f_j \in [0,1]^d\), a per-step, per-unit, learned and content-dependent value with no repeated weight matrix multiplication. If the network learns \(f_j \approx 1\) for a unit that needs to remember something, that unit's gradient signal is passed through almost unchanged — this is the Constant Error Carousel (CEC) from Hochreiter & Schmidhuber's original 1997 paper.

Full Backward Pass (Sketch)

Gradients also flow into each gate. With \(\delta h_t = \partial\mathcal{L}/\partial h_t\) (from the loss plus the next timestep), the local gate gradients are:

$$\delta o_t = \delta h_t \odot \tanh(c_t) \odot \sigma'(\cdot),\quad \delta c_t \mathrel{+}= \delta h_t \odot o_t \odot \tanh'(c_t)$$
$$\delta f_t = \delta c_t \odot c_{t-1} \odot \sigma'(\cdot), \quad \delta i_t = \delta c_t \odot \tilde c_t \odot \sigma'(\cdot), \quad \delta \tilde c_t = \delta c_t \odot i_t \odot \tanh'(\cdot)$$

Each of \(\delta f_t, \delta i_t, \delta \tilde c_t, \delta o_t\) then backpropagates through its own affine layer into \(\partial\mathcal{L}/\partial W_\bullet, \partial\mathcal{L}/\partial U_\bullet, \partial\mathcal{L}/\partial x_t\), and \(\partial\mathcal{L}/\partial h_{t-1}\) (summed across all four gates) — this is exactly Backpropagation Through Time (BPTT) applied to the LSTM cell, computed once per timestep and accumulated backward from \(t=T\) to \(t=1\).

⚠️ Common Misconception

"LSTMs completely solve vanishing gradients." Not quite — they solve it along the cell-state path as long as the forget gate stays near 1 for units that need long memory. If the network (mis)learns \(f_t \approx 0\) — e.g. from poor initialization — that path is closed and gradients still vanish. A common fix is initializing the forget-gate bias \(b_f\) to a positive value (e.g. 1–2) so gates start mostly open and the network has to learn to close them, not open them.

Key Takeaways
▼

When to use LSTM:

  • Sequences with long-range dependencies (language modeling, speech, time series) where a plain RNN's gradients vanish
  • Tasks needing selective memory — remembering some tokens/events for a long time while quickly discarding irrelevant ones
  • As a strong, well-understood baseline before reaching for attention/Transformers, especially with limited data or streaming/online constraints

When NOT to use / prefer alternatives:

  • Very long sequences with abundant compute and data — Transformers capture long-range dependencies in parallel and typically outperform LSTMs at scale
  • Latency-critical training on huge sequences — LSTMs are inherently sequential (can't parallelize across time), unlike attention
  • When a lighter-weight recurrent unit suffices — GRUs match LSTM performance on many tasks with fewer parameters and no separate cell state

💡 Big Picture

The single idea that makes LSTM work is separating what to store from how much to keep, and making the "keep" fraction additive rather than repeatedly squashed. Every later gated architecture — GRU, highway networks, even residual connections in Transformers/ResNets — is a variation on this same additive-shortcut idea for fighting vanishing gradients.

Code Trace
▼
import numpy as np
def sigmoid(z): return 1.0 / (1.0 + np.exp(-z))
# Scalar (1-unit) peephole LSTM cell, weights fixed for this demo
Wf,Uf,Pf,bf = 0.5, 0.3, 0.2, 0.1
Wi,Ui,Pi,bi = 0.6, 0.2, 0.15, -0.1
Wc,Uc,bc = 0.4, 0.25, 0.0
Wo,Uo,Po,bo = 0.55, 0.35, 0.25, 0.05
def lstm_step(x, h_prev, c_prev):
# forget gate peeps at c_prev (memory BEFORE this update)
f = sigmoid(Wf*x + Uf*h_prev + Pf*c_prev + bf)
# input gate peeps at c_prev too
i = sigmoid(Wi*x + Ui*h_prev + Pi*c_prev + bi)
# candidate content -- tanh, no peephole (it's content, not a gate)
g = np.tanh(Wc*x + Uc*h_prev + bc)
# additive cell-state update -- the constant error carousel
c = f * c_prev + i * g
# output gate peeps at c (memory AFTER the update)
o = sigmoid(Wo*x + Uo*h_prev + Po*c + bo)
h = o * np.tanh(c)
return h, c, dict(f=f, i=i, g=g, o=o)
h, c = 0.0, 0.0
for x in [1.0, 0.5, -0.8]:
h, c, gates = lstm_step(x, h, c)
print(f"h={h:.4f} c={c:.4f} f={gates['f']:.3f} i={gates['i']:.3f} o={gates['o']:.3f}")
# Backward pass (BPTT), one timestep -- gradient into c_{t-1}:
# dL/dc_prev = dL/dc_t * f_t <-- no weight matrix, no repeated squashing
def lstm_backward_step(dc_t, f_t):
return dc_t * f_t # this is the whole "constant error carousel" step
