What Is Bagging?

Imagine you can't afford one perfect advisor, but you can ask many independent advisors who each see a slightly different slice of the evidence. Their disagreements average out — what remains is signal. That is bagging.

Formally: draw \(B\) bootstrap samples (sample \(n\) points with replacement from an \(n\)-point dataset), train one base learner on each, then aggregate by averaging (regression) or majority vote (classification).

Key Invariant
When \(B\) base learners each have variance \(\sigma^2\) and pairwise correlation \(\rho\), the ensemble variance is $$\text{Var}_{\text{bag}} = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2$$ As \(B \to \infty\) the second term vanishes, leaving the irreducible floor \(\rho\sigma^2\). Bias is unchanged.
If you remember one thing
Bagging trades nothing for variance reduction. It costs compute (train \(B\) models) but reduces variance toward \(\rho\sigma^2\) without increasing bias — and gives you free OOB validation because ~37 % of samples are left out of every bootstrap.

Mechanics & Key Numbers

Bootstrap resample probability

When drawing \(n\) samples with replacement from \(n\) items, the probability that a given point is never chosen is:

$$\left(1 - \frac{1}{n}\right)^n \xrightarrow{n\to\infty} e^{-1} \approx 0.368$$

So each bootstrap bag contains roughly 63.2 % unique observations; the remaining ~36.8 % form the out-of-bag (OOB) set — a free held-out validation set, no cross-validation needed.

Variance decomposition

Let each base learner \(\hat{f}_b\) have variance \(\sigma^2\) and let \(\rho\) be the average pairwise correlation between any two learners. The ensemble \(\bar{f} = \frac{1}{B}\sum_b \hat{f}_b\) has:

$$\text{Var}(\bar{f}) = \rho\sigma^2 + \frac{1-\rho}{B}\,\sigma^2$$

The first term is the irreducible floor set by inter-learner correlation. The second term shrinks to 0 as \(B\) grows. This is why Random Forests deliberately inject extra randomness (feature subsampling) to reduce \(\rho\).

Common Misconception
Bagging does not reduce bias. If every base learner is systematically wrong in the same direction, their average will be equally wrong. Bagging only kills variance from model instability.

Historical Context & Comparisons

Breiman (1996) — "Bagging Predictors" — Leo Breiman coined the term and showed that unstable learners (decision trees, neural nets) benefit dramatically; stable learners (k-NN, linear models) see little gain.

Key Takeaways & Interview Essentials

When to use Bagging

  • Base learner has high variance & low bias (deep trees, neural nets)
  • Dataset is large enough that bootstrap diversity is meaningful
  • Free OOB error estimate is desirable (no k-fold needed)

When NOT to use Bagging

  • Base learner is stable (linear regression, k-NN) — little variance to kill
  • Problem has high bias — bagging won't fix systematic underfitting
  • Compute budget is tiny — need \(B\) full training runs

Common Interview Questions

Q: Why is the OOB estimate ~36.8% of points?
Because \((1-1/n)^n \to e^{-1} \approx 0.368\) — the probability a point is never picked in \(n\) draws with replacement. This is asymptotically exact for large \(n\).
Q: Does bagging reduce bias?
No. The expected value of the average equals the expected value of a single model. Bagging only reduces variance. (Exception: some nonlinear averaging effects can slightly reduce bias in practice, but this is not the mechanism.)
Q: How does Random Forest improve on Bagging?
By decorrelating trees via random feature subsampling at each split. This lowers \(\rho\), pushing the variance floor \(\rho\sigma^2\) down further, at the cost of slightly higher per-tree bias.
Ensemble Variance Formula
$$\text{Var}\!\left(\frac{1}{B}\sum_{b=1}^B \hat{f}_b\right) = \rho\sigma^2 + \frac{1-\rho}{B}\,\sigma^2$$ where \(\sigma^2 = \text{Var}(\hat{f}_b)\) and \(\rho = \text{Corr}(\hat{f}_b, \hat{f}_{b'})\) for \(b \neq b'\).
