Linear Discriminant Analysis (LDA)

Supervised dimensionality reduction for maximizing class separability
Foundational Classical ML Dimensionality Reduction O(p³ + Np²) solve
1
Understanding LDA
▼

What is it? Linear Discriminant Analysis (LDA) is a supervised dimensionality reduction technique. Unlike PCA (Principal Component Analysis), which seeks to find directions of maximum variance in the data, LDA explicitly aims to find projections that maximize the separation between known classes while minimizing the variance within each class. It's often used as a preprocessing step for classification or for visualization.

Analogy: Imagine you have a mixed pile of red and blue LEGO bricks, scattered on a table. If you look at them from above, they might appear mixed. LDA is like finding the perfect angle to look at the pile such that the red bricks form a distinct cluster on one side, and the blue bricks form another distinct cluster on the other side, with minimal overlap. It's about finding the "best view" to tell the classes apart.

💡 If you remember one thing

LDA finds a linear combination of features (a projection direction) that maximizes the ratio of between-class scatter to within-class scatter. This results in a new, lower-dimensional representation where classes are maximally separable.

2
How LDA Works Internally
▼

The Core Idea: Maximize Separation

LDA operates on the principle of maximizing the "Fisher's criterion" (or generalized Rayleigh quotient). This criterion quantifies how well classes are separated after projection. To do this, LDA calculates two key scatter matrices:

  1. Within-class scatter matrix (\(S_W\)): Measures the compactness of samples within each class. We want to *minimize* this after projection. It's essentially a pooled covariance matrix, assuming all classes share the same covariance structure (homoscedasticity).
  2. Between-class scatter matrix (\(S_B\)): Measures the separation between the means of different classes. We want to *maximize* this after projection. It captures how far apart the class centers are from the overall mean of the data.

LDA then searches for a projection vector (or a set of vectors) \(w\) such that the ratio \(\frac{w^\top S_B w}{w^\top S_W w}\) is maximized. This ratio is Fisher's criterion.

LDA vs. PCA: A Crucial Difference

While both LDA and PCA are linear dimensionality reduction techniques, their objectives are fundamentally different:

  • PCA: Unsupervised. Finds directions (principal components) that capture the maximum variance in the data, regardless of class labels. It's good for general data compression or noise reduction.
  • LDA: Supervised. Finds directions (linear discriminants) that maximize class separation. It's specifically designed for classification tasks, making it a powerful feature extractor when class labels are available.

Dimensionality Reduction Limit

For a dataset with \(C\) classes and \(p\) features, LDA can project the data down to at most \(C-1\) dimensions. For example, with 2 classes, LDA will find a single optimal projection line (1 dimension). With 3 classes, it will find up to two optimal projection planes (2 dimensions).

🔑 Key Property

LDA assumes that the data for each class is drawn from a Gaussian distribution and that all classes share the same covariance matrix. If these assumptions are violated, LDA's performance may degrade, and Quadratic Discriminant Analysis (QDA) or other non-linear methods might be more appropriate for direct classification.

3
Why It Works — The Math
▼

Defining the Scatter Matrices

Let \(N\) be the total number of samples, \(C\) be the number of classes, \(N_k\) be the number of samples in class \(k\), \(\mu_k\) be the mean vector of class \(k\), and \(\mu\) be the overall mean vector of all data. Let \(x\) be a data point.

The Within-class scatter matrix is the sum of the covariance matrices of each class, weighted by their sample counts:

$$S_W = \sum_{k=1}^C \sum_{x \in \text{class } k} (x - \mu_k)(x - \mu_k)^\top$$

The Between-class scatter matrix measures the spread of the class means around the global mean:

$$S_B = \sum_{k=1}^C N_k (\mu_k - \mu)(\mu_k - \mu)^\top$$

The Optimization Problem

LDA's objective is to find a projection vector \(w\) that maximizes Fisher's criterion \(J(w)\):

$$J(w) = \frac{w^\top S_B w}{w^\top S_W w}$$

To find the \(w\) that maximizes \(J(w)\), we take the derivative with respect to \(w\) and set it to zero. This leads to the generalized eigenvalue problem:

$$S_B w = \lambda S_W w$$

If \(S_W\) is non-singular (invertible), we can rewrite this as:

$$S_W^{-1} S_B w = \lambda w$$

This means that the optimal projection vectors \(w\) are the eigenvectors of the matrix \(S_W^{-1} S_B\), and the corresponding eigenvalues \(\lambda\) represent the "discriminant power" of each direction. We select the eigenvector(s) corresponding to the largest eigenvalue(s) as our linear discriminant(s).

⚠️ Common Pitfall

If the number of features \(p\) is much larger than the number of samples \(N\), the within-class scatter matrix \(S_W\) can become singular (non-invertible). This is a common problem in high-dimensional, small-sample datasets. Solutions include using PCA as a preprocessing step to reduce dimensionality before LDA, or using methods like Regularized LDA or Pseudo-inverse LDA.

Key Takeaways
▼

When to use LDA:

  • As a supervised dimensionality reduction technique when you have labeled data and want to maximize class separation.
  • As a preprocessing step for classification algorithms (e.g., SVM, Logistic Regression) to improve performance and reduce computational cost, especially when dealing with high-dimensional data.
  • For visualizing high-dimensional data by projecting it down to 1 or 2 dimensions, where class clusters are clearly visible.
  • When your data approximately satisfies the Gaussianity and homoscedasticity (equal covariance matrices) assumptions for each class.

When NOT to use:

  • When you don't have class labels (unsupervised learning) — PCA is a better choice.
  • When the decision boundary between classes is highly non-linear. While LDA finds linear boundaries, Kernel LDA can extend it to non-linear cases.
  • When the number of features is very large compared to the number of samples, leading to a singular \(S_W\) matrix.
  • If the homoscedasticity assumption (equal covariance matrices for all classes) is strongly violated. In such cases, Quadratic Discriminant Analysis (QDA) might be more suitable for classification, as it allows for different covariance matrices per class.
💡 Contrast with PCA

PCA is like finding the widest possible road through your data (maximizing overall variance), while LDA is like finding the narrowest possible bridge between distinct towns (maximizing class separation). PCA is for structure discovery, LDA is for classification enhancement.

Code Trace (Python/NumPy)
▼
import numpy as np
def lda_solve(X, y):
n_samples, n_features = X.shape
n_classes = len(np.unique(y))
# Calculate overall mean
overall_mean = np.mean(X, axis=0)
# Calculate Within-class scatter matrix (Sw)
Sw = np.zeros((n_features, n_features))
for c in range(n_classes):
X_c = X[y == c]
mean_c = np.mean(X_c, axis=0)
diff = X_c - mean_c
Sw += diff.T @ diff # sum of (X_c - mu_c)^T (X_c - mu_c)
# Calculate Between-class scatter matrix (Sb)
Sb = np.zeros((n_features, n_features))
for c in range(n_classes):
X_c = X[y == c]
mean_c = np.mean(X_c, axis=0)
diff = mean_c - overall_mean
Sb += X_c.shape[0] * np.outer(diff, diff) # N_c * (mu_c - mu) (mu_c - mu)^T
# Solve the generalized eigenvalue problem S_B w = lambda S_W w
# This is equivalent to S_W^-1 S_B w = lambda w
eigen_values, eigen_vectors = np.linalg.eig(np.linalg.inv(Sw) @ Sb)
# Sort eigenvectors by eigenvalues in descending order
idx = eigen_values.argsort()[::-1]
eigen_vectors = eigen_vectors[:, idx]
# Select the first C-1 eigenvectors (or just 1 for 2 classes)
# The optimal projection vector is the first eigenvector
w = eigen_vectors[:, 0]
return w
