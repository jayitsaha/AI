A historical generative model for unsupervised feature learning and deep pre-training
Foundational Deep Learning Generative Models O(n⋅m) per CD step
1
Understanding RBMs
▼

What is it? A Restricted Boltzmann Machine (RBM) is a generative stochastic artificial neural network that can learn a probability distribution over its set of inputs. It's a type of Boltzmann machine but with a crucial restriction: no connections between units within the same layer. This means RBMs have two layers — a visible layer (for input data) and a hidden layer (for learned features) — with undirected, symmetric connections between them, but no intra-layer connections.

Analogy: Imagine trying to understand a complex system, like a city, by only observing its surface-level phenomena (the visible layer, e.g., traffic patterns, power consumption, noise levels). An RBM attempts to infer the underlying, abstract "causes" or "features" (the hidden layer, e.g., economic activity, major events, cultural trends) that explain these surface observations. By learning the relationships between visible data and hidden features, the RBM can then generate new, plausible surface-level observations that are consistent with its learned understanding of the city.

💡 If you remember one thing

RBMs learn a probabilistic model of the input data, effectively performing dimensionality reduction and feature learning. They are historically significant because they provided the first effective way to pre-train deep neural networks (by stacking RBMs to form Deep Belief Networks), paving the way for the modern deep learning revolution.

How RBMs Work Internally
▼

Architecture and Energy

An RBM consists of a visible layer of \(N_v\) units (\(v\)) and a hidden layer of \(N_h\) units (\(h\)). All units are typically binary (0 or 1). There are no connections between visible units or between hidden units. Every visible unit is connected to every hidden unit via symmetric weights \(w_{ij}\). Each unit also has a bias term (\(b_i\) for visible units, \(c_j\) for hidden units).

The behavior of an RBM is defined by an energy function \(E(v, h)\) that assigns a scalar energy to each possible joint configuration of visible and hidden units. Lower energy means higher probability:

$$E(v, h) = -\sum_{i=1}^{N_v} b_i v_i - \sum_{j=1}^{N_h} c_j h_j - \sum_{i=1}^{N_v} \sum_{j=1}^{N_h} w_{ij} v_i h_j$$

From this energy, a joint probability distribution \(P(v, h)\) can be derived, where \(P(v,h) \propto e^{-E(v,h)}\).

Gibbs Sampling and Conditional Independence

The "restricted" architecture is key: because there are no intra-layer connections, the visible units are conditionally independent given the hidden units, and vice-versa. This means we can efficiently compute the conditional probabilities:

  • \(P(h_j=1|v)\): The probability that hidden unit \(j\) is active, given the current state of all visible units.
  • \(P(v_i=1|h)\): The probability that visible unit \(i\) is active, given the current state of all hidden units.

This conditional independence allows for efficient Gibbs sampling: to sample a state \((v, h)\), we can iteratively sample all hidden units given the visible units, then all visible units given the hidden units, and repeat. This alternating Gibbs sampling is the core mechanism for both inference and learning.

Learning with Contrastive Divergence (CD)

Training an RBM means adjusting its weights and biases to make the probability distribution \(P(v)\) (obtained by marginalizing \(P(v,h)\) over \(h\)) match the distribution of the training data. This is done by maximizing the log-likelihood of the training data, typically using an approximate gradient ascent algorithm called Contrastive Divergence (CD), introduced by Geoffrey Hinton in 2002. CD works by comparing statistics from the "data-driven" phase (where visible units are clamped to data) with statistics from a "reconstruction" phase (where the model generates its own samples).

🔑 Key Property

The restriction (no intra-layer connections) is crucial. It simplifies inference by making conditional probabilities \(P(h|v)\) and \(P(v|h)\) tractable. Each unit's activation probability depends only on its biases and the states of the units in the *other* layer, allowing for efficient parallel computation within each layer.

Why It Works — The Math
▼

Energy Function and Joint Probability

The energy of a configuration \((v, h)\) is given by:

$$E(v, h) = -\sum_{i} b_i v_i - \sum_{j} c_j h_j - \sum_{i,j} w_{ij} v_i h_j$$

The joint probability distribution over visible and hidden states is then defined as:

$$P(v, h) = \frac{e^{-E(v, h)}}{Z}$$

where \(Z = \sum_{v,h} e^{-E(v,h)}\) is the partition function, which sums over all possible \(2^{N_v+N_h}\) configurations and makes exact likelihood computation intractable for large RBMs.

Conditional Probabilities

Due to the bipartite graph structure, the conditional probabilities for units are simple sigmoids:

$$P(h_j=1|v) = \sigma\left(c_j + \sum_i w_{ij} v_i\right)$$
$$P(v_i=1|h) = \sigma\left(b_i + \sum_j w_{ij} h_j\right)$$

where \(\sigma(x) = 1/(1+e^{-x})\) is the logistic sigmoid function. These equations are fundamental for Gibbs sampling and the Contrastive Divergence algorithm.

Contrastive Divergence Gradient

The goal of training is to adjust parameters \((w, b, c)\) to maximize the log-likelihood of the training data. The gradient of the log-likelihood with respect to a weight \(w_{ij}\) is:

$$\frac{\partial \log P(v)}{\partial w_{ij}} = \langle v_i h_j \rangle_{\text{data}} - \langle v_i h_j \rangle_{\text{model}}$$

where \(\langle \cdot \rangle_{\text{data}}\) is the expectation under the data distribution, and \(\langle \cdot \rangle_{\text{model}}\) is the expectation under the RBM's model distribution. The second term is intractable. Contrastive Divergence (CD-k) approximates \(\langle \cdot \rangle_{\text{model}}\) by running \(k\) steps of Gibbs sampling starting from the data, yielding the update rule:

$$\Delta w_{ij} = \eta \left( \langle v_i h_j \rangle_{\text{data}} - \langle v_i h_j \rangle_{\text{reconstruction}} \right)$$

where \(\eta\) is the learning rate. The term \(\langle v_i h_j \rangle_{\text{data}}\) is computed from the initial data-clamped state, and \(\langle v_i h_j \rangle_{\text{reconstruction}}\) is computed after \(k\) steps of Gibbs sampling. Similar rules apply to biases.

⚠️ Common Pitfall

The Contrastive Divergence algorithm is an approximation to true gradient ascent on the log-likelihood. It uses a very short chain of Gibbs sampling (typically \(k=1\), hence CD-1) to estimate the negative phase expectation. While effective in practice, especially for pre-training, it does not guarantee convergence to a local optimum of the true likelihood, and can sometimes lead to biased learning.

Key Takeaways
▼

When RBMs were used (historically):

  • Unsupervised Pre-training: RBMs were famously used to pre-train layers of Deep Belief Networks (DBNs). Each RBM learned features from the previous layer's activations, initializing a deep network with useful representations before fine-tuning with supervised learning. This was a breakthrough for training deep neural networks.
  • Collaborative Filtering: RBMs achieved state-of-the-art results in the Netflix Prize competition, learning latent factors from user movie ratings to recommend new movies.
  • Dimensionality Reduction & Feature Learning: Like autoencoders, RBMs can learn compact, meaningful representations of high-dimensional data without explicit labels.
  • Generative Models: RBMs can generate new samples from their learned probability distribution, for example, generating new images that resemble the training data.

Why RBMs are less common today:

  • Training Speed & Complexity: Contrastive Divergence is an approximation and can be slower to converge than modern deep learning optimization techniques. The layer-wise pre-training of DBNs is also more cumbersome than end-to-end training with backpropagation.
  • Architectural Limitations: RBMs are typically limited to two layers (visible and hidden) and binary units, though extensions exist. Modern deep learning favors highly flexible architectures.
  • Replaced by Newer Models: For generative tasks, Variational Autoencoders (VAEs) and Generative Adversarial Networks (GANs) offer more powerful and stable generation. For unsupervised feature learning, standard autoencoders, self-supervised learning, and large pre-trained models (e.g., BERT, CLIP) have largely superseded RBMs.
💡 Big Picture

RBMs were a critical stepping stone in the resurgence of deep learning. They demonstrated that deep, unsupervised feature learning was not only possible but could yield powerful representations, directly inspiring the architectures and training paradigms that dominate AI today.

Code Trace (Python/NumPy)
▼
import numpy as np
def sigmoid(x):
return 1 / (1 + np.exp(-x))
class RBM:
def __init__(self, n_visible, n_hidden, seed=42):
self.n_visible = n_visible
self.n_hidden = n_hidden
rng = np.random.default_rng(seed)
self.W = rng.normal(0, 0.1, (n_visible, n_hidden)) # Weights
self.b_v = np.zeros(n_visible) # Visible biases
self.b_h = np.zeros(n_hidden) # Hidden biases
def sample_h_given_v(self, v):
h_prob = sigmoid(np.dot(v, self.W) + self.b_h)
h_sample = (np.random.rand(self.n_hidden) < h_prob).astype(int)
return h_prob, h_sample
def sample_v_given_h(self, h):
v_prob = sigmoid(np.dot(h, self.W.T) + self.b_v)
v_sample = (np.random.rand(self.n_visible) < v_prob).astype(int)
return v_prob, v_sample
def train_cd1(self, v_data, learning_rate=0.1):
# Positive phase (data-driven)
h0_prob, h0_sample = self.sample_h_given_v(v_data)
# Negative phase (reconstruction)
v1_prob, v1_sample = self.sample_v_given_h(h0_sample)
h1_prob, h1_sample = self.sample_h_given_v(v1_sample)
# Update weights and biases
positive_gradient = np.outer(v_data, h0_prob)
negative_gradient = np.outer(v1_sample, h1_prob)
self.W += learning_rate * (positive_gradient - negative_gradient)
self.b_v += learning_rate * (v_data - v1_sample)
self.b_h += learning_rate * (h0_prob - h1_prob)
# Example usage:
# rbm = RBM(n_visible=4, n_hidden=3)
# data_pattern = np.array([1, 1, 0, 0])
# rbm.train_cd1(data_pattern, learning_rate=0.1)
