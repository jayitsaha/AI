NER & POS Tagging

Sequence Labeling with Feature Templates, CRF & BiLSTM-CRF
Intermediate Classical ML · NLP Part III: Classical ML Sequence Labeling
1
Understanding the Concept

Named Entity Recognition (NER) finds "who, what, and where" in text — spotting that Barack Obama is a person, Google is an organization, London is a location. Part-of-Speech (POS) tagging labels every word with its grammatical role: noun, verb, adjective, preposition, and so on.

Both tasks are instances of sequence labeling: given a sequence of words \(w_1, w_2, \ldots, w_n\), assign a label \(y_i\) to every word \(w_i\). What makes this hard is that the best label for word \(i\) depends on its neighbors — the tag assigned to word \(i{-}1\) strongly constrains word \(i\).

💡 The Core Insight

Labels are not chosen independently per word. A CRF models the whole output sequence jointly, capturing that B-PER → I-PER is valid but B-PER → I-ORG is not.

The standard label encoding for NER is the BIO scheme: Beginning of entity, Inside entity, Outside. For POS, labels come from the Penn Treebank tagset (NNP, VBZ, DT, IN, …).

🔑 BIO Tagging Contract

B-TYPE starts an entity of TYPE. I-TYPE continues an entity of TYPE — and must follow a B-TYPE or I-TYPE of the same type. O marks non-entity tokens.

2
How It Works — Feature Templates & the CRF

A linear-chain CRF defines a log-linear model over the entire output sequence given the input. Its score for a labeling \(\mathbf{y} = (y_1, \ldots, y_n)\) given words \(\mathbf{x}\) is:

$$\log P(\mathbf{y}\mid\mathbf{x}) = \sum_{t=1}^{n} \sum_k \lambda_k f_k(y_{t-1}, y_t, \mathbf{x}, t) - \log Z(\mathbf{x})$$

where \(f_k\) are feature functions, \(\lambda_k\) are learned weights, and \(Z(\mathbf{x})\) is the partition function (sum over all possible labelings — computed efficiently via the forward algorithm in \(O(n|\mathcal{Y}|^2)\)).

Feature templates are patterns that fire on the input context. Classic examples for position \(t\):

At inference time, the CRF uses the Viterbi algorithm to find the highest-scoring label sequence exactly:

$$\mathbf{y}^* = \underset{\mathbf{y}}{\arg\max} \sum_{t=1}^{n} \sum_k \lambda_k f_k(y_{t-1}, y_t, \mathbf{x}, t)$$

The BiLSTM-CRF replaces hand-crafted features with a bidirectional LSTM that reads the full sentence in both directions and produces per-position emission scores (one per label), which feed into the CRF layer as potentials. This removes the need for feature engineering while keeping the globally optimal label sequence.

📐 BiLSTM-CRF Pipeline

Characters → CharCNN → Word Embedding + CharEmb → BiLSTM → Emission scores (n × |Y|) → CRF → Viterbi → Label sequence

3
The Math — CRF Training & Viterbi Decoding

Training maximizes the conditional log-likelihood over the training set. The partition function \(Z(\mathbf{x})\) is computed via the forward algorithm. Let \(\phi(y_{t-1}, y_t, \mathbf{x}, t) = \sum_k \lambda_k f_k(\cdot)\) be the total score for a transition.

$$Z(\mathbf{x}) = \sum_{\mathbf{y}'} \exp\!\left(\sum_{t=1}^n \phi(y'_{t-1}, y'_t, \mathbf{x}, t)\right)$$

Forward variable \(\alpha_t(j)\) = total score of all partial sequences ending in label \(j\) at position \(t\):

$$\alpha_t(j) = \log\sum_{i} \exp\!\bigl(\alpha_{t-1}(i) + \phi(i, j, \mathbf{x}, t)\bigr)$$

Computed in \(O(n|\mathcal{Y}|^2)\). The partition function is \(\log Z = \log\sum_j \exp(\alpha_n(j))\).

Viterbi replaces log-sum-exp with max:

$$\delta_t(j) = \max_i \bigl(\delta_{t-1}(i) + \phi(i, j, \mathbf{x}, t)\bigr)$$

Back-pointers \(\psi_t(j) = \arg\max_i(\cdot)\) reconstruct the optimal path.

Numerical example (3 tokens, 3 labels O / B-PER / I-PER). Emission scores from BiLSTM (log-scale):

Tokene(O)e(B-PER)e(I-PER)

Viterbi at \(t=2\) for I-PER: \(\delta_2(I) = \delta_1(B) + T(B\to I) + e_2(I) = 1.8 + 2.5 + 2.1 = 6.4\) — dominant path → B-PER, I-PER, O.

⚠️ Common Mistake

Treating NER as independent per-token classification ignores label constraints (I-PER cannot start a sequence). The CRF's transition matrix encodes these hard constraints via very negative weights, making them effectively impossible.

  • BIO tagging turns span detection into token classification — but label transitions must be modeled.
  • CRF adds a globally normalized layer on top of any emission scorer (hand features or neural).
  • The BiLSTM provides bidirectional context; the CRF provides valid label sequences.
  • For POS tagging, label dependency is weaker — a simple BiLSTM softmax often suffices.
  • Training objective: maximize \(\log P(\mathbf{y}^*|\mathbf{x})\) = emission score + transition score − log Z.
🎯 Decision Rule

Label constraints matter? → Use CRF layer. Need interpretability? → Hand features + CRF. Have GPU + data? → BiLSTM-CRF or BERT+CRF.
