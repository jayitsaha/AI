Understanding Bellman Equations
▼

What are they? The Bellman equations are a set of recursive equations that form the cornerstone of dynamic programming and Reinforcement Learning (RL). They describe the value of a decision process at a certain state by relating it to the values of successor states. Essentially, they break down a complex, multi-step problem into simpler, recursive subproblems.

In RL, these equations define the value functions, which estimate how good it is for an agent to be in a given state, or to perform a given action in a given state. There are two main types:

  1. The Bellman Expectation Equation (for policy evaluation) describes the value of a state or state-action pair under a *given fixed policy*.
  2. The Bellman Optimality Equation (for policy improvement) describes the value of a state or state-action pair assuming the agent *always takes the best possible action* to maximize future reward.

Analogy: Imagine planning a multi-day road trip. The "value" of being in a city isn't just the immediate fun you have there, but also the fun you'll have on all subsequent days, discounted by how far in the future they are. The Bellman equations say: "The value of being in City A is the immediate reward of being in City A, plus the discounted value of the *best* (or *expected*) next city you could drive to from A." You recursively apply this logic until you reach your destination (terminal states).

💡 If you remember one thing

Bellman equations express the value of a state as a sum of the immediate reward and the discounted value of future states. They are recursive definitions of value functions, allowing complex sequential decision problems to be solved iteratively.

How They Work Internally
▼

Markov Decision Processes (MDPs)

Bellman equations apply to Markov Decision Processes, which model sequential decision-making. An MDP is defined by:

  • \(S\): A set of states (e.g., cells in a grid).
  • \(A\): A set of actions (e.g., UP, DOWN, LEFT, RIGHT).
  • \(P(s'|s,a)\): Transition probabilities — the probability of reaching state \(s'\) from state \(s\) after taking action \(a\).
  • \(R(s,a,s')\): Reward function — the immediate reward received after transitioning from \(s\) to \(s'\) via action \(a\).
  • \(\gamma \in [0,1]\): Discount factor — how much future rewards are valued relative to immediate rewards.

The goal is to find a policy \(\pi(a|s)\) (a mapping from states to actions) that maximizes the agent's cumulative discounted reward over time.

Value Functions: \(V(s)\) and \(Q(s,a)\)

To find optimal policies, we first need to quantify "how good" states and actions are:

  • The state-value function \(V^\pi(s)\) is the expected return (sum of discounted future rewards) starting from state \(s\) and following policy \(\pi\) thereafter.
  • The action-value function \(Q^\pi(s,a)\) is the expected return starting from state \(s\), taking action \(a\), and then following policy \(\pi\) thereafter.

Bellman equations relate these values at one time step to values at the next, allowing for iterative computation.

Design Decision: Expectation vs. Optimality

Why two sets of equations? They serve different purposes:

  • Expectation Equations are used for policy evaluation: given a specific policy \(\pi\), what are the values \(V^\pi(s)\) and \(Q^\pi(s,a)\)? This is a prediction problem.
  • Optimality Equations are used for policy improvement: they define the maximum possible value \(V^*(s)\) and \(Q^*(s,a)\) achievable from any state/action, which directly leads to the optimal policy \(\pi^*\). This is a control problem.

They are fundamentally different because the expectation versions average over the policy's action probabilities, while the optimality versions take a maximum over actions.

🔑 Key Property

The Bellman equations are recursive definitions. This recursive structure allows us to solve for value functions using iterative methods like Policy Iteration (which uses the expectation equations) and Value Iteration (which uses the optimality equations).

Why They Work — The Math
▼

Bellman Expectation Equation (State-Value)

The value of a state \(s\) under policy \(\pi\) is the expected immediate reward plus the discounted expected value of the next state \(s'\):

$$V^\pi(s) = \sum_a \pi(a|s) \sum_{s', r} p(s', r|s, a) [r + \gamma V^\pi(s')]$$

Here, \(\pi(a|s)\) is the probability of taking action \(a\) in state \(s\) according to policy \(\pi\). \(p(s', r|s, a)\) is the probability of transitioning to state \(s'\) and receiving reward \(r\) when taking action \(a\) from state \(s\). The term \([r + \gamma V^\pi(s')]\) represents the immediate reward plus the discounted value of the next state.

Bellman Expectation Equation (Action-Value)

The value of taking action \(a\) in state \(s\) under policy \(\pi\) is the expected immediate reward plus the discounted expected value of the next state-action pair, where the next action is chosen according to \(\pi\):

$$Q^\pi(s,a) = \sum_{s', r} p(s', r|s, a) [r + \gamma \sum_{a'} \pi(a'|s') Q^\pi(s', a')]$$

This equation shows that \(Q^\pi(s,a)\) can be defined in terms of other \(Q^\pi\) values. Notice how \(V^\pi\) and \(Q^\pi\) are interlinked: \(V^\pi(s) = \sum_a \pi(a|s) Q^\pi(s,a)\) and \(Q^\pi(s,a) = \sum_{s',r} p(s',r|s,a) [r + \gamma V^\pi(s')]\).

Bellman Optimality Equation (State-Value)

The optimal value of a state \(s\), \(V^*(s)\), is the maximum expected return achievable from \(s\). This means choosing the action \(a\) that maximizes the immediate reward plus the discounted optimal value of the next state:

$$V^*(s) = \max_a \sum_{s', r} p(s', r|s, a) [r + \gamma V^*(s')]$$

The key difference here is the \(\max_a\) operator, which implies we are always selecting the best action from state \(s\) to maximize future returns, rather than averaging over a fixed policy.

Bellman Optimality Equation (Action-Value)

The optimal value of taking action \(a\) in state \(s\), \(Q^*(s,a)\), is the maximum expected return achievable. After taking action \(a\) from state \(s\), the agent then acts optimally from the next state \(s'\):

$$Q^*(s,a) = \sum_{s', r} p(s', r|s, a) [r + \gamma \max_{a'} Q^*(s', a')]$$

From \(Q^*(s,a)\), the optimal policy \(\pi^*(s)\) is simply to choose the action \(a\) that yields \(Q^*(s,a)\) for each state \(s\).

⚠️ Key Distinction

The Bellman Expectation Equations describe the value of following a given policy. The Bellman Optimality Equations describe the value of the optimal policy, using a maximization over actions. They are both recursive but serve different purposes: evaluation vs. control.

Key Takeaways
▼

When to use Bellman Equations:

  • Policy Evaluation: To determine the value of a specific policy (using expectation equations). This is crucial for Policy Iteration.
  • Optimal Policy Discovery: To find the best possible policy (using optimality equations). This is the core of Value Iteration.
  • Model-Based RL: When the MDP dynamics (transition probabilities and rewards) are known, these equations allow for direct computation or iterative approximation of value functions.
  • Foundation for other RL algorithms: Many model-free algorithms (like Q-learning, SARSA) are inspired by or directly derived from the Bellman equations, even when the full MDP model is unknown.

When NOT to use / limitations:

  • Model-Free Settings: If the transition probabilities \(p(s',r|s,a)\) are unknown, you cannot directly apply the Bellman equations. You'll need to learn from experience (e.g., Q-learning, which estimates Q-values directly).
  • Large State/Action Spaces: The "curse of dimensionality" means that storing and iterating over all possible states and actions becomes computationally infeasible. Function approximation (e.g., neural networks) is needed in such cases.
  • Continuous State/Action Spaces: For continuous environments, the summation over states/actions becomes an integral, requiring approximation methods.
💡 Big Picture

The Bellman equations are a powerful mathematical framework for dynamic programming. They show how sequential decision problems can be recursively broken down, enabling efficient solutions for a wide range of planning and control tasks in Reinforcement Learning.

Code Trace — Value Iteration from Scratch
▼
import numpy as np
# Define Grid World (simplified for code example)
GRID_SIZE = 3
TERMINAL_STATES = {(0,2): 10, (1,2): -10} # (row, col): reward
DEFAULT_REWARD = -1
GAMMA = 0.9
ACTIONS = [(-1,0), (1,0), (0,-1), (0,1)] # UP, DOWN, LEFT, RIGHT
def get_next_state_reward(s, a):
r, c = s
if s in TERMINAL_STATES:
return s, TERMINAL_STATES[s] # Stay in terminal state with its reward
next_r, next_c = r + a[0], c + a[1]
# Boundary checks
next_r = max(0, min(GRID_SIZE - 1, next_r))
next_c = max(0, min(GRID_SIZE - 1, next_c))
next_s = (next_r, next_c)
immediate_reward = DEFAULT_REWARD
terminal_reward = TERMINAL_STATES.get(next_s, 0)
return next_s, immediate_reward + terminal_reward
def value_iteration():
V = np.zeros((GRID_SIZE, GRID_SIZE)) # Initialize V(s) to 0
policy = np.full((GRID_SIZE, GRID_SIZE), ' ', dtype='
theta = 1e-6 # Convergence threshold
while True:
delta = 0
for r in range(GRID_SIZE):
for c in range(GRID_SIZE):
s = (r, c)
if s in TERMINAL_STATES:
V[r,c] = TERMINAL_STATES[s] # Terminal states have fixed value
policy[r,c] = 'T'
continue
v_old = V[r,c]
q_values = []
for i, action_tuple in enumerate(ACTIONS):
next_s, reward = get_next_state_reward(s, action_tuple)
q_values.append(reward + GAMMA * V[next_s])
V[r,c] = np.max(q_values) # Bellman Optimality Equation
delta = max(delta, abs(v_old - V[r,c]))
policy[r,c] = ['↑', '↓', '←', '→'][np.argmax(q_values)] # Store best action
if delta < theta:
break
return V, policy
# Run Value Iteration
optimal_V, optimal_policy = value_iteration()
print("Optimal Value Function V*:\n", optimal_V)
print("Optimal Policy π*:\n", optimal_policy)
