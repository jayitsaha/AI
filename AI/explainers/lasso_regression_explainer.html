Understanding Lasso
▼

What is it? Lasso (Least Absolute Shrinkage and Selection Operator) is a regularized regression that adds a penalty proportional to the sum of absolute values of the coefficients. Unlike its cousin Ridge (which shrinks all coefficients toward zero but keeps them all nonzero), Lasso drives many coefficients to exactly zero — performing automatic feature selection built into the optimization.

Analogy: Imagine fitting a budget to expenses across 100 categories. Ridge regression gives every category a small cut. Lasso is harsher: it gives a few categories their full (or reduced) budget and zeros out the rest entirely. The result is a sparse budget — most lines read $0. This is exactly what Lasso does to regression coefficients.

💡 If you remember one thing

Lasso minimizes $$\hat{\beta} = \underset{\beta}{\operatorname{argmin}} \; \|y - X\beta\|_2^2 + \lambda \|\beta\|_1$$ The \(\ell_1\) penalty's geometry (a diamond in 2D) has corners on the axes — so the loss contour almost always meets the constraint set at a corner where some \(\beta_j = 0\) exactly. Ridge uses a sphere: no corners, never exact zeros.

Why No Closed Form — Coordinate Descent
▼

Why Ridge Has a Closed Form but Lasso Does Not

Ridge regression minimizes \(\|y - X\beta\|_2^2 + \lambda\|\beta\|_2^2\). The objective is strictly convex and differentiable everywhere, so setting the gradient to zero gives the closed-form solution \(\hat{\beta}_\text{Ridge} = (X^\top X + \lambda I)^{-1} X^\top y\) directly.

Lasso adds \(\lambda\|\beta\|_1 = \lambda \sum_j |\beta_j|\). The absolute-value function \(|\beta_j|\) is not differentiable at \(\beta_j = 0\). The subgradient at zero is the interval \([-\lambda, \lambda]\), not a single value. So we cannot solve a simple linear system — we need an iterative optimization algorithm.

Coordinate Descent

The standard approach is coordinate descent: hold all coefficients fixed and optimize one at a time, cycling through all \(j = 1, \ldots, p\) until convergence. The key insight is that the one-dimensional Lasso subproblem has an exact analytic solution — the soft-threshold operator.

For feature \(j\), define the partial residual \(r_j = y - \sum_{k \neq j} X_k \hat{\beta}_k\) (all contributions except feature \(j\)). The update is:

$$\hat{\beta}_j \leftarrow S\!\left(\frac{X_j^\top r_j}{\|X_j\|_2^2},\; \frac{\lambda}{\|X_j\|_2^2}\right)$$

where the soft-threshold operator is:

$$S(z, \gamma) = \operatorname{sign}(z) \cdot \max(|z| - \gamma,\; 0)$$
🔑 Soft-Threshold Intuition

\(S(z, \gamma)\) shrinks \(z\) toward zero by \(\gamma\). If \(|z| \leq \gamma\), the output is exactly 0 — the coefficient is killed. If \(|z| > \gamma\), the output is \(z\) with its magnitude reduced by \(\gamma\). This is fundamentally different from Ridge's scaling: Ridge multiplies by \(\frac{1}{1+\lambda}\), never reaching zero.

Numerical Trace: One Coordinate Descent Step

Suppose \(X\) has 2 standardized features, \(y = [2, 1, 3, 0]^\top\), current \(\hat{\beta} = [0.5, 0.0]\), \(\lambda = 0.4\).

Partial residual for j=0: r_0 = y - X[:,1]*beta[1] = y - 0
= [2, 1, 3, 0] (beta[1]=0 contributes nothing)
OLS update: z_0 = X[:,0]^T r_0 / ||X[:,0]||^2
Suppose z_0 = 1.20 (correlation of feature 0 with residual)
Threshold: gamma = lambda / ||X[:,0]||^2 = 0.4/1.0 = 0.40
Soft-threshold: S(1.20, 0.40) = sign(1.20)*max(1.20-0.40,0) = 0.80

Threshold: gamma = 0.4/1.0 = 0.40
Soft-threshold: S(0.35, 0.40) = sign(0.35)*max(0.35-0.40,0) = 0.00
beta[1] updated: 0.00 → 0.00 (stays exactly zero!)

The Math — L1 Geometry & KKT Conditions
▼

Why the Diamond Produces Exact Zeros

Consider 2D Lasso. The constraint form is \(\min_\beta \|y - X\beta\|_2^2\) subject to \(\|\beta\|_1 \leq t\). The feasible set is the L1 ball — a diamond with vertices at \((\pm t, 0)\) and \((0, \pm t)\). The loss \(\|y - X\beta\|_2^2\) has elliptical contours centered at the OLS solution \(\hat{\beta}_{OLS}\).

Because the diamond has corners on the coordinate axes, as the ellipse expands from \(\hat{\beta}_{OLS}\) outward (as we reduce \(t\), i.e., increase \(\lambda\)), it nearly always first touches the diamond at a corner — a point where one coordinate is exactly 0. In high dimensions, with \(p\) features, the L1 ball has \(2p\) corners and \(\binom{2p}{k}\) faces, making axis-aligned corners overwhelmingly likely to be hit first.

KKT Optimality Conditions

The Lasso objective is \(L(\beta) = \|y-X\beta\|_2^2 + \lambda\|\beta\|_1\). Since \(\|\beta\|_1\) is convex but non-smooth, the optimality condition uses subgradients. At the optimum \(\hat{\beta}\):

$$-2X_j^\top(y - X\hat{\beta}) + \lambda\,s_j = 0, \quad s_j \in \partial|\hat{\beta}_j|$$

where the subgradient of \(|\beta_j|\) is:

$$\partial|\beta_j| = \begin{cases} \{+1\} & \beta_j > 0 \\ [-1,+1] & \beta_j = 0 \\ \{-1\} & \beta_j < 0 \end{cases}$$

This gives the necessary and sufficient conditions:

$$\hat{\beta}_j \neq 0: \quad -2X_j^\top r = \lambda\,\operatorname{sign}(\hat{\beta}_j)$$
$$\hat{\beta}_j = 0: \quad |2X_j^\top r| \leq \lambda$$

The second condition says: feature \(j\) is zeroed out if and only if its correlation with the residual \(r = y - X\hat{\beta}_{(-j)}\) is small (at most \(\lambda/2\)). This is exactly the soft-threshold decision.

∑ Key Equations

Lasso objective: \(\hat{\beta} = \arg\min_\beta \|y - X\beta\|_2^2 + \lambda\|\beta\|_1\)
Soft-threshold: \(S(z,\gamma) = \operatorname{sign}(z)(|z|-\gamma)_+\)
Coordinate update: \(\hat\beta_j \leftarrow S\!\bigl(X_j^\top r_j / \|X_j\|^2,\; \lambda/\|X_j\|^2\bigr)\)

⚠️ Correlated Features

When features are highly correlated, Lasso tends to select one and zero out the rest — somewhat arbitrarily. Elastic Net (\(\ell_1 + \ell_2\) combined) handles correlated features more gracefully by grouping them. Lasso's sparsity can be unstable under feature correlation.

From Scratch — Coordinate Descent Lasso (NumPy)

import numpy as np
def soft_threshold(z, gamma):
"""S(z, gamma) = sign(z) * max(|z| - gamma, 0)"""
return np.sign(z) * np.maximum(np.abs(z) - gamma, 0.0)
def lasso_coordinate_descent(X, y, lam, max_iter=1000, tol=1e-6):
n, p = X.shape
Xnorms = (X ** 2).sum(axis=0) # ||X_j||^2 for each feature
beta = np.zeros(p) # warm-start at zero
r = y.copy() # residual r = y - X @ beta = y
for iteration in range(max_iter):
beta_old = beta.copy()
for j in range(p): # cycle through features
r_j = r + X[:, j] * beta[j] # partial residual (add beta_j back)
z_j = X[:, j] @ r_j / Xnorms[j] # OLS update for feature j
beta[j] = soft_threshold(z_j, lam / Xnorms[j])
r = r_j - X[:, j] * beta[j] # update residual
if np.max(np.abs(beta - beta_old)) < tol:
break
return beta

Production Usage — scikit-learn

from sklearn.linear_model import Lasso, LassoCV
from sklearn.preprocessing import StandardScaler
# ALWAYS standardize before Lasso (penalty is not scale-invariant)
scaler = StandardScaler()
X_std = scaler.fit_transform(X_train)
# Cross-validate to find optimal lambda
lasso_cv = LassoCV(cv=5, alphas=np.logspace(-4, 2, 100), max_iter=10000)
lasso_cv.fit(X_std, y_train)
print(f"Optimal lambda: {lasso_cv.alpha_:.4f}")
print(f"Nonzero features: {np.sum(lasso_cv.coef_ != 0)} / {X.shape[1]}")
# Gotcha: max_iter default (1000) often insufficient — use 10000+
# Gotcha: alpha in sklearn = lambda/n in math convention
⚠️ Gotcha

Lasso is not scale-invariant. Always standardize features (zero mean, unit variance) before fitting. Otherwise the penalty treats large-scale features more aggressively than small-scale ones, producing arbitrary sparsity patterns.

Key Takeaways
▼

When to use Lasso:

  • You believe only a small number of features are truly relevant (sparsity assumption)
  • You want automatic feature selection built into the regression
  • \(p \gg n\) settings (high-dimensional, more features than samples)
  • Interpretability matters — sparse models are easier to explain

When NOT to use Lasso:

  • Features are highly correlated — Lasso picks one arbitrarily; use Elastic Net
  • All features are relevant — Ridge will outperform (no true sparsity)
  • You need smooth coefficient paths — Lasso paths can have sharp kinks
💡 Lasso vs Ridge vs Elastic Net

Ridge (\(\ell_2\)): Shrinks all coefficients, never exactly zero. Best when all features matter.
Lasso (\(\ell_1\)): Exact zeros, built-in feature selection. Best when few features matter.
Elastic Net (\(\ell_1+\ell_2\)): Both effects. Best with correlated features in groups.
