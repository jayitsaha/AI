Understanding Rejection Sampling Fine-Tuning
▼

What is it? Rejection sampling fine-tuning, often called "Best-of-N" (BoN), is a method to improve the quality of a language model's outputs. Instead of directly training on a single generated response, the model generates \(N\) candidate responses for a given prompt. These \(N\) candidates are then evaluated by a separate scoring mechanism (e.g., a reward model, a heuristic, or even human feedback), and only the single "best" response is selected. This best response is then used as the target for a supervised fine-tuning (SFT) update on the original model.

Analogy: Imagine a student who needs to write an essay. Instead of just writing one and submitting it, they write \(N\) different essays on the same topic. They then meticulously review all \(N\) essays, pick the absolute best one, and only study *that* essay to understand why it was superior. The next time they write an essay, they're more likely to produce a higher-quality result because they've learned directly from their own best work, guided by an external "critic." This process iteratively nudges the student's writing skills towards excellence.

💡 If you remember one thing

Best-of-N fine-tuning directly optimizes the language model to produce higher-quality outputs by selecting from a diverse set of its own generations. It's a simpler, yet effective, alternative to more complex reinforcement learning methods like PPO, directly leveraging a scoring function to curate high-quality training data.

How Best-of-N Works Internally
▼

The Four-Step Iteration

The Best-of-N (BoN) fine-tuning process typically involves these four steps, repeated iteratively:

  1. Generate \(N\) Samples: For a given input prompt \(x\), the current language model (the policy model, \(P_{\theta}\)) generates \(N\) distinct candidate responses: \(y_1, y_2, \dots, y_N\). These samples are typically generated with some temperature to encourage diversity.
  2. Score Samples: Each of the \(N\) generated samples \((x, y_k)\) is evaluated by a scoring function, \(R(x, y)\). This scoring function can be a separately trained reward model (RM), a simple heuristic (e.g., checking for keywords, length, stylistic properties), or even human preferences.
  3. Select Best: From the \(N\) scored samples, the one with the highest score is chosen as the "best" sample, denoted \(y^*\). All other \(N-1\) samples are "rejected" or discarded.
  4. Fine-tune: The original language model \(P_{\theta}\) is then fine-tuned using the prompt \(x\) and the selected best sample \(y^*\) as a new supervised training pair \((x, y^*)\). This is typically done using standard next-token prediction (cross-entropy) loss, updating the model's parameters \(\theta\) to increase the likelihood of generating \(y^*\) given \(x\).

This iterative process allows the model to progressively learn from its own best outputs, guided by the external scoring function, effectively shifting its generative distribution towards higher-quality responses.

Design Decision: Why "N" Samples?

The choice of \(N\) is a crucial trade-off. A larger \(N\) increases the probability of generating at least one high-quality response, thereby providing better training signals and leading to a more significant quality improvement. This is analogous to taking more shots on goal – you're more likely to score. However, generating \(N\) samples also incurs a proportional computational cost (latency and compute resources). For practical applications, \(N\) is often chosen between 4 and 64, balancing quality gains with resource constraints. The "Best-of-N" approach is particularly effective when the underlying model already has some capacity to generate good responses, but needs to learn to do so more consistently.

🔑 Key Property

Unlike Reinforcement Learning from Human Feedback (RLHF) which trains a separate reward model and then uses Proximal Policy Optimization (PPO) to align the policy, Best-of-N directly uses the scoring function to curate high-quality data for a standard supervised fine-tuning step. This bypasses the complexities of RL training, making it simpler to implement and debug.

Why It Works — The Math
▼

Formalizing the Process

Let \(P_{\theta}(y|x)\) be the probability distribution of generating response \(y\) given prompt \(x\) by a language model with parameters \(\theta\). Let \(R(x,y)\) be a scalar reward function that evaluates the quality of response \(y\) for prompt \(x\).

The Best-of-N process for a single training iteration can be formalized as follows:

  1. Sample Generation: For a given prompt \(x\), generate \(N\) independent responses \(y_1, \dots, y_N\), where each \(y_k \sim P_{\theta}(y|x)\).
  2. Best Sample Selection: Identify the response \(y^*\) that maximizes the reward function among the \(N\) samples: $$y^* = \arg\max_{y_k \in \{y_1, \dots, y_N\}} R(x, y_k)$$
  3. Supervised Fine-tuning Update: The model parameters \(\theta\) are updated to maximize the log-likelihood of generating \(y^*\) given \(x\). This is typically achieved by minimizing the negative log-likelihood (cross-entropy loss): $$L(\theta) = -\log P_{\theta}(y^*|x)$$ The gradient for this update is: $$\nabla_{\theta} L = -\nabla_{\theta} \log P_{\theta}(y^*|x)$$

This update rule implicitly encourages the model to generate responses that are likely to receive high scores from the reward function. By repeatedly performing this process, the model's policy \(P_{\theta}(y|x)\) is effectively steered towards regions of the response space that correspond to higher rewards, as defined by \(R(x,y)\).

The Implicit Distribution Shift

The core idea is that even if the current model \(P_{\theta}\) has a low probability of generating a very high-quality response, by sampling \(N\) times, we increase the chance of "stumbling upon" a better response. Once found, this superior response \(y^*\) is then explicitly reinforced through supervised fine-tuning. This process can be seen as a form of self-improvement or distillation, where the model learns from an "oracle" (the reward function) applied to its own best outputs.

⚠️ Common Pitfall

The effectiveness of Best-of-N fine-tuning heavily relies on the quality and alignment of the scoring function \(R(x,y)\). If the scoring function is noisy, biased, or poorly correlated with the desired human preferences, the model will learn to optimize for the flaws of the scoring function rather than true quality. Investing in a robust scoring mechanism (whether a good reward model or carefully designed heuristics) is paramount.

Key Takeaways
▼

When to use Rejection Sampling Fine-Tuning:

  • Simplicity: It's a conceptually and practically simpler alternative to complex reinforcement learning (RL) algorithms like PPO, avoiding the need for intricate RL training loops.
  • Direct Optimization: It directly reinforces high-quality outputs by selecting from actual generations, rather than relying on a learned reward model's internal representation.
  • Leveraging Existing Scores: Ideal when you already have a good reward model or a reliable heuristic (e.g., rule-based checks, semantic similarity metrics) that can accurately score text quality.
  • Targeted Improvement: Effective for improving specific aspects of model behavior (e.g., factual accuracy, creativity, safety) if the scoring function is designed to capture these attributes.
  • Iterative Refinement: Can be applied iteratively, allowing the model to continuously learn from increasingly better versions of its own outputs.

When NOT to use / Considerations:

  • Scoring Function Dependency: The entire process hinges on a high-quality, unbiased scoring function. A flawed scorer will lead to the model optimizing for those flaws.
  • Computational Cost: Generating \(N\) samples for every training example can be computationally expensive, especially for large \(N\) or long sequences, impacting training speed and resource usage.
  • Mode Collapse Risk: If the scoring function is too narrow or the model becomes too good at exploiting it, there's a risk of reducing output diversity, leading to "mode collapse" where the model always produces very similar "best" responses.
  • Exploration vs. Exploitation: BoN primarily exploits the best samples found. It might not explore the entire space of potentially good responses as effectively as some RL methods designed for exploration.
  • No Explicit Reward Model Training: If the ultimate goal is to train a generalizable reward model that can be used for other tasks or models, BoN doesn't directly contribute to that.
💡 Big Picture

Rejection sampling fine-tuning offers a powerful and accessible method for aligning large language models with desired quality metrics. By strategically curating training data from its own generations, it efficiently guides the model towards producing more desirable outputs, making it a valuable tool in the LLM fine-tuning toolkit.
