Mish Activation

f(x) = x · tanh(softplus(x)) — a smooth, self-regularized, non-monotonic activation
Intermediate Deep Learning Activation Functions O(1) per element
1
Understanding Mish
▼

What is it? Mish is a smooth, non-monotonic activation function: \(f(x) = x \cdot \tanh(\text{softplus}(x))\), where \(\text{softplus}(x) = \ln(1+e^x)\). Unlike ReLU's hard cutoff at zero, Mish lets small negative signals through, dips slightly below zero, then rises smoothly and unboundedly for positive inputs.

Analogy: ReLU is a light switch — below zero, it's instantly and completely OFF. Mish is a dimmer with a bit of spring resistance: push it slightly negative and it dips a little before settling near zero, rather than snapping off. That small "give" preserves a trickle of gradient that ReLU would kill entirely.

💡 If you remember one thing

Mish self-gates its input through a smooth, bounded function of itself: $$f(x) = x \cdot \tanh(\ln(1+e^x))$$ It is infinitely smooth (\(C^\infty\)), unbounded above, and has a shallow global minimum ≈ -0.31 near \(x \approx -1.19\) — this dip is what makes it non-monotonic and "self-regularized."

2
How Mish Works Internally
▼

The Three-Stage Pipeline

Mish computes its output in three stages, applied elementwise: (1) softplus turns \(x\) into a smooth, always-positive quantity; (2) tanh squashes that into \([0,1)\), producing a smooth "gate"; (3) the original \(x\) is multiplied by its own gate (self-gating), the same trick Swish uses with a different gate shape.

$$x \;\xrightarrow{\text{softplus}}\; s = \ln(1+e^x) \;\xrightarrow{\tanh}\; g = \tanh(s) \in [0,1) \;\xrightarrow{\times x}\; f(x) = x \cdot g$$

Why This Shape Helps Training

Because the gate is never exactly 0, gradients never fully die (unlike ReLU for \(x<0\)). Because softplus grows like \(x\) for large positive \(x\), the gate saturates to 1 and \(f(x) \to x\) — large positive activations are not squashed (unlike sigmoid/tanh directly on \(x\)). For moderately negative \(x\), the gate is small but the product \(x \cdot g\) briefly becomes ​more negative before decaying to 0 — the non-monotonic dip.

Design Decision: tanh(softplus(x)) vs sigmoid(x) (Mish vs Swish)

Swish's gate \(\sigma(\beta x)\) is a plain sigmoid. Mish's gate \(\tanh(\text{softplus}(x))\) is a composition of two smooth functions, producing a gate that saturates differently and yields a deeper non-monotonic dip. The Mish paper shows this produces a smoother output/loss landscape empirically, giving small but consistent accuracy gains over Swish/ReLU in deep CNN backbones such as YOLOv4's CSPDarknet-53 — at the cost of extra compute (exp, log, tanh vs. ReLU's single max).

🔑 Key Property

Mish is \(C^\infty\) smooth (no kinks anywhere), unbounded above (\(f(x)\to x\) as \(x\to\infty\)), and bounded below by \(\approx -0.3113\) at \(x\approx -1.1924\) — this asymmetric boundedness is the "self-regularization."

3
Why It Works — The Math
▼

Derivative via Product Rule

With \(f(x) = x \cdot g(x)\), \(g(x) = \tanh(\text{softplus}(x))\):

$$f'(x) = \tanh(\text{softplus}(x)) + x \cdot \sigma(x) \cdot \operatorname{sech}^2(\text{softplus}(x))$$

using \(\tanh'(s) = \operatorname{sech}^2(s)\) and \(\text{softplus}'(x) = \sigma(x)\) (the sigmoid function).

The Global Minimum

Since \(f(x) \to 0^-\) as \(x \to -\infty\) and \(f(0) = 0\), but \(f\) dips below zero in between, \(f\) cannot be monotonic. Solving \(f'(x)=0\) numerically gives the unique critical point:

$$x^\star \approx -1.19424, \qquad f(x^\star) \approx -0.30884$$
⚠️ Common Misconception

"Mish outputs ≈0 for negative inputs, just like ReLU." False — for moderately negative \(x\) (roughly \(-4 < x < 0\)), Mish outputs a small negative value, dipping to \(\approx -0.31\). This non-monotonic dip is exactly what preserves gradient flow that ReLU would zero out entirely.

Key Takeaways
▼

When to use Mish:

  • Deep CNN backbones for detection/segmentation (e.g. YOLOv4's CSPDarknet-53) where extra compute is affordable
  • You've benchmarked it against ReLU/Swish/GELU on your specific task and it wins

When NOT to use:

  • Latency-critical / edge / mobile inference — prefer ReLU or hardware-friendly h-swish
  • Transformer/LLM architectures — GELU (or SwiGLU) is the standard, validated choice
💡 Family Tree

ReLU (hard cutoff, dies) → Swish/SiLU (smooth self-gate, sigmoid) → Mish (smooth self-gate, tanh∘softplus, deeper non-monotonic dip). All three are self-gated except ReLU; GELU is a separate lineage motivated by stochastic regularization (multiplying x by the Gaussian CDF) and dominates Transformers.

Code Trace
▼
import numpy as np
def softplus_stable(x):
# ln(1+e^x); avoids overflow for large x
return np.where(x > 20, x, np.log1p(np.exp(np.minimum(x, 20))))
def mish(x):
sp = softplus_stable(x) # stage 1: softplus
gate = np.tanh(sp) # stage 2: tanh gate
return x * gate # stage 3: self-gate multiply
def mish_derivative(x):
sp = softplus_stable(x)
tanh_sp = np.tanh(sp)
sigmoid_x = 1.0 / (1.0 + np.exp(-x))
sech2_sp = 1.0 - tanh_sp ** 2
return tanh_sp + x * sigmoid_x * sech2_sp
# Global minimum check
x_star = -1.19424
print(mish(np.array([x_star]))) # -> ~ -0.30884
print(mish_derivative(np.array([x_star]))) # -> ~ 0 (critical point)
