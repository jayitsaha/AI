Understanding VAR
▼

What is it? Vector AutoRegression (VAR) is a statistical model used to capture the linear interdependencies among multiple time series. Unlike a simple AutoRegressive (AR) model that predicts a single variable based on its own past, VAR models each variable in the system as a linear function of its own past values, the past values of all other variables in the system, and an error term.

Analogy: Imagine a small ecosystem where the population of foxes, rabbits, and grass are interdependent. A simple AR model for foxes would only consider past fox populations. A VAR model, however, would say: "Today's fox population depends on yesterday's fox, rabbit, and grass populations. Similarly, today's rabbit population depends on yesterday's fox, rabbit, and grass populations." It explicitly models these dynamic, bidirectional relationships.

💡 If you remember one thing

VAR is essentially a system of Ordinary Least Squares (OLS) regressions, where each variable in the multivariate time series has its own equation. It is a powerful tool for understanding Granger causality (i.e., whether one time series can predict another) and for multivariate forecasting. The core formula for a VAR(p) model is: $$Y_t = c + A_1 Y_{t-1} + \dots + A_p Y_{t-p} + \varepsilon_t$$ where \(Y_t\) is a vector of \(K\) variables at time \(t\), \(c\) is an intercept vector, \(A_j\) are \(K \times K\) coefficient matrices for each lag \(j\), and \(\varepsilon_t\) is a vector of white noise error terms.

2
How VAR Works Internally
▼

The System of Equations

For a system with \(K\) time series variables \(Y_t = [Y_{1,t}, Y_{2,t}, \dots, Y_{K,t}]^\top\), a VAR model of order \(p\) (denoted VAR(p)) consists of \(K\) equations. Each equation models the current value of one variable as a linear combination of its own past \(p\) values and the past \(p\) values of all \(K-1\) other variables in the system.

For example, if \(K=2\) and \(p=1\), the model equations are:

$$Y_{1,t} = c_1 + a_{11}^{(1)} Y_{1,t-1} + a_{12}^{(1)} Y_{2,t-1} + \varepsilon_{1,t}$$ $$Y_{2,t} = c_2 + a_{21}^{(1)} Y_{1,t-1} + a_{22}^{(1)} Y_{2,t-1} + \varepsilon_{2,t}$$

Here, \(a_{ij}^{(l)}\) represents the influence of variable \(j\)'s value at lag \(l\) on variable \(i\)'s current value. These coefficients are collected into \(K \times K\) matrices \(A_l\).

Lag Order (p) and Stationarity

The lag order \(p\) is crucial; it determines how far back in time the model looks. Choosing an appropriate \(p\) typically involves information criteria like AIC or BIC. VAR models generally assume that the underlying time series are stationary (constant mean, variance, and autocorrelation over time). If series are non-stationary, they often need to be differenced (e.g., \(Y_t - Y_{t-1}\)) to achieve stationarity before applying VAR. If series are cointegrated (non-stationary but move together in the long run), a Vector Error Correction Model (VECM) is more appropriate.

Design Decision: Why a System of Regressions?

The brilliance of VAR is its simplicity in estimation. Since the regressors (past values of all variables) are predetermined at time \(t\), each of the \(K\) equations can be estimated independently using standard Ordinary Least Squares (OLS). This makes VAR computationally efficient and robust. While OLS on individual equations is consistent and asymptotically efficient, the full system properties (like the covariance of error terms) are often considered jointly for inference and forecasting.

🔑 Key Property

The coefficient matrices \(A_1, \dots, A_p\) are the heart of the VAR model. Each element \((A_j)_{ik}\) quantifies the directed influence of variable \(k\)'s value at lag \(j\) on variable \(i\)'s current value. For example, a non-zero \((A_1)_{12}\) suggests that \(Y_{2,t-1}\) has a direct impact on \(Y_{1,t}\), even after accounting for \(Y_{1,t-1}\).

3
Why It Works — The Math
▼

The VAR(p) Model Equation

A VAR(p) process for a \(K\)-dimensional time series \(Y_t = [Y_{1,t}, \dots, Y_{K,t}]^\top\) is defined as:

$$Y_t = c + A_1 Y_{t-1} + A_2 Y_{t-2} + \dots + A_p Y_{t-p} + \varepsilon_t$$

where:

  • \(Y_t\) is a \(K \times 1\) vector of observations at time \(t\).
  • \(c\) is a \(K \times 1\) vector of intercepts.
  • \(A_j\) for \(j=1, \dots, p\) are \(K \times K\) matrices of coefficients.
  • \(\varepsilon_t\) is a \(K \times 1\) vector of error terms (white noise, with \(\mathbb{E}[\varepsilon_t] = 0\) and \(\mathbb{E}[\varepsilon_t \varepsilon_t^\top] = \Sigma_\varepsilon\), where \(\Sigma_\varepsilon\) is a positive-definite covariance matrix).

Estimation using OLS

To estimate the coefficients, we can rewrite the system of equations. For each equation \(i \in \{1, \dots, K\}\), we have:

$$Y_{i,t} = c_i + \sum_{j=1}^p \sum_{k=1}^K (A_j)_{ik} Y_{k,t-j} + \varepsilon_{i,t}$$

This is a standard linear regression form. For a sample of \(T\) observations, we stack the lagged variables into a design matrix \(X\). For the \(i\)-th equation, the dependent variable is \(Y_{i,t}\) and the regressors are \(1\) (for the intercept), \(Y_{1,t-1}, \dots, Y_{K,t-1}, Y_{1,t-2}, \dots, Y_{K,t-p}\). The total number of parameters to estimate for each equation is \(1 + pK\). Since there are \(K\) such equations, the total number of parameters in a VAR(p) model is \(K(1 + pK)\).

The OLS estimator for the coefficients of the \(i\)-th equation is:

$$\hat{\beta}_i = (X^\top X)^{-1} X^\top y_i$$

where \(y_i\) is the vector of observations for \(Y_{i,t}\) and \(X\) is the common design matrix of lagged values (and a constant term). The overall coefficient matrices \(A_j\) are then assembled from these individual \(\hat{\beta}_i\) vectors.

➕ Matrix Form for Estimation

The entire system can be estimated simultaneously using multivariate OLS. Define \(Z_t = [1, Y_{t-1}^\top, Y_{t-2}^\top, \dots, Y_{t-p}^\top]^\top\). Then \(Y_t^\top = Z_t^\top B + \varepsilon_t^\top\), where \(B\) is a \((1+pK) \times K\) matrix containing all coefficients. The estimator is \(\hat{B} = (Z^\top Z)^{-1} Z^\top Y\), where \(Z\) and \(Y\) are stacked matrices over time.

⚠️ Too Many Parameters

With \(K(1+pK)\) parameters, VAR models quickly become over-parameterized for large \(K\) or \(p\). For example, a VAR(3) with \(K=10\) variables has \(10(1+3 \times 10) = 310\) parameters. This can lead to unstable estimates and poor out-of-sample forecasts. Techniques like Bayesian VAR (BVAR) or sparse VAR are used to mitigate this.

Key Takeaways
▼

When to use VAR:

  • When you have multiple time series that are theoretically or empirically interdependent (e.g., macroeconomic variables, stock prices, physiological signals).
  • For short to medium-term multivariate forecasting where dynamic interactions are important.
  • To perform Granger causality tests, which assess whether past values of one series help predict another.
  • For Impulse Response Function (IRF) analysis, to understand how a shock to one variable propagates through the system over time.

When NOT to use:

  • If the time series are highly non-stationary and non-cointegrated (differencing might be needed, or consider VECM for cointegrated data).
  • For very high-dimensional systems (large \(K\)), as the number of parameters \(K(1+pK)\) grows quadratically with \(K\), leading to overfitting and unstable estimates. Consider sparse VAR or factor models instead.
  • For very long-term forecasting, as forecast uncertainty grows rapidly, and VAR models tend to revert to the mean or trend.
  • If the primary goal is a deep structural understanding with economic theory-based restrictions (consider Structural VAR, SVAR).
💡 Robust and Flexible

VAR is a workhorse model in econometrics and other fields because of its flexibility and relative ease of estimation. It provides a data-driven way to model complex dynamic relationships without imposing strong theoretical assumptions. For many practical applications, especially short-term forecasting and policy analysis, it remains a powerful and interpretable choice.

Code Trace (Python with NumPy)
▼
import numpy as np
# 1. Generate synthetic data (K=2 variables, T=100 observations)
# Y_t = c + A1*Y_{t-1} + A2*Y_{t-2} + eps_t
np.random.seed(42)
T, K, p = 100, 2, 2
Y = np.zeros((T, K))
c = np.array([0.1, -0.05])
A1 = np.array([[0.5, 0.2], [-0.1, 0.4]])
A2 = np.array([[-0.3, 0.1], [0.05, -0.2]])
for t in range(2, T):
Y[t] = c + A1 @ Y[t-1] + A2 @ Y[t-2] + np.random.normal(0, 0.1, K)
# 2. Prepare data for OLS estimation
# Each equation is Y_i,t = c_i + sum_j(A1_ij * Y_j,t-1) + sum_j(A2_ij * Y_j,t-2) + ...
# For VAR(p), regress Y_t on [1, Y_{t-1}, ..., Y_{t-p}]
y_target = Y[p:] # Y_t from t=p to T-1
# Construct regressor matrix X for all K equations
X_regressors = []
for t in range(p, T):
lagged_values = [1] # Intercept
for lag in range(1, p + 1):
lagged_values.extend(Y[t - lag].tolist())
X_regressors.append(lagged_values)
X_regressors = np.array(X_regressors)
# 3. Estimate coefficients for each variable's equation
estimated_coeffs = np.zeros((1 + p * K, K)) # (intercept + p*K lags) x K variables
for k_idx in range(K):
# Solve for beta_k: y_k = X @ beta_k
beta_k = np.linalg.lstsq(X_regressors, y_target[:, k_idx], rcond=None)[0]
estimated_coeffs[:, k_idx] = beta_k
# Reconstruct c, A1, A2 from estimated_coeffs
est_c = estimated_coeffs[0, :]
est_A1 = estimated_coeffs[1:1+K, :]
est_A2 = estimated_coeffs[1+K:1+2*K, :] # if p=2
print("Estimated Intercept (c):", est_c)
print("Estimated A1:\n", est_A1)
if p > 1: print("Estimated A2:\n", est_A2)
# 4. Forecast future values
def forecast_var(last_Y_hist, c_coeffs, A_matrices, num_forecast_steps):
K = last_Y_hist.shape[1]
p = len(A_matrices)
forecast = np.zeros((num_forecast_steps, K))
current_Y_lags = list(last_Y_hist) # list of past vectors, most recent last
for t in range(num_forecast_steps):
next_Y = c_coeffs
for lag_idx in range(p):
next_Y += A_matrices[lag_idx] @ current_Y_lags[p - 1 - lag_idx]
forecast[t] = next_Y
# Update lags: drop oldest, add newest forecast
current_Y_lags.pop(0)
current_Y_lags.append(next_Y)
return forecast
last_p_hist_values = Y[T-p:] # last p historical vectors
forecast_horizon = 5
forecasted_Y = forecast_var(last_p_hist_values, est_c, [est_A1, est_A2], forecast_horizon)
print("\nForecasted Y for next", forecast_horizon, "steps:\n", forecasted_Y)
