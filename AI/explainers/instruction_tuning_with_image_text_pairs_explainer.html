Visual Instruction Tuning

Teaching a language model to follow instructions about images — with loss masked to response tokens only
Advanced Multimodal LLM Fine-Tuning O(n) masked NLL
1
Understanding Visual Instruction Tuning
▼

What is it? A pretrained language model is very good at continuing text, but it has never seen a picture and doesn't know how to "chat" — it just predicts the next word. Visual instruction tuning is the finishing step that turns a plain language model plus an image encoder into an assistant that can look at a picture, read your question, and answer conversationally. It works by training on thousands of triples: (image, instruction, response) — and, crucially, the model is only graded on how well it predicts the response words, never the image or the question.

Analogy: Imagine handing a brilliant but sheltered novelist a photograph, a question written under it ("what is happening here?"), and a model answer written by an expert. You don't quiz the novelist on the photo or the question — you only check whether their own written answer matches the expert's. Do this thousands of times with diverse photos and questions, and the novelist learns to actually look before answering, even though they were never explicitly "tested" on the picture itself.

💡 If you remember one thing

The training sequence is [image tokens] + [instruction tokens] + [response tokens], but the autoregressive loss only sums over response-token positions: $$\mathcal{L}(\theta) = -\sum_{t \in \text{response}} \log p_\theta(x_t \mid x_{<t})$$ Image and instruction tokens are context the model must attend to, never targets it is scored on.

2
How It Works Internally
▼

Three Modules, One Sequence

A visual-instruction-tuned model (LLaVA-style) is built from three pieces: (1) a frozen vision encoder (e.g. CLIP ViT-L/14) that turns an image into a grid of patch embeddings; (2) a small trainable projection layer \(W\) (a linear map or 2-layer MLP) that maps each visual embedding into the same vector space as the language model's word embeddings; (3) the language model itself, which receives the projected visual tokens concatenated with the tokenized instruction and is asked to generate the response token by token, exactly like ordinary next-token prediction.

Where the Training Data Comes From

You can't just scrape (image, instruction, response) triples from the web — they barely exist. LLaVA's trick: feed text-only GPT-4 a symbolic description of an image (its caption plus object bounding boxes, no pixels) and prompt it to synthesize plausible conversations, detailed descriptions, and multi-step reasoning Q&A as if it could see the picture. This produces ~150K high-quality synthetic instruction-response pairs grounded in real images, without ever needing a human annotator or a vision-language teacher model.

Two Training Stages

Stage 1 — Feature alignment: freeze both the vision encoder and the LLM; train only the projection layer \(W\) on ~595K filtered image-caption pairs. This is a cheap "translation lesson" that teaches \(W\) to speak the LLM's embedding language. Stage 2 — Instruction tuning: keep the vision encoder frozen but unfreeze \(W\) and the LLM; train end-to-end on the (image, instruction, response) triples with the response-masked loss described below. This is the stage that actually teaches conversational, instruction-following behavior.

🔑 Key Property

Even though the loss is computed only on response tokens, gradients still flow backward through causal self-attention into every image and instruction token's representation — and from there into \(W\) and the vision-adjacent layers. Masking the loss target is not the same as blocking the gradient path; it only decides which positions supply an error signal.

3
Why It Works — The Math
▼

The Masked Autoregressive Objective

Let the full input sequence be \(x_1, \dots, x_T\), formed by concatenating projected image tokens, instruction tokens, and response tokens. Define a binary mask \(m_t \in \{0,1\}\), where \(m_t = 1\) iff position \(t\) belongs to the response. The model is trained with standard teacher-forced cross-entropy, but restricted to masked positions:

$$\mathcal{L}(\theta) = -\frac{1}{\sum_t m_t}\sum_{t=1}^{T} m_t \cdot \log p_\theta\big(x_t \mid x_{<t}\big)$$

where \(p_\theta(x_t \mid x_{<t}) = \operatorname{softmax}\big(f_\theta(x_{<t})\big)_{x_t}\) is the probability the causal transformer assigns to the true next token, given every token before it (image tokens included). In implementation, this mask is realized by setting the label at every non-response position to a sentinel ignore_index (commonly \(-100\)), so the cross-entropy loss simply skips those positions.

Gradient Flow Through Masked Positions

Taking the gradient of \(\mathcal{L}\) with respect to parameters \(\theta\):

$$\nabla_\theta \mathcal{L} = -\frac{1}{\sum_t m_t}\sum_{t=1}^{T} m_t \cdot \nabla_\theta \log p_\theta(x_t \mid x_{<t})$$

Because \(p_\theta(x_t \mid x_{<t})\) is itself a function of every earlier token's hidden state (through causal self-attention), the chain rule routes non-zero gradient back into the hidden states — and therefore the parameters — that produced the image and instruction tokens, even though \(m_t = 0\) at those positions. The mask only zeroes out terms in the outer sum, not the internal dependency graph.

⚠️ Common Pitfall

Forgetting to mask the prompt (image + instruction) tokens is a classic bug: the model then wastes capacity trying to "predict" the question it was just given verbatim, which is a trivial, uninformative task that dilutes the gradient signal that should be teaching it to generate good answers. Always verify that labels equal -100 everywhere except the assistant's turn.

5
Key Takeaways
▼

When response-masked instruction tuning helps:

  • You want a base LLM + vision encoder to become a conversational multimodal assistant
  • You have (or can synthesize) diverse (image, instruction, response) data covering description, reasoning, and dialogue
  • You need the model to generalize to instructions and images it never saw verbatim in training

When it can go wrong:

  • Forgetting to mask the prompt — the model wastes gradient "predicting" the question instead of answering it
  • Skipping Stage-1 alignment — an untrained projection layer feeds near-random vectors into the LLM, so Stage-2 gradients mostly relearn alignment instead of instruction-following
  • Synthetic data with GPT-4-generated hallucinated details — the student model inherits any factual errors baked into the teacher-generated responses
💡 Hierarchy

Pretraining (next-token prediction on raw text) → Feature alignment (Stage 1: only \(W\) trained, image-caption pairs) → Visual instruction tuning (Stage 2: \(W\) + LLM trained end-to-end, response-masked loss on (image, instruction, response) triples). Each stage narrows the objective toward the final behavior: a model that looks, reads, and answers.

Code Trace
▼
import torch, torch.nn.functional as F
# Build one training sequence: image + instruction + response
image_tokens = vision_encoder(pixel_values) # (N_img, d_vis)
image_tokens = projector(image_tokens) # (N_img, d_llm) -- trainable W
instr_tokens = tokenizer(instruction) # e.g. "USER: what is the dog doing?"
resp_tokens = tokenizer(response) # e.g. "The dog is running."
input_embeds = concat(image_tokens, instr_tokens, resp_tokens)
IGNORE_INDEX = -100
labels = concat(
full(len(image_tokens), IGNORE_INDEX), # no loss on image tokens
full(len(instr_tokens), IGNORE_INDEX), # no loss on instruction tokens
resp_tokens.input_ids # loss ONLY on response tokens
)
# Forward pass: causal LM over the full multimodal sequence
logits = llm(inputs_embeds=input_embeds).logits # (T, vocab_size)
# Shift for next-token prediction, then masked cross-entropy
shift_logits = logits[:-1, :]
shift_labels = labels[1:]
loss = F.cross_entropy(shift_logits, shift_labels, ignore_index=IGNORE_INDEX)
loss.backward() # gradient reaches W and LLM weights via attention,
# even though image/instruction positions had no target
optimizer.step()
