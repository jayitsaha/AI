Understanding the Concepts

A classifier assigns a label (Positive / Negative) to every input. After running it on a labelled test set, you compare predictions to ground truth and fill a 2×2 confusion matrix. Every metric we care about is just arithmetic on those four numbers.

💡 One-line intuition

Accuracy lies when classes are imbalanced. Precision asks "were my alarms right?", Recall asks "did I catch everything?", and F1 forces a tradeoff. β in Fβ controls how much more you care about recall vs. precision.

2
Every Metric Derived from the Confusion Matrix

Let \(P = \text{TP}+\text{FN}\) be actual positives, \(N = \text{FP}+\text{TN}\) be actual negatives, and \(n = P + N\) total samples.

$$\text{Accuracy} = \frac{\text{TP}+\text{TN}}{n}$$

Fraction of all predictions that are correct. Misleading when \(P \ll N\) (imbalanced).

$$\text{Precision} = \frac{\text{TP}}{\text{TP}+\text{FP}}$$

Of all items flagged positive, what fraction truly is? Penalises false alarms.

$$\text{Recall} = \text{Sensitivity} = \text{TPR} = \frac{\text{TP}}{\text{TP}+\text{FN}} = \frac{\text{TP}}{P}$$

Of all true positives, what fraction did we catch? Penalises missed cases.

$$\text{Specificity} = \text{TNR} = \frac{\text{TN}}{\text{TN}+\text{FP}} = \frac{\text{TN}}{N}$$

Of all true negatives, what fraction did we correctly reject? The "recall of the negative class."

$$F_1 = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2\,\text{TP}}{2\,\text{TP}+\text{FP}+\text{FN}}$$

Harmonic mean of precision and recall. The harmonic mean is chosen because it punishes extreme imbalance between the two: if either is 0, F1 = 0.

$$F_\beta = \frac{(1+\beta^2)\cdot \text{Precision} \cdot \text{Recall}}{\beta^2 \cdot \text{Precision} + \text{Recall}}$$

Generalised harmonic mean where \(\beta\) controls the weighting. \(\beta > 1\) weights recall more (catch everything); \(\beta < 1\) weights precision more (be accurate). \(\beta = 1 \Rightarrow F_1\).

∑ Why the harmonic mean?

The arithmetic mean of precision and recall can be gamed: a classifier that predicts positive for everything gets recall=1 but precision=P/N (poor). The harmonic mean (the reciprocal of the arithmetic mean of reciprocals) equals zero if either term is zero, preventing such degenerate solutions.

$$H(a,b) = \frac{2ab}{a+b} \leq \frac{a+b}{2} = A(a,b)$$
⚠️ Accuracy trap

In cancer screening with 1% prevalence (P=100, N=9900, n=10000): a model that always predicts negative gets Accuracy = 99% but Recall = 0%. Never use accuracy alone on imbalanced data.

From-Scratch Implementation
# All six metrics from the confusion matrix — no sklearn needed
import numpy as np

def confusion_matrix_counts(y_true, y_pred):
    """Returns (TP, FP, FN, TN) from binary arrays."""
    tp = np.sum((y_pred == 1) & (y_true == 1))
    fp = np.sum((y_pred == 1) & (y_true == 0))  # false alarm
    fn = np.sum((y_pred == 0) & (y_true == 1))  # missed positive
    tn = np.sum((y_pred == 0) & (y_true == 0))
    return tp, fp, fn, tn

def classification_metrics(y_true, y_pred, beta=1.0):
    tp, fp, fn, tn = confusion_matrix_counts(y_true, y_pred)
    n = tp + fp + fn + tn

    acc  = (tp + tn) / n if n > 0 else 0
    prec = tp / (tp + fp) if (tp + fp) > 0 else 0  # precision
    rec  = tp / (tp + fn) if (tp + fn) > 0 else 0  # recall = sensitivity
    spec = tn / (tn + fp) if (tn + fp) > 0 else 0  # specificity

    # F1 — harmonic mean of precision and recall
    f1   = (2 * prec * rec) / (prec + rec) if (prec + rec) > 0 else 0

    # Fβ — generalised harmonic mean; β>1 weights recall, β<1 weights precision
    b2   = beta ** 2
    fb   = (1 + b2) * prec * rec / (b2 * prec + rec) if (b2 * prec + rec) > 0 else 0

    return {
        "accuracy": acc, "precision": prec, "recall": rec,
        "specificity": spec, "f1": f1, f"f{beta}": fb,
        "TP": int(tp), "FP": int(fp), "FN": int(fn), "TN": int(tn),
    }

# --- Quick demo ---
np.random.seed(42)
y_true = np.array([1]*60 + [0]*140)         # 60 positives, 140 negatives
y_pred = np.array([1]*50 + [0]*10 + [1]*5 + [0]*135)  # TP=50, FN=10, FP=5, TN=135

m = classification_metrics(y_true, y_pred, beta=2)
for k, v in m.items():
    print(f"  {k:15s}: {v:.4f}" if isinstance(v, float) else f"  {k:15s}: {v}")
Production (sklearn)

When to Use Which Metric
Metric Use when… Avoid when…
Accuracy Classes are balanced; stakeholders need a single number Imbalanced data (diabetes, fraud, cancer screening)
Precision False alarms are costly (spam filter, recommendation) Missing positives is dangerous
Recall / Sensitivity Missing a positive is dangerous (disease detection, fraud) False alarm cost is very high
Specificity / TNR Screening tests where true negatives are critical Positive class is the focus
F1 You need one number balancing P and R; imbalanced classes You specifically care more about one of P or R
Fβ (β≠1) You have a principled β: β=2 for medical, β=0.5 for spam You cannot justify a specific β to stakeholders
🎯 Key Takeaways
  • Every metric reduces to four numbers: TP, FP, FN, TN.
  • Precision↑ and Recall↑ are in tension — as threshold rises one falls and the other rises.
  • F1 is the harmonic mean: it equals zero if either P or R is zero.
  • Fβ lets you encode domain knowledge about the relative cost of false negatives vs. false positives.
  • For imbalanced problems, always report precision, recall, and F1 — never just accuracy.
