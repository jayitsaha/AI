The three pillars of single-variable calculus — foundations for every gradient in ML

1
Understanding the Concepts
▼

Limits — what a function approaches. Imagine driving toward a city. The limit is the city itself — it tells you where you're heading, even if you never quite arrive. Formally, \(\lim_{x \to a} f(x) = L\) means: make \(x\) as close to \(a\) as you like (but not equal), and \(f(x)\) gets as close to \(L\) as you want.

Continuity — no jumps, holes, or explosions. A function is continuous at \(a\) if the limit exists, the function is defined there, and they agree: \(\lim_{x \to a} f(x) = f(a)\). Intuitively, you can draw the graph without lifting your pen.

Differentiability — the function has a well-defined tangent slope. The derivative \(f'(a)\) is the limit of the slope of secant lines as the two points merge into one. If that limit exists, the curve "looks like a straight line" when you zoom in far enough — a property called local linearity.

💡 If you remember one thing

Differentiability implies continuity (a smooth curve has no jumps), but continuity does NOT imply differentiability (think of \(|x|\) at 0: no jump, but the corner means no unique slope). The chain of implications is: differentiable ⇒ continuous ⇒ limit exists. None of the converses hold in general.

2
How Each Concept Works Internally
▼

The ε-δ Definition of a Limit (Precise)

We say \(\lim_{x \to a} f(x) = L\) if and only if:

$$\forall\, \varepsilon > 0,\; \exists\, \delta > 0 \text{ such that } 0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon$$

Translation: You name any desired output tolerance \(\varepsilon\) (how close to \(L\) you want \(f(x)\)), and I can find an input window \(\delta\) (how close to \(a\) to restrict \(x\)) that guarantees it. The condition \(0 < |x-a|\) is critical — it excludes \(x = a\) itself, so the function need not even be defined at \(a\).

Types of Discontinuity

A function fails to be continuous at \(a\) in exactly three qualitatively different ways:

  • Removable — the limit \(L\) exists, but \(f(a) \neq L\) (or \(f(a)\) is undefined). Example: \(\frac{\sin x}{x}\) at \(x=0\). The "hole" can be plugged by redefining \(f(0) = 1\).
  • Jump — the left-hand limit and right-hand limit both exist but differ: \(\lim_{x \to a^-} f(x) \neq \lim_{x \to a^+} f(x)\). Example: the Heaviside step function at \(x=0\). Cannot be fixed by redefining the point.
  • Essential (infinite/oscillatory) — at least one one-sided limit is \(\pm\infty\) or does not exist. Examples: \(1/x\) at \(x=0\) (infinite) and \(\sin(1/x)\) at \(x=0\) (oscillatory). Most severe — no redefinition helps.

The Derivative as a Limit

The derivative of \(f\) at \(a\) is defined as:

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

This is the slope of the secant line through \((a, f(a))\) and \((a+h, f(a+h))\) as \(h \to 0\). If this limit exists (and is finite), \(f\) is differentiable at \(a\). The limit may fail to exist if: (i) there's a corner (|x| at 0: left slope = −1, right slope = +1, limits disagree), (ii) a cusp (infinite slope from one side), or (iii) a discontinuity.

🔑 Local Linearity

A function is differentiable at \(a\) if and only if it is locally linear there: zooming into the graph near \((a, f(a))\) makes it look indistinguishable from a straight line. The slope of that line is \(f'(a)\). This is why the derivative is the fundamental building block of linear approximation and gradient-based optimization.

3
Why It Works — The Math
▼

Proof: Differentiability ⇒ Continuity

Suppose \(f\) is differentiable at \(a\), so \(\lim_{h \to 0} \frac{f(a+h) - f(a)}{h} = f'(a)\) exists. We want to show \(\lim_{h \to 0} f(a+h) = f(a)\), i.e., \(f\) is continuous at \(a\). Write:

$$f(a+h) - f(a) = \frac{f(a+h)-f(a)}{h} \cdot h \xrightarrow{h \to 0} f'(a) \cdot 0 = 0$$

So \(\lim_{h \to 0} f(a+h) = f(a)\). Continuity follows. QED.

Counterexample: Continuous But Not Differentiable

Consider \(f(x) = |x|\) at \(a = 0\). Continuity: \(\lim_{x \to 0} |x| = 0 = f(0)\). ✓ But the derivative:

$$\lim_{h \to 0^+} \frac{|h| - 0}{h} = \lim_{h \to 0^+} \frac{h}{h} = 1, \qquad \lim_{h \to 0^-} \frac{|h| - 0}{h} = \lim_{h \to 0^-} \frac{-h}{h} = -1$$

The one-sided limits disagree, so \(f'(0)\) does not exist. The corner at 0 makes the function non-differentiable despite being continuous everywhere.

The ε-δ Proof for a Linear Function

Claim: \(\lim_{x \to 3} (2x + 1) = 7\). Proof: Given \(\varepsilon > 0\), choose \(\delta = \varepsilon / 2\). Then:

$$0 < |x - 3| < \delta \implies |f(x) - 7| = |2x + 1 - 7| = 2|x - 3| < 2\delta = \varepsilon \quad \checkmark$$
⚠️ Common Misconception

Students often think "the limit is just the function value." This fails for three reasons: (1) the function may not be defined at \(a\), (2) the function may be defined but with \(f(a) \neq L\), or (3) the limit may not exist at all. The ε-δ definition avoids the function value at \(a\) entirely (note \(0 < |x-a|\), not \(|x-a| \geq 0\)).

Numerical Trace: Derivative of x² at x = 2

Using the difference quotient \(\frac{(2+h)^2 - 4}{h} = \frac{4 + 4h + h^2 - 4}{h} = 4 + h\):

$$h = 0.1: \frac{4.41-4}{0.1} = 4.1 \qquad h = 0.01: \frac{4.0401-4}{0.01} = 4.01 \qquad h \to 0: 4$$

So \(f'(2) = 4\), matching the formula \((x^2)' = 2x\) at \(x=2\).

Key Takeaways & ML Connections
▼

Why These Concepts Matter for ML

  • Gradient descent requires differentiable loss functions. Non-differentiable points (like ReLU at 0) are handled with subgradients.
  • Backpropagation is just the chain rule for derivatives applied recursively through a computation graph.
  • Continuity of neural networks — universal approximation theorems require continuous activation functions.
  • Local linearity is the foundation of first-order Taylor approximations, which underlie every gradient-based optimizer.

Implication Hierarchy

$$\text{Differentiable at } a \;\Rightarrow\; \text{Continuous at } a \;\Rightarrow\; \lim_{x \to a} f(x) \text{ exists}$$

None of the reverse implications hold in general. The Weierstrass function is continuous everywhere but differentiable nowhere — a pathological but important example.

💡 Interview Anchor

When asked "why can't we use a step function as an activation in neural networks?", the answer is: it's not differentiable (jump discontinuity at 0), so gradients are zero everywhere except at the discontinuity, making gradient-based learning impossible. ReLU is continuous but not differentiable at 0 — we use the convention \(\text{ReLU}'(0) = 0\) (a subgradient) to make training work.

Code Trace — Numerical Verification
▼
import numpy as np
# ── Limit: lim_{x→0} sin(x)/x = 1 ──
f = lambda x: np.sin(x) / x
xs = [0.1, 0.01, 0.001, 0.0001]
vals = [f(x) for x in xs]
# [0.9983, 0.99998, 0.9999998, 0.999999998] → 1
# ── Derivative via finite difference ──
def numerical_deriv(f, a, h=1e-7):
return (f(a + h) - f(a - h)) / (2 * h) # central diff
g = lambda x: x**2
print(numerical_deriv(g, 2)) # → 4.000000000
# ── Differentiability check via one-sided limits ──
def left_deriv(f, a, h=1e-7): return (f(a) - f(a-h)) / h
def right_deriv(f, a, h=1e-7): return (f(a+h) - f(a)) / h
abs_val = lambda x: abs(x)
print(left_deriv(abs_val, 0)) # → -1.0
print(right_deriv(abs_val, 0)) # → +1.0
# Left ≠ Right → NOT differentiable at 0
# ── ε-δ verification for f(x)=2x+1 at x=3, L=7 ──
def verify_limit(f, a, L, eps):
delta = eps / 2 # works for f(x)=2x+1
xs = np.linspace(a - delta + 1e-10, a + delta - 1e-10, 1000)
xs = xs[xs != a]
return all(abs(f(x) - L) < eps for x in xs)
f_lin = lambda x: 2*x + 1
print(verify_limit(f_lin, 3, 7, 0.1)) # → True
