Explained Variance Score

Regression evaluation: how much of the target's variance do predictions capture?
Intermediate Classical ML · Evaluation O(n) computation
1
Understanding the Concept

What is it? Imagine you're trying to predict house prices. Your predictions will never be perfect — there's always some residual error. The explained variance score measures what fraction of the fluctuations in the true prices your model captures. A score of 1.0 means perfect prediction; 0.0 means your model is no better than just predicting a constant.

Everyday analogy: Think of your model as a weather forecast. The "variance" in actual weather is how wildly temperatures swing day-to-day. Explained variance is: what fraction of that wildness does your forecast successfully track? If the temperature swings a lot and your forecast swings with it in the right direction, you explain much of the variance. If your forecast is always flat (say, "it'll be 20°C every day") you explain almost none of it.

Key Definition

$$\text{EV} = 1 - \frac{\operatorname{Var}(y - \hat{y})}{\operatorname{Var}(y)}$$

where \(\operatorname{Var}(\cdot)\) is the population variance. The numerator is the variance of the residuals; the denominator is the variance of the ground truth.

⚠️ Not the Same as R²

Explained variance equals \(R^2\) only when the residuals have zero mean (i.e., your model is unbiased). If your predictions are systematically off by a constant, EV can be high while R² is lower — EV ignores the mean shift, R² penalises it.

2
The Math — EV vs R² Side by Side

Explained Variance Score

$$\text{EV}(y, \hat{y}) = 1 - \frac{\operatorname{Var}(y - \hat{y})}{\operatorname{Var}(y)} = 1 - \frac{\frac{1}{n}\sum_{i=1}^{n}(e_i - \bar{e})^2}{\frac{1}{n}\sum_{i=1}^{n}(y_i - \bar{y})^2}$$

where \(e_i = y_i - \hat{y}_i\) is the residual and \(\bar{e} = \frac{1}{n}\sum e_i\) is the mean residual.

R² (Coefficient of Determination)

$$R^2(y, \hat{y}) = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2} = 1 - \frac{\text{RSS}}{\text{TSS}}$$

The Key Algebraic Relationship

Using the variance decomposition \(\operatorname{Var}(e) = \frac{1}{n}\sum(e_i - \bar{e})^2\), and RSS \(= \sum e_i^2\), we can write:

$$R^2 = \text{EV} - \frac{\bar{e}^2}{\operatorname{Var}(y)}$$

When \(\bar{e} = 0\) (unbiased residuals), EV \(= R^2\). When \(\bar{e} \neq 0\), \(R^2 < \text{EV}\) — the gap is exactly \(\bar{e}^2 / \operatorname{Var}(y)\).

Numerical Example

Suppose \(y = [1, 2, 3, 4, 5]\), \(\bar{y} = 3\), \(\operatorname{Var}(y) = 2\).

Case A — Unbiased: \(\hat{y} = [1.1, 1.9, 3.1, 3.9, 5.0]\). Residuals \(\approx [-0.1, 0.1, -0.1, 0.1, 0]\), \(\bar{e} \approx 0\). EV \(\approx R^2 \approx 0.997\).

Case B — Biased (+1 shift): \(\hat{y} = [2.1, 2.9, 4.1, 4.9, 6.0]\). Residuals \(= [-1.1, -0.9, -1.1, -0.9, -1.0]\), \(\bar{e} = -1\). EV \(\approx 0.997\) still (residual shape unchanged), but \(R^2 = 0.997 - 1/2 = 0.497\). The gap is \(\bar{e}^2 / \operatorname{Var}(y) = 1/2 = 0.5\).

Practical Insight

If a model produces EV ≈ 1 but R² ≈ 0.5, your predictions track the target's shape perfectly but are systematically shifted. This is a calibration problem, not a pattern-capture problem — the fix is adjusting the intercept, not the model complexity.

Code — From Scratch & sklearn

From Scratch (NumPy)

import numpy as np
def explained_variance_score(y_true, y_pred):
"""EV = 1 - Var(residuals) / Var(y)."""
e = y_true - y_pred # residuals
var_e = np.var(e) # Var(y - ŷ), uses mean(e) internally
var_y = np.var(y_true) # Var(y)
if var_y == 0:
return 1.0 if var_e == 0 else 0.0 # degenerate: constant target
return 1.0 - var_e / var_y
def r2_score(y_true, y_pred):
"""R² = 1 - RSS / TSS."""
ss_res = np.sum((y_true - y_pred)**2) # RSS
ss_tot = np.sum((y_true - np.mean(y_true))**2) # TSS
return 1.0 - ss_res / ss_tot
# Demonstrate the gap with a biased predictor
y = np.array([1., 2., 3., 4., 5.])
y_pred_biased = y + 1.0 # perfect shape, shifted by 1
print(explained_variance_score(y, y_pred_biased)) # → 1.0
print(r2_score(y, y_pred_biased)) # → 0.5

sklearn (Production)

from sklearn.metrics import explained_variance_score, r2_score
import numpy as np
y_true = np.array([3, -0.5, 2, 7])
y_pred = np.array([2.5, 0.0, 2, 8]) # unbiased predictions
y_pred_biased = y_pred + 2.0 # systematic over-prediction
# Unbiased: EV ≈ R²
print(explained_variance_score(y_true, y_pred)) # 0.957
print(r2_score(y_true, y_pred)) # 0.949
# Biased: EV stays high, R² drops
print(explained_variance_score(y_true, y_pred_biased)) # 0.957
print(r2_score(y_true, y_pred_biased)) # -0.621
# ⚠️ Multioutput: 'uniform_average' or 'raw_values' or 'variance_weighted'
Y_true = np.array([[0.5, 1], [-1, 1], [7, -6]])
Y_pred = np.array([[0, 2], [-1, 2], [8, -5]])
print(explained_variance_score(Y_true, Y_pred, multioutput='variance_weighted'))
⚠️ Gotcha

sklearn's explained_variance_score defaults to multioutput='uniform_average', which averages EV across outputs with equal weight. Use 'variance_weighted' when outputs have very different scales.

Key Takeaways
  • EV measures shape, R² measures accuracy. EV asks "does my prediction move with the truth?" R² asks "does my prediction land near the truth?"
  • EV ≥ R² always (equality when \(\bar{e}=0\)). The gap is \(\bar{e}^2 / \operatorname{Var}(y)\).
  • Use EV when systematic bias is acceptable or will be corrected post-hoc (e.g., you're evaluating whether a model's rank-ordering of predictions is correct, not the absolute values).
  • Use R² for end-to-end regression quality — it penalises both variance mis-capture and systematic bias.
  • Related: R², MSE, MAE, Huber loss, calibration.
💡 If you remember one thing

Explained Variance \(= 1 - \operatorname{Var}(y-\hat{y})/\operatorname{Var}(y)\). It equals R² only when residuals are zero-mean — with a constant prediction bias, EV stays high while R² plummets by exactly \(\bar{e}^2/\operatorname{Var}(y)\).
