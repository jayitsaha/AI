Understanding Softmax Regression
▼

What is it? Binary logistic regression answers "yes or no?" — but most real problems have more than two answers: "Is this photo a cat, dog, or bird?" Multinomial logistic regression (also called softmax regression) extends logistic regression to handle any number \(K\) of classes. It computes a score for each class and then converts all scores into probabilities that sum to exactly 1 using the softmax function.

Analogy: Imagine you're a judge scoring 3 Olympic gymnasts. Each gymnast gets a raw score (higher is better). To declare a winner, you don't just pick the highest score — you convert scores into shares of a pie: if gymnast A scored 9, B scored 8, and C scored 6, their softmax probabilities reflect how much better A is than B and C. The model learns the scoring rules automatically from training data.

💡 If you remember one thing

For each class \(k\), compute a linear score \(z_k = \mathbf{w}_k^\top \mathbf{x}\). Convert to probabilities via softmax: $$P(y=k \mid \mathbf{x}) = \frac{\exp(z_k)}{\sum_{j=1}^{K} \exp(z_j)}$$ This gives \(K\) probabilities that are non-negative and sum to 1. The model is trained by minimizing cross-entropy loss.

Prerequisites: Binary logistic regression, gradient descent, probability basics (conditional probability, softmax, cross-entropy).

How It Works Internally
▼

Step 1 — Linear Scoring (one weight vector per class)

The model has \(K\) weight vectors \(\mathbf{w}_1, \ldots, \mathbf{w}_K \in \mathbb{R}^d\) (plus biases). For a given input \(\mathbf{x} \in \mathbb{R}^d\), it computes K logits: \(z_k = \mathbf{w}_k^\top \mathbf{x} + b_k\). These are unbounded real numbers — larger \(z_k\) means the model "leans toward" class \(k\).

Step 2 — Softmax Normalization

The softmax converts the raw logit vector \(\mathbf{z} = [z_1,\ldots,z_K]\) into a valid probability distribution. Subtracting \(\max_k z_k\) before exponentiating is the standard numerical stability trick (log-sum-exp trick): it prevents overflow without changing the output.

$$P(y=k \mid \mathbf{x}) = \frac{e^{z_k - z_{\max}}}{\displaystyle\sum_{j=1}^{K} e^{z_j - z_{\max}}}$$

Step 3 — Decision Boundaries (K−1 hyperplanes)

The model predicts \(\hat{y} = \arg\max_k P(y=k|\mathbf{x})\), which equals \(\arg\max_k z_k\). The decision boundary between class \(j\) and class \(k\) is where \(z_j = z_k\), i.e., \((\mathbf{w}_j - \mathbf{w}_k)^\top \mathbf{x} = 0\) — a linear hyperplane through the origin. With \(K\) classes there are \(\binom{K}{2}\) pairwise boundaries, creating a piecewise-linear partition of the feature space.

Identifiability: The Reference Class

Adding the same vector \(\mathbf{c}\) to every \(\mathbf{w}_k\) leaves all differences \(z_j - z_k\) unchanged, so the softmax probabilities are identical. This means there are infinitely many equivalent weight matrices — the model is not identified without a constraint. The standard fix is to pin one class as reference (set \(\mathbf{w}_K = \mathbf{0}\)), reducing the free parameters from \(Kd\) to \((K-1)d\). This is exactly how sklearn's LogisticRegression with multi_class='multinomial' operates internally.

🔑 Key Property

Softmax regression produces K−1 linear decision boundaries that partition the input space into convex regions — one per class. It is the maximum entropy model subject to the constraint that expected feature values match the training data statistics.

⚠️ Design Decision: Why not K separate binary classifiers?

One-vs-Rest (OvR) trains K independent binary classifiers — their outputs don't sum to 1 and calibration is poor. Softmax regression trains them jointly with a shared constraint (probabilities sum to 1), producing better-calibrated outputs and allowing gradient to flow across all classes simultaneously.

The Math Behind It
▼

Model Parameterization

Let \(\mathbf{x} \in \mathbb{R}^d\), \(K\) classes, weight matrix \(W \in \mathbb{R}^{K \times d}\), bias \(\mathbf{b} \in \mathbb{R}^K\). Logits: \(\mathbf{z} = W\mathbf{x} + \mathbf{b}\).

$$P(y = k \mid \mathbf{x}; W, \mathbf{b}) = \text{softmax}(\mathbf{z})_k = \frac{\exp(z_k)}{\sum_{j=1}^{K} \exp(z_j)}$$

Cross-Entropy Loss (Negative Log-Likelihood)

For a single training example \((\mathbf{x}^{(i)}, y^{(i)})\), the loss is the negative log-probability of the true class:

$$\mathcal{L}_i = -\log P(y=y^{(i)} \mid \mathbf{x}^{(i)}) = -z_{y^{(i)}} + \log\!\sum_{j=1}^{K} e^{z_j}$$

Over a dataset of \(n\) examples (optionally with L2 regularization):

$$\mathcal{L} = \frac{1}{n}\sum_{i=1}^n \mathcal{L}_i + \frac{\lambda}{2}\|W\|_F^2$$

Gradient Derivation

Let \(\hat{p}_k = P(y=k|\mathbf{x})\) and \(\mathbf{1}[y=k]\) the indicator. The gradient of the loss with respect to the logit \(z_k\) is elegantly:

$$\frac{\partial \mathcal{L}}{\partial z_k} = \hat{p}_k - \mathbf{1}[y=k]$$

This means: the gradient is the prediction error for each class — how much the predicted probability exceeds the true label (0 or 1). Back-propagating to weights:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{w}_k} = (\hat{p}_k - \mathbf{1}[y=k])\,\mathbf{x}$$

Numerical Trace (3 classes, 2 features)

Weight matrix \(W\), input \(\mathbf{x} = [2.0,\, 1.5]^\top\), true label \(y=1\):

$$W = \begin{bmatrix}0.5 & -0.3 \\ -0.2 & 0.8 \\ 0.1 & 0.2\end{bmatrix},\quad \mathbf{z} = W\mathbf{x} = \begin{bmatrix}0.55 \\ 0.80 \\ 0.50\end{bmatrix}$$

Softmax (subtracting max=0.80 for stability):

$$e^{[0.55-0.80,\;0.80-0.80,\;0.50-0.80]} = e^{[-0.25,\;0,\;-0.30]} \approx [0.779,\;1.000,\;0.741]$$
$$\hat{\mathbf{p}} = \frac{[0.779,\;1.000,\;0.741]}{2.520} \approx [0.309,\;0.397,\;0.294]$$

Loss: \(-\log(0.397) \approx 0.924\). Gradient on logits: \([0.309,\; 0.397-1,\; 0.294] = [0.309,\; -0.603,\; 0.294]\).

📐 Softmax Jacobian

The full Jacobian of softmax is \(\mathbf{J} = \text{diag}(\hat{\mathbf{p}}) - \hat{\mathbf{p}}\hat{\mathbf{p}}^\top\). Each entry: \(\partial \hat{p}_i/\partial z_j = \hat{p}_i(\delta_{ij} - \hat{p}_j)\). This is used in backprop through non-output layers.

⚠️ Common Mistake

Softmax outputs are not calibrated probabilities out of the box. A model predicting class A with 0.90 may be wrong 30% of the time — calibration (Platt scaling, temperature scaling) is required before trusting these as true probabilities.

From-Scratch Implementation
▼

A complete, numerically stable softmax regression in NumPy — forward pass, loss, gradients, and mini-batch gradient descent.

import numpy as np
def softmax(Z):
"""Numerically stable row-wise softmax. Z: (n, K)"""
Z_shifted = Z - Z.max(axis=1, keepdims=True) # subtract max per row
E = np.exp(Z_shifted)
return E / E.sum(axis=1, keepdims=True)
def cross_entropy_loss(P_hat, y, W, lam=1e-3):
"""P_hat: (n,K) softmax probs; y: (n,) integer class labels"""
n = len(y)
log_probs = -np.log(P_hat[np.arange(n), y] + 1e-12) # NLL for true class
reg = 0.5 * lam * np.sum(W**2) # L2 regularization
return log_probs.mean() + reg
def grad(X, P_hat, y, W, lam=1e-3):
"""Gradient of loss w.r.t. W: shape (K, d)"""
n, K = P_hat.shape
dZ = P_hat.copy() # shape (n, K)
dZ[np.arange(n), y] -= 1 # subtract 1 at true class: (p_k - 1[y=k])
dZ /= n
dW = dZ.T @ X + lam * W # (K, d): sum over examples + regularizer
db = dZ.sum(axis=0) # (K,)
return dW, db
class SoftmaxRegression:
def __init__(self, K, lr=0.1, epochs=200, lam=1e-3):
self.K, self.lr, self.epochs, self.lam = K, lr, epochs, lam
def fit(self, X, y):
n, d = X.shape
self.W = np.zeros((self.K, d)) # (K, d) weight matrix
self.b = np.zeros(self.K) # (K,) bias
for epoch in range(self.epochs):
Z = X @ self.W.T + self.b # (n, K) logits
P = softmax(Z) # (n, K) probabilities
loss = cross_entropy_loss(P, y, self.W, self.lam)
dW, db = grad(X, P, y, self.W, self.lam)
self.W -= self.lr * dW # gradient descent step
self.b -= self.lr * db
def predict_proba(self, X):
return softmax(X @ self.W.T + self.b)
def predict(self, X):
return self.predict_proba(X).argmax(axis=1)

Key Takeaways & When to Use
▼

When to Use Softmax Regression

Use it when: classes are mutually exclusive (an image is exactly one animal), you need calibrated probabilities, the problem is linearly separable in feature space, or you want a fast interpretable baseline before trying neural nets.

When NOT to Use

Avoid when: classes overlap heavily (non-linear boundary needed), labels are multi-label (one example can belong to multiple classes — use sigmoid per class instead), or class imbalance is severe without resampling.

🎯 Decision Rule

Start with softmax regression for any multi-class tabular or linearly-separable problem. If accuracy is insufficient, add feature transformations or switch to gradient-boosted trees / neural nets — but keep softmax as the output layer in neural architectures for mutually exclusive classes.
