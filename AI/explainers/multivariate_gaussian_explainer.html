Understanding the Multivariate Gaussian
▼

What is this? The univariate Gaussian \(\mathcal{N}(\mu, \sigma^2)\) describes a single measurement with a bell-curve distribution. The multivariate Gaussian extends this to d measurements at once — it tells you the probability of observing a vector of values \(\mathbf{x} \in \mathbb{R}^d\). Instead of one mean and one variance, you need a mean vector \(\boldsymbol{\mu}\) (where the cloud is centred) and a covariance matrix \(\boldsymbol{\Sigma}\) (the shape, size and orientation of the cloud).

Real-world analogy: Imagine measuring a person's height and weight. Taller people tend to weigh more — the two measurements are correlated. A 2D Gaussian captures this: the probability cloud is an ellipse tilted along the height-weight correlation direction, not a circle. The covariance matrix encodes both the individual spreads and the tilt. The Mahalanobis distance is then the question "how many standard-deviations away from the average person is this individual, accounting for the correlation?"

💡 If you remember one thing

The iso-density contours of a multivariate Gaussian are ellipses (in 2D) or ellipsoids (in \(d\)D). Their shape and orientation are determined entirely by \(\boldsymbol{\Sigma}\): the eigenvectors give the axes, and the eigenvalues give the squared semi-axis lengths. Points on the same ellipse are equidistant from the mean in Mahalanobis sense: \(D_M(\mathbf{x}) = \sqrt{(\mathbf{x}-\boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x}-\boldsymbol{\mu})}\).

Covariance Matrix & Ellipse Shape
▼

The Covariance Matrix \(\boldsymbol{\Sigma}\)

For a random vector \(\mathbf{x} \in \mathbb{R}^d\), the covariance matrix is defined element-wise as \(\Sigma_{ij} = \mathbb{E}[(x_i - \mu_i)(x_j - \mu_j)]\). Its diagonal entries \(\Sigma_{ii} = \sigma_i^2\) are the individual variances; its off-diagonal entries \(\Sigma_{ij}\) (for \(i \neq j\)) encode how features co-vary. Any valid covariance matrix is symmetric positive semi-definite (SPSD).

How \(\boldsymbol{\Sigma}\) shapes the ellipse

Because \(\boldsymbol{\Sigma}\) is real symmetric, it has an eigendecomposition \(\boldsymbol{\Sigma} = V \Lambda V^\top\) where \(V = [\mathbf{v}_1 \cdots \mathbf{v}_d]\) are orthonormal eigenvectors and \(\Lambda = \operatorname{diag}(\lambda_1, \ldots, \lambda_d)\) holds the (non-negative) eigenvalues. The geometry is direct:

  • Each eigenvector \(\mathbf{v}_k\) is an axis direction of the ellipse.
  • The corresponding semi-axis length at the \(c\)-standard-deviation level is \(c\sqrt{\lambda_k}\).
  • Large \(\lambda_k\) → long axis (high variance in that direction). Small \(\lambda_k\) → short axis.
$$\boldsymbol{\Sigma} = V \Lambda V^\top = \sum_{k=1}^d \lambda_k \,\mathbf{v}_k \mathbf{v}_k^\top$$

🔑 Key Property

A covariance matrix \(\boldsymbol{\Sigma}\) is valid if and only if it is symmetric positive semi-definite (SPSD): all eigenvalues \(\lambda_k \geq 0\). For the Gaussian PDF to be non-degenerate (i.e., the distribution doesn't collapse to a lower-dimensional subspace), we need strict positive definiteness: all \(\lambda_k > 0\), which guarantees \(\boldsymbol{\Sigma}^{-1}\) exists.

Mahalanobis Distance — The Right Metric
▼

The Problem with Euclidean Distance

Euclidean distance \(\|\mathbf{x} - \boldsymbol{\mu}\|_2\) treats every direction equally. But if one feature has very high variance, a large displacement in that direction is expected and should be penalised less. Conversely, a small displacement in a low-variance direction is surprising and should count more. Euclidean distance is blind to this structure.

$$D_E(\mathbf{x}) = \sqrt{(\mathbf{x}-\boldsymbol{\mu})^\top I\, (\mathbf{x}-\boldsymbol{\mu})} = \|\mathbf{x}-\boldsymbol{\mu}\|_2$$

Mahalanobis Distance

Replace the identity with \(\boldsymbol{\Sigma}^{-1}\): weight each direction by the inverse of its variance. Points at Mahalanobis distance \(c\) lie exactly on the \(c\)-sigma iso-density ellipse.

$$D_M(\mathbf{x}) = \sqrt{(\mathbf{x}-\boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x}-\boldsymbol{\mu})}$$

Numerical Trace (concrete example)

Let \(\boldsymbol{\mu} = \mathbf{0}\), \(\boldsymbol{\Sigma} = \begin{bmatrix} 2 & 1.2 \\ 1.2 & 1 \end{bmatrix}\), and point \(\mathbf{x} = (2, 1.5)\).

  1. Compute \(\mathbf{d} = \mathbf{x} - \boldsymbol{\mu} = (2,\, 1.5)\)
  2. Invert: \(\boldsymbol{\Sigma}^{-1} = \frac{1}{2\cdot1 - 1.2^2}\begin{bmatrix}1 & -1.2\\-1.2 & 2\end{bmatrix} = \begin{bmatrix}1.786 & -2.143\\-2.143 & 3.571\end{bmatrix}\)
  3. Multiply: \(\boldsymbol{\Sigma}^{-1}\mathbf{d} = (0.357,\, 1.071)\)
  4. Inner product: \(\mathbf{d}^\top(\boldsymbol{\Sigma}^{-1}\mathbf{d}) = 2(0.357) + 1.5(1.071) = 2.321\)
  5. \(D_M = \sqrt{2.321} \approx 1.524\) vs Euclidean \(\|\mathbf{d}\| = \sqrt{4+2.25} = 2.500\)

Geometric Intuition: Whitening

Mahalanobis distance is exactly the Euclidean distance after whitening: applying the linear transform \(W = \boldsymbol{\Sigma}^{-1/2}\) to the data. Whitening rotates and rescales the axes so that the Gaussian becomes a unit spherical Gaussian — all directions have equal variance and zero covariance. In whitened coordinates, the iso-density ellipses become circles and Mahalanobis = Euclidean.

$$D_M(\mathbf{x}) = \|W(\mathbf{x}-\boldsymbol{\mu})\|_2, \quad W = \boldsymbol{\Sigma}^{-1/2}$$
⚠️ Common Misconception

Point B = (1, 4) with \(\mu=(1,2)\) has Euclidean distance 2 from the mean — same as Point A = (3, 3). But with the correlated \(\boldsymbol{\Sigma}\) above, Point B's Mahalanobis distance is 3.78 while A's is only 1.46. The displacement (0, 2) — perpendicular to the high-variance direction — is actually very unusual for this distribution, even though it looks closer in raw space.

From-Scratch Implementation
▼

From Scratch (NumPy)

import numpy as np
def mvn_pdf(x, mu, Sigma):
"""Multivariate Gaussian PDF. x: (d,) or (n,d), mu: (d,), Sigma: (d,d)."""
d = len(mu)
diff = x - mu # (d,) or (n,d)
Sigma_inv = np.linalg.inv(Sigma) # (d,d)
sign, log_det = np.linalg.slogdet(Sigma) # numerically stable log-det
if x.ndim == 1:
maha_sq = diff @ Sigma_inv @ diff # scalar
else:
# Efficient batch: (n,d) @ (d,d) @ (d,n) → take diagonal
maha_sq = np.einsum('ni,ij,nj->n', diff, Sigma_inv, diff)
log_norm = -0.5 * (d * np.log(2*np.pi) + log_det)
return np.exp(log_norm - 0.5 * maha_sq) # exp for numerical stability
def mahalanobis(x, mu, Sigma):
"""Mahalanobis distance from point x to distribution (mu, Sigma)."""
diff = x - mu
Sigma_inv = np.linalg.inv(Sigma)
return np.sqrt(diff @ Sigma_inv @ diff)
def whiten(X, mu, Sigma):
"""Apply whitening transform: z = Sigma^{-1/2}(x - mu)."""
vals, vecs = np.linalg.eigh(Sigma) # eigh: symmetric, guaranteed real
W = (vecs / np.sqrt(vals)) @ vecs.T # W = V D^{-1/2} V^T = Sigma^{-1/2}
return (X - mu) @ W.T # whitened data
# ── Example ──────────────────────────────────────────────────────────────
mu = np.array([1.0, 2.0])
Sigma = np.array([[2.0, 1.2], [1.2, 1.0]])
x = np.array([3.0, 3.0])
print(f"PDF at x: {mvn_pdf(x, mu, Sigma):.6f}")
print(f"Mahalanobis: {mahalanobis(x, mu, Sigma):.4f}") # 1.4639
print(f"Euclidean: {np.linalg.norm(x - mu):.4f}") # 2.2361

Production Usage (SciPy)

from scipy.stats import multivariate_normal
from scipy.spatial.distance import mahalanobis as scipy_maha
import numpy as np
mu = np.array([1.0, 2.0])
Sigma = np.array([[2.0, 1.2], [1.2, 1.0]])
x = np.array([3.0, 3.0])
# PDF evaluation
rv = multivariate_normal(mean=mu, cov=Sigma)
pdf = rv.pdf(x) # scalar
log_pdf = rv.logpdf(x) # log-scale (more numerically stable)
# Sampling
samples = rv.rvs(size=1000, random_state=42) # (1000, 2)
# Mahalanobis via scipy (uses inverse covariance = precision matrix)
VI = np.linalg.inv(Sigma) # precision matrix
d = scipy_maha(x, mu, VI) # 1.4639
# ⚠️ Gotcha: scipy.spatial.distance.mahalanobis takes the INVERSE cov (VI),
# not Sigma itself. Passing Sigma directly gives wrong results!

When to use the Multivariate Gaussian

  • Anomaly detection — Flag points with large Mahalanobis distance.
  • Gaussian Mixture Models (GMM) — Each cluster is a multivariate Gaussian.
  • Linear Discriminant Analysis (LDA) — Shared Gaussian per class.
  • Kalman filters — State belief is a Gaussian; covariance tracks uncertainty.
  • Gaussian Processes — GP prior is an infinite-dimensional Gaussian; finite evaluations are jointly Gaussian.
  • PCA initialisation & whitening — Eigendecompose Σ̂, whiten before feeding downstream models.
