Understanding Matrix Rank
▼

What is it? The rank of a matrix tells you how many truly independent directions of information it contains. When you have a set of equations (or a data table), some rows or columns might be redundant — just copies or combinations of others. Rank counts only the genuinely unique ones.

Real-world analogy: Imagine a class of 30 students and their answers to 5 questions. If question 3 is always the same as question 1, and question 5 is always question 2 doubled, then despite having 5 columns of answers, you only really have 3 independent sources of information. The rank of the answer matrix is 3 — not 5.

Why it matters for ML: Rank determines whether a system of equations \(Ax = b\) has a unique solution (rank = number of unknowns), infinitely many solutions (rank is less), or no solution. It also directly limits how expressive a linear model can be — a low-rank matrix cannot span the full output space.

💡 If you remember one thing

The rank of an \(m \times n\) matrix \(A\) equals the number of pivots in its row echelon form. Crucially, row rank always equals column rank, and they are constrained by: $$\operatorname{rank}(A) + \operatorname{nullity}(A) = n$$ where \(n\) is the number of columns.

How Rank Is Computed — Row Reduction
▼

Gaussian Elimination to Row Echelon Form (REF)

The standard algorithm: apply row operations (swap rows, multiply a row by a non-zero scalar, add a multiple of one row to another) to bring the matrix into REF. A pivot is the first non-zero entry in each row. Count the pivots — that is the rank.

Row operations do not change the row space (the set of all linear combinations of rows). So the number of non-zero rows in REF equals the number of linearly independent rows in the original matrix.

🔑 Key Property: Row Rank = Column Rank

For any matrix \(A \in \mathbb{R}^{m \times n}\), the dimension of the row space equals the dimension of the column space: $$\dim(\operatorname{Row}(A)) = \dim(\operatorname{Col}(A)) = \operatorname{rank}(A)$$ This is not obvious — rows and columns live in completely different vector spaces! The proof follows from the pivot structure of REF.

Why Row Rank = Column Rank

Intuitively: Gaussian elimination to REF reveals \(r\) pivot columns in the original matrix (column rank = \(r\)) and \(r\) non-zero rows (row rank = \(r\)). The pivot rows are linearly independent; the non-pivot rows are zero in REF, meaning they were linear combinations of earlier rows. The same \(r\) is discovered both ways.

The Null Space and Rank-Nullity

The null space (or kernel) of \(A\) is \(\ker(A) = \{x \in \mathbb{R}^n : Ax = 0\}\). Its dimension is the nullity. The non-pivot columns in REF indicate free variables — one free variable per dimension of the null space. Since every column is either a pivot column or a free column: $$\underbrace{\operatorname{rank}(A)}_{\text{pivot cols}} + \underbrace{\operatorname{nullity}(A)}_{\text{free cols}} = n \quad \text{(Rank-Nullity Theorem)}$$

⚠️ Common Pitfall

The rank-nullity theorem counts columns (domain dimension). For the row space and left null space: \(\operatorname{rank}(A) + \operatorname{dim}(\operatorname{Left Null}(A)) = m\). The four fundamental subspaces of \(A\) are: column space \(\subseteq \mathbb{R}^m\), left null space \(\subseteq \mathbb{R}^m\), row space \(\subseteq \mathbb{R}^n\), null space \(\subseteq \mathbb{R}^n\).

3
Why It Works — The Math
▼

Formal Definitions

Let \(A \in \mathbb{R}^{m \times n}\). Define:

$$\operatorname{Col}(A) = \{Ax : x \in \mathbb{R}^n\} \subseteq \mathbb{R}^m \quad \text{(column space / image)}$$
$$\operatorname{Row}(A) = \operatorname{Col}(A^\top) \subseteq \mathbb{R}^n \quad \text{(row space)}$$
$$\ker(A) = \{x \in \mathbb{R}^n : Ax = 0\} \subseteq \mathbb{R}^n \quad \text{(null space)}$$
$$\operatorname{rank}(A) = \dim(\operatorname{Col}(A)) = \dim(\operatorname{Row}(A))$$

Proof of Rank-Nullity Theorem

Let \(r = \operatorname{rank}(A)\), so \(A\) has \(r\) pivot columns and \(n - r\) free columns in REF. For each free column \(j\), there is a null-space vector \(v_j\) with 1 in position \(j\), values determined by the pivot rows, and 0 in other free positions. These \(n - r\) vectors are linearly independent and span \(\ker(A)\), so \(\operatorname{nullity}(A) = n - r\), giving:

$$\operatorname{rank}(A) + \operatorname{nullity}(A) = r + (n - r) = n \quad \blacksquare$$

Proof that Row Rank = Column Rank

Let \(c = \operatorname{col\,rank}(A)\) (dimension of column space). The column space is spanned by \(c\) independent vectors in \(\mathbb{R}^m\). Consider the restriction \(A: \mathbb{R}^n \to \operatorname{Col}(A)\). By rank-nullity applied to this map: \(n = c + \operatorname{nullity}(A)\). Now apply the same to \(A^\top \in \mathbb{R}^{n \times m}\): its column rank is the row rank of \(A\), call it \(r\). Then \(m = r + \operatorname{nullity}(A^\top)\). The pivot structure of REF shows both \(r\) and \(c\) count the same pivots, hence \(r = c\).

📐 Key Bounds

For \(A \in \mathbb{R}^{m \times n}\): \(\operatorname{rank}(A) \leq \min(m, n)\). A matrix is full rank if \(\operatorname{rank}(A) = \min(m, n)\). For square \(n \times n\) matrices: full rank \(\Leftrightarrow\) invertible \(\Leftrightarrow\) \(\det(A) \neq 0\) \(\Leftrightarrow\) \(\ker(A) = \{0\}\).

Rank Under Operations

Key identities useful in practice:

$$\operatorname{rank}(AB) \leq \min(\operatorname{rank}(A), \operatorname{rank}(B))$$
$$\operatorname{rank}(A + B) \leq \operatorname{rank}(A) + \operatorname{rank}(B) \quad \text{(subadditivity)}$$
$$\operatorname{rank}(A) = \operatorname{rank}(A^\top) = \operatorname{rank}(A^\top A) = \operatorname{rank}(AA^\top)$$

Key Takeaways & Applications
▼

When Rank Matters in ML

  • Linear regression: The design matrix \(X^\top X\) must be full rank for a unique OLS solution. Low-rank (multicollinearity) → singular or ill-conditioned gram matrix.
  • PCA: The number of non-zero eigenvalues of the covariance matrix equals its rank — this is the true intrinsic dimensionality of the data.
  • Low-rank approximations (SVD): \(A \approx U_r \Sigma_r V_r^\top\) compresses a matrix to rank \(r\), used in recommendation systems, LoRA fine-tuning, and matrix factorization.
  • Neural networks: Weight matrices with low rank have limited expressive power. LoRA explicitly parameterizes updates as low-rank matrices to save parameters.

Rank-Deficiency Diagnostics

  • If \(\operatorname{rank}(A) < n\), then \(Ax = b\) has infinitely many solutions (if consistent) or no solution (if inconsistent)
  • If \(\operatorname{rank}(A) < m\), the map \(A: \mathbb{R}^n \to \mathbb{R}^m\) is not surjective — not every target is reachable
  • Numerically, use the count of singular values above a threshold \(\varepsilon\) rather than exact REF (SVD-based rank is more stable)
💡 The Four Fundamental Subspaces

Every matrix \(A \in \mathbb{R}^{m \times n}\) with rank \(r\) determines four orthogonal subspaces: column space \(\dim = r\), null space \(\dim = n-r\), row space \(\dim = r\), left null space \(\dim = m-r\). The column space and left null space are orthogonal complements in \(\mathbb{R}^m\); the row space and null space are orthogonal complements in \(\mathbb{R}^n\).

Code Trace — Computing Rank
▼
import numpy as np
# Our 4x5 matrix (rank 3)
A = np.array([[1, 2, 0, 1, 3],
[2, 4, 1, 3, 7],
[0, 0, 1, 1, 1],
[1, 2, 2, 3, 5]])
# Method 1: numpy (SVD-based, numerically stable)
r = np.linalg.matrix_rank(A)
print(f"rank(A) = {r}") # 3
# Method 2: count non-zero singular values
_, s, _ = np.linalg.svd(A)
tol = 1e-10 * max(A.shape) * s[0] # relative tolerance
r_svd = int(np.sum(s > tol))
print(f"rank via SVD = {r_svd}") # 3
# Null space basis (nullity = n - rank = 5 - 3 = 2)
U, s, Vt = np.linalg.svd(A)
null_space = Vt[r:].T # last (n-r) rows of Vt, transposed
print(f"null space shape: {null_space.shape}") # (5, 2)
print(f"||A @ null_space||: {np.linalg.norm(A @ null_space):.2e}") # ~0
# Rank-nullity check
nullity = null_space.shape[1]
n = A.shape[1]
print(f"rank + nullity = {r} + {nullity} = {r + nullity} = n = {n}") # 3+2=5
