Multi-class Averaging: Macro, Micro & Weighted

How precision, recall, and F1 generalise beyond binary classification — and how the choice of average changes your story
Intermediate Classical ML Evaluation F1 · Precision · Recall
1
Understanding the Concept
▼

Imagine you're a doctor diagnosing three diseases: common cold (10 000 patients), flu (500 patients), and a rare autoimmune disorder (50 patients). Your model gets the cold almost perfect but ignores the autoimmune disorder entirely. Should the overall score be great (because accuracy is 99%) or poor (because the rarest disease is never caught)?

Macro, micro, and weighted averaging are three answers to that question — each with a different opinion about which classes matter most.

Key Concept

Macro: Average the per-class metric unweighted — every class counts equally regardless of how many samples it has. Minority classes pull the score as much as majority classes.

Micro: Pool all true positives, false positives, and false negatives across every class first, then compute the metric from those totals. Dominated by whichever classes have the most samples.

Weighted: Like macro, but each class's metric is multiplied by its support (number of true instances) before averaging. A middle ground that respects size yet still separates per-class contributions.

Analogy

Think of three polling booths: one with 1 000 voters, one with 100, one with 10. Macro treats all three booths identically — each booth's result contributes one-third. Micro pools all 1 110 votes and counts. Weighted gives each booth influence proportional to its voter count.

If You Remember One Thing

When classes are imbalanced, macro can be optimistic about a model that ignores minority classes (it penalises them), micro can be optimistic about a model that nails majority classes (it rewards them), and weighted lies in between. No single average is universally correct — choose based on what you care about.

2
How It Works — The Formulas
▼

For a \(K\)-class problem, let class \(k\) have:

  • \(\text{TP}_k\) — true positives for class \(k\)
  • \(\text{FP}_k\) — false positives (predicted \(k\), actually something else)
  • \(\text{FN}_k\) — false negatives (actually \(k\), predicted something else)
  • \(n_k = \text{TP}_k + \text{FN}_k\) — support (total real instances of class \(k\))

Per-class precision & recall

$$P_k = \frac{\text{TP}_k}{\text{TP}_k + \text{FP}_k} \qquad R_k = \frac{\text{TP}_k}{\text{TP}_k + \text{FN}_k} \qquad F_k = \frac{2 P_k R_k}{P_k + R_k}$$

Macro Averaging — equal weight per class

$$F_{\text{macro}} = \frac{1}{K}\sum_{k=1}^{K} F_k$$
Caution

Macro average of F1 is not the same as computing F1 from macro-averaged precision and macro-averaged recall. The former is standard (sklearn default); the latter gives a different number. Always average the final metric, not the inputs.

Micro Averaging — pool all TP/FP/FN first

$$P_{\text{micro}} = \frac{\sum_k \text{TP}_k}{\sum_k (\text{TP}_k + \text{FP}_k)} \qquad R_{\text{micro}} = \frac{\sum_k \text{TP}_k}{\sum_k (\text{TP}_k + \text{FN}_k)}$$
$$F_{\text{micro}} = \frac{2\,P_{\text{micro}}\,R_{\text{micro}}}{P_{\text{micro}} + R_{\text{micro}}}$$
Key Property

For multi-class (non-multi-label) classification where every sample belongs to exactly one class: \(\sum_k \text{FP}_k = \sum_k \text{FN}_k\), so \(P_{\text{micro}} = R_{\text{micro}} = F_{\text{micro}} = \text{accuracy}\). The micro-F1 collapses to accuracy in this setting.

Weighted Averaging — weight by support

$$F_{\text{weighted}} = \frac{\sum_{k=1}^{K} n_k \cdot F_k}{\sum_{k=1}^{K} n_k} = \frac{\sum_{k=1}^{K} n_k \cdot F_k}{N}$$

where \(N = \sum_k n_k\) is the total number of samples.

Insight

Weighted F1 is a proper weighted mean of per-class F1 scores. Unlike micro, it still computes each class's precision and recall separately before combining — so it can detect a model that ignores a class even if that class is large.

Worked Numerical Example
▼

Consider a 3-class imbalanced dataset: Cat (900 samples), Dog (80 samples), Rabbit (20 samples). Total = 1 000.

Suppose the classifier produces this confusion matrix (rows = actual, columns = predicted):

Pred CatPred DogPred Rabbit
Act Cat8504010
Act Dog205010
Act Rabbit1532

Step 1 — derive TP, FP, FN per class

ClassTPFPFNSupportPrecisionRecallF1
Cat 8503550900 850/885 = 0.960 850/900 = 0.944 0.952
Dog 50433080 50/93 = 0.538 50/80 = 0.625 0.578
Rabbit 2201820 2/22 = 0.091 2/20 = 0.100 0.095

FP(Cat) = 20+15=35; FP(Dog) = 40+3=43; FP(Rabbit) = 10+10=20. FN(Cat) = 40+10=50; FN(Dog) = 20+10=30; FN(Rabbit) = 15+3=18.

Step 2 — compute each average

$$F_{\text{macro}} = \frac{0.952 + 0.578 + 0.095}{3} = \frac{1.625}{3} \approx \mathbf{0.542}$$
$$\Sigma\text{TP}=902,\;\Sigma(\text{TP}+\text{FP})=1000,\;\Sigma(\text{TP}+\text{FN})=1000 \implies F_{\text{micro}} = \frac{2 \cdot 0.902 \cdot 0.902}{2 \cdot 0.902} = \mathbf{0.902}$$
$$F_{\text{weighted}} = \frac{900 \times 0.952 + 80 \times 0.578 + 20 \times 0.095}{1000} = \frac{856.8 + 46.24 + 1.9}{1000} = \frac{904.94}{1000} \approx \mathbf{0.905}$$
Key Observation — Divergence Under Imbalance

The same model scores 0.542 macro, 0.902 micro, and 0.905 weighted. Macro exposes the catastrophic failure on Rabbit (F1=0.095). Micro and weighted are dominated by Cat's good performance. A stakeholder who cares about rare animals must use macro or per-class F1 — never micro.

Key Takeaways & Interview Compass
▼
Three facts that matter in interviews

1. Micro-F1 = accuracy for single-label multi-class classification (all TP/FP/FN pool to the same total). Memorise this.

2. Macro-F1 is sensitive to class imbalance — it equally weights a class with 10 samples and one with 10 000, so a poor minority class immediately tanks the score.

3. Weighted-F1 can be inflated when majority classes score well even if minority classes are completely missed — always report macro alongside weighted for imbalanced data.

sklearn Usage

from sklearn.metrics import f1_score
f1_score(y_true, y_pred, average='macro')
f1_score(y_true, y_pred, average='micro')
f1_score(y_true, y_pred, average='weighted')
f1_score(y_true, y_pred, average=None) # per-class array
