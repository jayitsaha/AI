1
Understanding Graph Isomorphism & WL
▼

What is it? Two graphs are isomorphic if you can rename the nodes of one so it becomes identical to the other — same edges, different labels. The question "are these two graphs the same shape?" turns out to be surprisingly hard for computers. The Weisfeiler-Leman (WL) test is an efficient color-refinement algorithm that can often tell graphs apart, and has become the theoretical yardstick for measuring the power of Graph Neural Networks (GNNs).

Analogy: Imagine two social networks printed on different sheets of paper with scrambled usernames. Are they the same network? One approach: give every person a rank based on how many friends they have, then update the rank based on friends' ranks, and repeat. If at any point the rank-distributions differ, the networks must be different. This is exactly what WL does with "colors" instead of ranks. The catch: two genuinely different networks can fool this test if they always produce the same rank-distribution.

💡 If you remember one thing

The 1-WL test assigns colors by iteratively hashing each node's own color together with the multiset of its neighbors' colors. Message-passing GNNs (like GCN, GraphSAGE, GAT) are at most as powerful as 1-WL: they cannot distinguish any pair of graphs that 1-WL cannot. The Graph Isomorphism Network (GIN) by Xu et al. (2019) achieves exactly 1-WL power.

Prerequisites

Graph basics (nodes, edges, adjacency matrix), multisets, hash functions, and familiarity with message-passing neural networks will help. Graph isomorphism is formally in the complexity class GI — neither known to be in P nor NP-complete.

2
The 1-WL Color Refinement Algorithm
▼

The Algorithm (1-WL / Naive Vertex Classification)

Given a graph \(G = (V, E)\), the 1-WL test proceeds as follows:

  1. Initialization: Assign every node \(v\) the same initial color \(c^{(0)}(v) = 0\).
  2. Refinement (round \(t\)): For each node \(v\), compute a new color by hashing its current color together with the sorted multiset of its neighbors' colors:
    $$c^{(t+1)}(v) = \operatorname{HASH}\!\bigl(c^{(t)}(v),\; \{\!\{ c^{(t)}(u) : u \in \mathcal{N}(v) \}\!\}\bigr)$$
  3. Termination: Repeat until the color partition stabilizes (same partition in two consecutive rounds).
  4. Test: Compare the multiset of final colors. If they differ, the graphs are non-isomorphic. If they match, the test is inconclusive (graphs may or may not be isomorphic).
🔑 Key Property — Soundness but not Completeness

1-WL is a necessary condition for isomorphism, not sufficient. If 1-WL says "different" → graphs are definitely non-isomorphic. If 1-WL says "same" → we cannot conclude they are isomorphic. Counterexamples exist (e.g., C₆ vs 2×C₃).

Numerical Trace — Distinguishing C₃ from P₃

Graph G₁: triangle C₃ (nodes 0,1,2; edges 0–1, 1–2, 2–0). Graph G₂: path P₃ (nodes a,b,c; edges a–b, b–c).

Round 0: All nodes get color 0. Multisets: G₁ = {0,0,0}, G₂ = {0,0,0} — same so far.

Round 1 — G₁ (triangle): Node 0 has neighbors {1,2}, both color 0. Signature = (0, [0,0]). All nodes identical → new color A. Multiset: {A,A,A}.

Round 1 — G₂ (path): Node b has neighbors {a,c}, both color 0. Signature = (0, [0,0]) → new color A. Nodes a and c each have one neighbor. Signature = (0, [0]) → new color B. Multiset: {B,A,B}.

{A,A,A} ≠ {A,B,B} → DISTINGUISHED in round 1. G₁ and G₂ are non-isomorphic.

⚠️ Multiset vs Set

The \(\{\!\{\cdot\}\!\}\) notation denotes a multiset — order doesn't matter but multiplicities do. Using a set instead loses information: a node with two red neighbors and a node with one red + one blue would both reduce to {red, blue} under a set hash. WL must use sorted multisets (equivalently, sort then hash) for correctness.

3
GNNs are Bounded by 1-WL (Xu et al., GIN)
▼

Message-Passing GNNs as WL Instances

A message-passing GNN updates node representations by aggregating neighbor features:

$$h_v^{(k)} = \phi\!\left(h_v^{(k-1)},\; \operatorname{AGG}\!\bigl(\{\!\{ h_u^{(k-1)} : u \in \mathcal{N}(v)\}\!\}\bigr)\right)$$

This is structurally identical to WL color refinement — replace discrete colors with continuous vectors and HASH with a learnable \(\phi\) + AGG. Therefore, any two graphs that WL assigns the same color histogram will receive the same GNN embedding, no matter how deep the GNN or how large its hidden dimension.

The GIN Result (Xu et al., ICLR 2019)

Xu et al. proved two complementary theorems:

  1. Upper bound: Any message-passing GNN is at most as powerful as 1-WL in distinguishing graphs.
  2. Achievability: If the AGG and COMBINE functions are injective over multisets, the GNN is exactly as powerful as 1-WL.

The injective aggregator for multisets is achieved by the Graph Isomorphism Network (GIN):

$$h_v^{(k)} = \operatorname{MLP}^{(k)}\!\left((1 + \varepsilon^{(k)})\cdot h_v^{(k-1)} + \sum_{u \in \mathcal{N}(v)} h_u^{(k-1)}\right)$$

The key insight: sum aggregation (not mean or max) preserves multiset information. Mean aggregation collapses nodes with the same ratio of neighbor types; max aggregation ignores multiplicity entirely.

🚫 GCN and GraphSAGE are Strictly Weaker than 1-WL

GCN uses mean pooling (normalized sum), which loses multiplicity. GraphSAGE with max-pooling loses both order and multiplicity. Both are strictly less expressive than 1-WL. GIN with sum pooling is the minimal architecture that matches 1-WL power.

What Lies Beyond 1-WL?

Higher-order WL tests (\(k\)-WL) operate on \(k\)-tuples of nodes and are strictly more powerful. Specifically, 2-WL \(\subsetneq\) 3-WL \(\subsetneq\) \(\cdots\). The \(k\)-WL hierarchy corresponds to the counting logic \(\mathcal{C}^k\). Going beyond 1-WL in GNNs requires either: (a) random node features (breaks isomorphism symmetry), (b) higher-order GNNs operating on node tuples, or (c) structural positional encodings (e.g., random-walk PEs, Laplacian EPs).

What 1-WL Cannot See — and the GIN Fix
▼

The Canonical Hard Pair: C₆ vs 2×C₃

The 6-cycle (C₆: a ring of 6 nodes) and two disjoint triangles (2×C₃) are the smallest graphs that 1-WL cannot distinguish:

  • Both have 6 nodes, all with degree 2.
  • In every WL round, every node in C₆ has two degree-2 neighbors → same signature as every node in 2×C₃.
  • Color histograms stay identical forever: {A,A,A,A,A,A} for all rounds.
  • Yet the graphs are not isomorphic: C₆ is connected; 2×C₃ has two components.

This means a standard message-passing GNN trained on these graphs will produce identical embeddings for them — and cannot learn any function that requires telling them apart (e.g., predicting graph connectivity).

Why Sum > Mean > Max for Expressiveness

$$\text{Example: node } v \text{ has neighbors } \{r,r,b\} \text{ vs } \{r,b,b\}$$
  • Sum: (2r+1b) ≠ (1r+2b) → distinguished ✓
  • Mean: (2r/3+b/3) ≠ (r/3+2b/3) → still distinguished here, but fails when counts differ
  • Max: max(r,r,b)=r, max(r,b,b)=r or b depending on ordering → may conflate ✗

Crucially, sum over one-hot encodings fully encodes a multiset (it's the characteristic vector). Mean divides out the count, losing size information. A node with 2 red neighbors looks the same as a node with 4 red neighbors under mean aggregation if all neighbors are red.

∑ The GIN Injectivity Theorem

For countably many colors, \(\sum_{x \in S} f(x)\) is an injective function of multisets \(S\) for any injective \(f: X \to \mathbb{R}^n\) (with \(n\) large enough). This is the foundation of GIN: if \(h^{(k-1)}\) is injective on node types, then sum aggregation + injective MLP preserves all multiset information, achieving 1-WL power.

From-Scratch GIN Implementation

import torch
import torch.nn as nn
from torch_geometric.nn import MessagePassing
from torch_geometric.utils import add_self_loops, degree
class GINConv(MessagePassing):
"""Graph Isomorphism Network layer (Xu et al., ICLR 2019)."""
def __init__(self, mlp, eps=0.0, train_eps=False):
super().__init__(aggr='add') # SUM aggregation — critical!
self.mlp = mlp
# eps scales the self-loop: h_v' = MLP((1+eps)*h_v + sum_neighbors)
self.eps = nn.Parameter(torch.tensor([eps])) if train_eps \
else torch.tensor([eps])
def forward(self, x, edge_index):
# Propagate: aggregates neighbor features via sum
out = self.propagate(edge_index, x=x)
# Combine: (1+eps)*self + sum(neighbors), then MLP
return self.mlp((1 + self.eps) * x + out)
def message(self, x_j): # x_j: features of each neighbor
return x_j # No transformation — just pass through
# Usage
mlp = nn.Sequential(nn.Linear(64, 64), nn.ReLU(), nn.Linear(64, 64))
conv = GINConv(mlp, eps=0.0, train_eps=True)
# ⚠️ Mean/max aggregation makes this strictly weaker than 1-WL!

Key Takeaways
▼
  • Graph isomorphism asks whether two graphs are structurally identical up to node relabeling. It is in GI (a class between P and NP), not known to be in P.
  • 1-WL is a sound but incomplete isomorphism test: "different" is conclusive; "same" is not.
  • Message-passing GNNs ≤ 1-WL: they can never distinguish graphs that 1-WL cannot. This is a hard theoretical ceiling.
  • GIN achieves exactly 1-WL by using sum aggregation + injective MLP. GCN (mean) and GraphSAGE (max) are strictly weaker.
  • Beyond 1-WL: higher-order WL (k-WL), random features, structural PEs (RWPE, LapPE), and subgraph GNNs all break the 1-WL barrier at increasing computational cost.
  • Practical implication: If your task requires counting triangles, detecting cycles, or distinguishing connected from disconnected graphs with the same degree sequence, standard message-passing GNNs will fail. Use GIN + structural features or higher-order models.
🎯 When to Use What

GCN/GraphSAGE: node classification where local degree structure suffices. GIN: graph classification tasks where full 1-WL power is needed. Higher-order GNNs (NGNN, k-GNN): tasks requiring cycle counting, subgraph patterns. Transformers on graphs: when global structure matters and compute allows.
