Random Initialization

Small uniform & normal weight init — how the scale controls signal survival across depth
Foundational Deep Learning Optimization O(n²) per layer
1
Understanding Random Initialization
▼

What is it? Before a neural network learns anything, its weights need starting values. Random initialization means drawing each weight independently from a small random distribution — usually a Normal (Gaussian) or Uniform distribution centered at zero — instead of setting them all to zero or to some fixed constant. The one number that matters most is the scale: the standard deviation \(\sigma\) (or the width of the uniform range) each weight is sampled from.

Analogy: Imagine a choir where every singer starts on the exact same note with the exact same voice — no matter how much they rehearse, they'll always sing in perfect unison and the choir will never sound richer than one voice. Random initialization is like giving every singer a slightly different starting pitch, so they can each learn a distinct part. But give them wildly different starting pitches and the choir is chaos before rehearsal even begins; make the differences imperceptibly small and it still sounds like one voice. The scale of the randomness is the whole game.

💡 If you remember one thing

The shape of the init distribution (Normal vs. Uniform) barely matters. The variance of the weights is what determines whether activations and gradients shrink to zero (vanish), blow up (explode), or stay well-behaved as signals propagate through depth — and that variance must scale with \(1/\text{fan-in}\), roughly \(\sigma^2 = 1/n\) (Xavier) or \(2/n\) (He).

How It Works Internally
▼

Why Not Zero (or Any Constant)?

If every weight in a layer starts identical, every neuron in that layer computes the exact same function of the input, and — critically — receives the exact same gradient during backprop. They update in lockstep forever. This is the symmetry-breaking problem: a layer of \(n\) neurons initialized identically behaves like a layer of 1 neuron, no matter how much you train it. Randomness gives each neuron a different starting function so gradient descent can differentiate their roles.

The Forward-Pass Variance Chain

Once weights are random, a second problem appears: scale. Consider one layer computing \(z = Wa + b\) where \(a \in \mathbb{R}^n\) is the incoming activation vector and each \(W_{ij}\) is drawn i.i.d. with mean 0 and variance \(\sigma_w^2\). Each output coordinate is a sum of \(n\) independent-ish terms, so its variance is \(n\) times larger than a single term's variance. Push this through many layers and the variance either compounds multiplicatively — shrinking toward 0 if \(\sigma_w^2\) is too small, or growing toward \(\infty\) if too large.

Concretely: a saturating nonlinearity like \(\tanh\) squashes large pre-activations toward \(\pm1\), so with a too-large \(\sigma_w\) the post-activation variance looks deceptively "fine" while nearly every unit is pinned at the flat part of the curve — where the local derivative \(\tanh'(z) = 1-\tanh^2(z)\) is almost 0. The forward signal survives; the backward gradient does not.

Design Decision: Independent Sampling Per Weight

Why sample every weight independently rather than, say, one random scalar per layer? Independent sampling is what makes different output units compute different linear combinations of the input — it's the actual mechanism of symmetry breaking, not just "add some noise." A single shared random scalar would keep every unit in a layer perfectly correlated, reproducing the zero-init failure mode in disguise.

🔑 Key Property

For a linear layer with fan-in \(n\), zero-mean independent weights, and zero-mean independent inputs: \(\operatorname{Var}(z) \approx n\,\sigma_w^2\,\operatorname{Var}(a)\). Preserving variance layer-to-layer (\(\operatorname{Var}(z)=\operatorname{Var}(a)\)) requires \(\sigma_w^2 = 1/n\) — this single relation is the seed of both Xavier and He initialization.

3
Why It Works — Deriving Xavier & He Init
▼

Setting Up the Variance Recursion

Let layer \(l\) compute \(z^l = W^l a^{l-1}\), with \(W^l_{ij} \sim \mathcal{D}(0, \sigma_w^2)\) i.i.d. and independent of \(a^{l-1}\), and \(\mathbb{E}[a^{l-1}]\approx 0\). Each output coordinate is:

$$z^l_i = \sum_{k=1}^{n} W^l_{ik}\, a^{l-1}_k$$

Since the \(n\) terms are independent with mean 0:

$$\operatorname{Var}(z^l_i) = \sum_{k=1}^{n} \operatorname{Var}\!\left(W^l_{ik}\,a^{l-1}_k\right) = n\,\sigma_w^2\,\operatorname{Var}(a^{l-1})$$

This is the core recursion: each layer multiplies the running variance by \(n\sigma_w^2\). If that factor is \(< 1\), variance shrinks geometrically with depth (vanishing); if \(>1\), it grows geometrically (exploding).

Xavier / Glorot Initialization (1)

Glorot & Bengio (2010) required the factor to equal exactly 1 for the forward pass — and, by a symmetric argument on the backward pass, also for fan-out \(n_{out}\). Averaging both constraints gives the standard Xavier variance:

$$\sigma_w^2 = \frac{2}{n_{in} + n_{out}} \quad\text{(or the simpler forward-only version } \sigma_w^2 = \tfrac{1}{n_{in}}\text{)}$$

For the equivalent Uniform initialization with the same variance, since \(\operatorname{Var}(\mathcal{U}(-a,a)) = a^2/3\), Glorot's uniform init sets \(a = \sqrt{6/(n_{in}+n_{out})}\).

He Initialization (for ReLU)

Xavier assumes a roughly linear, symmetric activation. ReLU zeroes out half its inputs on average, halving the variance at every layer on top of the linear-layer shrinkage. He et al. (2015) correct for this by doubling the target variance:

$$\sigma_w^2 = \frac{2}{n_{in}}$$

Derivation sketch: for \(z\) symmetric around 0, \(\mathbb{E}[\text{ReLU}(z)^2] = \tfrac{1}{2}\mathbb{E}[z^2]\), so \(\operatorname{Var}(a^l) = \tfrac12\operatorname{Var}(z^l) = \tfrac12 n\sigma_w^2\operatorname{Var}(a^{l-1})\). Setting this ratio to 1 forces \(\sigma_w^2 = 2/n\).

⚠️ Common Misconception

"Smaller weights are always safer." Not true — too small is just as broken as too large, only the failure mode differs (vanishing vs. exploding/saturating). There is a specific scale, set by fan-in (and the activation function), that keeps signal variance close to 1 across depth. Neither "small" nor "large" alone is the goal — matched to fan-in is.

When it still matters today: Modern very-deep nets lean on residual connections, BatchNorm/LayerNorm, and warmup to be more init-robust — but init still sets the starting point those techniques have to correct from, and it is decisive for RNNs, small networks, and the first few steps of training in general.

💡 Rule of Thumb

Match the initialization variance to the activation function's effect on signal energy: Xavier for symmetric/linear-ish activations, He for ReLU-family activations. The distribution family (Normal vs. Uniform) is a minor, second-order choice — get the variance right first.

Code Trace
▼
import numpy as np
def init_weights(n_in, n_out, scheme="xavier_normal"):
if scheme == "zeros":
return np.zeros((n_out, n_in)) # symmetry never breaks
if scheme == "small_normal":
return np.random.randn(n_out, n_in) * 0.01 # vanishes with depth
if scheme == "xavier_normal":
std = np.sqrt(1.0 / n_in) # tanh / sigmoid / linear
return np.random.randn(n_out, n_in) * std
if scheme == "xavier_uniform":
a = np.sqrt(6.0 / (n_in + n_out))
return np.random.uniform(-a, a, (n_out, n_in))
if scheme == "he_normal":
std = np.sqrt(2.0 / n_in) # ReLU family
return np.random.randn(n_out, n_in) * std
# Forward pass through L layers, tracking activation variance
def variance_trace(n=40, L=6, std=0.01, act="tanh", batch=120):
a = np.random.randn(batch, n) # input, Var ≈ 1
variances = [a.var()]
for l in range(L):
W = np.random.randn(n, n) * std # fan_in = n
z = a @ W.T
a = np.tanh(z) if act == "tanh" else np.maximum(0, z)
variances.append(a.var())
return variances # watch this shrink / blow up / hold
