1
Understanding the Hybrid Family
▼

What is it? Plain ViT chops an image into a single grid of patches and runs full self-attention over all of them — great for classification, but wrong for dense tasks (detection, segmentation) that need multi-scale features, and painfully expensive as resolution grows because attention cost is quadratic in the number of tokens. PVT, CvT, and CoAtNet each reintroduce a piece of "how CNNs think" — pyramids, local convolutions, translation equivariance — directly into the Transformer to fix this, without giving up global attention.

Analogy: Think of a CNN as a near-sighted local shopkeeper who knows every neighbor's face (locality, weight sharing) but never looks across town, and a plain ViT as a globe-trotting analyst who can compare any two points on Earth but must personally re-examine every pair of pixels each time. PVT shrinks the map as the analyst zooms out (pyramid + fewer points to compare). CvT hires a local scout (convolution) to pre-filter who's worth comparing before the analyst gets involved. CoAtNet merges the two jobs into one: the same person applies both a fixed "nearby matters" rule and a flexible "who's actually relevant" judgment at once.

💡 If you remember one thing

Convolution and self-attention are both just weighted sums over a neighborhood: convolution uses fixed, input-independent weights (translation-equivariant, sample-efficient); attention uses input-dependent weights (flexible, needs more data). Hybrids like CoAtNet literally add the two weighting schemes together: $$y_i = \sum_{j \in \mathcal{G}} \frac{\exp(x_i^\top x_j + w_{i-j})}{\sum_{k \in \mathcal{G}} \exp(x_i^\top x_k + w_{i-k})}\, x_j$$ where \(w_{i-j}\) is a static, convolution-like relative bias and \(x_i^\top x_j\) is the dynamic attention score.

2
How Each Architecture Works Internally
▼

PVT — Pyramid Vision Transformer: shrink the grid, shrink the keys

PVT (Wang et al., 2021) organizes the network into 4 stages, exactly like a ResNet: each stage starts with a strided patch-embedding conv that halves (stage 1: quarters) spatial resolution while doubling-ish channels, producing feature maps at strides 4, 8, 16, 32 — a genuine pyramid usable by FPN-style detection/segmentation heads, unlike single-scale ViT. Inside each stage, ordinary multi-head attention is replaced by Spatial-Reduction Attention (SRA): queries keep full resolution, but keys/values are first spatially downsampled by a factor \(R\) (via a strided conv + LayerNorm) before the attention matrix is formed. At stage 1 with a 224×224 image, patch4/stride4 gives 56×56 = 3136 tokens; full attention would cost \(\propto n^2 d = 3136^2 \times 64 \approx 6.3\times10^8\); with \(R{=}8\), keys/values shrink to 7×7=49 tokens, cutting cost to \(\propto n\, m\, d = 3136\times49\times64\approx9.8\times10^6\) — a 64× (\(R^2\)) reduction, exactly where it's needed most (the highest-resolution, most expensive stage).

CvT — Convolutional vision Transformer: put convolutions inside the block

CvT (Wu et al., 2021) keeps ViT's flat token sequence per stage (3 stages total) but replaces two components with convolutions. First, Convolutional Token Embedding: instead of non-overlapping patch splitting, an overlapping strided conv (e.g. 7×7/stride4 at stage 1) produces tokens with built-in local context and — crucially — implicit position information, so CvT drops positional encodings entirely. Second, Convolutional Projection: the linear layers that produce Q, K, V from tokens are replaced with depthwise-separable convolutions applied on the reshaped 2D token map. Q uses stride 1 (keep full resolution — we still want fine-grained queries), while K and V use stride 2, shrinking the key/value token count 4× per stage and giving attention both a locality prior and a built-in efficiency gain.

CoAtNet — one operator, and a searched stage layout

CoAtNet (Dai et al., 2021) goes one step further: instead of alternating conv and attention blocks, it unifies them into a single relative attention operator that adds a static, translation-equivariant relative-position bias \(w_{i-j}\) directly inside the attention logits alongside the dynamic \(x_i^\top x_j\) score (pre-softmax, so both terms compete for the same normalization) — algebraically, ordinary depthwise convolution is the special case where the dynamic term is dropped and only \(w_{i-j}\) remains. Architecturally, CoAtNet keeps 5 stages (stem + S1..S4) and empirically searches the type assigned to each stage over the space {C,T}⁴: C-C-C-C, C-C-C-T, C-C-T-T, C-T-T-T. Early, high-resolution stages use MBConv (inverted-bottleneck depthwise conv + squeeze-excite) for cheap, generalizable, data-efficient features; late, low-resolution stages (14×14, 7×7 — cheap enough for full attention) switch to relative-attention Transformer blocks for global receptive field and capacity that scales with data. C-C-T-T wins the search: enough convolution to generalize well on modest data, enough attention to keep scaling with more data and larger models.

🔑 Key Property

All three hybrids attack the same ViT bottleneck (quadratic cost, single scale, weak locality prior) from three different angles: PVT reduces where attention looks (spatial reduction), CvT reduces how tokens are formed (convolutional embedding + projection), and CoAtNet reduces what attention IS (a generalized conv+attention operator, plus a searched stage schedule).

Why It Works — The Math
▼

PVT: Spatial-Reduction Attention

Given a token map reshaped to \(H\times W\times C\), SRA first reduces it:

$$SR(x) = \text{LayerNorm}\big(\text{Reshape}(x)\,W^S\big),\qquad \text{Reshape}: \mathbb{R}^{n\times C}\to\mathbb{R}^{\frac{H}{R}\cdot\frac{W}{R}\times (R^2 C)}$$

where \(W^S \in \mathbb{R}^{(R^2C)\times C}\) is implemented as a conv with kernel \(R\), stride \(R\). Attention then runs as usual but with reduced keys/values:

$$\text{SRA}(Q,K,V) = \text{softmax}\!\left(\frac{Q\,SR(K)^\top}{\sqrt{d_k}}\right) SR(V)$$

Complexity drops from \(O(n^2 d)\) to \(O\!\left(\frac{n^2}{R^2} d\right)\) — a quadratic-in-\(R\) win, because both the row and column dimensions of the attention matrix shrink.

CvT: Convolutional Projection

$$Q = \text{Flatten}\big(\text{DWConv}(\text{Reshape}(x), s_q{=}1)\big),\quad K,V = \text{Flatten}\big(\text{DWConv}(\text{Reshape}(x), s_{kv}{=}2)\big)$$

Depthwise-separable convolution adds only a handful of extra parameters (one small kernel per channel) but injects a strong locality + translation-equivariance prior directly into how Q/K/V are computed, and the stride-2 K/V downsampling gives roughly the same \(4\times\) token-count saving per stage as PVT's \(R{=}2\) case.

CoAtNet: unifying conv and attention as one weighted sum

Depthwise convolution with a fixed kernel \(w\) and (pre-softmax) global relative attention are both instances of:

$$y_i = \sum_{j\in\mathcal{G}} A(i,j)\, x_j$$

Convolution sets \(A(i,j)=w_{i-j}\) — input-independent, translation-equivariant, but a fixed receptive field. Attention sets \(A(i,j)=\dfrac{\exp(x_i^\top x_j)}{\sum_k \exp(x_i^\top x_k)}\) — global, input-adaptive, but data-hungry. CoAtNet's relative attention simply sums the two logits before the softmax normalizes them:

$$y_i = \sum_{j\in\mathcal{G}} \frac{\exp\!\big(x_i^\top x_j + w_{i-j}\big)}{\sum_{k\in\mathcal{G}} \exp\!\big(x_i^\top x_k + w_{i-k}\big)}\, x_j$$

Because \(w_{i-j}\) depends only on relative position (not on the batch or the actual pixel values), it costs no extra parameters beyond a small lookup table, yet supplies convolution's generalization benefit for free inside a fully global attention operator.

⚠️ Common Pitfall

Spatial reduction (PVT's \(R\), CvT's stride-2 K/V) trades information for speed — push \(R\) too high at early, detail-critical stages and small objects / fine boundaries get blurred out of the key/value set entirely before attention ever sees them. Likewise, CoAtNet's C-C-T-T layout is the winner of a specific architecture search on ImageNet-scale data; the generalization-vs-capacity trade-off it encodes is empirical, not a theorem, and can shift with dataset size or task.

When to reach for a hybrid:

  • You need multi-scale features for detection/segmentation → PVT-style pyramid backbone
  • Training data is limited and you want convolution's sample efficiency inside attention → CvT
  • You want one architecture that scales gracefully from small to huge data/model regimes → CoAtNet

When plain ViT or plain CNN is still fine:

  • Huge pretraining data + single-scale classification only → plain ViT is simpler and just as strong
  • Small model, latency-critical, no need for global context → a pure CNN (e.g. MobileNet/EfficientNet) is cheaper
💡 Big Picture

PVT and CvT bolt convolutional ideas onto a Transformer (pyramid scaffolding, convolutional token/QKV formation). CoAtNet dissolves the boundary entirely — convolution and attention become two terms of one equation, and the only remaining architectural choice is how many stages of each to use, which becomes a search problem rather than a design intuition.

import torch, torch.nn as nn
# ---- PVT: Spatial-Reduction Attention ----
class SRA(nn.Module):
def __init__(self, dim, heads, R):
super().__init__()
self.q = nn.Linear(dim, dim)
self.kv = nn.Linear(dim, dim * 2)
self.sr = nn.Conv2d(dim, dim, kernel_size=R, stride=R) # spatial reduction
self.norm = nn.LayerNorm(dim)
self.heads = heads
def forward(self, x, H, W): # x: (B, N, C), N = H*W
q = self.q(x) # full resolution queries
x_ = x.permute(0,2,1).reshape(-1, x.shape[-1], H, W)
x_ = self.sr(x_).reshape(x.shape[0], -1, x.shape[-1]) # N -> N / R^2
x_ = self.norm(x_)
k, v = self.kv(x_).chunk(2, dim=-1) # reduced keys / values
return attention(q, k, v, self.heads)
# ---- CvT: Convolutional Projection ----
class ConvProjection(nn.Module):
def __init__(self, dim, s_q=1, s_kv=2):
super().__init__()
self.dwconv_q = DepthwiseConv(dim, stride=s_q) # full-res queries
self.dwconv_kv = DepthwiseConv(dim, stride=s_kv) # downsampled keys/values
def forward(self, x, H, W):
q = flatten(self.dwconv_q(to_2d(x, H, W)))
k = flatten(self.dwconv_kv(to_2d(x, H, W)))
v = flatten(self.dwconv_kv(to_2d(x, H, W)))
return q, k, v # no positional encoding needed
# ---- CoAtNet: Relative Attention ----
class RelativeAttention(nn.Module):
def __init__(self, dim, heads, grid_size):
super().__init__()
n = grid_size * grid_size
self.rel_bias = nn.Parameter(torch.zeros(heads, n, n)) # static w_{i-j}
self.qkv = nn.Linear(dim, dim * 3)
def forward(self, x):
q, k, v = self.qkv(x).chunk(3, dim=-1)
logits = (q @ k.transpose(-2, -1)) / q.shape[-1] ** 0.5
logits = logits + self.rel_bias # dynamic + static, summed pre-softmax
attn = logits.softmax(dim=-1)
return attn @ v
# CoAtNet stage layout, searched over {C,T}^4:
stages = ['stem_conv', 'MBConv', 'MBConv', 'RelAttn', 'RelAttn'] # C-C-T-T
