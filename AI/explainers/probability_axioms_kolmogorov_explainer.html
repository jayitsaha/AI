1
Understanding the Concept
▼

What is this? Probability theory answers the question: "How do we rigorously measure the likelihood of uncertain events?" In 1933, Andrei Kolmogorov gave the first axiomatic foundation — three simple rules that all probability calculations must obey. Everything in statistics, machine learning, and data science rests on this bedrock.

The intuition: Think of a probability as the "fraction of a cake" you allocate to each possible outcome. The whole cake = 1 (something must happen). Each slice is non-negative (you can't have negative cake). And if two slices don't overlap, their combined size is just the sum of their individual sizes.

If you remember one thing

Probability is a function \(P\) from events to \([0,1]\) satisfying: (1) non-negativity \(P(A)\geq 0\), (2) normalization \(P(\Omega)=1\), (3) countable additivity \(P(A\cup B)=P(A)+P(B)\) when \(A\cap B=\emptyset\). Every other probability rule — complement, union, inclusion-exclusion — is a theorem derived from just these three axioms.

2
The Three Building Blocks
▼

1. The Sample Space \(\Omega\)

The sample space \(\Omega\) (omega) is the set of all possible outcomes of an experiment. For a fair six-sided die: \(\Omega = \{1, 2, 3, 4, 5, 6\}\). For a coin flip: \(\Omega = \{\text{H}, \text{T}\}\). For a continuous measurement: \(\Omega = \mathbb{R}\).

2. Events — Subsets of \(\Omega\)

An event \(A\) is any subset of \(\Omega\) to which we can assign a probability. "Roll an even number" is the event \(A = \{2, 4, 6\} \subseteq \Omega\). Events can be combined: \(A \cup B\) (A or B), \(A \cap B\) (A and B), \(A^c\) (not A). The collection of all "allowed" events forms a \(\sigma\)-algebra (sigma-algebra) — a technical requirement ensuring we can consistently assign probabilities to all combinations of events.

3. Kolmogorov's Three Axioms

Axiom 1 — Non-negativity
$$P(A) \geq 0 \quad \forall A \subseteq \Omega$$

Probabilities are never negative. Likelihood is a magnitude, not a direction.

Axiom 2 — Normalization
$$P(\Omega) = 1$$

The entire sample space has probability 1. Something must happen — certainty is our reference point.

Axiom 3 — Countable Additivity
$$P\!\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

For pairwise disjoint events \(A_i\), probability of "any of them" = sum of individual probabilities.

Key Property — Probability as a Measure

The triple \((\Omega, \mathcal{F}, P)\) — sample space, sigma-algebra, probability measure — is called a probability space. It is a special case of a measure space from measure theory, where the total measure equals 1. This abstraction lets us handle both discrete (die, cards) and continuous (height, temperature) settings with identical machinery.

3
Derived Theorems — Why the Axioms Are Enough
▼

The three axioms generate an entire calculus of probability. Here are the key theorems, each derived directly from the axioms:

Theorem 1: Complement Rule

For any event \(A\), its complement \(A^c\) satisfies:

$$P(A^c) = 1 - P(A)$$

Proof: \(A\) and \(A^c\) are disjoint and \(A \cup A^c = \Omega\). By Axiom 3: \(P(A) + P(A^c) = P(\Omega) = 1\) (Axiom 2). Rearranging gives the result. \(\square\)

Theorem 2: Empty Set

$$P(\emptyset) = 0$$

Proof: \(\Omega^c = \emptyset\), so \(P(\emptyset) = 1 - P(\Omega) = 1 - 1 = 0\). \(\square\)

Theorem 3: Monotonicity

If \(A \subseteq B\) then \(P(A) \leq P(B)\). Also: \(0 \leq P(A) \leq 1\).

Proof: Write \(B = A \cup (B \setminus A)\) (disjoint). By Axiom 3: \(P(B) = P(A) + P(B\setminus A) \geq P(A)\) by Axiom 1. The bounds \([0,1]\) follow from Axioms 1, 2, and \(A \subseteq \Omega\). \(\square\)

Theorem 4: General Addition Rule (Inclusion-Exclusion)

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

Proof: Decompose: \(A \cup B = A \cup (B \setminus A)\) (disjoint), and \(B = (A \cap B) \cup (B \setminus A)\) (disjoint). Axiom 3 gives \(P(A \cup B) = P(A) + P(B\setminus A)\) and \(P(B\setminus A) = P(B) - P(A\cap B)\). Substituting: \(P(A\cup B) = P(A) + P(B) - P(A\cap B)\). \(\square\)

Dice Example — All Theorems at Work

Fair die, \(\Omega = \{1,2,3,4,5,6\}\), each outcome has probability \(\frac{1}{6}\).

  • \(A = \{2,4,6\}\) (even): \(P(A) = \frac{3}{6} = \frac{1}{2}\)
  • \(B = \{4,5,6\}\) (greater than 3): \(P(B) = \frac{3}{6} = \frac{1}{2}\)
  • \(A \cap B = \{4,6\}\): \(P(A\cap B) = \frac{2}{6} = \frac{1}{3}\)
  • \(A \cup B = \{2,4,5,6\}\): \(P(A\cup B) = \frac{1}{2} + \frac{1}{2} - \frac{1}{3} = \frac{2}{3}\) ✓
  • \(A^c = \{1,3,5\}\) (odd): \(P(A^c) = 1 - \frac{1}{2} = \frac{1}{2}\) ✓
Common Misconception

"Probability zero means impossible." False! For a continuous uniform distribution on \([0,1]\), every single point \(x\) has \(P(X = x) = 0\), yet every point is possible. Zero probability and impossibility coincide only for discrete/finite spaces. This is why Axiom 3 requires countable additivity — uncountable additivity would force \(P([0,1]) = 0\), contradicting Axiom 2.

Key Takeaways & When This Matters
▼

Why this is foundational to ML: Every probabilistic model — Naive Bayes, logistic regression, Bayesian networks, VAEs, diffusion models — relies on these axioms. When you write a likelihood function \(p(x|\theta)\), you're implicitly invoking all three Kolmogorov axioms.

  • Axiom 1 guarantees softmax outputs are valid (they're non-negative).
  • Axiom 2 guarantees softmax outputs sum to 1 (normalization).
  • Axiom 3 underlies the chain rule of probability and Bayes' theorem.
The Power of Abstraction

By abstracting probability to three axioms on a measure space, Kolmogorov unified classical probability (counting outcomes), geometric probability (areas), and frequency-based probability under a single framework. The same theorems apply whether you're computing the probability of rolling a 6, of a Gaussian exceeding \(2\sigma\), or of a neural network outputting class "cat".

Code Trace — From Axioms to Computation
▼
import numpy as np
# Sample space: fair die
Omega = {1, 2, 3, 4, 5, 6} # Axiom 2: |Omega| is our reference
n = len(Omega) # n = 6
# Uniform probability measure: P(A) = |A| / |Omega|
def P(event, space=Omega):
# Axiom 1: P >= 0 (len always >= 0)
# Axiom 2: P(Omega) = len(Omega)/len(Omega) = 1
return len(event) / len(space)
# Events
A = {2, 4, 6} # "roll even"
B = {4, 5, 6} # "roll > 3"
# Verify all axioms and derived theorems
assert P(Omega) == 1.0 # Axiom 2 check
assert P(A) >= 0 # Axiom 1 check
# Complement rule: P(A^c) = 1 - P(A)
Ac = Omega - A # {1, 3, 5}
assert abs(P(Ac) - (1 - P(A))) < 1e-10 # == 0.5
# Inclusion-exclusion: P(A|B) = P(A) + P(B) - P(A&B)
print(P(A | B)) # 4/6 = 0.667
print(P(A) + P(B) - P(A & B)) # 3/6 + 3/6 - 2/6 = 4/6 = 0.667
# Countable additivity (Axiom 3) for disjoint A, Ac
assert len(A & Ac) == 0 # disjoint
assert P(A | Ac) == P(A) + P(Ac) # additivity holds: 1.0
