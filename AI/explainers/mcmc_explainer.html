Understanding MCMC
▼

What is it? Markov Chain Monte Carlo (MCMC) is a class of algorithms for sampling from probability distributions, especially useful when direct sampling is difficult (e.g., high-dimensional, complex, or unnormalized distributions). The core idea is to construct a Markov Chain whose stationary distribution is the target distribution. By simulating this chain for a sufficiently long time, the sequence of states visited will approximate samples from the target distribution.

Analogy: Imagine you want to estimate the average height of people in a city, but you can only ask people you meet on the street. Instead of randomly picking people (which might be hard to do truly randomly), you start at a random location, ask someone, then randomly walk to a nearby location and ask another person, and so on. If your "random walk" eventually lets you visit all parts of the city in proportion to how many people live there, then your collected heights will eventually represent the city's population. MCMC is like this, but for abstract "states" in a probability space.

💡 If you remember one thing

MCMC methods generate a sequence of samples (a Markov chain) where each new sample depends only on the previous one. If designed correctly, this chain will eventually converge to the desired target distribution, meaning the samples become representative of it. The challenge is designing efficient chains that explore the space quickly.

How Different MCMC Samplers Work
▼

1. Metropolis-Hastings (MH)

MH is the most general MCMC algorithm. From a current state \(x\), it proposes a new state \(x^*\) from a proposal distribution \(Q(x^*|x)\). It then accepts \(x^*\) with a probability \(\alpha\) that balances the target density at \(x^*\) versus \(x\), and the proposal likelihoods. If accepted, \(x_{t+1}=x^*\); otherwise, \(x_{t+1}=x\). This ensures detailed balance, leading to the target as the stationary distribution.

2. Gibbs Sampling

Gibbs sampling is a special case of MH used when the target distribution is high-dimensional and it's easy to sample from the conditional distributions. Instead of proposing a jump for all variables at once, Gibbs updates one variable at a time, sampling it from its conditional distribution given the current values of all other variables. This avoids calculating an acceptance ratio, as these proposals are always accepted.

3. Hamiltonian Monte Carlo (HMC)

HMC introduces auxiliary "momentum" variables \(p\) to the state space. It then simulates Hamiltonian dynamics (potential energy \(U(q) = -\log P(q)\), kinetic energy \(K(p)\)) to propose a new state. This simulation generates a "trajectory" that efficiently explores the state space, making larger, more directed jumps than random-walk MH. A final MH acceptance step corrects for numerical integration errors.

4. No-U-Turn Sampler (NUTS)

NUTS is an extension of HMC that automatically tunes the number of "leapfrog" steps to take in the Hamiltonian simulation. Instead of fixing a number of steps, NUTS builds a trajectory forward and backward until it detects a "U-turn," indicating that further steps would lead back towards the starting point or reduce sampling efficiency. This eliminates a critical hyperparameter (trajectory length) and makes HMC much more robust and easier to use.

🔑 Key Property

All MCMC algorithms rely on the Markov property: the next state depends only on the current state. They differ in how they propose and accept new states. MH uses arbitrary proposals, Gibbs uses conditional sampling, and HMC/NUTS use gradient information to guide proposals along a simulated physical trajectory.

Why It Works — The Math
▼

Metropolis-Hastings Acceptance Ratio

Given a current state \(x\) and a proposed state \(x^*\), the MH algorithm accepts \(x^*\) with probability \(\alpha\):

$$\alpha(x^*|x) = \min\left(1, \frac{P(x^*)Q(x|x^*)}{P(x)Q(x^*|x)}\right)$$

Here, \(P(x)\) is the target probability density (or proportional to it), and \(Q(x^*|x)\) is the proposal density. This ratio ensures that the Markov chain satisfies detailed balance, a sufficient condition for the chain to converge to \(P(x)\) as its stationary distribution. If \(Q\) is symmetric (\(Q(x^*|x) = Q(x|x^*)\)), this simplifies to the Metropolis algorithm: \(\alpha = \min(1, P(x^*)/P(x))\).

Hamiltonian Dynamics and Leapfrog Integration

HMC introduces a fictitious momentum vector \(p\) for each position variable \(q\). The system's energy, the Hamiltonian \(H(q,p)\), is defined as:

$$H(q, p) = U(q) + K(p) = -\log P(q) + \frac{1}{2}p^\top M^{-1}p$$

where \(U(q)\) is the potential energy (negative log-probability) and \(K(p)\) is the kinetic energy (chosen as a Gaussian). The system evolves according to Hamilton's equations:

$$\frac{dq_i}{dt} = \frac{\partial H}{\partial p_i} = (M^{-1}p)_i \quad \text{and} \quad \frac{dp_i}{dt} = -\frac{\partial H}{\partial q_i} = -\frac{\partial U}{\partial q_i}$$

These equations are numerically integrated using a symplectic integrator like the leapfrog algorithm over a fixed number of steps \(\text{L}\) with step size \(\epsilon\). This ensures energy conservation and reversibility, critical for MCMC. After integration, a new state \((q^*, p^*)\) is proposed, and an MH step corrects for numerical errors.

⚠️ Common Pitfall

A common mistake is assuming MCMC samples are independent. They are not! They are autocorrelated. To get truly independent samples or reliable statistics, you need to "thin" the chain (take every N-th sample) or calculate the Effective Sample Size (ESS), which measures how many independent samples your chain is equivalent to. Also, don't forget the "burn-in" period, where initial samples are discarded as the chain converges to the target distribution.

Key Takeaways
▼

When to use MCMC:

  • When you need to sample from a complex, high-dimensional probability distribution (e.g., posterior distributions in Bayesian inference).
  • When the distribution is known up to a normalizing constant, making direct sampling or exact integration intractable.
  • For estimating expectations of functions with respect to the target distribution.

Choosing an MCMC method:

  • Metropolis-Hastings: General-purpose, easy to implement. Can be slow if proposals are poor (high rejection rate or small steps). Requires careful tuning of proposal distribution.
  • Gibbs Sampling: Efficient if conditional distributions are easy to sample from. Avoids acceptance/rejection. Can be slow if variables are highly correlated (slow mixing).
  • Hamiltonian Monte Carlo (HMC): Uses gradient information to make large, directed moves. Highly efficient for continuous, differentiable distributions. Requires tuning of step size and number of leapfrog steps.
  • NUTS: An adaptive form of HMC that automatically tunes the trajectory length, making it more robust and easier to use than vanilla HMC, especially for complex geometries. Often the go-to for many modern Bayesian inference problems (e.g., Stan).
💡 Big Picture

MCMC methods are indispensable tools in modern statistics and machine learning, particularly for Bayesian inference where posteriors are often analytically intractable. Understanding their mechanics and trade-offs allows practitioners to select the most appropriate sampler for their problem, balancing computational cost with sampling efficiency.

import numpy as np
from scipy.stats import multivariate_normal, norm
# Target distribution (e.g., 2D correlated Gaussian)
target_mean = np.array([0., 0.])
target_cov = np.array([[1., 0.8], [0.8, 1.]])
P_target = multivariate_normal(mean=target_mean, cov=target_cov).pdf
def metropolis_hastings(initial_x, num_samples, proposal_sd):
x = initial_x
samples = [x]
Q_proposal = multivariate_normal(mean=[0,0], cov=np.eye(2) * proposal_sd**2).pdf
for _ in range(num_samples - 1):
x_star = x + np.random.normal(0, proposal_sd, size=2) # Symmetric proposal
alpha = min(1, P_target(x_star) / P_target(x))
if np.random.rand() < alpha:
x = x_star
samples.append(x)
return np.array(samples)
def gibbs_sampling(initial_x, num_samples):
x = initial_x
samples = [x]
for _ in range(num_samples - 1):
# Sample x1 given x2: P(x1|x2) = N(mu1 + rho*sigma1/sigma2*(x2-mu2), sigma1^2*(1-rho^2))
# For our target: mu=[0,0], sigma=[1,1], rho=0.8
mean_x1_cond = target_cov[0,1] * x[1] / target_cov[1,1]
var_x1_cond = target_cov[0,0] * (1 - target_cov[0,1]**2 / (target_cov[0,0]*target_cov[1,1]))
x[0] = np.random.normal(mean_x1_cond, np.sqrt(var_x1_cond))
# Sample x2 given x1: P(x2|x1) = N(mu2 + rho*sigma2/sigma1*(x1-mu1), sigma2^2*(1-rho^2))
mean_x2_cond = target_cov[0,1] * x[0] / target_cov[0,0]
var_x2_cond = target_cov[1,1] * (1 - target_cov[0,1]**2 / (target_cov[0,0]*target_cov[1,1]))
x[1] = np.random.normal(mean_x2_cond, np.sqrt(var_x2_cond))
samples.append(x.copy())
return np.array(samples)
# HMC (simplified, without mass matrix M for clarity)
def hmc_step(q_curr, U_func, grad_U_func, epsilon, L):
p_curr = np.random.normal(0, 1, size=len(q_curr)) # Sample momentum
q_prop, p_prop = q_curr.copy(), p_curr.copy()
# Leapfrog integration
p_prop -= epsilon / 2 * grad_U_func(q_prop)
for _ in range(L - 1):
q_prop += epsilon * p_prop
p_prop -= epsilon * grad_U_func(q_prop)
q_prop += epsilon * p_prop
p_prop -= epsilon / 2 * grad_U_func(q_prop)
p_prop = -p_prop # Negate momentum for reversibility
# MH acceptance step
current_H = U_func(q_curr) + 0.5 * np.sum(p_curr**2)
proposed_H = U_func(q_prop) + 0.5 * np.sum(p_prop**2)
alpha = min(1, np.exp(current_H - proposed_H))
if np.random.rand() < alpha:
return q_prop, True, [(q_curr,p_curr), (q_prop,p_prop)] # Trajectory not shown here
return q_curr, False, [(q_curr,p_curr), (q_curr,p_curr)]
