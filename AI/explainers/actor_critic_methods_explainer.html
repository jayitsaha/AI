Actor-Critic Methods

Separate policy (Actor) and value (Critic) networks for efficient Reinforcement Learning
Foundational Reinforcement Learning O(N) per step
1
Understanding Actor-Critic
▼

What is it? Actor-Critic methods are a fundamental class of algorithms in Reinforcement Learning (RL) that combine elements from both policy-based and value-based approaches. They use two distinct neural networks (or function approximators): an Actor network that learns the policy (what actions to take), and a Critic network that learns the value function (how good a state or action is).

Analogy: Imagine a theater director (the Actor) who decides what actions the characters on stage should take. After each scene, a seasoned theater critic (the Critic) provides feedback, not just on the final outcome, but on how good each specific moment or decision was. The director uses this nuanced feedback to improve their future choices, rather than waiting for the entire play to finish and only getting a single "good" or "bad" review. The critic, in turn, gets better at evaluating scenes by observing the director's evolving choices and the audience's reactions.

💡 If you remember one thing

Actor-Critic methods leverage the best of both worlds: the Actor is a policy-gradient agent that learns what to do (stochastic actions, continuous control), while the Critic is a value-based agent that learns how good it is (reduces variance, speeds up learning). The Critic's value estimates guide the Actor's policy updates, making learning more stable and efficient than pure policy gradient methods.

2
How It Works Internally
▼

The Two Networks

At its core, an Actor-Critic agent maintains two separate components:

  • The Actor (Policy Network): This network, parameterized by \(\theta\), takes the current state \(s\) as input and outputs a probability distribution over possible actions \(a\), denoted \(\pi(a|s;\theta)\). For discrete action spaces, this is often a softmax output. For continuous action spaces, it might output parameters of a Gaussian distribution (mean and standard deviation). The Actor's goal is to learn an optimal policy that maximizes expected cumulative reward.
  • The Critic (Value Network): This network, parameterized by \(w\), takes the current state \(s\) as input and outputs an estimate of the expected future return from that state, \(V(s;w)\). This is often a single scalar output. The Critic's role is to evaluate the Actor's policy, providing a baseline for how "good" the current state is.

The Learning Loop

During training, the Actor and Critic interact in a continuous loop:

  1. The agent observes the current state \(s_t\).
  2. The Actor takes \(s_t\) and samples an action \(a_t\) from its policy \(\pi(a|s_t;\theta)\).
  3. The agent executes \(a_t\) in the environment, observes a reward \(r_t\), and transitions to a new state \(s_{t+1}\).
  4. The Critic estimates the value of the current state \(V(s_t;w)\) and the next state \(V(s_{t+1};w)\).
  5. A Temporal Difference (TD) error, \(\delta_t = r_t + \gamma V(s_{t+1};w) - V(s_t;w)\), is calculated. This \(\delta_t\) is the difference between the observed (estimated) return and the predicted value of the current state.
  6. The Critic's parameters \(w\) are updated to minimize the squared TD error, making its value estimates more accurate.
  7. The Actor's parameters \(\theta\) are updated using a policy gradient, where the TD error \(\delta_t\) serves as an estimate of the "advantage" of taking action \(a_t\) in state \(s_t\). If \(\delta_t\) is positive, it means the action was better than expected, and the Actor adjusts its policy to make that action more likely in the future. If negative, less likely.

Design Decision: Why Two Networks?

Pure policy gradient methods (like REINFORCE) use the full discounted return (\(G_t\)) to update the policy, which has very high variance. Pure value-based methods (like Q-learning) struggle with continuous action spaces. Actor-Critic combines the policy-optimization strength of policy gradients with the variance reduction of value functions. The Critic's value estimate acts as a learned baseline, reducing the variance of the policy gradient signal and enabling more stable and faster learning, especially in complex environments.

🔑 Key Property

The TD error \(\delta_t\) is central: it's used to train the Critic (as its target) and to train the Actor (as its advantage estimate). This tight coupling allows both networks to learn simultaneously and cooperatively. The Actor explores, and the Critic evaluates the Actor's exploration, providing a local "compass" for improvement.

3
Why It Works — The Math
▼

Policy Gradient with a Baseline

The general form of the policy gradient theorem states that the gradient of the policy's objective function \(J(\theta)\) (expected total reward) with respect to policy parameters \(\theta\) is:

$$\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\left[\nabla_\theta \log \pi_\theta(a|s) Q^{\pi}(s,a)\right]$

where \(Q^{\pi}(s,a)\) is the true action-value function. Estimating \(Q^{\pi}(s,a)\) from sampled returns can be very noisy. A common technique to reduce variance without introducing bias is to subtract a baseline \(b(s)\), typically the state-value function \(V^{\pi}(s)\):

$$\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\left[\nabla_\theta \log \pi_\theta(a|s) \left(Q^{\pi}(s,a) - V^{\pi}(s)\right)\right] = \mathbb{E}_{\pi_\theta}\left[\nabla_\theta \log \pi_\theta(a|s) A^{\pi}(s,a)\right]$

Here, \(A^{\pi}(s,a)\) is the advantage function. This is where the Critic comes in: it learns to approximate \(V^{\pi}(s)\), and we can derive an estimate for \(A^{\pi}(s,a)\) using the Temporal Difference (TD) error.

Temporal Difference (TD) Error as Advantage

The TD error for a state-value function is defined as the difference between a one-step lookahead estimate of the return and the current value estimate:

$$\delta_t = r_t + \gamma V(s_{t+1};w) - V(s_t;w)$$

This \(\delta_t\) serves as an excellent, low-variance estimate of the advantage \(A^{\pi}(s_t, a_t)\). If \(\delta_t > 0\), the action \(a_t\) in state \(s_t\) led to a better-than-expected outcome, and the Actor should make it more likely. If \(\delta_t < 0\), the outcome was worse than expected, and the Actor should make it less likely.

Actor and Critic Updates

With \(\delta_t\) as our advantage estimate, the Actor and Critic update rules become:

  • Critic Update: The Critic's parameters \(w\) are updated via gradient descent on the squared TD error. This is essentially supervised learning where the target is \(r_t + \gamma V(s_{t+1};w)\) and the prediction is \(V(s_t;w)\). $$\Delta w = \alpha_w \cdot \delta_t \cdot \nabla_w V(s_t;w)$$
  • Actor Update: The Actor's parameters \(\theta\) are updated using the policy gradient, using \(\delta_t\) as the advantage score. $$\Delta \theta = \alpha_\theta \cdot \nabla_\theta \log \pi_\theta(a_t|s_t) \cdot \delta_t$$

Where \(\alpha_w\) and \(\alpha_\theta\) are the learning rates for the Critic and Actor, respectively. These updates are performed after each step or after a short sequence of steps, in an "online" fashion.

⚠️ Common Pitfall

Actor-Critic methods can be sensitive to hyperparameter choices, especially the learning rates for the Actor and Critic. If the Critic learns too slowly, it provides poor feedback to the Actor. If it learns too fast, it might overfit to early, suboptimal policies. Balancing their learning is crucial, and often involves separate optimizers and schedules.

Key Takeaways
▼

When to use Actor-Critic methods:

  • Continuous Action Spaces: Policy-based methods (and thus Actor-Critic) naturally handle continuous actions by outputting parameters of a probability distribution (e.g., mean and std dev of a Gaussian).
  • Complex Environments: When the state space is large or continuous, function approximation (neural networks) is necessary, and Actor-Critic provides a robust framework.
  • Variance Reduction: When pure policy gradient methods (like REINFORCE) suffer from high variance in their updates, the Critic's baseline significantly stabilizes learning.
  • On-Policy Learning: When the agent needs to learn directly from its current experience, rather than from a replay buffer (though off-policy variants exist, e.g., DDPG, SAC).

When NOT to use:

  • Simple Tabular Problems: For small, discrete state/action spaces, simpler value-based methods like Q-learning or SARSA are often more sample-efficient and easier to implement.
  • Extreme Sample Efficiency: While more stable than REINFORCE, on-policy Actor-Critic methods can still be less sample-efficient than off-policy value-based methods (especially with experience replay) for discrete action spaces.
  • Hard-to-Learn Value Functions: If the environment's reward structure makes the value function inherently difficult to approximate accurately, the Critic might provide poor feedback, hindering Actor learning.
💡 Hierarchy

Actor-Critic is a broad category. Simple Actor-Critic (like the one shown) directly uses TD error. More advanced variants include A2C/A3C (Asynchronous Advantage Actor-Critic) for parallel training, DDPG (Deep Deterministic Policy Gradient) for continuous actions with off-policy learning, and SAC (Soft Actor-Critic) which incorporates entropy regularization for better exploration.

Code Trace (PyTorch-like Pseudocode)
▼
import torch
import torch.nn as nn
import torch.optim as optim
# Define Actor Network (Policy)
class Actor(nn.Module):
def __init__(self, state_dim, action_dim):
super().__init__()
self.net = nn.Sequential(
nn.Linear(state_dim, 64),
nn.ReLU(),
nn.Linear(64, action_dim),
nn.Softmax(dim=-1) # Outputs action probabilities
)
def forward(self, state):
return self.net(state)
# Define Critic Network (Value Function)
class Critic(nn.Module):
def __init__(self, state_dim):
super().__init__()
self.net = nn.Sequential(
nn.Linear(state_dim, 64),
nn.ReLU(),
nn.Linear(64, 1) # Outputs a single state value
)
def forward(self, state):
return self.net(state)
# --- Training Loop Snippet ---
actor = Actor(state_dim=2, action_dim=4)
critic = Critic(state_dim=2)
actor_optim = optim.Adam(actor.parameters(), lr=1e-3)
critic_optim = optim.Adam(critic.parameters(), lr=5e-3)
gamma = 0.99 # Discount factor
# Assume s_t, a_t, r_t, s_t_plus_1 are from environment interaction
# 1. Critic Update (Value Function)
V_s_t = critic(s_t)
V_s_t_plus_1 = critic(s_t_plus_1)
TD_target = r_t + gamma * V_s_t_plus_1.detach() # Detach next state value
TD_error = TD_target - V_s_t
critic_loss = TD_error.pow(2)
critic_optim.zero_grad()
critic_loss.backward()
critic_optim.step()
# 2. Actor Update (Policy Function)
action_probs = actor(s_t)
log_prob_a_t = torch.log(action_probs.squeeze(0)[a_t])
actor_loss = -log_prob_a_t * TD_error.detach() # Use TD_error as Advantage
actor_optim.zero_grad()
actor_loss.backward()
actor_optim.step()
