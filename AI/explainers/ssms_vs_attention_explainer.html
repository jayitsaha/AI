SSMs vs Attention: Efficiency & Expressiveness

Comparing two fundamental sequence modeling paradigms: global context vs. recurrent state
Intermediate Deep Learning Sequence Models O(N) vs O(N²)
1
Understanding SSMs vs Attention
▼

What are they? Both Attention and State Space Models (SSMs) are fundamental building blocks for modeling sequences in deep learning (e.g., text, audio, time series). They aim to capture dependencies between elements in a sequence, but they do so with vastly different computational trade-offs, particularly concerning efficiency and expressiveness as sequence length grows.

Analogy: Imagine you're trying to understand a long book. With Attention, you can instantly flip to any page or chapter, cross-referencing ideas from anywhere in the book to understand the current paragraph. This is powerful but slow if you have to do it for every word in a very long book (like finding every mention of a character across thousands of pages). With an SSM, you read the book strictly page by page, holding a mental summary (the "state") that updates with each new page. This is very efficient for long books (you only need to remember the summary, not every word you've read), but it's harder to directly link an idea from page 1000 back to page 5 without explicitly carrying that information in your summary.

💡 If you remember one thing

Attention offers unparalleled expressiveness by modeling arbitrary pairwise interactions (global context), but at a high computational cost that scales quadratically with sequence length (\(O(N^2)\)). SSMs offer superior efficiency (linear \(O(N)\) time, constant \(O(1)\) memory for the state), making them ideal for very long sequences, but historically with more constrained expressiveness due to their fixed recurrent structure. Modern SSMs like Mamba aim to bridge this gap.

2
How They Work Internally
▼

Attention: Global Context, Parallel Computation

The core idea of attention (Vaswani et al., 2017) is to compute a weighted sum of input "value" vectors, where the weights are determined by the "query" vector's similarity to all "key" vectors. For a sequence of length \(N\), each element can attend to every other element, including itself. This involves three linear projections (Query, Key, Value) and then:

  1. Compute similarity scores: \(Q K^\top\). This is an \(N \times N\) matrix.
  2. Normalize scores: apply softmax row-wise to get attention probabilities.
  3. Weighted sum: multiply probabilities by \(V\) to get context vectors.

This allows direct access to any part of the sequence, making it highly expressive. Crucially, all \(N\) output context vectors can be computed in parallel, making it efficient for hardware but still quadratically expensive in time and memory for long sequences.

State Space Models: Recurrent State, Efficient Memory

Classic State Space Models (SSMs) originate from control theory and define a system's evolution through a hidden state. For sequence modeling, they process inputs \(x_t\) one at a time, updating a fixed-size hidden state \(h_t\) and producing an output \(y_t\):

$$ h_t = \bar{A} h_{t-1} + \bar{B} x_t $$ $$ y_t = \bar{C} h_t + \bar{D} x_t $$

Here, \(\bar{A}, \bar{B}, \bar{C}, \bar{D}\) are fixed matrices. The state \(h_t\) acts as a compressed memory of the past. Since \(h_t\) has a fixed dimension (e.g., \(d_{state}\)), processing each token takes constant time and memory, leading to \(O(N)\) time and \(O(1)\) memory (for the state) across the entire sequence length \(N\). This sequential nature makes parallel training more complex than attention, but inference is very fast.

Design Decision: Why Hybrid SSMs (e.g., Mamba) are Emerging

The "fixed matrices" of classic SSMs limit their ability to selectively remember or forget information, a key strength of attention. Modern SSMs like Mamba address this by making the \(\bar{A}, \bar{B}, \bar{C}\) parameters data-dependent. This "selective SSM" mechanism allows the model to dynamically adjust its memory based on the input, achieving much of attention's expressiveness while retaining the \(O(N)\) efficiency, especially for long contexts.

🔑 Key Property

Attention's strength comes from its direct, global access to all past (and future) information, enabling complex reasoning. SSMs excel at efficiently compressing historical context into a fixed-size state, making them memory- and compute-friendly for very long sequences, particularly in recurrent inference settings.

3
Why It Works — The Math
▼

Attention: Quadratic Complexity

For an input sequence \(X \in \mathbb{R}^{N \times d_{model}}\), we project it into queries \(Q\), keys \(K\), and values \(V\), each of dimension \(N \times d_k\), \(N \times d_k\), and \(N \times d_v\) respectively. The self-attention mechanism is:

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$

The term \(QK^\top\) involves multiplying an \(N \times d_k\) matrix by a \(d_k \times N\) matrix, resulting in an \(N \times N\) attention scores matrix. This matrix multiplication has a computational cost of \(O(N^2 d_k)\). The subsequent multiplication by \(V\) (an \(N \times N\) matrix by an \(N \times d_v\) matrix) costs \(O(N^2 d_v)\). Thus, the overall computational complexity is \(\mathbf{O(N^2)}\) in sequence length \(N\). Memory complexity for storing the attention scores matrix is also \(\mathbf{O(N^2)}\).

SSMs: Linear Complexity

State Space Models are often defined in continuous time and then discretized. A continuous-time linear ODE is:

$$ \dot{h}(t) = Ah(t) + Bx(t) $$ $$ y(t) = Ch(t) + Dx(t) $$

where \(h(t)\) is the state, \(x(t)\) is the input, \(y(t)\) is the output, and \(A, B, C, D\) are matrices. Discretizing this system with a step size \(\Delta\) (e.g., using zero-order hold) yields a recurrent relation for discrete time steps \(t\):

$$ h_t = \bar{A} h_{t-1} + \bar{B} x_t $$ $$ y_t = \bar{C} h_t + \bar{D} x_t $$

Here, \(\bar{A} = e^{A\Delta}\) and \(\bar{B} = (A^{-1}(e^{A\Delta}-I))B\). If the state dimension \(d_{state}\) is constant (e.g., \(d_{state} \ll N\)), then each step of the recurrence (matrix-vector products) costs \(O(d_{state}^2)\). Processing the entire sequence of length \(N\) then costs \(\mathbf{O(N \cdot d_{state}^2)}\), which simplifies to \(\mathbf{O(N)}\) if \(d_{state}\) is treated as a constant. The memory required to store the state \(h_t\) at any given time is \(\mathbf{O(d_{state})}\), or \(\mathbf{O(1)}\) if \(d_{state}\) is constant.

⚠️ Practical Considerations

While SSMs offer linear complexity, the matrices \(\bar{A}, \bar{B}, \bar{C}\) can be large (e.g., \(d_{state} \times d_{state}\)). Training modern SSMs like Mamba often involves a parallel scan algorithm (convolutional view) to speed up training, which still retains \(O(N)\) complexity but can have larger constant factors than a simple recurrent pass. The key is that the computational cost per token remains bounded, unlike attention.

Key Takeaways
▼

When to use Attention:

  • When global context and fine-grained interactions between any two tokens are critical (e.g., complex reasoning in NLP).
  • For relatively shorter sequences where \(N^2\) complexity is manageable (e.g., standard Transformer context window of 512-4096 tokens).
  • When parallelizability during training is paramount, leveraging modern GPU architectures.
  • When the task requires strong inductive biases for arbitrary relationships, not just local or sequential ones.

When to consider SSMs (especially modern variants):

  • For very long sequences (e.g., hundreds of thousands to millions of tokens) where \(N^2\) complexity becomes prohibitive.
  • When efficient inference (generation) is a primary concern, due to their \(O(1)\) recurrent state.
  • In domains like audio or genomics, where local dependencies and memory of long-range patterns are important.
  • When a strong inductive bias for sequential processing and memory retention is beneficial.
💡 Architectural Inductive Biases

The choice between Attention and SSMs often boils down to the inductive biases you want to embed. Attention assumes "all tokens are equally important to all other tokens" (no bias). SSMs assume "the past can be compressed into a fixed state" (strong sequential bias). Modern hybrids attempt to combine the best of both worlds by introducing selective, data-dependent memory mechanisms into the SSM framework.

Code Trace (PyTorch-like Pseudocode)
▼
import torch
import torch.nn as nn
# --- Self-Attention (simplified) ---
class SelfAttention(nn.Module):
def __init__(self, d_model, d_k):
super().__init__()
self.wq = nn.Linear(d_model, d_k)
self.wk = nn.Linear(d_model, d_k)
self.wv = nn.Linear(d_model, d_k)
self.sqrt_d_k = d_k**0.5
def forward(self, x): # x: (batch, N, d_model)
Q = self.wq(x) # (batch, N, d_k)
K = self.wk(x) # (batch, N, d_k)
V = self.wv(x) # (batch, N, d_k)
# Compute attention scores: O(N^2 * d_k)
scores = torch.matmul(Q, K.transpose(-2, -1)) / self.sqrt_d_k
attn_weights = torch.softmax(scores, dim=-1) # (batch, N, N)
# Weighted sum of values: O(N^2 * d_k)
output = torch.matmul(attn_weights, V) # (batch, N, d_k)
return output
# --- Recurrent State Space Model (simplified) ---
class RecurrentSSM(nn.Module):
def __init__(self, d_model, d_state):
super().__init__()
# A, B, C, D are fixed matrices (for classic SSM)
self.A = nn.Parameter(torch.randn(d_state, d_state))
self.B = nn.Parameter(torch.randn(d_state, d_model))
self.C = nn.Parameter(torch.randn(d_model, d_state))
self.D = nn.Parameter(torch.randn(d_model)) # scalar for simplicity
def forward(self, x): # x: (batch, N, d_model)
batch_size, N, d_model = x.shape
d_state = self.A.shape[0]
h = torch.zeros(batch_size, d_state, device=x.device) # initial state
outputs = []
# Process sequence token by token: O(N * d_state^2)
for t in range(N):
current_input = x[:, t, :] # (batch, d_model)
h = torch.matmul(self.A, h.unsqueeze(-1)).squeeze(-1) + \
torch.matmul(self.B, current_input.unsqueeze(-1)).squeeze(-1) # (batch, d_state)
y = torch.matmul(self.C, h.unsqueeze(-1)).squeeze(-1) + \
self.D * current_input # (batch, d_model)
outputs.append(y)
return torch.stack(outputs, dim=1) # (batch, N, d_model)
