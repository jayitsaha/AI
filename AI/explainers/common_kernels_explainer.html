1
Understanding GP Kernels
▼

What is it? A Gaussian Process (GP) is a distribution over functions, fully specified by a mean function \(m(x)\) and a covariance function (kernel) \(k(x,x')\): \(f \sim \mathcal{GP}(m, k)\). The kernel is the entire story — it encodes prior beliefs about how the function behaves: how smooth it is, whether it repeats, whether it trends up or down, at what scale it wiggles. Two points that are "close" under the kernel have highly correlated function values; two points that are "far" become nearly independent.

Analogy: Think of a kernel as a pair of glasses you put on before looking at data. The RBF lens sees only impossibly smooth, gently rolling landscapes. The Matérn lens sees more realistic, slightly rugged terrain — like an actual mountain range instead of a rendered 3D hill. The periodic lens only sees repeating waves. The linear lens sees straight ramps. Choosing a kernel is choosing which family of shapes your model is even capable of imagining before it ever sees data.

💡 If you remember one thing

A kernel must be symmetric and positive semi-definite (Mercer's condition) — any valid choice implicitly corresponds to an inner product \(k(x,x') = \phi(x)^\top \phi(x')\) in some (possibly infinite-dimensional) feature space \(\phi\). Different kernels correspond to different implicit feature spaces, hence different inductive biases about smoothness, periodicity, or trend.

2
How Each Kernel Family Works Internally
▼

Squared-Exponential / RBF

\(k(x,x') = \sigma^2 \exp\!\left(-\dfrac{(x-x')^2}{2\ell^2}\right)\). Infinitely differentiable — samples are \(C^\infty\)-smooth. The lengthscale \(\ell\) controls how far apart two inputs can be before correlation decays: small \(\ell\) → wiggly functions, large \(\ell\) → near-flat functions. It is the default "I have no strong prior beyond smoothness" kernel, but it is often criticized as unrealistically smooth for physical processes.

Matérn Family

\(k_\nu(r) = \sigma^2 \dfrac{2^{1-\nu}}{\Gamma(\nu)}\left(\dfrac{\sqrt{2\nu}\,r}{\ell}\right)^{\!\nu} K_\nu\!\left(\dfrac{\sqrt{2\nu}\,r}{\ell}\right)\), where \(K_\nu\) is a modified Bessel function and \(r=|x-x'|\). The smoothness parameter \(\nu\) gives a dial between "rough" and "RBF-smooth": as \(\nu \to \infty\), the Matérn kernel converges exactly to RBF. Half-integer \(\nu\) gives closed forms with no Bessel function needed — these are the three variants used in practice: \(\nu=\tfrac12\) (exponential / Ornstein–Uhlenbeck, continuous but nowhere differentiable — like Brownian-motion-flavored noise), \(\nu=\tfrac32\) (once differentiable), \(\nu=\tfrac52\) (twice differentiable, a common default for physical/spatial data).

Periodic (Exp-Sine-Squared)

\(k(x,x') = \sigma^2 \exp\!\left(-\dfrac{2\sin^2(\pi|x-x'|/p)}{\ell^2}\right)\). Built by warping the input through \(u(x) = (\sin(2\pi x/p), \cos(2\pi x/p))\) and applying RBF to \(\lVert u(x)-u(x')\rVert\) — this literally wraps the real line onto a circle of circumference \(p\), so the kernel automatically repeats with period \(p\). \(\ell\) still controls smoothness within each cycle.

Linear & Polynomial

Linear: \(k(x,x') = \sigma_b^2 + \sigma_v^2 (x-c)(x'-c)\) — this is exactly the covariance implied by Bayesian linear regression with a Gaussian prior on the slope; samples are straight lines through a random pivot. Polynomial: \(k(x,x') = (\sigma_v^2\, x\cdot x' + c)^d\) generalizes this to degree-\(d\) curves with cross-terms. Both are non-stationary — they depend on the absolute position of \(x\) and \(x'\), not just their difference, unlike every kernel above.

Spectral Mixture (Wilson & Adams, 2013)

\(k(\tau) = \sum_{q=1}^Q w_q \exp(-2\pi^2\tau^2 v_q)\cos(2\pi\tau\mu_q)\). By Bochner's theorem, every stationary kernel is the Fourier transform of some spectral density. SM directly parametrizes that spectral density as a mixture of Gaussians (one per frequency component \(\mu_q\)) and inverts the Fourier transform in closed form. With enough components \(Q\), it can approximate essentially any stationary covariance — it is a near-universal kernel, subsuming RBF (\(Q{=}1,\mu_1{=}0\)) and quasi-periodic structure as special cases.

🔑 Kernels compose

Sums and products of valid kernels are still valid kernels. \(k_{\text{periodic}} \times k_{\text{RBF}}\) gives a locally periodic function (repeats, but drifts over long ranges). \(k_{\text{linear}} + k_{\text{periodic}}\) gives a trend plus seasonality. This compositional algebra is why kernels are often called the "grammar" of Gaussian process modeling.

3
Why It Works — The Math
▼

Deriving the Periodic Kernel from RBF

Map \(x \mapsto u(x) = (\sin(\pi x/p), \cos(\pi x/p))\). Then:

$$\lVert u(x)-u(x')\rVert^2 = 2 - 2\cos\!\left(\tfrac{\pi(x-x')}{p}\right) = 4\sin^2\!\left(\tfrac{\pi(x-x')}{p}\right)$$

Substituting this squared "warped distance" into the RBF formula \(\exp(-\lVert u(x)-u(x')\rVert^2 / 2\ell^2)\) yields exactly the Exp-Sine-Squared kernel above — periodicity falls out of wrapping the line onto a circle before measuring Euclidean distance.

Bochner's Theorem & the Spectral Mixture

Any stationary, continuous kernel \(k(\tau)\) (with \(\tau = x-x'\)) has a spectral representation (Wiener–Khinchin):

$$k(\tau) = \int_{-\infty}^{\infty} e^{i2\pi s \tau}\, S(s)\, ds$$

where \(S(s) \geq 0\) is the power spectral density. The spectral mixture kernel simply chooses \(S(s)\) to be a symmetric mixture of \(Q\) Gaussians centered at frequencies \(\pm\mu_q\) with variance \(v_q\); the integral above then has the closed form \(k(\tau)=\sum_q w_q e^{-2\pi^2\tau^2 v_q}\cos(2\pi\tau\mu_q)\). Because Gaussian mixtures can approximate any density arbitrarily well as \(Q\to\infty\), SM kernels can approximate any stationary covariance — including RBF, Matérn, and periodic as special/limiting cases.

Smoothness = Differentiability at the Origin

A GP with kernel \(k\) has sample paths that are (mean-square) \(m\)-times differentiable if and only if \(k(\tau)\) is \(2m\)-times differentiable at \(\tau=0\). RBF is \(C^\infty\) at 0 → infinitely differentiable samples. Matérn-\(\nu\) is exactly \(\lceil \nu \rceil - 1\) times differentiable at 0 for half-integer \(\nu\) (so \(\nu{=}1/2\): 0 times — rough; \(\nu{=}3/2\): once; \(\nu{=}5/2\): twice). This is why the covariance's local curvature at the origin is a direct dial on visual roughness.

⚠️ Common Pitfall

Kernel hyperparameters (\(\ell,\sigma^2,\) period \(p\), degree \(d\), mixture weights) are not free lunches — they must be fit, typically by maximizing the marginal likelihood \(\log p(y\mid X) = -\tfrac12 y^\top K^{-1} y - \tfrac12\log|K| - \tfrac{n}{2}\log 2\pi\). Too small an \(\ell\) overfits noise as signal; too large oversmooths; a periodic kernel with the wrong period aliases badly.

Key Takeaways
▼
KernelStationary?DifferentiabilityTypical use
RBF / SEYes\(C^\infty\)Default smooth prior
Matérn 1/2Yes0 (continuous only)Rough / jagged physical processes
Matérn 3/2Yes1Mildly rough signals

PeriodicYes\(C^\infty\) within cycleSeasonality, cycles
LinearNo\(C^\infty\)Global linear trend
PolynomialNo\(C^\infty\)Global curved trend
Spectral mixtureYesDepends on \(Q\)Arbitrary stationary structure, extrapolation

When to combine:

  • Long-term trend + seasonality → linear + periodic
  • Locally periodic (repeats but drifts) → periodic × RBF
  • Unknown, complex stationary structure → spectral mixture with several components
  • Uncertain smoothness → prefer Matérn 5/2 over RBF as a safer default
💡 Hierarchy

Matérn-\(\nu\) → RBF as \(\nu\to\infty\); Spectral Mixture → RBF as \(Q{=}1\) and \(\mu_1{=}0\); Polynomial degree 1 → Linear kernel. RBF and Matérn are the smoothest, most "default" choices; periodic, linear, polynomial encode strong structural assumptions; spectral mixture is the most flexible but needs the most data to fit well.

Code Trace

import numpy as np
def rbf(x1, x2, l=1.0, sigma2=1.0):
d2 = (x1[:, None] - x2[None, :]) ** 2
return sigma2 * np.exp(-d2 / (2 * l ** 2))
def matern(x1, x2, nu=1.5, l=1.0, sigma2=1.0):
r = np.abs(x1[:, None] - x2[None, :])
if nu == 0.5: s = r / l; return sigma2 * np.exp(-s)
if nu == 1.5: s = np.sqrt(3) * r / l; return sigma2 * (1 + s) * np.exp(-s)
if nu == 2.5: s = np.sqrt(5) * r / l; return sigma2 * (1 + s + s**2/3) * np.exp(-s)
def periodic(x1, x2, l=1.0, p=1.5, sigma2=1.0):
r = np.abs(x1[:, None] - x2[None, :])
s = np.sin(np.pi * r / p)
return sigma2 * np.exp(-2 * s**2 / l**2)
def linear(x1, x2, sv=1.0, sb=0.1, c=0.0):
return sb**2 + sv**2 * np.outer(x1 - c, x2 - c)
def polynomial(x1, x2, sv=1.0, c=1.0, d=2):
return (sv**2 * np.outer(x1, x2) + c) ** d
def spectral_mixture(x1, x2, weights, mus, vs):
tau = x1[:, None] - x2[None, :]
k = np.zeros_like(tau)
for w, mu, v in zip(weights, mus, vs):
k += w * np.exp(-2*np.pi**2*tau**2*v) * np.cos(2*np.pi*tau*mu)
return k
# Draw GP samples from any kernel via Cholesky
def gp_samples(K, n_samples=3, jitter=1e-6, seed=0):
L = np.linalg.cholesky(K + jitter * np.eye(len(K)))
z = np.random.default_rng(seed).standard_normal((len(K), n_samples))
return L @ z # each column is one sample function
