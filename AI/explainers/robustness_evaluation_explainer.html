Understanding Robustness Evaluation
▼

What is it? Machine learning models, especially deep neural networks, are notoriously susceptible to "adversarial examples" — imperceptibly perturbed inputs that cause misclassification. Robustness evaluation quantifies how resilient a model is to such attacks. It typically involves two key metrics: Robust Accuracy (an empirical measure of how well a model performs under specific attacks) and Certified Radius (a mathematical guarantee that a model will classify an input correctly within a certain perturbation ball).

Analogy: Imagine a fortress. Its Robust Accuracy is like testing its defenses by sending a team of highly skilled spies to find weak points and exploit them. If the spies fail to breach the walls, the fortress is robust for *that specific attack*. Its Certified Radius, on the other hand, is like a mathematical proof that *no* attack of a certain magnitude (e.g., a bomb up to 500kg) can breach the walls, regardless of where it's placed or how cleverly it's used. The certified radius offers a stronger, but often looser, guarantee.

💡 If you remember one thing

Robust Accuracy is an *empirical* measure: "How well does the model perform against a *known* adversarial attack within a given perturbation budget \(\epsilon\)?" It's a lower bound on true robustness. Certified Radius is a *mathematical guarantee*: "For a specific input, what is the *largest* perturbation radius \(r\) such that the model *provably* classifies *all* points within that ball correctly?" It's a lower bound on local robustness.

2
How Robustness Metrics Work
▼

Robust Accuracy: Empirical Evaluation with Adversarial Attacks

To measure robust accuracy, we typically use an adversarial attack algorithm (like PGD, FGSM, or AutoAttack) to generate adversarial examples. For each input \(x\) in a test set, the attack aims to find a perturbation \(\delta\) such that \(\| \delta \|_p \le \epsilon\) (where \(\epsilon\) is the perturbation budget, and \(p\) is the norm, typically \(L_\infty\) or \(L_2\)) and the model misclassifies \(x+\delta\). If no such \(\delta\) can be found (or the attack fails to find one), the model is considered robust for that specific input and \(\epsilon\). Robust accuracy is then the fraction of inputs for which the model remains correctly classified after the attack.

The challenge: robust accuracy is only as strong as the attack used. A stronger attack might find more adversarial examples, leading to lower robust accuracy. It's a lower bound on true robustness because there might always be a stronger, undiscovered attack.

Certified Radius: Provable Guarantees with Randomized Smoothing

Certified robustness aims to provide a mathematical guarantee. Instead of searching for an attack, it constructs a "smoothed" version of the classifier. For a base classifier \(f\), a smoothed classifier \(g(x)\) is defined as the class that is most likely when \(f\) is evaluated on many noisy versions of \(x\). That is, \(g(x) = \arg\max_c \mathbb{P}(f(x+\xi)=c)\), where \(\xi \sim \mathcal{N}(0, \sigma^2 I)\) is Gaussian noise.

With a smoothed classifier, one can provably determine a radius \(r\) around any given input \(x\) such that for all points \(x'\) within \(\|x-x'\|_2 \le r\), the smoothed classifier \(g(x')\) will output the same class \(g(x)\). This \(r\) is the certified radius. The key insight is that adding Gaussian noise makes the classifier locally linearizable, allowing for analytical bounds.

Design Decision: When to use which?

Robust accuracy is widely used because it's practical, directly measures performance against known threats, and doesn't require specialized architectures. Certified robustness, while offering stronger guarantees, often yields looser bounds (the certified radius can be much smaller than the true robust region) and can be computationally expensive. Certified methods are crucial for safety-critical applications where provable guarantees are paramount, even if conservative. For general-purpose robustness benchmarking, empirical robust accuracy is usually sufficient.

🔑 Key Property

Robust accuracy is measured *against a specific attack* within an \(\ell_p\)-ball of radius \(\epsilon\). Certified radius provides a *provable guarantee* for *any* \(\ell_2\)-norm perturbation within a radius \(r\), often using a smoothed version of the model. The former is a practical lower bound, the latter a theoretical lower bound.

3
Why It Works — The Math
▼

Formalizing Robust Accuracy

For a classifier \(f:\mathbb{R}^d \to \{1, \dots, K\}\), an input \(x\), and its true label \(y\), the robust accuracy at perturbation budget \(\epsilon\) (with respect to an \(\ell_p\) norm) is:

$$\text{Robust Accuracy}(\epsilon) = \frac{1}{N} \sum_{i=1}^N \mathbb{I}\left( \forall \delta \text{ s.t. } \|\delta\|_p \le \epsilon, f(x_i + \delta) = y_i \right)$$

In practice, the "for all \(\delta\)" part is approximated by running a strong adversarial attack (e.g., PGD) to find the worst-case \(\delta\), and checking if \(f(x_i + \delta_{adv}) = y_i\). The empirical robust accuracy is then:

$$\text{Empirical Robust Accuracy}(\epsilon) = \frac{1}{N} \sum_{i=1}^N \mathbb{I}\left( f(x_i + \text{AdvAttack}(x_i, y_i, \epsilon)) = y_i \right)$$

where \(\text{AdvAttack}(x_i, y_i, \epsilon)\) finds an adversarial perturbation \(\delta\) within the \(\epsilon\)-ball.

Certified Radius from Randomized Smoothing

Let \(f\) be a base classifier and \(g\) be its smoothed version, where \(g(x) = \arg\max_c \mathbb{P}(f(x+\xi)=c)\) with \(\xi \sim \mathcal{N}(0, \sigma^2 I)\). The probabilities \(\mathbb{P}(f(x+\xi)=c)\) can be estimated by Monte Carlo sampling. For a given \(x\), let \(c_A\) be the predicted class \(g(x)\) and \(c_B\) be the second most likely class.

If we can establish lower and upper bounds on these probabilities, say \(p_A \ge \underline{p_A}\) and \(p_B \le \overline{p_B}\), then the certified \(\ell_2\) radius \(r\) around \(x\) for which \(g(x')=c_A\) for all \(\|x-x'\|_2 \le r\) is given by (Cohen et al., 2019):

$$r = \frac{\sigma}{2} \left( \Phi^{-1}(\underline{p_A}) - \Phi^{-1}(\overline{p_B}) \right)$$

where \(\Phi^{-1}\) is the inverse CDF of the standard normal distribution. This formula explicitly links the noise level \(\sigma\) and the separation between the top two class probabilities to the guaranteed radius. A larger \(\sigma\) or a larger gap between \(\underline{p_A}\) and \(\overline{p_B}\) leads to a larger certified radius.

⚠️ Common Pitfall

A model can have high standard accuracy but low robust accuracy (i.e., it's vulnerable to adversarial attacks). Conversely, a model trained for robustness might have slightly lower standard accuracy but significantly higher robust accuracy and larger certified radii. These metrics are not interchangeable and measure different aspects of model performance.

Key Takeaways
▼

When to use Robust Accuracy:

  • For practical benchmarking against known adversarial threats.
  • When comparing different robust training methods (e.g., adversarial training).
  • To quickly assess a model's empirical resilience in a specific threat model (e.g., \(\ell_\infty\) attacks with \(\epsilon=8/255\)).
  • When computational cost of certification is prohibitive for large models or datasets.

When to use Certified Radius:

  • In safety-critical applications (e.g., autonomous driving, medical diagnosis) where provable guarantees are essential.
  • To understand the fundamental limits of a model's local robustness, independent of specific attack algorithms.
  • When designing new robust methods, to ensure they provide mathematically sound guarantees, not just empirical resistance.
  • To establish a baseline of provable robustness, even if the certified radii are small.

Trade-offs: Robust accuracy is typically higher than certified accuracy (i.e., empirical attacks often fail to find a perturbation, even if one exists, or certified bounds are conservative). Certified radii are often much smaller than the actual robust region. There's an ongoing research effort to close this gap and develop methods that achieve both high empirical and provable robustness.

💡 Robustness is a spectrum

Neither robust accuracy nor certified radius tells the whole story. A truly robust system often requires a combination of empirical testing (against the strongest known attacks) and theoretical guarantees (for safety-critical components), alongside other defense strategies like detection and recovery mechanisms.

import torch
import torch.nn.functional as F
from advertorch.attacks import LInfPGDAttack # or other attack library
from scipy.stats import norm # for inverse CDF (Phi_inv)
# Assume 'model' is a trained PyTorch classifier
# Assume 'test_loader' provides (x, y) batches
def evaluate_robust_accuracy(model, test_loader, epsilon, attack_params):
model.eval()
robust_correct = 0
for x, y in test_loader:
# 1. Generate adversarial examples (e.g., PGD)
attacker = LInfPGDAttack(model, loss_fn=F.cross_entropy, eps=epsilon, **attack_params)
x_adv = attacker.perturb(x, y)
# 2. Classify adversarial examples
with torch.no_grad():
output = model(x_adv)
pred = output.argmax(dim=1, keepdim=True)
# 3. Count correct classifications
robust_correct += pred.eq(y.view_as(pred)).sum().item()
return robust_correct / len(test_loader.dataset)
def certify_radius(smoothed_classifier, x, y_pred, sigma, alpha=0.001):
"""Estimates and certifies radius for a single input x."""
# 1. Estimate probabilities for top-1 and top-2 classes
# (This involves many forward passes of base_classifier with noise)
p_A_lower, p_B_upper = smoothed_classifier.estimate_bounds(x, y_pred, alpha)
# 2. Apply the certified radius formula
if p_A_lower == p_B_upper: # or p_A_lower is 0.5 and p_B_upper is 0.5 (for binary)
return 0.0 # Cannot certify a radius if probabilities are equal
if p_A_lower < 0.5: # Or if p_A_lower is not significantly > p_B_upper
return 0.0 # Not confident enough to certify
radius = sigma / 2 * (norm.ppf(p_A_lower) - norm.ppf(p_B_upper))
return radius
