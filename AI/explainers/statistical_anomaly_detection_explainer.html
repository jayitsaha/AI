Understanding the Concept
▾

An outlier is a data point that deviates so far from the rest of the data that it is unlikely to have been generated by the same process. Detecting outliers matters: a single bad sensor reading, a fraudulent transaction, or a mislabeled training example can silently corrupt downstream analysis.

Three classical univariate tests dominate in practice — they all ask the same question ("is this point suspiciously far from the bulk?") but answer it in different ways:

The Three Methods at a Glance

Z-score — measures how many standard deviations a point lies from the mean: \(z = |x - \mu| / \sigma\). Flag if \(z > \tau\) (typically 2.5–3).

Grubbs' test — formally tests whether the most extreme point in a sample is a statistically significant outlier. Uses a critical value derived from the \(t\)-distribution.

IQR / Tukey fences — uses the interquartile range as a spread measure that ignores tails. Any point outside \([Q_1 - 1.5\cdot\text{IQR},\; Q_3 + 1.5\cdot\text{IQR}]\) is an outlier.

The real-world analogy: imagine weighing students in a class. Z-score says "flag anyone more than 3 standard deviations from the average weight." Grubbs says "run a formal hypothesis test on the heaviest student." IQR says "ignore the top and bottom 25% to define 'normal', then flag anyone double that range away from the middle."

If You Remember One Thing

Z-score and Grubbs are parametric (assume Gaussianity); IQR is non-parametric and robust — it does not break down when outliers inflate the standard deviation.

2
How Each Method Works Internally
▾

Z-Score Method

Given a dataset \(\{x_1, \dots, x_n\}\), compute the sample mean \(\bar{x}\) and sample standard deviation \(s\). For each point \(x_i\), compute \(z_i = |x_i - \bar{x}| / s\). Flag \(x_i\) as an outlier if \(z_i > \tau\), where \(\tau \in \{2.5, 3, 3.5\}\) is a user-chosen threshold. A threshold of 3 corresponds, under Gaussianity, to a two-tailed probability of about 0.27% per point.

Masking Problem

When genuine outliers are present, they inflate both \(\bar{x}\) and \(s\), which inflates the denominator and shrinks the z-score of the outlier — possibly hiding it. This is called masking. Grubbs' test is affected too, but robust alternatives like the modified z-score (using median and MAD) mitigate it.

Grubbs' Test (Maximum Normed Residual Test)

Grubbs tests whether the single most extreme point is an outlier. The test statistic is:

$$G = \frac{\max_i |x_i - \bar{x}|}{s}$$

Under \(H_0\) (all points from the same normal distribution), the critical value at significance level \(\alpha\) is derived from Student's \(t\)-distribution with \(n-2\) degrees of freedom:

$$G_{\text{crit}}(\alpha, n) = \frac{n-1}{\sqrt{n}} \sqrt{\frac{t^2_{\alpha/(2n),\, n-2}}{n - 2 + t^2_{\alpha/(2n),\, n-2}}}$$

Reject \(H_0\) (declare the extreme point an outlier) when \(G > G_{\text{crit}}\). Grubbs must be applied iteratively if multiple outliers are suspected — remove the flagged point and repeat.

IQR / Tukey Fences

Sort the data. Compute the first quartile \(Q_1\) (25th percentile) and third quartile \(Q_3\) (75th percentile). The interquartile range is \(\text{IQR} = Q_3 - Q_1\). Tukey's inner fences are:

$$\text{Lower fence} = Q_1 - 1.5 \cdot \text{IQR}, \quad \text{Upper fence} = Q_3 + 1.5 \cdot \text{IQR}$$

Any point outside \([\text{LF}, \text{UF}]\) is a mild outlier; outside \(Q_1 \pm 3\cdot\text{IQR}\) is an extreme outlier. For a perfect Gaussian, the 1.5×IQR rule flags approximately 0.7% of points by chance.

Why 1.5?

John Tukey chose 1.5 empirically so that for Gaussian data the fence sits at roughly \(\mu \pm 2.7\sigma\) — comparable to a z-score threshold of 2.7, but computed without using the potentially contaminated \(\sigma\).

3
The Math — Derivations & Guarantees
▾

Z-Score: Chebyshev vs Gaussian Interpretation

Without distributional assumptions, Chebyshev's inequality gives a distribution-free bound: \(P(|X - \mu| \geq k\sigma) \leq 1/k^2\). For \(k=3\), at most ~11% of points can lie beyond 3σ from any distribution. Under Gaussianity the bound tightens to 0.27%.

$$P(|Z| > 3) = 2\Phi(-3) \approx 0.0027 \quad \text{(Gaussian)}$$

Grubbs Statistic Distribution Under H₀

The maximum absolute deviation \(\max_i |x_i - \bar{x}|\) follows the distribution of the maximum of \(n\) correlated normal random variables (since they share the sample mean). The exact distribution is complex; Grubbs (1950) derived the relationship with the \(t\)-distribution shown above. The \(p\)-value is obtained via:

$$p = n \cdot P\!\left(t_{n-2} \geq t_0\right), \quad t_0 = G\sqrt{\frac{n(n-2)}{n-1-G^2(n-1)}}$$

The factor \(n\) is a Bonferroni correction for testing \(n\) candidates simultaneously.

IQR Robustness: Breakdown Point

The breakdown point of an estimator is the fraction of data that can be arbitrarily corrupted before the estimator becomes arbitrarily bad. The sample mean has breakdown point 0 (one extreme point can move it anywhere). The median has breakdown point 50%. The IQR has breakdown point 25% — you need to corrupt more than 25% of the data before it explodes. This is why IQR fences are preferred in practice when contamination rates are unknown.

Key Formulas Summary

Z-score: \(z_i = |x_i - \bar{x}| / s\); flag if \(z_i > 3\)
Grubbs: \(G = \max_i |x_i - \bar{x}| / s\); compare to \(G_{\text{crit}}(\alpha, n)\)
IQR fences: \([Q_1 - 1.5\cdot\text{IQR},\; Q_3 + 1.5\cdot\text{IQR}]\)

Decision Guide

Use Z-score when data is approximately Gaussian and n is large (n > 200); apply a threshold of 3 for conservative detection.
Use Grubbs when you need a statistically rigorous single-outlier test with a p-value (e.g., lab measurements, clinical data).
Use IQR as your default for exploratory analysis, skewed distributions, or when outliers may contaminate mean/std estimates.

Key Takeaways & Code
▾
Core Insight

All three methods measure "distance from the bulk." They differ in how they estimate the bulk (mean±std vs quartiles) and whether they attach a formal probability to the deviation.

From-Scratch Python Implementation

import numpy as np
from scipy import stats
def zscore_outliers(x, threshold=3.0):
mu, s = np.mean(x), np.std(x, ddof=1)
z = np.abs(x - mu) / s # z_i = |x_i - mu| / s
return z > threshold # True where outlier
def grubbs_test(x, alpha=0.05):
n = len(x); mu, s = np.mean(x), np.std(x, ddof=1)
G = np.max(np.abs(x - mu)) / s # test statistic
t_crit = stats.t.ppf(1 - alpha / (2*n), df=n-2)
G_crit = ((n-1)/np.sqrt(n)) * np.sqrt(t_crit**2 / (n-2+t_crit**2))
return G, G_crit, G > G_crit # stat, critical, is_outlier
def iqr_outliers(x, k=1.5):
Q1, Q3 = np.percentile(x, [25, 75])
IQR = Q3 - Q1
lower, upper = Q1 - k*IQR, Q3 + k*IQR
return (x < lower) | (x > upper) # True where outlier
