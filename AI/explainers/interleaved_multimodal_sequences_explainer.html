Understanding Interleaved Multimodal Sequences
▼

What is it? Most early vision-language models bolt a fixed number of images onto a fixed slot ("one image + one caption"). Real documents don't work that way — a Wikipedia article, a recipe, or a multi-turn chat interleaves photos and paragraphs in arbitrary order, and a photo three screens down is irrelevant to the sentence you're reading now. Interleaved multimodal sequences treat text tokens and image tokens as one linear stream in document order, so the model reads "paragraph → photo → paragraph → photo" exactly like a human scrolling a web page.

Analogy: Imagine reading an illustrated recipe. You don't memorize every photo in the article before you start cooking — you glance at the photo right above the step you're currently reading, and mostly ignore photos attached to other steps. A well-designed interleaved model builds that locality bias directly into its attention pattern instead of hoping the network learns it from scratch.

💡 If you remember one thing

An interleaved sequence is a single ordered list \(z_1, z_2, \dots, z_N\) where each \(z_i\) is either a text token or an image (patch/latent) token, tagged with a modality label and a document position. The masking rule — which tokens each position is allowed to attend to — is what turns "images and text in one list" into a model that does in-context multimodal learning.

How It Works Internally
▼

Step 1 — Turning an Image Into a Handful of Tokens

A raw image might yield 256+ patch embeddings from a ViT encoder — far too many to splice into a text stream without exploding sequence length. Flamingo's Perceiver Resampler fixes this: a small set of \(k\) learned latent query vectors (e.g. \(k=64\)) cross-attends into the variable-length patch grid and outputs exactly \(k\) tokens per image, regardless of resolution or aspect ratio. Every image — no matter how large — becomes a constant-size chunk in the stream.

Step 2 — Two Schools of Assembly

Flamingo (cross-attention insertion): a frozen, pretrained text-only LLM is kept untouched. New gated cross-attention blocks are interleaved between its frozen self-attention layers. Text tokens never sit in the same sequence as image tokens for self-attention purposes — instead, at each inserted block, text queries cross-attend into the resampled latents of the single most recent image. A learnable gate \(\tanh(\alpha)\), initialized at \(\alpha=0\), lets training start as a no-op (recovering the original frozen LM) and gradually blend in visual information.

MM1 / native interleaving: there is no separate cross-attention module. Resampled image tokens are concatenated directly into the same token sequence the decoder already processes with ordinary causal self-attention — an image is "just more tokens" at their document position. This needs no architectural surgery (any decoder-only LLM works), but every text token now pays full self-attention cost against every previous image token, and the model must learn image-locality behavior itself rather than having it hard-wired.

🔑 Key Design Decision

Flamingo trades architectural complexity for a strong locality inductive bias (image-causal masking, O(n·k) cost) and cheap adaptation of a frozen LM. MM1-style native concatenation trades that bias for simplicity and full end-to-end trainability, at the cost of O(n²) attention over the whole interleaved history.

3
Why It Works — The Math
▼

Formalizing the Interleaved Stream

Let the document produce a sequence \(z_1,\dots,z_N\) with modality labels \(m_i \in \{\text{text}, \text{img}\}\) and document positions. Define \(\text{im}(i)\) as the index of the most recent image whose tokens occur strictly before position \(i\). This single function is the crux of Flamingo-style masking.

Dense Causal Mask (MM1-style, one shared self-attention)

$$\text{Attn}(z)_i = \sum_{j \le i} \operatorname{softmax}_j\!\left(\frac{q_i^\top k_j}{\sqrt{d}}\right) v_j \qquad \forall\, m_i, m_j$$

Every token — text or image — attends to every earlier token regardless of modality. Simple, but the cost of a single query token grows with the number of accumulated image tokens, and the mask carries no modality-aware inductive bias.

Sparse Image-Causal Mask (Flamingo gated cross-attention)

Text self-attention stays exactly as in the frozen LM (causal, text-only). Separately, at each gated cross-attention block, a text token \(i\) cross-attends only into the resampled tokens of image \(\text{im}(i)\):

$$\text{XAttn}(z)_i = \sum_{j \,\in\, \text{tokens}(\text{im}(i))} \operatorname{softmax}_j\!\left(\frac{q_i^\top k_j}{\sqrt{d}}\right) v_j$$

The block's output is merged back with a learned gate:

$$x_i \leftarrow x_i + \tanh(\alpha)\cdot \text{XAttn}(\text{LN}(x_i))$$

Because the mask restricts the key/value set to \(k\) tokens (one image's latents) instead of all \(n\) prior tokens, this cross-attention costs \(O(n\cdot k)\) rather than \(O(n^2)\), and text before the first image trivially attends to nothing (\(\text{im}(i)\) undefined ⇒ cross-attention skipped).

⚠️ Common Pitfall

"Image-causal" does not mean "attends to all past images" — it means attends to the single nearest preceding image only. Letting text attend to every past image (instead of just \(\text{im}(i)\)) reintroduces the O(n²)-style cost Flamingo was designed to avoid and dilutes the gradient signal for the image actually being discussed. Getting this off-by-one wrong (using the image at or after position \(i\)) also breaks causality and leaks future information during training.

Key Takeaways
▼

Why interleaving matters:

  • Enables true few-shot in-context learning across modalities: multiple (image, text) exemplar pairs sit in one context window, and causal text self-attention lets the final query chain back through every prior example.
  • Matches how web/document data actually looks — training on naturally-scraped interleaved corpora (webpages, slides, textbooks) rather than curated (one-image, one-caption) pairs.
  • Supports document-level tasks: multi-image reasoning, visual dialogue, illustrated instructions.

When each masking style wins:

  • Flamingo-style gated cross-attention: best when you must reuse a large frozen LM cheaply, or documents contain many images and O(n²) self-attention over all image tokens is too costly.
  • MM1-style native concatenation: best when you can afford to train the whole stack end-to-end and want architectural simplicity — one attention mechanism, no bespoke cross-attention layers, and the model can in principle learn to attend across multiple images, not just the nearest one.
💡 Hierarchy

Single-image captioning (one image, one caption) ⊂ Interleaved dense causal (MM1: many images/text, one shared O(n²) mask) ⊂ Interleaved image-causal (Flamingo: many images/text, sparse O(n·k) mask with an explicit locality prior). Each generalizes the previous by allowing more images per context, at a different point on the simplicity/efficiency trade-off curve.

import numpy as np
# Document: text segments interleaved with 3 images
doc = ["The","cat","sat", IMG(1), "on","mat", IMG(2), "Now","consider", IMG(3), "this","?"]
# Step 1: Perceiver Resampler -- variable patches -> fixed k tokens/image
def perceiver_resample(patch_embeds, latents, n_layers=6):
for _ in range(n_layers):
latents = cross_attn(q=latents, kv=concat(patch_embeds, latents))
return latents # shape (k, d), k fixed regardless of resolution
# Step 2: assemble interleaved token stream in document order
tokens = flatten([tok_embed(t) if is_text(t) else perceiver_resample(t) for t in doc])
# Step 3a: MM1-style dense causal mask (one shared self-attention)
def dense_causal_mask(n):
return np.tril(np.ones((n, n))) # allowed[i][j] = 1 if j <= i
# Step 3b: Flamingo-style sparse image-causal mask
def most_recent_image(i, modality, image_id):
for j in range(i-1, -1, -1):
if modality[j] == "img":
return image_id[j]
return None
def gated_xattn(x_i, image_latents, alpha):
out = cross_attn(q=x_i, kv=image_latents)
return x_i + np.tanh(alpha) * out # alpha starts at 0 -> no-op at init
# Step 4: next-token prediction uses causal text history + nearest image
logits = lm_head(decoder(tokens, dense_mask_or_gated_xattn))
