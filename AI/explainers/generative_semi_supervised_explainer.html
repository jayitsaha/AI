Generative Models for Semi-Supervised Learning

Modeling the joint distribution \(p(x, y)\) to leverage unlabeled data — EM over Gaussian mixtures shifts the decision boundary to respect data structure.

Advanced Classical ML Semi-Supervised EM Algorithm · GMM · Bayesian
1
Understanding the Concept

Most classifiers only model which label given data — the conditional \(p(y \mid x)\). A generative semi-supervised model instead models the full joint \(p(x, y)\) = \(p(x \mid y)\,p(y)\). This makes unlabeled data useful: they constrain the shape of each class-conditional density \(p(x \mid y = k)\), which in turn pins the decision boundary.

Everyday Analogy

Imagine sorting fruit by color (label) and size (feature). With only 10 labeled fruits you draw a shaky boundary. But even unlabeled fruits cluster by size on the table — their arrangement tells you where the clusters live, so your boundary snaps to the natural gap. Generative SSL does this mathematically.

The Core Insight

Unlabeled data \(\{x_i\}\) are i.i.d. from the marginal \(p(x) = \sum_k \pi_k\,p(x \mid y=k)\). Fitting this marginal — even without labels — tightens the estimate of each class-conditional, pulling the decision boundary into natural low-density gaps.

The canonical implementation: model each class as a Gaussian, fit a Gaussian Mixture Model (GMM) with the Expectation-Maximization (EM) algorithm. Labeled points supply hard class assignments; unlabeled points contribute soft fractional assignments called responsibilities.

If You Remember One Thing

Unlabeled data shift the decision boundary by reshaping the class-conditional Gaussians — EM soft-assigns unlabeled points to classes, letting cluster structure override the labeled-only boundary.

How It Works — EM for Generative SSL

The Joint Model

Let \(K\) classes, mixing weights \(\pi_k\), per-class Gaussians \(\mathcal{N}(\mu_k, \Sigma_k)\). The complete-data log-likelihood (if all labels were known) is:

$$\ell_c(\theta) = \sum_{i \in \mathcal{L}} \log p(x_i, y_i; \theta) + \sum_{j \in \mathcal{U}} \log p(x_j; \theta)$$

where \(\mathcal{L}\) = labeled set, \(\mathcal{U}\) = unlabeled set, and the marginal for unlabeled points is the mixture:

$$p(x; \theta) = \sum_{k=1}^K \pi_k\,\mathcal{N}(x;\,\mu_k,\,\Sigma_k)$$

E-Step — Compute Responsibilities

For each unlabeled point \(x_j\), compute the posterior probability it belongs to class \(k\):

$$r_{jk} = \frac{\pi_k\,\mathcal{N}(x_j;\,\mu_k,\,\Sigma_k)}{\sum_{k'} \pi_{k'}\,\mathcal{N}(x_j;\,\mu_{k'},\,\Sigma_{k'})}$$

For each labeled point \((x_i, y_i)\), the responsibility is hard: \(r_{ik} = \mathbf{1}[y_i = k]\).

M-Step — Update Parameters

Define the effective count for class \(k\):

$$N_k = \underbrace{\sum_{i \in \mathcal{L}} \mathbf{1}[y_i=k]}_{\text{labeled}} + \underbrace{\lambda \sum_{j \in \mathcal{U}} r_{jk}}_{\text{unlabeled (weighted by }\lambda)}$$

where \(\lambda \in (0,1]\) down-weights unlabeled data if the model is misspecified. Then:

$$\hat{\mu}_k = \frac{1}{N_k}\Bigl(\sum_{i \in \mathcal{L}} \mathbf{1}[y_i=k]\,x_i + \lambda\sum_{j \in \mathcal{U}} r_{jk}\,x_j\Bigr)$$
$$\hat{\Sigma}_k = \frac{1}{N_k}\Bigl(\sum_{i \in \mathcal{L}} \mathbf{1}[y_i=k](x_i-\hat{\mu}_k)(x_i-\hat{\mu}_k)^\top + \lambda\sum_{j \in \mathcal{U}} r_{jk}(x_j-\hat{\mu}_k)(x_j-\hat{\mu}_k)^\top\Bigr)$$
$$\hat{\pi}_k = \frac{N_k}{\sum_{k'}N_{k'}}$$

Classification

At test time, apply Bayes' rule using the fitted generative model:

$$\hat{y} = \arg\max_k\;\hat{\pi}_k\,\mathcal{N}(x;\,\hat{\mu}_k,\,\hat{\Sigma}_k)$$
Critical Caveat

The SSL improvement only materialises when the generative model is roughly correct — i.e., the data truly form Gaussian clusters aligned with class labels. If classes overlap complexly or the cluster structure contradicts the label structure, unlabeled data can hurt performance (the "SSL degradation" phenomenon documented by Cozman & Cohen 2002).

Why It Works — Information Flow & Guarantees

EM Monotonically Increases the Observed Log-Likelihood

Define \(Q(\theta;\theta^{\text{old}}) = \mathbb{E}_{z \mid x,\theta^{\text{old}}}[\log p(x,z;\theta)]\). The EM guarantee is:

$$\ell(\theta^{\text{new}}) \;\geq\; Q(\theta^{\text{new}};\theta^{\text{old}}) \;\geq\; Q(\theta^{\text{old}};\theta^{\text{old}}) = \ell(\theta^{\text{old}})$$

The first inequality uses Jensen + the identity \(\log p(x;\theta) = Q - \mathbb{E}[\log q(z)]\). Each EM step is guaranteed to not decrease the marginal likelihood — convergence to a local maximum is assured.

Why Unlabeled Data Carry Information

The Fisher information in \(n_u\) unlabeled observations about \(\theta\) is:

$$\mathcal{I}_U(\theta) = n_u\,\mathbb{E}_x\!\left[\nabla_\theta \log p(x;\theta)\,\nabla_\theta \log p(x;\theta)^\top\right]$$

This is non-zero whenever \(p(x;\theta)\) is identifiable from \(x\) alone — precisely when the generative model is correct. The combined (labeled + unlabeled) Fisher information is \(\mathcal{I}_L + \mathcal{I}_U\), so the MLE from both is at least as efficient as from labeled data alone.

Bayes Optimal Decision Boundary

For two Gaussian classes with equal covariance \(\Sigma\), the Bayes boundary is the linear hyperplane:

$$(\mu_1 - \mu_2)^\top \Sigma^{-1} x = \frac{1}{2}(\mu_1^\top\Sigma^{-1}\mu_1 - \mu_2^\top\Sigma^{-1}\mu_2) - \log\frac{\pi_1}{\pi_2}$$

Better estimates of \(\mu_k, \Sigma, \pi_k\) from EM (using unlabeled data) move this boundary closer to the true Bayes boundary.

Connection to the Cluster Assumption

The cluster assumption in SSL states: the decision boundary should pass through low-density regions of \(p(x)\). The generative model enforces this automatically — the boundary between class posteriors \(p(y=k \mid x)\) lies exactly in low-density zones of the fitted marginal GMM, because each component's density falls off in that region.

Decision Guide

Use generative SSL when: data cluster visibly, clusters correspond to classes, labeled data is very scarce (<1% of total), and you can afford model misspecification checks.
Avoid when: class structure is non-Gaussian, cluster structure contradicts class structure (then unlabeled data will hurt), or you need discriminative accuracy on boundary cases.
