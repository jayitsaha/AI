Diagonalization: Conditions & Multiplicity

When can a matrix be diagonalized? Algebraic vs geometric multiplicity, defective matrices, and the Jordan alternative
Foundational Lean Intermediate Linear Algebra Eigenvalues Spectral Theory
1
Understanding Diagonalization
▼

What is diagonalization? A square matrix \(A\) is diagonalizable if there exists an invertible matrix \(P\) such that \(P^{-1}AP = D\), where \(D\) is diagonal. Intuitively, diagonalizing \(A\) means finding a new coordinate system (the eigenvector basis) in which the transformation \(A\) acts as pure stretching along each axis — no mixing, no shearing.

Analogy: Imagine a funhouse mirror that stretches and tilts your reflection in complicated ways. Diagonalization finds the special "magic viewing angles" (eigenvectors) from which the mirror looks perfectly simple — it only stretches, never tilts. If no such set of angles exists (defective matrix), the mirror is fundamentally twisted and cannot be simplified that way.

Why it matters: A diagonal matrix \(D\) is trivial to work with: \(D^n\) just raises each diagonal entry to the \(n\)th power. So computing \(A^n\) becomes \(A^n = PD^nP^{-1}\) — an enormous simplification for differential equations, Markov chains, and PageRank.

💡 If you remember one thing

A matrix is diagonalizable if and only if for every eigenvalue \(\lambda\), its geometric multiplicity equals its algebraic multiplicity: \(\dim(\ker(A-\lambda I)) = \text{multiplicity of } \lambda \text{ as root of } \det(A - \lambda I)\). When this fails for any eigenvalue, the matrix is defective and cannot be diagonalized.

2
Algebraic vs Geometric Multiplicity
▼

Algebraic Multiplicity (AM): what the characteristic polynomial says

The characteristic polynomial of an \(n \times n\) matrix \(A\) is \(p(\lambda) = \det(\lambda I - A)\), a degree-\(n\) polynomial. When factored over \(\mathbb{C}\), it has the form:

$$p(\lambda) = (\lambda - \lambda_1)^{a_1}(\lambda - \lambda_2)^{a_2}\cdots(\lambda - \lambda_k)^{a_k}$$

The algebraic multiplicity of eigenvalue \(\lambda_i\) is the exponent \(a_i\) — how many times it appears as a root of \(p(\lambda)\). The sum \(a_1 + a_2 + \cdots + a_k = n\).

Geometric Multiplicity (GM): what the eigenspace says

The eigenspace of \(\lambda_i\) is \(E_{\lambda_i} = \ker(A - \lambda_i I) = \{v : Av = \lambda_i v\}\) — the set of all eigenvectors for that eigenvalue (plus the zero vector). The geometric multiplicity is its dimension:

$$g_i = \dim\ker(A - \lambda_i I) = n - \operatorname{rank}(A - \lambda_i I)$$
🔑 Fundamental Inequality

For every eigenvalue: \(1 \leq g_i \leq a_i\). Geometric multiplicity is always at least 1 (since \(\lambda_i\) is an eigenvalue, there's at least one eigenvector) and at most the algebraic multiplicity. The "gap" \(a_i - g_i \geq 0\) is called the defect.

The diagonalizability criterion

Diagonalizable \(\Leftrightarrow\) \(g_i = a_i\) for all \(i\) \(\Leftrightarrow\) the eigenvectors of \(A\) span all of \(\mathbb{R}^n\) (or \(\mathbb{C}^n\)).

Diagonalizable example: \(A = \begin{pmatrix}3&0\\0&3\end{pmatrix}\)

Char. poly: \((\lambda-3)^2\), so \(a = 2\).

Eigenspace: \(\ker(A - 3I) = \ker(0) = \mathbb{R}^2\), so \(g = 2\).

Since \(g = a = 2\): diagonalizable (it IS already diagonal).

Defective example: \(A = \begin{pmatrix}2&1\\0&2\end{pmatrix}\)

Char. poly: \((\lambda-2)^2\), so \(a = 2\).

Eigenspace: \(\ker(A - 2I) = \ker\begin{pmatrix}0&1\\0&0\end{pmatrix}\) — only \(\text{span}\{(1,0)\}\), so \(g = 1\).

Since \(g = 1 < a = 2\): NOT diagonalizable.

⚠️ Common Misconception

A repeated eigenvalue does NOT automatically mean the matrix is defective. The \(3 \times 3\) identity \(I_3\) has eigenvalue 3 with \(a = 3\) and \(g = 3\) — perfectly diagonalizable. Defectiveness requires \(g < a\) for some eigenvalue.

3
Why the Condition Works — Proof Sketch
▼

Constructing \(P\): the eigenvector basis

To diagonalize \(A\), we need \(n\) linearly independent eigenvectors as columns of \(P\). Two key facts drive this:

Fact 1: Eigenvectors from different eigenvalues are always linearly independent (provable by induction). So distinct eigenvalues never cause trouble.

Fact 2: For a repeated eigenvalue \(\lambda_i\), we need exactly \(a_i\) linearly independent eigenvectors from its eigenspace. That requires \(\dim E_{\lambda_i} = g_i = a_i\).

Why defective matrices fail

Consider \(A = \begin{pmatrix}2&1\\0&2\end{pmatrix}\). Suppose \(Av = 2v\) for some \(v = (x,y)^\top\). Then \(2x + y = 2x\) gives \(y = 0\). So all eigenvectors have the form \((x, 0)^\top\) — only one independent direction. There is no second eigenvector: the equation \((A-2I)w = v\) for a "generalized eigenvector" \(w\) is consistent, but that means \(w\) satisfies \((A-\lambda I)^2 w = 0\) without \((A-\lambda I)w = 0\). Such vectors populate a Jordan chain, not an eigenspace.

The Jordan Normal Form — the defective alternative

Every matrix is similar to a Jordan normal form: \(A = PJP^{-1}\), where \(J\) is block-diagonal with Jordan blocks. A Jordan block for \(\lambda\) with size \(m\) looks like:

$$J_m(\lambda) = \begin{pmatrix}\lambda & 1 & 0 & \cdots & 0 \\ 0 & \lambda & 1 & \cdots & 0 \\ \vdots & & \ddots & \ddots & \vdots \\ 0 & 0 & \cdots & \lambda & 1 \\ 0 & 0 & \cdots & 0 & \lambda\end{pmatrix}$$

The number of Jordan blocks for \(\lambda\) equals \(g\) (geometric multiplicity). The sum of their sizes equals \(a\) (algebraic multiplicity). When \(g = a\), every Jordan block is \(1 \times 1\) — that IS diagonalization. When \(g < a\), at least one block is larger than \(1 \times 1\), and those super-diagonal 1s cannot be removed.

🔢 Counting Rule

For an \(n\times n\) matrix with eigenvalue \(\lambda\): the number of Jordan blocks = \(g = \dim\ker(A-\lambda I)\); total size of all blocks = \(a\) = root multiplicity in char. poly; size of the largest Jordan block = index of \(\lambda\) = smallest \(k\) such that \(\ker(A-\lambda I)^k = \ker(A-\lambda I)^{k+1}\).

5
Code: Checking Diagonalizability
▼

In practice, you compute eigenvalues and check if the matrix of eigenvectors is invertible (has full rank). Here is a from-scratch NumPy trace for both our example matrices:

import numpy as np
def check_diagonalizability(A):
n = A.shape[0]
eigenvalues, eigenvectors = np.linalg.eig(A) # eig returns (vals, vecs)
# P columns are eigenvectors
P = eigenvectors
rank_P = np.linalg.matrix_rank(P)
is_diag = (rank_P == n) # full rank <=> diagonalizable
return is_diag, eigenvalues, P
# Diagonalizable: A = 2*I (scalar multiple of identity)
A_diag = np.array([[2., 0.], [0., 2.]])
ok, vals, P = check_diagonalizability(A_diag)
print(f"A_diag diagonalizable: {ok}") # True
print(f"Eigenvalues: {vals}") # [2. 2.]
print(f"rank(P) = {np.linalg.matrix_rank(P)}") # 2
# Defective: Jordan block J_2(2)
A_def = np.array([[2., 1.], [0., 2.]])
ok, vals, P = check_diagonalizability(A_def)
print(f"A_def diagonalizable: {ok}") # False
print(f"Eigenvalues: {vals}") # [2. 2.]
print(f"rank(P) = {np.linalg.matrix_rank(P)}") # 1 — rank-deficient!
# Geometric multiplicity: dim(ker(A - lambda*I))
def geo_mult(A, lam):
return A.shape[0] - np.linalg.matrix_rank(A - lam*np.eye(A.shape[0]))
print(geo_mult(A_diag, 2)) # 2 (full eigenspace)
print(geo_mult(A_def, 2)) # 1 (only one eigenvector direction)
⚠️ Numerical Gotcha

np.linalg.eig on a defective matrix may return numerically close (but not identical) eigenvalues and nearly-dependent eigenvectors. Always use np.linalg.matrix_rank with a tolerance to detect rank deficiency. Exact integer arithmetic (e.g., via sympy) is more reliable for detecting defectiveness.

6
Key Takeaways & Decision Guide
▼

Checklist: Is \(A\) diagonalizable?

For each distinct eigenvalue \(\lambda\), compute \(a = \) root multiplicity in \(\det(\lambda I - A)\) and \(g = n - \operatorname{rank}(A - \lambda I)\). If \(g = a\) for all eigenvalues: diagonalizable. Otherwise: defective, and you need Jordan form.

Quick cases

Always diagonalizable: symmetric real matrices (spectral theorem), matrices with \(n\) distinct eigenvalues (all \(a_i = 1\)), scalar matrices \(cI\).

Never diagonalizable over \(\mathbb{R}\): matrices with non-real eigenvalues (unless you extend to \(\mathbb{C}\)), any matrix where \(g < a\) for some eigenvalue.

Note on field: A matrix may fail to be diagonalizable over \(\mathbb{R}\) (no real eigenvalues) yet be diagonalizable over \(\mathbb{C}\). Diagonalizability depends on the field.

💡 Connection to PCA & SVD

The spectral theorem guarantees that every symmetric matrix \(A = A^\top\) is orthogonally diagonalizable: \(A = Q\Lambda Q^\top\) where \(Q\) has orthonormal eigenvectors. This is the foundation of PCA — the eigenvectors of the covariance matrix form the principal component directions. Asymmetric matrices may be defective; that is why SVD (which decomposes any matrix) is more general than eigendecomposition.
