Why Logistic Regression is a Linear Classifier

Despite using a nonlinear sigmoid function, the decision boundary is always a hyperplane

Intermediate Classical ML Logistic Regression Key Insight
1
Understanding the Concept
›

Logistic regression outputs a probability — a smooth S-curve (the sigmoid) that squashes any real number into \((0,1)\). At first glance, this looks thoroughly nonlinear. Yet ML practitioners universally call it a linear classifier. How?

The key is to distinguish what the sigmoid does to probabilities from where the decision boundary sits.

Key Concept — The Core Argument

The decision boundary is the set of points \(\mathbf{x}\) where the model is exactly 50% confident — i.e., where \(\hat{y} = 0.5\). Because \(\sigma(z) = 0.5\) if and only if \(z = 0\), the boundary is simply \(\mathbf{w}^\top \mathbf{x} + b = 0\). That is a hyperplane — linear in \(\mathbf{x}\).

The sigmoid is monotone (strictly increasing). Monotone functions preserve order: if \(z > 0\) then \(\sigma(z) > 0.5\), and if \(z < 0\) then \(\sigma(z) < 0.5\). So predicting class 1 iff \(\hat{y} > 0.5\) is equivalent to predicting class 1 iff \(\mathbf{w}^\top \mathbf{x} + b > 0\) — a purely linear rule. The sigmoid only reshapes the probabilities on either side; it does not reshape which side the boundary falls on.

Insight — One-Sentence Summary

The sigmoid is monotone, so \(\{\sigma(\mathbf{w}^\top\mathbf{x}+b)=0.5\} = \{\mathbf{w}^\top\mathbf{x}+b=0\}\) — a hyperplane; nonlinearity only reshapes probabilities, not the boundary.

2
Internal Mechanics — Step by Step
›

Step 1 — Linear score

The model first computes a scalar logit (log-odds score) \(z = \mathbf{w}^\top\mathbf{x} + b \in \mathbb{R}\). This is a linear function of \(\mathbf{x}\); geometrically it measures signed distance from the hyperplane \(\mathbf{w}^\top\mathbf{x}+b=0\), scaled by \(\|\mathbf{w}\|\).

Step 2 — Sigmoid squashing

The sigmoid \(\sigma(z) = \frac{1}{1+e^{-z}}\) maps \(z\) to \((0,1)\). This step is nonlinear in \(z\), but since \(z\) is itself linear in \(\mathbf{x}\), we can think of \(\sigma\) as merely relabelling the probability axis — it does not introduce any new "kinks" in input space \(\mathbf{x}\).

$$\hat{p} = \sigma\!\left(\mathbf{w}^\top\mathbf{x}+b\right) = \frac{1}{1+\exp\!\left(-\mathbf{w}^\top\mathbf{x}-b\right)}$$

Step 3 — Decision rule

Predict class 1 iff \(\hat{p} \ge 0.5\). Since \(\sigma\) is strictly increasing:

$$\hat{p} \ge 0.5 \iff z \ge 0 \iff \mathbf{w}^\top\mathbf{x}+b \ge 0$$

The decision rule in input space is a half-space. Its boundary \(\mathbf{w}^\top\mathbf{x}+b=0\) is a hyperplane (line in 2D, plane in 3D, hyperplane in \(d\)-D).

Numerical trace (2D example)

Let \(\mathbf{w}=(2,-1)\), \(b=-0.5\). Consider points:

  • \(\mathbf{x}_A = (1,1)\): \(z = 2(1)+(-1)(1)-0.5 = 0.5\), \(\sigma(0.5)=0.622\) → class 1 ✓
  • \(\mathbf{x}_B = (0,1)\): \(z = 0-1-0.5 = -1.5\), \(\sigma(-1.5)=0.182\) → class 0 ✓
  • \(\mathbf{x}_C = (0.25, 0)\): \(z = 0.5+0-0.5 = 0\), \(\sigma(0)=0.500\) → boundary ✗ (threshold exactly)

The boundary passes through \(\mathbf{x}_C\). Moving perpendicular to \(\mathbf{w}\) along the line \(2x_1 - x_2 = 0.5\) keeps you exactly on the boundary — a straight line in 2D. The sigmoid value changes continuously on either side, but the classification flips only when crossing this line.

Warning — Common Confusion

Students often say "the sigmoid makes logistic regression nonlinear." True for the output function \(\hat{p}(\mathbf{x})\). But classification linearity is about the decision boundary, not the probability surface. A model can have a curved probability surface yet a flat decision boundary.

3
Why It Works — Formal Proof
›

We want to characterise the decision boundary \(\mathcal{B} = \{\mathbf{x} : \hat{p}(\mathbf{x}) = 0.5\}\).

$$\hat{p}(\mathbf{x}) = 0.5 \iff \sigma(\mathbf{w}^\top\mathbf{x}+b) = \frac{1}{2}$$

Apply \(\sigma^{-1} = \text{logit}\) (the inverse sigmoid, which exists because \(\sigma\) is a bijection from \(\mathbb{R}\) to \((0,1)\)):

$$\sigma(z) = \frac{1}{2} \iff z = \sigma^{-1}\!\left(\tfrac{1}{2}\right) = \ln\!\frac{0.5}{0.5} = \ln 1 = 0$$

Therefore:

$$\mathcal{B} = \left\{\mathbf{x} \in \mathbb{R}^d : \mathbf{w}^\top\mathbf{x}+b = 0\right\}$$

This is an affine subspace of dimension \(d-1\) — a hyperplane. \(\square\)

Why monotonicity is the crucial property

The argument works for any strictly increasing link function \(g\), not just the sigmoid. The logit link \(g = \sigma^{-1}\) makes logistic regression a Generalized Linear Model (GLM); the linear predictor \(\eta = \mathbf{w}^\top\mathbf{x}+b\) is what makes it linear. The link function \(g\) just maps between probability space and linear predictor space — it cannot curve the boundary because it operates on a scalar after the linear combination is done.

Key Theorem

For any strictly monotone \(g: \mathbb{R} \to (0,1)\) and threshold \(\tau \in (0,1)\), the classifier \(\hat{y} = \mathbf{1}[g(\mathbf{w}^\top\mathbf{x}+b) \ge \tau]\) has a hyperplane decision boundary \(\mathbf{w}^\top\mathbf{x}+b = g^{-1}(\tau)\).

Log-odds interpretation

Taking the log-odds of \(\hat{p}\):

$$\ln\frac{\hat{p}}{1-\hat{p}} = \mathbf{w}^\top\mathbf{x}+b$$

The log-odds is exactly the linear score. The model is linear in log-odds space — this is why it is both a GLM and a linear classifier.

Decision Guide

Use logistic regression when the classes are (approximately) linearly separable in the feature space, you need calibrated probabilities, or you need model interpretability. Add polynomial or interaction features manually if you need curved boundaries while keeping interpretability. Switch to kernel SVM or neural networks when the data is genuinely nonlinearly separable.

6
Key Takeaways
›

Logistic regression is called a linear classifier because its decision boundary — the surface separating classes — is a hyperplane. This follows from three facts:

  1. The logit (linear score) \(z = \mathbf{w}^\top\mathbf{x}+b\) is linear in \(\mathbf{x}\).
  2. The sigmoid \(\sigma\) is strictly monotone, so \(\sigma(z)=0.5 \iff z=0\).
  3. Therefore, the boundary \(\{z=0\} = \{\mathbf{w}^\top\mathbf{x}+b=0\}\) is a hyperplane.

The sigmoid nonlinearity only reshapes the probability values on either side of the boundary — it cannot move or curve the boundary itself, because it is applied after the linear combination and is monotone.

Insight — Connecting to GLMs

Logistic regression is a Generalized Linear Model (GLM) with a logit link. "Generalized" means the response distribution is non-Gaussian; "linear" still refers to the linear predictor \(\eta = \mathbf{w}^\top\mathbf{x}+b\). The link function \(g\) connects \(\eta\) to the mean, but the linearity is always in \(\eta\), hence in \(\mathbf{x}\).
