Saddle Points, Local Minima & Flat Regions

Classifying critical points via the Hessian — and why it matters for deep learning
Foundational Calculus & Optimization Part I · Section 0.2 Hessian eigenvalues
1
Understanding Critical Points
▼

What is a critical point? A point where the gradient of a function is zero — i.e., \(\nabla f = \mathbf{0}\). The function is momentarily "flat" in the sense that there is no first-order slope, but second-order behaviour (curvature) determines the character of the point. There are three fundamentally different types:

  • Local minimum — the function increases in every direction you step away from the point. A "bowl."
  • Local maximum — the function decreases in every direction. A "hill-top."
  • Saddle point — the function increases in some directions and decreases in others. A "mountain pass."
  • Flat / degenerate region — the second derivative is zero too; higher-order terms determine behaviour. A "plateau."

Why does it matter for ML? Gradient-based optimizers (SGD, Adam) navigate the loss landscape by following the negative gradient. At a critical point the gradient vanishes, so the optimizer stalls. Whether it is stuck for good (a minimum) or can escape (a saddle) determines training dynamics.

If you remember one thing

The Hessian \(H = \nabla^2 f\) classifies every critical point: all eigenvalues positive → local min; all negative → local max; mixed signs → saddle; any zero → degenerate/flat. In high-dimensional deep learning, saddles dominate because the probability that all \(d\) eigenvalues happen to be positive collapses to zero exponentially fast.

2
The Hessian Classification Test
▼

The Second-Order Test

Given a smooth function \(f : \mathbb{R}^d \to \mathbb{R}\), its Hessian at a critical point \(\mathbf{x}^*\) is the \(d \times d\) symmetric matrix of second partial derivatives:

$$H_{ij} = \frac{\partial^2 f}{\partial x_i \, \partial x_j}\bigg|_{\mathbf{x}^*}$$

Because \(H\) is real and symmetric, all its eigenvalues \(\lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_d\) are real. The classification rule follows directly from the sign pattern of eigenvalues:

Eigenvalue patternCritical point typeGradient behaviour
All \(\lambda_i > 0\) Local minimum \(H\) positive definite — every nearby perturbation increases \(f\)
All \(\lambda_i < 0\) Local maximum \(H\) negative definite — every perturbation decreases \(f\)
Mixed \(\lambda_i < 0\) and \(\lambda_j > 0\) Saddle point \(H\) indefinite — increases in some, decreases in other directions
Some \(\lambda_i = 0\) Degenerate / flat Second-order test inconclusive — higher-order terms decide

The Saddle Index

The saddle index of a critical point is the fraction of negative eigenvalues:

$$\text{index}(\mathbf{x}^*) = \frac{\#\{i : \lambda_i < 0\}}{d}$$

A local minimum has index 0. A local maximum has index 1. A "typical" saddle in a \(d\)-dimensional landscape encountered at a given loss level has index \(\approx 0.5\) — roughly half the curvature directions point down. The loss value at a saddle correlates with the index: near the global minimum, most saddles have very small loss and index close to 0, making them nearly indistinguishable from minima in practice.

Key Property — Quadratic Approximation

Near a critical point \(\mathbf{x}^*\), Taylor expansion gives \(f(\mathbf{x}^* + \mathbf{v}) \approx f(\mathbf{x}^*) + \tfrac{1}{2}\mathbf{v}^\top H \mathbf{v}\). The Hessian completely controls local behaviour. The quadratic form \(\mathbf{v}^\top H \mathbf{v}\) is positive for all \(\mathbf{v}\) iff all eigenvalues of \(H\) are positive (positive definite).

Degenerate Case — Higher-Order Analysis Required

For \(f(x) = x^4\), \(f'(0) = 0\) and \(f''(0) = 0\). The Hessian gives eigenvalue 0 — the test is inconclusive. We need the 4th derivative: \(f^{(4)}(0) = 24 > 0\) confirms a minimum. For flat loss plateaus in DL (e.g., near-zero-gradient regions of ReLU networks), the situation is more severe — gradients are numerically zero over a region, not just at a point.

3
Why Deep Learning Is Dominated by Saddles
▼

The Counting Argument

For a critical point to be a local minimum, all \(d\) eigenvalues of the Hessian must be positive. With random initialisation, a gradient computation at a random point in parameter space has eigenvalues scattered across positive and negative values roughly 50/50 (from random matrix theory: the Wigner semicircle law). So the probability that all \(d\) eigenvalues are positive shrinks exponentially:

$$P(\text{all } \lambda_i > 0) \approx \left(\frac{1}{2}\right)^d \longrightarrow 0 \quad \text{as } d \to \infty$$

A modern neural network with \(d \sim 10^7\) to \(10^{10}\) parameters will essentially never encounter a true local minimum during early training. Almost every critical point found is a saddle.

Why Does Training Still Converge?

Dauphin et al. (2014) and Goodfellow et al. confirmed empirically that in practice: (1) local minima are very rare and (2) the rare minima that exist have loss values close to the global minimum. This means:

  • Saddles near the global optimum have almost all eigenvalues near zero or slightly negative — they look like "wide flat valleys." Gradient descent wanders through them.
  • Saddles with high loss (encountered early in training) have more negative eigenvalues, but SGD noise helps escape them.
  • Flat plateaus (e.g., from dying ReLUs) can genuinely stall training — these are the practical concern, not local minima.
The Practical Takeaway for DL

The classical fear of "getting stuck in a local minimum" is largely a myth for overparameterised networks. The real challenge is (a) saddle-point plateaus where gradients are small and (b) flat loss regions from improper initialisation or dead units. This motivated second-order methods (using \(\nabla^2 L\) to detect negative curvature) and adaptive optimizers (Adam) that implicitly rescale curvature.

Escape Time from a Saddle

Near a saddle with most-negative eigenvalue \(\lambda_{\min} < 0\), the time for gradient flow to escape scales as \(T_{\text{escape}} \propto 1/|\lambda_{\min}|\). When \(\lambda_{\min} \approx 0\) (nearly flat saddle), escape is very slow — this is the plateau problem. When \(|\lambda_{\min}|\) is large, escape is fast. SGD noise has variance \(\propto \eta\) that perturbs along the escape eigenvector, giving escape time \(\propto 1/(|\lambda_{\min}| \cdot \eta)\).

Key Takeaways & When Each Type Appears
▼
TypeHessian SignatureGradient BehaviourDL Significance
Local Minimum All \(\lambda_i > 0\) Optimizer stays put — no gradient signal to move Rare in high-d; loss ≈ global min when found
Saddle Point Mixed \(\lambda_i\) Zero gradient — temporarily stalls; escapes via noise or curvature Dominant obstacle in DL; SGD + momentum handles it
Flat Plateau Some \(\lambda_i = 0\) Near-zero gradient over a region — slow convergence Caused by dying ReLUs, bad init, vanishing gradients
Local Maximum All \(\lambda_i < 0\) Unstable — gradient always points away Never encountered in practice; optimizer moves away immediately
Decision Guide

Training stalls early, loss is high? Likely a saddle or flat region — try increasing learning rate, switching to Adam, or checking initialisation. Training stalls late, loss is low? Possibly at or very near a (good) saddle/minimum — gradient clipping or learning-rate warmup helps. Gradients are exactly zero? Dead ReLU problem — check initialisation and consider Leaky ReLU / GELU.

Code — Hessian Classification in NumPy
▼
import numpy as np
def classify_critical_point(H):
"""Classify a critical point by Hessian eigenvalues."""
eigs = np.linalg.eigvalsh(H) # real eigenvalues (H symmetric)
if np.all(eigs > 0): # all positive -> local min
return "local_minimum", eigs
elif np.all(eigs < 0): # all negative -> local max
return "local_maximum", eigs
elif np.any(eigs == 0): # zero eigenvalue -> degenerate/flat
return "degenerate_flat", eigs
else: # mixed signs -> saddle
return "saddle_point", eigs
# Example 1: f(x,y) = x^2 + y^2 (bowl)
H_min = np.array([[2., 0.], [0., 2.]])
print(classify_critical_point(H_min))
# ('local_minimum', array([2., 2.]))
# Example 2: f(x,y) = x^2 - y^2 (horse-saddle)
H_sad = np.array([[2., 0.], [0., -2.]])
print(classify_critical_point(H_sad))
# ('saddle_point', array([-2., 2.]))
# Example 3: f(x) = x^4 at x=0 (flat — 2nd deriv = 0)
H_flat = np.array([[0., 0.], [0., 0.]])
print(classify_critical_point(H_flat))
# ('degenerate_flat', array([0., 0.]))
# High-d: fraction of negative eigenvalues = saddle "index"
n = 1000 # dimension
H_rand = np.random.randn(n, n)
H_sym = (H_rand + H_rand.T) / 2 # make symmetric
eigs_r = np.linalg.eigvalsh(H_sym)
neg_frac = np.mean(eigs_r < 0)
print(f"Neg eigenvalue fraction ≈ {neg_frac:.2f}") # ≈ 0.50
