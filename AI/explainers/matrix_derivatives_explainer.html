1
What is Matrix Calculus?
▼

Scalar calculus asks: "how does a number change as I tweak a number?" Matrix calculus generalises that: "how does a vector or scalar change as I tweak an entire vector or matrix?" The result is not a single number but a gradient vector or a Jacobian matrix.

Think of it like this: when you gradient-descend a neural network, every weight update is a matrix derivative applied to a loss scalar. The three identities on this page appear inside every backprop step you have ever run.

One-Line Summary

Matrix derivatives are just organised collections of scalar derivatives — the layout convention (numerator vs denominator) decides how you arrange them.

The Three Core Identities
$$\frac{\partial (Ax)}{\partial x} = A^\top \quad\text{(denominator layout)}$$
$$\frac{\partial (x^\top\!Ax)}{\partial x} = (A + A^\top)x \quad\Rightarrow\quad 2Ax \text{ if } A \text{ symmetric}$$
$$\frac{\partial \operatorname{tr}(AB)}{\partial A} = B^\top$$
Layout Convention Warning

The answer to \(\partial(Ax)/\partial x\) is either \(A\) or \(A^\top\) depending solely on which layout convention you use — not on the math. Always state your convention explicitly. This page uses denominator layout (also called Hessian layout or Jacobian transpose) as default but includes a toggle to flip all results.

2
Numerator vs Denominator Layout
▼

If \(f: \mathbb{R}^n \to \mathbb{R}^m\) is a vector-valued function of a vector, the derivative has \(m \times n\) scalar entries. The two conventions arrange them differently:

$$\text{Numerator layout: } \frac{\partial f}{\partial x} \in \mathbb{R}^{m\times n},\quad \left(\frac{\partial f}{\partial x}\right)_{ij} = \frac{\partial f_i}{\partial x_j}$$
$$\text{Denominator layout: } \frac{\partial f}{\partial x} \in \mathbb{R}^{n\times m},\quad \left(\frac{\partial f}{\partial x}\right)_{ij} = \frac{\partial f_j}{\partial x_i}$$

For \(f(x) = Ax\) with \(A \in \mathbb{R}^{m\times n}\), \(x \in \mathbb{R}^n\):

  • Numerator layout: \(\partial(Ax)/\partial x = A\) — the \((i,j)\)-th entry is \(\partial(Ax)_i/\partial x_j = A_{ij}\).
  • Denominator layout: \(\partial(Ax)/\partial x = A^\top\) — the \((i,j)\)-th entry is \(\partial(Ax)_j/\partial x_i = A_{ji}\).
Practical Rule

Machine learning papers (PyTorch autograd, backprop derivations) nearly always use denominator layout so that gradient vectors are column vectors of the same shape as the parameter. The formula \(\nabla_x(Ax) = A^\top\) is therefore the one you will see most often.

3
Index-Summation Derivations
▼

Every matrix identity is derived by expanding into scalar index form, differentiating entry-by-entry, and reading off the pattern.

Identity 1 — \(\partial(Ax)/\partial x\)

Write \((Ax)_i = \sum_k A_{ik}\,x_k\). Differentiate w.r.t. \(x_j\):

i-th component of Ax:   (Ax)i = Σk Aik · xk
∂(Ax)i / ∂xj = Aij   (only the k=j term survives)
Numerator layout Jacobian: Jij = Aij  ⟹  J = A
Denominator layout: Jdenomji = Aij = ATji  ⟹  Jdenom = AT

Identity 2 — \(\partial(x^\top\!Ax)/\partial x\)

Expand the scalar \(x^\top\!Ax = \sum_i \sum_j A_{ij}\,x_i\,x_j\). Differentiate w.r.t. \(x_k\):

xTAx = ΣiΣj Aij xi xj
∂/∂xk: the product rule picks terms where i=k or j=k
= Σj Akj xj  +  Σi Aik xi
= (Ax)k + (ATx)k = ((A + AT)x)k
Special case A symmetric: = 2(Ax)k

Identity 3 — \(\partial\operatorname{tr}(AB)/\partial A\)

Write \(\operatorname{tr}(AB) = \sum_i \sum_k A_{ik}\,B_{ki}\). Differentiate w.r.t. \(A_{pq}\):

tr(AB) = ΣiΣk Aik Bki
∂tr(AB)/∂Apq = Bqp   (only the (i,k)=(p,q) term survives)
Gradient matrix Gpq = Bqp = BTpq
⇒ ∂tr(AB)/∂A = BT

Numerical Verification (Finite Differences)
▼

All three identities can be verified numerically with a central-difference approximation \(\partial f/\partial x_i \approx (f(x+\epsilon e_i)-f(x-\epsilon e_i))/(2\epsilon)\). Here are concrete 3×3 / 4×4 checks:

Identity 1 Check — ∂(Ax)/∂x = Aᵀ

With \(A \in \mathbb{R}^{3\times 3}\), \(x \in \mathbb{R}^3\), \(\varepsilon = 10^{-5}\):

A = [[2, 1, 0], x = [1, -1, 2] [0, 3,-1], [1, 0, 4]] Ax = [2·1+1·(-1)+0·2, 0·1+3·(-1)+(-1)·2, 1·1+0·(-1)+4·2] = [1, -5, 9] Jacobian row 0: d(Ax)_0/dx = [d(2x₀+x₁)/dx₀, d/dx₁, d/dx₂] = [2, 1, 0] ← row 0 of A FD check: [(f(x+ε·e₀)-f(x-ε·e₀))/(2ε)]_0 = 2.000000 ✓ [(f(x+ε·e₁)-f(x-ε·e₁))/(2ε)]_0 = 1.000000 ✓ [(f(x+ε·e₂)-f(x-ε·e₂))/(2ε)]_0 = 0.000000 ✓ Numerator layout: J = A ✓ verified Denominator layout: J = Aᵀ ✓ verified
Identity 2 Check — ∂(xᵀAx)/∂x = (A+Aᵀ)x
A = [[1, 2], [3, 4]], x = [1, -1] xᵀAx = 1·(A[0,0]·1 + A[0,1]·(-1)) + (-1)·(A[1,0]·1 + A[1,1]·(-1)) = 1·(1-2) + (-1)·(3-4) = -1 + 1 = 0 Analytical gradient = (A+Aᵀ)x = [[2,5],[5,8]] @ [1,-1] = [-3,-3] FD grad[0] = (xᵀAx at x₀+ε - xᵀAx at x₀-ε)/(2ε) = -3.000000 ✓ FD grad[1] = -3.000000 ✓ For symmetric A (A=Aᵀ): gradient simplifies to 2Ax ✓
Identity 3 Check — ∂tr(AB)/∂A = Bᵀ
A = [[1,2],[3,4]], B = [[5,6],[7,8]] AB = [[1·5+2·7, 1·6+2·8],[3·5+4·7, 3·6+4·8]] = [[19,22],[43,50]] tr(AB) = 19+50 = 69 ∂tr(AB)/∂A[0,0]: FD = (tr((A+ε·E₀₀)B) - tr((A-ε·E₀₀)B))/(2ε) = B[0,0] = 5 = Bᵀ[0,0] ✓ ∂tr(AB)/∂A[0,1]: FD = B[1,0] = 7 = Bᵀ[0,1] ✓ ∂tr(AB)/∂A[1,0]: FD = B[0,1] = 6 = Bᵀ[1,0] ✓ ∂tr(AB)/∂A[1,1]: FD = B[1,1] = 8 = Bᵀ[1,1] ✓ Full gradient matrix = Bᵀ = [[5,7],[6,8]] ✓ verified

Key Takeaways & ML Connections
▼
Where these appear in ML
  • ∂(Ax)/∂x = Aᵀ — backprop through a linear layer: gradient w.r.t. input is \(W^\top \delta\).
  • ∂(xᵀAx)/∂x = (A+Aᵀ)x — gradient of quadratic loss (e.g., L2 regularizer \(\lambda x^\top x\) → gradient \(2\lambda x\)), also the Gauss-Newton approximation.
  • ∂tr(AB)/∂A = Bᵀ — gradient of trace-based losses (covariance trace, Frobenius norm \(\|W\|_F^2 = \operatorname{tr}(W^\top W)\)), used in PCA, LDA, Kalman filters.
The Transpose Pattern

Notice that every result involves a transpose. This is not a coincidence — the transpose arises because differentiation swaps the role of rows and columns in the index expansion. Whenever you see a transpose in a backprop formula, there is an implicit matrix derivative underneath it.

Common Exam / Interview Traps
  • Forgetting to state the layout convention — the "correct" answer flips.
  • For \(x^\top Ax\): the answer is \((A+A^\top)x\), not \(Ax\), unless A is symmetric.
  • For \(\operatorname{tr}(AB)\): gradient is \(B^\top\), not \(B\).
  • Mixing layout conventions mid-derivation produces wrong shapes.
