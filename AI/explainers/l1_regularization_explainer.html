L1 Regularization: The Sparsity Effect

How L1 regularization drives feature selection by shrinking coefficients to zero
Foundational Machine Learning Regularization O(p) Coordinate Descent
1
Understanding L1 Regularization
▼

What is it? L1 regularization, also known as Lasso (Least Absolute Shrinkage and Selection Operator) regression, adds a penalty term to the standard loss function (e.g., Mean Squared Error for linear regression). This penalty is proportional to the sum of the absolute values of the model's coefficients:

$$J(\beta) = \text{Loss}(\beta) + \lambda \sum_{j=1}^p |\beta_j|$$

The goal is to prevent overfitting by discouraging overly complex models. The unique property of L1 regularization is its ability to shrink some coefficients exactly to zero, effectively performing automatic feature selection.

Analogy: Imagine you're designing a recipe and have a pantry full of many spices, but you want to keep the ingredient list short and impactful. L2 regularization (Ridge) would tell you to use a tiny pinch of almost every spice. L1 regularization, however, would force you to pick only a few key spices and use them in meaningful quantities, while completely omitting many others. This results in a simpler, more interpretable recipe (model).

💡 If you remember one thing

L1 regularization encourages sparsity in model coefficients. By adding the sum of absolute coefficients to the loss, it drives less important features' weights to exactly zero, performing automatic feature selection and yielding more interpretable models, unlike L2 regularization which only shrinks coefficients towards zero.

How It Works Internally: The Geometry of Sparsity
▼

The core mechanism of L1 regularization's sparsity effect can be understood geometrically in the parameter space. For a model with two coefficients, \(\beta_1\) and \(\beta_2\):

Loss Contours

The unregularized loss function (e.g., Mean Squared Error) typically forms elliptical contour lines in the \(\beta_1\)-\(\beta_2\) plane. The center of these ellipses is the Ordinary Least Squares (OLS) solution, \(\hat{\beta}_{OLS}\), which minimizes the loss without any penalty.

Constraint Regions

Minimizing \(J(\beta) = \text{Loss}(\beta) + \lambda \sum |\beta_j|\) is mathematically equivalent to minimizing \(\text{Loss}(\beta)\) subject to the constraint \(\sum |\beta_j| \le C\) for some constant \(C\) related to \(\lambda\). The shape of this constraint region is crucial:

  • L1 (\(\sum |\beta_j| \le C\)): This forms a diamond shape (an L1-ball) centered at the origin \((0,0)\). The corners of this diamond lie on the axes.
  • L2 (\(\sum \beta_j^2 \le C^2\)): This forms a circular shape (an L2-ball) centered at the origin \((0,0)\).

The optimal regularized solution, \(\hat{\beta}\), is found at the point where the smallest elliptical loss contour first "touches" the boundary of the constraint region.

The "Kink" at Zero

Because the L1 constraint region has sharp corners at the axes (where one \(\beta_j\) is zero), it is highly probable that the loss contours will intersect the L1 diamond at one of these corners. When this happens, the corresponding coefficient is driven exactly to zero. In contrast, the L2 constraint is smooth and circular, so the loss contours typically make a tangential contact at a point where all coefficients are non-zero, merely shrinking them towards the origin.

🔑 Key Property

The geometric shape of the L1 penalty (a diamond/square rotated by 45 degrees in 2D) has "kinks" at the axes. These kinks make it much more likely for the optimal solution to occur where one or more coefficients are exactly zero, leading to sparsity.

3
Why It Works — The Math Behind Sparsity
▼

The Penalized Loss Function

For linear regression, the L1-regularized objective function (Lasso) is:

$$J(\beta) = \frac{1}{2N} \sum_{i=1}^N (y_i - x_i^\top \beta)^2 + \lambda \sum_{j=1}^p |\beta_j|$$

where \(N\) is the number of samples, \(p\) is the number of features, \(\beta\) is the vector of coefficients, and \(\lambda \ge 0\) is the regularization strength. The \(\frac{1}{2N}\) factor is for convenience in differentiation.

Subgradient and Soft Thresholding

The absolute value function \(|x|\) is not differentiable at \(x=0\). To optimize the L1 objective, we use the concept of a subgradient. The subgradient of \(|\beta_j|\) is:

$$\partial |\beta_j| / \partial \beta_j = \begin{cases} -1 & \text{if } \beta_j < 0 \\ [ -1, 1 ] & \text{if } \beta_j = 0 \\ 1 & \text{if } \beta_j > 0 \end{cases}$$

Setting the subgradient of \(J(\beta)\) to zero gives the optimal \(\hat{\beta}\). For a single coefficient \(\beta_j\), the update rule (e.g., in coordinate descent) involves a process called soft thresholding. If we consider the partial derivative of the unregularized loss with respect to \(\beta_j\) as \(g_j = \frac{\partial \text{Loss}}{\partial \beta_j}\), then the condition for \(\hat{\beta}_j = 0\) to be optimal is:

$$|g_j| \le \lambda$$

This means if the unregularized gradient for a coefficient is small enough (i.e., its contribution to the loss is minor), the L1 penalty will successfully push that coefficient to exactly zero. If \(|g_j| > \lambda\), then \(\hat{\beta}_j = \operatorname{sgn}(g_j) ( |g_j| - \lambda)\). This mathematical property is the direct cause of sparsity.

⚠️ Common Pitfall

L1 regularization's coefficient shrinkage is sensitive to feature scaling. If features are on different scales, the L1 penalty will disproportionately penalize features with larger coefficients. Always standardize your features (mean 0, variance 1) before applying L1 regularization to ensure fair penalization.

Key Takeaways & Practical Considerations
▼

When to use L1 Regularization (Lasso):

  • Feature Selection: When you have many features and suspect only a subset are truly important, L1 can automatically select them by driving others to zero.
  • High-Dimensional Data: Especially useful when \(p > N\) (more features than samples), where OLS is ill-defined or overfits severely.
  • Model Interpretability: A sparse model (with many zero coefficients) is easier to understand and explain, as it highlights the most influential features.
  • Reducing Variance: Like L2, L1 helps reduce model variance, leading to better generalization on unseen data.

When NOT to use L1 Regularization:

  • Highly Correlated Features: If you have a group of highly correlated features, L1 tends to pick one of them and completely zero out the others, which might not be ideal if you want to retain all related features. L2 or Elastic Net (a combination of L1 and L2) might be better here.
  • When All Features Are Important: If you know or suspect that all features contribute meaningfully and should be retained (even if small), L2 regularization might be preferred as it shrinks all coefficients without necessarily setting them to zero.
💡 Hierarchy

OLS (no regularization) ⊂ Ridge (L2) (shrinks coefficients) ⊂ Lasso (L1) (shrinks coefficients and performs feature selection by setting some to zero). Elastic Net combines L1 and L2 for both sparsity and group effect.

Code Trace (Python/NumPy)
▼

Here's a simplified Python example demonstrating L1 regularization using coordinate descent, a common algorithm for Lasso due to its non-differentiability at zero. We'll solve for \(\beta_1, \beta_2\) assuming \(\beta_0\) (intercept) is handled separately or fixed.

import numpy as np
def soft_threshold(rho, lambda_val):
"""Soft thresholding operator for Lasso coordinate descent."""
if np.abs(rho) <= lambda_val:
return 0.0
else:
return np.sign(rho) * (np.abs(rho) - lambda_val)
def lasso_coordinate_descent(X, y, lambda_val, max_iters=1000, tol=1e-4):
N, P = X.shape
beta = np.zeros(P) # Initialize coefficients to zero
for iteration in range(max_iters):
beta_old = np.copy(beta)
for j in range(P): # Iterate through each coefficient
# Calculate residual without beta_j's contribution
# y_pred_minus_j = X @ beta - X[:, j] * beta[j]
# residual = y - y_pred_minus_j
# Simplified for demo: assume X is already centered
# and we're optimizing for beta_j given others.
# This is the 'rho' term in soft thresholding derivation.
rho_j = (X[:, j] * (y - (X @ beta - X[:, j] * beta[j]))).sum()
# Calculate Z_j (denominator in soft thresholding)
Z_j = (X[:, j]**2).sum()
# Update beta_j using soft thresholding
beta[j] = soft_threshold(rho_j, lambda_val * N) / Z_j # N factor for consistent lambda
# Check for convergence
if np.sum(np.abs(beta - beta_old)) < tol:
break
return beta
