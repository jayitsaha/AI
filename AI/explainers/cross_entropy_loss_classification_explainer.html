Cross-Entropy Loss for Classification

The connection between minimizing CE loss, maximizing likelihood, and minimizing KL divergence from the empirical label distribution — plus the clean softmax gradient \(q - p\).
Intermediate Information Theory Loss Functions Must Know
1
Understanding Cross-Entropy Loss
▾

When you train a neural network to classify images — say, "cat", "dog", or "bird" — you need a score that tells the model how wrong its predictions are. Cross-entropy loss is that score. It answers: "How surprised would we be if we assigned probabilities to these classes and the true label turned out to be what it is?"

Analogy: Think of a weather forecaster who says "70% chance of rain." If it actually rains, the forecast was decent. If it doesn't, the forecast was overconfident. Cross-entropy measures exactly this kind of embarrassment — it penalizes overconfident wrong predictions harshly and rewards confident correct ones.

Given a true class label \(y\) and a predicted probability vector \(\hat{q} = (\hat{q}_1, \ldots, \hat{q}_K)\), the classification cross-entropy loss is:

$$\mathcal{L}_{CE} = -\sum_{k=1}^{K} y_k \log \hat{q}_k$$

For a one-hot label (exactly one \(y_k = 1\)), this simplifies elegantly to just \(-\log \hat{q}_{k^*}\) where \(k^*\) is the true class. The loss is small when the model is confident and correct; it blows up toward \(\infty\) when the model assigns near-zero probability to the true class.

Key Insight

Minimizing the average cross-entropy loss over one-hot labels is exactly equivalent to: (1) maximizing the log-likelihood under a categorical distribution (MLE), and (2) minimizing the KL divergence from the empirical label distribution to the model. These three objectives are the same optimization problem.

Prerequisites

Shannon entropy, KL divergence, softmax function, maximum likelihood estimation, one-hot encoding.

2
The Softmax → Cross-Entropy Pipeline
▾

In a classification neural network, raw scores (logits) \(z_1, \ldots, z_K\) exit the final linear layer. These are not probabilities — they can be any real number. The softmax function converts them into a valid probability distribution:

$$\hat{q}_k = \text{softmax}(z)_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$$

Softmax guarantees \(\hat{q}_k > 0\) for all \(k\) and \(\sum_k \hat{q}_k = 1\). Once we have these class probabilities, cross-entropy measures how well they match the one-hot true label.

Numerical Example — 3 Classes

Suppose a model produces logits \(z = [2.1,\ 0.8,\ -0.5]\) and the true class is 0 (cat):

$$\hat{q} = \text{softmax}([2.1,\ 0.8,\ -0.5]) = [0.7425,\ 0.2024,\ 0.0551]$$
$$\mathcal{L}_{CE} = -\log(0.7425) \approx 0.2977$$

The loss is low because the model is correctly confident (74%). If the model had assigned only 10% to the true class, the loss would be \(-\log(0.10) \approx 2.30\).

Softmax–CE Gradient: The Clean Formula

The combined gradient of the cross-entropy loss with respect to the logits (not the probabilities) has a remarkably clean form. For the true class \(k^*\):

$$\frac{\partial \mathcal{L}_{CE}}{\partial z_k} = \hat{q}_k - y_k$$

That's it — just predicted probability minus true label (0 or 1). For our example with true class 0:

$$\nabla_z \mathcal{L} = [0.7425 - 1,\ 0.2024 - 0,\ 0.0551 - 0] = [-0.2575,\ 0.2024,\ 0.0551]$$
Why the gradient is \(\hat{q} - y\)

The softmax Jacobian and the CE gradient chain-rule together to cancel the softmax denominator. The gradient tells the model: "push logit \(z_{k^*}\) up (negative gradient) and push all other logits down." The magnitude of the push is exactly the probability assigned to that class.

Numerical Stability

Never compute \(\log(\text{softmax}(z))\) naively — softmax can overflow with large logits. Use the log-sum-exp trick: \(\log \hat{q}_k = z_k - \log \sum_j e^{z_j}\), computed after subtracting \(\max(z)\). PyTorch's F.cross_entropy does this automatically.

3
Three Equivalent Views: CE = MLE = KL
▾

The power of cross-entropy for classification comes from three perfectly equivalent interpretations. Each gives a different geometric and probabilistic intuition.

View 1 — Minimize Cross-Entropy

Over a dataset of \(N\) examples with empirical label distribution \(\hat{p}(x,y) = \frac{1}{N}\sum_i \delta(x_i, y_i)\), the average CE loss is:

$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N} \log q_\theta(y_i \mid x_i)$$

We minimize this over model parameters \(\theta\) (weights of the neural network).

View 2 — Maximize Log-Likelihood (MLE)

Assume each label \(y_i\) is drawn from a categorical distribution parameterized by the model. The log-likelihood is:

$$\ell(\theta) = \frac{1}{N}\sum_{i=1}^{N} \log q_\theta(y_i \mid x_i)$$

Maximizing \(\ell(\theta)\) is identical to minimizing \(\mathcal{L}\). The negative sign is the only difference.

View 3 — Minimize KL from Empirical Distribution

Define the empirical label distribution \(\hat{p}\) (the one-hot or empirical frequency distribution over classes). The KL divergence from \(\hat{p}\) to the model \(q_\theta\) is:

$$D_{\text{KL}}(\hat{p} \,\|\, q_\theta) = H(\hat{p},\, q_\theta) - H(\hat{p})$$

Since the empirical entropy \(H(\hat{p})\) is a constant (does not depend on \(\theta\)), minimizing the KL is the same as minimizing the cross-entropy \(H(\hat{p}, q_\theta)\). For one-hot labels, \(H(\hat{p}) = 0\), so:

$$D_{\text{KL}}(\hat{p} \,\|\, q_\theta) = H(\hat{p},\, q_\theta) = \mathcal{L}_{CE}$$
The Equivalence Triangle

$$\underbrace{\min_\theta \mathcal{L}_{CE}}_{\text{minimize cross-entropy}} = \underbrace{\max_\theta \ell(\theta)}_{\text{maximize likelihood}} = \underbrace{\min_\theta D_{\text{KL}}(\hat{p} \,\|\, q_\theta)}_{\text{minimize KL from empirical dist}}$$

These are not approximations — they are algebraically identical for the same \(\theta\).

This equivalence is profound: when you use the standard CE loss in PyTorch or TensorFlow, you are simultaneously performing MLE and minimizing the information-theoretic "distance" between what the data actually looks like and what your model predicts.

Multi-Class vs Binary

Binary cross-entropy (BCE) is a special case with \(K = 2\) and sigmoid instead of softmax. The gradient is still \(\hat{q} - y\), but the pipeline is: logit → sigmoid → BCE. The MLE equivalence holds identically — BCE is MLE for a Bernoulli model.

5
The Beautiful Gradient & Key Takeaways
▾

Why the Gradient \(\hat{q} - y\) is Beautiful

The gradient of CE loss with respect to logits \(z\) (through softmax) is simply \(\hat{q} - y\). This is one of the cleanest results in deep learning. Let's derive it for the true class \(k^*\):

$$\frac{\partial \mathcal{L}_{CE}}{\partial z_k} = \frac{\partial}{\partial z_k}\!\left[-\log \hat{q}_{k^*}\right] = \hat{q}_k - y_k$$

When the model is perfectly calibrated (\(\hat{q}_{k^*} = 1\)), the gradient vanishes. The gradient magnitude tells the optimizer exactly how far off the prediction is. This signal is smooth everywhere — unlike, say, hinge loss which is flat far from the margin.

Properties of the Softmax-CE Gradient

  • For the true class: gradient \(= \hat{q}_{k^*} - 1 < 0\), so logit is pushed up.
  • For all other classes: gradient \(= \hat{q}_k > 0\), so logits are pushed down.
  • The gradients sum to zero: \(\sum_k (\hat{q}_k - y_k) = 1 - 1 = 0\). The optimizer "redistributes" probability mass.
  • Gradient is large when model is wrong and confident — large learning signal exactly when needed.

When to Use Cross-Entropy

  • Multi-class classification (exactly one true class per example): softmax + CE.
  • Binary classification: sigmoid + binary CE (BCE).
  • Multi-label classification (multiple true classes): sigmoid per class + BCE per class.
  • Label smoothing: replace one-hot \(y\) with \((1-\epsilon)y + \epsilon/K\) — improves calibration.
The Big Picture

Every time you call nn.CrossEntropyLoss() in PyTorch, you are running MLE on a categorical model, minimizing KL divergence from the data distribution, and getting a gradient signal \(\hat{q} - y\) that is provably the most efficient (in the Fisher information sense) estimator for the softmax parameters. The three perspectives are the same truth seen from different angles.

Common Mistakes
  • Applying softmax before nn.CrossEntropyLoss — this function expects raw logits; it applies log-softmax internally.
  • Using CE loss for regression — CE assumes categorical outputs. Use MSE or MAE for continuous targets.
  • Confusing "CE is low" with "model is calibrated" — CE loss can be low while confidence is still miscalibrated.
