Understanding Primal & Dual Problems
▼

What is it? Every constrained optimization problem — "minimise cost subject to rules" — has a primal form. The dual is a companion problem that, instead of optimising over the original variables, optimises over prices placed on the constraints. These prices are called Lagrange multipliers, and they measure how much violating each constraint "costs." The dual is almost always easier or structurally simpler than the primal.

Analogy: Imagine a factory (primal) that minimises production cost while respecting resource limits. The dual asks: "What's the most you'd pay per unit of each resource such that your budget still never exceeds the factory's minimum cost?" The dual finds the tightest lower bound the resource-pricing game can produce. Under ideal conditions (strong duality) the two games have the same answer.

If you remember one thing

The dual function \(g(\lambda) = \inf_x \mathcal{L}(x,\lambda)\) is always concave and is always a lower bound on the primal optimum \(p^*\), regardless of whether the primal is convex. When Slater's condition holds for a convex primal, the duality gap closes to zero: \(\max_{\lambda \geq 0} g(\lambda) = p^*\).

Prerequisites

Calculus (taking partial derivatives), basic convexity (convex functions and sets), and Lagrange multipliers. Familiarity with KKT conditions is helpful but not required.

2
The Lagrangian & Dual Function
▼

The Primal Problem

We write a general constrained optimisation problem in standard form:

$$p^* = \min_{x} f_0(x) \quad \text{subject to } f_i(x) \leq 0,\; i=1,\ldots,m, \quad h_j(x) = 0,\; j=1,\ldots,p$$

Here \(f_0\) is the objective, \(f_i\) are inequality constraints, and \(h_j\) are equality constraints. The optimal value is \(p^*\). The feasible set is \(\mathcal{D} = \{x \mid f_i(x)\leq 0,\; h_j(x)=0\}\).

The Lagrangian

Attach a multiplier (price) \(\lambda_i \geq 0\) to each inequality and \(\nu_j \in \mathbb{R}\) to each equality. The Lagrangian absorbs the constraints into the objective:

$$\mathcal{L}(x,\lambda,\nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{j=1}^p \nu_j h_j(x)$$

For any feasible \(x\) and \(\lambda \geq 0\), we have \(\mathcal{L}(x,\lambda,\nu) \leq f_0(x)\) — the penalty terms \(\lambda_i f_i(x)\) are non-positive at feasibility. So the unconstrained infimum of \(\mathcal{L}\) over all \(x \in \mathbb{R}^n\) underestimates \(p^*\).

The Dual Function

Minimise the Lagrangian over all (unconstrained) \(x\) to get the dual function:

$$g(\lambda,\nu) = \inf_{x} \mathcal{L}(x,\lambda,\nu)$$

Key properties:

  • Always a lower bound: \(g(\lambda,\nu) \leq p^*\) for all \(\lambda \geq 0\), even if the primal is non-convex.
  • Always concave: \(g\) is the pointwise infimum of affine functions of \((\lambda,\nu)\), hence concave — even when \(f_0\) is not convex.
  • May equal \(-\infty\): If the Lagrangian is unbounded below for some \((\lambda,\nu)\), then \(g = -\infty\) at that point (those multipliers are useless as lower bounds).

The Dual Problem

Find the best (highest) lower bound:

$$d^* = \max_{\lambda \geq 0,\;\nu} g(\lambda,\nu)$$

This is the Lagrange dual problem. It is a concave maximisation problem — always convex, regardless of the primal. The optimal dual value is \(d^*\).

Common Misconception

The dual problem optimises over multipliers \((\lambda,\nu)\), NOT over \(x\). The variable \(x\) was already eliminated when you took \(\inf_x \mathcal{L}\). The dual lives in a completely different space than the primal.

3
Weak & Strong Duality — The Math
▼

Weak Duality (always holds)

Theorem: \(d^* \leq p^*\). The dual optimum is never larger than the primal optimum.

Proof sketch: For any feasible primal \(x\) and dual \((\lambda,\nu)\) with \(\lambda \geq 0\):

$$g(\lambda,\nu) = \inf_{x'}\mathcal{L}(x',\lambda,\nu) \leq \mathcal{L}(x,\lambda,\nu) = f_0(x) + \underbrace{\sum_i \lambda_i f_i(x)}_{\leq 0} + \underbrace{\sum_j \nu_j h_j(x)}_{=0} \leq f_0(x)$$

Taking \(\sup\) over dual variables and \(\inf\) over primal feasible \(x\) gives \(d^* \leq p^*\). The gap \(p^* - d^*\) is called the duality gap.

Strong Duality (requires conditions)

Theorem: If the primal is convex (\(f_0, f_i\) convex, \(h_j\) affine) and Slater's condition holds, then \(d^* = p^*\) (zero duality gap).

Slater's Condition

There exists a strictly feasible point: \(\exists \tilde{x}\) such that \(f_i(\tilde{x}) < 0\) for all \(i\) and \(h_j(\tilde{x}) = 0\) for all \(j\). This ensures the feasible interior is non-empty. In practice, Slater's condition is easy to check and almost always satisfied by well-posed convex programs.

Concrete Example (verified numerically)

Primal: \(\min_x (x-3)^2\) subject to \(x \leq 1\). Feasible set: \((-\infty, 1]\). Unconstrained minimum at \(x=3\) is infeasible, so \(p^* = f(1) = 4\).

Lagrangian: \(\mathcal{L}(x,\lambda) = (x-3)^2 + \lambda(x-1)\). Minimising over \(x\) (setting derivative to zero):

$$\frac{\partial \mathcal{L}}{\partial x} = 2(x-3) + \lambda = 0 \implies x^*(\lambda) = 3 - \frac{\lambda}{2}$$

Substituting back gives the dual function:

$$g(\lambda) = -\frac{\lambda^2}{4} + 2\lambda$$

Dual problem: \(\max_{\lambda \geq 0} g(\lambda)\). Setting \(g'(\lambda) = -\lambda/2 + 2 = 0\) gives \(\lambda^* = 4\), and \(g(4) = -4 + 8 = 4 = p^*\). Zero duality gap.

Why the Dual Gives a Certificate

Any dual feasible point \(\lambda\) certifies \(p^* \geq g(\lambda)\). At optimality, the dual multiplier \(\lambda^*\) is a "shadow price" of the constraint: it equals the rate at which \(p^*\) decreases if you relax the constraint by \(\epsilon\) (increase the right-hand side from 1 to \(1+\epsilon\)). This is the economic interpretation: \(\lambda^* = 4\) means "each unit of extra resource saves 4 units of cost."

KKT Conditions: When Primal = Dual

At strong duality, the primal-dual optimum \((x^*, \lambda^*, \nu^*)\) must satisfy the Karush–Kuhn–Tucker (KKT) conditions: stationarity \(\nabla f_0 + \sum \lambda_i^* \nabla f_i + \sum \nu_j^* \nabla h_j = 0\), primal feasibility, dual feasibility (\(\lambda^* \geq 0\)), and complementary slackness \(\lambda_i^* f_i(x^*) = 0\). Complementary slackness means: either a constraint is tight or its multiplier is zero — never both non-zero simultaneously.

Key Takeaways
▼

The dual is always convex — even when the primal is not. This is why duality is so powerful: you can solve a hard non-convex primal by first solving its convex dual.

Weak duality always holds: \(d^* \leq p^*\). Any dual-feasible point certifies a lower bound on the primal.

Strong duality requires convexity + regularity (e.g., Slater's condition). When it holds, the duality gap is zero and dual multipliers reveal the economic value of each constraint.

Where You See This in ML

Support Vector Machines: the primal maximises the margin. The dual (in terms of support vectors \(\alpha_i\)) leads to the kernel trick — you never need to compute \(w\) explicitly, only inner products \(K(x_i, x_j)\). ADMM and many distributed optimisation algorithms are dual methods. Lagrangian relaxation bounds integer programs. Constrained policy optimisation (CPO) in RL uses dual ascent to enforce safety constraints.

  • Use duality when: the dual is much simpler (fewer variables, unconstrained), or you need a certified lower bound, or the primal lacks a closed form but the dual does.
  • Do not assume strong duality: check Slater's condition. Non-convex primals may have a positive duality gap.
  • Complementary slackness is your diagnostic: if \(\lambda_i^* > 0\), constraint \(i\) is active at optimum; if \(f_i(x^*) < 0\) (slack), then \(\lambda_i^* = 0\).

Code Trace
▼

From-scratch Python for the concrete example: \(\min (x-3)^2\) s.t. \(x \leq 1\). Highlighted lines track the animation steps.

import numpy as np
import scipy.optimize as opt
# ── Primal ────────────────────────────────────────
def f0(x): return (x - 3)**2 # objective
def g1(x): return x - 1 # constraint: g1(x) <= 0
# Primal optimum: constrained min
res = opt.minimize(f0, x0=0.0, constraints={'type':'ineq','fun': lambda x:-g1(x)})
x_star, p_star = res.x[0], res.fun
print(f"x* = {x_star:.4f}, p* = {p_star:.4f}") # 1.0, 4.0
# ── Lagrangian ────────────────────────────────────
def lagrangian(x, lam): return f0(x) + lam * g1(x)
# ── Dual function ─────────────────────────────────
def dual(lam):
# min_x L(x, lam) analytically: x*(lam) = 3 - lam/2
x_opt = 3 - lam / 2
return lagrangian(x_opt, lam) # g(lam) = -lam^2/4 + 2*lam
# ── Dual problem ──────────────────────────────────
lam_vals = np.linspace(0, 8, 400)
g_vals = [dual(l) for l in lam_vals]
lam_star = lam_vals[np.argmax(g_vals)]
d_star = max(g_vals)
print(f"lam* = {lam_star:.4f}, d* = {d_star:.4f}") # 4.0, 4.0
# ── Duality gap ───────────────────────────────────
print(f"Duality gap = {p_star - d_star:.6f}") # 0.0 (strong duality)
# ── Complementary slackness check ─────────────────
print(f"lam* * g1(x*) = {lam_star * g1(x_star):.6f}") # 0.0 (active constraint)
