1
Understanding the Concept

What is it? Ordinal logistic regression is a statistical model for predicting an ordered outcome — categories that have a natural ranking (e.g., low < medium < high, or 1-star < 2-star < 3-star < 4-star < 5-star) — without assuming the gaps between categories are equal.

Real-World Analogy: Imagine a doctor rating a patient's pain level: none / mild / moderate / severe. These are clearly ordered — severe is worse than moderate — but the "distance" from mild to moderate may not be the same as from moderate to severe. Ordinal logistic regression models this structure exactly: it respects the order without forcing artificial equal spacing.

💡 If You Remember One Thing

The proportional-odds model fits a single coefficient vector \(\boldsymbol{\beta}\) that shifts a latent continuous score left or right, while ordered thresholds \(\theta_1 < \theta_2 < \cdots < \theta_{K-1}\) partition that score into \(K\) categories. One \(\boldsymbol{\beta}\), many cut-points — that's the elegance.

One-sentence summary: Ordinal logistic regression models the cumulative probability \(P(Y \leq k)\) of falling in category \(k\) or below via a logistic function of a latent score shifted by predictors, with ordered thresholds ensuring category order is preserved.

2
How It Works Internally

The proportional-odds model (Walker & Duncan 1967; McCullagh 1980) posits a latent continuous variable \(Y^* = \mathbf{x}^\top \boldsymbol{\beta} + \varepsilon\) where \(\varepsilon\) follows a standard logistic distribution. The observed ordinal outcome arises from thresholding \(Y^*\):

$$Y = k \quad \Longleftrightarrow \quad \theta_{k-1} < Y^* \leq \theta_k$$

with boundary conventions \(\theta_0 = -\infty\) and \(\theta_K = +\infty\). This implies:

$$P(Y \leq k \mid \mathbf{x}) = \sigma(\theta_k - \mathbf{x}^\top \boldsymbol{\beta}) = \frac{1}{1 + e^{-(\theta_k - \mathbf{x}^\top \boldsymbol{\beta})}}$$

where \(\sigma(\cdot)\) is the logistic sigmoid. The cumulative logit (log-odds of being ≤ category \(k\)) is:

$$\text{logit}\,P(Y \leq k \mid \mathbf{x}) = \theta_k - \mathbf{x}^\top \boldsymbol{\beta}$$

Note the sign convention: positive \(\beta_j\) means a larger \(x_j\) pushes \(Y^*\) rightward → higher categories more likely. The same \(\boldsymbol{\beta}\) applies to all \(K-1\) cumulative logits — this is the "proportional odds" assumption.

🔑 The Proportional Odds Property

For any pair of covariate vectors \(\mathbf{x}_1, \mathbf{x}_2\), the log-odds ratio \(\log\frac{P(Y\leq k \mid \mathbf{x}_1)/P(Y>k \mid \mathbf{x}_1)}{P(Y\leq k \mid \mathbf{x}_2)/P(Y>k \mid \mathbf{x}_2)}\) is constant across all \(k\). The odds ratio \(e^{\beta_j}\) represents how much a unit increase in \(x_j\) multiplies the odds of being in a lower category, uniformly across all cut-points.

Category probabilities are recovered by differencing cumulative probabilities:

$$P(Y = k \mid \mathbf{x}) = P(Y \leq k \mid \mathbf{x}) - P(Y \leq k-1 \mid \mathbf{x})$$
3
Mathematical Derivation & Estimation

Parameters: \(\boldsymbol{\theta} = (\theta_1, \ldots, \theta_{K-1})^\top\) (thresholds, constrained \(\theta_1 < \cdots < \theta_{K-1}\)) and \(\boldsymbol{\beta} \in \mathbb{R}^p\) (covariate effects), for a total of \(K-1+p\) parameters.

Log-likelihood. For \(n\) observations with \(y_i \in \{1, \ldots, K\}\):

$$\ell(\boldsymbol{\theta}, \boldsymbol{\beta}) = \sum_{i=1}^n \sum_{k=1}^{K} \mathbf{1}[y_i = k]\,\log \Big[\sigma(\theta_k - \mathbf{x}_i^\top \boldsymbol{\beta}) - \sigma(\theta_{k-1} - \mathbf{x}_i^\top \boldsymbol{\beta})\Big]$$

Score equations. Let \(\pi_{ik} = P(Y_i = k \mid \mathbf{x}_i)\), \(F_{ik} = P(Y_i \leq k \mid \mathbf{x}_i) = \sigma(\theta_k - \mathbf{x}_i^\top\boldsymbol{\beta})\), and \(f_{ik} = F_{ik}(1 - F_{ik})\). Then:

$$\frac{\partial \ell}{\partial \theta_k} = \sum_{i=1}^n \frac{f_{ik}}{\pi_{ik}} \mathbf{1}[y_i = k] - \frac{f_{ik}}{\pi_{i,k+1}} \mathbf{1}[y_i = k+1]$$
$$\frac{\partial \ell}{\partial \boldsymbol{\beta}} = -\sum_{i=1}^n \mathbf{x}_i \sum_{k=1}^{K} \mathbf{1}[y_i = k]\left(\frac{f_{ik}}{\pi_{ik}} - \frac{f_{i,k-1}}{\pi_{ik}}\right)$$

These are solved via Newton-Raphson (Fisher scoring). The observed information matrix is block-structured: \(\boldsymbol{\theta}\) and \(\boldsymbol{\beta}\) blocks are linked through the \(f_{ik}\) weights. Convergence is guaranteed (under identifiability) because the log-likelihood is concave in \((\boldsymbol{\theta}, \boldsymbol{\beta})\).

📐 Key Formula Summary

Cumulative probability: \(F_k(\mathbf{x}) = \sigma(\theta_k - \mathbf{x}^\top \boldsymbol{\beta})\)

Category probability: \(\pi_k(\mathbf{x}) = F_k(\mathbf{x}) - F_{k-1}(\mathbf{x})\)

Proportional odds ratio: \(\text{OR}(k) = e^{\boldsymbol{\beta}^\top(\mathbf{x}_2 - \mathbf{x}_1)}\) (constant in \(k\))

⚠️ Proportional Odds Assumption Test

The constant-\(\boldsymbol{\beta}\) assumption must be tested (e.g., Brant test). If it fails — odds ratios vary by category — use a partial proportional odds or stereotype logistic model instead.

5
Key Takeaways
  • Single \(\boldsymbol{\beta}\), multiple thresholds: The covariate effect is global — it shifts the whole latent distribution, not just one boundary.
  • Respects order without equal spacing: Unlike treating outcomes as continuous, ordinal LR makes no equal-interval assumption.
  • Interpret odds ratios as cumulative: \(e^{\beta_j}\) = odds ratio for \(P(Y \leq k)\) vs \(P(Y > k)\), same for every \(k\).
  • Generalizes binary logistic regression: When \(K=2\), the model reduces exactly to binary logistic regression with one threshold \(\theta_1\) and one intercept.
  • When to use: Survey Likert scales, pain scores, education levels, star ratings, disease severity stages.
  • When NOT to use: If proportional odds assumption fails badly, or if categories are truly nominal (use multinomial logistic instead).

Code — From Scratch & Production

From Scratch (NumPy) — Newton-Raphson MLE:

import numpy as np
from scipy.special import expit  # sigmoid σ(x)

def ordinal_log_likelihood(params, X, y, K):
    """Negative log-likelihood for proportional-odds model.
    params = [theta_1, ..., theta_{K-1}, beta_1, ..., beta_p]
    thetas are stored raw; enforced ordered by cumsum trick during fitting.
    """
    n, p = X.shape
    # Unpack: first K-1 are thresholds (sorted), rest are betas
    thetas = np.sort(params[:K-1])          # enforce θ₁ < θ₂ < ...
    beta   = params[K-1:]                   # covariate coefficients

    eta = X @ beta                          # n-vector: xᵀβ for each obs

    log_lik = 0.0
    for i in range(n):
        k = y[i] - 1                        # 0-indexed category
        # P(Y=k) = σ(θₖ - ηᵢ) - σ(θₖ₋₁ - ηᵢ)
        hi = expit(thetas[k]   - eta[i]) if k < K-1 else 1.0
        lo = expit(thetas[k-1] - eta[i]) if k > 0   else 0.0
        prob = hi - lo
        log_lik += np.log(np.maximum(prob, 1e-12))

    return -log_lik  # return negative for minimization

from scipy.optimize import minimize

def fit_ordinal_logistic(X, y, K):
    n, p = X.shape
    # Initial params: evenly-spaced thresholds, zero betas
    init_thetas = np.linspace(-1, 1, K-1)
    init_beta   = np.zeros(p)
    params0 = np.concatenate([init_thetas, init_beta])

    result = minimize(ordinal_log_likelihood, params0,
                      args=(X, y, K), method='L-BFGS-B')
    thetas = np.sort(result.x[:K-1])
    beta   = result.x[K-1:]
    return thetas, beta

def predict_proba(X, thetas, beta, K):
    """Return (n, K) matrix of category probabilities."""
    eta = X @ beta
    F = np.zeros((len(X), K+1))
    F[:, 0]  = 0.0     # P(Y≤0) = 0
    F[:, -1] = 1.0     # P(Y≤K) = 1
    for k in range(K-1):
        F[:, k+1] = expit(thetas[k] - eta)
    return np.diff(F, axis=1)  # P(Y=k) = F(k) - F(k-1)

from statsmodels.miscmodels.ordinal_model import OrderedModel

mod = OrderedModel(df["pain"],              # ordered outcome
                   df[["age","dose"]],      # covariates (no intercept column!)
                   distr="logit")           # proportional-odds / logistic link

res = mod.fit(method="bfgs")
