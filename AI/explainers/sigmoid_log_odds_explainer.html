Sigmoid Function & Log-Odds Interpretation

How logistic regression maps log-odds to probabilities, and why a unit increase in x multiplies the odds by eβ
Foundational Classical ML Logistic Regression Must Know
1
Understanding the Concept
▾

Imagine you're predicting whether an email is spam. Your model computes a score \(z\) — a raw number that can be anywhere from \(-\infty\) to \(+\infty\). Positive scores mean "probably spam," negative means "probably not spam." But probabilities must live in \([0, 1]\). The sigmoid function is the bridge:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

It squashes any real number into a probability. The deeper insight is what \(z\) represents: \(z\) is the log-odds (logit) — the log of the ratio of success probability to failure probability. This is why logistic regression lives in two equivalent worlds simultaneously:

  • In probability space: output is \(\hat{p} \in (0,1)\)
  • In log-odds space: input \(z = \log\frac{p}{1-p}\) is unbounded
Key Insight

The sigmoid and logit are inverses of each other. Sigmoid converts log-odds → probability; logit converts probability → log-odds. Logistic regression is linear in log-odds space, not probability space.

If You Remember One Thing

A unit increase in \(x_j\) adds \(\beta_j\) to the log-odds, which multiplies the odds by \(e^{\beta_j}\). This is the odds ratio — the fundamental quantity for interpreting logistic regression coefficients.

2
How It Works Internally
▾

The Two-Space View

Logistic regression models the log-odds as a linear function of features:

$$\log\frac{p}{1-p} = \beta_0 + \beta_1 x_1 + \cdots + \beta_k x_k = \mathbf{x}^\top \boldsymbol{\beta}$$

Applying the inverse logit (sigmoid) to both sides gives the probability:

$$p = \sigma(\mathbf{x}^\top \boldsymbol{\beta}) = \frac{1}{1 + e^{-\mathbf{x}^\top \boldsymbol{\beta}}}$$

Numerical Trace — Concrete Example

Say a model predicts loan default with one feature: income (standardized). Let \(\beta_0 = -1.5\), \(\beta_1 = 0.8\), and a borrower has \(x_1 = 1.0\):

  1. Log-odds: \(z = -1.5 + 0.8 \times 1.0 = -0.7\)
  2. Odds: \(e^{-0.7} \approx 0.497\) — odds of default is roughly 1:2
  3. Probability: \(\sigma(-0.7) = \frac{1}{1+e^{0.7}} = \frac{1}{1+2.0138} \approx 0.332\)
  4. Interpretation: A unit increase in income changes log-odds by \(+0.8\), multiplying odds by \(e^{0.8} \approx 2.23\)
Odds Ratio Formula

For coefficient \(\beta_j\): \(\text{Odds Ratio} = e^{\beta_j}\). If \(\beta_j > 0\), odds increase; if \(\beta_j < 0\), odds decrease; if \(\beta_j = 0\), no effect.

Why Sigmoid (Not Linear)?

Linear regression on a binary outcome can predict values outside \([0,1]\), violates Bernoulli likelihood assumptions, and gives non-constant variance (heteroscedasticity). The sigmoid enforces valid probabilities and links naturally to the Bernoulli log-likelihood, which is convex and has a unique global maximum.

Common Misconception

\(\beta_j\) is NOT the increase in probability per unit of \(x_j\). It is the increase in log-odds. Probability is non-linear — the same \(\Delta x\) produces different \(\Delta p\) depending on where you are on the sigmoid curve (effect is largest near \(p = 0.5\)).

3
The Mathematics
▾

Sigmoid Properties

The sigmoid \(\sigma: \mathbb{R} \to (0,1)\) has four important properties used constantly in ML:

  1. Symmetry: \(\sigma(-z) = 1 - \sigma(z)\) — follows from algebra; the curve is point-symmetric around \((0, 0.5)\)
  2. Derivative: \(\sigma'(z) = \sigma(z)(1 - \sigma(z))\) — elegant self-referential form used in backprop
  3. Limits: \(\sigma(z) \to 1\) as \(z \to +\infty\); \(\sigma(z) \to 0\) as \(z \to -\infty\)
  4. Inverse (logit): \(\sigma^{-1}(p) = \log\frac{p}{1-p}\)
$$\frac{d\sigma}{dz} = \sigma(z)(1 - \sigma(z))$$

Proof: Let \(s = \sigma(z) = (1+e^{-z})^{-1}\). Then \(\frac{ds}{dz} = e^{-z}(1+e^{-z})^{-2} = \frac{e^{-z}}{(1+e^{-z})^2}\). Factor: \(= \frac{1}{1+e^{-z}} \cdot \frac{e^{-z}}{1+e^{-z}} = s \cdot (1-s)\). ✓

Log-Likelihood & Why It's Convex

Given binary labels \(y_i \in \{0,1\}\), the negative log-likelihood is:

$$\mathcal{L}(\boldsymbol{\beta}) = -\sum_{i=1}^n \left[ y_i \log \sigma(z_i) + (1-y_i)\log(1-\sigma(z_i)) \right]$$

The Hessian is \(\mathbf{X}^\top \mathbf{W} \mathbf{X}\) where \(\mathbf{W} = \text{diag}(\sigma(z_i)(1-\sigma(z_i)))\) — positive semi-definite, so \(\mathcal{L}\) is convex, guaranteeing a unique global minimum (found via Newton-Raphson / IRLS).

Gradient for Training

\(\nabla_{\boldsymbol{\beta}} \mathcal{L} = \mathbf{X}^\top (\hat{\mathbf{p}} - \mathbf{y})\) where \(\hat{p}_i = \sigma(\mathbf{x}_i^\top\boldsymbol{\beta})\). Clean form: error signal is predicted probability minus actual label.

Code Implementation
▾

From Scratch (NumPy)

import numpy as np

def sigmoid(z):
    """Numerically stable sigmoid."""
    # Avoid overflow: use positive branch for z>0
    return np.where(z >= 0,
        1 / (1 + np.exp(-z)),
        np.exp(z) / (1 + np.exp(z)))

def logit(p):
    """Inverse sigmoid: probability → log-odds."""
    p = np.clip(p, 1e-9, 1 - 1e-9)  # guard against log(0)
    return np.log(p / (1 - p))

def fit_logistic(X, y, lr=0.1, n_iter=1000):
    """Logistic regression via gradient descent."""
    n, k = X.shape
    beta = np.zeros(k)
    for _ in range(n_iter):
        p_hat = sigmoid(X @ beta)        # predicted probs
        grad = X.T @ (p_hat - y) / n    # gradient of NLL
        beta -= lr * grad               # gradient step
    return beta

# Odds ratio for feature j:
# OR = np.exp(beta[j])
# Interpretation: per unit increase in x_j,
# odds are multiplied by OR.

Key Takeaways & When to Use
▾
  • \(\sigma(z) = 1/(1+e^{-z})\) maps log-odds to probability — always in \((0,1)\)
  • \(z = \log(p/(1-p))\) is the logit (log-odds) — the linear predictor in logistic regression
  • A unit increase in \(x_j\) multiplies the odds by \(e^{\beta_j}\) (the odds ratio)
  • Derivative: \(\sigma'(z) = \sigma(z)(1-\sigma(z))\) — maximal sensitivity at \(z=0\) (p=0.5)
  • Log-likelihood is convex → unique global optimum, no local minima
Use Sigmoid When

Binary classification with interpretable probabilities; understanding feature effects via odds ratios; as the final activation of a binary classifier neural network; in the gate mechanisms of LSTMs and GRUs.

Watch Out For

Vanishing gradients in deep networks (\(\sigma'(z) \approx 0\) for large \(|z|\)); never use as hidden-layer activation in deep nets (use ReLU). Perfectly separable data causes coefficient blow-up (need regularization).
