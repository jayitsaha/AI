Bayesian Networks: DAG Structure & Joint Probability Factorization

How a directed acyclic graph compactly encodes a joint distribution via local conditional tables — and why conditional independence is the key.

Understanding the Concept

A Bayesian Network is a directed acyclic graph (DAG) where each node is a random variable and each directed edge encodes a direct probabilistic influence. The structure of the graph tells you exactly which variables are conditionally independent of which others — and that structure lets you factor a high-dimensional joint distribution into a product of small local terms.

Without a Bayesian Network, describing a joint distribution over \(n\) binary variables requires \(2^n - 1\) numbers — exponential in \(n\). A Bayesian Network replaces this with one conditional probability table (CPT) per node, where each CPT conditions only on that node's parents. For sparse graphs this is exponentially cheaper.

💡 If you remember one thing
A Bayesian Network encodes the chain rule with a conditional independence assumption: each node is independent of its non-descendants given its parents. This is the Markov condition, and it is what allows the factorization $$P(x_1, x_2, \ldots, x_n) = \prod_{i=1}^{n} P(x_i \mid \text{parents}(x_i)).$$

Real-world analogy. Imagine a blame graph at work. If rain caused the sprinkler to be off, and the sprinkler caused the grass to be wet, then once you know whether the sprinkler is on or off you don't need to know about rain to predict wet grass. The sprinkler "screens off" rain from the grass. That's conditional independence encoded in a DAG.

How It Works — The Factorization & D-Separation

Joint Factorization

Given a DAG \(\mathcal{G}\) over variables \(X_1, \ldots, X_n\), the joint probability factorizes as:

$$P(X_1, X_2, \ldots, X_n) = \prod_{i=1}^{n} P\!\left(X_i \;\middle|\; \text{Pa}(X_i)\right)$$

where \(\text{Pa}(X_i)\) denotes the set of parent nodes of \(X_i\) in \(\mathcal{G}\). Root nodes (no parents) have \(P(X_i \mid \text{Pa}(X_i)) = P(X_i)\).

This is just the probabilistic chain rule — applied in a topological ordering of the DAG — with the independence assumption that each node \(X_i\) depends only on its parents, not on all earlier nodes.

The Markov Condition (Local Markov Property)

Key Concept — Local Markov Property
Each node \(X_i\) is conditionally independent of all its non-descendants given its parents: \[ X_i \perp \!\!\! \perp \text{NonDesc}(X_i) \;\big|\; \text{Pa}(X_i). \]

D-Separation — Reading Independence from the Graph

D-separation is the graphical criterion that tells you which pairs (or sets) of variables are conditionally independent. Three patterns matter:

  • Chain: \(A \to B \to C\). Blocking: given \(B\), \(A \perp C\). Information flows along a chain unless the middle node is observed.
  • Fork (common cause): \(A \leftarrow B \rightarrow C\). Blocking: given \(B\), \(A \perp C\). Common cause screens off correlation.
  • Collider (v-structure): \(A \rightarrow B \leftarrow C\). Blocking logic reverses — \(B\) is not on an active path by default; but conditioning on \(B\) (or a descendant of \(B\)) opens the path — explaining away. This is the notorious "Berkson's paradox" structure.

A path between \(X\) and \(Y\) is d-separated by set \(Z\) if every path is blocked. Variables \(X\) and \(Y\) are conditionally independent given \(Z\) in every distribution compatible with the graph if and only if they are d-separated by \(Z\).

⚠️ Common Mistake — Collider Confusion
Most learners get chains and forks right but trip on colliders. Remember: collider = blocked by default, OPENS when observed. This "explaining away" effect is the source of many surprising probabilistic dependencies (e.g., selection bias, Berkson's paradox in clinical trials).

The Sprinkler / Rain Network — Numerical Trace

The classic five-node Bayesian Network has variables: Cloudy (C), Sprinkler (S), Rain (R), Wet Grass (W).

$$C \rightarrow S, \quad C \rightarrow R, \quad S \rightarrow W, \quad R \rightarrow W$$

Conditional Probability Tables

# P(C) (prior, root node, no parents) P(C=T) = 0.5, P(C=F) = 0.5 # P(S | C) P(S=T | C=T) = 0.10, P(S=F | C=T) = 0.90 P(S=T | C=F) = 0.50, P(S=F | C=F) = 0.50 # P(R | C) P(R=T | C=T) = 0.80, P(R=F | C=T) = 0.20 P(R=T | C=F) = 0.20, P(R=F | C=F) = 0.80 # P(W | S, R) — 4 rows for 2x2 parent combinations P(W=T | S=T, R=T) = 0.99, P(W=F | S=T, R=T) = 0.01 P(W=T | S=T, R=F) = 0.90, P(W=F | S=T, R=F) = 0.10 P(W=T | S=F, R=T) = 0.90, P(W=F | S=F, R=T) = 0.10 P(W=T | S=F, R=F) = 0.01, P(W=F | S=F, R=F) = 0.99

Factorized Joint

$$P(C,S,R,W) = P(C)\cdot P(S\mid C)\cdot P(R\mid C)\cdot P(W\mid S,R)$$

Numerical Query: P(W=T)

We marginalize over all combinations of \(C, S, R\):

$$P(W=T) = \sum_{c,s,r} P(C=c)\,P(S=s\mid C=c)\,P(R=r\mid C=c)\,P(W=T\mid S=s,R=r)$$

Evaluating all 8 terms (C∈{T,F}, S∈{T,F}, R∈{T,F}):

c=T, s=T, r=T: 0.5 × 0.10 × 0.80 × 0.99 = 0.03960 c=T, s=T, r=F: 0.5 × 0.10 × 0.20 × 0.90 = 0.00900 c=T, s=F, r=T: 0.5 × 0.90 × 0.80 × 0.90 = 0.32400 c=T, s=F, r=F: 0.5 × 0.90 × 0.20 × 0.01 = 0.00090 c=F, s=T, r=T: 0.5 × 0.50 × 0.20 × 0.99 = 0.04950 c=F, s=T, r=F: 0.5 × 0.50 × 0.80 × 0.90 = 0.18000 c=F, s=F, r=T: 0.5 × 0.50 × 0.20 × 0.90 = 0.04500 c=F, s=F, r=F: 0.5 × 0.50 × 0.80 × 0.01 = 0.00200 Sum → P(W=T) ≈ 0.6500

Explaining Away — Posterior Query

Given \(W=T\) (wet grass observed), what is \(P(R=T \mid W=T)\)?

$$P(R=T \mid W=T) = \frac{P(W=T \mid R=T)\,P(R=T)}{P(W=T)}$$

First compute \(P(R=T) = 0.5\times0.80 + 0.5\times0.20 = 0.50\). Via the same enumeration approach, \(P(W=T, R=T) = 0.03960+0.32400+0.04950+0.04500 = 0.45810\). So:

$$P(R=T \mid W=T) = \frac{0.45810}{0.65000} \approx 0.705$$

Now additionally observe \(S=T\): the rain probability drops from 0.705 to ~0.43. This is the explaining away effect — the sprinkler and rain are marginally independent (given C blocked by collider W) but knowing one is on reduces the probability of the other when W is observed.

Math — Storage Complexity
Without independence assumptions: \(2^4 - 1 = 15\) parameters. With the factorization: \(P(C)\) needs 1, \(P(S|C)\) needs 2, \(P(R|C)\) needs 2, \(P(W|S,R)\) needs 4. Total: 9 parameters — a 40% saving here, growing exponentially with sparser graphs and more nodes.

Key Takeaways
  • A Bayesian Network is a DAG + CPTs. The DAG encodes conditional independence; the CPTs give numerical probabilities.
  • The joint factorizes as \(\prod_i P(X_i \mid \text{Pa}(X_i))\) — exponential savings in sparse graphs.
  • D-separation is the graphical test for conditional independence: chains and forks block when middle node observed; colliders block by default but open when observed.
  • Explaining away (Berkson's paradox) arises from collider structures and is a key source of counterintuitive reasoning.
  • Inference (querying posteriors) is #P-hard in general but tractable for small treewidth networks via variable elimination or belief propagation.
