Regression Losses: MSE, MAE, Huber, Log-Cosh

Same residual, four different ways to be punished — outlier sensitivity vs. robustness
Intermediate Classical ML Loss Functions O(n) per step
1
Understanding Regression Losses
▼

What is it? Every regression loss turns a residual — the gap \(r = \hat{y} - y\) between prediction and truth — into a single penalty number \(L(r)\). Squaring that gap (MSE) makes big mistakes catastrophically worse; taking the absolute value (MAE) treats every unit of error equally; Huber and log-cosh split the difference, staying quadratic near zero and roughly linear far away.

Analogy: Picture two teachers grading estimation errors. The "squaring" teacher's penalty explodes for wild guesses — one terrible answer can wreck your grade more than ten mediocre ones combined. The "absolute-value" teacher counts distance linearly, so one huge miss counts the same per-unit as many small ones. Huber is a teacher who's lenient like the squaring teacher for small slips, but switches to the linear teacher's grading once you're clearly way off.

💡 If you remember one thing

The whole story is in the gradient. MSE's gradient \(L'(r)=r\) grows without bound — outliers dominate training. MAE's gradient \(L'(r)=\operatorname{sign}(r)\) is always \(\pm 1\) — outliers get no extra vote. Huber and log-cosh smoothly interpolate: quadratic (MSE-like) near \(r=0\), linear/bounded (MAE-like) far away.

2
How Each Loss Works Internally
▼

MSE (L2): \(L(r) = \tfrac12 r^2\)

The gradient \(L'(r) = r\) is directly proportional to the error — a residual of 10 pushes 10× harder than a residual of 1. This is the maximum-likelihood loss under Gaussian noise, and gives linear regression its classic closed-form solution. Failure mode: a single residual of 100 contributes gradient 100, big enough to dominate an entire batch and drag the fit toward that one bad point.

MAE (L1): \(L(r) = |r|\)

The gradient is \(\operatorname{sign}(r)\) — always magnitude 1, no matter how large the error. A residual of 100 pushes exactly as hard as a residual of 1. This is the ML loss under Laplace noise; its minimizer is the conditional median, which barely moves when one extreme outlier is added. Failure mode: the constant gradient never "slows down" near convergence, and the kink at \(r=0\) breaks second-order optimizers.

Huber\(_\delta\): quadratic inside \(\pm\delta\), linear outside

For \(|r|\le\delta\) it behaves exactly like MSE (smooth, efficient). Beyond \(\delta\) it switches to a line with slope \(\delta\), matched in both value and slope at the boundary so the loss stays \(C^1\) continuous — no kink in the derivative. \(\delta\) is literally the residual size beyond which you stop trusting the exact magnitude of an error and only trust its direction.

Log-Cosh: \(L(r) = \log(\cosh r)\)

A fully smooth (\(C^\infty\)) approximation to Huber/MAE with zero hyperparameters: for small \(r\), \(\log\cosh(r)\approx r^2/2\) (quadratic); for large \(|r|\), \(\log\cosh(r)\approx |r|-\log 2\) (linear). It auto-transitions without ever needing a \(\delta\) to tune.

🔑 Key Property

A loss is robust to outliers exactly when its gradient is bounded as \(|r|\to\infty\). MSE's gradient is unbounded; MAE, Huber, and log-cosh all saturate — that saturation is the entire mechanism behind "robustness."

3
Why It Works — The Math
▼

Gradients

$$L_2'(r)=r \qquad L_1'(r)=\operatorname{sign}(r) \qquad \text{Huber}_\delta'(r)=\begin{cases} r & |r|\le\delta \\ \delta\operatorname{sign}(r) & |r|>\delta\end{cases} \qquad \frac{d}{dr}\log\cosh(r)=\tanh(r)$$

At \(r=\delta\): the quadratic branch gives derivative \(\delta\), the linear branch also gives \(\delta\) — they agree, confirming \(C^1\) continuity. Values match too: \(\tfrac12\delta^2 = \delta(\delta-\tfrac12\delta)\).

Why the Minimizer Differs: Mean vs. Median

Minimizing expected MSE for a constant prediction \(c\): \(\frac{d}{dc}\mathbb{E}[(c-y)^2]=2\mathbb{E}[c-y]=0 \implies c=\mathbb{E}[y]\) — the mean. Minimizing expected MAE: \(\mathbb{E}[\operatorname{sign}(c-y)]=0\) requires equal probability mass on both sides of \(c\) — the definition of the median. This is exactly why L1 is robust: the median barely moves when one extreme point is added; the mean can move arbitrarily far.

Second Derivatives (Curvature)

$$L_2''(r)=1 \qquad L_1''(r)=0\ (r\ne0) \qquad \text{Huber}_\delta''(r)=\begin{cases}1 & |r|<\delta\\0 & |r|>\delta\end{cases} \qquad \frac{d^2}{dr^2}\log\cosh(r)=\operatorname{sech}^2(r)$$

Newton-style optimizers (and XGBoost's exact split-finding) need a nonzero, informative Hessian. MAE's curvature is 0 almost everywhere — this is exactly why gradient-boosted trees often use log-cosh or pseudo-Huber as smooth MAE surrogates.

⚠️ Common Misconception

"MAE is always better because it's robust." Robustness trades off against statistical efficiency: under genuinely Gaussian noise, MAE's estimator has higher variance than MSE's — you pay a cost for robustness you don't need. Huber (well-tuned \(\delta\)) or log-cosh aim to get most of MSE's efficiency with most of MAE's robustness.

Key Takeaways
▼

When to use which:

  • MSE — clean data, roughly Gaussian noise, you need the conditional mean (e.g. expected-value forecasts)
  • MAE — you explicitly want the median, or data is heavily contaminated and slower convergence is acceptable
  • Huber — general-purpose robust regression when you can tune/estimate δ (good default in boosting & robust linear models)
  • Log-Cosh — want Huber's robustness with zero hyperparameters and full (C∞) smoothness for 2nd-order optimizers

When NOT to use:

  • MSE on data you suspect has label noise or sensor glitches — a few bad rows can dominate training
  • MAE with vanilla Newton-style optimizers — zero curvature breaks them
  • Huber if you truly cannot tune δ — log-cosh is the zero-tuning fallback
💡 Decision Rule

Clean data + need the mean → MSE. Contaminated data + need the median → MAE. Contaminated data + need mean-like predictions + willing to tune → Huber. Same benefits, zero tuning → Log-Cosh.

Code Trace
▼
import numpy as np
r = y_pred - y_true # residual
# MSE: quadratic penalty, unbounded gradient
mse = np.mean(0.5 * r**2)
grad_mse = r # grows with |r|
# MAE: linear penalty, bounded gradient
mae = np.mean(np.abs(r))
grad_mae = np.sign(r) # always +-1
# Huber: quadratic near 0, linear beyond delta
delta = 1.0
abs_r = np.abs(r)
quad = np.minimum(abs_r, delta)
lin = abs_r - quad
huber = np.mean(0.5*quad**2 + delta*lin)
grad_huber = np.where(abs_r <= delta, r, delta*np.sign(r))
# Log-Cosh: smooth surrogate, numerically stable form
logcosh = np.mean(abs_r + np.log1p(np.exp(-2*abs_r)) - np.log(2))
grad_logcosh = np.tanh(r)
