Understanding Positive-Definite Matrices
▼

What is it? A symmetric matrix \(A\) is positive-definite (PD) if for every non-zero vector \(x\), the scalar \(x^\top A x > 0\). Think of \(A\) as defining a shape: positive-definiteness means that shape is always an upward-curving bowl — no matter which direction you look, the surface goes up. If the shape dips in any direction, the matrix is indefinite.

Analogy: Imagine placing a marble on a surface defined by \(f(x, y) = [x, y]\, A \begin{bmatrix}x\\y\end{bmatrix}\). If \(A\) is PD, the marble always rolls to the center — the function has a unique global minimum. If \(A\) is indefinite, there are valleys and ridges — the marble rolls away in some directions. PD matrices are the "bowl" matrices; indefinite ones are "saddles."

💡 If you remember one thing

A symmetric matrix \(A\) is positive-definite if and only if all its eigenvalues are strictly positive. Equivalently: its Cholesky decomposition \(A = LL^\top\) exists with positive diagonal entries. Every valid covariance matrix and every Gram matrix built from a non-degenerate kernel is PD.

2
How to Test for Positive-Definiteness
▼

Three Equivalent Tests (all must pass for PD)

Given a real symmetric \(n \times n\) matrix \(A\), each test is a different angle on the same property:

Test 1 — Eigenvalue test: Compute all eigenvalues \(\lambda_1, \ldots, \lambda_n\). \(A\) is PD iff \(\lambda_i > 0\) for all \(i\). Cost: \(O(n^3)\) (full eigendecomposition). Most expensive, but gives full spectral picture.

Test 2 — Sylvester's criterion (leading principal minors): The \(k\)-th leading principal minor is \(\det(A_k)\), where \(A_k\) is the top-left \(k \times k\) submatrix. \(A\) is PD iff \(\det(A_k) > 0\) for all \(k = 1, \ldots, n\). Cheaper than eigenvalues for small matrices, but still \(O(n^4)\) naively (\(O(n^3)\) if using LU).

Test 3 — Cholesky test: Attempt the Cholesky decomposition \(A = LL^\top\). Succeeds (without NaN/imaginary pivots) iff \(A\) is PD. This is the most practical test in code — numpy's linalg.cholesky raises LinAlgError for non-PD matrices. Cost: \(O(n^3/3)\) — fastest of the three for large matrices.

🔑 Key Equivalences

For a real symmetric matrix, these are equivalent: (1) all eigenvalues \(> 0\); (2) all leading principal minors \(> 0\) (Sylvester); (3) Cholesky decomposition exists with positive diagonal; (4) \(x^\top Ax > 0\) for all \(x \neq 0\); (5) \(A = B^\top B\) for some invertible \(B\).

Positive Semi-Definite (PSD)

If we relax to \(x^\top Ax \geq 0\) (allowing zero), \(A\) is positive semi-definite. Equivalently: all eigenvalues \(\geq 0\). PSD matrices arise when some directions are "flat" (e.g., a degenerate Gaussian, a rank-deficient kernel matrix). Cholesky fails on PSD (zero pivots), but Cholesky with pivoting works.

⚠️ Common Trap

"All diagonal entries positive" does NOT imply PD. Counter-example: \(\begin{bmatrix}1 & 2\\2 & 1\end{bmatrix}\) has positive diagonal but \(\det = -3 < 0\) and eigenvalues \(-1, 3\) — indefinite! You must check the minors or eigenvalues.

3
Why It Works — Cholesky & Geometry
▼

Cholesky Decomposition: the "Matrix Square Root"

For every PD matrix \(A\), there exists a unique lower-triangular matrix \(L\) with positive diagonal entries such that:

$$A = LL^\top$$

The algorithm computes \(L\) column by column. For a \(3 \times 3\) matrix:

$$L_{jj} = \sqrt{A_{jj} - \sum_{k=1}^{j-1} L_{jk}^2}, \qquad L_{ij} = \frac{1}{L_{jj}}\!\left(A_{ij} - \sum_{k=1}^{j-1} L_{ik}L_{jk}\right) \text{ for } i > j$$

The square root \(\sqrt{\cdot}\) succeeds only if \(A_{jj} - \sum_{k} L_{jk}^2 > 0\) — this is exactly the PD condition expressed incrementally. If any pivot goes negative or zero, \(A\) is not PD.

Geometric Interpretation: the Quadratic Form

The function \(f(x) = x^\top A x\) is a quadratic form. In 2D with \(A = \begin{bmatrix}a & b\\b & c\end{bmatrix}\):

$$f(x_1, x_2) = a x_1^2 + 2b x_1 x_2 + c x_2^2$$

This is an upward paraboloid (bowl) when \(A\) is PD, a saddle when \(A\) is indefinite, and a degenerate flat ridge when \(A\) is PSD. The level curves \(\{x : x^\top Ax = 1\}\) form an ellipse for PD matrices — the eigenvectors give the ellipse axes, and eigenvalues give their inverse-squared lengths.

Why Kernels and Covariance Matrices Are Always PD

A Gram matrix \(K_{ij} = k(x_i, x_j)\) built from a positive-definite kernel (e.g., RBF: \(k(x, y) = e^{-\|x-y\|^2/2\sigma^2}\)) satisfies \(x^\top K x = \sum_{ij} x_i x_j k(x_i, x_j) \geq 0\). By Mercer's theorem, any kernel that is PD as a function produces a PSD Gram matrix (PD if points are distinct and kernel is strictly PD). For empirical covariance: if \(n \geq p\) and no redundant features, \(\Sigma = \frac{1}{n}X^\top X\) is PD because it equals \(B^\top B\) for \(B = X/\sqrt{n}\).

📐 Sylvester's Criterion — Proof Sketch

By induction: \(A\) is PD iff the restriction to the span of the first \(k\) basis vectors is PD for all \(k\). The determinant of \(A_k\) equals the product of the first \(k\) pivots in LU/Cholesky. Each pivot is positive iff the corresponding leading minor is positive — this is the direct equivalence between Sylvester's criterion and Cholesky success.

Why It Matters — Applications & Key Takeaways
▼

Where PD Matrices Appear in ML

Covariance Matrix

\(\Sigma = \mathbb{E}[(X-\mu)(X-\mu)^\top]\) is always PSD; PD iff no feature is a linear combo of others. Powers Gaussian distributions, LDA, PCA.

Kernel / Gram Matrix

\(K_{ij}=k(x_i,x_j)\) for RBF, polynomial, Matérn kernels. Mercer's theorem: PD kernel \(\Rightarrow\) PSD Gram matrix. Used in SVMs, GPR.

Hessian of a Convex Loss

\(H = \nabla^2 \mathcal{L}\) is PD at a strict local minimum. Newton's method converges when \(H\) is PD — ensures step direction is a descent direction.

GLS / Mixed Models

The error covariance \(\Omega\) must be PD for GLS to work. Cholesky of \(\Omega\) gives the whitening matrix \(P=L^{-1}\) used to decorrelate residuals.

When to Use Cholesky vs Eigendecomposition

Use Cholesky when you need: solving \(Ax = b\) with PD \(A\) (substitute \(LL^\top x = b\)), computing \(\log\det A = 2\sum_i \log L_{ii}\), sampling from a multivariate Gaussian (\(x = L z\) where \(z \sim \mathcal{N}(0,I)\)), or testing PD-ness quickly. Cost: \(O(n^3/3)\).

Use eigendecomposition when you need: the actual spectrum, matrix powers \(A^p = Q\Lambda^p Q^\top\), or diagnosing near-singularity (condition number = \(\lambda_{\max}/\lambda_{\min}\)). Cost: \(O(n^3)\), roughly \(3\times\) more than Cholesky.

💡 Numerical Stability Tip

Real covariance matrices may fail Cholesky due to floating-point errors even when theoretically PD. Fix: add a small jitter \(\epsilon I\) (e.g., \(\epsilon = 10^{-6}\)) before Cholesky. This is standard in GPR libraries. The condition number \(\kappa(A) = \lambda_{\max}/\lambda_{\min}\) tells you how large jitter needs to be.

Code Trace — PD Tests & Cholesky
▼
import numpy as np
# Define a 3x3 PD matrix A
A = np.array([[4.0, 2.0, 1.0],
[2.0, 5.0, 3.0],
[1.0, 3.0, 6.0]])
# Test 1: Eigenvalue test
eigenvalues = np.linalg.eigvalsh(A) # eigvalsh for symmetric
is_pd_eig = bool(np.all(eigenvalues > 0))
# eigenvalues ≈ [1.127, 3.593, 10.280] → all positive ✓
# Test 2: Sylvester's criterion (leading principal minors)
minors = [np.linalg.det(A[:k+1, :k+1]) for k in range(len(A))]
is_pd_syl = all(m > 0 for m in minors)
# minors ≈ [4.0, 16.0, 57.0] → all positive ✓
# Test 3: Cholesky test (fastest in practice)
try:
L = np.linalg.cholesky(A)
is_pd_chol = True
except np.linalg.LinAlgError:
is_pd_chol = False
# Verify: A = L @ L.T
print(np.allclose(L @ L.T, A)) # True
# L diagonal: [2.0, 2.0, 1.871] — all positive ✓
# log-determinant via Cholesky (numerically stable)
log_det_A = 2 * np.sum(np.log(np.diag(L)))
# log(det A) = 2*(log 2 + log 2 + log 1.871) ≈ 4.043
# Sample from N(0, A) using Cholesky
z = np.random.randn(3) # z ~ N(0, I)
x = L @ z # x ~ N(0, A) since Cov(Lz)=L I L^T=A
# Numerical safety: add jitter for near-PD matrices
def safe_cholesky(A, jitter=1e-6):
return np.linalg.cholesky(A + jitter * np.eye(len(A)))
