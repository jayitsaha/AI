Steering generative models towards prompt adherence by amplifying conditional predictions
Intermediate Generative AI Diffusion Models O(1) extra cost
1
Understanding Classifier-Free Guidance
▼

What is it? Classifier-Free Guidance (CFG) is a technique used in generative models (especially diffusion models) to enhance the influence of a conditioning input (like a text prompt) on the generated output. It works by combining predictions from a model that *uses* the prompt with predictions from the *same model* that ignores the prompt, effectively amplifying the "prompt-relevant" signal. The strength of this amplification is controlled by a parameter called the guidance scale.

Analogy: Imagine you're a chef trying to bake a cake. You have two sets of instructions: one is a very specific recipe for a "chocolate fudge cake" (conditional guidance), and the other is a generic guide for "how to bake any cake" (unconditional guidance). If you follow only the specific recipe, you get a chocolate fudge cake. If you follow only the generic guide, you get a bland, generic cake. CFG is like deliberately exaggerating the "chocolate fudge" parts of the specific recipe while reducing the "generic cake" parts. The guidance scale tells you *how much* to exaggerate the specific instructions: a low scale means you're still making a somewhat generic cake; a high scale means you're making an intensely chocolatey, fudgy cake, possibly even to the point of being overwhelming or burnt if you go too far.

💡 If you remember one thing

CFG works by taking the unconditional prediction (what the model would do without a prompt) and pushing it in the direction of the conditional prediction (what the model would do with the prompt). The guidance scale \(s\) controls how far to push: \(s=0\) is purely unconditional, \(s=1\) is purely conditional, and \(s>1\) extrapolates beyond the conditional prediction.

2
How It Works Internally
▼

The Need for Guidance

Generative models like Diffusion Models learn to reverse a noisy process. At each step, they predict the noise that needs to be removed from a noisy input \(x_t\) to get closer to a clean image \(x_{t-1}\). When we condition these models on a prompt (e.g., "a cat in space"), we want the generated image to adhere strongly to that prompt. However, models often struggle to perfectly capture all nuances of a prompt, sometimes producing generic or off-topic outputs.

From Classifier Guidance to Classifier-Free Guidance

The original idea, Classifier Guidance (CG), used a separate, pre-trained classifier to guide the generation. At each step, the diffusion model would predict noise, and then the classifier would estimate the gradient of the log-probability of the target class with respect to the generated image. This gradient would then be added to the diffusion model's noise prediction, pushing the generation towards regions that the classifier believes belong to the target class. This works, but requires a separate, well-performing classifier, which can be expensive to train and maintain, and might introduce its own biases.

Classifier-Free Guidance (CFG), introduced by Ho and Salimans (2021), simplifies this. Instead of a separate classifier, the *same* diffusion model is trained to generate both conditionally (given a prompt \(c\)) and unconditionally (without a prompt, or with an empty/null prompt \(\emptyset\)). During inference, the model runs two forward passes:

  1. One conditional pass: predicting noise \(\varepsilon_\theta(x_t, t, c)\) given the noisy input \(x_t\), timestep \(t\), and prompt \(c\).
  2. One unconditional pass: predicting noise \(\varepsilon_\theta(x_t, t, \emptyset)\) given \(x_t\) and \(t\), but *ignoring* the prompt.

These two noise predictions are then combined using the guidance scale \(s\) to produce a final, guided noise prediction.

Design Decision: Why CFG over CG?

CFG is generally preferred because it:

  • Simplifies the pipeline: No need to train or maintain a separate classifier. The guidance comes from the generative model itself.
  • Often produces better results: The guidance signal is "in-domain" with the generative process, leading to more coherent and higher-quality outputs.
  • More flexible: The same model can be used for conditional or unconditional generation simply by adjusting \(s\).
🔑 Key Property

For CFG to work, the generative model must be trained to handle both conditional inputs (e.g., text embeddings) and unconditional inputs (e.g., an empty text embedding, or a special token indicating "no condition"). This is often done by randomly dropping out the conditional input during a fraction of training steps.

3
Why It Works — The Math
▼

The Diffusion Noise Prediction

In a diffusion model, at each timestep \(t\), we have a noisy latent \(x_t\). The model's job is to predict the noise \(\varepsilon\) that was added to a clean latent \(x_0\) to get \(x_t\). Let \(\varepsilon_\theta(x_t, t, c)\) denote the noise predicted by the model \(\theta\) given \(x_t\), \(t\), and a condition \(c\). Similarly, \(\varepsilon_\theta(x_t, t, \emptyset)\) is the noise predicted unconditionally.

The Classifier Guidance Formula

The original Classifier Guidance formula combined the unconditional score function (gradient of log-probability of the data) with the gradient of the classifier's log-probability:

$$\nabla_{x_t} \log p(x_t \mid c) \approx \nabla_{x_t} \log p(x_t) + s \cdot \nabla_{x_t} \log p(c \mid x_t)$$

where \(s\) is the guidance scale. This is for the score function. In diffusion models, we work with noise predictions, which are related to score functions. The insight of CFG is to approximate this score-based guidance using only the noise predictions from a single model.

The Classifier-Free Guidance Formula

CFG directly combines the conditional and unconditional noise predictions. The final noise prediction \(\hat{\varepsilon}\) used to denoise \(x_t\) is given by:

$$\hat{\varepsilon}(x_t, t, c, s) = \varepsilon_\theta(x_t, t, \emptyset) + s \cdot \left( \varepsilon_\theta(x_t, t, c) - \varepsilon_\theta(x_t, t, \emptyset) \right)$$

Let's break this down:

  • \(\varepsilon_\theta(x_t, t, \emptyset)\) (let's call it \(\varepsilon_{uncond}\)) is the model's best guess for the noise without any prompt. This drives the generation towards generic, high-likelihood outputs.
  • \(\varepsilon_\theta(x_t, t, c)\) (let's call it \(\varepsilon_{cond}\)) is the model's best guess for the noise with the prompt \(c\). This drives the generation towards outputs matching the prompt.
  • The term \(\left( \varepsilon_{cond} - \varepsilon_{uncond} \right)\) represents the "direction" in which the model needs to shift its noise prediction to satisfy the condition \(c\). It's the difference between "what to remove for a generic image" and "what to remove for a prompt-specific image."
  • The guidance scale \(s\) then amplifies this "prompt-specific direction."

This formula can be rewritten as:

$$\hat{\varepsilon}(x_t, t, c, s) = (1-s) \cdot \varepsilon_\theta(x_t, t, \emptyset) + s \cdot \varepsilon_\theta(x_t, t, c)$$

This shows it's a linear interpolation/extrapolation. If \(s=0\), \(\hat{\varepsilon} = \varepsilon_{uncond}\) (no guidance). If \(s=1\), \(\hat{\varepsilon} = \varepsilon_{cond}\) (direct conditional generation). If \(s>1\), the effect of the conditional prediction is exaggerated, pushing the generation even further in the direction of the prompt.

⚠️ Common Pitfall

While higher guidance scales generally lead to better prompt adherence, too high a value can introduce artifacts, oversaturation, or unnatural features. This is because extrapolation beyond the trained conditional distribution can lead to out-of-distribution noise predictions. Finding the optimal \(s\) is often a hyperparameter search.

Key Takeaways
▼

When to use Classifier-Free Guidance:

  • When you need strong adherence to a conditioning input (e.g., a text prompt, an image, a class label) in generative models.
  • Commonly used in text-to-image diffusion models (Stable Diffusion, Midjourney, DALL-E 3) to make generated images match the prompt more accurately.
  • Applicable to other conditional generation tasks like text-to-audio, text-to-video, or image inpainting/outpainting.

When NOT to use or be careful with CFG:

  • If your model was not trained to produce both conditional and unconditional predictions (i.e., by occasionally dropping out the conditioning input during training).
  • If you prioritize diversity and novelty over strict prompt adherence; a low guidance scale might be preferred, or no guidance at all.
  • Using excessively high guidance scales (e.g., \(s > 10\)) can lead to mode collapse, oversaturation, or generation of undesirable artifacts, as the model is pushed far outside its learned distribution.
  • For tasks where the conditioning is inherently weak or ambiguous, high guidance might not yield better results and could even degrade quality.
💡 Trade-off

Classifier-Free Guidance introduces a fundamental trade-off between prompt adherence (how well the output matches the prompt) and generation quality/diversity. Higher guidance scales increase adherence but can reduce quality and diversity, and vice-versa. The optimal guidance scale is task- and model-dependent.

Code Trace (PyTorch-like Pseudocode)
▼
import torch
# Assume 'model' is a diffusion UNet trained for CFG
# It takes (noisy_latent, timestep, conditioning_embedding)
# and returns predicted noise epsilon.
def predict_noise_cfg(noisy_latent, timestep, cond_embed, guidance_scale):
# 1. Prepare unconditional embedding (e.g., a zero vector or special token embedding)
uncond_embed = get_unconditional_embedding()
# 2. Concatenate inputs for batched inference (optional, but common for efficiency)
# batch = [uncond_latent, cond_latent] -> [noisy_latent, noisy_latent]
# conds = [uncond_embed, cond_embed]
batched_latent = torch.cat([noisy_latent, noisy_latent])
batched_cond = torch.cat([uncond_embed, cond_embed])
# 3. Predict noise for both conditional and unconditional paths in one go
# model(noisy_latent, timestep, cond_embed) -> epsilon_pred
noise_pred_batch = model(batched_latent, timestep, batched_cond)
# 4. Split the predictions
noise_pred_uncond, noise_pred_cond = noise_pred_batch.chunk(2)
# 5. Apply Classifier-Free Guidance formula
# epsilon_cfg = epsilon_uncond + s * (epsilon_cond - epsilon_uncond)
noise_pred_guided = noise_pred_uncond + guidance_scale * (noise_pred_cond - noise_pred_uncond)
return noise_pred_guided
