Understanding Random Forest
▼

Imagine asking 1,000 people to independently estimate a crowd's age distribution. Each person sees only a random sample of the crowd and uses only a random subset of clues (height, hair colour, posture). Even if each person is a mediocre estimator, their average is remarkably accurate — because their errors are uncorrelated and cancel out.

That is Random Forest in one sentence: grow many decision trees, each on a different random bootstrap sample of the data, each considering only a random subset of features at every split. Then average their predictions (regression) or take a majority vote (classification).

The crucial insight that separates RF from plain bagging is the random subspace method: at each node in each tree, only \(m_{try}\) of the \(p\) features are eligible for splitting. This forcibly decorrelates the trees — even when one feature dominates (e.g., a very strong predictor), different trees are forced to discover alternative splitting rules, producing genuinely diverse trees whose errors cancel.

Key Insight

If you remember one thing: RF trades a little extra bias for a large reduction in variance by decorrelating trees via random feature subsets. The ensemble variance is \(\rho\sigma^2 + \frac{(1-\rho)\sigma^2}{B}\) — only the first term survives as \(B \to \infty\), so lowering the inter-tree correlation \(\rho\) is the whole game.

2
How Random Forest Works Internally
▼

Step 1 — Bootstrap Sampling

For each of the \(B\) trees, draw \(n\) samples with replacement from the training set. Each bootstrap sample has expected \(1-(1-1/n)^n \to 1-e^{-1} \approx 63.2\%\) unique examples. The remaining \(\approx 36.8\%\) that were never selected for that tree form that tree's out-of-bag (OOB) set — a free held-out validation set with no extra cost.

Step 2 — Random Feature Selection (mtry)

At every node of every tree, only \(m_{try}\) features are randomly sampled (without replacement) from all \(p\) features. The best split among those \(m_{try}\) candidates is chosen. Standard defaults: \(m_{try} = \lfloor\sqrt{p}\rfloor\) for classification, \(m_{try} = \lfloor p/3 \rfloor\) for regression. Trees are grown to maximum depth (no pruning) — individual trees overfit, but the ensemble averages away that variance.

Step 3 — Prediction (Aggregate)

For regression: \(\hat{f}_{RF}(x) = \frac{1}{B}\sum_{b=1}^{B} T_b(x)\). For classification: majority vote among \(\{T_b(x)\}_{b=1}^B\). As \(B\to\infty\) the ensemble converges (adding more trees never overfits — it only reduces variance toward the limiting value \(\rho\sigma^2\)).

Step 4 — OOB Error Estimate

For each training point \(x_i\), collect predictions only from trees for which \(x_i\) was OOB. Average (or vote) those predictions to get \(\hat{f}_{OOB}(x_i)\). The OOB error \(\frac{1}{n}\sum_{i=1}^n L(y_i, \hat{f}_{OOB}(x_i))\) is an approximately unbiased estimate of the test error — equivalent to leave-one-out cross-validation in large samples.

Design Decision: Why Grow Full Trees?

Unlike boosting (which uses shallow stumps), RF uses fully grown trees with maximum bias-variance profile. High variance is fine because averaging decorrelated high-variance estimators dramatically reduces total variance. Pruning would only increase bias without the variance benefit.

Step 5 — Feature Importance

MDI (Mean Decrease in Impurity) — for each feature \(X_j\), sum the weighted Gini/entropy reduction that feature contributed across all splits in all trees. Fast but biased toward high-cardinality features.

MDA (Mean Decrease in Accuracy / Permutation Importance) — for each tree \(b\) and feature \(j\), permute \(X_j\) in the OOB set, record the accuracy drop \(\Delta_b^j\), then average over trees: \(\text{MDA}_j = \frac{1}{B}\sum_b \Delta_b^j\). Unbiased but slower (one permutation per feature per tree).

3
The Math: Variance Reduction, OOB Error & Feature Importance
▼

Variance Decomposition of the Ensemble

Let each tree \(T_b\) have marginal variance \(\sigma^2\) and pairwise correlation \(\rho\) (for any two trees \(T_b, T_{b'}\)). The variance of the ensemble mean is:

$$\text{Var}\!\left(\frac{1}{B}\sum_{b=1}^B T_b(x)\right) = \rho\,\sigma^2 + \frac{1-\rho}{B}\,\sigma^2$$

As \(B\to\infty\), the second term vanishes, leaving the irreducible floor \(\rho\sigma^2\). Reducing \(\rho\) via random feature subsets is therefore the primary lever. With \(m_{try}=\lfloor\sqrt{p}\rfloor\) and a strong dominant feature, \(\rho\) drops from \(\approx 0.8\) (bagging only) to \(\approx 0.25\) — a 68% variance reduction relative to bagging alone.

OOB Probability (Exact)

The probability that sample \(i\) is excluded from a single bootstrap of size \(n\) is \((1-1/n)^n\). By the limit:

$$\lim_{n\to\infty}\left(1-\frac{1}{n}\right)^n = e^{-1} \approx 0.3679$$

For finite \(n=100\): \(\approx 0.3660\). For \(n=1000\): \(\approx 0.3677\). The OOB error estimate converges to the true generalization error as \(B\to\infty\) (Breiman 2001 shows it is an almost sure limit).

MDI — Gini Impurity Decrease

For a node \(t\) that splits on feature \(j\) with left/right children \(t_L, t_R\):

$$\Delta I(t,j) = \frac{n_t}{n}\left[I(t) - \frac{n_{t_L}}{n_t}I(t_L) - \frac{n_{t_R}}{n_t}I(t_R)\right]$$

where \(I(t) = 1 - \sum_k p_k^2\) is the Gini impurity at node \(t\). MDI for feature \(j\) sums \(\Delta I\) over all nodes in all trees where feature \(j\) was chosen:

$$\text{MDI}_j = \frac{1}{B}\sum_{b=1}^B \sum_{t \in T_b : s(t)=j} \Delta I(t,j)$$

MDA — Permutation Importance

For tree \(b\) with OOB set \(\mathcal{L}_b\), let \(\text{acc}_b\) = OOB accuracy. Permute column \(j\) randomly in \(\mathcal{L}_b\) to get permuted accuracy \(\widetilde{\text{acc}}_b^j\). Then:

$$\text{MDA}_j = \frac{1}{B}\sum_{b=1}^B \left(\text{acc}_b - \widetilde{\text{acc}}_b^j\right)$$
MDI Bias Warning

MDI is biased toward features with many unique values (continuous or high-cardinality categorical). A feature with 100 categories can always find a better Gini split than one with 2. Always complement MDI with MDA or SHAP for reliable feature selection.

Key Takeaways & When to Use
▼

When to Use Random Forest

  • Tabular data with mixed numeric + categorical features
  • When you need a reliable feature importance estimate out of the box
  • When interpretability of individual trees is not required
  • As a strong baseline before trying gradient boosting
  • When OOB error is useful (avoids need to split off a validation set)

When NOT to Use

  • Very high-dimensional sparse data (text, images) — gradient boosting or neural nets win
  • When maximum predictive accuracy matters — XGBoost/LightGBM typically outperform RF
  • When you need calibrated probabilities — RF probabilities are poorly calibrated (use Platt scaling)
  • Extremely large datasets — training \(B\) full trees is memory-heavy; use LightGBM instead
RF vs Gradient Boosting Decision Rule

RF: parallel training, robust to hyperparameters, harder to overfit. GBM: sequential, more tuning needed, typically 5–15% better accuracy. Use RF when you want a reliable out-of-the-box result; use XGBoost/LightGBM when squeezing every point of AUC matters.

From Scratch (NumPy)

import numpy as np
from collections import Counter

# ── Decision stump node ─────────────────────────────────────────────────────
class Node:
    def __init__(self, feature=None, threshold=None, left=None, right=None, value=None):
        self.feature = feature       # feature index used for split
        self.threshold = threshold   # split threshold
        self.left = left             # left subtree
        self.right = right           # right subtree
        self.value = value           # leaf prediction (if leaf node)

# ── Gini impurity ────────────────────────────────────────────────────────────
def gini(y):
    n = len(y)
    if n == 0: return 0.0
    counts = Counter(y)
    return 1.0 - sum((c/n)**2 for c in counts.values())

# ── Find best split among mtry random features ───────────────────────────────
def best_split(X, y, mtry):
    n, p = X.shape
    # Randomly select mtry features (the random subspace method)
    features = np.random.choice(p, min(mtry, p), replace=False)
    best_gain, best_feat, best_thresh = -np.inf, None, None
    parent_gini = gini(y)
    for f in features:
        thresholds = np.unique(X[:, f])
        for t in thresholds[:-1]:
            mask = X[:, f] <= t
            if mask.sum() == 0 or (~mask).sum() == 0: continue
            gain = parent_gini - (mask.sum()/n)*gini(y[mask]) \
                               - ((~mask).sum()/n)*gini(y[~mask])
            if gain > best_gain:
                best_gain, best_feat, best_thresh = gain, f, t
    return best_feat, best_thresh

# ── Grow one tree ─────────────────────────────────────────────────────────────
def grow_tree(X, y, mtry, max_depth=None, depth=0):
    if len(set(y)) == 1 or (max_depth and depth >= max_depth):
        return Node(value=Counter(y).most_common(1)[0][0])
    feat, thresh = best_split(X, y, mtry)
    if feat is None: return Node(value=Counter(y).most_common(1)[0][0])
    mask = X[:, feat] <= thresh
    return Node(feat, thresh,
                grow_tree(X[mask], y[mask], mtry, max_depth, depth+1),
                grow_tree(X[~mask], y[~mask], mtry, max_depth, depth+1))

def predict_tree(node, x):
    if node.value is not None: return node.value
    return predict_tree(node.left if x[node.feature] <= node.threshold else node.right, x)

# ── Random Forest ─────────────────────────────────────────────────────────────
class RandomForestClassifier:
    def __init__(self, n_estimators=100, mtry=None, max_depth=None, random_state=42):
        self.n_estimators = n_estimators
        self.mtry = mtry          # None → sqrt(p)
        self.max_depth = max_depth
        self.random_state = random_state
        self.trees = []
        self.oob_indices = []     # OOB sample indices per tree

    def fit(self, X, y):
        np.random.seed(self.random_state)
        n, p = X.shape
        mtry = self.mtry or int(np.sqrt(p))
        self.trees, self.oob_indices = [], []
        for _ in range(self.n_estimators):
            # Bootstrap sample (with replacement)
            idx = np.random.choice(n, n, replace=True)
            oob = np.array(sorted(set(range(n)) - set(idx)))
            X_b, y_b = X[idx], y[idx]
            tree = grow_tree(X_b, y_b, mtry, self.max_depth)
            self.trees.append(tree)
            self.oob_indices.append(oob)
        return self

    def predict(self, X):
        # Majority vote across all trees
        preds = np.array([[predict_tree(t, x) for x in X] for t in self.trees])
        return np.array([Counter(preds[:, i]).most_common(1)[0][0] for i in range(X.shape[0])])

    def oob_score(self, X, y):
        n = len(y)
        oob_preds = [[] for _ in range(n)]
        for tree, oob in zip(self.trees, self.oob_indices):
            for i in oob:
                oob_preds[i].append(predict_tree(tree, X[i]))
        correct = sum(Counter(v).most_common(1)[0][0] == y[i]
                      for i, v in enumerate(oob_preds) if v)
        return correct / n

Production Usage (sklearn)

from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import permutation_importance
import numpy as np

# ── Fit ────────────────────────────────────────────────────────────────────────
rf = RandomForestClassifier(
    n_estimators=500,         # more trees = lower variance (no overfitting risk)
    max_features='sqrt',      # mtry = sqrt(p) — classification default
    max_depth=None,           # grow full trees
    min_samples_leaf=1,       # standard RF (increase for smoother boundaries)
    oob_score=True,           # compute OOB error automatically
    n_jobs=-1,                # parallelise across all CPU cores
    random_state=42,
)
rf.fit(X_train, y_train)

# ── OOB error (free cross-validation substitute) ───────────────────────────────
print(f"OOB accuracy: {rf.oob_score_:.4f}")  # rf.oob_decision_function_ for probs

# ── MDI feature importance (built-in, biased) ─────────────────────────────────
mdi = rf.feature_importances_          # normalized to sum to 1

# ── MDA permutation importance (unbiased) ─────────────────────────────────────
result = permutation_importance(rf, X_val, y_val, n_repeats=10, random_state=42)
mda = result.importances_mean          # mean accuracy drop per feature
