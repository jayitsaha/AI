Understanding the MLP
▼

What is it? A Multi-Layer Perceptron (MLP) is the simplest "deep" neural network: a stack of fully-connected layers. Data enters at the input layer, passes through one or more hidden layers that each apply a linear transform followed by a nonlinearity, and exits through an output layer shaped for the task (a single number, a class score, a probability vector).

Analogy: Think of a factory assembly line. Raw materials (input features) enter the first station. Each station (layer) takes what the previous station handed it, reshapes and recombines it (affine transform), then stamps it with a "keep or discard" filter (nonlinearity) before passing it on. By the time the product reaches the final station (output layer), it has been refined through several stages of increasingly abstract combination — early stations detect edges, later ones detect shapes, the last one recognizes the object.

💡 If you remember one thing

Every layer does the same two-step recipe: affine transform then nonlinearity: $$a^{(l)} = \sigma\!\left(W^{(l)} a^{(l-1)} + b^{(l)}\right)$$ Stack enough of these and the network can approximate any continuous function — the nonlinearity is what makes stacking layers meaningfully different from stacking one giant linear layer.

How the MLP Works Internally
▼

The Three Layer Types

The input layer is not a computational layer at all — it is just the raw feature vector \(x \in \mathbb{R}^{n_0}\) (e.g. pixel values, tabular features). Each hidden layer \(l\) holds \(n_l\) neurons, and computes a pre-activation \(z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}\) followed by an elementwise nonlinearity \(a^{(l)} = \sigma(z^{(l)})\), typically ReLU. The output layer applies its own affine transform and a task-appropriate final function — identity for regression, sigmoid for binary classification, softmax for multi-class.

Why Depth Builds Hierarchical Features

Layer 1's neurons can only combine raw inputs linearly then threshold them — they learn simple, localized patterns. Layer 2 takes layer 1's outputs as its inputs, so it can combine those simple patterns into more complex ones. Each additional layer composes the representation one level higher, which is why early CNN layers detect edges while deep layers detect whole objects — the same compositional principle, generalized.

Design Decision: Why Affine + Nonlinearity, and Not Just Affine?

Composing two linear (affine) maps is still just one linear map: \(W_2(W_1x+b_1)+b_2 = (W_2W_1)x + (W_2b_1+b_2)\). Without a nonlinearity between layers, stacking any number of layers collapses to a single linear layer — no representational gain. The nonlinearity \(\sigma\) breaks this collapse, which is the entire reason "depth" means anything.

🔑 Key Property

The Universal Approximation Theorem guarantees a single hidden layer with enough neurons and a non-polynomial activation can approximate any continuous function on a compact domain to arbitrary precision. In practice, depth (many narrow layers) is far more parameter-efficient than width (one huge layer) for learning hierarchical structure.

Why It Works — The Math
▼

The Forward Pass, Layer by Layer

For layer \(l = 1, \dots, L\), with \(a^{(0)} = x\) the input:

$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}, \qquad a^{(l)} = \sigma^{(l)}\!\left(z^{(l)}\right)$$

where \(W^{(l)} \in \mathbb{R}^{n_l \times n_{l-1}}\), \(b^{(l)} \in \mathbb{R}^{n_l}\), and \(\sigma^{(l)}\) is applied elementwise (except at the output layer, where softmax normalizes across the whole vector). The full network is a composition:

$$f(x) = \sigma^{(L)}\!\left(W^{(L)} \sigma^{(L-1)}\!\left(\cdots \sigma^{(1)}\!\left(W^{(1)}x + b^{(1)}\right)\cdots\right) + b^{(L)}\right)$$

Shape Bookkeeping

If layer \(l\) has \(n_l\) neurons, then \(W^{(l)}\) is \(n_l \times n_{l-1}\) so that \(W^{(l)}a^{(l-1)}\) maps an \(n_{l-1}\)-vector to an \(n_l\)-vector. Total trainable parameters:

$$\text{params} = \sum_{l=1}^{L} \left(n_{l-1} \cdot n_l + n_l\right)$$

Gradient Flow (Backpropagation Preview)

Training minimizes a loss \(\mathcal{L}(f(x), y)\) via gradient descent. The chain rule propagates error backward layer by layer:

$$\frac{\partial \mathcal{L}}{\partial W^{(l)}} = \delta^{(l)} \left(a^{(l-1)}\right)^\top, \qquad \delta^{(l)} = \left(\left(W^{(l+1)}\right)^\top \delta^{(l+1)}\right) \odot \sigma'^{(l)}\!\left(z^{(l)}\right)$$

where \(\delta^{(l)}\) is the error signal at layer \(l\) and \(\odot\) is elementwise product. This is why the choice of \(\sigma\) matters for trainability: ReLU's derivative is 0 or 1 (cheap, avoids vanishing gradients for active units), while sigmoid/tanh derivatives saturate near 0 for large \(|z|\), causing vanishing gradients in deep stacks.

⚠️ Common Misconception

"More hidden layers always means a strictly more expressive, better model." Depth increases capacity, but without nonlinearity, regularization, and proper initialization, deep MLPs suffer vanishing/exploding gradients and overfit small datasets. Capacity is necessary but not sufficient for good generalization.

Key Takeaways
▼

When to use a plain MLP:

  • Tabular / structured data with no strong spatial or sequential structure
  • As the final classification/regression "head" on top of CNN or Transformer features
  • Small-to-medium datasets where a simple, fast baseline is needed
  • Function approximation, regression, and low-dimensional embeddings

When NOT to use a plain MLP:

  • Images — MLPs ignore spatial locality; use CNNs instead (far fewer parameters via weight sharing)
  • Sequences / text — MLPs have no notion of order; use RNNs or Transformers
  • Very high-dimensional raw input — parameter count in the first layer explodes (\(n_0 \times n_1\))
💡 Hierarchy

A single-layer perceptron (no hidden layer) can only separate linearly separable data. An MLP adds one or more hidden layers, giving it the ability to carve arbitrarily complex, non-linear decision boundaries — every modern deep architecture (CNN, Transformer, etc.) is built from MLP-style feedforward blocks at some point in its pipeline.

Code Trace
▼
import numpy as np
# Input layer: 3 features
x = np.array([1.0, 0.5, -0.5])
# Hidden layer 1: 3 -> 4, ReLU
W1 = np.array([[0.30,-0.20, 0.50],
[0.10, 0.40,-0.30],
[-0.40,0.20, 0.10],
[0.25, 0.25, 0.25]])
b1 = np.array([0.1, -0.1, 0.05, 0.0])
relu = lambda z: np.maximum(0, z)
z1 = W1 @ x + b1 # affine transform
a1 = relu(z1) # nonlinearity
# Hidden layer 2: 4 -> 3, ReLU
W2 = np.array([[0.20,-0.10, 0.30, 0.05],
[-0.30,0.40, 0.10,-0.20],
[0.15, 0.15,-0.25, 0.35]])
b2 = np.array([0.05, -0.05, 0.1])
z2 = W2 @ a1 + b2
a2 = relu(z2)
# Output layer: 3 -> 2, softmax
W3 = np.array([[0.40,-0.30, 0.20],
[-0.20,0.50, 0.10]])
b3 = np.array([0.0, 0.1])
z3 = W3 @ a2 + b3 # logits
exp_z = np.exp(z3 - np.max(z3))
probs = exp_z / exp_z.sum() # softmax
print(probs) # [0.4818, 0.5182]
