Understanding Power Iteration
▼

What is it? Power iteration is the simplest algorithm for finding a matrix's dominant eigenvector — the direction that gets stretched the most when you apply the matrix. You start with any vector, multiply by the matrix, then normalize back to unit length. Repeat until the vector stops changing.

Analogy: Imagine you're standing in a strong wind that blows mostly eastward but slightly northward. No matter which way you initially face, if you always turn to face the wind direction after each gust, you'll quickly settle pointing east-by-northeast — the wind's dominant direction. The matrix \(A\) is the "wind," and the dominant eigenvector is the direction you end up facing.

If you remember one thing

The loop \(x \leftarrow Ax / \|Ax\|\), repeated from any start, converges to the dominant eigenvector \(v_1\). The convergence rate is \(|\lambda_2/\lambda_1|^k\) — small spectral gap means slow convergence. The Rayleigh quotient \(\rho(x) = x^\top A x\) gives the eigenvalue estimate.

Connection to PageRank

Google's original PageRank is exactly power iteration on the column-stochastic web-link matrix \(G\). The dominant eigenvector (eigenvalue = 1) gives each page's importance score. Brin & Page ran this loop on ~25 million pages in 1998. Modern PageRank still uses variants of this loop.

How It Works Internally
▼

The Algorithm

Given a matrix \(A \in \mathbb{R}^{n \times n}\) with distinct eigenvalues \(|\lambda_1| > |\lambda_2| \geq \cdots \geq |\lambda_n|\), start with any \(x_0\) not orthogonal to \(v_1\). Repeat:

$$x_{k+1} = \frac{A x_k}{\|A x_k\|}$$

Why Multiplication by A Works

Any vector \(x_0\) can be written as a linear combination of all eigenvectors: \(x_0 = c_1 v_1 + c_2 v_2 + \cdots + c_n v_n\). After \(k\) multiplications without normalization:

$$A^k x_0 = c_1 \lambda_1^k v_1 + c_2 \lambda_2^k v_2 + \cdots = \lambda_1^k \!\left[ c_1 v_1 + c_2 \!\left(\frac{\lambda_2}{\lambda_1}\right)^{\!k} v_2 + \cdots \right]$$

Since \(|\lambda_2/\lambda_1| < 1\), the terms for \(v_2, v_3, \ldots\) shrink geometrically. Dividing by \(\lambda_1^k\), we get \(x_0 \to c_1 v_1\) (up to normalization). The normalization step keeps \(\|x_k\| = 1\) to prevent numerical overflow.

The Rayleigh Quotient — Getting the Eigenvalue

Once \(x_k \approx v_1\), the eigenvalue is estimated by:

$$\rho(x) = \frac{x^\top A x}{x^\top x} \xrightarrow{x \to v_1} \lambda_1$$

The Rayleigh quotient converges twice as fast as the vector itself: if the vector error is \(O(r^k)\) where \(r = |\lambda_2/\lambda_1|\), the eigenvalue error is \(O(r^{2k})\). This is because Rayleigh is stationary at eigenvectors (its gradient is zero there).

Prerequisite — Dominant Eigenvalue Must Be Unique

Power iteration requires \(|\lambda_1| > |\lambda_2|\) (the dominant eigenvalue is strictly largest in magnitude). If two eigenvalues tie in magnitude, the iterates oscillate. For symmetric \(A\), all eigenvalues are real, so the condition becomes \(\lambda_1 > |\lambda_2|\). PageRank satisfies this by the Perron-Frobenius theorem.

Why It Works — The Math
▼

Convergence Proof Sketch

Expand \(x_0 = \sum_i c_i v_i\) in the eigenbasis (assuming \(c_1 \neq 0\)). After normalizing the power \(A^k x_0 / \|A^k x_0\|\):

$$x_k = \pm \frac{c_1 v_1 + \sum_{i \geq 2} c_i (\lambda_i/\lambda_1)^k v_i}{\left\| c_1 v_1 + \sum_{i \geq 2} c_i (\lambda_i/\lambda_1)^k v_i \right\|}$$

As \(k \to \infty\), \((\lambda_i / \lambda_1)^k \to 0\) for all \(i \geq 2\). So \(x_k \to \pm v_1\). The error in the direction satisfies:

$$\sin(\angle(x_k, v_1)) = O\!\left(\left|\frac{\lambda_2}{\lambda_1}\right|^{\!k}\right)$$

Our 2×2 Example

For \(A = \begin{bmatrix} 3 & 1 \\ 1 & 2 \end{bmatrix}\): eigenvalues \(\lambda_1 = \tfrac{5+\sqrt{5}}{2} \approx 3.618\), \(\lambda_2 = \tfrac{5-\sqrt{5}}{2} \approx 1.382\). Note \(\lambda_1 = 2 + \phi\) and \(\lambda_2 = 2 + 1/\phi\) where \(\phi = (1+\sqrt{5})/2\) is the golden ratio. Ratio \(|\lambda_2/\lambda_1| \approx 0.382 = 1/\phi^2\). Each iteration shrinks the angular error by \(\approx 38\%\).

Exact Eigenvalues for A = [[3,1],[1,2]]

Characteristic polynomial: \(\det(A - \lambda I) = (3-\lambda)(2-\lambda) - 1 = \lambda^2 - 5\lambda + 5 = 0\).
Roots: \(\lambda = \tfrac{5 \pm \sqrt{5}}{2}\), so \(\lambda_1 \approx 3.61803\), \(\lambda_2 \approx 1.38197\).
Eigenvector for \(\lambda_1\): \((A - \lambda_1 I)v = 0\) gives \(v_1 \propto [1, \lambda_1 - 3] = [1, \phi - 1] \propto [\phi, 1]\), normalized to \(\approx [0.8507, 0.5257]\).

Rayleigh Quotient Converges Quadratically

If the iterate error in direction is \(\epsilon_k = O(r^k)\), then \(|\rho(x_k) - \lambda_1| = O(r^{2k})\). This is because \(\rho\) is a stationary function at eigenvectors: its first-order Taylor expansion around \(v_1\) vanishes, leaving only second-order terms. After 5 steps in our example, the vector is 99.7% accurate but the Rayleigh quotient is 99.99% accurate.

Key Takeaways & PageRank Connection
▼

When to Use Power Iteration

  • Only need the dominant eigenvector — e.g., PageRank, PCA's first principal component, spectral clustering's leading vector
  • Large sparse matrices — each step costs only one matrix-vector product \(O(nnz)\), far cheaper than full eigendecomposition \(O(n^3)\)
  • Matrix is only available as a linear operator — you never need to form \(A\) explicitly; just implement \(x \mapsto Ax\)

When NOT to Use

  • Need multiple eigenvectors — use QR iteration or Lanczos/Arnoldi instead
  • Spectral gap \(|\lambda_2/\lambda_1|\) is close to 1 — convergence is very slow; Shift-and-invert power iteration is better
  • Full eigendecomposition needed — just use numpy.linalg.eig
PageRank in One Paragraph

Build the column-stochastic Google matrix \(G = \alpha L + (1-\alpha) \tfrac{1}{n} \mathbf{1}\mathbf{1}^\top\) where \(L\) is the normalized link matrix and \(\alpha \approx 0.85\) is the damping factor. The PageRank vector \(\pi\) satisfies \(G\pi = \pi\) — it is the dominant eigenvector with \(\lambda_1 = 1\). Power iteration starting from the uniform distribution converges in \(\approx \log_{1/\alpha}(1/\epsilon)\) steps. With \(\alpha = 0.85\), the spectral gap is \(1 - 0.85 = 0.15\), so about 50 iterations gives double-precision accuracy.

Summary: The Three Facts to Know

1. Loop: \(x \leftarrow Ax / \|Ax\|\) converges to the dominant eigenvector \(v_1\).
2. Rate: error shrinks as \(|\lambda_2/\lambda_1|^k\) per iteration.
3. Eigenvalue: extract \(\lambda_1\) via Rayleigh quotient \(\rho = x^\top Ax\), which converges twice as fast.

Code Trace
▼
import numpy as np
A = np.array([[3., 1.],
[1., 2.]]) # symmetric, eigenvalues ≈ 3.618, 1.382
x = np.array([1., 0.]) # arbitrary start
for k in range(30):
x_new = A @ x # multiply: stretch toward dominant dir
rayleigh = (x @ A @ x)/(x @ x) # Rayleigh quotient → λ₁
x = x_new / np.linalg.norm(x_new) # normalize back to unit sphere
if k < 4:
print(f"k={k+1} x={x} λ≈{rayleigh:.5f}")
# Rayleigh quotient gives eigenvalue estimate
lambda1_est = x @ A @ x # ≈ 3.61803
print(f"λ₁ ≈ {lambda1_est:.5f}") # golden ratio + 2!
