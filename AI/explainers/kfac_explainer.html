K-FAC: Kronecker-Factored Approximate Curvature

Practical second-order / natural-gradient training via cheap Kronecker-product Fisher inverses
Advanced Optimization Second-Order O(d_in³ + d_out³) per layer
1
Understanding K-FAC
▼

What is it? Standard gradient descent (SGD) treats all parameters as equally important and ignores how the loss curves. The curvature (Fisher information or Hessian) tells you the optimal step size in each direction, but computing and inverting the full curvature matrix for a neural net costs trillions of operations — completely infeasible. K-FAC approximates the curvature of each layer as a Kronecker product of two small matrices, making the inverse cheap to compute.

Analogy: Imagine navigating a mountain range blindfolded (SGD) vs. having a terrain map (natural gradient). The map is prohibitively large to carry, so K-FAC gives you a compressed approximation of the map — good enough to take smarter steps, light enough to actually carry. The compression works because each layer's curvature has a special structure: input statistics and output-gradient statistics are nearly independent, so you only need two small matrices instead of one giant one.

💡 If you remember one thing

K-FAC approximates each layer's Fisher block as \(\mathbf{F}_\ell \approx \mathbf{G}_\ell \otimes \mathbf{A}_\ell\) where \(\mathbf{A}_\ell = \mathbb{E}[\mathbf{a}\mathbf{a}^\top]\) is the input covariance and \(\mathbf{G}_\ell = \mathbb{E}[\boldsymbol{\delta}\boldsymbol{\delta}^\top]\) is the output-gradient covariance. The inverse then factorizes as \(\mathbf{F}_\ell^{-1} \approx \mathbf{G}_\ell^{-1} \otimes \mathbf{A}_\ell^{-1}\), turning one massive inversion into two small ones.

How K-FAC Works Internally
▼

The Problem: The Fisher Matrix Is Enormous

Natural gradient descent updates parameters as \(\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \alpha \mathbf{F}^{-1}\mathbf{g}\), where \(\mathbf{F}\) is the Fisher information matrix and \(\mathbf{g}\) is the gradient. For a layer with weight matrix \(\mathbf{W} \in \mathbb{R}^{d_\text{out} \times d_\text{in}}\), the corresponding Fisher block has size \((d_\text{out} \cdot d_\text{in})^2\). For a single fully-connected layer with 1000 inputs and 1000 outputs, that's a \(10^6 \times 10^6\) matrix — impossible to store or invert.

The K-FAC Approximation: Exploit Layer Structure

For a layer computing \(\mathbf{s} = \mathbf{W}\mathbf{a}\), where \(\mathbf{a}\) is the (augmented) input and \(\boldsymbol{\delta} = \partial \mathcal{L}/\partial \mathbf{s}\) is the pre-activation gradient, the gradient of the loss w.r.t. \(\mathbf{W}\) is:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{W}} = \boldsymbol{\delta}\,\mathbf{a}^\top$$

The exact Fisher block is \(\mathbf{F} = \mathbb{E}[\text{vec}(\boldsymbol{\delta}\mathbf{a}^\top)\,\text{vec}(\boldsymbol{\delta}\mathbf{a}^\top)^\top]\). Expanding the Kronecker structure: \(\text{vec}(\boldsymbol{\delta}\mathbf{a}^\top) = \mathbf{a} \otimes \boldsymbol{\delta}\), so

$$\mathbf{F} = \mathbb{E}[(\mathbf{a}\otimes\boldsymbol{\delta})(\mathbf{a}\otimes\boldsymbol{\delta})^\top] = \mathbb{E}[\mathbf{a}\mathbf{a}^\top \otimes \boldsymbol{\delta}\boldsymbol{\delta}^\top]$$

K-FAC makes the independence approximation: \(\mathbb{E}[\mathbf{a}\mathbf{a}^\top \otimes \boldsymbol{\delta}\boldsymbol{\delta}^\top] \approx \mathbb{E}[\mathbf{a}\mathbf{a}^\top] \otimes \mathbb{E}[\boldsymbol{\delta}\boldsymbol{\delta}^\top]\), giving:

$$\mathbf{F} \approx \mathbf{A} \otimes \mathbf{G} \quad \text{where} \quad \mathbf{A} = \mathbb{E}[\mathbf{a}\mathbf{a}^\top],\quad \mathbf{G} = \mathbb{E}[\boldsymbol{\delta}\boldsymbol{\delta}^\top]$$

The Cheap Inverse via Mixed-Product Property

The Kronecker mixed-product property states \((\mathbf{B}\otimes\mathbf{A})(\mathbf{D}\otimes\mathbf{C}) = (\mathbf{BD})\otimes(\mathbf{AC})\). Applying this:

$$(\mathbf{A}\otimes\mathbf{G})^{-1} = \mathbf{A}^{-1}\otimes\mathbf{G}^{-1}$$

The natural gradient update for the weight matrix then becomes:

$$\Delta\mathbf{W} = \mathbf{G}^{-1}\,\frac{\partial\mathcal{L}}{\partial\mathbf{W}}\,\mathbf{A}^{-1}$$

Instead of inverting an \((d_\text{out}\cdot d_\text{in})^2\) matrix, we invert two matrices: \(\mathbf{A}^{-1}\) of size \(d_\text{in}\times d_\text{in}\) and \(\mathbf{G}^{-1}\) of size \(d_\text{out}\times d_\text{out}\).

🔑 Key Property

K-FAC reduces the per-layer cost from \(\mathcal{O}((d_\text{in}d_\text{out})^3)\) to \(\mathcal{O}(d_\text{in}^3 + d_\text{out}^3)\). For a 1000×1000 layer that's \(10^{18}\) vs \(2\times 10^9\) — a billion-fold reduction. In practice, the factors \(\mathbf{A}\) and \(\mathbf{G}\) are updated with an exponential moving average, and damping \(\lambda\mathbf{I}\) is added before inversion.

3
The Math Behind K-FAC
▼

Kronecker Product Recap

For matrices \(\mathbf{A} \in \mathbb{R}^{m\times m}\) and \(\mathbf{G} \in \mathbb{R}^{n\times n}\), their Kronecker product \(\mathbf{G}\otimes\mathbf{A} \in \mathbb{R}^{mn\times mn}\) has the block form where block \((i,j)\) equals \(G_{ij}\mathbf{A}\). The critical identity is the mixed-product property:

$$(\mathbf{B}\otimes\mathbf{A})(\mathbf{D}\otimes\mathbf{C}) = (\mathbf{BD})\otimes(\mathbf{AC})$$

Setting \(\mathbf{B}=\mathbf{G}\), \(\mathbf{D}=\mathbf{G}^{-1}\), \(\mathbf{A}=\mathbf{A}\), \(\mathbf{C}=\mathbf{A}^{-1}\) immediately gives \((\mathbf{G}\otimes\mathbf{A})(\mathbf{G}^{-1}\otimes\mathbf{A}^{-1}) = \mathbf{I}\).

The vec-Gradient and Fisher Derivation

Let \(\mathbf{W} \in \mathbb{R}^{d_\text{out}\times d_\text{in}}\). Using \(\text{vec}(\mathbf{XYZ}) = (\mathbf{Z}^\top \otimes \mathbf{X})\,\text{vec}(\mathbf{Y})\), and noting \(\partial\mathcal{L}/\partial\mathbf{W} = \boldsymbol{\delta}\mathbf{a}^\top\), we have:

$$\mathbf{g} = \text{vec}\!\left(\frac{\partial\mathcal{L}}{\partial\mathbf{W}}\right) = \text{vec}(\boldsymbol{\delta}\mathbf{a}^\top) = \mathbf{a}\otimes\boldsymbol{\delta}$$

The exact Fisher block for layer \(\ell\) is:

$$\mathbf{F}_\ell = \mathbb{E}[\mathbf{g}\mathbf{g}^\top] = \mathbb{E}[(\mathbf{a}\otimes\boldsymbol{\delta})(\mathbf{a}\otimes\boldsymbol{\delta})^\top] = \mathbb{E}[\mathbf{a}\mathbf{a}^\top\otimes\boldsymbol{\delta}\boldsymbol{\delta}^\top]$$

K-FAC replaces this with its approximation under the independence assumption \(\mathbf{a} \perp\!\!\!\perp \boldsymbol{\delta}\):

$$\hat{\mathbf{F}}_\ell = \mathbb{E}[\mathbf{a}\mathbf{a}^\top]\otimes\mathbb{E}[\boldsymbol{\delta}\boldsymbol{\delta}^\top] = \mathbf{A}_\ell\otimes\mathbf{G}_\ell$$

Damped Update Rule

In practice, raw \(\mathbf{A}_\ell\) and \(\mathbf{G}_\ell\) can be near-singular. Tikhonov damping is added:

$$\Delta\mathbf{W}_\ell = (\mathbf{G}_\ell + \lambda\mathbf{I})^{-1}\,\frac{\partial\mathcal{L}}{\partial\mathbf{W}_\ell}\,(\mathbf{A}_\ell + \lambda\mathbf{I})^{-1}$$

The factors are updated with exponential moving averages at every step \(t\):

$$\mathbf{A}_\ell \leftarrow (1-\rho)\mathbf{A}_\ell + \rho\,\mathbf{a}\mathbf{a}^\top, \quad \mathbf{G}_\ell \leftarrow (1-\rho)\mathbf{G}_\ell + \rho\,\boldsymbol{\delta}\boldsymbol{\delta}^\top$$

Inverses \(\mathbf{A}_\ell^{-1}\), \(\mathbf{G}_\ell^{-1}\) are recomputed less frequently (every \(T_\text{inv}\) steps, typically 100) to amortize cost.

⚠️ The Independence Approximation

The factorization \(\mathbb{E}[\mathbf{a}\mathbf{a}^\top\otimes\boldsymbol{\delta}\boldsymbol{\delta}^\top] \approx \mathbb{E}[\mathbf{a}\mathbf{a}^\top]\otimes\mathbb{E}[\boldsymbol{\delta}\boldsymbol{\delta}^\top]\) assumes inputs \(\mathbf{a}\) and output gradients \(\boldsymbol{\delta}\) are uncorrelated across the mini-batch. This is generally not true — \(\boldsymbol{\delta}\) is computed via backprop through layers that see the same \(\mathbf{a}\). The approximation is justified empirically but lacks formal guarantees. The error is often acceptable in practice.

Key Takeaways & Comparisons
▼

When to use K-FAC:

  • Large-scale deep networks where SGD/Adam is slow to converge
  • Training from scratch (not fine-tuning) where curvature structure is stable
  • Scientific ML, continual learning, Bayesian deep learning (Laplace approximation)
  • Distributed settings where the factored updates amortize well

When NOT to use:

  • Very small models — overhead of maintaining A, G matrices outweighs benefit
  • Recurrent / attention layers without careful handling (the independence assumption is especially poor)
  • When memory is highly constrained (each layer stores two covariance matrices)

💡 Hierarchy of Approximations

SGD (identity curvature) ⊂ Adam (diagonal Fisher) ⊂ K-FAC (block-diagonal Kronecker) ⊂ Full Natural Gradient (exact Fisher). Each adds more curvature information at higher cost. K-FAC occupies the sweet spot for many deep learning workloads.

Code Trace — K-FAC from Scratch
▼

NumPy implementation of one K-FAC update step for a single linear layer.

import numpy as np
# Layer: d_out=2, d_in=3 (bias absorbed: d_in becomes 4)
d_in, d_out, n_batch = 3, 2, 4
W = np.random.randn(d_out, d_in) # weight matrix (bias separate)
# Mini-batch forward pass
X = np.random.randn(n_batch, d_in) # inputs: (n, d_in)
a = np.hstack([X, np.ones((n_batch,1))]) # augmented: (n, d_in+1)
s = a @ W.T # pre-activations: (n, d_out)
# Backprop: compute delta = dL/ds (n, d_out)
delta = np.random.randn(n_batch, d_out) # from upstream backprop
# Gradient of loss w.r.t. W: dL/dW = delta.T @ a / n (d_out, d_in+1)
grad_W = delta.T @ a / n_batch
# ── K-FAC: compute factor statistics ──
A = a.T @ a / n_batch # input covariance (d_in+1, d_in+1)
G = delta.T @ delta / n_batch # grad covariance (d_out, d_out)
# ── Damped inversion ──
lam = 0.1
A_inv = np.linalg.inv(A + lam * np.eye(d_in+1))
G_inv = np.linalg.inv(G + lam * np.eye(d_out))
# ── Natural gradient update (matrix form) ──
# Equiv to F^{-1} g, where F = G⊗A and g = vec(grad_W)
nat_grad = G_inv @ grad_W @ A_inv # shape (d_out, d_in+1)
# ── Apply update ──
lr = 0.01
W -= lr * nat_grad[:, :d_in] # drop bias column if needed
print("Natural gradient update shape:", nat_grad.shape) # (2, 4)
print("Updated W:", W)
