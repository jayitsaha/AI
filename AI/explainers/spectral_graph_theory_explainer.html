Understanding Spectral Graph Theory
▼

What is it? Spectral graph theory studies graphs by analyzing the eigenvalues and eigenvectors of matrices derived from them — chiefly the Laplacian. Just as music is characterized by its frequency spectrum, a graph is characterized by its Laplacian spectrum: a fingerprint that encodes connectivity, clustering, and flow.

Analogy: Think of a graph as a road network. The Laplacian is like a system of springs connecting intersections. The eigenvalues are the resonant frequencies of those springs. A disconnected city (two islands) has two zero-frequency modes — the whole island can sway independently. The smallest nonzero frequency (Fiedler value \(\lambda_2\)) tells you how hard it is to split the network at its weakest link.

💡 If you remember one thing

The graph Laplacian \(L = D - A\) is positive semidefinite. Its smallest eigenvalue is always \(\lambda_1 = 0\). The multiplicity of 0 equals the number of connected components. The second eigenvalue \(\lambda_2\) (Fiedler value) measures algebraic connectivity — how hard it is to disconnect the graph — and the Cheeger inequality pins it to the graph's actual bottleneck conductance.

The Laplacian and Its Spectrum
▼

Building the Laplacian

Given a graph \(G = (V, E)\) with \(n\) vertices, form:

$$L = D - A \quad \text{where } D_{ii} = \deg(i),\; A_{ij} = \mathbf{1}[(i,j)\in E]$$

Each off-diagonal entry \(L_{ij} = -1\) if \((i,j)\) is an edge, and 0 otherwise. Each row sums to zero: \(L\mathbf{1} = \mathbf{0}\), so \(\mathbf{1}\) is always an eigenvector with eigenvalue 0.

The Quadratic Form — Why Laplacians are PSD

For any vector \(f: V \to \mathbb{R}\):

$$f^\top L f = \sum_{(i,j)\in E}(f_i - f_j)^2 \geq 0$$

This is the Dirichlet energy of \(f\) on the graph — it measures how much \(f\) varies across edges. Being a sum of squares, it is always nonneg, confirming \(L \succeq 0\).

What the Eigenvalues Encode

Sorting eigenvalues \(0 = \lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n\):

  • \(\lambda_1 = 0\) always. Its eigenvector is the constant vector \(\mathbf{1}/\sqrt{n}\).
  • Multiplicity of 0 = number of connected components. Each component contributes one zero eigenvalue (its own constant mode).
  • \(\lambda_2 > 0\) iff the graph is connected. Called the Fiedler value or algebraic connectivity.
  • Large \(\lambda_2\) means the graph is well-connected (expander-like). Small \(\lambda_2\) means there's a bottleneck cut.
🔑 Key Property

By the min-cut max-flow analogy, \(\lambda_2 = \min_{f \perp \mathbf{1}} \frac{f^\top L f}{\|f\|^2}\). This Rayleigh quotient is minimized by the Fiedler vector \(v_2\), whose sign pattern gives the optimal spectral 2-partition of the graph.

Cheeger Inequality — Connecting Spectrum to Cuts
▼

Graph Conductance (Cheeger Constant)

For a set \(S \subset V\), define the cut \(|E(S, \bar{S})|) = \#\{\text{edges crossing the partition}\)\) and the volume \(\text{vol}(S) = \sum_{i \in S} \deg(i)\). The conductance of the cut is:

$$\phi(S) = \frac{|E(S,\bar{S})|}{\min(\text{vol}(S), \text{vol}(\bar{S}))}$$

The Cheeger constant (edge expansion) is \(h(G) = \min_{S} \phi(S)\) — the minimum conductance over all nontrivial cuts.

The Cheeger Inequality

$$\frac{\lambda_2}{2} \leq h(G) \leq \sqrt{2\lambda_2}$$

This two-sided bound is the central theorem of spectral graph theory. Left side (easy direction): any cut's conductance is at least \(\lambda_2/2\). Right side (hard direction): the Fiedler vector gives an actual cut with conductance at most \(\sqrt{2\lambda_2}\).

Proof Sketch of the Lower Bound

Let \(f = \mathbf{1}_S - \frac{\text{vol}(S)}{\text{vol}(V)}\mathbf{1}\) (mean-shifted indicator). Then \(f \perp D\mathbf{1}\) (in the degree-weighted sense) and the Rayleigh quotient of the normalized Laplacian gives \(\lambda_2 \leq 2\phi(S)\), rearranging to \(\phi(S) \geq \lambda_2/2\).

⚠️ Important Subtlety

The upper bound \(h(G) \leq \sqrt{2\lambda_2}\) uses the normalized Laplacian \(L_{\text{sym}} = D^{-1/2}LD^{-1/2}\). For regular graphs the two Laplacians agree (up to scaling), but for irregular graphs you must distinguish them. The Cheeger constant also depends on which Laplacian you use.

Spectral Clustering Connection

The Fiedler vector \(v_2\) minimizes the Rayleigh quotient over all \(f \perp \mathbf{1}\). Its sign partition gives the spectral cut: assign node \(i\) to cluster 1 if \(v_2(i) \geq 0\), else cluster 2. Cheeger guarantees this achieves conductance \(\leq \sqrt{2\lambda_2}\). For \(k\) clusters, use the top \(k\) eigenvectors of \(L\) (or \(L_{\text{sym}}\)) and apply k-means in that spectral embedding.

📐 Spectral Clustering Algorithm

1. Compute \(L = D - A\) (or normalized \(L_{\text{sym}}\)).
2. Find eigenvectors \(v_2, \ldots, v_k\) (smallest nonzero eigenvalues).
3. Embed each node \(i\) as row \((v_2(i), \ldots, v_k(i)) \in \mathbb{R}^{k-1}\).
4. Run k-means on the embedded points. The clusters correspond to the spectral partition.

Key Takeaways & When to Use
▼

When to apply spectral methods:

  • Clustering: data with non-convex cluster shapes (where k-means fails but spectral clustering succeeds)
  • Graph partitioning: VLSI design, parallel computing load balancing, social community detection
  • Random walks / PageRank: the stationary distribution and mixing time are governed by \(\lambda_2\)
  • Graph neural networks: spectral convolution filters operate on the Laplacian eigenbasis

Limitations:

  • Eigenvector computation is \(O(n^3)\) in general — too slow for billion-node graphs (use approximate / randomized methods)
  • Choosing \(k\) (number of clusters) requires inspection of the eigenvalue gap
  • Cheeger upper bound \(\sqrt{2\lambda_2}\) can be loose — spectral cut may not achieve the true optimal conductance
💡 The Eigenvalue Gap Heuristic

Choose \(k\) clusters where there is a large gap between \(\lambda_k\) and \(\lambda_{k+1}\). A big gap means the next eigenvector adds little clustering information. This is the spectral analogue of the "elbow" in k-means.

Code — From Scratch & scikit-learn
▼
import numpy as np
from scipy.sparse.linalg import eigsh
# 5-node graph: edges (0,1),(1,2),(2,3),(3,4),(0,3)
n = 5
A = np.zeros((n, n))
for i,j in [(0,1),(1,2),(2,3),(3,4),(0,3)]:
A[i,j] = A[j,i] = 1
# Graph Laplacian: L = D - A
D = np.diag(A.sum(axis=1)) # degree matrix
L = D - A # L[i,j] = deg(i) if i=j, -1 if edge
# Verify: L is PSD, rows sum to 0
assert np.allclose(L.sum(axis=1), 0) # each row sums to 0
# Eigendecomposition (eigh for symmetric matrices)
vals, vecs = np.linalg.eigh(L)
# vals: [0.0, 0.8299, 2.0, 2.6889, 4.4812]
# Lambda_1 = 0 (always), Lambda_2 = 0.8299 (Fiedler value)
# Fiedler vector: eigenvector for lambda_2
fiedler = vecs[:, 1]
# fiedler ≈ [-0.256, -0.438, -0.256, 0.138, 0.812]
# Spectral 2-clustering by Fiedler vector sign
cluster = (fiedler >= 0).astype(int) # 0: [0,1,2], 1: [3,4]
# Conductance of the cut
S = set(np.where(cluster == 0)[0]) # {0, 1, 2}
cut = sum(A[i,j] for i in S for j in set(range(n))-S)
volS = sum(A[i,:].sum() for i in S) # vol({0,1,2}) = 6
h = cut / volS # h = 2/6 = 0.333...
# Cheeger check: lambda_2/2 <= h <= sqrt(2*lambda_2)
lam2 = vals[1] # 0.8299
assert lam2/2 <= h <= np.sqrt(2*lam2) # 0.415 <= 0.5 <= 1.288
# Production: scikit-learn SpectralClustering
from sklearn.cluster import SpectralClustering
sc = SpectralClustering(n_clusters=2, affinity='precomputed')
labels = sc.fit_predict(A) # uses normalized Laplacian internally
