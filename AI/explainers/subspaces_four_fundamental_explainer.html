The Four Fundamental Subspaces

Column space, null space, row space, left null space — Strang's big picture of linear algebra
Foundational / Intermediate Linear Algebra Math Foundations Must Know for ML
1
Understanding the Four Subspaces
▼

What is this? Every matrix \(A\) of shape \(m \times n\) generates exactly four fundamental subspaces — two living in the input space \(\mathbb{R}^n\) and two in the output space \(\mathbb{R}^m\). Together they completely describe what \(A\) does as a linear map: what outputs are reachable (column space), which inputs map to zero (null space), which linear combinations of rows matter (row space), and which outputs cannot be hit by any input (left null space).

Real-world analogy: Think of \(A\) as a projection from a 3D room (\(\mathbb{R}^n\)) onto a 2D wall (\(\mathbb{R}^m\)). The column space is the illuminated region on the wall — every point you can project onto. The null space is all the depth along the projector beam that vanishes — infinite 3D points that all cast the same shadow. The row space is the useful lateral motion in the room that changes the shadow. The left null space is the dark part of the wall no projector can ever reach.

💡 If you remember one thing

For an \(m \times n\) matrix of rank \(r\): the row space and null space are orthogonal complements in \(\mathbb{R}^n\), and the column space and left null space are orthogonal complements in \(\mathbb{R}^m\). Every vector splits uniquely into a row-space part + a null-space part.

Why ML cares: In PCA the column space of the data matrix holds the directions of variation. Solving \(Ax = b\) requires \(b\) to be in the column space. Underdetermined systems (\(n > m\)) always have null-space freedom. Rank-deficiency in weight matrices = compressed null spaces that matter for generalization.

2
The Four Subspaces — Precise Definitions
▼

Let \(A\) be an \(m \times n\) real matrix with rank \(r\). The four fundamental subspaces are:

1. Column Space \(\operatorname{Col}(A)\) — lives in \(\mathbb{R}^m\)

The set of all linear combinations of the columns of \(A\); equivalently, the range of the linear map \(x \mapsto Ax\):

$$\operatorname{Col}(A) = \{ Ax : x \in \mathbb{R}^n \} \subseteq \mathbb{R}^m, \quad \dim = r$$

A system \(Ax = b\) has a solution if and only if \(b \in \operatorname{Col}(A)\).

2. Null Space \(\operatorname{Null}(A)\) — lives in \(\mathbb{R}^n\)

All vectors mapped to zero by \(A\):

$$\operatorname{Null}(A) = \{ x \in \mathbb{R}^n : Ax = 0 \}, \quad \dim = n - r$$

By the rank-nullity theorem: \(r + (n - r) = n\). If \(A\) has full column rank (\(r = n\)), the null space is trivial: only \(\{0\}\).

3. Row Space \(\operatorname{Row}(A) = \operatorname{Col}(A^\top)\) — lives in \(\mathbb{R}^n\)

All linear combinations of the rows of \(A\):

$$\operatorname{Row}(A) = \operatorname{Col}(A^\top) = \{ A^\top y : y \in \mathbb{R}^m \} \subseteq \mathbb{R}^n, \quad \dim = r$$

4. Left Null Space \(\operatorname{Null}(A^\top)\) — lives in \(\mathbb{R}^m\)

All vectors \(y\) such that \(A^\top y = 0\), i.e., \(y^\top A = 0\):

$$\operatorname{Null}(A^\top) = \{ y \in \mathbb{R}^m : A^\top y = 0 \}, \quad \dim = m - r$$
🔑 The Rank-Nullity Dimension Count

In \(\mathbb{R}^n\): \(\dim\operatorname{Row}(A) + \dim\operatorname{Null}(A) = r + (n-r) = n\).
In \(\mathbb{R}^m\): \(\dim\operatorname{Col}(A) + \dim\operatorname{Null}(A^\top) = r + (m-r) = m\).
The four dimensions are: \(r,\; n-r,\; r,\; m-r\) — completely determined by rank.

The Key Orthogonality Relations

The most important structural fact (proved via the definition of \(Ax = 0\)):

$$\operatorname{Row}(A) \perp \operatorname{Null}(A) \quad \text{in } \mathbb{R}^n$$
$$\operatorname{Col}(A) \perp \operatorname{Null}(A^\top) \quad \text{in } \mathbb{R}^m$$

Proof sketch: If \(r\) is in the row space, then \(r = A^\top y\) for some \(y\). If \(x\) is in the null space, \(Ax=0\). Then \(r^\top x = y^\top A x = y^\top 0 = 0\). So every row-space vector is perpendicular to every null-space vector. QED.

📐 Vector Decomposition Theorem

Every \(x \in \mathbb{R}^n\) decomposes uniquely as \(x = x_r + x_n\) where \(x_r \in \operatorname{Row}(A)\) and \(x_n \in \operatorname{Null}(A)\), with \(x_r \perp x_n\). The map \(A\) then satisfies \(Ax = Ax_r\) (the null component vanishes). This is just the orthogonal decomposition \(\mathbb{R}^n = \operatorname{Row}(A) \oplus \operatorname{Null}(A)\).

3
Strang's Big Picture + Historical Context
▼

Gilbert Strang systematized the "four fundamental subspaces" framework in his 1976 textbook Linear Algebra and Its Applications, making it the organizing principle for understanding linear maps. The insight — that all four spaces arise naturally from one matrix and tile its domain and codomain — was not new (it follows from the 1880s Sylvester rank theorem and Fredholm's 1904 alternative), but Strang popularized the geometric picture that made it teachable.

The Fredholm Alternative (1904)

Ivar Fredholm showed for the equation \(Ax = b\): either (1) a solution exists for every \(b\), or (2) \(A^\top y = 0\) has non-trivial solutions and \(b\) must satisfy \(y^\top b = 0\) for consistency. This is the orthogonality between \(\operatorname{Col}(A)\) and \(\operatorname{Null}(A^\top)\) phrased as a solvability condition.

Why the "Four" and not two?

A matrix and its transpose each generate two subspaces (range + kernel). The transpose flips the roles of \(\mathbb{R}^m\) and \(\mathbb{R}^n\), giving four in total. The SVD (Eckart-Young, 1936; Schmidt, 1907) provides orthonormal bases for all four via the singular vectors: the left singular vectors \(u_i\) (columns of \(U\)) span \(\operatorname{Col}(A)\) and \(\operatorname{Null}(A^\top)\); the right singular vectors \(v_i\) (rows of \(V^\top\)) span \(\operatorname{Row}(A)\) and \(\operatorname{Null}(A)\).

SubspaceSVD basisDimensionLiving in
\(\operatorname{Col}(A)\)First \(r\) cols of \(U\)\(r\)\(\mathbb{R}^m\)
\(\operatorname{Null}(A^\top)\)Last \(m-r\) cols of \(U\)\(m-r\)\(\mathbb{R}^m\)
\(\operatorname{Row}(A)\)First \(r\) rows of \(V^\top\)\(r\)\(\mathbb{R}^n\)
\(\operatorname{Null}(A)\)Last \(n-r\) rows of \(V^\top\)\(n-r\)\(\mathbb{R}^n\)
💡 ML Connection

In ML, the data matrix \(X \in \mathbb{R}^{n \times p}\) (n samples, p features) has: column space = directions reachable by predictions, null space = feature directions that contribute nothing to predictions (multicollinearity!), row space = the "information" in feature space, left null space = sample directions orthogonal to all fitted values. PCA keeps only the row space (top-\(k\) right singular vectors).

4
Computing the Subspaces — Math & Code
▼

Worked Example: \(A = \begin{bmatrix}1&2&0\\0&0&1\end{bmatrix}\), \(m=2, n=3, r=2\)

Row reduce (already in REF):

$$A = \begin{bmatrix}1&2&0\\0&0&1\end{bmatrix}, \quad \text{pivot cols: 1 and 3}$$

The null space: from \(x_1 + 2x_2 = 0,\; x_3 = 0\), set \(x_2 = t\) free: \(x = t[-2, 1, 0]^\top\). So \(\operatorname{Null}(A) = \operatorname{span}\{[-2,1,0]^\top\}\), dimension \(= 3 - 2 = 1\). Verify: \(A[-2,1,0]^\top = [-2+2+0, 0+0+0]^\top = [0,0]^\top\). ✓

The row space: span of the two pivot rows \([1,2,0]\) and \([0,0,1]\), dimension \(= 2\).

The column space: the two pivot columns \([1,0]^\top\) and \([0,1]^\top\) — this is all of \(\mathbb{R}^2\), so \(A\) has full row rank.

The left null space: \(\dim = m - r = 2 - 2 = 0\) (trivial, only \(\{0\}\)).

Orthogonality Check

$$[1,2,0] \cdot [-2,1,0] = -2+2+0 = 0 \quad \checkmark \qquad [0,0,1] \cdot [-2,1,0] = 0 \quad \checkmark$$

From-Scratch Python (NumPy + SVD)

import numpy as np
A = np.array([[1,2,0],[0,0,1]], dtype=float) # 2x3, rank 2
m, n = A.shape # m=2, n=3
# SVD: A = U @ diag(s) @ Vt
U, s, Vt = np.linalg.svd(A, full_matrices=True)
r = np.sum(s > 1e-10) # numerical rank
# Four subspace bases
col_space = U[:, :r] # first r cols of U → in R^m
left_null = U[:, r:] # last m-r cols of U → in R^m
row_space = Vt[:r, :] # first r rows of Vt → in R^n
null_space = Vt[r:, :] # last n-r rows of Vt→ in R^n
# Verify null space: A @ null_vec should be ~0
for nv in null_space:
assert np.allclose(A @ nv, 0, atol=1e-10)
# Vector decomposition: any x = x_row + x_null
x = np.array([3., 1., 2.]) # arbitrary vector in R^3
x_row = row_space.T @ (row_space @ x) # project onto row space
x_null = x - x_row # null component
assert np.allclose(A @ x_null, 0) # null component maps to 0
assert np.allclose(x_row + x_null, x) # partition of unity

Production: scipy.linalg

from scipy.linalg import null_space, orth
import numpy as np
A = np.array([[1,2,0],[0,0,1]], dtype=float)
col = orth(A) # orthonormal basis for Col(A)
null = null_space(A) # orthonormal basis for Null(A)
row = orth(A.T) # orthonormal basis for Row(A)
lnul = null_space(A.T) # orthonormal basis for Left Null(A)
print(f'rank={A.shape[1] - null.shape[1]}')
print(f'nullity={null.shape[1]}')
⚠️ Common Mistake

Row reducing \(A\) gives the null space and row space of \(A\). But the column space is not the span of the pivot columns of the reduced form — it's the span of the pivot columns of the original \(A\). Reduction changes columns; it doesn't change rows.

5
Interview Cheat-Sheet
▼

Q1 (Easy): What is the rank-nullity theorem?

A: For \(A: \mathbb{R}^n \to \mathbb{R}^m\), \(\dim\operatorname{Col}(A) + \dim\operatorname{Null}(A) = n\). The rank counts independent output directions; the nullity counts the "wasted" input directions.

Q2 (Easy): When does \(Ax = b\) have a solution?

A: If and only if \(b \in \operatorname{Col}(A)\). For a unique solution, additionally require \(\operatorname{Null}(A) = \{0\}\) (i.e., full column rank).

Q3 (Medium): Why is \(\operatorname{Row}(A) \perp \operatorname{Null}(A)\)?

A: If \(r = A^\top y \in \operatorname{Row}(A)\) and \(Ax = 0\), then \(r^\top x = (A^\top y)^\top x = y^\top(Ax) = y^\top 0 = 0\). The inner product is zero for every pair, so the subspaces are orthogonal.

Q4 (Medium): How does SVD reveal the four subspaces?

A: In \(A = U \Sigma V^\top\), the first \(r\) columns of \(U\) span \(\operatorname{Col}(A)\), the last \(m-r\) span \(\operatorname{Null}(A^\top)\). The first \(r\) rows of \(V^\top\) span \(\operatorname{Row}(A)\), the last \(n-r\) span \(\operatorname{Null}(A)\). All four bases are orthonormal.

Q5 (Hard): In ML, you train a linear model \(\hat{y} = Xw\). The training loss is zero. What does this imply about \(y\) and the four subspaces of \(X\)?

A: Zero training loss means \(y = Xw\) for some \(w\), i.e., \(y \in \operatorname{Col}(X)\). If \(X\) is \(n \times p\) with \(p > n\) (over-parameterized), then \(\operatorname{Null}(X^\top)\) is trivial but \(\operatorname{Null}(X)\) has dimension \(p - n\) — infinitely many solutions \(w\) exist, all differing by a null-space direction of \(X^\top\) (i.e., an arbitrary vector in \(\operatorname{Null}(X^\top)\) added to a particular solution). The minimum-norm solution is the pseudoinverse \(w^+ = X^+ y = V\Sigma^+ U^\top y\), which lies entirely in the row space of \(X^\top\) (= column space of \(X\)) — i.e., there is zero null-space component.

🚨 Interview Red Flag

Confusing the null space with the left null space is a red flag. The null space of \(A\) contains inputs that collapse to zero. The left null space of \(A\) contains output-space directions unreachable by \(A\). They live in different spaces (\(\mathbb{R}^n\) vs \(\mathbb{R}^m\)).
