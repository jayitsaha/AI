LDA Parameter Inference

Estimating topics and document distributions in Latent Dirichlet Allocation
Foundational Probabilistic ML NLP Advanced
1
Understanding LDA Inference
▼

What is Latent Dirichlet Allocation (LDA)? LDA is a generative probabilistic model for collections of discrete data, like text corpora. It assumes that each document is a mixture of a small number of topics, and that each word in the document is attributable to one of the document's topics. Topics themselves are distributions over words.

Why is inference hard? The core challenge is that the topic assignments for each word, and thus the per-document topic mixtures (\(\theta\)) and per-topic word distributions (\(\phi\)), are latent (hidden) variables. We only observe the words in the documents. Inferring these hidden structures from the observed words is the "inference problem" in LDA.

Analogy: Imagine you have a large collection of recipe books, but all the pages have been torn out and mixed into a huge pile. Each recipe (document) is a list of ingredients (words), and each dish type (topic) has a characteristic set of ingredients. Your goal is to reverse-engineer the original recipes, figure out what kinds of dishes exist, and which ingredients belong to which dish type. This requires inferring which ingredients on a given page belong to which dish, and then using those assignments to reconstruct the overall dish types and individual recipes. This is exactly what LDA inference does, but with words and topics.

💡 If you remember one thing

LDA inference is about estimating the hidden variables (topic assignments \(z_{dn}\) for each word \(w_{dn}\), per-document topic distributions \(\theta_d\), and per-topic word distributions \(\phi_k\)) and hyperparameters (\(\alpha, \beta\)) that best explain the observed words in a corpus. Two main approaches are Variational EM and Gibbs Sampling.

2
How Inference Works Internally
▼

Both Variational Expectation-Maximization (VEM) and Gibbs sampling are iterative algorithms designed to approximate the posterior distributions of LDA's latent variables and parameters. They tackle the intractability of direct computation by different means.

Variational EM (VEM)

VEM is a deterministic algorithm that optimizes a lower bound on the log-likelihood of the observed data. It introduces a simpler, tractable "variational" distribution \(q(\theta, z)\) to approximate the true posterior \(p(\theta, z \mid \mathbf{w}, \alpha, \phi)\). The process alternates between two steps:

  • E-step (Expectation): For each document, find the optimal variational parameters (\(\gamma_d\) for \(\theta_d\) and \(\lambda_{dn}\) for \(z_{dn}\)) that best approximate the posterior distributions of the latent variables, given the current topic-word distributions \(\phi\). This typically involves an inner iterative loop until convergence for each document.
  • M-step (Maximization): Update the global LDA parameters (\(\alpha\) and \(\phi\)) by maximizing the lower bound with respect to these parameters, using the variational posteriors found in the E-step. This step aggregates statistics from all documents.

VEM is generally faster for large corpora because it's deterministic and often converges in fewer macro-iterations. However, it only finds a local optimum of the lower bound, which may not be the global optimum of the true log-likelihood.

Gibbs Sampling

Gibbs sampling is a stochastic algorithm based on Markov Chain Monte Carlo (MCMC). Instead of optimizing, it samples topic assignments for each word. By repeatedly sampling from the conditional distribution of each latent variable given all others, the sequence of samples forms a Markov chain that eventually converges to the true posterior distribution.

  • Sampling Step: For each word \(w_{dn}\) in each document \(d\), temporarily remove its current topic assignment. Then, sample a new topic \(k\) for \(w_{dn}\) from a multinomial distribution whose probabilities are proportional to:
    1. The proportion of words in document \(d\) already assigned to topic \(k\).
    2. The proportion of times word \(w_{dn}\) has been assigned to topic \(k\) across the entire corpus.
    These proportions are smoothed by the Dirichlet hyperparameters \(\alpha\) and \(\beta\).
  • Aggregation: After a "burn-in" period (discarding initial samples), subsequent samples of topic assignments are collected. The final \(\theta_d\) and \(\phi_k\) distributions are estimated by averaging these sampled counts.

Gibbs sampling is conceptually simpler and often easier to implement from scratch. It provides samples from the true posterior, which can be more robust for smaller corpora or when precise uncertainty estimates are needed. However, it can be slower to converge and its stochastic nature means results vary between runs.

🔑 Key Difference

VEM uses a deterministic optimization to find a point estimate of the latent variables and parameters by maximizing a lower bound on the likelihood. Gibbs sampling uses a stochastic process to draw samples from the true posterior distribution, which can then be used to estimate parameters.

3
Why It Works — The Math
▼

The Generative Story of LDA

LDA assumes a hierarchical Bayesian model. For a corpus of \(D\) documents, \(K\) topics, and a vocabulary of size \(V\):

  1. For each topic \(k \in \{1, \dots, K\}\): Draw a topic-word distribution \(\phi_k \sim \text{Dirichlet}(\beta)\).
  2. For each document \(d \in \{1, \dots, D\}\):
    1. Draw a document-topic distribution \(\theta_d \sim \text{Dirichlet}(\alpha)\).
    2. For each word \(n \in \{1, \dots, N_d\}\) in document \(d\):
      1. Draw a topic assignment \(z_{dn} \sim \text{Categorical}(\theta_d)\).
      2. Draw a word \(w_{dn} \sim \text{Categorical}(\phi_{z_{dn}})\).

The goal of inference is to reverse this process: given the observed words \(\mathbf{w}\), find the latent variables \(\mathbf{z}, \mathbf{\theta}, \mathbf{\phi}\) and hyperparameters \(\alpha, \beta\).

Gibbs Sampling: The Core Update Equation

For Gibbs sampling, the key is the conditional probability of assigning a word \(w_{dn}\) to a topic \(k\), given all other topic assignments \(\mathbf{z}_{\neg dn}\) and the observed words \(\mathbf{w}\). This is derived using Bayes' theorem and the conjugacy of Dirichlet-Multinomial distributions:

$$P(z_{dn}=k \mid \mathbf{z}_{\neg dn}, \mathbf{w}, \alpha, \beta) \propto \frac{n_{d,k}^{\neg dn} + \alpha_k}{\sum_{k'=1}^K (n_{d,k'}^{\neg dn} + \alpha_{k'})} \cdot \frac{n_{k,w_{dn}}^{\neg dn} + \beta_{w_{dn}}}{\sum_{w'=1}^V (n_{k,w'}^{\neg dn} + \beta_{w'})}$$

Where:

  • \(n_{d,k}^{\neg dn}\) is the number of words in document \(d\) assigned to topic \(k\), excluding the current word \(w_{dn}\).
  • \(n_{k,w_{dn}}^{\neg dn}\) is the number of times word \(w_{dn}\) is assigned to topic \(k\) across all documents, excluding the current word.
  • \(\alpha_k\) and \(\beta_w\) are elements of the Dirichlet hyperparameters \(\alpha\) and \(\beta\). For symmetric priors, \(\alpha_k = \alpha/K\) and \(\beta_w = \beta/V\).

The first term represents the probability of topic \(k\) given document \(d\), and the second term represents the probability of word \(w_{dn}\) given topic \(k\). The product of these two (smoothed by priors) gives the relative probability for sampling.

Variational EM: Variational Lower Bound and Updates

VEM aims to maximize the Evidence Lower Bound (ELBO) on the log-likelihood. The ELBO involves a variational distribution \(q(\theta, z \mid \gamma, \lambda)\) that approximates the true posterior. The update equations for the variational parameters \(\gamma\) and \(\lambda\) in the E-step are (after some derivation):

$$\gamma_{dk} = \alpha_k + \sum_{n=1}^{N_d} \mathbb{E}_{q}[z_{dnk}] \quad \text{and} \quad \lambda_{kw} = \beta_w + \sum_{d=1}^D \sum_{n=1}^{N_d} \mathbb{E}_{q}[z_{dnk}] \mathbb{I}(w_{dn}=w)$$

The expectation \(\mathbb{E}_{q}[z_{dnk}]\) (often denoted \(\phi_{dnk}\) in original papers, not to be confused with \(\phi_k\)) represents the "soft" assignment of word \(w_{dn}\) to topic \(k\). It is calculated as:

$$\mathbb{E}_{q}[z_{dnk}] \propto \exp\left(\Psi(\gamma_{dk}) - \Psi\left(\sum_{k'=1}^K \gamma_{dk'}\right) + \Psi(\lambda_{kw_{dn}}) - \Psi\left(\sum_{w'=1}^V \lambda_{k w'}\right)\right)$$

Here, \(\Psi\) is the digamma function, the derivative of the log-gamma function, which appears when taking expectations over Dirichlet distributions. The M-step then updates \(\alpha\) and \(\beta\) (or \(\phi\)) using these aggregated expectations.

⚠️ Computational Complexity

While Gibbs sampling is generally simpler to implement, each iteration involves iterating over every word in the corpus. VEM's E-step involves an inner loop per document, which can be expensive. For very large corpora, optimized versions of VEM (e.g., online LDA) are often preferred for their speed, even if they sacrifice some theoretical guarantees.

5
Key Takeaways
▼

Choosing between Variational EM and Gibbs sampling for LDA inference depends on your specific needs and constraints:

When to use Variational EM (VEM):

  • Large Corpora: VEM is generally faster and more scalable, especially with online variants (e.g., Online LDA) that process documents in mini-batches.
  • Deterministic Results: If you need reproducible results across runs (given the same initialization), VEM's deterministic nature is an advantage.
  • Computational Efficiency: Its optimization approach can converge faster in terms of wall-clock time for large datasets.

When to use Gibbs Sampling:

  • Smaller Corpora: For smaller datasets, Gibbs sampling can provide more accurate posterior estimates as it directly samples from the true (albeit approximate) posterior.
  • Simplicity of Implementation: The core sampling equations are often simpler to implement from scratch than the full VEM algorithm with digamma functions.
  • Uncertainty Estimates: Gibbs sampling naturally provides a set of samples from the posterior, which can be used to derive uncertainty estimates (e.g., credible intervals) for \(\theta\) and \(\phi\).

Common Challenges:

  • Choosing \(K\): The number of topics is a critical hyperparameter, often chosen via perplexity or coherence scores.
  • Hyperparameters \(\alpha, \beta\): These Dirichlet priors influence the sparsity of document-topic and topic-word distributions. Small values encourage sparsity.
  • Local Optima (VEM): VEM can get stuck in local optima, requiring multiple random restarts.
  • Convergence (Gibbs): Determining when Gibbs sampling has converged (i.e., reached its stationary distribution) and how long the burn-in period should be can be tricky.
💡 One-Line Summary

VEM offers speed and deterministic approximation by optimizing a lower bound, while Gibbs sampling offers more robust posterior estimates for smaller datasets through stochastic sampling, each with its own trade-offs in complexity and guarantees.

Code Trace (Gibbs Sampling)
▼

Here's a simplified Python-like pseudocode for the core Gibbs sampling step, focusing on resampling a single word's topic assignment. This loop is repeated for every word in every document for many iterations.

import numpy as np
# Initial counts (n_dk: doc-topic, n_kw: topic-word)
# z_dn: current topic assignments for each word
# alpha, beta: Dirichlet priors
# V: vocabulary size, K: number of topics
def gibbs_sample_word_topic(d, n, word_idx, current_z, n_dk, n_kw, alpha, beta, V, K):
# 1. Remove current word's topic assignment from counts
old_topic = current_z[d][n]
n_dk[d][old_topic] -= 1
n_kw[old_topic][word_idx] -= 1
# 2. Compute probabilities for each topic k
p_z = np.zeros(K)
for k in range(K):
# Term 1: P(topic k | document d)
term1 = (n_dk[d][k] + alpha) / (np.sum(n_dk[d]) + K * alpha)
# Term 2: P(word_idx | topic k)
term2 = (n_kw[k][word_idx] + beta) / (np.sum(n_kw[k]) + V * beta)
p_z[k] = term1 * term2
# 3. Normalize probabilities
p_z /= np.sum(p_z)
# 4. Sample a new topic from the computed distribution
new_topic = np.random.choice(K, p=p_z)
# 5. Add new topic assignment back to counts
n_dk[d][new_topic] += 1
n_kw[new_topic][word_idx] += 1
current_z[d][n] = new_topic
return new_topic

This function is called for each word in the corpus, repeatedly. After a sufficient number of iterations (and a burn-in period), the accumulated counts \(n_{dk}\) and \(n_{kw}\) can be used to estimate \(\theta_d\) and \(\phi_k\).
