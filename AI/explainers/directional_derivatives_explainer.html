Understanding Directional Derivatives
▼

What is it? A standard derivative tells you how steeply a curve rises or falls along the x-axis or y-axis. A directional derivative generalises this: it measures how steeply a surface rises or falls if you walk in any direction you choose — not just along an axis. Pick a direction, take a step, measure how much height you gain per unit of distance.

Analogy: Imagine you're standing on a hillside. Looking north, the ground may rise sharply. Looking east, it may be flat. Looking back down the slope, it falls. The directional derivative is exactly the rate of ascent you'd feel if you walked in a specific compass direction. The gradient tells you which direction is steepest of all.

💡 If you remember one thing

The directional derivative in direction \(\mathbf{u}\) is just the dot product $$D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}$$ where \(\mathbf{u}\) is a unit vector. It is maximised when \(\mathbf{u}\) points along \(\nabla f\), and zero when \(\mathbf{u}\) is perpendicular to \(\nabla f\) (i.e., along a level curve).

Why it matters for ML: Gradient descent moves opposite to \(\nabla f\). Directional derivatives explain why that direction is optimal — any other direction has a smaller (or negative) rate of decrease.

How It Works — Definitions & Geometry
▼

Formal Definition

Let \(f: \mathbb{R}^n \to \mathbb{R}\) and let \(\mathbf{u} \in \mathbb{R}^n\) be a unit vector (\(\|\mathbf{u}\|=1\)). The directional derivative of \(f\) at point \(\mathbf{x}_0\) in direction \(\mathbf{u}\) is:

$$D_{\mathbf{u}} f(\mathbf{x}_0) = \lim_{h \to 0} \frac{f(\mathbf{x}_0 + h\,\mathbf{u}) - f(\mathbf{x}_0)}{h}$$

This is exactly the ordinary derivative of the one-variable function \(g(h) = f(\mathbf{x}_0 + h\,\mathbf{u})\) evaluated at \(h=0\). You "slice" the surface with a vertical plane oriented in direction \(\mathbf{u}\) and measure the slope of that cross-section curve.

The Gradient Connection

When \(f\) is differentiable, the chain rule gives the key formula:

$$D_{\mathbf{u}} f(\mathbf{x}_0) = \nabla f(\mathbf{x}_0) \cdot \mathbf{u} = \|\nabla f(\mathbf{x}_0)\| \cos\theta$$

where \(\theta\) is the angle between \(\nabla f\) and \(\mathbf{u}\). This immediately shows:

  • Maximum slope: \(\cos\theta = 1\) when \(\mathbf{u} = \nabla f / \|\nabla f\|\) — uphill steepest
  • Zero slope: \(\cos\theta = 0\) when \(\mathbf{u} \perp \nabla f\) — moving along a level set
  • Maximum descent: \(\cos\theta = -1\) when \(\mathbf{u} = -\nabla f / \|\nabla f\|\) — steepest downhill
🔑 Key Property

The gradient \(\nabla f\) is the unique vector such that \(D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}\) for every unit vector \(\mathbf{u}\). It points in the direction of maximum increase, and its magnitude \(\|\nabla f\|\) equals that maximum rate of increase.

Numerical Example: \(f(x,y) = x^2 + 2y^2\) at \((1,1)\)

Gradient: \(\nabla f = (2x, 4y) = (2, 4)\) at \((1,1)\). Magnitude: \(\|\nabla f\| = \sqrt{4+16} = \sqrt{20} \approx 4.47\).

  • Direction \(\mathbf{u} = (1,0)\): \(D_{\mathbf{u}}f = (2,4)\cdot(1,0) = 2\)
  • Direction \(\mathbf{u} = (0,1)\): \(D_{\mathbf{u}}f = (2,4)\cdot(0,1) = 4\)
  • Direction \(\mathbf{u} = (1,2)/\sqrt{5}\): \(D_{\mathbf{u}}f = (2+8)/\sqrt{5} \approx 4.47\) (steepest!)
  • Direction \(\mathbf{u} = (-2,1)/\sqrt{5}\): \(D_{\mathbf{u}}f = (-4+4)/\sqrt{5} = 0\) (level set)

Why It Works — The Math
▼

Derivation via Chain Rule

Define the path \(\mathbf{x}(h) = \mathbf{x}_0 + h\,\mathbf{u}\). Each component is \(x_i(h) = x_{0,i} + h\,u_i\), so \(dx_i/dh = u_i\). By the multivariable chain rule:

$$D_{\mathbf{u}} f = \frac{d}{dh} f(\mathbf{x}(h))\bigg|_{h=0} = \sum_{i=1}^n \frac{\partial f}{\partial x_i} \cdot \frac{dx_i}{dh} = \sum_{i=1}^n \frac{\partial f}{\partial x_i} u_i = \nabla f \cdot \mathbf{u}$$

This derivation requires that \(f\) is differentiable at \(\mathbf{x}_0\) (all partial derivatives exist AND are continuous). Mere existence of partial derivatives does not suffice.

Cauchy-Schwarz Bound

By Cauchy-Schwarz: \(|\nabla f \cdot \mathbf{u}| \leq \|\nabla f\| \cdot \|\mathbf{u}\| = \|\nabla f\|\). The upper bound is achieved exactly when \(\mathbf{u} = \nabla f / \|\nabla f\|\). Hence:

$$\max_{\|\mathbf{u}\|=1} D_{\mathbf{u}} f = \|\nabla f(\mathbf{x}_0)\|$$
⚠️ Common Pitfall

The direction vector must be a unit vector. If you use \(\mathbf{v}\) with \(\|\mathbf{v}\| \neq 1\), you get \(\nabla f \cdot \mathbf{v}\), which is not a directional derivative — it scales with the magnitude of \(\mathbf{v}\). Always normalise first: \(\mathbf{u} = \mathbf{v}/\|\mathbf{v}\|\).

Level Set Orthogonality

A level set \(\{f(\mathbf{x}) = c\}\) is a curve/surface on which \(f\) is constant. Moving along a level set: \(D_{\mathbf{u}} f = 0\), so \(\nabla f \cdot \mathbf{u} = 0\) — the gradient is perpendicular (normal) to every level set. This geometric fact underlies contour plots: gradient arrows always cross contours at right angles.

$$\nabla f(\mathbf{x}_0) \perp \{\mathbf{x} : f(\mathbf{x}) = f(\mathbf{x}_0)\}$$

Key Takeaways & Connections
▼

Summary

  • The directional derivative \(D_{\mathbf{u}}f = \nabla f \cdot \mathbf{u}\) requires \(\mathbf{u}\) to be a unit vector
  • It equals \(\|\nabla f\|\cos\theta\) where \(\theta\) is the angle to \(\nabla f\)
  • Maximum is \(\|\nabla f\|\) (direction of steepest ascent = gradient direction)
  • Zero when \(\mathbf{u}\) is perpendicular to \(\nabla f\) (moving along a level set)
  • Gradient descent uses \(-\nabla f / \|\nabla f\|\) as the direction of steepest descent

Connections to Machine Learning

  • Gradient descent: Each step moves in direction \(-\nabla_\theta \mathcal{L}\), which maximises decrease for unit step length
  • Natural gradient: Changes the geometry; the "direction" is measured in parameter space with a different metric (Fisher information)
  • Gradient checking: Numerically approximating \(D_{\mathbf{e}_i} f \approx (f(\mathbf{x}+\varepsilon\mathbf{e}_i)-f(\mathbf{x}))/\varepsilon\) verifies backprop
  • Sensitivity analysis: \(D_{\mathbf{u}}f\) at a trained model's weights tells you how sensitive the loss is to perturbations in direction \(\mathbf{u}\)
💡 Gradient Descent Insight

Gradient descent is optimal in the first-order, unit-step sense: among all directions \(\mathbf{u}\) with \(\|\mathbf{u}\|=1\), moving in \(-\nabla f / \|\nabla f\|\) decreases \(f\) the fastest. This is exactly the statement that \(D_{-\nabla f/\|\nabla f\|} f = -\|\nabla f\|\) is the most negative directional derivative.

Code Trace
▼
import numpy as np
# f(x,y) = x^2 + 2y^2
def f(x, y): return x**2 + 2*y**2
# Analytical gradient: ∇f = (2x, 4y)
def grad_f(x, y): return np.array([2*x, 4*y])
# Point of interest
x0, y0 = 1.0, 1.0
g = grad_f(x0, y0) # g = [2, 4]
# Choose direction (MUST be unit vector)
theta = np.radians(63) # gradient direction ≈ 63.4°
v = np.array([np.cos(theta), np.sin(theta)]) # unit vec
# Directional derivative via dot product
D_u_f = np.dot(g, v) # ≈ 4.47 (maximum!)
# Verify numerically (finite difference)
eps = 1e-6
D_numerical = (f(x0+eps*v[0], y0+eps*v[1]) - f(x0, y0)) / eps
print(f"Analytical: {D_u_f:.6f}") # 4.472136
print(f"Numerical: {D_numerical:.6f}") # ≈ 4.472136
# Direction perpendicular to gradient → zero derivative
perp = np.array([-g[1], g[0]]) / np.linalg.norm(g) # rotate 90°
print(np.dot(g, perp)) # ≈ 0.0 (level set direction)
