Understanding Swish / SiLU
▼

What is it? Swish is a smooth activation function that multiplies an input by a soft "gate" computed from the input's own sigmoid: \(\text{Swish}_\beta(x) = x \cdot \sigma(\beta x)\). SiLU (Sigmoid Linear Unit) is the specific, most common case where \(\beta = 1\): \(\text{SiLU}(x) = x\cdot\sigma(x)\). Unlike ReLU, which hard-zeroes every negative input, Swish lets a small sliver of negative signal through, and it never has a sharp corner.

Analogy: Imagine a smart dimmer switch that reads the brightness of the room (the value of x itself) and decides how much of that light to actually let through. A bright room (large positive x) gets almost all its light passed. A pitch-black room (very negative x) gets almost none. But a moderately dim room still lets a little light through, smoothly — unlike a normal on/off light switch (ReLU) that flips abruptly at zero.

💡 If you remember one thing

Swish multiplies x by its own sigmoid gate. At \(\beta=1\) it's called SiLU. As \(\beta \to 0\) it becomes linear (\(x/2\)); as \(\beta \to \infty\) it becomes exactly ReLU. It was discovered by an automated search over thousands of candidate functions — not hand-designed.

How Swish Works Internally
▼

The Problem with ReLU

ReLU (2011) fixed the vanishing-gradient problem of sigmoid/tanh, but introduced its own issues: a hard kink at \(x=0\) (not smooth — the derivative jumps discontinuously), and "dying ReLU" neurons that output exactly 0 forever once their pre-activation goes negative, permanently killing their gradient.

The Swish Solution: Self-Gating

Instead of a hard cutoff, Swish computes a soft gate \(g = \sigma(\beta x) \in (0,1)\) directly from x, then multiplies: \(\text{out} = x \cdot g\). No separate parameters are needed to compute the gate — the same value being transformed also decides how much of itself survives.

$$\text{Swish}_\beta(x) = x \cdot \underbrace{\sigma(\beta x)}_{\text{self-computed gate}}$$

Design Decision: Why Discover It via Search?

Ramachandran, Zoph & Le (Google Brain, 2017) used an RNN controller trained with reinforcement learning — the same NAS-style methodology used to search neural architectures — to search over a huge space of candidate scalar functions built from primitives like x, sigmoid, exp and max. Across thousands of evaluated candidates, \(x\cdot\sigma(\beta x)\) was the most consistent winner across depths and datasets.

🔑 Key Property

Swish is self-gated — the gate uses the exact same scalar x that is being transformed, unlike classic Gated Linear Units, which learn a completely separate projection to compute the gate.

Why It Works — The Math
▼

Derivative Derivation

Starting from \(f(x) = x\cdot\sigma(\beta x)\), apply the product rule. Recall \(\sigma'(z) = \sigma(z)(1-\sigma(z))\):

$$f'(x) = \sigma(\beta x) + \beta x\,\sigma(\beta x)\big(1-\sigma(\beta x)\big)$$

Substituting \(f(x)=x\sigma(\beta x)\) back in gives the compact form used in backprop:

$$f'(x) = \beta f(x) + \sigma(\beta x)\big(1-\beta f(x)\big)$$

Limiting Cases

As \(\beta \to 0\): \(\sigma(\beta x) \to 0.5\) for every finite x, so \(f(x) \to x/2\) — purely linear, no nonlinearity left. As \(\beta \to \infty\): \(\sigma(\beta x)\) converges to the Heaviside step function, so \(f(x) \to x\cdot H(x) = \max(x,0) = \text{ReLU}(x)\).

Global Minimum (β = 1)

Setting \(f'(x)=0\) and solving numerically (no closed form exists) gives the unique global minimum:

$$x^\ast \approx -1.2784, \qquad f(x^\ast) \approx -0.2785$$
⚠️ Common Pitfall

Non-monotonic does not mean non-differentiable. Swish dips below zero and rises back up, but it is \(C^\infty\) smooth everywhere — its second derivative exists at every point, unlike ReLU's (undefined at \(x=0\)).

Key Takeaways
▼

When to use Swish / SiLU:

  • Deep CNNs where a small accuracy gain justifies extra compute (EfficientNet family)
  • Transformer feed-forward blocks, via the SwiGLU gating variant (LLaMA, PaLM)
  • When dying-ReLU neurons are empirically hurting training of a very deep network

When NOT to use:

  • Extremely latency/memory-constrained inference (mobile/edge) — ReLU's near-zero cost wins
  • Simple, shallow models where ReLU already trains fine
  • Learnable β without constraining it \(\geq 0\) — can produce pathological, unbounded-below shapes
💡 The Interpolation Family

Linear (\(\beta{=}0\)) ⊂ Swish (\(0 < \beta < \infty\)) ⊂ ReLU (\(\beta \to \infty\)). A single scalar β continuously sweeps the whole family — SiLU (\(\beta{=}1\)) sits right in the middle, and it's the shape a NAS search converged on as the sweet spot.

Code Trace
▼
import numpy as np
def sigmoid(z):
# numerically stable logistic sigmoid
return np.where(z >= 0, 1/(1+np.exp(-z)), np.exp(z)/(1+np.exp(z)))
def swish(x, beta=1.0):
return x * sigmoid(beta * x) # self-gated: x times its own gate
def swish_grad(x, beta=1.0):
g = sigmoid(beta * x)
f = x * g
return beta * f + g * (1 - beta * f) # f'(x) closed form
# Sanity check against the numerical trace (beta=1)
x = np.array([-3, -1.278, -1, 0, 1, 3])
print(swish(x))
# -> [-0.1423 -0.2785 -0.2689 0. 0.7311 2.8577]
# Production (PyTorch): nn.SiLU() is fused & fixed at beta=1
import torch, torch.nn as nn
y = nn.SiLU()(x_tensor) # == x_tensor * torch.sigmoid(x_tensor)
