1
Understanding Basis Function Regression
▼

What is it? Ordinary linear regression draws a straight line through data: \(\hat{y} = w_0 + w_1 x\). That works when the relationship truly is linear. For curves, bumps, or oscillations, you need something richer. Basis function regression replaces the raw input \(x\) with a set of feature functions — called basis functions \(\phi_k(x)\) — and fits a linear model on top of those transformed features.

The trick: Even though the model is linear in the weights, it is nonlinear in the original input x, because each \(\phi_k(x)\) can curve, peak, oscillate, or bump in any shape you like. The model becomes:

$$\hat{y}(x) = \sum_{k=1}^{K} w_k \phi_k(x) = \mathbf{w}^\top \boldsymbol{\phi}(x)$$

Two flavors of basis functions:

Radial Basis Functions (RBF): Gaussian bells centered at fixed points \(\mu_k\): \(\phi_k(x) = \exp\!\bigl(-\gamma\,\|x - \mu_k\|^2\bigr)\). Each bump "activates" locally near its center and fades elsewhere. The fitted model is a weighted sum of overlapping bumps.

Fourier basis: Sine and cosine functions at increasing frequencies: \(\phi_k(x) \in \{1, \sin(\omega x), \cos(\omega x), \sin(2\omega x), \cos(2\omega x), \ldots\}\). They cover the whole domain globally, making them ideal for periodic or smooth signals.

💡 If you remember one thing

Basis function regression maps \(x \mapsto \boldsymbol{\phi}(x) \in \mathbb{R}^K\), then fits an ordinary linear model in that higher-dimensional space. The nonlinearity is all in the feature map — the learning step is just least squares: \(\hat{\mathbf{w}} = (\Phi^\top \Phi)^{-1} \Phi^\top \mathbf{y}\).

2
How It Works — The Feature Map Trick
▼

Step 1 — Choose Basis Functions and Build the Design Matrix

Given training data \(\{(x_i, y_i)\}_{i=1}^n\), choose \(K\) basis functions \(\phi_1, \ldots, \phi_K\). Evaluate each at every training point to form the design matrix \(\Phi \in \mathbb{R}^{n \times K}\):

$$\Phi = \begin{bmatrix} \phi_1(x_1) & \phi_2(x_1) & \cdots & \phi_K(x_1) \\ \phi_1(x_2) & \phi_2(x_2) & \cdots & \phi_K(x_2) \\ \vdots & \vdots & \ddots & \vdots \\ \phi_1(x_n) & \phi_2(x_n) & \cdots & \phi_K(x_n) \end{bmatrix}$$

This matrix looks exactly like an ordinary regression design matrix — the only difference is that the columns are nonlinear functions of \(x\), not raw inputs.

Step 2 — Solve an Ordinary Least Squares Problem

Now minimize the squared error over the weights \(\mathbf{w} \in \mathbb{R}^K\):

$$\hat{\mathbf{w}} = \underset{\mathbf{w}}{\operatorname{argmin}}\;\|\mathbf{y} - \Phi\mathbf{w}\|_2^2 = (\Phi^\top \Phi)^{-1} \Phi^\top \mathbf{y}$$

This is the Moore-Penrose normal equation — identical to OLS, just applied to the feature-expanded data \(\Phi\). If \(\Phi^\top \Phi\) is ill-conditioned (basis functions too similar, or \(K > n\)), regularize: \(\hat{\mathbf{w}} = (\Phi^\top\Phi + \lambda I)^{-1}\Phi^\top\mathbf{y}\) (ridge regression in feature space).

Step 3 — Predict with Weighted Sum

For a new input \(x^*\), compute its feature vector \(\boldsymbol{\phi}(x^*) = [\phi_1(x^*), \ldots, \phi_K(x^*)]^\top\), then:

$$\hat{y}(x^*) = \hat{\mathbf{w}}^\top \boldsymbol{\phi}(x^*) = \sum_{k=1}^K \hat{w}_k\,\phi_k(x^*)$$

Design Decision: Fixed vs Learned Centers (for RBF)

The simplest approach fixes RBF centers at a regular grid or at the training points. Alternatively, centers can be learned (e.g., by k-means on the training inputs). Bandwidth \(\gamma\) controls the width: large \(\gamma\) → narrow bumps (low bias, high variance); small \(\gamma\) → wide bumps (high bias, low variance). Cross-validation selects both \(K\) and \(\gamma\).

🔑 Key Property

The model is linear in the parameters \(\mathbf{w}\) — so it has a closed-form global optimum, convex loss surface, and all OLS theory (unbiasedness, BLUE under Gauss-Markov) carries over to the feature space. The nonlinearity is entirely encapsulated in \(\boldsymbol{\phi}\).

⚠️ Common Pitfall

If you use one RBF center per training point (\(K = n\)), the model can interpolate perfectly (zero training error), but it will almost certainly overfit. Regularization (ridge) or restricting \(K \ll n\) is essential.

3
The Mathematics
▼

Loss Function and Normal Equations

The residual sum of squares in feature space is:

$$\mathcal{L}(\mathbf{w}) = \|\mathbf{y} - \Phi\mathbf{w}\|_2^2 = (\mathbf{y} - \Phi\mathbf{w})^\top(\mathbf{y} - \Phi\mathbf{w})$$

Expand and differentiate with respect to \(\mathbf{w}\):

$$\frac{\partial \mathcal{L}}{\partial \mathbf{w}} = -2\Phi^\top(\mathbf{y} - \Phi\mathbf{w}) = 0 \implies \Phi^\top\Phi\,\mathbf{w} = \Phi^\top\mathbf{y}$$

Solving (assuming \(\Phi^\top\Phi\) is invertible):

$$\hat{\mathbf{w}} = (\Phi^\top \Phi)^{-1} \Phi^\top \mathbf{y}$$

RBF Basis — Key Formula

The Gaussian RBF centered at \(\mu_k\) with bandwidth \(\gamma > 0\):

$$\phi_k(x) = \exp\!\left(-\gamma \|x - \mu_k\|^2\right)$$

For \(x, \mu_k \in \mathbb{R}^d\), \(\|\cdot\|^2\) is the squared Euclidean norm. In 1D: \(\phi_k(x) = \exp(-\gamma(x-\mu_k)^2)\). The peak is 1 at \(x=\mu_k\) and decays to 0 as \(|x-\mu_k| \to \infty\). The effective support radius is \(\approx 1/\sqrt{\gamma}\).

Fourier Basis — Key Formula

For a signal on \([0, T]\), the \(M\)-th order Fourier feature map is:

$$\boldsymbol{\phi}(x) = \Bigl[1,\;\sin\!\tfrac{2\pi x}{T},\;\cos\!\tfrac{2\pi x}{T},\;\sin\!\tfrac{4\pi x}{T},\;\cos\!\tfrac{4\pi x}{T},\;\ldots,\;\sin\!\tfrac{2\pi M x}{T},\;\cos\!\tfrac{2\pi M x}{T}\Bigr]^\top$$

This gives \(K = 2M+1\) features. By Parseval's theorem, any square-integrable function on \([0,T]\) can be approximated arbitrarily well as \(M \to \infty\).

Regularized (Ridge) Solution

When \(\Phi^\top\Phi\) is ill-conditioned or \(K \geq n\), add an \(\ell_2\) penalty:

$$\hat{\mathbf{w}}_\lambda = (\Phi^\top\Phi + \lambda I_K)^{-1}\Phi^\top\mathbf{y}, \quad \lambda > 0$$

From Scratch — RBF Regression (NumPy)

import numpy as np
def rbf(x, center, gamma):
"""Gaussian RBF: phi_k(x) = exp(-gamma * ||x - center||^2)"""
return np.exp(-gamma * np.sum((x - center)**2, axis=-1))
class RBFRegressor:
def __init__(self, centers, gamma=1.0, ridge=1e-6):
self.centers = np.array(centers) # (K, d) — K RBF centers in d dims
self.gamma = gamma # bandwidth
self.ridge = ridge # L2 regularization strength
self.w = None
def _phi(self, X):
# X: (n, d), returns Phi: (n, K)
return np.column_stack([
rbf(X[:, None] if X.ndim==1 else X, c, self.gamma)
for c in self.centers
])
def fit(self, X, y):
Phi = self._phi(X.reshape(-1, 1) if X.ndim==1 else X) # (n, K)
# Ridge normal equations: w = (Phi^T Phi + lambda I)^{-1} Phi^T y
A = Phi.T @ Phi + self.ridge * np.eye(len(self.centers))
self.w = np.linalg.solve(A, Phi.T @ y)
return self
def predict(self, X):
Phi = self._phi(X.reshape(-1, 1) if X.ndim==1 else X) # (n, K)
return Phi @ self.w # weighted sum of basis functions
# --- usage ---
X = np.array([0.5,1.2,1.8,2.5,3.1,3.8,4.5,5.0])
y = np.array([0.8,2.2,1.4,3.8,2.9,4.8,3.5,5.2])
centers = np.linspace(X.min(), X.max(), 4) # evenly-spaced centers
model = RBFRegressor(centers, gamma=0.8, ridge=1e-4)
model.fit(X, y)
print(model.w) # [0.89, 1.875, 2.125, 4.004]
print(model.predict([3.5])) # ~3.82

From Scratch — Fourier Basis Regression

def fourier_features(x, M, T=2*np.pi):
"""Build Fourier design matrix: [1, sin(wx), cos(wx), ..., sin(Mwx), cos(Mwx)]
x: (n,) array; M: number of harmonics; T: period"""
cols = [np.ones_like(x)]
for m in range(1, M+1):
omega = 2 * np.pi * m / T
cols.append(np.sin(omega * x))
cols.append(np.cos(omega * x))
return np.column_stack(cols) # (n, 2M+1)
x = np.linspace(0, 2*np.pi, 100)
y = np.sin(x) + 0.5*np.cos(2*x) + 0.1*np.random.randn(100)
Phi = fourier_features(x, M=2) # (100, 5)
w, _, _, _ = np.linalg.lstsq(Phi, y, rcond=None)
print(w) # ≈ [0, 1, 0, 0, 0.5] — recovers true coefficients

Production — scikit-learn Pipeline

from sklearn.preprocessing import FunctionTransformer
from sklearn.linear_model import Ridge
from sklearn.pipeline import Pipeline
import numpy as np
def rbf_features(X, centers, gamma=1.0):
"""Vectorized RBF feature map."""
return np.exp(-gamma * (X - centers[None, :])**2)
centers = np.linspace(0, 10, 20) # 20 RBF centers
pipe = Pipeline([
('rbf', FunctionTransformer(rbf_features,
kw_args={'centers': centers, 'gamma': 0.5})),
('ridge', Ridge(alpha=0.01)), # regularized linear fit in feature space

⚠️ Common Gotchas

1. RBF centers outside the test range extrapolate with zero feature activation — all basis functions are near zero, so predictions revert to the mean. 2. Fourier basis assumes the signal is periodic; use it only on data defined on a fixed interval. 3. Forgetting to scale \(x\) to \([0, T]\) before computing Fourier features produces wrong frequencies.

Key Takeaways & When to Use
▼

When to Use Basis Function Regression

RBF regression: Use when the function is smooth but nonlinear, when you have domain knowledge about where the signal concentrates (to place centers), or when you need fast closed-form fitting (no iterative optimization). Works in 1D–3D; suffers the curse of dimensionality in higher dimensions.

Fourier basis: Use when the signal is periodic or quasi-periodic (audio, cyclical time-series, seasonal data). The Fourier basis is the maximum-likelihood feature map under a Gaussian process with a stationary spectral density (Bochner's theorem).

🎯 Decision Guide

Smooth 1D curve, fast closed-form? → RBF regression (4–20 centers, tune γ by cross-validation).
Periodic signal? → Fourier basis (choose M via AIC/BIC).
High-dimensional inputs? → Neural networks or kernel methods (RBF kernel SVM) — explicit basis expansion becomes impractical above ~4D.
Need uncertainty estimates? → Gaussian Process Regression, which uses the same RBF kernel implicitly.

Related topics: Polynomial regression (special case), Gaussian Process regression (kernel = infinite RBF basis), Random Fourier Features (Rahimi & Recht 2007 — approximate kernel machines via random Fourier sampling), Regularization / Ridge regression, Kernel ridge regression.
