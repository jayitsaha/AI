Self-Training (Pseudo-Labeling)

Bootstrap labeled data by letting a model teach itself — with confidence-gated selection.

Intermediate Classical ML Semi-Supervised Iterative Confirmation-Bias Risk
1
Understanding the Concept

What is this? You have a small pile of data with correct answers (labeled) and a huge pile without (unlabeled). Self-training says: train a model on the labeled pile, let it guess labels for the unlabeled pile, then treat the most confident guesses as real — and retrain. Repeat until you run out of unlabeled data or the model stops improving.

Real-world analogy. Imagine training a new postal worker. You show them 50 correctly sorted letters. Then you give them 10,000 unsorted letters and ask them to sort whatever they're confident about. You check only the high-confidence ones (say, top 20%), correct any errors, then re-train the worker using both original letters and accepted ones. The pile shrinks; the worker's skill grows.

💡 If you remember one thing

Self-training iteratively expands the labeled set by filtering predictions through a confidence threshold \(\tau\): only pseudo-labels with \(p(\hat{y}|x) \geq \tau\) are accepted. The threshold is the single most important hyperparameter.

⚠️ Confirmation Bias Risk

Once the model makes an early wrong prediction and accepts it as truth, that error reinforces future iterations. The model "doubles down" on its mistakes — confidence does not equal correctness, especially near decision boundaries.

2
How It Works Internally — Algorithm & Mechanics

Self-training is a wrapper method: it wraps any base classifier that outputs calibrated probabilities. The algorithm is:

  1. Train classifier \(f_\theta\) on labeled set \(\mathcal{L} = \{(x_i, y_i)\}_{i=1}^{n}\).
  2. Run \(f_\theta\) on each unlabeled point \(x_j \in \mathcal{U}\). Obtain \(\hat{p}_j = f_\theta(x_j)\).
  3. Compute confidence: \(c_j = \max_k \hat{p}_j^{(k)}\) (max class probability).
  4. Assign pseudo-label: \(\hat{y}_j = \arg\max_k \hat{p}_j^{(k)}\).
  5. Accept if \(c_j \geq \tau\). Add \((x_j, \hat{y}_j)\) to \(\mathcal{L}\); remove from \(\mathcal{U}\).
  6. Retrain \(f_\theta\) on updated \(\mathcal{L}\). Go to step 2.
  7. Halt when \(\mathcal{U} = \varnothing\) or no new samples accepted in an iteration.
🔑 Key Invariant

Self-training is sound only if the model's confidence is calibrated — i.e., a 90% confidence score actually reflects ~90% accuracy. Uncalibrated models (common with neural nets) require Temperature Scaling or Platt Scaling before applying a threshold.

Design decisions:

  • Static vs. dynamic threshold: Fixed \(\tau\) is simple; curriculum thresholding (start low, increase over iterations) prevents early stagnation.
  • Hard vs. soft pseudo-labels: Hard assigns argmax; soft uses the full probability vector \(\hat{p}_j\) as targets — reduces overconfidence and is used in FixMatch, MixMatch.
  • Top-k vs. threshold: Some implementations accept the top-\(k\) most confident per class per iteration to maintain class balance.
  • Retraining from scratch vs. fine-tuning: Retraining from scratch is more expensive but avoids catastrophic forgetting; fine-tuning is faster but riskier.
3
The Mathematics — Objective & Confidence Thresholding

Let \(\mathcal{L} = \{(x_i, y_i)\}_{i=1}^n\) be labeled and \(\mathcal{U} = \{x_j\}_{j=1}^m\) unlabeled, with \(m \gg n\). Classes \(k \in \{1,\ldots,K\}\).

Supervised loss (initial):

$$\mathcal{L}_s(\theta) = -\frac{1}{n}\sum_{i=1}^{n} \sum_{k=1}^{K} y_i^{(k)} \log f_\theta^{(k)}(x_i)$$

Pseudo-label confidence at iteration \(t\):

$$c_j^{(t)} = \max_{k} f_\theta^{(t)}(x_j)^{(k)}, \quad \hat{y}_j^{(t)} = \arg\max_{k} f_\theta^{(t)}(x_j)^{(k)}$$

Accepted pseudo-label set at iteration \(t\):

$$\mathcal{P}^{(t)} = \left\{ (x_j,\, \hat{y}_j^{(t)}) : x_j \in \mathcal{U},\; c_j^{(t)} \geq \tau \right\}$$

Combined loss for retraining:

$$\mathcal{L}^{(t+1)}(\theta) = \underbrace{-\frac{1}{|\mathcal{L}|}\sum_{(x,y)\in\mathcal{L}} \log f_\theta^{(y)}(x)}_{\text{labeled}} \;+\; \lambda\underbrace{\left(-\frac{1}{|\mathcal{P}^{(t)}|}\sum_{(x,\hat{y})\in\mathcal{P}^{(t)}} \log f_\theta^{(\hat{y})}(x)\right)}_{\text{pseudo-labeled}}$$

where \(\lambda \in [0,1]\) down-weights uncertain pseudo-labels. Setting \(\lambda = 1 - c_j^{(t)}\) (inverse confidence) is a common adaptive variant.

Theoretical justification (Expectation-Maximization view): Self-training approximately maximises the log-likelihood of a Gaussian Mixture Model (GMM). The labeled E-step assigns responsibility; the pseudo-label M-step updates cluster parameters. This holds exactly for GMMs and gives self-training its theoretical grounding — the EM convergence guarantee transfers partially to calibrated classifiers.

📐 Calibration Criterion

A classifier is calibrated if \(\Pr(\hat{y} = y \mid f_\theta(x) = p) = p\) for all \(p \in [0,1]\). Only then does \(c_j \geq \tau\) reliably imply accuracy \(\geq \tau\). Reliability diagrams and Expected Calibration Error (ECE) diagnose this.

Confidence thresholding — numerical example. Suppose \(\tau = 0.80\) and a 3-class softmax output is \(f_\theta(x) = [0.85, 0.10, 0.05]\). Then \(c = 0.85 \geq 0.80\) → accepted as class 0. If \(f_\theta(x') = [0.72, 0.18, 0.10]\), \(c' = 0.72 < 0.80\) → rejected, stays in \(\mathcal{U}\).

🎯 Decision Guide

Use self-training when: your model already outputs calibrated probabilities (e.g., sklearn LogisticRegression), you have a large unlabeled pool, and labeling more data is expensive. Avoid when: your base model is miscalibrated (e.g., raw neural softmax without temperature scaling), or class imbalance is severe (the confident predictions will skew toward majority class).

6
Key Takeaways
  • Self-training expands labeled data by accepting model predictions above a confidence threshold \(\tau\) as pseudo-labels — no human annotation needed.
  • Threshold \(\tau\) is critical: too low → noisy labels corrupt the model; too high → few samples accepted, slow or no improvement.
  • Confirmation bias is the main failure mode — early wrong predictions get reinforced. Mitigate with calibration, co-training, or soft labels.
  • Theoretical grounding via EM: self-training approximates the E-step of EM on a mixture model over labeled + unlabeled data.
  • Modern descendants include FixMatch, UDA, and MixMatch — they add data augmentation consistency regularization on top of the core self-training loop.
  • Related topics to study next: Co-training (§14.1), Label Propagation (§14.1), Transductive SVM, FixMatch, Temperature Scaling for calibration.
