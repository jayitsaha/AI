Understanding Embedded Methods
▼

What is it? Embedded methods for feature selection integrate the selection process directly into the model training algorithm. Unlike filter methods (which select features independently of the model, e.g., by correlation) or wrapper methods (which use a specific model to evaluate subsets of features in an iterative search), embedded methods perform selection as a side effect or inherent part of learning the model itself.

Analogy: Imagine building a custom car (your machine learning model). A filter method would be like picking parts from a catalog based solely on their specifications (e.g., "this engine is powerful"). A wrapper method would be like building many different prototype cars, each with a different combination of parts, and testing them all on a track. An embedded method, however, is like having a smart assembly line that, as it builds the car, automatically decides which parts are essential and discards unnecessary ones, optimizing for performance and efficiency simultaneously. The selection is intrinsic to the construction process.

💡 If you remember one thing

Embedded methods offer a powerful balance: they capture feature interactions (unlike filter methods) and are computationally more efficient than wrapper methods, often leading to better performance and interpretability by identifying truly predictive features during model construction.

2
How Embedded Methods Work Internally
▼

L1 (Lasso) Regularization for Linear Models

Lasso (Least Absolute Shrinkage and Selection Operator) is a modification of linear regression that adds a penalty term to the loss function proportional to the absolute value of the coefficients. This L1 penalty has a unique property: it tends to shrink some coefficients exactly to zero. When a coefficient becomes zero, the corresponding feature is effectively removed from the model, performing automatic feature selection.

Contrast this with L2 (Ridge) regularization, which adds a penalty proportional to the square of coefficients. L2 shrinks coefficients but rarely to exactly zero, making it less suitable for feature selection when sparsity is desired.

Tree-based Feature Importance

For ensemble models built from decision trees (like Random Forests, Gradient Boosting Machines, XGBoost, LightGBM), feature importance can be directly extracted from the trained model. During tree construction, features are chosen for splitting nodes based on how much they reduce impurity (e.g., Gini impurity for classification, variance for regression). A feature's importance is typically calculated as the sum of all impurity reductions it causes across all trees in the ensemble, weighted by the number of samples passing through those nodes. Features that are never used for splitting or contribute little to impurity reduction will have low importance scores.

SHAP-based Feature Selection

SHAP (SHapley Additive exPlanations) values provide a unified framework to explain individual predictions of any machine learning model. Based on cooperative game theory, a SHAP value for a feature represents the average marginal contribution of that feature to the prediction, across all possible combinations of features. For global feature selection, we typically aggregate SHAP values across the entire dataset (e.g., by taking the mean absolute SHAP value for each feature). Features with high mean absolute SHAP values are considered more important, as they have a larger average impact on the model's output.

🔑 Key Property

All three methods integrate feature selection directly into the learning process, leveraging specific model properties (Lasso's penalty, tree split criteria, SHAP's attribution logic) to identify and prioritize relevant features.

Why It Works — The Math
▼

L1 (Lasso) Regularization: The Loss Function

The objective function for Lasso regression minimizes the ordinary least squares (OLS) loss plus the L1 penalty term:

$$L(\beta) = \frac{1}{2N} \sum_{i=1}^N (y_i - x_i^\top \beta)^2 + \lambda \sum_{j=1}^p |\beta_j|$$

Here, \(N\) is the number of samples, \(p\) is the number of features, \(\beta\) is the vector of coefficients, \((y_i, x_i)\) are the observed target and feature vector for sample \(i\), and \(\lambda \ge 0\) is the regularization strength. The key is the non-differentiable absolute value term. Optimization algorithms like coordinate descent or subgradient methods are used. Geometrically, the L1 constraint forms a diamond shape in the parameter space. As the \(\lambda\) increases, this diamond shrinks, and the loss function's contours are more likely to touch the corners of the diamond, which correspond to some \(\beta_j\) being exactly zero.

Tree-based Importance: Gini Impurity Reduction

For a decision tree classifier, Gini impurity at a node \(t\) is \(G(t) = 1 - \sum_{k=1}^K p_k^2\), where \(p_k\) is the proportion of samples belonging to class \(k\). When a node \(t\) is split into left \(t_L\) and right \(t_R\) children using a feature \(j\), the information gain (reduction in impurity) is:

$$IG(t, j) = G(t) - \frac{N_L}{N_t} G(t_L) - \frac{N_R}{N_t} G(t_R)$$

where \(N_t, N_L, N_R\) are the number of samples in node \(t\), \(t_L\), and \(t_R\) respectively. The overall importance of feature \(j\) in an ensemble model is the sum of these gains across all nodes where feature \(j\) is used for splitting, typically normalized across all features:

$$Importance_j = \frac{\sum_{t \in \text{trees}} \sum_{s \in \text{splits on } j \text{ at node } t} IG(t, j)}{\sum_{k=1}^p \sum_{t' \in \text{trees}} \sum_{s' \in \text{splits on } k \text{ at node } t'} IG(t', k)}$$

This provides a relative measure of how much a feature contributes to the model's predictive power.

SHAP Values: Average Marginal Contribution

The SHAP value for a feature \(j\) for a specific prediction \(x\) is defined as:

$$\phi_j(f, x) = \sum_{S \subseteq F \setminus \{j\}} \frac{|S|!(|F|-|S|-1)!}{|F|!} [f_x(S \cup \{j\}) - f_x(S)]$$

where \(F\) is the set of all features, \(S\) is a subset of features excluding \(j\), and \(f_x(S)\) is the model prediction using only features in \(S\). This formula averages the marginal contribution of feature \(j\) when added to all possible subsets \(S\) of other features. For global feature selection, we compute the mean absolute SHAP value for each feature across the entire dataset: \(\text{MeanAbsSHAP}_j = \frac{1}{N} \sum_{i=1}^N |\phi_j(f, x_i)|\). Features with higher mean absolute SHAP values are globally more important.

⚠️ Common Pitfall

Lasso is effective for linear models but can be sensitive to multicollinearity, potentially selecting only one of a group of highly correlated features. Tree-based importances can be biased towards features with more unique values or continuous scales. SHAP values are robust but computationally intensive, especially for large feature sets, as they involve evaluating \\(2^p\\) subsets in the worst case (though approximations exist).

Key Takeaways
▼

When to use each method:

  • L1 (Lasso) Regularization: Ideal for linear models (regression, logistic regression) when you suspect many features are irrelevant or when you need a sparse model (fewer features). Particularly useful in high-dimensional datasets where interpretability is key. Be mindful of multicollinearity, as Lasso tends to pick one feature from a correlated group and zero out the others.
  • Tree-based Importance: A natural choice for ensemble tree models (Random Forest, Gradient Boosting). It inherently captures non-linear relationships and interactions. Feature importances are readily available after training. Useful when your model is already tree-based and you want a quick, interpretable ranking.
  • SHAP-based Selection: Highly versatile and model-agnostic, making it suitable for complex models like deep neural networks or black-box ensembles. Provides a robust, theoretically-sound measure of feature contribution for individual predictions, which can be aggregated for global importance. Excellent when high interpretability and fairness are critical, and you can afford the computational cost.

When NOT to use:

  • Lasso: If your underlying data generating process is highly non-linear, or if you need to retain all correlated features (e.g., for domain knowledge reasons), Lasso might be too aggressive.
  • Tree-based: Can be biased towards features with many unique values or continuous scales. For very simple linear problems, it might overfit compared to a well-regularized linear model.
  • SHAP: Can be computationally expensive, especially for large datasets or models, as exact SHAP calculation involves many model evaluations. Approximate SHAP methods exist to mitigate this.
💡 Big Picture

Embedded methods are powerful because they learn feature importance during the model training itself, leading to more relevant feature subsets and often better predictive performance. The choice among them depends on the model type, data characteristics, and your goals for sparsity, interpretability, and computational efficiency.

Code Trace (Python Examples)
▼
import numpy as np
from sklearn.linear_model import LinearRegression, Lasso
from sklearn.ensemble import RandomForestRegressor
import shap
# 1. Generate synthetic data
X = np.random.rand(100, 8) * 10
y = (X[:, 0]*2 + X[:, 1]*1.5 - X[:, 2]*0.8 + # Important features
X[:, 3]*0.2 + X[:, 4]*0.1 + # Weakly important
X[:, 5]*0.01 + X[:, 6]*0.005 + # Noise features
np.random.randn(100)*2)
X[:, 7] = X[:, 0] * 0.9 + np.random.randn(100)*0.5 # F8 correlated with F0
feature_names = [f'F{i+1}' for i in range(8)]
# 2. OLS (baseline)
ols_model = LinearRegression().fit(X, y)
print("OLS Coefficients:", ols_model.coef_)
# 3. Lasso Regularization
lasso_model = Lasso(alpha=0.1, max_iter=10000).fit(X, y) # alpha is lambda in sklearn
print("Lasso Coefficients (alpha=0.1):", lasso_model.coef_)
# 4. Tree-based Feature Importance
rf_model = RandomForestRegressor(n_estimators=100, random_state=42).fit(X, y)
print("Random Forest Feature Importances:", rf_model.feature_importances_)
# 5. SHAP-based Feature Selection
explainer = shap.TreeExplainer(rf_model)
shap_values = explainer.shap_values(X)
mean_abs_shap = np.mean(np.abs(shap_values), axis=0)
print("Mean Absolute SHAP Values:", mean_abs_shap)
