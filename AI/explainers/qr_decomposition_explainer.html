Understanding QR Decomposition
▼

What is it? Given any matrix \(A\), QR decomposition writes it as a product \(A = QR\) where \(Q\) is an orthogonal matrix (its columns are perpendicular unit vectors) and \(R\) is an upper-triangular matrix (zeros below the diagonal). Think of it as finding the "most natural" coordinate system in which to describe the columns of \(A\).

Analogy: Imagine you have a pile of rulers pointing in random directions. Gram-Schmidt is like straightening them one at a time — you keep the first ruler as-is, then tilt each subsequent ruler so it's perfectly perpendicular to all the ones you've already placed. The result (Q) is a perfect orthonormal frame. The original rulers (A) can be reconstructed by recording "how much of each frame vector you needed" — that record is R.

💡 If you remember one thing

QR decomposes \(A = QR\) so that solving \(Ax = b\) becomes \(Rx = Q^\top b\) — a cheap back-substitution. Householder QR is numerically far superior to classical Gram-Schmidt because it does not accumulate floating-point errors. Always use Householder (or Givens) in production.

Why does it matter?

  • Linear systems: Solving \(Ax=b\) via \(Rx = Q^\top b\) is more stable than via the normal equations \(A^\top A x = A^\top b\).
  • Least squares: The QR approach avoids squaring the condition number — the core advantage over forming \(A^\top A\).
  • Eigenvalues: The QR algorithm iterates QR decompositions to reveal eigenvalues — it's how LAPACK computes them.
  • SVD: QR is a building block in bidiagonalization before the final SVD pass.

Three Roads to QR — Internal Mechanisms
▼

Algorithm 1: Classical Gram-Schmidt (CGS)

Build orthonormal columns of \(Q\) one at a time. For column \(j\) of \(A\), subtract off its projections onto all previously built \(q_i\)'s, then normalize the residual:

$$u_j = a_j - \sum_{i=1}^{j-1}\langle a_j, q_i\rangle\, q_i, \qquad q_j = \frac{u_j}{\|u_j\|_2}$$

The entries \(r_{ij} = \langle a_j, q_i\rangle\) for \(i < j\) fill the upper triangle of \(R\); \(r_{jj} = \|u_j\|_2\). Problem: in finite precision, subtracting large nearly-equal numbers destroys orthogonality — \(Q^\top Q\) drifts far from \(I\) when columns of \(A\) are nearly dependent.

⚠️ Classical Gram-Schmidt Instability

CGS loses orthogonality catastrophically when the input matrix is ill-conditioned. Modified Gram-Schmidt (MGS) re-orthogonalizes at each step and is far better, but still not as stable as Householder in the worst case.

Algorithm 2: Householder Reflections (HH)

Instead of building \(Q\) explicitly, apply a sequence of reflection matrices \(H_k\) to zero out below-diagonal entries column by column. A Householder reflector zeroing all entries of vector \(x\) below the first is:

$$H = I - 2\frac{vv^\top}{\|v\|^2}, \qquad v = x \pm \|x\|_2\, e_1$$

The sign is chosen as \(+\,\text{sign}(x_1)\) to avoid cancellation. After \(n\) reflections: \(H_n \cdots H_1 A = R\), so \(Q = H_1 \cdots H_n\). Crucially, \(H\) is orthogonal and symmetric (\(H^\top H = I\), \(H = H^\top\)), and can be applied implicitly — never forming the full \(m \times m\) matrix.

🔑 Numerical Superiority of Householder

Householder QR is backward stable — it computes the exact QR of a slightly perturbed matrix \(A + \delta A\) with \(\|\delta A\| \sim \varepsilon_\text{mach}\|A\|\). Classical Gram-Schmidt is not backward stable; errors can be much larger.

Algorithm 3: Givens Rotations

Zero one entry at a time with a \(2{\times}2\) rotation in the \((i,k)\)-plane:

$$G(i,k,\theta) = I \text{ except } \begin{pmatrix}g_{ii}&g_{ik}\\g_{ki}&g_{kk}\end{pmatrix} = \begin{pmatrix}c & s \\ -s & c\end{pmatrix}, \quad c^2+s^2=1$$

Choose \(c, s\) to zero \(a_{ki}\). Applying \(G^\top\) to \(A\) affects only two rows at a time — ideal for sparse matrices and parallel hardware. Takes \(O(mn^2)\) rotations total for a dense \(m \times n\) matrix.

Why It Works — The Mathematics
▼

Existence & Uniqueness

For any \(A \in \mathbb{R}^{m \times n}\) with \(m \geq n\), a thin QR decomposition \(A = Q_1 R_1\) always exists with \(Q_1 \in \mathbb{R}^{m \times n}\) having orthonormal columns and \(R_1 \in \mathbb{R}^{n \times n}\) upper triangular. It is unique if \(A\) has full column rank and we require positive diagonal entries of \(R\).

Projection Interpretation of Gram-Schmidt

The projection of \(a\) onto unit vector \(q\) is \(\text{proj}_q(a) = \langle a,q\rangle q\). The residual \(a - \text{proj}_q(a)\) is orthogonal to \(q\). Gram-Schmidt iteratively removes the component of \(a_j\) in the span of \(\{q_1,\dots,q_{j-1}\}\):

$$u_j = a_j - \sum_{i < j} \langle a_j, q_i\rangle\, q_i, \qquad q_j = u_j / \|u_j\|$$

The upper-triangular structure of \(R\) follows because \(r_{ij} = \langle a_j, q_i\rangle\) is nonzero only when \(i \leq j\) (we only project onto already-computed \(q\)'s).

Least Squares via QR

The normal equations for \(\min_x \|Ax - b\|^2\) are \(A^\top A x = A^\top b\). With \(A = QR\):

$$A^\top A = R^\top Q^\top QR = R^\top R, \qquad A^\top b = R^\top Q^\top b$$
$$R^\top R x = R^\top Q^\top b \implies Rx = Q^\top b$$

Solve by back-substitution in \(O(n^2)\). Crucially, \(\kappa(R) = \kappa(A)\) while \(\kappa(A^\top A) = \kappa(A)^2\) — using QR halves the condition number exponent, giving far better numerical accuracy.

Householder: Why \(v = x + \|x\|e_1\)?

We want \(Hx = -\|x\|e_1\) (or \(+\|x\|e_1\)). With \(H = I - 2vv^\top/\|v\|^2\):

$$Hx = x - \frac{2v^\top x}{\|v\|^2}v = x - \frac{2(x+\|x\|e_1)^\top x}{\|x+\|x\|e_1\|^2}(x+\|x\|e_1)$$

Expanding the numerator: \(2(x^\top x + \|x\|x_1) = 2(\|x\|^2 + \|x\|x_1)\). The denominator \(\|v\|^2 = \|x\|^2 + 2\|x\|x_1 + \|x\|^2 = 2(\|x\|^2 + \|x\|x_1)\). The ratio is exactly 1, so \(Hx = x - (x + \|x\|e_1) = -\|x\|e_1\). QED.

Key Formula

The QR least-squares solution: $$\hat{x} = R^{-1}(Q^\top b)$$ where the condition number satisfies \(\kappa(R) = \kappa(A)\), versus \(\kappa(A^\top A) = \kappa(A)^2\) for the normal equations.

def gram_schmidt(A):
m, n = A.shape # m=3, n=2
Q = np.zeros((m, n))
R = np.zeros((n, n))
for j in range(n): # iterate columns
v = A[:, j].copy() # j=0: v = a1 = [3,4,0]
for i in range(j): # subtract projections
R[i,j] = Q[:,i] @ A[:,j] # r01 = q1·a2
v -= R[i,j] * Q[:,i] # remove projection
R[j,j] = np.linalg.norm(v) # r00=5.0, r11=3.394
Q[:,j] = v / R[j,j] # normalize to unit length
return Q, R # A = Q @ R ✓

Householder: The Numerical Workhorse
▼

Householder QR zeroes below-diagonal entries column by column using orthogonal reflections. For each column \(k\), it zeros entries in rows \(k+1,\dots,m\) without touching the upper-left block already processed.

Numerical Trace on A = [[3,1],[4,2],[0,0.5]]

Step k=0: Take \(x = [3,4,0]^\top\). \(\|x\|=5\). Choose \(v = x + 5e_1 = [8,4,0]^\top\). \(\|v\|^2 = 80\). Then \(H_1 A\):

$$H_1 = I - \frac{2vv^\top}{80} = \begin{bmatrix}1-1.6&-0.8&0\\-0.8&1-0.4&0\\0&0&1\end{bmatrix} = \begin{bmatrix}-0.6&-0.8&0\\-0.8&0.6&0\\0&0&1\end{bmatrix}$$

First column of \(H_1 A\): \([-5, 0, 0]^\top\) (exact zero by construction). Second column: \(H_1[1,2,0.5]^\top = [-0.6-1.6, -0.8+1.2, 0.5]^\top = [-2.2, 0.4, 0.5]^\top\).

Step k=1: Now work on the \(2\times 1\) submatrix \([0.4, 0.5]^\top\). \(\|x_2\|=\sqrt{0.41}\approx0.6403\). Build \(H_2\) on this subspace, zeroing the (2,1) entry. Final \(R\) is upper triangular.

⚠️ The Sign Choice Matters

Always pick \(v = x + \text{sign}(x_1)\|x\|e_1\) to avoid cancellation. If \(x_1 > 0\) and we used \(v = x - \|x\|e_1\), the first component of \(v\) would be \(x_1 - \|x\| \approx 0\) — massive cancellation loss. The standard choice ensures \(|v_1| = |x_1| + \|x\| \geq \|x\|\).

Why Implicit Q is Faster

Storing all \(k\) Householder vectors \(v_1,\dots,v_n\) takes \(O(mn)\) space and applying \(Q^\top b = H_n\cdots H_1 b\) costs \(O(mn)\) — no need to form the full \(m \times m\) matrix \(Q\). LAPACK's dgeqrf stores precisely these Householder vectors in the below-diagonal entries of the working matrix, plus an auxiliary \(\tau\) array.

Givens in Action — Sparse Example

For a tridiagonal matrix with only 3 nonzeros per column, Givens is \(O(mn)\) while Householder remains \(O(mn^2)\). Each Givens rotation targets a single sub-diagonal entry:

$$G(i,k)^\top A: \text{ rows } i,k \text{ only} \implies \text{perfect for parallel pipelines}$$

Key Takeaways & When to Use What
▼

Decision guide:

  • Dense general matrix, any language → Householder (LAPACK dgeqrf, NumPy linalg.qr)
  • Sparse or banded matrix → Givens rotations (minimal fill-in)
  • Streaming / rank-1 updates → Givens on existing R (incremental update)
  • Teaching / understanding → Classical Gram-Schmidt, then Modified GS
  • Ill-conditioned system → Always Householder; never form \(A^\top A\)

Interview one-liner: "QR factorizes \(A = QR\) with \(Q\) orthogonal and \(R\) upper triangular. Householder is numerically backward stable and avoids the condition-number squaring of normal equations. Gram-Schmidt builds Q explicitly but loses orthogonality in finite precision."
