Tree Construction: ID3, C4.5 & CART

Greedy recursive partitioning — entropy, gain ratio, and Gini impurity compared side-by-side

Intermediate Classical ML Decision Trees O(mn log n)

Understanding the Concept ▶

A decision tree classifies an example by asking a sequence of yes/no questions about features, routing the data down branches until it reaches a leaf node that gives a prediction. Building the tree is the hard part: out of all the features and thresholds you could split on, which one should go at the root? Which at each subsequent node?

The core insight: pick the split that makes the resulting groups as pure as possible — groups where almost all examples belong to one class. Three algorithms measure "purity" differently:

  • ID3 (Quinlan, 1986) — maximizes information gain (entropy reduction). Categorical features only, multiway splits.
  • C4.5 (Quinlan, 1993) — maximizes gain ratio (information gain divided by split information). Handles continuous values and missing data; includes pruning.
  • CART (Breiman et al., 1984) — minimizes Gini impurity. Always binary splits, works for both classification and regression.
Core Insight

All three algorithms are greedy: at each node, they pick the locally best split without backtracking. The tree grows top-down until a stopping criterion is met (max depth, min samples in a leaf, or when a node is already pure).

Analogy: Think of 20 Questions. Each question partitions the remaining candidates into groups. A good player asks questions that roughly halve the candidates — maximizing information gain. ID3/C4.5/CART all automate this "which question is best?" step, but score questions differently.

How It Works: Three Algorithms ▶

The Greedy Recursive Algorithm (shared skeleton)

def build_tree(X, y, depth=0):
if pure(y) or depth == max_depth:
return Leaf(majority_class(y)) # stopping condition
best_feat, best_thresh = best_split(X, y) # <-- differs per algo
node = Node(best_feat, best_thresh)
for branch in partition(X, best_feat, best_thresh):
node.add_child(build_tree(X_branch, y_branch, depth+1))
return node

ID3 — Information Gain (multiway, categorical only)

At every node, ID3 evaluates every categorical feature \(A\) and picks the one with the largest information gain:

$$\text{IG}(A) = H(S) - \sum_{v \in \text{vals}(A)} \frac{|S_v|}{|S|} H(S_v)$$

where \(H(S) = -\sum_k p_k \log_2 p_k\) is the Shannon entropy of the current node \(S\) and \(S_v\) is the subset where feature \(A\) takes value \(v\). A multiway split creates one branch per unique value. Problem: ID3 prefers features with many distinct values (e.g., a unique ID column has IG = H(S) since every leaf is pure).

C4.5 — Gain Ratio (fixes ID3's bias)

C4.5 divides the information gain by the split information, which penalizes features that create many small branches:

$$\text{GainRatio}(A) = \frac{\text{IG}(A)}{\text{SplitInfo}(A)}, \quad \text{SplitInfo}(A) = -\sum_{v} \frac{|S_v|}{|S|} \log_2 \frac{|S_v|}{|S|}$$

C4.5 also adds continuous feature handling: it sorts values and evaluates all midpoint thresholds, converting them into binary (≤ / >) splits before computing gain ratio. Missing values are handled by distributing a fractional sample to each branch proportionally.

C4.5 Bias Correction Demo

On our 14-sample dataset: IG(Outlook)=0.381, IG(Humidity)=0.258. ID3 picks Outlook. But SplitInfo(Outlook)=1.577 vs SplitInfo(Humidity)=1.000, so GainRatio(Outlook)=0.241 while GainRatio(Humidity)=0.258. C4.5 would pick Humidity at the root instead!

CART — Gini Impurity (always binary)

CART always produces binary trees. For classification, it minimizes the weighted Gini impurity:

$$\text{Gini}(S) = 1 - \sum_k p_k^2, \quad \text{GiniGain}(A, t) = \text{Gini}(S) - \frac{|S_L|}{|S|}\text{Gini}(S_L) - \frac{|S_R|}{|S|}\text{Gini}(S_R)$$

For regression, CART replaces Gini with MSE reduction, and leaf predictions are the mean \(\bar{y}\) of samples that reach that leaf. This unifies classification and regression trees in a single framework.

The Math Behind Each Criterion ▶

Shannon Entropy

Entropy measures the impurity of a node. For a binary classification with \(p^+\) positive examples and \(p^- = 1-p^+\) negative:

$$H(S) = -p^+ \log_2 p^+ - p^- \log_2 p^-$$

Entropy is maximized at 1.0 bit when classes are equal (\(p^+ = 0.5\)) and 0 when a node is pure. For our root: \(p^+ = 8/14 \approx 0.571\), giving \(H(\text{root}) = 0.985\) bits.

Numerical Trace — ID3 at the Root

Dataset: 14 samples, 9 Yes / 5 No (we relabel to 8Y/6N for our version). Features: Outlook (S/O/R), Humidity (High/Normal).

$$H(\text{root}) = -\tfrac{8}{14}\log_2\tfrac{8}{14} - \tfrac{6}{14}\log_2\tfrac{6}{14} = 0.985 \text{ bits}$$

IG(Outlook): Sunny(5): H=0.722, Overcast(4): H=0.000 (pure!), Rain(5): H=0.971.

$$\text{IG}(\text{Outlook}) = 0.985 - \tfrac{5}{14}(0.722) - \tfrac{4}{14}(0.000) - \tfrac{5}{14}(0.971) = 0.381$$

IG(Humidity): High(7): H=0.863, Normal(7): H=0.592.

$$\text{IG}(\text{Humidity}) = 0.985 - \tfrac{7}{14}(0.863) - \tfrac{7}{14}(0.592) = 0.258$$

ID3 picks Outlook (IG=0.381 > 0.258).

Gini Impurity — CART

Gini measures the probability of a random misclassification:

$$\text{Gini}(S) = 1 - \sum_{k} p_k^2 = 1 - \left(\tfrac{8}{14}\right)^2 - \left(\tfrac{6}{14}\right)^2 = 1 - 0.327 - 0.184 = 0.490$$

CART evaluates binary splits. Best binary on Outlook: Overcast vs {Sunny, Rain}. Left=4 (pure Yes, Gini=0), Right=10 (Gini=0.480):

$$\text{GiniGain} = 0.490 - \tfrac{4}{14}(0.000) - \tfrac{10}{14}(0.480) = 0.490 - 0.343 = 0.147$$

CART Regression — MSE Reduction

For regression, CART finds threshold \(t\) that minimizes weighted MSE. With price (thousands) vs sqft, a split at 1350 sqft:

$$\text{MSE\_reduction} = \text{Var}(y) - \frac{n_L}{n}\text{Var}(y_L) - \frac{n_R}{n}\text{Var}(y_R)$$

Left leaf (≤1350, n=3): \(\bar{y}_L = 180\)k. Right leaf (>1350, n=5): \(\bar{y}_R = 380\)k. Total variance = 13300, weighted MSE = 3925, reduction = 9375.

Gini vs Entropy: Are They Different?

Empirically, Gini and entropy choose the same split ~95% of the time. Gini is slightly faster (no log), and both are minimized at pure nodes. The key practical difference between the algorithms is binary vs multiway splits and how they handle continuous features — not the impurity measure.

C4.5 Pruning (Reduced Error Pruning)

After growing the full tree, C4.5 prunes it bottom-up. A subtree is replaced by a leaf if accuracy on the validation set does not decrease. The error rate at a leaf with \(E\) errors out of \(N\) examples is estimated with the upper bound of a binomial confidence interval:

$$\text{UpperBound}(E, N, \text{CF}) = \frac{E + z^2/2 + z\sqrt{E - E^2/N + z^2/4}}{N + z^2}$$

where \(z\) corresponds to confidence factor CF (default 25%). This pessimistic estimate penalizes leaves with few samples, driving pruning of overfitted subtrees.

Common Misconception

"Gini and entropy make the same splits." True ~95% of the time, but when they diverge it matters. Gini is computationally cheaper (no log). The bigger practical difference is binary vs multiway splits: CART's binary splits allow continuous thresholds and integrate naturally with ensembles; ID3's multiway splits can fragment data too finely.

Key Takeaways & Code ▶

Summary

  • All three use greedy recursive partitioning — locally optimal splits, no global search.
  • ID3: entropy / information gain, multiway, categorical only, no pruning. Good for teaching.
  • C4.5: gain ratio fixes ID3's high-cardinality bias; handles continuous + missing data; prunes.
  • CART: Gini/MSE, always binary, classification + regression, powers all major ensembles.
  • All grow until a stopping criterion (max depth, min samples, pure leaf) then optionally prune.

CART from Scratch (Python)

import numpy as np
def gini(y):
if len(y) == 0: return 0
p = np.bincount(y) / len(y) # class probabilities
return 1 - np.sum(p ** 2) # Gini = 1 - sum(p_k^2)
def best_split_cart(X, y):
best_gain, best_f, best_t = -1, None, None
G = gini(y) # impurity before split
n = len(y)
for f in range(X.shape[1]):
thresholds = np.unique(X[:, f]) # candidate thresholds
for t in thresholds:
L, R = y[X[:,f] <= t], y[X[:,f] > t]
if len(L)==0 or len(R)==0: continue
gain = G - (len(L)/n)*gini(L) - (len(R)/n)*gini(R)
if gain > best_gain:
best_gain, best_f, best_t = gain, f, t
return best_f, best_t
class Node:
def __init__(self, feat=None, thresh=None, left=None, right=None, val=None):
self.feat, self.thresh = feat, thresh
self.left, self.right, self.val = left, right, val
def build_cart(X, y, max_depth=4, min_samples=2, depth=0):
if len(np.unique(y))==1 or depth==max_depth or len(y)<min_samples:
return Node(val=np.bincount(y).argmax())
f, t = best_split_cart(X, y)
if f is None: return Node(val=np.bincount(y).argmax())
L_mask = X[:, f] <= t
return Node(f, t,
left = build_cart(X[L_mask], y[L_mask], max_depth, min_samples, depth+1),
right = build_cart(X[~L_mask], y[~L_mask], max_depth, min_samples, depth+1))
def predict(node, x):
if node.val is not None: return node.val # leaf
return predict(node.left if x[node.feat]<=node.thresh else node.right, x)
