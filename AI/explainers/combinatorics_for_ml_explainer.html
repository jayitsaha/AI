Understanding Combinatorial Arguments in ML
▼

What is this? In machine learning theory, we constantly ask: "how many possible patterns can my model class represent?" and "is that enough to overfit — or does the sample give genuine information?" Combinatorics — the mathematics of counting — gives sharp, rigorous answers. Without it, we would have no formal guarantee that a trained model generalizes beyond its training data.

Analogy: Imagine you have a flashlight (hypothesis class) that can project at most 1000 distinct shadow shapes on a wall. No matter how many objects (data points) you add, the flashlight cannot produce more than 1000 distinct labelings. Combinatorics tells us exactly how quickly this "effective size" grows, which directly controls how much data we need to learn reliably.

💡 If you remember one thing

A hypothesis class \(\mathcal{H}\) can only produce \(\Pi_{\mathcal{H}}(m)\) distinct dichotomies on \(m\) points. When \(\Pi_{\mathcal{H}}(m)\) grows polynomially (not exponentially), the class is learnable. The Sauer-Shelah lemma bounds this: $$\Pi_{\mathcal{H}}(m) \leq \sum_{i=0}^{d} \binom{m}{i} \leq \left(\frac{em}{d}\right)^d$$ where \(d\) is the VC dimension.

Why it matters: The four key counting arguments in ML are: (1) shattering / growth function — how many labelings can \(\mathcal{H}\) realize on \(m\) points; (2) Sauer-Shelah lemma — the polynomial upper bound on the growth function; (3) union bound — bounding the probability that any one of many bad events occurs; (4) pigeonhole principle — collision guarantees in hashing and information-theoretic lower bounds.

2
Shattering, VC Dimension & Growth Functions
▼

Dichotomies and Shattering

Fix a set \(S = \{x_1,\ldots,x_m\}\) and a hypothesis class \(\mathcal{H}\) of binary classifiers \(h: \mathcal{X} \to \{-1,+1\}\). The restriction of \(\mathcal{H}\) to \(S\) is all distinct binary label patterns (dichotomies) producible by some \(h \in \mathcal{H}\):

$$\mathcal{H}_S = \{ (h(x_1),\ldots,h(x_m)) : h \in \mathcal{H} \}$$

We say \(\mathcal{H}\) shatters \(S\) if \(|\mathcal{H}_S| = 2^m\) — every possible \(\{-1,+1\}^m\) labeling is realized by some \(h\). Shattering means \(\mathcal{H}\) is expressive enough to memorize \(S\) with any labels.

VC Dimension

The Vapnik-Chervonenkis (VC) dimension of \(\mathcal{H}\) is the size of the largest set that \(\mathcal{H}\) can shatter:

$$\operatorname{VCdim}(\mathcal{H}) = \max \{ m : \exists S \text{ with } |S|=m, \; \mathcal{H} \text{ shatters } S \}$$
  • Halfplanes in \(\mathbb{R}^2\): VC dim = 3 (any 3 non-collinear points shattered; no 4 points ever)
  • Degree-\(p\) polynomials in \(\mathbb{R}^d\): VC dim = \(\binom{d+p}{p}\)
  • Neural net with \(W\) weights, depth \(L\): \(O(WL\log W)\) upper bound
  • Axis-aligned rectangles in \(\mathbb{R}^2\): VC dim = 4

The Growth Function

The growth function \(\Pi_{\mathcal{H}}(m)\) counts the maximum number of distinct dichotomies over any \(m\) points:

$$\Pi_{\mathcal{H}}(m) = \max_{S: |S|=m} |\mathcal{H}_S|$$

Always \(\Pi_{\mathcal{H}}(m) \leq 2^m\). For \(m \leq d\) (VC dim), shattering is still possible so \(\Pi_{\mathcal{H}}(m) = 2^m\). For \(m > d\), the bound drops below \(2^m\) — this transition is the heart of generalization theory.

🔑 Key Property

For halfplanes in \(\mathbb{R}^2\) (VC dim \(d=3\)): \(\Pi_{\mathcal{H}}(4)=15\), not \(16\). The one missing labeling is the "XOR-like" configuration that no single halfplane can achieve. This single missing labeling is the entire gap between shattering and non-shattering, and it cascades into a polynomial growth bound for all larger \(m\).

Numerical Trace: Halfplane Growth Function

For the halfplane class with \(d=3\), we can compute \(\Pi_{\mathcal{H}}(m) = \sum_{i=0}^{3}\binom{m}{i}\):

  • \(m=3\): \(\binom{3}{0}+\binom{3}{1}+\binom{3}{2}+\binom{3}{3}=1+3+3+1=8=2^3\) ✓ (shatters)
  • \(m=4\): \(1+4+6+4=15 < 16=2^4\) ✗ (cannot shatter any 4 points)
  • \(m=8\): \(1+8+28+56=93 \ll 256=2^8\) (exponential gap opens up)

Sauer-Shelah Lemma & Union Bound
▼

Sauer-Shelah Lemma

If \(\operatorname{VCdim}(\mathcal{H}) \leq d\), then for all \(m \geq d\):

$$\Pi_{\mathcal{H}}(m) \leq \sum_{i=0}^{d} \binom{m}{i}$$

Since \(\binom{m}{i} \leq \frac{m^i}{i!}\), summing \(d+1\) terms gives \(\Pi_{\mathcal{H}}(m) \leq (d+1) m^d\), which is polynomial in \(m\). Equivalently via \(\sum_{i=0}^d \binom{m}{i} \leq \left(\frac{em}{d}\right)^d\).

Proof sketch (by induction on \(m+d\)): Base cases are clear. For the inductive step, split the \(m\) points into the first \(m-1\) and the last. Any dichotomy on \(m\) points either differs or not on the last point. Count: at most \(\Pi_{\mathcal{H}_{d}}(m-1)\) patterns from classes that shatter \(\leq d\) points on the first \(m-1\), plus at most \(\Pi_{\mathcal{H}_{d-1}}(m-1)\) "doubled" patterns. Applying Pascal's identity gives the binomial sum.

📐 Generalization Bound from Sauer-Shelah

With probability \(\geq 1-\delta\) over the training sample of size \(m\), for all \(h \in \mathcal{H}\) simultaneously:

$$L(h) \leq \hat{L}(h) + \sqrt{\frac{d \log\!\left(\frac{2em}{d}\right) + \log\!\left(\frac{2}{\delta}\right)}{2m}}$$

where \(L(h)\) is the true risk, \(\hat{L}(h)\) is the empirical risk, \(d = \operatorname{VCdim}(\mathcal{H})\). The \(\sqrt{d/m}\) scaling tells us we need \(m \sim d/\varepsilon^2\) samples for \(\varepsilon\)-generalization — the fundamental sample complexity of PAC learning.

Union Bound (Boole's Inequality)

The union bound says: for any collection of events \(A_1,\ldots,A_k\):

$$\mathbb{P}\!\left[\bigcup_{i=1}^k A_i\right] \leq \sum_{i=1}^k \mathbb{P}[A_i]$$

In ML: we want to show that no hypothesis in \(\mathcal{H}\) has a large gap between its training and test error simultaneously. For a finite class \(\mathcal{H}\) with \(|\mathcal{H}|\) hypotheses, the union bound + Hoeffding's inequality gives:

$$\mathbb{P}\!\left[\exists h \in \mathcal{H}: |L(h)-\hat{L}(h)| > \varepsilon\right] \leq 2|\mathcal{H}|\cdot e^{-2m\varepsilon^2}$$

For infinite \(\mathcal{H}\), we replace \(|\mathcal{H}|\) with \(\Pi_{\mathcal{H}}(2m)\) (the growth function evaluated on \(2m\) points, via the symmetrization/ghost-sample argument). This is where Sauer-Shelah converts the exponential effective class size into a manageable polynomial, enabling the bound above.

⚠️ Common Misconception

The union bound is not tight — it assumes the bad events for each hypothesis are nearly disjoint. In practice, hypotheses with similar structure share the same bad samples. Tighter concentration tools (McDiarmid, Rademacher complexity) exploit this dependence. But the union-bound argument is the foundational step that makes the whole proof machinery work.

Numerical Example — Union Bound

Suppose \(|\mathcal{H}| = 1000\) hypotheses, \(\varepsilon = 0.1\), and we want probability of failure \(\leq 0.05\). Solve \(2 \cdot 1000 \cdot e^{-2m(0.01)} \leq 0.05\):

$$m \geq \frac{\ln(40{,}000)}{0.02} = \frac{10.597}{0.02} \approx 530 \text{ samples}$$

With \(m=530\): bound = \(2000 \cdot e^{-10.6} \approx 0.049 \leq 0.05\). Verified computationally: at \(m=500\), bound = \(1000 \cdot e^{-10} \approx 0.045\). The logarithm in \(m\) means we pay only \(O(\log |\mathcal{H}|)\) extra data to account for more hypotheses.

Pigeonhole in Hashing & Key Takeaways
▼

Pigeonhole Principle in ML

The pigeonhole principle states: if \(n\) items are placed into \(k\) bins with \(n > k\), at least one bin has \(\geq 2\) items. In ML/CS this appears in three places:

  • Hashing & hash collisions: Hashing \(n\) keys into \(m\) buckets guarantees a collision when \(n > m\). More precisely (birthday paradox), about \(\sqrt{2m}\) items suffice for a 50% collision probability. With \(m=256\) buckets, expect a collision after ~18.8 items.
  • Information-theoretic lower bounds: Any compression algorithm must enlarge some inputs. If we compress \(n\)-bit strings into \(k < n\) bits, by pigeonhole \(\geq 2^{n-k}\) inputs map to the same code — lossless compression is impossible for all inputs.
  • PAC lower bounds: To learn a class of VC dim \(d\), you need \(\Omega(d/\varepsilon)\) samples. Proof: by pigeonhole, with fewer samples some hypothesis that fits the data perfectly will have high true error.

Hash Collision Computation

For \(m\) buckets, the probability of no collision among \(n\) items is:

$$\mathbb{P}[\text{no collision}] = \prod_{k=0}^{n-1}\left(1 - \frac{k}{m}\right) \approx e^{-n(n-1)/(2m)}$$

Setting this to \(1/2\): \(n \approx \sqrt{2m \ln 2} \approx 1.177\sqrt{m}\). This is why SHA-256 (\(m = 2^{256}\)) is collision-resistant for astronomical \(n\), while a 32-bit hash (\(m = 2^{32} \approx 4\) billion) collides after only ~77,000 items — a serious practical concern.

💡 Key Takeaways
  • Shattering quantifies the "memorization capacity" of a hypothesis class on a set of points.
  • Growth function \(\Pi_{\mathcal{H}}(m)\) measures the maximum distinct labelings over all \(m\)-point sets.
  • Sauer-Shelah converts VC dimension into a polynomial growth bound \(\leq \left(\frac{em}{d}\right)^d\), enabling generalization guarantees.
  • Union bound + Sauer-Shelah gives the VC generalization theorem: sample complexity \(\sim d/\varepsilon^2\).
  • Pigeonhole underlies collision bounds in hashing and information-theoretic learning lower bounds.

Code: Growth Function & VC Bound

import math
def growth_function_upper_bound(m: int, d: int) -> int:
"""Sauer-Shelah: upper bound on growth function Pi_H(m)."""
# sum_{i=0}^{d} C(m, i)
return sum(math.comb(m, i) for i in range(d + 1))
def vc_generalization_bound(m: int, d: int, delta: float = 0.05) -> float:
"""VC generalization bound: with prob >= 1-delta, all h have L(h) <= L_hat(h) + eps."""
# eps = sqrt((d*log(2em/d) + log(2/delta)) / (2m))
numerator = d * math.log(2 * math.e * m / d) + math.log(2 / delta)
return math.sqrt(numerator / (2 * m))
def union_bound_finite_class(H_size: int, m: int, eps: float) -> float:
"""P[exists h: |L(h)-L_hat(h)| > eps] <= 2*|H|*exp(-2*m*eps^2)."""
return 2 * H_size * math.exp(-2 * m * eps**2)
def birthday_collision_threshold(m: int) -> float:
"""Number of items for 50% collision probability in m buckets."""
return math.sqrt(2 * m * math.log(2))
# Example: halfplane class in R^2, VC dim = 3
d = 3
for m in [3, 4, 5, 8, 10]:
bound = growth_function_upper_bound(m, d)
print(f"m={m}: Pi_H(m) <= {bound}, 2^m = {2**m}")
# m=3: Pi_H(m) <= 8, 2^m = 8 (shatters)
# m=4: Pi_H(m) <= 15, 2^m = 16 (cannot shatter)
# VC bound: how much data for eps=0.05, d=10, delta=0.05?
import scipy.optimize as opt
eps_target = 0.05
m_needed = opt.brentq(lambda m: vc_generalization_bound(m,10)-eps_target, 10, 100000)
print(f"Samples needed for eps=0.05, d=10: {int(m_needed)+1}") # ~26862
