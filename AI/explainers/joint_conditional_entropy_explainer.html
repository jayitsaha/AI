Understanding Joint & Conditional Entropy
▼

What is this? Entropy measures uncertainty about a single random variable. When we have two variables, we need richer measures: joint entropy \(H(X,Y)\) captures the total uncertainty in the pair; conditional entropy \(H(X|Y)\) captures the uncertainty about \(X\) that remains after we already know \(Y\).

Analogy: Imagine predicting tomorrow's weather (\(X\)) and whether a specific street will flood (\(Y\)). The joint entropy \(H(X,Y)\) is your total uncertainty about both outcomes together. The conditional entropy \(H(X|Y)\) is how uncertain you still are about the weather after you've already learned whether the street flooded. If flooding only happens when it rains heavily, then knowing the street flooded tells you a lot about the weather — so \(H(X|Y)\) will be much smaller than \(H(X)\).

If you remember one thing

Conditional entropy equals joint entropy minus the marginal: \(H(X|Y) = H(X,Y) - H(Y)\). The chain rule \(H(X,Y) = H(X) + H(Y|X)\) says: "To describe the pair, first describe \(X\), then describe \(Y\) given \(X\)." Together with mutual information, these four quantities tile the information Venn diagram without overlap or gap.

2
The Information Venn Diagram
▼

The information Venn diagram is the single most useful picture in information theory. Draw two overlapping circles, one for \(H(X)\) and one for \(H(Y)\). Every region has a precise meaning:

  • Left exclusive region — \(H(X|Y)\): bits of \(X\) not explained by \(Y\)
  • Right exclusive region — \(H(Y|X)\): bits of \(Y\) not explained by \(X\)
  • Overlap — \(I(X;Y)\): shared information, the "mutual" part
  • Entire union — \(H(X,Y)\): total uncertainty in the pair
$$H(X,Y) = H(X|Y) + I(X;Y) + H(Y|X)$$

Two boundary cases

Independence: If \(X \perp Y\), the circles don't overlap at all. \(I(X;Y)=0\), \(H(X|Y)=H(X)\), \(H(X,Y)=H(X)+H(Y)\). Knowing \(Y\) tells you nothing about \(X\).

Determinism: If \(X\) is a deterministic function of \(Y\) (or vice versa), the circles perfectly overlap. \(H(X|Y)=0\), \(I(X;Y)=H(X)=H(Y)\). Knowing \(Y\) completely determines \(X\).

Key Property — Non-negativity

All regions are non-negative: \(H(X|Y) \geq 0\), \(I(X;Y) \geq 0\). This means conditioning can only reduce or maintain entropy — \(H(X|Y) \leq H(X)\) always, with equality iff \(X \perp Y\). Knowing something can never hurt. (This is not true for conditional entropy given a specific outcome \(y\) — only in expectation.)

3
Key Identities & Chain Rule
▼

Definitions

$$H(X,Y) \;=\; -\sum_{x}\sum_{y} p(x,y)\log_2 p(x,y)$$
$$H(X|Y) \;=\; \sum_{y} p(y)\,H(X|Y=y) \;=\; -\sum_{x,y} p(x,y)\log_2 p(x|y)$$

Chain Rule (most important identity)

$$H(X,Y) \;=\; H(X) + H(Y|X) \;=\; H(Y) + H(X|Y)$$

This decomposes joint entropy sequentially: describe one variable first, then the other conditionally. The order doesn't matter for the total — both factorisations give \(H(X,Y)\).

Relationship to mutual information

$$I(X;Y) \;=\; H(X) - H(X|Y) \;=\; H(Y) - H(Y|X) \;=\; H(X)+H(Y)-H(X,Y)$$
Common Misconception

\(H(X|Y)\) is an expectation over \(y\), not entropy at a specific \(y\). For a fixed outcome \(Y=y_0\), the conditional entropy \(H(X|Y=y_0)\) can be larger or smaller than \(H(X)\). Only the average \(\mathbb{E}_Y[H(X|Y=y)]\) is guaranteed to satisfy \(H(X|Y) \leq H(X)\).

Numerical trace (our example)

With \(P(0,0)=P(1,1)=0.4\), \(P(0,1)=P(1,0)=0.1\), marginals are uniform \((0.5, 0.5)\):

$$H(X,Y) = -(2 \times 0.4\log_2 0.4 + 2 \times 0.1\log_2 0.1) \approx 1.722 \text{ bits}$$
$$H(X|Y) = H(X,Y) - H(Y) = 1.722 - 1.000 = 0.722 \text{ bits}$$
$$I(X;Y) = H(X) + H(Y) - H(X,Y) = 1 + 1 - 1.722 = 0.278 \text{ bits}$$

5
Key Takeaways
▼

When to use these measures:

  • \(H(X,Y)\) — total bit-cost to encode both variables; upper-bound on compression
  • \(H(X|Y)\) — residual uncertainty after side information \(Y\) is given; key in lossless coding with side information (Slepian-Wolf theorem)
  • \(I(X;Y)\) — channel capacity, feature relevance, independence testing
  • Chain rule — decompose multi-variable entropy sequentially; basis for entropy coding of correlated sources
The Full Picture

The four quantities \(H(X|Y)\), \(H(Y|X)\), \(I(X;Y)\) and \(H(X,Y)\) are not independent — any three determine the fourth. The Venn diagram makes this visual: the entire union equals the left exclusive + overlap + right exclusive. Memorise the identity \(H(X,Y) = H(X) + H(Y) - I(X;Y)\) and you can derive everything else.

Code Trace
▼
import numpy as np
# Joint distribution: P(X=x, Y=y)
P = np.array([[0.40, 0.10], # X=0: Y=0, Y=1
[0.10, 0.40]]) # X=1: Y=0, Y=1
# Marginals by summing out the other variable
Px = P.sum(axis=1) # [0.5, 0.5]
Py = P.sum(axis=0) # [0.5, 0.5]
def H(probs):
"""Shannon entropy in bits."""
p = probs[probs > 0]
return -np.sum(p * np.log2(p))
# Individual entropies
HX = H(Px) # 1.0000 bits
HY = H(Py) # 1.0000 bits
# Joint entropy: treat 2D joint as flat 1D distribution
HXY = H(P.flatten()) # 1.7219 bits
# Conditional entropies via chain rule
HXGY = HXY - HY # H(X|Y) = 0.7219 bits
HYGX = HXY - HX # H(Y|X) = 0.7219 bits
# Mutual information
IXY = HX + HY - HXY # I(X;Y) = 0.2781 bits
# Verify chain rule
assert abs(HX + HYGX - HXY) < 1e-10 # H(X,Y) = H(X) + H(Y|X)
assert abs(HY + HXGY - HXY) < 1e-10 # H(X,Y) = H(Y) + H(X|Y)
