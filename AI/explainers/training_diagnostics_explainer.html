Training Diagnostics

Reading loss curves, gradient norms, activation stats & dead neurons to catch failing training runs early
Intermediate Deep Learning MLOps / Practical O(params) per step
1
Understanding Training Diagnostics
▼

What is it? Training a neural network is mostly invisible — you stare at a single number (the loss) slowly ticking down and hope it means the model is learning something useful. Training diagnostics are the instruments that turn that black box into a cockpit: the loss curve tells you if you're converging at all, per-layer gradient norms tell you if learning signal is actually reaching every layer, activation statistics tell you if the numbers flowing through the network stay in a sane range, and dead-neuron detection tells you if parts of the network have silently stopped participating.

Analogy: Think of training a deep network like driving a very long convoy of trucks (layers) relaying a package (the gradient) backward from the last truck to the first. The loss curve is the speedometer of the lead truck. But if truck #2's radio is broken, it never gets the message to slow down or speed up — that's a dead neuron. If the message gets fainter each time it's relayed, by the time it reaches truck #40 it's inaudible — that's a vanishing gradient. If the driver overreacts to every instruction, the whole convoy swerves and crashes — that's a learning rate that's too high.

💡 If you remember one thing

A healthy training run looks boring: loss decreases smoothly, gradient norms are similar in magnitude across layers (roughly \(10^{-3}\) to \(10^{0}\)), activation variance stays near 1, and the dead-neuron fraction stays low and flat. Any diagnostic that trends toward zero, toward infinity, or oscillates wildly is telling you exactly which knob to turn — before you waste a full run finding out the hard way.

2
How the Four Signals Work Internally
▼

Signal 1 — The Loss Curve

Plot training (and validation) loss against step/epoch. Underfitting looks like a curve that plateaus early, high and flat — the model lacks capacity or hasn't trained long enough. Overfitting looks like train loss still falling while validation loss turns upward — the gap widens. Learning rate too high has a distinctive signature: loss drops for a few steps, then oscillates with growing amplitude, sometimes spiking to NaN — the optimizer is overshooting the minimum of the loss surface on every step.

Signal 2 — Per-Layer Gradient Norms

At every layer \(l\), compute \(\|\nabla_{W^{(l)}} L\|_2\) — the L2 norm of the loss gradient with respect to that layer's weights. Log these per layer, per step. In a healthy network, norms across layers sit within roughly one order of magnitude of each other. A vanishing gradient shows norms shrinking geometrically as you move from the output toward the input — layer 1 might be 100x smaller than layer 6. An exploding gradient shows norms growing without bound, usually all layers rising together and correlated with loss spikes.

Signal 3 — Activation Statistics

For each layer's output (post-nonlinearity), track the running mean and variance across a batch. WHY it matters: if variance shrinks layer over layer, the signal is being crushed toward a constant (common with saturating activations like sigmoid/tanh, or with vanishing gradients feeding back). If variance explodes, activations blow past the linear region of the next layer's weights and saturate or produce extreme values that dominate the loss.

Signal 4 — Dead Neuron Detection

For ReLU-family units, a neuron is "dead" if its pre-activation \(z = w^\top x + b\) is \(\le 0\) for every example in the batch (or, more robustly, over a large validation set) — meaning it outputs zero and receives zero gradient, so it can never recover on its own. Track the fraction of dead units per layer over training. A small stable fraction (a few percent) is normal; a fraction climbing toward 100% signals the layer is losing effective capacity.

Design Decision: Why track all four together?

Each signal alone is ambiguous — a flat loss curve could mean vanishing gradients, dead neurons, a learning rate that's too low, or a model that has already converged. Cross-referencing the four narrows it down immediately: flat loss + shrinking gradient norms by depth = vanishing gradients. Flat loss + high dead-neuron fraction + healthy gradient norms in surviving units = dying ReLUs. Oscillating loss + gradient norms growing every step = learning rate too high.

🔑 Key Property

These four signals form a diagnostic basis for training pathologies: together they can distinguish optimization problems (LR, vanishing/exploding gradients) from capacity problems (dead units, underfitting) from generalization problems (overfitting) — three failure families that require entirely different fixes.

3
Why It Works — The Math
▼

Gradient Norm, Defined

For layer weight matrix \(W^{(l)}\), the diagnostic quantity is the Frobenius (L2) norm of the gradient:

$$\|\nabla_{W^{(l)}} L\|_2 = \sqrt{\sum_{i,j}\left(\frac{\partial L}{\partial W^{(l)}_{ij}}\right)^2}$$

Vanishing / Exploding Gradients from the Chain Rule

Backpropagation computes the gradient at hidden layer \(l\) by chaining Jacobians from the output layer \(L\) back to \(l\):

$$\frac{\partial \mathcal{L}}{\partial h^{(l)}} = \frac{\partial \mathcal{L}}{\partial h^{(L)}} \prod_{k=l+1}^{L} \underbrace{W^{(k)\top}\,\operatorname{diag}\!\big(\phi'(z^{(k)})\big)}_{\text{per-layer Jacobian } J^{(k)}}$$

If the spectral norm \(\rho = \|J^{(k)}\|_2\) is roughly constant across layers, the gradient magnitude scales like \(\rho^{L-l}\). For \(\rho < 1\) (small weights, or saturating activations with \(\phi' \ll 1\)) this shrinks geometrically with depth — vanishing. For \(\rho > 1\) it grows geometrically — exploding. This is exactly why gradient norms plotted against layer index reveal the problem: a straight line on a log-scale y-axis is the signature of geometric decay/growth.

The Dead-ReLU Criterion

A ReLU unit \(j\) in layer \(l\) is dead with respect to dataset \(\mathcal{D}\) if:

$$\forall x \in \mathcal{D}: \; z_j^{(l)}(x) = w_j^{(l)\top} a^{(l-1)}(x) + b_j^{(l)} \le 0 \;\Longrightarrow\; a_j^{(l)}(x)=0$$

Because \(\operatorname{ReLU}'(z)=0\) for \(z \le 0\), the local gradient through this unit is exactly zero — no update ever pushes \(w_j^{(l)}, b_j^{(l)}\) again. This is a genuine absorbing state, not a transient dip, which is why dead-neuron fraction should be monitored as a monotonically-informative signal, not just a snapshot.

Why Learning Rate Too High Diverges

For a locally quadratic loss with Hessian \(H\), gradient descent \(\theta_{t+1} = \theta_t - \eta \nabla \mathcal{L}(\theta_t)\) converges only if the step size satisfies:

$$\eta < \frac{2}{\lambda_{\max}(H)}$$

where \(\lambda_{\max}(H)\) is the largest eigenvalue (curvature) of the local Hessian. Exceeding this bound causes each update to overshoot the minimum by a larger margin than the previous step — producing the oscillating-then-diverging loss curve that is the textbook signature of \(\eta\) set too high.

⚠️ Common Pitfall

Don't compute dead-neuron fraction from a single mini-batch — a unit can look dead on one batch and alive on the next purely from batch composition. Use a fixed, larger evaluation set (or an exponential moving average across many batches) so the fraction reflects a persistent, not transient, state.

Key Takeaways
▼

Quick reference — symptom to likely cause:

SymptomLikely CauseFix
Loss oscillates / spikes / NaNsLearning rate too highLower LR, add warmup, gradient clipping
Gradient norm shrinks with depth (early layers ≪ late layers)Vanishing gradientsResidual connections, better init, normalization
Gradient norm grows with depth or over timeExploding gradientsGradient clipping, lower LR, normalization
Dead-neuron fraction climbs steadilyDying ReLUs (often from large negative updates)Leaky ReLU/GELU, lower LR, better init
Train loss ↓ but val loss ↑OverfittingRegularization, more data, early stopping
Loss plateaus high for both train/valUnderfitting / capacity or LR too lowBigger model, train longer, raise LR
💡 Practical Habit

Log all four diagnostics (loss, per-layer gradient norm, per-layer activation stats, dead-neuron fraction) from step 1 — not after something looks wrong. Pathologies like dying ReLUs are far cheaper to catch and fix at epoch 3 than to discover at epoch 300 after burning a full training budget.
