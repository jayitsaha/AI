Understanding Deep Gaussian Processes
▼

What is it? A Gaussian Process (GP) defines a distribution over functions: any finite set of function values is jointly Gaussian, and the covariance between two points is governed by a kernel \(k(x,x')\). A single GP with a stationary kernel is powerful but has one crippling limitation — its "wiggliness" (lengthscale) is the same everywhere in the input space. A Deep Gaussian Process (DGP) fixes this by feeding the output of one GP as the input to another: \(f(x) = f_L(f_{L-1}(\cdots f_2(f_1(x))\cdots))\). Each layer warps the space the next layer operates in, so the composition can be smooth in one region and wildly non-smooth in another — a non-stationary function drawn from a much richer prior.

Analogy: Imagine sketching on a sheet of rubber. A single GP is like drawing a wiggly line on a flat sheet — the wiggle rate is fixed everywhere. A deep GP first stretches and compresses the rubber sheet itself (layer 1), then draws the wiggly line on the deformed sheet (layer 2). Where the sheet was stretched, the same wiggle now looks slow and smooth in the original coordinates; where it was compressed, the same wiggle looks fast and jagged. Stacking more layers repeats this warping, composing simple transformations into highly expressive ones — exactly the intuition behind deep neural networks, except every layer here is a full Bayesian, uncertainty-aware Gaussian Process.

💡 If you remember one thing

A deep GP is function composition of GPs: $$f(x) = f_L\big(f_{L-1}(\cdots f_1(x)\cdots)\big),\qquad f_\ell \sim \mathcal{GP}(0, k_\ell)$$ Composing Gaussians through a nonlinear warp destroys joint Gaussianity — the marginal prior over \(f\) is non-Gaussian and non-stationary, which is precisely what makes it more expressive than any single GP.

How Deep GPs Work Internally
▼

Layer-by-layer generative process

Given input \(x\), sample \(h_1 = f_1(x)\) from \(\mathcal{GP}(0, k_1)\) evaluated at \(x\). Then treat \(h_1\) as the input to the next GP: sample \(h_2 = f_2(h_1)\) from \(\mathcal{GP}(0, k_2)\), where the kernel \(k_2\) is now evaluated on distances in \(h_1\)-space, not \(x\)-space. Repeat for \(L\) layers. Because each intermediate layer's kernel depends on the (random) output of the previous layer, the covariance of the final function in the original \(x\)-space is no longer a simple function of \(|x - x'|\) — it inherits whatever stretching/compressing the warp layers performed.

Why this beats a single stationary kernel

A single GP's kernel \(k(x,x') = \sigma^2\exp(-\tfrac{1}{2\ell^2}(x-x')^2)\) has one global lengthscale \(\ell\). A deep GP effectively induces an input-dependent lengthscale: where the warp \(f_1\) has large derivative \(|f_1'(x)|\), nearby \(x\) points map to far-apart \(h_1\) points, so the next layer treats them as uncorrelated — locally short effective lengthscale (rough function). Where \(|f_1'(x)|\) is small, nearby \(x\) points stay close in \(h_1\)-space and remain correlated — locally long effective lengthscale (smooth function). This gives one prior that is simultaneously smooth in some regions and rough in others.

Doubly stochastic variational inference

Exact inference in a DGP is intractable — the marginal likelihood requires integrating out every hidden layer, and the composition is non-Gaussian. The standard practical fix (Salimbeni & Deisenroth, 2017) places inducing points \(Z_\ell, U_\ell\) at every layer, keeps a variational distribution \(q(U_\ell) = \mathcal{N}(m_\ell, S_\ell)\) per layer, and approximates the predictive distribution by Monte Carlo sampling forward through the stack: draw a sample at layer 1, feed it as the (random) input to layer 2's variational posterior, draw a sample there, and so on. This is "doubly stochastic" because there are two sources of randomness being averaged over during training: the mini-batch of data and the forward Monte Carlo samples propagated through the layers.

🔑 Key Property

Each layer keeps an Evidence Lower Bound (ELBO) contribution consisting of an expected log-likelihood term (estimated by sampling) and a KL divergence term \(\mathrm{KL}(q(U_\ell)\,\|\,p(U_\ell))\) computed exactly in closed form, because inducing-point priors and their variational Gaussians are both multivariate normal. Stacking GPs buys non-stationarity; doubly-stochastic sampling is the price paid to keep inference tractable.

Why It Works — The Math
▼

Generative model

For \(L\) layers with hidden functions \(h_0 = x\), the joint density factorizes across layers because each layer only depends on the previous one's output:

$$p(y, h_1,\dots,h_{L-1} \mid x) = p(y \mid h_{L-1})\prod_{\ell=1}^{L-1} p(h_\ell \mid h_{\ell-1}), \qquad p(h_\ell \mid h_{\ell-1}) = \mathcal{GP}(0, k_\ell)$$

Each conditional is Gaussian, but the marginal \(p(y\mid x) = \int p(y\mid h_{L-1})\cdots p(h_1\mid x)\, dh_1\cdots dh_{L-1}\) integrates out the intermediate warps and is generally not Gaussian — it can be skewed, multimodal, or heavy-tailed depending on the warp.

The evidence lower bound (ELBO)

With inducing variables \(U_\ell\) at pseudo-inputs \(Z_\ell\) and variational posterior \(q(U_\ell)=\mathcal{N}(m_\ell,S_\ell)\), the DSVI objective is:

$$\mathcal{L} = \sum_{n=1}^{N}\mathbb{E}_{q(f_L(x_n))}\big[\log p(y_n \mid f_L(x_n))\big] \;-\; \sum_{\ell=1}^{L} \mathrm{KL}\big(q(U_\ell)\,\|\,p(U_\ell)\big)$$

The expectation is approximated by drawing a chain of samples \(\hat h_1 \sim q(f_1(x_n)), \hat h_2 \sim q(f_2(\hat h_1)), \dots\) — one Monte Carlo forward pass per layer — because the composition of Gaussians through a nonlinear kernel evaluation is analytically intractable. Each KL term, by contrast, is closed-form since both distributions are multivariate Gaussian over the same inducing variables:

$$\mathrm{KL}(q\|p) = \tfrac12\Big[\operatorname{tr}(K_{mm}^{-1}S) + m^\top K_{mm}^{-1} m - M + \log\frac{|K_{mm}|}{|S|}\Big]$$

Effective non-stationary kernel

For a 2-layer DGP, the marginal covariance of the composed function can be approximated by moment-matching (averaging over the random warp):

$$k_{\text{deep}}(x,x') \approx \mathbb{E}_{f_1}\big[k_2(f_1(x), f_1(x'))\big] \approx \frac{1}{M}\sum_{m=1}^{M} k_2\big(h_1^{(m)}(x),\, h_1^{(m)}(x')\big)$$

This is exactly the empirical estimator used in the interactive walkthrough below to build a genuinely non-stationary "deep kernel" from Monte Carlo draws of the first layer, then run ordinary GP regression with it.

⚠️ Common Pitfall — Pathologies of Depth

Duvenaud et al. (2014) showed that naively stacking zero-mean GP layers tends to produce warps that are locally either near-flat or near-vertical almost everywhere as depth grows — the composed function degenerates toward a step function and loses representational power rather than gaining it. Fixes include adding an identity/skip connection to the mean function of each layer (so \(f_\ell(h) \approx h + \text{GP}(h)\)) so that depth only adds where it helps.

Key Takeaways
▼

When Deep GPs help:

  • The target function has heterogeneous smoothness (smooth in some regions, rough/discontinuous in others)
  • You need calibrated, non-stationary predictive uncertainty rather than a fixed-width band
  • You want a fully Bayesian alternative to deep neural networks with built-in uncertainty quantification
  • Data is scarce enough that neural nets overfit, but a single GP is too rigid (constant lengthscale)

When NOT to use:

  • A single stationary GP already fits well — depth adds inference cost and pathology risk for no gain
  • Very large datasets where a well-tuned deep neural network will be both cheaper and as accurate
  • Layers are added without identity-mean/skip connections — risk of the Duvenaud degeneracy above
💡 Hierarchy

Linear regression ⊂ GP regression (\(L=1\), stationary kernel) ⊂ Deep GP (\(L>1\), composed non-stationary kernel) ⊂ Deep GP with skip connections (avoids the pathology while keeping expressiveness). Each level relaxes an assumption of the one before it.
