Understanding Outlier Detection
▼

What is it? An outlier is a point that deviates so much from the pattern set by the rest of the data that it looks like it came from a different process altogether — a typo in a spreadsheet, a fraudulent transaction, a broken sensor, a genuinely rare event. Outlier detection is the task of scoring or flagging those points automatically, usually without labels telling you in advance which ones are “bad.”

Analogy: Picture a choir where everyone sings the same note. One singer drifts off-key — obvious. But “off-key” can be measured differently: how far from the average pitch and how much the choir usually wavers (z-score); how far from the middle singer, ignoring a couple of already-terrible singers (median/IQR); whether a singer breaks the harmony pattern even if their pitch alone looks fine (Mahalanobis distance); whether a singer stands in a part of the room that is far emptier than everywhere else (LOF); or how few yes/no questions it takes to separate that singer from the group (Isolation Forest). Same goal, five different rulers.

💡 If you remember one thing

Every outlier method is really just a distance or a rarity measure in disguise: $$z_i = \frac{x_i-\bar{x}}{s}$$ is “how many standard deviations away,” and every fancier method (MAD, Mahalanobis, LOF, Isolation Forest) is a more robust or more general version of that same question.

2
How the Five Methods Work Internally
▼

Univariate rules: Z-score, Modified Z-score, IQR

The classic z-score assumes the feature is roughly Gaussian and flags \(|z_i| > 3\). Its Achilles heel is masking: a huge outlier inflates the mean and, worse, the standard deviation, which can shrink every z-score enough that even the outlier itself — or a smaller second outlier — no longer crosses the threshold. The modified z-score fixes this by swapping the mean/std for the median and the median absolute deviation (MAD), statistics with a 50% breakdown point (half the data would need to be corrupted before they lie). The IQR / Tukey fence rule is the same robust spirit applied to quartiles: anything below \(Q_1 - 1.5\,\text{IQR}\) or above \(Q_3 + 1.5\,\text{IQR}\) is flagged — this is exactly what draws the whiskers on a boxplot.

Multivariate: Mahalanobis distance

Z-score only looks at one feature at a time. A point can be perfectly normal on every individual axis and still be a severe outlier once you consider how the features move together. Mahalanobis distance whitens the space using the inverse covariance matrix \(\Sigma^{-1}\), effectively measuring distance in units of “standard deviations along the data cloud’s natural (correlated) axes” instead of raw Euclidean units. A point that breaks the correlation pattern gets a large Mahalanobis distance even if its raw coordinates look tame.

Density-based: Local Outlier Factor (LOF)

LOF drops the global-distribution assumption entirely. For each point it compares its own local density to the local densities of its \(k\) nearest neighbors. A point buried inside a dense cluster gets \(\text{LOF}\approx 1\); a point sitting in a neighborhood sparser than its neighbors’ neighborhoods gets \(\text{LOF}\gg 1\). This lets LOF catch local outliers even when the data has several clusters of very different densities — a case where one global covariance matrix or one global threshold would fail badly.

Model-based: Isolation Forest

Isolation Forest flips the problem around: instead of modeling what “normal” looks like, it directly measures how easy a point is to isolate. Build a tree by repeatedly picking a random feature and a random split value between that feature’s current min and max, recursively partitioning the data. Outliers — few and different — tend to get separated from everyone else after just a handful of random splits (short path length); dense, normal points need many splits. Average the path length over a forest of random trees and rescale it against the expected path length for uniformly random data to get an anomaly score in \((0,1]\).

🔑 Key Property

Robustness increases roughly in this order: z-score (breakdown point 0) → IQR / modified z-score (≈50%, but 1-D only) → Mahalanobis (multivariate but still fragile if \(\Sigma\) itself is contaminated) → LOF (distribution-free, local) → Isolation Forest (distribution-free, scales to high dimensions, no distance computation needed at all).

Why It Works — The Math
▼

Univariate formulas

$$z_i=\frac{x_i-\bar{x}}{s}\qquad M_i=\frac{0.6745\,(x_i-\tilde{x})}{\text{MAD}},\quad \text{MAD}=\operatorname{median}(|x_i-\tilde{x}|)$$
$$\text{IQR}=Q_3-Q_1 \qquad \text{flag if } x_i < Q_1-1.5\,\text{IQR} \ \text{ or }\ x_i > Q_3+1.5\,\text{IQR}$$

The constant 0.6745 rescales MAD so that, under normality, \(M_i\) is comparable to a standard z-score; the usual flag threshold is \(|M_i|>3.5\).

Mahalanobis distance

$$D_M(x)=\sqrt{(x-\mu)^\top \Sigma^{-1} (x-\mu)}$$

Under a multivariate Gaussian, \(D_M(x)^2\) follows a \(\chi^2\) distribution with \(p\) degrees of freedom (\(p\) = number of features), which gives a principled threshold: for 2 features, \(\chi^2_{0.975,\,2}\approx 7.378\), so \(D_M \approx 2.72\) marks the 97.5th-percentile boundary.

LOF formulas

$$\text{reach-dist}_k(p,o)=\max(k\text{-distance}(o),\ d(p,o))$$
$$\text{lrd}_k(p)=\left(\frac{\sum_{o\in N_k(p)}\text{reach-dist}_k(p,o)}{|N_k(p)|}\right)^{-1}\qquad \text{LOF}_k(p)=\frac{\sum_{o\in N_k(p)}\text{lrd}_k(o)}{|N_k(p)|\cdot\text{lrd}_k(p)}$$

Isolation Forest anomaly score

$$s(x,n)=2^{-\,E(h(x))/c(n)}\qquad c(n)=2\Big(\ln(n-1)+\gamma\Big)-\frac{2(n-1)}{n}$$

\(E(h(x))\) is the average path length to isolate \(x\) across all trees, \(\gamma\approx0.5772\) is the Euler–Mascheroni constant, and \(c(n)\) is the expected path length of an unsuccessful search in a Binary Search Tree of \(n\) points — the normalizer that turns raw path length into a score near 1 for outliers and near 0.5 (or below) for inliers.

⚠️ Common Pitfall

Every one of these methods can be fooled by the outliers it is trying to find. A single huge value inflates \(\bar{x}\) and \(s\) (masking a z-score outlier), and it inflates the sample covariance \(\Sigma\) exactly the same way, shrinking Mahalanobis distances for everyone. In practice, robust covariance estimators (e.g. Minimum Covariance Determinant) are used instead of the plain sample covariance, and \(k\) for LOF and the contamination fraction for Isolation Forest both need tuning — there is no universally “correct” threshold.

Key Takeaways
▼

When to use which method:

  • Z-score — quick single-feature screen on roughly Gaussian data with few/no contaminants
  • Modified z-score / IQR — same, but robust to the outliers themselves; the default for boxplot-style 1-D screening
  • Mahalanobis distance — multiple correlated features, roughly elliptical/Gaussian cloud, need a single global “normal region”
  • LOF — clusters of different densities, local anomalies that a global rule would miss, moderate dataset size (it’s \(O(n^2)\) naively)
  • Isolation Forest — large or high-dimensional data, no distributional assumptions, need something fast and scalable

Contamination and thresholding: Nearly every method above produces a continuous score, not a hard yes/no — you still need to pick a cutoff. Rather than a fixed magic number, most libraries expose a contamination parameter: the expected fraction of outliers in the data. The threshold is then simply the \((1-\text{contamination})\) quantile of the score distribution. Set it too low and you drown in false positives; too high and real anomalies slip through unflagged.

💡 Escalation path

A practical pipeline often runs all five in sequence: robust 1-D screens (IQR/modified z-score) catch obvious per-feature glitches first; Mahalanobis catches correlation-breaking multivariate outliers; LOF catches points that are locally weird even if globally unremarkable; Isolation Forest scales the whole thing to messy, high-dimensional, real-world data.

import numpy as np
from scipy import stats
from sklearn.covariance import EmpiricalCovariance
from sklearn.neighbors import LocalOutlierFactor
from sklearn.ensemble import IsolationForest
# --- Univariate: Z-score ---
z = (x - x.mean()) / x.std(ddof=1)
z_flags = np.abs(z) > 3.0
# --- Univariate: Modified Z-score (MAD) ---
med = np.median(x)
mad = np.median(np.abs(x - med))
mod_z = 0.6745 * (x - med) / mad
mad_flags = np.abs(mod_z) > 3.5
# --- Univariate: IQR / Tukey fences ---
q1, q3 = np.percentile(x, [25, 75])
iqr = q3 - q1
lo, hi = q1 - 1.5*iqr, q3 + 1.5*iqr
iqr_flags = (x < lo) | (x > hi)
# --- Multivariate: Mahalanobis distance ---
cov = EmpiricalCovariance().fit(X)
d2 = cov.mahalanobis(X) # squared distance
thresh = stats.chi2.ppf(0.975, df=X.shape[1])
mahal_flags = d2 > thresh
# --- Density: Local Outlier Factor ---
lof = LocalOutlierFactor(n_neighbors=20, contamination=0.1)
lof_flags = lof.fit_predict(X) == -1 # -1 = outlier
lof_scores = -lof.negative_outlier_factor_
# --- Model-based: Isolation Forest ---
iso = IsolationForest(n_estimators=200, contamination=0.1, random_state=0)
iso_flags = iso.fit_predict(X) == -1
iso_scores = -iso.score_samples(X) # higher = more anomalous
