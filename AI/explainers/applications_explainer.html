Understanding NER & POS Tagging
▼

What are they? Named Entity Recognition (NER) and Part-of-Speech (POS) tagging are two fundamental tasks in Natural Language Processing (NLP). Both involve sequence labeling, where each word (or token) in a sentence is assigned a specific label.

  • Part-of-Speech (POS) Tagging: Identifies the grammatical category of each word in a sentence (e.g., noun, verb, adjective, adverb, preposition). It's about understanding the syntactic role of words. Example: "The dog barks loudly" → "The/DET dog/NOUN barks/VERB loudly/ADV".
  • Named Entity Recognition (NER): Identifies and classifies "named entities" in text into predefined categories such as person names, organizations, locations, dates, monetary values, etc. It's about extracting semantic information. Example: "Apple acquired Zoom in California." → "Apple/ORG acquired Zoom/ORG in California/LOC."

Analogy: Imagine you're a linguistic detective. POS tagging is like identifying the role each person plays in a sentence (who is the subject, what is the action). NER is like identifying the specific individuals, companies, or places involved, and then categorizing them based on their real-world identity. Both are crucial for making sense of unstructured text.

💡 If you remember one thing

Both NER and POS tagging are classic examples of sequence labeling, where the output is a sequence of tags, one for each input token. POS focuses on syntax, while NER focuses on semantics.

2
How They Work Internally
▼

Sequence Labeling Foundation

At their core, both tasks take an input sequence of words \((w_1, w_2, \dots, w_N)\) and output a corresponding sequence of labels \((t_1, t_2, \dots, t_N)\). The challenge is that the best tag for a word often depends on its neighbors.

Part-of-Speech Tagging

Early POS taggers used statistical models like Hidden Markov Models (HMMs) or Conditional Random Fields (CRFs) which explicitly model transition probabilities between tags and emission probabilities of words given tags. Modern approaches leverage deep learning:

  • Recurrent Neural Networks (RNNs): Especially Bi-directional LSTMs (Bi-LSTMs), process words in context (left-to-right and right-to-left) to build rich contextual embeddings.
  • Transformers: State-of-the-art models (like BERT, RoBERTa) use self-attention to capture long-range dependencies, producing highly effective contextual embeddings for each word, which are then fed into a simple linear classifier to predict POS tags.

Named Entity Recognition

NER is more complex due to multi-word entities (e.g., "New York City"). This requires a special tagging scheme:

  • IOB (Inside, Outside, Beginning) Scheme:
    • B-TAG: Beginning of an entity of type TAG (e.g., B-PER for a person's first name).
    • I-TAG: Inside an entity of type TAG (e.g., I-PER for a person's last name).
    • O: Outside any named entity.
    Other schemes like BIOES (Beginning, Inside, End, Single, Outside) offer finer granularity.
  • Features: Models learn from various features: word embeddings (pre-trained or learned), character embeddings (to handle out-of-vocabulary words or morphology), capitalization patterns, prefixes/suffixes.
  • Models: Similar to POS, Bi-LSTMs with a CRF layer on top were a powerful combination, modeling both contextual word features and tag dependencies. Today, fine-tuned Transformer models dominate, often achieving near-human performance.
🔑 Key Property

The strength of modern sequence labeling models comes from their ability to generate contextualized word representations. This allows them to disambiguate words (e.g., "bank" as a financial institution vs. river bank) and correctly identify multi-word entities.

3
Why It Works — The Math of CRFs
▼

Conditional Random Fields (CRFs) for Sequence Labeling

While modern deep learning models often use a simple linear layer on top of contextual embeddings, a Conditional Random Field (CRF) layer is still highly relevant for sequence labeling, especially for tasks like NER. A CRF is a discriminative probabilistic model that directly models the conditional probability of a tag sequence given an observation sequence: \(P(y|x)\).

The core idea is to find the tag sequence \(\hat{y}\) that maximizes this conditional probability:

$$\hat{y} = \underset{y \in \mathcal{Y}^N}{\operatorname{argmax}} \, P(y|x)$$

For linear-chain CRFs (common in NLP), this probability is typically defined using two types of scores:

  1. Emission Scores (\(E(y_i, x_i)\)): How well a tag \(y_i\) "fits" word \(x_i\). These often come from a neural network (e.g., Bi-LSTM output).
  2. Transition Scores (\(T(y_{i-1}, y_i)\)): How likely it is to transition from tag \(y_{i-1}\) to tag \(y_i\). These are learned parameters that capture label dependencies (e.g., "B-PER" is often followed by "I-PER", never "B-LOC").

The score for an entire tag sequence \(y = (y_1, \dots, y_N)\) given words \(x = (x_1, \dots, x_N)\) is:

$$\operatorname{Score}(y, x) = \sum_{i=1}^N \Big( E(y_i, x_i) + T(y_{i-1}, y_i) \Big)$$

where \(y_0\) is a special "start" tag. The probability is then \(P(y|x) = \frac{\exp(\operatorname{Score}(y, x))}{\sum_{y' \in \mathcal{Y}^N} \exp(\operatorname{Score}(y', x))}\).

Finding the \(\operatorname{argmax}\) (the best tag sequence) efficiently is done using the Viterbi algorithm, a dynamic programming approach. It computes the maximum score path to each possible tag at each position, building up the optimal sequence:

$$\delta_i(j) = \max_{k \in \mathcal{Y}} \Big( \delta_{i-1}(k) + T(k, j) \Big) + E(j, x_i)$$

Here, \(\delta_i(j)\) is the maximum score of a tag sequence of length \(i\) that ends with tag \(j\). This ensures globally optimal tag sequences, respecting tag dependencies, which is crucial for tasks like NER to avoid invalid sequences (e.g., "I-PER" following "B-LOC").

⚠️ Data Annotation is Key

The performance of both NER and POS tagging models heavily relies on high-quality, consistently annotated training data. Creating such datasets, especially for NER across diverse domains, is often the most expensive and time-consuming part of developing these systems.

Key Takeaways
▼

When to use NER & POS Tagging:

  • Information Extraction: Automatically pull out key facts (names, dates, locations) from documents.
  • Search & Recommendation: Improve search relevance by understanding entity types, or recommend content based on entities mentioned.
  • Question Answering: Identify potential answers by filtering for specific entity types (e.g., "Who invented X?" → look for PERSON entities).
  • Text Summarization: Identify important entities to retain in summaries.
  • Sentiment Analysis: Understand sentiment towards specific entities.
  • Grammar Checking & Text Generation: POS tags are crucial for syntactic analysis and generating grammatically correct sentences.

Limitations & Challenges:

  • Ambiguity: Many words have multiple POS tags or can be different entity types depending on context ("Apple" as a company vs. fruit).
  • Domain Specificity: Models trained on news articles may perform poorly on medical or legal texts without fine-tuning.
  • Rare Entities: New entities (e.g., a newly formed company, a unique product name) are hard to detect without specific training.
  • Nested Entities: "Director of [New York University]" — "New York University" is an ORG, but "New York" is also a LOC.
💡 Building Blocks

NER and POS tagging are often the first steps in an NLP pipeline, providing structured information that fuels more complex tasks like relation extraction, event detection, coreference resolution, and knowledge graph construction.

import torch
import torch.nn as nn
class SequenceTagger(nn.Module):
def __init__(self, vocab_size, embedding_dim, hidden_dim, num_tags):
super().__init__()
self.embedding = nn.Embedding(vocab_size, embedding_dim)
# Bi-directional LSTM for contextual embeddings
self.lstm = nn.LSTM(embedding_dim, hidden_dim, bidirectional=True)
# Linear layer to project LSTM output to tag scores (emissions)
self.hidden2tag = nn.Linear(hidden_dim * 2, num_tags) # *2 for bidir
# Optional: CRF layer for global sequence optimization
# self.crf = CRF(num_tags)
def forward(self, sentence):
# 1. Embed words
embeds = self.embedding(sentence) # (seq_len, embedding_dim)
# 2. Pass through Bi-LSTM to get contextual representations
lstm_out, _ = self.lstm(embeds.view(len(sentence), 1, -1))
lstm_out = lstm_out.view(len(sentence), -1) # (seq_len, hidden_dim*2)
# 3. Project to raw tag scores (logits/emissions)
tag_scores = self.hidden2tag(lstm_out) # (seq_len, num_tags)
# 4. If using CRF, compute Viterbi path (during inference)
# if self.crf:
# best_tags = self.crf.decode(tag_scores)
# return best_tags
# Else, simple argmax over scores (greedy approach)
return torch.argmax(tag_scores, dim=1)
