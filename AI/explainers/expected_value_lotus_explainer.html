Understanding Expected Value
▼

What is it? The expected value of a random variable is its long-run average — the value you'd get if you repeated the random experiment infinitely many times and averaged the results. More precisely, it is the weighted average of all possible outcomes, where each outcome is weighted by its probability.

Analogy: Imagine a perfectly balanced seesaw with weights placed at different positions on a number line. The expected value is the fulcrum point — the exact position where the seesaw would balance. For a fair die, placing equal masses at 1, 2, 3, 4, 5, and 6 gives a balance point at 3.5. Note: 3.5 is not even a possible outcome of the die, but it is where the probability mass "balances."

If you remember one thing

Two golden rules: (1) Linearity — \(\mathbb{E}[aX + bY] = a\mathbb{E}[X] + b\mathbb{E}[Y]\) always, even when \(X\) and \(Y\) are dependent. (2) LOTUS — \(\mathbb{E}[g(X)] = \sum_x g(x)\,p(x)\), using \(X\)'s original distribution without finding the distribution of \(g(X)\).

$$\mathbb{E}[X] = \sum_{x} x \cdot p(x) \quad \text{(discrete)}, \qquad \mathbb{E}[X] = \int_{-\infty}^{\infty} x\, f(x)\, dx \quad \text{(continuous)}$$

For a fair die: \(\mathbb{E}[X] = \frac{1}{6}(1+2+3+4+5+6) = \frac{21}{6} = 3.5\).

Linearity of Expectation
▼

The Statement

$$\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y]$$

This holds for any constants \(a, b\) and any random variables \(X, Y\) — even if they are dependent. This is one of the most useful and counterintuitive facts in probability.

Why It Holds (Proof Sketch)

For discrete RVs, just expand the definition:

$$\mathbb{E}[X + Y] = \sum_{x}\sum_{y}(x+y)\,p(x,y) = \sum_x x \underbrace{\sum_y p(x,y)}_{=\,p_X(x)} + \sum_y y \underbrace{\sum_x p(x,y)}_{=\,p_Y(y)} = \mathbb{E}[X] + \mathbb{E}[Y]$$

The double sum factors into marginals regardless of whether \(X\) and \(Y\) are correlated. Independence is not required.

Numerical Example

Fair die \(X\), and \(Y = X\) (perfectly dependent). Then \(\mathbb{E}[X] = 3.5\), \(\mathbb{E}[Y] = 3.5\), and \(\mathbb{E}[X+Y] = \mathbb{E}[2X] = 7.0 = \mathbb{E}[X] + \mathbb{E}[Y]\). Linearity still works.

Key Application: Indicator RVs

Linearity powers the indicator variable trick. Let \(I_k = 1\) if event \(k\) occurs, 0 otherwise. Since \(\mathbb{E}[I_k] = P(\text{event } k)\), the expected count of events is:

$$\mathbb{E}\!\left[\sum_{k=1}^{n} I_k\right] = \sum_{k=1}^{n} P(\text{event } k)$$
Common Pitfall

Linearity of expectation does NOT extend to products: \(\mathbb{E}[XY] \neq \mathbb{E}[X]\cdot\mathbb{E}[Y]\) in general. Equality holds only when \(X\) and \(Y\) are uncorrelated (weaker condition than independence). Confusing these is a classic error.

LOTUS — Law of the Unconscious Statistician
▼

The Law

$$\mathbb{E}[g(X)] = \sum_{x} g(x)\,p_X(x)$$

To compute the expected value of a function of \(X\), you do NOT need to find the distribution of \(g(X)\). You just apply \(g\) to each value of \(X\) and weight by \(X\)'s own PMF (or PDF).

Why "Unconscious Statistician"?

The name is ironic: a naive statistician might "unconsciously" write \(\mathbb{E}[g(X)] = \sum_y y \cdot p_{g(X)}(y)\) — which is correct but requires finding the distribution of \(g(X)\), a potentially hard step. LOTUS says you can be "unconscious" about this and just use the original \(p_X\). This is proved by the change-of-variables theorem: \(\sum_y y \cdot p_{g(X)}(y) = \sum_x g(x) \cdot p_X(x)\).

Three Concrete Uses

  • Variance shortcut: \(\operatorname{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2\). Here \(g(X) = X^2\). For the fair die: \(\mathbb{E}[X^2] = \tfrac{1^2+2^2+\cdots+6^2}{6} = \tfrac{91}{6} \approx 15.167\), so \(\operatorname{Var}(X) = \tfrac{91}{6} - \tfrac{49}{4} = \tfrac{35}{12} \approx 2.917\).
  • Absolute deviation: \(\mathbb{E}[|X - \mu|]\). Here \(g(X) = |X-3.5|\). For the die: \(\mathbb{E}[|X-3.5|] = \tfrac{2.5+1.5+0.5+0.5+1.5+2.5}{6} = \tfrac{9}{6} = 1.5\). Finding the distribution of \(|X-3.5|\) directly would be tedious.
  • Moment generating functions: \(M_X(t) = \mathbb{E}[e^{tX}] = \sum_x e^{tx} p_X(x)\). All moments follow from LOTUS with \(g(X) = e^{tX}\).
Key Insight

LOTUS is especially powerful when \(g\) is non-invertible (e.g., \(g(X) = X^2\) maps both \(+x\) and \(-x\) to the same value). In those cases, finding the distribution of \(g(X)\) requires careful casework. LOTUS bypasses this entirely.

Key Takeaways
▼

Three rules to internalize:

  • Definition: \(\mathbb{E}[X] = \sum_x x\,p(x)\) — the probability-weighted average of all outcomes.
  • Linearity: \(\mathbb{E}[aX + bY] = a\mathbb{E}[X] + b\mathbb{E}[Y]\) — always, even for dependent \(X, Y\). This is the #1 tool for computing expected counts (indicator variable trick).
  • LOTUS: \(\mathbb{E}[g(X)] = \sum_x g(x)\,p_X(x)\) — use \(X\)'s original distribution; never need to find the distribution of \(g(X)\).
When to reach for LOTUS

Any time you need \(\mathbb{E}[h(X)]\) — variance (\(h=x^2\)), standard deviation, log-likelihood (\(h=\log p\)), exponential moment (\(h=e^{tx}\)), absolute deviation, or any polynomial/transform of a RV — apply LOTUS directly. Do not stop to derive the distribution of \(h(X)\).

Where these appear in ML:

  • Expected loss / risk: \(\mathcal{R}(f) = \mathbb{E}_{(X,Y)}[\ell(f(X), Y)]\) — LOTUS with \(g = \ell\circ f\).
  • Variance of gradient estimators (important for variance reduction in RL).
  • Entropy: \(H(X) = -\mathbb{E}[\log p(X)] = -\sum_x p(x)\log p(x)\) — LOTUS with \(g(x) = -\log p(x)\).
  • KL divergence: \(D_{KL}(P\|Q) = \mathbb{E}_P[\log(P/Q)]\) — LOTUS under distribution \(P\).

Code Trace
▼
import numpy as np
# Fair die: X ~ Uniform{1,2,3,4,5,6}
x = np.array([1, 2, 3, 4, 5, 6])
p = np.ones(6) / 6 # each outcome has prob 1/6
# Basic expected value E[X] = sum(x * p(x))
EX = np.sum(x * p) # = 3.5
# Linearity: E[2X + 3] = 2*E[X] + 3
E_linear_direct = np.sum((2*x + 3) * p) # direct: 10.0
E_linear_formula = 2 * EX + 3 # formula: 10.0
# LOTUS: E[g(X)] = sum(g(x) * p(x)) — no need for distribution of g(X)
g = lambda xv: xv**2 # g(X) = X^2
EgX = np.sum(g(x) * p) # = 91/6 ≈ 15.167 (via LOTUS)
# Variance via LOTUS: Var(X) = E[X^2] - (E[X])^2
VarX = EgX - EX**2 # = 35/12 ≈ 2.917
# LOTUS: E[|X - mu|] — absolute deviation (hard to find dist of |X-mu|!)
E_abs_dev = np.sum(np.abs(x - EX) * p) # = 1.5
print(f"E[X] = {EX}") # 3.5
print(f"E[2X+3] = {E_linear_direct}") # 10.0
print(f"E[X^2] = {EgX:.4f}") # 15.1667
print(f"Var(X) = {VarX:.4f}") # 2.9167
print(f"E[|X-3.5|] = {E_abs_dev}") # 1.5
