Understanding Energy-Based Models (EBMs)
▼

What is it? An Energy-Based Model (EBM) defines a probability distribution \(p(x)\) over data \(x\) via an energy function \(E(x)\):

$$p(x) = \frac{1}{Z} e^{-E(x)}$$

where \(E(x)\) is typically a neural network, and \(Z = \int e^{-E(x)} dx\) is the intractable partition function (a normalizing constant that makes the probabilities sum to 1). Lower energy \(E(x)\) means higher probability \(p(x)\).

Analogy: Imagine a hilly landscape. The height of the land at any point \(x\) is its energy \(E(x)\). Valleys (low energy) represent data points that are highly probable (e.g., realistic images), while hilltops (high energy) represent improbable points (e.g., noisy static). An EBM is essentially learning to sculpt this landscape so that desirable data points reside in deep valleys.

💡 If you remember one thing

EBMs offer incredible flexibility because the energy function \(E(x)\) can be any neural network, without constraints for tractability. The challenge is that the normalizing constant \(Z\) is usually impossible to compute, making direct likelihood estimation and sampling difficult.

How EBMs Work Internally & Challenges
▼

Learning EBMs: The Score Function

Training an EBM generally involves pushing down the energy of real data samples (positive phase) and pushing up the energy of "non-data" samples (negative phase). The negative phase is tricky because it requires sampling from the current model distribution \(p(x)\), which itself depends on the unknown \(Z\).

A key concept that bypasses \(Z\) is the score function of the data distribution:

$$\nabla_x \log p(x) = \nabla_x \left( \log \frac{1}{Z} e^{-E(x)} \right) = \nabla_x \left( -E(x) - \log Z \right) = -\nabla_x E(x)$$

The score function tells us the direction of steepest ascent in log-probability (or steepest descent in energy). Crucially, it does not depend on the partition function \(Z\)! This means we can learn to estimate the score function \(s_\theta(x) \approx -\nabla_x E(x)\) without ever computing \(Z\).

Sampling from EBMs: Langevin Dynamics

Once we have the score function (either analytically or a learned approximation \(s_\theta(x)\)), we can use Markov Chain Monte Carlo (MCMC) methods like Langevin Dynamics to sample from \(p(x)\). The update rule for Langevin Dynamics is:

$$x_{t+1} = x_t + \frac{\epsilon}{2} \nabla_x \log p(x_t) + \sqrt{\epsilon} z_t$$

where \(\epsilon\) is a small step size and \(z_t \sim \mathcal{N}(0, I)\) is Gaussian noise. This process iteratively moves \(x_t\) towards higher probability regions, eventually converging to samples from \(p(x)\).

🔑 Key Property

The score function \(\nabla_x \log p(x)\) is the central object in modern EBMs. It can be estimated without knowing the intractable partition function \(Z\), and it directly drives generative sampling via Langevin Dynamics. This connection is fundamental to how diffusion models work.

Why It Works — Score Matching & Diffusion Connections
▼

Score Matching: Learning \(-\nabla_x E(x)\)

The goal of score matching (Hyvärinen, 2005) is to learn a neural network \(s_\theta(x)\) that approximates \(\nabla_x \log p(x)\). The loss function directly minimizes the squared difference between the model's score and the true data score:

$$\mathcal{L}_{SM}(\theta) = \mathbb{E}_{p(x)}\left[\frac{1}{2}\|s_\theta(x) - \nabla_x \log p(x)\|^2\right]$$

While \(\nabla_x \log p(x)\) is unknown, Hyvärinen showed that this loss can be equivalently minimized without explicitly computing the true score function, using an alternative objective:

$$\mathcal{L}_{SM}(\theta) = \mathbb{E}_{p(x)}\left[\operatorname{tr}(\nabla_x s_\theta(x)) + \frac{1}{2}\|s_\theta(x)\|^2\right]$$

This formulation only requires computing the trace of the Jacobian of \(s_\theta(x)\) and the squared norm of \(s_\theta(x)\), both of which can be done without \(Z\). This is powerful, but computing the Jacobian trace can still be expensive in high dimensions.

Denoising Score Matching & Diffusion Models

A more practical variant, Denoising Score Matching (DSM), addresses the Jacobian trace issue and forms the basis of modern diffusion models. Instead of learning \(\nabla_x \log p(x)\) directly, DSM learns the score function of data corrupted by a small amount of noise. Diffusion models extend this by defining a sequence of distributions \(p(x_t)\) where \(x_t\) is \(x_0\) (original data) progressively corrupted by Gaussian noise over time \(t\).

The forward diffusion process is fixed: \(q(x_t|x_0) = \mathcal{N}(x_t; \sqrt{\alpha_t} x_0, (1-\alpha_t)I)\). The key insight: the score function \(\nabla_{x_t} \log q(x_t|x_0)\) is known analytically!

$$\nabla_{x_t} \log q(x_t|x_0) = -\frac{x_t - \sqrt{\alpha_t} x_0}{1-\alpha_t}$$

Diffusion models train a neural network \(s_\theta(x_t, t)\) to predict this score for various noise levels \(t\). Then, to generate new data, they reverse the diffusion process by starting from pure noise \(x_T \sim \mathcal{N}(0, I)\) and iteratively denoising it back to \(x_0\), using the learned score \(s_\theta(x_t, t)\) in a generalized Langevin-like update: \(x_{t-1} = x_t - \frac{\beta_t}{2} s_\theta(x_t, t) + \sqrt{\beta_t} z\). This is essentially running Langevin dynamics on a sequence of noisy EBMs.

⚠️ Common Pitfall

Naive score matching requires computing \(\operatorname{tr}(\nabla_x s_\theta(x))\), which is a sum of partial derivatives. This can be computationally expensive (e.g., \(D\) backward passes for \(D\)-dimensional data). Denoising score matching (DSM) elegantly sidesteps this by using noisy data, where the true score function for the noise distribution is known, simplifying the loss to a regression task.

Key Takeaways
▼

When to use EBMs (and diffusion models):

  • Generative modeling: producing high-fidelity, diverse samples (images, audio, text).
  • Implicit density estimation: when the exact likelihood \(p(x)\) is hard to model but the "shape" of the data distribution can be defined by an energy function.
  • Denoising tasks: the core mechanism of diffusion is denoising.
  • When you need a flexible model that doesn't rely on explicit variational bounds (like VAEs) or adversarial training (like GANs).

Key challenges & considerations:

  • Intractable partition function \(Z\) is the perennial problem for EBMs, making direct likelihood difficult.
  • Sampling from EBMs via MCMC (Langevin) can be slow and requires careful tuning of step sizes.
  • Diffusion models effectively "side-step" the intractable \(Z\) by learning scores of noisy data, but require many forward/backward passes for sampling.
  • Training diffusion models is computationally intensive, requiring large datasets and significant GPU resources.
💡 Big Picture

Diffusion models are a powerful realization of the EBM philosophy. By learning the score function of data at various noise levels, they effectively learn a sequence of EBMs that can be "reversed" to generate data from pure noise. The underlying principles of energy landscapes, score functions, and Langevin dynamics are central to understanding their success.

import torch
import torch.nn as nn
import torch.optim as optim
# 1. Energy Function (e.g., a simple MLP)
class EnergyNet(nn.Module):
def __init__(self, input_dim):
super().__init__()
self.net = nn.Sequential(
nn.Linear(input_dim, 128),
nn.SiLU(),
nn.Linear(128, 128),
nn.SiLU(),
nn.Linear(128, 1) # Output a scalar energy
)
def forward(self, x):
return self.net(x).squeeze(-1)
# 2. Score Function (computed from EnergyNet)
def compute_score(energy_model, x):
x.requires_grad_(True)
energy_val = energy_model(x)
score = -torch.autograd.grad(energy_val.sum(), x, create_graph=True)[0]
return score
# 3. Langevin Dynamics for sampling
def langevin_sample(energy_model, initial_x, steps=100, epsilon=0.1):
x = initial_x.clone().detach()
for _ in range(steps):
x.requires_grad_(True)
energy_val = energy_model(x)
# Compute score = -dE/dx
score = -torch.autograd.grad(energy_val.sum(), x, create_graph=False)[0]
noise = torch.randn_like(x)
x = x.detach() + (epsilon / 2) * score + torch.sqrt(torch.tensor(epsilon)) * noise
return x
# 4. Simplified Denoising Score Matching Loss (core of Diffusion)
class ScoreNet(nn.Module): # This model learns the score function directly
def __init__(self, input_dim):
super().__init__()
self.net = nn.Sequential(
nn.Linear(input_dim + 1, 128), # +1 for time/noise level embedding
nn.SiLU(),
nn.Linear(128, 128),
nn.SiLU(),
nn.Linear(128, input_dim) # Output a vector (the score)
)
def forward(self, x, t):
return self.net(torch.cat([x, t.unsqueeze(-1)], dim=-1))
def dsm_loss(score_model, x0_batch, sigma):
noise = torch.randn_like(x0_batch)
xt_batch = x0_batch + sigma * noise # Add noise to data
# True score for p(xt|x0) is -(xt - x0) / sigma^2
true_score = -noise / sigma # Simplified true score for p(xt|x0) with unit variance noise
# Predict score using model, passing sigma as 't'
predicted_score = score_model(xt_batch, torch.full((x0_batch.shape[0],), sigma))
loss = torch.mean((predicted_score - true_score)**2)
return loss
