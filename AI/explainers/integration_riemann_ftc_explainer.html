Integration: Riemann Sums & the Fundamental Theorem of Calculus

How infinite slices of area become exact — and why differentiation and integration are inverses

1
Understanding Integration
▼

What is it? Integration answers one fundamental question: how much area lies under a curve? If you plot speed over time, the area under the curve is distance traveled. If you plot power, the area is energy. Integration converts a rate into an accumulated quantity.

The Riemann idea: Bernhard Riemann (1854) formalized the idea that we can approximate area by stacking thin rectangles under the curve and then take the limit as the rectangles become infinitely many and infinitely thin. Each rectangle has width \(\Delta x\) and height \(f(x_i^*)\), contributing area \(f(x_i^*)\Delta x\). Summing all gives a Riemann sum. As \(n \to \infty\), the sum converges to the definite integral \(\int_a^b f(x)\,dx\).

The Fundamental Theorem of Calculus (FTC) is the great shortcut: instead of computing an infinite limit every time, we can evaluate the integral by finding an antiderivative \(F\) (where \(F'=f\)) and computing \(F(b) - F(a)\). It links two seemingly separate operations — area and slope — revealing they are inverses of each other.

If you remember one thing

The definite integral is the limit of Riemann sums: $$\int_a^b f(x)\,dx = \lim_{n\to\infty}\sum_{i=1}^n f(x_i^*)\,\Delta x$$ and the FTC says you can compute it as \(F(b)-F(a)\) where \(F'=f\) — no infinite limit required.

2
How Riemann Sums Work Internally
▼

Partition and Sample

Divide \([a,b]\) into \(n\) equal subintervals of width \(\Delta x = \frac{b-a}{n}\). On each subinterval \([x_{i-1},x_i]\), pick a sample point \(x_i^*\). The three classical choices:

  • Left sum — \(x_i^* = x_{i-1}\): use the left endpoint height.
  • Right sum — \(x_i^* = x_i\): use the right endpoint height.
  • Midpoint sum — \(x_i^* = \frac{x_{i-1}+x_i}{2}\): generally most accurate for smooth functions at the same \(n\).

The Riemann sum is:

$$R_n = \sum_{i=1}^n f(x_i^*)\,\Delta x = \sum_{i=1}^n f\!\left(a + i\cdot\frac{b-a}{n}\right)\cdot\frac{b-a}{n} \quad \text{(right-sum form)}$$

For \(f(x)=x^2\) on \([0,1]\) with \(n=4\) and right endpoints: \(\Delta x = 0.25\), sample points \(0.25,0.5,0.75,1.0\), sum \(= 0.0625+0.25+0.5625+1.0)\times 0.25 = 0.46875\). True value: \(\tfrac{1}{3}\approx 0.3333\). Error shrinks as \(n\) grows.

Key convergence property

For any Riemann-integrable function, all choices of sample point yield the same limit as \(n\to\infty\). Left, right, and midpoint sums all converge to \(\int_a^b f(x)\,dx\). The convergence rate for smooth \(f\) is \(O(1/n)\) for left/right and \(O(1/n^2)\) for midpoint.

Why rectangles? Why not trapezoids?

Rectangles (piecewise constant approximation) are the simplest conceptual building block. Trapezoids and Simpson's rule offer faster convergence (\(O(1/n^2)\) and \(O(1/n^4)\) respectively) for smooth functions — these are numerical integration methods, all grounded in the same Riemann idea of subdividing the domain.

3
The Fundamental Theorem of Calculus — Why It Works
▼

Part 1 — The Area Accumulation Function

Define the area accumulation function:

$$A(x) = \int_a^x f(t)\,dt$$

FTC Part 1 says \(A'(x) = f(x)\) — the derivative of the accumulated area at \(x\) equals the function value there. Proof sketch: \(A(x+h)-A(x)\approx f(x)\cdot h\) (the thin sliver of area is approximately a rectangle of height \(f(x)\) and width \(h\)), so \(\frac{A(x+h)-A(x)}{h}\to f(x)\) as \(h\to 0\).

Part 2 — The Evaluation Theorem

If \(F\) is any antiderivative of \(f\) (i.e., \(F'=f\)), then:

$$\int_a^b f(x)\,dx = F(b) - F(a)$$

This follows because \(A(x)=F(x)+C\) for some constant (two antiderivatives differ only by a constant), and \(A(a)=0\), giving \(C=-F(a)\), so \(A(b)=F(b)-F(a)\).

Worked example: \(\int_0^1 x^2\,dx\)

Antiderivative: \(F(x)=\frac{x^3}{3}\). Apply FTC Part 2: \(F(1)-F(0) = \frac{1}{3}-0 = \frac{1}{3}\approx 0.3333\).

The Riemann sum with \(n=100\) right rectangles gives \(0.33835\); with \(n=1000\) it gives \(0.33383\) — converging to \(\frac{1}{3}\) from above.

Common confusion

The indefinite integral \(\int f(x)\,dx = F(x)+C\) is a family of antiderivatives, not a number. The definite integral \(\int_a^b f(x)\,dx\) is a specific number — the signed area. The "+C" disappears when you subtract \(F(a)\) from \(F(b)\).

Key Takeaways & When to Use
▼

Riemann sums matter for: numerical integration (when you have data, not a formula), understanding convergence, and error analysis in ML (e.g., approximating expectations as Monte Carlo averages is essentially Riemann-sum reasoning).

FTC matters for: every analytic calculation of area, probability (CDF from PDF), expectations, and optimization.

  • Left/right Riemann sums: \(O(1/n)\) error — linear convergence
  • Midpoint/trapezoid rule: \(O(1/n^2)\) error — quadratic convergence
  • Simpson's rule: \(O(1/n^4)\) error — needs even \(n\)
  • Monte Carlo integration: \(O(1/\sqrt{n})\) — scales to high dimensions
The deep connection

Differentiation and integration are inverse operations. FTC is the bridge: the derivative of the accumulated area is the original function, and the area can be recovered from any antiderivative. This duality underpins virtually all of applied mathematics and ML — from computing loss gradients (differentiation) to computing expected losses (integration).

Code Trace
▼
import numpy as np
def f(x): return x**2 # the integrand
a, b = 0.0, 1.0 # limits
# Right Riemann sum with n rectangles
def riemann_right(n):
dx = (b - a) / n
xs = a + np.arange(1, n+1) * dx # right endpoints
return np.sum(f(xs)) * dx
# Midpoint Riemann sum (more accurate)
def riemann_mid(n):
dx = (b - a) / n
xs = a + (np.arange(n) + 0.5) * dx # midpoints
return np.sum(f(xs)) * dx
# FTC: antiderivative of x^2 is x^3/3
def F(x): return x**3 / 3
exact = F(b) - F(a) # 1/3 ≈ 0.33333
# Compare at various n
for n in [4, 10, 100, 1000]:
r = riemann_right(n)
m = riemann_mid(n)
print(f"n={n:4d} right={r:.6f} mid={m:.6f} exact={exact:.6f}")
# n= 4 right=0.468750 mid=0.328125 exact=0.333333
# n= 10 right=0.385000 mid=0.332500 exact=0.333333
# n= 100 right=0.338350 mid=0.333325 exact=0.333333
# n=1000 right=0.333833 mid=0.333333 exact=0.333333
