Understanding Audio Classification
▼

What is it? Audio classification (a.k.a. audio tagging) takes a raw sound clip — a dog barking, rain falling, a siren wailing — and predicts which of hundreds of everyday sound categories are present. Unlike speech recognition (which transcribes words), this is about recognizing what made the sound, and unlike single-label image classification, a single clip can contain many simultaneous tags at once.

Analogy: Imagine a security guard watching a bank of ambient microphones. They don't need to transcribe conversations — they just need to notice "glass breaking," "car alarm," "dog barking," "footsteps," all possibly at the same moment. That's audio tagging: a multi-label detector for the acoustic world, not a transcriber of speech.

AudioSet (Gemmeke et al., 2017, Google) is the field's benchmark: 2M+ 10-second YouTube clips labeled with 527 hierarchical classes (e.g. "Animal" → "Domestic animals" → "Dog" → "Bark"), each clip carrying multiple weak labels. It turned audio tagging into a large-scale, ImageNet-like problem.

💡 If you remember one thing

Audio classification converts sound into an image-like log-mel spectrogram, then applies image-style architectures — CNNs (PANNs) or Vision Transformers (AST) — to that spectrogram, ending in independent per-class sigmoids because sounds overlap and are not mutually exclusive.

2
How It Works Internally
▼

Step 1 — Turn sound into an image

A raw waveform \(x[n]\) is chopped into overlapping frames, each transformed with a Short-Time Fourier Transform (STFT) into a time-frequency magnitude grid. A bank of triangular mel filters (mimicking human pitch perception, which is roughly logarithmic) compresses hundreds of linear frequency bins into ~64–128 perceptual mel bins, and a log() compresses the huge dynamic range of loudness. The result — the log-mel spectrogram — is a single-channel image: mel-bin on one axis, time-frame on the other.

Step 2a — PANNs: a CNN over the spectrogram

PANNs (Pretrained Audio Neural Networks, Kong et al. 2020) treat the log-mel spectrogram exactly like an image and run it through a CNN (a CNN14/ResNet/Wavegram-CNN stack): stacked 3×3 convolutions build up receptive field, pooling layers downsample, and a final global-average-pool collapses the whole clip into one embedding vector, regardless of clip length. A linear layer maps that embedding to 527 logits, followed by a sigmoid per class (not softmax) — because "Dog bark" and "Speech" can both be true in the same 10 seconds.

Step 2b — AST: a Vision Transformer over the spectrogram

The Audio Spectrogram Transformer (Gong et al., 2021) instead slices the log-mel spectrogram into small fixed-size patches (e.g. 16×16, borrowed directly from ViT), linearly projects each flattened patch into a token, adds learned positional embeddings, prepends a CLS token, and runs the whole sequence through a standard Transformer encoder. Self-attention lets any patch — the onset of a bark, the harmonic sweep of a siren three seconds later — directly exchange information with any other patch in one layer, something a CNN needs many layers of depth to approximate.

🔑 Key Property

Both PANNs and AST solve the same multi-label problem on the same input representation (log-mel spectrogram); they differ only in the backbone: local, weight-shared convolution (PANNs) vs. global, content-based self-attention (AST). AST typically edges out PANNs in mAP on AudioSet but is more data- and compute-hungry.

Why It Works — The Math
▼

Log-mel spectrogram

For frame \(t\), the STFT bin \(k\) is \(X(k,t) = \sum_{n=0}^{N-1} x(tH+n)\, w(n)\, e^{-i2\pi kn/N}\), where \(w\) is a window (e.g. Hann) and \(H\) the hop size. Mel filter \(m\) (a triangular weighting \(H_m(k)\) over linear bins) aggregates power into a perceptual band:

$$S_{\text{mel}}(m,t) = \log\Big(\textstyle\sum_k H_m(k)\,|X(k,t)|^2 + \epsilon\Big)$$

Multi-label output: independent sigmoids

Given clip embedding \(\mathbf{e}\), each of the \(C\) AudioSet classes gets its own logit and independent probability:

$$\hat{y}_c = \sigma(\mathbf{w}_c^\top \mathbf{e} + b_c), \qquad \sigma(z) = \frac{1}{1+e^{-z}}, \qquad c = 1,\dots,C$$

Trained with per-class binary cross-entropy summed over classes — NOT a single softmax over all classes:

$$\mathcal{L} = -\sum_{c=1}^{C}\Big[y_c\log\hat{y}_c + (1-y_c)\log(1-\hat{y}_c)\Big]$$

AST: patch embedding and self-attention

Each patch \(P_i\) (say 16×16 spectrogram pixels) is flattened and linearly projected, with a learned positional code added:

$$\mathbf{z}_i^{(0)} = W_e\,\text{flatten}(P_i) + \mathbf{e}_{\text{pos},i}$$

Every Transformer layer lets patches exchange information via scaled dot-product self-attention:

$$\text{Attn}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V, \qquad Q=ZW_q,\ K=ZW_k,\ V=ZW_v$$
⚠️ Common Pitfall

Using softmax (instead of independent sigmoids) across AudioSet's 527 classes is a classic bug — softmax forces probabilities to sum to 1, which silently suppresses correct co-occurring tags (e.g. "Rain" and "Thunder" together) because raising one score necessarily lowers all others.

Key Takeaways
▼

When to reach for each approach:

  • PANNs / CNN backbones — strong default, cheaper to train/run, great transfer-learning embeddings for downstream audio tasks, robust with less data.
  • AST / Transformer backbones — higher ceiling on large labeled data (AudioSet-scale), better long-range structure (e.g. relating a sound's onset to its decay seconds later), but needs ImageNet/AudioSet pretraining to be data-efficient.
  • Sigmoid, always, for tagging (multi-label); reserve softmax for genuinely mutually-exclusive decisions (e.g. "which single speaker is active").
💡 The big picture

Audio classification is really computer vision applied to a picture of sound. Once you accept the log-mel spectrogram as "the image," every trick from CNNs and Vision Transformers — receptive fields, patch embeddings, self-attention, global pooling — transfers directly, with the one crucial twist that the final layer must allow multiple independent "yes" answers at once.

import numpy as np
# 1. Waveform -> STFT -> log-mel spectrogram
X = stft(waveform, frame=32, hop=16)
mel_fb = mel_filterbank(n_mels=12)
logmel = np.log(mel_fb @ (np.abs(X) ** 2) + 1e-6)
# 2. PANNs: CNN over the log-mel "image"
feat_maps = [relu(conv2d(logmel, k)) for k in kernels]
embedding = np.mean(feat_maps, axis=(1, 2)) # global avg pool
logits_panns = embedding @ W_panns + b_panns
probs_panns = sigmoid(logits_panns) # multi-label
# 3. AST: split spectrogram into patches (ViT-style)
patches = split_into_patches(logmel, size=(3, 4))
tokens = [W_embed @ flatten(p) + pos_embed[i] for i, p in enumerate(patches)]
# 4. Self-attention across patch tokens
Q, K, V = tokens @ Wq, tokens @ Wk, tokens @ Wv
attn = softmax(Q @ K.T / np.sqrt(d_k))
context = attn @ V
# 5. Classification head
logits_ast = context.mean(axis=0) @ W_cls + b_cls
probs_ast = sigmoid(logits_ast) # independent per-tag probs
probs_softmax = softmax(logits_ast) # contrast: forces sum=1
