Jensen's Inequality

Why the average of a function always lies above (or below) the function of the average — and why this single fact underlies ELBO, EM, entropy bounds, KL divergence, and AM-GM.
Foundational Math & Stats Convexity Must Know
1
Understanding the Concept
▾

Imagine you are predicting tomorrow's commute time. Your journey can take 20 minutes (good day) or 60 minutes (bad day) with equal probability, so the average time is 40 minutes. Now suppose your mood depends not linearly on time but as time² (it gets disproportionately worse the longer you are stuck). Should you use mood(average time) or average(mood(time)) to describe your expected suffering?

Jensen's Inequality says: for any convex function \(f\), applying the function to the average always gives a smaller or equal result than averaging the function values: $$f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$$

Geometrically, this is the chord-lies-above-the-curve property. The straight line (chord) connecting two points on a convex curve sits above the curve itself. Jensen lifts this from pairs of points to arbitrary probability distributions.

If You Remember One Thing

For convex \(f\): \(f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]\). For concave \(f\) (like \(\ln\)): the inequality flips: \(f(\mathbb{E}[X]) \geq \mathbb{E}[f(X)]\). The gap between the two sides equals a variance term (curvature × spread), and in ML it shows up as the ELBO gap in variational inference.

Key Concept — Convexity

A function \(f: \mathbb{R} \to \mathbb{R}\) is convex iff for all \(x, y\) and \(\lambda \in [0,1]\): $$f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)$$Equivalently: \(f''(x) \geq 0\) everywhere (for twice-differentiable \(f\)). Examples: \(x^2\), \(e^x\), \(|x|\), \(-\ln x\) (wait — \(-\ln x\) is convex; \(\ln x\) is concave). Concave: \(f'' \leq 0\). Examples: \(\ln x\), \(\sqrt{x}\), \(-x^2\).

The Math — Derivation & Proof
▾

Finite Version (two points)

Start with the definition of convexity. For any \(\lambda \in [0,1]\) and points \(a, b\):

$$f(\lambda a + (1-\lambda)b) \leq \lambda f(a) + (1-\lambda)f(b)$$

This is the chord inequality: the curve value at any convex combination is at most the convex combination of the curve values.

Extension to Discrete Distributions (Induction Proof)

For a discrete random variable \(X\) taking values \(x_1, \ldots, x_n\) with probabilities \(p_1, \ldots, p_n\) (summing to 1), the claim is:

$$f\!\left(\sum_{i=1}^n p_i x_i\right) \leq \sum_{i=1}^n p_i f(x_i)$$

Proof by induction on \(n\):

Base case \(n=2\): This is exactly the definition of convexity.

Inductive step: Assume it holds for \(n-1\) points. Write \(p_n' = 1 - p_n\) and define the renormalized weights \(q_i = p_i/p_n'\) for \(i=1,\ldots,n-1\). Then:

$$\sum_{i=1}^n p_i x_i = p_n x_n + p_n' \sum_{i=1}^{n-1} q_i x_i$$

Apply the two-point case with \(\lambda = p_n\), \(a = x_n\), \(b = \sum_{i=1}^{n-1} q_i x_i\):

$$f\!\left(\sum_{i=1}^n p_i x_i\right) \leq p_n f(x_n) + p_n' f\!\left(\sum_{i=1}^{n-1} q_i x_i\right)$$

By the inductive hypothesis (Jensen holds for \(n-1\) points with weights \(q_i\)):

$$f\!\left(\sum_{i=1}^{n-1} q_i x_i\right) \leq \sum_{i=1}^{n-1} q_i f(x_i) = \frac{1}{p_n'}\sum_{i=1}^{n-1} p_i f(x_i)$$

Substituting back: \(f(\sum p_i x_i) \leq p_n f(x_n) + \sum_{i=1}^{n-1} p_i f(x_i) = \sum_{i=1}^n p_i f(x_i)\). QED.

Continuous Extension

For a continuous random variable \(X\) with density \(p(x)\) on a convex domain:

$$f\!\left(\int x\, p(x)\, dx\right) \leq \int f(x)\, p(x)\, dx \quad \Longleftrightarrow \quad f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$$

This follows from the Lebesgue integral generalization via the supporting hyperplane argument: for a convex \(f\) there exists a supporting tangent line at \(\mu = \mathbb{E}[X]\), meaning \(f(x) \geq f(\mu) + f'(\mu)(x-\mu)\) for all \(x\). Taking expectations of both sides: \(\mathbb{E}[f(X)] \geq f(\mu) + f'(\mu)(\mathbb{E}[X]-\mu) = f(\mu)\).

The Supporting Hyperplane Proof (Elegant)

For convex \(f\), at any point \(\mu\) there exists a subgradient \(c\) such that \(f(x) \geq f(\mu) + c(x-\mu)\) for all \(x\). Set \(\mu = \mathbb{E}[X]\) and take expectations: $$\mathbb{E}[f(X)] \geq f(\mathbb{E}[X]) + c(\mathbb{E}[X]-\mathbb{E}[X]) = f(\mathbb{E}[X])$$

The Gap — Taylor Expansion

For twice-differentiable \(f\) and small variance, a second-order Taylor expansion around \(\mu = \mathbb{E}[X]\) gives:

$$\mathbb{E}[f(X)] - f(\mathbb{E}[X]) \approx \frac{1}{2} f''(\mu) \cdot \text{Var}(X)$$

For \(f(x) = x^2\): \(f''(x) = 2\), so the gap \(= \text{Var}(X)\) exactly (no approximation). This confirms our numeric result: Var({1,2,4}) = 7 − (7/3)² = 14/9 ≈ 1.556.

Warning — Common Misconceptions
  • Jensen applies to functions of random variables, not to statistics of samples. \(\hat{\mu}\) is not \(\mathbb{E}[X]\).
  • The inequality holds for all distributions, not just Gaussian. No moment assumptions needed beyond existence of \(\mathbb{E}[X]\) and \(\mathbb{E}[f(X)]\).
  • Equality holds iff \(X\) is constant a.s. (Dirac) or \(f\) is affine on the support of \(X\).
  • Convex \(\neq\) strictly convex. For strictly convex \(f\), equality only at degenerate distributions.
3
Applications in Machine Learning
▾

1. ELBO in Variational Inference (Most Important ML Use)

In variational inference we want \(\log p(x)\) but cannot compute it directly (intractable marginalisation over latent \(z\)). Apply Jensen's inequality using the concavity of \(\log\):

$$\log p(x) = \log \int p(x,z)\, dz = \log \mathbb{E}_{q(z)}\!\left[\frac{p(x,z)}{q(z)}\right] \geq \mathbb{E}_{q(z)}\!\left[\log \frac{p(x,z)}{q(z)}\right] = \mathcal{L}$$

The right-hand side \(\mathcal{L}\) is the Evidence Lower Bound (ELBO). The gap between \(\log p(x)\) and \(\mathcal{L}\) is exactly \(\text{KL}(q(z)\|p(z|x)) \geq 0\), which is itself a consequence of Jensen applied to \(-\log\). VAEs, VEM, VB-EM all maximize the ELBO.

2. EM Algorithm

The E-step of the EM algorithm introduces \(q(z) = p(z|x,\theta_t)\) which makes the ELBO gap zero at the current \(\theta_t\). The M-step maximises the ELBO. Jensen guarantees the ELBO is always a tight lower bound at the E-step, ensuring monotone improvement.

3. KL Divergence is Non-negative (Gibbs' Inequality)

$$\text{KL}(p \| q) = \mathbb{E}_p\!\left[-\log \frac{q(x)}{p(x)}\right] \geq -\log \mathbb{E}_p\!\left[\frac{q(x)}{p(x)}\right] = -\log 1 = 0$$

We applied Jensen with the convex function \(f = -\log\) and the ratio \(q/p\) as the random variable. \(\text{KL}(p\|q) = 0\) iff \(p = q\) almost everywhere.

4. AM-GM Inequality

The AM-GM inequality is a special case. Apply Jensen with \(f(x) = -\ln(x)\) (convex) to values \(a_1,\ldots,a_n\) with uniform weights \(1/n\):

$$-\ln\!\left(\frac{a_1+\cdots+a_n}{n}\right) \leq \frac{-\ln a_1 - \cdots - \ln a_n}{n} = -\frac{1}{n}\ln(a_1\cdots a_n)$$

Negating: \(\ln(\text{AM}) \geq \ln(\text{GM})\), i.e., AM \(\geq\) GM.

5. Entropy and Cross-Entropy Bounds

By Jensen (log concave): \(\mathbb{E}[\log p(X)] \leq \log \mathbb{E}[p(X)] = \log 1 = 0\), so the entropy \(H(X) = -\mathbb{E}[\log p(X)] \geq 0\). Also: \(H(p) \leq \log |X|\) (uniform maximises entropy), derivable via Jensen.

Central Role in ML

Jensen's Inequality is the single mathematical fact behind: ELBO derivation · KL ≥ 0 · EM convergence guarantee · log-sum-exp being a convex envelope · AM-GM · entropy bounds. Any time you see a log around an expectation or an expectation inside a log, Jensen is lurking.

From Scratch — Verifying Jensen Numerically

# Jensen's Inequality: numerical verification
import numpy as np

def check_jensen(f, X, p):
    """Verify Jensen: f(E[X]) <= E[f(X)] for convex f.

    Args:
        f  : callable, the function to apply
        X  : array of values the r.v. can take
        p  : probability weights (must sum to 1)
    Returns:
        dict with f_of_E, E_of_f, gap, holds
    """
    X, p = np.asarray(X, float), np.asarray(p, float)
    assert abs(p.sum() - 1) < 1e-9, "p must sum to 1"

    E_X   = np.dot(p, X)          # E[X]
    f_E_X = f(E_X)                # f(E[X])
    E_f_X = np.dot(p, f(X))      # E[f(X)]
    gap   = E_f_X - f_E_X        # >= 0 for convex f

    return {"E[X]": E_X, "f(E[X])": f_E_X,
            "E[f(X)]": E_f_X, "gap": gap,
            "Jensen holds (convex)": gap >= -1e-12}

# --- Convex f(x) = x² ---
X = [1, 2, 4]
p = [1/3, 1/3, 1/3]
print(check_jensen(lambda x: x**2, X, p))
# {'E[X]': 2.333, 'f(E[X])': 5.444, 'E[f(X)]': 7.0, 'gap': 1.556, 'Jensen holds': True}

# --- Concave f(x) = ln(x): inequality reverses ---
print(check_jensen(np.log, X, p))
# gap = E[ln(X)] - ln(E[X]) = 0.693 - 0.847 = -0.154  (negative for concave)

# --- ELBO lower bound via Jensen ---
def elbo(log_joint, log_q, q_samples):
    """E_q[log p(x,z) - log q(z)].  Always <= log p(x)."""
    return np.mean(log_joint(q_samples) - log_q(q_samples))

# --- Variance identity: Var(X) = E[X²] - (E[X])² >= 0 ---
def variance_via_jensen(X, p):
    E_X   = np.dot(p, X)
    E_X2  = np.dot(p, X**2)    # E[f(X)] with f=x²
    fEX   = E_X**2             # f(E[X]) = (E[X])²
    return E_X2 - fEX          # = Var(X) >= 0 by Jensen

print(f"Var(X) = {variance_via_jensen(np.array(X, float), np.array(p)):.4f}")  # 1.5556

Production — PyTorch VAE ELBO

# Jensen's Inequality in action: VAE ELBO loss
import torch
import torch.nn.functional as F

def vae_elbo(recon_x, x, mu, log_var):
    """VAE ELBO loss: -E_q[log p(x|z)] + KL(q(z|x)||p(z)).

    Jensen guarantees: log p(x) >= ELBO, so maximising ELBO
    tightens the gap = KL(q(z|x) || p(z|x)).

    Args:
        recon_x  : reconstructed x from decoder,  shape (B, D)
        x        : original input,                 shape (B, D)
        mu       : encoder mean,                   shape (B, latent_dim)
        log_var  : encoder log-variance,           shape (B, latent_dim)
    Returns:
        Scalar ELBO loss (negated, for minimisation)
    """
    # Reconstruction term: E_q[log p(x|z)]
    # Using Gaussian likelihood => MSE (or BCE for binary data)
    recon_loss = F.mse_loss(recon_x, x, reduction='sum')

    # KL term: KL(N(mu, sigma²) || N(0,1))
    # = -1/2 * sum(1 + log_var - mu² - exp(log_var))
    # This is a CLOSED FORM consequence of Jensen / KL >= 0
    kl_loss = -0.5 * torch.sum(1 + log_var - mu.pow(2) - log_var.exp())

    # ELBO = Reconstruction - KL  (we minimise negative ELBO)
    return recon_loss + kl_loss

# Usage
# loss = vae_elbo(recon_x, x, mu, log_var)
# loss.backward()
# optimizer.step()

# ⚠️ Gotcha: KL term drives q(z|x) towards N(0,1) (regularisation).
# If KL weight = 0 (beta=0), posterior collapses; if too high, reconstruction suffers.
# beta-VAE uses KL weight beta > 1 for disentanglement.

Key Takeaways & Connections
▾
Core Insight

Jensen's Inequality is the mathematical backbone of probabilistic ML. Whenever you apply a nonlinear function to an expectation (or vice versa), Jensen tells you which side is larger — and the gap is controlled by variance and curvature: \(\approx \frac{1}{2}f''(\mu)\cdot\text{Var}(X)\).

When Equality Holds

  • \(X\) is a constant (Dirac delta distribution — zero variance)
  • \(f\) is affine (\(f(x) = ax + b\)) on the support of \(X\)

Prerequisites You Should Know

  • Expectation and probability distributions
  • Convexity and second-order conditions (\(f''\geq 0\))
  • Basic real analysis (limits, integrals)

Topics That Build on Jensen

  • KL Divergence and information theory
  • Variational Inference (VI) and the ELBO
  • EM Algorithm — convergence proof
  • Convex optimisation duality
  • PAC learning / concentration inequalities (Markov, Chernoff)
