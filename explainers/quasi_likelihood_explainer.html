What Is Quasi-Likelihood?
▼

What is it? A generalized linear model (GLM) normally requires you to specify an entire probability distribution — Poisson, Binomial, Gamma, etc. Quasi-likelihood methods let you do almost everything a GLM does while specifying only how the variance relates to the mean. This "mean–variance relationship" \(V(\mu)\) is all you need to get consistent, asymptotically normal estimates and valid hypothesis tests.

Analogy: Imagine counting insects at different sites. You know more insects on average means more variability, but you don't trust any single textbook distribution. Quasi-likelihood says: "Tell me roughly how variance grows with the mean, and I'll give you coefficient estimates as if you had a full model — without assuming any particular distribution." You get the inference machinery of a GLM without committing to a specific probability law.

Why does this matter? Real count data almost always has overdispersion — more variability than a Poisson distribution predicts (where Var = mean). Ignoring it means your standard errors are too small, your p-values too optimistic, and you'll claim significance you don't have. Quasi-Poisson inflates all standard errors by \(\sqrt{\hat{\phi}}\), fixing this without switching to a Negative Binomial distribution.

💡 If you remember one thing

Specify only \(V(\mu)\) (variance as a function of mean). A dispersion parameter \(\hat{\phi}\) estimated from Pearson residuals rescales your standard errors. Point estimates (the \(\hat{\beta}\) coefficients) are identical to the corresponding GLM — only standard errors change. For quasi-Poisson: \(\operatorname{Var}(Y_i) = \phi \mu_i\), and \(\hat{\phi} = \tfrac{1}{n-p}\sum_i \frac{(y_i-\hat{\mu}_i)^2}{\hat{\mu}_i}\).

Historical Context & Core Theory
▼

Historical Motivation

By the late 1960s, practitioners had Poisson regression for counts and logistic regression for proportions, but real data routinely violated the exact variance constraints these models imposed. Ecologists modelling species counts, epidemiologists modelling event rates — all saw "overdispersed" data where observed variance exceeded the predicted mean. Fitting a Poisson GLM to such data gave artificially narrow confidence intervals.

Robert Wedderburn (1974) introduced the quasi-likelihood function, showing that only \(V(\mu)\) — not a full density — is needed to define a score equation with the same asymptotic properties as maximum likelihood. Peter McCullagh (1983) provided the rigorous theoretical foundation, coining the term and proving consistency and asymptotic normality without any distributional assumption beyond the mean-variance specification.

📐 The Quasi-Score

The quasi-score for a single observation, treating \(\mu\) as a function of linear predictor \(\eta = x^\top\beta\) via link \(g\):

$$U(\beta;\, y) = \frac{y - \mu}{\phi\, V(\mu)} \cdot \frac{d\mu}{d\eta} \cdot x$$

Summing over all \(n\) observations and setting to zero yields the quasi-likelihood estimating equations. The dispersion \(\phi\) cancels out of this equation — it does not affect \(\hat{\beta}\), only the variance of \(\hat{\beta}\).

🔑 Key Property — Consistency Without a Full Distribution

As long as the mean model \(E[Y_i] = \mu_i(\beta)\) is correctly specified (even if \(V(\mu)\) is wrong), the quasi-score estimating equations yield a consistent estimator of \(\beta\). This robustness is the core value proposition of quasi-likelihood over full GLM or maximum likelihood.

3
The Math — Quasi-Score & Dispersion
▼

Setup

Assume an independent sample \(y_1,\dots,y_n\) with mean \(\mu_i = g^{-1}(x_i^\top\beta)\) and variance \(\operatorname{Var}(Y_i) = \phi\, V(\mu_i)\), where \(g\) is the link function, \(\phi > 0\) is the (unknown) dispersion parameter, and \(V(\cdot)\) is the chosen variance function. No distributional form beyond these two moments is assumed.

The Quasi-Log-Likelihood

Wedderburn defined the quasi-log-likelihood contribution for observation \(i\) as:

$$Q(\mu_i;\, y_i) = \int_{y_i}^{\mu_i} \frac{y_i - t}{\phi\, V(t)}\, dt$$

This integral is constructed so that its derivative with respect to \(\mu\) equals \((y_i - \mu_i)/(\phi V(\mu_i))\) — exactly the score contribution of a genuine log-likelihood if the distribution were from the exponential family. The total quasi-score is:

$$U(\beta) = \sum_{i=1}^n \frac{\partial \mu_i}{\partial \beta} \cdot \frac{y_i - \mu_i}{\phi\, V(\mu_i)} = \frac{1}{\phi}\, X^\top D^\top W (y - \mu) = 0$$

where \(D = \operatorname{diag}\!\left(\frac{d\mu_i}{d\eta_i}\right)\), \(W = \operatorname{diag}\!\left(\frac{1}{V(\mu_i)}\right)\), and \(\eta_i = x_i^\top\beta\). Note \(\phi\) cancels — \(\hat\beta\) is found identically to the corresponding GLM.

Estimation via IRLS

The Newton-Raphson step for this score equation yields Iteratively Re-weighted Least Squares (IRLS). At each iteration, compute working weights \(w_i = \left(\frac{d\mu_i}{d\eta_i}\right)^2 / V(\mu_i)\) and working response \(z_i = \eta_i + (y_i - \mu_i) / (d\mu_i/d\eta_i)\), then solve the weighted least squares problem:

$$\hat\beta = (X^\top \tilde{W} X)^{-1} X^\top \tilde{W} z, \quad \tilde{W} = \operatorname{diag}(w_i)$$

Dispersion Estimation

After convergence, \(\hat\phi\) is estimated from Pearson residuals:

$$\hat\phi = \frac{1}{n - p}\sum_{i=1}^n \frac{(y_i - \hat\mu_i)^2}{V(\hat\mu_i)}$$

For quasi-Poisson (\(V(\mu)=\mu\)), this is the Pearson chi-squared statistic divided by its degrees of freedom. Values \(\hat\phi > 1\) signal overdispersion; \(\hat\phi < 1\) signal underdispersion.

Variance of \(\hat\beta\)

$$\operatorname{Var}(\hat\beta) = \hat\phi\, (X^\top \tilde{W} X)^{-1}$$

Standard errors are inflated (or deflated) by \(\sqrt{\hat\phi}\) relative to the plain GLM. This is the entire mechanism: same \(\hat\beta\), wider confidence intervals when overdispersed.

⚠️ Common Pitfall — Quasi ≠ Negative Binomial

Quasi-Poisson and Negative Binomial both handle overdispersed counts but differ crucially. Quasi-Poisson assumes \(\operatorname{Var}(Y) = \phi\mu\) (variance linear in mean); Negative Binomial assumes \(\operatorname{Var}(Y) = \mu + \mu^2/k\) (variance quadratic in mean for large \(\mu\)). For mildly overdispersed data they agree; for strongly overdispersed data they diverge. Quasi-Poisson gives no likelihood for model comparison (AIC undefined), while NB does.

Code Implementation
▼

From Scratch (NumPy) — IRLS for Quasi-Poisson

import numpy as np

def quasi_poisson_irls(X, y, max_iter=50, tol=1e-8):
    """Quasi-Poisson GLM via IRLS.

    V(mu) = mu  (Poisson variance function)
    Link: log   d(mu)/d(eta) = mu
    phi: estimated from Pearson chi-squared / (n - p)

    Returns: beta, phi_hat, se_poisson, se_quasi
    """
    n, p = X.shape
    # Initialize: use log(y+0.5) as starting eta
    beta = np.linalg.lstsq(X, np.log(y + 0.5), rcond=None)[0]

    for _ in range(max_iter):
        mu   = np.exp(X @ beta)          # fitted means
        dmu  = mu                         # d(mu)/d(eta) = mu (log link)
        W    = mu                         # working weights = dmu^2 / V(mu) = mu^2/mu = mu
        z    = np.log(mu) + (y - mu)/mu  # working response

        # Weighted least squares: (X' W X) beta = X' W z
        XtW  = X.T * W                   # shape (p, n)
        XtWX = XtW @ X                   # (p, p)
        XtWz = XtW @ z                   # (p,)
        beta_new = np.linalg.solve(XtWX, XtWz)

        if np.max(np.abs(beta_new - beta)) < tol:
            beta = beta_new
            break
        beta = beta_new

    mu_hat = np.exp(X @ beta)

    # Pearson chi-squared dispersion estimate
    pearson_chi2 = np.sum((y - mu_hat)**2 / mu_hat)
    phi_hat = pearson_chi2 / (n - p)     # ~1 = Poisson; >1 = overdispersed

    # Standard errors: plain Poisson vs quasi-Poisson
    XtWX_inv   = np.linalg.inv(XtWX)    # reuse last iteration weights
    se_poisson = np.sqrt(np.diag(XtWX_inv))
    se_quasi   = np.sqrt(phi_hat) * se_poisson  # inflate by sqrt(phi)

    return beta, phi_hat, se_poisson, se_quasi


# ── Worked example ────────────────────────────────────────────────────────────
X = np.column_stack([np.ones(5), [1., 2., 3., 4., 5.]])
y = np.array([2., 9., 8., 35., 28.])   # overdispersed counts

beta, phi, se_p, se_q = quasi_poisson_irls(X, y)
print(f"beta:       {beta}")          # [0.9367, 0.5313]
print(f"phi_hat:    {phi:.4f}")       # 4.629  (overdispersed)
print(f"SE_Poisson: {se_p}")          # [0.4864, 0.0923]
print(f"SE_Quasi:   {se_q}")          # [1.047,  0.1986]
print(f"SE inflation: sqrt(phi) = {phi**0.5:.4f}")   # 2.151x

Production Usage (R — glm / statsmodels)

# ── R ─────────────────────────────────────────────────────────────────────────
# Quasi-Poisson (same betas as Poisson; phi estimated from data)
fit_qp  <- glm(count ~ x1 + x2, data = df, family = quasipoisson(link = "log"))
summary(fit_qp)                  # phi shown in Dispersion parameter

# Quasi-Binomial for overdispersed proportions
fit_qb  <- glm(prop ~ x, data = df, family = quasibinomial(link = "logit"),
                weights = n_trials)

# Arbitrary variance function via quasi():
fit_cus <- glm(y ~ x, family = quasi(link = "log", variance = "mu^2"))

# ── Python (statsmodels) ──────────────────────────────────────────────────────
import statsmodels.api as sm

# quasi-Poisson
model = sm.GLM(y, X, family=sm.families.Poisson())
res   = model.fit(scale="X2")          # scale="X2" estimates phi via Pearson chi^2
# res.scale  => phi_hat
# res.bse    => quasi SEs (already inflated by sqrt(phi))

# quasi-Binomial
model_b = sm.GLM(y, X, family=sm.families.Binomial())
res_b   = model_b.fit(scale="X2")

# ⚠️ Gotcha: statsmodels' scale="dev" uses deviance not Pearson —
# use scale="X2" to match R's quasipoisson behaviour.
⚠️ No AIC for Quasi-Likelihood

Because no full log-likelihood exists, AIC and likelihood ratio tests are undefined for quasi-likelihood models. Use quasi-AIC (QAIC) for model comparison, or F-tests instead of chi-squared tests when comparing nested models. In R, anova(fit, test="F") instead of test="Chisq".

🎯 Decision Guide

Use Quasi-Poisson when: counts are overdispersed, overdispersion is roughly proportional to the mean (φ constant), and you don't need AIC-based model selection. Use Negative Binomial when overdispersion is severe and grows faster than linearly, or you need AIC. Use Quasi-Binomial for proportions from clustered designs where observations in the same cluster agree more than expected by chance.
