PDF, CDF, PMF — the geometry of probability

1
Understanding PDF & CDF
▼

What is it? When a random variable can take any value on a continuous range (height, temperature, time), you can't ask "what's the probability of being exactly 1.73 m?" — that probability is zero. Instead, probability lives in intervals. The probability density function (PDF) is the shape that tells you how probability is spread out; the cumulative distribution function (CDF) is the running total — it tells you how much probability has accumulated up to any point.

Analogy: Think of the PDF as the cross-section of a sandpile poured over a number line. Taller peaks = denser probability mass. The area under any stretch of the pile equals the probability of landing in that interval. The CDF is like a gauge that shows you the total sand to the left of any point — it starts at 0, rises as you move right, and reaches 1 at the far right.

💡 If you remember one thing

For a continuous random variable: \(P(a \le X \le b) = \int_a^b f(x)\,dx = F(b) - F(a)\). The PDF \(f(x)\) is the derivative of the CDF \(F(x)\). The PDF can exceed 1 — it is a density, not a probability. Area = probability, not height.

Why it matters for ML: Every likelihood function, every Gaussian prior, every KL divergence, every sampling algorithm rests on understanding PDFs and CDFs. The Gaussian PDF is the backbone of probabilistic modelling; the CDF and its inverse (quantile function) underlie hypothesis testing, confidence intervals, and inverse-transform sampling.

2
PDF vs CDF vs PMF — Internals
▼

PDF — Probability Density Function (Continuous)

For a continuous random variable \(X\), the PDF \(f:\mathbb{R}\to[0,\infty)\) satisfies:

  • \(f(x) \ge 0\) for all \(x\) — non-negative everywhere.
  • \(\int_{-\infty}^{\infty} f(x)\,dx = 1\) — total area = 1.
  • \(P(a \le X \le b) = \int_a^b f(x)\,dx\) — probability = area.

Crucially, \(f(x)\) is a density, not a probability. It can be any non-negative real number — including values greater than 1. For example, the Uniform distribution on \([0, 0.1]\) has \(f(x) = 10\) for \(x\in[0,0.1]\) (the area still integrates to 1).

CDF — Cumulative Distribution Function (Continuous)

The CDF is defined as the integral of the PDF from \(-\infty\) to \(x\):

$$F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)\,dt$$

The CDF has three guaranteed properties: (1) \(F\) is monotonically non-decreasing, (2) \(\lim_{x\to-\infty}F(x)=0\), (3) \(\lim_{x\to+\infty}F(x)=1\). By the Fundamental Theorem of Calculus, \(F'(x) = f(x)\) wherever \(f\) is continuous.

PMF — Probability Mass Function (Discrete)

For a discrete random variable (e.g., coin flips, die rolls), there is no density. Instead there is a probability mass function (PMF): \(p(k) = P(X = k)\), with \(\sum_k p(k) = 1\). The discrete CDF is a staircase: \(F(x) = \sum_{k \le x} p(k)\) — constant between integers, jumping at each support point.

🔑 Key Distinction

Continuous: PDF + area = probability; PDF can exceed 1.
Discrete: PMF value = probability; PMF ≤ 1 always.
Both: CDF is monotone, right-continuous, goes from 0 to 1.

The Quantile Function (Inverse CDF)

The quantile function \(Q(p) = F^{-1}(p)\) answers "what value \(x\) has exactly \(p\) of the probability below it?" It is the inverse of the CDF. For example, \(Q(0.95) = 1.645\) for the standard normal, meaning 95% of the distribution lies below 1.645. Quantiles underlie percentiles, confidence intervals, and inverse-transform sampling.

⚠️ Common Misconception

A PDF value of 2 does not mean "200% probability." It means the density is high there. Probability only comes from integrating the PDF over an interval. \(f(x_0) > 1\) is perfectly valid — check that \(\int f(x)\,dx = 1\), not that \(f(x) \le 1\).

The Math — Derivations & Key Properties
▼

The Normal Distribution: PDF and CDF

The Gaussian (Normal) \(\mathcal{N}(\mu, \sigma^2)\) is the most important continuous distribution:

$$f(x;\mu,\sigma) = \frac{1}{\sigma\sqrt{2\pi}}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

For the standard normal \(\mathcal{N}(0,1)\) the peak is \(f(0) = 1/\sqrt{2\pi} \approx 0.399 < 1\). With \(\sigma=0.1\) the peak is \(1/(0.1\sqrt{2\pi}) \approx 3.99 > 1\) — demonstrating that PDF values can exceed 1.

The CDF has no closed form and is expressed via the error function:

$$F(x) = \Phi\!\left(\frac{x-\mu}{\sigma}\right) = \frac{1}{2}\left[1 + \operatorname{erf}\!\left(\frac{x-\mu}{\sigma\sqrt{2}}\right)\right]$$

Interval Probability via the CDF

For any interval \([a, b]\):

$$P(a \le X \le b) = F(b) - F(a) = \int_a^b f(x)\,dx$$

Numerical examples for \(\mathcal{N}(0,1)\):

  • \(P(-1 \le X \le 1) = \Phi(1) - \Phi(-1) \approx 0.8413 - 0.1587 = 0.6827\) (the "68% rule")
  • \(P(-2 \le X \le 2) \approx 0.9772 - 0.0228 = 0.9545\) (the "95% rule")
  • \(P(X \le 1.645) \approx 0.9500\) (95th percentile)

Fundamental Theorem Link: \(F' = f\)

The Fundamental Theorem of Calculus guarantees that wherever \(f\) is continuous:

$$\frac{d}{dx}F(x) = f(x)$$

This is the deepest link between PDF and CDF — differentiation and integration are inverses. Graphically: the slope of the CDF curve at any point equals the height of the PDF curve there. Where the PDF is tallest (the mode), the CDF is steepest. Where the PDF is near zero (the tails), the CDF is nearly flat.

Properties of the CDF (any distribution)

PropertyFormal Statement
Right-continuous\(\lim_{x\to a^+} F(x) = F(a)\)
Monotone non-decreasing\(a \le b \Rightarrow F(a) \le F(b)\)
Boundary limits\(F(-\infty)=0,\; F(+\infty)=1\)
Probability of interval\(P(a < X \le b)=F(b)-F(a)\)
Complement\(P(X > a)=1-F(a)\)
📐 Inverse-Transform Sampling

To sample from any distribution with CDF \(F\): draw \(U \sim \text{Uniform}(0,1)\), return \(X = F^{-1}(U)\). Since \(P(F^{-1}(U) \le x) = P(U \le F(x)) = F(x)\), the result has the correct distribution. This is the mathematical foundation of random-number generators.

From Scratch — NumPy

import numpy as np
from scipy.special import erf # for the error function
# --- Standard Normal PDF ---
def normal_pdf(x, mu=0.0, sigma=1.0):
"""f(x) = 1/(σ√2π) · exp(−(x−μ)²/(2σ²))"""
z = (x - mu) / sigma # standardise
return np.exp(-0.5 * z**2) / (sigma * np.sqrt(2 * np.pi))
# --- Standard Normal CDF (via error function) ---
def normal_cdf(x, mu=0.0, sigma=1.0):
"""F(x) = (1/2)[1 + erf((x−μ)/(σ√2))]"""
return 0.5 * (1 + erf((x - mu) / (sigma * np.sqrt(2))))
# --- Interval probability ---
def P_interval(a, b, mu=0.0, sigma=1.0):
"""P(a ≤ X ≤ b) = F(b) − F(a)"""
return normal_cdf(b, mu, sigma) - normal_cdf(a, mu, sigma)
# --- Inverse CDF (quantile) via bisection ---
def normal_quantile(p, mu=0.0, sigma=1.0, tol=1e-8):
"""Q(p) = F⁻¹(p): find x such that F(x)=p"""
lo, hi = mu - 10*sigma, mu + 10*sigma
while hi - lo > tol:
mid = (lo + hi) / 2
(lo if normal_cdf(mid, mu, sigma) < p else hi).__class__ # dummy
if normal_cdf(mid, mu, sigma) < p: lo = mid
else: hi = mid
return (lo + hi) / 2
# --- Discrete: Binomial PMF and CDF ---
from math import comb
def binom_pmf(k, n, p): return comb(n,k) * p**k * (1-p)**(n-k)
def binom_cdf(x, n, p): return sum(binom_pmf(k,n,p) for k in range(int(x)+1))
# --- Inverse-transform sampling from any CDF ---
def inv_transform_sample(cdf_inv, n_samples):
"""Draw n_samples using U~Uniform(0,1), return cdf_inv(U)."""
U = np.random.uniform(0, 1, n_samples) # uniform draws
return np.array([cdf_inv(u) for u in U]) # apply Q = F⁻¹
# Example usage
print(normal_pdf(0)) # 0.3989 — peak of N(0,1)
print(normal_pdf(0, sigma=0.1)) # 3.989 — PDF > 1 for narrow dist!
print(P_interval(-1, 1)) # 0.6827 — 68% rule
print(normal_quantile(0.95)) # 1.6449 — 95th percentile
print(binom_cdf(2, n=5, p=0.5)) # 0.5 — median of B(5,0.5)

Production Usage — SciPy

from scipy import stats
import numpy as np
# --- Continuous: Normal distribution ---
dist = stats.norm(loc=0, scale=1) # N(μ=0, σ=1)
x = np.linspace(-4, 4, 200)
pdf_vals = dist.pdf(x) # PDF values
cdf_vals = dist.cdf(x) # CDF values
p_68 = dist.cdf(1) - dist.cdf(-1) # 0.6827: 68% rule
q95 = dist.ppf(0.95) # 1.6449: 95th percentile (ppf = percent-point fn = Q)
samples = dist.rvs(size=1000) # 1000 random samples
# ⚠️ Gotcha: ppf is the quantile (inverse CDF), not pdf!
# dist.ppf(0.5) == 0.0 (median) ✓
# dist.pdf(0.5) == 0.352 (density at x=0.5) ✓
# --- Discrete: Binomial ---
binom = stats.binom(n=5, p=0.5)
print(binom.pmf(2)) # 0.3125: P(X=2)
print(binom.cdf(2)) # 0.5000: P(X≤2)
print(binom.ppf(0.5)) # 2.0: median (smallest k with CDF≥0.5)
# --- KDE: empirical PDF from data ---
data = np.random.randn(500)
kde = stats.gaussian_kde(data) # kernel density estimate
pdf_empirical = kde(x) # evaluate empirical PDF
# Empirical CDF
from statsmodels.distributions.empirical_distribution import ECDF
ecdf = ECDF(data)
cdf_empirical = ecdf(x)

💡 5 Things to Lock In
  1. PDF can exceed 1 — it is a density, not a probability. Probability = area.
  2. CDF is always monotone non-decreasing, going from 0 to 1.
  3. \(F'(x) = f(x)\) everywhere \(f\) is continuous — derivative of CDF = PDF.
  4. \(P(a\le X\le b)=F(b)-F(a)\) — the CDF subtraction rule for intervals.
  5. Inverse-transform sampling: draw \(U\sim\text{Uniform}(0,1)\), return \(F^{-1}(U)\).

Where This Shows Up in ML

  • Likelihood functions: the Gaussian PDF is the backbone of linear regression (probabilistic form), Gaussian processes, and VAEs.
  • Hypothesis testing: p-values are CDF evaluations; confidence intervals use quantiles.
  • KL divergence / entropy: both defined as integrals of the PDF.
  • Normalising flows: explicitly learn an invertible CDF transformation.
  • Quantile regression: directly models \(Q(p|x)\) instead of the mean.
