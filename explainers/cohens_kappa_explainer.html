Understanding Cohen's Kappa
▾

Imagine two doctors independently diagnosing the same 100 patients as either "diabetic" or "healthy." If they agree on 80 patients, naïve accuracy says 80% agreement — but what if both doctors simply guessed "diabetic" for everyone? They'd still agree 100% of the time by pure accident. Cohen's Kappa corrects for this chance agreement, asking: how much better than random are two raters?

Key Concept

Cohen's Kappa \(\kappa\) measures agreement between two raters after removing the agreement we'd expect purely by chance. A \(\kappa\) of 0 means no better than chance; 1 means perfect agreement; negative values mean worse than chance.

The formula is elegantly simple: \(\kappa = \frac{p_o - p_e}{1 - p_e}\), where \(p_o\) is the observed agreement (fraction of items both raters agree on) and \(p_e\) is the expected agreement by chance (what agreement we'd predict if both raters assigned labels independently at their known base rates).

Analogy

Think of a coin-flip guessing game. You and a friend each flip a coin independently and write "Heads" or "Tails." By pure chance you'll match 50% of the time. If you actually match 75% of the time, your observed advantage over chance is 25 points out of a possible 50 more points — giving \(\kappa = 0.5\). Raw accuracy would say 75%, but Kappa reveals you're only halfway to perfect, beyond chance.

💡 If you remember one thing

Kappa = (observed agreement − chance agreement) / (1 − chance agreement). It's the fraction of possible improvement over chance that was actually achieved. Raw accuracy ignores class imbalance; Kappa does not.

How It Works — Step by Step
▾

Step 1 — Build the Confusion Matrix

For \(k\) classes, build a \(k \times k\) matrix \(\mathbf{C}\) where \(C_{ij}\) counts items rated as class \(i\) by Rater A and class \(j\) by Rater B. Diagonal entries are agreements; off-diagonal are disagreements.

Step 2 — Compute Observed Agreement \(p_o\)

$$p_o = \frac{\sum_i C_{ii}}{N}$$

Sum the diagonal (agreements) and divide by total items \(N\). This is simply accuracy.

Step 3 — Compute Expected Agreement \(p_e\)

For each class \(i\), the probability that both raters independently pick class \(i\) by chance is the product of their marginal proportions:

$$p_e = \sum_{i=1}^{k} \left(\frac{\sum_j C_{ij}}{N}\right)\left(\frac{\sum_j C_{ji}}{N}\right)$$

That is: (row sum of class \(i\)) × (column sum of class \(i\)) / \(N^2\), summed over all classes.

Step 4 — Compute Kappa

$$\kappa = \frac{p_o - p_e}{1 - p_e}$$
⚠ Common Mistake

"Just use accuracy when classes are balanced." Even with balanced classes, high accuracy can coexist with low Kappa if the raters have systematic biases in which cases they agree on. Kappa catches this; accuracy does not.

Numerical Example (Binary, 2×2)

Suppose two annotators label 100 images as Cat or Dog:

3
The Math — Derivation & Properties
▾

General \(k\)-class formulation

Let \(\mathbf{C} \in \mathbb{Z}_{\geq 0}^{k \times k}\) be the confusion matrix, \(N = \sum_{ij} C_{ij}\) the total count, \(a_i = \sum_j C_{ij}/N\) the row proportions (Rater A marginals), and \(b_j = \sum_i C_{ij}/N\) the column proportions (Rater B marginals).

$$p_o = \sum_{i=1}^{k} C_{ii}/N, \qquad p_e = \sum_{i=1}^{k} a_i b_i$$
$$\boxed{\kappa = \frac{p_o - p_e}{1 - p_e}}$$

Boundary Conditions

Mathematical Properties

• \(\kappa = 1\) iff \(p_o = 1\) (perfect agreement)
• \(\kappa = 0\) iff \(p_o = p_e\) (agreement at chance level)
• \(\kappa < 0\) iff \(p_o < p_e\) (systematic disagreement, worse than chance)
• \(\kappa \leq 1\) always (from \(p_e \leq 1\) and \(p_o \leq 1\))
• \(\kappa \rightarrow -\infty\) not possible since \(\kappa \geq \frac{-p_e}{1-p_e}\) (minimum at \(p_o=0\))

Standard Error & Significance

Large-sample asymptotic standard error (Fleiss 1969):

$$\text{SE}(\kappa) \approx \frac{1}{\sqrt{N}} \sqrt{\frac{p_e + p_e^2 - \sum_i a_i b_i (a_i + b_i)}{(1-p_e)^2}}$$

A 95% confidence interval is \(\kappa \pm 1.96 \cdot \text{SE}(\kappa)\). Test \(H_0: \kappa=0\) with \(z = \kappa / \text{SE}(\kappa)\).

Weighted Kappa

For ordinal categories (e.g., severity 1–5), not all disagreements are equally bad. Weighted Kappa uses a weight matrix \(w_{ij}\):

$$\kappa_w = 1 - \frac{\sum_{ij} w_{ij} C_{ij}/N}{\sum_{ij} w_{ij} a_i b_j}$$

Common choices: linear weights \(w_{ij}=|i-j|/(k-1)\), quadratic weights \(w_{ij}=(i-j)^2/(k-1)^2\). With quadratic weights on 2-class, \(\kappa_w\) equals the intraclass correlation coefficient (ICC).

Relationship to \(F_1\)

For binary classification: \(\kappa = \frac{2 \cdot \text{TP}}{2\cdot\text{TP} + \text{FP} + \text{FN}} \cdot \frac{1}{\text{(balanced case)}}\). Not identical to \(F_1\), but highly correlated in practice. Unlike \(F_1\), Kappa is symmetric between classes.

Interpretation Bands & When to Use
▾

Landis & Koch (1977) Benchmark Scale

κ ≤ 0 — Poor — worse than or equal to chance. Something is systematically wrong.
0.01 – 0.20 — Slight — barely better than chance. Annotation guidelines unclear.
0.21 – 0.40 — Fair — meaningful but low. Revisit task definition or rater training.
0.41 – 0.60 — Moderate — acceptable for exploratory or low-stakes tasks.
0.61 – 0.80 — Substantial — solid agreement; acceptable for most ML training data.
0.81 – 1.00 — Almost Perfect — high-quality annotation; benchmark gold standard.
⚠ Kappa's Known Limitations

Kappa paradoxes (Feinstein & Cicchetti 1990): Two scenarios can have identical Kappa despite very different raw agreements, when prevalence and bias differ. Specifically, high prevalence of one class inflates \(p_e\), deflating Kappa — making two highly agreeing raters look unreliable. Always report both raw accuracy and Kappa.

Decision Guide

Use Kappa when: comparing two raters / a classifier vs. ground truth, categorical labels, class imbalance exists.
Use Weighted Kappa when: ordinal categories (Likert scales, severity grades).
Use Krippendorff's α when: 3+ raters or missing annotations.
Use MCC when: extreme binary imbalance (fraud, rare disease).
Use ICC when: continuous ratings (quality scores).

Code — From Scratch & Production
▾

From Scratch (NumPy)

import numpy as np

def cohens_kappa(y_true, y_pred, weights=None):
    """
    Compute Cohen's Kappa (unweighted or weighted).

    Args:
        y_true  : array of true labels (ints 0..k-1)
        y_pred  : array of predicted/rater-B labels
        weights : None | 'linear' | 'quadratic'
    Returns:
        kappa   : float
    """
    classes = np.unique(np.concatenate([y_true, y_pred]))
    k = len(classes)
    idx = {c: i for i, c in enumerate(classes)}
    N = len(y_true)

    # Build confusion matrix
    C = np.zeros((k, k), dtype=float)
    for a, b in zip(y_true, y_pred):
        C[idx[a], idx[b]] += 1

    # Marginals
    row_sums = C.sum(axis=1)   # Rater A marginals
    col_sums = C.sum(axis=0)   # Rater B marginals

    # Weight matrix
    if weights is None:
        W = np.eye(k)  # unweighted: only diagonal counts
    elif weights == 'linear':
        W = 1 - np.abs(np.subtract.outer(np.arange(k), np.arange(k))) / (k - 1)
    elif weights == 'quadratic':
        W = 1 - (np.subtract.outer(np.arange(k), np.arange(k)) ** 2) / (k - 1) ** 2

    # p_o = weighted observed agreement
    p_o = np.sum(W * C) / N

    # p_e = weighted expected agreement
    # Expected cell counts under independence: (row_i * col_j) / N
    expected = np.outer(row_sums, col_sums) / N
    p_e = np.sum(W * expected) / N

    if 1 - p_e == 0:
        return 1.0  # perfect agreement, no chance variation possible

    kappa = (p_o - p_e) / (1 - p_e)
    return kappa

# Example
y_true = [0]*40 + [1]*10 + [0]*15 + [1]*35  # flatten: 40 TT, 10 FN, 15 FP, 35 FF
y_pred = [0]*40 + [0]*10 + [1]*15 + [1]*35
print(f"Kappa = {cohens_kappa(y_true, y_pred):.4f}")  # 0.5000

Production (scikit-learn)

from sklearn.metrics import cohen_kappa_score, confusion_matrix

y_true = [2, 0, 2, 2, 0, 1, 2, 1, 0, 1]
y_pred = [0, 0, 2, 2, 0, 2, 2, 1, 0, 1]

# Unweighted (categorical)
kappa = cohen_kappa_score(y_true, y_pred)
print(f"Kappa (unweighted): {kappa:.4f}")

# Weighted (ordinal / Likert scales)
kappa_lin = cohen_kappa_score(y_true, y_pred, weights='linear')
kappa_quad = cohen_kappa_score(y_true, y_pred, weights='quadratic')
print(f"Kappa (linear):     {kappa_lin:.4f}")
print(f"Kappa (quadratic):  {kappa_quad:.4f}")

# ⚠ Gotcha: cohen_kappa_score expects integer or string labels.
#   If labels are floats, cast first: y.astype(int)
# ⚠ Gotcha: both arrays must have the same label set;
#   use labels= param if one rater never uses a class:
kappa_safe = cohen_kappa_score(y_true, y_pred, labels=[0,1,2])
