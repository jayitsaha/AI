Generalized Least Squares (GLS)

Regression when errors are correlated or have unequal variance
Foundational Classical ML Stats O(n³) solve
1
Understanding GLS
▼

What is it? Ordinary Least Squares (OLS) assumes all data points are equally reliable and their errors are independent. In reality, some measurements are noisier than others, and errors can be correlated (e.g., time-series data where today's error is related to yesterday's). GLS fixes this by accounting for the covariance structure of the errors.

Analogy: Imagine you're averaging reviews from two critics. One is precise and consistent, the other is wildly unpredictable. OLS treats them equally. GLS says: "I'll trust the precise critic more and discount the erratic one." If the critics also copy each other's opinions (correlated errors), GLS accounts for that too.

💡 If you remember one thing

GLS transforms the data so that the errors become well-behaved (uncorrelated, equal variance), then applies OLS to the transformed data. The formula: $$\hat{\beta}_{GLS} = (X^\top \Omega^{-1} X)^{-1} X^\top \Omega^{-1} y$$ where \(\Omega\) is the error covariance matrix.

2
How GLS Works Internally
▼

The Problem with OLS

The linear model is \(y = X\beta + \varepsilon\), where \(\varepsilon \sim \mathcal{N}(0, \sigma^2 \Omega)\). OLS assumes \(\Omega = I\) (identity). When \(\Omega \neq I\), OLS estimates are still unbiased but no longer efficient — they have larger variance than necessary, and standard errors are wrong, making hypothesis tests unreliable.

The GLS Solution: Transform Then Solve

Since \(\Omega\) is symmetric positive-definite, it has a Cholesky decomposition: \(\Omega = LL^\top\). Define \(P = L^{-1}\). Premultiply the entire model by \(P\):

$$Py = PX\beta + P\varepsilon \implies y^* = X^*\beta + \varepsilon^* \quad \text{where } \operatorname{Var}(\varepsilon^*) = \sigma^2 I$$

Now \(\varepsilon^*\) has identity covariance — OLS on \((y^*, X^*)\) is BLUE (Best Linear Unbiased Estimator) by Gauss-Markov. This yields:

$$\hat{\beta}_{GLS} = (X^\top \Omega^{-1} X)^{-1} X^\top \Omega^{-1} y$$

Design Decision: Why \(\Omega^{-1}\) and not just weights?

Weighted Least Squares (WLS) is a special case where \(\Omega\) is diagonal — only unequal variances, no correlation. GLS generalizes to arbitrary covariance, handling both heteroscedasticity AND autocorrelation in one framework. The off-diagonal elements of \(\Omega\) capture error correlations.

🔑 Key Property

GLS is the maximum likelihood estimator under Gaussian errors with known covariance \(\Omega\). Equivalently, it is the BLUE — the minimum-variance linear unbiased estimator — by the generalized Gauss-Markov theorem.

3
Why It Works — The Math
▼

Derivation from Weighted Minimization

GLS minimizes the generalized sum of squares:

$$S(\beta) = (y - X\beta)^\top \Omega^{-1} (y - X\beta)$$

Taking the derivative and setting to zero:

$$\frac{\partial S}{\partial \beta} = -2X^\top \Omega^{-1}(y - X\beta) = 0 \implies X^\top \Omega^{-1} X \beta = X^\top \Omega^{-1} y$$

Solving (assuming \(X^\top \Omega^{-1} X\) is invertible):

$$\hat{\beta}_{GLS} = (X^\top \Omega^{-1} X)^{-1} X^\top \Omega^{-1} y$$

Variance of the GLS Estimator

$$\operatorname{Var}(\hat{\beta}_{GLS}) = \sigma^2 (X^\top \Omega^{-1} X)^{-1}$$

This is smaller (in the matrix sense) than the OLS variance \(\operatorname{Var}(\hat{\beta}_{OLS}) = \sigma^2 (X^\top X)^{-1} X^\top \Omega X (X^\top X)^{-1}\), which is the "sandwich" estimator. GLS achieves the Cramér-Rao lower bound.

⚠️ Common Pitfall

GLS requires knowing \(\Omega\). In practice, \(\Omega\) is unknown and must be estimated — this gives Feasible GLS (FGLS). FGLS is not exactly BLUE, but is asymptotically efficient. If \(\Omega\) is badly estimated, FGLS can be worse than OLS!

Key Takeaways
▼

When to use GLS:

  • Errors have unequal variance (heteroscedasticity) — e.g., variance grows with x
  • Errors are correlated — e.g., time-series with AR(1) structure
  • Spatial data with distance-based correlation
  • Repeated measures / panel data

When NOT to use:

  • Errors are already well-behaved (iid) — OLS is simpler and equally efficient
  • Ω is unknown and sample is too small to estimate reliably — use OLS with robust standard errors instead
  • Nonlinear relationships — GLS won't fix model misspecification
💡 Hierarchy

OLS (\(\Omega = I\)) ⊂ WLS (\(\Omega\) diagonal) ⊂ GLS (\(\Omega\) arbitrary PD). Each generalizes the previous by relaxing assumptions on the error structure.

Code Trace
▼
import numpy as np
# Data: 4 observations, 2 features + intercept
X = np.array([[1, 1.0, 0.5],
[1, 2.0, 1.5],
[1, 3.0, 2.0],
[1, 4.0, 3.5]])
y = np.array([2.1, 4.8, 5.9, 11.2])
# Error covariance (known or estimated)
Omega = np.array([[1.0, 0.5, 0.0, 0.0],
[0.5, 2.0, 0.3, 0.0],
[0.0, 0.3, 3.0, 0.7],
[0.0, 0.0, 0.7, 4.0]])
# GLS via Cholesky
L = np.linalg.cholesky(Omega)
P = np.linalg.inv(L) # P = L⁻¹
X_star = P @ X # transformed X
y_star = P @ y # transformed y
# OLS on transformed data = GLS
beta_gls = np.linalg.lstsq(X_star, y_star, rcond=None)[0]
# Direct formula (equivalent)
Omega_inv = np.linalg.inv(Omega)
beta_direct = np.linalg.inv(X.T @ Omega_inv @ X) @ X.T @ Omega_inv @ y
# Compare with OLS
beta_ols = np.linalg.lstsq(X, y, rcond=None)[0]
print(f"GLS: {beta_gls}") # More efficient
print(f"OLS: {beta_ols}") # Still unbiased
