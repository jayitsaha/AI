Understanding Linear Programming
▼

What is it? Linear Programming (LP) is the art of finding the best outcome — maximum profit, minimum cost, shortest path — when both the goal and the constraints can be written as straight-line (linear) equations. The "feasible region" of all legal solutions forms a geometric shape called a polytope (a polygon in 2D, a polyhedron in higher dimensions). The fundamental theorem of LP says: if an optimum exists, it lies at a corner (vertex) of the polytope.

Analogy: Imagine a factory making two products A and B, each needing machine time and raw materials. You can't exceed the machine hours or material supply (constraints), and you want to maximize profit (objective). Plot all legal combinations on graph paper — they form a polygon. The maximum profit is always at one of the corners. The simplex method is a systematic recipe to hop from corner to corner, always improving profit, until no better corner exists.

If you remember one thing

The optimum of an LP is always at a vertex of the feasible polytope. The simplex method exploits this by moving along edges from vertex to vertex, improving the objective each step, until no improving neighbor exists. LP duality says: for every maximization LP there is a paired minimization LP with the same optimal value (strong duality).

How the Simplex Method Works Internally
▼

Standard Form and Slack Variables

Every LP can be written in standard form: maximize \(\mathbf{c}^\top \mathbf{x}\) subject to \(A\mathbf{x} \leq \mathbf{b}\), \(\mathbf{x} \geq \mathbf{0}\). Converting to equality form by adding slack variables \(\mathbf{s} \geq 0\) gives \(A\mathbf{x} + I\mathbf{s} = \mathbf{b}\). Each vertex of the polytope corresponds to a basic feasible solution (BFS): exactly \(m\) variables are "basic" (nonzero) and the rest are zero.

Three-Step Simplex Iteration

At each step, the simplex method:

  1. Choose entering variable: Find a non-basic variable with a positive reduced cost \(\bar{c}_j = c_j - \mathbf{c}_B^\top B^{-1} A_j > 0\). (Most-positive-reduced-cost or Bland's rule.)
  2. Min-ratio test (leaving variable): Among basic variables, find the one that hits zero first as the entering variable increases — this prevents leaving the feasible region. Ratio \(= \bar{b}_i / \bar{a}_{ij}\) for \(\bar{a}_{ij} > 0\).
  3. Pivot: Perform a row reduction (Gaussian elimination step) that swaps entering and leaving variables in the basis, updating the tableau.
Key Property — Why vertices are enough

A linear objective \(\mathbf{c}^\top \mathbf{x}\) is convex (and concave). On a convex polytope, the maximum of a convex function is attained at an extreme point (vertex). So we only need to check vertices — and there are finitely many of them, making simplex well-defined.

Numerical Trace on Our Example

LP: maximize \(3x_1 + 5x_2\) subject to \(2x_1+x_2 \leq 12\), \(x_1+2x_2 \leq 10\), \(x_1+x_2 \leq 7\), \(x_1,x_2 \geq 0\).

Add slacks \(s_1,s_2,s_3\). Initial BFS: \((x_1,x_2)=(0,0)\), basis \(\{s_1,s_2,s_3\}\), objective = 0.

  • Pivot 1: Largest reduced cost is 5 (for \(x_2\)). Min-ratio test: \(12/1=12\), \(10/2=5^*\), \(7/1=7\). Leaving variable: \(s_2\). New BFS: \((0,5)\), obj = 25.
  • Pivot 2: Reduced cost for \(x_1\) is \(0.5 > 0\). Min-ratio on updated tableau: \(7/1.5 \approx 4.67\), \(5/0.5=10\), \(2/0.5=4^*\). Leaving variable: \(s_3\). New BFS: \((4,3)\), obj = 27.
  • Optimal: All reduced costs \(\leq 0\). Optimum is \(\mathbf{x}^* = (4,3)\), \(z^* = 27\).

LP Duality — The Mirror Optimization
▼

Constructing the Dual

Every LP (the primal) has a paired dual LP. For the primal: maximize \(\mathbf{c}^\top \mathbf{x}\), \(A\mathbf{x} \leq \mathbf{b}\), \(\mathbf{x} \geq \mathbf{0}\), the dual is: minimize \(\mathbf{b}^\top \mathbf{y}\), \(A^\top \mathbf{y} \geq \mathbf{c}\), \(\mathbf{y} \geq \mathbf{0}\).

The dual variable \(y_i\) is the shadow price of the \(i\)-th constraint — how much the optimal objective increases per unit of additional resource \(b_i\). Our example dual: minimize \(12y_1 + 10y_2 + 7y_3\) subject to \(2y_1+y_2+y_3 \geq 3\), \(y_1+2y_2+y_3 \geq 5\), \(\mathbf{y} \geq \mathbf{0}\).

$$\text{Weak duality: } \mathbf{c}^\top \mathbf{x} \leq \mathbf{b}^\top \mathbf{y} \quad \text{for all primal feasible } \mathbf{x} \text{ and dual feasible } \mathbf{y}$$
$$\text{Strong duality (LP): } \max_{\mathbf{x}} \mathbf{c}^\top \mathbf{x} = \min_{\mathbf{y}} \mathbf{b}^\top \mathbf{y}$$

Complementary Slackness

At optimality, complementary slackness links primal and dual: for each constraint \(i\), either the primal constraint is tight (\(a_i^\top \mathbf{x}^* = b_i\)) or the dual variable is zero (\(y_i^* = 0\)), and vice versa. This gives us the dual solution directly from the primal:

At \(\mathbf{x}^*=(4,3)\): constraint 1 has slack 1, so \(y_1^*=0\). Constraints 2 and 3 are tight (\(4+6=10\), \(4+3=7\)). Solve \(y_2+y_3=3\), \(2y_2+y_3=5\): \(\mathbf{y}^*=(0,2,1)\), dual obj = \(10{\cdot}2+7{\cdot}1=27\). Strong duality confirmed.

Common misconception

Strong duality holds for LP always (under feasibility). For general nonlinear or integer programs it does NOT hold — there can be a "duality gap." LP's special structure (polyhedral feasible set + linear objective) guarantees zero duality gap. This is one of LP's most powerful properties and is the basis for interior-point method convergence proofs.

Key Takeaways & When to Use LP
▼

When LP is the right tool:

  • Objective and all constraints are linear in the decision variables
  • Variables are continuous (not integer — use ILP/MIP for integers)
  • Problems: resource allocation, transportation, diet, network flow, support-vector machines (hard-margin SVM is an LP in dual form)

Complexity nuances:

  • Simplex runs in exponential worst-case (Klee-Minty cube), but is polynomial in practice
  • Interior-point methods (Karmarkar 1984) are provably polynomial in theory
  • Modern solvers (Gurobi, CPLEX) use primal simplex + dual simplex + barrier in hybrid
LP in ML

LP appears throughout ML: L1 regularization is an LP (via variable splitting), the Wasserstein distance (earth mover's) is an LP, linear SVM dualizes to a QP, and LP relaxations of integer programs are used for MAP inference in graphical models and combinatorial optimization.

Code Trace — Simplex from Scratch
▼
import numpy as np
from scipy.optimize import linprog
# ── Primal LP: max 3x1+5x2 s.t. Ax<=b, x>=0 ──
c = np.array([-3, -5]) # negate for linprog (minimizes)
A = np.array([[2,1],[1,2],[1,1]])
b = np.array([12., 10., 7.])
# ── Solve primal ──
res = linprog(c, A_ub=A, b_ub=b, bounds=[(0,None),(0,None)])
print(f"x* = {res.x}") # [4. 3.]
print(f"z* = {-res.fun}") # 27.0
# ── Dual solution from complementary slackness ──
# At x*=(4,3): constraints 2,3 active => y1=0
# y2 + y3 = 3 (from dual col x1)
# 2*y2 + y3 = 5 (from dual col x2)
A_dual = np.array([[1,1],[2,1]])
b_dual = np.array([3., 5.])
y23 = np.linalg.solve(A_dual, b_dual)
y_star = np.array([0., y23[0], y23[1]]) # [0, 2, 1]
print(f"y* = {y_star}") # [0. 2. 1.]
print(f"dual obj = {b @ y_star}") # 27.0 (strong duality!)
# ── Shadow prices: meaning ──
# y2=2: 1 extra unit of resource 2 (machine hours) => +2 profit
# y3=1: 1 extra unit of resource 3 (materials) => +1 profit
# y1=0: constraint 1 not binding (slack=1), no gain from relaxing it
