Part V — Deep Learning · Activation Functions

Tanh: zero-centered, still saturates

The hyperbolic tangent squashes any real number into (−1, 1), fixing sigmoid's zero-mean problem — but it inherits the same flat-gradient curse at the extremes.

Foundational Activation Function O(1) per element
1
Understanding the Concept
▾

What it is: tanh takes any real number and squeezes it into the range \((-1, 1)\), the same way sigmoid squeezes into \((0,1)\) — except tanh's output is centered on zero instead of on 0.5.

Analogy: think of sigmoid as a thermostat that only reports "how hot" on a scale of 0 to 1 — it can never say "cold." Tanh is the same thermostat rewired to report on a scale of −1 (cold) to +1 (hot), with 0 meaning "neutral." That extra ability to go negative is exactly what a neural network needs: activations that can push a downstream neuron's input up or down, not just up.

One-sentence summary: tanh is sigmoid's zero-centered sibling — same S-shape, same saturation problem, better gradient flow through stacked layers.

If you remember one thing

tanh(x) = 2·sigmoid(2x) − 1. It's a rescaled, shifted sigmoid — zero-centered output helps optimization, but the curve still flattens to (almost) zero slope for \(|x| > 3\), so gradients still vanish in deep stacks.

2
Why This Exists — and How It Works Internally
▾

The problem with sigmoid: in a network using sigmoid activations, every layer's output is strictly positive (between 0 and 1). That means the input to the next layer's weights is always positive, so the gradient of the loss with respect to every weight in that layer shares the same sign. The weight-update direction gets "zig-zag" constrained — all weights in a layer can only move up together or down together on a given step, which slows convergence. This was documented and analyzed as far back as LeCun et al.'s 1998 "Efficient BackProp."

The fix: center the activation on zero. Since tanh(x) is an odd function — tanh(−x) = −tanh(x) — its outputs are symmetric around 0, roughly half positive and half negative for typically-distributed inputs. That removes the systematic sign bias in gradients passed to the next layer, giving smoother, faster optimization than sigmoid in practice — which is why tanh was the default hidden-unit nonlinearity in RNNs, LSTMs, and early feedforward nets for years before ReLU took over.

Internally: tanh is computed from exponentials:

$$\tanh(x) = \frac{e^{x} - e^{-x}}{e^{x} + e^{-x}}$$

Numerically: at \(x=0\), \(e^0 - e^0 = 0\) so tanh(0) = 0 exactly. At \(x=2\): \(e^2 \approx 7.389\), \(e^{-2}\approx 0.135\), giving \(\tanh(2) = (7.389-0.135)/(7.389+0.135) \approx 0.964\) — already 96% of the way to saturation. At \(x=4\), tanh(4) ≈ 0.9993 — for all practical purposes the neuron is "stuck," and its local gradient is close to zero.

Design decision: why not just shift sigmoid?

You could use \(2\sigma(x) - 1\) instead — same range, same zero-centering. But tanh's specific scaling (\(2\sigma(2x)-1\)) gives it a steeper slope near the origin (max derivative = 1, vs sigmoid's max derivative of 0.25), so gradients are 4× stronger where it matters most — near zero, before saturation sets in.

3
The Math — Derivative & the Sigmoid Relation
▾

Relation to sigmoid. Starting from \(\sigma(x) = \frac{1}{1+e^{-x}}\), substitute and simplify:

$$\tanh(x) = 2\,\sigma(2x) - 1$$

Proof sketch: \(2\sigma(2x)-1 = \frac{2}{1+e^{-2x}} - 1 = \frac{2-(1+e^{-2x})}{1+e^{-2x}} = \frac{1-e^{-2x}}{1+e^{-2x}}\). Multiply numerator and denominator by \(e^{x}\): \(\frac{e^{x}-e^{-x}}{e^{x}+e^{-x}} = \tanh(x)\). ∎

The derivative. Using the quotient rule on \(e^x - e^{-x}\) over \(e^x+e^{-x}\), or more cleanly via \(1 - \tanh^2\):

$$\frac{d}{dx}\tanh(x) = 1 - \tanh^2(x)$$

Derivation: let \(u = e^x - e^{-x}\), \(v = e^x+e^{-x}\), so \(\tanh = u/v\). Then \(u' = v\) and \(v' = u\). Quotient rule: \(\tanh' = \frac{u'v - uv'}{v^2} = \frac{v^2 - u^2}{v^2} = 1 - \frac{u^2}{v^2} = 1-\tanh^2(x)\).

This derivative peaks at exactly 1.0 when \(x=0\) (since tanh(0)=0), compared to sigmoid's derivative \(\sigma(x)(1-\sigma(x))\) which peaks at only 0.25 at \(x=0\). But as \(|x|\) grows, \(\tanh(x) \to \pm1\), so \(1-\tanh^2(x) \to 0\) — the gradient vanishes just as it does for sigmoid, just from a higher peak.

The core invariant

\(\tanh\) trades sigmoid's asymmetric output for a symmetric one and a 4× steeper gradient near zero — but the saturation ceiling is structurally identical: both functions are bounded, monotonic S-curves whose derivative → 0 as \(|x|\to\infty\). Zero-centering fixes the bias problem; it does not fix the vanishing-gradient problem.

Key Takeaways
▾
  • Zero-centered output removes the systematic positive-gradient bias that slows sigmoid-based networks down.
  • Steeper near zero: max derivative of 1.0 vs sigmoid's 0.25 — four times the gradient signal where inputs are small.
  • Still saturates: for \(|x| \gtrsim 3\), \(1-\tanh^2(x) < 0.01\) — deep stacks of tanh layers still suffer vanishing gradients, which is exactly why ReLU-family activations displaced it for feedforward/CNN hidden layers.
  • Still standard where boundedness matters: LSTM/GRU gate outputs and cell-state squashing still use tanh precisely because its bounded, zero-centered range keeps hidden states numerically stable across many timesteps.
When to reach for tanh

Use tanh when you need a bounded, zero-centered signal (RNN/LSTM internal states, normalized outputs in \((-1,1)\)). Prefer ReLU/GELU for deep feedforward or convolutional hidden layers, where unbounded positive activations and cheap gradients matter more than zero-centering.
