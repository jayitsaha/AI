Mean Value Theorem & L'Hôpital's Rule

Two cornerstone tools of single-variable calculus — one guarantees a parallel tangent, the other resolves indeterminate limits.

Understanding the Concepts
▾

The Mean Value Theorem (MVT)

Imagine driving from city A to city B, a distance of 120 miles, in exactly 2 hours. Your average speed is 60 mph. The MVT says there must exist at least one instant during the trip when your speedometer read exactly 60 mph — your average speed. No matter how you accelerated or braked, that instant had to exist.

Formally: if \(f\) is continuous on \([a,b]\) and differentiable on \((a,b)\), there exists \(c \in (a,b)\) such that the instantaneous slope \(f'(c)\) equals the average slope (the secant slope) \(\tfrac{f(b)-f(a)}{b-a}\).

$$f'(c) = \frac{f(b) - f(a)}{b - a}$$
Key Insight — MVT

The tangent line at \(c\) is exactly parallel to the secant line through \((a, f(a))\) and \((b, f(b))\). They have the same slope.

L'Hôpital's Rule

Some limits produce "0/0" or "∞/∞" — fractions where both numerator and denominator vanish (or blow up) simultaneously. These are called indeterminate forms: we cannot simply plug in the limit point. L'Hôpital's rule resolves them by replacing the ratio of functions with the ratio of their derivatives.

$$\lim_{x \to a} \frac{f(x)}{g(x)} \;=\; \lim_{x \to a} \frac{f'(x)}{g'(x)} \quad \text{when the form is } \tfrac{0}{0} \text{ or } \tfrac{\infty}{\infty}$$
Key Concept — L'Hôpital

Differentiate numerator and denominator separately (not the quotient rule). Repeat if the new limit is still indeterminate.

Common Pitfall

L'Hôpital only applies when the limit form is genuinely \(0/0\) or \(\pm\infty/\infty\). Applying it to a determinate form (e.g., \(3/5\)) gives a wrong answer.

How They Work — Internal Mechanics
▾

MVT: Rolle's Theorem at its core

The MVT is proved by reducing to Rolle's Theorem: if \(h(a)=h(b)=0\), then \(h'(c)=0\) for some \(c\). Define the auxiliary function:

$$h(x) = f(x) - \left[f(a) + \frac{f(b)-f(a)}{b-a}(x-a)\right]$$

This is \(f\) minus the secant line. Then \(h(a)=0\) and \(h(b)=0\). By Rolle's Theorem, \(h'(c)=0\) for some \(c\), which gives \(f'(c) = \tfrac{f(b)-f(a)}{b-a}\). ∎

Numerical trace — MVT

Let \(f(x) = x^2\) on \([1, 3]\).

  • Secant slope: \(\dfrac{f(3)-f(1)}{3-1} = \dfrac{9-1}{2} = 4\)
  • We need \(f'(c) = 2c = 4\), so \(c = 2\). Check: \(2 \in (1,3)\). ✓
  • At \(x=2\): \(f(2) = 4\), and the tangent slope \(f'(2)=4\) matches the secant.

L'Hôpital: The linear approximation view

Near \(x=a\), differentiable functions look like their tangent lines:

$$f(x) \approx f(a) + f'(a)(x-a), \quad g(x) \approx g(a) + g'(a)(x-a)$$

If \(f(a) = g(a) = 0\), the ratio becomes \(\dfrac{f'(a)(x-a)}{g'(a)(x-a)} = \dfrac{f'(a)}{g'(a)}\). L'Hôpital makes this precise using Cauchy's MVT.

Numerical trace — L'Hôpital (0/0 case)

Evaluate \(\lim_{x\to 0} \dfrac{\sin x}{x}\).

  • At \(x=0\): form is \(0/0\) — indeterminate.
  • Apply L'Hôpital: \(\dfrac{(\sin x)'}{(x)'} = \dfrac{\cos x}{1}\)
  • \(\lim_{x\to 0} \cos x = \cos 0 = 1\). So the answer is \(\mathbf{1}\).

Numerical trace — L'Hôpital (∞/∞ case)

Evaluate \(\lim_{x\to\infty} \dfrac{x^2}{e^x}\).

  • Form: \(\infty/\infty\). Apply once: \(\dfrac{2x}{e^x}\) — still \(\infty/\infty\).
  • Apply again: \(\dfrac{2}{e^x} \to 0\) as \(x\to\infty\). Answer: \(\mathbf{0}\).
  • Meaning: exponentials grow faster than any polynomial.

The Mathematics — Proofs & Derivations
▾

Cauchy's Mean Value Theorem (generalised MVT)

The standard MVT is a special case. If \(f,g\) are continuous on \([a,b]\) and differentiable on \((a,b)\), and \(g'(x)\neq 0\) on \((a,b)\), then:

$$\frac{f(b)-f(a)}{g(b)-g(a)} = \frac{f'(c)}{g'(c)} \quad \text{for some } c \in (a,b)$$

Setting \(g(x)=x\) recovers the standard MVT.

L'Hôpital — Formal proof sketch (\(0/0\) case)

Given \(f(a)=g(a)=0\), define \(F(x)=[f(b)-f(a)][g(x)-g(a)] - [g(b)-g(a)][f(x)-f(a)]\). Apply Rolle to \(F\) on \([a,x]\):

$$F'(c) = 0 \implies \frac{f(x)-f(a)}{g(x)-g(a)} = \frac{f'(c)}{g'(c)}$$

As \(x\to a\), we need \(c\to a\) (by the squeeze of \(c\) between \(a\) and \(x\)), giving \(\lim_{x\to a}\tfrac{f(x)}{g(x)} = \lim_{c\to a}\tfrac{f'(c)}{g'(c)}\).

Other indeterminate forms — reduction

L'Hôpital handles \(0/0\) and \(\infty/\infty\) directly. Other forms reduce:

  • \(0 \cdot \infty\): write as \(\dfrac{f}{1/g}\) or \(\dfrac{g}{1/f}\) to get \(0/0\) or \(\infty/\infty\).
  • \(\infty - \infty\): find common denominator or factor to produce \(0/0\).
  • \(1^\infty, 0^0, \infty^0\): take logarithm, convert to \(0 \cdot \infty\), then reduce.
Formula Summary

MVT: \(\exists c \in (a,b)\) s.t. \(f'(c) = \dfrac{f(b)-f(a)}{b-a}\)

L'Hôpital: \(\lim_{x\to a}\dfrac{f(x)}{g(x)} = \lim_{x\to a}\dfrac{f'(x)}{g'(x)}\) (form \(0/0\) or \(\infty/\infty\))

Cauchy: \(\dfrac{f(b)-f(a)}{g(b)-g(a)} = \dfrac{f'(c)}{g'(c)}\)

Warning — When MVT Fails

MVT requires (1) continuity on the closed interval \([a,b]\) and (2) differentiability on the open interval \((a,b)\). Endpoints may have corners. If \(f\) has a jump discontinuity inside \([a,b]\), the theorem does not apply.

Code — Numerical Verification
▾

Finding the MVT point numerically

import numpy as np
from scipy.optimize import brentq
def mvt_point(f, df, a, b, tol=1e-8):
"""Find c in (a,b) where f'(c) == secant slope."""
secant_slope = (f(b) - f(a)) / (b - a) # average rate of change
h = lambda x: df(x) - secant_slope # solve f'(c) = secant
# brentq requires sign change — valid by IVT + MVT
c = brentq(h, a + tol, b - tol)
return c, secant_slope
f = lambda x: x**2 - x + 1
df = lambda x: 2*x - 1
c, slope = mvt_point(f, df, 0, 3)
print(f"c = {c:.4f}, f'(c) = {df(c):.4f}, secant = {slope:.4f}")
# c = 1.5000, f'(c) = 2.0000, secant = 2.0000 ✓

L'Hôpital via symbolic differentiation

from sympy import symbols, sin, exp, limit, diff, oo
x = symbols('x')
def lhopital(f, g, point, max_iter=5):
"""Iteratively apply L'Hôpital until limit is determinate."""
fn, gn = f, g
for i in range(max_iter):
L = limit(fn/gn, x, point)
if L.is_finite or L == oo or L == -oo:
print(f"Converged in {i+1} application(s): {L}")
return L
fn, gn = diff(fn, x), diff(gn, x) # differentiate separately
return None
lhopital(sin(x), x, 0) # → 1
lhopital(x**2, exp(x), oo) # → 0 (needs 2 iterations)
lhopital(1 - cos(x), x**2/2, 0) # → 1

Key Takeaways & Connections
▾
MVT Takeaway

The MVT is one of the most powerful existence theorems in calculus. It bridges local behaviour (the derivative at a point) with global behaviour (average change over an interval). It underlies monotonicity proofs, error bounds in numerical methods, and Taylor remainder estimates.

L'Hôpital Takeaway

L'Hôpital is a practical limit-evaluation tool. Its theoretical core is Cauchy's MVT. In ML, it appears when analysing softmax as temperature \(T\to 0\), entropy limits, and KL-divergence when one distribution approaches another.

When each tool applies

  • MVT: proving a function must cross a value, bounding errors, proving identities via monotonicity.
  • L'Hôpital: evaluating limits of the form \(0/0\), \(\infty/\infty\), and forms reducible to these.
