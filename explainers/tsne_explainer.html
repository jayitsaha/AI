Understanding t-SNE
▼

What is it? t-SNE (t-distributed Stochastic Neighbor Embedding) takes high-dimensional data — say, 784-pixel images or 512-dim embeddings — and squashes it down to 2D or 3D so humans can look at it, while trying hard to preserve which points were "neighbors" in the original space.

Analogy: Imagine flattening a crumpled ball of string onto a table without cutting it. You can't preserve every distance perfectly (that's mathematically impossible in general), but you can insist that points which were touching each other on the ball stay close together on the table. t-SNE does exactly this: it converts distances into "probability of being neighbors," then finds a flat layout where those neighbor probabilities are reproduced as faithfully as possible — even if absolute distances get distorted.

💡 If you remember one thing

t-SNE converts pairwise distances into neighbor probabilities in both high-D (Gaussian) and low-D (Student-t) space, then moves the low-D points with gradient descent to minimize $$KL(P \| Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$ — the mismatch between the two probability distributions.

How t-SNE Works Internally
▼

Step 1 — High-D Affinities via Perplexity-Calibrated Gaussians

For every point \(x_i\), t-SNE centers a Gaussian on it and asks: "how likely is \(x_j\) to be picked as a neighbor of \(x_i\)?" This gives a conditional probability \(p_{j|i}\). The Gaussian's bandwidth \(\sigma_i\) is not fixed globally — it's tuned per-point via binary search so the resulting distribution has a target perplexity (roughly, "effective number of neighbors," typically 5–50). Dense regions get small \(\sigma_i\); sparse regions get large \(\sigma_i\) — this is what makes t-SNE adapt to varying local density, unlike PCA.

Step 2 — Symmetrize into a Joint Distribution

The conditional \(p_{j|i}\) is not symmetric (\(p_{j|i} \neq p_{i|j}\) in general because \(\sigma_i \neq \sigma_j\)). t-SNE symmetrizes: \(p_{ij} = (p_{j|i} + p_{i|j})/2n\), producing one clean joint affinity matrix \(P\) over the whole dataset.

Step 3 — Low-D Affinities via Student-t

In the 2D map, t-SNE places points \(y_i\) and defines similarity \(q_{ij}\) using a Student-t distribution with 1 degree of freedom (equivalent to a Cauchy) instead of a Gaussian. This heavy-tailed kernel is the fix for the crowding problem (see Card 3/Step 4 of the walkthrough): it lets moderately-distant points in 2D still register meaningful dissimilarity without needing to be pushed to the edge of the map.

Step 4 — Gradient Descent on KL Divergence

Starting from a tiny random 2D initialization, t-SNE nudges every \(y_i\) to minimize \(KL(P\|Q)\) via gradient descent with momentum, typically for 500–1000 iterations, often using "early exaggeration" (multiplying \(P\) by ~4–12 for the first ~250 iterations) to force tight, well-separated initial clusters before relaxing.

Design Decision: Why Student-t and not Gaussian in low-D?

If both high-D and low-D used Gaussians (as in the earlier SNE algorithm), moderate-distance neighbors would be crushed together near the center of the map — there simply isn't enough 2D "area" at moderate radius to host all the points that had moderate similarity in high-D. The heavier tail of the Student-t distribution gives those points a similarity that decays more slowly with distance, so the optimizer is happy to push them further apart. This single substitution is why t-SNE plots show crisp, well-separated blobs instead of one crowded gray smear.

🔑 Key Property

t-SNE is a local, non-convex, non-parametric embedding: it faithfully preserves which points are close neighbors, but it does not preserve global distances, cluster sizes, or inter-cluster gaps. Two runs with different random seeds can produce visually different (but locally equally valid) layouts.

Why It Works — The Math
▼

High-Dimensional Affinities

The conditional probability that \(x_i\) picks \(x_j\) as a neighbor:

$$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}, \qquad p_{i|i} = 0$$

\(\sigma_i\) is found by binary search on the perplexity equation, where \(H(P_i)\) is Shannon entropy in bits/nats of the row distribution:

$$\mathrm{Perp}(P_i) = 2^{H(P_i)}, \qquad H(P_i) = -\sum_j p_{j|i}\log_2 p_{j|i}$$

Symmetrized joint probability (guarantees \(\sum_{ij} p_{ij}=1\) and every point contributes to the gradient even if it's an outlier):

$$p_{ij} = \frac{p_{j|i} + p_{i|j}}{2n}$$

Low-Dimensional Affinities (Student-t, 1 d.o.f.)

$$q_{ij} = \frac{(1+\|y_i-y_j\|^2)^{-1}}{\sum_{k\neq l}(1+\|y_k-y_l\|^2)^{-1}}$$

Objective and Gradient

t-SNE minimizes the KL divergence of \(P\) from \(Q\) over the low-D coordinates \(\{y_i\}\):

$$C = KL(P\|Q) = \sum_{i\neq j} p_{ij}\log\frac{p_{ij}}{q_{ij}}$$

Differentiating \(C\) with respect to a single point \(y_i\) (using \(d/dx \log(1+x)\)-style chain rule through both the numerator and the shared normalizer \(Z=\sum_{k\neq l}(1+\|y_k-y_l\|^2)^{-1}\)) yields the elegant closed form actually used in every t-SNE implementation:

$$\frac{\partial C}{\partial y_i} = 4\sum_{j\neq i}(p_{ij}-q_{ij})(y_i-y_j)(1+\|y_i-y_j\|^2)^{-1}$$

Read this as a sum of spring forces: each other point \(j\) pulls or pushes \(y_i\) along the direction \((y_i-y_j)\), scaled by how much the current map overestimates or underestimates similarity (\(p_{ij}-q_{ij}\)), damped by the Student-t weight \((1+\|y_i-y_j\|^2)^{-1}\) which fades slowly — this is precisely what lets distant points still exert a small corrective force instead of vanishing like a Gaussian tail would.

⚠️ Common Pitfall

t-SNE's objective is non-convex — gradient descent only finds a local optimum, so results are seeded by both the random initialization and the perplexity choice. Also, because \(Q\) uses squared Euclidean distance internally, inter-cluster distances and cluster sizes in the final plot are not meaningful — never read "cluster A is 3× farther from B than from C" off a t-SNE plot as a quantitative fact.

Key Takeaways
▼

When to use t-SNE:

  • Exploratory visualization of high-D embeddings, images, or genomic data (2D/3D scatter you can eyeball)
  • Checking whether a learned representation separates known classes / clusters
  • Data with strong local (manifold) structure that linear methods (PCA) flatten away

When NOT to use:

  • As a general-purpose dimensionality reduction step before a downstream model — it's not designed to preserve distances usably for that
  • Very large datasets without an approximate variant (Barnes-Hut / FIt-SNE) — naive t-SNE is \(O(n^2)\) per iteration
  • When you need reproducible, deterministic, or out-of-sample (new point) embeddings — vanilla t-SNE has no simple transform for unseen points
  • When you need to compare cluster sizes or inter-cluster distances quantitatively
💡 Practical Rule

Always try a few perplexity values (5, 30, 50) and a few random seeds before trusting a t-SNE plot — clusters that appear/disappear across settings are noise, not signal. For anything beyond quick visualization, prefer UMAP, which is faster, better preserves some global structure, and does support out-of-sample transform.
