Softmax as Continuous Argmax

How temperature morphs a uniform distribution into a one-hot vector — and why this matters for classification, attention, and sampling
Intermediate Calculus & Analysis Special Functions Jacobian: O(n²)
1
Understanding the Concept
▼

What is it? The argmax function picks the single largest value from a list and returns a one-hot vector — all zeros except a 1 at the winning position. It's the mathematical "winner takes all." But argmax is discontinuous and has zero gradient almost everywhere, so you can't train a neural network through it. Softmax is the fix: a smooth, differentiable function that behaves like argmax when its temperature parameter \(T\) is small, and like a uniform average when \(T\) is large.

Analogy: Think of an election where candidates have vote counts \([4, 2, 1, 0]\). Under "strict" rules (argmax), candidate A wins with 100% of power — nobody else matters. Under "proportional" rules (softmax at \(T=1\)), A gets ~73%, B gets ~20%, C gets ~7%. Now crank up a "confusion temperature" — at very high \(T\), all candidates share power equally. At very low \(T\), it snaps back to winner-takes-all.

💡 If you remember one thing

Softmax is the unique smooth approximation to argmax that (1) outputs sum to 1, (2) is everywhere differentiable, and (3) satisfies \(\lim_{T\to 0}\,\sigma_T(\mathbf{z}) = \text{argmax}(\mathbf{z})\) and \(\lim_{T\to\infty}\,\sigma_T(\mathbf{z}) = \tfrac{1}{n}\mathbf{1}\). Temperature is the single knob controlling this interpolation.

How Softmax Works Internally
▼

The Core Formula

Given a logit vector \(\mathbf{z} = [z_1, \ldots, z_n] \in \mathbb{R}^n\), softmax with temperature \(T > 0\) outputs:

$$\sigma_T(\mathbf{z})_i = \frac{\exp(z_i / T)}{\sum_{j=1}^{n} \exp(z_j / T)}, \quad i = 1,\ldots,n$$

At \(T = 1\) this is the standard softmax. Dividing logits by \(T\) scales their dynamic range: small \(T\) amplifies differences (making the winner dominate), large \(T\) compresses differences (making outputs nearly equal).

Numerical Trace — Logits [2.0, 1.0, 0.5, −1.0]

Step 1: Scale by temperature (shown for three values):

$$T=0.1:\; \mathbf{z}/T = [20,\;10,\;5,\;{-10}] \qquad T=1:\; [2,1,0.5,-1] \qquad T=10:\; [0.2,0.1,0.05,-0.1]$$

Step 2: Exponentiate and normalize. For \(T=0.1\): \(\exp(20-20)=1,\;\exp(10-20)\approx 0,\ldots\) giving \(\mathbf{p}\approx[1,0,0,0]\) — the argmax one-hot. For \(T=10\): \(\mathbf{p}\approx[0.285,0.258,0.246,0.211]\) — nearly uniform.

Numerical Stability — The Log-Sum-Exp Trick

Naive computation of \(\exp(z_i/T)\) overflows for large logits. The standard fix subtracts the max before exponentiating — this is algebraically identical but numerically safe:

$$\sigma_T(\mathbf{z})_i = \frac{\exp\!\bigl((z_i - \max_j z_j)/T\bigr)}{\sum_j \exp\!\bigl((z_j - \max_j z_j)/T\bigr)}$$
🔑 Key Property: Translation Invariance

Adding a constant \(c\) to all logits leaves softmax unchanged: \(\sigma(\mathbf{z}+c\mathbf{1}) = \sigma(\mathbf{z})\). This means softmax outputs depend only on the differences between logits, not their absolute scale. It also implies that one degree of freedom in \(\mathbf{z}\) is always unidentifiable.

The Smooth Maximum Interpretation

The log-sum-exp function \(\text{LSE}_T(\mathbf{z}) = T \log\!\sum_j \exp(z_j/T)\) is the smooth maximum (soft-max in the original sense). It satisfies \(\max_j z_j \le \text{LSE}_T(\mathbf{z}) \le \max_j z_j + T\log n\), and \(\text{LSE}_T \to \max\) as \(T \to 0\). Softmax is its gradient:

$$\sigma_T(\mathbf{z})_i = \frac{\partial}{\partial z_i}\,T\log\!\sum_j \exp(z_j/T)$$

The Math — Jacobian, Log-Sum-Exp & Gumbel
▼

The Jacobian \(\partial \sigma_i / \partial z_j = \sigma_i(\delta_{ij} - \sigma_j)\)

Let \(S = \sum_k \exp(z_k)\) and \(\sigma_i = e^{z_i}/S\). By the quotient rule:

$$\text{If } i = j:\quad \frac{\partial \sigma_i}{\partial z_i} = \frac{e^{z_i}\cdot S - e^{z_i}\cdot e^{z_i}}{S^2} = \sigma_i(1-\sigma_i)$$
$$\text{If } i \ne j:\quad \frac{\partial \sigma_i}{\partial z_j} = \frac{0\cdot S - e^{z_i}\cdot e^{z_j}}{S^2} = -\sigma_i\sigma_j$$

Unifying with the Kronecker delta \(\delta_{ij}\):

$$\frac{\partial \sigma_i}{\partial z_j} = \sigma_i(\delta_{ij} - \sigma_j)$$

In matrix form, the full Jacobian \(\mathbf{J} \in \mathbb{R}^{n\times n}\) is:

$$\mathbf{J} = \operatorname{diag}(\boldsymbol{\sigma}) - \boldsymbol{\sigma}\boldsymbol{\sigma}^\top$$

This matrix is symmetric, positive semi-definite, and rank-deficient (rank \(n-1\)) because \(\mathbf{J}\mathbf{1} = \mathbf{0}\) — a consequence of translation invariance. During backprop, the vector-Jacobian product \(\mathbf{v}^\top \mathbf{J}\) simplifies to \(\boldsymbol{\sigma}\odot(\mathbf{v} - \langle\mathbf{v},\boldsymbol{\sigma}\rangle\mathbf{1})\), which is \(O(n)\), not \(O(n^2)\).

Gumbel-Softmax (Straight-Through Estimator)

To backpropagate through a discrete sampling step (e.g., token selection), we can use the Gumbel-Max trick: if \(g_i \sim \text{Gumbel}(0,1)\) i.i.d., then \(\arg\max_i(z_i + g_i)\) has the same distribution as sampling from the categorical distribution \(\boldsymbol{\sigma}(\mathbf{z})\). Replacing argmax with softmax (at low temperature \(\tau\)) gives the Gumbel-Softmax:

$$y_i = \frac{\exp\!\bigl((z_i + g_i)/\tau\bigr)}{\sum_j \exp\!\bigl((z_j + g_j)/\tau\bigr)}, \quad g_i = -\log(-\log U_i),\; U_i \sim \mathrm{Uniform}(0,1)$$
⚠️ Common Misconception

Softmax outputs are not calibrated probabilities. A softmax score of 0.9 does not mean the model is 90% confident it will be correct. Neural networks can be wildly overconfident or underconfident at the softmax layer. Calibration (e.g., temperature scaling post-training, Platt scaling) is a separate step.

Numerical Jacobian Verification (logits = [2.0, 1.0, 0.5, −1.0], T=1)

With \(\boldsymbol{\sigma} \approx [0.610,\;0.224,\;0.136,\;0.030]\), the Jacobian diagonal entries are \(\sigma_i(1-\sigma_i)\): \([0.238,\;0.174,\;0.118,\;0.029]\). Off-diagonal entry \(J_{12} = -\sigma_1\sigma_2 = -0.610\times 0.224 \approx -0.137\). These match the numerically computed values exactly.

Applications: Attention, Classification & Gumbel-Softmax
▼

Scaled Dot-Product Attention

In transformers, attention weights are produced by softmax over scaled dot-products. For query \(\mathbf{q}\), keys \(K\), and head dimension \(d_k\):

$$\text{Attention}(\mathbf{q}, K, V) = \text{softmax}\!\Bigl(\frac{\mathbf{q}K^\top}{\sqrt{d_k}}\Bigr)V$$

The \(\sqrt{d_k}\) scaling acts like a fixed temperature: without it, large \(d_k\) pushes dot-products into extreme regions of softmax, causing gradient vanishing (the Jacobian approaches zero near one-hot outputs). At \(T \ll 1\) (over-confident attention), the model attends to a single token and ignores context — this hurts performance on long sequences.

Multi-class Classification

In classification, the cross-entropy loss combines softmax and log naturally via log-sum-exp:

$$\mathcal{L} = -z_y + \log\!\sum_j \exp(z_j)$$

where \(y\) is the true class. The gradient is simply \(\boldsymbol{\sigma} - \mathbf{e}_y\) (predicted probs minus one-hot label) — elegant and numerically stable when computed together.

Gumbel-Softmax in Practice (VAEs, Discrete RL)

The Gumbel-Softmax (Jang et al. 2017; Maddison et al. 2017) allows backpropagation through categorical sampling. Key trick: as \(\tau \to 0\), the output approaches a true one-hot (argmax) sample. In training, a moderate \(\tau\) (e.g., 0.5–1.0 with annealing) keeps gradients well-defined. This is used in discrete VAEs (DALL-E v1), VQ-VAE-style codebooks, and discrete action RL agents.

Key Takeaways & Code Trace
▼

When to use softmax:

  • Any multi-class classification output layer (n ≥ 3 classes)
  • Attention weight computation in transformers
  • When you need differentiability through a "selection" operation
  • Language model token sampling (with temperature)

When NOT to use:

  • Binary classification — use sigmoid (softmax with n=2 is redundant)
  • Multi-label problems — use independent sigmoids per label
  • When you need true probabilities — calibrate separately after training
💡 Hierarchy: argmax ⊃ softmax ⊃ sigmoid

Sigmoid is softmax for n=2 (collapses to \(\sigma(z_1-z_2)\)). Argmax is the zero-temperature limit of softmax. They form a family parameterised by temperature.

import numpy as np
def softmax(z, T=1.0):
"""Numerically stable softmax with temperature scaling."""
z_scaled = z / T # apply temperature
z_shifted = z_scaled - np.max(z_scaled, axis=-1, keepdims=True) # stability
exp_z = np.exp(z_shifted) # exponentiate
return exp_z / np.sum(exp_z, axis=-1, keepdims=True) # normalize
def softmax_jacobian(sigma):
"""Jacobian J[i,j] = sigma[i]*(delta_ij - sigma[j])."""
return np.diag(sigma) - np.outer(sigma, sigma) # O(n^2), symmetric
def vjp_softmax(sigma, v):
"""Vector-Jacobian product in O(n) — used in backprop."""
return sigma * (v - np.dot(v, sigma)) # sigma ⊙ (v - 1)
def gumbel_softmax(logits, tau=1.0):
"""Gumbel-softmax reparameterization trick."""
U = np.random.uniform(0, 1, size=logits.shape)
gumbel = -np.log(-np.log(U + 1e-10) + 1e-10) # sample Gumbel(0,1)
return softmax(logits + gumbel, T=tau) # differentiable sample
