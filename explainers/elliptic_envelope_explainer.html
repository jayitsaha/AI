Elliptic Envelope (Gaussian Assumption)

Robust Covariance Estimation & Mahalanobis-Distance Outlier Detection

Intermediate Classical ML · Anomaly Detection Part III — Section 12.3 O(n · d²) fit
1
The 30-Second Version

What is this?

Imagine you have a scatter of data points that you believe mostly follow an oval (elliptical) cloud shape. The Elliptic Envelope fits the tightest robust ellipse that covers the "normal" data, then flags any point sitting outside that ellipse as an outlier. It assumes your data looks like a multivariate Gaussian (bell curve in many dimensions) but is designed to be resistant to the very outliers it is trying to find.

Real-World Analogy

Think of a flock of migrating birds photographed from above. Most birds fly in a loose oval formation. A few birds got separated — they're outside the oval. The Elliptic Envelope draws that oval using only the tightly clustered birds (ignoring the stragglers so they don't distort the shape), then declares any bird beyond the oval boundary an outlier.

💡 If you remember one thing

Elliptic Envelope fits a robust Gaussian using Minimum Covariance Determinant (MCD), measures how far each point sits from the centre in Mahalanobis distance, and flags points beyond a \(\chi^2\) threshold as anomalies — all without needing any labels.

One-sentence summary

Fit the smallest-volume ellipse that covers ~(1 − contamination) of the data using MCD, then label every point outside it an outlier via a \(\chi^2_d\) distance threshold.

How It Works Internally

Step-by-step mechanism

  1. Assume Gaussianity. We posit \(\mathbf{x} \sim \mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})\), where \(\boldsymbol{\mu}\) is the centre and \(\boldsymbol{\Sigma}\) the covariance (shape + orientation of the cloud).
  2. Robust estimation via MCD. Instead of using all \(n\) points (which outliers would corrupt), find the subset \(H \subset \{1,\ldots,n\}\) of size \(h \approx \lfloor(n + d + 1)/2\rfloor\) to \(\lfloor n(1-\text{contamination})\rfloor\) that has the smallest sample covariance determinant \(|\mathbf{S}_H|\). Compute \(\hat{\boldsymbol{\mu}}_{MCD}\) and \(\hat{\boldsymbol{\Sigma}}_{MCD}\) from this "clean" subset.
  3. Reweight. Apply a consistency correction factor \(c\) so that \(\hat{\boldsymbol{\Sigma}}_{MCD}\) is asymptotically unbiased for the true covariance.
  4. Mahalanobis distance for each point. Compute \(d_M^2(\mathbf{x}_i) = (\mathbf{x}_i - \hat{\boldsymbol{\mu}})^\top \hat{\boldsymbol{\Sigma}}^{-1} (\mathbf{x}_i - \hat{\boldsymbol{\mu}})\).
  5. Threshold via \(\chi^2\). Under the Gaussian assumption, \(d_M^2 \sim \chi^2_d\). Set threshold at the \((1-\alpha)\)-quantile. Points exceeding the threshold are outliers; decision function returns negative values for outliers, positive for inliers.
🔑 Key Invariant

MCD seeks the subset of \(h\) points whose sample covariance has minimum determinant — the determinant of \(\boldsymbol{\Sigma}\) equals the squared volume of the covariance ellipsoid, so minimising it finds the most concentrated "core" of the data.

FastMCD Algorithm (Rousseeuw & Van Driessen, 1999)

Exact MCD is NP-hard (exhaustive search over \(\binom{n}{h}\) subsets). FastMCD uses a concentration step ("C-step"): starting from a random subset, repeatedly swap in the \(h\) points with the smallest Mahalanobis distances from the current estimate. C-steps are guaranteed to decrease the determinant monotonically, and the algorithm runs multiple random restarts.

⚠️ Design Decision

Why not just use the sample covariance? If 20% of points are outliers, the classical covariance is badly inflated along the outlier direction. MCD ignores those points entirely during fitting — it is a high-breakdown-point estimator (breakdown point ≈ (n−h)/n ≈ contamination fraction).

The Math — Mahalanobis Distance & χ² Threshold

Mahalanobis Distance

For a point \(\mathbf{x} \in \mathbb{R}^d\) and estimated distribution \(\mathcal{N}(\hat{\boldsymbol{\mu}}, \hat{\boldsymbol{\Sigma}})\):

$$d_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \hat{\boldsymbol{\mu}})^\top \hat{\boldsymbol{\Sigma}}^{-1} (\mathbf{x} - \hat{\boldsymbol{\mu}})}$$

The squared Mahalanobis distance, under the true Gaussian, is distributed as:

$$d_M^2(\mathbf{x}) \;\sim\; \chi^2_d$$

where \(d\) is the feature dimension. This chi-squared link gives the natural threshold: if we allow contamination fraction \(\alpha\), declare a point an outlier when:

$$d_M^2(\mathbf{x}) \;>\; \chi^2_{d,\;1-\alpha}$$

MCD Objective

Let \(\mathcal{H}_h\) be all size-\(h\) subsets of \(\{1,\ldots,n\}\). MCD solves:

$$\hat{H} = \underset{H \in \mathcal{H}_h}{\operatorname{argmin}} \; \det\!\left(\mathbf{S}_H\right)$$

where \(\mathbf{S}_H = \frac{1}{h-1}\sum_{i \in H}(\mathbf{x}_i - \bar{\mathbf{x}}_H)(\mathbf{x}_i - \bar{\mathbf{x}}_H)^\top\). The MCD estimates are then:

$$\hat{\boldsymbol{\mu}}_{MCD} = \bar{\mathbf{x}}_{\hat{H}}, \qquad \hat{\boldsymbol{\Sigma}}_{MCD} = c \cdot \mathbf{S}_{\hat{H}}$$

where \(c\) is a consistency factor ensuring \(\hat{\boldsymbol{\Sigma}}_{MCD} \to \boldsymbol{\Sigma}\) as \(n \to \infty\) under the Gaussian assumption.

📐 Mahalanobis vs. Euclidean

Euclidean distance treats all directions equally. Mahalanobis distance whitens the data first — stretching compressed directions and shrinking elongated ones — so a point can be "far" even if it's close in raw space, if it lies in a low-variance direction. This makes the Elliptic Envelope sensitive to the shape of the distribution, not just its scale.

Key Takeaways & When to Use

When to use Elliptic Envelope

  • Data is approximately Gaussian — the core assumption; check QQ-plots or use Mardia's test
  • Low-to-medium dimensionality — MCD is reliable up to ~20–30 dimensions; beyond that, the covariance matrix is poorly estimated (curse of dimensionality)
  • Known contamination fraction — set contamination to an informed estimate
  • Need interpretable geometry — the ellipse and Mahalanobis distances are directly inspectable

When NOT to use

  • Multimodal data (mixture of Gaussians) — use GMM-based approach or DBSCAN
  • Very high-dimensional data (d > 50) — covariance estimation degrades; prefer Isolation Forest
  • Non-convex outlier clusters — Isolation Forest or DBSCAN handles arbitrary shapes
  • Categorical or mixed-type data — Mahalanobis is defined only for continuous features

🎯 Decision Rule

Use Elliptic Envelope when your features are continuous, data has a single roughly Gaussian cluster, and \(d \lesssim 30\). Use Isolation Forest otherwise — it makes no distributional assumptions and scales to thousands of dimensions.
