Stacking (Meta-Learning)

Level-0 base models → out-of-fold predictions → level-1 meta-learner
Intermediate Classical ML · Ensembles Part III
1
Understanding Stacking
▾

Stacking — short for stacked generalization — trains several different models (the level-0 learners, or base learners) on the same data, then trains a second-tier model (the level-1 learner, or meta-learner) to combine their outputs into a final prediction.

💡 Analogy

Imagine three doctors (base learners) each examine a patient and give a probability estimate for a diagnosis. A senior consultant (meta-learner) then weighs those three opinions — knowing which doctor tends to be over-confident and which under-estimates — to produce the final verdict. The consultant never saw the original test results; she only sees the doctors' scores.

The key engineering constraint: the meta-learner must be trained on predictions the base learners made on data they have never seen during training. If we simply re-used training data, each base learner's predictions would be inflated by overfitting, and the meta-learner would learn a distorted mapping. The fix is out-of-fold (OOF) prediction using k-fold cross-validation.

Key Concept

Out-of-fold predictions guarantee that each training sample's level-0 features were produced by a model that was trained without seeing that sample. This is the fundamental leakage-prevention mechanism in stacking.

💡 If you remember one thing

The meta-learner sees only OOF predictions (plus optionally the raw features). It learns how to correct and combine each base learner's systematic biases. Without OOF, the meta-learner would overfit to the base learners' training-set memorisation, not their generalisation ability.

2
How Stacking Works Internally
▾

Training Phase — Two-Pass Protocol

Let \(D = \{(x_i, y_i)\}_{i=1}^n\) be the training set, \(K\) base learners \(h_1,\ldots,h_K\), and \(k\)-fold CV splits \(D_1,\ldots,D_k\).

Pass 1 — generate OOF predictions: For each fold \(f\):

$$\hat{z}_{i,j} = h_j\!\left(\,x_i;\; D \setminus D_f\right), \quad x_i \in D_f, \quad j = 1,\ldots,K$$

After all folds, every training sample \(i\) has \(K\) out-of-fold predictions \(\hat{z}_{i,1},\ldots,\hat{z}_{i,K}\). These form the meta-feature matrix \(Z \in \mathbb{R}^{n \times K}\).

Pass 2 — retrain base learners on full data:

$$\tilde{h}_j = \text{fit}(h_j,\; D) \quad j = 1,\ldots,K$$

Train meta-learner: Fit \(g\) on \((Z, y)\):

$$\hat{g} = \text{fit}(g,\; (Z, y))$$

Inference Phase

$$\hat{y}^* = \hat{g}\!\left(\tilde{h}_1(x^*),\ldots,\tilde{h}_K(x^*)\right)$$

Each test sample is fed through the \(K\) fully-retrained base learners, producing \(K\) predictions. These are passed as a single row to the meta-learner, which outputs the final prediction.

⚠ Leakage Without OOF

If base learners predict on training data they were trained on, they over-predict (e.g., a memorising tree gets 100% accuracy). The meta-learner then learns to trust overfitted signals — it will fail at test time because the base learners' test predictions look completely different from what it trained on.

Why Stacking Works — Bias–Variance View
▾

The expected squared error of any predictor decomposes as:

$$\text{MSE}(\hat{f}) = \text{Bias}^2(\hat{f}) + \text{Var}(\hat{f}) + \sigma^2_\varepsilon$$

Stacking exploits model diversity. If base learners make uncorrelated errors, the meta-learner can average away the variance components. Formally, if \(K\) learners each have variance \(\sigma^2\) and pairwise correlation \(\rho\), the variance of a weighted combination is:

$$\text{Var}\!\left(\sum_{j=1}^K w_j h_j\right) = \sum_j w_j^2 \sigma^2 + 2\sum_{j

With equal weights \(w_j=1/K\), this is \(\sigma^2/K + (1-1/K)\rho\sigma^2\). As \(\rho \to 0\) (diverse models), variance reduces at rate \(1/K\). As \(\rho \to 1\) (identical models), no benefit.

Unlike simple averaging, the meta-learner also corrects for systematic biases: if one base learner consistently under-predicts for a certain region of feature space, the meta-learner can compensate by assigning it a lower weight precisely there.

Wolpert's Theorem (Informal)

Wolpert (1992) showed that with an infinitely capable meta-learner and perfectly unbiased (OOF) level-0 predictions, stacking cannot do worse than the best single base learner in expectation. In practice, using a simple, regularised meta-learner (e.g. Ridge or Lasso) prevents the meta-learner itself from overfitting.

Why the Meta-Learner Must Be Simple

The meta-feature space \(Z \in \mathbb{R}^{n \times K}\) is low-dimensional (often \(K \leq 10\)). A complex meta-learner (e.g., a deep tree) will overfit this tiny feature set. A regularised linear model (Logistic Regression, Ridge, Lasso) or a shallow tree is almost always the right choice for the level-1 model.

Key Formula

Optimal meta-learner weights (Ridge, regression case):

$$\hat{w} = (Z^\top Z + \lambda I)^{-1} Z^\top y$$

Decision Guide

Use stacking when: you have diverse, well-performing base learners of different families (tree + linear + kNN). Gains are largest when models make uncorrelated errors.

Avoid stacking when: data is small (OOF folds reduce effective training size significantly), compute budget is tight (K × k full fits required), or a single strong model (XGBoost, LightGBM) already performs near ceiling.

6
Interview Q&A & Code
▾

Q1 (Easy) — What is the difference between blending and stacking?

Blending uses a fixed holdout set (e.g. 20%) to generate level-0 predictions for the meta-learner; the base learners train on the remaining 80%. Stacking uses k-fold OOF, so every training sample contributes a meta-feature while never being predicted by a base learner trained on it. Stacking wastes less data but is more complex.

Q2 (Medium) — Why must the meta-learner be simple?

The meta-feature matrix \(Z\) has only \(K\) columns (typically \(\leq 10\)) and the same \(n\) rows. A high-capacity model will overfit this low-dimensional space. A regularised linear model (Ridge, Lasso, Logistic Regression) provides well-calibrated combination weights without memorising noise. In competitions, even a simple weighted average sometimes wins over a full logistic meta-learner.

Q3 (Hard) — How does stacking relate to model selection in a Bayesian sense?

Bayesian model averaging (BMA) computes \(\hat{y} = \sum_j P(M_j | D)\, h_j(x)\), weighting each model by its posterior probability. Stacking approximates this but optimises predictive accuracy rather than posterior probability. Clyde & Iversen (2013) show stacking weights approximate leave-one-out cross-validated Bayesian model probabilities under regularity conditions. The key difference: BMA averages models; stacking trains a combiner that can do better than any single model when base learner errors are non-independently distributed.

From-Scratch Implementation (NumPy / sklearn)

import numpy as np
from sklearn.model_selection import KFold
from sklearn.linear_model import LogisticRegression, Ridge
from sklearn.tree import DecisionTreeClassifier
class Stacker:
def __init__(self, base_learners, meta_learner, n_folds=5):
self.base = base_learners # list of (name, estimator) tuples
self.meta = meta_learner # level-1 model
self.k = n_folds
def fit(self, X, y):
n, K = len(X), len(self.base)
Z = np.zeros((n, K)) # meta-feature matrix (OOF)
kf = KFold(n_splits=self.k, shuffle=True, random_state=42)
# Pass 1: generate OOF predictions
for j, (name, clf) in enumerate(self.base):
for train_idx, val_idx in kf.split(X):
clf.fit(X[train_idx], y[train_idx]) # fit on k-1 folds
Z[val_idx, j] = clf.predict_proba(X[val_idx])[:, 1] # OOF
# Pass 2: retrain each base learner on full data
self.fitted_base = []
for name, clf in self.base:
clf.fit(X, y)
self.fitted_base.append(clf)
# Train meta-learner on OOF meta-features
self.meta.fit(Z, y) # Z never leaked — each row was OOF
return self
def predict_proba(self, X):
Z_test = np.column_stack(
[clf.predict_proba(X)[:, 1] for clf in self.fitted_base]
) # shape: (n_test, K)
return self.meta.predict_proba(Z_test)
💡 Production Tip

In scikit-learn, StackingClassifier / StackingRegressor implement the above exactly. Use passthrough=True to also feed original features to the meta-learner — useful when the meta-learner needs context the base learner predictions discard.
