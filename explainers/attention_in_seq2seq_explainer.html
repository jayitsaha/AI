Attention in Seq2Seq (Bahdanau)

Dynamically focusing on relevant parts of the input sequence
Foundational Deep Learning NLP Intermediate
1
Understanding Attention
▼

What is it? In traditional sequence-to-sequence (Seq2Seq) models, an encoder processes the entire input sequence into a single "context vector." This vector then serves as the sole input for the decoder to generate the output sequence. This bottleneck often struggles with long sequences, as it's hard to compress all relevant information into a fixed-size vector.

Attention solves this by allowing the decoder to "look back" at the encoder's hidden states at each step of generating the output. Instead of a single context vector, the decoder computes a weighted sum of all encoder hidden states, where the weights (attention scores) indicate how much importance each input element has for generating the current output element.

Bahdanau Attention (also known as additive attention or concat attention) was one of the first and most influential attention mechanisms, introduced in 2014 for neural machine translation. It computes attention scores by feeding the decoder's current hidden state and each encoder's hidden state into a feed-forward neural network.

💡 If you remember one thing

Attention allows a neural network to focus on specific parts of its input when processing each part of its output. Bahdanau attention uses a feed-forward network to calculate how "aligned" each encoder hidden state is with the current decoder hidden state.

2
How Bahdanau Attention Works
▼

The Seq2Seq Baseline

A standard Seq2Seq model has two parts: an Encoder (typically an RNN/LSTM/GRU) that reads the input sequence \((x_1, \dots, x_N)\) and produces a sequence of hidden states \((h_1, \dots, h_N)\) and a final context vector. A Decoder (another RNN) then takes this context vector and generates the output sequence \((y_1, \dots, y_M)\).

The Attention Mechanism

Bahdanau attention modifies the decoder's process. At each decoding step \(t\) (when predicting \(y_t\)), the decoder has a current hidden state \(s_t\). Instead of just using \(s_t\) and the fixed encoder context, it performs these steps:

  1. Calculate Alignment Scores (Energies): For each encoder hidden state \(h_i\) (from \(i=1\) to \(N\)), a score \(e_{ti}\) is computed. This score measures how well \(h_i\) and \(s_t\) "match" or "align." Bahdanau uses a feed-forward network for this: \(e_{ti} = v_a^\top \tanh(W_a s_t + U_a h_i)\).
  2. Normalize to Attention Weights: The raw scores \(e_{ti}\) are passed through a softmax function to get attention weights \(\alpha_{ti}\). These weights sum to 1 across all encoder states: \(\alpha_{ti} = \frac{\exp(e_{ti})}{\sum_{k=1}^N \exp(e_{tk})}\).
  3. Compute Context Vector: A context vector \(c_t\) is created as a weighted sum of all encoder hidden states, using the attention weights: \(c_t = \sum_{i=1}^N \alpha_{ti} h_i\). This vector dynamically captures the most relevant input information for the current decoding step.
  4. Predict Output: The context vector \(c_t\) is concatenated with the decoder's current hidden state \(s_t\) to form a "attentional hidden state." This combined vector is then used to predict the next output token \(y_t\). The decoder's next hidden state \(s_{t+1}\) is also updated using \(s_t\) and \(c_t\).
🔑 Key Property

The attention weights \(\alpha_{ti}\) are dynamic and depend on the current decoder state \(s_t\). This means the model can choose to focus on different parts of the input for each word it generates, alleviating the information bottleneck of fixed-size context vectors.

3
Why It Works — The Math
▼

Encoder Hidden States

Let the input sequence be \((x_1, \dots, x_N)\). A bidirectional RNN encoder (as used in Bahdanau's original paper) produces forward hidden states \(\vec{h}_i\) and backward hidden states \(\overleftarrow{h}_i\). The final encoder hidden state for each input token \(i\) is the concatenation:

$$h_i = [\vec{h}_i^\top; \overleftarrow{h}_i^\top]^\top$$

These \(h_i\) vectors are what the decoder will attend over.

Decoder Hidden State

The decoder is typically an RNN (e.g., GRU). At each time step \(t\), before predicting the \(t\)-th output token, it computes a hidden state \(s_t\). This \(s_t\) is crucial for determining what to attend to.

Alignment Score Function

Bahdanau's attention mechanism uses an "additive" or "concatenation" score function. For each encoder hidden state \(h_i\) and the current decoder hidden state \(s_t\), the raw alignment score (or energy) \(e_{ti}\) is calculated as:

$$e_{ti} = v_a^\top \tanh(W_a s_t + U_a h_i)$$

Here, \(W_a\), \(U_a\) are weight matrices and \(v_a\) is a weight vector, all learned during training. The \(\tanh\) activation introduces non-linearity, allowing the model to learn complex relationships between \(s_t\) and \(h_i\).

Attention Weights and Context Vector

The alignment scores \(e_{ti}\) are then normalized using a softmax function to produce attention weights \(\alpha_{ti}\):

$$\alpha_{ti} = \frac{\exp(e_{ti})}{\sum_{k=1}^N \exp(e_{tk})}$$

These weights \(\alpha_{ti}\) tell us how much each \(h_i\) contributes to the context for predicting \(y_t\). The context vector \(c_t\) is then a weighted sum of the encoder hidden states:

$$c_t = \sum_{i=1}^N \alpha_{ti} h_i$$

This \(c_t\) is then used along with \(s_t\) to predict the next output token. The ability to learn these \(W_a, U_a, v_a\) parameters is what makes attention powerful and adaptive.

⚠️ Not just for translation

While popularized by machine translation, attention is a general mechanism. It's used in image captioning (attending to parts of an image), speech recognition (attending to parts of an audio signal), and is a core component of the Transformer architecture (self-attention).

5
Key Takeaways
▼

Advantages of Bahdanau Attention:

  • Solves the Bottleneck: No longer forces all input information into a single fixed-size vector.
  • Handles Long Sequences: Performance doesn't degrade as much with longer inputs.
  • Interpretability: The attention weights \(\alpha_{ti}\) provide insight into which input words are most relevant for each output word, creating an "alignment map."
  • Improved Performance: Significantly boosted performance in tasks like machine translation.

Limitations & Evolution:

  • Computational Cost: Calculating attention scores for every pair of decoder state and encoder state can be expensive, especially for very long sequences.
  • Still Sequential: While attention helps, the underlying RNNs in Seq2Seq are still sequential, limiting parallelization during encoding/decoding.
  • Dot-Product Attention: Luong attention (a "multiplicative" attention) is a simpler alternative where scores are computed via a dot product.
  • Self-Attention: The Transformer architecture takes attention to the next level with self-attention, where attention is applied within a single sequence to learn relationships between elements.
💡 Impact

Bahdanau attention was a pivotal innovation that paved the way for modern neural network architectures like the Transformer, which relies entirely on attention mechanisms to achieve state-of-the-art results in many NLP tasks.

Code Trace

import numpy as np
# Dummy parameters (d_model = 4)
d_model = 4
W_a = np.random.rand(d_model, d_model) * 0.1 # Weights for decoder state
U_a = np.random.rand(d_model, d_model) * 0.1 # Weights for encoder state
v_a = np.random.rand(d_model, 1) * 0.1 # Weight vector for tanh output
# Encoder hidden states (h_i for "Je suis étudiant")
h_encoder = np.array([
[0.1, 0.2, 0.3, 0.4], # h_1 (Je)
[0.5, 0.6, 0.7, 0.8], # h_2 (suis)
[0.9, 0.8, 0.7, 0.6], # h_3 (étudiant)
[0.5, 0.4, 0.3, 0.2] # h_4 (EOS)
])
# Current decoder hidden state (s_t for predicting "I")
s_decoder = np.array([0.1, 0.3, 0.5, 0.7])
# 1. Calculate Alignment Scores (Energies)
energies = []
for i in range(h_encoder.shape[0]):
h_i = h_encoder[i, :]
# W_a @ s_decoder + U_a @ h_i
concat_vector = np.tanh(np.dot(W_a, s_decoder) + np.dot(U_a, h_i))
# v_a.T @ concat_vector
e_ti = np.dot(v_a.T, concat_vector)
energies.append(e_ti[0])
energies = np.array(energies)
# 2. Normalize to Attention Weights (Softmax)
exp_energies = np.exp(energies - np.max(energies)) # numerical stability
attention_weights = exp_energies / np.sum(exp_energies)
# 3. Compute Context Vector
context_vector = np.sum(attention_weights[:, np.newaxis] * h_encoder, axis=0)
# 4. Predict Output (simplified)
# Typically, [context_vector; s_decoder] is fed to another layer
# For illustration, let's just combine them
combined_input = np.concatenate([context_vector, s_decoder])
# Then feed combined_input to a linear layer + softmax for vocabulary prediction
print("Attention Weights:", attention_weights)
print("Context Vector:", context_vector)
