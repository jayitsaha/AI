The Halko–Martinsson–Tropp algorithm: sketch → QR → project → exact SVD → lift
Intermediate → Advanced Linear Algebra Numerical Methods O(mnk) vs O(mn²)
1
Understanding Randomized SVD
▼

What is it? Singular Value Decomposition (SVD) is the gold standard for understanding what a matrix "does" — it finds the most important directions and how much the matrix stretches along each. But for a 1 million × 10,000 matrix (think Netflix ratings or document-term matrices), full SVD is impossibly expensive. Randomized SVD computes an approximate SVD in a fraction of the time by first sketching the column space with random projections.

Analogy: Imagine you need to describe a high-dimensional cloud of points. Instead of examining every dimension carefully, you throw random darts and measure where they land. Remarkably, a small set of carefully-chosen random directions captures almost all the structure. Then you compute an exact, small SVD on just those directions and lift back up. The randomness gives you a probabilistic guarantee — with overwhelming probability, you miss almost nothing.

💡 If you remember one thing

Form a random sketch \(Y = A\Omega\) (where \(\Omega\) is Gaussian), orthonormalize to get \(Q\), project \(B = Q^\top A\), SVD the small matrix \(B\), and lift: \(A \approx (QU_B)\Sigma_B V_B^\top\). This collapses an \(m \times n\) problem to \((k+p) \times n\), cutting cost from \(O(mn^2)\) to \(O(mnk)\).

Key references: Halko, Martinsson & Tropp, "Finding Structure with Randomness," SIAM Review 2011. Also Mahoney's randomized NLA survey (2011). Implemented in scikit-learn's TruncatedSVD and PyTorch's torch.linalg.svd via LAPACK.

2
The Halko–Martinsson–Tropp Algorithm
▼

Step 1 — Draw a random test matrix \(\Omega \in \mathbb{R}^{n \times (k+p)}\)

Each entry is drawn i.i.d. from \(\mathcal{N}(0,1)\). The target rank is \(k\); \(p\) is the oversampling parameter (typically 5–10). The columns of \(\Omega\) are random probes into the column space of \(A\).

Step 2 — Form the sketch \(Y = A\Omega\)

\(Y \in \mathbb{R}^{m \times (k+p)}\) is a "compressed" image of \(A\)'s action. By the Johnson–Lindenstrauss lemma and concentration of Gaussian measure, \(\text{range}(Y) \approx \text{range}(A)\) for any \(A\) with rapidly decaying singular values.

Step 3 — QR decomposition: \(Y = QR\)

Orthonormalize \(Y\) via QR to get \(Q \in \mathbb{R}^{m \times (k+p)}\). The columns of \(Q\) form an orthonormal basis capturing the approximate range of \(A\).

Step 4 — Project to small matrix \(B = Q^\top A\)

\(B \in \mathbb{R}^{(k+p) \times n}\). This is the key dimension reduction: instead of a huge \(m \times n\) SVD, we now have a tiny \((k+p) \times n\) matrix whose left singular vectors live in the approximate range of \(A\).

Step 5 — Small exact SVD: \(B = \hat{U}\Sigma V^\top\)

Compute the exact SVD of \(B\). Cost: \(O((k+p)^2 n)\) — tiny. Keep only the top \(k\) singular triplets.

Step 6 — Lift back: \(U = Q\hat{U}_k\)

The left singular vectors of \(A\) are \(U = Q\hat{U}_k \in \mathbb{R}^{m \times k}\). Final approximation: \(A \approx U\Sigma_k V_k^\top\).

🔑 Why oversampling \(p\) matters

Even \(p=5\) columns of extra slack virtually eliminate the probability that \(Q\) misses an important singular direction. The error bound scales as \(\sigma_{k+1}(A)\) (the first discarded singular value) plus an exponentially small correction in \(p\).

Power Iteration Refinement

When singular values decay slowly, replace \(Y = A\Omega\) with \(Y = (AA^\top)^q A\Omega\). Each power iteration squares the singular value ratios, making the spectrum decay faster. Two iterations (\(q=2\)) typically suffice for near-exact results even for ill-conditioned matrices.

⚠️ Numerical gotcha

In practice, re-orthogonalize between power iterations using QR (LU-based schemes exist too). Naively computing \((AA^\top)^q A\Omega\) without re-orthogonalizing causes catastrophic cancellation for ill-conditioned \(A\).

3
Error Bounds & Why It Works
▼

The key approximation guarantee

Let \(\hat{A}_k = QQ^\top A\) be the Stage-A approximation (before the small SVD). Halko et al. (Theorem 10.5) give, for \(\ell = k + p\) with \(p \geq 2\):

$$\mathbb{E}\|A - QQ^\top A\|_F \;\leq\; \left(1 + \frac{k}{p-1}\right)^{1/2}\left(\sum_{j > k}\sigma_j^2\right)^{1/2}$$

The term \(\left(\sum_{j>k}\sigma_j^2\right)^{1/2}\) is the best possible rank-\(k\) Frobenius error (Eckart–Young). The factor \(\left(1 + \frac{k}{p-1}\right)^{1/2}\) is the overhead from randomness — for \(p=10, k=50\) this is \(\approx 2.5\times\), shrinking fast with \(p\).

Spectral norm bound (Theorem 10.6)

$$\mathbb{E}\|A - QQ^\top A\|_2 \;\leq\; \left(1 + \sqrt{\frac{k}{\,p-1\,}}\right)\sigma_{k+1} + \frac{e\sqrt{k+p}}{p}\left(\sum_{j>k}\sigma_j^2\right)^{1/2}$$

With \(q\) power iterations

Replace \(A\) by \((AA^\top)^q A\). Since \(A = U\Sigma V^\top\), we have \((AA^\top)^q A = U\Sigma^{2q+1}V^\top\). The singular values of the powered matrix are \(\sigma_j^{2q+1}\), so the ratio \(\sigma_{k+1}^{2q+1}/\sigma_1^{2q+1}\) decays exponentially in \(q\). Thus:

$$\|A - QQ^\top A\|_2 \;\lesssim\; \left(\frac{\sigma_{k+1}}{\sigma_1}\right)^{2q}\sigma_{k+1}$$
📐 Total computational cost

\(A\Omega\): \(O(mn(k+p))\)  |  QR of \(Y\): \(O(m(k+p)^2)\)  |  \(Q^\top A\): \(O(mn(k+p))\)  |  SVD of \(B\): \(O((k+p)^2 n)\)
Total: \(O(mn(k+p))\) vs full SVD \(O(m^2 n)\) for \(m \leq n\).

From-Scratch Implementation & Production Code
▼

NumPy from-scratch (annotated)

import numpy as np
def randomized_svd(A, k, p=10, q=2, random_state=42):
m, n = A.shape # A is m×n
rng = np.random.default_rng(random_state)
ell = k + p # oversampled rank
Omega = rng.standard_normal((n, ell)) # Step 1: Gaussian test matrix
Y = A @ Omega # Step 2: sketch Y = AΩ (m×ℓ)
for _ in range(q): # Step 2b: power iterations
Y, _ = np.linalg.qr(Y) # re-orthogonalize (stability!)
Y = A @ (A.T @ Y) # apply AᵀA to boost spectrum
Q, _ = np.linalg.qr(Y) # Step 3: QR → orthonormal Q
B = Q.T @ A # Step 4: project B = QᵀA (ℓ×n)
Uhat, s, Vt = np.linalg.svd(B, full_matrices=False) # Step 5: exact small SVD
U = Q @ Uhat[:, :k] # Step 6: lift U back to ℝᵐ
return U, s[:k], Vt[:k, :] # rank-k factors: U,Σ,Vᵀ

Production usage (scikit-learn)

from sklearn.utils.extmath import randomized_svd
U, s, Vt = randomized_svd(A, n_components=50, n_iter=4, random_state=0)
# ⚠ n_iter maps to q above. n_components = k.
A_approx = U @ np.diag(s) @ Vt # reconstruction
# PyTorch: torch.svd_lowrank(A, q=50, niter=4)
⚠️ Common Gotchas

1. No re-orthogonalization in power iters — catastrophic cancellation for ill-conditioned A. Always QR between applications of AAT.

2. Choosing p=0 — no oversampling means high probability of missing a singular direction. Use p≥5.

3. Sparse A — A@Omega is fast if A is sparse; keep it sparse through the sketch. B=QT@A is dense but small.

6
When to Use & Key Takeaways
▼

Use Randomized SVD when:

• \(m, n \gg k\) — matrix is much larger than the target rank
• Spectrum decays fast — i.e., most information is in top \(k\) singular values
• Memory is a bottleneck — only need to store \(Q\) (\(m \times \ell\)) and \(B\) (\(\ell \times n\))
• Out-of-core or distributed — can compute \(A\Omega\) in streaming passes

Do NOT use when:

• All singular values are equal (flat spectrum) — need full SVD
• \(k \approx n/2\) — sketch is not much smaller than the full matrix
• Exact factorization required — Randomized SVD is probabilistically approximate

💡 The three-line summary

Sketch the range with \(Y = A\Omega\), orthonormalize with QR to get \(Q\), project to a small matrix \(B = Q^\top A\), compute exact SVD of \(B\), lift back: \(U = Q\hat{U}\). Oversampling \(p\) and power iterations \(q\) control the accuracy-vs-cost tradeoff.
