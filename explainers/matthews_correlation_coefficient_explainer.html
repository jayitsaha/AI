Part III · Classical ML · Section 13.1 Classification Metrics

Matthews Correlation Coefficient

A single balanced score from all four confusion-matrix cells — honest even under class imbalance.
Intermediate Classical ML Evaluation O(1)
1
Understanding the Concept

Imagine you're judging a spam filter. Of 1000 emails, 950 are ham and only 50 are spam. A lazy classifier that labels everything as ham scores 95% accuracy — yet it misses every single spam email. Accuracy lied to you.

The Matthews Correlation Coefficient (MCC) refuses to be fooled. It looks at all four outcomes — things correctly called positive (TP), correctly called negative (TN), wrongly called positive (FP), and wrongly called negative (FN) — and combines them into a single number between −1 and +1.

💡 The Core Intuition

MCC is a correlation coefficient between your predictions and the true labels. +1 = perfect, 0 = random chance, −1 = perfectly backwards. It is the only classification metric guaranteed to give a high score only when the classifier performs well on all four confusion-matrix quadrants.

One-sentence summary: MCC is the phi coefficient (φ) of a 2×2 contingency table — the same statistic statisticians use to measure association between two binary variables, applied to ground-truth vs. predicted labels.

2
The Formula — All Four Cells, No Exceptions

Given a confusion matrix with true positives \(TP\), true negatives \(TN\), false positives \(FP\), and false negatives \(FN\), the MCC is:

$$\mathrm{MCC} = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

The numerator \(TP \cdot TN - FP \cdot FN\) is the determinant of the confusion matrix — positive when the classifier is better than random, zero when performance equals chance, negative when predictions are inverted. The denominator normalises it to \([-1,+1]\) regardless of class imbalance.

⟨⟩ Equivalent Phi-Coefficient Form

Let \(N = TP+TN+FP+FN\), \(S = (TP+FN)/N\) (prevalence), \(P = (TP+FP)/N\) (predicted positive rate). Then:

$$\mathrm{MCC} = \frac{TP/N - S\cdot P}{\sqrt{P(1-P)\,S(1-S)}}$$

This is exactly Pearson's \(\phi\) between the binary vectors \(y_{\text{true}}\) and \(y_{\text{pred}}\).

⚠️ Edge Cases

If any row or column of the confusion matrix is all zeros, the denominator is 0. By convention (and sklearn's implementation), MCC is set to 0 in this case — not undefined, because it genuinely conveys "no better than random."

3
Why F1 & Accuracy Mislead — MCC Doesn't

Both accuracy and F1 ignore at least one confusion-matrix cell:

$$\text{Accuracy} = \frac{TP + TN}{N}\quad\text{(ignores class imbalance by averaging over majority)}$$
$$F_1 = \frac{2\,TP}{2\,TP + FP + FN}\quad\text{(entirely ignores }TN\text{)}$$

MCC's numerator uses all four cells via the determinant. This makes it the recommended summary metric by Chicco & Jurman (2020), who showed that — across thousands of real binary classification benchmarks — MCC is the only metric that does not produce misleadingly optimistic scores for trivial classifiers on imbalanced datasets.

When to Use MCC

Use MCC when:

  • Classes are imbalanced (any ratio ≠ 50/50)
  • Both false positives and false negatives have meaningful costs
  • You want a single metric that cannot be gamed by predicting the majority class
  • Comparing binary classifiers across datasets with different prevalences
  • Medical diagnostics, fraud detection, fault detection — high-stakes, rare-event settings
⚠️ Limitations

MCC does not generalise cleanly to multi-class settings (use the macro-averaged version or R\(_K\) statistic). For soft predictions (probability outputs), prefer AUROC or AUPRC over thresholded MCC.

📌 The One Thing to Remember

MCC = 0 whenever a classifier is no better than random — regardless of class imbalance. This is the property that accuracy and F1 both fail to guarantee.
