Query, Key, Value (QKV) Formulation

The core mechanism behind attention in Transformers
Foundational Deep Learning Transformers Matrix Operations
1
Understanding Q, K, V
▼

What is it? The Q, K, V (Query, Key, Value) formulation is the fundamental concept behind the self-attention mechanism in Transformer models. It allows a neural network to weigh the importance of different parts of an input sequence when processing each element, effectively creating a "context" for every token.

Analogy: Imagine you're searching for videos on YouTube.

  • Your Query (Q) is what you type into the search bar (e.g., "cat videos").
  • Each video has a Key (K) that describes its content (e.g., "funny cats", "cats playing", "cat compilation").
  • Each video also has a Value (V), which is the actual content of the video itself.
The search engine compares your Query to all the Keys. Videos with Keys similar to your Query get higher "attention scores", and their Values (the videos) are weighted more heavily to form your search results. In a Transformer, each word in a sentence acts as both a Query and a Key/Value for every other word (including itself).

💡 If you remember one thing

Q, K, V are three different linear projections of the same input embedding. The Query is used to "ask" for information, Keys are used to "describe" available information, and Values are the "information" itself. Attention is then computed as a weighted sum of the Values, where weights are determined by the similarity between Queries and Keys.

2
How QKV Works Internally
▼

Input Embeddings

The process begins with an input sequence, typically a sentence, where each word (or token) is converted into a numerical vector called an embedding. These embeddings capture semantic meaning. For a sequence of \(N\) tokens, each with an embedding dimension of \(D_{model}\), we get an input matrix \(X\) of shape \((N, D_{model})\).

Linear Transformations

Instead of directly using the input embeddings, the Transformer projects them into three different spaces using three distinct weight matrices: \(W^Q\), \(W^K\), and \(W^V\). These matrices are learned during training.

  • Query Matrix (Q): \(Q = X W^Q\)
  • Key Matrix (K): \(K = X W^K\)
  • Value Matrix (V): \(V = X W^V\)
Each weight matrix has dimensions \((D_{model}, D_k)\) for \(W^Q, W^K\) and \((D_{model}, D_v)\) for \(W^V\). Typically, \(D_k = D_v\) and often \(D_k = D_{model} / \text{num_heads}\) in multi-head attention. For simplicity, we'll assume \(D_k = D_v = D_{model}\) in this explainer.

Attention Scores (Similarity)

The core idea is to determine how much "attention" each word (Query) should pay to every other word (Key). This is done by computing a dot product similarity between each Query vector and all Key vectors. This results in a matrix of attention scores:

$$\text{Scores} = Q K^\top$$

If \(Q\) is \((N, D_k)\) and \(K^\top\) is \((D_k, N)\), then \(\text{Scores}\) is an \((N, N)\) matrix. Each entry \(\text{Scores}_{ij}\) represents how relevant the \(j\)-th token (Key) is to the \(i\)-th token (Query).

Scaling and Softmax

To prevent the dot products from growing too large (which can push the softmax function into regions with very small gradients), the scores are scaled by the square root of the key dimension, \(\sqrt{D_k}\). Then, a softmax function is applied row-wise to normalize these scores into a probability distribution, ensuring they sum to 1 for each Query:

$$\text{Attention Weights} = \text{Softmax}\left(\frac{Q K^\top}{\sqrt{D_k}}\right)$$

These attention weights indicate the actual "importance" or "focus" each Query places on each Key.

Weighted Sum of Values

Finally, these attention weights are used to take a weighted sum of the Value vectors. Each row of the resulting output matrix is a new representation for a token, enriched by information from other tokens, weighted by their relevance:

$$\text{Output} = \text{Attention Weights} \cdot V$$

This output matrix \((N, D_v)\) contains the context-aware representations that are then passed to the next layer of the Transformer.

🔑 Key Property

The QKV mechanism allows for dynamic weighting of input elements. Unlike fixed convolutional filters or recurrent connections, the attention weights are computed on-the-fly based on the relationships between tokens, making it highly adaptive to different contexts and long-range dependencies.

3
Why It Works — The Math
▼

The Attention Function

The entire self-attention mechanism can be summarized by a single equation, often referred to as "Scaled Dot-Product Attention":

$$\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{Q K^\top}{\sqrt{D_k}}\right) V$$

Let's break down the dimensions and operations:

Given an input matrix \(X \in \mathbb{R}^{N \times D_{model}}\) where \(N\) is the sequence length and \(D_{model}\) is the embedding dimension.

We define three weight matrices:

  • \(W^Q \in \mathbb{R}^{D_{model} \times D_k}\)
  • \(W^K \in \mathbb{R}^{D_{model} \times D_k}\)
  • \(W^V \in \mathbb{R}^{D_{model} \times D_v}\)

The Query, Key, and Value matrices are then computed as:

$$Q = X W^Q \in \mathbb{R}^{N \times D_k}$$ $$K = X W^K \in \mathbb{R}^{N \times D_k}$$ $$V = X W^V \in \mathbb{R}^{N \times D_v}$$

The dot product \(Q K^\top\) calculates the similarity between each query vector and all key vectors. If \(q_i\) is the \(i\)-th row of \(Q\) and \(k_j\) is the \(j\)-th row of \(K\), then \((Q K^\top)_{ij} = q_i \cdot k_j\). This matrix is \(\in \mathbb{R}^{N \times N}\).

The scaling factor \(\frac{1}{\sqrt{D_k}}\) is crucial. Without it, for large values of \(D_k\), the dot products can become very large in magnitude, pushing the softmax function towards extreme values (0 or 1). This results in very small gradients, hindering effective learning. Dividing by \(\sqrt{D_k}\) helps stabilize the gradients, especially during backpropagation.

Finally, the softmax function is applied row-wise to the scaled scores. For each row \(i\) of the scaled scores matrix, the softmax computes:

$$\text{Softmax}(\text{row}_i) = \left[ \frac{e^{\text{score}_{i1}}}{\sum_j e^{\text{score}_{ij}}}, \dots, \frac{e^{\text{score}_{iN}}}{\sum_j e^{\text{score}_{ij}}} \right]$$

This produces the attention weights matrix \(\text{Attention Weights} \in \mathbb{R}^{N \times N}\), where each row sums to 1. Multiplying this by \(V \in \mathbb{R}^{N \times D_v}\) yields the final output \(\text{Output} \in \mathbb{R}^{N \times D_v}\), where each output vector is a weighted sum of the original value vectors.

⚠️ Importance of Distinct Projections

Using separate \(W^Q, W^K, W^V\) matrices is critical. If we used the same projection (or no projection at all), the Query, Key, and Value vectors would be identical. This would simplify the attention mechanism, but greatly reduce its expressiveness and ability to learn complex relationships, as it would always be comparing and weighting the same underlying information.

Key Takeaways
▼

Why QKV is powerful:

  • Contextualization: Each token's representation is updated based on its relationship with all other tokens, creating rich, context-aware embeddings.
  • Parallelization: Matrix multiplications allow for efficient parallel computation, a key advantage of Transformers over sequential models like RNNs.
  • Long-Range Dependencies: Attention can directly connect any two tokens in a sequence, regardless of their distance, effectively solving the long-range dependency problem.
  • Interpretability (to an extent): The attention weights can offer some insight into which parts of the input the model is focusing on for a given output.

Where QKV is used:

  • Transformers: The foundational component of the Transformer architecture, used in both encoder and decoder blocks.
  • Large Language Models (LLMs): GPT, BERT, Llama, etc., all rely heavily on the QKV mechanism for their impressive capabilities.
  • Vision Transformers (ViT): Adapting Transformers for image processing, where image patches are treated as tokens.
  • Other Attention Mechanisms: While dot-product attention is most common, the QKV concept is generalized in other attention variants.
💡 Beyond Self-Attention

The QKV formulation isn't limited to self-attention (where Q, K, V come from the same source). In a Transformer decoder, cross-attention uses Queries from the decoder's previous output and Keys/Values from the encoder's output, allowing the decoder to focus on relevant parts of the input sequence.

Code Trace
▼
import numpy as np
# --- Configuration ---
num_tokens = 3
embedding_dim = 2 # D_model
dk = 2 # D_k (dimension of Q, K)
dv = 2 # D_v (dimension of V)
# --- Input Embeddings (X) ---
# Example: 3 tokens, each with a 2-dim embedding
X = np.array([[1.0, 0.5], # Token 1 embedding
[0.8, 1.2], # Token 2 embedding
[0.2, 0.9]])# Token 3 embedding
# --- Weight Matrices (learned during training) ---
# Wq, Wk: (embedding_dim, dk) ; Wv: (embedding_dim, dv)
Wq = np.array([[0.6, 0.3], [0.1, 0.7]])
Wk = np.array([[0.2, 0.8], [0.9, 0.4]])
Wv = np.array([[0.5, 0.2], [0.7, 0.9]])
# --- 1. Compute Q, K, V ---
Q = X @ Wq
K = X @ Wk
V = X @ Wv
# --- 2. Compute Attention Scores (QKᵀ) ---
attention_scores = Q @ K.T
# --- 3. Scale Scores ---
scaled_scores = attention_scores / np.sqrt(dk)
# --- 4. Apply Softmax to get Attention Weights ---
def softmax(x):
exp_x = np.exp(x - np.max(x, axis=-1, keepdims=True))
return exp_x / np.sum(exp_x, axis=-1, keepdims=True)
attention_weights = softmax(scaled_scores)
# --- 5. Compute Output (Weighted sum of Values) ---
output = attention_weights @ V
print("Q:\n", Q)
print("K:\n", K)
print("V:\n", V)
print("Attention Scores:\n", attention_scores)
print("Attention Weights:\n", attention_weights)
print("Output:\n", output)
