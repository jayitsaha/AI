Understanding hard vs. soft clustering and flexible cluster shapes
Foundational Classical ML Unsupervised O(nkd) per iter
1
Understanding GMM and K-Means
▼

What are they? Both K-Means and Gaussian Mixture Models (GMM) are clustering algorithms aiming to group similar data points together. However, they differ fundamentally in how they define "similarity" and "group membership":

  • K-Means assigns each data point to exactly one cluster (hard assignment). It assumes clusters are spherical and of equal size, defined solely by their central mean (centroid).
  • GMM assigns each data point a probability of belonging to each cluster (soft assignment). It models each cluster as a Gaussian distribution, allowing for elliptical shapes, varying sizes, and different orientations, captured by a full covariance matrix.

Analogy: Imagine you're organizing a school dance where students naturally form groups. K-Means is like a teacher who rigidly assigns each student to the *closest* group of friends. If a student is exactly equidistant between two groups, the teacher makes a hard, arbitrary choice. All groups are assumed to be perfect circles of similar size. GMM is like a sociologist observing the dance. They recognize that students might be part of several groups, with varying degrees of belonging. Some groups are more spread out, some are elongated, and some are denser. The sociologist assigns a probability to each student for each group, reflecting this nuanced reality.

💡 If you remember one thing

K-Means is a centroid-based, hard clustering algorithm assuming spherical clusters. GMM is a probabilistic, generative model that assumes data points are generated from a mixture of Gaussian distributions, allowing for soft assignments and flexible, elliptical cluster shapes.

2
How They Work Internally
▼

K-Means: The Iterative Assignment

K-Means operates through an iterative refinement process to minimize the sum of squared distances between data points and their assigned cluster centroids:

  1. Initialization: Randomly select \(K\) data points as initial cluster centroids.
  2. Assignment Step: Assign each data point to the cluster whose centroid is closest (Euclidean distance). This forms hard cluster assignments.
  3. Update Step: Recalculate the centroids as the mean of all data points assigned to that cluster.
  4. Repeat: Steps 2 and 3 until cluster assignments no longer change or a maximum number of iterations is reached.

K-Means is computationally efficient and works well when clusters are well-separated, spherical, and of similar density.

GMM: The Expectation-Maximization (EM) Algorithm

GMM uses the Expectation-Maximization (EM) algorithm to find the parameters of the Gaussian mixture components (means \(\mu_k\), covariances \(\Sigma_k\), and mixing coefficients \(\pi_k\)) that best explain the observed data. EM is an iterative two-step process:

  1. Initialization: Randomly initialize the parameters for \(K\) Gaussian components. Often, K-Means results are used for initial means and covariances.
  2. E-step (Expectation): For each data point, calculate the "responsibility" (posterior probability) that each Gaussian component takes for generating that point. This is the "soft assignment."
    $$ \gamma(z_{nk}) = P(z_{nk}=1 | x_n, \mu, \Sigma, \pi) = \frac{\pi_k \mathcal{N}(x_n | \mu_k, \Sigma_k)}{\sum_{j=1}^K \pi_j \mathcal{N}(x_n | \mu_j, \Sigma_j)} $$
    Where \(\mathcal{N}(x | \mu, \Sigma)\) is the multivariate Gaussian probability density function.
  3. M-step (Maximization): Update the parameters (\(\mu_k, \Sigma_k, \pi_k\)) of each Gaussian component using the responsibilities calculated in the E-step. The responsibilities act as "soft counts" for each data point belonging to a cluster.
  4. Repeat: Steps 2 and 3 until the change in log-likelihood of the data falls below a threshold or a maximum number of iterations is reached.

Design Decision: Covariance Types in GMM

The flexibility of GMM's cluster shapes comes from its covariance matrices \(\Sigma_k\). Different constraints can be placed on these matrices:

  • Full (default): Each component has its own arbitrary covariance matrix, allowing for ellipses of any size, shape, and orientation. This is the most flexible but requires more parameters and is prone to overfitting with sparse data.
  • Diagonal: Each component has its own diagonal covariance matrix. This means the principal axes of the ellipses are aligned with the coordinate axes (no rotation), but they can have different variances along each dimension.
  • Spherical: Each component has its own spherical covariance matrix, meaning \(\Sigma_k = \sigma_k^2 I\). This forces clusters to be circular, but allows them to have different radii. This is essentially K-Means with soft assignments.
  • Tied/Shared: All components share the same covariance matrix, \(\Sigma_k = \Sigma\). This reduces parameters but might not fit complex data well.
🔑 Key Property

K-Means minimizes within-cluster variance assuming spherical clusters. GMM maximizes the likelihood of data under a mixture of Gaussians, providing probabilistic assignments and capturing complex cluster geometries through flexible covariance matrices, making it a more powerful (but more complex) model.

Why It Works — The Math
▼

The Multivariate Gaussian PDF

The core of GMM is the multivariate Gaussian probability density function for a data point \(x\) with mean \(\mu\) and covariance \(\Sigma\):

$$ \mathcal{N}(x | \mu, \Sigma) = \frac{1}{\sqrt{(2\pi)^D |\Sigma|}} \exp\left(-\frac{1}{2}(x-\mu)^\top \Sigma^{-1} (x-\mu)\right) $$

where \(D\) is the dimensionality of the data, and \(|\Sigma|\) is the determinant of the covariance matrix. This function gives the likelihood of observing data point \(x\) if it were generated by that specific Gaussian component.

E-step: Calculating Responsibilities

The E-step computes the posterior probability (responsibility) that component \(k\) generated data point \(x_n\), given the current model parameters. This is a direct application of Bayes' Theorem:

$$ \gamma(z_{nk}) = P(z_{nk}=1 | x_n, \theta) = \frac{P(x_n | z_{nk}=1, \theta) P(z_{nk}=1 | \theta)}{P(x_n | \theta)} = \frac{\mathcal{N}(x_n | \mu_k, \Sigma_k) \pi_k}{\sum_{j=1}^K \mathcal{N}(x_n | \mu_j, \Sigma_j) \pi_j} $$

Here, \(\theta = \{\pi_k, \mu_k, \Sigma_k\}_{k=1}^K\) are the model parameters. The numerator is the joint probability of \(x_n\) and \(z_{nk}=1\), and the denominator is the marginal probability of \(x_n\), which acts as a normalizing constant ensuring \(\sum_k \gamma(z_{nk}) = 1\) for each point \(x_n\).

M-step: Updating Parameters

The M-step updates the parameters by maximizing the expected complete-data log-likelihood (which is a lower bound on the true log-likelihood). The updates are weighted averages, where the weights are the responsibilities \(\gamma(z_{nk})\). Let \(N_k = \sum_{n=1}^N \gamma(z_{nk})\) be the effective number of points assigned to cluster \(k\):

Update Mean: The new mean \(\mu_k^{new}\) is the weighted average of all data points:

$$ \mu_k^{new} = \frac{1}{N_k} \sum_{n=1}^N \gamma(z_{nk}) x_n $$

Update Covariance: The new covariance \(\Sigma_k^{new}\) is the weighted outer product of differences from the mean:

$$ \Sigma_k^{new} = \frac{1}{N_k} \sum_{n=1}^N \gamma(z_{nk}) (x_n - \mu_k^{new})(x_n - \mu_k^{new})^\top $$

Update Mixing Coefficient: The new mixing coefficient \(\pi_k^{new}\) is the proportion of points effectively assigned to cluster \(k\):

$$ \pi_k^{new} = \frac{N_k}{N} $$
⚠️ Common Pitfall

GMM is susceptible to singularities. If a Gaussian component's covariance matrix becomes singular (e.g., if it perfectly fits a single data point), its likelihood can go to infinity, causing numerical instability. Regularization (adding a small value to the diagonal of \(\Sigma\)) or careful initialization can mitigate this.

Key Takeaways
▼

When to use K-Means:

  • When you expect clusters to be spherical, roughly equal in size, and well-separated.
  • When computational efficiency is paramount, especially for very large datasets.
  • When you need hard assignments (each point belongs to exactly one cluster).
  • As an initialization step for GMM.

When to use GMM:

  • When you expect clusters to have varying sizes, elliptical shapes, or different orientations.
  • When clusters overlap, and you need soft assignments (probabilistic membership).
  • For anomaly detection (points with low probability under all components can be considered outliers).
  • When you need a generative model of the data's underlying distribution.

When NOT to use:

  • K-Means: For non-convex cluster shapes, clusters of vastly different densities, or when soft assignments are needed. It's also sensitive to outliers.
  • GMM: Can be computationally expensive for very large datasets or high dimensions (especially with full covariance). It's also sensitive to initialization and can suffer from singularities if not properly regularized. Choosing the right number of components \(K\) is also more complex than for K-Means (often using AIC/BIC).
💡 Generative vs. Discriminative

K-Means is a discriminative algorithm that focuses on partitioning the data. GMM is a generative model that learns the underlying probability distributions that generated the data. This distinction gives GMM its power to model more complex data structures.

Code Trace (Python-like Pseudocode)
▼
import numpy as np
from scipy.stats import multivariate_normal
# --- K-Means Pseudocode ---
def kmeans(X, K, max_iters=100):
# 1. Initialize K centroids randomly
centroids = X[np.random.choice(X.shape[0], K, replace=False)]
for i in range(max_iters):
# 2. Assignment Step: Assign each point to closest centroid
distances = np.sqrt(((X - centroids[:, np.newaxis])**2).sum(axis=2))
labels = np.argmin(distances, axis=0) # Hard assignment
# 3. Update Step: Recalculate centroids
new_centroids = np.array([X[labels == k].mean(axis=0) for k in range(K)])
if np.allclose(new_centroids, centroids): break
centroids = new_centroids
return labels, centroids
# --- GMM (EM Algorithm) Pseudocode ---
def gmm(X, K, cov_type='full', max_iters=100, tol=1e-3):
N, D = X.shape
# 1. Initialize parameters (means, covariances, mixing coefficients)
# (e.g., using K-Means for initial means)
means = X[np.random.choice(N, K, replace=False)]
covariances = [np.eye(D) for _ in range(K)] # Initial spherical
weights = np.ones(K) / K # Equal mixing coefficients
log_likelihood_prev = -np.inf
for i in range(max_iters):
# E-step: Calculate responsibilities (gamma)
responsibilities = np.zeros((N, K))
for k in range(K):
responsibilities[:, k] = weights[k] * multivariate_normal.pdf(X, mean=means[k], cov=covariances[k])
responsibilities /= responsibilities.sum(axis=1)[:, np.newaxis] # Normalize
# M-step: Update parameters
Nk = responsibilities.sum(axis=0) # Effective number of points
weights = Nk / N
means = (responsibilities.T @ X) / Nk[:, np.newaxis]
for k in range(K):
diff = X - means[k]
cov_k = (responsibilities[:, k, np.newaxis] * diff).T @ diff / Nk[k]
if cov_type == 'spherical':
covariances[k] = np.eye(D) * np.mean(np.diag(cov_k))
elif cov_type == 'diagonal':
covariances[k] = np.diag(np.diag(cov_k))
else: # 'full'
covariances[k] = cov_k + 1e-6 * np.eye(D) # Regularization
# Check for convergence (log-likelihood)
log_likelihood = np.sum(np.log(np.sum(responsibilities, axis=1)))
if abs(log_likelihood - log_likelihood_prev) < tol: break
log_likelihood_prev = log_likelihood
return responsibilities, means, covariances, weights
