Understanding SVD-Based Recommendations
▼

What is it? Netflix knows you loved Inception and The Matrix but skipped romantic comedies. Spotify knows you stream jazz at 2 am. These systems face a core problem: a giant table of users × items, where most entries are blank (you haven't watched 99.9% of Netflix's catalog). The challenge is to fill in the blanks — predict what rating you'd give to unseen items.

Analogy: Imagine summarising every reader's taste in books using just two numbers: "how much they love action" and "how much they love romance." If you know those two numbers for every reader, and the same two numbers for every book (its genre mix), you can predict any reader's rating for any book by taking a dot product. SVD discovers these hidden taste dimensions automatically from the rating data — you never have to label the genres yourself.

If you remember one thing

A rating matrix \(R \in \mathbb{R}^{m \times n}\) (users × items) is approximately low-rank. SVD finds the best rank-\(k\) approximation \(R \approx U_k \Sigma_k V_k^\top\), exposing \(k\) hidden "taste factors." Predicted rating: \(\hat{r}_{ui} = \mathbf{p}_u \cdot \mathbf{q}_i\) where \(\mathbf{p}_u\) and \(\mathbf{q}_i\) are \(k\)-dimensional latent vectors.

2
How It Works — Decomposition to Prediction
▼

Step 1: The Rating Matrix

Collect all known ratings into a matrix \(R\) of shape \(m \times n\) (users × items). Most entries are missing — in real systems, sparsity exceeds 99%. The collaborative filtering assumption is that similar users rate similar items similarly, so patterns exist to exploit.

Step 2: Truncated SVD

Any real matrix has an exact SVD: \(R = U \Sigma V^\top\), where \(U \in \mathbb{R}^{m \times m}\) (user eigenvectors), \(\Sigma \in \mathbb{R}^{m \times n}\) (diagonal singular values in descending order), and \(V^\top \in \mathbb{R}^{n \times n}\) (item eigenvectors). The truncated version keeps only the top \(k\) singular values:

$$R \approx U_k \Sigma_k V_k^\top = \sum_{j=1}^{k} \sigma_j \mathbf{u}_j \mathbf{v}_j^\top$$

Each term \(\sigma_j \mathbf{u}_j \mathbf{v}_j^\top\) is a rank-1 "taste pattern" — one latent factor capturing a theme (e.g., action films, arthouse, thriller). By Eckart–Young theorem, this is the best rank-\(k\) approximation in Frobenius norm.

Step 3: Factor Matrices & Predictions

Define user factor matrix \(P = U_k \Sigma_k^{1/2} \in \mathbb{R}^{m \times k}\) and item factor matrix \(Q = V_k \Sigma_k^{1/2} \in \mathbb{R}^{n \times k}\), so \(R \approx PQ^\top\). Predicting an unobserved rating is just a dot product:

$$\hat{r}_{ui} = \mathbf{p}_u \cdot \mathbf{q}_i = \sum_{j=1}^{k} p_{uj} \cdot q_{ij}$$
Key Insight: Why Low-Rank Works

User preferences are driven by a small number of themes (genre, pace, era…). A matrix generated by \(k\) independent taste axes is exactly rank \(k\). Real ratings are approximately generated this way, so a low-rank approximation captures most variance. The top singular values typically account for 80–99% of the signal.

Step 4: From Pure SVD to Learned Matrix Factorization (FunkSVD)

Pure SVD requires a complete matrix, but we only observe a tiny fraction of ratings. Simon Funk's 2006 breakthrough: learn \(P\) and \(Q\) directly by minimising prediction error only on observed entries, with \(\ell_2\) regularization to prevent overfitting:

$$\min_{P,Q} \sum_{(u,i)\in\mathcal{K}} \left(r_{ui} - \mathbf{p}_u \cdot \mathbf{q}_i\right)^2 + \lambda\left(\|\mathbf{p}_u\|^2 + \|\mathbf{q}_i\|^2\right)$$

This is optimised via stochastic gradient descent (SGD). The update rule for each observed rating:

$$e_{ui} = r_{ui} - \mathbf{p}_u \cdot \mathbf{q}_i, \quad \mathbf{p}_u \mathrel{+}= \eta (e_{ui}\, \mathbf{q}_i - \lambda\, \mathbf{p}_u), \quad \mathbf{q}_i \mathrel{+}= \eta (e_{ui}\, \mathbf{p}_u - \lambda\, \mathbf{q}_i)$$
Common Pitfall

Pure SVD on an incomplete matrix (by filling missing entries with 0 or mean) introduces systematic bias. FunkSVD/ALS trains only on known entries, which is the correct approach. Zero-filling would make the model think unrated items are rated 0.

3
Why It Works — Math & Bias Extension
▼

Eckart–Young–Mirsky Theorem

For any matrix \(R\) with SVD \(R = U\Sigma V^\top\), the best rank-\(k\) approximation in both Frobenius and spectral norm is:

$$R_k = \sum_{j=1}^k \sigma_j \mathbf{u}_j \mathbf{v}_j^\top, \quad \|R - R_k\|_F = \sqrt{\sigma_{k+1}^2 + \cdots + \sigma_r^2}$$

No other rank-\(k\) matrix achieves smaller reconstruction error. This guarantees the truncated SVD is an optimal feature extractor.

Bias-Augmented Model (Koren 2008)

Pure dot products miss global tendencies (some users rate high, some items are universally loved). The full biased model adds a global mean \(\mu\), user bias \(b_u\), and item bias \(b_i\):

$$\hat{r}_{ui} = \mu + b_u + b_i + \mathbf{p}_u \cdot \mathbf{q}_i$$

These biases absorb "user is strict/lenient" and "item is good/bad overall," leaving the latent factors free to capture interaction effects (this user loves this type of item specifically).

Alternating Least Squares (ALS)

For large-scale systems (e.g., Spark MLlib), ALS alternates between closed-form solutions: fixing \(Q\), each row of \(P\) is a ridge regression; fixing \(P\), each row of \(Q\) is a ridge regression. This is trivially parallelizable across users/items:

$$\mathbf{p}_u = \left(Q_u^\top Q_u + \lambda I\right)^{-1} Q_u^\top \mathbf{r}_u$$

where \(Q_u\) selects rows of \(Q\) for items rated by user \(u\), and \(\mathbf{r}_u\) is the vector of those ratings.

Key Takeaways & Method Comparison
▼

SVD family evolution:

  • Truncated SVD: Requires complete matrix; computationally clean but impractical for sparse data
  • FunkSVD: SGD on observed entries only; the Netflix Prize breakthrough (2006); no bias terms
  • SVD++ (Koren 2008): Adds implicit feedback (what you click, not just rate) to item factors
  • TimeSVD++: Adds temporal drift — tastes change over time
  • ALS (Spark MLlib): Distributed closed-form; scales to billions of ratings
When to Use Matrix Factorization

Use it when you have dense interaction history (e-commerce, streaming), need interpretable latent factors, and care about scalability. Don't use it for cold-start (new users/items with no history), or when content features (text, images) are more informative than interaction patterns.

Modern successors: Neural Collaborative Filtering (NCF) replaces dot products with MLPs; Two-Tower models learn separate user/item embeddings via deep networks; BERT4Rec models the sequence of interactions with transformers. Matrix factorization remains the interpretable, scalable baseline that all of these are compared against.

import numpy as np
# Rating matrix: 4 users x 5 items, 0 = missing
R = np.array([[5,4,1,1,5],[4,3,3,3,4],[2,1,5,4,2],[0,2,4,5,1]], dtype=float)
mask = R > 0 # which entries are observed
# ── Truncated SVD (requires complete matrix; fill missing w/ column mean) ──
R_filled = R.copy()
col_means = np.nanmean(np.where(mask, R, np.nan), axis=0)
R_filled[~mask] = col_means[np.where(~mask)[1]]
U, s, Vt = np.linalg.svd(R_filled, full_matrices=False)
k = 2 # number of latent factors
P = U[:, :k] * np.sqrt(s[:k]) # user factors (4 x 2)
Q = Vt[:k, :].T * np.sqrt(s[:k]) # item factors (5 x 2)
R_approx = P @ Q.T # predictions for ALL entries
# ── FunkSVD: SGD on observed entries only (correct approach) ──
P_sgd = np.random.normal(0, 0.1, (4, k))
Q_sgd = np.random.normal(0, 0.1, (5, k))
lr, reg = 0.01, 0.02
for epoch in range(200):
for u, i in zip(*np.where(mask)):
e = R[u,i] - P_sgd[u] @ Q_sgd[i] # prediction error
P_sgd[u] += lr * (e * Q_sgd[i] - reg * P_sgd[u])
Q_sgd[i] += lr * (e * P_sgd[u] - reg * Q_sgd[i])
# Predict missing rating (Dave x Matrix)
pred_dave_matrix = P_sgd[3] @ Q_sgd[0] # should be ~3-4 (Dave likes action a bit)
print(f"Predicted: {pred_dave_matrix:.2f}")
