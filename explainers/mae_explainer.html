Mean Absolute Error (MAE)

Regression loss · L1 penalty · minimized by the median
Foundational Classical ML Evaluation O(n) computation
1
Understanding the Concept

What is MAE? When a model predicts a number (like house price or temperature tomorrow), it will never be perfect. MAE measures how wrong the model is on average — but it measures errors in the most intuitive way: just take each prediction, measure how far off it is (ignoring the direction), and average those gaps.

Everyday analogy: Imagine you're estimating how long 10 tasks will take. You guess 5 min, 10 min, 8 min, ... After they're done, some tasks took longer, some shorter. MAE is the average of "how many minutes off was each guess?" — not caring if you overestimated or underestimated.

💡 If you remember one thing

MAE = average of |actual − predicted|. It treats all errors equally (linear penalty), is robust to outliers, and is minimized by the median (not the mean) of the target distribution.

The defining formula: given \(n\) samples with true values \(y_i\) and predictions \(\hat{y}_i\),

$$\text{MAE} = \frac{1}{n}\sum_{i=1}^{n}\left|y_i - \hat{y}_i\right|$$
2
Geometry: L1 vs L2 Loss

MAE is the L1 loss. MSE (Mean Squared Error) is the L2 loss. The key geometric difference: L1 penalises errors linearly — double the error, double the penalty. L2 penalises errors quadratically — double the error, quadruple the penalty.

📐 Geometric insight

The L1 "ball" (unit ball under L1 norm) is a diamond / rhombus in 2D. The L2 ball is a circle. This diamond shape has corners on the axes — so when you minimise L1 loss, solutions tend to be sparse (many parameters exactly zero), exactly as in LASSO regression.

Why the median minimises MAE: Take a single scalar. The value \(c\) that minimises \(\sum_i |y_i - c|\) is the sample median. Proof sketch: move \(c\) up by \(\epsilon\) — every point below \(c\) increases loss by \(\epsilon\), every point above \(c\) decreases by \(\epsilon\). The optimal \(c\) is where these cancel: the median. Contrast with MSE, which is minimised by the mean.

⚠️ Common mistake

People say "MAE is robust to outliers" and leave it there. The deeper reason: an outlier at distance 100 contributes +100 to MAE but +10,000 to MSE. MAE's linear growth means outliers don't dominate the gradient signal. The optimal prediction shifts toward the outlier much less than under MSE.

3
The Math — Gradient & Subgradient

MAE is not everywhere differentiable — the absolute value \(|r|\) has a kink at \(r=0\). The subgradient (generalised derivative) of \(|r|\) w.r.t. \(r\) is:

$$\frac{\partial}{\partial r}|r| = \text{sign}(r) = \begin{cases} +1 & r > 0 \\ [-1,+1] & r = 0 \\ -1 & r < 0 \end{cases}$$

So the gradient of MAE w.r.t. each prediction \(\hat{y}_i\) is:

$$\frac{\partial \,\text{MAE}}{\partial \hat{y}_i} = -\frac{1}{n}\,\text{sign}(y_i - \hat{y}_i)$$

This is constant magnitude \(\tfrac{1}{n}\) regardless of error size — the gradient does NOT explode for large errors (unlike MSE where gradient \(\propto e_i\)). This is both the source of robustness and a training challenge: near optimum the gradient is still \(\pm 1/n\), giving no "fine-tuning" signal.

∑ Key identities

Optimal constant predictor: \(\hat{y}^* = \text{median}(y_1,\ldots,y_n)\)  |  Units: same as \(y\) (interpretable)  |  Range: \([0, \infty)\)  |  Scale: \(\text{MAE} \leq \text{RMSE} \leq \sqrt{n}\cdot\text{MAE}\)

Huber loss — a smooth hybrid — is \(\delta\)-piecewise: quadratic for \(|r|\leq\delta\), linear (like MAE) for \(|r|>\delta\). It has a proper gradient everywhere and recovers MAE as \(\delta\to 0\).

$$L_\delta(r)=\begin{cases}\tfrac{1}{2}r^2 & |r|\le\delta\\\delta\left(|r|-\tfrac{1}{2}\delta\right) & |r|>\delta\end{cases}$$

🎯 Decision guide

Use MAE when outliers are real and should not dominate; when interpretability matters (same units as target); or when the cost of error is truly linear. Use MSE when all errors matter equally and you need smooth gradients. Use Huber for a balance. Use MAPE only when relative error matters and \(y \gg 0\).
