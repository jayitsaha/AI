1
Understanding PAC Learning & VC Dimension
▼

What is this? Two of the deepest questions in machine learning are: When is it even possible for an algorithm to learn from examples? and How many examples are enough? PAC (Probably Approximately Correct) learning gives a rigorous mathematical answer. The VC (Vapnik-Chervonenkis) dimension measures a hypothesis class's expressiveness — its capacity to "memorize" labels — and turns out to be the exact criterion that determines learnability.

Analogy: Imagine you're playing a guessing game. Someone picks a rule (say, "all red circles"), and you see labeled examples (this shape fits the rule / this one doesn't). PAC learning asks: "How many examples do you need before you can guess the rule well, no matter which rule they picked?" The VC dimension measures how "flexible" your set of guesses is. If your rules are too flexible (infinite VC dim), no finite sample suffices. If they're just right, a manageable number of examples pins down the rule reliably.

If you remember one thing

VC dimension = the size of the largest set that your hypothesis class can shatter (realize all \(2^n\) labelings). Linear classifiers in \(\mathbb{R}^2\) have VC dim 3 — they can label any 3 points in general position any way you like, but no 4 points. PAC learning requires finite VC dim: sample complexity \(m = O\!\left(\frac{d + \log(1/\delta)}{\varepsilon}\right)\) where \(d\) = VC dim.

2
Shattering, Growth Functions & the Sauer-Shelah Lemma
▼

Shattering

A hypothesis class \(\mathcal{H}\) shatters a set \(C = \{x_1,\ldots,x_n\}\) if for every binary labeling \(b \in \{0,1\}^n\), there exists some \(h \in \mathcal{H}\) that correctly assigns those labels. Formally:

$$\mathcal{H} \text{ shatters } C \iff |\{(h(x_1),\ldots,h(x_n)) : h \in \mathcal{H}\}| = 2^n$$

The VC dimension of \(\mathcal{H}\) is the size of the largest set it can shatter:

$$\operatorname{VCdim}(\mathcal{H}) = \max\{|C| : \mathcal{H} \text{ shatters } C\}$$

Growth Function

The growth function \(\Pi_\mathcal{H}(m)\) counts the maximum number of distinct dichotomies (binary labelings) that \(\mathcal{H}\) can produce on any \(m\) points:

$$\Pi_\mathcal{H}(m) = \max_{x_1,\ldots,x_m} |\{(h(x_1),\ldots,h(x_m)) : h \in \mathcal{H}\}|$$

If \(\operatorname{VCdim}(\mathcal{H}) = d\), then \(\Pi_\mathcal{H}(m) = 2^m\) for \(m \leq d\), but for \(m > d\), it grows polynomially.

Sauer-Shelah Lemma

This is the key combinatorial lemma that bridges shattering and generalization:

$$\Pi_\mathcal{H}(m) \leq \sum_{i=0}^{d} \binom{m}{i}$$

For \(m > d\), the right side is at most \(\left(\frac{em}{d}\right)^d\), a polynomial in \(m\). This polynomial growth (vs exponential \(2^m\)) is what makes uniform convergence possible.

Key Insight

For halfplanes in \(\mathbb{R}^2\) with VC dim \(d=3\): on \(m=4\) points, Sauer-Shelah gives \(\Pi \leq \binom{4}{0}+\binom{4}{1}+\binom{4}{2}+\binom{4}{3} = 1+4+6+4 = 15 < 16 = 2^4\). So some labeling of 4 points is always unrealizable.

3
PAC Learnability — The Math
▼

PAC Learning Model (Valiant 1984)

A hypothesis class \(\mathcal{H}\) is PAC learnable if there exists an algorithm \(\mathcal{A}\) and a polynomial function \(m_\mathcal{H}(\varepsilon, \delta)\) such that: for any \(\varepsilon, \delta \in (0,1)\), any distribution \(\mathcal{D}\) over the input space, and any target concept \(c \in \mathcal{H}\), if \(\mathcal{A}\) receives \(m \geq m_\mathcal{H}(\varepsilon,\delta)\) i.i.d. examples from \(\mathcal{D}\) labeled by \(c\), then with probability at least \(1-\delta\):

$$L_\mathcal{D}(h) \leq \varepsilon \quad \text{where } L_\mathcal{D}(h) = \Pr_{x \sim \mathcal{D}}[h(x) \neq c(x)]$$

Finite Hypothesis Classes (Warmup)

For a finite class \(\mathcal{H}\) with \(|\mathcal{H}| < \infty\), uniform convergence gives the bound:

$$m \geq \frac{1}{\varepsilon}\left(\ln|\mathcal{H}| + \ln\frac{1}{\delta}\right)$$

Fundamental Theorem of Statistical Learning

The central theorem connecting VC dimension to PAC learnability (Blumer et al. 1989):

Fundamental Theorem

Let \(\mathcal{H}\) be a hypothesis class of VC dimension \(d\). Then \(\mathcal{H}\) is PAC learnable if and only if \(d < \infty\). Furthermore, the sample complexity satisfies:

$$C_1 \cdot \frac{d + \ln(1/\delta)}{\varepsilon} \leq m_\mathcal{H}(\varepsilon, \delta) \leq C_2 \cdot \frac{d\ln(1/\varepsilon) + \ln(1/\delta)}{\varepsilon}$$

where \(C_1, C_2\) are universal constants. The upper bound comes from the VC generalization bound:

$$\Pr\!\left[\sup_{h \in \mathcal{H}} |L_S(h) - L_\mathcal{D}(h)| > \varepsilon\right] \leq 8\,\Pi_\mathcal{H}(2m)\,e^{-m\varepsilon^2/8}$$

Setting the right side to \(\delta\) and using Sauer-Shelah: \(\Pi_\mathcal{H}(2m) \leq (2m/d)^d\), yields the sample complexity upper bound.

Common Pitfall

Realizability vs Agnostic: The bound above assumes realizability (the true concept is in \(\mathcal{H}\)). In the agnostic setting (noise / model misspecification), the sample complexity grows as \(O(d/\varepsilon^2)\) instead of \(O(d/\varepsilon)\) — a quadratically worse dependence on \(\varepsilon\).

The Big Picture

The Fundamental Theorem of Statistical Learning gives us a clean trichotomy: finite VC dim → PAC learnable → \(O((d/\varepsilon)\log(1/\varepsilon))\) samples suffice. Infinite VC dim means no universal sample bound exists — the hypothesis class is too expressive to generalize from finitely many examples against adversarial distributions.

Nuance

Deep neural networks have enormous (often infinite) VC dimension yet generalize well in practice. This is the "double descent" mystery — classical VC theory gives vacuous bounds for overparameterized models. Modern theory uses algorithmic stability, implicit regularization, and PAC-Bayes to explain this gap.

Code: VC Dim & PAC Bounds in Python
▼
import numpy as np
from math import comb
# ── Sauer-Shelah growth function bound ──────────────────────
def growth_bound(m, d):
"""Upper bound on growth function for VC dim d, m samples."""
return sum(comb(m, i) for i in range(d + 1))
# halfplanes in R^2 have VC dim 3
d = 3
for m in range(1, 8):
bound = growth_bound(m, d)
actual = 2**m
print(f"m={m}: bound={bound}, 2^m={actual}, ratio={bound/actual:.3f}")
# ── PAC sample complexity bounds ─────────────────────────────
def pac_sample_upper(eps, delta, d):
"""Blumer et al. upper bound (realizable case)."""
import math
return int(np.ceil((4/eps) * (2*d*math.log(12/eps) + math.log(2/delta))))
def pac_sample_lower(eps, delta, d):
"""Ehrenfeucht et al. lower bound."""
import math
return int(max((d-1)/(32*eps), math.log(1/(4*delta))/(2*eps)))
eps, delta = 0.1, 0.05
for d in [1, 2, 3, 10, 100]:
lo = pac_sample_lower(eps, delta, d)
hi = pac_sample_upper(eps, delta, d)
print(f"d={d:3d}: need [{lo}, {hi}] samples")
# ── Check XOR is not linearly separable ──────────────────────
X_xor = np.array([[0,0],[1,1],[1,0],[0,1]], dtype=float)
y_xor = np.array([1,1,-1,-1]) # XOR: + + - -
# If linearly separable, SVM dual would find positive margin
from sklearn.svm import SVC
svm = SVC(kernel='linear').fit(X_xor, y_xor)
print("SVM accuracy on XOR:", svm.score(X_xor, y_xor)) # < 1.0
