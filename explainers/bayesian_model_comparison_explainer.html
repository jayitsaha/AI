Bayesian Model Comparison: Bayes Factors & BIC

Comparing models by their marginal likelihood — automatic Occam's razor built in
Advanced Bayesian Inference Probability & Statistics Must Know
1
Understanding the Concept
▼

Imagine you are a scientist who has collected data and now asks: did the signal come from a simple process or a complex one? Bayesian model comparison gives you a principled answer by computing how well each model predicted the data on average — not just at the best-fit parameter values, but integrated over every possible parameter setting.

The central quantity is the Bayes factor: $$\mathrm{BF}_{12} = \frac{p(D \mid M_1)}{p(D \mid M_2)}$$ where \(p(D \mid M_i)\) is the marginal likelihood (model evidence) — the probability of the observed data under model \(M_i\) after averaging out all parameters. A \(\mathrm{BF}_{12} > 10\) is considered strong evidence for \(M_1\); \(\mathrm{BF}_{12} < 0.1\) for \(M_2\).

Key Insight — Automatic Occam's Razor

Because the evidence integrates the likelihood over the prior, a model with extra parameters automatically "pays" for that flexibility: it spreads probability mass over a larger space, reducing the evidence it assigns to the region where the data actually fell. You get complexity penalisation for free — no regularisation hyperparameter needed.

The Bayesian Information Criterion (BIC) is a computationally cheap large-sample approximation: $$\mathrm{BIC} = -2\ln\hat{L} + k\ln n$$ where \(\hat{L}\) is the maximised likelihood, \(k\) the number of free parameters, and \(n\) the sample size. BIC approximates \(-2\ln p(D \mid M)\), so lower BIC = higher evidence, and \(\Delta\mathrm{BIC}/2 \approx \ln\mathrm{BF}_{12}\).

If You Remember One Thing

The Bayes factor compares models by their evidence — the likelihood integrated over parameters. Complex models are automatically penalised because they spread probability thinner. BIC is the tractable large-sample shortcut: prefer the model with lower BIC.

2
How It Works Internally
▼

Step 1 — Set up competing models

Let \(\mathcal{M} = \{M_1, M_2, \ldots, M_K\}\) be a set of candidate models. Each model \(M_i\) specifies a likelihood \(p(D \mid \theta_i, M_i)\) and a prior \(p(\theta_i \mid M_i)\) over its own parameter space \(\Theta_i\).

Step 2 — Compute the model evidence (marginal likelihood)

For each model, integrate the likelihood against the prior: $$p(D \mid M_i) = \int_{\Theta_i} p(D \mid \theta_i, M_i)\, p(\theta_i \mid M_i)\, d\theta_i$$ This integral is often analytically intractable and requires approximation (Laplace, Monte Carlo, variational inference). For conjugate-prior models it is closed-form.

Step 3 — Apply Bayes' theorem at the model level

Just as Bayes' rule updates parameter beliefs, it updates model beliefs: $$P(M_i \mid D) = \frac{p(D \mid M_i)\, P(M_i)}{\sum_j p(D \mid M_j)\, P(M_j)}$$ With equal priors \(P(M_1) = P(M_2)\), the ratio collapses to the Bayes factor: $$\frac{P(M_1 \mid D)}{P(M_2 \mid D)} = \mathrm{BF}_{12} \cdot \frac{P(M_1)}{P(M_2)}$$

Design Decision — Why integrate, not maximise?

Maximum likelihood always favours the more complex model (more parameters → better fit). Integration penalises complexity automatically because a complex model must assign non-trivial prior probability to a much larger parameter space; most of that space fits the data poorly, dragging the integral down. This is the Occam factor.

Numerical trace (Gaussian example, \(n=20\))

Two models for \(y_i \sim \mathcal{N}(\mu_0, \sigma^2)\): M1 sets \(k_1=2\) parameters (intercept + slope), M2 adds a quadratic term (\(k_2=3\)).

n=20, k1=2, k2=3 logL1 = −8.46 logL2 = −8.41 (M2 fits marginally better) BIC1 = 22.92 BIC2 = 25.81 ΔBIC = BIC2 − BIC1 = +2.89 ≈ 2 × ln(BF₁₂) BF₁₂ ≈ exp(1.44) ≈ 4.2 → positive evidence for M1

Despite M2 fitting the data slightly better (lower log-likelihood magnitude), the BIC penalty for the extra parameter makes M1 the preferred model. The Bayes factor of 4.2 is "positive" evidence on the Kass–Raftery scale.

3
The Math: Derivation & BIC Approximation
▼

1. Posterior model probabilities

By Bayes' theorem applied at the model level: $$P(M_i \mid D) \propto p(D \mid M_i)\, P(M_i)$$ With uniform model priors \(P(M_1) = P(M_2)\), the posterior odds equal the Bayes factor: $$\underbrace{\frac{P(M_1 \mid D)}{P(M_2 \mid D)}}_{\text{posterior odds}} = \underbrace{\frac{p(D \mid M_1)}{p(D \mid M_2)}}_{\mathrm{BF}_{12}} \cdot \underbrace{\frac{P(M_1)}{P(M_2)}}_{\text{prior odds}}$$

2. Closed-form marginal likelihood (conjugate case)

For a Gaussian likelihood with Gaussian prior on the mean (\(\sigma^2\) known): $$y_i \mid \mu \sim \mathcal{N}(\mu, \sigma^2), \qquad \mu \sim \mathcal{N}(\mu_0, \tau^2)$$ The marginal likelihood is: $$\ln p(y \mid M) = -\frac{n}{2}\ln(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_i(y_i - \bar{y})^2 - \frac{n(\bar{y}-\mu_0)^2}{2(\sigma^2 + n\tau^2)} - \frac{1}{2}\ln\!\left(1 + \frac{n\tau^2}{\sigma^2}\right)$$ The last two terms are the Occam factor: the log-prior-predictive penalty that grows with model effective complexity \(n\tau^2/\sigma^2\).

3. Laplace approximation (general case)

When the integral is intractable, expand \(\ln p(D \mid \theta)\) to second order around the MLE \(\hat{\theta}\): $$\ln p(D \mid M) \approx \ln p(D \mid \hat{\theta}, M) + \frac{k}{2}\ln(2\pi) - \frac{1}{2}\ln\det\mathcal{H}$$ where \(\mathcal{H} = -\nabla^2_\theta \ln p(D \mid \theta)\big|_{\hat\theta}\) is the observed Fisher information matrix. For \(n\) iid observations, \(\det\mathcal{H} \approx n^k \det\mathcal{I}(\hat\theta)\), giving: $$\ln p(D \mid M) \approx \ln\hat{L} - \frac{k}{2}\ln n + \frac{k}{2}\ln(2\pi) - \frac{1}{2}\ln\det\mathcal{I}(\hat\theta)$$

4. BIC derivation from Laplace

Dropping the terms that are \(O(1)\) relative to the leading \(\ln n\) term: $$\ln p(D \mid M) \approx \ln\hat{L} - \frac{k}{2}\ln n$$ Multiplying by \(-2\): $$\mathrm{BIC} \triangleq -2\ln\hat{L} + k\ln n \approx -2\ln p(D \mid M) + k\ln(2\pi)$$ So \(\mathrm{BIC}_1 - \mathrm{BIC}_2 \approx -2(\ln p(D\mid M_1) - \ln p(D \mid M_2)) = -2\ln\mathrm{BF}_{12}\), meaning: $$\ln\mathrm{BF}_{12} \approx \frac{\mathrm{BIC}_2 - \mathrm{BIC}_1}{2}$$

Core Formulas

\(\mathrm{BF}_{12} = p(D \mid M_1) / p(D \mid M_2)\)

\(\mathrm{BIC} = -2\ln\hat{L} + k\ln n\)

\(\ln\mathrm{BF}_{12} \approx (\mathrm{BIC}_2 - \mathrm{BIC}_1)/2\)

Warning — BIC is prior-free but not assumption-free

BIC assumes (a) flat priors on parameters, (b) the MLE is a good approximation to the posterior mode, and (c) \(n \gg k\). For small \(n\), AIC may be preferable (AIC = \(-2\ln\hat{L} + 2k\), consistent with leave-one-out CV asymptotically). The true Bayes factor requires specifying priors explicitly — BIC is an approximation that avoids this but loses the coherent Bayesian interpretation.

Key Takeaways & When to Use
▼
MethodFormulaRequires prior?Exact?Best for
Bayes Factor\(\mathrm{BF}_{12}\)Yes (full)Yes (conjugate) / approxRigorous hypothesis comparison
BIC\(-2\ln\hat{L}+k\ln n\)No (implicit flat)Approx (large \(n\))Model selection, large datasets
AIC\(-2\ln\hat{L}+2k\)NoNo (CV-consistent)Prediction, small \(n\)

Decision Guide

Use Bayes factors when you have principled priors and want a coherent probabilistic conclusion. Use BIC when priors are hard to specify and \(n\) is large. Use AIC/WAIC when the goal is predictive accuracy on new data.

When NOT to use Bayes Factors

Bayes factors are sensitive to prior specification on parameters — a diffuse prior spreads evidence thin and biases toward simpler models even when the complex model is correct (Lindley's paradox). Avoid using Bayes factors with improper priors: the normalising constant matters for the ratio and undefined constants cancel incorrectly.

Related topics in the vault

Prerequisites: Bayesian inference fundamentals, conjugate priors, maximum likelihood estimation. Successors: Bayesian model averaging, reversible-jump MCMC, variational Bayes, WAIC and LOO-CV.

From Scratch — Bayes Factor via Laplace Approximation

# Bayesian model comparison from scratch import numpy as np from scipy import linalg def log_marginal_likelihood_laplace(X, y, sigma2=1.0): """Laplace approximation to log p(y|M) for linear Gaussian model. Assumes MLE = MAP (flat prior) — this IS BIC up to O(k) constant.""" n, k = X.shape # Compute MLE beta_hat = np.linalg.lstsq(X, y, rcond=None)[0] residuals = y - X @ beta_hat rss = np.dot(residuals, residuals) # Maximum log-likelihood (sigma^2 estimated at MLE) sigma2_hat = rss / n logL_hat = -n/2 * np.log(2*np.pi*sigma2_hat) - n/2 # Laplace: subtract (k/2)*ln(n) (leading term; drop O(1) constants) log_evidence = logL_hat - (k/2) * np.log(n) # BIC = -2 * (logL_hat - (k/2)*ln(n) + (k/2)*ln(2pi)) ≈ -2*log_evidence bic = -2*logL_hat + k*np.log(n) return log_evidence, bic def bayes_factor(logE1, logE2): """BF_12 = exp(logE1 - logE2). Clip to avoid overflow.""" ln_bf = logE1 - logE2 return np.exp(np.clip(ln_bf, -20, 20)), ln_bf # Example np.random.seed(42) n = 50 x = np.linspace(0, 1, n) y = 1 + 2*x + np.random.randn(n)*0.5 X1 = np.column_stack([np.ones(n), x]) # linear (k=2) X2 = np.column_stack([np.ones(n), x, x**2]) # quadratic (k=3) lnE1, bic1 = log_marginal_likelihood_laplace(X1, y) lnE2, bic2 = log_marginal_likelihood_laplace(X2, y) BF12, ln_bf = bayes_factor(lnE1, lnE2) print(f"BF_12 = {BF12:.3f} (ln BF = {ln_bf:.3f})") print(f"BIC1={bic1:.2f}, BIC2={bic2:.2f}, ΔBIC={bic2-bic1:.2f}") # BF_12 ≈ exp(ΔBIC / 2)

Production Usage — PyMC / ArviZ

import pymc as pm import arviz as az # Fit two models and compare via WAIC (preferred over BIC in MCMC workflow) with pm.Model() as M1: alpha = pm.Normal('alpha', 0, 10) beta = pm.Normal('beta', 0, 10) sigma = pm.HalfNormal('sigma', 1) mu = alpha + beta * x obs = pm.Normal('obs', mu, sigma, observed=y) trace1 = pm.sample(1000, tune=1000, progressbar=False) idata1 = az.from_pymc(trace1) with pm.Model() as M2: alpha = pm.Normal('alpha', 0, 10) beta = pm.Normal('beta', 0, 10) gamma = pm.Normal('gamma', 0, 10) # quadratic term sigma = pm.HalfNormal('sigma', 1) mu = alpha + beta*x + gamma*x**2 obs = pm.Normal('obs', mu, sigma, observed=y) trace2 = pm.sample(1000, tune=1000, progressbar=False) idata2 = az.from_pymc(trace2) # Compare via LOO-CV (leave-one-out cross-validation, more reliable than WAIC) comparison = az.compare({"M1": idata1, "M2": idata2}, ic="loo") print(comparison) # ⚠️ Gotcha: az.compare() ranks by loo_i (higher=better); BIC ranks by lower score. # Always check 'p_loo' — values >> k suggest model misspecification.
Common Gotcha

Never compare models that were fit to different datasets or that exclude NaN observations differently. The marginal likelihood must be evaluated on identical data for a valid Bayes factor. Also, sklearn's BIC score uses the convention \(+2\ln\hat{L} - k\ln n\) (negated), so lower sklearn BIC is still better but the sign differs from the statistical convention.
