Understanding Highway Networks
▼

What is it? A Highway Network is a feedforward layer that learns, per unit, how much of its input to transform versus how much to let pass through unchanged. Instead of forcing every layer to reshape its input (as plain stacked layers do), each layer has a gate that can dial anywhere between "fully transform" and "fully carry through," and — crucially — that gate is learned and depends on the input itself.

Analogy: Picture a building where ordinary floors force you to walk through a full renovation crew's workspace (the transformation) on every level. A Highway Network installs an express elevator shaft (the carry path) alongside every floor. A gate at each floor decides, for each passenger, how much time to spend being "renovated" versus riding straight up. Early in training, the gate is set almost fully to "ride straight up" — so a 50-floor building behaves almost like a single floor, and only gradually, as training proceeds, do individual floors learn to do useful work.

💡 If you remember one thing

Highway Networks borrow the LSTM's gating idea and apply it to depth instead of time: $$y = H(x, W_H)\cdot T(x, W_T) + x\cdot\big(1 - T(x, W_T)\big)$$ where \(T\in[0,1]\) is a learned, input-dependent "how much to transform" gate. This was the first architecture (2015) to successfully train plain feedforward nets with 100+ layers via ordinary SGD — a year before ResNet.

How It Works Internally
▼

Three Coupled Sub-Networks

A highway layer computes three quantities from the same input \(x \in \mathbb{R}^n\):

  • Transform block \(H(x, W_H)\) — an ordinary affine layer plus nonlinearity: \(H(x) = \sigma_H(W_H x + b_H)\), typically ReLU or tanh. This does the "real work" of the layer.
  • Transform gate \(T(x, W_T)\) — an affine layer plus sigmoid: \(T(x) = \operatorname{sigmoid}(W_T x + b_T) \in (0,1)^n\), one gate value per unit.
  • Carry gate \(C(x)\) — in the original formulation, simply coupled to the transform gate: \(C(x) = 1 - T(x)\), reusing the same computation (borrowed from the GRU's coupled update/reset gates) instead of learning an independent third network.

Design Decision: Why couple \(C = 1-T\) instead of an independent gate?

An independent carry gate would need its own weight matrix \(W_C\), roughly doubling the gating parameters again. Coupling forces an explicit trade-off — more transform necessarily means less carry — which halves the parameter cost and, empirically, avoids a failure mode where both gates saturate toward 0 and the layer's output collapses to zero regardless of input.

Design Decision: Why initialize \(b_T\) to a negative value?

Setting \(b_T\) to, say, \(-2\) or \(-3\) means \(T(x) \approx \operatorname{sigmoid}(-2\text{ to }-3) \approx 0.05\text{–}0.12\) at the start of training, regardless of \(x\). That makes \(C(x) \approx 0.88\text{–}0.95\), so every layer begins life close to the identity function \(y \approx x\). This is the exact same trick Gers et al. (1999) used for LSTM forget-gate biases: bias the gate toward "pass information through" so gradients have an unobstructed path across depth before the network has learned anything useful. Only as training proceeds do individual units learn to open their transform gates where useful.

🔑 Key Property

Because \(C(x)=1-T(x)\) multiplies the raw input \(x\) directly into the output, every highway layer contains an unimpeded, nearly-linear path from its input to its output whenever \(T\) is small. Stacking such layers gives the whole network a route for information (and gradient) to skip most of the transformation machinery — the same structural idea that ResNet's additive shortcut exploits a year later, just gated instead of fixed.

Why It Works — The Math
▼

The Layer Equation

$$y = H(x, W_H)\odot T(x, W_T) \;+\; x \odot \big(1 - T(x, W_T)\big)$$

where \(\odot\) denotes elementwise (Hadamard) product, so the gate is applied per-unit, not globally.

Gradient Flow Across a Single Layer

Differentiating \(y\) with respect to \(x\) (treating \(H\) and \(T\) as vector functions of \(x\) with Jacobians \(J_H, J_T\)):

$$\frac{\partial y}{\partial x} = \operatorname{diag}\big(1-T(x)\big) \;+\; \operatorname{diag}\big(T(x)\big)\,J_H \;+\; \operatorname{diag}\big(H(x)-x\big)\,J_T$$

The first term, \(\operatorname{diag}(1-T(x)) = \operatorname{diag}(C(x))\), is the crucial one: it is close to the identity matrix whenever \(T(x)\) is near zero. Compare this to a plain layer \(y=\sigma(Wx)\), whose entire Jacobian is \(\operatorname{diag}(\sigma')W\) — no identity term at all, so every layer independently shrinks or amplifies gradient magnitude.

Why Depth Doesn't Kill the Gradient

For an \(L\)-layer stack, the gradient of the loss with respect to the input of layer 1 involves a product of per-layer Jacobians:

$$\frac{\partial \mathcal{L}}{\partial h_0} = \frac{\partial \mathcal{L}}{\partial h_L}\prod_{l=1}^{L}\left[\operatorname{diag}(C_l) + \operatorname{diag}(T_l)J_{H_l} + \operatorname{diag}(H_l-h_{l-1})J_{T_l}\right]$$

In a plain network, each bracketed factor is a Jacobian with no guaranteed structure — if its spectral norm is consistently \(<1\) (very common with saturating nonlinearities and small weights), the product shrinks geometrically with \(L\): classic vanishing gradients. In a highway network with \(b_T\) initialized very negative, each bracketed factor is close to \(\operatorname{diag}(C_l) \approx \operatorname{diag}(0.9\text{–}0.95)\), so the product decays far more slowly and remains well-conditioned for dozens of layers, giving gradients room to actually reach and update early layers.

⚠️ Common Misconception

The carry path is not a perfect identity shortcut like ResNet's \(y=x+F(x)\). Because \(C(x) = 1-T(x) < 1\) strictly whenever \(T(x)>0\), every layer still shrinks the carried signal a little. Highway layers slow the decay dramatically (geometric factor \(\approx 0.9\) instead of \(\approx 0.3\)) — they do not eliminate it. ResNet's unconditional \(+x\) is what later removed this residual decay entirely, which is one reason ResNet displaced Highway Networks in practice.

Key Takeaways
▼

When Highway-style gating helps:

  • Very deep plain (non-convolutional) feedforward stacks trained without normalization layers — the original 900-layer MNIST demo.
  • Character-level language models: a highway layer is the classic bridge between a char-CNN feature extractor and an LSTM (Kim et al., 2016, "Character-Aware Neural Language Models").
  • Any setting where you want a learned, input-dependent skip strength rather than a fixed one.

When NOT to use it / what replaced it:

  • Modern deep CNNs and Transformers — ResNet's unconditional \(y=x+F(x)\) plus BatchNorm/LayerNorm solves the same depth problem with fewer parameters and no extra sigmoid computation per layer.
  • When compute/parameter budget is tight — the transform gate roughly doubles the affine parameters of a layer for a benefit that normalization + additive residuals now deliver more cheaply.

💡 Lineage

Highway Networks (May 2015) proved that a learned identity-biased shortcut lets SGD train arbitrarily deep plain networks. ResNet (December 2015) showed you don't even need the gate — a fixed shortcut works just as well and is simpler. Highway Networks are best understood today as the conceptual bridge between LSTM gating and ResNet's residual connections.

import numpy as np
def sigmoid(z): return 1.0 / (1.0 + np.exp(-z))
def highway_layer(x, W_H, b_H, W_T, b_T):
H = np.tanh(W_H @ x + b_H) # transform block
T = sigmoid(W_T @ x + b_T) # transform gate, T in (0,1)^n
C = 1.0 - T # coupled carry gate
y = H * T + x * C # elementwise gated mix
return y, H, T, C

# => layer starts close to identity: y ~ x, gradients flow freely
# Stacking L highway layers (vs. a plain deep net)
def plain_deep_net(h, weights):
for W in weights:
h = np.tanh(W @ h) # no identity term -> norm can vanish
return h
def highway_deep_net(h, layers):
for (W_H, b_H, W_T, b_T) in layers:
h, _, _, _ = highway_layer(h, W_H, b_H, W_T, b_T)
return h # signal decays far more slowly across depth
