Understanding LeNet-5
▼

What is it? LeNet-5 is a seminal Convolutional Neural Network (CNN) architecture designed by Yann LeCun and his team in 1998. It was one of the first successful applications of CNNs for practical tasks, specifically handwritten digit recognition (e.g., ZIP codes on envelopes). It demonstrated the power of end-to-end learning, local receptive fields, shared weights, and subsampling to build robust visual feature hierarchies.

Analogy: Imagine a highly specialized inspector whose job is to identify digits. Instead of looking at the whole image at once, this inspector has a team of junior inspectors, each trained to spot tiny, specific patterns (like edges, corners, or curves) in small patches of the image. They then pass their summarized findings to a mid-level team, who combine these basic patterns into larger, more abstract features. Finally, a senior team makes the ultimate decision based on all these collected insights. LeNet-5 automates this hierarchical, pattern-detecting process.

💡 If you remember one thing

LeNet-5 established the core principles of modern CNNs: alternating convolutional layers (for feature extraction with local receptive fields and weight sharing) and subsampling layers (for spatial invariance and dimensionality reduction), culminating in fully connected layers for classification. It proved that deep learning could achieve state-of-the-art results on real-world image tasks.

How LeNet-5 Works Internally
▼

The LeNet-5 Architecture: A Classic Stack

LeNet-5 processes 32x32 pixel grayscale images through a sequence of convolutional (C), subsampling (S), and fully connected (F) layers:

  1. Input (32x32x1): The network expects a single-channel grayscale image.
  2. C1: Convolutional Layer (28x28x6):
    • 6 feature maps, each 28x28 pixels.
    • Each feature map uses a 5x5 kernel (filter) with stride 1.
    • Local Receptive Fields: Each neuron in C1 only "sees" a 5x5 patch of the input.
    • Shared Weights: All neurons within a single feature map share the same 5x5 kernel weights, significantly reducing parameters and enabling translation invariance.
  3. S2: Subsampling Layer (14x14x6):
    • 6 feature maps, each 14x14 pixels.
    • Each neuron connects to a non-overlapping 2x2 region in the corresponding C1 feature map.
    • Performs average pooling (subsampling) over the 2x2 region, then multiplies by a learnable weight and adds a learnable bias, followed by a non-linear activation. This is a slightly more complex pooling than modern max-pooling.
    • Spatial Invariance: Reduces spatial resolution, making the network less sensitive to small shifts or distortions in the input.
  4. C3: Convolutional Layer (10x10x16):
    • 16 feature maps, each 10x10 pixels.
    • Each neuron uses a 5x5 kernel.
    • Sparse Connections: Each C3 feature map is connected to only 3 or 4 (out of 6) specific S2 feature maps, not all of them. This was a design choice to limit computation and encourage diverse feature learning in 1998.
  5. S4: Subsampling Layer (5x5x16):
    • 16 feature maps, each 5x5 pixels.
    • Similar to S2, performs average pooling over 2x2 regions from C3 feature maps.
  6. F5: Fully Connected Layer (120 units):
    • Connects to all 400 neurons (5x5x16) from the S4 layer, flattening them into a 1D vector.
    • Each of the 120 units is fully connected to all inputs from S4.
  7. F6: Fully Connected Layer (84 units):
    • Fully connected to all 120 units from F5.
  8. Output Layer (10 units):
    • 10 units, one for each digit (0-9).
    • Uses a Euclidean Radial Basis Function (RBF) layer for classification, where each output unit computes the Euclidean distance between its input vector and its weight vector (a "prototype" for that class). The class with the smallest distance is chosen.
🔑 Key Innovations

LeNet-5 pioneered the combination of local receptive fields, shared weights (convolution), and subsampling (pooling) to build a robust hierarchy of features. This design significantly reduced the number of trainable parameters compared to a fully-connected network of similar depth, making deep learning feasible for image recognition.

Why It Works — The Math
▼

Convolutional Layer Output Dimensions

A fundamental aspect of CNNs is understanding how the spatial dimensions of feature maps change after a convolutional operation. For an input feature map of size \(W \times H \times C_{in}\), a convolutional layer with \(N_f\) filters of size \(F \times F\), stride \(S\), and padding \(P\), the output feature map dimensions \(W' \times H' \times C_{out}\) are given by:

$$W' = \left\lfloor \frac{W - F + 2P}{S} \right\rfloor + 1$$
$$H' = \left\lfloor \frac{H - F + 2P}{S} \right\rfloor + 1$$

And the number of output channels \(C_{out}\) is simply \(N_f\). For LeNet-5's C1 layer: Input \(W=32, H=32, C_{in}=1\). Filters \(F=5\), Stride \(S=1\), Padding \(P=0\), \(N_f=6\). Thus, \(W' = \lfloor (32-5+0)/1 \rfloor + 1 = 27+1 = 28\), \(H'=28\). Output: \(28 \times 28 \times 6\).

Parameter Count in Convolutional Layers

The efficiency of CNNs comes from parameter sharing. For a convolutional layer with \(N_f\) filters, each of size \(F \times F \times C_{in}\), and a bias term for each filter, the total number of trainable parameters is:

$$\text{Params} = (F \times F \times C_{in} + 1) \times N_f$$

For LeNet-5's C1 layer: \((5 \times 5 \times 1 + 1) \times 6 = (25+1) \times 6 = 26 \times 6 = 156\) parameters. This is remarkably small for processing a 32x32 image, compared to a fully connected layer where each input pixel would connect to each output neuron.

Subsampling Layer Output Dimensions

Subsampling (pooling) layers reduce spatial dimensions. For an input \(W \times H \times C_{in}\) and a pooling window \(K \times K\) with stride \(S\), the output dimensions are:

$$W' = \left\lfloor \frac{W - K}{S} \right\rfloor + 1$$
$$H' = \left\lfloor \frac{H - K}{S} \right\rfloor + 1$$

The number of channels \(C_{out}\) remains the same as \(C_{in}\). For LeNet-5's S2 layer: Input \(W=28, H=28, C_{in}=6\). Pooling window \(K=2\), Stride \(S=2\). Thus, \(W' = \lfloor (28-2)/2 \rfloor + 1 = 13+1 = 14\), \(H'=14\). Output: \(14 \times 14 \times 6\). Note that LeNet-5's subsampling layers also had learnable weights and biases, adding a small number of parameters (e.g., \((1+1) \times 6 = 12\) for S2).

⚠️ Historical Context & Modern Differences

LeNet-5 used average pooling with learnable parameters and a Euclidean RBF output layer. Modern CNNs typically use max pooling without learnable parameters and a softmax output layer with cross-entropy loss. While the core ideas are the same, the specific implementations have evolved for better performance and simplicity.

Key Takeaways
▼

When to study/apply LeNet-5's principles:

  • Learning CNN Fundamentals: It's the perfect historical starting point to understand local receptive fields, weight sharing, and subsampling.
  • Small-Scale Image Classification: For very simple, low-resolution image classification tasks (like MNIST), its architecture is still a solid, interpretable baseline.
  • Resource-Constrained Environments (Conceptual): The parameter efficiency of its convolutional layers and the sparse connections in C3 highlight how to design networks for limited computational budgets.

When NOT to use LeNet-5 directly:

  • State-of-the-Art Performance: For modern, complex vision tasks (ImageNet, object detection, segmentation), LeNet-5 is far too shallow and small. Modern architectures like ResNet, EfficientNet, or Vision Transformers offer vastly superior performance.
  • Large, High-Resolution Images: Its architecture is not designed to handle high-resolution inputs efficiently.
  • Transfer Learning: It's generally not used as a pre-trained backbone for transfer learning due to its age and limited feature complexity.
💡 Enduring Legacy

Despite its age, LeNet-5's architectural blueprint — alternating convolution and pooling, followed by fully connected layers — remains the backbone of many modern CNNs. Its success paved the way for the deep learning revolution in computer vision, proving the viability of trainable feature hierarchies.

Code Trace (Simplified Python)

import numpy as np
from scipy.signal import convolve2d
# --- Simplified LeNet-5 Layer Implementations ---
def conv_layer(input_map, num_filters, filter_size, stride, C_in):
"""Simulates a convolutional layer (e.g., C1, C3)"""
H_in, W_in = input_map.shape[:2]
H_out = (H_in - filter_size) // stride + 1
W_out = (W_in - filter_size) // stride + 1
output_maps = np.zeros((H_out, W_out, num_filters))
# Parameters: (filter_height * filter_width * input_channels + bias) * num_filters
params = (filter_size * filter_size * C_in + 1) * num_filters
print(f"Conv Layer Output: {H_out}x{W_out}x{num_filters}, Params: {params}")
return output_maps, params
def subsampling_layer(input_maps, pool_size, stride, C_in):
"""Simulates a subsampling/average pooling layer (e.g., S2, S4)"""
H_in, W_in = input_maps.shape[:2]
H_out = (H_in - pool_size) // stride + 1
W_out = (W_in - pool_size) // stride + 1
output_maps = np.zeros((H_out, W_out, C_in))
# LeNet-5 S-layers had learnable params (weight per map + bias per map)
params = (1 + 1) * C_in
print(f"Subsampling Layer Output: {H_out}x{W_out}x{C_in}, Params: {params}")
return output_maps, params
def fc_layer(input_vector_size, output_size):
"""Simulates a fully connected layer (e.g., F5, F6)"""
params = (input_vector_size + 1) * output_size
print(f"FC Layer Output: {output_size} units, Params: {params}")
return np.zeros(output_size), params
# --- LeNet-5 Full Forward Pass (Conceptual) ---
input_image = np.random.rand(32, 32, 1) # Example 32x32 grayscale image
total_params = 0
# C1: Convolutional Layer
c1_out, p = conv_layer(input_image, num_filters=6, filter_size=5, stride=1, C_in=1)
total_params += p
# S2: Subsampling Layer
s2_out, p = subsampling_layer(c1_out, pool_size=2, stride=2, C_in=6)
total_params += p
# C3: Convolutional Layer (simplified connection for param count)
c3_out, p = conv_layer(s2_out, num_filters=16, filter_size=5, stride=1, C_in=6)
total_params += p
# S4: Subsampling Layer
s4_out, p = subsampling_layer(c3_out, pool_size=2, stride=2, C_in=16)
total_params += p
# Flatten S4 output for FC layers
flattened_size = s4_out.shape[0] * s4_out.shape[1] * s4_out.shape[2] # 5*5*16 = 400
# F5: Fully Connected Layer
f5_out, p = fc_layer(flattened_size, output_size=120)
total_params += p
# F6: Fully Connected Layer
f6_out, p = fc_layer(120, output_size=84)
total_params += p
# Output Layer (RBF, no params for this conceptual trace)
output_probs, p = fc_layer(84, output_size=10) # RBF conceptually similar to FC output
total_params += p
print(f"Total Trainable Parameters: {total_params}") # ~60,000 for full LeNet-5
