Probit Model

Binary classification via the standard-normal CDF — a latent-variable approach to discrete choice
Intermediate Classical ML · Classification Link: Φ(z)
1
Understanding the Concept
▼

The Probit model is a classification algorithm for binary outcomes (yes/no, success/failure, 0/1). It answers: "Given a set of features \(\mathbf{x}\), what is the probability that the outcome \(Y=1\)?" — but it does so using the standard-normal CDF \(\Phi\) as the link function rather than the logistic sigmoid.

Real-world analogy. Imagine you're grading a student on a hidden continuous "academic talent" score \(y^*\). If \(y^*\) exceeds a threshold (say 0), the student passes (\(Y=1\)); otherwise they fail (\(Y=0\)). You can't observe \(y^*\) directly, but you know it has a standard-normal distribution. The probit model is exactly this: a latent variable \(y^* = \mathbf{x}^\top\boldsymbol{\beta} + \varepsilon\), \(\varepsilon \sim \mathcal{N}(0,1)\), and \(Y = \mathbf{1}[y^* > 0]\).

Key Insight

The probit and logit models differ only in their link function: probit uses \(\Phi(z)\) (normal CDF) while logit uses \(\sigma(z) = 1/(1+e^{-z})\). Their S-curves nearly overlap in the centre but have lighter tails under the probit. In practice the choice rarely changes predictions, but it matters for economic interpretation and Bayesian computation.

If you remember one thing: Probit \(=\) logit but with the Gaussian CDF as the squashing function. The latent-variable derivation gives the model its name and provides a structural economic interpretation that pure logit lacks.

2
How It Works Internally
▼

Latent Variable Mechanism

For observation \(i\), define a latent (unobserved) continuous variable:

$$y_i^* = \mathbf{x}_i^\top\boldsymbol{\beta} + \varepsilon_i, \quad \varepsilon_i \sim \mathcal{N}(0,1)$$

The observed binary outcome is the threshold rule:

$$Y_i = \begin{cases} 1 & y_i^* > 0 \\ 0 & y_i^* \le 0 \end{cases}$$

The probability that \(Y_i = 1\) is therefore:

$$P(Y_i = 1 \mid \mathbf{x}_i) = P(\varepsilon_i > -\mathbf{x}_i^\top\boldsymbol{\beta}) = \Phi(\mathbf{x}_i^\top\boldsymbol{\beta})$$

where \(\Phi\) is the standard-normal CDF. Because \(\Phi\) is symmetric, \(P(\varepsilon > -z) = P(\varepsilon < z) = \Phi(z)\).

Estimation — Maximum Likelihood

Parameters \(\boldsymbol{\beta}\) are found by maximising the log-likelihood:

$$\ell(\boldsymbol{\beta}) = \sum_{i=1}^n \left[ y_i \log \Phi(\mathbf{x}_i^\top\boldsymbol{\beta}) + (1-y_i)\log\bigl(1 - \Phi(\mathbf{x}_i^\top\boldsymbol{\beta})\bigr) \right]$$

This is concave in \(\boldsymbol{\beta}\) (unique global maximum). Optimisation uses Newton–Raphson (or Fisher scoring / IRLS), computing score and Hessian analytically via the normal PDF \(\phi\).

Scale Normalisation

The latent variance is fixed at 1. Only the ratio \(\beta/\sigma_\varepsilon\) is identified. This is why probit coefficients are not directly comparable to logit coefficients — they differ by a factor of roughly \(\pi/\sqrt{3} \approx 1.814\).

Numerical Trace (single observation)

Suppose \(\mathbf{x} = [1, 1.5]\) (intercept + feature), \(\boldsymbol{\beta} = [-0.8, 0.9]\):

  • Linear index: \(z = 1\cdot(-0.8) + 1.5\cdot(0.9) = -0.8 + 1.35 = 0.55\)
  • Probability: \(\Phi(0.55) \approx 0.7088\)
  • Marginal effect of feature: \(\phi(0.55)\cdot\beta_1 = 0.3410\cdot 0.9 \approx 0.307\)
  • Log-likelihood contribution (if \(y=1\)): \(\log(0.7088) \approx -0.344\)

Compare logit on same \(z\): \(\sigma(0.55) = 1/(1+e^{-0.55}) \approx 0.6342\). The probit gives a slightly higher probability here; near \(z=0\) the difference is largest (probit PDF is taller/narrower than logistic PDF).

3
The Math Behind It
▼

Score Vector

Let \(\eta_i = \mathbf{x}_i^\top\boldsymbol{\beta}\), \(\phi_i = \phi(\eta_i)\), \(\Phi_i = \Phi(\eta_i)\). Differentiating \(\ell\):

$$\frac{\partial \ell}{\partial \boldsymbol{\beta}} = \sum_{i=1}^n \left[\frac{y_i \phi_i}{\Phi_i} - \frac{(1-y_i)\phi_i}{1-\Phi_i}\right]\mathbf{x}_i$$

Hessian (expected Fisher Information)

$$\mathbf{I}(\boldsymbol{\beta}) = \sum_{i=1}^n \frac{\phi_i^2}{\Phi_i(1-\Phi_i)}\,\mathbf{x}_i\mathbf{x}_i^\top$$

This is positive definite, confirming concavity and a unique MLE.

Marginal Effects

Unlike linear regression, a unit change in \(x_j\) does not shift the probability by \(\beta_j\). The marginal effect at the mean (MEM) is:

$$\frac{\partial P(Y=1)}{\partial x_j} = \phi(\mathbf{x}^\top\boldsymbol{\beta})\cdot\beta_j$$

This is heterogeneous — it depends on the current value of \(\mathbf{x}^\top\boldsymbol{\beta}\). The Average Marginal Effect (AME) averages over all observations:

$$\text{AME}_j = \frac{1}{n}\sum_{i=1}^n \phi(\mathbf{x}_i^\top\hat{\boldsymbol{\beta}})\cdot\hat{\beta}_j$$
Probit vs Logit Scaling

If you multiply probit coefficients by \(\pi/\sqrt{3} \approx 1.814\), you get approximately the equivalent logit coefficients. This is because the logistic distribution has variance \(\pi^2/3\) while the standard normal has variance 1. AMEs are nearly identical between the two models.

Decision Rule

Use probit when (a) you want a structural latent-variable interpretation (common in econometrics and psychometrics), or (b) you need the Bayesian Albert-Chib Gibbs sampler. Use logit when you want log-odds interpretability, faster MLE (logistic is cheaper to evaluate than the normal CDF), or need easy coefficient communication.

When to use probit

  • Discrete choice models in economics (house buying, labour supply)
  • Item response theory in psychometrics (Rasch model)
  • Bayesian hierarchical models (data augmentation is elegant)
  • When the DGP is believed to have normally distributed errors

Common pitfalls

  • Complete separation: MLE diverges (same as logit) — use penalised or Bayesian estimation.
  • Reporting coefficients: Always report AMEs alongside coefficients — raw β has no intuitive unit.
  • Comparing across models: Coefficients are not comparable across probit models with different covariates (due to normalisation).
6
From-Scratch Implementation
▼

A minimal probit MLE using Newton–Raphson, matching the math above exactly:

import numpy as np
from scipy.stats import norm  # phi = norm.pdf, Phi = norm.cdf

def probit_mle(X, y, max_iter=100, tol=1e-8):
    """Probit MLE via Newton-Raphson.
    X: (n, p) design matrix (include intercept column)
    y: (n,)  binary outcomes {0, 1}
    Returns: beta (p,), standard errors (p,)
    """
    n, p = X.shape
    beta = np.zeros(p)              # initialise at zero

    for iteration in range(max_iter):
        eta  = X @ beta             # linear index η = Xβ
        Phi  = norm.cdf(eta)        # P(Y=1|x) via Φ
        phi  = norm.pdf(eta)        # standard normal PDF

        # Clip to avoid log(0)
        Phi  = np.clip(Phi, 1e-12, 1 - 1e-12)

        # Score vector ∂ℓ/∂β
        score = ((y * phi / Phi) - ((1 - y) * phi / (1 - Phi)))
        grad  = X.T @ score          # (p,)

        # Expected Fisher information (negative Hessian)
        w    = phi**2 / (Phi * (1 - Phi))   # (n,) weights
        info = (X.T * w) @ X                 # (p, p) = XᵀWX

        # Newton step: β ← β + I⁻¹ ∇ℓ
        step = np.linalg.solve(info, grad)
        beta = beta + step

        if np.max(np.abs(step)) < tol:
            print(f"  Converged in {iteration+1} iterations")
            break

    # Standard errors from inverse Fisher information
    eta  = X @ beta
    Phi  = np.clip(norm.cdf(eta), 1e-12, 1 - 1e-12)
    phi  = norm.pdf(eta)
    w    = phi**2 / (Phi * (1 - Phi))
    info = (X.T * w) @ X
    se   = np.sqrt(np.diag(np.linalg.inv(info)))

    # Average Marginal Effects
    ame  = norm.pdf(X @ beta).mean() * beta

    return beta, se, ame

# ── Example ──────────────────────────────────────────────
np.random.seed(42)
n = 500
X_raw = np.random.randn(n, 2)
X     = np.column_stack([np.ones(n), X_raw])  # add intercept
beta_true = np.array([0.0, 1.0, -0.5])
y_star    = X @ beta_true + np.random.randn(n)  # latent variable
y         = (y_star > 0).astype(int)            # threshold at 0

beta_hat, se_hat, ame_hat = probit_mle(X, y)
print("Estimates:", np.round(beta_hat, 3))
print("Std Errs: ", np.round(se_hat,  3))
print("AMEs:     ", np.round(ame_hat,  3))
# Estimates: [-0.014  0.984 -0.499]  ← recovers true β

Production: statsmodels.discrete.discrete_model.Probit(y, X).fit() — use .get_margeff() for AMEs, .summary() for full output. For large datasets, sklearn's LogisticRegression(solver='lbfgs') gives nearly identical predictions with fewer mathematical niceties.
