Balanced Accuracy

Mean of Per-Class Recall — The Imbalance Fix

Intermediate Evaluation O(n)
1 Understanding the Concept

Plain accuracy is a liar when classes are imbalanced. A fraud-detection model that stamps every transaction as "genuine" achieves 95% accuracy if 950 of 1,000 cases are genuine — yet it catches zero fraudulent transactions. The metric looks spectacular; the model is completely useless.

Balanced Accuracy fixes this by giving every class an equal voice. Instead of counting raw correct predictions, it asks: How well did the model do on each class individually? Then it averages those per-class recalls. A model that ignores the minority class entirely will score exactly 0.5 in binary settings — the theoretical chance level — making its worthlessness undeniable.

Real-world analogy: Imagine an exam grader who must fairly assess performance across easy and hard questions. Raw score rewards whoever memorized easy questions; balanced score checks mastery of every type equally.

Balanced accuracy is identical to the macro-averaged recall — a well-established concept that simply computes recall for each class and averages without weighting by class frequency.

2 How It Works Internally

The core idea is computing recall per class and averaging. Recall for a class is the fraction of true members of that class that the model correctly identified.

Binary Case
$$\text{BA} = \frac{\text{TPR} + \text{TNR}}{2} = \frac{\text{Recall}_{\text{pos}} + \text{Recall}_{\text{neg}}}{2}$$

where \(\text{TPR} = \frac{TP}{TP + FN}\) (sensitivity, fraud recall) and \(\text{TNR} = \frac{TN}{TN + FP}\) (specificity, genuine recall).

Multiclass Generalization (K classes)
$$\text{BA} = \frac{1}{K} \sum_{k=1}^{K} \frac{TP_k}{TP_k + FN_k}$$

Each \(TP_k\) is the count of class-\(k\) samples correctly classified. This is exactly macro-averaged recall.

Chance-Adjusted Variant
$$\text{Adjusted BA} = \frac{\text{BA} - \tfrac{1}{K}}{1 - \tfrac{1}{K}}$$

Re-scales so that random guessing yields 0 and perfect classification yields 1. For binary (\(K=2\)): chance = \(\tfrac{1}{2}\), so Adjusted BA \(\in [-1, 1]\). Negative values indicate worse than chance.

Computationally, balanced accuracy is O(n): a single pass through \(n\) predictions accumulates per-class TP and total counts. No sorting, no pairwise comparisons.

3 Why It Works

The invariant that makes balanced accuracy reliable is equal class weight. Each class's recall contributes \(1/K\) of the final score regardless of how many samples that class has. A class with 10 samples matters exactly as much as a class with 10,000.

Connection to macro recall: Balanced accuracy = macro-averaged recall. "Macro" means average over classes (not samples). Compare with "micro" recall (= plain accuracy) which weights by sample count and thus silences minority classes.

The chance-level semantics are elegant: a random classifier that always predicts one class in binary setting achieves TPR = 1, TNR = 0 (or vice versa), giving BA = 0.5. BA = 0.5 unambiguously means chance performance — the metric will not disguise a broken model.

When BA = 0.5: Either TPR or TNR is 0, meaning the model completely ignores one class. This is the smoking gun of class imbalance exploitation.

The adjusted variant pushes the zero-point to random chance, making it directly comparable to Cohen's Kappa and MCC — both of which also correct for chance agreement.

5 Key Takeaways
✓

When to Use

Imbalanced classification where minority-class performance matters. Medical screening, fraud, rare-event detection.

✗

When Not to Use

Balanced datasets where plain accuracy is fine. Also avoid if you need to trade off precision vs. recall explicitly — use F1 or AUC-PR instead.

⚖

vs. MCC

Matthews Correlation Coefficient accounts for all four confusion matrix cells simultaneously. MCC is often preferred for binary; BA generalises more cleanly to multiclass.

⬟

vs. F1 Score

F1 is the harmonic mean of precision and recall for the positive class only. BA treats both classes symmetrically. Use F1 when false positives are costly; BA when both class errors matter equally.

◑

vs. AUC-PR

AUC-PR (precision-recall area) evaluates across all decision thresholds. BA is a single-threshold metric. AUC-PR is richer but requires probability scores, not just hard labels.

0

Adjusted Variant

Use Adjusted BA when you want chance-corrected scores directly comparable across datasets with different numbers of classes.

Quick formula cheat sheet:
Binary: \(\text{BA} = \frac{TPR + TNR}{2}\)  |  Multiclass: \(\text{BA} = \frac{1}{K}\sum_k \text{Recall}_k\)  |  Adjusted: \(\hat{\text{BA}} = \frac{\text{BA} - \frac{1}{K}}{1 - \frac{1}{K}}\)
