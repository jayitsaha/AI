Probability mass, cumulative distribution, expectation, and variance for discrete outcomes
Foundational Lean Intermediate Probability & Statistics Must Know
1
Understanding Discrete Random Variables
▼

What is it? A random variable is a number whose value is determined by a random experiment. A discrete random variable can only take values from a countable list — like the face of a die (1 through 6) or the number of heads in three coin flips (0, 1, 2, or 3). It cannot take, say, the value 2.7.

Analogy: Think of a random variable as a score function on outcomes. When you roll a die, the experiment produces one of six outcomes: ⚀ ⚁ ⚂ ⚃ ⚄ ⚅. The random variable \(X\) assigns the number 1, 2, 3, 4, 5, or 6 to each outcome. The PMF (Probability Mass Function) tells you how likely each number is — like a bar chart where all bars sum to exactly 1. The CDF (Cumulative Distribution Function) tells you the probability of getting at most a given value — it stacks up the PMF bars from left to right.

💡 If you remember one thing

The PMF gives individual probabilities \(P(X=x)\) — bars summing to 1. The CDF is their running total \(F(x) = P(X \le x)\) — a non-decreasing staircase ending at 1. Expectation \(\mathbb{E}[X] = \sum_x x\,p(x)\) is the probability-weighted average; variance \(\operatorname{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2\) measures spread.

Prerequisites

  • Basic set theory (sample space, events)
  • Axioms of probability: \(P(\Omega)=1\), \(P(A) \ge 0\), countable additivity
  • Sigma notation for sums
2
PMF & CDF: Mechanics & Properties
▼

The Probability Mass Function (PMF)

Formally, for a discrete random variable \(X\) with support \(\mathcal{X} \subseteq \mathbb{Z}\), the PMF is the function \(p: \mathcal{X} \to [0,1]\) defined by:

$$p(x) = P(X = x) \quad \forall\, x \in \mathcal{X}$$

Two properties are necessary and sufficient for \(p\) to be a valid PMF:

  • Non-negativity: \(p(x) \ge 0\) for all \(x\)
  • Normalization: \(\sum_{x \in \mathcal{X}} p(x) = 1\)

Die example: For a fair six-sided die, \(\mathcal{X} = \{1,2,3,4,5,6\}\) and \(p(x) = \tfrac{1}{6}\) for each \(x\). Check: \(6 \times \tfrac{1}{6} = 1\). ✓

The Cumulative Distribution Function (CDF)

The CDF \(F: \mathbb{R} \to [0,1]\) is defined for all real \(x\) (not just support points):

$$F(x) = P(X \le x) = \sum_{k \le x,\, k \in \mathcal{X}} p(k)$$

For the fair die: \(F(1) = \tfrac{1}{6}\), \(F(2) = \tfrac{2}{6}\), \(F(3) = \tfrac{3}{6} = 0.5\), \(F(4) = \tfrac{4}{6}\), \(F(5) = \tfrac{5}{6}\), \(F(6) = 1\). Between integers, \(F\) is constant — that is why it looks like a staircase.

🔑 Three CDF Properties (Guaranteed)

1. Monotone non-decreasing: if \(a \le b\) then \(F(a) \le F(b)\).
2. Right-continuous: \(\lim_{h \downarrow 0} F(x+h) = F(x)\) — the staircase jumps at each support point and the value at the jump equals the top of the step.
3. Boundary conditions: \(\lim_{x \to -\infty} F(x) = 0\) and \(\lim_{x \to +\infty} F(x) = 1\).

Reading Range Probabilities from the CDF

One of the CDF's main uses is computing interval probabilities without summing individual terms:

$$P(a < X \le b) = F(b) - F(a)$$

Example: \(P(2 < X \le 5) = F(5) - F(2) = \tfrac{5}{6} - \tfrac{2}{6} = \tfrac{3}{6} = 0.5\). This counts outcomes 3, 4, 5 — exactly three out of six. ✓

⚠️ Common Confusion

The PMF is only defined at support points; the CDF is defined everywhere on \(\mathbb{R}\). Writing \(p(1.5)\) for a die is meaningless — but \(F(1.5) = \tfrac{1}{6}\) is perfectly valid (it equals \(P(X \le 1.5) = P(X=1) = \tfrac{1}{6}\)).

Expectation, Variance & the Math
▼

Expectation (Expected Value)

The expectation \(\mathbb{E}[X]\) is the probability-weighted average of all values — the "center of mass" of the PMF:

$$\mathbb{E}[X] = \sum_{x \in \mathcal{X}} x \cdot p(x)$$

Fair die trace:

$$\mathbb{E}[X] = 1 \cdot \tfrac{1}{6} + 2 \cdot \tfrac{1}{6} + 3 \cdot \tfrac{1}{6} + 4 \cdot \tfrac{1}{6} + 5 \cdot \tfrac{1}{6} + 6 \cdot \tfrac{1}{6} = \tfrac{21}{6} = 3.5$$

Note: \(X\) can never equal 3.5 — the expectation need not be in the support.

Law of the Unconscious Statistician (LOTUS)

For any function \(g\), the expectation of \(g(X)\) is computed by weighting \(g(x)\) by the original PMF — no need to find the PMF of \(g(X)\) first:

$$\mathbb{E}[g(X)] = \sum_{x \in \mathcal{X}} g(x) \cdot p(x)$$

Variance

Variance measures how spread out the distribution is around its mean:

$$\operatorname{Var}(X) = \mathbb{E}\!\left[(X - \mu)^2\right] = \sum_{x \in \mathcal{X}} (x - \mu)^2 \, p(x)$$

In practice, the computational shortcut (König-Huygens identity) is used:

$$\operatorname{Var}(X) = \mathbb{E}[X^2] - \left(\mathbb{E}[X]\right)^2$$

Fair die trace:

$$\mathbb{E}[X^2] = \frac{1^2+2^2+3^2+4^2+5^2+6^2}{6} = \frac{91}{6} \approx 15.1\overline{6}$$
$$\operatorname{Var}(X) = \frac{91}{6} - \left(\frac{7}{2}\right)^2 = \frac{91}{6} - \frac{49}{4} = \frac{182-147}{12} = \frac{35}{12} \approx 2.917$$

Standard Deviation

The standard deviation \(\sigma = \sqrt{\operatorname{Var}(X)}\) is in the same units as \(X\). For the fair die: \(\sigma = \sqrt{35/12} \approx 1.708\).

∑ Key Formulas

\(\mathbb{E}[aX + b] = a\,\mathbb{E}[X] + b\) (linearity of expectation)
\(\operatorname{Var}(aX + b) = a^2 \operatorname{Var}(X)\) (scaling; shift has no effect)
\(\operatorname{Var}(X) \ge 0\), with equality iff \(X\) is constant a.s.

⚠️ Variance Is Not Linear

For independent \(X, Y\): \(\operatorname{Var}(X+Y) = \operatorname{Var}(X)+\operatorname{Var}(Y)\). In general (dependence): \(\operatorname{Var}(X+Y) = \operatorname{Var}(X)+\operatorname{Var}(Y)+2\operatorname{Cov}(X,Y)\). Forgetting the covariance term is a very common error.

Key Takeaways & Common Distributions
▼
DistributionSupportPMF \(p(x)\)\(\mathbb{E}[X]\)\(\operatorname{Var}(X)\)Use When
Bernoulli(\(p\))\(\{0,1\}\)\(p^x(1-p)^{1-x}\)\(p\)\(p(1-p)\)Single binary trial
Binomial(\(n,p\))\(\{0,\ldots,n\}\)\(\binom{n}{x}p^x(1-p)^{n-x}\)\(np\)\(np(1-p)\)Count successes in \(n\) independent trials
Geometric(\(p\))\(\{1,2,\ldots\}\)\((1-p)^{x-1}p\)\(1/p\)\((1-p)/p^2\)Trials until first success
Poisson(\(\lambda\))\(\{0,1,2,\ldots\}\)\(e^{-\lambda}\lambda^x/x!\)\(\lambda\)\(\lambda\)Count of rare events in fixed window
Uniform(\(a,b\))\(\{a,\ldots,b\}\)\(1/(b-a+1)\)\((a+b)/2\)\((b-a+2)(b-a)/12\)All outcomes equally likely
✅ When to Use Each

Bernoulli → single flip (spam/not spam).
Binomial → fixed number of independent identical flips (defects in a batch).
Geometric → waiting time (calls until first sale).
Poisson → counts per time/space interval (requests per second, mutations per genome).
