1
Understanding the Concept

What is it? The kernel trick lets you compute a dot product in a (possibly infinite-dimensional) feature space without ever explicitly constructing that space. You replace every inner product \(\langle\phi(\mathbf{x}),\phi(\mathbf{x}')\rangle\) with a kernel function \(K(\mathbf{x},\mathbf{x}')\) — often far cheaper to evaluate.

💡 Real-World Analogy

Imagine measuring the similarity of two handwritten digits. You could map each image to 10,000 stroke features and take a dot product — expensive. Or you just use a function that directly computes how alike they look. The kernel does this: similarity answer without building the feature vector.

🔑 Key Concept — Mercer's Condition

A function \(K:\mathcal{X}\times\mathcal{X}\to\mathbb{R}\) corresponds to a valid inner product in some feature space if and only if the \(n\times n\) Gram (kernel) matrix \(\mathbf{K}\) with entries \(K_{ij}=K(\mathbf{x}_i,\mathbf{x}_j)\) is positive semi-definite (PSD) for every finite dataset. This is Mercer's theorem.

One-sentence summary: Kernels are similarity functions that secretly correspond to dot products in a high-dimensional space — valid kernels are exactly those that produce PSD Gram matrices (Mercer).

2
How It Works Internally

In a dual SVM the decision function and margin constraint involve only dot products \(\langle\mathbf{x}_i,\mathbf{x}_j\rangle\). The substitution \(\langle\mathbf{x}_i,\mathbf{x}_j\rangle \leftarrow K(\mathbf{x}_i,\mathbf{x}_j)\) is exact — we are truly computing in a feature space \(\phi:\mathcal{X}\to\mathcal{H}\) but never materialising \(\phi\).

Three steps:

  1. Choose a kernel \(K(\mathbf{x},\mathbf{x}')\) — RBF, polynomial, linear, etc.
  2. Build the Gram matrix \(\mathbf{K}\in\mathbb{R}^{n\times n}\), \(K_{ij}=K(\mathbf{x}_i,\mathbf{x}_j)\).
  3. Verify PSD — all eigenvalues \(\geq 0\). If yes, Mercer guarantees an implicit feature map exists and the SVM optimisation is a valid convex QP.
📐 The Substitution

Dual SVM objective (inner product form):

$$\max_{\boldsymbol{\alpha}} \sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \alpha_i\alpha_j y_i y_j \langle\mathbf{x}_i,\mathbf{x}_j\rangle$$

Kernelised — replace \(\langle\mathbf{x}_i,\mathbf{x}_j\rangle\) with \(K(\mathbf{x}_i,\mathbf{x}_j)\):

$$\max_{\boldsymbol{\alpha}} \sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i\alpha_j y_i y_j K(\mathbf{x}_i,\mathbf{x}_j)$$

⚠️ Sigmoid Kernel Caveat

The sigmoid kernel is not Mercer for all parameter values — its Gram matrix can be indefinite. Always verify PSD (e.g. check eigenvalues) before using custom kernels.

3
Why It Works — Mercer's Theorem

Mercer's Theorem (informal): Let \(K:\mathcal{X}\times\mathcal{X}\to\mathbb{R}\) be symmetric and continuous. \(K\) can be written as \(K(\mathbf{x},\mathbf{x}')=\langle\phi(\mathbf{x}),\phi(\mathbf{x}')\rangle_\mathcal{H}\) for some Hilbert space \(\mathcal{H}\) and map \(\phi\) if and only if \(K\) is positive semi-definite, meaning for any finite set of points \(\{\mathbf{x}_i\}_{i=1}^n\) and real coefficients \(c_i\):

$$\sum_{i=1}^n\sum_{j=1}^n c_i c_j K(\mathbf{x}_i,\mathbf{x}_j) \;\geq\; 0$$

Equivalently, the Gram matrix \(\mathbf{K}\) must satisfy \(\mathbf{v}^\top \mathbf{K}\,\mathbf{v}\geq 0\) for all \(\mathbf{v}\in\mathbb{R}^n\), i.e. all eigenvalues \(\lambda_i\geq 0\).

Proof sketch (RBF is PSD): For the RBF kernel, expand using the Gaussian integral representation:

$$K(\mathbf{x},\mathbf{x}')=\exp\!\left(-\gamma\|\mathbf{x}-\mathbf{x}'\|^2\right) = e^{-\gamma\|\mathbf{x}\|^2}\cdot e^{2\gamma\mathbf{x}^\top\mathbf{x}'}\cdot e^{-\gamma\|\mathbf{x}'\|^2}$$

The middle factor \(e^{2\gamma\mathbf{x}^\top\mathbf{x}'}\) is the exponential of a PSD kernel (linear), and a positive scaling by \(e^{-\gamma\|\mathbf{x}\|^2}\) on both sides preserves PSD-ness — therefore the RBF Gram matrix is always PSD (in fact, strictly PD for distinct points).

📐 PSD Conditions — Cheat Sheet

If \(K_1, K_2\) are valid (Mercer) kernels, so are:

$$K = K_1 + K_2, \quad K = c\,K_1\;(c>0), \quad K = K_1 \cdot K_2, \quad K = f(\mathbf{x})\,K_1(\mathbf{x},\mathbf{x}')\,f(\mathbf{x}')$$

These closure properties let you engineer kernels from building blocks.

Why PSD matters for the SVM QP: The dual objective is \(-\frac{1}{2}\boldsymbol{\alpha}^\top(\mathbf{K}\circ\mathbf{y}\mathbf{y}^\top)\boldsymbol{\alpha}+\mathbf{1}^\top\boldsymbol{\alpha}\). For this to be a convex QP (globally solvable to optimality), the matrix \(\mathbf{K}\circ\mathbf{y}\mathbf{y}^\top\) must be PSD — guaranteed when \(\mathbf{K}\) is PSD.

Key Takeaways

When to use the kernel trick: when data are not linearly separable in input space but may be separable in a higher-dimensional feature space, or when the inner-product structure of the problem allows a meaningful similarity function.

  • Kernel matrix (Gram matrix) \(\mathbf{K}\) must be PSD — this is Mercer's condition.
  • PSD is equivalent to all eigenvalues \(\geq 0\), and to \(\mathbf{v}^\top\mathbf{K}\mathbf{v}\geq 0\;\forall\mathbf{v}\).
  • RBF kernel maps to infinite-dimensional space; polynomial maps to finite \(\binom{d+p}{p}\)-dimensional space.
  • Cost: computing \(\mathbf{K}\) is \(O(n^2 d)\); storing it is \(O(n^2)\) — prohibitive for large \(n\).
  • Prediction: \(f(\mathbf{x})=\sum_i \alpha_i y_i K(\mathbf{x}_i,\mathbf{x})+b\) — only support vectors (SVs) contribute (\(\alpha_i>0\)).
