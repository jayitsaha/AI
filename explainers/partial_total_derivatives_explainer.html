Understanding Partial & Total Derivatives
▼

What is it? A partial derivative answers: "if I move only along one axis while holding all others fixed, how steeply does the surface rise?" For a function \(z = f(x, y)\), the partial \(\partial f/\partial x\) is the slope you'd measure if you walked along the surface in the x-direction without drifting sideways in y at all.

Analogy: Imagine standing on a hillside. You can ask "how steep is it if I walk due East?" or "how steep if I walk due North?" Those are partial derivatives — one direction at a time. The total derivative answers "if I walk in some arbitrary direction (moving both East and North simultaneously), what is the total rate of change I experience?" It combines both slopes into one number using the actual direction of travel.

💡 If you remember one thing

The partial \(\partial f/\partial x\) freezes \(y\) and differentiates. The total differential \(df = f_x\,dx + f_y\,dy\) is the tangent-plane approximation — it predicts how much \(f\) changes for any small simultaneous displacement \((dx, dy)\). This is the local linear model of \(f\) at a point.

Why it matters in ML: Gradient descent lives here. The gradient \(\nabla_\theta \mathcal{L}\) is a vector of partial derivatives — one per parameter. Backpropagation applies the multivariable chain rule to compute all these partials efficiently. Every optimizer update step uses the total derivative idea.

Core Concepts & The Math
▼

Partial Derivatives — Formal Definition

Let \(f: \mathbb{R}^n \to \mathbb{R}\). The partial derivative of \(f\) with respect to \(x_i\) at point \(\mathbf{a}\) is:

$$\frac{\partial f}{\partial x_i}(\mathbf{a}) = \lim_{h \to 0} \frac{f(a_1, \ldots, a_i + h, \ldots, a_n) - f(a_1, \ldots, a_n)}{h}$$

For \(f(x, y) = x^2 y + \sin(y)\) at the point \((1, 0)\):

$$\frac{\partial f}{\partial x} = 2xy \;\Big|_{(1,0)} = 0, \qquad \frac{\partial f}{\partial y} = x^2 + \cos(y)\;\Big|_{(1,0)} = 2$$

Gradient

The gradient \(\nabla f\) collects all partials into a vector pointing in the direction of steepest ascent:

$$\nabla f = \left(\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_n}\right)^\top$$

Total Differential (Total Derivative)

For a differentiable function \(f(x, y)\), the total differential is:

$$df = \frac{\partial f}{\partial x}\,dx + \frac{\partial f}{\partial y}\,dy = f_x\,dx + f_y\,dy$$

This is the equation of the tangent plane to the surface \(z = f(x,y)\) at point \((a, b, f(a,b))\):

$$z - f(a,b) = f_x(a,b)\,(x-a) + f_y(a,b)\,(y-b)$$

The tangent plane is the best linear approximation to the surface near the point — the total derivative is the linear map \(df: \mathbb{R}^2 \to \mathbb{R}\) whose matrix representation is the row vector \([f_x, f_y]\) (the Jacobian for a scalar function).

Multivariable Chain Rule

If \(x = x(t)\) and \(y = y(t)\), then along the path \((x(t), y(t))\):

$$\frac{dz}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} = \nabla f \cdot \dot{\mathbf{r}}(t)$$

This is the dot product of the gradient with the velocity vector of the path — it is the directional derivative in the direction of travel.

⚠️ Common Confusion

Existence of all partial derivatives does NOT guarantee differentiability. The function \(f(x,y) = \frac{xy}{x^2+y^2}\) (0 at origin) has both partials equal to 0 at the origin, but is not continuous (and thus not differentiable) there. Differentiability requires the remainder \(f(\mathbf{a}+\mathbf{h}) - f(\mathbf{a}) - \nabla f(\mathbf{a})\cdot\mathbf{h} = o(\|\mathbf{h}\|)\).

🔑 Key Property — Clairaut's Theorem

If \(f_{xy}\) and \(f_{yx}\) are both continuous at \((a,b)\), then \(f_{xy}(a,b) = f_{yx}(a,b)\). Mixed partial derivatives commute — the order of differentiation doesn't matter. This is why Hessian matrices are symmetric in practice.

Numerical Example: \(f(x,y) = x^2 + xy + y^2\)

At point \((1, 2)\):

  • \(f_x = 2x + y = 2(1) + 2 = 4\)
  • \(f_y = x + 2y = 1 + 2(2) = 5\)
  • \(f(1,2) = 1 + 2 + 4 = 7\)
  • Tangent plane: \(z = 7 + 4(x-1) + 5(y-2)\)
  • Approximate \(f(1.1, 2.05)\): \(7 + 4(0.1) + 5(0.05) = 7.65\)
  • Exact: \(f(1.1, 2.05) = 1.21 + 2.255 + 4.2025 = 7.6675\) — error \(0.0175\), second-order small ✓

How It Works Internally — Chain Rule in Neural Nets
▼

Backpropagation IS the Multivariable Chain Rule

In a neural network with loss \(\mathcal{L} = f(g(h(\mathbf{x}, \theta)))\), the gradient of \(\mathcal{L}\) w.r.t. a parameter deep in the network requires repeated application of the chain rule:

$$\frac{\partial \mathcal{L}}{\partial \theta} = \frac{\partial \mathcal{L}}{\partial f} \cdot \frac{\partial f}{\partial g} \cdot \frac{\partial g}{\partial h} \cdot \frac{\partial h}{\partial \theta}$$

Each term is a partial derivative — "how does my output change w.r.t. my input, holding everything else fixed?" The total effect is the product of all these local slopes, because function composition corresponds to chain rule multiplication.

The Jacobian — Total Derivative for Vector Functions

When both input and output are vectors, \(f: \mathbb{R}^m \to \mathbb{R}^n\), the total derivative is the Jacobian matrix \(J\):

$$J_{ij} = \frac{\partial f_i}{\partial x_j}, \qquad J \in \mathbb{R}^{n \times m}$$

Chain rule: if \(h = f \circ g\), then \(J_h = J_f \cdot J_g\). Backpropagation multiplies Jacobians — but never explicitly forming them (it uses vector-Jacobian products for efficiency).

Directional Derivative

The directional derivative in direction \(\hat{u}\) (unit vector) is:

$$D_{\hat{u}} f(\mathbf{a}) = \nabla f(\mathbf{a}) \cdot \hat{u} = \|\nabla f(\mathbf{a})\| \cos\theta$$

Maximum when \(\hat{u} = \nabla f / \|\nabla f\|\) — this is why gradient ascent works. The gradient points in the direction of steepest ascent, and the directional derivative equals \(\|\nabla f\|\) in that direction.

import numpy as np
def f(x, y): # z = x^2 + xy + y^2
return x**2 + x*y + y**2
def partial_x(x, y, h=1e-6): # numerical partial ∂f/∂x
return (f(x + h, y) - f(x - h, y)) / (2 * h)
def partial_y(x, y, h=1e-6): # numerical partial ∂f/∂y
return (f(x, y + h) - f(x, y - h)) / (2 * h)
x0, y0 = 1.0, 2.0
fx = partial_x(x0, y0) # ≈ 4.0 (exact: 2x+y = 4)
fy = partial_y(x0, y0) # ≈ 5.0 (exact: x+2y = 5)
dx, dy = 0.1, 0.05
df_approx = fx * dx + fy * dy # total differential = 0.4 + 0.25 = 0.65
df_exact = f(x0+dx, y0+dy) - f(x0, y0) # 0.6675 — error O(h²)

Interview Deep-Dive & Comparisons
▼

Interview Questions

Q1 (Easy): What is the difference between \(\partial f/\partial x\) and \(df/dx\)?

A: \(\partial f/\partial x\) treats all other variables as constants — the function varies only in x. \(df/dx\) (total derivative) accounts for all indirect dependencies: if y also depends on x, then \(df/dx = \partial f/\partial x + \partial f/\partial y \cdot dy/dx\).

Q2 (Medium): Why is the gradient the direction of steepest ascent?

A: The directional derivative \(D_{\hat{u}}f = \nabla f \cdot \hat{u} = \|\nabla f\|\cos\theta\). This is maximized when \(\theta=0\), i.e., \(\hat{u} = \nabla f / \|\nabla f\|\). So gradient ascent moves in the direction that maximally increases \(f\) locally.

Q3 (Medium): Explain backpropagation using the chain rule.

A: Given \(\mathcal{L}(f(g(\mathbf{x})))\), backprop computes \(\partial \mathcal{L}/\partial \mathbf{x} = (\partial \mathcal{L}/\partial f)(\partial f/\partial g)(\partial g/\partial \mathbf{x})\). Each factor is a Jacobian. The backward pass multiplies these right-to-left as vector-Jacobian products, avoiding forming the full Jacobians.

Q4 (Hard): What does "the total derivative at a point" mean formally?

A: The total derivative of \(f\) at \(\mathbf{a}\) is the unique linear map \(L: \mathbb{R}^n \to \mathbb{R}^m\) such that \(\|f(\mathbf{a}+\mathbf{h}) - f(\mathbf{a}) - L\mathbf{h}\| / \|\mathbf{h}\| \to 0\) as \(\mathbf{h} \to 0\). Its matrix is the Jacobian \(J\). It's not just a number — it's the best linear approximation, which makes it composable via the matrix chain rule.

⚠️ Follow-up Trap

"If all partial derivatives exist, does the total derivative exist?" No! Partials can all exist without the function being differentiable. You need all partials to be continuous (sufficient condition), or to directly verify the limit definition. The classic counterexample: \(f(x,y) = xy/(x^2+y^2)\) at the origin.

Comparison: Partial vs Total vs Directional

ConceptWhat it measuresResult typeWhen to use
Partial \(\partial f/\partial x_i\) Rate of change along axis \(x_i\), all others frozen Scalar Building gradients; holding context fixed
Total derivative \(df\) Best linear approximation — full sensitivity to all inputs Linear map (Jacobian) Chain rule; error propagation; tangent plane
Directional \(D_{\hat{u}}f\) Rate of change in arbitrary direction \(\hat{u}\) Scalar Optimization direction; steepest descent/ascent
Gradient \(\nabla f\) Vector of all partials; direction of steepest ascent Vector Gradient descent; sensitivity analysis

Key Takeaways & Further Reading
▼

Core summary:

  • Partial derivative: freeze all but one variable, take the 1D derivative.
  • Gradient: vector of all partials — encodes the full local slope of the surface.
  • Total differential \(df = f_x dx + f_y dy\): tangent-plane approximation, combines all directional information.
  • Chain rule: \(dz/dt = f_x (dx/dt) + f_y (dy/dt)\) — compose derivatives when inputs depend on other variables.
  • Differentiability ≠ existence of partials. Requires remainder to be \(o(\|\mathbf{h}\|)\).
💡 ML Connection

Gradient descent updates \(\theta \leftarrow \theta - \alpha \nabla_\theta \mathcal{L}\) use the gradient (vector of partials). Backpropagation is the multivariable chain rule applied to a computation graph. The total derivative is the Jacobian — essential for understanding vanishing/exploding gradients.
