Encoder Stack: Multi-Head Self-Attention + FFN + Residuals + LayerNorm

How N identical layers turn raw token embeddings into deeply contextualized representations
Advanced Transformers NLP O(n²·d + n·d²)
1
Understanding the Encoder Stack
▼

What is it? A Transformer encoder is a tower of N identical layers stacked on top of each other. Each layer takes a sequence of token vectors and does two things to them: first lets every token look at every other token and gather relevant context (multi-head self-attention), then lets each token individually "think" about what it just gathered (position-wise feed-forward network). Both steps are wrapped with a residual (skip) connection and followed by layer normalization — together called "Add & Norm."

Analogy: Picture a committee of editors revising a document, one pass per editor (layer). In the "attention" phase, each sentence briefly consults every other sentence in the document to check consistency and gather context ("does this pronoun refer to the noun three sentences back?"). In the "FFN" phase, each sentence is privately rewritten based on what it learned, independent of the others. After each phase, the editor doesn't throw away the original sentence — they add their edit ON TOP of it (residual) and re-balance the tone (normalize), so meaning is never lost, only refined. Repeat this N times and the document becomes deeply polished.

💡 If you remember one thing

Every encoder layer computes $$x' = \text{LayerNorm}\big(x + \text{MultiHeadAttn}(x)\big), \qquad \text{out} = \text{LayerNorm}\big(x' + \text{FFN}(x')\big)$$ Two sublayers, each wrapped in residual + norm, repeated \(N\) times (\(N=6\) in the original paper) — that pattern is the entire encoder.

2
How the Encoder Layer Works Internally
▼

Sublayer Order (per the original "Attention Is All You Need" layer)

Given input \(x \in \mathbb{R}^{n \times d}\) (n tokens, model width \(d\)):

  1. Sublayer 1 — Multi-Head Self-Attention. Project \(x\) into queries, keys, values with \(h\) independent heads, each attending over the full sequence, then concatenate and project back to width \(d\).
  2. Add & Norm. \(x_1 = \text{LayerNorm}(x + \text{MultiHead}(x))\) — the residual carries the ORIGINAL token vector forward untouched; attention only adds a correction.
  3. Sublayer 2 — Position-wise FFN. Apply the SAME two-layer MLP independently to every token position: \(\text{FFN}(u) = \max(0, uW_1+b_1)W_2+b_2\), typically expanding \(d \to 4d \to d\).
  4. Add & Norm. \(x_2 = \text{LayerNorm}(x_1 + \text{FFN}(x_1))\) — this becomes the layer's output, which is shape-identical to its input, so it can feed directly into the next layer.

Multi-Head Self-Attention, precisely

Each head \(i\) learns its own projections \(W_i^Q, W_i^K, W_i^V \in \mathbb{R}^{d\times d_k}\) (\(d_k = d/h\)):

$$\text{head}_i = \text{Attention}(xW_i^Q, xW_i^K, xW_i^V) = \text{softmax}\!\left(\frac{(xW_i^Q)(xW_i^K)^\top}{\sqrt{d_k}}\right)(xW_i^V)$$
$$\text{MultiHead}(x) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)\,W^O$$

Splitting into \(h\) small heads instead of one big attention lets different heads specialize (e.g., one tracks syntax, another coreference) while keeping total compute roughly the same as one full-width head.

Design Decision: Why residuals?

Without the \(+x\) skip connection, stacking many layers makes gradients vanish/explode and the model must relearn the identity function at every layer from scratch. The residual makes "do nothing" the default, so each sublayer only needs to learn a small ADDITIVE refinement — this is what makes training \(N=6,12,24,...\) layer stacks feasible at all.

Design Decision: Post-LN vs Pre-LN — where does the norm go?

The original paper normalizes AFTER the residual add ("Post-LN": \(\text{LN}(x+\text{Sublayer}(x))\)), shown above. Modern large-scale Transformers (GPT-2 and later, most LLMs) instead normalize the sublayer's INPUT ("Pre-LN": \(x + \text{Sublayer}(\text{LN}(x))\)). Pre-LN keeps an unnormalized, unbroken residual highway from input to output, which stabilizes gradients enough to train very deep stacks without a learning-rate warmup; Post-LN often trains to a slightly better final loss but is harder to optimize at large depth.

🔑 Key Property

Every sublayer — attention AND FFN — has the SAME input/output shape \((n, d)\). This shape invariance is what allows arbitrary depth: layer \(k\)'s output is a drop-in replacement for layer \(k\)'s input, so \(N\) layers can be stacked with zero shape bookkeeping.

3
Why It Works — The Math
▼

Scaled Dot-Product Attention — why divide by \(\sqrt{d_k}\)?

For query/key vectors with i.i.d. components of mean 0, variance 1, the dot product \(q\cdot k = \sum_{j=1}^{d_k} q_jk_j\) has variance \(d_k\). As \(d_k\) grows, raw scores grow in magnitude, pushing softmax into regions with tiny gradients (saturation). Dividing by \(\sqrt{d_k}\) rescales the scores back to unit variance, keeping softmax in a well-conditioned regime:

$$\text{Var}(q\cdot k) = d_k \implies \text{Var}\!\left(\frac{q\cdot k}{\sqrt{d_k}}\right) = 1$$

LayerNorm — full derivation

For a single token's activation vector \(x \in \mathbb{R}^d\) (normalizing ACROSS the feature dimension, not across the batch):

$$\mu = \frac{1}{d}\sum_{j=1}^d x_j, \qquad \sigma^2 = \frac{1}{d}\sum_{j=1}^d (x_j-\mu)^2$$
$$\text{LayerNorm}(x)_j = \gamma_j\cdot\frac{x_j - \mu}{\sqrt{\sigma^2+\epsilon}} + \beta_j$$

The learnable \(\gamma,\beta \in \mathbb{R}^d\) let the network UNDO the normalization if that's optimal, so LayerNorm never strictly reduces expressive power — it only reparameterizes optimization to be better conditioned. Because it normalizes per-token (not per-batch), it works identically at any batch size and any sequence length, which is exactly why sequence models use LayerNorm instead of BatchNorm.

Gradient flow through the residual

For \(y = x + F(x)\), backpropagation gives:

$$\frac{\partial y}{\partial x} = I + \frac{\partial F}{\partial x}$$

The identity term \(I\) guarantees that a gradient signal from the loss can flow all the way back to layer 1 completely undiminished, no matter how small \(\partial F/\partial x\) becomes. Stack this across \(N\) layers and the gradient at the input is (approximately, ignoring the norm's rescaling) a SUM of \(2N\) paths of varying depth rather than a single \(2N\)-deep product — this is precisely why residual networks avoid vanishing gradients.

⚠️ Common Pitfall

LayerNorm's \(\gamma,\beta\) are PER-FEATURE, shared across all tokens and all positions — they are not per-token parameters. Also: because attention is a set operation (permutation-equivariant), the encoder has zero notion of token order without an explicitly added positional encoding at the input — the stack itself has no built-in sequence bias.

Key Takeaways
▼

Post-LN vs Pre-LN at a glance

DimensionPost-LN (original, 2017)Pre-LN (GPT-2+, most LLMs)
Formula\(\text{LN}(x+\text{Sub}(x))\)\(x+\text{Sub}(\text{LN}(x))\)
Residual streamRenormalized every sublayerUnbroken, unnormalized highway
Training stability at large \(N\)Needs careful LR warmupStable even at 50+ layers
Final loss (shallow \(N\))Slightly betterSlightly worse
Final LayerNorm needed?NoYes — one extra LN before output

Complexity per layer: self-attention costs \(O(n^2\cdot d)\) (all-pairs scores) and the FFN costs \(O(n\cdot d^2)\) (per-token, but wide). For short sequences the FFN dominates; for long sequences (\(n \gg d\)) attention's quadratic term dominates — this is exactly the bottleneck that motivates sparse/linear attention variants.

Why stack \(N\) layers instead of one wide layer? Depth lets the model compose simple operations into increasingly abstract features — early layers often capture local syntax, later layers capture longer-range semantics — the same reason depth helps CNNs. The original Transformer used \(N=6\); modern LLMs use \(N\) in the dozens to hundreds.

💡 Decision Rule

Building something shallow (≤12 layers) and want the best final quality with careful tuning? Post-LN is fine. Training something deep, or want robust training without extensive warmup tuning? Pre-LN (or its refinements like Sandwich-LN / DeepNorm) is the standard modern choice.

Lines highlight green as you step through the walkthrough above — this is the exact structure the live JS in this page executes on the toy 4×6 example.

import numpy as np
# x: (n_tokens, d_model) — input embeddings + positional encoding
def encoder_layer(x, Wq, Wk, Wv, Wo, bo, W1, b1, W2, b2, gamma1, beta1, gamma2, beta2, h=2):
n, d = x.shape; dk = d // h
# 1) Linear projections
Q, K, V = x @ Wq, x @ Wk, x @ Wv
# 2) Split into h heads, scaled dot-product attention per head
heads = []
for i in range(h):
Qh, Kh, Vh = Q[:, i*dk:(i+1)*dk], K[:, i*dk:(i+1)*dk], V[:, i*dk:(i+1)*dk]
scores = (Qh @ Kh.T) / np.sqrt(dk)
weights = softmax(scores, axis=-1)
heads.append(weights @ Vh)
# 3) Concat heads + output projection
Z = np.concatenate(heads, axis=-1) @ Wo + bo
# 4) Add & Norm (residual 1)
h1 = layer_norm(x + Z, gamma1, beta1)
# 5) Position-wise feed-forward (same MLP applied to every token)
ffn_out = np.maximum(0, h1 @ W1 + b1) @ W2 + b2
# 6) Add & Norm (residual 2) — output feeds into layer i+1
h2 = layer_norm(h1 + ffn_out, gamma2, beta2)
return h2
def encoder_stack(x, layer_params_list):
for params in layer_params_list: # N layers, each with its OWN weights
x = encoder_layer(x, *params)
return x # final contextualized representations
