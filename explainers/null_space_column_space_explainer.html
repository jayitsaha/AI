Null Space & Column Space

The Four Fundamental Subspaces of a Linear Map — kernel, range, row space, and left null space
Foundational Linear Algebra Math & Stats Must Know
1
Understanding the Four Fundamental Subspaces
▼

What is it? Every matrix \(A\) (size \(m \times n\)) defines a linear transformation \(A : \mathbb{R}^n \to \mathbb{R}^m\). This single transformation gives rise to four special subspaces that together completely describe what the matrix does, what it cannot reach, and what it "throws away."

Analogy: Imagine a projector that maps 3D objects onto a 2D screen. Some 3D directions (depth into/out of the screen) completely vanish — they are the null space. The set of all images that CAN appear on the screen is the column space. The 3D directions that actually survive (depth isn't one of them) form the row space. And the directions behind the projector lens that produce blank output form the left null space.

💡 If you remember one thing

The null space \(\mathcal{N}(A)\) is the set of inputs that map to zero. The column space \(\mathcal{C}(A)\) is the set of all reachable outputs. They live in different spaces and are orthogonal complements of one another's companions — \(\mathcal{N}(A) \perp \mathcal{C}(A^\top)\) in \(\mathbb{R}^n\), and \(\mathcal{N}(A^\top) \perp \mathcal{C}(A)\) in \(\mathbb{R}^m\).

The Four Subspaces at a Glance

Row Space \(\mathcal{C}(A^\top)\) — lives in \(\mathbb{R}^n\) Span of the rows of \(A\). Dimension = rank \(r\). Inputs that produce nonzero outputs.
Null Space \(\mathcal{N}(A)\) — lives in \(\mathbb{R}^n\) All \(\mathbf{x}\) with \(A\mathbf{x} = \mathbf{0}\). Dimension = \(n - r\). Inputs that map to zero.
Column Space \(\mathcal{C}(A)\) — lives in \(\mathbb{R}^m\) Span of the columns of \(A\). Dimension = rank \(r\). All reachable outputs \(A\mathbf{x}\).
Left Null Space \(\mathcal{N}(A^\top)\) — lives in \(\mathbb{R}^m\) All \(\mathbf{y}\) with \(A^\top \mathbf{y} = \mathbf{0}\). Dimension = \(m - r\). Output directions A cannot reach.

How the Subspaces Arise — Rank-Nullity & Orthogonality
▼

The Rank-Nullity Theorem

For any \(m \times n\) matrix \(A\) with rank \(r\):

$$\underbrace{\dim\,\mathcal{C}(A^\top)}_{\text{row space}} + \underbrace{\dim\,\mathcal{N}(A)}_{\text{null space}} = n$$

In words: every direction in \(\mathbb{R}^n\) either "gets used" (lives in the row space and produces a nonzero output) or "gets killed" (lives in the null space and maps to zero). Together they partition \(\mathbb{R}^n\) completely: \(\mathbb{R}^n = \mathcal{C}(A^\top) \oplus \mathcal{N}(A)\).

$$\underbrace{\dim\,\mathcal{C}(A)}_{\text{column space}} + \underbrace{\dim\,\mathcal{N}(A^\top)}_{\text{left null space}} = m$$

The Fundamental Orthogonality

This is the deepest fact: the null space is orthogonal to the row space, and the left null space is orthogonal to the column space:

$$\mathcal{N}(A) \perp \mathcal{C}(A^\top), \quad \mathcal{N}(A^\top) \perp \mathcal{C}(A)$$

Proof sketch for the first: if \(A\mathbf{x} = \mathbf{0}\), then for any row \(\mathbf{r}_i^\top\) of \(A\), we have \(\mathbf{r}_i^\top \mathbf{x} = 0\). So \(\mathbf{x}\) is orthogonal to every row, hence to every linear combination of rows. QED.

🔑 Key Property — Unique Decomposition

Every input \(\mathbf{x} \in \mathbb{R}^n\) decomposes uniquely as \(\mathbf{x} = \mathbf{x}_r + \mathbf{x}_n\) where \(\mathbf{x}_r \in \mathcal{C}(A^\top)\) and \(\mathbf{x}_n \in \mathcal{N}(A)\). Only \(\mathbf{x}_r\) survives: \(A\mathbf{x} = A\mathbf{x}_r\). This is why least-squares solutions have the form \(\hat{\mathbf{x}} = \mathbf{x}_r\) (minimum-norm component from the row space).

Why This Matters for Linear Systems \(A\mathbf{x} = \mathbf{b}\)

  • No solution — \(\mathbf{b} \notin \mathcal{C}(A)\) (b is outside the column space)
  • Unique solution — \(\mathbf{b} \in \mathcal{C}(A)\) and \(\mathcal{N}(A) = \{\mathbf{0}\}\)
  • Infinitely many solutions — \(\mathbf{b} \in \mathcal{C}(A)\) and \(\dim\,\mathcal{N}(A) \geq 1\)

Computing the Subspaces — RREF & Worked Example
▼

Example Matrix

Let us work through the \(3 \times 4\) matrix:

$$A = \begin{bmatrix} 1 & 2 & 0 & -1 \\ 2 & 4 & 1 & 3 \\ 3 & 6 & 1 & 2 \end{bmatrix}$$

Step 1 — Row Reduce to RREF

Perform Gaussian elimination \((R_2 \leftarrow R_2 - 2R_1,\ R_3 \leftarrow R_3 - 3R_1,\ R_3 \leftarrow R_3 - R_2)\):

$$\text{RREF}(A) = \begin{bmatrix} 1 & 2 & 0 & -1 \\ 0 & 0 & 1 & 5 \\ 0 & 0 & 0 & 0 \end{bmatrix}$$

Pivot columns: 1, 3. Free columns: 2, 4. Rank \(r = 2\).

Step 2 — Column Space \(\mathcal{C}(A)\)

The column space is spanned by the original pivot columns of \(A\) (not RREF):

$$\mathcal{C}(A) = \operatorname{span}\!\left\{\begin{bmatrix}1\\2\\3\end{bmatrix},\; \begin{bmatrix}0\\1\\1\end{bmatrix}\right\} \subset \mathbb{R}^3$$

Step 3 — Null Space \(\mathcal{N}(A)\)

Free variables: \(x_2 = s\), \(x_4 = t\). Back-substituting into RREF:

$$x_1 = -2s + t,\quad x_3 = -5t$$
$$\mathcal{N}(A) = s\begin{bmatrix}-2\\1\\0\\0\end{bmatrix} + t\begin{bmatrix}1\\0\\-5\\1\end{bmatrix}$$

Dimension of null space \(= n - r = 4 - 2 = 2\). Verify: \(A \cdot (-2,1,0,0)^\top = (0,0,0)^\top\). ✓ \(A \cdot (1,0,-5,1)^\top = (0,0,0)^\top\). ✓

⚠️ Common Mistake

The column space uses original columns of \(A\), not the RREF columns. The RREF pivot columns (like \((1,0,0)^\top\)) are NOT columns of \(A\). Row operations change columns but preserve which columns are pivot columns.

Step 4 — Row Space \(\mathcal{C}(A^\top)\)

The nonzero rows of RREF form a basis for the row space:

$$\mathcal{C}(A^\top) = \operatorname{span}\!\left\{\begin{bmatrix}1\\2\\0\\-1\end{bmatrix},\; \begin{bmatrix}0\\0\\1\\5\end{bmatrix}\right\} \subset \mathbb{R}^4$$

Step 5 — Left Null Space \(\mathcal{N}(A^\top)\)

Solve \(A^\top \mathbf{y} = \mathbf{0}\). Since rank \(r = 2\) and \(m = 3\), the left null space has dimension \(m - r = 1\). Because row 3 of \(A\) equals row 1 + row 2, the vector \(\mathbf{l} = (-1, -1, 1)^\top\) satisfies:

$$A^\top (-1,-1,1)^\top = (-1)\text{[row 1]}^\top + (-1)\text{[row 2]}^\top + (1)\text{[row 3]}^\top = \mathbf{0}$$
$$\mathcal{N}(A^\top) = \operatorname{span}\!\left\{\begin{bmatrix}-1\\-1\\1\end{bmatrix}\right\} \subset \mathbb{R}^3$$

Verification: Orthogonality

Check null space ⊥ row space: \((-2,1,0,0) \cdot (1,2,0,-1) = -2+2+0+0 = 0\). ✓

Check left null space ⊥ column space: \((-1,-1,1) \cdot (1,2,3) = -1-2+3 = 0\). ✓ \((-1,-1,1) \cdot (0,1,1) = 0-1+1 = 0\). ✓

Key Takeaways & Applications
▼

The Dimension Theorem Summary

$$\text{rank}(A) + \text{nullity}(A) = n \quad\text{(columns of }A\text{)}$$
$$\text{rank}(A) + \text{dim}\,\mathcal{N}(A^\top) = m \quad\text{(rows of }A\text{)}$$

When Each Subspace Is Trivial

  • Full column rank (\(r = n\)): null space is \(\{\mathbf{0}\}\) — \(A\mathbf{x} = \mathbf{b}\) has at most one solution.
  • Full row rank (\(r = m\)): left null space is \(\{\mathbf{0}\}\) — \(A\mathbf{x} = \mathbf{b}\) always has a solution.
  • Square full rank (\(r = m = n\)): both null spaces are trivial — \(A\) is invertible.

Applications in ML & Data Science

  • Least squares — Minimum-norm solution lives in the row space; the null space component is arbitrary and can be zeroed out via pseudoinverse.
  • PCA / SVD — Left singular vectors span \(\mathcal{C}(A)\) and \(\mathcal{N}(A^\top)\); right singular vectors span \(\mathcal{C}(A^\top)\) and \(\mathcal{N}(A)\).
  • Neural networks — Dead neurons create large null spaces; rank deficiency signals redundant features.
  • Regularization — Ridge regression (\(A^\top A + \lambda I\)) always has trivial null space for \(\lambda > 0\).
💡 The Big Picture

The four fundamental subspaces, discovered by Gilbert Strang, are the complete answer to "what does \(A\) do?" The column space tells you what's reachable; the null space tells you what's lost; their orthogonal complements (row space and left null space) complete the picture in both the domain and codomain.

Code Trace — Computing the Four Subspaces
▼
import numpy as np
from scipy.linalg import null_space, orth
A = np.array([[ 1, 2, 0, -1],
[ 2, 4, 1, 3],
[ 3, 6, 1, 2]], dtype=float)
# Rank
r = np.linalg.matrix_rank(A) # r = 2
# Column space: ONB via SVD
C_A = orth(A) # shape (3, r) — r left singular vectors
# Null space: right singular vectors for zero singular values
N_A = null_space(A) # shape (4, n-r) = (4, 2)
# Row space (= col space of A.T)
R_A = orth(A.T) # shape (4, r)
# Left null space (= null space of A.T)
LN_A = null_space(A.T) # shape (3, m-r) = (3, 1)
# Verify orthogonality: N(A) ⊥ C(A^T)
print(np.allclose(N_A.T @ R_A, 0)) # True
# Verify: null space vectors map to 0
print(np.allclose(A @ N_A, 0)) # True
# Pseudoinverse — minimum-norm least-squares solution
b = np.array([1.0, 5.0, 3.0])
x_min = np.linalg.pinv(A) @ b # lives in row space
print("||x_min||:", np.linalg.norm(x_min)) # minimum norm
