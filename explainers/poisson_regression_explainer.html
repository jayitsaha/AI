1
Understanding Poisson Regression
▼

What is it? Ordinary linear regression predicts a continuous number that can be positive or negative. But many real outcomes are counts — the number of website visits per hour, road accidents per month, emails received per day — which are always non-negative integers. Poisson regression is the right tool: it models the expected count \(\mu\) using an exponential function so the prediction is always positive, and assumes the data follows a Poisson distribution around that mean.

Analogy: Imagine you run a bakery and want to predict how many customers arrive each hour based on the day of the week and whether it is raining. Customers arrive one at a time (counts!), never a negative number. Poisson regression says: "Each feature shifts the rate multiplicatively." Rain might halve the expected arrivals; being a Saturday might double them. The effects combine by multiplication, not addition — that is the key structural insight.

💡 If you remember one thing

Poisson regression uses the log link: $$\log(\mu) = x^\top\beta \quad\Longrightarrow\quad \mu = e^{x^\top\beta}$$ This guarantees \(\mu > 0\) always, and each coefficient \(\beta_j\) acts as a rate ratio on the multiplicative scale — \(e^{\beta_j}\) is how much the expected count is multiplied when \(x_j\) increases by 1.

2
The Log Link & Exponential Mean Curve
▼

Why Not Use OLS on Count Data?

Three problems arise with ordinary linear regression on counts: (1) the fitted line can predict negative counts, which are nonsensical; (2) the Gaussian error assumption is wrong — count variance grows with the mean; and (3) errors are heteroscedastic by nature. Poisson regression fixes all three by choosing a distribution that lives on non-negative integers and a link function that maps the mean to the real line.

The Log Link: \(\eta = \log(\mu)\)

A Generalized Linear Model (GLM) has three parts: a random component (Poisson distribution), a systematic component (linear predictor \(\eta = x^\top\beta\)), and a link function connecting them. For Poisson regression the canonical link is the natural logarithm:

$$\eta = \log(\mu) = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p$$

Inverting gives the mean function — an exponential in the predictors:

$$\mu = e^{\beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p} = e^{\beta_0} \cdot e^{\beta_1 x_1} \cdots e^{\beta_p x_p}$$

Multiplicative Effects (Rate Ratios)

Because the effects are exponentiated, they combine multiplicatively. When \(x_j\) increases by 1 unit, \(\mu\) is multiplied by \(e^{\beta_j}\). This quantity is called the rate ratio (or incidence rate ratio, IRR). If \(\beta_j = 0.3\) then \(e^{0.3} \approx 1.35\): each unit increase in \(x_j\) increases the expected count by 35%.

🔑 Key Property — Mean-Variance Equality

For a Poisson random variable \(Y \sim \text{Poisson}(\mu)\): $$\mathbb{E}[Y] = \mu \quad \text{and} \quad \operatorname{Var}(Y) = \mu$$ Mean equals variance. This is the defining constraint. In practice, real count data often show overdispersion (\(\operatorname{Var} > \mathbb{E}\)) — in that case use Negative Binomial regression instead.

Exposure / Offset Terms

Often counts are observed over varying exposure windows (different time periods, population sizes). An offset adjusts for this without estimating an additional coefficient. If exposure is \(t\) (e.g., person-years at risk), we model the rate \(\lambda = \mu/t\):

$$\log(\mu) = \log(t) + x^\top\beta \quad\Longrightarrow\quad \log\!\left(\frac{\mu}{t}\right) = x^\top\beta$$

The offset \(\log(t)\) is added to \(\eta\) with its coefficient fixed at 1 (not estimated). This is critical for comparing rates across groups with different follow-up times.

3
Why It Works — The Math
▼

The Poisson Log-Likelihood

The probability mass function for \(Y_i \sim \text{Poisson}(\mu_i)\) is \(P(Y_i = y_i) = e^{-\mu_i}\mu_i^{y_i}/y_i!\). Taking the log-likelihood over \(n\) observations:

$$\ell(\beta) = \sum_{i=1}^n \left[y_i \log(\mu_i) - \mu_i - \log(y_i!)\right] = \sum_{i=1}^n \left[y_i \cdot x_i^\top\beta - e^{x_i^\top\beta}\right] + C$$

where \(C\) does not depend on \(\beta\). We maximize this with respect to \(\beta\).

Score Equations (Gradient)

The score (gradient of \(\ell\)) with respect to \(\beta\) is:

$$\frac{\partial \ell}{\partial \beta} = \sum_{i=1}^n x_i(y_i - \mu_i) = X^\top(y - \mu)$$

Setting to zero gives the MLE condition: the residuals \(y_i - \mu_i\) are orthogonal to the design matrix \(X\).

Hessian & Fisher Information

The negative expected Hessian (Fisher information) is:

$$\mathcal{I}(\beta) = X^\top W X \quad\text{where } W = \operatorname{diag}(\mu_1, \ldots, \mu_n)$$

So the covariance of the MLE is \(\operatorname{Var}(\hat\beta) \approx (X^\top W X)^{-1}\).

IRLS — Iteratively Reweighted Least Squares

There is no closed-form solution; we use Newton-Raphson. The update at iteration \(t\) is:

$$\beta^{(t+1)} = \beta^{(t)} + (X^\top W^{(t)} X)^{-1} X^\top (y - \mu^{(t)})$$

Equivalently, this solves a weighted least squares problem at each step on the adjusted dependent variable \(z_i = \eta_i^{(t)} + (y_i - \mu_i^{(t)})/\mu_i^{(t)}\) with weights \(w_i = \mu_i^{(t)}\). Convergence is typically achieved in 5–10 iterations.

⚠️ Overdispersion Warning

If \(\operatorname{Var}(y) \gg \bar{y}\) the Poisson assumption is violated. Check the dispersion statistic \(\phi = \text{Deviance} / (n - p)\). If \(\phi \gg 1\), use Negative Binomial regression (adds a variance parameter \(r\): \(\operatorname{Var} = \mu + \mu^2/r\)) or quasi-Poisson (scale standard errors by \(\sqrt{\phi}\)).

5
Key Takeaways & When to Use
▼

Use Poisson regression when:

  • The response is a non-negative integer count (accidents, goals, website hits, mutations).
  • The mean-variance equality \(\mathbb{E}[Y] = \operatorname{Var}(Y)\) is roughly satisfied (check the dispersion statistic).
  • You need multiplicative / rate-ratio interpretations of coefficients.
  • You want to compare rates across groups with different exposures (use offset).

Prefer alternatives when:

  • Overdispersion (\(\operatorname{Var} \gg \mathbb{E}\)): use Negative Binomial or quasi-Poisson.
  • Zero-inflation (too many zeros): use Zero-Inflated Poisson (ZIP) or Hurdle models.
  • Bounded counts (e.g., successes out of \(n\) trials): use Binomial / logistic regression.
  • Continuous non-negative (e.g., revenue): use Gamma GLM or log-normal regression.
🎯 Decision Rule

Always plot a histogram of your outcome. If it looks like discrete non-negative counts and the mean ≈ variance, Poisson is your starting point. Fit it, then check residuals and the dispersion statistic. Upgrade to Negative Binomial if over-dispersed.

From-Scratch IRLS Code
▼

Pure NumPy IRLS implementation of Poisson regression — every step matches the math above.

import numpy as np
def poisson_irls(X, y, max_iter=25, tol=1e-8):
"""Fit Poisson GLM via Iteratively Reweighted Least Squares."""
n, p = X.shape
beta = np.zeros(p) # initialise at zero
for it in range(max_iter):
eta = X @ beta # linear predictor η = Xβ
mu = np.exp(eta) # fitted mean μ = exp(η), always > 0
W = np.diag(mu) # weight matrix W = diag(μ)
score = X.T @ (y - mu) # ∂ℓ/∂β = Xᵀ(y − μ)
hessian = -X.T @ W @ X # ∂²ℓ/∂β² = −XᵀWX
delta = np.linalg.solve(-hessian, score) # Newton step
beta += delta
if np.max(np.abs(delta)) < tol:
break
cov = np.linalg.inv(X.T @ W @ X) # asymptotic covariance (XᵀWX)⁻¹
se = np.sqrt(np.diag(cov)) # standard errors
return beta, se, np.exp(beta) # β, SE, rate ratios e^β
# --- Example: count of bike rentals by hour and temperature ---
X = np.column_stack([np.ones(8), np.arange(8)]) # intercept + predictor
y = np.array([0, 6, 5, 8, 8, 22, 27, 40]) # observed counts
beta, se, rr = poisson_irls(X, y)
print(f"β₀={beta[0]:.4f} β₁={beta[1]:.4f}")
print(f"Rate ratio e^β₁ = {rr[1]:.4f} → each +1 unit × count by {rr[1]:.3f}")

Production usage: Use statsmodels.formula.api.glm(formula, family=sm.families.Poisson()) or scikit-learn's PoissonRegressor. For offsets add offset=np.log(exposure) to the GLM call.
