1
Understanding f-Divergences
▼

What is it? An f-divergence is a universal framework for measuring how different two probability distributions P and Q are. Almost every classical statistical "distance" — KL divergence, Total Variation, Jensen-Shannon, Pearson \(\chi^2\) — is a special case obtained by choosing a different generator function \(f\).

Analogy: Imagine two stacks of coins, one representing distribution P and one Q. The f-divergence asks: "How costly is it to account for the discrepancy?" Different cost functions \(f\) give different answers. A quadratic \(f\) punishes large discrepancies heavily; a logarithmic \(f\) is more moderate. All valid choices share one property: the cost is zero when the two stacks are identical.

$$D_f(P \,\|\, Q) = \sum_x q(x)\, f\!\left(\frac{p(x)}{q(x)}\right) \quad \text{or continuously} \quad \int q(x)\, f\!\left(\frac{p(x)}{q(x)}\right) dx$$

where \(f : (0,\infty) \to \mathbb{R}\) is convex with \(f(1) = 0\). The argument \(t = p(x)/q(x)\) is the density ratio (likelihood ratio) at each point \(x\).

💡 If you remember one thing

Every f-divergence is \(D_f(P\|Q) = \mathbb{E}_Q[f(p/q)]\) — the expectation under Q of a convex penalty on the likelihood ratio. Jensen's inequality guarantees \(D_f \geq f(\mathbb{E}_Q[p/q]) = f(1) = 0\), with equality iff \(P = Q\).

The Generator Function Zoo
▼

Choosing different convex generators \(f(t)\) recovers every classical divergence. The five most important, with numerically verified values on the demo distributions \(P=(0.35, 0.25, 0.20, 0.15, 0.05)\), \(Q=(0.20, 0.30, 0.20, 0.20, 0.10)\):

🔑 Non-negativity via Jensen's Inequality

Since \(\mathbb{E}_Q[p/q] = \sum_x p(x) = 1\) and \(f\) is convex: $$D_f(P\|Q) = \mathbb{E}_Q\!\left[f\!\left(\tfrac{p}{q}\right)\right] \geq f\!\left(\mathbb{E}_Q\!\left[\tfrac{p}{q}\right]\right) = f(1) = 0.$$ Equality holds iff \(P = Q\) \(\mu\)-almost everywhere.

Asymmetry: KL vs Reverse-KL

KL(P‖Q) blows up when \(q(x)\to 0\) but \(p(x)>0\): the model Q must "cover" all of P's support. This causes mass-covering behavior. Reverse-KL(Q‖P) blows up when \(p(x)\to 0\) but \(q(x)>0\): it forces Q to zero-out where P is zero, causing mode-dropping in variational inference.

3
The Fenchel Variational Bound — f-GAN
▼

Why Variational Bounds Matter

We can't evaluate \(D_f(P\|Q)\) directly when we only have samples from P (data) and Q (model), not closed-form densities. Nowozin et al. (2016) showed how to turn any f-divergence into a tractable minimax game using Fenchel conjugation.

The Fenchel Conjugate

$$f^*(s) = \sup_{t > 0}\, \bigl\{s \cdot t - f(t)\bigr\}$$

Since \(f\) is convex, \(f^*\) is also convex and the double conjugate restores \(f\): \(f(t) = \sup_{s}\{s \cdot t - f^*(s)\}\). Plugging into \(D_f\) and swapping sup and integral (valid by measurability):

$$D_f(P\|Q) \;\geq\; \sup_{T\colon\mathcal{X}\to\mathbb{R}}\!\left\{\mathbb{E}_P[T(x)] - \mathbb{E}_Q[f^*(T(x))]\right\}$$

The bound is tight at \(T^*(x) = f'(p(x)/q(x))\). In the f-GAN framework, \(T\) is a neural network discriminator.

f-GAN Conjugate Pairs

Divergence\(f(t)\)\(f^*(s)\)Output activation \(g_f(v)\)
KL\(t\log t\)\(e^{s-1}\)\(v\) (identity)
Reverse KL\(-\log t\)\(-1-\log(-s),\; s{<}0\)\(-e^v\)
JSD(see above)\(-\log(1+e^{-s})\)\(\log\sigma(v)\) where \(\sigma\) = sigmoid
Total Variation\(\frac{1}{2}|t-1|\)\(s,\; |s|\leq\tfrac{1}{2}\)\(\tfrac{1}{2}\tanh(v)\)
Pearson \(\chi^2\)\((t-1)^2\)\(\tfrac{s^2}{4}+s\)\(v\)
∑ Unified f-GAN Objective

For any f-divergence, the GAN minimax game is: $$\min_\theta \max_\phi \; \mathbb{E}_{x \sim P_{\text{data}}}\!\left[g_f(T_\phi(x))\right] - \mathbb{E}_{x \sim P_\theta}\!\left[f^*(g_f(T_\phi(x)))\right]$$ The original GAN (Goodfellow 2014) corresponds to \(f = \text{JSD}\). Wasserstein GAN uses a different (non-f) divergence.

⚠️ Support Overlap Requirement

f-divergences require P to be absolutely continuous w.r.t. Q (\(P \ll Q\)). If the model and data have non-overlapping support (common early in GAN training), KL and reverse-KL are infinite and JSD/TV become constants — giving zero gradient. This is the core motivation for Wasserstein distance, which is not an f-divergence.

Key Takeaways — When to Use Each
▼
  • KL(P‖Q) — VAE ELBO, cross-entropy loss, MLE. Forces model to cover all of P's support (may spread thin).
  • Reverse-KL(Q‖P) — Variational inference, wake-sleep. Mode-seeking: Q collapses to one mode of P.
  • JSD — Original GAN objective. Symmetric, bounded, but vanishes with disjoint support.
  • TV — Theoretical analysis, data processing inequality. Equals \(\tfrac{1}{2}\|P-Q\|_{L^1}\).
  • \(\chi^2\) — Importance sampling, RKHS divergence testing. Sensitive to heavy tails (ratio far from 1).
💡 Sensitivity Ordering by Tail Behavior

As the density ratio \(t \to \infty\), f(t) grows as: \(\chi^2 \sim t^2\) (fastest) > KL \(\sim t\log t\) > TV \(\sim t/2\) (slowest among these five). This means \(\chi^2\) and KL are most sensitive to regions where the model under-covers the data; TV and JSD are more robust when support barely overlaps.

Code — From Scratch
▼
import numpy as np
# Two discrete distributions over 5 outcomes
P = np.array([0.35, 0.25, 0.20, 0.15, 0.05])
Q = np.array([0.20, 0.30, 0.20, 0.20, 0.10])
def f_divergence(P, Q, f):
"""D_f(P||Q) = E_Q[f(P/Q)] = sum_x Q(x) * f(P(x)/Q(x))"""
t = P / Q # density ratio at each outcome
return np.sum(Q * f(t)) # expectation under Q
# KL(P||Q): f(t) = t*log(t)
kl = f_divergence(P, Q, lambda t: t * np.log(t)) # = 0.0725
# Reverse KL(Q||P): f(t) = -log(t)
rkl = f_divergence(P, Q, lambda t: -np.log(t)) # = 0.0696
# Jensen-Shannon divergence (correct generator)
jsd_f = lambda t: (t/2)*np.log(2*t/(t+1)) + 0.5*np.log(2/(t+1))
jsd = f_divergence(P, Q, jsd_f) # = 0.0175
# Total Variation: f(t) = |t-1|/2
tv = f_divergence(P, Q, lambda t: np.abs(t - 1) / 2) # = 0.1500
# Pearson chi-squared: f(t) = (t-1)^2
chi2 = f_divergence(P, Q, lambda t: (t - 1)**2) # = 0.1583
# ── Fenchel variational bound (f-GAN) ──
def kl_fenchel_bound(P_samples, Q_samples, T_fn):
"""KL(P||Q) >= E_P[T] - E_Q[exp(T-1)], tight when T=log(p/q)+1"""
return np.mean(T_fn(P_samples)) - np.mean(np.exp(T_fn(Q_samples) - 1))
# PyTorch f-GAN loss (KL variant)
# loss_D = -(E_real[T(x)] - E_fake[exp(T(x)-1)]) # maximize wrt discriminator
# loss_G = E_fake[exp(T(x)-1)] # minimize wrt generator
