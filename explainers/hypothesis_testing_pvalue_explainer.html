Understanding Hypothesis Testing
▼

What is it? Hypothesis testing is a formal procedure for deciding whether observed data provide enough evidence to reject a "default" claim. Think of it like a trial: the null hypothesis (\(H_0\)) is "innocent until proven guilty." You never prove \(H_0\) true — you either find enough evidence to reject it, or you don't.

Analogy: Imagine you flip a coin 100 times and get 62 heads. Could this be a fair coin? If the coin were fair (\(H_0\)), you'd expect about 50 heads. Getting 62 is unusual, but HOW unusual? Hypothesis testing answers exactly this: it computes the probability of seeing 62 or more heads under the assumption the coin is fair. If that probability is tiny (say 1%), you conclude the coin is likely unfair.

If you remember one thing

The p-value is the probability of observing a test statistic as extreme as (or more extreme than) the one we actually got, assuming the null hypothesis is true: \(p = P(T \geq t_{\text{obs}} \mid H_0)\). A small p-value means the data are surprising under \(H_0\), not that \(H_0\) is false.

The four components every hypothesis test shares:

  • Null hypothesis \(H_0\): the "no effect / no difference" claim (e.g. \(\mu = 100\)).
  • Alternative hypothesis \(H_1\): what we hope to show (e.g. \(\mu > 100\), one-sided, or \(\mu \neq 100\), two-sided).
  • Test statistic: a number computed from the sample that summarises the evidence (e.g. the z-score or t-score).
  • P-value (or critical region): the decision rule — how "surprising" is the observed statistic under \(H_0\)?
2
The Null Distribution & Test Statistic
▼

Null Distribution — The Central Object

Before collecting any data, we ask: if \(H_0\) were true, what would the test statistic look like? For a z-test of a mean with known \(\sigma\), the answer is \(Z \sim \mathcal{N}(0,1)\). For a t-test with unknown \(\sigma\) and \(n-1\) degrees of freedom, it is \(T \sim t_{n-1}\). This theoretical distribution is the null distribution.

Test Statistic — Standardising the Evidence

The test statistic converts the raw observation into a dimensionless "how far from \(H_0\)?" score. For a one-sample z-test:

$$Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}}$$

With \(\bar{x}=105\), \(\mu_0=100\), \(\sigma=15\), \(n=36\): \(Z = (105-100)/(15/6) = 5/2.5 = 2.0\). When \(\sigma\) is unknown, replace it with the sample standard deviation \(s\) and use the t-distribution with \(n-1\) degrees of freedom:

$$T = \frac{\bar{X} - \mu_0}{s / \sqrt{n}} \sim t_{n-1} \text{ under } H_0$$

One-Sided vs Two-Sided Tests

One-sided (directional): \(H_1: \mu > \mu_0\) — shade the right tail only. Use this only when you have a strong a priori reason to expect the effect in one direction.

Two-sided (non-directional): \(H_1: \mu \neq \mu_0\) — shade both tails. This is almost always the safer, more honest choice. It is harder to reach significance (p-value doubles), which is the point.

Key Property

Under \(H_0\), the p-value follows a Uniform(0,1) distribution. This is why the false-positive rate equals \(\alpha\) exactly when the null is true — not just approximately, but exactly (for continuous test statistics).

3
The Math — P-Value & Critical Region
▼

Formal Definition of the P-Value

For a right-sided test with observed statistic \(t_{\text{obs}}\):

$$p = P(T \geq t_{\text{obs}} \mid H_0) = 1 - F_{H_0}(t_{\text{obs}})$$

where \(F_{H_0}\) is the CDF of the test statistic under \(H_0\). For the two-sided case:

$$p = P(|T| \geq |t_{\text{obs}}| \mid H_0) = 2\bigl(1 - F_{H_0}(|t_{\text{obs}}|)\bigr)$$

With \(z_{\text{obs}} = 2.0\): one-sided \(p = 1 - \Phi(2.0) = 0.0228\); two-sided \(p = 2 \times 0.0228 = 0.0455\).

Critical Region and Significance Level \(\alpha\)

Choose \(\alpha\) (typically 0.05 or 0.01) before seeing the data. The critical region is the set of values for the test statistic that would lead to rejection:

$$\text{Reject } H_0 \iff |Z| \geq z_{\alpha/2} \quad \text{(two-sided)}$$

For \(\alpha = 0.05\): \(z_{0.025} = 1.96\) (two-sided) or \(z_{0.05} = 1.645\) (one-sided). Equivalently, reject iff \(p < \alpha\). Both rules give identical decisions — they are mathematically equivalent.

Type I and Type II Errors

Type I error (\(\alpha\)): Rejecting \(H_0\) when it is true — a false positive. \(P(\text{Type I}) = \alpha\) by construction.

Type II error (\(\beta\)): Failing to reject \(H_0\) when it is false — a false negative. Power = \(1 - \beta\). Power grows with sample size and effect size.

Common Pitfall

Choosing \(\alpha\) after seeing the data ("p-hacking") inflates the true Type I error rate well above the nominal \(\alpha\). Pre-registration of hypotheses and analysis plans addresses this.

Key Takeaways & P-Value Misinterpretations
▼

What p < 0.05 actually means

The p-value is the probability of observing a test statistic at least as extreme as the one computed, if the null hypothesis were true. A small p-value says: "This result would be rare by chance." It does NOT say by how much you should update your belief in \(H_0\).

Five Things p < 0.05 Does NOT Mean

1. It is NOT the probability that \(H_0\) is true.
2. It is NOT the probability of making a false positive decision (that depends on the prior).
3. It does NOT imply the effect is large or practically meaningful (effect size matters).
4. It does NOT "replicate" — p-values are noisy; a 0.049 today may be 0.12 next study.
5. p > 0.05 does NOT prove \(H_0\) — absence of evidence is not evidence of absence.

Use effect sizes and confidence intervals alongside p-values

  • Cohen's d: \(d = (\bar{x} - \mu_0)/\sigma\). Small ~0.2, medium ~0.5, large ~0.8.
  • 95% CI for \(\mu\): \(\bar{x} \pm 1.96\,\sigma/\sqrt{n}\). If it excludes \(\mu_0\), the test rejects at \(\alpha=0.05\) — same information, more interpretable.
  • With large \(n\), tiny, meaningless effects become statistically significant. Always report effect size.
When to use which test

Known \(\sigma\) → z-test. Unknown \(\sigma\), continuous → t-test. Proportions → z-test for proportions. Counts / categories → chi-squared. Non-normal, small n → non-parametric (Wilcoxon, permutation).

Code Trace
▼
import numpy as np
from scipy import stats
# One-sample z-test (known population std)
mu_0 = 100 # null hypothesis mean
sigma = 15 # known population std
n = 36 # sample size
x_bar = 105 # observed sample mean
# Test statistic
se = sigma / np.sqrt(n) # standard error = 15/6 = 2.5
z = (x_bar - mu_0) / se # z = (105-100)/2.5 = 2.0
print(f"z = {z:.4f}") # z = 2.0000
# One-sided p-value: P(Z >= 2.0 | H0)
p_one = stats.norm.sf(z) # sf = 1 - cdf = 0.0228
print(f"one-sided p = {p_one:.4f}") # 0.0228
# Two-sided p-value: P(|Z| >= 2.0 | H0)
p_two = 2 * stats.norm.sf(abs(z)) # 0.0455
print(f"two-sided p = {p_two:.4f}") # 0.0455
# t-test with unknown sigma
sample = np.array([102,107,98,110,103,106,99,108,104,101]) # n=10
t_stat, p_ttest = stats.ttest_1samp(sample, popmean=100)
print(f"t = {t_stat:.4f}, p = {p_ttest:.4f}")
