Understanding the Decoder Stack
▼

What is it? A Transformer decoder layer is the block that generates output tokens one at a time. Each layer runs THREE sub-operations in sequence: (1) masked self-attention over the tokens generated so far, (2) cross-attention over the encoder's finished representation of the source sequence, and (3) a position-wise feed-forward network (FFN) that refines each token's vector independently. Every sub-layer is wrapped in a residual connection and LayerNorm ("Add & Norm").

Analogy: Picture a translator writing a French sentence live, word by word. Before writing the next word they (1) re-read only the French words already on the page — never words they haven't written yet, that's masked self-attention; (2) glance back at the original English sentence for meaning — that's cross-attention, and it's the only channel through which source information enters the decoder; (3) apply their personal style rules to polish the word choice — that's the FFN, applied identically to every word position.

💡 If you remember one thing

A decoder layer is masked self-attention → cross-attention → FFN, each followed by Add & Norm. Self-attention lets a position see the past; cross-attention lets it see the entire source; the FFN does per-token nonlinear processing. Stack this block \(N\) times (6, 12, 96...) and finish with a linear layer + softmax over the vocabulary.

How the Decoder Layer Works Internally
▼

Sub-layer 1 — Masked Multi-Head Self-Attention

The decoder's own partial output \(Y \in \mathbb{R}^{T_y \times d}\) is projected into queries, keys, and values: \(Q=YW^Q, K=YW^K, V=YW^V\). Raw attention scores \(QK^\top/\sqrt{d_k}\) are computed for every pair of positions, but before the softmax a causal mask sets every score where the key position \(j\) is strictly after the query position \(i\) to \(-\infty\). This guarantees position \(i\) can only draw information from positions \(\le i\) — the same constraint that holds at inference time, when future tokens simply don't exist yet.

Sub-layer 2 — Encoder-Decoder Cross-Attention

Queries now come from the decoder's own (masked-self-attended) hidden state; keys and values come from the encoder's final output "memory" \(M \in \mathbb{R}^{T_x \times d}\), which is fixed for the whole decoding process and reused by every decoder layer and every generation step. No causal mask is applied here — a decoder position is allowed to look at the entire source sentence, since the source is fully known in advance. This is the ONLY sub-layer where information crosses from encoder to decoder.

Sub-layer 3 — Position-wise Feed-Forward Network

Each token's vector is passed independently through the same two-layer MLP: expand to \(d_{ff}\) (typically \(4d\)), apply a nonlinearity (ReLU or GELU), then project back to \(d\). "Position-wise" means the exact same weights are applied to every position separately — there is no mixing across positions inside the FFN; all cross-position mixing happens in the attention sub-layers.

Add & Norm

Every sub-layer is wrapped as \(x \leftarrow \text{LayerNorm}(x + \text{Sublayer}(x))\). The residual path gives gradients a direct identity route through dozens of stacked layers; LayerNorm keeps activation scale stable regardless of depth.

🔑 Design Decision — Why keep self-attn and cross-attn separate?

Splitting "what have I generated" (self-attention) from "what does the source say" (cross-attention) lets each be optimized independently, and — critically for inference speed — the cross-attention keys/values from the encoder are computed once and reused (cached) at every decoding step, while only the self-attention K/V cache grows token by token.

⚠️ Why −∞ masking, not zero-out-after-softmax?

Adding \(-\infty\) BEFORE the softmax makes \(\exp(-\infty)=0\) exactly, so masked positions contribute nothing to the normalizing sum. Zeroing weights AFTER a softmax computed over all positions would still let future tokens skew the normalization constant — a subtle but real correctness bug.

3
Why It Works — The Math
▼

Masked Scaled Dot-Product Attention

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}} + M\right)V, \qquad M_{ij} = \begin{cases}0 & j \le i \\ -\infty & j > i\end{cases}$$

The mask \(M\) is added ONLY in self-attention. In cross-attention \(M \equiv 0\) (aside from optional source-padding masks), and \(K, V\) are derived from the encoder memory \(M_{enc}\) instead of \(Y\):

$$Q = YW^Q, \quad K = M_{enc}W^K, \quad V = M_{enc}W^V, \qquad \text{CrossAttn}(Y, M_{enc}) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

Multi-Head Form

Each attention (self or cross) is run \(h\) times in parallel on \(d_k = d/h\)-dimensional projections, then concatenated and mixed with an output projection \(W^O\):

$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O, \quad \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

Position-wise FFN

$$\text{FFN}(x) = \max(0,\, xW_1 + b_1)\,W_2 + b_2, \qquad W_1 \in \mathbb{R}^{d \times d_{ff}},\; W_2 \in \mathbb{R}^{d_{ff} \times d}$$

Full Layer Recurrence

$$\begin{aligned}Z_1 &= \text{LayerNorm}\big(Y + \text{MaskedSelfAttn}(Y)\big)\\ Z_2 &= \text{LayerNorm}\big(Z_1 + \text{CrossAttn}(Z_1, M_{enc})\big)\\ Z_3 &= \text{LayerNorm}\big(Z_2 + \text{FFN}(Z_2)\big)\end{aligned}$$

Why Residuals Matter for Depth

Differentiating the wrapper \(x + f(x)\) with respect to \(x\) gives \(I + \partial f/\partial x\) — an identity term is always present, so gradients cannot vanish purely from stacking sub-layers, even across very deep stacks (GPT-style models routinely exceed 80 decoder layers).

⚠️ Common Pitfall

The causal mask alone is not enough with batched, padded sequences — you must ALSO combine it with a padding mask so attention never attends to \(\langle\text{pad}\rangle\) tokens. Forgetting the padding mask silently leaks garbage into otherwise-correct causal attention.

When each sub-layer matters:

  • Masked self-attention is what makes generation autoregressive — it enforces that training (teacher forcing) and inference (token-by-token decoding) see the same causal structure.
  • Cross-attention is the ONLY bridge between encoder and decoder — remove it and you get a decoder-only language model that can no longer condition on a separate source sequence.
  • The FFN holds roughly two-thirds of a Transformer's parameters (\(2 \times d \times d_{ff}\) vs. \(4d^2\) for attention when \(d_{ff}=4d\)) and is where much per-token "knowledge" is believed to be stored.
💡 KV-Cache Insight

At inference time, cross-attention K/V are computed once per source sentence and cached; self-attention K/V grow by one row per generated token and are also cached. This is why autoregressive decoding is \(O(T_y)\) incremental steps rather than recomputing the whole stack from scratch each time.

import numpy as np
def layer_norm(x, eps=1e-5):
mu = x.mean(-1, keepdims=True)
var = x.var(-1, keepdims=True)
return (x - mu) / np.sqrt(var + eps)
def attention(Q, K, V, mask=None):
scores = Q @ K.T / np.sqrt(Q.shape[-1])
if mask is not None:
scores = scores + mask # mask: 0 or -inf
weights = softmax(scores, axis=-1)
return weights @ V
def causal_mask(T):
m = np.triu(np.ones((T, T)), k=1) # j > i
return np.where(m == 1, -np.inf, 0.0)
def decoder_layer(Y, M_enc, W):
# 1. Masked self-attention
Q1, K1, V1 = Y @ W.Wq1, Y @ W.Wk1, Y @ W.Wv1
self_out = attention(Q1, K1, V1, causal_mask(Y.shape[0]))
Z1 = layer_norm(Y + self_out)
# 2. Cross-attention (Q from decoder, K/V from encoder memory)
Q2 = Z1 @ W.Wq2
K2, V2 = M_enc @ W.Wk2, M_enc @ W.Wv2
cross_out = attention(Q2, K2, V2, mask=None)
Z2 = layer_norm(Z1 + cross_out)
# 3. Position-wise feed-forward network
hidden = np.maximum(0, Z2 @ W.W1 + W.b1) # expand + ReLU
ffn_out = hidden @ W.W2 + W.b2 # project back down
Z3 = layer_norm(Z2 + ffn_out)
return Z3 # feeds the next decoder layer, or Linear+softmax if last
