Understanding Bagging
▼

What is it? Bagging — short for Bootstrap Aggregating — is an ensemble technique that trains many copies of the same learning algorithm on different random sub-samples of the training data, then combines their outputs. For regression the outputs are averaged; for classification they are decided by majority vote (or averaged probabilities for soft voting).

Analogy: Imagine asking 100 doctors to each look at a subset of your test results and give a diagnosis. Each doctor sees slightly different evidence and will make different errors. When you take the majority verdict, individual mistakes cancel out and the group is almost always right — even if no single doctor is excellent. That is bagging.

Why does it work? A single high-variance model (like a deep decision tree) overfits badly to whatever noise it was trained on. By averaging B such models trained on B different bootstrap samples, the noise-driven deviations average out while the true signal reinforces itself.

💡 If you remember one thing

Bagging attacks variance, not bias. If \(\hat{f}_b(x)\) are B iid estimators each with variance \(\sigma^2\), their average has variance \(\sigma^2 / B\). Bias is unchanged. This is why bagging helps high-variance learners (deep trees) but not high-bias ones (stumps). The aggregate prediction is $$\hat{f}_{bag}(x) = \frac{1}{B}\sum_{b=1}^{B} \hat{f}_b(x) \quad \text{(regression)}$$ or majority vote over \(\hat{y}_b(x)\) for classification.

2
How Bagging Works Internally
▼

Step 1 — Bootstrap Sampling

Given a training set \(\mathcal{D} = \{(x_i, y_i)\}_{i=1}^n\), draw B bootstrap samples \(\mathcal{D}^{*b}\) by sampling n points with replacement. Each \(\mathcal{D}^{*b}\) contains on average \(\approx 63.2\%\) of the original points (some repeated, some absent). The excluded \(\approx 36.8\%\) become the out-of-bag (OOB) set for \(b\).

Step 2 — Train B Base Learners

Fit a base learner \(\hat{f}_b\) on each \(\mathcal{D}^{*b}\) independently. For bagging, the base learner is typically an unpruned decision tree (maximum variance, minimum bias). Each tree overfits its own bootstrap sample — that is intentional.

Step 3 — Aggregate

Regression: \(\hat{f}_{bag}(x) = \frac{1}{B}\sum_{b=1}^{B} \hat{f}_b(x)\). The average smooths out the jagged individual curves.

Classification (hard vote): \(\hat{y}_{bag}(x) = \operatorname{mode}\{\hat{y}_b(x)\}_{b=1}^B\). The class predicted by the majority of trees wins.

Classification (soft vote): \(\hat{p}_{bag}(c|x) = \frac{1}{B}\sum_{b=1}^{B} \hat{p}_b(c|x)\), then \(\hat{y} = \operatorname{argmax}_c \hat{p}_{bag}(c|x)\). Soft voting uses probability estimates rather than hard labels and is generally preferred when classifiers are well-calibrated.

Out-of-Bag Error Estimation

Each training point \((x_i, y_i)\) is OOB for roughly \(B/e \approx 0.368 \cdot B\) trees. Averaging only over those trees gives a free cross-validation estimate — no separate validation set needed. OOB error tracks test error well as \(B \to \infty\).

🔑 Key Property — Variance Decomposition

Let \(\rho\) be the pairwise correlation between any two base learners' predictions. For B learners each with variance \(\sigma^2\):

$$\operatorname{Var}\!\left(\hat{f}_{bag}(x)\right) = \rho\,\sigma^2 + \frac{1-\rho}{B}\,\sigma^2$$

As \(B \to \infty\) the second term vanishes, leaving \(\rho\,\sigma^2\). Bagging cannot eliminate variance attributable to correlation between learners. This is why Random Forests additionally randomize features: to drive \(\rho\) toward zero.

⚠️ Common Misconception

Bagging does not reduce bias. Averaging biased estimators gives a biased estimator with the same bias. If the base learner consistently under-predicts (e.g., a shallow tree), averaging many of them still under-predicts. Bagging fixes variance, boosting fixes bias.

3
Why It Works — The Math
▼

Bias-Variance Decomposition for Regression

For a regression target with irreducible noise \(\varepsilon\), the expected squared error of any estimator \(\hat{f}(x)\) at a point \(x\) decomposes as:

$$\mathbb{E}\!\left[(y - \hat{f}(x))^2\right] = \underbrace{\operatorname{Bias}^2(\hat{f}(x))}_{\text{systematic error}} + \underbrace{\operatorname{Var}(\hat{f}(x))}_{\text{sampling noise}} + \underbrace{\sigma_\varepsilon^2}_{\text{irreducible}}$$

Assume each base learner \(\hat{f}_b\) is unbiased (or has bias \(\mu_\beta\)). The bias of the average equals the bias of each learner (linearity of expectation):

$$\operatorname{Bias}(\hat{f}_{bag}) = \operatorname{Bias}(\hat{f}_b)$$

For the variance, assume learners are identically distributed with pairwise correlation \(\rho\):

$$\operatorname{Var}\!\left(\frac{1}{B}\sum_{b=1}^B \hat{f}_b\right) = \frac{1}{B^2}\left(B\sigma^2 + B(B-1)\rho\sigma^2\right) = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2$$

Condorcet Jury Theorem (Classification)

If each of B classifiers independently has accuracy \(p > 0.5\), the probability that a strict majority are correct is:

$$P(\text{majority correct}) = \sum_{k=\lceil B/2 \rceil}^{B} \binom{B}{k} p^k (1-p)^{B-k}$$

By the law of large numbers this converges to 1 as \(B \to \infty\) whenever \(p > 0.5\). Numerically: with \(p = 0.7\) and \(B = 11\), ensemble accuracy \(\approx 0.922\); with \(B = 51\), it reaches \(0.999\).

📝 Bootstrap Sampling Probability

The probability that any given training point is not selected in a bootstrap sample of size \(n\) drawn with replacement is \(\left(1 - \tfrac{1}{n}\right)^n \to e^{-1} \approx 0.368\) as \(n \to \infty\). Hence each model sees \(\approx 63.2\%\) unique points, and \(\approx 36.8\%\) are OOB.

Why Bootstrap Rather Than Disjoint Folds?

Bootstrap sampling keeps each learner's training set at size \(n\), preserving the same capacity as the full model. Splitting into B disjoint folds would give each learner only \(n/B\) points — starving them. Repetition is the price paid; OOB gives it back for free validation.

⚠️ When Bagging Hurts

If the base learner is high-bias (e.g., a decision stump), \(\operatorname{Bias}^2\) dominates and bagging cannot help — averaging many bad models gives a bad model. Also, \(\rho \approx 1\) when all trees see the same dominant feature: variance barely shrinks. This motivates Random Forests (random feature subsets lower \(\rho\)).

Key Takeaways
▼

When to use Bagging:

  • Base learner has high variance and low bias (deep unpruned trees are ideal)
  • You need a free OOB error estimate without a held-out validation set
  • Training is parallelisable — each tree is independent
  • You want a simple, reliable ensemble baseline before trying boosting

When NOT to use:

  • Base learner is already low-variance (linear regression, naive Bayes) — minimal gain
  • High-bias learner — boosting is the right tool
  • Interpretability is required — a bag of 500 trees is a black box
  • Inference latency matters — must run B predictions instead of one
💡 Decision Guide

High variance? Use Bagging / Random Forest. High bias? Use Boosting (AdaBoost, Gradient Boosting). Both? Use stacking or a boosted forest. Need speed + accuracy? XGBoost or LightGBM (gradient-boosted trees with regularization).

From Scratch (NumPy + pure Python)

import numpy as np
from collections import Counter
class BaggingRegressor:
"""Bootstrap-Aggregating regressor using any base learner."""
def __init__(self, base_learner_fn, B=100):
# base_learner_fn() must return an object with .fit(X,y) and .predict(X)
self.base_learner_fn = base_learner_fn
self.B = B # number of bootstrap replications
self.models = [] # trained base learners
self.oob_preds = {} # {sample_idx: [predictions from OOB trees]}
def fit(self, X, y):
n = len(y)
self.oob_preds = {i: [] for i in range(n)}
for b in range(self.B):
# Bootstrap sample with replacement
idx = np.random.choice(n, size=n, replace=True)
oob_idx = np.setdiff1d(np.arange(n), np.unique(idx))
# Train base learner on bootstrap sample
model = self.base_learner_fn()
model.fit(X[idx], y[idx])
self.models.append(model)
# Collect OOB predictions for free error estimate
for i in oob_idx:
self.oob_preds[i].append(model.predict(X[[i]])[0])
return self
def predict(self, X):
# Average predictions across all B models ← regression aggregate
preds = np.stack([m.predict(X) for m in self.models], axis=0)
return preds.mean(axis=0)
def oob_score(self, y):
# Mean-squared error using only OOB predictions per sample
errors = []
for i, preds in self.oob_preds.items():
if preds: # skip if point was never OOB
errors.append((np.mean(preds) - y[i]) ** 2)
return np.mean(errors)

Production Usage (scikit-learn)

from sklearn.ensemble import BaggingClassifier, BaggingRegressor
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor
from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_score
# ── Regression ────────────────────────────────────────────────────────
reg = BaggingRegressor(
estimator=DecisionTreeRegressor(max_depth=None), # deep = high variance
n_estimators=200, # B — more is better, plateau around 100-200
max_samples=1.0, # fraction of n to bootstrap (1.0 = standard)
max_features=1.0, # fraction of features per tree (1.0 = all)
bootstrap=True, # set False for pasting (no replacement)
oob_score=True, # free OOB validation
n_jobs=-1, # parallelise across all CPU cores
random_state=42,
)
reg.fit(X_train, y_train)
