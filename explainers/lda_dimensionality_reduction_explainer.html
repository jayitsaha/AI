1
Understanding LDA
▼

What is it? LDA finds the best labeled lower-dimensional view of your data — the direction(s) where classes are most spread apart and each class is most internally compact. It uses class labels to guide the projection, unlike PCA which is completely blind to labels and just finds directions of maximum total variance.

Analogy: Imagine three groups of people standing on a 2D field. You want to project them onto a single line (1D) so that you can tell them apart. PCA projects along the direction of most overall spread — which might still blend all three groups together. LDA finds the line where the three clusters are most separated and most internally tight. It "knows" which people belong to which group and uses that knowledge.

💡 If you remember one thing

LDA finds at most \(C-1\) projection axes (where \(C\) = number of classes) by solving the generalized eigenproblem \(S_W^{-1}S_B\mathbf{w} = \lambda\mathbf{w}\). PCA maximizes total variance; LDA maximizes the ratio of between-class to within-class scatter.

PCA vs LDA — The Core Difference

Both are linear projections \(\mathbf{z} = W^\top \mathbf{x}\), but they optimize completely different objectives. PCA maximizes the total variance of the projected data (unsupervised). LDA maximizes Fisher's criterion — the ratio of projected between-class scatter to projected within-class scatter (supervised). The result: PCA can destroy class structure; LDA preserves and amplifies it.

How LDA Works Internally
▼

Step 1 — Compute scatter matrices

Given data \(\mathbf{x}_i \in \mathbb{R}^d\) with class labels \(y_i \in \{1,\ldots,C\}\), compute class means \(\boldsymbol{\mu}_c\) and overall mean \(\boldsymbol{\mu}\). The within-class scatter matrix \(S_W\) measures how spread each class is internally:

$$S_W = \sum_{c=1}^C \sum_{i: y_i=c} (\mathbf{x}_i - \boldsymbol{\mu}_c)(\mathbf{x}_i - \boldsymbol{\mu}_c)^\top$$

The between-class scatter matrix \(S_B\) measures how far apart the class means are from the overall mean:

$$S_B = \sum_{c=1}^C n_c (\boldsymbol{\mu}_c - \boldsymbol{\mu})(\boldsymbol{\mu}_c - \boldsymbol{\mu})^\top$$

Step 2 — Solve the generalized eigenproblem

Fisher's criterion for direction \(\mathbf{w}\) is \(J(\mathbf{w}) = \frac{\mathbf{w}^\top S_B \mathbf{w}}{\mathbf{w}^\top S_W \mathbf{w}}\). Maximizing this is equivalent to the generalized eigenproblem:

$$S_B \mathbf{w} = \lambda S_W \mathbf{w} \iff S_W^{-1} S_B \mathbf{w} = \lambda \mathbf{w}$$

The top \(C-1\) eigenvectors of \(S_W^{-1}S_B\) form the LDA projection matrix \(W \in \mathbb{R}^{d \times (C-1)}\).

Step 3 — Project

Project each data point: \(\mathbf{z}_i = W^\top \mathbf{x}_i \in \mathbb{R}^{C-1}\). The projected data has maximally separated class clouds.

🔑 Rank Limit: at most C−1 discriminant axes

\(S_B\) has rank at most \(C-1\) (sum of \(C\) rank-1 matrices with one linear constraint). This means LDA can produce at most \(C-1\) non-trivial projection directions regardless of the original dimensionality \(d\). For binary classification (\(C=2\)), LDA gives a single axis.

Why It Works — The Math
▼

Numerical trace on our 3-class 2D dataset

We use 60 points in \(\mathbb{R}^2\), 20 per class, with true means \(\boldsymbol{\mu}_0=[2,1.5]\), \(\boldsymbol{\mu}_1=[5,4]\), \(\boldsymbol{\mu}_2=[7.5,7]\). The computed scatter matrices are:

$$S_W = \begin{bmatrix}21.20 & 13.64 \\ 13.64 & 22.69\end{bmatrix}, \quad S_B = \begin{bmatrix}320.49 & 321.49 \\ 321.49 & 324.17\end{bmatrix}$$

Solving \(S_W^{-1}S_B\mathbf{w} = \lambda\mathbf{w}\) gives eigenvalues \(\lambda_1 = 18.12,\ \lambda_2 = 0.10\) and dominant eigenvector \(\mathbf{w}_1 = [0.760, 0.650]^\top\).

For PCA on the same data, the first principal component is \(\mathbf{v}_1 = [-0.704, -0.710]^\top\) (nearly the diagonal — total variance direction). The LDA axis is also near-diagonal but chosen to align with class separability.

⚠️ LDA Assumptions to Watch

(1) Gaussian classes with equal covariances: LDA's Fisher criterion is optimal under these assumptions (then LDA = Bayes-optimal). If covariances differ, use QDA. (2) \(S_W\) must be invertible: Fails when \(d \geq n\) (high-dimensional small sample). Fix: PCA first, then LDA (PCA+LDA pipeline). (3) Collinear classes: LDA fails if class means are collinear — use kernel LDA.

Key Takeaways & Trade-offs
▼
DimensionPCA (unsupervised)LDA (supervised)
Uses labelsNoYes
OptimizesTotal varianceBetween/within scatter ratio
Max axesmin(n−1, d)C−1
Best forCompression, visualization, noise reductionClassification preprocessing, feature extraction
Fails whenVariance ≠ discriminationd ≥ n, unequal covariances, nonlinear classes

When to use LDA:

  • Classification pipeline: reduce to \(C-1\) dimensions before a classifier
  • Visualization of labeled multi-class data (better than PCA for this)
  • Face recognition (Fisherfaces), speech features

When NOT to use:

  • High-dimensional data (\(d \geq n\)): \(S_W\) is singular — use PCA+LDA or regularized LDA
  • Non-Gaussian, multimodal, or non-linearly separable data — use kernel LDA or manifold methods
💡 Hierarchy

LDA (supervised, linear) ⊂ Kernel LDA (supervised, nonlinear) | PCA (unsupervised, linear) ⊂ Kernel PCA (unsupervised, nonlinear)

Code Trace — From Scratch & sklearn
▼
import numpy as np
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
# ── 1. From scratch ─────────────────────────────────────
def lda_from_scratch(X, y, n_components=None):
classes = np.unique(y)
C = len(classes)
d = X.shape[1]
mu = X.mean(axis=0) # overall mean
mu_c = {c: X[y==c].mean(0) for c in classes} # class means
# Within-class scatter S_W
S_W = np.zeros((d, d))
for c in classes:
Xc = X[y==c] - mu_c[c]
S_W += Xc.T @ Xc
# Between-class scatter S_B
S_B = np.zeros((d, d))
for c in classes:
diff = (mu_c[c] - mu).reshape(-1, 1)
S_B += np.sum(y==c) * (diff @ diff.T)
# Generalized eigenproblem: S_W^{-1} S_B w = lambda w
M = np.linalg.inv(S_W) @ S_B # d×d matrix
evals, evecs = np.linalg.eig(M)
evals, evecs = evals.real, evecs.real
idx = np.argsort(-evals) # descending
k = n_components or (C - 1) # at most C-1
W = evecs[:, idx[:k]] # projection matrix
return X @ W # projected data
# ── 2. sklearn (production) ─────────────────────────────
lda = LinearDiscriminantAnalysis(n_components=2) # C-1 max
Z = lda.fit_transform(X, y) # shape: (n, 2)
# ⚠️ sklearn uses SVD internally for numerical stability
# ⚠️ sklearn auto-normalizes; from-scratch does not
