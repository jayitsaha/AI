Understanding Integration Techniques
▼

What are integration techniques? The derivative rules (chain rule, product rule) have inverse counterparts for integration. Because integrals have no single mechanical algorithm, we recognise structural patterns in the integrand and apply the matching technique to undo how the function was constructed.

Analogy: Think of integration as solving a puzzle in reverse. Differentiation tells you how to break a function apart; integration asks you to reconstruct the original puzzle. Each technique is a different strategy: substitution reverses the chain rule, integration by parts reverses the product rule, partial fractions reverses adding fractions over a common denominator.

💡 If you remember one thing

Pick the technique by recognising the structure: composite function? → u-substitution. Product of unlike functions? → integration by parts (LIATE). Rational function? → partial fractions. Applying the wrong technique is not wrong — you'll simply reach a dead end and try again.

The Three Core Techniques at a Glance

  • u-Substitution — reverses the Chain Rule. Works when the integrand contains a function and (roughly) its derivative.
  • Integration by Parts — reverses the Product Rule via \(\int u\,dv = uv - \int v\,du\). The LIATE heuristic guides which factor to call \(u\).
  • Partial Fractions — rewrites a rational function \(P(x)/Q(x)\) as a sum of simpler fractions whose integrals are elementary.
2
How Each Technique Works Internally
▼

u-Substitution — Reverse Chain Rule

If \(f(x) = h(g(x)) \cdot g'(x)\), the chain rule says \(\frac{d}{dx}[H(g(x))] = H'(g(x)) \cdot g'(x)\). So setting \(u = g(x)\), \(du = g'(x)\,dx\) transforms \(\int h(g(x))\,g'(x)\,dx\) into the simpler \(\int h(u)\,du\). After integrating, substitute back \(u = g(x)\).

🔑 Recognition Signal

Look for an "inner function" \(g(x)\) whose derivative \(g'(x)\) appears (possibly up to a constant multiple) elsewhere in the integrand. Example: in \(\int 2x\cos(x^2)\,dx\), let \(u = x^2\), \(du = 2x\,dx\).

Integration by Parts — Reverse Product Rule

The product rule \((uv)' = u'v + uv'\) integrates to \(uv = \int u'v\,dx + \int uv'\,dx\), which rearranges to:

$$\int u\,dv = uv - \int v\,du$$

The LIATE heuristic chooses \(u\) (the factor to differentiate) in priority order: Logarithmic, Inverse trig, Algebraic (polynomials), Trigonometric, Exponential. This puts the "easier to integrate" factor as \(dv\).

⚠️ LIATE is a heuristic, not a law

For \(\int e^x \cos x\,dx\), both T and E are at the same LIATE level. Either choice works — you apply IBP twice, then solve an equation for the original integral (the "cyclic IBP" trick).

Partial Fractions — Decompose Then Integrate

Given \(\int \frac{P(x)}{Q(x)}\,dx\) where \(\deg P < \deg Q\), factor \(Q(x)\) over the reals. Each factor contributes terms to the decomposition:

  • Linear factor \((ax+b)^k\): terms \(\frac{A_1}{ax+b} + \cdots + \frac{A_k}{(ax+b)^k}\)
  • Irreducible quadratic \((ax^2+bx+c)^k\): terms \(\frac{B_1 x + C_1}{ax^2+bx+c} + \cdots\)

Each term integrates to a logarithm or arctangent, making the result elementary. If \(\deg P \geq \deg Q\), perform polynomial long division first.

3
Why They Work — The Math
▼

u-Substitution (Change of Variables Theorem)

If \(g\) is differentiable on \([a,b]\) and \(f\) is continuous on \(g([a,b])\), then:

$$\int_a^b f(g(x))\,g'(x)\,dx = \int_{g(a)}^{g(b)} f(u)\,du$$

The justification is the Chain Rule: \(\frac{d}{dx}[F(g(x))] = F'(g(x))\cdot g'(x) = f(g(x))\cdot g'(x)\). Integrating both sides gives the formula.

Integration by Parts (from the Product Rule)

Integrate \((uv)' = u'v + uv'\) over \([a,b]\):

$$\left[uv\right]_a^b = \int_a^b u'v\,dx + \int_a^b uv'\,dx$$

Rearranging and writing in indefinite form: \(\int u\,dv = uv - \int v\,du\). The key is that \(\int v\,du\) should be simpler than the original integral — this is guaranteed when LIATE is applied correctly.

Partial Fractions (Lagrange Interpolation + FTA)

The Fundamental Theorem of Algebra guarantees \(Q(x)\) factors completely over \(\mathbb{C}\); real coefficients force complex roots to come in conjugate pairs, yielding real linear and irreducible quadratic factors. The decomposition existence is proved by the uniqueness of polynomial remainder and the structure of the rational function field. Each term \(\frac{A}{(ax+b)^k}\) integrates by the power rule, and \(\frac{Bx+C}{ax^2+bx+c}\) integrates via completing the square and arctangent.

∫ Key formulas

u-sub: \(\int f(g(x))\,g'(x)\,dx = F(g(x)) + C\)

IBP: \(\int u\,dv = uv - \int v\,du\)

PF building block: \(\int \frac{1}{ax+b}\,dx = \tfrac{1}{a}\ln|ax+b| + C\)

LIATE Heuristic & Technique Selection Guide
▼

When facing an integral, ask these questions in order:

  1. Is there a composite function with its derivative nearby? → u-substitution
  2. Is the integrand a product of algebraically unlike functions? → integration by parts
  3. Is the integrand a ratio of polynomials? → partial fractions

LIATE Priority Table for Integration by Parts

PriorityFunction TypeExamplesRole
LLogarithmic\(\ln x,\; \log_a x\)Choose as \(u\) (differentiate)
IInverse Trig\(\arctan x,\; \arcsin x\)Choose as \(u\)
AAlgebraic\(x^2,\; x^3-1\)Often \(u\) unless paired with exp
TTrigonometric\(\sin x,\; \cos x\)Often \(dv\) (integrate)
EExponential\(e^x,\; 2^x\)Choose as \(dv\) (easy to integrate)
💡 Decision Flowchart

Spot a ln or arctan? → IBP, set it as \(u\). Spot \(x^n e^x\) or \(x^n \cos x\)? → IBP, polynomial is \(u\). Spot \(\frac{\text{poly}}{\text{poly}}\)? → partial fractions. Spot composition? → u-sub.

6
Code — Symbolic Computation (SymPy)
▼

Using Python's SymPy library to verify each technique symbolically:

import sympy as sp
x, u, A, B, C = sp.symbols('x u A B C')
# ── u-Substitution: ∫ 2x·cos(x²) dx ──────────────────────
f_usub = 2*x * sp.cos(x**2)
result_usub = sp.integrate(f_usub, x) # → sin(x²) + C
print("u-sub:", result_usub) # sin(x**2)
# Verify via substitution: let u = x², du = 2x dx
inner = x**2 # g(x)
f_in_u = sp.cos(u) # h(u)
result_u = sp.integrate(f_in_u, u) # sin(u)
result_back = result_u.subs(u, inner) # sin(x²)
print("manual u-sub:", result_back)
# ── Integration by Parts: ∫ x·eˣ dx ──────────────────────
f_ibp = x * sp.exp(x)
result_ibp = sp.integrate(f_ibp, x) # → (x-1)eˣ + C
print("IBP:", result_ibp) # (x - 1)*exp(x)
# Manual IBP: u=x, dv=eˣ dx → du=dx, v=eˣ
u_term = x; dv = sp.exp(x)
v_term = sp.integrate(dv, x) # eˣ
ibp_manual = u_term*v_term - sp.integrate(v_term, x) # x·eˣ - eˣ
print("IBP manual:", sp.simplify(ibp_manual - result_ibp)) # 0
# ── Partial Fractions: ∫ 1/(x²-1) dx ─────────────────────
f_pf = 1 / (x**2 - 1)
pf_decomp = sp.apart(f_pf, x) # -1/(2(x+1)) + 1/(2(x-1))
print("PF decomp:", pf_decomp)
result_pf = sp.integrate(pf_decomp, x) # ½ ln|x-1| - ½ ln|x+1| + C
print("PF:", result_pf) # log(x-1)/2 - log(x+1)/2
