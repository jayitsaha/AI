1
What is SVD and Why Does It Power So Much?
▼

What is SVD? Every matrix \(A\) — no matter the shape — can be factored as \(A = U\Sigma V^\top\), where \(U\) and \(V\) are orthogonal matrices (pure rotations/reflections) and \(\Sigma\) is diagonal (the singular values, always non-negative, sorted descending). Think of it as finding the natural axes of the data.

The key insight: The singular values \(\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_r\) measure importance. Truncating to the top \(k\) — keeping only \(\sigma_1, \ldots, \sigma_k\) — gives the best rank-\(k\) approximation to \(A\) in both Frobenius and spectral norm (Eckart–Young theorem). This single fact is the engine behind all five applications below.

💡 If you remember one thing

The rank-\(k\) truncated SVD \(\hat{A}_k = U_k \Sigma_k V_k^\top\) is the closest rank-\(k\) matrix to \(A\) in Frobenius norm. This optimality makes it the foundation of dimensionality reduction, image compression, LSA, matrix completion, and the pseudoinverse — all at once.

2
Core Theory — The Eckart–Young Theorem
▼

The Decomposition

For \(A \in \mathbb{R}^{m \times n}\) with rank \(r\), the full SVD is:

$$A = U\Sigma V^\top = \sum_{i=1}^{r} \sigma_i \mathbf{u}_i \mathbf{v}_i^\top$$

where \(U \in \mathbb{R}^{m \times m}\), \(\Sigma \in \mathbb{R}^{m \times n}\) (diagonal, non-negative), \(V \in \mathbb{R}^{n \times n}\). The outer-product form \(\sum_i \sigma_i \mathbf{u}_i \mathbf{v}_i^\top\) shows each singular triplet as a rank-1 "building block."

The Eckart–Young Theorem (1936)

The best rank-\(k\) approximation (in Frobenius or spectral norm) is:

$$\hat{A}_k = U_k \Sigma_k V_k^\top = \sum_{i=1}^{k} \sigma_i \mathbf{u}_i \mathbf{v}_i^\top$$

The truncation error is exactly \(\|\,A - \hat{A}_k\|_F^2 = \sigma_{k+1}^2 + \cdots + \sigma_r^2\). No rank-\(k\) matrix can do better.

🔑 Key Property

The fraction of variance (energy) captured by rank-\(k\) is \(\sum_{i=1}^{k}\sigma_i^2 \big/ \sum_{i=1}^{r}\sigma_i^2\). In PCA this equals the explained variance ratio. In image compression it equals pixel fidelity. The same quantity governs all 5 applications.

Numerical Example

For \(A = \begin{bmatrix}3&2&2\\2&3&-2\end{bmatrix}\): singular values are \(\sigma_1 = 5,\; \sigma_2 = 3\). Rank-1 captures \(5^2/(5^2+3^2) = 73.5\%\) of variance; rank-2 (full) captures 100%.

3
Five Applications — Mathematical Summary
▼

1. Dimensionality Reduction (PCA)

Project data matrix \(X \in \mathbb{R}^{n \times d}\) onto top-\(k\) right singular vectors: \(Z = X V_k\). This is equivalent to PCA (centered data). The columns of \(V_k\) are the principal components.

2. Image Compression

Store only \(k\) rank-1 components instead of all \(mn\) pixels. Storage: \(k(m+n+1)\) vs \(mn\). Reconstruction: \(\hat{A}_k = \sum_{i=1}^k \sigma_i \mathbf{u}_i \mathbf{v}_i^\top\).

3. Latent Semantic Analysis (LSA)

Apply SVD to a term-document matrix \(M\). The left singular vectors \(U_k\) span a "latent topic" space. Documents close in this reduced space share topics even if they use different vocabulary — solving the synonym problem in IR.

4. Matrix Completion

Observe only entries \(\Omega \subseteq [m]\times[n]\). Assume \(A\) is low-rank. Solve: \(\min_{\hat{A},\,\text{rank}\leq k}\|\mathcal{P}_\Omega(\hat{A}-A)\|_F^2\). The nuclear-norm relaxation \(\min\|A\|_*\) (sum of singular values) subject to observed entries is convex and recovers the low-rank matrix exactly under RIP conditions.

5. Pseudoinverse \(A^+\)

For \(A = U\Sigma V^\top\), invert only the non-zero singular values:

$$A^+ = V \Sigma^+ U^\top \qquad \Sigma^+_{ii} = \begin{cases}1/\sigma_i & \sigma_i > 0 \\ 0 & \text{otherwise}\end{cases}$$

\(A^+\) gives the minimum-norm least-squares solution \(\hat{x} = A^+ b\). It satisfies the 4 Moore-Penrose conditions and handles rank-deficient / non-square systems gracefully.

⚠️ Common Pitfall

In matrix completion, the pseudoinverse, and compressed-sensing interpretations of LSA, people confuse truncating small singular values (low-rank approximation) with inverting only non-zero ones (pseudoinverse). These are dual operations but serve different goals: truncation reduces noise, inversion solves linear systems.

📐 Key Formula

$$Z = X V_k$$

Data row \(\mathbf{x}_i \in \mathbb{R}^d\) → projection \(\mathbf{z}_i = V_k^\top \mathbf{x}_i \in \mathbb{R}^k\). Reconstruction: \(\hat{\mathbf{x}}_i = V_k \mathbf{z}_i\). The column space of \(V_k\) is the optimal \(k\)-dimensional subspace minimising total reconstruction error.

💡 PCA Connection

If \(X\) is mean-centred, then \(V_k\) from SVD equals the eigenvectors of the covariance matrix \(\frac{1}{n-1}X^\top X\). The singular value \(\sigma_i = \sqrt{(n-1)\lambda_i}\) where \(\lambda_i\) is the eigenvalue. SVD is numerically preferred — it avoids forming \(X^\top X\) explicitly.

📐 Storage Savings

$$\hat{A}_k = \sum_{i=1}^{k}\sigma_i\,\mathbf{u}_i\mathbf{v}_i^\top$$

For an \(m\times n\) image, rank-\(k\) stores \(k(m+n+1)\) numbers. Here \(4\times4\), so full requires 16 values; rank-1 needs only \(1(4+4+1)=9\); rank-2 needs \(18\) (but 99.3% fidelity).

💡 JPEG Connection

JPEG uses block DCT (a unitary transform related to SVD on 8×8 patches). Modern image codecs like WebP and AVIF additionally use low-rank tensor decompositions. SVD rank-truncation is the conceptually cleanest formulation of the core idea.

📐 Nuclear Norm

$$\|A\|_* = \sum_{i}\sigma_i(A)$$

The nuclear norm is the convex envelope of the rank function — minimising it promotes low-rank solutions. Candès & Recht (2009): exact recovery guaranteed with high probability when \(\Omega\) is sampled uniformly and the matrix is incoherent.

💡 Netflix Prize

The Netflix Prize (2006–09) popularized matrix completion. Users × movies with 99% missing ratings. The winning Bellkor solution used a combination of SVD-based matrix factorisation (ALS) and ensemble methods — beating Netflix's own Cinematch by 10.06% RMSE.

The nuclear-norm relaxation finds the lowest-rank matrix consistent with observations, recovering the four missing values (green). This is the mathematical foundation of collaborative filtering in recommender systems.

📐 Least-Squares Solution

$$\hat{x} = A^+ b = V\Sigma^+ U^\top b$$

For overdetermined \(Ax\approx b\): \(\hat{x}=A^+b\) is the minimum-norm least-squares solution — it minimises \(\|Ax-b\|_2\) and among all minimisers has smallest \(\|x\|_2\). For underdetermined: selects minimum-norm solution from the solution hyperplane.

🔑 Moore-Penrose Conditions

Four conditions uniquely define \(A^+\):
(1) \(AA^+A=A\)   (2) \(A^+AA^+=A^+\)
(3) \((AA^+)^\top=AA^+\)   (4) \((A^+A)^\top=A^+A\)
The SVD formula \(V\Sigma^+U^\top\) satisfies all four automatically.

Application 5/5
Pseudoinverse Computation
For \(A\in\mathbb{R}^{3\times 2}\) with SVD \(U\Sigma V^\top\), the pseudoinverse \(A^+=V\Sigma^+U^\top\) inverts \(\sigma_1=9.525\) and \(\sigma_2=0.514\) to get \(A^+\in\mathbb{R}^{2\times 3}\). The product \(A^+\) solves any overdetermined least-squares system \(Ax\approx b\) with minimum-norm solution. If \(A\) had a zero singular value, \(\Sigma^+\) would place 0 there — gracefully handling rank deficiency.

Key Takeaways & When to Use Each
▼
🔵 Dim Reduction

Use when: high-dimensional data, need interpretable axes. Equivalent to PCA for centred data. Prefer randomised SVD (\(k\ll\min(m,n)\)).

🟣 Image Compression

Use when: need rank-\(k\) matrix approximation with known \(m,n\). In practice, DCT/wavelets beat SVD for images (less correlation structure exploited), but SVD is theoretically optimal.

🟢 LSA / Text

Use when: synonym bridging matters, vocabulary mismatch is a problem. Modern NLP prefers transformer embeddings, but LSA remains a strong baseline and is explainable.

🟡 Matrix Completion

Use when: sparse observations of a low-rank structure (recommender systems, sensor networks). Check incoherence assumptions. ALS is scalable; nuclear-norm SDP is exact but expensive.

🔑 Pseudoinverse

Use always for least-squares and minimum-norm problems. \(\texttt{np.linalg.lstsq}\) uses SVD internally. Prefer over computing \((A^\top A)^{-1}A^\top\) directly — numerically unstable when \(A^\top A\) is near-singular.

From-Scratch Code
▼

All five applications in pure NumPy:

import numpy as np
# 1. Dimensionality Reduction (PCA via SVD)
X_centered = X - X.mean(axis=0) # centre columns
U, s, Vt = np.linalg.svd(X_centered, full_matrices=False)
Z = X_centered @ Vt[:k].T # project onto top-k directions
var_explained = s[:k]**2 / np.sum(s**2) # fraction of variance
# 2. Image Compression (rank-k reconstruction)
U, s, Vt = np.linalg.svd(A, full_matrices=False)
A_k = (U[:,:k] * s[:k]) @ Vt[:k,:] # rank-k approx
error = np.linalg.norm(A - A_k, 'fro') # = sqrt(sum of sq. remaining sv)
# 3. LSA — project query into latent topic space
U, s, Vt = np.linalg.svd(M, full_matrices=False) # M = term×doc
docs_k = np.diag(s[:k]) @ Vt[:k,:] # document coords in latent space
query_k = U[:,:k].T @ q # project query vector q
similarity = docs_k.T @ query_k # cosine similarity (if normalised)
# 4. Matrix Completion (ALS sketch)
def als_completion(A_obs, mask, rank, iters=100, lr=0.01):
m, n = A_obs.shape
L = np.random.randn(m, rank); R = np.random.randn(n, rank)
for _ in range(iters):
err = mask * (L @ R.T - A_obs)
L -= lr * (err @ R); R -= lr * (err.T @ L)
return L @ R.T # completed matrix
# 5. Pseudoinverse via SVD
U, s, Vt = np.linalg.svd(A, full_matrices=False)
s_inv = np.where(s > 1e-10, 1.0/s, 0.0) # invert non-zeros only
A_pinv = Vt.T @ np.diag(s_inv) @ U.T # A+ = V Σ+ Uᵀ
x_lstsq = A_pinv @ b # min-norm least-squares solution
