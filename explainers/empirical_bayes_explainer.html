Understanding Empirical Bayes
▼

What is it? Standard Bayesian inference requires you to choose a prior distribution before seeing any data. Empirical Bayes (EB) bends that rule: it estimates the prior from the data itself, then uses that estimated prior to do Bayesian inference. The prior is no longer a matter of belief — it is a parameter to be fitted.

Analogy: Imagine you're a teacher grading 30 students' exams. Each student's true ability is unknown. Standard Bayes says: "Before grading, I believe abilities are spread with mean 70 and std 10." Empirical Bayes says: "I'll look at all the raw scores first, estimate the class-wide distribution from them, then use that as a prior when scoring each individual." The class-level pattern is estimated empirically; individual estimates are then shrunk toward it.

💡 If you remember one thing

EB borrows strength across groups. By estimating a shared prior from all groups simultaneously, each group's estimate is shrunk toward the overall mean, yielding lower total MSE than treating each group independently — a provable improvement called the Stein phenomenon.

Key insight: Individually, each group's observed value \(y_i\) is an unbiased estimate of \(\theta_i\). But collectively, \(y_1, \ldots, y_p\) also tell us about the population distribution of the \(\theta_i\). EB uses that global signal to regularize local estimates — the statistical version of "wisdom of the crowd."

How It Works: The Hierarchical Model
▼

The Two-Level Hierarchy

EB operates on a two-level generative model. At the top level, true group means are drawn from a population prior. At the bottom level, each observation is a noisy measurement of its group mean:

$$\theta_i \sim \mathcal{N}(\mu_0,\, \tau^2) \qquad \text{(level 1: prior on means)}$$
$$y_i \mid \theta_i \sim \mathcal{N}(\theta_i,\, \sigma^2) \qquad \text{(level 2: observation model)}$$

In full Bayes you would fix \((\mu_0, \tau^2)\) beforehand. EB instead estimates them from the marginal likelihood — the distribution of \(y_i\) after integrating out \(\theta_i\):

$$y_i \sim \mathcal{N}(\mu_0,\, \tau^2 + \sigma^2)$$

Estimating the Hyperparameters

Given \(p\) independent groups, the marginal log-likelihood is:

$$\ell(\mu_0, \tau^2) = -\frac{p}{2}\log\bigl(2\pi(\tau^2+\sigma^2)\bigr) - \frac{1}{2(\tau^2+\sigma^2)}\sum_{i=1}^p(y_i - \mu_0)^2$$

Maximizing over \(\mu_0\) gives \(\hat{\mu}_0 = \bar{y}\). Substituting and maximizing over \(\tau^2\) gives the MoM/MLE estimate:

$$\hat{\tau}^2 = \max\!\left(0,\; \frac{1}{p-1}\sum_{i=1}^p(y_i - \bar{y})^2 - \sigma^2\right)$$

Posterior Mean (the Shrinkage Formula)

Plugging \((\hat{\mu}_0, \hat{\tau}^2)\) into the exact Bayesian posterior gives the EB estimate:

$$\hat{\theta}_i^{\text{EB}} = \hat{\mu}_0 + (1 - \hat{B})\,(y_i - \hat{\mu}_0), \qquad \hat{B} = \frac{\sigma^2}{\sigma^2 + \hat{\tau}^2}$$
🔑 Key Property: Shrinkage Factor

The shrinkage coefficient \(\hat{B} \in [0,1]\) measures how much we trust the prior vs. the data. When \(\hat{\tau}^2 \gg \sigma^2\) (groups are very different), \(\hat{B} \to 0\) — each \(y_i\) stands alone. When \(\hat{\tau}^2 \approx 0\) (groups are nearly identical), \(\hat{B} \to 1\) — everything collapses to \(\bar{y}\).

⚠️ Double-Dipping

EB uses the same data to estimate the prior AND to form posteriors — a philosophical departure from strict Bayesian coherence. The posterior intervals it produces are slightly too narrow because they ignore uncertainty in \((\hat{\mu}_0, \hat{\tau}^2)\). Parametric bootstrap or MCMC over hyperparameters fixes this.

Why Shrinkage Beats MLE: The Stein Phenomenon
▼

The Shocking Result

Charles Stein (1956) proved something statisticians found hard to believe: for \(p \geq 3\) parameters, the MLE \(\hat{\theta}^{\text{MLE}} = y\) is inadmissible — there always exists an estimator with uniformly lower MSE. James and Stein (1961) gave the explicit shrinkage estimator. For simultaneous estimation of \(p\) means under squared-error loss:

$$\mathbb{E}\bigl[\|\hat{\theta}^{\text{JS}} - \theta\|^2\bigr] < \mathbb{E}\bigl[\|\hat{\theta}^{\text{MLE}} - \theta\|^2\bigr] = p\sigma^2 \quad \text{for all } \theta \in \mathbb{R}^p, \; p \geq 3$$

Intuition: Borrowing Across Groups

When many groups share a common background distribution, the MLE "wastes" information by ignoring this structure. The shrinkage estimator effectively acts as if it knows some \(\theta_i\) will be near the center — and punishes outliers by pulling them back. Even if the \(\theta_i\) come from wildly different domains (baseball batting averages, temperature, GDP), the estimator still wins because it is admissible.

Connection to Empirical Bayes

The James-Stein estimator turns out to be exactly the EB posterior mean under a Normal-Normal model. Define \(S = \sum_i (y_i - \bar{y})^2\). Then \(\hat{\tau}^2_{\text{MoM}} = S/(p-1) - \sigma^2\), giving shrinkage factor \(\hat{B} = \sigma^2/(S/(p-1))\). The JS formula follows directly:

$$\hat{\theta}_i^{\text{JS}} = \bar{y} + \left(1 - \frac{(p-3)\sigma^2}{S}\right)(y_i - \bar{y})$$

This is the positive-part shrinkage version: if the factor becomes negative (S very small), we clamp at 0, collapsing all estimates to \(\bar{y}\).

∑ Risk Comparison (p=6, σ²=1, τ²=1.5)

MLE total risk: \(p\sigma^2 = 6.00\)
Oracle Bayes risk: \(p\sigma^2\tau^2/(\sigma^2+\tau^2) = 3.60\)
EB/JS risk: between 3.60 and 6.00, approaching oracle as \(p \to \infty\)

⚠️ Why p ≥ 3?

For \(p = 1\) or \(p = 2\), the MLE is admissible — Stein's paradox does not apply. The phenomenon arises because in \(p \geq 3\) dimensions, the expected distance from the MLE to the truth grows enough that shrinkage consistently helps. For \(p = 1\), shrinking \(y\) toward 0 hurts as often as it helps.

Key Takeaways & From-Scratch Code

When to Use Empirical Bayes

EB shines whenever you have multiple related groups (hospitals, schools, genes, sports teams, A/B experiment cells) and want per-group estimates that borrow strength from the population. It is the backbone of:

  • Benjamini–Hochberg multiple testing (estimates null proportion from data)
  • Efron's Large-Scale Inference (genomics, GWAS)
  • Random-effects models in meta-analysis
  • Stein-type shrinkage in ridge regression (MAP with Normal prior)
  • Hierarchical Bayesian models fitted by MCMC (EB is the Type-II MLE limit)

From-Scratch Python

import numpy as np
def empirical_bayes_shrinkage(y, sigma2):
"""
Empirical Bayes shrinkage estimator (Normal-Normal model).
y : observed group means, shape (p,)
sigma2 : known within-group variance (scalar)
Returns theta_eb, mu0_hat, tau2_hat, B_hat
"""
p = len(y)
# Step 1: estimate prior mean (grand mean)
mu0_hat = np.mean(y)
# Step 2: estimate prior variance via MoM/MLE
S = np.sum((y - mu0_hat)**2) # sum of squared deviations
tau2_hat = max(0.0, S / (p - 1) - sigma2)
# Step 3: shrinkage coefficient
B_hat = sigma2 / (sigma2 + tau2_hat) if tau2_hat > 0 else 1.0
# Step 4: posterior mean = shrink y_i toward mu0_hat
theta_eb = mu0_hat + (1 - B_hat) * (y - mu0_hat)
return theta_eb, mu0_hat, tau2_hat, B_hat
def james_stein(y, sigma2):
"""Positive-part James-Stein estimator (centered version)."""
p = len(y)
assert p >= 3, "JS inadmissibility requires p >= 3"
ybar = np.mean(y)
S = np.sum((y - ybar)**2)
shrink = max(0.0, 1.0 - (p - 3) * sigma2 / S)
return ybar + shrink * (y - ybar)
# Demo: 6 groups, sigma^2=1
y = np.array([2.6, 3.1, 4.8, 4.5, 1.4, 5.3])
eb, mu0, tau2, B = empirical_bayes_shrinkage(y, sigma2=1.0)
js = james_stein(y, sigma2=1.0)
print(f"mu0_hat={mu0:.2f}, tau2_hat={tau2:.3f}, B_hat={B:.3f}")
print("EB:", np.round(eb, 3))
print("JS:", np.round(js, 3))
💡 Summary

Empirical Bayes is the pragmatist's answer to the prior problem: estimate it from the data, then condition on it. The cost is slight understatement of posterior uncertainty; the gain is massive reduction in total MSE across groups — a free lunch that arises only when \(p \geq 3\) estimates are made simultaneously.
