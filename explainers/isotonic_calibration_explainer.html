Isotonic Regression Calibration

Transform raw classifier scores into calibrated probabilities using the Pool Adjacent Violators Algorithm (PAVA)
Intermediate Classical ML · Calibration O(n log n)
1
Understanding the Concept

Most classifiers output scores, not true probabilities. A random forest might output 0.87 for a sample, but does that really mean an 87% chance it belongs to the positive class? Usually not — the scores are not calibrated.

Isotonic Regression Calibration fixes this by learning a monotone non-decreasing staircase function that maps raw scores to calibrated probabilities. The key constraint: higher scores must always produce higher (or equal) calibrated probabilities.

Real-World Analogy

Imagine a weather app that shows you a "storm likelihood score" from 0–100. A score of 80 might historically correspond to only 60% actual storms. Isotonic calibration is like building a lookup table from historical data: "score 80 → real probability 0.62." The table must be monotone: score 90 can never map to a lower probability than score 80.

Key Insight

Isotonic calibration solves: find the best-fitting monotone non-decreasing step function through the (score, label) data points — using the Pool Adjacent Violators Algorithm (PAVA) in \(O(n)\) time once data is sorted. More flexible than Platt scaling (which is just logistic regression), but requires more data and can overfit on small datasets.

2
How PAVA Works Internally

PAVA runs in a single left-to-right pass over sorted (score, label) pairs. It maintains a stack of "blocks," each with a running mean.

Algorithm Steps

  1. Sort all training samples by their raw scores: \((s_1 \le s_2 \le \cdots \le s_n)\)
  2. Initialize each sample as its own block with mean = label \((0\text{ or }1)\)
  3. Scan left to right. Whenever the current block's mean is less than the previous block's mean (a violation of monotonicity), merge the two blocks and recompute the pooled mean
  4. Continue merging backwards until monotonicity is restored, or no previous block exists
  5. After the full pass, every sample in a block receives the block's pooled mean as its calibrated probability
Pooled Mean Formula

When merging blocks \(A\) and \(B\) (where block \(B\) violates \(\bar{p}_B \ge \bar{p}_A\)):

$$\bar{p}_{A \cup B} = \frac{n_A \cdot \bar{p}_A + n_B \cdot \bar{p}_B}{n_A + n_B}$$

This is the weighted average of labels in the merged block — exactly the empirical positive rate.

Design Decision

PAVA produces a step function, not a smooth curve. Steps can be very wide (many samples pooled) or very narrow (single sample). On small datasets, narrow steps can overfit: a single positive label gets probability 1.0. This is why isotonic calibration needs a held-out calibration set, not the training data.

3
The Mathematics

Isotonic regression solves a constrained least-squares problem. Given labels \(y_i \in \{0,1\}\) and sorted scores \(s_1 \le \cdots \le s_n\), find calibrated values \(p_i\) that minimise:

$$\hat{p} = \underset{p}{\operatorname{argmin}} \sum_{i=1}^{n} (y_i - p_i)^2 \quad \text{subject to } p_1 \le p_2 \le \cdots \le p_n$$

PAVA solves this exactly in \(O(n)\) after the \(O(n \log n)\) sort. The solution is unique and consists of block-constant segments where each block's value equals the weighted mean of \(y_i\) within it.

Why Least Squares = Calibration

For binary labels, the least-squares predictor for any block is the empirical mean: \(\hat{p} = \frac{1}{n_B}\sum_{i \in B} y_i\). This is the empirical positive rate — exactly what we want for a calibrated probability estimate.

Calibration Error Metric

After calibration, measure quality with Expected Calibration Error (ECE):

$$\text{ECE} = \sum_{b=1}^{B} \frac{|S_b|}{n} \left| \operatorname{acc}(S_b) - \operatorname{conf}(S_b) \right|$$

where \(S_b\) are score bins, \(\operatorname{acc}\) is actual positive rate, and \(\operatorname{conf}\) is mean predicted probability. Perfect calibration → ECE = 0.

Isotonic vs Platt Scaling

Platt scaling fits a logistic function \(\sigma(a \cdot s + b)\) — only 2 parameters, robust on small data, but can't model non-sigmoidal shapes. Isotonic regression fits any monotone step function — many effective parameters, captures complex shapes, but needs ≥ 1000 calibration samples to be reliable.

Key Takeaways & When to Use
  • Use isotonic calibration when you have ≥ 1000 calibration samples and suspect the score-to-probability relationship is non-sigmoidal (e.g., random forests, gradient boosting)
  • Use Platt scaling when data is limited (< 500 samples) or you want a smooth, interpretable calibration curve
  • Always calibrate on a held-out set — never on training data. Cross-validation calibration (cv="prefit") is standard
  • Isotonic calibration can overfit on small calibration sets — each unique score gets its own step, potentially giving probabilities of exactly 0 or 1
  • The resulting function is a step function: scores that never appeared in calibration data are interpolated by nearest-neighbour extrapolation in sklearn
  • Sklearn's CalibratedClassifierCV(method='isotonic') handles the full pipeline including cross-validation
Bottom Line

Isotonic regression calibration = PAVA on sorted (score, label) pairs. The result is the unique monotone non-decreasing step function that minimises squared error. More flexible than Platt, but needs more data. Always validate with a reliability diagram and ECE before deploying.
