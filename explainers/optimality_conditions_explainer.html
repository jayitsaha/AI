Optimality Conditions

First-order (∇f = 0) and second-order (Hessian classification) conditions for minima, maxima, and saddle points
Intermediate Optimization Theory Math & Stats Requires Calculus & Linear Algebra
1
Understanding Optimality Conditions
▼

What is this? When you want to find the "best" value of a function — the highest peak or deepest valley — you need to locate where the function stops rising or falling. These locations are called stationary points, and two types of mathematical conditions tell you (a) where to look and (b) what you found.

First-order condition (FOC): Set the gradient to zero, \(\nabla f(\mathbf{x}^*) = \mathbf{0}\). This is like saying "the slope is flat in every direction here." Stationary points are the only candidates for optima — if the slope is non-zero, you can always move to improve the objective. So FOC is necessary: every minimum, maximum, and saddle point satisfies it.

Second-order condition (SOC): Look at the Hessian matrix \(H = \nabla^2 f(\mathbf{x}^*)\) — the matrix of second derivatives. It tells you whether the function curves upward, downward, or in mixed directions near \(\mathbf{x}^*\). The sign pattern of its eigenvalues classifies the stationary point definitively.

Analogy: Finding where a hiking trail levels out (gradient = 0) identifies candidate "flat spots." But a flat spot could be a valley floor (minimum), a summit (maximum), or a mountain pass (saddle). The second-order curvature — how the terrain curves in every direction — tells you which one you're at.

💡 If you remember one thing

\(\nabla f = \mathbf{0}\) is necessary but not sufficient for a minimum. The Hessian is positive definite (\(H \succ 0\)) if and only if it is a local minimum. For a convex function, \(\nabla f = \mathbf{0}\) alone is sufficient for a global minimum.

2
First-Order Conditions: Finding Candidates
▼

The Gradient Encodes All Partial Derivatives

For \(f: \mathbb{R}^n \to \mathbb{R}\), the gradient is the vector of all partial derivatives:

$$\nabla f(\mathbf{x}) = \left[\frac{\partial f}{\partial x_1},\; \frac{\partial f}{\partial x_2},\; \ldots,\; \frac{\partial f}{\partial x_n}\right]^\top$$

The gradient points in the direction of steepest ascent. Setting it to zero means no direction improves the objective — the function is locally flat. This gives us the first-order necessary condition (FONC):

$$\nabla f(\mathbf{x}^*) = \mathbf{0}$$

Why Necessary but Not Sufficient?

Gradient zero identifies stationary points — which include local minima, local maxima, and saddle points. All three satisfy FOC. To distinguish them, we need second-order information. A classic example: \(f(x) = x^3\) has \(f'(0) = 0\) but \(x=0\) is neither a min nor a max.

⚠ Common Mistake

It is wrong to conclude "gradient zero implies minimum." The FOC is necessary for all stationary points. You need the SOC to tell the difference. Also: if the domain is bounded or the function is not differentiable, optima can occur at boundaries or kinks without \(\nabla f = \mathbf{0}\).

Numerical Example

Consider \(f(x, y) = x^2 - y^2\). Set the gradient to zero:

$$\nabla f = \begin{bmatrix} 2x \\ -2y \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix} \implies x^* = 0,\; y^* = 0$$

The unique stationary point is the origin. But is it a minimum? Moving along the \(x\)-axis: \(f(\epsilon, 0) = \epsilon^2 > 0 = f(0,0)\). Moving along the \(y\)-axis: \(f(0, \epsilon) = -\epsilon^2 < 0 = f(0,0)\). So the origin is neither a min nor a max — it is a saddle point. FOC alone could not tell us this.

3
Second-Order Conditions: The Hessian Classifier
▼

The Hessian Matrix

The Hessian \(H(\mathbf{x})\) is the \(n \times n\) matrix of all second partial derivatives, capturing curvature in every direction and every mixed direction:

$$H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}, \qquad H = \nabla^2 f$$

By Schwarz's theorem (for \(C^2\) functions), \(H\) is symmetric: \(H_{ij} = H_{ji}\). Being symmetric, all its eigenvalues are real, and their signs reveal the curvature in the corresponding eigenvector directions.

Classification by Eigenvalues

At a stationary point \(\mathbf{x}^*\) where \(\nabla f(\mathbf{x}^*) = \mathbf{0}\):

$$H \succ 0 \text{ (all } \lambda_i > 0\text{)} \implies \mathbf{x}^* \text{ is a strict local minimum}$$
$$H \prec 0 \text{ (all } \lambda_i < 0\text{)} \implies \mathbf{x}^* \text{ is a strict local maximum}$$
$$H \text{ indefinite (mixed } \lambda_i\text{)} \implies \mathbf{x}^* \text{ is a saddle point}$$
$$H \succeq 0 \text{ (all } \lambda_i \geq 0\text{, some } = 0\text{)} \implies \text{inconclusive (need higher-order test)}$$

Four Canonical Cases (2D)

FunctionHessianEigenvaluesClassification
\(x^2 + y^2\)diag(2, 2)+2, +2Local minimum (PD)
\(-x^2 - y^2\)diag(−2, −2)−2, −2Local maximum (ND)
\(x^2 - y^2\)diag(2, −2)+2, −2Saddle point (indefinite)
\(x^4 + y^4\)diag(0, 0) at origin0, 0Inconclusive (PSD)

Note: \(f(x,y) = x^4 + y^4\) does have a global minimum at the origin, but the Hessian is zero there — the SOC cannot confirm it. Higher-order analysis or a direct argument is needed.

🔑 Key Property: Sylvester's Criterion

For a \(2 \times 2\) symmetric matrix, positive definiteness is equivalent to: (1) \(H_{11} > 0\) and (2) \(\det(H) = H_{11}H_{22} - H_{12}^2 > 0\). Equivalently, all leading principal minors are positive. This avoids computing eigenvalues explicitly.

The SOC Is Sufficient, Not Necessary

If \(H \succ 0\), you have a local minimum — guaranteed. But a local minimum can exist even when \(H\) is only PSD (e.g., \(x^4\)). So SOC with \(H \succ 0\) is sufficient but not necessary for a minimum. The hierarchy: FOC necessary → SOC sufficient (strict) → for convex \(f\), FOC is both necessary and sufficient for a global min.

Convexity: When First-Order Is Enough
▼

Convexity Changes Everything

A function \(f\) is convex if its epigraph (the region above the graph) is a convex set, equivalently:

$$f(\lambda \mathbf{x} + (1-\lambda)\mathbf{y}) \leq \lambda f(\mathbf{x}) + (1-\lambda)f(\mathbf{y}), \quad \forall \lambda \in [0,1]$$

For twice-differentiable \(f\), convexity is equivalent to \(H(\mathbf{x}) \succeq 0\) (PSD) everywhere — not just at the critical point. When \(f\) is convex:

$$\nabla f(\mathbf{x}^*) = \mathbf{0} \iff \mathbf{x}^* \text{ is a global minimum}$$

This is the key theorem: for convex functions, the FOC is both necessary and sufficient for a global minimum. There are no local-but-not-global minima, and no saddle points (with positive curvature in some directions). Every stationary point is the global optimum.

Why This Matters for ML

Most classical ML objectives are convex: linear regression's squared loss, logistic regression's log-loss, SVMs with convex kernels. Gradient methods on convex objectives are guaranteed to find the global minimum — no matter where they start. In contrast, neural networks have non-convex losses with many saddle points and local minima, requiring more careful optimization strategies.

∑ Strict Convexity ⟹ Unique Global Minimum

If \(f\) is strictly convex (\(H(\mathbf{x}) \succ 0\) everywhere), then the global minimum is unique. This is why ridge regression and L2-regularized logistic regression have unique solutions, while L1-regularized problems (non-strictly convex) can have multiple optima.

PSD Hessian Everywhere ⟺ Convex Function

Connection to SOC: if we check PSD not just at one critical point but at all points, we get convexity. The SOC (\(H \succeq 0\) at a single point) is a local property; convexity (\(H \succeq 0\) everywhere) is global. For convex \(f\), the second-order condition at a stationary point is automatically satisfied and provides the global minimum guarantee.

Python: Check Optimality Conditions from Scratch

import numpy as np
from scipy.optimize import approx_fprime
def check_optimality(f, x_star, eps=1e-5):
"""Check FOC and SOC at candidate point x_star."""
n = len(x_star)
# --- First-Order Condition ---
grad = approx_fprime(x_star, f, eps) # numerical gradient
grad_norm = np.linalg.norm(grad)
foc_satisfied = grad_norm < 1e-6 # near-zero gradient
# --- Second-Order Condition: Hessian via finite differences ---
H = np.zeros((n, n))
for i in range(n):
ei = np.zeros(n); ei[i] = eps
H[i] = (approx_fprime(x_star + ei, f, eps) -
approx_fprime(x_star - ei, f, eps)) / (2 * eps)
eigenvalues = np.linalg.eigvalsh(H) # symmetric, so eigvalsh
# --- Classify ---
if not foc_satisfied:
return "Not a stationary point"
if np.all(eigenvalues > 1e-10):
return "Local minimum (H positive definite)"
elif np.all(eigenvalues < -1e-10):
return "Local maximum (H negative definite)"
elif np.any(eigenvalues > 1e-10) and np.any(eigenvalues < -1e-10):
return "Saddle point (H indefinite)"
else:
return "Inconclusive (H is PSD or NSD, need higher-order test)"
# Example: f(x,y) = x^2 - y^2 (saddle at origin)
f_saddle = lambda x: x[0]**2 - x[1]**2
print(check_optimality(f_saddle, np.array([0.0, 0.0])))
# -> "Saddle point (H indefinite)"
# Example: f(x,y) = x^2 + y^2 (minimum at origin)
f_bowl = lambda x: x[0]**2 + x[1]**2
print(check_optimality(f_bowl, np.array([0.0, 0.0])))
# -> "Local minimum (H positive definite)"
