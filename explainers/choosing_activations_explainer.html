Choosing Activations: Hidden Layers vs Output Layers

A task-driven decision guide — one family of activations for the inside of the network, a different one dictated by the loss for the output
Intermediate Deep Learning Architecture Design O(1) per unit
1
Understanding the Concept
▼

What is it? Every neuron computes a weighted sum z = Wx+b, then passes it through an activation function φ(z). That single choice, repeated for every hidden layer, controls how well gradients flow during training. A completely separate choice — the output activation — controls what shape the network's final answer takes.

Analogy: Hidden layers are assembly-line workstations that all use the same general-purpose tool (ReLU/GELU/SiLU) to keep the signal moving efficiently. The output layer is the final packaging station — it needs a tool matched exactly to the product: a ruler for continuous numbers (linear), a yes/no stamp for binary decisions (sigmoid), or a ticket dispenser that gives out exactly one winner (softmax).

💡 If you remember one thing

Hidden-layer activations are chosen for healthy gradients (non-saturating: ReLU, GELU, SiLU). Output-layer activations are chosen to match the loss function's probabilistic assumption — never out of habit.

2
How Hidden-Layer Activations Work Internally
▼

The Saturation Problem

Sigmoid \(\sigma(x)=\frac{1}{1+e^{-x}}\) and tanh squash inputs into a bounded range. Their derivative \(\sigma'(x)=\sigma(x)(1-\sigma(x))\) peaks at 0.25 and decays toward 0 as \(|x|\) grows. Stack many layers of this and the backward gradient is a product of many small numbers — it vanishes.

ReLU: Non-Saturating, But Fragile

\(\text{ReLU}(x)=\max(0,x)\) has gradient exactly 1 for \(x>0\) — no shrinkage. But for \(x \le 0\) the gradient is exactly 0: if a unit is pushed permanently negative, it never updates again (the "dying ReLU" problem).

GELU / SiLU: Smooth Self-Gating

\(\text{GELU}(x)=x\Phi(x)\) and \(\text{SiLU}(x)=x\sigma(x)\) multiply the input by a smooth 0-1 gate derived from itself. Neither has a hard zero region, so gradients never fully die, and the smooth curvature near 0 gives better-behaved optimization — why Transformers (BERT, GPT) default to GELU and LLaMA-style models default to SiLU.

🔑 Key Property

Non-saturating hidden activations keep the average gradient magnitude stable across depth — this is the single biggest lever for training networks that are dozens or hundreds of layers deep.

3
Why the Output Activation Is Math, Not Habit
▼

Every (output activation, loss) pair is the negative log-likelihood of a specific distribution assumption on the target \(y\):

$$\text{Linear} \leftrightarrow \text{MSE} \leftrightarrow y\mid x \sim \mathcal{N}(f(x),\sigma^2)$$
$$\text{Sigmoid} \leftrightarrow \text{Binary Cross-Entropy} \leftrightarrow y\mid x \sim \text{Bernoulli}(\sigma(z))$$
$$\text{Softmax} \leftrightarrow \text{Categorical Cross-Entropy} \leftrightarrow y\mid x \sim \text{Categorical}(\text{softmax}(z))$$

For softmax + cross-entropy, the gradient with respect to the logits collapses to a remarkably clean form:

$$\frac{\partial L}{\partial z} = p - y$$

which is exactly "predicted probability minus true label" — this is why frameworks fuse softmax into the loss rather than applying it as a separate layer.

⚠️ Common Pitfall

Applying softmax yourself and then feeding the result into a loss (e.g. PyTorch's CrossEntropyLoss) that already applies softmax internally silently breaks training — a "double softmax" bug.

Key Takeaways
▼

Hidden layers: default to GELU or SiLU for modern architectures (Transformers, large CNNs); ReLU remains a fine cheap baseline for smaller models. Avoid sigmoid/tanh as general-purpose hidden activations in deep stacks — reserve them for gating mechanisms (LSTM/GRU gates) where a bounded signal is the intended semantic.

Output layers: derive the activation from the task, not habit — linear for regression, sigmoid for binary/multi-label, softmax for exclusive multiclass. Let the framework's fused loss (BCEWithLogitsLoss, CrossEntropyLoss) apply it internally.

Related topics: weight initialization (He/Xavier), batch/layer normalization, vanishing/exploding gradients, gated linear units (SwiGLU) in modern LLM feed-forward blocks.
