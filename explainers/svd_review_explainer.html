1
Understanding SVD
▼

What is SVD? Every matrix \(A\) — whether it is a data table, an image, or a transformation — can be written as three simpler matrices multiplied together: \(A = U\Sigma V^\top\). Here \(U\) and \(V\) are rotation/reflection matrices (orthogonal), and \(\Sigma\) is a diagonal matrix of non-negative numbers called singular values. This is the Singular Value Decomposition.

Analogy. Imagine any function in the plane that stretches and rotates a rubber sheet. SVD says: no matter how complicated the deformation looks, it can always be broken into three steps — first rotate the sheet one way (that's \(V^\top\)), then stretch it along the axes by different amounts (that's \(\Sigma\)), then rotate it again (that's \(U\)). The stretching amounts are the singular values.

If you remember one thing

SVD decomposes any matrix into rotate → scale → rotate: \(A = U\Sigma V^\top\). The singular values \(\sigma_1 \geq \sigma_2 \geq \cdots \geq 0\) measure how much \(A\) stretches in each direction. They exist for every real matrix, unlike eigenvalues.

$$A = U \Sigma V^\top \qquad A \in \mathbb{R}^{m \times n}, \quad U \in \mathbb{R}^{m \times m}, \quad \Sigma \in \mathbb{R}^{m \times n}, \quad V \in \mathbb{R}^{n \times n}$$

The columns of \(U\) are the left singular vectors (output directions), the columns of \(V\) are the right singular vectors (input directions), and both sets are orthonormal: \(U^\top U = I\) and \(V^\top V = I\).

2
Full vs Economy (Thin) SVD
▼

For a non-square matrix \(A \in \mathbb{R}^{m \times n}\) with \(m > n\) (more rows than columns), the full SVD pads \(U\) to be square (\(m \times m\)) and \(\Sigma\) to match the shape of \(A\) (\(m \times n\)). The economy (thin) SVD discards those extras.

Sizes at a glance for \(A \in \mathbb{R}^{m \times n}\), \(r = \min(m, n)\)

FactorFull SVDEconomy SVDContent of extra part
\(U\)m × mm × rExtra \(m-r\) cols span left null space of \(A\)
\(\Sigma\)m × nr × rExtra rows are all zeros
\(V^\top\)n × nn × n— (same in both)
$$\underbrace{A}_{m \times n} = \underbrace{U}_{m \times m}\;\underbrace{\Sigma}_{m \times n}\;\underbrace{V^\top}_{n \times n} \quad \textbf{(full)} \qquad = \underbrace{\hat{U}}_{m \times r}\;\underbrace{\hat{\Sigma}}_{r \times r}\;\underbrace{V^\top}_{n \times n} \quad \textbf{(economy)}$$

Why do the extras contribute nothing? In the full SVD, \(\Sigma\) has exactly \(r\) nonzero diagonal entries. The columns of \(U\) beyond column \(r\) are always multiplied by zero rows in \(\Sigma\), so they cancel out. Economy SVD simply removes these columns — and the corresponding zero rows of \(\Sigma\) — to save memory and computation without changing the result.

Key Property

Both full and economy SVD give the same reconstruction \(A = U\Sigma V^\top\). The difference is purely in how many columns of \(U\) you keep. Economy SVD is what np.linalg.svd(A, full_matrices=False) returns and is the default in most ML libraries.

Common Confusion

A third variant — the truncated (rank-k) SVD — keeps only the top \(k\) singular triplets (\(k < r\)) and gives a best rank-k approximation. That is different from the economy SVD, which keeps all \(r\) triplets and reconstructs \(A\) exactly.

3
Geometric Picture — Rotate→Scale→Rotate
▼

The cleanest way to understand SVD is geometrically. Every matrix \(A\) maps the unit ball to an ellipsoid. SVD tells you exactly how — in three composable, interpretable steps.

Step-by-step for \(A = U\Sigma V^\top\) acting on a vector \(x\):

1. \(V^\top x\) — Rotate/reflect the input: Since \(V\) is orthogonal, \(V^\top\) is a pure rotation (or reflection). It maps the unit circle to itself but aligns the input coordinates with the natural directions \(A\) "cares about" — the right singular vectors \(v_1, v_2, \ldots\)

2. \(\Sigma(V^\top x)\) — Scale along coordinate axes: \(\Sigma = \operatorname{diag}(\sigma_1, \sigma_2, \ldots)\) stretches the rotated vector by \(\sigma_1\) in the first direction, \(\sigma_2\) in the second, etc. An input unit circle becomes an axis-aligned ellipse with semi-axes \(\sigma_1 \geq \sigma_2 \geq \cdots\).

3. \(U(\Sigma V^\top x)\) — Rotate/reflect the output: \(U\) is another orthogonal matrix that rotates the axis-aligned ellipse to its final orientation in the output space. The columns of \(U\) (left singular vectors) are the principal output directions.

$$\text{unit circle} \xrightarrow{V^\top} \text{rotated circle} \xrightarrow{\Sigma} \text{axis-aligned ellipse} \xrightarrow{U} \text{oriented ellipse}$$

Concrete example: \(A = \begin{bmatrix}3&1\\1&2\end{bmatrix}\)

NumPy gives singular values \(\sigma_1 = 3.618\), \(\sigma_2 = 1.382\) (the golden ratio pair — note \(\sigma_1 + \sigma_2 = 5 = \operatorname{tr}(A)\) and \(\sigma_1 \sigma_2 = 5 = \det(A)\)). The unit circle maps to an ellipse with semi-major axis 3.618 and semi-minor axis 1.382 after the three transformations.

Key Geometric Facts

(1) \(\sigma_i = \max_{\|x\|=1, x \perp v_1,\ldots,v_{i-1}} \|Ax\|\) — singular values are the stretch magnitudes in the principal directions.
(2) \(\|A\|_2 = \sigma_1\) — the spectral norm equals the largest singular value.
(3) \(\|A\|_F^2 = \sum_i \sigma_i^2\) — the squared Frobenius norm is the sum of squared singular values.
(4) \(\det(A) = \prod_i \sigma_i\) (for square \(A\)) — the volume scaling factor.

5
Key Takeaways
▼

Existence and uniqueness: SVD exists for every real (or complex) matrix. The singular values are unique; the singular vectors are unique when all \(\sigma_i\) are distinct (up to sign).

  • Full SVD: \(U\) is \(m\times m\) (square), \(\Sigma\) is \(m\times n\) (same shape as \(A\)). Keeps all directions including the null space.
  • Economy SVD: \(U\) is \(m\times r\), \(\Sigma\) is \(r\times r\) where \(r=\min(m,n)\). Drops null-space directions. Equivalent reconstruction.
  • Truncated SVD: keep top \(k < r\) triplets for best rank-\(k\) approximation (Eckart-Young theorem).

When to use economy SVD: Almost always in practice. It is cheaper (stores \(O(mr+r^2+nr)\) vs \(O(m^2+mn+n^2)\)) and gives the same result. Use full SVD only when you need to work with the null space of \(A\) explicitly.

Applications of SVD

PCA (via SVD of centered data matrix), low-rank compression (truncated SVD), pseudoinverse \(A^+ = V\Sigma^+U^\top\), least squares (stable solver), condition number \(\kappa(A) = \sigma_1/\sigma_r\), collaborative filtering, and more. SVD is the backbone of numerical linear algebra.

Code Trace
▼
import numpy as np
A = np.array([[3., 1.],
[1., 2.]])
# Full SVD: U is m×m, Vt is n×n
U, s, Vt = np.linalg.svd(A, full_matrices=True)
print(U.shape, s.shape, Vt.shape) # (2,2) (2,) (2,2)
# For a 3×2 matrix m>n:
B = np.array([[1.,2.],[3.,4.],[5.,6.]])
U_f, s_f, Vt_f = np.linalg.svd(B, full_matrices=True) # full
print(U_f.shape) # (3, 3) ← extra column!
U_e, s_e, Vt_e = np.linalg.svd(B, full_matrices=False) # economy
print(U_e.shape) # (3, 2) ← trimmed to rank
# Both reconstruct A exactly:
Sigma_f = np.zeros((3,2)); Sigma_f[:2,:2] = np.diag(s_f)
B_full = U_f @ Sigma_f @ Vt_f # full reconstruction
B_eco = U_e @ np.diag(s_e) @ Vt_e # economy reconstruction
print(np.allclose(B, B_full)) # True
print(np.allclose(B, B_eco)) # True
