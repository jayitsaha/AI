Understanding Tanh
▼

What is it? Tanh (hyperbolic tangent) is a squashing function that takes any real number and compresses it into the range \((-1, 1)\). It looks like an S-curve, just like the sigmoid, but it's centered on zero instead of on 0.5 — negative inputs give negative outputs, positive inputs give positive outputs.

Analogy: Imagine a thermostat dial that reports "how strongly" a room feels cold or hot on a scale from −1 (freezing) to +1 (scorching), with 0 meaning "perfectly neutral." Sigmoid instead reports on a 0-to-1 scale where "neutral" sits at 0.5 — there's no true zero, so even a "neutral" signal still looks like a positive number to whatever reads it next. Tanh's zero really means zero.

💡 If you remember one thing

Tanh is just a rescaled, shifted sigmoid: $$\tanh(x) = 2\sigma(2x) - 1$$ It keeps sigmoid's smooth S-shape and probability-like squashing, but because its output is zero-centered, gradients flowing into the next layer aren't all pushed in the same direction — which speeds up training. It still saturates for large \(|x|\), so it doesn't solve vanishing gradients.

How Tanh Works Internally
▼

Definition

Tanh is defined via the ratio of hyperbolic sine and cosine:

$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} = \frac{e^{2x}-1}{e^{2x}+1}$$

As \(x \to +\infty\), \(e^{-x} \to 0\) so \(\tanh(x) \to 1\). As \(x \to -\infty\), \(\tanh(x) \to -1\). At \(x=0\), \(\tanh(0) = 0\) exactly — the function passes through the origin.

Why Zero-Centering Matters (Design Decision)

Sigmoid outputs are strictly positive, \(\sigma(x) \in (0,1)\). During backpropagation, the gradient of a neuron's weights is proportional to the input activation that fed it. If every activation coming out of the previous layer is positive, then every component of the weight-gradient vector for the next layer has the same sign as the upstream error signal — the gradient can only push all weights up together or all down together in a zig-zag, which slows convergence. Tanh's outputs straddle zero, so downstream gradients point in mixed directions, letting optimization take more direct paths.

Numerical Trace

Compare tanh and sigmoid at a few inputs:

  • \(x = 0\): \(\tanh(0) = 0.0000\), \(\sigma(0) = 0.5000\)
  • \(x = 1\): \(\tanh(1) = 0.7616\), \(\sigma(1) = 0.7311\)
  • \(x = 2\): \(\tanh(2) = 0.9640\), \(\sigma(2) = 0.8808\)
  • \(x = -1\): \(\tanh(-1) = -0.7616\) (negative!), \(\sigma(-1) = 0.2689\) (still positive)
🔑 Key Property

Tanh is an odd function: \(\tanh(-x) = -\tanh(x)\). It is also just a scaled sigmoid: \(\tanh(x) = 2\sigma(2x) - 1\). Every property of sigmoid (monotonic, smooth, bounded, saturating) carries over — only the range and centering change.

Why It Works — The Math
▼

Derivative Derivation

Using the quotient rule on \(\tanh(x) = \frac{e^x-e^{-x}}{e^x+e^{-x}}\), and the identity \(\cosh^2(x) - \sinh^2(x) = 1\):

$$\frac{d}{dx}\tanh(x) = \frac{\cosh(x)\cosh(x) - \sinh(x)\sinh(x)}{\cosh^2(x)} = \frac{1}{\cosh^2(x)} = 1 - \tanh^2(x)$$

So the derivative is expressible entirely in terms of the function's own output — exactly like sigmoid's \(\sigma'(x) = \sigma(x)(1-\sigma(x))\). This is why both are cheap to backpropagate: cache the forward activation, reuse it for the backward pass.

Maximum Gradient and Saturation

Since \(\tanh(x) \in (-1,1)\), \(\tanh^2(x) \in [0,1)\), so \(1-\tanh^2(x) \in (0, 1]\). The derivative peaks at \(x=0\) with value exactly \(1\) (four times larger than sigmoid's peak of \(0.25\)), then decays toward \(0\) as \(|x|\) grows:

$$1-\tanh^2(0)=1.000 \quad 1-\tanh^2(1)=0.420 \quad 1-\tanh^2(2)=0.0707 \quad 1-\tanh^2(3)=0.0099$$

Vanishing Gradient in Deep Networks

By the chain rule, the gradient reaching layer 1 of an \(L\)-layer network is a product of per-layer local derivatives (times weights): \(\frac{\partial \mathcal{L}}{\partial h_1} = \frac{\partial \mathcal{L}}{\partial h_L}\prod_{l=2}^{L} W_l^\top \, \text{diag}(1-\tanh^2(z_l))\). If neurons operate in the saturated regime (\(|z_l| \gtrsim 2\), so each factor \(\approx 0.07\)), stacking just 5 layers multiplies the signal by roughly \(0.07^5 \approx 1.7\times10^{-6}\) — the gradient vanishes exponentially with depth.

⚠️ Common Misconception

"Tanh fixes vanishing gradients because it's zero-centered." False. Zero-centering only fixes the zig-zag convergence problem of sigmoid outputs; it does nothing about saturation. Tanh's derivative still caps at 1 and decays to 0 for large \(|x|\), so deep tanh networks suffer vanishing gradients just as sigmoid ones do — this is exactly why ReLU (derivative is a constant 1 for \(x>0\), no saturation on the positive side) displaced both in deep architectures.

Key Takeaways
▼

When to use tanh:

  • Hidden layers of RNNs/LSTMs/GRUs (still common as the internal state-update nonlinearity, e.g. LSTM's candidate cell state and GRU's candidate hidden state)
  • When outputs must be interpreted as signed/bounded values in \((-1,1)\), e.g. certain normalized regression targets or generator output layers (paired with rescaling)
  • Shallow networks where zero-centering meaningfully speeds up convergence and depth-related vanishing gradients aren't a concern

When NOT to use:

  • Deep feedforward/convolutional networks — ReLU/GELU/SiLU avoid saturation on the positive side and train faster
  • Very deep architectures without residual connections — gradients still vanish through many saturated tanh layers
  • Compute-constrained inference at massive scale — exponentials are pricier than ReLU's max(0,x)
💡 Hierarchy

Sigmoid (range \((0,1)\), not zero-centered) → Tanh (range \((-1,1)\), zero-centered, same saturation problem) → ReLU family (no saturation for \(x>0\), solves vanishing gradients in deep nets, but can "die" for \(x<0\)). Tanh is a strict improvement over sigmoid for hidden-layer optimization dynamics, but not a fix for depth.

import numpy as np
def tanh(x):
# Numerically stable: use np.tanh directly (handles overflow internally)
return np.tanh(x)
def tanh_grad(x):
# Derivative reuses the forward output — cheap backward pass
t = np.tanh(x)
return 1 - t**2
def sigmoid(x):
return 1 / (1 + np.exp(-x))
# Identity check: tanh(x) == 2*sigmoid(2x) - 1
x = np.array([-2, -1, 0, 1, 2])
assert np.allclose(tanh(x), 2*sigmoid(2*x) - 1)
# PyTorch production usage
import torch, torch.nn as nn
layer = nn.Sequential(nn.Linear(64, 64), nn.Tanh())
h = layer(torch.randn(8, 64))
# Gotcha: init weights with Xavier/Glorot (gain=5/3 for tanh) to
# keep activations away from the saturated tails at the start of training.
nn.init.xavier_uniform_(layer[0].weight, gain=nn.init.calculate_gain('tanh'))
