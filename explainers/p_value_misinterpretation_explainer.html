p-value: Definition & Misinterpretation

The most misunderstood number in science — what it actually means, and what it does not
Foundational Probability & Statistics Hypothesis Testing Must Know
1
What Is a p-value?
▼

What is it? After running an experiment, you need a number that tells you how surprised you should be by your results — assuming nothing is actually going on. The p-value is that number. It is the probability of seeing data as extreme as yours (or more extreme) if the null hypothesis were true.

Concrete analogy: Imagine a friend claims a coin is fair. You flip it 10 times and get 8 heads. You ask: "If the coin really were fair, how often would I see 8 or more heads?" The answer — roughly 5.5% — is the p-value. It's not the probability the coin is fair. It's the probability of this outcome or worse under the assumption the coin is fair.

The Exact Definition (ASA 2016)

A p-value is the probability, under the assumption that the null hypothesis \(H_0\) is true, of obtaining a test statistic at least as extreme as the one actually observed.

$$p = P(T \geq t_\text{obs} \mid H_0 \text{ true})$$

It is a conditional probability conditioning on \(H_0\). It is NOT a posterior probability of \(H_0\).

If You Remember One Thing

The p-value is the area in the tail(s) of the null distribution beyond your observed statistic. Small area = data rarely seen under \(H_0\) = evidence against \(H_0\). It does NOT tell you whether \(H_0\) is true, how big the effect is, or that the result is practically important.

2
Four Dangerous Misconceptions
▼

These four beliefs are widespread even among professional researchers. Each one is demonstrably wrong.

Fallacy 1 — Inverse Probability
"p = 0.04 means there's a 4% chance H₀ is true."
WRONG. p = P(data | H₀). The probability P(H₀ | data) requires Bayes' theorem and a prior — the p-value cannot give it to you.
Fallacy 2 — The Fluke Fallacy
"p = 0.04 means there's only a 4% chance this result occurred by chance."
WRONG. This conflates P(data | H₀) with P(fluke). The data already occurred. The p-value is a long-run frequency, not a statement about a single experiment.
Fallacy 3 — Effect Size Confusion
"p = 0.001 means the effect is large or important."
WRONG. With \(n = 10^6\), even a clinically trivial Δ = 0.001 mmHg blood pressure change produces p ≪ 0.001. p-values conflate effect size and sample size.
Fallacy 4 — Replication Fallacy
"p = 0.04 means future experiments will replicate with 96% probability."
WRONG. The replication rate depends on power (1 − β), effect size, and multiple sources of variability. A single p-value gives no information about replication probability.
Why These Fallacies Persist

The p-value is the wrong answer to the question we actually want answered. Researchers want P(H₀ | data), but the p-value gives P(data | H₀). Confusing these two — called the "prosecutor's fallacy" — is a cognitive error embedded in frequentist statistics training. The 2016 ASA Statement on p-values directly addresses all four fallacies above.

3
The Precise Mathematics
▼

Setup: Hypothesis Test

State the null \(H_0: \theta = \theta_0\) and alternative \(H_1: \theta \neq \theta_0\). Pick a test statistic \(T(X)\) whose distribution under \(H_0\) is known. For a z-test with known variance \(\sigma^2\) and sample size \(n\):

$$Z = \frac{\bar{X} - \mu_0}{\sigma / \sqrt{n}} \sim \mathcal{N}(0,1) \quad \text{under } H_0$$

p-value as Tail Area

For a two-sided test (most common), the p-value is:

$$p = P\bigl(|Z| \geq |z_\text{obs}| \mid H_0\bigr) = 2\,\Phi(-|z_\text{obs}|) = 2\bigl(1 - \Phi(|z_\text{obs}|)\bigr)$$

where \(\Phi\) is the standard normal CDF. For \(z_\text{obs} = 2.0\): \(p = 2(1 - 0.9772) = 2 \times 0.0228 = 0.0455\).

Decision Rule vs. p-value

The Neyman–Pearson framework compares \(p\) to a pre-specified significance level \(\alpha\) (usually 0.05). The test rejects \(H_0\) if and only if:

$$p \leq \alpha \iff |z_\text{obs}| \geq z_{\alpha/2}$$

For \(\alpha = 0.05\), the critical value is \(z_{0.025} = 1.960\). Since \(2.0 > 1.960\), we reject \(H_0\). But \(p = 0.0455\) is continuous evidence — the threshold 0.05 is arbitrary.

Type I & Type II Errors

\(\alpha = P(\text{reject } H_0 \mid H_0 \text{ true})\) — the false positive rate.
\(\beta = P(\text{fail to reject} H_0 \mid H_1 \text{ true})\) — the false negative rate.
Power \(= 1 - \beta = P(\text{reject} H_0 \mid H_1 \text{ true})\).
Setting \(\alpha = 0.05\) controls long-run Type I error but says nothing about Type II.

Critical Subtlety: P(data | H₀) vs P(H₀ | data)

By Bayes' theorem: \(P(H_0 \mid \text{data}) = \frac{P(\text{data} \mid H_0)\,P(H_0)}{P(\text{data})}\). With prior \(P(H_0) = 0.5\) and \(p = 0.05\), the minimum Bayes factor is \(-e \cdot p \cdot \ln p \approx 0.407\), giving a posterior \(P(H_0 \mid \text{data}) \geq 0.29\) — meaning up to 29% chance the null is still true even with a "significant" p = 0.05 (Sellke et al. 2001). A p-value of 0.05 is much weaker evidence than most researchers believe.

5
p-Hacking & The ASA Statement
▼

What is p-Hacking?

p-hacking (also called "data dredging" or "researcher degrees of freedom") is the practice of exploiting flexibility in data collection, analysis, or reporting to obtain a statistically significant result. Because the significance threshold is a binary gate at \(\alpha = 0.05\), researchers are incentivized to cross it.

Common p-hacking tactics:

  • Outcome switching: Measure 20 outcomes, report only the significant one
  • Optional stopping: Keep collecting data and test repeatedly until p < 0.05
  • Covariate mining: Add/remove covariates until the result is significant
  • Subsample selection: Run on different subgroups, report only the significant subgroup
  • Outlier exclusion: Try different outlier removal rules until significant
The Multiple Comparisons Problem

If you run \(k\) independent tests each at \(\alpha = 0.05\), the probability of at least one false positive is \(1 - (1-0.05)^k\). For \(k=20\) tests: \(1 - 0.95^{20} \approx 0.64\). Optional stopping is even worse — it inflates Type I error to 1 as you continuously test.

The ASA Statement on p-values (2016)

The American Statistical Association published a landmark statement (Wasserstein & Lazar, 2016, The American Statistician) with six principles:

  1. p-values indicate how incompatible data are with a specified statistical model.
  2. p-values do NOT measure the probability that H₀ is true, or the probability data were produced by random chance.
  3. Scientific conclusions should NOT be based only on whether p crosses a threshold.
  4. Proper inference requires full reporting and transparency.
  5. A p-value, or statistical significance, does NOT measure the size of an effect or the importance of a result.
  6. By itself, a p-value does NOT provide a good measure of evidence regarding a model or hypothesis.
The 2019 Call to "Abandon Statistical Significance"

A 2019 follow-up in Nature (Amrhein et al.) signed by 800+ scientists called for eliminating the use of "statistically significant" as a binary label. Instead: report exact p-values continuously, report effect sizes and confidence intervals, and use Bayesian methods or pre-registered equivalence tests when appropriate.

6
Key Takeaways & Code
▼

Correct and complete reporting includes:

  • The exact p-value (e.g., p = 0.046), not "p < 0.05"
  • Effect size (Cohen's d, odds ratio, partial η²)
  • 95% confidence interval for the effect
  • Sample size and statistical power
  • Whether the hypothesis was pre-registered
Practical Alternatives to p-values

Bayes factors: Ratio of evidence for H₁ vs H₀ — answers "how much more likely is the data under H₁ than H₀?"
Confidence intervals: The 95% CI for a parameter tells you effect size AND uncertainty.
Equivalence testing (TOST): Tests whether an effect is practically negligible (within a pre-specified bound \(\Delta\)).
False Discovery Rate: Controls the expected proportion of false positives among significant results (Benjamini–Hochberg 1995).

import numpy as np
from scipy import stats
# One-sample z-test (known sigma)
def z_test(data, mu0, sigma):
n = len(data)
z_obs = (np.mean(data) - mu0) / (sigma / np.sqrt(n))
p_two = 2 * (1 - stats.norm.cdf(abs(z_obs))) # tail area
ci_lo = np.mean(data) - 1.96 * sigma/np.sqrt(n)
ci_hi = np.mean(data) + 1.96 * sigma/np.sqrt(n)
return {'z': z_obs, 'p': p_two, 'ci': (ci_lo, ci_hi)}
# Example: drug lowers blood pressure by 2 mmHg, sigma=10, n=30
np.random.seed(42)
data = np.random.normal(loc=-2, scale=10, size=30) # true effect = -2 mmHg
result = z_test(data, mu0=0, sigma=10)
print(f"z = {result['z']:.3f}, p = {result['p']:.4f}") # p > 0.05 despite real effect!
print(f"95% CI: {result['ci'][0]:.2f} to {result['ci'][1]:.2f} mmHg")
# Small n = large p even when H0 is false — p conflates effect + sample size
# Bonferroni correction for k=20 tests
k, alpha = 20, 0.05
corrected_alpha = alpha / k # = 0.0025
print(f"Bonferroni threshold: {corrected_alpha}") # 0.0025
