Parameter Learning in Bayesian Networks

MLE · MAP (Dirichlet Prior) · EM for Missing Data — estimating CPT entries from data

Intermediate Probabilistic ML Bayesian Networks Part III — Classical ML
1
Understanding the Concept

What is this? A Bayesian Network encodes conditional independence relationships as a directed acyclic graph. Each node has a Conditional Probability Table (CPT) — a table that says "given my parents' values, how likely am I to take each of my values?" Parameter learning answers: How do we fill in those CPT numbers from data?

Analogy. Imagine estimating how often it rains given that the sprinkler is ON. You watch 100 days and count: 30 days "sprinkler=ON, rain=YES" and 70 days "sprinkler=ON, rain=NO". The MLE answer is simply those frequencies: \(P(\text{rain=Y} \mid \text{spr=ON}) = 30/100 = 0.30\). MAP says: "I slightly believe rain is rare, so I nudge that estimate downward." EM handles days where we forgot to record whether the sprinkler was on.

💡 If You Remember One Thing

MLE = raw counts / total counts (can be zero!). MAP = (raw counts + α−1) / (total + k(α−1)) — a Dirichlet prior α adds "pseudo-observations" to smooth away zeros.

Why it matters. Incorrectly estimated CPTs lead to wrong inference. MLE is simple but fragile with small data. MAP + Dirichlet prior trades a tiny bias for greatly reduced variance — the Bayesian sweet spot.

2
How It Works Internally

MLE — Maximum Likelihood Estimation

Given fully observed data \(\mathcal{D} = \{x^{(1)}, \ldots, x^{(N)}\}\), the log-likelihood of a Bayesian Network factors over nodes (due to the Markov property):

$$\ell(\theta \mid \mathcal{D}) = \sum_{i=1}^{n} \sum_{j=1}^{q_i} \sum_{k=1}^{r_i} N_{ijk} \log \theta_{ijk}$$

where \(N_{ijk}\) = number of samples where node \(X_i\) = value \(k\) and its parents \(\text{Pa}(X_i)\) = configuration \(j\); \(r_i\) = number of values of \(X_i\); \(q_i\) = number of parent configurations. The maximiser (subject to \(\sum_k \theta_{ijk} = 1\)) is:

$$\hat{\theta}_{ijk}^{\text{MLE}} = \frac{N_{ijk}}{N_{ij\cdot}} \quad \text{where } N_{ij\cdot} = \sum_{k'} N_{ijk'}$$

This is just the observed frequency. Simple, unbiased, but zero if a combination never appears in training data.

MAP — Maximum A Posteriori with Dirichlet Prior

The Dirichlet distribution \(\text{Dir}(\alpha_1, \ldots, \alpha_{r_i})\) is the conjugate prior over a categorical distribution. With a symmetric prior \(\alpha_k = \alpha\) for all \(k\):

$$\hat{\theta}_{ijk}^{\text{MAP}} = \frac{N_{ijk} + \alpha - 1}{N_{ij\cdot} + r_i(\alpha - 1)}$$

For \(\alpha = 1\): prior is uniform → MAP = MLE. For \(\alpha = 2\): each cell gets one pseudo-count (Laplace smoothing). For \(\alpha \to \infty\): the prior dominates and \(\hat{\theta} \to 1/r_i\) (uniform).

📐 Key Concept — Conjugacy

Dirichlet is conjugate to Categorical/Multinomial. This means: Dirichlet prior × Multinomial likelihood = Dirichlet posterior — closed form, no MCMC needed. The MAP estimate is just the mode of this posterior Dirichlet.

EM for Missing Data

When some variables are unobserved (latent or missing at random), we cannot directly count \(N_{ijk}\). EM alternates:

  • E-step: Using current parameters \(\theta^{(t)}\), compute expected counts \(\hat{N}_{ijk} = \sum_m P(X_i^{(m)}=k, \text{Pa}^{(m)}=j \mid \text{observed}^{(m)}, \theta^{(t)})\) via belief propagation on the BN.
  • M-step: Plug expected counts into MLE (or MAP) formula: \(\theta_{ijk}^{(t+1)} = \hat{N}_{ijk} / \hat{N}_{ij\cdot}\).

EM is guaranteed to increase the log-likelihood monotonically at each iteration and converges to a local maximum.

⚠️ EM Pitfall

EM finds local optima. With multiple latent variables the likelihood surface can be highly multimodal. Run EM from multiple random initialisations and pick the highest final likelihood.

3
The Math — Complete Derivation

MLE Derivation

Form the Lagrangian enforcing \(\sum_k \theta_{ijk} = 1\):

$$\mathcal{L} = \sum_k N_{ijk} \log \theta_{ijk} - \lambda\!\left(\sum_k \theta_{ijk} - 1\right)$$

Setting \(\partial \mathcal{L}/\partial \theta_{ijk} = N_{ijk}/\theta_{ijk} - \lambda = 0\) gives \(\theta_{ijk} = N_{ijk}/\lambda\). Summing over \(k\): \(\lambda = \sum_k N_{ijk} = N_{ij\cdot}\). Therefore:

$$\hat{\theta}_{ijk}^{\text{MLE}} = \frac{N_{ijk}}{N_{ij\cdot}}$$

MAP Derivation (Dirichlet–Multinomial)

The log-posterior is log-likelihood plus log-prior. The Dirichlet log-prior is \(\sum_k (\alpha_k - 1)\log \theta_{ijk}\) (plus a normalising constant). Adding to the log-likelihood:

$$\log p(\theta_{ij\cdot} \mid \mathcal{D}) \propto \sum_k (N_{ijk} + \alpha_k - 1)\log \theta_{ijk}$$

This is the log of a Dirichlet with parameters \(N_{ijk} + \alpha_k\). The mode of \(\text{Dir}(\alpha_1', \ldots, \alpha_{r}')\ \) (for \(\alpha_k' > 1\)) is \((\alpha_k'-1)/(\sum_k \alpha_k' - r)\):

$$\hat{\theta}_{ijk}^{\text{MAP}} = \frac{N_{ijk} + \alpha - 1}{N_{ij\cdot} + r_i(\alpha-1)} \qquad (\text{symmetric } \alpha)$$

EM Q-function

The EM algorithm maximises the expected complete-data log-likelihood \(Q(\theta \mid \theta^{(t)})\):

$$Q(\theta \mid \theta^{(t)}) = \mathbb{E}_{\mathbf{H} \mid \mathbf{O}, \theta^{(t)}}\!\left[\log p(\mathbf{O}, \mathbf{H} \mid \theta)\right] = \sum_{i,j,k} \hat{N}_{ijk} \log \theta_{ijk}$$

The M-step maximises this — identical in form to the fully observed MLE, but with expected counts \(\hat{N}_{ijk}\) in place of actual counts. The E-step computes these expectations using the current network parameters and the junction tree (belief propagation) algorithm.

∑ Key Formulas at a Glance

MLE: \(\hat{\theta}_{ijk} = N_{ijk}/N_{ij\cdot}\)
MAP: \(\hat{\theta}_{ijk} = (N_{ijk}+\alpha-1)/(N_{ij\cdot}+r_i(\alpha-1))\)
EM E-step: \(\hat{N}_{ijk} = \sum_m P(X_i^{(m)}\!=\!k,\text{Pa}^{(m)}\!=\!j\mid \mathbf{o}^{(m)}, \theta^{(t)})\)
EM M-step: \(\theta_{ijk}^{(t+1)} = \hat{N}_{ijk}/\hat{N}_{ij\cdot}\)

🎯 Decision Guide

Large data, fully observed → MLE. Small data or sparse cells → MAP with α=2 (Laplace). Unknown latents/missing data → EM. Need uncertainty quantification → Bayesian (sample from Dirichlet posterior).

6
Key Takeaways
  • CPT parameters \(\theta_{ijk} = P(X_i = k \mid \text{Pa}(X_i) = j)\) are learned independently per parent configuration — the log-likelihood decomposes.
  • MLE is just frequency counting. MAP adds Dirichlet pseudocounts: \(\alpha-1\) extra observations per cell. \(\alpha=2\) = Laplace smoothing.
  • The Dirichlet prior is conjugate — posterior is also Dirichlet, making MAP a closed-form mode calculation.
  • EM handles missing/latent variables: soft E-step via belief propagation, then MLE-style M-step on fractional counts.
  • EM is sensitive to initialisation and may find local optima — run multiple times.
  • In BNs with many parent configurations, small datasets will have many sparse or empty cells — MAP/Laplace smoothing is almost always preferable to pure MLE.
