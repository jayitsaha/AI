Understanding Cholesky Decomposition
▼

What is it? A positive-definite matrix \(A\) (think: a symmetric matrix with all-positive "spread") can be factored as \(A = LL^\top\), where \(L\) is a lower-triangular matrix with positive diagonal entries. This is the matrix equivalent of writing \(x = (\sqrt{x})^2\) for a positive number.

Analogy: Imagine you have a blob of correlated measurements — think of a 3D scatter plot of data points that tilts and stretches in various directions. The covariance matrix \(\Sigma\) describes this blob's shape. Cholesky finds the "triangular square root" \(L\) such that applying \(L\) transforms a perfectly round (uncorrelated) blob into the correlated one. This is exactly how you draw samples from a multivariate Gaussian: generate uncorrelated noise, then multiply by \(L\).

💡 If you remember one thing

Cholesky computes \(A = LL^\top\) where \(L\) is lower-triangular. It exists if and only if \(A\) is symmetric positive-definite (SPD). The diagonal entries require a square root — if any would-be pivot is \(\le 0\), the matrix is not SPD and the algorithm fails. In ML, this failure is your cheapest SPD detector.

Key Applications

  • Sampling correlated Gaussians: if \(z \sim \mathcal{N}(0, I)\), then \(Lz \sim \mathcal{N}(0, \Sigma)\) where \(\Sigma = LL^\top\)
  • GLS / whitening: pre-multiply data by \(L^{-1}\) to decorrelate errors (the Mahalanobis transform)
  • Solving linear systems: solve \(Ax = b\) via two triangular solves (\(O(n^2)\) each) after one \(O(n^3/3)\) factorization
  • Gaussian Processes: the core numerical step in GP training and prediction
  • Kalman filters, covariance propagation in robotics and state estimation

The Cholesky–Banachiewicz Algorithm
▼

The Cholesky–Banachiewicz recursion fills \(L\) column by column (equivalently row by row for the outer-product version). For each position \((i, j)\) with \(j \le i\):

$$L_{jj} = \sqrt{A_{jj} - \sum_{k=0}^{j-1} L_{jk}^2} \quad \text{(diagonal — requires sqrt)}$$ $$L_{ij} = \frac{1}{L_{jj}}\!\left(A_{ij} - \sum_{k=0}^{j-1} L_{ik} L_{jk}\right) \quad \text{(off-diagonal, } i > j\text{)}$$

All entries above the diagonal in \(L\) are zero. The upper-triangle of \(A\) is never read — only the lower triangle and diagonal are used.

Failure condition — not SPD

If the radicand \(A_{jj} - \sum_k L_{jk}^2\) is \(\le 0\) for any pivot \(j\), the matrix is not positive-definite and the algorithm raises an error. This is the cheapest PD test: attempt Cholesky, catch the failure.

🔑 Existence & Uniqueness

\(A = LL^\top\) exists with \(L\) lower-triangular and \(L_{ii} > 0\) if and only if \(A\) is symmetric positive-definite. Moreover, the factorization is unique.

Numerical worked example — 3×3 SPD matrix

Let \(A = \begin{bmatrix}4&2&2\\2&5&3\\2&3&6\end{bmatrix}\). Computing \(L\) step by step:

  • \(L_{00} = \sqrt{4} = 2\)
  • \(L_{10} = \tfrac{1}{2}(2) = 1\) ; \(\quad L_{11} = \sqrt{5 - 1^2} = \sqrt{4} = 2\)
  • \(L_{20} = \tfrac{1}{2}(2) = 1\) ; \(\quad L_{21} = \tfrac{1}{2}(3 - 1\cdot1) = 1\) ; \(\quad L_{22} = \sqrt{6-1-1} = \sqrt{4} = 2\)

Result: \(L = \begin{bmatrix}2&0&0\\1&2&0\\1&1&2\end{bmatrix}\) and you can verify \(LL^\top = A\).

Complexity

Cholesky requires \(\approx n^3/3\) flops — exactly half the cost of LU decomposition (\(2n^3/3\)), exploiting symmetry. It is also numerically stable without pivoting for SPD matrices.

3
The Mathematics Behind It
▼

Positive-Definite Matrices

A symmetric matrix \(A \in \mathbb{R}^{n \times n}\) is positive-definite (PD) if \(x^\top A x > 0\) for all \(x \neq 0\). Equivalently, all eigenvalues are strictly positive. A matrix that is only \(\ge 0\) is positive semi-definite (PSD).

$$x^\top A x > 0 \quad \forall x \neq 0 \iff A \text{ is positive-definite}$$

Proof Sketch of Cholesky Existence

By induction on \(n\). Partition \(A = \begin{bmatrix}a_{11} & b^\top \\ b & C\end{bmatrix}\) where \(a_{11} > 0\) (since \(A\) is PD). Set \(\ell_{11} = \sqrt{a_{11}}\), \(\ell = b/\ell_{11}\). Then:

$$A = \begin{bmatrix}\ell_{11} & 0 \\ \ell & I\end{bmatrix}\begin{bmatrix}\ell_{11} & \ell^\top \\ 0 & C - \ell\ell^\top\end{bmatrix}$$

The Schur complement \(S = C - \ell\ell^\top = C - bb^\top/a_{11}\) is PD (inherits PD from \(A\)). Apply the argument recursively to \(S\). The resulting \(L\) has \(\ell_{11} > 0\) and the rest built inductively.

Whitening and Mahalanobis Distance

If \(\Sigma\) is a covariance matrix with Cholesky factor \(L\), then \(L^{-1} x\) transforms data into an uncorrelated, unit-variance space. The Mahalanobis distance becomes ordinary Euclidean distance after this transformation:

$$d_M(x) = \sqrt{x^\top \Sigma^{-1} x} = \|L^{-1}x\|_2$$

Sampling from \(\mathcal{N}(\mu, \Sigma)\)

To draw \(x \sim \mathcal{N}(\mu, \Sigma)\): compute \(L\) (Cholesky of \(\Sigma\)), draw \(z \sim \mathcal{N}(0, I)\), then set \(x = \mu + Lz\). This works because \(\operatorname{Cov}(Lz) = L I L^\top = \Sigma\).

⚠️ Common Misconception

"Near-SPD" matrices (from rounding or accumulated floating-point errors) can fail Cholesky even though they're theoretically PD. Fix: add a small multiple of the identity, \(A + \epsilon I\), to ensure strict positivity — this is called jitter or nugget and is standard in Gaussian Processes.

Code: From Scratch & Production
▼

From Scratch (NumPy)

import numpy as np
def cholesky(A):
"""Cholesky–Banachiewicz decomposition. Returns L s.t. A = L @ L.T
Raises ValueError if A is not positive-definite."""
n = A.shape[0]
L = np.zeros_like(A, dtype=float)
for j in range(n): # column j
s = A[j, j] - np.dot(L[j, :j], L[j, :j]) # pivot
if s <= 0: # not PD check
raise ValueError(f"Matrix not PD: pivot[{j}] = {s:.6f}")
L[j, j] = np.sqrt(s) # diagonal
for i in range(j + 1, n): # off-diagonal
L[i, j] = (A[i, j] - np.dot(L[i, :j], L[j, :j])) / L[j, j]
return L
# Verify on our 3x3 example
A = np.array([[4,2,2],[2,5,3],[2,3,6]], dtype=float)
L = cholesky(A)
print(L) # [[2,0,0],[1,2,0],[1,1,2]]
print(np.allclose(L @ L.T, A)) # True

Production Usage

import numpy as np
from scipy.linalg import cholesky, cho_solve, cho_factor
Sigma = np.array([[4,2,2],[2,5,3],[2,3,6]], dtype=float)
# --- 1. Factorize ---
L = np.linalg.cholesky(Sigma) # returns lower-triangular L
# scipy version: upper=False → lower L (same convention)
# --- 2. Sample correlated Gaussians ---
mu = np.array([1.0, 2.0, 3.0])
z = np.random.randn(3, 10000) # 10k iid samples
x = mu[:, None] + L @ z # x ~ N(mu, Sigma)
print(np.cov(x)) # ≈ Sigma
# --- 3. Solve Ax = b via Cholesky (twice as fast as LU) ---
c, low = cho_factor(Sigma) # factorize once
b = np.array([1.0, 2.0, 3.0])
x = cho_solve((c, low), b) # solve Sigma @ x = b
# --- 4. PD check / jitter ---
def ensure_pd(M, jitter=1e-6):
try:
return np.linalg.cholesky(M), True
except np.linalg.LinAlgError:
return np.linalg.cholesky(M + jitter * np.eye(len(M))), False
⚠️ Gotcha: Upper vs Lower convention

NumPy's np.linalg.cholesky returns the lower triangular factor \(L\) (so \(A = LL^\top\)). SciPy's scipy.linalg.cholesky defaults to upper triangular \(U\) (so \(A = U^\top U\)). Always check the convention before using the factor!

Key Takeaways & Comparison to Other Decompositions
▼
DecompositionRequiresCostUse when
Cholesky \(A=LL^\top\)Symmetric PD\(n^3/3\)Covariance matrices, GPs, GLS
LU \(A=PLU\)Square (any)\(2n^3/3\)General linear systems
QR \(A=QR\)Any \(m\times n\)\(2mn^2\)Least squares, rank-deficient
Eigen \(A=Q\Lambda Q^\top\)Symmetric\(O(n^3)\)PCA, eigenanalysis
SVD \(A=U\Sigma V^\top\)Any\(O(mn^2)\)Rank-k approx, pseudoinverse
🎯 Decision Guide

Use Cholesky whenever \(A\) is known to be SPD (covariance/kernel matrix) — it's twice as fast as LU, numerically stable, and gives you the sampling factor \(L\) "for free." Use LU for general square systems. Use QR for least squares or rank-deficient problems. Use SVD when you need a low-rank approximation or the pseudoinverse.
