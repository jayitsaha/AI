Vector norms, unit ball geometry, and their ML implications (sparsity, regularization, robustness)

1
Understanding Norms
▼

What is it? A norm is a function that measures the "size" or "length" of a vector. Different norms measure size differently — some count nonzero entries, some sum absolute values, some use Pythagorean distance, some look only at the largest entry. Each choice leads to different geometry and different behaviour in machine learning.

Analogy: Imagine measuring how "far" a city is. You could count how many streets you cross (L0-like), walk the Manhattan grid adding up blocks (L1), fly in a straight line (L2), or care only about the single longest road you must travel (L\(\infty\)). Same city, four different distances.

💡 If you remember one thing

The shape of the unit ball \(\{\mathbf{x} : \|\mathbf{x}\|_p \leq 1\}\) determines everything: L1's diamond has sharp corners on the axes (inducing sparsity), L2's circle is smooth (inducing shrinkage), L\(\infty\)'s square constrains the worst coordinate, and L0 is the coordinate axes themselves (non-convex, NP-hard to optimize).

All norms for \(p \geq 1\) satisfy three axioms: (1) \(\|\mathbf{x}\|=0 \Leftrightarrow \mathbf{x}=\mathbf{0}\) (definiteness); (2) \(\|\alpha\mathbf{x}\|=|\alpha|\|\mathbf{x}\|\) (positive homogeneity); (3) \(\|\mathbf{x}+\mathbf{y}\|\leq\|\mathbf{x}\|+\|\mathbf{y}\|\) (triangle inequality). L0 violates axiom (2) and is a pseudonorm.

2
The Four Norms in Detail
▼

L0 — Counting Nonzeros

$$\|\mathbf{x}\|_0 = \sum_{i=1}^n \mathbf{1}[x_i \neq 0] = |\{i : x_i \neq 0\}|$$

L0 counts how many entries are nonzero. For \(\mathbf{x}=[3, 0, -2, 0]\): \(\|\mathbf{x}\|_0 = 2\). It is not a true norm: \(\|2\mathbf{x}\|_0 = \|\mathbf{x}\|_0 = 2\) (violates homogeneity). Minimizing L0 gives the sparsest solution to a system, but the problem is NP-hard in general. The L1 norm is its tractable convex relaxation.

L1 — Sum of Absolute Values (Manhattan)

$$\|\mathbf{x}\|_1 = \sum_{i=1}^n |x_i|$$

For \(\mathbf{x}=[3, 0, -2, 0]\): \(\|\mathbf{x}\|_1 = 5\). Also called the Manhattan, taxicab, or city-block norm. Its unit ball is a cross-polytope (diamond in 2D). This is the tightest convex relaxation of L0, which is why LASSO uses it for sparse regression.

🔑 L1 vs L0

L1 is the convex hull of the L0 unit ball. Minimizing \(\|\mathbf{w}\|_1\) subject to \(A\mathbf{w}=\mathbf{b}\) under Restricted Isometry Property (RIP) conditions recovers the same sparse solution as minimizing \(\|\mathbf{w}\|_0\) — this is the Basis Pursuit theorem (Candès & Tao, 2005).

L2 — Euclidean Distance (Pythagorean)

$$\|\mathbf{x}\|_2 = \sqrt{\sum_{i=1}^n x_i^2} = \sqrt{\mathbf{x}^\top \mathbf{x}}$$

For \(\mathbf{x}=[3, 0, -2, 0]\): \(\|\mathbf{x}\|_2 = \sqrt{9+4} \approx 3.606\). The L2 norm is the standard Euclidean distance, induced by the inner product \(\langle\mathbf{x},\mathbf{y}\rangle = \mathbf{x}^\top\mathbf{y}\). Its unit ball is a sphere. Ridge regression penalizes \(\|\mathbf{w}\|_2^2\) (squared L2), which gives the closed-form solution \(\hat{\mathbf{w}} = (X^\top X + \lambda I)^{-1}X^\top\mathbf{y}\).

L\(\infty\) — Maximum Absolute Value (Chebyshev)

$$\|\mathbf{x}\|_\infty = \max_{i} |x_i|$$

For \(\mathbf{x}=[3, 0, -2, 0]\): \(\|\mathbf{x}\|_\infty = 3\). The L\(\infty\) norm picks the largest absolute entry. Its unit ball is a hypercube \([-1,1]^n\). Used in adversarial robustness to bound the maximum per-feature perturbation, and in max-norm regularization for embedding tables.

The general \(\ell_p\) norm unifies L1, L2, L\(\infty\): \(\|\mathbf{x}\|_p = \left(\sum_i |x_i|^p\right)^{1/p}\) for \(p \geq 1\). As \(p\to\infty\), \(\|\mathbf{x}\|_p \to \max_i|x_i| = \|\mathbf{x}\|_\infty\). As \(p\to 1\), we get L1. At \(p=2\), Euclidean.

3
Why L1 Induces Sparsity (and L2 Doesn't)
▼

The sparsity-inducing property of L1 is geometric. Consider regularized regression: minimize \(\mathcal{L}(\mathbf{w})\) subject to \(\|\mathbf{w}\|_p \leq t\). The loss \(\mathcal{L}\) has elliptical level-set contours centered at the unconstrained optimum \(\hat{\mathbf{w}}\). The constraint region is the Lp ball. The optimal constrained solution is where a loss contour first touches the ball as we expand outward from \(\hat{\mathbf{w}}\).

L1: Corners Guarantee Sparsity

The L1 ball in 2D is a diamond with 4 corners at \((\pm 1, 0)\) and \((0, \pm 1)\). A linear objective \(\mathbf{c}^\top\mathbf{w}\) is maximized on the L1 ball at a vertex: whichever \(e_i\) such that \(c_i = \max_j |c_j|\). For any gradient \(\mathbf{c}\) that is not axis-aligned (i.e., no two components equal in absolute value — a measure-zero event), the optimal point is exactly a corner — one coordinate is 1, all others are 0.

In \(n\) dimensions, the L1 ball \(\|\mathbf{w}\|_1 \leq t\) has \(2n\) vertices, each with exactly one nonzero coordinate. The loss contour generically hits one of these, giving a solution with at most 1 nonzero entry per active constraint. With multiple constraints or a loss that is strictly convex (not linear), a solution can have more nonzeros, but still far fewer than \(n\).

$$\hat{\mathbf{w}}_{LASSO} = \underset{\mathbf{w}}{\operatorname{argmin}}\; \|\mathbf{y} - X\mathbf{w}\|_2^2 \quad \text{s.t.} \quad \|\mathbf{w}\|_1 \leq t$$

Lagrangian form (equivalent): \(\hat{\mathbf{w}}_{LASSO} = \underset{\mathbf{w}}{\operatorname{argmin}}\; \|\mathbf{y} - X\mathbf{w}\|_2^2 + \lambda\|\mathbf{w}\|_1\). The soft-thresholding solution for orthonormal \(X\) is: \(\hat{w}_j = \operatorname{sign}(\hat{w}_j^{OLS})(|\hat{w}_j^{OLS}| - \lambda/2)_+\), which sets small coefficients to exactly zero.

L2: Smooth Ball, No Exact Zeros

The L2 ball is smooth — no corners, no edges. The gradient of the loss at any non-origin constrained optimum points radially toward the center, balanced against the norm constraint's gradient. For any loss gradient \(\mathbf{c} \neq \mathbf{0}\), the constrained optimum on the L2 ball is \(\mathbf{c}/\|\mathbf{c}\|_2\), which has all coordinates nonzero unless \(\mathbf{c}\) itself is axis-aligned. Ridge regression shrinks all weights proportionally but never to exactly zero.

$$\hat{\mathbf{w}}_{Ridge} = (X^\top X + \lambda I)^{-1} X^\top \mathbf{y} = \frac{\hat{w}_j^{OLS}}{1 + \lambda / \|\mathbf{x}_j\|^2}$$

L0: NP-Hard but Sparsest

Minimizing \(\|\mathbf{w}\|_0\) subject to \(X\mathbf{w} = \mathbf{y}\) is equivalent to finding the sparsest solution to a linear system — NP-hard in general (reducible from subset sum). Convex relaxation to L1 is exact under the Restricted Isometry Property (RIP): if the column submatrices of \(X\) are well-conditioned (specifically \(\delta_{2k} < \sqrt{2}-1\)), the L1 minimizer equals the L0 minimizer whenever the true solution has at most \(k\) nonzeros.

⚠ Common Misconception

L1 does NOT always give sparser solutions than L2 for any specific problem instance — it depends on the geometry of \(X\) and the true signal. The sparsity guarantee is probabilistic or holds under RIP conditions. In correlated designs (e.g., collinear features), LASSO arbitrarily picks one correlated feature; Elastic Net (L1+L2) handles this better.

L\(\infty\): Bounding the Worst Case

L\(\infty\) regularization or constraints appear when you want no single weight to be too large. Its unit ball is a hypercube \([-1,1]^n\). An objective tangent to this ball can touch any face, not just corners — so L\(\infty\) constraints do not induce sparsity. Instead, they bound the maximum single weight magnitude, useful for max-norm regularization in recommendation systems.

ML Applications: LASSO, Ridge, Max-Norm, Adversarial
▼

LASSO Regression (L1)

LASSO (Least Absolute Shrinkage and Selection Operator) adds an L1 penalty: \(\mathcal{L} = \|\mathbf{y}-X\mathbf{w}\|_2^2 + \lambda\|\mathbf{w}\|_1\). The subgradient at zero allows LASSO to produce exact zeros. Coordinate descent solves it efficiently via soft-thresholding: \(\hat{w}_j \leftarrow \operatorname{sign}(r_j)(|r_j|-\lambda)_+\) where \(r_j\) is the partial residual. Used in gene selection, text classification, signal recovery.

Ridge Regression (L2)

Ridge adds an L2\({}^2\) penalty: \(\mathcal{L} = \|\mathbf{y}-X\mathbf{w}\|_2^2 + \lambda\|\mathbf{w}\|_2^2\). The closed-form solution \(\hat{\mathbf{w}} = (X^\top X + \lambda I)^{-1}X^\top\mathbf{y}\) always exists (regularizes ill-posed problems). Ridge is the MAP estimator under a Gaussian prior \(\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \sigma_w^2 I)\). It handles correlated features better than LASSO.

Elastic Net (L1 + L2)

$$\hat{\mathbf{w}} = \underset{\mathbf{w}}{\operatorname{argmin}}\; \|\mathbf{y}-X\mathbf{w}\|_2^2 + \lambda_1\|\mathbf{w}\|_1 + \lambda_2\|\mathbf{w}\|_2^2$$

Combines sparsity (L1) with grouping of correlated features (L2). When features are correlated, LASSO picks one arbitrarily; Elastic Net selects the group. Widely used in genomics, finance, and whenever feature groups are correlated.

Max-Norm Regularization (L\(\infty\))

In collaborative filtering and language model embeddings, max-norm regularization constrains \(\|\mathbf{w}\|_2 \leq c\) per row/column of the weight matrix — effectively bounding the L2 norm of each embedding. A harder variant constrains the spectral norm (largest singular value, also an L\(\infty\) analog for matrices). Used in Dropout-based generalization bounds and word2vec training stability.

Adversarial Robustness (L\(\infty\))

An adversarial perturbation \(\boldsymbol{\delta}\) with \(\|\boldsymbol{\delta}\|_\infty \leq \varepsilon\) allows each input pixel to change by at most \(\varepsilon\). FGSM (Fast Gradient Sign Method) produces L\(\infty\)-bounded attacks: \(\boldsymbol{\delta} = \varepsilon \cdot \operatorname{sign}(\nabla_\mathbf{x}\mathcal{L})\). PGD (Projected Gradient Descent) attacks iterate in the L\(\infty\) ball. L1-bounded attacks are sparser (few pixels changed a lot); L2-bounded attacks have bounded total distortion.

Weight Decay in Neural Networks

Most neural network optimizers implement weight decay as L2 penalty on all parameters: \(\mathcal{L}_{total} = \mathcal{L}_{task} + \frac{\lambda}{2}\|\theta\|_2^2\). This is equivalent to Ridge regression for linear models. With Adam optimizer, weight decay and L2 penalty are NOT equivalent (decoupled weight decay, AdamW, fixes this). L1 weight decay (sparse neural networks) requires separate proximal gradient steps.

import numpy as np
from sklearn.linear_model import Lasso, Ridge, ElasticNet
X = np.random.randn(100, 50) # 100 samples, 50 features
y = X[:, :5] @ np.ones(5) + 0.1*np.random.randn(100) # only 5 true features
lasso = Lasso(alpha=0.1).fit(X, y)
print(np.sum(lasso.coef_ != 0)) # ~5 nonzero (sparse)
ridge = Ridge(alpha=1.0).fit(X, y)
print(np.sum(ridge.coef_ != 0)) # 50 (all nonzero, dense)

Key Takeaways & Cheat Sheet
▼

One-Line Summary per Norm

L0

Counts nonzeros. NP-hard. Best sparsity, not optimizable directly. Convex relax → L1.

L1 / LASSO

Convex, subgradient at 0. Induces exact zeros via corner contact. Robust to outliers in loss.

L2 / Ridge

Smooth, differentiable everywhere. Closed-form solution. Handles correlated features. No exact zeros.

L\(\infty\) / Max-Norm

Constrains worst-case coordinate. Adversarial robustness, embedding clipping, min-max problems.

Decision Guide

🎯 When to Use Which

Need sparse weights → L1 (LASSO)
Correlated features, all weights matter → L2 (Ridge)
Correlated features but want some sparsity → Elastic Net (L1+L2)
Adversarial robustness (per-pixel bound) → L\(\infty\) (PGD, FGSM)
Feature selection theoretical guarantee → L0 with RIP conditions
Embedding norms bounded → Max-norm (L2 per row, L\(\infty\) per entry)

📐 Hölder's Inequality

For dual exponents \(1/p + 1/q = 1\): $$|\mathbf{x}^\top\mathbf{y}| \leq \|\mathbf{x}\|_p \|\mathbf{y}\|_q$$ Special case \(p=q=2\): Cauchy-Schwarz. Special case \(p=1, q=\infty\): \(|\mathbf{x}^\top\mathbf{y}| \leq \|\mathbf{x}\|_1\|\mathbf{y}\|_\infty\). The dual norm of L1 is L\(\infty\) and vice versa.
