Part I · Linear Algebra · 1.5 SVD

Compact, Economy & Truncated SVD

Four flavours of Singular Value Decomposition — shrink the matrices, save the storage, keep the signal.

Foundational Linear Algebra O(min(m,n)² · max(m,n))
1
Understanding the Concept

Every real matrix \(A \in \mathbb{R}^{m \times n}\) (say 6 rows × 4 columns) can be exactly factored as a product of three special matrices:

$$A = U \Sigma V^\top$$

But that equation hides four different choices of how big to make each factor. The difference is how many columns of U and V, and how many singular values in Σ, you keep.

Key Concept

The singular values \(\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_r > 0\) (where \(r = \text{rank}(A)\)) carry all the information. Zeros carry nothing. Small values carry very little. The four SVD variants differ only in how many of those values — and their matching columns — they retain.

Real-world analogy: Think of a photo compressed to JPEG. The "full SVD" is like keeping every pixel of the original. The "economy SVD" throws away the blank canvas border. The "compact SVD" throws away any pixel channel that is pure zero. The "truncated SVD" keeps only the top-k most important channels and discards the rest — tiny approximation error, massive savings.

If you remember one thing

Full SVD pads with zeros and extra columns to make square factors. Economy removes that padding. Compact removes exact-zero singular values. Truncated keeps only the top \(k\) singular values — a lossy approximation. Each step trades exactness for storage.

2
How the Four Variants Work

Fix a matrix \(A \in \mathbb{R}^{m \times n}\) with \(m \geq n\) (tall matrix, more rows than columns) and suppose its rank is \(r \leq n\). Let \(p = \min(m,n) = n\).

VariantU shapeΣ shapeV shapeExact?When useful
Full SVD \(m \times m\) \(m \times n\) \(n \times n\) Yes Theoretical completeness; solving least-squares systems with full null-space info
Economy (Thin) SVD \(m \times n\) \(n \times n\) \(n \times n\) Yes Default in NumPy (full_matrices=False); standard regression / pseudoinverse
Compact SVD \(m \times r\) \(r \times r\) \(n \times r\) Yes Rank-deficient matrices; symbolic algebra; exact representation with no zeros
Truncated (rank-k) SVD \(m \times k\) \(k \times k\) \(n \times k\) Approx (\(k < r\)) PCA, LSA, recommendation, compression; dominant use in ML
Storage Formulas

For an \(m \times n\) matrix with rank \(r\), keeping \(k\) singular values:

  • Original matrix: \(mn\) numbers
  • Full SVD: \(m^2 + mn + n^2\) numbers (usually bigger!)
  • Economy SVD: \(mn + n + n^2 = mn + n(n+1)\) numbers
  • Compact SVD: \(mr + r + nr = r(m + n + 1)\) numbers
  • Truncated SVD (rank-k): \(k(m + n + 1)\) numbers

Truncated beats original when \(k < \dfrac{mn}{m+n+1}\).

Common Confusion

"Economy" and "thin" are synonyms (MATLAB calls it "economy", NumPy calls the mode full_matrices=False). "Compact" specifically means retaining only non-zero singular values. "Truncated" is a rank-\(k\) approximation — it is the only variant that is not exact.

3
The Math — Derivation & Guarantees

Outer-product expansion. Any SVD can be written as a sum of rank-1 outer products:

$$A = \sum_{i=1}^{\min(m,n)} \sigma_i \, u_i v_i^\top$$

where \(u_i\) is the \(i\)-th column of \(U\) and \(v_i\) is the \(i\)-th column of \(V\). When \(\sigma_i = 0\), the term vanishes — that is why compact SVD drops those columns without any error.

Eckart–Young–Mirsky theorem (optimality of truncation). For any \(k < r\):

$$\underset{\text{rank}(B) \leq k}{\operatorname{argmin}} \|A - B\|_F = U_k \Sigma_k V_k^\top \quad \text{with error} \quad \|A - A_k\|_F = \sqrt{\sigma_{k+1}^2 + \cdots + \sigma_r^2}$$

The same theorem holds for the spectral norm \(\|\cdot\|_2\) with error \(\sigma_{k+1}\). This means the rank-\(k\) truncated SVD is the best possible rank-\(k\) approximation — no other rank-\(k\) matrix is closer to \(A\) in either the Frobenius or spectral norm.

Pseudoinverse via Compact SVD

The Moore–Penrose pseudoinverse \(A^+\) is computed cleanly from the compact SVD:

$$A^+ = V_r \Sigma_r^{-1} U_r^\top$$

This requires only inverting the \(r \times r\) diagonal \(\Sigma_r\) (flip each \(\sigma_i \to 1/\sigma_i\)). Full SVD would include zero singular values that cannot be inverted — hence compact SVD is the correct tool for the pseudoinverse.

Numerical Subtlety

In floating-point arithmetic, "exact zeros" rarely appear — there will be tiny near-zero singular values (e.g., \(10^{-14}\)). Compact SVD in practice uses a threshold \(\epsilon \cdot \sigma_1\) (often \(\epsilon = n \cdot \text{machine epsilon}\)) to decide which singular values to treat as zero. NumPy's np.linalg.matrix_rank uses exactly this approach.

Code — NumPy Walkthrough

The code below reproduces all four variants on the same 6 × 4 rank-3 matrix used in the visualisation. Step through with the active-line highlight.

import numpy as np
# Build a 6×4 matrix of rank 3 (two cols are linear combinations)
rng = np.random.default_rng(42)
base = rng.standard_normal((6, 3)) # rank-3 base
A = np.hstack([base, base[:, :1] + base[:, 1:2]]) # col4 = col1+col2
print("A shape:", A.shape, " rank:", np.linalg.matrix_rank(A)) # (6,4) 3
# ─── FULL SVD ───────────────────────────────────────────────────────────
U_f, s_f, Vt_f = np.linalg.svd(A, full_matrices=True)
print("Full: U", U_f.shape, " s", s_f.shape, " Vt", Vt_f.shape)
# Full: U (6,6) s (4,) Vt (4,4) — s has 4 vals; 4th ≈ 0
# ─── ECONOMY (THIN) SVD ─────────────────────────────────────────────────
U_e, s_e, Vt_e = np.linalg.svd(A, full_matrices=False)
print("Economy: U", U_e.shape, " s", s_e.shape, " Vt", Vt_e.shape)
# Economy: U (6,4) s (4,) Vt (4,4) — last singular value ≈ 1e-16
# ─── COMPACT SVD ────────────────────────────────────────────────────────
tol = max(A.shape) * np.finfo(float).eps * s_e[0] # numerical threshold
r = np.sum(s_e > tol) # numerical rank = 3
U_c, s_c, Vt_c = U_e[:, :r], s_e[:r], Vt_e[:r, :]
print("Compact: U", U_c.shape, " s", s_c.shape, " Vt", Vt_c.shape)
# Compact: U (6,3) s (3,) Vt (3,4) — exact reconstruction
# ─── TRUNCATED SVD (rank-k) ──────────────────────────────────────────────
k = 2 # keep top-2 only
U_t, s_t, Vt_t = U_e[:, :k], s_e[:k], Vt_e[:k, :]
A_approx = U_t @ np.diag(s_t) @ Vt_t # rank-2 approximation
err = np.linalg.norm(A - A_approx, 'fro') # Frobenius error = σ₃
print("Truncated k=2: U", U_t.shape, " error =", round(err, 4))
# ─── STORAGE COMPARISON ─────────────────────────────────────────────────
m, n = A.shape # 6, 4
print(f"Original: {m*n} floats")
print(f"Full SVD: {m*m + m*n + n*n} floats (U²+Σ+V²)")
print(f"Economy: {m*n + n + n*n} floats")
print(f"Compact: {r*(m+n+1)} floats")
print(f"Truncated: {k*(m+n+1)} floats")
Production: sklearn TruncatedSVD

For large sparse matrices, use sklearn.decomposition.TruncatedSVD which uses randomised SVD (Halko–Martinsson–Tropp 2011) — far cheaper than full SVD for large \(m,n\) when \(k \ll \min(m,n)\). It is the engine behind sklearn's LSA and PCA-on-sparse.

5
Key Takeaways & When to Use Which
  • Full SVD — need complete null-space or want unitary \(U\) and \(V\) (both square). Rarely needed in practice.
  • Economy (Thin) SVD — default choice for pseudoinverse, regression, QR-less least squares. NumPy default with full_matrices=False.
  • Compact SVD — matrix is rank-deficient; want exact arithmetic with no zero singular values cluttering \(\Sigma\). Right tool for pseudoinverse: \(A^+ = V_r \Sigma_r^{-1} U_r^\top\).
  • Truncated SVD — you care about a \(k\)-dimensional approximation (PCA, latent semantic analysis, collaborative filtering, image compression). The Eckart–Young theorem guarantees optimality.
Decision Rule

If you need exact reconstruction → use compact SVD. If you need the best rank-\(k\) approximation → use truncated SVD. If you need the full orthogonal basis for both the column and row spaces → use full SVD. For everything else, economy SVD is the sensible default.
