What Is Conic Optimization?
▼

What is it? Imagine you need to find the cheapest way to allocate resources — but your allowed choices aren't a nice box; they form a cone: a set that contains 0 and, if a point is feasible, so is any positive multiple of it. Conic optimization says: minimize a linear cost over all feasible choices that lie inside one of these special cone shapes.

Analogy: Think of three nesting-doll cones. The smallest is a "flat" cone — the nonnegative orthant \(\mathbb{R}^n_+\) (every variable just has to be ≥ 0). Inside a bigger ice-cream scoop lives the second-order cone, where you can also bound the length of a vector. The biggest doll is the positive semidefinite (PSD) cone — here your variable is a matrix and it must have no negative eigenvalues. Each larger cone can express more shapes, but they all share one miraculous property: any convex problem expressible in this form can be solved in polynomial time.

One-sentence summary: Conic optimization is the theory that unifies LP, SOCP, and SDP under a single problem template — minimize \(c^\top x\) subject to \(Ax = b\) and \(x \in K\) for a convex cone \(K\) — unlocking a hierarchy of expressive power and a universal duality theory.

💡 If you remember one thing

LP, SOCP, and SDP are all special cases of conic optimization. The feasible set is always a convex cone \(K\):
— LP: \(K = \mathbb{R}^n_+\) (nonnegative orthant)
— SOCP: \(K = \mathcal{L}^{n+1}\) (Lorentz / second-order cone)
— SDP: \(K = \mathbb{S}^n_+\) (positive semidefinite matrices)
All three are self-dual and solvable in polynomial time by interior-point methods.

2
Historical Context
▼

The Problem Linear Programming Could Not Solve

George Dantzig's simplex method (1947) handled linear programs beautifully, but many real engineering problems — antenna design, truss structures, control systems — required optimizing over quadratic or matrix constraints. These fell outside LP's reach.

Emergence of Interior-Point Methods

The pivotal year was 1984, when Narendra Karmarkar published a polynomial-time interior-point algorithm for LP, outperforming simplex in the worst case. This reignited theoretical interest. In 1987, Nesterov and Nemirovski proved that self-concordant barrier functions could drive interior-point methods to solve any convex conic program in polynomial time — the theoretical foundation of modern conic optimization.

Second-Order Cone Programming

SOCP was formalized in the 1990s as researchers realized that many norm-constrained and quadratic problems could be recast as LP over the Lorentz cone. Lobo, Vandenberghe, Boyd, and Lebret's 1998 paper "Applications of Second-Order Cone Programming" catalogued hundreds of applications in signal processing, finance, and geometry.

Semidefinite Programming

SDP rose to prominence with Vandenberghe and Boyd's 1996 survey "Semidefinite Programming". It turned out that many combinatorial approximation algorithms (Goemans–Williamson MAX-CUT, 1995), control theory (Lyapunov stability conditions), and sum-of-squares polynomial optimization all reduce to SDP. The ability to optimize over matrix inequalities \(X \succeq 0\) made it extraordinarily expressive.

The Cone Hierarchy and Core Math
▼

The Universal Conic Program

Every problem in the hierarchy has the same form. Given \(c \in \mathbb{R}^n\), \(A \in \mathbb{R}^{m \times n}\), \(b \in \mathbb{R}^m\), and a convex cone \(K \subseteq \mathbb{R}^n\):

$$\min_{x \in \mathbb{R}^n} \; c^\top x \quad \text{s.t.} \quad Ax = b,\; x \in K$$

The cone \(K\) determines the problem class. Three canonical choices give the full hierarchy:

Level 1 — LP: Nonnegative Orthant \(\mathbb{R}^n_+\)

$$K_{\text{LP}} = \mathbb{R}^n_+ = \{x \in \mathbb{R}^n : x_i \geq 0 \;\forall i\}$$

This is the most restricted cone — a "flat" boundary of halfspaces. LP optimal solutions always occur at extreme points (vertices) of the polyhedron \(\{x : Ax = b, x \geq 0\}$.

Level 2 — SOCP: Lorentz (Ice-Cream) Cone

$$K_{\text{SOCP}} = \mathcal{L}^{n+1} = \bigl\{(t, \mathbf{x}) \in \mathbb{R} \times \mathbb{R}^n : \|\mathbf{x}\|_2 \leq t \bigr\}$$

The Lorentz cone is a smooth cone with a circular cross-section — picture an ice cream cone pointing downward. Constraints like \(\|Ax + b\|_2 \leq c^\top x + d\) live here. SOCP strictly contains LP: every LP is an SOCP (use the degenerate case where the \(\mathbf{x}\) part is 1D and the constraint degenerates to \(|x_i| \leq x_i\), i.e., \(x_i \geq 0\)).

Level 3 — SDP: Positive Semidefinite Cone

$$K_{\text{SDP}} = \mathbb{S}^n_+ = \bigl\{X \in \mathbb{S}^n : v^\top X v \geq 0 \;\forall v \in \mathbb{R}^n\bigr\} = \bigl\{X : \lambda_{\min}(X) \geq 0\bigr\}$$

Here the optimization variable is a symmetric matrix \(X \in \mathbb{S}^n\) (the symmetric matrices form a vector space of dimension \(n(n+1)/2\)), and the constraint is that all eigenvalues are nonnegative. SDP strictly contains SOCP: the Lorentz cone is isomorphic to a particular slice of \(\mathbb{S}^2_+\) via

$$\|(x_1, x_2)\|_2 \leq t \;\iff\; \begin{pmatrix} t & x_1 & x_2 \\ x_1 & t & 0 \\ x_2 & 0 & t \end{pmatrix} \succeq 0 \quad \text{(via Schur complement)}$$
∑ Containment Summary

$$\text{LP}\;\subset\;\text{SOCP}\;\subset\;\text{SDP}$$ Every LP is an SOCP; every SOCP is an SDP. The converse is false. SDP can express non-polyhedral feasible sets that LP and SOCP cannot.

Self-Duality

All three cones are self-dual: \(K^* = K\) where the dual cone is \(K^* = \{y : x^\top y \geq 0 \;\forall x \in K\}\). This is why conic duality has such elegant symmetry — the dual problem has exactly the same cone structure as the primal.

⚠️ What SDP Cannot Do Efficiently

Not every convex program is an SDP. The copositive cone \(\{A : x^\top A x \geq 0 \;\forall x \geq 0\}\) is strictly larger than \(\mathbb{S}^n_+\) and can encode NP-hard problems. The "conic hierarchy" terminates at SDP for polynomial-time solvability.

Conic Duality and Strong Duality
▼

Primal–Dual Pair

Every conic program has a natural dual derived by Lagrangian relaxation. For the primal

$$\text{(P)}\quad \min_{x} \; c^\top x \quad \text{s.t.} \quad Ax = b,\; x \in K$$

introduce multipliers \(y \in \mathbb{R}^m\) for the equality constraint and \(s \in K^*\) for the cone constraint. The dual is

$$\text{(D)}\quad \max_{y,s} \; b^\top y \quad \text{s.t.} \quad A^\top y + s = c,\; s \in K^*$$

Because \(K\) is self-dual (\(K^* = K\)) for all three standard cones, the dual has identical structure to the primal — just with the roles of \(c\) and \(b\) swapped and \(A\) transposed.

Weak and Strong Duality

Weak duality (always holds): for any primal feasible \(x \in K\) and dual feasible \((y,s)\) with \(s \in K^*\):

$$c^\top x - b^\top y = c^\top x - (c - s)^\top x + b^\top y - b^\top y = s^\top x \geq 0$$

so the primal objective is always ≥ the dual objective (duality gap \(\geq 0\)).

Strong duality (requires Slater's condition): if there exists a strictly feasible primal point \(\hat{x} \in \text{int}(K)\) with \(A\hat{x} = b\), then the duality gap is zero at optimality and the dual achieves its supremum:

$$p^* = d^* \quad \text{(zero duality gap)}$$

Complementary Slackness

At optimality, primal \(x^*\) and dual \((y^*, s^*)\) satisfy:

$$(x^*)^\top s^* = 0 \quad \text{(complementary slackness)}$$

For LP this means: if \(x^*_i > 0\) then \(s^*_i = 0\) (and vice versa) — exactly the familiar LP complementarity condition. For SDP it means \(X^* S^* = 0\) where \(X^*, S^* \succeq 0\), which implies \(X^* S^* = 0\) has rank at most \(n\) and the optimal matrices share a common null space.

💡 Conic Duality in One Picture

Think of the cone \(K\) and its dual \(K^*\) as two cones pointing toward each other. The primal says "pick \(x\) in my cone to minimize cost." The dual says "pick \(s\) in the dual cone to maximize a lower bound." When Slater's condition holds they meet exactly — zero gap. The complementary slackness condition \(x^\top s = 0\) means the optimal primal and dual points are "perpendicular" — one is on the boundary of the cone wherever the other is strictly inside.

Code: From Scratch to Solvers
▼

LP via Interior-Point (from scratch, log-barrier)

import numpy as np
from scipy.linalg import solve
def lp_barrier(c, A, b, x0, t=1.0, mu=10.0, tol=1e-8):
"""Log-barrier interior-point for LP: min cTx s.t. Ax=b, x>0."""
x = x0.copy() # strictly feasible starting point
m, n = A.shape
while n / t > tol: # duality-gap proxy: n/t
# Centering step: Newton on t*cTx - sum(log xi)
# Gradient: t*c - 1/x, Hessian: diag(1/x^2)
g = t * c - 1.0 / x # gradient
H = np.diag(1.0 / x**2) # Hessian
# KKT system: [H AT; A 0][dx; nu] = [-g; 0]
KKT = np.block([[H, A.T], [A, np.zeros((m, m))]])
rhs = np.concatenate([-g, np.zeros(m)])
sol = solve(KKT, rhs) # Newton step
dx = sol[:n]
# Backtrack to stay in x > 0
alpha = min(1.0, 0.99 * np.min(-x[dx < 0] / dx[dx < 0], initial=1.0))
x = x + alpha * dx
t *= mu # increase t toward optimum
return x
# Example: min x1 + 2*x2 s.t. x1+x2=3, x1,x2>0
c = np.array([1.0, 2.0])
A = np.array([[1.0, 1.0]])
b = np.array([3.0])
x0 = np.array([1.5, 1.5]) # strictly feasible
x_opt = lp_barrier(c, A, b, x0)
print(x_opt) # ≈ [3, 0] (boundary, approached from interior)

SOCP and SDP via CVXPY (production)

import cvxpy as cp, numpy as np
# ── SOCP: min t s.t. ||Ax+b||_2 <= t, Cx = d ──
A_mat = np.array([[1,0],[0,1],[1,1]], dtype=float)
b_vec = np.array([1.0, 2.0, 0.5])
x = cp.Variable(2)
t = cp.Variable() # epigraph variable
prob_socp = cp.Problem(
cp.Minimize(t),
[cp.norm(A_mat @ x + b_vec, 2) <= t,
x[0] + x[1] == 5.0] # equality constraint
)
prob_socp.solve(solver=cp.ECOS)
print("SOCP x*:", x.value, " t*:", t.value)
# ── SDP: min tr(C @ X) s.t. tr(A_i @ X) = b_i, X >> 0 ──
C = np.array([[1., 0.], [0., 2.]]) # cost matrix
A1 = np.array([[1., 0.], [0., 0.]]) # A_1 x = 2
X = cp.Variable((2, 2), symmetric=True)
prob_sdp = cp.Problem(
cp.Minimize(cp.trace(C @ X)),
[cp.trace(A1 @ X) == 2.0, # linear matrix constraint
X >> 0] # PSD cone
)
prob_sdp.solve(solver=cp.SCS)
print("SDP X*:", X.value)
print("tr(C X*):", np.trace(C @ X.value)) # optimal = 2.0
