1
Understanding Naive Bayes
▼

What is it? Naive Bayes is a family of probabilistic classifiers built on Bayes' theorem with one "naive" simplifying assumption: all features are conditionally independent given the class label. This means we can multiply per-feature probabilities together instead of estimating a full joint distribution — making training lightning-fast and surprisingly competitive on many real-world tasks.

Analogy: Imagine diagnosing a patient by checking each symptom one at a time, assuming the symptoms don't influence each other. "Does the patient have a fever? What about a cough? Sore throat?" You multiply the independent probabilities for each symptom given each disease, then pick the most probable disease. Real symptoms are correlated, but the naive assumption often works well enough in practice.

Why four variants? The "naive" assumption says features are independent, but it says nothing about what distribution each feature follows. Different data types call for different per-feature likelihood models:

Gaussian NB

Continuous features — models each as a Gaussian \(\mathcal{N}(\mu_c, \sigma_c^2)\). Best for real-valued measurements like height, temperature, or sensor readings.

Multinomial NB

Count features — word frequencies, term counts. Models the probability of each term given class. Classic choice for text classification.

Bernoulli NB

Binary features — word present/absent (0 or 1). Penalizes absence explicitly. Better for short documents and sparse binary data.

Complement NB

Fits parameters on the complement of each class, then classifies by the lowest complement score. Corrects for class imbalance.

💡 If you remember one thing

All four Naive Bayes variants share the same Bayes decision rule — they only differ in which likelihood model \(P(x_j \mid c)\) they assume. Choose the variant that matches your feature type, and NB will be hard to beat for its training speed.

2
The Four Likelihood Models
▼

Shared Framework — Bayes' Theorem

Every NB variant applies the same MAP decision rule. Given a feature vector \(\mathbf{x} = (x_1, \ldots, x_d)\) and class \(c\):

$$\hat{c} = \underset{c}{\arg\max}\; \log P(c) + \sum_{j=1}^{d} \log P(x_j \mid c)$$

The log-sum form is numerically stable and avoids underflow from multiplying many tiny probabilities. The four variants differ only in the definition of \(P(x_j \mid c)\).

1 — Gaussian NB (continuous features)

Assumes each feature \(x_j\) is drawn from a Gaussian with class-specific mean and variance:

$$P(x_j \mid c) = \frac{1}{\sqrt{2\pi\sigma_{jc}^2}} \exp\!\left(-\frac{(x_j - \mu_{jc})^2}{2\sigma_{jc}^2}\right)$$

Parameters \(\mu_{jc}\) and \(\sigma_{jc}^2\) are estimated by the sample mean and variance of feature \(j\) over training examples of class \(c\). Use for: continuous sensor data, physical measurements, spectral features.

2 — Multinomial NB (count features)

Models documents as bags of words with term counts \(x_j \geq 0\). The likelihood of a document is the multinomial probability of its term frequency vector. With Laplace smoothing \(\alpha\):

$$\hat{\theta}_{jc} = \frac{N_{jc} + \alpha}{N_c + \alpha d}, \qquad P(\mathbf{x} \mid c) \propto \prod_{j=1}^{d} \hat{\theta}_{jc}^{\,x_j}$$

where \(N_{jc}\) = count of word \(j\) in class-\(c\) documents, \(N_c\) = total words in class \(c\), \(d\) = vocabulary size. Use for: TF-based text classification, document categorization.

3 — Bernoulli NB (binary features)

Features are binary: \(x_j \in \{0, 1\}\). The model explicitly penalizes absent features as evidence against a class:

$$P(x_j \mid c) = \hat{p}_{jc}^{\,x_j}(1 - \hat{p}_{jc})^{1 - x_j}, \qquad \hat{p}_{jc} = \frac{N_{jc} + \alpha}{N_c + 2\alpha}$$

If word \(j\) is absent (\(x_j = 0\)), Bernoulli NB multiplies by \((1 - \hat{p}_{jc})\) — Multinomial NB would simply skip it. This makes Bernoulli NB more sensitive to word absence in short texts.

4 — Complement NB (imbalanced classes)

Rather than estimating parameters from class \(c\), Complement NB fits parameters from all other classes (the complement \(\bar{c}\)) and classifies by the lowest complement log-likelihood:

$$\hat{\theta}_{j\bar{c}} = \frac{N_{j\bar{c}} + \alpha}{N_{\bar{c}} + \alpha d}, \qquad \hat{c} = \underset{c}{\arg\min}\;\sum_{j} x_j \log \hat{\theta}_{j\bar{c}}$$

Rennie et al. (2003) showed CNB dominates MNB on text benchmarks because it corrects for biased parameter estimation when classes are imbalanced.

🔑 Design Decision — Why "Naive"?

The conditional independence assumption \(P(\mathbf{x} \mid c) = \prod_j P(x_j \mid c)\) reduces a \(d\)-dimensional joint distribution (exponentially many parameters) to \(d\) independent 1-D models. Even when features are correlated, NB classification boundaries are often correct because the relative ordering of posteriors is preserved even with biased probability estimates.

⚠️ When naive independence fails badly

If two features are highly correlated (e.g., "bank" and "river" co-occurring), NB over-counts their combined evidence. The posterior probabilities become poorly calibrated — but the classification label can still be correct. Never trust NB's raw probability outputs for downstream decisions (use isotonic regression or Platt scaling for calibration).

The Mathematics — Derivation & Estimates
▼

From Bayes' Theorem to the Decision Rule

By Bayes' theorem, the posterior probability of class \(c\) given \(\mathbf{x}\) is:

$$P(c \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid c)\,P(c)}{P(\mathbf{x})}$$

Since \(P(\mathbf{x})\) is constant across classes, we classify by the MAP estimate:

$$\hat{c} = \underset{c}{\arg\max}\; P(\mathbf{x} \mid c)\,P(c)$$

Applying the naive independence assumption \(P(\mathbf{x}\mid c) = \prod_{j=1}^{d} P(x_j \mid c)\) and taking logs:

$$\hat{c} = \underset{c}{\arg\max}\left[\log P(c) + \sum_{j=1}^{d} \log P(x_j \mid c)\right]$$

Numerical Trace — Gaussian NB

Training set: Class 0 samples \(\{1.0, 1.5, 2.0\}\), Class 1 samples \(\{5.0, 5.5, 6.0\}\). Equal priors \(P(c_0)=P(c_1)=0.5\).

MLE estimates:

$$\mu_0 = 1.5,\quad \sigma_0^2 = 0.1\overline{6},\qquad \mu_1 = 5.5,\quad \sigma_1^2 = 0.1\overline{6}$$

For a new point \(x_\text{new} = 2.5\):

$$P(x=2.5 \mid c_0) = \frac{1}{\sqrt{2\pi \cdot 0.1\overline{6}}} e^{-\frac{(2.5-1.5)^2}{2 \cdot 0.1\overline{6}}} = 0.9772 \times 0.04979 \approx 0.04865$$
$$P(x=2.5 \mid c_1) \approx 1.84 \times 10^{-12} \quad(\text{exponent} = -24)$$

Log posteriors: \(\log P(c_0\mid x) \approx -3.02\), \(\log P(c_1\mid x) \approx -27.02\). Predict class 0. ✓

Numerical Trace — Multinomial NB

Vocabulary \(\{w_1, w_2, w_3\}\). Class 0 counts \([3,1,0]\), class 1 counts \([0,1,3]\). Laplace smoothing \(\alpha=1\):

$$\hat{\theta}_{j,c_0} = \frac{N_{j,c_0}+1}{N_{c_0}+3} \Rightarrow [0.5714,\;0.2857,\;0.1429]$$

Test document \(\mathbf{x}=[2,0,1]\): log-likelihood for \(c_0 = 2\ln(0.5714)+0+1\ln(0.1429) = -3.065\); for \(c_1 = -4.451\). Predict class 0. ✓

Numerical Trace — Bernoulli NB

Binary features: \(\hat{p}_{1,c_0}=0.75,\;\hat{p}_{2,c_0}=0.50,\;\hat{p}_{3,c_0}=0.25\). Test \(\mathbf{x}=[1,0,1]\):

$$\log P(\mathbf{x}\mid c_0) = \ln(0.75) + \ln(0.5) + \ln(0.25) = -0.288 - 0.693 - 1.386 = -2.367$$

Same result for \(c_1\) due to symmetric setup — tie broken by prior. Key: the \(\ln(1-\hat{p}_{2,c})\) term penalises the absent feature, which Multinomial NB skips.

Complement NB — Correcting for Imbalance

CNB estimates \(\hat{\theta}_{j\bar{c}}\) from the complement class, then minimises the complement score. For equal-sized classes this is equivalent to MNB, but for imbalanced data where \(|c_0| \ll |c_1|\), the majority class dominates MNB's estimates while CNB remains robust.

$$\hat{c} = \underset{c}{\arg\min}\sum_{j=1}^{d} x_j \log \hat{\theta}_{j\bar{c}}$$
📐 Parameter Estimation Summary

GNB: \(\hat{\mu}_{jc} = \frac{1}{N_c}\sum_{i:y_i=c} x_{ij}\), \(\hat{\sigma}_{jc}^2 = \frac{1}{N_c}\sum_{i:y_i=c}(x_{ij}-\hat{\mu}_{jc})^2\)
MNB: \(\hat{\theta}_{jc} = \frac{N_{jc}+\alpha}{N_c+\alpha d}\)
BNB: \(\hat{p}_{jc} = \frac{N_{jc}+\alpha}{N_c+2\alpha}\)
CNB: \(\hat{\theta}_{j\bar{c}} = \frac{N_{j\bar{c}}+\alpha}{N_{\bar{c}}+\alpha d}\), predict \(\arg\min_c \sum_j x_j \log\hat{\theta}_{j\bar{c}}\)

Key Takeaways & When to Use Each
▼

When to Use Each Variant

Gaussian NB

Continuous real-valued features. Medical diagnostics, sensor classification, iris-type datasets. Fails for heavy-tailed or multimodal distributions.

Multinomial NB

Term-frequency text features (TF / TF-IDF counts). Document classification, spam detection. Needs non-negative features.

Bernoulli NB

Binary bag-of-words. Short texts, email spam, sentiment on small vocab. Penalises word absence — useful when absence is informative.

Complement NB

Imbalanced text datasets. News categorisation with rare classes. Usually outperforms MNB on text benchmarks (Rennie et al., 2003).

Strengths across all variants

O(n·d) training, O(d) prediction, no iterations required. Works well with very small training sets. Naturally handles missing features. Excellent baseline for text classification tasks.

Common gotchas

Raw probabilities are not calibrated — do not use them as confidence scores without Platt scaling. Zero counts without smoothing produce zero-probability catastrophes. Gaussian NB with very non-Gaussian features (e.g., pixel values) can underperform logistic regression despite competitive accuracy on separable tasks.
