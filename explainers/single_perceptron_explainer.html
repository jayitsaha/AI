Understanding the Concept

What is it?

A perceptron is the simplest possible artificial neuron. It takes a bunch of numbers as input, multiplies each by a weight (importance score), adds a bias, and decides: output 1 or 0. That's it. It's a binary yes/no machine.

Real-World Analogy

Imagine a loan officer who decides "approve" or "reject" a loan application. They look at income, credit score, and years of employment — each weighted by importance. If the total score crosses a threshold, they approve. The perceptron is exactly that officer, but instead of a human threshold, it uses a step function: if \(\mathbf{w}^\top \mathbf{x} + b \geq 0\), output 1; otherwise, output 0.

If you remember one thing
A perceptron draws a straight line (or hyperplane in higher dimensions) to separate two classes. The learning rule nudges that line toward misclassified points until all points are correctly separated — if such a line exists.

The Output Formula

$$\hat{y} = \text{step}(\mathbf{w}^\top \mathbf{x} + b) = \begin{cases} 1 & \text{if } \mathbf{w}^\top \mathbf{x} + b \geq 0 \\ 0 & \text{otherwise} \end{cases}$$

How It Works Internally

Architecture

For input \(\mathbf{x} \in \mathbb{R}^n\), weights \(\mathbf{w} \in \mathbb{R}^n\), and bias \(b \in \mathbb{R}\):

  1. Linear combination: compute \(z = \mathbf{w}^\top \mathbf{x} + b = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b\)
  2. Step function: output \(\hat{y} = 1\) if \(z \geq 0\), else \(\hat{y} = 0\)
  3. Compare to label: compute error \(e = y - \hat{y}\)
  4. Update weights: \(\mathbf{w} \leftarrow \mathbf{w} + \eta (y - \hat{y})\mathbf{x}\), \(\quad b \leftarrow b + \eta (y - \hat{y})\)

The Learning Rule

$$\mathbf{w} \leftarrow \mathbf{w} + \eta\,(y - \hat{y})\,\mathbf{x}$$

When correctly classified: \(y - \hat{y} = 0\), so no update. When misclassified as 0 but true label is 1: weights increase in the direction of \(\mathbf{x}\), moving the boundary so \(\mathbf{x}\) is more likely to be on the positive side next time. Conversely for the opposite error.

Key Invariant
The update \(\eta(y - \hat{y})\mathbf{x}\) always moves the decision boundary toward the misclassified point. After convergence (if the data is linearly separable), every point is on the correct side.

Numerical Trace (2D Example)

Let \(\mathbf{x} = [1, 2]\), \(y = 1\), \(\mathbf{w} = [0.3, -0.5]\), \(b = 0.1\), \(\eta = 0.1\).

  • \(z = 0.3(1) + (-0.5)(2) + 0.1 = 0.3 - 1.0 + 0.1 = -0.6\)
  • \(\hat{y} = \text{step}(-0.6) = 0\) → misclassified (true label 1)
  • Error \(e = 1 - 0 = 1\)
  • Update: \(\mathbf{w} \leftarrow [0.3 + 0.1 \cdot 1, -0.5 + 0.2 \cdot 1] = [0.4, -0.3]\)
  • New bias: \(b \leftarrow 0.1 + 0.1 = 0.2\)
  • Re-check: \(z' = 0.4(1) + (-0.3)(2) + 0.2 = 0.4 - 0.6 + 0.2 = 0.0\)
  • \(\hat{y} = \text{step}(0.0) = 1\) ✓ correct now
XOR Failure
XOR is not linearly separable: no single straight line can separate the four points \((0,0) \to 0\), \((0,1) \to 1\), \((1,0) \to 1\), \((1,1) \to 0\). The perceptron will cycle forever, never converging. This limitation motivated multi-layer networks.

Why It Works — Convergence Theorem

Perceptron Convergence Theorem (Rosenblatt, 1958)

If the data is linearly separable with margin \(\gamma > 0\) and all inputs satisfy \(\|\mathbf{x}\| \leq R\), the perceptron learning rule converges in at most

$$T \leq \left(\frac{R}{\gamma}\right)^2 \text{ mistakes}$$

where \(\gamma = \min_i y_i (\mathbf{w}^*{}^\top \mathbf{x}_i + b^*) > 0\) is the margin of the optimal separator \(\mathbf{w}^*\).

Sketch of Proof Idea

Track two quantities across updates:

  1. Angle progress: Each update increases \(\mathbf{w} \cdot \mathbf{w}^*\) by at least \(\eta\gamma\) (because the update moves \(\mathbf{w}\) in a direction correlated with the correct separator).
  2. Norm growth: Each update increases \(\|\mathbf{w}\|^2\) by at most \(\eta^2 R^2\) (because \(\|\mathbf{x}\| \leq R\)).

The cosine \(\cos\theta = \frac{\mathbf{w} \cdot \mathbf{w}^*}{\|\mathbf{w}\|\|\mathbf{w}^*\|}\) is bounded by 1, so the number of updates \(T\) is bounded by \((R/\gamma)^2\).

No Guarantee Without Linear Separability
When data is not linearly separable, the perceptron never converges. It cycles among weight vectors indefinitely. Use logistic regression or multi-layer networks instead.

Comparison & Key Takeaways

Perceptron Step function No loss (direct rule) No No (step is not differentiable)
Logistic Regression Sigmoid \(\sigma(z)\) Binary cross-entropy No Yes — gradient-based training
SVM Sign function Hinge loss + margin Yes (with kernel) Yes (with slack variables)
MLP (2+ layers) ReLU/tanh/sigmoid Cross-entropy Yes Yes — backpropagation
Decision Guide
Use a perceptron for: linearly separable data, quick prototyping, historical understanding.
Use logistic regression for: probabilistic outputs, gradient-based training.
Use MLP for: non-linearly separable data (XOR, spirals, etc.).
