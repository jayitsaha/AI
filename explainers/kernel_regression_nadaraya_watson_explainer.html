Understanding Nadaraya-Watson
▼

What is it? Nadaraya-Watson kernel regression is a technique for predicting a continuous output \(\hat{y}(x)\) at any query point \(x\) without assuming a fixed parametric form (like a line or polynomial). Instead, it computes a weighted average of nearby training labels, where "nearby" is defined by a kernel function that assigns higher weight to closer points.

Analogy: Imagine you want to know the typical house price in your neighbourhood. You don't fit a global formula — instead you ask neighbours, but you trust the house next door far more than one ten miles away. The kernel is your "trust decay function": a Gaussian bell that gives nearly full weight to the immediate neighbours and almost zero weight to distant houses. As you walk from house to house (sliding the query point \(x\)), you recompute this local average each time — that's the fitted curve.

💡 If you remember one thing

The estimate $$\hat{y}(x) = \frac{\sum_{i=1}^n K_h(x - x_i)\, y_i}{\sum_{i=1}^n K_h(x - x_i)}$$ is a kernel-weighted average of all training labels — each \(y_i\) is weighted by how close \(x_i\) is to query \(x\) under kernel \(K_h\). The bandwidth \(h\) controls how wide the kernel is, trading bias for variance.

Prerequisites: Basic probability (mean/expectation), understanding of a regression problem (predicting continuous output from inputs). Familiarity with the bias-variance tradeoff helps for the bandwidth discussion.

How It Works Internally
▼

Step-by-step at query point x

Given training data \(\{(x_1,y_1),\ldots,(x_n,y_n)\}\) and a query point \(x\):

1. Compute kernel distances. For each training point \(x_i\), evaluate the kernel \(K_h(x - x_i)\). The Gaussian (RBF) kernel is most common: \(K_h(u) = \exp\!\left(-\frac{u^2}{2h^2}\right)\). This gives a value in \((0,1]\) — exactly 1 when \(u=0\), decaying to ~0 beyond 3\(h\).

2. Normalise to get weights. Divide each kernel value by the sum: \(w_i = K_h(x - x_i) / \sum_j K_h(x - x_j)\). These weights sum to 1 and form a proper probability distribution over the training set. They are local — only points within a few bandwidths of \(x\) get non-negligible weight.

3. Take the weighted average. \(\hat{y}(x) = \sum_i w_i y_i\). This is a conditional expectation estimator: it approximates \(\mathbb{E}[Y \mid X = x]\) using the empirical distribution weighted by kernel proximity.

4. Trace the fitted curve. Repeat for a dense grid of query points \(x \in [\min x_i, \max x_i]\). Connecting the outputs \(\hat{y}(x)\) gives the smooth fitted curve. This is \(O(n)\) per query point, \(O(n^2)\) for an \(n\)-point grid — no training phase at all.

Bandwidth h: the critical hyperparameter

Bandwidth \(h\) controls the width of the kernel window:

  • Small h (narrow window): Each prediction uses only the 1–2 nearest points → wiggly, high-variance, low-bias curve. Risk of overfitting.
  • Large h (wide window): All points contribute nearly equally → very smooth, low-variance, high-bias curve. Approaches the global mean as \(h \to \infty\).
  • Optimal h: Chosen by leave-one-out cross-validation or MISE (Mean Integrated Squared Error) minimisation. The optimal rate is \(h^* \propto n^{-1/5}\) for Gaussian kernels.
🔑 Key Property

Nadaraya-Watson is consistent: as \(n \to \infty\) with \(h \to 0\) and \(nh \to \infty\), the estimate converges to the true conditional expectation \(\mathbb{E}[Y|X=x]\) — no matter the true functional form. This is the power of non-parametric regression.

Numerical trace at x=5, h=1 (our demo dataset)

With 10 points on \([0,10]\) fitting \(\sin(x)\), at query \(x=5\), bandwidth \(h=1\):

  • Points at \(x_5=4.44\) and \(x_6=5.56\) each get weight \(\approx 0.377\) (closest)
  • Points at \(x_4=3.33\) and \(x_7=6.67\) get weight \(\approx 0.110\) (one step out)
  • All other points: weight \(<0.001\) — essentially ignored
  • Result: \(\hat{y}(5) \approx -0.564\) vs true \(\sin(5) \approx -0.959\)

The Math Behind It
▼

Formal definition

Assume the regression model \(Y = m(X) + \varepsilon\) where \(m(x) = \mathbb{E}[Y \mid X=x]\) is the unknown regression function and \(\mathbb{E}[\varepsilon \mid X]=0\). The Nadaraya-Watson estimator is:

$$\hat{m}(x) = \frac{\displaystyle\sum_{i=1}^n K_h(x - x_i)\, y_i}{\displaystyle\sum_{i=1}^n K_h(x - x_i)}$$

where \(K_h(u) = \frac{1}{h} K\!\left(\frac{u}{h}\right)\) for any kernel \(K\) satisfying \(\int K(u)\,du = 1\), \(\int u K(u)\,du = 0\) (symmetry), and \(\int u^2 K(u)\,du = \mu_2(K) < \infty\).

Derivation from kernel density estimation

The conditional expectation can be written as a ratio of joint and marginal densities:

$$m(x) = \mathbb{E}[Y|X=x] = \frac{\int y \cdot f_{XY}(x,y)\,dy}{f_X(x)}$$

Estimate numerator and denominator with kernel density estimators. For the joint density at \((x, y_i)\):

$$\widehat{f_{XY}}(x, y) \approx \frac{1}{nh} \sum_i K_h(x - x_i) \cdot \delta(y - y_i)$$

Integrating out \(y\) (replacing the delta by \(y_i\) times the mass) and dividing by the marginal density estimator \(\hat{f}_X(x) = \frac{1}{nh}\sum_i K_h(x-x_i)\) yields the Nadaraya-Watson formula exactly. The \(\frac{1}{nh}\) factors cancel in the ratio.

Bias-variance decomposition

The conditional mean squared error at a point \(x\) (for a twice-differentiable \(m\)) is:

$$\operatorname{MSE}[\hat{m}(x)] \approx \underbrace{\frac{h^4}{4}\mu_2(K)^2 \left[m''(x) + 2m'(x)\frac{f'(x)}{f(x)}\right]^2}_{\text{bias}^2} + \underbrace{\frac{\sigma^2(x) R(K)}{n h f(x)}}_{\text{variance}}$$

where \(R(K) = \int K(u)^2\,du\) is the kernel roughness and \(f(x)\) is the input density. Optimal bandwidth minimising MISE:

$$h^* = \left(\frac{R(K)}{\mu_2(K)^2 \int [m''(x)]^2 f(x)\,dx}\right)^{1/5} n^{-1/5}$$
⚠️ Boundary Bias

At the boundary of the data range, the kernel is asymmetric — more training points lie on one side. This causes the estimate to be systematically biased toward the interior. Fixes include boundary kernels, local linear regression (which has zero boundary bias), or reflecting the data.

Connection to local polynomial regression

Nadaraya-Watson is equivalent to fitting a local constant polynomial — degree 0 — by weighted least squares at each query point \(x\):

$$\hat{\beta}_0(x) = \underset{\beta_0}{\operatorname{argmin}}\; \sum_{i=1}^n K_h(x-x_i)\,(y_i - \beta_0)^2$$

Setting derivative to zero gives \(\hat{\beta}_0 = \hat{m}(x)\). Local linear (\(p=1\)) and local polynomial (\(p=2,3,\ldots\)) extensions reduce bias near boundaries and at curvature extremes.

Code Trace
▼

Step through the annotated NumPy implementation. Active line highlighted in green as the algorithm progresses.

import numpy as np
def gaussian_kernel(u, h):
# Unnorm. Gaussian: K(u) = exp(-u²/2h²). Norm. factor cancels in NW ratio.
return np.exp(-0.5 * (u / h) ** 2)
def nadaraya_watson(x_q, x_data, y_data, h):
# Vectorised: compute all n kernel values at once → shape (n,)
weights = gaussian_kernel(x_q - x_data, h) # K_h(x - x_i) for all i
denom = weights.sum() # Σ K_h(x - x_i)
if denom < 1e-10: return np.nan # guard: query far from data
return np.dot(weights, y_data) / denom # Σ w_i y_i (normalised)
def fit_curve(x_data, y_data, h, n_grid=200):
x_grid = np.linspace(x_data.min(), x_data.max(), n_grid)
y_hat = [nadaraya_watson(x, x_data, y_data, h) for x in x_grid]
return x_grid, np.array(y_hat) # O(n · n_grid) total

✅ Use Nadaraya-Watson when

You have small-to-medium \(n\) (<10k), 1–2 input dimensions, no assumed functional form, and you want a fast non-parametric baseline with interpretable weights. Great for exploratory data analysis.

🚫 Avoid when

Dimensionality \(d \geq 4\) (curse of dimensionality: you need exponentially more data to maintain local density). Or when prediction speed matters — every query costs \(O(n)\). Or when you need confidence intervals (use Gaussian Processes instead).
