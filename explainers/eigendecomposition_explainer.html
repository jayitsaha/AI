Eigendecomposition: \(A = PDP^{-1}\)

Factoring a matrix into eigenvectors, eigenvalues, and their inverse — the spectral backbone of linear algebra
Foundational Lean Intermediate Linear Algebra Spectral Theory Must Know
1
What Is Eigendecomposition?
▾

Every square matrix encodes a linear transformation — it rotates, stretches, and shears vectors in space. Eigendecomposition asks: are there special directions the matrix merely scales without rotating? Those directions are eigenvectors, and the scaling factors are eigenvalues.

Formally, \(\mathbf{v}\) is an eigenvector of \(A\) with eigenvalue \(\lambda\) if:

$$A\mathbf{v} = \lambda \mathbf{v}$$

The matrix multiplies \(\mathbf{v}\) — yet the result is just \(\lambda\) times the same vector. No rotation, only scaling.

The Analogy

Imagine a funhouse mirror that stretches you tall without changing your horizontal position. Your vertical axis is an eigenvector (unchanged direction), and the stretch factor is the eigenvalue. The mirror's full effect can be understood by decomposing it into these stretch-only directions.

If a matrix \(A \in \mathbb{R}^{n \times n}\) has \(n\) linearly independent eigenvectors stacked as columns of \(P\), and their eigenvalues on the diagonal of \(D\), then:

$$A = PDP^{-1}$$

This is eigendecomposition — factoring \(A\) into a change-of-basis (\(P^{-1}\)), a pure diagonal scaling (\(D\)), and a change back (\(P\)). The beauty: in the eigenbasis, \(A\) is just multiplication by scalars.

Key Invariant

A matrix \(A\) is diagonalizable if and only if it has \(n\) linearly independent eigenvectors. This fails for defective matrices — those with repeated eigenvalues and insufficient eigenvectors (requiring Jordan normal form instead).

2
Finding Eigenvalues and Eigenvectors
▾

Step 1 — Characteristic Polynomial

We want non-zero \(\mathbf{v}\) satisfying \(A\mathbf{v} = \lambda \mathbf{v}\), equivalently \((A - \lambda I)\mathbf{v} = \mathbf{0}\). For this homogeneous system to have non-trivial solutions, the matrix \((A - \lambda I)\) must be singular:

$$\det(A - \lambda I) = 0$$

This is the characteristic equation. Expanding the determinant gives a degree-\(n\) polynomial in \(\lambda\) — the characteristic polynomial \(p(\lambda)\). Its roots are the eigenvalues.

Worked 2×2 Example

Take the matrix used throughout this explainer:

$$A = \begin{bmatrix} 3 & 1 \\ 0 & 2 \end{bmatrix}$$

Characteristic equation:

$$\det\begin{bmatrix} 3-\lambda & 1 \\ 0 & 2-\lambda \end{bmatrix} = (3-\lambda)(2-\lambda) - 0 = \lambda^2 - 5\lambda + 6 = 0$$

Factoring: \((\lambda - 3)(\lambda - 2) = 0\), giving \(\lambda_1 = 3\) and \(\lambda_2 = 2\).

Step 2 — Find Eigenvectors

For each eigenvalue, solve \((A - \lambda_i I)\mathbf{v} = \mathbf{0}\):

\(\lambda_1 = 3\): \((A - 3I)\mathbf{v} = \begin{bmatrix}0 & 1 \\ 0 & -1\end{bmatrix}\mathbf{v} = \mathbf{0}\) gives \(\mathbf{v}_1 = \begin{bmatrix}1 \\ 0\end{bmatrix}\)

\(\lambda_2 = 2\): \((A - 2I)\mathbf{v} = \begin{bmatrix}1 & 1 \\ 0 & 0\end{bmatrix}\mathbf{v} = \mathbf{0}\) gives \(\mathbf{v}_2 = \begin{bmatrix}-1 \\ 1\end{bmatrix}\)

Step 3 — Assemble P, D, P⁻¹

Stack eigenvectors as columns of \(P\), eigenvalues on the diagonal of \(D\):

$$P = \begin{bmatrix}1 & -1 \\ 0 & 1\end{bmatrix}, \quad D = \begin{bmatrix}3 & 0 \\ 0 & 2\end{bmatrix}, \quad P^{-1} = \begin{bmatrix}1 & 1 \\ 0 & 1\end{bmatrix}$$

Verification: \(PDP^{-1} = \begin{bmatrix}1&-1\\0&1\end{bmatrix}\begin{bmatrix}3&0\\0&2\end{bmatrix}\begin{bmatrix}1&1\\0&1\end{bmatrix} = \begin{bmatrix}3&1\\0&2\end{bmatrix} = A\) ✓

Defective Matrices — When This Fails

The matrix \(B = \begin{bmatrix}2 & 1 \\ 0 & 2\end{bmatrix}\) has characteristic polynomial \((\lambda - 2)^2 = 0\), giving only one eigenvalue \(\lambda = 2\) with algebraic multiplicity 2 but geometric multiplicity 1 (only one independent eigenvector \([1, 0]^\top\)). This matrix is defective and cannot be diagonalized — it requires a Jordan block \(J = \begin{bmatrix}2&1\\0&2\end{bmatrix}\) in the Jordan normal form.

The Power Formula and Why It Matters
▾

Matrix Powers via Eigendecomposition

One of the most powerful payoffs: computing \(A^k\) for large \(k\). Direct multiplication requires \(O(n^3)\) per step. But once we have \(A = PDP^{-1}\):

$$A^k = (PDP^{-1})^k = PD^kP^{-1}$$

Since \(D\) is diagonal, \(D^k\) is trivially computed — just raise each diagonal entry to the \(k\)th power:

$$D^k = \begin{bmatrix}\lambda_1^k & 0 \\ 0 & \lambda_2^k\end{bmatrix}$$

For our example \(A = \begin{bmatrix}3&1\\0&2\end{bmatrix}\) with \(\lambda_1=3, \lambda_2=2\):

$$A^k = \begin{bmatrix}1&-1\\0&1\end{bmatrix}\begin{bmatrix}3^k&0\\0&2^k\end{bmatrix}\begin{bmatrix}1&1\\0&1\end{bmatrix} = \begin{bmatrix}3^k & 3^k - 2^k \\ 0 & 2^k\end{bmatrix}$$

Verify at \(k=2\): \(\begin{bmatrix}9 & 9-4\\0&4\end{bmatrix} = \begin{bmatrix}9&5\\0&4\end{bmatrix}\). Direct: \(A^2 = \begin{bmatrix}3&1\\0&2\end{bmatrix}^2 = \begin{bmatrix}9&5\\0&4\end{bmatrix}\) ✓

Spectral Decomposition (Symmetric Matrices)

For symmetric matrices \(A = A^\top\), the spectral theorem guarantees real eigenvalues and orthogonal eigenvectors. Writing \(P = Q\) (orthogonal, so \(Q^{-1} = Q^\top\)):

$$A = Q\Lambda Q^\top = \sum_{i=1}^{n} \lambda_i \mathbf{q}_i \mathbf{q}_i^\top$$

Each term \(\lambda_i \mathbf{q}_i \mathbf{q}_i^\top\) is a rank-1 matrix — a projection onto the \(i\)-th eigenvector, scaled by \(\lambda_i\). The matrix \(A\) is literally the weighted sum of projections onto its eigenvectors. This is the foundation of PCA, SVD, and spectral methods.

Key Formula Summary

\(A\mathbf{v} = \lambda\mathbf{v}\) — eigenvalue equation
\(\det(A - \lambda I) = 0\) — characteristic equation (find \(\lambda\))
\(A = PDP^{-1}\) — eigendecomposition (general)
\(A = Q\Lambda Q^\top\) — spectral decomposition (symmetric \(A\))
\(A^k = PD^kP^{-1}\) — matrix powers
\(e^{At} = Pe^{Dt}P^{-1}\) — matrix exponential (ODEs, control)

Common Misconceptions
  • Order matters: The columns of \(P\) must match the corresponding diagonal entries of \(D\). Swapping an eigenvector column without swapping the eigenvalue gives a wrong factorization.
  • Not all matrices diagonalize: Only matrices with \(n\) independent eigenvectors. Complex eigenvalues are possible for real matrices (rotation matrices have no real eigenvectors).
  • Eigenvectors are not unique: Any non-zero scalar multiple of an eigenvector is also an eigenvector. The direction is unique, not the magnitude.

From-Scratch NumPy Implementation
▾

Below is a numerically correct implementation of eigendecomposition from scratch, matching every formula on this page. Active line is highlighted as you step through the visualization above.

import numpy as np
A = np.array([[3., 1.], [0., 2.]]) # our matrix
# Step 1: Solve det(A - λI) = 0 via characteristic polynomial
eigenvalues, P = np.linalg.eig(A)
# eigenvalues = [3., 2.] ← λ₁, λ₂
# P = [[1, -1], [0, 1]] ← eigenvectors as columns
D = np.diag(eigenvalues) # diagonal matrix of eigenvalues
P_inv = np.linalg.inv(P) # inverse of eigenvector matrix
# Verify: A = P @ D @ P_inv
A_reconstructed = P @ D @ P_inv
# A_reconstructed ≈ [[3, 1], [0, 2]] ✓
# Matrix power: A^k = P @ D^k @ P_inv
def matrix_power_via_eig(A, k):
vals, vecs = np.linalg.eig(A)
Dk = np.diag(vals ** k) # raise each eigenvalue to k
return vecs @ Dk @ np.linalg.inv(vecs)
A2 = matrix_power_via_eig(A, 2) # [[9, 5], [0, 4]]
A5 = matrix_power_via_eig(A, 5) # [[243, 211], [0, 32]]

Key Takeaways & When to Use
▾

Applications in ML/AI

  • PCA: Eigenvectors of the covariance matrix \(C = \frac{1}{n}X^\top X\) are principal components; eigenvalues give explained variance.
  • Spectral clustering: Eigenvectors of the graph Laplacian reveal cluster structure.
  • PageRank: The dominant eigenvector of the (stochastic) web link matrix.
  • Recurrent dynamics: Stability of RNN hidden states determined by eigenvalues of the recurrent weight matrix (spectral radius < 1 ⟹ stable).
  • Kernel methods: Mercer's theorem expresses kernels via eigenfunctions — SVMs, Gaussian processes.

Interview One-Liner

Eigendecomposition \(A = PDP^{-1}\) says: change to a coordinate system where A acts diagonally, scale each axis by the eigenvalue, then change back. It exists iff \(A\) has \(n\) independent eigenvectors; for symmetric matrices this is always true and \(P\) is orthogonal (\(P^{-1} = P^\top\)).

Red Flags in Interviews
  • Saying "every matrix has an eigendecomposition" — false for defective matrices.
  • Confusing eigendecomposition (square matrices only) with SVD (any matrix).
  • Forgetting that \(P\) columns must be ordered consistently with \(D\) diagonal.
