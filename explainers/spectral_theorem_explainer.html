Spectral Theorem for Symmetric / Hermitian Matrices

Every symmetric real matrix has real eigenvalues and an orthonormal eigenbasis — the foundation of PCA, covariance geometry, and quadratic forms
Intermediate Linear Algebra Math Foundations A = QΛQᵀ
1
Understanding the Spectral Theorem
▼

What is it? When a matrix is symmetric (equal to its own transpose), something remarkable happens: its eigenvalues are always real numbers, and its eigenvectors can always be chosen to be perfectly perpendicular (orthogonal) to each other. This is the Spectral Theorem — and it's why covariance matrices in PCA are so well-behaved.

Analogy: Imagine a stretching/squishing machine. For most machines, if you push a direction in, it might come out pointing somewhere completely different. But for a symmetric machine, there always exist special directions (the eigenvectors) that come out pointing exactly the same way — just stretched or squished by a real number (the eigenvalue). Even better, those special directions are always at right angles to each other, like the x-, y-, z-axes of a coordinate system you can discover hidden inside the matrix.

💡 If you remember one thing

Every symmetric real matrix \(A = A^\top\) factors as $$A = Q\Lambda Q^\top$$ where \(Q\) is orthogonal (\(QQ^\top = I\)) and \(\Lambda\) is diagonal with real entries. This is the eigendecomposition with a bonus: the eigenvectors are automatically orthonormal.

The Decomposition Internally
▼

What the Three Matrices Mean

For a symmetric \(n \times n\) matrix \(A\), the Spectral Theorem gives \(A = Q\Lambda Q^\top\). Each matrix has a clear geometric role:

  • Q — an orthogonal matrix whose columns are the eigenvectors \(q_1, \ldots, q_n\). These form a new, rotated coordinate system aligned with the matrix's "natural axes."
  • Λ — a diagonal matrix with real eigenvalues \(\lambda_1, \ldots, \lambda_n\) on the diagonal. These are the stretching factors along each eigenvector direction.
  • Qᵀ — the transpose of Q, which rotates coordinates from the standard basis to the eigenbasis.

Geometric Action on a Vector

Multiplying \(Ax\) can be read in three steps via \(A = Q\Lambda Q^\top\):

  1. \(Q^\top x\): Rotate \(x\) into the eigenbasis (find the components along each eigenvector).
  2. \(\Lambda(Q^\top x)\): Scale each component by the corresponding eigenvalue — stretch or compress independently along each axis.
  3. \(Q(\Lambda Q^\top x)\): Rotate back to the standard basis.

Why Symmetry Forces Orthogonality

The key proof step: if \(q_i, q_j\) are eigenvectors with distinct eigenvalues \(\lambda_i \neq \lambda_j\), then from \(A = A^\top\) we get \(\lambda_i \langle q_i, q_j \rangle = \langle Aq_i, q_j \rangle = \langle q_i, Aq_j \rangle = \lambda_j \langle q_i, q_j \rangle\). Since \(\lambda_i \neq \lambda_j\), we must have \(\langle q_i, q_j \rangle = 0\) — orthogonality is forced by symmetry.

🔑 Key Property

Symmetry → Real eigenvalues + orthogonal eigenvectors. This is NOT true for general matrices. The matrix \(\begin{bmatrix}0 & -1 \\ 1 & 0\end{bmatrix}\) has complex eigenvalues \(\pm i\). Symmetry is the special structure that eliminates complex eigenvalues and forces orthogonality.

3
Why It Works — The Math
▼

Eigenvalues are Real (Proof)

Let \(Av = \lambda v\), \(v \neq 0\), \(A = A^\top\). Consider \(\bar{v}^\top A v\) two ways:

$$\bar{v}^\top A v = \bar{v}^\top (\lambda v) = \lambda \|v\|^2$$

Also, since \(A = A^\top\) (and real, so \(A = \bar{A}\)): \(\overline{\bar{v}^\top A v} = v^\top A \bar{v} = v^\top (\bar{\lambda} \bar{v}) = \bar{\lambda}\|v\|^2\)

Since \(\bar{v}^\top Av\) is a scalar equal to its own conjugate (i.e. \(\bar{v}^\top Av \in \mathbb{R}\)), we get \(\lambda = \bar{\lambda}\), so \(\lambda \in \mathbb{R}\).

The Quadratic Form

The quadratic form \(f(x) = x^\top A x\) has a beautiful geometric meaning via the spectral decomposition. Writing \(x = \sum_i c_i q_i\) in the eigenbasis:

$$x^\top A x = x^\top (Q\Lambda Q^\top) x = (Q^\top x)^\top \Lambda (Q^\top x) = \sum_{i=1}^n \lambda_i c_i^2$$

where \(c_i = q_i^\top x\) are the coordinates of \(x\) in the eigenbasis. The level set \(\{x : x^\top A x = 1\}\) is an ellipsoid whose axes are the eigenvectors \(q_i\), with semi-axis lengths \(1/\sqrt{\lambda_i}\) (when all \(\lambda_i > 0\)).

Positive Definiteness Connection

$$A \succ 0 \iff \text{all eigenvalues } \lambda_i > 0 \iff x^\top Ax > 0 \text{ for all } x \neq 0$$
⚠️ Common Misconception

The spectral theorem guarantees orthonormal eigenvectors, but only when eigenvalues are distinct. If eigenvalue \(\lambda_k\) has multiplicity \(m > 1\) (a "repeated eigenvalue"), the eigenspace is \(m\)-dimensional and you can choose any orthonormal basis for it — but you must use Gram–Schmidt to orthonormalize. The theorem still holds; you just have a choice of basis.

Connection to Covariance Matrices in PCA

Any sample covariance matrix \(\Sigma = \frac{1}{n}X^\top X\) is symmetric positive semi-definite. By the Spectral Theorem, \(\Sigma = Q\Lambda Q^\top\). PCA simply reads off the eigenvectors (principal components) and eigenvalues (explained variance). The matrix \(Q\) rotates data to align with its natural axes of variation.

Key Takeaways & Connections
▼

When does the Spectral Theorem apply?

  • Symmetric real matrices \(A = A^\top\): eigenvectors are orthonormal, eigenvalues real
  • Hermitian complex matrices \(A = A^*\): eigenvectors unitary-orthogonal, eigenvalues real
  • Normal matrices \(AA^* = A^*A\): generalization — orthonormal eigenvectors but possibly complex eigenvalues

Applications across ML:

  • PCA — eigenvectors of the covariance matrix are principal components; eigenvalues give explained variance
  • Graph Laplacians — spectral clustering uses eigenvectors of the symmetric Laplacian \(L = D - W\)
  • Kernel methods — Mercer's theorem: symmetric PD kernels have spectral expansions
  • Optimization — curvature of loss = Hessian; Hessian is symmetric, its eigenvalues tell you convergence speed
  • Diffusion maps — spectral structure of symmetric diffusion operators
💡 The Big Picture

The Spectral Theorem is the reason covariance matrices are so tractable in ML. Any algorithm that needs to "understand the shape" of a distribution — its principal axes, its variance structure, its condition number — is implicitly exploiting the spectral theorem.

Code Trace — NumPy
▼
import numpy as np
# Symmetric matrix A
A = np.array([[3, 1],
[1, 3]]) # A == A.T ✓
# Spectral decomposition (use eigh for symmetric — guaranteed real, orthogonal)
eigenvalues, Q = np.linalg.eigh(A)
# eigenvalues = [2., 4.] (real, ascending order from eigh)
# Q columns = eigenvectors: Q[:,0]≈[-0.707, 0.707], Q[:,1]≈[0.707, 0.707]
# Verify: Q is orthogonal
np.allclose(Q @ Q.T, np.eye(2)) # True
# Verify: A = Q @ diag(eigenvalues) @ Q.T
Lambda = np.diag(eigenvalues)
A_reconstructed = Q @ Lambda @ Q.T
np.allclose(A, A_reconstructed) # True
# Quadratic form: for x on ellipse boundary, x.T @ A @ x = 1
x = np.array([0.5, 0.0]) # test point
qf = x.T @ A @ x # = 3*(0.5)^2 + 2*(1)*(0.5)*(0) + 3*(0)^2 = 0.75
# PCA application: covariance matrix spectral decomp
X_data = np.random.randn(100, 2) @ np.array([[2,1],[0,1]]) # correlated data
Sigma = np.cov(X_data.T) # symmetric PSD covariance
eigvals, eigvecs = np.linalg.eigh(Sigma) # principal components
explained_var = eigvals / eigvals.sum() # fraction of variance each PC explains
