Autoencoder-based Anomaly Detection

Unsupervised anomaly detection via reconstruction error thresholding
Advanced Unsupervised Learning Anomaly Detection Reconstruction Error · Threshold · Latent Space
1
Understanding the Concept
▾

Imagine you work at a factory and you've only ever seen normal products roll off the line. One day, a defective part appears. Even without a manual, you know it's wrong because it looks nothing like what you've memorised. Autoencoders do exactly this — they memorise the compact structure of normal data, then flag anything they can't reconstruct well.

An autoencoder is a neural network trained to compress its input into a low-dimensional "bottleneck" (the latent code \(z\)) and then decompress it back to the original. When trained exclusively on normal data, it learns to faithfully encode normal patterns. When an anomaly arrives, the latent space has no good representation for it, so the reconstruction is poor — yielding a large reconstruction error \(\|x - \hat{x}\|^2\).

Core Insight

Train only on normal data. At inference time, high reconstruction error = anomaly. The autoencoder has never seen anomalies, yet it detects them.

A scalar threshold \(\tau\) converts the continuous error into a binary label: points with \(\|x - \hat{x}\|^2 > \tau\) are flagged anomalous. This threshold is tuned on a small held-out validation set or set to a high quantile (e.g., 95th percentile) of training errors.

Key Property

No anomaly labels are needed during training. The signal comes entirely from the inability to reconstruct — a purely unsupervised criterion.

2
Architecture & Internal Mechanism
▾

Encoder \(f_\phi\): \(\mathbb{R}^d \to \mathbb{R}^k\)

A stack of linear + nonlinear layers that progressively compresses \(x \in \mathbb{R}^d\) to a bottleneck \(z \in \mathbb{R}^k\) where \(k \ll d\). Compression forces the encoder to retain only the most informative features of normal data.

Decoder \(g_\theta\): \(\mathbb{R}^k \to \mathbb{R}^d\)

A symmetric stack that expands \(z\) back to a reconstruction \(\hat{x} \in \mathbb{R}^d\). The decoder must "fill in" details from the compressed code — easy for familiar patterns, hard for unseen anomalous ones.

Training objective (MSE)

$$\mathcal{L}(\phi, \theta) = \frac{1}{N}\sum_{i=1}^{N} \|x_i - g_\theta(f_\phi(x_i))\|_2^2$$

All \(N\) training samples are normal. SGD/Adam minimises this loss, nudging both encoder and decoder weights to reconstruct normal points accurately.

Numerical Trace (2-D example)

Let \(d=2\), \(k=1\). Normal point \(x=[0.8, 0.6]\), anomaly \(x'=[3.5, -2.1]\).

  • Encode normal: \(z = \tanh(W_e x + b_e)\approx 0.82\). Decode: \(\hat{x}=[0.79, 0.61]\). Error = \((0.01)^2+(0.01)^2\approx 0.0002\).
  • Encode anomaly: \(z' = \tanh(W_e x' + b_e)\approx 0.97\) (saturated). Decode: \(\hat{x}'=[0.96, 0.72]\). Error = \((2.54)^2+(2.82)^2\approx 14.5\).
  • With threshold \(\tau=0.5\): normal flagged? No. Anomaly flagged? Yes.
Design Decision

Bottleneck dimensionality \(k\) is critical. Too large (\(k \approx d\)): the AE can memorise anomalies too. Too small: high reconstruction error even for normal points (underfitting). Typical: \(k \approx d/4\) to \(d/8\).

3
The Math Behind It
▾

Reconstruction Error as an Anomaly Score

For input \(x\), define the anomaly score:

$$s(x) = \|x - g_\theta(f_\phi(x))\|_2^2 = \sum_{j=1}^{d}(x_j - \hat{x}_j)^2$$

Threshold rule: \(\hat{y} = \mathbf{1}[s(x) > \tau]\), where \(\tau\) is chosen to control the false-positive rate on a clean validation set.

Why normal points reconstruct well

After training, the decoder has learned to span the manifold of normal data in latent space. Formally, the encoder projects \(x\) onto this manifold and the decoder maps it back. For \(x\) near the training manifold:

$$s(x) \approx d^2(x, \mathcal{M}_{\text{normal}})$$

where \(\mathcal{M}_{\text{normal}}\) is the learned data manifold. Anomalies lie far from \(\mathcal{M}_{\text{normal}}\), so \(s(x)\) is large.

Threshold Selection

Let \(\{s_i\}_{i=1}^N\) be training reconstruction errors (all normal). A common strategy:

$$\tau = \mu_s + k\,\sigma_s \quad (\text{e.g., } k=3 \Rightarrow \approx 99.7\% \text{ normal points below threshold})$$

Or use a held-out contamination-free validation set and sweep \(\tau\) over quantiles to maximise F1/AUROC.

Gradient Flow During Training

$$\frac{\partial \mathcal{L}}{\partial \theta} = -\frac{2}{N}\sum_i \frac{\partial g_\theta}{\partial \theta}^\top (x_i - \hat{x}_i)$$
$$\frac{\partial \mathcal{L}}{\partial \phi} = -\frac{2}{N}\sum_i \left(\frac{\partial g_\theta}{\partial z} \cdot \frac{\partial f_\phi}{\partial \phi}\right)^\top (x_i - \hat{x}_i)$$

Both encoder and decoder weights are trained jointly via backpropagation. The error signal \((x_i - \hat{x}_i)\) drives both to improve reconstruction of normal patterns.

Key Formula

Anomaly score: \(s(x) = \|x - g_\theta(f_\phi(x))\|_2^2\). Flag if \(s(x) > \tau\). Threshold: \(\tau = \mu_s + 3\sigma_s\) on training errors.

Interview Questions & Key Takeaways
▾

Q1 (Easy): Why do we train only on normal data?

Because anomaly labels are expensive or impossible to obtain, and anomaly classes are diverse. The AE's inability to reconstruct unseen patterns is the detection signal.

Q2 (Medium): How do you choose the bottleneck size?

Sweep \(k\) on a validation set with a small fraction of known anomalies; pick the value maximising AUROC. Rule of thumb: \(k \approx d/4\) to \(d/8\) for tabular data. Too large → memorisation; too small → underfitting.

Q3 (Hard): What are the failure modes of reconstruction-error detection?

1. Anomalies that happen to look reconstructable: if the anomaly lies in the span of normal data in latent space, the AE reconstructs it well (low error, missed). 2. Threshold sensitivity: without anomaly labels, threshold selection is ad hoc — a 3σ rule may miss clustered anomalies or flag too many normals. 3. Overfit bottleneck: if the AE is too expressive, it generalises to anomalies. Use regularisation or sparse coding.

Follow-up trap: "Can you just use a VAE instead?"

A VAE adds a KL regulariser that forces the latent space toward \(\mathcal{N}(0,I)\), giving smoother interpolations and better-calibrated scores, but reconstruction error is still the primary signal. VAE also enables ELBO-based anomaly scoring: \(s(x) = -\text{ELBO}(x) = \mathcal{L}_{\text{recon}} + \text{KL}\).

Key Takeaways
  • Train on normal only → reconstruction error is the anomaly score.
  • Threshold \(\tau\) converts score to label; tuned on validation data.
  • Bottleneck size controls the bias-variance of the anomaly detector.
  • Fails when anomalies lie on the same manifold as normal data.
  • Variants: sparse AE, VAE, convolutional AE for images, LSTM-AE for time series.

Comparison: AE vs other anomaly detectors

vs Isolation Forest: AE captures feature correlations; IForest ignores them. AE wins on high-dimensional correlated data (images, sensors). vs One-Class SVM: OCSVM needs hand-crafted kernel; AE learns features end-to-end. vs Statistical methods (z-score): AE captures non-linear manifolds; z-score only works for Gaussian univariate distributions.

From-Scratch Implementation
▾
import numpy as np
import torch, torch.nn as nn
class Autoencoder(nn.Module):
def __init__(self, d=32, k=4):
super().__init__()
self.encoder = nn.Sequential(
nn.Linear(d, 16), nn.ReLU(),
nn.Linear(16, k)) # bottleneck
self.decoder = nn.Sequential(
nn.Linear(k, 16), nn.ReLU(),
nn.Linear(16, d))
def forward(self, x):
z = self.encoder(x) # compress
x_hat = self.decoder(z) # reconstruct
return x_hat
def train(model, X_normal, epochs=50, lr=1e-3):
opt = torch.optim.Adam(model.parameters(), lr=lr)
loss_fn = nn.MSELoss()
for _ in range(epochs):
x_hat = model(X_normal)
loss = loss_fn(x_hat, X_normal) # only normal data!
opt.zero_grad(); loss.backward(); opt.step()
def anomaly_score(model, x):
with torch.no_grad():
x_hat = model(x)
return ((x - x_hat)**2).sum(dim=-1) # per-sample MSE
def set_threshold(model, X_normal, k=3):
scores = anomaly_score(model, X_normal)
mu, sigma = scores.mean(), scores.std()
return mu + k * sigma # 3-sigma rule
def predict(model, x, tau):
s = anomaly_score(model, x)
return (s > tau).int() # 1=anomaly, 0=normal
