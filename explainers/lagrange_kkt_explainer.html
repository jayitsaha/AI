Understanding Constrained Optimization
▼

What is it? Unconstrained optimization asks: "where is the lowest valley?" Constrained optimization adds a fence: "where is the lowest point you can reach without leaving the allowed region?" Lagrange multipliers and KKT conditions are the rigorous toolkit for answering this question — they tell you both where the optimum is and how hard the constraint is pushing at the solution.

Analogy: Imagine you want to find the coldest point on a hiking trail (the constraint is "stay on the trail"). If you could leave the trail, you might find a colder lake. But constrained to the trail, the coldest point is where the temperature contours are tangent to the trail — if they crossed, you could move along the trail and get colder. Lagrange's insight: at the optimum, the trail and the temperature contours must be tangent, meaning their gradients point in the same direction.

💡 If you remember one thing

At a constrained optimum, the gradient of the objective equals a scalar multiple of the gradient of the constraint: \(\nabla f(x^*) = \lambda \nabla g(x^*)\). This scalar \(\lambda\) is the Lagrange multiplier — it measures how much the optimal value would improve if you relaxed the constraint by one unit. KKT extends this to inequality constraints by adding sign conditions and complementary slackness.

How Lagrange Multipliers and KKT Work
▼

Equality Constraints — Lagrange Multipliers

For \(\min_x f(x)\) subject to \(g(x) = 0\), form the Lagrangian:

$$\mathcal{L}(x, \lambda) = f(x) - \lambda\, g(x)$$

Set both partial derivatives to zero: \(\nabla_x \mathcal{L} = 0\) gives \(\nabla f = \lambda \nabla g\); \(\partial \mathcal{L}/\partial \lambda = 0\) recovers the constraint \(g(x) = 0\). Together these \(n+1\) equations determine the \(n+1\) unknowns \((x, \lambda)\).

Why does this work? On the constraint surface \(g(x)=0\), any feasible direction \(v\) satisfies \(\nabla g \cdot v = 0\) (it lives in the tangent plane). For \(x^*\) to be a minimum, \(f\) must not decrease along any feasible direction: \(\nabla f \cdot v = 0\) for all \(v\) in the tangent plane. This is only possible if \(\nabla f\) is proportional to \(\nabla g\) — i.e., \(\nabla f = \lambda \nabla g\).

Inequality Constraints — KKT Conditions

For \(\min_x f(x)\) subject to \(g_i(x) \leq 0,\; i=1,\ldots,m\) and \(h_j(x) = 0,\; j=1,\ldots,p\), the KKT conditions are:

$$\nabla f(x^*) + \sum_{i=1}^m \mu_i \nabla g_i(x^*) + \sum_{j=1}^p \lambda_j \nabla h_j(x^*) = 0 \quad \text{(Stationarity)}$$
$$g_i(x^*) \leq 0 \quad \text{(Primal feasibility — inside region)}$$
$$\mu_i \geq 0 \quad \text{(Dual feasibility — multipliers non-negative)}$$
$$\mu_i \, g_i(x^*) = 0 \quad \text{(Complementary slackness)}$$

Complementary slackness is the key KKT insight: either the constraint is active (\(g_i = 0\), constraint "touches" the optimum) or its multiplier is zero (\(\mu_i = 0\), the constraint is irrelevant and doesn't affect the solution). You can't have both \(\mu_i > 0\) and \(g_i < 0\) — that would mean an inactive constraint is still "pushing."

🔑 Key Property: Sufficiency

KKT conditions are necessary for any local minimum under constraint qualifications (e.g., LICQ). They are sufficient for a global minimum when \(f\) is convex and the feasible set is convex — covering virtually all ML problems (SVM, logistic regression, LASSO, etc.).

Connection to SVM Dual

The hard-margin SVM primal is \(\min_{w,b} \tfrac{1}{2}\|w\|^2\) subject to \(y_i(w^\top x_i + b) \geq 1\). Rewrite as \(1 - y_i(w^\top x_i + b) \leq 0\). KKT stationarity gives \(w = \sum_i \alpha_i y_i x_i\); complementary slackness says \(\alpha_i > 0\) only for support vectors (points exactly on the margin). The Lagrangian, maximized over the dual variables \(\alpha_i \geq 0\), becomes the famous dual: \(\max_\alpha \sum_i \alpha_i - \tfrac{1}{2} \sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^\top x_j\). Replacing \(x_i^\top x_j\) with a kernel \(K(x_i, x_j)\) gives non-linear SVMs — all powered by KKT.

Full Mathematical Derivation
▼

Step-by-Step: Equality Constraint

Problem: Minimize \(f(x, y) = x^2 + y^2\) subject to \(g(x,y) = x + y - 1 = 0\).

Step 1 — Lagrangian:

$$\mathcal{L}(x, y, \lambda) = x^2 + y^2 - \lambda(x + y - 1)$$

Step 2 — Stationarity:

$$\frac{\partial \mathcal{L}}{\partial x} = 2x - \lambda = 0 \implies x = \frac{\lambda}{2}$$
$$\frac{\partial \mathcal{L}}{\partial y} = 2y - \lambda = 0 \implies y = \frac{\lambda}{2}$$

Step 3 — Primal feasibility recovers \(\lambda\):

$$x + y = 1 \implies \frac{\lambda}{2} + \frac{\lambda}{2} = 1 \implies \lambda = 1$$

Step 4 — Solution: \(x^* = y^* = \tfrac{1}{2}\), \(f(x^*) = \tfrac{1}{4}+\tfrac{1}{4} = \tfrac{1}{2}\).

Geometric check: \(\nabla f = [2x, 2y] = [1,1]\) and \(\lambda \nabla g = 1 \cdot [1,1] = [1,1]\). Equal — tangency condition confirmed ✓

Step-by-Step: Inequality Constraint (KKT)

Problem: Minimize \(f(x,y) = (x-2)^2 + (y-2)^2\) (closest point to \((2,2)\)) subject to \(g(x,y) = x^2 + y^2 - 1 \leq 0\) (inside unit disk).

Since \((2,2)\) lies outside the unit disk, the optimum is on the boundary \(g = 0\).

$$\mathcal{L}(x,y,\mu) = (x-2)^2 + (y-2)^2 + \mu(x^2+y^2-1)$$

Stationarity:

$$\frac{\partial \mathcal{L}}{\partial x} = 2(x-2) + 2\mu x = 0 \implies x(1+\mu) = 2 \implies x = \frac{2}{1+\mu}$$
$$\frac{\partial \mathcal{L}}{\partial y} = 2(y-2) + 2\mu y = 0 \implies y = \frac{2}{1+\mu}$$

By symmetry \(x^* = y^*\). Applying \(g = 0\):

$$2\left(\frac{2}{1+\mu}\right)^2 = 1 \implies (1+\mu)^2 = 8 \implies \mu = 2\sqrt{2}-1 \approx 1.828$$
$$x^* = y^* = \frac{2}{1+2\sqrt{2}-1} = \frac{2}{2\sqrt{2}} = \frac{1}{\sqrt{2}} \approx 0.707$$

KKT check: \(\mu \approx 1.828 \geq 0\) ✓ (dual feasibility); \(g(x^*) = 0\) ✓ (active constraint); \(\mu \cdot g = 0\) ✓ (complementary slackness).

⚠️ Sign Convention

Different textbooks use different sign conventions. When minimizing, some write \(\nabla f + \mu \nabla g = 0\) (multiplier added); others write \(\nabla f = \mu \nabla g\) (multiplier absorbed). The crucial rule: for \(g(x) \leq 0\) constraints with minimization, the KKT multipliers \(\mu_i \geq 0\). A negative multiplier signals an error in setup or an infeasible problem.

Second-Order Sufficiency

The bordered Hessian test confirms minima vs. saddle points. For one constraint, form:

$$\bar{H} = \begin{pmatrix} 0 & \nabla g^\top \\ \nabla g & \nabla^2 \mathcal{L} \end{pmatrix}$$

For our equality example: \(\nabla^2 \mathcal{L} = \nabla^2 f = 2I\) (positive definite), so the constraint manifold inherits positive curvature — confirmed minimum.

Key Takeaways & When to Use
▼

Use Lagrange multipliers when: your problem has equality constraints and you need the exact optimum (e.g., constrained MLE, optimal portfolio with budget constraint).

Use KKT conditions when: your problem has inequality constraints (e.g., SVM margin constraints, barrier methods in interior-point solvers, LASSO active-set methods).

Lagrange Multiplier Solver (NumPy)

import numpy as np
from scipy.optimize import fsolve
def lagrange_solve(f_grad, g, g_grad, x0, lam0):
"""Solve equality-constrained min f(x) s.t. g(x)=0 via Lagrange."""
def kkt_system(vars):
x, lam = vars[:-1], vars[-1]
# Stationarity: grad f - lambda * grad g = 0
stationarity = f_grad(x) - lam * g_grad(x)
# Primal feasibility: g(x) = 0
return np.append(stationarity, g(x))
sol = fsolve(kkt_system, np.append(x0, lam0), full_output=True)
x_star, lam_star = sol[0][:-1], sol[0][-1]
return x_star, lam_star
# Example: min x^2 + y^2 s.t. x + y = 1
f_grad = lambda x: 2 * x # [2x, 2y]
g = lambda x: x[0] + x[1] - 1 # scalar constraint
g_grad = lambda x: np.array([1.0, 1.0]) # constant gradient
x_star, lam = lagrange_solve(f_grad, g, g_grad, [0.3, 0.3], 0.5)
# x_star ≈ [0.5, 0.5], lam ≈ 1.0 (analytically exact)
# SVM dual (hard-margin) via quadratic programming
from scipy.optimize import minimize
def svm_dual(X, y):
"""Hard-margin SVM: maximize dual s.t. alpha>=0, sum(alpha*y)=0."""
n = len(y)
K = (X @ X.T) * np.outer(y, y) # kernel matrix
# Dual: max sum(alpha) - 0.5 * alpha^T K alpha
dual = lambda a: 0.5*(a @ K @ a) - a.sum() # negate for minimization
constraints = [{'type':'eq','fun': lambda a: a @ y}]
bounds = [(0, None)] * n
res = minimize(dual, np.ones(n)/n, constraints=constraints, bounds=bounds)
alpha = res.x
sv_mask = alpha > 1e-5 # KKT complementary slackness: support vectors
w = (alpha * y) @ X # primal weights from dual variables
b = np.mean(y[sv_mask] - X[sv_mask] @ w)
return w, b, alpha, sv_mask
⚠️ Production Gotchas

Constraint qualification failure: KKT can fail as necessary conditions if the LICQ (linear independence constraint qualification) is violated — e.g., two constraints both active with linearly dependent gradients. Always verify regularity.
Numerical precision: Complementary slackness holds to machine epsilon, not exactly. Use a tolerance (e.g., \(\alpha_i > 10^{-5}\)) to identify support vectors.
Non-convex pitfalls: KKT finds stationary points, not necessarily global optima. Use multiple restarts or global solvers for non-convex problems.
