Hidden State & the Recurrence Equation

How an RNN compresses an unbounded past into a fixed-size vector, one timestep at a time
Foundational Deep Learning Sequence Models O(T·d²) per sequence
1
Understanding the Hidden State
▼

What is it? A Recurrent Neural Network reads a sequence one element at a time (a word, an audio frame, a stock price). At every step it keeps a small "memory" vector — the hidden state \(h_t\) — that summarizes everything relevant it has seen so far. Each new input doesn't just get processed in isolation; it gets blended with that memory to produce an updated memory. The rule that performs this blending, applied identically at every timestep, is the recurrence equation.

Analogy: Imagine reading a novel and keeping a one-paragraph mental summary that you update after every sentence. You don't re-read the whole book each time — you take your current summary, fold in the new sentence, and rewrite a new (still one-paragraph) summary. That paragraph is the hidden state; the rule "read old summary + new sentence → write new summary" is the recurrence equation. The paragraph has a fixed size, so old details eventually get compressed away or overwritten.

💡 If you remember one thing

The hidden state is a fixed-size vector updated by the same learned function at every timestep: $$h_t = f(W_{hh}h_{t-1} + W_{xh}x_t + b_h)$$ Because the weights \(W_{hh}, W_{xh}, b_h\) are shared across time, an RNN of finite size can, in principle, process sequences of any length.

2
How the Recurrence Works Internally
▼

The Two Inputs to Every Step

At timestep \(t\), the cell receives two things: the current input \(x_t \in \mathbb{R}^{d_x}\) and the previous hidden state \(h_{t-1} \in \mathbb{R}^{d_h}\) (with \(h_0\) usually initialized to the zero vector). It produces a pre-activation by linearly combining both, then squashes the result:

$$z_t = W_{xh}x_t + W_{hh}h_{t-1} + b_h \qquad h_t = f(z_t) = \tanh(z_t)$$

\(W_{xh}\) (shape \(d_h \times d_x\)) projects the input into hidden space; \(W_{hh}\) (shape \(d_h \times d_h\)) propagates the previous memory forward; \(b_h\) is a learned bias. \(\tanh\) is the classic choice because it is zero-centered and bounds \(h_t\) to \((-1,1)\), which keeps the recurrent dynamics numerically stable across many steps (\(\text{ReLU}\) or gated \(\text{LSTM/GRU}\) cells are common modern alternatives).

Weight Sharing = Unrolling in Time

If you "unroll" the recursion for \(T\) steps, you get a deep feedforward computation graph — one layer per timestep — but every layer reuses the exact same \(W_{xh}, W_{hh}, b_h\). This is the single most important design decision in an RNN: parameters do not grow with sequence length, so a model trained on 10-token sequences can, structurally, run on a 10,000-token sequence.

Reading Out a Prediction

The hidden state itself is rarely the final answer. A separate output head reads it out at each step (or just at the last step): \(y_t = W_{hy}h_t + b_y\), optionally followed by softmax for classification. \(h_t\) is the model's entire compressed belief about the sequence so far — everything the output layer is allowed to see.

🔑 Key Property

The hidden state is a sufficient-statistic bottleneck: \(h_t\) has fixed dimension \(d_h\) regardless of how long the prefix \(x_1,\dots,x_t\) is. All information the network can use about the past must be squeezed through this \(d_h\)-dimensional pipe — this is both the source of RNNs' compactness and their biggest limitation (long-range information gets overwritten).

3
Why It Works — Unrolling & Backprop Through Time
▼

Unrolling the Recursion

Applying the recurrence repeatedly from \(h_0\) exposes \(h_t\) as a nested composition of every input seen so far:

$$h_t = f\big(W_{hh}\,f(W_{hh}\,f(\cdots) + W_{xh}x_{t-1} + b_h) + W_{xh}x_t + b_h\big)$$

This is exactly a \(t\)-layer feedforward network with tied weights — which is why RNNs are trained with Backpropagation Through Time (BPTT): unroll for \(T\) steps, run ordinary backprop on the resulting DAG, then sum the gradient contributions to the shared \(W_{hh}, W_{xh}, b_h\) from every timestep.

Gradient of the Loss Through Time

For a loss \(L = \sum_t L_t\), the gradient flowing back to an earlier hidden state \(h_k\) from a later loss \(L_t\) (\(t>k\)) requires the chain rule through every intermediate step:

$$\frac{\partial L_t}{\partial h_k} = \frac{\partial L_t}{\partial h_t}\prod_{i=k+1}^{t}\frac{\partial h_i}{\partial h_{i-1}}, \qquad \frac{\partial h_i}{\partial h_{i-1}} = \text{diag}\big(1-h_i^2\big)\,W_{hh}$$

(using \(f=\tanh\), so \(f'(z_i) = 1-\tanh^2(z_i) = 1-h_i^2\)). Each factor \(\frac{\partial h_i}{\partial h_{i-1}}\) is the local Jacobian of one recurrent step; the gradient across \(t-k\) steps is a product of \(t-k\) Jacobian matrices.

⚠️ Vanishing / Exploding Gradients

Because gradients through time are a long product of Jacobians, their norm behaves roughly like \(\|W_{hh}\|^{t-k}\). If the dominant eigenvalue of \(W_{hh}\) (scaled by \(\tanh'\) saturation) is \(<1\), the product shrinks toward zero exponentially (vanishing gradients — the network "forgets" long-range dependencies). If it's \(>1\), the product blows up (exploding gradients — training diverges, usually fixed with gradient clipping). This single fact motivated LSTM and GRU gating mechanisms, which add near-identity "gradient highways."

Key Takeaways
▼

When the plain recurrence works well:

  • Short-to-medium sequences where long-range dependencies are not critical
  • Streaming / online settings where you must process one token at a time with O(1) memory
  • As a building block inside gated cells (LSTM/GRU still contain this same linear+nonlinearity recurrence, just wrapped in gates)

Where it breaks down:

  • Long sequences — vanishing gradients prevent learning dependencies spanning many steps
  • Tasks needing random access to any past position — the fixed-size \(h_t\) bottleneck forces lossy compression
  • Large-scale parallel training — the recurrence is inherently sequential (step \(t\) needs step \(t-1\)), unlike attention
💡 Hierarchy

Vanilla RNN (this equation) → LSTM/GRU (add gates that let \(\partial h_i/\partial h_{i-1}\) stay near identity) → Attention/Transformers (drop recurrence entirely; every position can look directly at every other position, at the cost of \(O(T^2)\) computation).

import numpy as np
# Weights are SHARED across every timestep
Wxh = np.array([[0.5, -0.3], [0.2, 0.8]]) # d_h x d_x
Whh = np.array([[0.1, 0.4], [-0.2, 0.3]]) # d_h x d_h
Why = np.array([[0.6, -0.5], [0.3, 0.2]]) # d_y x d_h
bh = np.array([0.1, -0.1])
by = np.array([0.05, -0.05])
x_seq = [np.array([1,0]), np.array([0,1]), np.array([1,1])]
h = np.zeros(2) # h_0
hidden_states, outputs = [], []
for x_t in x_seq:
z = Wxh @ x_t + Whh @ h + bh # recurrence equation
h = np.tanh(z) # new hidden state
y = Why @ h + by # readout
hidden_states.append(h); outputs.append(y)
# --- Backprop through time (BPTT), simplified ---
dh_next = np.zeros(2)
for t in reversed(range(len(x_seq))):
dtanh = 1 - hidden_states[t]**2 # f'(z_t)
dh = dtanh * (Why.T @ d_out[t] + dh_next) # chain rule
dWhh += np.outer(dh, hidden_states[t-1])
dh_next = Whh.T @ dh # propagate to t-1
