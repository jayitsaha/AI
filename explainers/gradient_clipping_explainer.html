Gradient Clipping

Taming exploding gradients — clip-by-value vs clip-by-norm, with norm-ball geometry
Intermediate Optimization Training Dynamics Must Know
1
Understanding the Concept
▶
If you remember one thing

Clip-by-norm rescales the whole gradient vector when its \(\ell_2\) norm exceeds a threshold — preserving direction. Clip-by-value clamps each component independently — distorting direction but bounding every weight update independently.

When you train a deep network, the gradient \(\mathbf{g} = \nabla_\theta \mathcal{L}\) tells each weight how much to change. In networks with many layers — especially recurrent networks (RNNs, LSTMs) and deep Transformers — gradients can grow exponentially large through repeated matrix multiplications. A gradient with norm 10 000 will destroy your weights in a single update.

Gradient clipping is a simple surgical fix: before applying the optimizer step, detect whether the gradient is "too large" and scale it back. The two canonical strategies are clip-by-value (truncate each component) and clip-by-norm (rescale the whole vector).

Think of it like a speed limiter on a car. Clip-by-value puts a cap on each wheel independently — the car may swerve. Clip-by-norm limits the overall speed while keeping the heading constant — safer and more principled.

Key Invariant

Clip-by-norm is the unique projection of \(\mathbf{g}\) onto the \(\ell_2\)-ball \(\{\mathbf{v} : \|\mathbf{v}\|_2 \le c\}\). It is the closest vector inside the ball to \(\mathbf{g}\), measured in Euclidean distance, and it perfectly preserves gradient direction.

2
Two Clipping Strategies
▶

Strategy A — Clip by Value

Each component of the gradient vector is independently clamped to the interval \([-c, c]\):

$$g'_i = \operatorname{clip}(g_i,\,-c,\,c) = \max(-c,\,\min(c,\,g_i))$$

Example. Let \(\mathbf{g} = [3.5,\,-0.2,\,8.1,\,-4.7]\) and \(c = 1.0\). Then:

$$\mathbf{g}' = [1.0,\,-0.2,\,1.0,\,-1.0]$$

Notice that the component \(g_2 = -0.2\) is unchanged (it is already within \([-1,1]\)), but \(g_3 = 8.1\) is hard-truncated to \(1.0\). This changes the direction of \(\mathbf{g}\) — the resulting update no longer points in the steepest-descent direction.

Direction Distortion

After clip-by-value, \(\mathbf{g}'/\|\mathbf{g}'\|_2\) is generally not parallel to \(\mathbf{g}/\|\mathbf{g}\|_2\). The optimizer no longer descends in the true gradient direction.

Strategy B — Clip by Norm

Compute the global \(\ell_2\) norm of the gradient. If it exceeds threshold \(c\), rescale the entire vector uniformly:

$$\mathbf{g}' = \begin{cases} \mathbf{g} & \text{if } \|\mathbf{g}\|_2 \le c \\ \dfrac{c}{\|\mathbf{g}\|_2}\,\mathbf{g} & \text{if } \|\mathbf{g}\|_2 > c \end{cases}$$

Example. Same \(\mathbf{g} = [3.5,\,-0.2,\,8.1,\,-4.7]\), \(\|\mathbf{g}\|_2 \approx 10.00\), \(c = 1.0\):

$$\mathbf{g}' = \frac{1.0}{10.00}\,[3.5,\,-0.2,\,8.1,\,-4.7] \approx [0.350,\,-0.020,\,0.810,\,-0.470]$$

The direction is identical to \(\mathbf{g}\), and \(\|\mathbf{g}'\|_2 = 1.0\) exactly. This is the standard choice in modern practice (PyTorch's clip_grad_norm_).

The Math: Projection onto a Norm Ball
▶

Clip-by-norm has a clean geometric interpretation as a projection onto the \(\ell_2\)-ball. Define the feasible set \(\mathcal{B}(c) = \{\mathbf{v} \in \mathbb{R}^d : \|\mathbf{v}\|_2 \le c\}\). The projected gradient is:

$$\mathbf{g}' = \Pi_{\mathcal{B}(c)}(\mathbf{g}) = \underset{\mathbf{v}\,:\,\|\mathbf{v}\|_2 \le c}{\operatorname{argmin}} \|\mathbf{g} - \mathbf{v}\|_2$$

Proof that the formula \(\mathbf{g}' = c\,\mathbf{g}/\|\mathbf{g}\|_2\) is correct. For any \(\mathbf{v}\) with \(\|\mathbf{v}\|_2 = c\):

$$\|\mathbf{g} - \mathbf{v}\|_2^2 = \|\mathbf{g}\|_2^2 - 2\,\mathbf{g}^\top\mathbf{v} + \|\mathbf{v}\|_2^2 \ge \|\mathbf{g}\|_2^2 - 2c\|\mathbf{g}\|_2 + c^2 = \bigl(\|\mathbf{g}\|_2 - c\bigr)^2$$

The bound uses Cauchy-Schwarz: \(\mathbf{g}^\top\mathbf{v} \le \|\mathbf{g}\|_2\|\mathbf{v}\|_2 = c\|\mathbf{g}\|_2\). Equality holds when \(\mathbf{v} = c\,\mathbf{g}/\|\mathbf{g}\|_2\) — the rescaled gradient. So the minimum distance from \(\mathbf{g}\) to the ball surface is \(\|\mathbf{g}\|_2 - c\), achieved exactly at the rescaled point.

Why Exploding Gradients Happen in RNNs

In an RNN, the hidden state update is \(\mathbf{h}_t = \tanh(W\mathbf{h}_{t-1} + U\mathbf{x}_t)\). The gradient of the loss \(\mathcal{L}\) with respect to \(\mathbf{h}_0\) involves products of Jacobians:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{h}_0} = \prod_{t=1}^{T} \frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_{t-1}} \cdot \frac{\partial \mathcal{L}}{\partial \mathbf{h}_T}$$

Each factor \(\partial \mathbf{h}_t/\partial \mathbf{h}_{t-1} = \operatorname{diag}(\tanh'(\cdot))\,W\). If the largest singular value of \(W\) exceeds 1, these products grow exponentially with \(T\). For a sequence of length 100, a singular value of 1.02 gives \(1.02^{100} \approx 7.2\) — but for real weights the blow-up is far worse.

Why Clipping Works

Clipping does not fix the root cause (poorly conditioned weight matrices), but it enforces a global upper bound on the step size \(\|\Delta\theta\| = \eta\|\mathbf{g}'\|_2 \le \eta c\). This keeps parameter updates bounded, stabilising training until the model learns more moderate gradients.

The Update Rule After Clipping

The full optimizer step (for vanilla SGD with clip-by-norm) is:

$$\theta_{t+1} = \theta_t - \eta \cdot \frac{\min\!\bigl(c,\,\|\mathbf{g}_t\|_2\bigr)}{\|\mathbf{g}_t\|_2}\,\mathbf{g}_t$$

For Adam/AdamW, clipping is applied to the raw gradient before the Adam moment estimates are updated — the clipped gradient replaces \(\mathbf{g}_t\) everywhere in the Adam update equations.

Key Takeaways & When to Use
▶
Decision Rule

Default choice: clip-by-norm with max_norm = 1.0 (Transformers) or 5.0 (RNNs). Use clip-by-value only when you need per-parameter bounds independent of dimensionality (rare; some RL/policy-gradient settings).

  • Use clip-by-norm for sequence models (RNN, LSTM, GRU, Transformer). It is the standard in GPT-2/3/4, T5, BERT fine-tuning. PyTorch default: max_norm=1.0.
  • Use clip-by-value in policy-gradient RL where each gradient component maps to a distinct action dimension and you want independent bounds.
  • Monitor the gradient norm during training. Frequent clipping (>10% of steps) signals learning rate is too high, or the model architecture needs attention (e.g., better initialisation, gradient checkpointing).
  • Not a cure for vanishing gradients — clipping only prevents the exploding direction. Use skip connections, layer-norm, or LSTMs for vanishing issues.
  • Related topics: Gradient vanishing, LSTM gates, Adam optimizer, layer normalisation, learning rate warmup.

Code Trace — PyTorch Implementation
▶

The annotated code trace below shows the active line highlighted as you step through it.

import torch
import torch.nn as nn
model = nn.LSTM(input_size=128, hidden_size=256, num_layers=2, batch_first=True)
optimizer = torch.optim.Adam(model.parameters(), lr=3e-4)
loss = criterion(outputs, targets) # forward pass + loss computation
optimizer.zero_grad() # clear previous gradients
loss.backward() # backprop: computes raw g for all params
# --- CLIP BY NORM (preferred) ---
torch.nn.utils.clip_grad_norm_( # operates on ALL parameters jointly
model.parameters(),
max_norm=1.0, # threshold c
norm_type=2.0 # L2 norm (default)
) # returns: total_norm before clipping
# --- CLIP BY VALUE (alternative) ---
# torch.nn.utils.clip_grad_value_(model.parameters(), clip_value=1.0)
optimizer.step() # apply clipped gradient update

Key insight: clip_grad_norm_ concatenates all parameter gradients into one virtual vector, computes its global L2 norm, and rescales proportionally if the norm exceeds max_norm. The rescaling factor is the same for every parameter tensor.

Common Gotcha

Call loss.backward() BEFORE clipping. Calling optimizer.zero_grad() AFTER clipping will erase the clipped gradients. Order: forward → zero_grad → backward → clip → step.
