Understanding the Concept
▾

What Is a Mixture Distribution?

Imagine a city where some people are very short (children), some are medium height, and some are tall (adults). If you measured the height of a random person, the overall histogram would look like multiple humps — not a single bell curve. That multimodal shape is a mixture distribution: a population made of sub-populations, each with its own statistics.

Formally, a mixture distribution combines \(K\) component distributions, each weighted by a mixing proportion \(\pi_k\). The density of the mixture is:

$$p(x) = \sum_{k=1}^{K} \pi_k \, p_k(x)$$

where \(\pi_k \geq 0\) and \(\sum_k \pi_k = 1\). A Gaussian Mixture Model (GMM) uses Gaussian (normal) components, so each \(p_k\) is a Gaussian \(\mathcal{N}(x \mid \mu_k, \Sigma_k)\).

Key Insight

GMMs are universal approximators of smooth densities — with enough components, any smooth probability density can be approximated arbitrarily well. This makes them the go-to choice for density estimation when the true distribution is unknown but complex.

Real-World Analogy

A GMM is like a music playlist that blends tracks from three genres (jazz, pop, classical), where each genre has its own "sound" (mean and spread). When you hear a random song, it was drawn from one of the three genres with some probability. You can't tell which genre just from listening — you have to infer it. That inference is exactly what the EM algorithm does.

If You Remember One Thing

A GMM assigns each data point a soft membership over \(K\) Gaussian clusters. The EM algorithm alternates between computing these soft memberships (E-step) and updating the Gaussian parameters to best explain them (M-step) until convergence.

2
How It Works Internally — EM Algorithm
▾

The Hidden Variable Perspective

Each observation \(x_n\) was secretly generated by one component. We introduce a latent variable \(z_n \in \{1, \ldots, K\}\) indicating which component was responsible. The joint model is:

$$p(x_n, z_n = k) = \pi_k \, \mathcal{N}(x_n \mid \mu_k, \Sigma_k)$$

We observe only \(x_n\); we never see \(z_n\). This is the incomplete data problem. Direct maximum likelihood of \(p(x_n)\) involves \(\log \sum_k\), which has no closed form. EM sidesteps this by working with the expected complete-data log-likelihood.

E-Step: Compute Responsibilities

Given current parameters \(\theta^{(t)} = \{\pi_k, \mu_k, \Sigma_k\}\), compute the posterior probability that component \(k\) generated \(x_n\):

$$r_{nk} = \frac{\pi_k \, \mathcal{N}(x_n \mid \mu_k, \Sigma_k)}{\displaystyle\sum_{j=1}^{K} \pi_j \, \mathcal{N}(x_n \mid \mu_j, \Sigma_j)}$$

These \(r_{nk}\) are called responsibilities. They are soft assignments: \(r_{nk} \in [0,1]\) and \(\sum_k r_{nk} = 1\) for each \(n\). Hard K-means can be seen as taking \(r_{nk} \in \{0,1\}\) (argmax assignment).

M-Step: Update Parameters

Define the effective count of each component: \(N_k = \sum_n r_{nk}\). Then update:

$$\mu_k^{\text{new}} = \frac{1}{N_k} \sum_{n=1}^{N} r_{nk} \, x_n$$
$$\Sigma_k^{\text{new}} = \frac{1}{N_k} \sum_{n=1}^{N} r_{nk} \, (x_n - \mu_k^{\text{new}})(x_n - \mu_k^{\text{new}})^\top$$
$$\pi_k^{\text{new}} = \frac{N_k}{N}$$

Each update is a weighted average, where data points are weighted by their responsibility to that component. The M-step has closed-form solutions because the complete-data log-likelihood decomposes over components.

⚠ Failure Mode: Singularities

If a component captures just one point, its variance collapses to 0, causing the likelihood to go to infinity — a degenerate solution. Fix: add a small regularization \(\Sigma_k \leftarrow \Sigma_k + \epsilon I\), or use a Bayesian GMM with a Wishart prior on \(\Sigma_k\).

Convergence

EM is guaranteed to monotonically increase the log-likelihood \(\ell(\theta) = \sum_n \log p(x_n \mid \theta)\) at every iteration. It converges to a local maximum (not necessarily global). In practice, run multiple random restarts and keep the solution with highest final \(\ell\).

3
The Math Behind It
▾

Log-Likelihood and the Objective

The observed-data log-likelihood for \(N\) i.i.d. observations is:

$$\ell(\theta) = \sum_{n=1}^{N} \log \left[ \sum_{k=1}^{K} \pi_k \, \mathcal{N}(x_n \mid \mu_k, \Sigma_k) \right]$$

The \(\log \sum\) is intractable for direct optimization. EM uses the Evidence Lower BOund (ELBO). By Jensen's inequality, for any distribution \(q(z)\):

$$\log p(x) \geq \mathbb{E}_{q(z)}[\log p(x, z)] - \mathbb{E}_{q(z)}[\log q(z)] = \mathcal{L}(q, \theta)$$

E-step: maximize \(\mathcal{L}\) over \(q\) holding \(\theta\) fixed → optimal \(q^*(z_n = k) = r_{nk} = p(z_n = k \mid x_n, \theta)\). M-step: maximize \(\mathcal{L}\) over \(\theta\) holding \(q\) fixed.

Why M-Step Has Closed Form

After the E-step, the expected complete-data log-likelihood is:

$$Q(\theta \mid \theta^{(t)}) = \sum_{n,k} r_{nk} \left[ \log \pi_k + \log \mathcal{N}(x_n \mid \mu_k, \Sigma_k) \right]$$

This separates over components. For each \(k\), optimizing over \(\mu_k\) gives a weighted mean; over \(\Sigma_k\) gives a weighted scatter matrix; over \(\pi_k\) (with constraint \(\sum \pi_k = 1\)) via Lagrange multiplier gives \(\pi_k = N_k / N\). All closed-form.

BIC for Model Selection

To choose \(K\), use the Bayesian Information Criterion:

$$\text{BIC} = -2\ell(\hat{\theta}) + d_K \log N$$

where \(d_K\) is the number of free parameters (for full covariance: \(d_K = K-1 + Kd + K \cdot \frac{d(d+1)}{2}\) for \(d\)-dimensional data). Lower BIC is better. BIC penalizes model complexity, preventing overfitting by adding too many components.

Key Formula Summary

Full GMM density for \(d\)-dimensional data:

\(p(x) = \sum_{k=1}^K \pi_k \cdot \mathcal{N}(x \mid \mu_k, \Sigma_k)\) where \(\mathcal{N}(x \mid \mu, \Sigma) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}} \exp\!\left(-\frac{1}{2}(x-\mu)^\top \Sigma^{-1}(x-\mu)\right)\)

Key Takeaways & When to Use
▾

When to Use GMMs

  • Density estimation: When data is multimodal and you need a smooth generative model, not just cluster labels.
  • Soft clustering: When data points plausibly belong to multiple clusters — GMM gives probabilistic assignments, not hard labels.
  • Anomaly detection: Points with very low \(p(x)\) under the fitted GMM are outliers.
  • Generative modelling: Sample new data by first drawing \(z \sim \text{Cat}(\pi)\), then \(x \sim \mathcal{N}(\mu_z, \Sigma_z)\).

Comparison: GMM vs K-Means

DimensionK-MeansGMM
Assignment typeHard (one cluster per point)Soft (probabilities)
Cluster shapeSpherical (Euclidean distance)Elliptical (covariance-aware)
OutputCluster labelsPosterior probabilities + generative model
ObjectiveMinimize within-cluster varianceMaximize log-likelihood
Outlier sensitivityHighModerate (can add low-weight component)
Special caseGMM with spherical Σ, T→0General

Covariance Types

  • Full: Each component has its own arbitrary \(\Sigma_k\) — most expressive, most parameters.
  • Diagonal: \(\Sigma_k = \text{diag}(\sigma_{k1}^2, \ldots, \sigma_{kd}^2)\) — axis-aligned ellipses, fewer parameters.
  • Spherical: \(\Sigma_k = \sigma_k^2 I\) — circles, minimal parameters (analogous to K-means).
  • Tied: All components share one \(\Sigma\) — useful with small datasets.
Connection to Related Topics

GMMs connect to: EM algorithm (the fitting procedure), K-means (hard-assignment limit), Bayesian GMM / DPGMM (non-parametric — automatically infers K), VAEs (continuous latent variable generalization), HMMs (GMM observations over time sequences).

▾

From-Scratch NumPy Implementation

import numpy as np
from scipy.stats import multivariate_normal
def fit_gmm(X, K, max_iter=100, tol=1e-6, reg=1e-6):
N, D = X.shape
# ── Initialize ──────────────────────────────────────────
idx = np.random.choice(N, K, replace=False)
mus = X[idx].copy() # shape (K, D)
sigmas = [np.eye(D)] * K # (K, D, D)
pis = np.ones(K) / K # mixing weights
prev_ll = -np.inf
for it in range(max_iter):
# ── E-step: compute responsibilities ────────────────
R = np.zeros((N, K))
for k in range(K):
R[:, k] = pis[k] * multivariate_normal.pdf(
X, mean=mus[k], cov=sigmas[k])
# Normalize across components
R_sum = R.sum(axis=1, keepdims=True) # (N, 1)
R /= R_sum # r_nk in [0,1]
# ── M-step: update parameters ───────────────────────
Nk = R.sum(axis=0) # effective counts
for k in range(K):
mus[k] = (R[:, k:k+1] * X).sum(0) / Nk[k]
diff = X - mus[k] # (N, D)
sigmas[k] = (R[:, k:k+1] * diff).T @ diff / Nk[k]
sigmas[k] += reg * np.eye(D) # regularize!
pis = Nk / N
# ── Log-likelihood ───────────────────────────────────
ll = np.log(R_sum).sum()
if abs(ll - prev_ll) < tol: break
prev_ll = ll
return pis, mus, sigmas, R

Production: sklearn GaussianMixture

from sklearn.mixture import GaussianMixture
import numpy as np
# Fit GMM (BIC-optimal K selection)
bics = []
for k in range(1, 10):
gm = GaussianMixture(n_components=k, covariance_type='full',
n_init=5, random_state=42)
gm.fit(X)
bics.append(gm.bic(X))
K_best = np.argmin(bics) + 1
gm = GaussianMixture(n_components=K_best, covariance_type='full',
n_init=10, random_state=42).fit(X)
probs = gm.predict_proba(X) # soft assignments (N, K)
labels = gm.predict(X) # hard assignments via argmax
log_px = gm.score_samples(X) # log p(x_n) per point
new_X = gm.sample(100)[0] # generate 100 new points
# ⚠ Gotcha: covariance_type='diag' is faster but restricts
# cluster shapes to axis-aligned ellipses. Use 'full' unless
# N is small relative to D (risk of singular covariance).
