Understanding Undirected Graphical Models
▾

A Markov Random Field (MRF), also called an undirected graphical model or Gibbs random field, encodes a joint probability distribution over a set of random variables using an undirected graph. Each node is a variable; edges express statistical affinity — not causal direction. If two nodes have no edge, they are conditionally independent given their common neighbors.

Key Concept — Factorization over Cliques

The joint distribution factorizes as a product of clique potentials, normalized by the partition function \(Z\):

$$p(\mathbf{x}) = \frac{1}{Z} \prod_{C \in \mathcal{C}} \psi_C(\mathbf{x}_C), \qquad Z = \sum_{\mathbf{x}} \prod_{C \in \mathcal{C}} \psi_C(\mathbf{x}_C)$$

Each clique potential \(\psi_C \geq 0\) is a non-negative function of the variables in clique \(C\); \(Z\) is the normalizing constant that makes \(p\) a valid distribution.

Real-world analogy. Imagine pixels in an image. Nearby pixels tend to have similar colors — but the influence is mutual; there is no single "source" causing the others. MRFs model exactly this type of symmetric, local correlation, which is why they underpin image segmentation (MRF-MAP labeling), statistical physics (Ising model), and social network analysis.

If you remember one thing

MRFs factorize over cliques via non-negative potentials; a global normalizer \(Z\) is required. This \(Z\) is the source of all computational hardness — computing it exactly is #P-hard in general graphs.

Clique Potentials, Pairwise MRFs & the Markov Blanket
▾

A clique is a fully-connected subgraph. The Hammersley–Clifford theorem (1971) establishes that any strictly positive distribution that satisfies the global Markov property on a graph \(G\) can be written as a product of potentials over the maximal cliques of \(G\).

Pairwise MRF. The most common special case restricts potentials to unary and pairwise terms:

$$p(\mathbf{x}) = \frac{1}{Z} \prod_{i} \psi_i(x_i) \prod_{(i,j)\in\mathcal{E}} \psi_{ij}(x_i, x_j)$$

where \(\mathcal{E}\) is the edge set. Unary potentials encode per-node preferences; pairwise potentials encode pairwise compatibility.

Exponential family / Gibbs form. Writing \(\psi_C = \exp(-E_C)\) gives the energy-based form: \(p(\mathbf{x}) = \frac{1}{Z}\exp\!\bigl(-\sum_C E_C(\mathbf{x}_C)\bigr)\). The negative log of the unnormalized density is the energy; lower energy ↔ higher probability.

Markov Blanket in an Undirected Graph

For a node \(v\) in an undirected graph, the Markov blanket is simply its set of immediate neighbors \(\mathcal{N}(v)\). Given \(\mathcal{N}(v)\), node \(v\) is conditionally independent of all other nodes:

$$p(x_v \mid \mathbf{x}_{-v}) = p(x_v \mid x_{\mathcal{N}(v)})$$

This is simpler than in directed BNs, where the Markov blanket includes parents, children, and co-parents.

Contrast with Directed Bayesian Networks.

Common Pitfall

Clique potentials \(\psi_C\) are not probabilities — they need not sum/integrate to 1. They express compatibility, not conditional distributions. The partition function \(Z\) does all the normalizing work.

The Math — Hammersley–Clifford & Numerical Trace
▾

Hammersley–Clifford Theorem. Let \(p(\mathbf{x}) > 0\) for all \(\mathbf{x}\). Then \(p\) satisfies the global Markov property with respect to \(G\) if and only if it factorizes over the cliques of \(G\).

Proof sketch (necessity). For a clique \(C\), define the Möbius-style inclusion–exclusion:

$$\ln p(\mathbf{x}) = \sum_{C \subseteq V} \phi_C(\mathbf{x}_C), \quad \phi_C(\mathbf{x}_C) = \sum_{S \subseteq C} (-1)^{|C \setminus S|} \ln p(\mathbf{x}_S, \mathbf{0}_{V\setminus S})$$

The Markov property forces \(\phi_C = 0\) whenever \(C\) is not a clique, leaving only clique terms.

Ising model — concrete numerical trace. Consider a \(2\times 2\) binary grid (nodes \(1,2,3,4\) with edges \(\{1,2\},\{3,4\},\{1,3\},\{2,4\}\)). Pairwise Ising potentials with coupling \(J=1\):

$$\psi_{ij}(x_i, x_j) = e^{J x_i x_j}, \quad x \in \{-1,+1\}$$

For configuration \(\mathbf{x} = (+1,+1,+1,+1)\): all 4 edges agree, each contributes \(e^1 \approx 2.718\). Unnormalized score:

$$\tilde{p}(+,+,+,+) = e^{1}\cdot e^{1}\cdot e^{1}\cdot e^{1} = e^4 \approx 54.60$$

For \(\mathbf{x} = (+1,-1,+1,-1)\): edges \(\{1,2\},\{3,4\}\) disagree (\(e^{-1}\)); edges \(\{1,3\},\{2,4\}\) agree (\(e^1\)).

$$\tilde{p}(+,-,+,-) = e^{-1}\cdot e^{-1}\cdot e^{1}\cdot e^{1} = e^0 = 1.00$$

Full \(Z = \sum_{2^4=16\,\text{configs}} \tilde{p}(\mathbf{x})\). By symmetry the dominant configurations are the two fully-aligned ones (\(e^4\) each) and the 6 "half-aligned" ones (\(e^0=1\) each). \(Z = 2e^4 + 6\cdot1 + 8 \times e^{-2} \approx 2(54.60)+6+8(0.135) \approx 116.28\). So \(p(+,+,+,+) = 54.60/116.28 \approx 0.470\).

Computing Z — The Core Challenge

For \(n\) binary variables, \(Z\) sums over \(2^n\) configurations — exponential in the tree-width. Exact inference is #P-hard for general graphs. Tractable special cases: trees (belief propagation), planar graphs (Kasteleyn), Gaussians (matrix determinants). Approximate methods: loopy BP, variational inference (mean field), MCMC.

Log-linear parameterization. In practice, potentials are parameterized as \(\psi_C(\mathbf{x}_C;\theta) = \exp(\theta_C^\top f_C(\mathbf{x}_C))\) for feature vector \(f_C\). The log-likelihood gradient is:

$$\frac{\partial \ln p(\mathbf{x};\theta)}{\partial \theta_C} = f_C(\mathbf{x}_C) - \mathbb{E}_{p(\cdot;\theta)}[f_C(\mathbf{x}_C)]$$

The second term (model expectation) requires computing \(Z\) — making MRF training hard. Contrastive divergence and pseudo-likelihood sidestep this by approximating the expectation.

Key Takeaways & When to Use MRFs
▾

Use MRFs when:

  • Relationships are symmetric (no natural causal direction) — pixel grids, social graphs.
  • You want a discriminative structured output model: Conditional Random Fields (CRFs) are discriminative MRFs \(p(y \mid x)\) that bypass computing \(Z_x\) over inputs.
  • The graph has low tree-width — exact inference via junction tree algorithm is then feasible.

Prefer Bayesian Networks when:

  • The model is generative with clear causal structure.
  • Conditional independence has a natural topological ordering (HMMs, LDA).
  • You need easy ancestral sampling.
Key Connections
  • CRF — conditional MRF for structured prediction (NLP, vision)
  • Boltzmann Machine / RBM — bipartite MRF used in deep generative models
  • Gaussian MRF — precision matrix \(\Lambda = \Sigma^{-1}\); off-diagonal zeros encode independence
  • Belief Propagation — message-passing exact on trees, approximate ("loopy BP") on graphs

From-Scratch Code — Pairwise MRF Exact Inference
▾

Exact brute-force inference for a small binary pairwise MRF (exponential in \(n\), educational only):

import numpy as np
from itertools import product
def pairwise_mrf(n_vars, unary, pairwise_edges, J=1.0):
"""Exact joint over n binary {-1,+1} variables."""
configs = list(product([-1, 1], repeat=n_vars)) # 2^n configs
scores = []
for x in configs:
energy = -sum(unary[i]*x[i] for i in range(n_vars)) # unary
energy -= J * sum(x[i]*x[j] for i,j in pairwise_edges) # pairwise
scores.append(np.exp(-energy)) # psi = exp(-E)
Z = sum(scores) # partition function
probs = [s/Z for s in scores]
return {x: p for x, p in zip(configs, probs)}
# 2x2 Ising grid: nodes {0,1,2,3}
edges = [(0,1),(2,3),(0,2),(1,3)]
dist = pairwise_mrf(4, unary=[0,0,0,0], pairwise_edges=edges)
print(dist[(1,1,1,1)]) # ≈ 0.470 — all-aligned config

For large graphs: use pgmpy, libDAI, or OpenGM; for CRFs use sklearn-crfsuite or PyTorch-CRF.
