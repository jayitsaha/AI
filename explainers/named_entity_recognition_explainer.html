Understanding NER
▼

What is it? Named Entity Recognition (NER) is a fundamental task in Natural Language Processing (NLP) that involves locating and classifying named entities in unstructured text into pre-defined categories such as person names, organizations, locations, medical codes, time expressions, quantities, monetary values, etc.

Why is it important? NER acts as a crucial first step for many advanced NLP applications. It helps in information extraction (e.g., finding all companies mentioned in a news article), question answering (identifying entities in a query to match against a knowledge base), building knowledge graphs, and improving search relevance. Without NER, a system might treat "Apple" (the company) and "apple" (the fruit) identically.

Analogy: Imagine you're reading a dense legal document and need to quickly find all parties involved, dates, and locations. NER is like having a smart assistant that automatically highlights and labels these key pieces of information for you, making the document much easier to parse and understand at a glance.

💡 If you remember one thing

NER is typically framed as a sequence labeling task. For each word (token) in a sentence, we predict a tag that indicates if it's part of an entity, and if so, what type and position (Beginning, Inside, or Outside of an entity).

2
How NER Works Internally
▼

From Rules to Deep Learning

Early NER systems relied on hand-crafted rules, dictionaries, and regular expressions. While precise for specific domains, they struggled with ambiguity and generalization. Modern NER predominantly uses machine learning, especially deep learning models like Recurrent Neural Networks (RNNs), Long Short-Term Memory (LSTMs), and more recently, Transformer architectures (e.g., BERT, RoBERTa).

BIO/IOB Tagging Scheme

To represent multi-word entities and their types, a tagging scheme is used. The most common is BIO (Beginning, Inside, Outside) or IOB2.

  • B-TYPE: Indicates the Beginning of an entity of a specific TYPE (e.g., B-PER for "Barack").
  • I-TYPE: Indicates an Inside token of an entity of a specific TYPE (e.g., I-PER for "Obama").
  • O: Indicates an Outside token, meaning it's not part of any named entity.
For example, "Barack Obama met with Apple Inc. in Cupertino." would be tagged as: Barack (B-PER) Obama (I-PER) met (O) with (O) Apple (B-ORG) Inc. (I-ORG) in (O) Cupertino (B-LOC).

The Role of a CRF Layer

While a neural network (like an LSTM or Transformer) can predict a tag for each token independently using a softmax layer, this approach doesn't guarantee a valid sequence of tags. For example, a simple softmax might predict I-ORG after an O tag, which is invalid (an "Inside" tag must follow a "Beginning" or another "Inside" tag of the same type). A Conditional Random Field (CRF) layer is often added on top of the neural network's output to model dependencies between adjacent tags. It learns transition probabilities between tags (e.g., how likely is B-PER to be followed by I-PER, or by O?).

Span-Based NER

An alternative approach, particularly popular with Transformer models, is span-based NER. Instead of tagging each token, the model identifies all possible spans of text (e.g., "Apple", "Apple acquired", "Apple acquired Siri") and then classifies each span as an entity of a certain type or not an entity. This can sometimes simplify handling nested entities or more complex entity structures, but it's computationally more intensive as the number of spans grows quadratically with sentence length.

🔑 Key Property

The CRF layer ensures that the predicted sequence of tags is globally optimal and adheres to linguistic constraints, significantly improving NER performance by preventing impossible tag transitions.

3
Why It Works — The Math (CRF Layer)
▼

CRF: Modeling Tag Dependencies

A Conditional Random Field (CRF) layer, when applied to sequence tagging, aims to find the sequence of tags \(y = (y_1, y_2, \dots, y_n)\) for an input sequence \(x = (x_1, x_2, \dots, x_n)\) that maximizes a probability score. This score is a combination of emission scores (how well a tag fits a token) and transition scores (how well a tag follows the previous tag).

The probability of a tag sequence \(y\) given an input sequence \(x\) is defined as:

$$P(y|x) = \frac{\exp(\text{Score}(x, y))}{\sum_{y' \in \mathcal{Y}} \exp(\text{Score}(x, y'))}$$

where \(\mathcal{Y}\) is the set of all possible tag sequences. The score of a sequence is the sum of emission and transition scores:

$$\text{Score}(x, y) = \sum_{i=1}^n \left( \text{EmissionScore}(x_i, y_i) + \text{TransitionScore}(y_{i-1}, y_i) \right)$$

Here, \(\text{EmissionScore}(x_i, y_i)\) is the logit (raw output) from the neural network for token \(x_i\) being tag \(y_i\). \(\text{TransitionScore}(y_{i-1}, y_i)\) is a learned parameter representing the likelihood of transitioning from tag \(y_{i-1}\) to \(y_i\). For the first token, \(y_0\) is a special "start" tag.

Finding the Best Path with Viterbi

To find the most probable tag sequence (the one with the maximum score), we use the Viterbi algorithm. This dynamic programming algorithm efficiently computes the optimal path by iteratively finding the best path to each possible tag at each time step.

Let \(V_{i,k}\) be the maximum score of a tag sequence ending with tag \(k\) at token \(i\). The Viterbi recurrence relation is:

$$V_{i,k} = \text{EmissionScore}(x_i, y_k) + \max_{j \in \text{Tags}} \left( V_{i-1,j} + \text{TransitionScore}(y_j, y_k) \right)$$

The base case for \(i=1\) is \(V_{1,k} = \text{EmissionScore}(x_1, y_k) + \text{TransitionScore}(\text{START}, y_k)\). After computing all \(V_{i,k}\), the final tag sequence is found by backtracking from the tag \(k\) that yields the maximum \(V_{n,k}\).

➗ Key Math Insight

The Viterbi algorithm effectively explores all possible tag sequences, but by storing intermediate maximum scores, it avoids exponential complexity, solving the problem in polynomial time (typically \(O(N \times T^2)\), where \(N\) is sequence length and \(T\) is number of tags).

Key Takeaways
▼

When to use NER:

  • Information Extraction: Automatically pull out key facts from documents (e.g., company names, product names, dates).
  • Knowledge Graph Construction: Identify entities and relationships to build structured knowledge bases.
  • Search & Recommendation: Improve relevance by understanding the entities in queries and documents.
  • Question Answering: Pinpoint potential answers by matching entities in questions to text.
  • Content Categorization: Summarize content by identifying dominant entities.

Key Concepts Recap:

  • BIO/IOB Tagging: Standard way to represent entity spans (Beginning, Inside, Outside).
  • CRF Layer: Crucial for sequence modeling, ensuring linguistically valid and globally optimal tag sequences by learning transition probabilities.
  • Viterbi Algorithm: Efficient dynamic programming algorithm used by CRF to decode the best tag path.
  • Span-based NER: An alternative to token-level tagging, often used with Transformers, where the model classifies entire text spans.
💡 Modern NER

While LSTMs with CRFs were dominant, Transformer-based models (like BERT, RoBERTa, etc.) have significantly advanced NER performance, often achieving state-of-the-art results even without an explicit CRF layer by implicitly learning sequence dependencies through their attention mechanisms and pre-training objectives. However, CRFs still offer a strong explicit modeling of output constraints.

Code Trace: Simplified CRF Viterbi
▼
import numpy as np
# Example: Sentence with 5 tokens, 7 possible tags
tokens = ["Apple", "acquired", "Siri", "in", "2010"]
tags = ["O", "B-ORG", "I-ORG", "B-PER", "I-PER", "B-DATE", "I-DATE"]
num_tokens = len(tokens)
num_tags = len(tags)
# Emission scores (logits from neural network for each token-tag pair)
# Shape: (num_tokens, num_tags)
emission_scores = np.array([
# O B-ORG I-ORG B-PER I-PER B-DATE I-DATE
[0.1, 2.5, -1.0, 0.5, -2.0, -1.5, -2.0], # Apple
[2.0, -1.0, -1.5, -0.5, -1.0, 0.1, -0.8], # acquired
[-0.5, 2.8, -0.8, 0.2, -1.5, -1.0, -1.0], # Siri
[3.0, -2.0, -2.5, -1.0, -1.8, -1.0, -1.5], # in
[-1.0, -1.5, -2.0, -0.5, -1.0, 2.9, -0.5], # 2010
])
# Transition scores (learned by CRF, e.g., from_tag -> to_tag)
# Shape: (num_tags + 1, num_tags) (+1 for START tag)
# Simplified example, real values are learned.
# Penalize invalid transitions (e.g., O -> I-ORG, B-ORG -> B-PER)
transition_scores = np.zeros((num_tags + 1, num_tags))
# Add some valid transitions (positive scores)
transition_scores[tags.index("B-ORG"), tags.index("I-ORG")] = 1.5
transition_scores[tags.index("I-ORG"), tags.index("I-ORG")] = 1.0
transition_scores[tags.index("B-PER"), tags.index("I-PER")] = 1.5
transition_scores[tags.index("I-PER"), tags.index("I-PER")] = 1.0
transition_scores[tags.index("O"), tags.index("B-ORG")] = 0.5
transition_scores[tags.index("O"), tags.index("B-PER")] = 0.5
transition_scores[tags.index("O"), tags.index("B-DATE")] = 0.5
transition_scores[tags.index("B-DATE"), tags.index("I-DATE")] = 1.5
# Viterbi algorithm
# viterbi_scores[i][j] = max score of path ending at token i with tag j
viterbi_scores = np.full((num_tokens, num_tags), -np.inf)
backpointers = np.full((num_tokens, num_tags), -1, dtype=int)
# Initialization for the first token
for j in range(num_tags):
# Assume START tag is at index num_tags
viterbi_scores[0, j] = emission_scores[0, j] + transition_scores[num_tags, j]
# Forward pass
for i in range(1, num_tokens):
for j in range(num_tags): # current tag
max_prev_score = -np.inf
max_prev_tag_idx = -1
for k in range(num_tags): # previous tag
score = viterbi_scores[i-1, k] + transition_scores[k, j]
if score > max_prev_score:
max_prev_score = score
max_prev_tag_idx = k
viterbi_scores[i, j] = emission_scores[i, j] + max_prev_score
backpointers[i, j] = max_prev_tag_idx
# Backtrack to find the best path
best_path_score = -np.inf
last_best_tag_idx = -1
for j in range(num_tags):
if viterbi_scores[num_tokens-1, j] > best_path_score:
best_path_score = viterbi_scores[num_tokens-1, j]
last_best_tag_idx = j
best_tag_sequence = [0] * num_tokens
best_tag_sequence[num_tokens-1] = last_best_tag_idx
for i in range(num_tokens - 2, -1, -1):
best_tag_sequence[i] = backpointers[i+1, best_tag_sequence[i+1]]
predicted_tags = [tags[idx] for idx in best_tag_sequence]
print(f"Tokens: {tokens}")
print(f"Predicted Tags: {predicted_tags}")
