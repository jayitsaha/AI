Understanding the Exponential Family
▼

What is it? The exponential family is a single unifying template that encompasses dozens of the most important probability distributions — Bernoulli, Gaussian, Poisson, Gamma, Beta, Multinomial, and more — all written in one canonical form. Instead of memorising each distribution separately, you learn one formula and then "plug in" parameters to recover each specific distribution.

Analogy: Think of it like a universal power adapter. Every country has a different plug shape (Bernoulli, Gaussian, Poisson…), but the underlying electricity is the same. The exponential family is that universal standard. Once you understand the standard, every "plug" works the same way internally.

If you remember one thing

The canonical form is $$p(x \mid \eta) = h(x)\exp\!\bigl(\eta^\top T(x) - A(\eta)\bigr)$$ where \(\eta\) are the natural parameters, \(T(x)\) the sufficient statistics, \(h(x)\) the base measure, and \(A(\eta) = \log \int h(x)\exp(\eta^\top T(x))\,dx\) the log-partition function that ensures normalisation. All moments flow from \(A\): \(\mathbb{E}[T(x)] = \nabla A(\eta)\) and \(\operatorname{Cov}[T(x)] = \nabla^2 A(\eta)\).

How It Works — The Canonical Form in Detail
▼

The Four Building Blocks

Every exponential family distribution is characterised by four components:

  • Natural parameter \(\eta \in \mathcal{H} \subseteq \mathbb{R}^k\) — the "free" parameter vector in the canonical parameterisation. For Bernoulli it is the log-odds; for Gaussian it is the mean divided by variance.
  • Sufficient statistic \(T(x)\) — the data summary that carries all information about \(\eta\). By the Fisher–Neyman factorisation theorem, once you know \(T(x)\), you gain no additional information about \(\eta\) from the raw data \(x\).
  • Base measure \(h(x)\) — the part of the density independent of \(\eta\). It determines the support and the counting measure (e.g., \(1/x!\) for Poisson keeps it a valid PMF).
  • Log-partition function \(A(\eta)\) — the normalisation constant in log-space. It is a convex function of \(\eta\), and its cumulant-generating properties are the engine behind all moment formulas.
$$p(x \mid \eta) = h(x)\exp\!\bigl(\eta^\top T(x) - A(\eta)\bigr), \quad A(\eta) = \log\!\int h(x)\exp\!\bigl(\eta^\top T(x)\bigr)\,\nu(dx)$$

Key Property — Sufficiency

The statistic \(T(x)\) is sufficient for \(\eta\): the conditional distribution \(p(x \mid T(x), \eta)\) does not depend on \(\eta\). This means that any inference about \(\eta\) can be based entirely on \(T(x)\) without loss. For iid data \(x_1,\ldots,x_n\), the joint sufficient statistic is just \(\sum_i T(x_i)\) — a massive dimension reduction.

Why It Works — Log-Partition Moments & Max-Entropy
▼

Moments from \(A(\eta)\) — The Central Miracle

Differentiate \(A(\eta) = \log \int h(x)\exp(\eta^\top T(x))\,dx\) with respect to \(\eta\):

$$\nabla_\eta A(\eta) = \frac{\int T(x)\,h(x)\exp(\eta^\top T(x))\,dx}{\int h(x)\exp(\eta^\top T(x))\,dx} = \mathbb{E}_\eta[T(x)]$$

Differentiate again to get the covariance matrix of \(T(x)\):

$$\nabla^2_\eta A(\eta) = \mathbb{E}_\eta[T(x)T(x)^\top] - \mathbb{E}_\eta[T(x)]\mathbb{E}_\eta[T(x)]^\top = \operatorname{Cov}_\eta[T(x)]$$

Since a covariance matrix is always positive semi-definite, \(A(\eta)\) is convex in \(\eta\) — which makes maximum likelihood well-behaved (a single global maximum in the natural parameter space).

Concrete: Bernoulli at \(p = 0.3\)

With \(\eta = \log(0.3/0.7) = -0.8473\) and \(A(\eta) = \log(1+e^\eta)\):

$$A'(\eta) = \frac{e^\eta}{1+e^\eta} = \sigma(\eta) = 0.3000 \quad \text{(mean)} \qquad A''(\eta) = \sigma(\eta)(1-\sigma(\eta)) = 0.21 \quad \text{(variance)}$$

Maximum Entropy Characterisation

The exponential family distributions are exactly the maximum-entropy distributions subject to constraints on the expected sufficient statistics. If you impose \(\mathbb{E}[T(x)] = \mu\) and maximise entropy over all distributions satisfying this constraint (and normalisation), the solution is always an exponential family member with the Lagrange multipliers as natural parameters. This is why Gaussian is max-entropy given mean and variance constraints, and Poisson is max-entropy on non-negative integers given a mean constraint.

Common Misconception

The "natural parameter space" \(\mathcal{H} = \{\eta : A(\eta) < \infty\}\) may be a strict subset of \(\mathbb{R}^k\). For Bernoulli it is all of \(\mathbb{R}\), but for a Gamma(\(\alpha, \beta\)) with shape and rate natural parameters \((\alpha{-}1, -\beta)\), the constraint \(\alpha > 0\) means \(\eta_1 > -1\). Ignoring these boundary constraints causes numerical overflow in optimisation.

Link to GLMs

In a Generalised Linear Model (GLM), the response \(y\) is modelled as an exponential family member whose natural parameter is a linear function of features: \(\eta = \mathbf{x}^\top \boldsymbol{\beta}\). The link function \(g\) maps the mean \(\mu = A'(\eta)\) back to the linear predictor: \(g(\mu) = \mathbf{x}^\top \boldsymbol{\beta}\). The canonical link is precisely \(g = (A')^{-1}\) — the inverse of the mean function. This explains why logistic regression uses sigmoid (inverse logit) and Poisson regression uses log link: they are the canonical links for their respective exponential families.

Key Takeaways & Connections
▼

Why the exponential family matters:

  • MLE has a closed-form in terms of \(T(x)\): the score equation is \(\mathbb{E}_\eta[T(x)] = \bar{T}_n\), i.e., match predicted moments to empirical moments. No iterative method needed for natural parameters.
  • Sufficient statistics are complete: for regular exponential families, \(T(x)\) is a complete sufficient statistic, so the Lehmann–Scheffé theorem guarantees that any unbiased estimator based on \(T(x)\) is UMVUE (uniformly minimum-variance unbiased).
  • Conjugate priors exist: the conjugate prior for an exponential family likelihood is itself an exponential family. This makes Bayesian updating analytically tractable.
  • GLMs are exponential families with linear natural parameters: logistic, Poisson, Gamma regression all follow from choosing the appropriate exponential family member.
  • Information geometry: the Fisher information matrix equals \(\nabla^2 A(\eta)\), and the manifold of exponential family distributions is a dually flat Riemannian manifold (the foundation of information geometry).
The MLE Moment-Matching Principle

For iid data \(x_1,\ldots,x_n\) from an exponential family, the MLE \(\hat{\eta}\) satisfies $$\nabla A(\hat{\eta}) = \frac{1}{n}\sum_{i=1}^n T(x_i)$$ i.e., the predicted mean of \(T\) equals the sample mean of \(T\). For Bernoulli: \(\hat{p} = \bar{x}\). For Poisson: \(\hat{\lambda} = \bar{x}\). For Gaussian: \(\hat{\mu} = \bar{x}\). All the same equation, different \(A\).

Code Trace — Exponential Family in NumPy
▼
import numpy as np
# Exponential family canonical form components
class BernoulliExpFam:
"""Bernoulli: eta=log(p/1-p), T(x)=x, h(x)=1, A(eta)=log(1+exp(eta))"""
@staticmethod
def eta(p): return np.log(p / (1 - p)) # logit
@staticmethod
def A(eta): return np.log1p(np.exp(eta)) # softplus
@staticmethod
def A_prime(eta): return 1/(1+np.exp(-eta)) # sigmoid = mean
@staticmethod
def A_dbl(eta): s=1/(1+np.exp(-eta)); return s*(1-s) # variance
class PoissonExpFam:
"""Poisson: eta=log(lam), T(x)=x, h(x)=1/x!, A(eta)=exp(eta)"""
@staticmethod
def eta(lam): return np.log(lam)
@staticmethod
def A(eta): return np.exp(eta) # = lambda
@staticmethod
def A_prime(eta): return np.exp(eta) # mean = lambda
@staticmethod
def A_dbl(eta): return np.exp(eta) # var = lambda
# MLE via moment matching: E[T(x)] = sample mean of T
data_bern = np.array([1,0,1,1,0,0,1,0]) # 4 successes / 8
eta_mle = BernoulliExpFam.eta(data_bern.mean()) # logit(0.5) = 0.0
mean_pred = BernoulliExpFam.A_prime(eta_mle) # sigmoid(0) = 0.5
var_pred = BernoulliExpFam.A_dbl(eta_mle) # 0.25
print(f"MLE eta: {eta_mle:.4f}") # 0.0000
print(f"E[T(x)]: {mean_pred:.4f}") # 0.5000
print(f"Var[T(x)]:{var_pred:.4f}") # 0.2500
