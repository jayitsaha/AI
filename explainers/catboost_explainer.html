Understanding CatBoost
▼

What is it? CatBoost is a gradient-boosting framework from Yandex (2017) built specifically to handle categorical features — things like "city = London", "device = iPhone", "color = red" — without you having to encode them manually. Most boosting libraries treat these as numbers after you've done the encoding; CatBoost encodes them automatically inside training in a smarter, leakage-free way.

Analogy: Imagine grading students by city. Naive approach: look at the average grade of ALL London students including today's student when encoding "London". That cheats — you've peeked at the answer. CatBoost instead shuffles all students into a random queue, then for each student computes "average grade of London students who came BEFORE me in the queue." This never peeks at the current student's grade.

Two key innovations:

  • Ordered target encoding — encodes categories using only prior rows in a random permutation, eliminating target leakage.
  • Oblivious (symmetric) trees — at each depth level, the exact same feature/threshold is used for every node. This produces balanced trees, enables fast array-based evaluation, and regularizes the model.
💡 If You Remember One Thing

CatBoost's ordered target statistic for category \(c\) at permutation position \(i\) is: $$\text{TS}(c,i) = \frac{\sum_{j:\sigma(j)<\sigma(i),\, x_j^c = c} y_j + a\cdot p}{\left|\{j:\sigma(j)<\sigma(i),\, x_j^c=c\}\right| + a}$$ where \(\sigma\) is the random permutation, \(p\) is the prior (global mean), and \(a\) is the prior weight. The key: row \(i\)'s own target is never included.

2
How CatBoost Works Internally
▼

Problem: Target Leakage in Categorical Encoding

Traditional target encoding computes \(\text{TS}(c) = \mathbb{E}[y \mid x^c = c]\) using ALL training rows. But when row \(i\) has category \(c\), its own target \(y_i\) contributes to \(\text{TS}(c)\), so the encoded feature for row \(i\) contains information about its own label. This is target leakage — the model appears to learn in training but the encoding is useless at inference time (the test row's target is unknown). Result: dramatic overfit.

CatBoost's Ordered Target Statistics

Before building tree \(t\), CatBoost samples a random permutation \(\sigma\) of the training indices. For row \(i\), the target statistic for category \(c\) at its permutation position is built using ONLY rows that come BEFORE \(i\) in \(\sigma\): $$\text{TS}(c,i) = \frac{\displaystyle\sum_{j:\,\sigma(j)<\sigma(i),\;x_j^c=c} y_j \;+\; a \cdot p}{\displaystyle\bigl|\{j:\,\sigma(j)<\sigma(i),\;x_j^c=c\}\bigr| \;+\; a}$$ where \(p = \frac{1}{n}\sum_i y_i\) is the global mean and \(a > 0\) is a smoothing prior weight (hyperparameter, default 1). At position 0 (no priors), TS reduces to just \(p\).

Ordered Boosting

Beyond encoding, CatBoost extends the "ordered" idea to the residuals themselves. It maintains \(n\) separate model versions \(M_0, M_1, \ldots, M_{n-1}\) in the permutation. When computing the gradient (residual) for row \(i\) to train tree \(t\), it uses \(M_i^{t-1}\) — a model trained on all rows BEFORE \(i\) in the permutation. This eliminates target leakage in the gradient computation too, not just the encoding.

Oblivious (Symmetric) Trees

Standard decision trees choose a different (feature, threshold) split at each node of a given level. CatBoost uses oblivious trees: at level \(d\), one (feature, threshold) pair is chosen globally and applied identically to EVERY node at that level. A depth-\(D\) tree uses exactly \(D\) split conditions, and row routing is a \(D\)-bit binary code. This means: (1) the tree is perfectly balanced with \(2^D\) leaves, (2) evaluation is an array lookup rather than tree traversal, (3) fewer degrees of freedom → implicit regularization, (4) all split conditions at a level are independent → amenable to SIMD and GPU parallelism.

🔑 Key Property: No Leakage Guarantee

For any row \(i\), the features used to build the tree for row \(i\) are computed from a disjoint prefix of the permutation. Row \(i\)'s target \(y_i\) never contributes to its own encoding or its own gradient estimate. This is a strict information-theoretic guarantee against target leakage within training.

GPU Training

Oblivious trees unlock GPU efficiency. Because all nodes at depth \(d\) use the same split, computing "which leaf does row \(i\) land in?" reduces to: compute \(D\) binary comparisons, pack them into a \(D\)-bit integer, use as an index into the leaf-value array. This is fully vectorizable. CatBoost implements histogram-based split finding on GPU similarly to LightGBM but benefits from the simpler symmetric structure — split candidates for an entire level are evaluated in one GPU kernel.

3
The Math — Ordered Boosting & Target Statistics
▼

Ordered TS Formula

Let \(\sigma\) be a uniformly random permutation of \(\{1,\ldots,n\}\), \(a > 0\) be the prior weight, and \(p = \bar{y}\) be the global target mean. The ordered target statistic for row \(i\) with category value \(c\) is:

$$\text{TS}(c,i;\sigma) = \frac{\displaystyle\sum_{j=1}^{n} \mathbf{1}[\sigma(j)<\sigma(i),\;x_j^c=c]\cdot y_j \;+\; a\cdot p}{\displaystyle\sum_{j=1}^{n}\mathbf{1}[\sigma(j)<\sigma(i),\;x_j^c=c] \;+\; a}$$

This is a Bayesian shrinkage estimator: as the number of prior rows with category \(c\) grows, the estimate converges to the empirical frequency; with few priors, it is pulled toward the global mean \(p\). The denominator is \(n_c^{(i)} + a\) where \(n_c^{(i)} = |\{j:\sigma(j)<\sigma(i), x_j^c=c\}|\).

Numerical Trace (5 rows, prior weight \(a=1\), \(p=0.6\))

$$\text{Row 2 (perm pos 1):}\quad \text{TS} = \frac{0 + 1.0 \times 0.6}{0 + 1.0} = 0.600$$ $$\text{Row 0 (perm pos 2):}\quad \text{TS} = \frac{1 + 1.0 \times 0.6}{1 + 1.0} = \frac{1.6}{2} = 0.800$$ $$\text{Row 4 (perm pos 3):}\quad \text{TS(B)} = \frac{0 + 1.0 \times 0.6}{0 + 1.0} = 0.600\quad(\text{first B, no priors})$$ $$\text{Row 1 (perm pos 4):}\quad \text{TS(B)} = \frac{1 + 0.6}{1 + 1.0} = \frac{1.6}{2} = 0.800\quad(\text{row 4 is prior B with target=1})$$ $$\text{Row 3 (perm pos 5):}\quad \text{TS(A)} = \frac{2 + 0.6}{2 + 1.0} = \frac{2.6}{3} \approx 0.867$$

Gradient Boosting with Ordered Trees

Let \(F_0(x) = p\) be the initial prediction. At step \(t\), the residual for row \(i\) is \(r_i^{(t)} = -\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\). For MSE loss, \(r_i^{(t)} = y_i - F^{(t-1)}(x_i)\). CatBoost fits tree \(h_t\) to these residuals and updates:

$$F^{(t)}(x) = F^{(t-1)}(x) + \eta \cdot h_t(x)$$

For oblivious tree with depth \(D\), the leaf assignment of any row \(x\) is determined by the \(D\) binary split outcomes stacked into an index \(\ell(x) = \sum_{d=1}^D b_d(x) \cdot 2^{d-1}\), where \(b_d(x) = \mathbf{1}[x_{j_d} \geq t_d]\). The leaf prediction minimizes:

$$v_\ell^* = \underset{v}{\operatorname{argmin}} \sum_{i:\,\ell(x_i)=\ell} L(y_i,\; F^{(t-1)}(x_i) + v)$$

For MSE, \(v_\ell^* = \bar{r}_\ell\) (mean residual in leaf \(\ell\)). Split (feature \(j_d\), threshold \(t_d\)) at depth \(d\) is chosen by scanning all histogrammed candidates and picking the one minimizing total squared residual across the partitioned data.

⚠️ Subtlety: Ordered vs Standard Mode

CatBoost supports both boosting_type='Ordered' (default for small datasets, uses \(n\) model copies — \(O(n)\) memory overhead) and boosting_type='Plain' (standard gradient boosting, like XGBoost). The ordered mode is theoretically motivated but slower on very large datasets; plain mode with ordered TS encoding is a useful middle ground.

When to choose CatBoost:

  • Dataset has high-cardinality categorical columns (country, user_id, product_id).
  • You want minimal feature engineering — CatBoost can consume raw string categoricals.
  • GPU is available and you want very fast inference (oblivious trees compile to SIMD lookups).
  • Small-to-medium datasets where ordered boosting's variance reduction matters.

When NOT to use CatBoost:

  • Purely numeric features with no categorical columns — LightGBM is faster.
  • Very large datasets (>10M rows) in ordered mode — memory for n model copies is prohibitive.
  • You need interpretable asymmetric trees — oblivious trees sacrifice some asymmetry for speed.
🎯 Decision Rule

Categorical-heavy data → try CatBoost first. Numeric-only, memory-constrained, or very large scale → LightGBM. Need a well-calibrated well-supported baseline → XGBoost. All three are worth benchmarking; CatBoost often wins on validation but loses on raw training speed vs LightGBM.

import numpy as np
from catboost import CatBoostClassifier
# === FROM SCRATCH: Ordered Target Statistic ===
def ordered_target_stat(X_cat, y, prior_weight=1.0):
"""Compute ordered TS for a single categorical column."""
n = len(y)
global_mean = np.mean(y) # prior p
perm = np.random.permutation(n) # random sigma
ts = np.zeros(n)
cat_sum = {}; cat_cnt = {}
for pos in range(n):
i = perm[pos] # original row index
c = X_cat[i]
cnt = cat_cnt.get(c, 0); s = cat_sum.get(c, 0.0)
# TS uses only PRIOR rows — no leakage of y[i]
ts[i] = (s + prior_weight * global_mean) / (cnt + prior_weight)
cat_sum[c] = s + y[i] # update AFTER computing ts
cat_cnt[c] = cnt + 1
return ts
# === FROM SCRATCH: Oblivious Tree (depth=2) ===
def fit_oblivious_tree(X, residuals, depth=2):
"""Find best symmetric splits greedily level by level."""
n, p = X.shape
splits = [] # list of (feature_idx, threshold) per level
leaf_assign = np.zeros(n, dtype=int)
for d in range(depth):
best_gain, best_j, best_t = -1e9, 0, 0.0
for j in range(p):
for t in np.unique(X[:, j]):
# Same split applied to ALL current leaves (oblivious!)
bit = (X[:, j] >= t).astype(int)
new_leaf = leaf_assign * 2 + bit
gain = 0.0
for l in np.unique(new_leaf):
mask = new_leaf == l
gain += residuals[mask].sum()**2 / mask.sum()
if gain > best_gain:
best_gain, best_j, best_t = gain, j, t
splits.append((best_j, best_t))
leaf_assign = leaf_assign * 2 + (X[:, best_j] >= best_t).astype(int)
# Leaf predictions = mean residual per leaf
leaf_preds = {l: residuals[leaf_assign==l].mean() for l in np.unique(leaf_assign)}
return splits, leaf_preds, leaf_assign
# === PRODUCTION: CatBoost API ===
import pandas as pd
df = pd.DataFrame({'city': ['London','Paris','London','Berlin','Paris'],
'age': [25, 34, 28, 45, 31],
'label':[1, 0, 1, 0, 1]})
X = df[['city','age']]; y = df['label']
cat_features = [0] # column index of 'city' (string)
model = CatBoostClassifier(
iterations=500,
learning_rate=0.05,
depth=6, # oblivious tree depth (2^6=64 leaves)
l2_leaf_reg=3.0, # L2 regularisation on leaf weights
boosting_type='Ordered', # use ordered boosting (default)
cat_features=cat_features, # pass raw string column!
task_type='GPU', # GPU acceleration
verbose=100
)
model.fit(X, y, eval_set=(X, y))
# ⚠️ Gotcha: cat_features expects column INDICES, not names when using numpy arrays
# ⚠️ Gotcha: task_type='GPU' silently falls back to CPU if no CUDA device found
