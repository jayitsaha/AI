Understanding Quadratic Programming
▼

What is it? Quadratic Programming (QP) is an optimization problem where the objective function is quadratic (think a bowl or saddle shape) and the constraints are linear (think flat walls cutting through space). It generalizes linear programming by allowing a curved, not flat, surface to minimize.

Analogy: Imagine you're rolling a marble on a curved bowl (the quadratic objective). Without walls, it rolls to the very bottom. Now imagine placing flat dividers (linear constraints) inside the bowl — the marble can't cross them. The marble comes to rest at the lowest reachable point: either still at the bottom (if no wall blocks it) or pressed against a wall. QP finds that resting point exactly.

Standard form:

$$\min_{\mathbf{x}} \quad \tfrac{1}{2}\mathbf{x}^\top Q\mathbf{x} + \mathbf{c}^\top\mathbf{x} \quad \text{s.t.} \quad A\mathbf{x} \leq \mathbf{b},\; G\mathbf{x} = \mathbf{h}$$

The matrix \(Q \in \mathbb{R}^{n\times n}\) shapes the bowl. When \(Q \succeq 0\) (positive semi-definite), the bowl is convex and QP has a unique global minimum. The linear terms \(\mathbf{c}\) tilt the bowl; \(A,\mathbf{b}\) define inequality walls; \(G,\mathbf{h}\) define equality planes.

If you remember one thing

QP = minimize a quadratic bowl inside a polyhedron. When \(Q \succeq 0\), it's convex — guaranteed global optimum, no local traps. KKT conditions give the exact solution: the optimum sits where the gradient of the Lagrangian vanishes.

How QP Works Internally
▼

The Geometry

The feasible set \(\{\mathbf{x}: A\mathbf{x} \leq \mathbf{b}, G\mathbf{x} = \mathbf{h}\}\) is a convex polyhedron (a region bounded by flat hyperplanes). The objective \(\frac{1}{2}\mathbf{x}^\top Q\mathbf{x} + \mathbf{c}^\top\mathbf{x}\) draws concentric ellipsoidal level sets around the unconstrained minimum \(\mathbf{x}^* = -Q^{-1}\mathbf{c}\). The QP solution is the first level set that touches the feasible polyhedron.

Active Constraints & the KKT System

At optimality, some inequality constraints are active (tight, \(a_i^\top\mathbf{x} = b_i\)) and some are inactive (slack). The KKT (Karush-Kuhn-Tucker) conditions characterize the solution:

$$Q\mathbf{x}^* + \mathbf{c} + A^\top\boldsymbol{\lambda}^* + G^\top\boldsymbol{\nu}^* = \mathbf{0}$$

where \(\boldsymbol{\lambda}^* \geq 0\) are the multipliers for inequality constraints and \(\boldsymbol{\nu}^*\) for equalities. Multipliers measure how much the objective worsens per unit tightening of the constraint — they are the "shadow prices" of the constraints.

Key Property — Complementary Slackness

For each inequality constraint: \(\lambda_i^* (b_i - a_i^\top\mathbf{x}^*) = 0\). Either the constraint is active (\(a_i^\top\mathbf{x}^* = b_i\)) or its multiplier is zero — never both nonzero. This partitions constraints into active and inactive sets at the optimum.

Solvers: Active-Set vs Interior-Point

Active-set methods guess which constraints are active and solve a reduced equality-constrained QP, iteratively updating the active set. They work well for warm-starts (e.g., sequential QP in nonlinear optimization). Interior-point methods follow a path through the interior of the feasible region using a barrier function, converging in \(O(\sqrt{n})\) Newton steps. For large-scale QPs (SVMs, portfolio), interior-point dominates.

When Q is indefinite

If \(Q\) has negative eigenvalues (indefinite), QP becomes NP-hard in general. The bowl has saddle points or is unbounded in some directions. Convexity (\(Q \succeq 0\)) is the key assumption enabling efficient solvers.

3
The Math — KKT Conditions & Duality
▼

Lagrangian & KKT Derivation

Form the Lagrangian:

$$\mathcal{L}(\mathbf{x},\boldsymbol{\lambda},\boldsymbol{\nu}) = \tfrac{1}{2}\mathbf{x}^\top Q\mathbf{x} + \mathbf{c}^\top\mathbf{x} + \boldsymbol{\lambda}^\top(A\mathbf{x}-\mathbf{b}) + \boldsymbol{\nu}^\top(G\mathbf{x}-\mathbf{h})$$

Stationarity condition \(\nabla_\mathbf{x}\mathcal{L}=0\):

$$Q\mathbf{x}^* + \mathbf{c} + A^\top\boldsymbol{\lambda}^* + G^\top\boldsymbol{\nu}^* = \mathbf{0}$$

Full KKT system (primal feasibility, dual feasibility, complementary slackness):

$$A\mathbf{x}^* \leq \mathbf{b}, \quad G\mathbf{x}^* = \mathbf{h}, \quad \boldsymbol{\lambda}^* \geq \mathbf{0}, \quad \lambda_i^*(b_i - a_i^\top\mathbf{x}^*) = 0 \;\forall i$$

Equality-Constrained QP — Closed Form

For QP with only equality constraints \(G\mathbf{x}=\mathbf{h}\), the KKT system becomes a linear system (the saddle-point system):

$$\begin{bmatrix} Q & G^\top \\ G & 0 \end{bmatrix} \begin{bmatrix} \mathbf{x}^* \\ \boldsymbol{\nu}^* \end{bmatrix} = \begin{bmatrix} -\mathbf{c} \\ \mathbf{h} \end{bmatrix}$$

This is solvable in \(O(n^3)\) by direct factorization — the cost of one QP with only equality constraints is the same as solving a linear system.

QP Dual

The Lagrange dual of a convex QP is also a QP (this is rare — most LP duals are LP, most QP duals stay QP). The dual function is:

$$g(\boldsymbol{\lambda},\boldsymbol{\nu}) = -\tfrac{1}{2}(Q^{-1}(c+A^\top\lambda+G^\top\nu))^\top Q\,(Q^{-1}(c+A^\top\lambda+G^\top\nu)) - \mathbf{b}^\top\boldsymbol{\lambda} - \mathbf{h}^\top\boldsymbol{\nu}$$

Strong duality holds when \(Q\succ 0\) or Slater's condition is satisfied — the dual gap is zero, and solving the dual recovers the primal solution. This is the key property that makes the SVM dual tractable.

SVM as QP — The Dual

The soft-margin SVM primal is a QP in \((w, b, \xi)\). Its dual (via Lagrangian) becomes: maximize \(\sum_i \alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j\,\mathbf{x}_i^\top\mathbf{x}_j\) subject to \(0\leq\alpha_i\leq C\) and \(\sum_i\alpha_i y_i=0\). This is a QP with \(n\) variables (one per training point) — solvable by SMO or interior-point.

Applications & Key Takeaways
▼

Where QP Appears

  • Support Vector Machines: The SVM hard-margin primal is \(\min \frac{1}{2}\|w\|^2\) s.t. \(y_i(w^\top x_i+b)\geq 1\). Convex QP in \((w,b)\), \(n\) inequality constraints. Dual is also QP with \(n\) variables.
  • Portfolio Optimization (Markowitz): \(\min w^\top\Sigma w\) s.t. \(\mu^\top w\geq r_{\min},\; \mathbf{1}^\top w=1,\; w\geq 0\). Minimize variance (quadratic) at a target return (linear constraint).
  • Model Predictive Control (MPC): At each time step, solve a QP to minimize a quadratic stage cost over a horizon subject to linear state/input constraints.
  • Lasso Dual / Elastic Net: Certain formulations of regularized regression are QPs or can be solved via sequential QP.
Decision Rule

Equality constraints only? Solve the saddle-point linear system in one shot. Inequality constraints? Use an active-set method (warm start friendly) or interior-point (large scale). Q is identity or diagonal? Often a simpler NNLS or isotonic solver applies. Q indefinite? Consider SDP relaxation or branch-and-bound.

Complexity

Convex QP with \(n\) variables and \(m\) constraints: interior-point methods run in \(O((n+m)^3)\) per iteration, \(O(\sqrt{n+m})\) iterations to \(\epsilon\)-accuracy. For the SVM dual with \(n\) training points, SMO (Sequential Minimal Optimization) solves 2-variable QPs analytically and converges in \(O(n^2)\) amortized steps — enabling SVM training at scale.

Code Trace — Solving the Running Example
▼
import numpy as np
from scipy.optimize import minimize
# QP: min 0.5*(2*x1^2 + 2*x2^2) - 4*x1 - 6*x2
# s.t. x1+x2 <= 4, x1 >= 0, x2 >= 0
Q = np.array([[2.0, 0.0], [0.0, 2.0]]) # PSD — convex!
c = np.array([-4.0, -6.0])
def objective(x): return 0.5 * x @ Q @ x + c @ x
def gradient(x): return Q @ x + c
# Unconstrained minimum: x* = -Q^{-1} c
x_unc = np.linalg.solve(Q, -c) # [2.0, 3.0]
print("Unconstrained min:", x_unc) # sum=5 > 4, infeasible!
# KKT: x1+x2=4 active; solve directly
# KKT system: [Q a'] [x ] [-c]
# [a 0 ] [lam] = [b ]
a = np.array([1.0, 1.0]); b = 4.0
KKT = np.array([[2,0,1],[0,2,1],[1,1,0]], dtype=float)
rhs = np.array([4.0, 6.0, 4.0]) # [-c, b]
sol = np.linalg.solve(KKT, rhs) # [1.5, 2.5, 1.0]
x_opt, lam_opt = sol[:2], sol[2]
print("x* =", x_opt) # [1.5, 2.5]
print("λ* =", lam_opt) # 1.0 (shadow price of constraint)
# Production: use CVXPY or scipy
cons = [{'type':'ineq','fun':lambda x: 4-x[0]-x[1]}]
bnds = [(0,None),(0,None)]
res = minimize(objective, [0,0], jac=gradient,
constraints=cons, bounds=bnds, method='SLSQP')
print("Scipy x* =", res.x) # [1.5, 2.5]
