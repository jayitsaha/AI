1
Understanding SAM
▼

What is it? Every segmentation model before SAM was trained to find one fixed set of things — 80 COCO categories, 150 ADE20K classes, whatever the label schema was. SAM (Meta AI, 2023) flips this: instead of "find a cat," you give it a prompt — a click, a box, a rough scribble mask — anywhere on any image, and it hands back a precise pixel mask for whatever object that prompt is pointing at, even objects it never saw a labeled example of during training.

Analogy: Think of the old magic-wand tool in image editors that only worked on flat, high-contrast regions. SAM is that tool after it has watched a billion masks across eleven million photos — it has internalized "objectness" itself, not a list of object names, so it outlines a coral reef, a satellite rooftop, or a microscope slide's cell nucleus just as confidently as a dog on a couch.

💡 If you remember one thing

A single click is ambiguous — it could mean "the button," "the shirt," or "the person." SAM never guesses one answer: it always returns 3 ranked masks (whole / part / sub-part) with a predicted quality score for each, and lets the score — or the user — resolve the ambiguity.

How SAM Works Internally
▼

Three Decoupled Modules

SAM splits the problem into a heavy, prompt-independent piece and a light, prompt-dependent piece — this split is the whole trick behind making an interactive tool out of a 636M-parameter model.

(a) Image Encoder — an MAE-pretrained ViT-H/16 ingests a 1024×1024 image and produces a 64×64×256 embedding (4096 tokens). It runs once per image, taking ~0.15–0.5s on a GPU, and the result is cached.

(b) Prompt Encoder — turns a point, box, or mask into an embedding. Points/boxes get Fourier positional encodings summed with a learned "foreground/background" type embedding (256-d). Free-form text prompts route through a frozen CLIP text encoder.

(c) Mask Decoder — a lightweight 2-layer two-way transformer: prompt tokens attend to image tokens AND image tokens attend back to prompt tokens, in both directions, every layer. It re-runs in ~50ms, which is what makes dragging a point around feel instantaneous even though the backbone is huge.

Numerical Trace

1024×1024×3 image → patchify at 16×16 → 64×64 = 4096 tokens × 256-d. A point prompt at (x,y) becomes PE(x,y) ⊕ embed[foreground], a single 256-d sparse token. The decoder concatenates this with 4 learned output tokens (1 IoU token + 3 mask tokens), cross-attends against all 4096 image tokens, then a small transposed-conv head upsamples each mask token's response 4× to 256×256 logits — thresholded at 0 and bilinearly upsampled back to the original resolution.

🔑 Design Decision

Why decouple encoder and decoder at all? Because re-running a 636M-parameter ViT on every single click would make interactive annotation unusable. By computing the image embedding once and re-running only the ~4M-parameter decoder per prompt, SAM turns an offline batch model into a real-time tool.

Why It Works — The Math
▼

Point Positional Encoding

A prompt point \((x,y)\) is embedded with random Fourier features (Tancik et al., 2020) so the network can represent continuous coordinates at multiple frequencies:

$$\gamma(x,y) = \big[\sin(2\pi B v),\ \cos(2\pi B v)\big], \qquad v = (x,y),\ B \in \mathbb{R}^{128\times 2} \text{ fixed Gaussian}$$

This 256-d vector is summed with a learned embedding for the point's label (foreground / background / box-corner), giving the sparse prompt token fed to the decoder.

The Ambiguity-Aware Loss

Because a single click has multiple valid interpretations, SAM predicts 3 masks \(M_1, M_2, M_3\) per prompt but backpropagates the segmentation loss through only the best-matching one:

$$\mathcal{L}_{mask} = \min_{i \in \{1,2,3\}} \Big[\, 20\cdot \mathcal{L}_{focal}(M_i, G) + \mathcal{L}_{dice}(M_i, G) \,\Big]$$

where \(G\) is the ground-truth mask. Taking the \(\min\) means gradients only flow to whichever head already best matches the target — over training this specializes the 3 heads into consistent granularities (sub-part, part, whole) instead of collapsing onto each other.

The IoU Prediction Head

A 4th small MLP head predicts each mask's own quality, trained with plain regression against the mask's real computed IoU against ground truth — all 3 heads get this gradient, unlike the min-routed mask loss:

$$\mathcal{L}_{iou} = \sum_{i=1}^{3} \big(\widehat{\text{IoU}}_i - \text{IoU}(M_i, G)\big)^2$$

At inference, \(\widehat{\text{IoU}}_i\) is what ranks the 3 masks — it is exactly what the interactive walkthrough below computes live as you move the prompt point.

⚠️ Common Misconception

"SAM classifies objects." It does not — there is no category head anywhere in the network. SAM only decides which pixels form a coherent visual entity; assigning a semantic label ("dog", "wheel") requires chaining a separate classifier (commonly CLIP) after it.

Key Takeaways
▼

When to use SAM:

  • Interactive annotation tools — click-to-mask instead of polygon drawing
  • Zero-shot segmentation in novel domains (medical imaging, satellite, microscopy) with no fine-tuning
  • Bootstrapping training masks at scale, the way SAM itself generated SA-1B
  • As a building block: Grounded-SAM (text → box → mask), SAM+tracking (SAM 2) for video

When NOT to use:

  • Fixed, closed-vocabulary semantic labeling — a discriminatively trained classifier is cheaper and more accurate
  • Structures finer than the ~16px patch resolution can resolve
  • Tight on-device latency budgets — use a distilled variant (MobileSAM, EdgeSAM, FastSAM) instead of full ViT-H

💡 The Core Separation

SAM decouples "what counts as an object" (learned generically from 1.1B masks, frozen at inference) from "which object do you want" (specified per-call via the prompt). That separation — not any single architectural trick — is why it generalizes zero-shot.

Code Trace — Prompt Encoding & Mask Selection
▼
import numpy as np
# --- Prompt encoder: Fourier positional encoding of a click ---
B = np.random.randn(128, 2) * 10 # frozen random Gaussian matrix
def encode_point(xy_norm, label_embed):
proj = 2 * np.pi * (B @ xy_norm) # (128,)
pe = np.concatenate([np.sin(proj), np.cos(proj)]) # (256,)
return pe + label_embed # foreground / background bias
# --- Mask decoder (schematic): two-way cross-attention ---
def two_way_block(image_tokens, prompt_tokens):
prompt_tokens = prompt_tokens + attn(q=prompt_tokens, k=image_tokens, v=image_tokens)
image_tokens = image_tokens + attn(q=image_tokens, k=prompt_tokens, v=prompt_tokens)
return image_tokens, prompt_tokens
# --- Ambiguity-aware mask selection at inference ---
masks, iou_pred = mask_decoder(image_embed, prompt_tokens) # 3 masks + 3 scores
best = np.argmax(iou_pred) # rank by predicted IoU
final_mask = masks[best] > 0 # threshold logits at 0
print(f"chosen granularity: {best}, confidence: {iou_pred[best]:.2f}")
