1
Understanding the Pseudo-inverse
▼

What is it? A regular matrix inverse \(A^{-1}\) only exists when \(A\) is square and full-rank. The Moore-Penrose pseudo-inverse \(A^+\) generalises this to any matrix — tall, wide, or rank-deficient. It gives the best possible "inverse-like" mapping, solving \(Ax = b\) in the least-squares sense when an exact solution does not exist.

Analogy: Imagine you have more equations than unknowns — an overdetermined system (e.g., you measured a line 100 times and each reading disagrees slightly). You can't satisfy all equations exactly. \(A^+\) gives you the unique answer that is simultaneously: (1) closest to satisfying every equation (minimum residual), and (2) the shortest such answer (minimum norm). It is the "fairest" solution.

If you remember one thing

For a tall full-rank matrix \(A\), the pseudo-inverse \(A^+ = (A^\top A)^{-1} A^\top\) solves the least-squares problem \(\min_x \|Ax - b\|^2\). Via SVD, it generalises to any shape: \(A^+ = V\Sigma^+ U^\top\) where \(\Sigma^+\) simply reciprocates the nonzero singular values.

2
How It Works — Three Views
▼

View 1 — Normal Equations (tall, full column rank)

When \(A \in \mathbb{R}^{m \times n}\) has \(m > n\) and full column rank, \(Ax = b\) is overdetermined. The least-squares solution minimises \(\|Ax - b\|^2\). Setting the gradient to zero gives the normal equations:

$$A^\top A \hat{x} = A^\top b \implies \hat{x} = (A^\top A)^{-1} A^\top b = A^+ b$$

Here \(A^+ = (A^\top A)^{-1} A^\top\). The matrix \(P = A A^+ = A(A^\top A)^{-1}A^\top\) is the orthogonal projector onto the column space of \(A\).

View 2 — SVD (universal)

Any matrix admits the SVD: \(A = U \Sigma V^\top\). The pseudo-inverse is:

$$A^+ = V \Sigma^+ U^\top$$

where \(\Sigma^+\) replaces each nonzero singular value \(\sigma_i\) with \(1/\sigma_i\) (and leaves zeros as zeros). This works for any matrix regardless of shape or rank.

View 3 — The 4 Moore-Penrose Conditions (axiomatic)

The unique \(A^+\) is the matrix satisfying all four conditions simultaneously:

Condition 1 — Reflexive
\(A A^+ A = A\)
\(A^+\) is a "generalised inverse" of \(A\)
Condition 2 — Weak inverse of \(A^+\)
\(A^+ A A^+ = A^+\)
\(A\) is a generalised inverse of \(A^+\)
Condition 3 — \(AA^+\) symmetric
\((A A^+)^\top = A A^+\)
Projection onto col\((A\)) is orthogonal
Condition 4 — \(A^+A\) symmetric
\((A^+ A)^\top = A^+ A\)
Projection onto row\((A\)) is orthogonal
Key Property — Uniqueness

These 4 conditions uniquely determine \(A^+\). Any matrix satisfying all four is the Moore-Penrose pseudo-inverse. The SVD formula \(V\Sigma^+ U^\top\) is the standard way to compute it.

3
Why It Works — The Geometry
▼

Projection onto the Column Space

When \(b\) is not in the column space of \(A\), there is no exact solution to \(Ax = b\). The least-squares solution \(\hat{x} = A^+ b\) produces \(\hat{b} = A\hat{x}\), the orthogonal projection of \(b\) onto \(\text{col}(A)\). The residual \(r = b - \hat{b}\) is perpendicular to every column of \(A\), i.e., \(A^\top r = 0\) (the normal equations).

Why the SVD Formula Works

Write \(Ax = b\) in the SVD basis: \(U\Sigma V^\top x = b\). Let \(y = V^\top x\), \(c = U^\top b\). Then \(\Sigma y = c\). For nonzero \(\sigma_i\): \(y_i = c_i/\sigma_i\). For zero \(\sigma_i\): \(y_i = 0\) (minimum norm). Back-substituting: \(x = Vy = V\Sigma^+ U^\top b = A^+b\).

Numerical Trace (our 4×2 example)

\(A \in \mathbb{R}^{4\times 2}\) with columns \([1,1,1,1]^\top\) and \([1,2,3,4]^\top\). Target \(b = [2.0, 2.8, 3.9, 5.2]^\top\).

\(A^\top A = \begin{bmatrix}4 & 10\\ 10 & 30\end{bmatrix}\), \(\quad (A^\top A)^{-1} = \begin{bmatrix}1.5 & -0.5\\ -0.5 & 0.2\end{bmatrix}\)

\(\hat{x} = A^+b = [0.80,\; 1.07]^\top\) — intercept 0.80, slope 1.07.

\(\hat{b} = A\hat{x} = [1.87, 2.94, 4.01, 5.08]^\top\). Residual \(r = [0.13, -0.14, -0.11, 0.12]^\top\), \(\|r\|^2 = 0.063\) (minimum possible).

Common Pitfall

For a wide (underdetermined) system \(A \in \mathbb{R}^{m\times n}\) with \(m < n\), the formula \(A^+ = A^\top(AA^\top)^{-1}\) applies (assuming full row rank). This gives the minimum-norm solution — not the same as the tall case! Always determine your system's shape before computing.

Key Takeaways & When to Use
▼

When to use \(A^+\):

  • Overdetermined systems (\(m > n\)) — gives the least-squares fit (regression)
  • Underdetermined systems (\(m < n\)) — gives the minimum-norm solution
  • Rank-deficient matrices — \(A^{-1}\) does not exist; \(A^+\) still does
  • Wherever you'd want to "invert" a non-square matrix (signal processing, control, robotics)

Hierarchy of inverses:

Hierarchy

Regular inverse \(A^{-1}\) (square, full rank) ⊂ Left inverse \((A^\top A)^{-1}A^\top\) (tall, full col rank) ⊂ Right inverse \(A^\top(AA^\top)^{-1}\) (wide, full row rank) ⊂ Pseudo-inverse \(A^+\) (any shape, any rank — always exists, always unique).

Computational cost: SVD costs \(O(\min(mn^2, m^2n))\). For numerical stability, always prefer SVD over directly computing \((A^\top A)^{-1}\) — the Gram matrix squares the condition number.

Code Trace
▼
import numpy as np
# Overdetermined system: 4 observations, 2 unknowns (intercept + slope)
A = np.array([[1, 1],
[1, 2],
[1, 3],
[1, 4]], dtype=float)
b = np.array([2.0, 2.8, 3.9, 5.2])
# Method 1: Normal equations — A^+ = (A^T A)^{-1} A^T
AtA = A.T @ A # [[4, 10], [10, 30]]
AtA_inv = np.linalg.inv(AtA) # [[1.5, -0.5], [-0.5, 0.2]]
A_pinv = AtA_inv @ A.T # shape (2, 4)
x_hat = A_pinv @ b # [0.80, 1.07]
# Method 2: SVD — more numerically stable
U, s, Vt = np.linalg.svd(A, full_matrices=False)
Sigma_plus = np.diag(1.0 / s) # reciprocate singular values
A_pinv_svd = Vt.T @ Sigma_plus @ U.T # = V Sigma^+ U^T
# Method 3: NumPy built-in (uses SVD internally)
A_pinv_np = np.linalg.pinv(A) # same result
# Projection of b onto col(A)
P_proj = A @ A_pinv # 4x4 projection matrix
b_hat = P_proj @ b # [1.87, 2.94, 4.01, 5.08]
residual = b - b_hat # [0.13, -0.14, -0.11, 0.12]
print(f"||r||^2 = {residual @ residual:.4f}") # 0.0630 (minimum)
# Verify 4 Moore-Penrose conditions
Ap = A_pinv
print(np.allclose(A @ Ap @ A, A)) # True — condition 1
print(np.allclose(Ap @ A @ Ap, Ap)) # True — condition 2
print(np.allclose((A @ Ap).T, A @ Ap)) # True — condition 3
print(np.allclose((Ap @ A).T, Ap @ A)) # True — condition 4
