Understanding LDA Inference
▼

What is it? LDA says each document is a mixture of hidden topics, and each topic is a mixture of words. Given only raw text, we must infer those hidden mixtures. The exact posterior \(p(\theta,\phi,z\mid w)\) requires summing over every possible topic assignment for every word and integrating over every possible topic-mixture — intractable for anything but toy corpora. Variational EM and collapsed Gibbs sampling are the two classic ways to get a good approximate answer anyway.

Analogy: Sorting a huge box of mixed LEGO bricks into "kits" (topics) with no instructions, where each finished model (document) uses bricks from several kits. Gibbs sampling repeatedly picks up one brick, guesses which kit it fits best given where everything else currently sits, and slowly the piles clean up. Variational EM instead builds a simplified, easy-to-reason-about rulebook that approximates the true sorting rules well enough to sort everything in one systematic, repeatable pass.

💡 If you remember one thing

Variational EM optimizes a simpler, factorized distribution \(q\) to be as close as possible to the true posterior (fast, deterministic, biased). Collapsed Gibbs sampling draws one hidden topic assignment at a time from its exact conditional, after algebraically integrating \(\theta,\phi\) out of the model (slower, stochastic, asymptotically exact).

2
How It Works Internally
▼

A. Mean-Field Variational EM

Replace the true posterior with a fully factorized family: \(q(\theta,\phi,z) = \prod_k \text{Dir}(\phi_k;\lambda_k)\prod_d \text{Dir}(\theta_d;\gamma_d)\prod_{d,n}\text{Cat}(z_{d,n};\varphi_{d,n})\). Because Dirichlet is conjugate to Categorical, each factor has a closed-form update via the digamma function \(\psi(x)=\frac{d}{dx}\log\Gamma(x)\):

$$\varphi_{d,n,k} \propto \exp\big(\psi(\gamma_{d,k}) - \psi(\textstyle\sum_{k'}\gamma_{d,k'}) \;+\; \psi(\lambda_{k,w_{d,n}}) - \psi(\textstyle\sum_v \lambda_{k,v})\big)$$

E-step (per document): iterate \(\varphi_{d,n}\) ↔ \(\gamma_d = \alpha + \sum_n \varphi_{d,n}\) to convergence. M-step (corpus-wide): aggregate \(\lambda_{k,w} = \eta + \sum_{d,n:\,w_{d,n}=w}\varphi_{d,n,k}\). Repeat until the ELBO stops improving.

B. Collapsed Gibbs Sampling

Instead of approximating, first do exact algebra: \(\theta_d\) only interacts with \(z_d\)'s counts, and \(\phi_k\) only interacts with the word-counts of tokens assigned to topic \(k\) — both can be analytically integrated ("collapsed") out via Dirichlet-Multinomial conjugacy, leaving a sampler over \(z\) alone:

$$p(z_{d,n}=k \mid z_{\neg(d,n)}, w) \propto \big(n_{d,k}^{\neg(d,n)}+\alpha_k\big)\cdot\frac{n_{k,w_{d,n}}^{\neg(d,n)}+\eta_{w_{d,n}}}{n_k^{\neg(d,n)}+\sum_v \eta_v}$$

Remove token \((d,n)\) from the counts first ("leave-one-out", so it doesn't vote for itself), then resample its topic from this ratio: a document-affinity term \((n_{d,k}+\alpha_k)\) times a corpus-wide word-affinity term. Cycle through every token, repeatedly, for many iterations.

Design Decision: why collapse at all?

Collapsing shrinks the state space and removes the strong coupling between \(\theta,\phi,z\) (all tightly linked through the same data) — this is why Griffiths & Steyvers' collapsed sampler mixes far faster than naively block-sampling \(\theta,\phi,z\) directly, and became the de facto standard.

🔑 Key Property

Both algorithms exploit the same conjugacy fact (Dirichlet + Categorical/Multinomial ⇒ closed form). VI uses it to get closed-form coordinate-ascent updates for an approximate \(q\). Gibbs uses it to marginalize away the continuous parameters entirely, sampling only discrete assignments from simple count ratios.

Why It Works — The Math
▼

The ELBO (Variational EM)

By Jensen's inequality, for any distribution \(q\):

$$\log p(w\mid\alpha,\eta) \;\geq\; \mathbb{E}_q\Big[\log\frac{p(\theta,\phi,z,w\mid\alpha,\eta)}{q(\theta,\phi,z)}\Big] \;\triangleq\; \mathcal{L}(q)$$

The gap is exactly \(\text{KL}(q\,\|\,p)\), so maximizing \(\mathcal{L}(q)\) minimizes the distance from \(q\) to the true posterior within the factorized family. Coordinate ascent on \(\mathcal{L}(q)\) — fix all factors but one, optimize it in closed form, cycle — provably never decreases \(\mathcal{L}\), which is VI's convergence guarantee (to a local optimum; the ELBO is non-convex jointly).

Deriving the Collapsed Conditional

Integrating out \(\theta,\phi\) from the joint gives products of multivariate Beta functions:

$$p(z,w\mid\alpha,\eta) = \prod_{d=1}^{D}\frac{B(n_d+\alpha)}{B(\alpha)}\cdot\prod_{k=1}^{K}\frac{B(n_k+\eta)}{B(\eta)}$$

Taking the ratio "token \((d,n)\) included" vs. "excluded" cancels almost all Gamma functions (using \(\Gamma(x+1)=x\,\Gamma(x)\)), leaving the simple integer-count ratio used above. This is exact — no approximation, unlike the VI derivation.

Convergence Guarantees

VI: ELBO is monotonically non-decreasing; converges to a stationary point — generally only a local optimum. Gibbs: the Markov chain over \(z\) is ergodic under mild conditions, so its stationary distribution is exactly \(p(z\mid w,\alpha,\eta)\) — post-burn-in samples are asymptotically exact draws, with no fixed bias (unlike VI).

⚠️ Common Misconception

"Gibbs is exact, so it's always better than VI." True only in the limit of infinite samples — with a finite compute budget, Gibbs gives noisy, autocorrelated draws whose accuracy depends on mixing time, while VI gives a fast, reproducible, but structurally biased point estimate. For huge corpora under a time budget, biased-but-fast (stochastic) VI often wins in practice.

Key Takeaways
▼

When to use collapsed Gibbs:

  • Small-to-medium static corpora where topic interpretability matters more than speed
  • Offline research / benchmarking where you can afford multiple chains + burn-in
  • You need genuinely unbiased (asymptotically) posterior samples, not a point estimate

When to use variational EM (batch or stochastic/online):

  • Large or continuously-growing corpora needing fast, parallel, reproducible inference
  • Production topic-model services under a latency/compute budget
  • Streaming data where the model must update incrementally without a full retrain
💡 The Core Trade-off

Both exploit the same Dirichlet-Multinomial conjugacy. VI trades exactness for a fast, deterministic, but biased optimization. Gibbs trades speed/determinism for asymptotic unbiasedness via a stochastic Markov chain. Neither is "wrong" — they sit at different points on the same bias/speed trade-off curve.
