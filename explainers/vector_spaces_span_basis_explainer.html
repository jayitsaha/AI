Vector Spaces, Subspaces, Span & Basis

The geometric and algebraic language underlying all of linear algebra — and modern ML
Foundational Linear Algebra Math Foundations Part I · Section 1.1
1
Understanding the Concepts
▼

What is a vector space? A vector space is a collection of objects (called vectors) where you can do two things: add any two vectors together, and multiply any vector by a number (called a scalar). The results always stay inside the same collection. Think of it as a "universe" that is closed under addition and scaling.

What is span? The span of a set of vectors is the set of all vectors you can make by scaling and adding those vectors together. If you have two non-parallel arrows in 3D, their span is the entire flat plane those arrows lie in — every point on that plane can be reached by combining the two arrows in some way.

What is a basis? A basis is the smallest set of vectors whose span equals the entire space — a minimal "recipe kit." You can write any vector in the space as a unique combination of basis vectors. Your familiar x-y coordinate axes form a basis for 2D space.

If you remember one thing

A basis is a set of vectors that is both spanning (reaches everywhere in the space) and linearly independent (no vector is redundant). The number of basis vectors equals the dimension of the space. This number — dimension — is the most fundamental invariant in linear algebra.

2
How These Concepts Work Internally
▼

The Vector Space Axioms

A vector space \(V\) over field \(\mathbb{F}\) (usually \(\mathbb{R}\)) must satisfy 8 axioms. The key ones: closure under addition (\(\mathbf{u}+\mathbf{v} \in V\)), closure under scalar multiplication (\(c\mathbf{v} \in V\)), existence of a zero vector, and distributive/associative laws. These axioms guarantee geometry works the same way everywhere in the space.

Linear Independence — The Heart of It All

Vectors \(\mathbf{v}_1, \ldots, \mathbf{v}_k\) are linearly independent if the only solution to

$$c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \cdots + c_k \mathbf{v}_k = \mathbf{0}$$

is the trivial one \(c_1 = c_2 = \cdots = c_k = 0\). Geometrically: no vector points in a direction that the others already cover. If vectors are dependent, at least one is redundant — it can be expressed as a combination of the rest.

Subspaces

A subspace \(W \subseteq V\) is a subset that is itself a vector space: it contains the zero vector, is closed under addition, and closed under scalar multiplication. Examples in \(\mathbb{R}^3\): any line through the origin (1D subspace), any plane through the origin (2D subspace), the origin alone (0D), and all of \(\mathbb{R}^3\) (3D). Notice: a plane NOT through the origin is NOT a subspace — it fails closure (adding two vectors can leave the plane).

Key Property — The Basis Theorem

Every vector space has a basis, and all bases of the same space have the same number of vectors. That number is the dimension \(\dim(V)\). This is why dimension is well-defined and why different coordinate systems (different bases) all capture the same space.

The Span–Independence–Basis Hierarchy

Given \(n\) vectors in \(\mathbb{R}^m\):

  • Too few / dependent: span is a strict subspace — you can't reach everywhere
  • Too many / dependent: span may be the full space but they're not a basis (redundant vectors)
  • Just right — a basis: spanning + independent; dimension exactly \(= k\)
3
Why It Works — The Math
▼

Coordinates and Change of Basis

Given a basis \(\mathcal{B} = \{\mathbf{b}_1, \ldots, \mathbf{b}_n\}\) for \(V\), every vector \(\mathbf{v} \in V\) has a unique representation:

$$\mathbf{v} = c_1 \mathbf{b}_1 + c_2 \mathbf{b}_2 + \cdots + c_n \mathbf{b}_n$$

The scalars \((c_1, \ldots, c_n)\) are the coordinates of \(\mathbf{v}\) in basis \(\mathcal{B}\). Uniqueness follows from independence; existence follows from spanning. Change of basis is then a matrix multiplication: if \(B\) has the basis vectors as columns, then \([\mathbf{v}]_{\mathcal{B}} = B^{-1}\mathbf{v}\).

Rank-Nullity Theorem

For a linear map \(T: V \to W\), the four fundamental subspaces (column space, null space, row space, left null space) satisfy:

$$\operatorname{rank}(T) + \operatorname{nullity}(T) = \dim(V)$$

This deep theorem says: the dimensions of "where the map goes" plus "what it kills" always sum to the input dimension. It underpins the solvability conditions for \(A\mathbf{x} = \mathbf{b}\).

Gram-Schmidt: Building an Orthonormal Basis

Given any basis \(\{\mathbf{v}_1, \ldots, \mathbf{v}_n\}\), Gram-Schmidt constructs an orthonormal basis \(\{\mathbf{e}_1, \ldots, \mathbf{e}_n\}\) by successively projecting out components:

$$\mathbf{u}_k = \mathbf{v}_k - \sum_{j=1}^{k-1} \frac{\mathbf{v}_k \cdot \mathbf{u}_j}{\mathbf{u}_j \cdot \mathbf{u}_j} \mathbf{u}_j, \quad \mathbf{e}_k = \frac{\mathbf{u}_k}{\|\mathbf{u}_k\|}$$
Common Misconception

The span of \(\{(1,0), (2,0)\}\) in \(\mathbb{R}^2\) is just the x-axis — a 1D subspace, not all of \(\mathbb{R}^2\). Two vectors do NOT automatically span a 2D space; they must be linearly independent. Always check independence before claiming dimension equals the number of vectors.

5
Key Takeaways
▼

Why this matters for ML:

  • Embeddings — word vectors live in a high-dimensional vector space; directions capture semantics
  • PCA — finds the subspace (lower-dimensional) that captures the most variance; basis = principal components
  • Neural network layers — each linear layer is a change of basis followed by a nonlinearity
  • SVD — decomposes a matrix into orthonormal bases for its four fundamental subspaces
  • Rank & solvability — \(A\mathbf{x} = \mathbf{b}\) is solvable iff \(\mathbf{b}\) is in the column space (span of columns) of \(A\)
The Core Hierarchy

Vector Space ⊇ Subspace ⊇ Span of a set; and Basis = minimal spanning set = maximally independent set. Dimension is the invariant shared by all bases of the same space.

When to think about subspaces vs full space

  • Dimensionality reduction: map into a low-dim subspace (PCA, autoencoders)
  • Null space of A reveals the "kernel" — inputs that produce zero output
  • Column space tells you which targets \(\mathbf{b}\) are achievable by \(A\mathbf{x} = \mathbf{b}\)

Code Trace — NumPy Implementation
▼
import numpy as np
# ── Vector space: R^3 ──────────────────────────────────
v1 = np.array([2.0, 1.0, 0.0]) # first vector
v2 = np.array([0.0, 1.0, 1.0]) # second vector
v3 = np.array([2.0, 3.0, 2.0]) # v3 = v1 + 2*v2 — DEPENDENT!
# ── Check linear independence via rank ─────────────────
A = np.column_stack([v1, v2, v3]) # shape (3, 3)
rank = np.linalg.matrix_rank(A) # rank = 2 (not 3!)
print(f"rank = {rank}") # → 2: v3 is redundant
# ── Span: express target as linear combination ──────────
target = np.array([4.0, 5.0, 3.0]) # is this in span(v1,v2)?
B = np.column_stack([v1, v2])
coeffs, res, _, _ = np.linalg.lstsq(B, target, rcond=None)
in_span = np.allclose(res, 0, atol=1e-9)
print(f"coeffs: {coeffs}") # → [2., 3.] i.e. 2*v1 + 3*v2
print(f"in span: {in_span}") # → True
# ── Gram-Schmidt: build orthonormal basis ───────────────
def gram_schmidt(vecs):
basis = []
for v in vecs:
u = v.copy().astype(float)
for b in basis:
u -= np.dot(u, b) * b # subtract projection
if np.linalg.norm(u) > 1e-10:
basis.append(u / np.linalg.norm(u)) # normalize
return np.array(basis)
Q = gram_schmidt([v1, v2]) # orthonormal basis for span(v1,v2)
print(f"Q shape: {Q.shape}") # → (2, 3): 2 orthonormal vecs in R^3
print(f"Q @ Q.T:\n{Q @ Q.T}") # → identity (orthonormal check)
# ── Subspace: column space and null space of a matrix ───
M = np.array([[1,2,3],[0,1,1],[0,0,0]]) # rank-2 matrix
U, S, Vt = np.linalg.svd(M)
col_space = U[:, :2] # basis for column space (rank=2)
null_space = Vt[2:].T # basis for null space (dim = n - rank = 1)
