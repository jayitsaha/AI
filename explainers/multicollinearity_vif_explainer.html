Multicollinearity: VIF & Condition Number

Diagnosing and remedying correlated predictors in linear regression
Intermediate Classical ML Linear Regression O(p³) diagnosis
1
Understanding Multicollinearity
▼

What is it? Multicollinearity occurs when two or more predictor variables in a linear regression model are highly correlated with each other. The model can still fit the data, but it can no longer reliably tell which predictor is causing the outcome — the coefficient estimates become wildly unstable and their standard errors balloon.

Analogy: Imagine trying to determine how much each of two nearly-identical twins contributed to a group project. Their behavior is so similar you can't separate their individual contributions — you know the total, but attributing it is ambiguous. Add one twin or remove one, and your whole story changes. That's multicollinearity: the outcome is fine, but individual predictor contributions are indeterminate.

💡 If you remember one thing

Multicollinearity inflates the variance of coefficient estimates without biasing them. Diagnosis: VIFj = 1/(1 − R²j) quantifies inflation per predictor; the design-matrix condition number \(\kappa(X^\top X)\) flags global near-singularity. Ridge regression is the canonical remedy.

2
How Multicollinearity Breaks OLS
▼

The Core Problem: Near-Singular Design Matrix

OLS computes \(\hat{\beta} = (X^\top X)^{-1} X^\top y\). If two predictors are perfectly correlated, \(X^\top X\) is singular — its inverse does not exist. Near-perfect correlation makes \(X^\top X\) ill-conditioned: tiny perturbations in \(y\) produce enormous swings in \(\hat{\beta}\). The variance of each coefficient is:

$$\operatorname{Var}(\hat{\beta}_j) = \sigma^2 \cdot [(X^\top X)^{-1}]_{jj} = \sigma^2 \cdot \frac{1}{1 - R_j^2} \cdot \frac{1}{\sum_i (x_{ij} - \bar{x}_j)^2}$$

where \(R_j^2\) is the coefficient of determination from regressing \(X_j\) on all other predictors. As collinearity increases, \(R_j^2 \to 1\), making \((1-R_j^2) \to 0\) and \(\operatorname{Var}(\hat{\beta}_j) \to \infty\).

VIF: Variance Inflation Factor

The VIF for predictor \(j\) isolates exactly how much the collinearity inflates its coefficient variance compared to an orthogonal design:

$$\text{VIF}_j = \frac{1}{1 - R_j^2}$$

A VIF of 1 means no inflation (predictor \(j\) is uncorrelated with all others). VIF = 5 means the variance is 5× larger than it would be in an orthogonal design. Rules of thumb: VIF > 5 is concerning; VIF > 10 is severe.

Condition Number: Global Diagnosis

The condition number of the Gram matrix \(X^\top X\) is the ratio of its largest to smallest eigenvalue:

$$\kappa(X^\top X) = \frac{\lambda_{\max}}{\lambda_{\min}}$$

Equivalently, \(\kappa(X) = \sigma_{\max}/\sigma_{\min}\) using singular values of \(X\). A condition number \(> 30\) suggests moderate multicollinearity; \(> 1000\) indicates severe numerical problems. Unlike VIF (per-predictor), the condition number is a single global signal.

🔑 Key Property

Multicollinearity does not bias \(\hat{\beta}\) — the estimates are correct in expectation. It inflates their variance, making individual coefficients unreliable. Predictions on the observed data range remain stable; out-of-sample extrapolation degrades severely.

Ridge as the Remedy

Ridge regression adds a penalty \(\lambda \|\beta\|^2\) to the OLS objective, shrinking coefficients toward zero. The ridge estimator:

$$\hat{\beta}_{\text{ridge}} = (X^\top X + \lambda I)^{-1} X^\top y$$

The added \(\lambda\) bumps the smallest eigenvalue, reducing the condition number from \(\kappa\) to \(\kappa/( 1 + \lambda/\lambda_{\min})\) and directly reducing coefficient variance at the cost of introducing a small bias.

3
Why It Works — Deep Math
▼

Eigendecomposition of the Gram Matrix

Write \(X^\top X = Q \Lambda Q^\top\) where \(\Lambda = \operatorname{diag}(\lambda_1, \ldots, \lambda_p)\) and \(Q\) is orthogonal. Then:

$$(X^\top X)^{-1} = Q \Lambda^{-1} Q^\top, \quad [(X^\top X)^{-1}]_{jj} = \sum_{k=1}^p \frac{q_{jk}^2}{\lambda_k}$$

When \(\lambda_k \approx 0\), the term \(q_{jk}^2 / \lambda_k\) dominates and explodes. This is exactly why a small eigenvalue (near-singular direction) inflates the variance of all coefficients that have any component in that direction.

VIF from Auxiliary Regression — Derivation

Partition \(X = [X_j, X_{-j}]\). The OLS projection of \(X_j\) onto \(X_{-j}\) has residuals \(\tilde{x}_j = (I - H_{-j}) x_j\) where \(H_{-j} = X_{-j}(X_{-j}^\top X_{-j})^{-1} X_{-j}^\top\). Then:

$$[(X^\top X)^{-1}]_{jj} = \frac{1}{\|\tilde{x}_j\|^2} = \frac{1}{\sum_i x_{ij}^2 \cdot (1 - R_j^2)} \implies \text{VIF}_j = \frac{1}{1 - R_j^2}$$

Ridge Bias-Variance Trade-off

In the rotated basis \(\alpha = Q^\top \beta\), ridge shrinks each component by a factor:

$$\hat{\alpha}_k^{\text{ridge}} = \frac{\lambda_k}{\lambda_k + \lambda} \hat{\alpha}_k^{\text{OLS}}$$

The shrinkage factor \(\lambda_k / (\lambda_k + \lambda)\) is smallest (most shrinkage) for small eigenvalue directions — exactly the directions corrupted by collinearity. This is the bias-variance trade-off: we accept bias in the ill-determined directions to dramatically reduce variance.

⚠️ Common Pitfall

High VIF does not mean a predictor should be dropped. It means its individual coefficient is unreliably estimated. If the goal is prediction (not interpretation), multicollinearity may be irrelevant — ridge or elastic net handle it implicitly. Only drop a predictor if it is substantively redundant.

n = 100
X = np.random.multivariate_normal([0,0], [[1,rho],[rho,1]], n)
# VIF for X1: regress X1 on X2, get R²
X2_col = X[:, 1].reshape(-1, 1)
r2 = LinearRegression().fit(X2_col, X[:,0]).score(X2_col, X[:,0])

# Condition number of X'X
gram = X.T @ X

💡 Summary

Always check VIF (>10 = red flag) and condition number (>30 = check; >1000 = severe). If predicting, ridge usually suffices. If interpreting coefficients, consider collecting orthogonal data, centering, or PCA regression. Never panic-drop predictors just because VIF is high — check if the predictor is theoretically important.

Production Code

Diagnosing Multicollinearity in Python

import numpy as np import pandas as pd from numpy.linalg import cond from sklearn.linear_model import LinearRegression, Ridge def compute_vif(X_df): """Compute VIF for each column in DataFrame X.""" vifs = {} cols = X_df.columns.tolist() for j, col in enumerate(cols): others = [c for c in cols if c != col] y_j = X_df[col].values X_j = X_df[others].values r2 = LinearRegression().fit(X_j, y_j).score(X_j, y_j) vifs[col] = 1.0 / (1.0 - r2) # VIF = 1/(1-R²) return pd.Series(vifs, name="VIF") def condition_number(X_arr): """Condition number of the Gram matrix X'X.""" gram = X_arr.T @ X_arr return cond(gram) # lambda_max / lambda_min # Example rng = np.random.default_rng(42) n = 200 rho = 0.92 # high collinearity X_arr = rng.multivariate_normal([0,0], [[1,rho],[rho,1]], n) X_df = pd.DataFrame(X_arr, columns=["X1","X2"]) print(compute_vif(X_df)) # X1 12.76 ← severe (>10) # X2 12.76 print(f"Condition number: {condition_number(X_arr):.1f}") # Condition number: 24.4 ← approaching problematic # Ridge remedy y = 2*X_arr[:,0] + 0.5*X_arr[:,1] + rng.standard_normal(n) ridge = Ridge(alpha=1.0).fit(X_arr, y) ols = LinearRegression().fit(X_arr, y) print("OLS coef:", ols.coef_.round(3)) # wildly unstable print("Ridge coef:", ridge.coef_.round(3)) # stable, slightly shrunk
