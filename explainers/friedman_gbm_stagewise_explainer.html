Friedman's GBM: Stagewise Additive Modeling

Forward stagewise additive modeling via functional gradient descent — the algorithmic heart of XGBoost, LightGBM, and CatBoost.

Advanced Classical ML Boosting Must Know
1
The Core Idea

Gradient Boosting Machines (Friedman, 2001) build a strong predictor by summing many weak ones — specifically, shallow decision trees. The key insight: instead of fitting each new tree to the original labels, fit it to the negative gradient of the loss with respect to the current model's predictions.

One-Sentence Summary

GBM = gradient descent in function space: each stage adds a tree that points in the direction that reduces loss fastest.

Real-world analogy. A committee of advisors gives a forecast. The first advisor guesses. The second does not repeat the first's guess — instead, they focus only on what the first got wrong. The third focuses on what both got wrong. Each new member specialises in the remaining errors. That's GBM.

Key Invariant

At every stage \(m\), the pseudo-residuals \(r_{im} = -\left[\dfrac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}\) are the steepest descent direction in function space. Fitting a tree to them performs one step of gradient descent.

2
The Forward Stagewise Algorithm

Friedman frames boosting as forward stagewise additive modeling (FSAM): we want the best additive expansion \(F(x) = \sum_{m=1}^{M} \nu \cdot h_m(x)\) where each \(h_m\) is a base learner (tree) and \(\nu\) is the shrinkage (learning rate).

Rather than optimising all trees jointly (intractable), FSAM freezes previously fitted trees and only optimises the next one greedily:

$$F_m(x) = F_{m-1}(x) + \nu \cdot h_m(x)$$

where \(h_m\) minimises \(\sum_i L(y_i, F_{m-1}(x_i) + h_m(x_i))\). The gradient-descent analogy replaces exact minimisation with a tree fit to the negative gradient — one Newton step in function space.

Pseudo-Residual Formula

$$r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$$

For squared-error loss \(L = \tfrac{1}{2}(y-F)^2\): \(r_{im} = y_i - F_{m-1}(x_i)\) — exactly the ordinary residual. For logloss: \(r_{im} = y_i - p_i\). For absolute loss: \(r_{im} = \operatorname{sign}(y_i - F_{m-1}(x_i))\).

Leaf values. After fitting a tree structure, Friedman optimises each leaf value \(\gamma_{jm}\) independently to minimise the loss:

$$\gamma_{jm} = \underset{\gamma}{\operatorname{argmin}} \sum_{x_i \in R_{jm}} L(y_i,\, F_{m-1}(x_i) + \gamma)$$

For squared-error this gives the mean of residuals in the leaf; for logloss it requires a Newton step.

Common Misconception

GBM does not fit trees to residuals in general — that is only true for squared-error loss. The correct statement is: GBM fits trees to negative gradients of whatever loss function you specify. For logloss, these pseudo-residuals equal \(y_i - \hat{p}_i\), not raw label residuals.

Mathematical Foundation

The full GBM algorithm (Algorithm 1 from Friedman 2001):

  1. Initialise \(F_0(x) = \underset{\gamma}{\operatorname{argmin}} \sum_i L(y_i, \gamma)\)
  2. For \(m = 1, \ldots, M\):
    1. Compute pseudo-residuals: \(r_{im} = -\left[\dfrac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}\)
    2. Fit a regression tree \(h_m\) to \(\{(x_i, r_{im})\}_{i=1}^n\) giving leaves \(\{R_{jm}\}\)
    3. Compute leaf outputs: \(\gamma_{jm} = \underset{\gamma}{\operatorname{argmin}} \sum_{x_i\in R_{jm}} L(y_i, F_{m-1}(x_i)+\gamma)\)
    4. Update: \(F_m(x) = F_{m-1}(x) + \nu\sum_j \gamma_{jm}\mathbf{1}[x\in R_{jm}]\)
Why Functional Gradient Descent?

In parameter space, gradient descent updates \(\theta \leftarrow \theta - \eta \nabla_\theta L\). In function space, the "parameter" is \(F\) itself. The functional gradient \(\partial L / \partial F(x_i)\) tells us how to change the model's prediction at each training point. A regression tree fitted to these values approximates that gradient direction, then we take a step of size \(\nu\).

Shrinkage \(\nu\). Multiplying each tree by \(0 < \nu \leq 1\) is the single most important regulariser. It prevents the model from committing too aggressively to any one tree. Empirically, smaller \(\nu\) needs more trees \(M\) but generalises better — \(\nu \cdot M\) ≈ constant for similar test error.

$$\text{Effective capacity} \approx \frac{1}{\nu} \cdot J \cdot M$$

where \(J\) is the number of leaves per tree. Typical choices: \(\nu \in [0.01, 0.1]\), \(M = 100\text{–}3000\), \(J = 2\text{–}8\).

Overfitting & Stochastic GBM

Friedman (2002) introduced subsampling: at each stage, draw a fraction \(\eta \in (0,1]\) of training rows without replacement. This adds variance-based regularisation (like bagging), speeds up training, and provides an OOB error estimate. Typical \(\eta = 0.5\text{–}0.8\).

Stage 1: a depth-1 split separates x₁ (leaf mean −1.2) from the rest (leaf mean ≈ +0.56). After applying with \(\nu=0.5\), MSE drops from 0.394 → 0.174. Shrinkage halves the tree's output, slowing descent but avoiding overfit.

Why residuals shrink by roughly ν each stage

For squared-error loss, each stage fits the residuals perfectly (a sufficiently deep tree), then scales by \(\nu\). The remaining residual is \((1-\nu)\) of the prior residual (for a single leaf). With stumps and overlapping leaves, shrinkage is approximate but the trend holds: residuals decay geometrically.

Decision Guide

Use Friedman GBM (sklearn's GradientBoostingClassifier) for small-to-medium datasets where you need a reference implementation. Use XGBoost/LightGBM for production: they add 2nd-order Taylor approximation of the loss (more stable leaf values), histogram splits, and regularisation terms in the objective.
