Credible Intervals vs Confidence Intervals

Two ways to express uncertainty — but with fundamentally different meanings
Intermediate Bayesian Inference Probability & Statistics HPD · Coverage Guarantee
1
Understanding the Difference
▼

What are they? Both credible intervals and confidence intervals are ways to communicate uncertainty about an unknown quantity. But they answer fundamentally different questions and are rooted in opposite philosophies of probability.

Credible Interval (Bayesian): A 95% credible interval is a region where you can say "given the data I observed, there is a 95% probability that the true parameter \(\theta\) lies here." The parameter \(\theta\) is treated as a random variable with a probability distribution. The interval is a direct posterior probability statement.

Confidence Interval (Frequentist): A 95% confidence interval is a procedure with the property that if you repeated it on many datasets, 95% of the resulting intervals would contain the true (fixed, unknown) parameter. For any specific interval you compute, the parameter either is or isn't inside — no probability applies to that individual interval.

💡 If you remember one thing

A credible interval makes a direct probability statement about \(\theta\): \(P(\theta \in [a,b] \mid \text{data}) = 0.95\). A confidence interval is a long-run coverage guarantee about the random interval, not about \(\theta\). The CI says "this type of interval covers \(\theta\) 95% of the time over repeated experiments" — NOT that there's a 95% chance your specific interval contains \(\theta\).

Analogy: Imagine shooting arrows at a target. A confidence interval is like saying "my technique, when used repeatedly, will land the arrow within 10 cm of the bullseye 95% of the time." A credible interval is like looking at where your specific arrow landed and saying "given where the arrow hit, the bullseye is probably in this region with 95% probability." One describes your long-run shooting skill; the other describes where the bullseye probably is given one specific shot.

2
How Each Is Constructed
▼

Credible Interval — The Bayesian Path

Start with a prior distribution \(p(\theta)\) encoding beliefs before seeing data. Observe data \(x\), then apply Bayes' theorem to get the posterior:

$$p(\theta \mid x) = \frac{p(x \mid \theta)\, p(\theta)}{p(x)}$$

A credible interval \([a, b]\) satisfies:

$$\int_a^b p(\theta \mid x)\, d\theta = 0.95$$

The most common choice is the Highest Posterior Density (HPD) interval: the shortest interval containing 95% of the posterior mass. For unimodal symmetric posteriors, HPD equals the equal-tails interval. For skewed posteriors, HPD gives a strictly shorter interval.

Confidence Interval — The Frequentist Path

Treat the data \(X_1, \ldots, X_n\) as random. Find an interval \([L(\mathbf{X}), U(\mathbf{X})]\) — whose endpoints are functions of the random data — such that:

$$P_\theta\!\bigl(L(\mathbf{X}) \le \theta \le U(\mathbf{X})\bigr) = 0.95 \quad \text{for all } \theta$$

For the normal model with known \(\sigma\): given \(\bar{X} = \frac{1}{n}\sum X_i\), the interval is:

$$\left[\bar{X} - z_{0.975}\frac{\sigma}{\sqrt{n}},\; \bar{X} + z_{0.975}\frac{\sigma}{\sqrt{n}}\right]$$

where \(z_{0.975} \approx 1.960\). The probability statement is about the random interval before data are collected — once \(\bar{X}\) is observed and the interval is pinned, \(\theta\) is fixed (not random) and no probability statement applies to whether it's inside.

🔑 The Key Asymmetry

Bayesian: \(\theta\) is random, data are fixed → \(P(\theta \in [a,b] \mid \text{data observed}) = 0.95\) is meaningful.
Frequentist: \(\theta\) is fixed, data are random → \(P(\text{interval covers } \theta) = 0.95\) is a statement about the procedure, not a specific interval.

⚠️ The Most Common Misconception

Saying "there's a 95% chance \(\theta\) is in my confidence interval" is the classic error. Once computed, a specific 95% CI either contains \(\theta\) or it doesn't — the "probability" is 0 or 1, not 0.95. The 95% refers to the long-run frequency of the procedure, not the result.

3
Numerical Example — Identical Data, Different Meanings
▼

Consider estimating a normal mean \(\theta\). Observed: \(n=20\) i.i.d. draws, known \(\sigma = 2\), sample mean \(\bar{x} = 3.0\).

Bayesian Setup

Prior: \(\theta \sim \mathcal{N}(0, 10^2)\) (weakly informative, centered at 0). With normal-normal conjugacy, the posterior is:

$$\theta \mid \mathbf{x} \sim \mathcal{N}\!\left(\mu_n,\; \sigma_n^2\right)$$

where the posterior precision \(\tau_n^{-2}\) adds prior and likelihood precisions:

$$\frac{1}{\sigma_n^2} = \frac{1}{\sigma_0^2} + \frac{n}{\sigma^2} = \frac{1}{100} + \frac{20}{4} = 5.01 \implies \sigma_n^2 \approx 0.1996,\; \sigma_n \approx 0.4468$$
$$\mu_n = \sigma_n^2\!\left(\frac{\mu_0}{\sigma_0^2} + \frac{n\bar{x}}{\sigma^2}\right) = 0.1996 \times \left(\frac{0}{100} + \frac{20 \times 3.0}{4}\right) \approx 2.994$$

95% credible interval (equal-tails = HPD for symmetric Normal):

$$[2.994 \pm 1.960 \times 0.4468] = [2.118,\; 3.870]$$

This means: \(P(\theta \in [2.118, 3.870] \mid \mathbf{x}) = 0.95\). Direct probability about \(\theta\).

Frequentist Setup

The classic 95% CI (known \(\sigma\)):

$$\left[3.0 \pm 1.960 \times \frac{2}{\sqrt{20}}\right] = [3.0 \pm 0.877] = [2.123,\; 3.877]$$

Interpretation: This specific interval \([2.123, 3.877]\) either does or doesn't contain \(\theta\). The "95%" means that over many experiments, 95% of such intervals would trap the true \(\theta\).

📐 Why They're Numerically Close Here

With a weak (diffuse) prior and large \(n\), the likelihood dominates and both intervals converge. Here they differ only at the 3rd decimal (\([2.118, 3.870]\) vs \([2.123, 3.877]\)) because the prior pulls the posterior mean very slightly toward 0 (from 3.0 to 2.994). With informative priors or small \(n\), they can differ dramatically.

Key Takeaways & When to Use Each
▼

Use a Credible Interval when:

  • You genuinely have prior knowledge to encode (historical data, domain expertise)
  • You want a direct probability statement about where \(\theta\) is
  • Small sample size — the prior provides regularization
  • Decision-making requires posterior probabilities (e.g., \(P(\theta > 0 \mid \text{data})\))

Use a Confidence Interval when:

  • No credible prior exists or you want prior-free inference
  • You need guaranteed coverage frequency regardless of the true \(\theta\)
  • Regulatory or scientific reporting requires frequentist standards
  • Large sample size where prior effect is negligible
💡 The Practical Punchline

In large samples with diffuse priors, credible intervals and confidence intervals are numerically nearly identical — but their meanings are always different. The credible interval is always answering the question you actually want to ask. The confidence interval answers a related but subtler question about the procedure's long-run behavior.

Code: From Scratch
▼
import numpy as np
from scipy import stats
# Data: n=20 observations, known sigma=2, x_bar=3.0
n, sigma, x_bar = 20, 2.0, 3.0
# ── FREQUENTIST: 95% Confidence Interval ──────────────────
z_crit = stats.norm.ppf(0.975) # 1.960
se = sigma / np.sqrt(n) # standard error
ci_lo = x_bar - z_crit * se # 2.123
ci_hi = x_bar + z_crit * se # 3.877
print(f"95% CI: [{ci_lo:.3f}, {ci_hi:.3f}]")
# Interpretation: the PROCEDURE covers theta 95% of the time.
# NOT: 95% prob theta is in [2.123, 3.877].
# ── BAYESIAN: 95% Credible Interval ───────────────────────
mu0, sigma0 = 0.0, 10.0 # Prior: N(0, 10^2)
# Posterior precision = prior precision + likelihood precision
post_prec = 1/sigma0**2 + n/sigma**2 # 5.01
post_var = 1.0 / post_prec # 0.1996
post_mean = post_var * (mu0/sigma0**2 + n*x_bar/sigma**2) # 2.994
cred_lo = post_mean - z_crit * np.sqrt(post_var) # 2.118
cred_hi = post_mean + z_crit * np.sqrt(post_var) # 3.870
print(f"95% CrI: [{cred_lo:.3f}, {cred_hi:.3f}]")
# Interpretation: P(theta in [2.118, 3.870] | data) = 0.95
# This IS a direct probability statement about theta.
# ── HPD for asymmetric posterior (general case) ────────────
posterior = stats.norm(loc=post_mean, scale=np.sqrt(post_var))
hpd_lo = posterior.ppf(0.025) # = cred_lo for symmetric
hpd_hi = posterior.ppf(0.975) # = cred_hi for symmetric
