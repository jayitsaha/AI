Layer Normalization Placement: Post-LN vs Pre-LN

Moving one operation before or after a residual add decides whether your transformer needs a warmup schedule — or trains at all past 50 layers
Advanced Transformer Architecture Optimization Gradient Scale · Depth-Critical
1
Understanding Post-LN vs Pre-LN
▼

What is it? Every transformer block wraps a sublayer (self-attention or a feed-forward network) in a residual connection and a LayerNorm. The only question is where the normalization sits relative to the residual add. Post-LN (the original 2017 "Attention Is All You Need" design) normalizes after adding the sublayer output to the residual stream: \(x_{l+1} = \mathrm{LN}(x_l + \mathrm{Sublayer}(x_l))\). Pre-LN (used by GPT-2, GPT-3, LLaMA, and almost every modern LLM) normalizes the sublayer's input instead, and adds its raw output straight onto the stream: \(x_{l+1} = x_l + \mathrm{Sublayer}(\mathrm{LN}(x_l))\).

Analogy: Think of the residual stream as a relay race baton. In Pre-LN, the baton itself is never touched — each runner just glances at a photocopy of it (the normalized copy), does their work, and tapes their contribution onto the original baton. The baton is always intact and can be handed straight back to the start if you ever need to retrace the race (a clean gradient path). In Post-LN, every runner literally repaints the baton before passing it on. Nothing is lost, but now retracing the race means undoing N layers of repainting — and if the paint (LayerNorm's rescaling) is uneven early in training, the trace can blow up or vanish.

💡 If you remember one thing

Pre-LN keeps the residual stream as an unnormalized running sum, giving gradients a clean identity path straight back to the embeddings — stable at any depth, but the stream's variance grows with depth. Post-LN renormalizes the stream itself every layer, which bounds its scale but forces gradients through N extra LayerNorm Jacobians — unstable at init unless you carefully warm up the learning rate.

2
How Placement Shapes the Forward & Backward Pass
▼

Forward Pass: What Happens to the Residual Stream

In Post-LN, \(\mathrm{LN}\) is the last operation applied before the stream is handed to the next block. Because LayerNorm rescales its input to zero mean / unit variance (per token, across the feature dimension) and then applies a learned affine \((\gamma,\beta)\), the output of every single block has essentially the same scale — roughly unit variance forever, no matter how deep the stack is. The stream never grows, but it also never remembers its own history in raw form: each layer only ever sees a freshly-renormalized version of "everything so far."

In Pre-LN, \(\mathrm{LN}\) only touches the copy that is fed into the sublayer; the sublayer's output is added unnormalized to \(x_l\). If each sublayer contributes output with roughly unit variance (a reasonable approximation near initialization, since its input was just normalized), then \(\operatorname{Var}(x_l) \approx \operatorname{Var}(x_{l-1}) + 1\), so \(\operatorname{Var}(x_l) \approx l\) and \(\lVert x_l \rVert \approx \sqrt{l}\). The residual stream's norm grows roughly as the square root of depth — this is the well-documented Pre-LN "residual stream variance growth."

Backward Pass: Where the Gradient Path Breaks (or Doesn't)

Differentiate the Pre-LN recursion: \(\dfrac{\partial x_L}{\partial x_l} = I + \dfrac{\partial \mathrm{Sublayer}(\mathrm{LN}(x_l))}{\partial x_l}\). The identity matrix \(I\) is always present — there is a direct, untouched shortcut from the loss all the way back to layer \(l\), for every \(l\), regardless of network depth \(L\). This is exactly the ResNet argument (He et al., 2016) applied to transformers.

Differentiate the Post-LN recursion instead: \(x_{l+1} = \mathrm{LN}(x_l + \mathrm{Sublayer}(x_l))\), so \(\dfrac{\partial x_{l+1}}{\partial x_l} = J_{\mathrm{LN}}\big(x_l + \mathrm{Sublayer}(x_l)\big)\cdot\Big(I + \dfrac{\partial \mathrm{Sublayer}(x_l)}{\partial x_l}\Big)\), where \(J_{\mathrm{LN}}\) is LayerNorm's Jacobian. There is no bare identity term any more — every layer's gradient must pass through a LayerNorm Jacobian, and \(J_{\mathrm{LN}}\) has a spectral norm of roughly \(1/\sigma\) where \(\sigma\) is the pre-normalization standard deviation. Multiplying \(L\) such Jacobians together is what makes Post-LN's gradient magnitude highly depth- and scale-sensitive at initialization.

Design Decision: Why Did the Original Transformer Use Post-LN, and Why Did Everyone Switch?

Vaswani et al. (2017) used Post-LN because it mirrors how normalization was used in earlier seq2seq / CNN work, and it empirically gives slightly better final quality once training succeeds (the stream is kept "clean" and rescaled every layer, which acts as a mild regularizer). But Post-LN's gradient instability at init only gets worse as depth \(L\) grows, so training beyond ~12 layers reliably requires a learning-rate warmup phase. Xiong et al. (2020, ICML), "On Layer Normalization in the Transformer Architecture," proved this formally and showed Pre-LN removes the need for warmup — which is why virtually every large modern LLM (GPT-2/3, LLaMA, PaLM) adopted Pre-LN as depth scaled into the dozens-to-hundreds of layers.

🔑 Key Property

Pre-LN's residual path contains a literal, un-transformed identity map from output to input — the same trick that let ResNets scale past 1000 layers. Post-LN has no such bare identity map: every layer's contribution is filtered through a LayerNorm Jacobian, so gradient magnitude is a product of \(L\) Jacobians rather than a sum with an identity term.

3
Why It Works — The Gradient-Scale Math
▼

Setup

Let a network have \(L\) residual sublayers with parameters \(\theta_1,\dots,\theta_L\). Write the residual stream after layer \(l\) as \(x_l\), with \(x_0\) the input embedding. Assume near initialization that each sublayer output \(\mathrm{Sublayer}(\cdot)\) has roughly unit variance per feature (standard init schemes are designed for this).

Pre-LN: The Telescoping Sum

Unrolling the Pre-LN recursion gives a telescoping sum rather than a nested composition:

$$x_L = x_0 + \sum_{l=1}^{L} \mathrm{Sublayer}_l\big(\mathrm{LN}(x_{l-1})\big)$$

Differentiating the loss \(\mathcal{L}\) with respect to an early layer's parameters uses the chain rule through this sum, and the identity term in \(\partial x_L/\partial x_l = I + (\cdots)\) means:

$$\left\lVert \frac{\partial \mathcal{L}}{\partial x_l} \right\rVert \;=\; \left\lVert \frac{\partial \mathcal{L}}{\partial x_L}\Big(I + \textstyle\sum(\cdots)\Big)\right\rVert \;\ge\; \left\lVert \frac{\partial \mathcal{L}}{\partial x_L}\right\rVert - \epsilon_l$$

so the gradient magnitude at any layer \(l\) is bounded below and does not shrink toward zero as \(L\) grows — this is Xiong et al.'s (2020) formal result: for Pre-LN, \(\mathbb{E}\left[\lVert \partial\mathcal{L}/\partial \theta_l \rVert\right] = \Theta(1/\sqrt{L})\) for every layer \(l\), i.e. depth-independent scale, uniformly small and never exploding.

Post-LN: The Nested Jacobian Product

Post-LN's chain rule has no telescoping shortcut — the gradient at layer \(l\) is a full product of \(L-l\) Jacobians, each dominated by a LayerNorm term:

$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L}\prod_{k=l}^{L-1} J_{\mathrm{LN}}(u_k)\Big(I + \tfrac{\partial \mathrm{Sublayer}_k(x_k)}{\partial x_k}\Big), \qquad u_k = x_k + \mathrm{Sublayer}_k(x_k)$$

Xiong et al. show this product concentrates so that the expected gradient magnitude of the parameters closest to the output is \(\Theta(1)\) — large — while gradients further from the output are comparatively suppressed, and crucially the output-layer gradient itself does not shrink with \(L\) the way a naive vanishing-gradient story would predict; instead it stays large at every depth. Combined with Adam's per-parameter learning-rate normalization, a large, poorly-scaled gradient at step 1 (before Adam's second-moment estimate has "seen" enough data to normalize it) causes a large, poorly-calibrated update — this is exactly what makes Post-LN training diverge without warmup.

Why Warmup Fixes It

A linear warmup schedule \(\eta(t) = \eta_{\max}\cdot\min(t/T_{warmup}, 1)\) keeps the effective step size near zero during the first \(T_{warmup}\) steps, while Adam's moving averages \(\hat m_t, \hat v_t\) accumulate enough samples to produce a well-calibrated, variance-reduced update direction. By the time \(\eta(t)\) reaches \(\eta_{\max}\), the large, poorly-scaled gradients from Post-LN's first few steps have already been smoothed by the optimizer state, so the update no longer diverges. Pre-LN does not need this crutch because its gradient magnitude is already well-scaled at \(t=0\).

⚠️ Common Pitfall

Pre-LN's stability is not free. Because \(\operatorname{Var}(x_l) \approx l\), each sublayer's fixed-scale contribution becomes a shrinking fraction of the total stream norm as \(l\) grows — a phenomenon documented as "representation collapse" / the "curse of depth" (Liu et al. 2020's Admin analysis; Wang et al. 2022's DeepNet paper). Very deep Pre-LN stacks can effectively behave like a much shallower ensemble, since late layers contribute vanishingly little to the final normalized output. Fixes include scaling residual branches (DeepNet's \(\alpha\)-scaling), Sandwich-LN (norm both before and after each sublayer, used in CogView/GLM-130B), or hybrid schemes.

💡 Decision Rule

Training a shallow (≤12 layer) model and can tune warmup carefully? Post-LN may squeeze out marginally better final quality. Training anything deep, at scale, with limited hyperparameter search budget — which describes essentially every modern LLM — use Pre-LN (or a hybrid like Sandwich-LN / DeepNet's scaled residuals to also curb representation collapse). This is exactly why the field converged on Pre-LN as models scaled from 6 layers to 100+.

Code Trace

import torch, torch.nn as nn
class PostLNBlock(nn.Module):
def __init__(self, d_model, sublayer):
super().__init__()
self.sublayer = sublayer
self.norm = nn.LayerNorm(d_model)
def forward(self, x):
# normalize AFTER the residual add
return self.norm(x + self.sublayer(x))
class PreLNBlock(nn.Module):
def __init__(self, d_model, sublayer):
super().__init__()
self.sublayer = sublayer
self.norm = nn.LayerNorm(d_model)
def forward(self, x):
# normalize the INPUT to the sublayer only
return x + self.sublayer(self.norm(x))
# --- measuring the effect: gradient norm at layer 0 ---
def probe_grad_at_input(block_cls, d_model=64, depth=48):
x0 = torch.randn(1, 8, d_model, requires_grad=True)
x = x0
for _ in range(depth):
ffn = nn.Sequential(nn.Linear(d_model, d_model), nn.GELU(),
nn.Linear(d_model, d_model))
x = block_cls(d_model, ffn)(x)
loss = x.sum()
loss.backward()
return x0.grad.norm().item()
# Post-LN: grad norm at x0 is erratic / blows up as depth grows
# Pre-LN: grad norm at x0 stays O(1) regardless of depth
print("Post-LN grad@input:", probe_grad_at_input(PostLNBlock, depth=48))
print("Pre-LN grad@input:", probe_grad_at_input(PreLNBlock, depth=48))
# Linear LR warmup — needed for Post-LN, optional for Pre-LN
def lr_at_step(t, warmup_steps, base_lr):
return base_lr * min(t / warmup_steps, 1.0)
