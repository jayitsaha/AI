1
Understanding Image Inpainting
▼

What is it? Image inpainting is the task of filling in missing or corrupted regions of an image in a semantically plausible and visually coherent way. It's like digital photo restoration, used for removing unwanted objects, repairing damaged photos, or even generating new content.

Analogy: Imagine an art restorer working on a damaged painting. They don't just "blur" the missing parts; they carefully analyze the surrounding brushstrokes, colors, and textures to infer what should be there, often drawing on their knowledge of the artist's style and the subject matter. Modern inpainting models act similarly, leveraging deep neural networks to "understand" image context and synthesize missing pixels.

Two prominent approaches for deep learning inpainting are Contextual Attention (CA) and LaMa (Large Mask Inpainting):

  • Contextual Attention (Yu et al., 2018): This method explicitly searches for relevant features in the known regions of the image to "borrow" and fill the missing parts. It's like a highly skilled puzzle solver, finding the best-matching pieces from the available context.
  • LaMa (Suvorov et al., 2021): LaMa tackles large missing regions and high-resolution images by employing Fast Fourier Convolutions (FFC) to achieve a massive receptive field, allowing it to synthesize content with a truly global understanding. Think of it as a clairvoyant artist who can imagine the whole picture even with huge chunks missing.
💡 If you remember one thing

Inpainting is about hallucinating missing content. Contextual Attention does this by explicitly finding and copying similar feature patches from the known regions. LaMa does this by using Fourier Convolutions to gain a global understanding of the image for synthesis.

2
How It Works Internally
▼

Contextual Attention (CA)

CA operates within an encoder-decoder architecture. The encoder extracts high-level features from the damaged image. For each patch in the masked region (the "query"), the network performs a search across all known patches (the "keys") in the feature map. This search is essentially a convolutional correlation (dot product similarity). The similarity scores are then normalized via a softmax function to produce attention weights. These weights are used to aggregate (a weighted sum) the corresponding "value" features from the known regions, which are then used to reconstruct the missing patch. This process is repeated for all masked patches, and the decoder upsamples these filled features back to pixel space.

  • Encoder-Decoder: Extracts features from known regions, reconstructs pixels.
  • Patch Matching: For a "query" patch in the hole, find the most similar "key" patches in the valid region.
  • Attention: Softmax over similarities to get weights, then aggregate "value" features.
  • Challenges: Can sometimes lead to repetitive textures if the best match is too similar, or blurring if no good match exists.

LaMa (Large Mask Inpainting)

LaMa addresses limitations of earlier methods, especially with large masks and high resolutions. Its core innovation is the use of Fast Fourier Convolutions (FFC). Unlike standard convolutions that have a limited local receptive field, FFCs perform convolutions in the frequency domain. This allows a single convolutional layer to effectively "see" and integrate information from the entire image, regardless of its size, without needing many stacked layers or dilated convolutions. This global receptive field is crucial for understanding context across large missing regions.

  • Fast Fourier Convolutions (FFC): Achieves a global receptive field by performing convolutions in the Fourier domain, allowing information to travel across long distances efficiently.
  • High-Resolution Robustness: Handles large masks and high-resolution images effectively due to the global context.
  • Loss Functions: Utilizes a strong perceptual loss (e.g., LPIPS) and adversarial training to ensure high-quality, realistic output.
  • Efficiency: FFCs are computationally efficient, often outperforming dilated convolutions for large receptive fields.
🔑 Key Property

Both Contextual Attention and LaMa aim for semantically coherent and visually consistent image infill. CA achieves this through explicit patch-wise feature matching and aggregation, while LaMa achieves it through a globally aware feature synthesis via Fast Fourier Convolutions.

3
Why It Works — The Math
▼

Contextual Attention: Patch Matching & Aggregation

Let \(F \in \mathbb{R}^{C \times H \times W}\) be the feature map extracted by the encoder. We divide \(F\) into overlapping patches. For a query patch \(q_i\) (from a masked region) and a set of key patches \(k_j\) (from known regions), their similarity is typically a dot product:

$$s_{ij} = \langle q_i, k_j \rangle$$

These similarities are then normalized using a softmax function to obtain attention weights \(\alpha_{ij}\). A temperature parameter \(\tau\) can be introduced to control the sharpness of the distribution (higher \(\tau\) makes it softer):

$$\alpha_{ij} = \frac{\exp(s_{ij} / \tau)}{\sum_{l \in \text{known}} \exp(s_{il} / \tau)}$$

Finally, the reconstructed feature for the query patch \(\hat{f}_i\) is a weighted sum of corresponding value features \(v_j\) from the known regions:

$$\hat{f}_i = \sum_{j \in \text{known}} \alpha_{ij} v_j$$

This \(\hat{f}_i\) then replaces the original masked feature at position \(i\), and the decoder converts the complete feature map back to an image.

LaMa: Global Context with Fourier Convolutions

LaMa's core, the Fast Fourier Convolution (FFC), replaces standard convolutions with a block that processes features in both spatial and frequency domains. The frequency branch performs convolution using element-wise multiplication in the Fourier domain (after FFT), achieving a global receptive field. The overall objective function for LaMa combines several terms:

$$L = \lambda_{rec} L_{rec} + \lambda_{perc} L_{perc} + \lambda_{adv} L_{adv}$$

Where \(L_{rec}\) is a reconstruction loss (e.g., L1) on the pixels, \(L_{perc}\) is a perceptual loss (e.g., LPIPS) comparing high-level features, and \(L_{adv}\) is an adversarial loss from a discriminator to make the inpainted regions indistinguishable from real image content. The FFC module's ability to propagate information globally allows these losses to be optimized effectively even for large masks.

⚠️ Common Pitfall

Contextual Attention can struggle with highly semantic or novel content within large masks, as it relies on finding similar existing patches. If no good match exists, it might "hallucinate" repetitive or blurry textures. LaMa mitigates this by synthesizing content with a more holistic, global understanding, but requires careful implementation of FFC and robust training with advanced loss functions.

Key Takeaways
▼

When to use Contextual Attention (CA):

  • For smaller, less complex masks where local texture or pattern matching is highly effective.
  • When computational efficiency for very large images is not the primary concern (relative to LaMa).
  • If you need a more explicit, interpretable "copy-paste" mechanism for infill.

When to use LaMa:

  • For large, arbitrary masks that cover significant portions of the image, requiring deep semantic understanding.
  • At high image resolutions where a global receptive field is critical for coherent results.
  • When speed and robustness are paramount, especially in real-world applications or production pipelines.
  • When the missing content is more complex and requires synthesis rather than just copying.

When NOT to use:

  • CA for very large masks or complex semantic gaps, as it may struggle to find appropriate matches and produce artifacts.
  • LaMa if the overhead of FFC (though efficient for large scale) is unnecessary for very small images or simple inpainting tasks.
  • Both methods require substantial training data and computational resources.
💡 One-Line Summary

Contextual Attention explicitly searches for and aggregates similar features from known regions, while LaMa employs Fast Fourier Convolutions to achieve a global receptive field for synthesizing missing content with holistic image understanding.

import numpy as np
import torch # or tensorflow
import torch.nn.functional as F
# --- Contextual Attention (Simplified) ---
def contextual_attention_step(features, mask, patch_size=3, temperature=0.1):
# features: (N, C, H, W), mask: (N, 1, H, W) (0 for masked, 1 for known)
N, C, H, W = features.shape
# 1. Extract query patches from masked region (padded with 0s)
queries = F.unfold(features * (1 - mask), kernel_size=patch_size, padding=patch_size//2) # (N, C*k*k, L_query)
# 2. Extract key and value patches from known region
keys = F.unfold(features * mask, kernel_size=patch_size, padding=patch_size//2) # (N, C*k*k, L_key)
values = keys # For simplicity, values are same as keys (can be separate)
# 3. Compute similarity (dot product) and attention weights
# queries: (N, C*k*k, L_query), keys: (N, C*k*k, L_key)
similarity = torch.einsum('ncl,nck->nlk', queries, keys) / (C * patch_size**2)**0.5 # (N, L_query, L_key)
attention_weights = F.softmax(similarity / temperature, dim=-1) # (N, L_query, L_key)
# 4. Aggregate value features using attention weights
# values: (N, C*k*k, L_key), attention_weights: (N, L_query, L_key)
aggregated_features = torch.einsum('nck,nlk->ncl', values, attention_weights) # (N, C*k*k, L_query)
# 5. Fold back aggregated features into feature map structure
# This is complex; conceptually, it fills the masked regions.
# For simplicity, let's assume we average over overlapping patches.
# In practice, a proper `fold` operation with mask handling is used.
reconstructed_features = F.fold(aggregated_features, output_size=(H,W), kernel_size=patch_size, padding=patch_size//2)
# Combine original known features with reconstructed masked features
output_features = features * mask + reconstructed_features * (1 - mask)
return output_features
# --- LaMa (Conceptual FFC Block) ---
class FFCBlock(torch.nn.Module):
def __init__(self, in_channels, out_channels):
super().__init__()
# Local branch (standard convolution)
self.local_conv = torch.nn.Conv2d(in_channels, out_channels // 2, kernel_size=3, padding=1)
# Global branch (Fourier convolution)
self.global_conv = torch.nn.Conv2d(in_channels, out_channels // 2, kernel_size=1, padding=0) # Placeholder for FFC logic
# In a real FFC, this would involve FFT, element-wise product, IFFT.
# The key is that the 'kernel' in frequency domain is global.
def forward(self, x):
local_out = self.local_conv(x)
global_out = self.global_conv(x) # This is where global context is infused
return torch.cat([local_out, global_out], dim=1) # Combine local and global features
