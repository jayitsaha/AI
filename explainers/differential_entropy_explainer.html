Differential Entropy

The continuous analogue of Shannon entropy — can go negative, not coordinate-invariant, maximised by the Gaussian for fixed variance.

Intermediate Information Theory Probability & Statistics Math-Heavy
1
Understanding Differential Entropy
▼

Entropy measures uncertainty or information content. For a discrete random variable, Shannon entropy is \(H = -\sum_i p_i \log p_i\) — always non-negative. But what happens when X is continuous — e.g., a Gaussian, uniform, or exponential distribution?

We can't just sum probabilities; we integrate a density. The result is differential entropy:

$$h(X) = -\int_{-\infty}^{\infty} f(x) \log f(x)\, dx$$

where \(f\) is the probability density function (PDF). The "log" is base \(e\) (nats) or base 2 (bits).

Real-world analogy

Think of a dart board. Discrete entropy measures how many distinct spots you might hit. Differential entropy measures how spread out your throws are. A tight cluster near the bullseye has low (even negative) differential entropy. A throw that could land anywhere on the board has high differential entropy. Unlike counting spots, the "spread" can be smaller than the reference unit, giving negative values.

The critical surprises compared to discrete entropy:

  • h(X) can be negative — a very concentrated distribution (e.g., σ = 0.1) gives h < 0.
  • h(X) is not coordinate-invariant — changing units (rescaling X by a constant) changes h.
  • Gaussian maximises h for fixed variance — this is the maximum-entropy theorem.
  • Relative entropy (KL divergence) stays coordinate-free and is always ≥ 0.
If you remember one thing

\(h(X) = -\int f \log f\,dx\) is the continuous entropy; it can be negative, changes under rescaling by \(\log|a|\), and the Gaussian achieves the maximum \(h = \tfrac{1}{2}\log(2\pi e\sigma^2)\) among all distributions with variance \(\sigma^2\).

2
Formal Definition & Key Properties
▼

Definition

Let \(X\) be a continuous random variable with PDF \(f : \mathbb{R} \to [0,\infty)\). The differential entropy is:

$$h(X) \;=\; -\int_{\mathcal{X}} f(x)\,\log f(x)\,dx$$

where \(\mathcal{X} = \{x : f(x) > 0\}\) is the support. The integral is taken over the support only (the convention \(0 \log 0 = 0\) extends it gracefully).

Closed-form examples

DistributionPDFDifferential Entropy (nats)
Gaussian \(\mathcal{N}(\mu,\sigma^2)\)\(\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}\)\(\frac{1}{2}\log(2\pi e\sigma^2)\)
Uniform \(\mathcal{U}[a,b]\)\(\frac{1}{b-a}\)\(\log(b-a)\)
Exponential \(\text{Exp}(\lambda)\)\(\lambda e^{-\lambda x}\)\(1 - \log\lambda\)
Laplace \(b\)-scale\(\frac{1}{2b}e^{-|x|/b}\)\(1 + \log(2b)\)
Gamma \(\text{Gamma}(k,\theta)\)—\(k + \log\theta + \log\Gamma(k) + (1-k)\psi(k)\)

Key properties

1. Can be negative. For Uniform\([0, \ell]\), h = \(\log \ell\), which is negative when \(\ell < 1\). For Gaussian, h < 0 when \(\sigma^2 < \frac{1}{2\pi e}\), i.e., \(\sigma < \frac{1}{\sqrt{2\pi e}} \approx 0.242\).

2. Scaling / coordinate-change rule. If \(Y = aX\) (linear scaling):

$$h(Y) = h(aX) = h(X) + \log|a|$$

More generally, for invertible differentiable \(g\), if \(Y = g(X)\):

$$h(Y) = h(X) + \mathbb{E}_X[\log|g'(X)|] = h(X) + \mathbb{E}[\log|J|]$$

where \(J = dg/dx\) is the Jacobian. This is the formal proof that h is not coordinate-invariant.

3. Chain rule. For jointly continuous \((X,Y)\):

$$h(X,Y) = h(X) + h(Y|X)$$

4. KL divergence (relative entropy). For two densities \(f, g\):

$$D_{\mathrm{KL}}(f \| g) = \int f(x)\log\frac{f(x)}{g(x)}\,dx \;\geq\; 0$$

KL divergence is coordinate-invariant (the Jacobians cancel). This is why it, not h, is the fundamental unit of information in continuous settings.

Common misconception

"Negative entropy means the distribution is impossible." — False. Differential entropy is not a probability; it can be negative when the PDF concentrates probability mass in a region smaller than the unit interval. What is always non-negative: mutual information \(I(X;Y) = h(X) + h(Y) - h(X,Y) \geq 0\), and KL divergence \(D_{\mathrm{KL}} \geq 0\).

Max-Entropy Theorem & Relative Entropy Fix
▼

The Maximum-Entropy Theorem for Continuous Distributions

Theorem: Among all continuous distributions with fixed mean \(\mu\) and variance \(\sigma^2\), the Gaussian \(\mathcal{N}(\mu, \sigma^2)\) has the maximum differential entropy:

$$h(f) \;\leq\; \frac{1}{2}\log(2\pi e\sigma^2) \;=\; h\!\left(\mathcal{N}(\mu,\sigma^2)\right)$$

with equality if and only if \(f = \mathcal{N}(\mu,\sigma^2)\) almost everywhere.

Proof sketch (via KL divergence)

Let \(f\) be any density with variance \(\sigma^2\), and let \(g = \mathcal{N}(\mu,\sigma^2)\). Since \(D_\mathrm{KL}(f\|g) \geq 0\):

$$0 \;\leq\; D_\mathrm{KL}(f\|g) = \int f\log\frac{f}{g}\,dx = -h(f) - \int f\log g\,dx$$

Now compute \(\int f \log g\, dx\) using the Gaussian log:

$$\log g(x) = -\frac{(x-\mu)^2}{2\sigma^2} - \frac{1}{2}\log(2\pi\sigma^2)$$
$$\int f\log g\,dx = -\frac{\mathbb{E}_f[(X-\mu)^2]}{2\sigma^2} - \frac{1}{2}\log(2\pi\sigma^2) = -\frac{1}{2} - \frac{1}{2}\log(2\pi\sigma^2) = -\frac{1}{2}\log(2\pi e\sigma^2)$$

where we used \(\mathbb{E}_f[(X-\mu)^2] = \sigma^2\) (same variance as g). Therefore:

$$0 \leq -h(f) + \frac{1}{2}\log(2\pi e\sigma^2) \;\implies\; h(f) \leq \frac{1}{2}\log(2\pi e\sigma^2)$$
Numerical check

Laplace with same variance \(\sigma^2 = 1\) (so \(b = 1/\sqrt{2}\)): \(h_\text{Laplace} = 1 + \log(2b) = 1 + \log(\sqrt{2}) \approx 1.347\) nats. Gaussian: \(h_\mathcal{N} = \tfrac{1}{2}\log(2\pi e) \approx 1.419\) nats. Indeed \(1.347 < 1.419\) — the Gaussian wins by \(\approx 0.072\) nats.

Why KL divergence rescues coordinate-invariance

Under a change of variables \(Y = g(X)\), both \(f_X(x)\) and \(f_Y(y)\) acquire a Jacobian factor \(|g'|\). In the KL divergence these Jacobians appear in both \(f\) and \(q\) and cancel exactly:

$$D_\mathrm{KL}(f_Y \| q_Y) = D_\mathrm{KL}(f_X \| q_X)$$

This is why information-theoretic quantities used in practice — mutual information, KL divergence, conditional entropy — are well-defined for continuous variables, whereas differential entropy alone is only a semi-invariant quantity useful in relative comparisons (e.g., entropy differences).

Why this matters in ML

The Gaussian max-entropy property justifies using Gaussians as priors (maximum-entropy prior given known variance), underpins the VAE latent space regularisation (KL to \(\mathcal{N}(0,I)\)), and explains why the Gaussian channel capacity formula has the \(\frac{1}{2}\log(1 + \text{SNR})\) form (Shannon's channel coding theorem). The coordinate-change formula is implicit in every change-of-variables in normalising flows: the log-det Jacobian correction is exactly \(\mathbb{E}[\log|J|]\).

Code: Computing Differential Entropy
▼

From scratch: differential entropy via numerical integration

import numpy as np
from scipy import integrate, stats
def h_gaussian(sigma): # h = 0.5 * log(2*pi*e*sigma^2)
return 0.5 * np.log(2 * np.pi * np.e * sigma**2)
def h_uniform(a, b): # h = log(b - a)
return np.log(b - a)
def h_exponential(lam): # h = 1 - log(lambda)
return 1.0 - np.log(lam)
def h_quadrature(pdf, support=(-10, 10)):
"""Compute h via Gaussian quadrature (exact for smooth PDFs)."""
def integrand(x):
f = pdf(x)
return -f * np.log(f + 1e-300) if f > 0 else 0.0
result, _ = integrate.quad(integrand, *support, limit=200)
return result
# -- Verification --
sigma = 1.0
pdf_N01 = lambda x: stats.norm.pdf(x, scale=sigma)
print(f"Gaussian s=1 analytical: {h_gaussian(sigma):.6f}") # 1.418939
print(f"Gaussian s=1 quadrature: {h_quadrature(pdf_N01):.6f}")
print(f"Uniform [0,1]: {h_uniform(0,1):.6f}") # 0.0
print(f"Uniform [0,0.5]: {h_uniform(0,0.5):.6f}") # -0.693 (negative!)
print(f"Exp(lambda=1): {h_exponential(1.0):.6f}") # 1.0

Production: scipy.stats + KL divergence

from scipy.stats import norm, expon, uniform
import numpy as np
# scipy .entropy() returns differential entropy in nats
print(norm(scale=1.0).entropy()) # 1.4189 N(0,1)
print(expon(scale=1.0).entropy()) # 1.0 Exp(1)
print(uniform(0, 1).entropy()) # 0.0 U[0,1]
# KL divergence between two Gaussians (analytical)
# KL(N(mu1,s1^2) || N(mu2,s2^2)) = log(s2/s1) + (s1^2+(mu1-mu2)^2)/(2*s2^2) - 0.5
def kl_gaussians(mu1, s1, mu2, s2):
return np.log(s2/s1) + (s1**2 + (mu1-mu2)**2)/(2*s2**2) - 0.5
print(kl_gaussians(0, 1, 0, 2)) # 0.3181 nats
# Coordinate-change: h(aX) = h(X) + log|a|
rng = np.random.default_rng(42)
x = rng.standard_normal(100_000) # X ~ N(0,1)
a = 3.0
y = a * x # Y = 3X ~ N(0,9)
h_x = norm(scale=1.0).entropy() # 1.4189
h_y = norm(scale=a).entropy() # h(X) + log(3) = 2.518
print(f"h(X) = {h_x:.4f}, h(3X) = {h_y:.4f}, diff = {h_y-h_x:.4f}, log3 = {np.log(3):.4f}")

Key Takeaways & Comparisons
▼

Differential entropy vs. discrete entropy

DimensionDiscrete H(X)Differential h(X)
DomainFinite/countableContinuous support
SignAlways ≥ 0Can be negative
Coordinate-invariant?Yes (bijections)No: changes by log|J|
Max-entropy dist.Uniform (fixed alphabet)Gaussian (fixed variance)
KL divergence≥ 0, coordinate-invariant≥ 0, coordinate-invariant
Used inCoding, compression, NLPVAEs, flows, channel capacity

When to use which

  • Use h(X) for comparing spreads within the same distribution family; in channel capacity formulas; in the VAE ELBO KL term (analytical Gaussian case).
  • Use KL divergence for any relative information measurement and training objectives; it is coordinate-invariant and always ≥ 0.
  • Use mutual information I(X;Y) for feature selection and independence testing — equals h(X) + h(Y) − h(X,Y) and is always ≥ 0.
  • Avoid bare h(X) for cross-parameterisation comparisons; the log|J| shift makes them meaningless.
Key ML connections

VAEs: KL(q||p) between Gaussians uses analytical h implicitly. Normalizing flows: log-likelihood = log p(z) + log|det J| — the exact coordinate-change rule. Gaussian channel capacity: C = ½log(1 + SNR) nats — Gaussian input maximises capacity by max-entropy theorem. MaxEnt NLP: feature-constrained distributions generalise the continuous max-entropy principle.
