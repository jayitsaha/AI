1
Understanding MLR — The Core Idea
▼

What is it? Multiple Linear Regression (MLR) fits a straight-surface (hyperplane) through data that has multiple input variables. You have \(n\) measurements, each with \(p\) features \((x_1, x_2, \ldots, x_p)\) and a numeric outcome \(y\). MLR finds the one hyperplane that minimises the total squared distance from the data points to the surface.

Analogy: Imagine predicting house price from size and number of bedrooms. OLS draws the "best flat" through the 3-D cloud of (size, bedrooms, price) points. "Best" means the sum of squared vertical distances (price errors) is as small as possible. The formula \(\hat{\beta} = (X^\top X)^{-1} X^\top y\) is the one-shot closed-form recipe that finds those optimal slope coefficients without any iterative search.

💡 If you remember one thing

The fitted value vector \(\hat{y} = X\hat{\beta} = Hy\) is literally the orthogonal projection of \(y\) onto the column space of \(X\). The hat matrix \(H = X(X^\top X)^{-1}X^\top\) does the projecting. The residual \(e = y - \hat{y}\) is always perpendicular to every predictor column.

Prerequisites you should know

Matrix multiplication, matrix inverse, the concept of column space (span of column vectors), and the idea of minimizing a squared-error loss. Simple linear regression (one predictor) helps but isn't required.

Key notation

Throughout: \(n\) = number of observations, \(p\) = number of predictors (not counting intercept), \(X \in \mathbb{R}^{n \times (p+1)}\) = design matrix (first column all ones), \(y \in \mathbb{R}^n\) = response vector, \(\beta \in \mathbb{R}^{p+1}\) = coefficient vector, \(\varepsilon \in \mathbb{R}^n\) = error vector.

2
The Matrix Machinery — How β̂ is Computed
▼

The Model

The linear model in matrix form is:

$$y = X\beta + \varepsilon, \quad \varepsilon \sim (0, \sigma^2 I_n)$$

where the design matrix \(X\) has rows \([1, x_{i1}, \ldots, x_{ip}]\) — the leading 1 encodes the intercept. We want \(\hat{\beta}\) that minimises the residual sum of squares (RSS):

$$\text{RSS}(\beta) = \|y - X\beta\|^2 = (y - X\beta)^\top(y - X\beta)$$

Deriving the Normal Equations

Expand RSS and differentiate with respect to \(\beta\):

$$\frac{\partial \text{RSS}}{\partial \beta} = -2X^\top y + 2X^\top X\beta = 0$$

This gives the normal equations:

$$X^\top X \,\hat{\beta} = X^\top y$$

Provided \(X\) has full column rank (\(\text{rank}(X) = p+1\)), \(X^\top X\) is positive definite and invertible, so:

$$\boxed{\hat{\beta} = (X^\top X)^{-1} X^\top y}$$

Why "normal" equations?

The word "normal" here means perpendicular (as in a normal to a surface). The normal equations say exactly that the residual vector \(e = y - X\hat{\beta}\) is perpendicular to the column space of \(X\): \(X^\top e = 0\). This geometric interpretation is the key to understanding everything else about MLR.

🔑 Key Property — BLUE by Gauss-Markov

Under the assumptions (linearity, full rank, \(\mathbb{E}[\varepsilon]=0\), \(\text{Var}(\varepsilon)=\sigma^2 I\)), the OLS estimator \(\hat{\beta}\) is the Best Linear Unbiased Estimator (BLUE): unbiased (\(\mathbb{E}[\hat{\beta}]=\beta\)) and minimum variance among all linear unbiased estimators. Its covariance is \(\text{Var}(\hat{\beta}) = \sigma^2 (X^\top X)^{-1}\).

3
Geometric Insight — Projection onto Column Space
▼

The most powerful way to understand MLR is geometric. Think of \(y \in \mathbb{R}^n\) as a vector in n-dimensional space. The columns of \(X\) — the predictor vectors \(x_1, \ldots, x_p\) and the all-ones intercept column — span a p+1 dimensional subspace of \(\mathbb{R}^n\) called the column space \(\text{col}(X)\).

ŷ is the orthogonal projection of y

Since we can only form combinations \(X\beta\) (i.e., vectors in \(\text{col}(X)\)), the closest point in \(\text{col}(X)\) to \(y\) — the one minimising \(\|y - X\beta\|^2\) — is the orthogonal projection of \(y\) onto \(\text{col}(X)\).

$$\hat{y} = X\hat{\beta} = X(X^\top X)^{-1} X^\top y = Hy$$

The matrix \(H = X(X^\top X)^{-1}X^\top\) is the hat matrix (or projection matrix) because it puts a "hat" on \(y\). It maps any vector \(y\) to its projection onto \(\text{col}(X)\).

Hat matrix properties — provable from H²=H and Hᵀ=H

$$H^2 = H \quad (\text{idempotent}) \qquad H^\top = H \quad (\text{symmetric}) \qquad \text{rank}(H) = p+1$$

Idempotent means projecting twice is the same as projecting once — you stay in the subspace. The complementary matrix \(M = I - H\) projects onto the orthogonal complement of \(\text{col}(X)\), and \(e = My = (I-H)y\).

Orthogonality of residuals — the fundamental theorem

Because \(e = (I-H)y\) and \(H(I-H) = H - H^2 = 0\):

$$X^\top e = X^\top(y - \hat{y}) = 0$$

This says the residual vector is orthogonal to every column of \(X\) — every predictor and the intercept column. Consequently, \(\sum e_i = 0\) (residuals sum to zero) and \(\sum x_{ij}e_i = 0\) for each predictor \(j\).

📐 Hat Matrix Numerical Trace (n=5, p=2)

For our 5-point dataset: diag(H) = [0.808, 0.233, 0.608, 0.975, 0.375]. These leverage values (\(h_{ii}\)) measure how far each point is from the centre of the predictor space. Point 4 (h=0.975) has extreme leverage — remove it and the fit changes dramatically. By construction, \(\text{tr}(H) = p+1 = 3\) and \(0 \le h_{ii} \le 1\).

⚠️ Invertibility Requires Full Column Rank

\((X^\top X)^{-1}\) exists iff \(\text{rank}(X) = p+1\), i.e., no predictor is a perfect linear combination of others. If predictors are collinear, \(X^\top X\) is singular (or near-singular), making estimates unstable. Fix: remove duplicates, use Ridge regression (\(X^\top X + \lambda I\))^{-1}, or use QR/SVD decomposition for numerical stability.

From-Scratch NumPy Implementation
▼

The code below implements MLR from scratch using only NumPy, mirroring every step in the interactive walkthrough. Each line is annotated to show which mathematical operation it performs.

import numpy as np
def mlr_fit(X_raw, y):
"""Multiple Linear Regression via normal equations β = (XᵀX)⁻¹Xᵀy.
X_raw : (n, p) array of raw features (no intercept column).
y : (n,) response vector.
Returns dict with beta, y_hat, residuals, H_diag, R_squared."""
n, p = X_raw.shape
# Step 1: Build design matrix — prepend column of ones for intercept
X = np.column_stack([np.ones(n), X_raw]) # shape (n, p+1)
# Step 2: Form Gram matrix XᵀX — O(n·(p+1)²)
XtX = X.T @ X # shape (p+1, p+1)
# Step 3: Form moment vector Xᵀy
Xty = X.T @ y # shape (p+1,)
# Step 4: Solve normal equations — use lstsq for numerical stability
# (avoids explicit inversion which can amplify round-off errors)
beta, _, _, _ = np.linalg.lstsq(XtX, Xty, rcond=None)
# Equivalent (but less stable): beta = np.linalg.inv(XtX) @ Xty
# Step 5: Fitted values ŷ = Xβ̂
y_hat = X @ beta # shape (n,)
# Step 6: Residuals e = y − ŷ
e = y - y_hat
# Step 7: Hat matrix diagonal (leverage) — full H = X @ inv(XtX) @ X.T
# Compute diag(H) efficiently without forming the full n×n matrix
XtX_inv = np.linalg.inv(XtX)
H_diag = np.einsum('ij,jk,ik->i', X, XtX_inv, X) # diag(X @ XtX_inv @ Xᵀ)
# Step 8: R² = 1 − RSS/TSS
RSS = e @ e
TSS = np.sum((y - y.mean())**2)
R2 = 1 - RSS / TSS
return {"beta": beta, "y_hat": y_hat, "e": e,
"H_diag": H_diag, "R2": R2}
# ── Example matching the interactive walkthrough ──
X_raw = np.array([[0.0, 0.0], [1.0, 0.5], [2.0, 1.0],
[0.5, 1.5], [1.5, 0.5]])
y = np.array([1.3, 4.1, 8.2, 7.0, 5.2])
res = mlr_fit(X_raw, y)
print("β̂:", res["beta"].round(4)) # [1.0558 1.7183 3.4083]
print("R²:", round(res["R2"], 4)) # 0.9881
# Verify orthogonality: Xᵀe ≈ 0
X = np.column_stack([np.ones(5), X_raw])
print("‖Xᵀe‖:", np.linalg.norm(X.T @ res["e"])) # ~1.7e-14
⚠️ Production gotcha: never use inv() on XᵀX directly

In production, use np.linalg.lstsq or QR decomposition (np.linalg.qr) instead of explicit matrix inversion. Direct inversion is numerically fragile when predictors are even mildly correlated — condition numbers balloon and estimates become unreliable. sklearn's LinearRegression uses LAPACK's DGELSD (divide-and-conquer SVD) internally.

Key Takeaways & When to Use
▼
MethodWhen to useCostNotes
Normal equations \(\hat{\beta}=(X^\top X)^{-1}X^\top y\)Small/medium datasets, p ≪ nO(np²) + O(p³)Closed-form; unstable when X near-singular
QR decompositionPreferred in practice (sklearn default)O(np²)More numerically stable than inverting XᵀX
SVDCollinear predictors, wide matrices (p≈n)O(np²)Most robust; underpins lstsq
Gradient descentVery large n where matrix ops are costlyO(np) per iterationMini-batch for massive datasets
Ridge (L2 reg.)Collinear predictorsO(np²) + O(p³)Replaces \((X^\top X)^{-1}\) with \((X^\top X + \lambda I)^{-1}\)

When to use the matrix normal equations:

  • n up to ~100k, p up to ~1000 — direct solve is fast enough
  • You need the exact closed-form solution (e.g., for deriving variance formulas)
  • Educational context — the formula reveals geometric structure

When NOT to use direct normal equations:

  • p is large and predictors are correlated — \(X^\top X\) near-singular, amplifies error
  • n > 10⁶ — assembling XᵀX is expensive; use mini-batch gradient descent instead
  • Regularisation needed — switch to Ridge/Lasso
  • p > n ("wide" data) — \(X^\top X\) is rank-deficient; must regularise or use pseudoinverse

Residuals are always orthogonal to every predictor column: \(X^\top e = 0\). Gauss-Markov guarantees OLS is BLUE under \(\text{Var}(\varepsilon) = \sigma^2 I\)."
