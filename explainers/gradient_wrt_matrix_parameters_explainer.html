Understanding the Gradient w.r.t. W
▼

What is this? When a neural network learns, it needs to know how much each weight in a layer should change to reduce the loss. For a linear layer \(y = Wx\), the answer is a matrix called the weight gradient, written \(\partial L/\partial W\). The fundamental fact: this gradient has exactly the same shape as \(W\) itself.

Analogy: Think of \(W\) as a mixing board with rows of sliders — each row controls one output channel, each column controls one input source. After a song comes out wrong (loss is high), you want a "correction dial" for every slider. The gradient \(\partial L/\partial W\) is that correction board — same layout, one number per slider.

If you remember one thing

For a linear layer \(y = Wx\), the weight gradient is the outer product of the upstream gradient \(\delta = \partial L/\partial y\) and the input \(x\):

\(\dfrac{\partial L}{\partial W} = \delta\, x^\top\)

This matrix has the same shape as \(W\) and tells you exactly how to nudge each weight.

Shape Consistency Principle

The gradient of a scalar loss \(L\) with respect to any parameter tensor has the same shape as that tensor. If \(W\) is \(m \times n\), then \(\partial L/\partial W\) is also \(m \times n\). Entry \((i,j)\) gives \(\partial L/\partial W_{ij}\) — "if I increase \(W_{ij}\) by a tiny amount, how much does \(L\) change?"

2
The Outer Product Identity: \(\partial L/\partial W = \delta\, x^\top\)
▼

Consider the linear layer \(y = Wx\) where \(W \in \mathbb{R}^{m \times n}\), \(x \in \mathbb{R}^n\), and \(y \in \mathbb{R}^m\). Let \(L\) be any scalar loss depending on \(y\). Define the upstream gradient:

$$\delta = \frac{\partial L}{\partial y} \in \mathbb{R}^m$$

Then the weight gradient is:

$$\frac{\partial L}{\partial W} = \delta\, x^\top \in \mathbb{R}^{m \times n}$$

This is the outer product — a rank-1 matrix formed by multiplying a column vector by a row vector. Entry \((i,j)\) equals \(\delta_i \cdot x_j\): the \(i\)-th output's error sensitivity times the \(j\)-th input that caused it.

Why the outer product structure?

\(W_{ij}\) only connects input \(j\) to output \(i\). The loss changes through this weight via the chain: \(L \to y_i \to W_{ij} x_j\). So \(\partial L/\partial W_{ij} = (\partial L/\partial y_i)\cdot x_j = \delta_i \cdot x_j\). Writing this for all \((i,j)\) simultaneously gives the outer product.

Entry-by-entry formula

\(\Bigl(\dfrac{\partial L}{\partial W}\Bigr)_{ij} = \delta_i \cdot x_j\)

Each row \(i\) of the gradient is \(\delta_i\) times the full input vector \(x^\top\). Rows that had large error (\(\delta_i\) large) receive larger gradient updates across all their incoming weights.

The companion identity: gradient w.r.t. x

By the chain rule, the gradient with respect to the input (needed to propagate errors back to earlier layers) is:

$$\frac{\partial L}{\partial x} = W^\top \delta \in \mathbb{R}^n$$

Together, \(\partial L/\partial W = \delta x^\top\) and \(\partial L/\partial x = W^\top \delta\) are the two backprop equations for a linear layer. Every deep-learning framework implements exactly these.

Common confusion — shape of δ

\(\delta = \partial L/\partial y\) has the same shape as \(y\), which is \(\mathbb{R}^m\) (a column vector). The outer product \(\delta x^\top\) then multiplies a column \((m\times1)\) by a row \((1\times n)\) to get \((m\times n)\) — same as \(W\). Never confuse \(\delta\) with a scalar.

3
Why It Works — The Derivation
▼

Full derivation using the chain rule

Write out the forward pass element-wise: \(y_i = \sum_{k=1}^n W_{ik} x_k\). The loss depends on all outputs, so by the chain rule:

$$\frac{\partial L}{\partial W_{ij}} = \sum_{i'} \frac{\partial L}{\partial y_{i'}} \cdot \frac{\partial y_{i'}}{\partial W_{ij}}$$

Now, \(y_{i'}\) depends on \(W_{ij}\) only when \(i' = i\) (because output \(i'\) uses row \(i'\) of \(W\), not row \(i\)). So the sum collapses:

$$\frac{\partial L}{\partial W_{ij}} = \frac{\partial L}{\partial y_i} \cdot \frac{\partial y_i}{\partial W_{ij}} = \delta_i \cdot x_j$$

Stacking all \((i,j)\) entries into a matrix gives the outer product identity \(\partial L/\partial W = \delta x^\top\).

Numerical trace with our example

Let \(W = \begin{pmatrix}0.5 & -0.3 & 0.8\\ 0.2 & 0.6 & -0.1\end{pmatrix}\), \(x = [1, 2, -1]^\top\). Then:

$$y = Wx = \begin{pmatrix}-0.9\\ 1.5\end{pmatrix}, \quad L = \tfrac{1}{2}\|y\|^2 = 1.53, \quad \delta = y = \begin{pmatrix}-0.9\\ 1.5\end{pmatrix}$$
$$\frac{\partial L}{\partial W} = \delta x^\top = \begin{pmatrix}-0.9\\ 1.5\end{pmatrix}\begin{pmatrix}1 & 2 & -1\end{pmatrix} = \begin{pmatrix}-0.9 & -1.8 & 0.9\\ 1.5 & 3.0 & -1.5\end{pmatrix}$$

Finite-difference check confirms max error \(1.37\times10^{-11}\) — the formula is exact.

Geometric insight

The gradient \(\delta x^\top\) is a rank-1 matrix. It points in the direction of steepest ascent for \(L\) in weight space. Gradient descent subtracts \(\eta\,\delta x^\top\) from \(W\): each weight \(W_{ij}\) is decreased by an amount proportional to \(x_j\) (how strongly that input was active) and \(\delta_i\) (how wrong that output was).

Batched version (real training)

For a mini-batch \(X \in \mathbb{R}^{n \times B}\) (B samples), the forward pass is \(Y = WX\) and the gradient accumulates over samples: \(\partial L/\partial W = \Delta X^\top\) where \(\Delta = \partial L/\partial Y \in \mathbb{R}^{m\times B}\). Each sample contributes its own outer product; the sum is the full gradient.

Key Takeaways
▼

The three rules to remember:

  • Shape consistency: \(\partial L/\partial W\) always has the same shape as \(W\). If \(W\) is \(m\times n\), the gradient is \(m\times n\).
  • Outer product identity: \(\partial L/\partial W = \delta x^\top\) for \(y=Wx\). Entry \((i,j)\) = upstream error at output \(i\) × input \(j\).
  • Companion rule: \(\partial L/\partial x = W^\top \delta\). This passes the gradient backward to the previous layer.
Why this matters for deep learning

Every dense layer, embedding lookup, attention key/query/value projection, and output head uses this exact identity. When PyTorch calls loss.backward(), it computes grad_W = delta @ x.T for each linear layer. Understanding this makes gradient clipping, weight decay, and learning-rate scheduling intuitive.

Connection to the general rule

For any smooth \(f: \mathbb{R}^{m\times n} \to \mathbb{R}\), the gradient \(\partial f/\partial W\) is the unique matrix satisfying \(f(W+dW) \approx f(W) + \langle \partial f/\partial W,\, dW\rangle_F\) where \(\langle A,B\rangle_F = \operatorname{tr}(A^\top B)\). The outer product formula is simply the explicit solution of this equation for the linear-layer case.

import numpy as np
# Layer: y = W @ x, W shape (2,3), x shape (3,)
W = np.array([[ 0.5, -0.3, 0.8],
[ 0.2, 0.6, -0.1]])
x = np.array([1.0, 2.0, -1.0])
# Forward pass
y = W @ x # [-0.9, 1.5]
# Loss: L = 0.5 ||y||^2 (target = 0)
L = 0.5 * np.sum(y**2) # 1.53
# Upstream gradient dL/dy
delta = y # [-0.9, 1.5]
# *** THE KEY IDENTITY ***
dL_dW = np.outer(delta, x) # shape (2,3) == W.shape ✓
# Finite-difference verification
eps = 1e-5
fd = np.zeros_like(W)
for i in range(2):
for j in range(3):
Wp = W.copy(); Wp[i,j] += eps
Wm = W.copy(); Wm[i,j] -= eps
fd[i,j] = (0.5*np.sum((Wp@x)**2) - 0.5*np.sum((Wm@x)**2)) / (2*eps)
print(np.max(np.abs(dL_dW - fd))) # 1.37e-11 ✓ match
