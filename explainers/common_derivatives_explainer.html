1
What Are Derivatives?
▼

What is a derivative? A derivative answers the question: "how fast is this function changing right now?" If \(f(x)\) describes a curve, then \(f'(x)\) tells you the slope of that curve at every point — whether it's climbing steeply, barely moving, or falling.

Analogy: Think of a car trip. The position function \(s(t)\) tells you where the car is at time \(t\). Its derivative \(s'(t) = v(t)\) is the speedometer — it tells you how fast position is changing. The derivative of speed, \(v'(t) = a(t)\), is the accelerometer. In neural networks, derivatives tell the optimizer how fast the loss changes as each weight nudges — that's the entire foundation of gradient descent.

💡 If you remember one thing

Derivatives power backpropagation. The chain rule combines them: \(\frac{d}{dx}[f(g(x))] = f'(g(x)) \cdot g'(x)\). Every gradient in a neural network is a product of elementary derivatives chained together from output back to inputs.

Why ML Engineers Care

Activation functions like sigmoid \(\sigma(x) = \frac{1}{1+e^{-x}}\) and tanh are chosen specifically because their derivatives have elegant closed forms: \(\sigma'(x) = \sigma(x)(1-\sigma(x))\) and \(\tanh'(x) = 1 - \tanh^2(x)\). These formulas let us compute gradients efficiently without any numerical differentiation.

The "vanishing gradient" problem — where deep networks fail to train — is directly caused by these derivatives being very small (near 0) in saturated regions. Understanding where and why derivatives saturate is essential for choosing activations and initializations.

2
The Five Derivative Families
▼

1 · Polynomials — Power Rule

The power rule is the workhorse of calculus: if \(f(x) = x^n\), then \(f'(x) = nx^{n-1}\). It works for all real \(n\), including fractions and negative exponents. For a sum, differentiate term by term (linearity). Neural network layers compute weighted sums — their Jacobians are determined by power-rule derivatives.

$$\frac{d}{dx} x^n = nx^{n-1} \qquad \frac{d}{dx}[af(x)+bg(x)] = af'(x)+bg'(x)$$

2 · Exponentials — Self-Referential Growth

The natural exponential \(e^x\) is the only function that is its own derivative: \(\frac{d}{dx}e^x = e^x\). This is not a coincidence — it is the defining property of \(e\). For a general base: \(\frac{d}{dx}a^x = a^x \ln a\). The softplus activation \(\ln(1+e^x)\) and the attention softmax all descend from this family.

$$\frac{d}{dx} e^x = e^x \qquad \frac{d}{dx} e^{f(x)} = f'(x)\,e^{f(x)}$$

3 · Logarithms

The derivative of the natural log is beautifully simple: \(\frac{d}{dx}\ln x = \frac{1}{x}\). Cross-entropy loss \(-\ln \hat{p}\) is the most common loss in classification — its gradient \(-1/\hat{p}\) becomes large when the model is confidently wrong, providing a strong correction signal.

$$\frac{d}{dx}\ln x = \frac{1}{x} \qquad \frac{d}{dx}\log_a x = \frac{1}{x \ln a}$$

4 · Trigonometric

Sine and cosine are mutually self-referential: \(\frac{d}{dx}\sin x = \cos x\) and \(\frac{d}{dx}\cos x = -\sin x\). They cycle with period 4 under differentiation: \(\sin \to \cos \to -\sin \to -\cos \to \sin\). Positional encodings in Transformers use sinusoids; their smooth, bounded derivatives make them well-conditioned for gradient flow.

$$\frac{d}{dx}\sin x = \cos x \qquad \frac{d}{dx}\cos x = -\sin x \qquad \frac{d}{dx}\tan x = \sec^2 x$$

5 · Hyperbolic & ML Activations

Hyperbolic functions are defined via exponentials: \(\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}\). Their derivatives have the same elegant forms as circular trig but without sign alternation. The sigmoid \(\sigma(x)\) is a rescaled tanh: \(\sigma(x) = \frac{1+\tanh(x/2)}{2}\).

🔑 The ML-Critical Derivatives

These four appear in every deep learning framework:

Sigmoid: \(\sigma'(x) = \sigma(x)(1-\sigma(x))\)
Tanh: \(\tanh'(x) = 1 - \tanh^2(x) = \text{sech}^2(x)\)
Softplus: \(\frac{d}{dx}\ln(1+e^x) = \sigma(x)\) (sigmoid!)
ReLU: \(\text{ReLU}'(x) = \mathbf{1}[x > 0]\) (Heaviside step)

⚠️ Vanishing Gradient Regions

Sigmoid saturates: at \(x=5\), \(\sigma'(5) = \sigma(5)(1-\sigma(5)) \approx 0.0066\). Tanh also saturates at \(|x| \gg 0\). Stack 10 layers and the gradient shrinks by a factor of \(0.0066^{10} \approx 10^{-18}\). This is the vanishing gradient problem. ReLU (derivative = 1 for \(x>0\)) avoids this — but introduces "dead neurons" where \(x \leq 0\).

3
Deriving the ML Activation Gradients
▼

Sigmoid \(\sigma'(x) = \sigma(x)(1-\sigma(x))\) — Full Derivation

Let \(\sigma(x) = (1+e^{-x})^{-1}\). Apply the chain rule:

$$\sigma'(x) = -(1+e^{-x})^{-2} \cdot (-e^{-x}) = \frac{e^{-x}}{(1+e^{-x})^2}$$

Factor cleverly — multiply numerator and denominator by \((1+e^{-x})^{-1}\):

$$= \frac{1}{1+e^{-x}} \cdot \frac{e^{-x}}{1+e^{-x}} = \sigma(x) \cdot \frac{e^{-x}}{1+e^{-x}} = \sigma(x)\left(1 - \frac{1}{1+e^{-x}}\right) = \sigma(x)(1-\sigma(x))$$

Numerical check: At \(x=0\): \(\sigma(0)=0.5\), so \(\sigma'(0) = 0.5 \times 0.5 = 0.25\). Maximum gradient is exactly 0.25, achieved at \(x=0\).

Tanh \(\tanh'(x) = 1 - \tanh^2(x)\)

Using the quotient rule on \(\tanh x = \sinh x / \cosh x\):

$$\tanh'(x) = \frac{\cosh^2 x - \sinh^2 x}{\cosh^2 x} = 1 - \tanh^2(x) = \text{sech}^2(x)$$

Numerical check: At \(x=0\): \(\tanh(0)=0\), so \(\tanh'(0) = 1-0 = 1\). Maximum gradient is 1, twice that of sigmoid — tanh propagates gradients better.

Softplus \(\frac{d}{dx}\ln(1+e^x) = \sigma(x)\)

Apply chain rule with inner function \(u = 1+e^x\):

$$\frac{d}{dx}\ln(1+e^x) = \frac{e^x}{1+e^x} = \frac{1}{1+e^{-x}} = \sigma(x)$$

This is a beautiful result: softplus (a smooth ReLU approximation) has sigmoid as its exact derivative. Softplus "is" the antiderivative of sigmoid.

ReLU and Its Subgradient

ReLU is not differentiable at \(x=0\), but we use the subgradient:

$$\text{ReLU}'(x) = \begin{cases} 1 & x > 0 \\ 0 & x < 0 \\ \text{undefined (use 0)} & x = 0 \end{cases}$$

In practice, frameworks return 0 at exactly \(x=0\) (negligible probability in continuous data). The derivative being exactly 0 or 1 (never decaying with depth) is why ReLU solved the vanishing gradient problem that plagued sigmoid/tanh networks.

From-Scratch NumPy Implementation
▼

All ML-critical activation functions and their exact derivatives in one reference implementation. Note: the derivative implementations use only the function output — no second forward pass needed.

import numpy as np
# ── Sigmoid and its exact derivative ─────────────────────────────────
def sigmoid(x): # σ(x) = 1/(1+e^{-x})
return 1.0 / (1.0 + np.exp(-x)) # numerically stable for x > -709
def sigmoid_deriv(x): # σ'(x) = σ(x)(1-σ(x))
s = sigmoid(x)
return s * (1 - s) # max = 0.25 at x=0
# ── Tanh and its exact derivative ────────────────────────────────────
def tanh_deriv(x): # tanh'(x) = 1 - tanh²(x)
return 1.0 - np.tanh(x)**2 # max = 1.0 at x=0 (2x sigmoid)
# ── Softplus and its derivative (= sigmoid) ──────────────────────────
def softplus(x): # ln(1+e^x)
return np.log1p(np.exp(x)) # log1p more stable for x≈0
def softplus_deriv(x): # d/dx ln(1+e^x) = σ(x)
return sigmoid(x) # derivative IS sigmoid
# ── ReLU and its subgradient ──────────────────────────────────────────
def relu(x): return np.maximum(0, x)
def relu_deriv(x): return (x > 0).astype(float) # Heaviside step
# ── Quick numerical check ─────────────────────────────────────────────
x0 = 0.0
eps = 1e-5
num_grad = (sigmoid(x0+eps) - sigmoid(x0-eps)) / (2*eps)
ana_grad = sigmoid_deriv(x0)
print(f"Numerical: {num_grad:.6f} Analytical: {ana_grad:.6f}") # → 0.250000
💡 Production Tip

In PyTorch, you never compute these derivatives manually — autograd handles it. But knowing them lets you debug gradient issues: x.grad after loss.backward() will exactly match \(\sigma(x)(1-\sigma(x))\) for a sigmoid layer. Verify this when debugging vanishing gradients.

🎯 Decision Guide

Hidden layers: use ReLU (or GELU/SiLU for LLMs) — avoids saturation, fast.

Binary output: sigmoid — maps to probability, use with BCELoss.

RNN/LSTM gates: tanh for cell state (zero-centered, range [−1,1]).

Loss function: cross-entropy uses ln — gradient \(-1/\hat{p}\) is large when model is confidently wrong.
