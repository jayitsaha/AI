Residual Connections in Transformers

How the skip-connection x + Sublayer(x), paired with LayerNorm, keeps gradients alive through 96-layer stacks and turns training a transformer from "nearly impossible" into "routine."

Advanced Transformer Architecture Add & Norm O(1) extra compute
1
Understanding the Concept
▼

What is this? Inside every transformer block, a sublayer (Multi-Head Attention or the Feed-Forward Network) transforms the input x into Sublayer(x). A residual connection simply adds the original input back: the block outputs x + Sublayer(x) instead of just Sublayer(x), followed immediately by LayerNorm — the famous "Add & Norm" step drawn in every transformer diagram.

Analogy: Think of editing an essay. A bad editor rewrites the whole paragraph from scratch — if they mess up, your original ideas are gone. A good editor hands you back your original text plus their suggested changes in the margin. Even if the suggestions are useless, you still have your original essay intact. The residual connection is that margin note: the sublayer only needs to learn the correction to add, not reinvent the whole representation.

One-sentence summary: Residual connections give every layer a free "identity shortcut" back to its input, so the network only has to learn a small residual update — and gradients get a direct path back through dozens of stacked layers.

If you remember one thing
The gradient of x + Sublayer(x) with respect to x is I + ∂Sublayer/∂x — the identity matrix I guarantees a gradient of at least "1" flows straight back, no matter how small the sublayer's own gradient becomes.

How It Works Internally
▼

Every transformer block (Vaswani et al., 2017) contains exactly two sublayers, and both get the same treatment:

StageSublayer(x)Block output
1. Self-AttentionMulti-Head Attention(x) LayerNorm(x + MHA(x))
2. Feed-ForwardFFN(x) = W₂·ReLU(W₁x + b₁) + b₂ LayerNorm(x + FFN(x))

Design decision — why Add before Norm (Post-LN) or Norm before Add (Pre-LN)? The original paper normalizes after the residual sum ("Post-LN"): LN(x + Sublayer(x)). Modern large models (GPT-2/3, LLaMA) instead normalize inside the sublayer branch only — "Pre-LN": x + Sublayer(LN(x)). Pre-LN keeps the raw residual stream x completely untouched end-to-end, which makes very deep stacks (50+ layers) far more stable to train, at a small cost in final quality versus a well-tuned Post-LN model.

Internal mechanism, step by step (Post-LN, as in the diagram below):

  1. x enters the block and is cached (this is the "skip" copy).
  2. x also flows into the sublayer, producing Sublayer(x) — a vector of the same shape as x (this shape-matching is what makes the addition possible at all).
  3. The two are summed element-wise: y = x + Sublayer(x).
  4. LayerNorm re-centers and re-scales y across the feature dimension: subtract the mean, divide by the standard deviation, then apply learned γ, β.
  5. The normalized result becomes the input to the next sublayer / next block.
Edge case
The residual add only works because Sublayer(x) is shape-preserving — attention and the FFN are both designed so output dimensionality equals d_model exactly for this reason. This constraint quietly shapes the whole transformer architecture (e.g. why the FFN projects up to 4·d_model and then back down, rather than just up).

Why It Works — The Gradient Highway
▼

Without residual connections, backpropagating through N stacked sublayers multiplies the gradient by each sublayer's own Jacobian, layer after layer:

$$\frac{\partial \mathcal{L}}{\partial x_0} = \frac{\partial \mathcal{L}}{\partial x_N}\prod_{i=1}^{N}\frac{\partial \,\text{Sublayer}_i}{\partial x_{i-1}}$$

If each factor has magnitude a little below 1 (extremely common with saturating nonlinearities and normalization), the product shrinks exponentially with depth — the classic vanishing-gradient problem that made deep networks essentially untrainable before residual connections (He et al., ResNet, 2015).

With the residual add, each block's Jacobian becomes I + J instead of just J:

$$\frac{\partial \,(x + \text{Sublayer}(x))}{\partial x} = I + \frac{\partial \,\text{Sublayer}}{\partial x}$$
The core invariant
Because the chain rule now multiplies a product of (I + J_i) terms instead of J_i terms, the identity component guarantees a "gradient superhighway" — an unimpeded, depth-independent path from the loss straight back to layer 1. The sublayer only ever needs to learn a small additive correction on top of that guaranteed path.

This is also precisely why residual streams pair so naturally with LayerNorm: without normalization, repeatedly adding unnormalized activations across dozens of blocks would cause the residual stream's magnitude to explode. LayerNorm keeps the stream on a numerically stable scale while the identity path keeps gradients from vanishing — together they are what let transformers scale to 96+ layers (GPT-3) and beyond.

The Math
▼

Let x ∈ ℝᵈ be a token's hidden state (\(d = d_{model}\)). A block computes:

$$y = x + \text{Sublayer}(x), \qquad z = \text{LayerNorm}(y) = \gamma \odot \frac{y - \mu_y}{\sqrt{\sigma_y^2 + \epsilon}} + \beta$$

where \(\mu_y = \frac{1}{d}\sum_{k=1}^d y_k\) and \(\sigma_y^2 = \frac{1}{d}\sum_{k=1}^d (y_k-\mu_y)^2\) are computed per token, across the feature dimension (not across the batch — this is what distinguishes LayerNorm from BatchNorm).

Backward pass. Differentiating the residual sum with respect to the block's input gives the key result:

$$\frac{\partial y}{\partial x} = I + \frac{\partial \,\text{Sublayer}(x)}{\partial x}$$

Unrolling across N blocks (ignoring LayerNorm's near-identity rescaling for intuition, since it acts on already-unit-scale vectors):

$$\frac{\partial \mathcal{L}}{\partial x_0} = \frac{\partial \mathcal{L}}{\partial x_N}\prod_{i=1}^{N}\Big(I + J_i\Big), \qquad J_i = \frac{\partial\,\text{Sublayer}_i}{\partial x_{i-1}}$$

Expanding the product, the leading term is exactly I (order-0 in every J_i) — a gradient path that survives depth entirely untouched by how small or badly-conditioned the sublayer Jacobians are. Every other term involves at least one J_i factor and represents the "correction" the sublayers contribute on top of that guaranteed path.

Common misconception
"Residual connections make gradients constant / equal to exactly 1." Not quite — they guarantee a lower bound / an unobstructed additive path. The total gradient is still I + J, so it can still grow or shrink depending on J; residual connections prevent the catastrophic multiplicative decay of pure ∏Jᵢ, they don't freeze the gradient at 1.

Proof sketch (why deep plain nets fail): if each ‖Jᵢ‖ ≤ s < 1 (e.g. due to saturating activations), then ‖∏Jᵢ‖ ≤ sᴺ → 0 as N grows — exponential vanishing. With the identity term, the product ∏(I + Jᵢ) contains the I-only term as one of \(2^N\) expanded terms, so the gradient magnitude is bounded below by a path independent of N, breaking the exponential-decay argument entirely.

Key Takeaways & Code
▼

Takeaways: residual connections cost zero extra parameters and one elementwise add, yet they are what make it possible to stack transformer blocks 12, 96, or 120+ layers deep. Paired with LayerNorm (Add & Norm), they stabilize both the forward activation magnitudes and the backward gradient magnitudes simultaneously. Use Post-LN for smaller/well-tuned models, Pre-LN for very deep or unstable training runs.

class AddNorm(nn.Module):
def __init__(self, d_model, eps=1e-5):
super().__init__()
self.norm = nn.LayerNorm(d_model, eps=eps)
def forward(self, x, sublayer_out):
# residual add: identity path + learned correction
y = x + sublayer_out
# normalize per-token across feature dim
return self.norm(y)
# inside a transformer block (Post-LN, Vaswani et al. 2017):
x = add_norm1(x, self_attn(x, x, x))
x = add_norm2(x, ffn(x))
