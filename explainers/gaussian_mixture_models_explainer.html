Understanding GMM
▼

What is it? A Gaussian Mixture Model is a probabilistic model that assumes the data was generated by one of \(K\) hidden Gaussian "bells," each with its own mean, shape, and mixing weight. Unlike k-means (which gives every point one hard cluster label), GMM assigns each point a soft probability of belonging to each cluster — it says "this point is 80% from cluster 1 and 20% from cluster 2."

Analogy: Imagine you collect height measurements from a crowd without knowing whether each person is an adult, a child, or a basketball player. Heights within each group roughly follow a bell curve. A GMM figures out how many bells there are, where each is centered, and how wide each is — then tells you the probability each person belongs to each group, even though you never saw the group labels.

💡 If you remember one thing

A GMM models the joint density as $$p(x) = \sum_{k=1}^{K} \pi_k \,\mathcal{N}(x \mid \mu_k, \Sigma_k)$$ The EM algorithm alternates between computing soft memberships (\(\gamma_{ik}\), E-step) and re-estimating parameters (\(\pi, \mu, \Sigma\), M-step), monotonically increasing the log-likelihood until convergence.

Key vocabulary: \(\pi_k\) = mixing weight (how common is cluster \(k\)?), \(\mu_k\) = centroid, \(\Sigma_k\) = covariance (shape), \(\gamma_{ik}\) = responsibility (how much does cluster \(k\) "claim" point \(i\)?), \(K\) = number of components chosen via BIC/AIC.

2
How the EM Algorithm Works Internally
▼

The Problem: Hidden Variables

If we knew which component generated each point, we could just fit K separate Gaussians. But cluster membership is a latent variable — we never observe it. EM handles this by treating memberships as soft probabilistic guesses, updating them and the parameters in alternating steps.

Initialization

EM needs starting values. Common strategies: random initialization, k-means centroids (usually best), or random selection from data points. The choice matters because EM only finds a local maximum of the log-likelihood. Best practice: run EM multiple times with different starts, keep the highest log-likelihood result.

E-Step: Compute Responsibilities

Given current parameters \((\pi_k, \mu_k, \Sigma_k)\), compute how much each component "explains" each data point \(x_i\). This is a simple application of Bayes' rule — the posterior probability that point \(i\) came from component \(k\):

$$\gamma_{ik} = \frac{\pi_k \,\mathcal{N}(x_i \mid \mu_k, \Sigma_k)}{\displaystyle\sum_{j=1}^{K} \pi_j \,\mathcal{N}(x_i \mid \mu_j, \Sigma_j)}$$

Note that \(\sum_{k=1}^K \gamma_{ik} = 1\) for every point \(i\). The "effective count" for component \(k\) is \(N_k = \sum_{i=1}^n \gamma_{ik}\).

M-Step: Re-estimate Parameters

Use the responsibilities as soft weights to re-estimate all parameters — this is just weighted maximum likelihood estimation:

$$\hat{\pi}_k = \frac{N_k}{n}, \quad \hat{\mu}_k = \frac{1}{N_k}\sum_{i=1}^n \gamma_{ik}\, x_i, \quad \hat{\Sigma}_k = \frac{1}{N_k}\sum_{i=1}^n \gamma_{ik}(x_i - \hat{\mu}_k)(x_i - \hat{\mu}_k)^\top$$

Why It Always Improves

EM maximizes a lower bound (the ELBO) on the log-likelihood at each step. Both the E-step and M-step are guaranteed not to decrease the log-likelihood, so convergence to a local maximum is guaranteed. The full log-likelihood is \(\mathcal{L} = \sum_{i=1}^n \log \sum_{k=1}^K \pi_k \mathcal{N}(x_i \mid \mu_k, \Sigma_k)\).

🔑 Key Property

EM guarantees monotonic non-decreasing log-likelihood. It converges to a local (not global) optimum. K-means is equivalent to GMM with spherical covariance and hard (argmax) responsibilities — a special degenerate case of EM.

⚠️ Common Failure Mode

Degeneracy / Singularities: If a Gaussian collapses onto a single data point, its variance → 0 and its likelihood → ∞. Fix: add a small regularization term to the covariance diagonal (\(\hat{\Sigma}_k \leftarrow \hat{\Sigma}_k + \epsilon I\)) or use a conjugate prior (Bayesian GMM / Dirichlet Process).

3
The Math — Derivation, BIC/AIC, Covariance Types
▼

Complete Data Log-Likelihood (if labels were known)

Introduce latent one-hot vectors \(z_{ik} \in \{0,1\}\) where \(z_{ik}=1\) iff point \(i\) came from component \(k\). The complete log-likelihood factors cleanly:

$$\mathcal{L}_c = \sum_{i=1}^n \sum_{k=1}^K z_{ik}\left[\log \pi_k + \log \mathcal{N}(x_i \mid \mu_k, \Sigma_k)\right]$$

Observed Data Log-Likelihood (the actual objective)

Marginalising over \(z\) (sum over who generated each point) gives the log-sum-exp form that makes direct maximisation hard:

$$\mathcal{L} = \sum_{i=1}^n \log \sum_{k=1}^K \pi_k \,\mathcal{N}(x_i \mid \mu_k, \Sigma_k)$$

EM Lower Bound (Jensen's Inequality)

For any distribution \(q(z)\) over latent variables, Jensen gives \(\mathcal{L} \geq \mathbb{E}_q[\log p(x,z)] - \mathbb{E}_q[\log q(z)]\). The E-step sets \(q(z_{ik}) = \gamma_{ik} = p(z_{ik}=1 \mid x_i, \theta)\), which tightens the bound to equality. The M-step maximises the bound w.r.t. \(\theta\):

$$Q(\theta \mid \theta^{(t)}) = \sum_{i,k} \gamma_{ik}\left[\log \pi_k - \tfrac{1}{2}\log|\Sigma_k| - \tfrac{1}{2}(x_i-\mu_k)^\top\Sigma_k^{-1}(x_i-\mu_k)\right] + \text{const}$$

Setting \(\partial Q / \partial \mu_k = 0\) gives the weighted mean formula; \(\partial Q / \partial \Sigma_k^{-1} = 0\) gives the weighted covariance formula. Setting \(\partial Q / \partial \pi_k = 0\) subject to \(\sum \pi_k = 1\) (Lagrange multiplier) gives \(\hat{\pi}_k = N_k/n\).

BIC and AIC for Component Selection

Fitting more components always increases \(\mathcal{L}\), so we penalise complexity. Let \(\hat{\mathcal{L}}\) be the maximised log-likelihood and \(p\) be the number of free parameters:

$$\mathrm{BIC} = -2\hat{\mathcal{L}} + p\ln n, \qquad \mathrm{AIC} = -2\hat{\mathcal{L}} + 2p$$

Choose \(K\) that minimises BIC or AIC. BIC penalises more heavily for large \(n\) — tends to prefer sparser models. AIC is asymptotically equivalent to leave-one-out cross-validation for log-loss.

Covariance Types Explained

Full: Each cluster can be any ellipse at any rotation — most flexible, most parameters, can overfit with few data. Tied: All clusters share the same shape but have different centres — like LDA's shared covariance assumption. Diagonal: Ellipses aligned with axes only — features treated as conditionally independent given cluster (Naive Bayes connection). Spherical: Only a radius per cluster — clusters are circular; this is precisely the GMM underlying K-means (with hard responsibilities \(\gamma_{ik} \in \{0,1\}\)).

GMM vs K-Means: The Exact Relationship

K-means IS a degenerate GMM: spherical covariance (\(\Sigma_k = \sigma^2 I\)) + hard responsibilities (\(\gamma_{ik} \in \{0,1\}\) via argmax). As \(\sigma^2 \to 0\), GMM with spherical covariance and equal weights converges to K-means. This is sometimes called "hard EM."

🎯 Decision Guide

Use GMM when: you need probabilistic memberships, clusters have different shapes/orientations, or you want a generative model for density estimation and sampling.
Use K-Means when: very large datasets, equal-size spherical clusters, speed matters more than probabilistic output.
Use DBSCAN when: clusters have arbitrary shape, you expect outliers, K is unknown and clusters vary in density.

Choosing K: BIC in Practice

Fit GMMs with K = 1, 2, ..., K_max. Compute BIC = \(-2\hat{\mathcal{L}} + p\ln n\) for each. Plot BIC vs K — look for the "elbow" (minimum or flattening). AIC tends to choose larger K than BIC for the same dataset. In sklearn: GaussianMixture(n_components=k).bic(X).

⚠️ Practical Pitfalls

Degenerate solutions: Add reg_covar=1e-6 to prevent covariance collapse.
Local optima: Use n_init=10 to run EM 10 times, keep best result.
BIC assumes the model family is correct: If data truly isn't Gaussian, BIC will still pick a K but the model will be wrong. Always visualise.

From Scratch — NumPy EM for GMM

import numpy as np
from scipy.stats import multivariate_normal
class GMMFromScratch:
def __init__(self, K, n_init=5, max_iter=100, tol=1e-4, reg_covar=1e-6):
self.K, self.n_init, self.max_iter = K, n_init, max_iter
self.tol, self.reg_covar = tol, reg_covar
def _init_params(self, X):
n, d = X.shape
# K-Means init: pick K random points as initial means
idx = np.random.choice(n, self.K, replace=False)
self.mu = X[idx].copy() # (K, d)
self.Sigma = np.array([np.eye(d)] * self.K) # (K, d, d)
self.pi = np.ones(self.K) / self.K # (K,)
def _e_step(self, X): # Compute responsibilities
n = X.shape[0]
gamma = np.zeros((n, self.K))
for k in range(self.K):
# pi_k * N(x_i | mu_k, Sigma_k) for all i at once
gamma[:, k] = self.pi[k] * multivariate_normal.pdf(X, self.mu[k], self.Sigma[k])
gamma /= gamma.sum(axis=1, keepdims=True) + 1e-300 # Bayes' rule
return gamma
def _m_step(self, X, gamma): # Re-estimate parameters
n = X.shape[0]
Nk = gamma.sum(axis=0) # effective counts (K,)
self.pi = Nk / n # mixing weights
self.mu = (gamma.T @ X) / Nk[:, None] # weighted means (K, d)
for k in range(self.K):
diff = X - self.mu[k] # (n, d)
# weighted outer products summed over n
self.Sigma[k] = (gamma[:, k:k+1] * diff).T @ diff / Nk[k]
self.Sigma[k] += self.reg_covar * np.eye(diff.shape[1]) # regularise
def _log_likelihood(self, X):
ll = 0.0
for k in range(self.K):
ll_k = self.pi[k] * multivariate_normal.pdf(X, self.mu[k], self.Sigma[k])
ll += ll_k
return np.log(ll + 1e-300).sum()
def fit(self, X):
best_ll, best_params = -np.inf, None
for _ in range(self.n_init): # multiple restarts → avoid local optima
self._init_params(X)
prev_ll = -np.inf
for _ in range(self.max_iter):
gamma = self._e_step(X)
self._m_step(X, gamma)
ll = self._log_likelihood(X)
if ll - prev_ll < self.tol: break # converged
prev_ll = ll
if ll > best_ll:
best_ll = ll
best_params = (self.pi.copy(), self.mu.copy(), self.Sigma.copy())
self.pi, self.mu, self.Sigma = best_params
return self
def predict_proba(self, X): return self._e_step(X) # soft assignments
def predict(self, X): return self.predict_proba(X).argmax(axis=1) # hard
def bic(self, X):
n, d = X.shape
# full covariance param count
p = self.K * d*(d+1)//2 + self.K*d + (self.K-1)
return -2 * self._log_likelihood(X) + p * np.log(n)

Production Usage — sklearn

from sklearn.mixture import GaussianMixture
import numpy as np
# Select K via BIC
bic_scores = []
for K in range(1, 10):
gm = GaussianMixture(n_components=K, covariance_type='full',
n_init=10, random_state=0)
gm.fit(X_train)
bic_scores.append(gm.bic(X_train))
best_K = np.argmin(bic_scores) + 1 # 1-indexed
# Fit with best K
gmm = GaussianMixture(
n_components=best_K,
covariance_type='full', # 'full' | 'tied' | 'diag' | 'spherical'
n_init=10, # ⚠️ always use multiple restarts
reg_covar=1e-6, # prevent covariance singularity
random_state=42
).fit(X_train)
labels = gmm.predict(X_test) # hard cluster assignments
proba = gmm.predict_proba(X_test) # soft responsibilities
log_prob = gmm.score(X_test) # per-sample avg log-likelihood
samples = gmm.sample(n_samples=100) # generate new data from the model
# Key attributes
gmm.weights_ # pi_k shape (K,)
gmm.means_ # mu_k shape (K, d)
gmm.covariances_ # Sigma_k shape (K, d, d) for 'full'
✅ Key Takeaways

1. GMM = soft K-means + elliptical clusters + probabilistic framework.
2. EM = E-step (Bayes responsibilities) + M-step (weighted MLE), always increasing \(\mathcal{L}\).
3. Choose \(K\) via BIC (penalises harder) or AIC (asymptotically LOO-CV).
4. Covariance type trades expressiveness vs parameter efficiency vs overfitting risk.
5. Always use multiple restarts (n_init≥5) and covariance regularisation.
