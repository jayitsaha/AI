Understanding the Gamma & Beta Functions
▼

What are these? The factorial \(n!\) is defined only for non-negative integers: \(5! = 120\), \(3! = 6\), \(0! = 1\). The Gamma function \(\Gamma(x)\) smoothly extends this to all real (and complex) numbers. The Beta function \(B(a,b)\) is built from two Gamma values and appears constantly in probability theory — most visibly as the normalizing constant of the Beta distribution, the natural prior for probabilities.

Analogy: Imagine you can draw a smooth curve through the points \((1,1),(2,1),(3,2),(4,6),(5,24),(6,120),\ldots\) — the integer factorials. There are infinitely many such curves; Euler found the right one. The Gamma function is exactly that curve, defined by a definite integral. Similarly, the Beta function is the "area" of a particular shape on \([0,1]\) — and that area happens to be the normalizing constant that turns \(x^{a-1}(1-x)^{b-1}\) into a valid probability distribution.

💡 If you remember one thing

\(\Gamma(n) = (n-1)!\) for positive integers, \(\Gamma(x+1) = x\,\Gamma(x)\) for all \(x\), and \(\Gamma(\tfrac{1}{2}) = \sqrt{\pi}\). The Beta function ties two Gammas together: $$B(a,b) = \frac{\Gamma(a)\,\Gamma(b)}{\Gamma(a+b)}$$ — this single identity underpins the Beta distribution and Bayesian conjugate priors.

How They Work Internally
▼

The Gamma Function — Euler's Integral

Euler defined the Gamma function in 1729 using an integral that smoothly interpolates the factorial:

$$\Gamma(x) = \int_0^\infty t^{x-1} e^{-t}\,dt \qquad (x > 0)$$

The integrand \(t^{x-1}e^{-t}\) decays rapidly for large \(t\) (because of \(e^{-t}\)) and has a peak near \(t = x-1\). Increasing \(x\) shifts the peak rightward and lifts the curve, producing larger and larger values.

Recurrence derivation (integration by parts): Write \(\Gamma(x+1) = \int_0^\infty t^x e^{-t}\,dt\). Integrate by parts with \(u = t^x\), \(dv = e^{-t}dt\):

$$\Gamma(x+1) = \bigl[-t^x e^{-t}\bigr]_0^\infty + x\int_0^\infty t^{x-1}e^{-t}\,dt = 0 + x\,\Gamma(x)$$

Since \(\Gamma(1) = \int_0^\infty e^{-t}\,dt = 1\), applying the recurrence gives \(\Gamma(n) = (n-1)!\) for all positive integers.

The Beta Function — Two Ways to Compute

The Beta function has an integral representation:

$$B(a,b) = \int_0^1 t^{a-1}(1-t)^{b-1}\,dt \qquad (a,b > 0)$$

and a Gamma-function representation proved by evaluating the product \(\Gamma(a)\Gamma(b)\) as a double integral and changing variables:

$$B(a,b) = \frac{\Gamma(a)\,\Gamma(b)}{\Gamma(a+b)}$$
🔑 Why This Matters for ML

The Beta distribution \(\text{Beta}(a,b)\) has PDF \(f(\theta) = \theta^{a-1}(1-\theta)^{b-1}/B(a,b)\). The parameters \(a,b\) act as "pseudo-counts" of observed successes and failures. When combined with a Binomial likelihood, the posterior is still a Beta distribution — this conjugacy makes Bayesian inference analytically tractable and is exploited in Thompson sampling, Bayesian A/B testing, and LDA topic models.

Why They Work — The Key Identities
▼

Key Identities You Must Know

1. Recurrence (functional equation):

$$\Gamma(x+1) = x\,\Gamma(x)$$

2. Integer values (the factorial connection):

$$\Gamma(n) = (n-1)! \quad \text{for } n = 1,2,3,\ldots$$

3. Half-integer base case and recurrence:

$$\Gamma\!\left(\tfrac{1}{2}\right) = \sqrt{\pi}, \qquad \Gamma\!\left(\tfrac{3}{2}\right) = \tfrac{1}{2}\sqrt{\pi}, \qquad \Gamma\!\left(\tfrac{2k+1}{2}\right) = \frac{(2k-1)!!}{2^k}\sqrt{\pi}$$

The proof that \(\Gamma(\tfrac{1}{2})=\sqrt{\pi}\): substitute \(t = u^2\) in the defining integral to get \(\int_{-\infty}^\infty e^{-u^2}\,du = \sqrt{\pi}\) — the Gaussian integral.

4. Reflection formula (Euler):

$$\Gamma(x)\,\Gamma(1-x) = \frac{\pi}{\sin(\pi x)}$$

This extends Gamma to the negative reals (with poles at non-positive integers) and gives \(\Gamma(\tfrac{1}{2})^2 = \pi/\sin(\pi/2) = \pi\), confirming \(\Gamma(\tfrac{1}{2})=\sqrt{\pi}\).

5. Beta–Gamma link (proof sketch): Compute \(\Gamma(a)\Gamma(b) = \int_0^\infty \int_0^\infty s^{a-1}t^{b-1}e^{-(s+t)}\,ds\,dt\). Substitute \(s = xy\), \(t = x(1-y)\) (so \(x = s+t\), \(y = s/(s+t)\), Jacobian \(= x\)):

$$\Gamma(a)\Gamma(b) = \int_0^\infty x^{a+b-1}e^{-x}\,dx \cdot \int_0^1 y^{a-1}(1-y)^{b-1}\,dy = \Gamma(a+b)\,B(a,b)$$
⚠️ Common Pitfalls

Gamma shift: \(\Gamma(n) = (n-1)!\) — there is an off-by-one! \(\Gamma(5) = 4! = 24\), not \(5!\). In scipy: gamma(n+1) = n! or factorial(n).
Beta(0.5, 0.5) = π: This equals \(\Gamma(0.5)^2/\Gamma(1) = \pi/1 = \pi\) — not 3.14 by accident; it comes from \(\Gamma(\tfrac{1}{2}) = \sqrt{\pi}\).
Gamma is NOT factorial for non-integers — it is the unique log-convex extension (Bohr–Mollerup theorem).

Key Takeaways
▼

Where you will see these functions:

  • Gamma: Normalizing constant in the Gamma distribution (used in Poisson process and exponential family models), in the multivariate normal normalizer, in Stirling's approximation.
  • Beta: Conjugate prior for the Binomial (Bayesian A/B testing), Dirichlet distribution (Beta generalized to K categories — used in LDA topic models and Bayesian neural nets), Beta-Binomial distribution, Thompson sampling for multi-armed bandits.
  • In code: scipy.special.gamma, scipy.special.betaln (log-Beta for numerical stability), scipy.stats.beta for the full distribution.
💡 The Big Picture Hierarchy

Binomial \(\subset\) Beta-Binomial \(\subset\) Dirichlet-Multinomial. The Beta / Dirichlet functions are the spine of the entire Bayesian nonparametric toolkit. Understanding \(\Gamma\) and \(B\) is prerequisite to LDA, Gaussian Processes (through the Gamma process), and Bayesian neural network priors.

Code Trace
▼
import numpy as np
from scipy.special import gamma, beta as beta_fn, betaln
# 1. Gamma function: Gamma(n) = (n-1)! for positive integers
print(gamma(6)) # 120.0 (= 5!)
print(gamma(0.5)) # 1.7724 (= sqrt(pi))
# 2. Recurrence: Gamma(x+1) = x * Gamma(x)
x = 2.5
print(gamma(x+1)) # = x * gamma(x) = 2.5 * 1.3293 = 3.3234
# 3. Beta function: B(a,b) = Gamma(a)*Gamma(b)/Gamma(a+b)
a, b = 2.0, 5.0
print(beta_fn(a, b)) # 0.0333 = 1/(a+b-1)*C(a+b-2,a-1)^-1
# 4. Beta distribution PDF (conjugate prior for Binomial)
from scipy.stats import beta as beta_dist
alpha_prior, beta_prior = 2.0, 5.0 # prior belief
k, n = 7, 10 # observed: 7 heads in 10 tosses
# 5. Bayesian update: Beta(a,b) + Binomial(k,n) -> Beta(a+k, b+n-k)
alpha_post = alpha_prior + k # 2 + 7 = 9
beta_post = beta_prior + n - k # 5 + 3 = 8
posterior = beta_dist(alpha_post, beta_post)
print(posterior.mean()) # (9)/(9+8) ≈ 0.529
print(posterior.std()) # sqrt(9*8/((17^2)*18)) ≈ 0.115
