Bayesian Linear Regression

Gaussian priors on weights → conjugate posterior → predictive uncertainty that grows away from data
Advanced Classical ML Probabilistic ML Conjugate Bayes
1
Understanding the Concept
▾

Standard linear regression finds a single best set of weights \(\mathbf{w}\) — a point estimate. Bayesian linear regression treats \(\mathbf{w}\) as a random variable with a prior distribution. After observing data, we update that prior into a posterior distribution. Instead of one line, we have a distribution over lines.

The Core Bayesian Loop

Prior belief about weights \(\mathbf{w}\) + observed data \(\mathcal{D}\) → posterior belief about \(\mathbf{w}\). For new input \(\mathbf{x}_*\), we integrate over all plausible weight vectors to get a predictive distribution — not just a prediction, but a prediction with calibrated uncertainty.

Key Insight

With a Gaussian prior and Gaussian noise, the posterior is also Gaussian — the model is analytically tractable. No MCMC needed. Uncertainty is exact, not approximate.

Real-World Analogy

Imagine estimating how much coffee improves productivity. Before any experiment you have a vague belief (prior). Each data point narrows your belief, but you never become infinitely certain — you always maintain a distribution. In regions where you have no data, your uncertainty is high; near many observations, it is low. This is Bayesian linear regression: principled uncertainty tracking from prior to posterior to prediction.

If You Remember One Thing

MAP estimation with a zero-mean Gaussian prior on \(\mathbf{w}\) is exactly equivalent to ridge regression. The prior precision \(\alpha\) plays the role of the ridge penalty \(\lambda\). Bayes gives you ridge plus full uncertainty quantification for free.

2
How It Works Internally
▾

Model Setup

We model outputs as \(y = \mathbf{w}^\top \boldsymbol{\phi}(\mathbf{x}) + \varepsilon\) where \(\boldsymbol{\phi}\) are (possibly nonlinear) basis functions and \(\varepsilon \sim \mathcal{N}(0, \sigma^2)\). The likelihood of all \(N\) observations is:

$$p(\mathbf{y} \mid \mathbf{w}, \sigma^2) = \mathcal{N}(\mathbf{y} \mid \boldsymbol{\Phi}\mathbf{w},\, \sigma^2 \mathbf{I})$$

We place a zero-mean isotropic Gaussian prior on weights:

$$p(\mathbf{w}) = \mathcal{N}(\mathbf{w} \mid \mathbf{0},\, \alpha^{-1}\mathbf{I})$$

Conjugate Posterior (Exact)

Because both prior and likelihood are Gaussian, the posterior is Gaussian with closed-form parameters:

$$p(\mathbf{w} \mid \mathbf{y}) = \mathcal{N}(\mathbf{w} \mid \mathbf{m}_N,\, \mathbf{S}_N)$$
$$\mathbf{S}_N^{-1} = \alpha\mathbf{I} + \beta\,\boldsymbol{\Phi}^\top\boldsymbol{\Phi}, \qquad \mathbf{m}_N = \beta\,\mathbf{S}_N\,\boldsymbol{\Phi}^\top\mathbf{y}$$

where \(\beta = 1/\sigma^2\) is the noise precision. The posterior mean \(\mathbf{m}_N\) shifts toward the data; the posterior covariance \(\mathbf{S}_N\) shrinks as more data arrives.

Predictive Distribution

For a new test point \(\mathbf{x}_*\), marginalizing over the weight posterior gives:

$$p(y_* \mid \mathbf{x}_*, \mathbf{y}) = \mathcal{N}(y_* \mid \mathbf{m}_N^\top\boldsymbol{\phi}(\mathbf{x}_*),\; \sigma^2_*(\mathbf{x}_*))$$
$$\sigma^2_*(\mathbf{x}_*) = \underbrace{\sigma^2}_{\text{aleatoric}} + \underbrace{\boldsymbol{\phi}(\mathbf{x}_*)^\top \mathbf{S}_N \boldsymbol{\phi}(\mathbf{x}_*)}_{\text{epistemic}}$$

The epistemic (model) uncertainty grows large where \(\boldsymbol{\phi}(\mathbf{x}_*)\) is far from the training manifold. This is the famous error bars widening away from data property.

Common Mistake

People confuse aleatoric (irreducible noise \(\sigma^2\)) and epistemic (reducible model) uncertainty. Only epistemic uncertainty shrinks with more data. Aleatoric uncertainty is fixed by the problem's inherent noise level.

3
The Math — Full Derivation
▾

Completing the Square

The posterior is proportional to prior × likelihood. Taking logs:

$$\ln p(\mathbf{w}\mid\mathbf{y}) = -\frac{\alpha}{2}\mathbf{w}^\top\mathbf{w} - \frac{\beta}{2}(\mathbf{y} - \boldsymbol{\Phi}\mathbf{w})^\top(\mathbf{y} - \boldsymbol{\Phi}\mathbf{w}) + \text{const}$$

Expanding and collecting terms in \(\mathbf{w}\):

$$= -\frac{1}{2}\mathbf{w}^\top(\alpha\mathbf{I} + \beta\boldsymbol{\Phi}^\top\boldsymbol{\Phi})\mathbf{w} + \beta\mathbf{w}^\top\boldsymbol{\Phi}^\top\mathbf{y} + \text{const}$$

This is a quadratic form in \(\mathbf{w}\), so the posterior is Gaussian. Completing the square yields:

$$\mathbf{S}_N = (\alpha\mathbf{I} + \beta\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}, \qquad \mathbf{m}_N = \beta\,\mathbf{S}_N\,\boldsymbol{\Phi}^\top\mathbf{y}$$

MAP = Ridge Regression

The MAP (maximum a posteriori) estimate maximizes the log-posterior, which equals minimizing:

$$\mathcal{L}(\mathbf{w}) = \|\mathbf{y} - \boldsymbol{\Phi}\mathbf{w}\|^2 + \frac{\alpha}{\beta}\|\mathbf{w}\|^2$$

Setting \(\lambda = \alpha/\beta\), this is exactly the ridge regression objective. The MAP solution is:

$$\mathbf{w}_{\mathrm{MAP}} = \mathbf{m}_N = \beta\,\mathbf{S}_N\,\boldsymbol{\Phi}^\top\mathbf{y} = (\beta^{-1}\alpha\mathbf{I} + \boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top\mathbf{y}$$

Numerical Trace (1D, 2 data points)

Let \(\phi(x) = [1, x]^\top\) (bias + slope), \(\sigma^2 = 0.25\) (\(\beta=4\)), \(\alpha=1\). Data: \((x_1,y_1)=(0, 0.5)\), \((x_2, y_2)=(1, 1.8)\).

$$\boldsymbol{\Phi} = \begin{bmatrix}1 & 0 \\ 1 & 1\end{bmatrix}, \quad \boldsymbol{\Phi}^\top\boldsymbol{\Phi} = \begin{bmatrix}2 & 1 \\ 1 & 1\end{bmatrix}$$
$$\mathbf{S}_N^{-1} = \mathbf{I} + 4\begin{bmatrix}2 & 1 \\ 1 & 1\end{bmatrix} = \begin{bmatrix}9 & 4 \\ 4 & 5\end{bmatrix} \implies \mathbf{S}_N = \frac{1}{29}\begin{bmatrix}5 & -4 \\ -4 & 9\end{bmatrix}$$
$$\mathbf{m}_N = 4\,\mathbf{S}_N\begin{bmatrix}2.3 \\ 1.8\end{bmatrix} = \begin{bmatrix}0.448 \\ 1.152\end{bmatrix}$$

So the posterior mean predicts \(\hat{y}(x) \approx 0.448 + 1.152\,x\). Predictive variance at \(x_* = 0.5\): \(\sigma^2_* = 0.25 + [1, 0.5]\,\mathbf{S}_N\,[1, 0.5]^\top = 0.25 + 0.028 = 0.278\). At \(x_* = 3\) (extrapolation): \(\sigma^2_* = 0.25 + 0.72 = 0.97\) — uncertainty is much larger far from data.

Evidence (Marginal Likelihood)

The model evidence \(p(\mathbf{y}) = \int p(\mathbf{y}\mid\mathbf{w})p(\mathbf{w})\,d\mathbf{w}\) is also Gaussian and closed-form. Maximizing it over \(\alpha,\beta\) (the Empirical Bayes / type-II ML approach) automatically sets the regularization strength — no cross-validation needed.

From-Scratch Implementation
▾

NumPy — Exact Posterior

import numpy as np

class BayesianLinearRegression:
    """Exact Bayesian linear regression with Gaussian conjugate prior.

    Model:  y = Phi @ w + eps,  eps ~ N(0, sigma2)
    Prior:  w ~ N(0, (1/alpha) * I)
    """
    def __init__(self, alpha=1.0, sigma2=0.25):
        self.alpha = alpha      # prior precision (= ridge lambda * beta)
        self.beta  = 1/sigma2  # noise precision
        self.m_N   = None       # posterior mean (set after fit)
        self.S_N   = None       # posterior covariance

    def _phi(self, X):
        """Polynomial basis: [1, x, x^2, ...]. Override for other bases."""
        return X  # assume X already has bias column

    def fit(self, X, y):
        Phi = self._phi(X)                    # (N, D)
        N, D = Phi.shape
        # Posterior precision = alpha*I + beta * Phi^T Phi
        S_N_inv = self.alpha * np.eye(D) + self.beta * Phi.T @ Phi
        self.S_N = np.linalg.inv(S_N_inv)    # (D, D)
        # Posterior mean = beta * S_N * Phi^T y
        self.m_N = self.beta * self.S_N @ Phi.T @ y  # (D,)
        return self

    def predict(self, X_star):
        """Returns (mean, variance) for each test point."""
        Phi_star = self._phi(X_star)          # (M, D)
        mean = Phi_star @ self.m_N            # (M,)
        # epistemic: phi^T S_N phi per point
        ep = np.einsum('md,dd,md->m', Phi_star, self.S_N, Phi_star)
        var = 1/self.beta + ep                # aleatoric + epistemic
        return mean, var

    def log_marginal_likelihood(self, X, y):
        """Closed-form log p(y) for model selection / hyperparameter tuning."""
        Phi = self._phi(X)
        N = len(y)
        C = (1/self.beta)*np.eye(N) + (1/self.alpha)*Phi @ Phi.T
        sign, logdet = np.linalg.slogdet(2*np.pi*C)
        return -0.5*(logdet + y @ np.linalg.solve(C, y))

# --- Demo ---
np.random.seed(42)
# True: y = 0.5 + 1.2*x + noise
X_train = np.column_stack([np.ones(10), np.linspace(0, 1, 10)])
y_train = X_train @ [0.5, 1.2] + np.random.randn(10)*0.5

model = BayesianLinearRegression(alpha=1.0, sigma2=0.25).fit(X_train, y_train)
print("Posterior mean:", model.m_N)   # ≈ [0.5, 1.2]

X_test = np.column_stack([np.ones(5), [0, 0.5, 1.0, 1.5, 2.0]])
mu, var = model.predict(X_test)
print("Means:", mu.round(3))
print("Std:  ", np.sqrt(var).round(3))  # larger at x=2.0 (extrapolation)

Scikit-learn / GPy Production Usage

# sklearn BayesianRidge (automatically estimates alpha, beta via Empirical Bayes)
from sklearn.linear_model import BayesianRidge
import numpy as np

model = BayesianRidge(
    alpha_init=1.0,   # prior precision initial guess
    lambda_init=1.0,  # noise precision initial guess
    compute_score=True,  # compute marginal likelihood at each EM step
)
model.fit(X_train[:, 1:], y_train)  # sklearn handles bias internally
mu, std = model.predict(X_test[:, 1:], return_std=True)

# ⚠️ Gotcha: sklearn's 'alpha_' is the NOISE precision (our beta),
#    and 'lambda_' is the PRIOR precision (our alpha). Naming is reversed
#    compared to Bishop's PRML convention!
print(f"Estimated noise std: {1/np.sqrt(model.alpha_):.3f}")
print(f"Estimated prior prec: {model.lambda_:.3f}")

Key Takeaways & Comparisons
▾

Bayesian vs Frequentist vs Ridge

The table below positions Bayesian linear regression against its closest alternatives:

Dimension OLS Ridge Bayesian LR
OutputPoint estimatePoint estimateFull distribution
UncertaintyBootstrap/asymptoticNone (by default)Exact, calibrated
RegularizationNoneManual \(\lambda\)Prior \(\alpha\) (tunable via evidence)
TractabilityExact \(O(D^3)\)Exact \(O(D^3)\)Exact \(O(D^3)\)
Model selectionAIC/BIC/CVCV for \(\lambda\)Marginal likelihood
  • Use Bayesian LR when you need calibrated uncertainty, small data, or out-of-distribution detection.
  • Use Ridge/OLS for large-scale problems where a point estimate suffices and computational cost is critical.
  • Bridge to GPs: Bayesian linear regression in infinite feature space = Gaussian Process regression.
