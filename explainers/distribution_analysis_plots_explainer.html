1
Understanding Distribution Analysis
▼

What is it? When you collect data — exam scores, sensor readings, prices — the first question is: how is it spread out? Distribution analysis gives you five different "lenses" to see the same data. Each lens reveals different features: raw counts, smooth density, normality, outliers, and shape all at once.

Real-world analogy: Imagine you have 120 students' test scores. A histogram bins them into ranges ("20 students scored 60–70"). KDE smooths that into a curve, like blurring a photo to see the overall shape. A Q-Q plot asks: "are these scores normally distributed?" The box plot gives you just five key numbers (min, Q1, median, Q3, max). The violin plot combines the box with the smooth density — the widest part shows where most students scored.

💡 If you remember one thing

All five plots show the same data — but reveal different things. Use histogram to see raw counts, KDE for smooth shape, Q-Q to check normality, box plot to spot outliers and skew, violin to see density + statistics together. In EDA, always use at least two.

Why it matters for ML: Before training any model, understanding your data's distribution tells you: whether to apply log-transforms (skewed data), whether outliers will corrupt gradient-based learning, whether normality assumptions in linear models are valid, and whether train/test data come from the same distribution (covariate shift detection).

2
How Each Plot Works Internally
▼

Histogram: bin counts

The x-axis is divided into \(k\) equal-width bins of width \(h = (\text{max} - \text{min}) / k\). For each bin \([x_i, x_{i+1})\), count the number of data points. Bar height = count. The critical choice is \(h\) (bin width). The Freedman-Diaconis rule sets \(h = 2 \cdot \text{IQR} \cdot n^{-1/3}\), balancing bias and variance. For our n=120: h ≈ 7.0, giving 12 bins. Too few bins → oversmooth (miss structure). Too many → noisy.

🔑 Histogram bias-variance tradeoff

Narrow bins: high variance (noisy counts), low bias (captures sharp features). Wide bins: low variance, high bias (misses peaks/valleys). The Freedman-Diaconis rule minimizes the mean integrated squared error between the histogram and the true density \(f(x)\).

KDE: kernel density estimation

KDE is a non-parametric density estimator. For each data point \(x_i\), place a Gaussian kernel of bandwidth \(h\): \(K_h(u) = \frac{1}{h\sqrt{2\pi}} e^{-u^2/(2h^2)}\). The estimated density is their average:

$$\hat{f}(x) = \frac{1}{nh} \sum_{i=1}^{n} K\!\left(\frac{x - x_i}{h}\right)$$

Silverman's rule of thumb for Gaussian kernels: \(h = 0.9 \cdot \min(\hat{\sigma}, \text{IQR}/1.34) \cdot n^{-1/5}\). For our data: h = 0.9 × min(15.56, 12.95) × 120⁻⁰·² = 4.48. The resulting curve integrates to 1.

Q-Q Plot: quantile comparison

Order the data: \(x_{(1)} \le x_{(2)} \le \ldots \le x_{(n)}\). Assign plotting positions \(p_i = (i - 0.5)/n\) (Hazen formula, avoids 0 and 1). Compute the theoretical normal quantile at each \(p_i\): \(\Phi^{-1}(p_i) \cdot \hat{\sigma} + \hat{\mu}\). Plot the pair (theoretical, empirical). If data is normal, all points fall on the 45° diagonal. Curves away from the line indicate non-normality.

Box Plot: Tukey's five-number summary

The box spans Q1 to Q3 (the IQR). The line inside is the median. Whiskers extend to the most extreme values within 1.5 × IQR of the box edges ("fences"). Points outside fences are plotted individually as outliers. For our data: lower fence = 57.8 − 26.0 = 31.7; upper fence = 75.1 + 26.0 = 101.1. Values 110.1 and 114.7 exceed the upper fence.

Violin Plot: density + statistics overlay

A violin mirrors the KDE on both sides of a center axis. The width at height \(y\) equals the KDE density at value \(y\) (scaled to a max width). A miniature box plot is drawn in the center. This gives you shape, modality, density, and the five-number summary in one view.

⚠️ Common Mistake

Trusting the histogram alone. Histograms are sensitive to bin origin — shifting the bin edges by half a bin width can make a unimodal distribution look bimodal. Always cross-check with KDE or a density rug plot. Also: box plots hide bimodality entirely.

3
The Math Behind It
▼

Histogram density estimator

The histogram with bin width \(h\) estimates the density at \(x\) in bin \(B_j\) as:

$$\hat{f}_h(x) = \frac{1}{nh} \#\{x_i \in B_j\}, \quad x \in B_j$$

The mean integrated squared error (MISE) of this estimator is:

$$\operatorname{MISE}(h) = \frac{1}{nh} \int f(x)\,dx + \frac{h^2}{12}\int [f'(x)]^2\,dx + O(h^4)$$

Minimizing MISE over \(h\) gives the optimal bin width \(h^* \propto n^{-1/3}\). The Freedman-Diaconis rule uses the interquartile range to make this robust to outliers:

$$h_{\text{FD}} = 2 \cdot \text{IQR}(x) \cdot n^{-1/3}$$

For our dataset: \(h_{\text{FD}} = 2 \times 17.36 \times 120^{-1/3} = 2 \times 17.36 \times 0.2027 = 7.04\). We use 12 bins for the range [20, 120].

KDE — full derivation

The Nadaraya-Watson kernel density estimator with Gaussian kernel \(K(u) = \frac{1}{\sqrt{2\pi}}e^{-u^2/2}\) is:

$$\hat{f}(x; h) = \frac{1}{nh} \sum_{i=1}^{n} K\!\left(\frac{x - x_i}{h}\right)$$

The bias and variance of this estimator are:

$$\operatorname{Bias}[\hat{f}(x)] \approx \frac{h^2}{2} f''(x) \int u^2 K(u)\,du, \quad \operatorname{Var}[\hat{f}(x)] \approx \frac{f(x)}{nh} \int K^2(u)\,du$$

The AMISE-optimal bandwidth under Gaussian kernel and assuming \(f\) is Gaussian is Silverman's rule:

$$h_{\text{Silverman}} = \left(\frac{4\hat{\sigma}^5}{3n}\right)^{1/5} \approx 1.06\,\hat{\sigma}\,n^{-1/5}$$

The robust variant replaces \(\hat{\sigma}\) with \(\min(\hat{\sigma}, \text{IQR}/1.34)\): for our data \(h = 0.9 \times \min(15.56, 12.95) \times 120^{-0.2} = \mathbf{4.48}\).

Numerical trace — KDE at \(x = 70\): sum of 120 Gaussian kernels \(\frac{1}{4.48\sqrt{2\pi}} e^{-[(70-x_i)/4.48]^2/2}\), then divide by 120. Result: \(\hat{f}(70) = 0.02463\).

Q-Q Plot — quantile theory

If \(X \sim F\) (any distribution) and \(Y \sim G\), then a Q-Q plot of \(F^{-1}(p)\) vs \(G^{-1}(p)\) is linear if and only if \(F\) and \(G\) belong to the same location-scale family. For testing normality, we use \(G = \Phi\) (standard normal) and plot:

$$\left(\Phi^{-1}\!\left(\frac{i-0.5}{n}\right),\; x_{(i)}\right), \quad i = 1,\ldots, n$$

If \(X \sim \mathcal{N}(\mu, \sigma^2)\), we expect \(x_{(i)} \approx \mu + \sigma \cdot \Phi^{-1}((i-0.5)/n)\), giving a straight line with slope \(\sigma\) and intercept \(\mu\). Upward curvature in the right tail (empirical > theoretical) indicates a heavy right tail. Our two outliers at 110.1 and 114.7 deviate above the reference line — confirming this.

Box plot — Tukey fences

Define the interquartile range \(\text{IQR} = Q_3 - Q_1\). The Tukey fences are:

$$\text{Lower fence} = Q_1 - 1.5 \cdot \text{IQR}, \quad \text{Upper fence} = Q_3 + 1.5 \cdot \text{IQR}$$

For our data: Lower = 57.79 − 26.04 = 31.75; Upper = 75.15 + 26.04 = 101.19. Any point outside these fences is plotted as a suspected outlier. The 1.5 multiplier was chosen by Tukey to give ~0.7% chance of falsely flagging a Gaussian observation as an outlier.

∑ Mean vs Median skewness test (Pearson)

For our dataset: Mean = 66.70, Median = 65.44, so \(\bar{x} > \text{Med}\) by 1.27. Pearson's second coefficient \(\approx 3(\bar{x} - \text{Med})/\hat{\sigma} = 0.24\). Fisher's moment skewness \(\gamma_1 = 0.47\). Both confirm mild positive (right) skew, consistent with the upper-tail cluster.

🎯 Decision Guide
  • Want to see raw counts / present to non-technical audience → Histogram
  • Want the true shape, mode structure, or to overlay distributions → KDE
  • Testing whether data is Gaussian (for model assumptions) → Q-Q plot
  • Comparing groups / spotting outliers quickly → Box plot
  • Comparing groups AND seeing density shape simultaneously → Violin plot
  • Best EDA practice → Use histogram + Q-Q as a pair, or KDE + box plot

When NOT to use each

  • Histogram — Don't use with tiny datasets (n < 15), or when you need to compare many groups overlaid.
  • KDE — Don't trust with n < 30. Don't use for discrete data (produces spurious density between integers).
  • Q-Q plot — Only tests against a reference distribution; doesn't show density or counts.
  • Box plot — Never use alone when the shape matters (can't detect bimodality or heavy tails beyond outlier dots).
  • Violin — Can be misleading with small n (KDE will be noisy). Use beeswarm plots for n < 30.

From-scratch Python (NumPy only)

import numpy as np
from scipy import stats
np.random.seed(42)
# Our dataset: 120 samples, right-skewed, 2 outliers
data = np.concatenate([np.random.normal(65,12,100), np.random.normal(95,8,15), np.random.normal(40,5,5)])
# ── Histogram stats ──────────────────────────
iqr = np.percentile(data,75) - np.percentile(data,25) # 17.36
fd_h = 2 * iqr * len(data)**(-1/3) # Freedman-Diaconis: h=7.04
counts, edges = np.histogram(data, bins=int(np.ceil((data.max()-data.min())/fd_h)))
# ── KDE from scratch ──────────────────────────
def kde(x_eval, data, bw):
"""Gaussian KDE: sum of n Gaussian kernels, normalized."""
n = len(data)
kernels = np.exp(-0.5*((x_eval - data)/bw)**2) / (bw * np.sqrt(2*np.pi))
return kernels.mean() # divide by n
bw = 0.9 * min(data.std(), iqr/1.34) * len(data)**(-0.2) # Silverman: 4.476
xs = np.linspace(20, 120, 500)
density = np.array([kde(x, data, bw) for x in xs]) # vectorise for speed
# ── Q-Q plot ──────────────────────────────────
n = len(data); sorted_data = np.sort(data)
probs = (np.arange(1, n+1) - 0.5) / n # Hazen plotting positions
theoretical = stats.norm.ppf(probs, loc=data.mean(), scale=data.std())
# Plot: theoretical on x-axis, sorted_data on y-axis
# Points on diagonal → normal; curves → non-normal
# ── Box plot stats ────────────────────────────
q1, median, q3 = np.percentile(data, [25,50,75])
iqr = q3 - q1 # 17.36
lo_fence, hi_fence = q1 - 1.5*iqr, q3 + 1.5*iqr # 31.75, 101.19
outliers = data[(data < lo_fence) | (data > hi_fence)] # [110.1, 114.7]
whisker_lo = data[data >= lo_fence].min() # 33.6
whisker_hi = data[data <= hi_fence].max() # 98.2

Production: matplotlib + seaborn

import matplotlib.pyplot as plt
import seaborn as sns
fig, axes = plt.subplots(1, 5, figsize=(20, 5))
# 1. Histogram (auto bin-width via Freedman-Diaconis)
axes[0].hist(data, bins='fd', color='#4A90D9', alpha=0.8, edgecolor='white')
# 2. KDE (Silverman bandwidth, adjust= multiplies it)
sns.kdeplot(data, ax=axes[1], bw_method='silverman', fill=True)
# 3. Q-Q plot
import scipy.stats as stats
stats.probplot(data, dist='norm', plot=axes[2]) # auto draws reference line
# 4. Box plot (whis=1.5 is Tukey default)
axes[3].boxplot(data, whis=1.5, patch_artist=True)
# 5. Violin plot (inner='box' adds miniature box inside)
sns.violinplot(y=data, ax=axes[4], inner='box', bw_method='silverman')
plt.tight_layout(); plt.show()
💡 Key Takeaways
  • Use at least two complementary plots in EDA (e.g., KDE + Q-Q, or histogram + box plot)
  • Bin-width / bandwidth are the most impactful parameters — always try multiple values
  • Q-Q plot is the fastest way to check normality assumptions before linear regression or t-tests
  • Violin plots are the best single plot for multi-group comparison presentations
  • All five plots agree: our dataset is roughly normal with a right-skewed tail and 2 outliers
