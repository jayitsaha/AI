Decision Tree Pruning

Pre-pruning (max_depth, min_samples_split) & Post-pruning (Cost-Complexity α)
Intermediate Classical ML Trees Review Track
1
The Concept in 30 Seconds
▼

What is pruning? A decision tree left to grow freely memorises the training data — every leaf contains just one or two examples, and the model fails on new data. Pruning is the corrective surgery: trim the tree so it generalises instead of memorising.

Two strategies, opposite order:

  • Pre-pruning — set guardrails before growing. You tell the tree: "don't go deeper than 5 levels" (max_depth) or "don't split a node that has fewer than 10 samples" (min_samples_split). The tree stops early and never sees the data it would have overfit.
  • Post-pruning (cost-complexity / CART) — grow the full tree first, then collapse the weakest subtrees. A penalty parameter \(\alpha \geq 0\) trades accuracy for simplicity; the best \(\alpha\) is chosen by cross-validation.

Analogy: Pre-pruning is telling a sculptor "only use 5 chisels per session." Post-pruning is letting the sculptor finish, then removing every detail whose visual impact is smaller than the effort it cost.

💡 If you remember one thing

Pre-pruning stops growth early via hard constraints. Post-pruning grows fully then collapses subtrees whose per-leaf impurity gain is less than a regularisation constant \(\alpha\). Cross-validation selects the right \(\alpha\).

2
How It Works — Mechanisms & Math
▼

Pre-Pruning Parameters

max_depth — hard ceiling on tree depth. A node at depth \(d = \texttt{max\_depth}\) becomes a leaf regardless of impurity. Prevents exponential node growth: a balanced binary tree of depth \(d\) has \(2^d\) leaves.

min_samples_split — a node is split only if it contains at least \(n_{\min}\) samples. Formally, for a node \(t\) with \(|t|\) samples:

$$\text{split}(t) \iff |t| \geq n_{\min}$$

min_impurity_decrease — split only if the weighted impurity decrease \(\Delta i(t)\) exceeds a threshold \(\delta\):

$$\Delta i(t) = i(t) - \frac{|t_L|}{|t|}\,i(t_L) - \frac{|t_R|}{|t|}\,i(t_R) \geq \delta$$

where \(i(t)\) is the Gini impurity or entropy at node \(t\), and \(t_L, t_R\) are the left and right children.

Post-Pruning: Cost-Complexity (CART)

Let \(T\) be a fully grown tree and \(T_t\) be the subtree rooted at internal node \(t\). Define:

  • \(R(T)\) = total leaf misclassification (or impurity) — sum of \(p(t)\cdot e(t)\) over all leaves, where \(p(t)\) is the fraction of training samples reaching leaf \(t\) and \(e(t)\) is the leaf's error rate.
  • \(|\tilde{T}|\) = number of leaves in tree \(T\).

The cost-complexity criterion penalises tree size:

$$R_\alpha(T) = R(T) + \alpha\,|\tilde{T}|$$

For each internal node \(t\), compute the effective \(\alpha\) at which pruning that subtree becomes beneficial:

$$\alpha_{\text{eff}}(t) = \frac{R(t) - R(T_t)}{|\tilde{T}_t| - 1}$$

where \(R(t)\) is the resubstitution error if \(t\) were a leaf, and \(R(T_t)\) is the error of the full subtree. Prune the node with the smallest \(\alpha_{\text{eff}}\) first. Repeat to produce a sequence of trees \(T_0 \supset T_1 \supset \cdots \supset T_{\text{root}}\). Then cross-validate to pick the best \(\alpha^*\).

Key Formula

$$\alpha_{\text{eff}}(t) = \frac{R(t) - R(T_t)}{|\tilde{T}_t| - 1}$$

Numerator: error gained by pruning (error goes up by this). Denominator: leaves eliminated. The ratio is the per-leaf cost of the subtree's complexity. Prune cheapest first.

Numerical Trace

Suppose a subtree \(T_t\) has 3 leaves, \(R(T_t) = 0.10\) (10% weighted error), and collapsing \(t\) to a leaf gives \(R(t) = 0.16\):

$$\alpha_{\text{eff}}(t) = \frac{0.16 - 0.10}{3 - 1} = \frac{0.06}{2} = 0.03$$

If a second candidate subtree has \(\alpha_{\text{eff}} = 0.05\), prune the first subtree first. After pruning, the sequence moves to \(T_1\), recompute \(\alpha_{\text{eff}}\) for remaining nodes, prune smallest next, and so on.

⚠ Common Mistake

Scikit-learn's ccp_alpha is the \(\alpha\) in the criterion — not the effective \(\alpha\) of any particular node. You sweep \(\alpha\) from 0 to max effective and pick via CV. A single large \(\alpha\) collapses the tree to the root.

Decision Rule

Use pre-pruning when you need fast training and interpretable controls. Use post-pruning (ccp_alpha) when generalisation is the priority and you can afford a CV sweep. In practice, combine both: set modest max_depth and tune ccp_alpha for fine control.

Interview Q&A (Review)

Q: What does min_samples_split = 20 mean?
A: A node is only split if it has at least 20 training samples. Prevents learning from tiny groups.

Q: Can ccp_alpha = 0 produce overfitting?
A: Yes — \(\alpha = 0\) disables the penalty entirely, giving the full unpruned tree.

Q: How do you pick ccp_alpha in sklearn?
A: Use cost_complexity_pruning_path() to get the candidate alphas and impurities, then grid-search over them with cross-validation.

Q: Why is the denominator \(|\tilde{T}_t| - 1\) in the effective alpha formula?
A: Pruning the subtree replaces \(|\tilde{T}_t|\) leaves with 1 leaf — the gain in simplicity is \(|\tilde{T}_t| - 1\) leaves removed.

Code — sklearn Implementation
▼

Pre-Pruning

from sklearn.tree import DecisionTreeClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import cross_val_score
X, y = make_classification(n_samples=300, n_features=10, random_state=42)
# Pre-pruning: stop early using hard constraints
clf_pre = DecisionTreeClassifier(
max_depth=4, # max levels from root to leaf
min_samples_split=20, # must have >= 20 samples to split
min_impurity_decrease=0.01, # split only if gain >= delta
random_state=42
)
clf_pre.fit(X, y)
print("Pre-pruned leaves:", clf_pre.get_n_leaves()) # typically ~12
# Post-pruning via cost-complexity
path = DecisionTreeClassifier(random_state=42).cost_complexity_pruning_path(X, y)
ccp_alphas = path.ccp_alphas[:-1] # drop last (collapses to root)
# CV-select best alpha
best_alpha, best_score = 0, 0
for alpha in ccp_alphas:
clf = DecisionTreeClassifier(ccp_alpha=alpha, random_state=42)
score = cross_val_score(clf, X, y, cv=5).mean()
if score > best_score:
best_score, best_alpha = score, alpha
clf_post = DecisionTreeClassifier(ccp_alpha=best_alpha, random_state=42).fit(X, y)
print(f"Best alpha: {best_alpha:.4f}, leaves: {clf_post.get_n_leaves()}")
Production Tip

Always exclude the last alpha from cost_complexity_pruning_path — it collapses the tree to a single root leaf (100% error for multi-class). Use GridSearchCV over the alpha sequence for cleaner code.

Key Takeaways
▼
  • Pre-pruning: simple, fast, interpretable — controls via max_depth, min_samples_split, min_impurity_decrease.
  • Post-pruning: globally optimal via cost-complexity — build full tree, compute \(\alpha_{\text{eff}}(t)\) per node, prune smallest first, CV-select \(\alpha^*\).
  • Cost-complexity criterion: \(R_\alpha(T) = R(T) + \alpha\,|\tilde{T}|\). Higher \(\alpha\) → smaller tree.
  • Both methods combat overfitting but differ in when they act and how much data they see first.
  • In sklearn: max_depth / min_samples_split for pre-pruning; ccp_alpha from cost_complexity_pruning_path + CV for post-pruning.
