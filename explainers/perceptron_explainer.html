The Perceptron

Rosenblatt's linear threshold classifier — the mistake-driven learning rule that rotates a hyperplane until it separates two classes, and why it fails on XOR.

Foundational Classical ML O(1) update / O(R²/γ²) mistakes Must Know
1
Understanding the Concept

A perceptron is the simplest artificial neuron: it takes input features x, multiplies each by a learned weight, sums them with a bias, and fires +1 or −1 depending on which side of a threshold the sum lands on. Formally, \( \hat{y} = \operatorname{sign}(w^\top x + b) \). Geometrically, the equation \( w^\top x + b = 0 \) is a straight line (or hyperplane in higher dimensions) — everything on one side is classified +1, everything on the other side is −1.

Think of a bouncer scoring guests with a weighted checklist — points for being on the guest list, points deducted for sneakers — and admitting anyone whose total clears a cutoff. The perceptron's learning rule is that bouncer adjusting each checklist weight, but only after making a mistake: reject someone who should've been admitted, or vice versa. Over many corrections the checklist converges to one that never errs again — provided such a checklist exists at all.

💡 If you remember one thing

The update rule is \( w \leftarrow w + \eta(y-\hat y)x \) — weights move only on mistakes, and they move directly toward fixing the specific point that was misclassified.

2
How It Works Internally

Forward pass (inference): compute the linear combiner \( z = w^\top x + b \), then apply the hard step activation \( \hat y = \operatorname{sign}(z) \). That's the entire model — one dot product, one threshold.

Learning (training): for each labeled example, compare the prediction to the true label. If they agree, do nothing. If they disagree, nudge the weights:

$$w \leftarrow w + \eta\,(y-\hat y)\,x, \qquad b \leftarrow b + \eta\,(y-\hat y)$$

On a mistake \( (y-\hat y) = \pm 2 \), so the weight vector rotates toward a misclassified positive point (increasing \( w^\top x \)) or away from a misclassified negative point (decreasing \( w^\top x \)). Repeated across the dataset, this slowly rotates and shifts the decision line until every training point sits on its correct side — provided the classes are linearly separable. Rosenblatt's original 1958 design chose a hard step (not a smooth sigmoid) to model "fire / don't fire" biological neurons, and a mistake-driven rule (not gradient descent on a differentiable loss) because the step function has no useful gradient.

⚠️ Design decision

Because the step function isn't differentiable, this ISN'T literally backprop — it's a combinatorial "move toward the point you got wrong" rule, later shown to be sub-gradient descent on the unnormalized perceptron criterion \( L(w) = -\sum_{i \in \text{mistakes}} y^{(i)} w^\top x^{(i)} \).

3
Why It Works — Convergence Guarantee

Novikoff's theorem (1962): if the data is linearly separable with margin \( \gamma \) (the minimum distance from any point to the ideal separating hyperplane, using a unit weight vector \( w^* \)) and every input satisfies \( \|x\| \le R \), then the perceptron makes at most:

$$k \le \frac{R^2}{\gamma^2} \text{ mistakes before converging}$$

The intuition: every mistake grows the alignment \( w^{*\top}w \) with the ideal boundary by at least \( \gamma \) (linear growth), while it grows \( \|w\|^2 \) by at most \( R^2 \) (so \( \|w\| \) grows only like \( \sqrt{k} \)). Since alignment can never outpace norm (Cauchy–Schwarz), the number of mistakes is capped — independent of dataset size or dimensionality.

🔑 The core invariant

The perceptron's entire hypothesis class is linear hyperplanes. If no hyperplane separates the classes (e.g. XOR), the update rule cycles forever — this is a representational ceiling, not an optimization bug.

5
Key Takeaways

The perceptron is a linear classifier trained by a simple mistake-driven rule: leave weights alone when correct, nudge them toward the misclassified point when wrong. Novikoff's theorem guarantees convergence in a bounded number of mistakes — if and only if the data is linearly separable. XOR is the classic counterexample: no single line separates it, so the rule never converges, which is exactly what motivated stacking perceptron-like units into multi-layer networks trained with backpropagation.
