Attention as Soft Alignment

Dynamically focusing on relevant information in neural networks
Foundational NLP Deep Learning O(N²) complexity
1
Understanding Attention
▼

What is it? In complex tasks like translating a sentence or generating text, not all parts of the input are equally important for every output step. Attention mechanisms allow a neural network to dynamically weigh the importance of different input elements when processing or generating an output element.

Analogy: Imagine you're writing a summary of a long document. When you write a specific sentence in your summary, your "attention" focuses on a few key sentences or paragraphs in the original document that are most relevant to what you're currently writing. You don't read the whole document equally for every single word of your summary. Attention in neural networks works similarly: it allows the model to "look at" and prioritize specific parts of its input.

💡 If you remember one thing

Attention computes a weighted sum of "Value" vectors, where the weights are determined by the "similarity" between a "Query" vector and a set of "Key" vectors. This allows the model to "softly align" the query with relevant information.

2
How Attention Works Internally
▼

The QKV Triad

The core of attention revolves around three conceptual vectors:

  • Query (Q): Represents "what I'm looking for." This is typically the current state or element that needs context.
  • Keys (K): Represents "what I have." These are labels or summaries of available information.
  • Values (V): Represents "the actual information." These are the content associated with each key.

Think of it like searching a database: your search query (Q) is matched against a list of keywords (K) for each document. For the documents that match well, you retrieve their full content (V).

The Soft Alignment Process

  1. Calculate Similarity: The Query (Q) is compared to each Key (K) to determine how well they "align" or how similar they are. A common similarity measure is the dot product: \(Q \cdot K_i\).
  2. Scale (Optional but Common): The raw similarity scores are often scaled down by a factor (e.g., the square root of the key dimension, \(\sqrt{d_k}\)) to prevent the softmax function from having extremely small gradients when inputs are large.
  3. Softmax: The scaled similarity scores are passed through a softmax function. This converts them into a probability distribution, ensuring all weights are positive and sum to 1. These are the attention weights.
  4. Weighted Sum: Each Value (V) is multiplied by its corresponding attention weight. These weighted values are then summed up to produce the final context vector or output. This output is a blend of the input values, with more relevant values contributing more heavily.
🔑 Key Property

Attention is differentiable, meaning it can be learned via backpropagation. The model learns how to generate Q, K, and V vectors, and thus learns what to attend to, and how much.

3
Why It Works — The Math
▼

The Scaled Dot-Product Attention Formula

Given a Query vector \(\mathbf{q}\), a set of Key vectors \(\mathbf{K}\) (stacked as a matrix where each row is a key), and a set of Value vectors \(\mathbf{V}\) (stacked similarly), the attention output \(\mathbf{Z}\) is calculated as:

$$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}$$

Let's break this down step-by-step:

Step 1: Compute Raw Alignment Scores

The dot product \(\mathbf{Q}\mathbf{K}^\top\) measures the similarity between the query and each key. If \(\mathbf{Q}\) is a single vector, this results in a vector of scores. If \(\mathbf{Q}\) is a matrix (multiple queries), it results in a matrix of scores.

$$\text{Scores} = \mathbf{Q}\mathbf{K}^\top$$

Each element \(\text{Scores}_{ij}\) represents the similarity between query \(i\) and key \(j\).

Step 2: Scale the Scores

The scaling factor \(\frac{1}{\sqrt{d_k}}\) (where \(d_k\) is the dimension of the key vectors) is crucial. Without it, for large \(d_k\), the dot products can become very large in magnitude, pushing the softmax function into regions with extremely small gradients. This can hinder stable training.

$$\text{Scaled Scores} = \frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}$$

Step 3: Apply Softmax to Get Attention Weights

The softmax function converts the scaled scores into a probability distribution. For each query, the sum of its attention weights across all keys will be 1. This ensures that the model assigns a relative "importance" to each value.

$$\text{Attention Weights} = \text{softmax}(\text{Scaled Scores})$$

If \(\mathbf{Q}\) is a single vector, this results in a vector of weights \(\alpha_1, \alpha_2, \dots, \alpha_n\).

Step 4: Compute the Weighted Sum of Values

Finally, these attention weights are used to take a weighted average of the Value vectors. The resulting output vector \(\mathbf{Z}\) (or context vector) is a combination of the input values, emphasizing those values whose corresponding keys were most similar to the query.

$$\mathbf{Z} = \text{Attention Weights} \cdot \mathbf{V}$$

This output \(\mathbf{Z}\) then serves as a context-aware representation that can be used by subsequent layers in the neural network.

➗ Why \(\sqrt{d_k}\)?

If query and key components are independent random variables with mean 0 and variance 1, their dot product has mean 0 and variance \(d_k\). Dividing by \(\sqrt{d_k}\) ensures the variance of the scaled dot product remains 1, stabilizing training.

Key Takeaways
▼

When to use Attention:

  • Sequence-to-sequence tasks: Machine translation, summarization, where output words need to focus on different input words.
  • Long sequences: Helps models handle long-range dependencies by directly connecting distant parts of a sequence.
  • Contextual understanding: Allows models to build representations that are dynamically informed by relevant parts of the input.
  • Interpretability: Attention weights can sometimes be visualized to understand what parts of the input the model is focusing on.

Beyond Basic Attention:

  • Multi-Head Attention: Multiple attention mechanisms run in parallel, each focusing on different aspects of the input, then their outputs are concatenated. This is a core component of the Transformer architecture.
  • Self-Attention: The Query, Keys, and Values all come from the same input sequence. This allows elements within a sequence to attend to each other, capturing internal dependencies.
  • Cross-Attention: Queries come from one sequence (e.g., decoder state) and Keys/Values come from another (e.g., encoder output).
💡 Impact

Attention mechanisms, especially in the form of Self-Attention and Multi-Head Attention, are the bedrock of the Transformer architecture, which revolutionized NLP and is now widely used in computer vision and other domains.

Code Trace
▼
import numpy as np
def softmax(x):
e_x = np.exp(x - np.max(x)) # Subtract max for numerical stability
return e_x / e_x.sum(axis=-1, keepdims=True)
# Input vectors (example dimensions)
query = np.array([0.7, 0.3, -0.1]) # d_k = 3
keys = np.array([
[0.8, 0.2, 0.1],
[0.1, 0.9, 0.2],
[0.2, 0.1, 0.7]
])
values = np.array([
[1.0, 0.5], # d_v = 2
[0.2, 0.8],
[0.6, 0.4]
])
d_k = query.shape[-1] # Dimension of keys
# 1. Calculate raw alignment scores (dot product)
scores = np.dot(query, keys.T)
# 2. Scale scores
scaled_scores = scores / np.sqrt(d_k)
# 3. Apply softmax to get attention weights
attention_weights = softmax(scaled_scores)
# 4. Compute weighted sum of values
output = np.dot(attention_weights, values)
print("Query:", query)
print("Keys:\n", keys)
print("Values:\n", values)
print("Scores:", scores)
print("Scaled Scores:", scaled_scores)
print("Attention Weights:", attention_weights)
print("Output (Context Vector):", output)
