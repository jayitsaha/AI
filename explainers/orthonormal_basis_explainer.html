Orthogonality & Orthonormal Basis

When perpendicular vectors make everything trivial — coordinates, projections, and QᵀQ = I
Foundational Linear Algebra Part I · Math & Stats Review
1
The 30-Second Version
▼

What is it? Imagine your kitchen is arranged so every drawer handles exactly one category — one for cutlery, one for towels, one for gadgets — and none of the categories overlap. An orthonormal basis is the mathematical equivalent: a set of directions in space that are perfectly perpendicular to each other ("orthogonal") and each has length exactly one ("normal"). Together they give you a clean, non-redundant coordinate system.

Real-world analogy: Think of a building's coordinate system: East, North, and Up. Each direction is perpendicular to the others — moving east doesn't change how far north you are. That's orthogonality. If we scale each direction to mean "one city block," we have orthonormality. Finding your address in this system is effortless: just measure how far you went in each direction independently.

Why does this matter? In a standard (non-orthogonal) basis, to find the coordinates of a point you must solve a system of equations — matrix inversion. In an orthonormal basis, the coordinate along each axis is just a dot product — no inversion required. This is why nearly every numerical algorithm in ML (PCA, QR decomposition, SVD, Gram-Schmidt) chases orthonormality.

If you remember one thing

If \(Q\) has orthonormal columns, then \(Q^\top Q = I\). That single equation means: coordinates are free (just dot products), matrix inverse is free (\(Q^{-1} = Q^\top\)), and the transformation preserves lengths and angles.

2
Core Concepts & Definitions
▼

Orthogonality: dot product = 0

Two vectors \(\mathbf{u}, \mathbf{v} \in \mathbb{R}^n\) are orthogonal if their inner product vanishes:

$$\mathbf{u} \perp \mathbf{v} \iff \langle \mathbf{u}, \mathbf{v} \rangle = \mathbf{u}^\top \mathbf{v} = \sum_{i=1}^n u_i v_i = 0$$

Geometrically, this means the angle \(\theta\) between them satisfies \(\cos\theta = 0\), i.e., they meet at 90°. Orthogonality implies no information overlap — knowing the component of a vector along \(\mathbf{u}\) tells you nothing about its component along \(\mathbf{v}\).

Orthonormality: unit + orthogonal

A set \(\{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_n\}\) is an orthonormal set if every pair is orthogonal AND every vector has unit norm:

$$\langle \mathbf{e}_i, \mathbf{e}_j \rangle = \delta_{ij} = \begin{cases} 1 & i = j \\ 0 & i \neq j \end{cases}$$

where \(\delta_{ij}\) is the Kronecker delta. If these vectors span \(\mathbb{R}^n\), they form an orthonormal basis.

The Orthonormal Basis Superpower: Trivial Coordinates

Given any orthonormal basis \(\{\mathbf{e}_1, \ldots, \mathbf{e}_n\}\) and a vector \(\mathbf{x} \in \mathbb{R}^n\), its coordinates \(c_i\) in this basis are simply:

$$c_i = \langle \mathbf{x}, \mathbf{e}_i \rangle = \mathbf{x}^\top \mathbf{e}_i, \qquad \text{so that} \quad \mathbf{x} = \sum_{i=1}^n c_i \mathbf{e}_i$$

In a non-orthogonal basis, finding coordinates requires solving \(V\mathbf{c} = \mathbf{x}\), i.e., computing \(V^{-1}\). With an orthonormal basis, \(Q^{-1} = Q^\top\) — so coordinates cost only \(n\) dot products, not an \(O(n^3)\) inversion.

Key Property: QᵀQ = I

If \(Q \in \mathbb{R}^{n \times n}\) has columns \(\mathbf{e}_1, \ldots, \mathbf{e}_n\) that form an orthonormal basis, then \(Q^\top Q = I_n\). This means \(Q^{-1} = Q^\top\) — free inversion. Such matrices are called orthogonal matrices. They represent isometries: rotations and reflections that preserve lengths and angles.

Orthogonal Projection

The projection of \(\mathbf{x}\) onto a subspace \(V = \text{span}\{\mathbf{e}_1,\ldots,\mathbf{e}_k\}\) spanned by orthonormal vectors is:

$$\text{proj}_V(\mathbf{x}) = \sum_{i=1}^k \langle \mathbf{x}, \mathbf{e}_i \rangle \, \mathbf{e}_i = QQ^\top \mathbf{x}$$

where \(Q = [\mathbf{e}_1 \mid \cdots \mid \mathbf{e}_k]\). The matrix \(P = QQ^\top\) is the orthogonal projector onto \(V\). It satisfies \(P^2 = P\) (idempotent) and \(P^\top = P\) (symmetric). Again, the formula is effortless only because \(Q^\top Q = I_k\).

Common Confusion

"Orthogonal matrix" is a confusing name — it means a matrix with orthonormal columns (not just orthogonal columns). Orthogonal matrices satisfy \(Q^\top Q = QQ^\top = I\), which forces the columns AND the rows to be orthonormal. Do not confuse with a matrix whose columns are merely pairwise orthogonal (but not unit length).

The Math — Gram-Schmidt & Projections
▼

Gram-Schmidt Orthogonalization

Given any linearly independent set \(\{\mathbf{v}_1, \ldots, \mathbf{v}_k\}\), the Gram-Schmidt process constructs an orthonormal basis \(\{\mathbf{e}_1, \ldots, \mathbf{e}_k\}\) spanning the same subspace. The idea: at each step, subtract off everything parallel to the vectors already processed.

Algorithm (classical Gram-Schmidt):

$$\mathbf{u}_j = \mathbf{v}_j - \sum_{i=1}^{j-1} \langle \mathbf{v}_j, \mathbf{e}_i \rangle\, \mathbf{e}_i, \qquad \mathbf{e}_j = \frac{\mathbf{u}_j}{\|\mathbf{u}_j\|}$$

Each subtraction "kills" the component of \(\mathbf{v}_j\) along the previously computed basis directions, leaving a residual \(\mathbf{u}_j\) that is orthogonal to all of \(\mathbf{e}_1, \ldots, \mathbf{e}_{j-1}\). Normalizing gives the next orthonormal vector.

Numerical Trace (our 2D example)

Starting with \(\mathbf{v}_1 = [3, 1]\) and \(\mathbf{v}_2 = [2, 2]\):

$$\mathbf{e}_1 = \frac{\mathbf{v}_1}{\|\mathbf{v}_1\|} = \frac{[3,1]}{\sqrt{10}} = \left[\frac{3}{\sqrt{10}},\, \frac{1}{\sqrt{10}}\right] \approx [0.9487,\, 0.3162]$$
$$\text{proj} = \langle \mathbf{v}_2, \mathbf{e}_1 \rangle\, \mathbf{e}_1 = \frac{8}{\sqrt{10}} \cdot \frac{[3,1]}{\sqrt{10}} = \frac{8}{10}[3,1] = [2.4,\, 0.8]$$
$$\mathbf{u}_2 = \mathbf{v}_2 - \text{proj} = [2-2.4,\; 2-0.8] = [-0.4,\, 1.2]$$
$$\mathbf{e}_2 = \frac{\mathbf{u}_2}{\|\mathbf{u}_2\|} = \frac{[-0.4,1.2]}{\sqrt{0.16+1.44}} = \frac{[-0.4,1.2]}{4/\sqrt{10}} = \left[\frac{-1}{\sqrt{10}},\, \frac{3}{\sqrt{10}}\right] \approx [-0.3162,\, 0.9487]$$

Verification: \(\langle \mathbf{e}_1, \mathbf{e}_2 \rangle = (3/\sqrt{10})(-1/\sqrt{10}) + (1/\sqrt{10})(3/\sqrt{10}) = -3/10 + 3/10 = 0\). And \(\|\mathbf{e}_1\| = \|\mathbf{e}_2\| = 1\). Orthonormal!

The Q = U R Factorization (QR Decomposition)

Gram-Schmidt on the columns of a matrix \(A = [\mathbf{v}_1 | \cdots | \mathbf{v}_k]\) produces the QR factorization:

$$A = QR$$

where \(Q\) has orthonormal columns and \(R\) is upper triangular. The entries of \(R\) are exactly the projection scalars computed in Gram-Schmidt: \(R_{ij} = \langle \mathbf{v}_j, \mathbf{e}_i \rangle\) for \(i \leq j\). QR is fundamental to: solving least-squares problems, computing eigenvalues (QR algorithm), and numerical linear algebra.

Projection Formula — Why QᵀQ = I Makes It Trivial

To project \(\mathbf{x}\) onto the column space of \(A\) using a general basis, the formula is:

$$\hat{\mathbf{x}} = A(A^\top A)^{-1} A^\top \mathbf{x}$$

The \((A^\top A)^{-1}\) term requires matrix inversion. But if \(A = Q\) has orthonormal columns, \(Q^\top Q = I\), so:

$$\hat{\mathbf{x}} = Q(Q^\top Q)^{-1} Q^\top \mathbf{x} = Q I Q^\top \mathbf{x} = QQ^\top \mathbf{x}$$

No inversion. The coordinates are \(\mathbf{c} = Q^\top \mathbf{x}\), and the projection is \(Q\mathbf{c}\). This is why orthonormal bases are the computational workhorse of all projection-based methods.

Parseval's Identity (Energy Preservation)

For any orthonormal basis \(\{\mathbf{e}_i\}\) and any vector \(\mathbf{x}\):
\(\|\mathbf{x}\|^2 = \sum_{i=1}^n \langle \mathbf{x}, \mathbf{e}_i \rangle^2 = \sum_i c_i^2\).
The squared norm equals the sum of squared coordinates. In our example: \(p=[4,3]\) has \(\|p\|^2 = 25\), and \(c_1^2 + c_2^2 = (8/\sqrt{10})^2 + (2/\sqrt{10} \cdot \sqrt{10}/\sqrt{10})^2\). Let's verify: \(c_1 = 4(3/\sqrt{10})+3(1/\sqrt{10}) = 15/\sqrt{10}\), \(c_2 = 4(-1/\sqrt{10})+3(3/\sqrt{10}) = 5/\sqrt{10}\), and \(c_1^2+c_2^2 = 225/10+25/10 = 25 = \|p\|^2\). ✓

5
Why Orthonormal Bases Matter in ML
▼

Orthonormal bases are not just a mathematical elegance — they are the computational foundation of the most important algorithms in ML. Here is where they appear and why:

Principal Component Analysis (PCA)

PCA finds the directions of maximum variance in data. It computes the eigenvectors of the covariance matrix \(\Sigma = U \Lambda U^\top\), where \(U\) is an orthogonal matrix (columns are the principal components). Because the eigenvectors are orthonormal, projecting onto the top-\(k\) components is trivially \(\hat{X} = X U_k\), and the reconstruction is \(X U_k U_k^\top\) — no inversion. The orthonormality also guarantees the components are uncorrelated and ordered by variance.

QR Algorithm for Eigenvalues

The most widely used algorithm for computing eigenvalues works by repeatedly factoring \(A = QR\) and then forming \(A' = RQ\). Each iteration, the matrix converges toward an upper triangular form (Schur form) with eigenvalues on the diagonal. The stability and efficiency of this algorithm rely entirely on the orthogonality of \(Q\).

SVD and Least Squares

The Singular Value Decomposition writes \(A = U \Sigma V^\top\), where both \(U\) and \(V\) are orthogonal. The least-squares solution to \(A\mathbf{x} = \mathbf{b}\) is \(\hat{\mathbf{x}} = V \Sigma^+ U^\top \mathbf{b}\) — again, only matrix-vector products (no inversion) because of the orthogonal factors. This makes SVD-based least squares numerically stable even for ill-conditioned matrices.

Transformer Attention (Scaled Dot-Product)

While attention heads do not enforce orthogonality, research shows attention learns to spread queries across near-orthogonal key directions for efficient information routing. RoPE positional encodings use rotation matrices (orthogonal!) to encode position, preserving the inner-product structure that makes attention interpretable.

The Big Picture

Every time an ML algorithm decomposes a matrix into simpler parts, it chases orthonormality. The reason is always the same: orthonormal bases make coordinates free (dot products only), inversion free (\(Q^{-1}=Q^\top\)), and norms preserved (\(\|Q\mathbf{x}\|=\|\mathbf{x}\|\)). These three properties together make computations fast, numerically stable, and geometrically interpretable.

Code: Gram-Schmidt from Scratch
▼
import numpy as np
def gram_schmidt(V):
"""Classical Gram-Schmidt orthogonalization.
Args:
V: (n, k) matrix — k linearly independent column vectors in R^n
Returns:
Q: (n, k) matrix with orthonormal columns spanning same subspace as V
"""
n, k = V.shape
Q = np.zeros((n, k))
for j in range(k):
# Start with the j-th input vector
u = V[:, j].copy()
# Subtract projections onto all previous orthonormal vectors
for i in range(j):
coeff = np.dot(Q[:, i], V[:, j]) # = <v_j, e_i>
u -= coeff * Q[:, i] # remove component along e_i
# Normalize — if u ≈ 0, the vectors were linearly dependent
norm = np.linalg.norm(u)
if norm < 1e-10:
raise ValueError(f"Column {j} is linearly dependent on previous columns")
Q[:, j] = u / norm
return Q
# --- Demo with our 2D example ---
V = np.array([[3., 2.],
[1., 2.]]) # columns are v1=[3,1], v2=[2,2]
Q = gram_schmidt(V)
print("Orthonormal basis Q:\n", Q)
# e1 ≈ [0.9487, 0.3162], e2 ≈ [-0.3162, 0.9487]
# Verify orthonormality: Q^T Q should be I
print("Q^T Q:\n", Q.T @ Q) # Should be identity
# Coordinates of p=[4,3] via dot products (FREE — no inversion!)
p = np.array([4., 3.])
coords = Q.T @ p # c = Q^T p = [dot(p,e1), dot(p,e2)]
print("Coordinates:", coords) # ≈ [4.743, 1.581]
# Reconstruct p from coordinates (lossless)
p_hat = Q @ coords # p = Q c = c1*e1 + c2*e2
print("Reconstructed p:", p_hat) # Should be [4., 3.]
# Parseval: ||p||^2 == sum(c_i^2)
print("||p||^2:", np.dot(p,p), " sum(c^2):", np.sum(coords**2)) # Both 25.0
# --- Production: numpy's built-in QR ---
Q_np, R_np = np.linalg.qr(V, mode='reduced')
print("\nnumpy QR gives Q:\n", Q_np) # Same (up to sign conventions)
print("R (upper triangular):\n", R_np) # R[i,j] = <v_j, e_i> scalars
# Orthogonal projection onto span of Q
P_proj = Q @ Q.T # P = Q Q^T (n x n projector)
print("Projection of p onto span(Q):", P_proj @ p) # Should recover p (Q spans R^2)
