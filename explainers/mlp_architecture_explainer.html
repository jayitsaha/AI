Multi-Layer Perceptron Architecture

Input, hidden, and output layers — the blueprint of deep learning.

Foundational Deep Learning Neural Networks Part IV · Deep Learning Foundations
1
Understanding the Concept

An MLP (Multi-Layer Perceptron) is a stack of layers, where each layer applies a linear transformation (a weighted sum) followed by a nonlinear function. Input flows forward through the layers — input → hidden → output — producing a prediction.

Key Concept

Each layer \(\ell\) computes: $$\mathbf{a}^{(\ell)} = \sigma\!\left(\mathbf{W}^{(\ell)}\mathbf{a}^{(\ell-1)} + \mathbf{b}^{(\ell)}\right)$$ where \(\mathbf{W}^{(\ell)}\) are the weight matrix, \(\mathbf{b}^{(\ell)}\) the bias vector, and \(\sigma\) a nonlinear activation function.

Everyday analogy: Imagine a production line. Raw materials (input) enter station 1. Workers at each station transform them — cutting, shaping, polishing. The final station packages the product (output). Each station applies a specific, learned transformation. Stacking stations lets the line produce arbitrarily complex products from raw inputs.

💡 If You Remember One Thing

Without the nonlinearity \(\sigma\), stacking layers collapses to a single linear transformation — no depth benefit. Nonlinearity is what makes "deep" actually deep.

2
How It Works — Layer by Layer

An MLP has three types of layers:

  • Input layer — Passes raw features \(\mathbf{x} = \mathbf{a}^{(0)}\) unchanged. No parameters here.
  • Hidden layers — Each applies an affine map \(\mathbf{z}^{(\ell)} = \mathbf{W}^{(\ell)}\mathbf{a}^{(\ell-1)} + \mathbf{b}^{(\ell)}\), then an elementwise activation \(\mathbf{a}^{(\ell)} = \sigma(\mathbf{z}^{(\ell)})\).
  • Output layer — Same affine map, but activation \(\sigma\) is chosen for the task: softmax for classification, identity (linear) for regression, sigmoid for binary classification.
Forward Pass (Full Network, \(L\) layers)

$$\mathbf{a}^{(0)} = \mathbf{x}$$

$$\mathbf{a}^{(\ell)} = \sigma\!\left(\mathbf{W}^{(\ell)}\mathbf{a}^{(\ell-1)} + \mathbf{b}^{(\ell)}\right), \quad \ell = 1, \ldots, L-1$$

$$\hat{\mathbf{y}} = \sigma_{\text{out}}\!\left(\mathbf{W}^{(L)}\mathbf{a}^{(L-1)} + \mathbf{b}^{(L)}\right)$$

Why stacking works: Layer 1 learns edges; layer 2 combines edges into shapes; layer 3 combines shapes into objects. Each layer composes features from the previous, enabling hierarchical representations that a single linear model cannot capture.

⚠️ Design Decision

Choosing activation \(\sigma\): ReLU \(\max(0,z)\) is dominant for hidden layers (sparse, fast gradient). Tanh and sigmoid are used in specific architectures (LSTMs, gating). The output activation is always task-specific.

3
The Math — Numerical Trace

Consider a tiny MLP: 2 inputs → 3 hidden neurons (ReLU) → 1 output (sigmoid). Input: \(\mathbf{x} = [1.0,\; 2.0]^\top\).

Layer 1 — Affine Transform

$$\mathbf{W}^{(1)} = \begin{bmatrix}0.5 & -0.3\\0.2 & 0.8\\-0.1 & 0.4\end{bmatrix},\quad \mathbf{b}^{(1)} = \begin{bmatrix}0.1\\-0.2\\0.3\end{bmatrix}$$

$$\mathbf{z}^{(1)} = \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)} = \begin{bmatrix}0.5(1)+(-0.3)(2)+0.1\\0.2(1)+0.8(2)-0.2\\-0.1(1)+0.4(2)+0.3\end{bmatrix} = \begin{bmatrix}0.0\\1.8\\1.0\end{bmatrix}$$

$$\mathbf{a}^{(1)} = \text{ReLU}(\mathbf{z}^{(1)}) = \begin{bmatrix}\max(0,0.0)\\\max(0,1.8)\\\max(0,1.0)\end{bmatrix} = \begin{bmatrix}0.0\\1.8\\1.0\end{bmatrix}$$

Output Layer — Affine + Sigmoid

$$\mathbf{w}^{(2)} = [0.7,\; -0.4,\; 0.9],\quad b^{(2)} = 0.1$$

$$z^{(2)} = 0.7(0.0) + (-0.4)(1.8) + 0.9(1.0) + 0.1 = 0 - 0.72 + 0.9 + 0.1 = 0.28$$

$$\hat{y} = \sigma(0.28) = \frac{1}{1+e^{-0.28}} \approx \frac{1}{1+0.756} \approx 0.570$$

The network outputs \(\hat{y} \approx 0.570\) — interpreted as a 57% probability for the positive class. All steps are exact floating-point arithmetic; no approximations.

Key Takeaways & When to Use
  • The Universal Approximation Theorem guarantees that a single hidden layer with enough neurons can approximate any continuous function — but depth is more parameter-efficient than width.
  • Hidden layers learn intermediate representations — the deeper, the more abstract the feature hierarchy.
  • Without a nonlinearity \(\sigma\), composing \(L\) linear layers is equivalent to one linear layer: \(\mathbf{W}^{(L)}\cdots\mathbf{W}^{(1)}\mathbf{x} = \mathbf{W}_{\text{eff}}\mathbf{x}\).
  • Training is done via backpropagation: compute gradients of the loss w.r.t. all weights using the chain rule, then update with gradient descent.
