Advanced Classical ML Ensemble Methods K·M·fit + meta fit
1
Understanding Stacking
▼

What is it? Stacking trains a set of diverse machine learning models (called base learners or level-0 models), then trains a second-level model (the meta-learner) whose inputs are the predictions from those base learners. Instead of averaging their outputs equally, the meta-learner learns the optimal way to combine them — trusting some more than others depending on the situation.

Analogy: Imagine a hospital with three specialist doctors: a cardiologist, an oncologist, and a neurologist. Each examines a patient and gives a diagnosis. A senior physician (the meta-learner) listens to all three opinions and makes the final call — knowing, for instance, that the cardiologist tends to over-diagnose certain conditions, while the neurologist is very reliable for a specific set of symptoms. The senior physician doesn't just vote — they learn a personalized weighting from historical cases.

💡 If you remember one thing

To prevent data leakage, the meta-learner is trained on out-of-fold (OOF) predictions — predictions that each base learner makes on data it never saw during its own training. This is the entire trick that makes stacking legitimate. Without OOF, the meta-learner just learns to mimic whichever base learner overfits most.

One-sentence summary

Stacking trains diverse base models using cross-validation, collects their held-out predictions as meta-features, then trains a meta-learner to combine those predictions optimally.

2
How Stacking Works — OOF Protocol
▼

The Two-Level Architecture

Let \(\mathcal{D} = \{(x_i, y_i)\}_{i=1}^n\) be the training set, and let \(h_1, \ldots, h_M\) be \(M\) base learners. Stacking builds a meta-feature matrix \(Z \in \mathbb{R}^{n \times M}\) where column \(j\) holds out-of-fold predictions from \(h_j\), then fits a meta-learner \(g\) on \((Z, y)\).

Why Naïve Stacking Leaks

If you train each base learner on the full training set and use those predictions as meta-features, each base learner has already memorised the labels — its predictions are near-perfect on the training set. The meta-learner then just picks the base learner with least training error, which is always the most overfit one. This is a severe information leak.

⚠️ Data Leakage Without OOF

Training base learners on all of \(\mathcal{D}\) and feeding their train-set predictions to the meta-learner gives it access to leaked label information. The meta-learner will learn to exploit overfitting rather than generalisation. Always use held-out (OOF) predictions.

The K-Fold OOF Protocol

Partition the training set into \(K\) folds \(F_1, \ldots, F_K\). For each fold \(k\) and each base learner \(h_j\):

  1. Train \(h_j\) on \(\mathcal{D} \setminus F_k\) (all folds except \(k\)).
  2. Predict on \(F_k\) to fill rows of column \(j\) in \(Z\) corresponding to fold \(k\).

After \(K\) rounds, every row \(i\) of \(Z\) is filled with predictions made by base learners that were never trained on sample \(i\). This is the OOF guarantee. Finally:

$$Z_{ij} = \hat{h}_j^{(-k(i))}(x_i) \quad \text{(prediction on } x_i \text{ by } h_j \text{ trained without fold } k(i))$$

The meta-learner is trained: \(\hat{g} = \operatorname{fit}(Z, y)\). At test time, base learners are re-fit on the full training set, and their predictions form the test meta-features.

🔑 Key Property

Each \(Z_{ij}\) is a statistically valid held-out prediction — it was produced by a model that never saw \(x_i\). The meta-learner therefore trains on an unbiased estimate of each base learner's generalisation performance, not its memorisation ability.

Design Decisions

Why diverse base learners? Stacking works best when base learner errors are uncorrelated. A linear model captures smooth global trends; a tree captures local non-linearity; a KNN captures density patterns. Their errors tend to cancel when combined.

Why a simple meta-learner? The meta-learner itself can overfit, especially with many base learners. Logistic regression (for classification) or ridge regression (for regression) are standard choices — they are regularised and interpretable, giving learnable weights to each base learner.

The Mathematics of Stacking
▼

Formal Setup

Let \(\mathcal{H} = \{h_1, \ldots, h_M\}\) be \(M\) base hypothesis classes, and \(\mathcal{G}\) be the meta-learner class. The stacking prediction for a new point \(x\) is:

$$\hat{y} = g\!\left(h_1(x),\, h_2(x),\, \ldots,\, h_M(x)\right)$$

where \(g\) is trained on OOF meta-features.

Bias-Variance Decomposition

For a single model with mean squared error decomposition: \(\text{MSE} = \text{Bias}^2 + \text{Variance} + \text{Noise}\). Diverse base learners trained separately have different bias and variance profiles. Let base learner \(j\) have bias \(b_j\) and variance \(v_j\). A linear meta-learner with weights \(w_j\) gives:

$$\text{Bias}_{\text{stack}}^2 = \left(\sum_j w_j b_j\right)^2, \quad \text{Var}_{\text{stack}} = \sum_{j,k} w_j w_k \rho_{jk} \sqrt{v_j v_k}$$

where \(\rho_{jk}\) is the correlation between learners \(j\) and \(k\). When errors are uncorrelated (\(\rho_{jk} \approx 0\)), the variance term is \(\sum_j w_j^2 v_j\), which can be much smaller than any individual \(v_j\).

OOF Estimator as Cross-Validated Prediction

The OOF prediction vector \(\hat{z}_j \in \mathbb{R}^n\) for base learner \(j\) satisfies, for each sample \(i\):

$$\hat{z}_{ij} = h_j^{(-k(i))}(x_i), \quad h_j^{(-k)} := \underset{h \in \mathcal{H}_j}{\operatorname{argmin}} \sum_{i \notin F_k} \ell(h(x_i), y_i)$$

This is the \(k\)-fold cross-validation prediction — well-known to produce an approximately unbiased estimate of test error. The meta-learner therefore operates on an unbiased signal.

Meta-Learner as Ridge Regression

When \(g\) is linear ridge regression with regularisation \(\lambda\):

$$\hat{w} = \underset{w}{\operatorname{argmin}}\; \|y - Zw\|_2^2 + \lambda\|w\|_2^2 = (Z^\top Z + \lambda I)^{-1} Z^\top y$$

The regularisation prevents the meta-learner from assigning extreme weights and is crucial when base learners are correlated (near-collinear \(Z\)).

📐 Numerical Trace (4 samples, 3 base learners, K=3)

True labels: \(y = [2, 4, 6, 8]^\top\). OOF meta-features (after 3-fold CV): \(Z = \begin{bmatrix} 2.1 & 3.5 & 1.5 \\ 3.9 & 2.8 & 4.8 \\ 6.2 & 8.0 & 5.0 \\ 7.7 & 7.0 & 9.2 \end{bmatrix}\). Ridge fit (\(\lambda=0.01\)) yields weights \(w \approx [0.45,\, 0.20,\, 0.35]^\top\) (LR, DT, KNN). Meta prediction: \(\hat{y} = Zw \approx [2.09,\, 3.91,\, 6.06,\, 8.00]^\top\). MSE: LR=0.029, DT=1.27, KNN=0.56, Meta=0.012.

⚠️ Common Misconception

Stacking does NOT always outperform the best base learner. If one base learner is vastly superior and the others are noisy, the meta-learner still has to deal with the noise injected by bad predictors. Stacking shines when learners are comparably good but complementarily diverse.

From-Scratch Code — OOF Stacking
▼

Complete implementation in NumPy/scikit-learn showing every step of the OOF stacking protocol:

import numpy as np
from sklearn.model_selection import KFold
from sklearn.linear_model import Ridge, LinearRegression
from sklearn.tree import DecisionTreeRegressor
from sklearn.neighbors import KNeighborsRegressor
def stacking_oof(X_train, y_train, base_learners, meta_learner, K=5):
"""OOF stacking: trains base learners K-fold, builds meta-features."""
n, M = len(X_train), len(base_learners)
Z = np.zeros((n, M)) # out-of-fold meta-feature matrix
kf = KFold(n_splits=K, shuffle=True, random_state=42)
for j, learner in enumerate(base_learners): # for each base learner
for fold_idx, (tr, val) in enumerate(kf.split(X_train)):
learner.fit(X_train[tr], y_train[tr]) # train on K-1 folds
Z[val, j] = learner.predict(X_train[val]) # predict on held-out fold
# Z[val, j] is OOF: model never saw X_train[val] during fit
meta_learner.fit(Z, y_train) # train meta-learner on OOF predictions
# Re-fit each base learner on the FULL training set for test-time use
for learner in base_learners:
learner.fit(X_train, y_train)
return Z, meta_learner
def stacking_predict(X_test, base_learners, meta_learner):
"""Predict: base learner preds → meta-features → meta prediction."""
Z_test = np.column_stack([l.predict(X_test) for l in base_learners])
return meta_learner.predict(Z_test)

Key Takeaways & When to Use
▼

Summary

  • Stacking combines diverse base learners via a learned meta-model, not simple averaging.
  • OOF predictions prevent data leakage: each base learner predicts on data it never trained on.
  • Meta-learner should be simple and regularised (ridge, logistic regression) to avoid overfitting.
  • Diversity among base learners is the key driver of stacking's improvement over any single model.

🎯 Decision Guide

Use stacking when: you want maximum predictive performance, have diverse model types available, and inference speed is not critical.

Avoid stacking when: training time is a constraint (K×M fits), you need interpretability, or your base learners are highly correlated (provides little benefit).
