1
Understanding the SVM Dual
▼

What is it? A Support Vector Machine finds the widest possible "street" that separates two classes of data. The dual formulation is an equivalent reformulation of this geometric problem as a mathematical program involving weights \(\alpha_i\) — one per training point — that reveals which points matter (the support vectors) and naturally introduces kernels.

Analogy: Imagine you are stretching a rubber band between two groups of pins on a pegboard to find the widest gap. Most pins are irrelevant — the band only touches a few support pins. The dual approach asks each pin: "How hard are you pressing against the band?" Only the touching pins press at all. Those pressing forces are the dual variables \(\alpha_i\).

💡 If you remember one thing

The SVM dual is $$\max_{\boldsymbol{\alpha}} \sum_i \alpha_i - \tfrac{1}{2}\sum_i\sum_j \alpha_i\alpha_j y_iy_j\,\mathbf{x}_i^\top\mathbf{x}_j \quad \text{s.t.}\;\sum_i\alpha_iy_i=0,\;0\leq\alpha_i\leq C.$$ Support vectors are exactly the points where \(\alpha_i>0\). The weight vector reconstructs as \(\mathbf{w}=\sum_i\alpha_iy_i\mathbf{x}_i\). Only inner products \(\mathbf{x}_i^\top\mathbf{x}_j\) appear — swap in a kernel function to get non-linear SVMs.

Prerequisites

To understand this fully you should know: Lagrangian duality (convex optimization), KKT conditions, the SVM primal problem, and basic linear algebra (inner products, norms).

2
From Primal to Dual — Step by Step
▼

Step 1 — Primal QP

The hard-margin SVM minimizes \(\frac{1}{2}\|\mathbf{w}\|^2\) subject to \(y_i(\mathbf{w}^\top\mathbf{x}_i+b)\geq 1\) for all \(i=1,\ldots,n\). This is a convex quadratic program in \(\mathbf{w}\in\mathbb{R}^d\) and \(b\in\mathbb{R}\) with \(n\) linear inequality constraints.

Step 2 — Lagrangian

Attach multiplier \(\alpha_i\geq 0\) to each constraint:

$$\mathcal{L}(\mathbf{w},b,\boldsymbol{\alpha}) = \frac{1}{2}\|\mathbf{w}\|^2 - \sum_{i=1}^n \alpha_i\bigl[y_i(\mathbf{w}^\top\mathbf{x}_i+b)-1\bigr]$$

Step 3 — Stationarity Conditions (Eliminate Primals)

Set partial derivatives to zero:

$$\nabla_\mathbf{w}\mathcal{L}=0 \implies \mathbf{w} = \sum_{i=1}^n \alpha_i y_i \mathbf{x}_i$$
$$\frac{\partial\mathcal{L}}{\partial b}=0 \implies \sum_{i=1}^n \alpha_i y_i = 0$$

Step 4 — Substitute Back to Get the Dual

Substitute \(\mathbf{w}=\sum\alpha_iy_i\mathbf{x}_i\) into \(\mathcal{L}\) and simplify:

$$\mathcal{L} = \tfrac{1}{2}\Bigl\|\sum_i\alpha_iy_i\mathbf{x}_i\Bigr\|^2 - \sum_i\alpha_i\Bigl[y_i\bigl(\sum_j\alpha_jy_j\mathbf{x}_j\bigr)^\top\mathbf{x}_i + y_ib - 1\Bigr]$$

After expanding the squared norm and cancelling terms (the \(b\) terms vanish due to \(\sum\alpha_iy_i=0\)):

$$W(\boldsymbol{\alpha}) = \sum_{i=1}^n\alpha_i - \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \alpha_i\alpha_j y_iy_j\,\mathbf{x}_i^\top\mathbf{x}_j$$
🔑 Key Property — Convex QP

The dual is a concave quadratic in \(\boldsymbol{\alpha}\) — maximizing a concave function is equivalent to minimizing a convex one. The matrix \(Q_{ij}=y_iy_j\mathbf{x}_i^\top\mathbf{x}_j\) is positive semi-definite (it is the Gram matrix \(\text{diag}(y)K\,\text{diag}(y)\)). So the QP has a unique global maximum.

Soft Margin (C-SVM)

Adding slack variables \(\xi_i\geq 0\) for misclassification cost \(C\sum\xi_i\) changes only the upper bound on \(\alpha_i\): the dual becomes identical except \(0\leq\alpha_i\leq C\). No other change — the same QP machinery applies.

3
KKT Conditions & Complementary Slackness
▼

The KKT (Karush-Kuhn-Tucker) conditions are necessary and sufficient for optimality in convex programs. For the SVM primal-dual pair they say:

$$\alpha_i\bigl[y_i(\mathbf{w}^\top\mathbf{x}_i+b)-1\bigr] = 0 \quad \forall\,i$$

This is complementary slackness: either \(\alpha_i=0\) or the constraint is tight at equality. This gives three cases:

Three Point Categories

  • Non-support vectors: \(\alpha_i=0\) and \(y_i(\mathbf{w}^\top\mathbf{x}_i+b)>1\). Point lies strictly outside the margin — contributes zero to \(\mathbf{w}\).
  • Support vectors (hard margin): \(\alpha_i>0\) and \(y_i(\mathbf{w}^\top\mathbf{x}_i+b)=1\). Point lies exactly on the margin hyperplane — fully defines \(\mathbf{w}\).
  • Soft-margin violators: \(\alpha_i=C\) and \(y_i(\mathbf{w}^\top\mathbf{x}_i+b)<1\). Point inside the margin or misclassified — clipped at the upper bound \(C\).

Recovering b from KKT

For any support vector \(s\) with \(0<\alpha_s<C\) (so \(y_s(\mathbf{w}^\top\mathbf{x}_s+b)=1\)):

$$b = y_s - \mathbf{w}^\top\mathbf{x}_s = y_s - \sum_{i}\alpha_iy_i\,\mathbf{x}_i^\top\mathbf{x}_s$$

In practice, average over all support vectors for numerical stability.

Strong Duality

By Slater's condition (strict feasibility holds — the data are linearly separable) the duality gap is zero:

$$\frac{1}{2}\|\mathbf{w}^*\|^2 = W(\boldsymbol{\alpha}^*) = \sum_i\alpha_i^* - \frac{1}{2}\sum_i\sum_j\alpha_i^*\alpha_j^*y_iy_j\,\mathbf{x}_i^\top\mathbf{x}_j$$

In our 4-point example: \(\frac{1}{2}\|(0.5,0.5)\|^2 = \frac{1}{2}(0.25+0.25) = 0.25\) and \(W^*=0.25+0.25-\frac{1}{2}(0.25) \approx 0.25+0.25-0.125=0.375\).

⚠️ Common Misconception

Support vectors are not necessarily the hardest points to classify. They are the points closest to the decision boundary — specifically those for which the functional margin \(y_i(\mathbf{w}^\top\mathbf{x}_i+b)=1\) is exactly satisfied. Easy points far from the boundary get \(\alpha_i=0\) and play no role whatsoever in defining the classifier.

Why the Dual Exposes Inner Products

Notice the dual objective contains only \(\mathbf{x}_i^\top\mathbf{x}_j\) — the inner product between training points. The prediction for a new point \(\mathbf{x}\) is:

$$f(\mathbf{x}) = \mathbf{w}^\top\mathbf{x}+b = \sum_i\alpha_iy_i\,\mathbf{x}_i^\top\mathbf{x}+b$$

Replace \(\mathbf{x}_i^\top\mathbf{x}_j\) with any kernel \(k(\mathbf{x}_i,\mathbf{x}_j)=\phi(\mathbf{x}_i)^\top\phi(\mathbf{x}_j)\) to operate implicitly in a high-(possibly infinite-)dimensional feature space without ever computing \(\phi(\mathbf{x})\) explicitly. The primal formulation in \(\mathbf{w}\) cannot do this when \(\phi\) is infinite-dimensional.

Soft Margin, Kernels & Why the Dual Matters
▼

Soft-Margin SVM (C-SVM)

Real data is rarely linearly separable. Add slack variables \(\xi_i\geq 0\): the primal becomes minimizing \(\frac{1}{2}\|\mathbf{w}\|^2 + C\sum_i\xi_i\) subject to \(y_i(\mathbf{w}^\top\mathbf{x}_i+b)\geq 1-\xi_i\). The dual is identical except for a box constraint:

$$\max_{\boldsymbol{\alpha}}\sum_i\alpha_i - \frac{1}{2}\sum_i\sum_j\alpha_i\alpha_jy_iy_j\,\mathbf{x}_i^\top\mathbf{x}_j \quad\text{s.t.}\;\sum_i\alpha_iy_i=0,\;0\leq\alpha_i\leq C$$

The hyperparameter \(C\) controls the bias-variance trade-off: large \(C\) → hard margin (risk of overfitting); small \(C\) → tolerates more violations (softer, wider margin).

The Kernel Trick

The dual exposes \(\mathbf{x}_i^\top\mathbf{x}_j\) everywhere. Replace it with a Mercer kernel \(k(\mathbf{x}_i,\mathbf{x}_j)\) that corresponds to an implicit feature map \(\phi\):

  • Linear: \(k(\mathbf{x},\mathbf{z})=\mathbf{x}^\top\mathbf{z}\)
  • Polynomial: \(k(\mathbf{x},\mathbf{z})=(\mathbf{x}^\top\mathbf{z}+c)^d\)
  • RBF/Gaussian: \(k(\mathbf{x},\mathbf{z})=\exp(-\gamma\|\mathbf{x}-\mathbf{z}\|^2)\) — infinite-dimensional \(\phi\)

With RBF, the primal \(\mathbf{w}\) would be infinite-dimensional and uncountable — only the dual makes this tractable.

💡 Decision Rule

Use the dual when: (a) you need a kernel, (b) \(d\gg n\), or (c) you want sparse representations. Use the primal (e.g. LinearSVC in sklearn) when \(n\) is large and a linear kernel suffices — it avoids the \(O(n^2)\) kernel matrix.

Code Trace — SVM Dual from Scratch
▼
import numpy as np
from scipy.optimize import minimize
# Training data: 4 points, 2D, linearly separable
X = np.array([[-2,0],[-1,-1],[1,1],[2,0]], dtype=float)
y = np.array([-1,-1,1,1], dtype=float) # labels ±1
n = len(y)
# Step 1: Build kernel matrix K_ij = x_i^T x_j (linear kernel)
K = X @ X.T
# K[1,2] = [-1,-1]·[1,1] = -2 (cross-class → negative)
# Step 2: Define dual objective to MAXIMIZE
# W(α) = Σαᵢ − ½ ΣΣ αᵢαⱼyᵢyⱼ K_ij
def neg_dual(alpha):
Q = (y[:,None]*y[None,:])*K # Q_ij = yᵢyⱼKᵢⱼ
return 0.5*np.dot(alpha, Q@alpha) - np.sum(alpha)
def jac(alpha): # gradient: Q*alpha - 1
return ((y[:,None]*y[None,:])*K)@alpha - np.ones(n)
# Step 3: Solve QP with constraints
cons = [{'type':'eq','fun': lambda a: np.dot(a,y)}] # Σαᵢyᵢ=0
bounds = [(0,None)]*n # 0 ≤ αᵢ (hard margin)
res = minimize(neg_dual, np.ones(n)*0.1, jac=jac,
method='SLSQP', bounds=bounds, constraints=cons)
alpha = res.x # → [0, 0.25, 0.25, 0]
# Step 4: Recover primal solution from dual
sv = alpha > 1e-6 # support vectors: αᵢ > 0
w = (alpha*y)@X # w = Σ αᵢyᵢxᵢ
b = np.mean(y[sv] - X[sv]@w) # KKT: yᵢ(w·xᵢ+b)=1 for SVs
# Results: w≈[0.5,0.5], b≈0, margin=2/||w||≈2.83
print(f"w = {w}") # [0.5, 0.5]
print(f"b = {b:.4f}") # ≈ 0
print(f"margin = {2/np.linalg.norm(w):.4f}") # ≈ 2.828
