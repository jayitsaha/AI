Understanding Conditional Expectation
▼

What is it? Suppose you know the value of a random variable \(Y\), and you want to guess another random variable \(X\). The conditional expectation \(\mathbb{E}[X \mid Y]\) is the best guess for \(X\) — it minimises the mean squared error among all functions of \(Y\). Crucially, \(\mathbb{E}[X \mid Y]\) is itself a random variable: a function of \(Y\).

Analogy: Imagine forecasting tomorrow's temperature \(X\). You observe today's temperature \(Y = 22°C\). Your best forecast — that minimises average squared error across all possible days — is \(\mathbb{E}[X \mid Y=22]\). This forecast changes each day depending on \(Y\); it's a function of what you observe.

💡 If you remember one thing

\(\mathbb{E}[X \mid Y]\) is the function of \(Y\) that minimises \(\mathbb{E}\bigl[(X - g(Y))^2\bigr]\). It is a random variable, not a number — its randomness comes from \(Y\). For bivariate normal \((X,Y)\) with correlation \(\rho\), this function is linear: \(\mathbb{E}[X \mid Y] = \mu_X + \rho\,\tfrac{\sigma_X}{\sigma_Y}(Y - \mu_Y)\) — exactly the regression line.

Definition (Discrete Case)

If \((X, Y)\) is a discrete pair, the conditional expectation given the event \(\{Y=y\}\) is:

$$\mathbb{E}[X \mid Y = y] = \sum_x x \cdot P(X = x \mid Y = y) = \frac{\sum_x x \cdot P(X=x, Y=y)}{P(Y=y)}$$

Definition (Continuous Case)

For jointly continuous \((X,Y)\) with density \(f_{X,Y}\):

$$\mathbb{E}[X \mid Y = y] = \int_{-\infty}^{\infty} x \cdot f_{X \mid Y}(x \mid y)\, dx, \quad f_{X\mid Y}(x\mid y) = \frac{f_{X,Y}(x,y)}{f_Y(y)}$$

It Is a Function of Y

Define \(\varphi(y) = \mathbb{E}[X \mid Y=y]\). Then \(\mathbb{E}[X \mid Y] = \varphi(Y)\) is a random variable — it equals \(\varphi(Y(\omega))\) for each outcome \(\omega\). This is the conceptual leap: conditioning produces a new random variable, not a scalar.

🔑 Key Property — Best Predictor

For any function \(g\): \(\mathbb{E}\bigl[(X - \mathbb{E}[X\mid Y])^2\bigr] \le \mathbb{E}\bigl[(X - g(Y))^2\bigr]\). The conditional expectation is the minimum mean-square-error (MMSE) estimator of \(X\) given \(Y\).

The Tower Property (Law of Iterated Expectations)
▼

Statement: If \(X\) is any integrable random variable and \(Y\) is any random variable on the same probability space, then:

$$\mathbb{E}\bigl[\mathbb{E}[X \mid Y]\bigr] = \mathbb{E}[X]$$

More generally, if \(\mathcal{G} \subseteq \mathcal{F}\) are two sub-sigma-algebras, the tower property states \(\mathbb{E}[\mathbb{E}[X \mid \mathcal{F}] \mid \mathcal{G}] = \mathbb{E}[X \mid \mathcal{G}]\). "Iterating" conditions and then taking a coarser view gives the coarser expectation.

Concrete Example: Dice

Roll two fair dice \(D_1\) and \(D_2\). Let \(X = D_1 + D_2\) and \(Y = D_1\). For each value \(y \in \{1,\ldots,6\}\):

$$\mathbb{E}[X \mid Y = y] = y + \mathbb{E}[D_2] = y + 3.5$$

The tower property says:

$$\mathbb{E}\bigl[\mathbb{E}[X \mid Y]\bigr] = \mathbb{E}[Y + 3.5] = \mathbb{E}[Y] + 3.5 = 3.5 + 3.5 = 7 = \mathbb{E}[X] \checkmark$$

Proof Sketch (Discrete)

Using the definition of conditional expectation and the law of total probability:

$$\mathbb{E}\bigl[\mathbb{E}[X\mid Y]\bigr] = \sum_y \mathbb{E}[X\mid Y=y]\cdot P(Y=y) = \sum_y \sum_x x\,P(X=x\mid Y=y)\,P(Y=y) = \sum_x x\,P(X=x) = \mathbb{E}[X]$$

Why "Tower"?

The name comes from the pictorial arrangement of nested conditioning. If \(Z\) contains less information than \(Y\) (i.e., \(\sigma(Z) \subseteq \sigma(Y)\)), then the tower property generalises to:

$$\mathbb{E}\bigl[\mathbb{E}[X \mid Y] \mid Z\bigr] = \mathbb{E}[X \mid Z]$$

First condition on the finer information \(Y\), then "average out" the \(Y\)-information you don't have by conditioning on the coarser \(Z\). The outer conditioning "towers over" the inner one.

⚠️ Common Confusion

\(\mathbb{E}[X \mid Y]\) is a random variable; \(\mathbb{E}[X]\) is a number. The tower property says: if you take the expectation of that random variable, you recover the number \(\mathbb{E}[X]\). Don't confuse \(\mathbb{E}[\mathbb{E}[X\mid Y]]\) (which equals \(\mathbb{E}[X]\)) with \(\mathbb{E}[X\mid Y]\) itself.

Orthogonal Projection & Regression
▼

Hilbert Space View

Consider the space \(L^2(\Omega, \mathcal{F}, P)\) of square-integrable random variables with inner product \(\langle X, Z\rangle = \mathbb{E}[XZ]\). Define the closed subspace \(L^2(Y) = \{g(Y) : g\text{ measurable}, \mathbb{E}[g(Y)^2]<\infty\}\) — all functions of \(Y\) with finite second moment.

The orthogonal projection of \(X\) onto \(L^2(Y)\) is the unique element \(\hat{X} \in L^2(Y)\) minimising \(\|X - \hat{X}\|^2 = \mathbb{E}[(X-\hat{X})^2]\). By the projection theorem in Hilbert spaces, this minimiser is exactly \(\mathbb{E}[X \mid Y]\).

$$\mathbb{E}[X \mid Y] = \operatorname{Proj}_{L^2(Y)} X$$

Orthogonality Condition

The projection satisfies the fundamental orthogonality condition: the residual \(X - \mathbb{E}[X\mid Y]\) is orthogonal to every function \(g(Y) \in L^2(Y)\):

$$\mathbb{E}\bigl[(X - \mathbb{E}[X\mid Y])\, g(Y)\bigr] = 0 \quad \forall\, g \in L^2(Y)$$

This is the abstract form of the normal equations in regression. The residual is uncorrelated with any function of the predictor.

Connection to Linear Regression

For bivariate normal \((X,Y)\) with means \((\mu_X, \mu_Y)\), variances \((\sigma_X^2, \sigma_Y^2)\), and correlation \(\rho\):

$$\mathbb{E}[X \mid Y = y] = \mu_X + \rho\,\frac{\sigma_X}{\sigma_Y}(y - \mu_Y)$$

This is exactly the linear regression of \(X\) on \(Y\). The slope \(\beta_1 = \rho\,\sigma_X / \sigma_Y = \operatorname{Cov}(X,Y)/\operatorname{Var}(Y)\) is the OLS coefficient. Thus linear regression computes the conditional expectation (for Gaussian pairs), and more generally, OLS computes the best linear approximation to \(\mathbb{E}[X \mid Y]\).

MMSE Decomposition

The variance of \(X\) decomposes cleanly through the law of total variance:

$$\operatorname{Var}(X) = \mathbb{E}[\operatorname{Var}(X\mid Y)] + \operatorname{Var}(\mathbb{E}[X\mid Y])$$

The first term is the unexplained variance (within-group); the second is the explained variance (between-group). The fraction explained is \(R^2 = \operatorname{Var}(\mathbb{E}[X\mid Y])/\operatorname{Var}(X)\). For bivariate normal, \(R^2 = \rho^2\).

📐 Numerical Example (\(\rho = 0.6\), \(\mu_X = \mu_Y = 0\), \(\sigma_X = \sigma_Y = 1\))

\(\mathbb{E}[X \mid Y=1] = 0.6\), \(\mathbb{E}[X\mid Y=-1] = -0.6\), \(\mathbb{E}[X\mid Y=2] = 1.2\). MSE of naive predictor \(g=0\): \(\operatorname{Var}(X) = 1.0\). MSE of best predictor \(\mathbb{E}[X\mid Y]\): \(1 - \rho^2 = 1 - 0.36 = 0.64\). The conditional expectation reduces prediction error by \(R^2 = 36\%\).

Key Takeaways
▼

Core properties to remember:

  • \(\mathbb{E}[X \mid Y]\) is a random variable — a function of \(Y\), not a number.
  • It is the MMSE estimator: no function of \(Y\) can predict \(X\) with lower expected squared error.
  • Tower property: \(\mathbb{E}[\mathbb{E}[X\mid Y]] = \mathbb{E}[X]\) — averaging out the condition recovers the unconditional mean.
  • Orthogonality: the residual \(X - \mathbb{E}[X\mid Y]\) is uncorrelated with every function of \(Y\).
  • Regression = conditional expectation: for jointly Gaussian \((X,Y)\), \(\mathbb{E}[X\mid Y]\) is the linear regression function.
  • Law of total variance: \(\operatorname{Var}(X) = \mathbb{E}[\operatorname{Var}(X\mid Y)] + \operatorname{Var}(\mathbb{E}[X\mid Y])\).
💡 The Grand Unification

Conditional expectation, linear regression, MMSE estimation, and orthogonal projection in Hilbert space are the same object viewed from different angles. Understanding this unifies a huge chunk of statistics, ML, and probability theory under one roof.

Where it appears in ML & Stats:

  • Every regression model estimates \(\mathbb{E}[Y \mid X=x]\) — the conditional mean.
  • The tower property underlies EM algorithm derivations and belief propagation.
  • Iterated expectations appear in causal inference (do-calculus), martingale theory, and Bayesian updating.
  • The orthogonal projection view motivates Gauss-Markov theorem and GLS.

import numpy as np
from scipy import stats
# ── Bivariate Normal: E[X|Y=y] = rho * y (when mu=0, sigma=1) ──
rho = 0.6
cond_exp = lambda y: rho * y # E[X | Y=y]
# Verify MMSE property numerically
np.random.seed(42)
n = 100_000
Y = np.random.randn(n)
X = rho * Y + np.sqrt(1 - rho**2) * np.random.randn(n)
# MSE of conditional expectation vs naive predictor
mse_cond = np.mean((X - rho * Y)**2) # ≈ 1 - rho^2 = 0.64
mse_naive = np.mean(X**2) # ≈ Var(X) = 1.0
print(f"MSE(E[X|Y]): {mse_cond:.4f}") # → 0.6400
print(f"MSE(0): {mse_naive:.4f}") # → 1.0000
# ── Tower Property: E[E[X|Y]] = E[X] ──
EX_via_tower = np.mean(rho * Y) # E[E[X|Y]] ≈ rho * E[Y] = 0
EX_direct = np.mean(X) # E[X] ≈ 0
print(f"E[E[X|Y]]: {EX_via_tower:.4f} ≈ E[X]: {EX_direct:.4f}")
# ── Law of Total Variance ──
var_X = np.var(X) # ≈ 1.0
explained = np.var(rho * Y) # Var(E[X|Y]) ≈ rho^2 = 0.36
unexplained = np.mean(np.var(X - rho*Y)) # E[Var(X|Y)] ≈ 1 - rho^2 = 0.64
print(f"Var(X) = {var_X:.4f} ≈ {explained:.4f} + {unexplained:.4f}")
print(f"R² = {explained/var_X:.4f} = rho² = {rho**2:.4f}")
# ── Orthogonality of residual ──
residual = X - rho * Y
corr_resid_Y = np.corrcoef(residual, Y)[0,1] # Should ≈ 0
print(f"Corr(residual, Y) = {corr_resid_Y:.4f}") # → ~0.0
