Understanding the Concept

What is this? Every neural network draws a collection of "decision boundaries" in the space of inputs. Representation capacity asks: how complex and varied can those boundaries be? A network with more capacity can separate more intricate patterns — but capacity alone doesn't mean the network will learn to do so correctly on new data.

💡 The one thing to remember
A depth-\(L\) ReLU network with \(n\) neurons per layer can carve at most \(\mathcal{O}\!\left(n^{d}\cdot L\right)\) distinct linear regions in \(d\)-dimensional input space — and this count grows exponentially with depth but only polynomially with width. More depth = exponentially more complex function classes, even with the same parameter count.

Real-world analogy. Think of a piece of modelling clay. A wide but shallow network is like rolling the clay into one thick slab — you can cut one big complicated silhouette, but only one "layer" of complexity. A deep network is like folding the clay repeatedly before cutting — each fold doubles the number of layers you're cutting through simultaneously, so the same cut creates an exponentially more intricate pattern.

Key concept — Expressivity vs. Generalization

Expressivity = the set of functions a network can represent (with optimal weights). Generalization = how well the learned function performs on unseen data. A network can be maximally expressive yet generalize catastrophically (overfitting), or moderately expressive yet generalize well. The Universal Approximation Theorem tells us capacity is sufficient — it says nothing about optimization or sample efficiency.

2
Linear Regions — The Core Mechanism

A ReLU activation \(\sigma(z) = \max(0,z)\) is piecewise-linear with one "kink" at the origin. When you compose many ReLU layers, the network partitions its input space into convex polytopes. Inside each polytope, the entire network is an affine (linear + constant) map. The number of such polytopes is the number of linear regions.

Formal bound (Montufar et al. 2014)

For a ReLU network with \(L\) hidden layers each of width \(n\) and input dimension \(d\leq n\):

$$\text{Linear regions} \;\leq\; \left(\prod_{i=1}^{L-1}\left\lfloor\tfrac{n}{d}\right\rfloor^d\right)\sum_{j=0}^{d}\binom{n}{j}$$

The right-most sum is the number of regions a single layer can create (a hyperplane arrangement bound). The product amplifies this exponentially with depth. A simplified asymptotic:

$$\text{Linear regions} \;=\; \Omega\!\left(\left(\frac{n}{d}\right)^{d(L-1)}\cdot \binom{n}{\leq d}\right)$$

Numerical trace — depth matters enormously

Take input dimension \(d=2\), width \(n=4\) neurons/layer. A single layer can create at most \(\sum_{j=0}^{2}\binom{4}{j} = 1+4+6 = 11\) regions. But with \(L\) hidden layers:

$$L=1:\;11 \quad L=2:\;\leq 11\cdot\left\lfloor\tfrac{4}{2}\right\rfloor^2 = 11\cdot 4 = 44 \quad L=3:\;\leq 176 \quad L=4:\;\leq 704$$

Each additional layer multiplies the count by \(\lfloor n/d\rfloor^d = 4\). Exponential in depth, polynomial in width — even with the same total parameter count.

⚠️ Common misconception

More linear regions ≠ better model. It means the network can make more distinct decisions. Whether gradient descent finds a good assignment of those regions to classes depends on the training procedure, data, and inductive biases of the architecture — not capacity alone.

Why It Works — Universal Approximation & Depth Separation

Universal Approximation Theorem (UAT) — Cybenko 1989, Hornik 1991

$$\text{For any } f \in C([0,1]^d),\;\varepsilon>0,\;\exists\;\text{1-hidden-layer network } \hat{f}:\;\sup_{x\in[0,1]^d}|f(x)-\hat{f}(x)|<\varepsilon$$

A single hidden layer with enough neurons can approximate any continuous function on a compact set. But the required width can be exponential in \(d\). Depth buys efficiency — the same approximation quality with polynomially many neurons instead of exponentially many.

Depth separation (Eldan & Shamir 2016; Telgarsky 2015)

There exist functions that can be represented exactly by a depth-3 network with \(O(n)\) nodes but require \(\Omega(2^n)\) nodes in any depth-2 network. Depth is strictly more powerful, not just more efficient.

∑ Capacity measure — VC dimension

For a network with \(W\) weights and \(L\) layers of ReLU activations, the VC dimension satisfies:

$$\text{VCdim} = O(W L \log W)$$

This means the network can shatter at most \(O(WL\log W)\) points in general position. PAC-learning bounds then give sample complexity \(m = O\!\left(\frac{WL\log W + \log(1/\delta)}{\varepsilon^2}\right)\) to learn to error \(\varepsilon\) with confidence \(1-\delta\).

Expressivity ≠ Generalization — Zhang et al. 2017

Zhang et al. showed that ResNets can memorise the entire CIFAR-10 training set with random labels (0% training error) while achieving near-chance test accuracy. The network had more than enough capacity to fit noise — yet classical VC theory would predict poor generalization. This "double descent" phenomenon (Belkin et al. 2019) shows that highly over-parameterized networks can still generalize when using SGD, due to implicit regularization.

⚠️ The generalization gap

Expressivity (capacity) is a property of the function class. Generalization depends on: (1) the training algorithm (SGD's implicit bias), (2) the data distribution, (3) explicit regularization (weight decay, dropout). High capacity is necessary but not sufficient for good generalization.

Key Takeaways
  • ReLU networks partition input space into linear regions. Each region is a convex polytope where the network is an affine map.
  • Depth compounds exponentially. Adding one layer multiplies the region count by \(\lfloor n/d \rfloor^d\). The same parameter budget in depth beats width for capacity.
  • Universal approximation is a floor, not a ceiling. UAT guarantees representation exists; it says nothing about learnability or sample efficiency.
  • Expressivity ≠ Generalization. Over-parameterized networks can memorise noise (Zhang et al. 2017) but can also generalise remarkably well (double descent, implicit SGD bias).
  • VC dimension scales as \(O(WL\log W)\). This governs classical sample complexity bounds — but modern deep learning routinely violates classical PAC assumptions.
  • When to care: Capacity analysis informs architecture search (do we need more depth or more width?), pruning (how many regions do we really need?), and understanding failure modes of tiny vs huge models.
💡 Interview punchline

"A depth-\(L\) ReLU network with \(n\) nodes per layer and \(d\)-dimensional inputs can form \(\Omega((n/d)^{d(L-1)})\) linear regions. This grows exponentially in depth — which is why deep networks are computationally more efficient than wide ones for complex function classes, even at the same parameter count. But capacity alone guarantees nothing about generalization."
