Understanding AlexNet
▼

What is it? AlexNet is a deep convolutional neural network — 8 learned layers (5 convolutional + 3 fully-connected) — that took a raw 227×227 pixel image and, for the first time at scale, correctly classified it into one of 1000 categories better than any hand-engineered computer vision system before it.

Analogy: Imagine a factory assembly line where each station strips away noise and keeps only what matters: the first stations detect edges and colour blobs, the middle stations combine those into textures and parts (an eye, a wheel, a leaf), and the final stations vote on "what object is this, given everything found so far." AlexNet is that assembly line, and crucially, every station's filters were learned from data rather than hand-designed by a vision expert.

Why it mattered: In the 2012 ImageNet Large Scale Visual Recognition Challenge (ILSVRC), AlexNet achieved a top-5 error of 15.3%, crushing the runner-up's 26.2% — a margin so large it convinced the entire computer vision field, almost overnight, to abandon hand-crafted features (SIFT, HOG) in favor of learned deep representations.

💡 If you remember one thing

AlexNet proved that a deep CNN trained end-to-end with backpropagation on enough labeled data (ImageNet's 1.2M images) and enough compute (2 GPUs, ~6 days) beats decades of hand-engineered computer vision — and it did so using three then-underrated tricks: ReLU activations, dropout regularization, and brute-force GPU parallelism.

How AlexNet Works Internally
▼

The Architecture, Stage by Stage

An input image of \(227\times227\times3\) flows through 5 convolutional layers (some followed by max-pooling and local response normalization), then 3 fully-connected layers, ending in a 1000-way softmax. Each conv/FC layer (except the last) is followed by a ReLU nonlinearity \(f(x)=\max(0,x)\).

Why ReLU, not tanh/sigmoid?

Saturating nonlinearities like \(\tanh\) or the logistic sigmoid have near-zero gradients for large \(|x|\), which slows gradient descent dramatically in deep nets. The AlexNet paper reports a network with ReLUs reaches 25% training error 6× faster than an equivalent network with tanh units, purely because ReLU's gradient is a constant 1 for all \(x>0\) — no saturation, no vanishing gradient in the positive regime.

Why split across 2 GPUs?

A single GTX 580 (2012) had only 3GB of memory — not enough to hold AlexNet's 60M parameters and activations for a large batch. The authors split the network's feature maps across 2 GPUs, with each GPU holding half the kernels. GPUs only communicate at specific layers (e.g., layer 3 sees all of layer 2's maps, but layers 4 and 5 only see maps on the same GPU) — an early example of model parallelism, and it also acted as a mild regularizer by limiting cross-talk.

Local Response Normalization (LRN)

After ReLU in layers 1 and 2, AlexNet normalizes each neuron's activity relative to its neighbors across adjacent feature-map channels — mimicking lateral inhibition in real neurons, encouraging "competition" so that high-activity detectors suppress their neighbors. This gave a modest ~1-2% error reduction (later architectures replaced it with Batch Normalization).

Dropout — regularizing 60M parameters

The two FC layers (4096 units each) contain the vast majority of the network's parameters and would badly overfit 1.2M training images. Dropout randomly zeroes each hidden unit's output with probability 0.5 during training, forcing the network to not rely on any single unit — effectively training an exponential ensemble of thinner networks that share weights.

🔑 Key Property

AlexNet is the first architecture to combine depth (8 learned layers — deep for 2012), ReLU (fast, non-saturating gradients), dropout (co-adaptation prevention), data augmentation (crops, flips, PCA color jitter), and GPU-scale training into one system, at a scale (1.2M images, 60M parameters) nobody had trained end-to-end before.

Design decision: overlapping pooling

AlexNet uses 3×3 max-pooling windows with stride 2 (instead of the traditional non-overlapping 2×2 stride 2). This small overlap reduced top-1/top-5 error by 0.4%/0.3% and made the network slightly harder to overfit — a subtle but deliberate choice validated empirically.

Why It Works — The Math
▼

Convolution Output Size

For an input of spatial size \(W\), a kernel of size \(K\), stride \(S\), and padding \(P\), the output spatial size is:

$$W_{out} = \left\lfloor \frac{W - K + 2P}{S} \right\rfloor + 1$$

This exact formula drives the shrinking feature maps in the visualization below — e.g. Conv1 takes \(W{=}227\), \(K{=}11\), \(S{=}4\), \(P{=}0\): \(\lfloor(227-11)/4\rfloor+1 = 55\), giving a \(55\times55\times96\) output volume.

ReLU and its Gradient

$$f(x) = \max(0, x) \qquad f'(x) = \begin{cases} 1 & x > 0 \\ 0 & x \le 0 \end{cases}$$

Because the gradient is exactly 1 (not "shrinking toward zero") for all active units, error signals propagate through many layers without the multiplicative decay that plagues \(\tanh\)/sigmoid networks — this is what gives AlexNet its dramatic training speedup.

Local Response Normalization

$$b_{x,y}^i = \frac{a_{x,y}^i}{\left(k + \alpha\sum_{j=\max(0,i-n/2)}^{\min(N-1,i+n/2)} (a_{x,y}^j)^2\right)^{\beta}}$$

where \(a^i_{x,y}\) is the ReLU output of kernel \(i\) at position \((x,y)\), and the sum runs over \(n\) adjacent kernel maps (paper uses \(n{=}5\), \(k{=}2\), \(\alpha{=}10^{-4}\), \(\beta{=}0.75\)). This divisive normalization suppresses a neuron's response when its neighbors are also highly active.

Dropout as Weight Scaling

During training, each unit's output is multiplied by a Bernoulli mask \(r \sim \text{Bernoulli}(p)\) with \(p=0.5\):

$$\tilde{y} = r \odot y, \qquad r_i \sim \text{Bernoulli}(0.5)$$

At test time, no units are dropped, but activations are scaled by \(p\) (or equivalently, scaled by \(1/p\) at train time — "inverted dropout") so the expected output magnitude matches between train and test:

$$\mathbb{E}_{r}[\tilde{y}] = p \cdot y$$
⚠️ Common Pitfall

Forgetting to disable dropout / rescale at inference time silently halves the effective activations, producing systematically wrong (underconfident) predictions — this is exactly why frameworks expose a model.eval() / training=False flag.

Key Takeaways
▼

What made AlexNet win:

  • Depth: 5 conv + 3 FC layers — removing any single conv layer measurably hurt accuracy
  • ReLU activations — ~6× faster convergence than saturating nonlinearities
  • Dropout (p=0.5) in the two 4096-unit FC layers — prevented catastrophic overfitting
  • Data augmentation — random 224×224 crops + horizontal flips + PCA color jitter, effectively multiplying the dataset
  • GPU training — 2× NVIDIA GTX 580s, model-parallel split, ~6 days of training on 1.2M images
  • Overlapping max-pooling and local response normalization — small but measurable error reductions

What came after: AlexNet's success directly triggered the deep learning boom in computer vision — ZFNet (2013) visualized what its filters learned, VGGNet (2014) showed depth with tiny 3×3 kernels helps even more, GoogLeNet (2014) introduced Inception modules for efficiency, and ResNet (2015) solved the vanishing-gradient problem for truly deep networks (152+ layers) with residual connections.

💡 Legacy

AlexNet didn't introduce a fundamentally new algorithm — CNNs, ReLU, and dropout-like ideas all predate it. Its contribution was proving that scale + engineering (enough data, enough depth, enough compute, careful regularization) makes deep learning work in practice. Every modern vision (and eventually language) model inherits this lesson.

Code Trace

import torch.nn as nn
class AlexNet(nn.Module):
def __init__(self, num_classes=1000):
super().__init__()
self.features = nn.Sequential(
# Conv1: 227x227x3 -> 55x55x96
nn.Conv2d(3, 96, kernel_size=11, stride=4),
nn.ReLU(inplace=True),
nn.LocalResponseNorm(5, alpha=1e-4, beta=0.75, k=2),
nn.MaxPool2d(kernel_size=3, stride=2), # -> 27x27x96
# Conv2: -> 27x27x256
nn.Conv2d(96, 256, kernel_size=5, padding=2),
nn.ReLU(inplace=True),
nn.LocalResponseNorm(5, alpha=1e-4, beta=0.75, k=2),
nn.MaxPool2d(kernel_size=3, stride=2), # -> 13x13x256
# Conv3-5: -> 13x13x384 -> 13x13x384 -> 13x13x256
nn.Conv2d(256, 384, kernel_size=3, padding=1), nn.ReLU(inplace=True),
nn.Conv2d(384, 384, kernel_size=3, padding=1), nn.ReLU(inplace=True),
nn.Conv2d(384, 256, kernel_size=3, padding=1), nn.ReLU(inplace=True),
nn.MaxPool2d(kernel_size=3, stride=2), # -> 6x6x256
)
self.classifier = nn.Sequential(
nn.Dropout(0.5),
nn.Linear(256 * 6 * 6, 4096), nn.ReLU(inplace=True),
nn.Dropout(0.5),
nn.Linear(4096, 4096), nn.ReLU(inplace=True),
nn.Linear(4096, num_classes), # softmax applied by loss fn
)
def forward(self, x):
x = self.features(x)
x = x.flatten(1)
return self.classifier(x)
