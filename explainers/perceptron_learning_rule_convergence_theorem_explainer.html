1
Understanding the Perceptron Rule
▼

What is it? The perceptron is the simplest possible linear classifier: it draws a straight line (or hyperplane) between two classes of points. It learns that line by trial and error — whenever it misclassifies a point, it nudges its weight vector a little in the direction that would have fixed that mistake, then moves on to the next point.

Analogy: Imagine adjusting a metal rod balanced on a table so that all the "red" marbles end up on one side and all the "blue" marbles on the other. Every time a marble ends up on the wrong side, you tilt the rod slightly toward it. Keep tilting, marble by marble, and — if such a split is possible at all — the rod eventually settles into a position that separates them perfectly, and you can prove in advance roughly how many tilts it will take.

💡 If you remember one thing

The update rule is only ever applied on a mistake: $$w \leftarrow w + \eta\,(y-\hat y)\,x$$ With labels \(y,\hat y \in \{-1,+1\}\), the error term \((y-\hat y)\) is exactly \(0\) when correct and \(\pm 2y\) when wrong — so up to a constant factor this collapses to the classic rule \(w \leftarrow w + \eta\, y\, x\) fired only when \(y(w\cdot x)\le 0\). The remarkable part: if the data is separable, this simple rule is guaranteed to stop making mistakes after a finite, boundable number of updates.

How the Rule Works Internally
▼

The Algorithm

Fold the bias into the weight vector by appending a constant \(1\) to every input: \(x' = [x_1, x_2, 1]\), \(w' = [w_1, w_2, b]\). Start with \(w' = \mathbf{0}\). Then repeatedly scan the training points in order:

  • Compute the activation \(a = w' \cdot x'_i\) and predicted label \(\hat y = \operatorname{sign}(a)\).
  • If \(y_i \cdot a \le 0\) (a mistake — including the boundary case), update: \(w' \leftarrow w' + \eta\, y_i\, x'_i\).
  • If \(y_i \cdot a > 0\) (already correct), leave \(w'\) untouched and move to the next point.

Because \(w'\) only changes on mistakes, the decision boundary — the line where \(w' \cdot x' = 0\) — sits still whenever the point in front of it is already correctly classified, and rotates/shifts only when it fails. Geometrically, adding \(y_i x'_i\) to \(w'\) tilts the normal vector toward the misclassified point's correct side.

Design Decision: Why This Update and Not Gradient Descent on a Smooth Loss?

The perceptron doesn't minimize a smooth loss with calculus — the \(0/1\) mistake indicator isn't differentiable. Instead the update is literally "move the boundary just enough that this one point would now be less wrong." This is equivalent to sub-gradient descent on the hinge-like perceptron loss \(\max(0, -y(w\cdot x))\), taking a step of size \(\eta\) only on the points where the loss is nonzero.

🔑 Key Property

The learning rate \(\eta\) only rescales \(w'\) — it never changes which points are misclassified or how many mistakes are made (the sign of \(w'\cdot x'\) is scale-invariant). So without loss of generality the classic convergence proof sets \(\eta = 1\).

3
Why It Works — The Convergence Theorem
▼

Setup (Novikoff, 1962)

Assume the data is linearly separable with a margin: there exists a unit vector \(u\) (\(\|u\|=1\)) and a margin \(\gamma > 0\) such that

$$y_i\,(u \cdot x_i) \ge \gamma \quad \text{for all } i = 1, \dots, n$$

Let \(R = \max_i \|x_i\|\) be the radius of the smallest ball containing the data. Starting from \(w_0 = \mathbf{0}\) with \(\eta=1\), the perceptron makes at most

$$M \;\le\; \left(\frac{R}{\gamma}\right)^2$$

mistakes (weight updates) — regardless of the order the points are presented in, and independent of the dimensionality of \(x\) or the number of points \(n\).

Proof Sketch: Sandwiching \(\|w_M\|\)

Step 1 — Alignment with \(u\) grows by at least \(\gamma\) per mistake. On the \(k\)-th mistake (on point \(x_i\)), \(w_{k} = w_{k-1} + y_i x_i\), so

$$w_k \cdot u = w_{k-1}\cdot u + y_i (u \cdot x_i) \;\ge\; w_{k-1}\cdot u + \gamma$$

By induction, after \(M\) mistakes: \(w_M \cdot u \ge M\gamma\).

Step 2 — Norm grows by at most \(R^2\) per mistake. Since a mistake means \(y_i(w_{k-1}\cdot x_i)\le 0\):

$$\|w_k\|^2 = \|w_{k-1}\|^2 + 2y_i(w_{k-1}\cdot x_i) + \|x_i\|^2 \;\le\; \|w_{k-1}\|^2 + R^2$$

By induction, after \(M\) mistakes: \(\|w_M\|^2 \le M R^2\), i.e. \(\|w_M\| \le \sqrt{M}\,R\).

Step 3 — Combine via Cauchy–Schwarz. Since \(\|u\|=1\):

$$M\gamma \;\le\; w_M \cdot u \;\le\; \|w_M\|\,\|u\| \;=\; \|w_M\| \;\le\; \sqrt{M}\,R$$

Dividing through by \(\sqrt{M}\gamma\) gives \(\sqrt{M} \le R/\gamma\), hence \(M \le (R/\gamma)^2\). Because \(M\) can only grow while mistakes keep happening, the algorithm must halt within this many updates — it cannot loop forever on separable data.

⚠️ Common Pitfall

The bound needs linear separability. If no separating hyperplane exists, no finite \(\gamma>0\) satisfies the margin condition, Step 1's induction never "outraces" Step 2, and the vanilla perceptron can cycle forever, never converging. Fixes: the Pocket algorithm (keep the best-so-far weights) or switch to a max-margin method (SVM) that optimizes \(\gamma\) directly instead of merely using whichever separator the mistake sequence happens to produce.

Key Takeaways
▼

When the guarantee applies:

  • Data is linearly separable — some hyperplane classifies every point correctly.
  • The bound \((R/\gamma)^2\) depends only on the geometry (radius \(R\), margin \(\gamma\)), never on the number of features or examples \(n\).
  • A larger margin (well-separated classes) converges much faster than a razor-thin margin — this is the same intuition SVMs exploit by maximizing \(\gamma\) directly.

When it breaks down:

  • Non-separable / noisy data → no finite mistake bound, may cycle forever (use Pocket algorithm, averaged/voted perceptron, or soft-margin SVM).
  • The perceptron finds some separator, not necessarily the max-margin one — it stops as soon as mistakes hit zero, unlike SVM which keeps optimizing.
💡 Big Picture

The perceptron is the ancestor of the modern neuron: a linear score plus a threshold, trained by a local, online, mistake-driven update. Its convergence theorem is one of the first (1962!) learning-theoretic guarantees in ML — a direct conceptual precursor to margin-based bounds in SVMs and generalization theory.

Code Trace — Perceptron From Scratch
▼
import numpy as np
# X: (n, d) inputs, y: (n,) labels in {-1, +1}
def perceptron_fit(X, y, max_epochs=100, eta=1.0):
n, d = X.shape
Xa = np.hstack([X, np.ones((n, 1))]) # append bias column
w = np.zeros(d + 1) # w0 = 0
updates = 0
for epoch in range(max_epochs):
mistakes = 0
for i in range(n):
activation = w @ Xa[i]
if y[i] * activation <= 0: # mistake (incl. boundary)
w += eta * y[i] * Xa[i] # w <- w + eta*(y-yhat)*x
updates += 1
mistakes += 1
if mistakes == 0:
break # converged: fully separated
return w, updates
# Novikoff bound: verify M <= (R/gamma)^2
R = np.max(np.linalg.norm(Xa, axis=1))
# gamma = max-margin found by searching unit directions u
gamma = max_margin_search(Xa, y) # see grid search in this page's JS
bound = (R / gamma) ** 2
assert updates <= bound # theorem guarantees this holds
