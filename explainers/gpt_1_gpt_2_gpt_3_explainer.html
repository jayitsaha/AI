Understanding GPT-1/2/3
▼

What is it? All three GPT models do exactly one thing: given some text so far, predict a probability distribution over what word (technically "token") comes next. That's it. There is no separate "reasoning module" or "translation module" — every capability (writing, summarizing, translating, coding) emerges from getting extremely good at this single next-token prediction game, at massive scale.

Analogy: Think of the world's most well-read autocomplete. GPT-1 read roughly 7,000 books and could finish your sentence reasonably. GPT-2 read a curated slice of the internet (40GB) and got good enough to write a whole paragraph that stays on-topic. GPT-3 read a huge fraction of the public web (~300B tokens) with a model 1,500× larger than GPT-1 — and something new appeared: show it 2-3 examples of a task in the prompt itself and it does the task, no retraining required.

💡 If you remember one thing

Same architecture, same objective — only scale changed — across all three models: $$P(x) = \prod_{i=1}^{N} P(x_i \mid x_1,\dots,x_{i-1})$$ GPT-1 → GPT-2 → GPT-3 is a controlled experiment in what happens when you multiply parameters, data, and compute by roughly 10× each generation.

2
How the GPT Family Works Internally
▼

The Shared Architecture: A Decoder-Only Transformer

All three models stack identical Transformer decoder blocks: masked multi-head self-attention → feed-forward network → residual connections + LayerNorm, repeated \(n_{layer}\) times. Tokens are embedded, added to learned positional embeddings, passed through the stack, then projected back onto the vocabulary (often with the input embedding matrix tied to the output projection). The critical detail is the causal mask: position \(i\) can only attend to positions \(\le i\), so the model can never "cheat" by looking at the future token it is trying to predict.

GPT-1 (2018) — Pretrain, Then Fine-tune

117M parameters, 12 layers, \(d_{model}=768\), trained on BooksCorpus (~7,000 unpublished books, ~800M words). GPT-1's recipe was two-stage: unsupervised language-model pretraining, then a separate supervised fine-tuning pass with a task-specific head (classification, entailment, etc.) bolted onto the final hidden state. Each downstream task still needed labeled data and a gradient-update step.

GPT-2 (2019) — Scale Removes the Fine-tuning Step

1.5B parameters, 48 layers, \(d_{model}=1600\), trained on WebText (40GB of high-karma Reddit-linked pages, ~10B tokens). GPT-2's headline result: with no task-specific fine-tuning at all, simply prompting the model ("TL;DR:" for summarization, "Translate to French:" for translation) produced usable zero-shot performance. The paper's thesis — "Language Models are Unsupervised Multitask Learners" — is that a big enough LM implicitly learns many tasks as a side effect of modeling all the text on the internet, which contains demonstrations of those tasks.

GPT-3 (2020) — In-Context Learning Without Any Gradient Step

175B parameters, 96 layers, \(d_{model}=12{,}288\), trained on a filtered/weighted mixture dominated by Common Crawl (~300B tokens total). GPT-3 went further: place a handful of input→output example pairs directly in the prompt (few-shot), and the frozen model conditions its next-token distribution on those examples to solve novel tasks — arithmetic, translation, unscrambling words — with zero weight updates. This is "in-context learning" (ICL): learning realized purely through the forward pass and attention over the prompt, not through backpropagation.

🔑 Design decision: why decoder-only, not encoder-decoder?

BERT-style encoders see the whole sequence bidirectionally, which is ideal for understanding but cannot naturally generate text left-to-right. The original Transformer's encoder-decoder split is built for a fixed source→target task (translation). GPT chose the causal decoder-only design because it is the minimal architecture whose training objective (next-token prediction) is also directly its inference-time capability (open-ended generation) — the same weights that were pretrained are used unmodified at generation time.

3
Why It Works — The Math
▼

The Training Objective

All three models minimize the same negative log-likelihood over a training corpus of token sequences \(\mathcal{U}=\{u_1,\dots,u_T\}\):

$$\mathcal{L}(\mathcal{U}) = -\sum_{i=1}^{T} \log P(u_i \mid u_{i-k},\dots,u_{i-1};\Theta)$$

where \(k\) is the context window (512 tokens for GPT-1, 1024 for GPT-2, 2048 for GPT-3) and \(\Theta\) are the Transformer's weights. This is exactly cross-entropy loss between the model's predicted distribution and the one-hot true next token, averaged over every position in every sequence.

Attention: How Context Is Aggregated

Inside every block, scaled dot-product self-attention lets each position gather information from earlier positions, weighted by learned relevance:

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}} + M\right)V$$

\(M\) is the causal mask (\(-\infty\) above the diagonal, \(0\) on/below it), which forces the softmax weight on any future position to zero. \(\sqrt{d_k}\) rescales the dot products so softmax doesn't saturate into a near-one-hot distribution as \(d_k\) grows — without it, gradients through attention vanish at large head dimensions.

The Scaling Law

Kaplan et al. (2020) showed the pretraining loss follows a smooth power law in the number of non-embedding parameters \(N\) (holding data/compute non-bottlenecked):

$$L(N) \approx \left(\frac{N_c}{N}\right)^{\alpha_N}, \qquad N_c \approx 8.8\times10^{13},\ \ \alpha_N \approx 0.076$$

This single formula (used live in the visualization below) is why "just make it bigger" was a rational strategy: loss decreases predictably, with no sign of saturation, across many orders of magnitude of \(N\). In-context learning is best understood as an emergent capability that appears because the pretraining loss keeps falling smoothly — at low enough loss the model must implicitly represent higher-order structure (e.g. "this looks like a translation task") to predict tokens that well.

⚠️ Common Misconception

In-context learning is not fine-tuning. No gradients are computed and no weight \(\Theta\) changes when you add few-shot examples to a GPT-3 prompt — the examples only change the input tokens that attention conditions on. This is why the "learning" disappears the moment you start a new conversation: nothing was actually stored in the weights.

Key Takeaways
▼

The hierarchy:

  • GPT-1 proved pretrain-then-finetune beats task-specific architectures from scratch.
  • GPT-2 proved scale alone buys zero-shot transfer — no fine-tuning needed for many tasks.
  • GPT-3 proved further scale buys few-shot in-context learning — no gradient step needed at all.

When each regime matters:

  • Small, fixed task with lots of labeled data → fine-tuning (GPT-1 style) is still often more accurate and far cheaper to run.
  • Many different tasks, little/no labeled data, need fast iteration → in-context learning (GPT-3 style) via prompting.
  • Scaling laws let you predict the loss of a bigger run before paying for it — the basis of modern compute-optimal training (Chinchilla built directly on this Kaplan-era analysis).
💡 The throughline

Nothing about the objective changed from GPT-1 to GPT-3 — only \(N\) (parameters), \(D\) (data), and \(C\) (compute). Every headline capability difference between the three models is a byproduct of the same next-token cross-entropy loss getting lower and lower.

Code Trace — Minimal Autoregressive Decoder
▼
import numpy as np
# Toy vocab (real GPT uses ~50K BPE subword tokens)
VOCAB = ["The","quick","brown","fox","jumps","over","the","lazy","dog","."]
stoi = {w:i for i,w in enumerate(VOCAB)}
def causal_mask(T):
# position i may only attend to j <= i
mask = np.triu(np.ones((T,T)), k=1) * -1e9
return mask
def self_attention(Q, K, V, mask):
d_k = Q.shape[-1]
scores = (Q @ K.T) / np.sqrt(d_k) + mask
weights = softmax(scores, axis=-1)
return weights @ V, weights
def softmax(z, axis=-1, temperature=1.0):
z = z / temperature
z = z - np.max(z, axis=axis, keepdims=True) # numerical stability
e = np.exp(z)
return e / np.sum(e, axis=axis, keepdims=True)
# --- next-token generation loop (greedy) ---
ids = [stoi["The"], stoi["quick"], stoi["brown"]]
for step in range(4):
logits = gpt_forward(ids) # [T, vocab] -- final linear layer
probs = softmax(logits[-1]) # distribution for NEXT token only
next_id = int(np.argmax(probs)) # greedy; GPT-3 API defaults to sampling
ids.append(next_id)
# --- params(N) grows 12*n_layer*d_model^2, loss(N) shrinks (Nc/N)^0.076 ---
def num_params(n_layer, d_model):
return 12 * n_layer * d_model**2 # attn(4d^2) + mlp(8d^2) per layer
def scaling_law_loss(N, Nc=8.8e13, alpha=0.076):
return (Nc / N) ** alpha # Kaplan et al. 2020
# --- in-context learning: NO gradient step, only new prompt tokens ---
prompt = "sea otter => loutre de mer\npeppermint => menthe poivree\ncheese =>"
out = gpt_forward(tokenize(prompt)) # weights Theta are frozen/unchanged
print(detokenize(argmax(softmax(out[-1])))) # -> "fromage"
