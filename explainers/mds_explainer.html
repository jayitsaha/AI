Multidimensional Scaling (MDS)

Reconstructing geometry from pairwise distances — classical eigendecomposition vs. non-metric stress minimization

Intermediate Unsupervised Learning Dimensionality Reduction O(n³) classical
1 Understanding MDS ›

Imagine you have a table of flight times between 10 cities — but no map. Multidimensional Scaling (MDS) reconstructs a map from those pairwise distances alone. It finds coordinates for every point in a low-dimensional space such that the distances between reconstructed points match the original dissimilarities as closely as possible.

💡 The Core Idea

MDS inverts the distance problem: given distances, recover positions. If you can compute distances from coordinates, MDS does the reverse — it reconstructs coordinates from distances.

There are two major variants:

  • Classical (metric) MDS — assumes distances are true Euclidean distances. Uses double-centering of the squared distance matrix followed by eigendecomposition. Produces an exact embedding when the data is truly Euclidean, and is algebraically equivalent to PCA in that case.
  • Non-metric MDS — only requires that the rank order of distances is preserved, not their exact values. Minimizes a stress function iteratively. Works with ordinal dissimilarities (e.g., "city A feels much farther than B to travelers").
📌 Key Property

MDS recovers configurations up to rotation, reflection, and translation. These transformations preserve all pairwise distances, so they cannot be determined from the distance matrix alone.

Real-world applications: perceptual mapping in psychology (how similar do colors look?), phylogenetic trees in biology, brand positioning in marketing, document similarity in NLP, visualization of high-dimensional embedding spaces.

2 How It Works — Classical vs. Non-Metric ›

Classical MDS — Step by Step

Given an \(n \times n\) distance matrix \(D\) where \(d_{ij}\) is the distance between points \(i\) and \(j\):

  1. Square: Form \(D^{(2)}\) with entries \(d_{ij}^2\).
  2. Double-center: Compute the inner-product matrix \(B = -\tfrac{1}{2} J D^{(2)} J\), where \(J = I_n - \tfrac{1}{n}\mathbf{1}\mathbf{1}^\top\) is the centering matrix. This converts squared distances into dot products: \(B_{ij} = \langle x_i, x_j \rangle\).
  3. Eigendecompose: \(B = V \Lambda V^\top\). Take the top \(k\) eigenpairs \((\lambda_1, v_1), \ldots, (\lambda_k, v_k)\).
  4. Embed: \(X = V_{1:k} \Lambda_{1:k}^{1/2}\). The rows of \(X\) are the low-dimensional coordinates.
∑ Why Double-Centering Works

If \(x_i \in \mathbb{R}^p\) are centered (\(\sum_i x_i = 0\)), then \(d_{ij}^2 = \|x_i - x_j\|^2 = \|x_i\|^2 + \|x_j\|^2 - 2x_i^\top x_j\). Double-centering removes the \(\|x_i\|^2\) and \(\|x_j\|^2\) terms, leaving \(B_{ij} = x_i^\top x_j\). So \(B\) is exactly the Gram matrix \(X X^\top\), whose eigendecomposition gives back \(X\).

Non-Metric MDS — Stress Minimization

Non-metric MDS (Kruskal 1964) relaxes the requirement: instead of matching distances exactly, it only requires that distances be monotonically related to the dissimilarities. It optimizes:

$$\text{Stress} = \sqrt{\frac{\sum_{i < j}(d_{ij} - \hat{d}_{ij})^2}{\sum_{i < j} d_{ij}^2}}$$

where \(\hat{d}_{ij}\) are disparities — a monotone transformation of the original dissimilarities fitted via isotonic regression. The optimization alternates between:

  • Isotonic regression step: given current \(d_{ij}\), find the best monotone \(\hat{d}_{ij}\) (pool adjacent violators algorithm).
  • Guttman transform step: given \(\hat{d}_{ij}\), update point coordinates to reduce stress (majorization / gradient descent).
⚠️ Common Confusion

Classical MDS on Euclidean distances is identical to PCA on the centered data matrix. But non-metric MDS is not PCA — it makes no linearity assumptions and minimizes a different objective via iterative optimization. Stress < 0.05 = excellent; 0.05–0.10 = good; 0.10–0.20 = fair; > 0.20 = poor fit.

3 The Mathematics ›

Classical MDS Full Derivation

Let \(X \in \mathbb{R}^{n \times p}\) be centered: \(\sum_i x_i = 0\). Define the squared Euclidean distance matrix \(D^{(2)}\) with \(D^{(2)}_{ij} = \|x_i - x_j\|^2\).

Expand: \(\|x_i - x_j\|^2 = x_i^\top x_i - 2x_i^\top x_j + x_j^\top x_j\). So \(D^{(2)}_{ij} = G_{ii} + G_{jj} - 2G_{ij}\) where \(G = XX^\top\) is the Gram matrix.

Applying the centering operator \(J = I - \tfrac{1}{n}\mathbf{1}\mathbf{1}^\top\) on both sides:

$$B = -\tfrac{1}{2} J D^{(2)} J = J G J = G$$

The last equality holds because \(X\) is already centered (\(JX = X\)), so \(JGJ = JXX^\top J = XX^\top = G\). Thus \(B = G\) exactly.

Eigendecompose \(B = V \Lambda V^\top\) (symmetric positive semidefinite). The reconstruction:

$$\hat{X} = V_{1:k} \Lambda_{1:k}^{1/2}$$

satisfies \(\hat{X}\hat{X}^\top = V_{1:k}\Lambda_{1:k}V_{1:k}^\top = B\) (truncated). The reconstruction is exact when \(k = \text{rank}(B)\).

Kruskal Stress Formula

$$S_1 = \sqrt{\frac{\sum_{i < j}\bigl(d_{ij}(\hat{X}) - \hat{d}_{ij}\bigr)^2}{\sum_{i < j} d_{ij}(\hat{X})^2}}$$

∑ Connection to Spectral Methods

Classical MDS, Kernel PCA (with the distance kernel), and the graph Laplacian eigenmap are all special cases of spectral embedding. The key insight: any positive-semidefinite kernel \(K\) induces inner products, and its eigendecomposition gives a low-dimensional embedding.

Conditions for Exact Recovery

  • Classical MDS recovers exact Euclidean geometry if and only if \(B\) is positive semidefinite (equivalently, all eigenvalues ≥ 0). This holds iff \(D\) is Euclidean.
  • For non-Euclidean dissimilarities (e.g., road distances with detours), some eigenvalues of \(B\) are negative. Classical MDS ignores them; the embedding introduces distortion.
  • Non-metric MDS handles non-Euclidean dissimilarities gracefully — it only needs rank order, not metric structure.

6 Key Takeaways & Code ›

From Scratch — Classical MDS (NumPy)

import numpy as np

def classical_mds(D, k=2):
    """Classical (metric) MDS from a distance matrix D.

    Args:
        D: (n, n) symmetric distance matrix, zeros on diagonal
        k: target dimensionality (default 2)
    Returns:
        X: (n, k) coordinates in k-D space
    """
    n = D.shape[0]

    # Step 1: Square the distance matrix
    D2 = D ** 2

    # Step 2: Double-centering  B = -½ J D² J
    # J = I - (1/n) 1 1ᵀ  (centering matrix)
    J = np.eye(n) - np.ones((n, n)) / n
    B = -0.5 * J @ D2 @ J  # shape (n, n), symmetric PSD

    # Step 3: Eigendecomposition (largest eigenvalues first)
    eigenvalues, eigenvectors = np.linalg.eigh(B)
    # eigh returns in ascending order — reverse
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues, eigenvectors = eigenvalues[idx], eigenvectors[:, idx]

    # Step 4: Take top-k, clip negative eigenvalues (non-Euclidean case)
    lam_k = np.maximum(eigenvalues[:k], 0)
    V_k   = eigenvectors[:, :k]

    # Step 5: Reconstruct coordinates X = V Λ^½
    X = V_k * np.sqrt(lam_k)  # (n, k)
    return X


def kruskal_stress(D_orig, X):
    """Kruskal's Stress-1 between original distances and embedding distances."""
    n = len(X)
    dists = np.array([[np.linalg.norm(X[i]-X[j]) for j in range(n)] for i in range(n)])
    mask = np.triu(np.ones((n,n), dtype=bool), k=1)
    d_ij  = dists[mask]
    d_hat = D_orig[mask]
    return np.sqrt(np.sum((d_ij - d_hat)**2) / np.sum(d_ij**2))

# Example: city distances (km)
D = np.array([
    [   0, 180, 320, 260, 140,  80],
    [ 180,   0, 180, 290, 250, 240],
    [ 320, 180,   0, 160, 290, 400],
    [ 260, 290, 160,   0, 150, 310],
    [ 140, 250, 290, 150,   0, 170],
    [  80, 240, 400, 310, 170,   0],
], dtype=float)

X = classical_mds(D, k=2)
print("2D coordinates:\n", X.round(1))
print("Stress:", kruskal_stress(D, X).round(4))

Key Takeaways

  • Classical MDS = PCA on Euclidean distance data. They produce the same result.
  • Non-metric MDS is more robust to non-Euclidean dissimilarities (road distances, survey ratings).
  • Both are \(O(n^3)\) — use Landmark MDS or UMAP for \(n > 5{,}000\).
  • Multiple random restarts are essential for non-metric MDS to avoid local minima.
  • Stress < 0.05 = excellent; 0.05–0.10 = good; > 0.20 = poor — consider more dimensions.
