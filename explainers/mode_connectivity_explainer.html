Understanding the Concept
▼

Imagine you train a deep neural network twice on the same dataset, starting from different random seeds. You end up with two sets of weights — call them Mode A and Mode B — both achieving nearly the same low test error. In the loss landscape, they represent two distinct valleys.

The naive question: can you blend the two solutions? If you linearly interpolate the weights — "take 50% of Model A plus 50% of Model B" — you get a model that is typically much worse than either endpoint. The interpolated model climbs out of both valleys and sits on a high-loss ridge.

Mode connectivity is the discovery (Garipov et al., 2018; Draxler et al., 2018) that despite this linear barrier, the two minima are always connected by a curved, low-loss path through weight space. You can travel from Mode A to Mode B without ever leaving low-loss terrain — but you must take the scenic route.

Key Insight

All well-trained minima of modern deep networks are mode-connected: there exists a piecewise-linear or Bezier path \(\gamma:[0,1]\to\mathbb{R}^d\) such that \(\mathcal{L}(\gamma(t)) \approx \mathcal{L}(\theta^*)\) for all \(t\). The linear chord between them is not such a path.

Why does this matter? It reveals that the loss landscape of deep networks is not a collection of isolated bowls separated by impassable mountains. Instead, it is a highly connected manifold of near-optimal solutions. This has direct implications for model merging, ensembling, fine-tuning, and our theoretical understanding of overparameterized optimization.

Real-world analogy: Two hikers reach separate mountain peaks via separate routes, and you want to walk from one peak to the other without climbing above a certain altitude. The direct ridgeline between the peaks may be too high (the linear path crosses a barrier), but by circling through a mountain pass — going slightly off the direct route — you can traverse between the peaks while staying low.

How It Works: Paths, Barriers, and Git Re-Basin
▼

Three phenomena to understand

1. Linear interpolation barrier. For two independently trained networks \(\theta_A, \theta_B \in \mathbb{R}^d\), the linear path \(\theta(t) = (1-t)\theta_A + t\theta_B\) usually exhibits a loss barrier: a region where loss is substantially higher than at either endpoint. The barrier height can be several percentage points of test error in practice.

2. Curved low-loss paths (Garipov et al., 2018). One can optimise a parametric curve between the two endpoints directly. A quadratic Bezier curve:

$$\gamma(t) = (1-t)^2 \theta_A + 2t(1-t)\theta_m + t^2\theta_B, \quad t\in[0,1]$$

where \(\theta_m\) is a free control-point (not necessarily the midpoint on the curve), optimised by minimising \(\mathbb{E}_{t\sim U[0,1]}[\mathcal{L}(\gamma(t))]\). The resulting curve dips through a low-loss corridor and stays near the loss at both endpoints. In our toy example, optimal \(\theta_m=(0,-1)\) makes the curve pass through the saddle \((0,0)\) at \(t=\tfrac{1}{2}\), cutting the barrier from 0.75 to 0.25.

3. Permutation symmetry and linear mode connectivity. Neural networks have a massive discrete symmetry: permuting the neurons in any hidden layer (and correspondingly permuting the weights of the adjacent layers) yields an identical function but a different point in weight space. Two independently trained networks compute the same function up to permutation, but their weight vectors may be far apart. The key insight of Git Re-Basin (Ainsworth et al., 2022) is:

Linear Mode Connectivity (after alignment)

After finding a permutation \(\pi^*\) that aligns \(\theta_B\) to \(\theta_A\), the linear interpolation \(\theta(t) = (1-t)\theta_A + t\pi^*(\theta_B)\) is nearly loss-flat: the barrier disappears or becomes negligible. The networks are linearly mode-connected in the aligned coordinate frame.

Git Re-Basin finds \(\pi^*\) by solving an assignment problem (linear sum assignment / matching) per layer, aligning activation statistics or weight matrices. This can be done in closed form for linear networks and approximately for nonlinear ones using alternating layer matching.

Why does the barrier exist?

The barrier is a direct consequence of permutation symmetry: if \(\theta_B\) is a permuted version of \(\theta_A\), linear interpolation produces a network that is trying to implement two different permutations simultaneously at each intermediate \(t\), leading to destructive interference and high loss.

Common Misconception

Mode connectivity does NOT mean the loss landscape is flat or easy to optimise. It means that, post-training, the set of optima has surprising geometric structure. The landscape during training is still highly non-convex and full of saddle points.

The Mathematics
▼

Loss landscape geometry

Let \(\mathcal{L}: \mathbb{R}^d \to \mathbb{R}\) be the training loss. A mode (or minimum) is a point \(\theta^* \in \mathbb{R}^d\) with \(\nabla \mathcal{L}(\theta^*) = 0\) and \(\nabla^2 \mathcal{L}(\theta^*) \succeq 0\). Two modes \(\theta_A, \theta_B\) are mode-connected if there exists a continuous path \(\gamma:[0,1]\to\mathbb{R}^d\) with \(\gamma(0)=\theta_A\), \(\gamma(1)=\theta_B\), and:

$$\max_{t\in[0,1]} \mathcal{L}(\gamma(t)) \leq \max\{\mathcal{L}(\theta_A), \mathcal{L}(\theta_B)\} + \epsilon$$

for small \(\epsilon \geq 0\). When \(\epsilon = 0\) exactly, the modes are called loss-monotone connected.

Bezier curve optimisation

The Fast Geometric Ensembling (FGE) / loss-surface curve-finding objective minimises the expected loss along the curve:

$$\hat{\theta}_m = \underset{\theta_m}{\operatorname{argmin}} \; \mathbb{E}_{t \sim \text{Uniform}[0,1]}\left[\mathcal{L}\!\left(\gamma_{\theta_m}(t)\right)\right]$$

In practice, this is approximated by sampling \(t \sim U[0,1]\) at each gradient step and computing \(\nabla_{\theta_m} \mathcal{L}(\gamma(t))\) via the chain rule through the Bezier parameterisation.

Permutation symmetry group

For a network with layers of widths \(n_1, \ldots, n_L\), the symmetry group is the permutation group \(\mathcal{S} = S_{n_1} \times S_{n_2} \times \cdots \times S_{n_{L-1}}\), where \(|S_{n_\ell}| = n_\ell!\). Applying \(\pi = (\pi_1,\ldots,\pi_{L-1}) \in \mathcal{S}\) to weights \(\theta\) gives a permuted network \(\pi(\theta)\) with:

$$W_\ell^{\pi} = P_{\pi_\ell} W_\ell P_{\pi_{\ell-1}}^\top, \quad b_\ell^{\pi} = P_{\pi_\ell} b_\ell$$

where \(P_\pi\) is the permutation matrix for \(\pi\), and satisfies \(f_{\pi(\theta)}(x) = f_\theta(x)\) for all inputs \(x\).

Weight matching (Git Re-Basin)

The alignment step finds \(\pi^*\) minimising the distance between aligned weight matrices:

$$\pi^* = \underset{\pi \in \mathcal{S}}{\operatorname{argmin}} \; \|\theta_A - \pi(\theta_B)\|_2^2$$

This decomposes into a layer-wise linear assignment problem: for each layer \(\ell\), find the permutation \(\pi_\ell\) that best aligns columns of \(W_\ell^B\) to columns of \(W_\ell^A\), solvable in \(O(n_\ell^3)\) via the Hungarian algorithm.

Toy Numerical Trace (Verified)

Loss surface: \(\mathcal{L}(w_1,w_2) = \tfrac{1}{2}(w_2 - w_1^2)^2 + \tfrac{1}{4}(w_1^2-1)^2\). Minima at \(\theta_A = (-1,1)\) and \(\theta_B = (1,1)\), both with \(\mathcal{L}=0\).

Linear path midpoint \((0,1)\): \(\mathcal{L}(0,1) = \tfrac{1}{2}(1-0)^2 + \tfrac{1}{4}(0-1)^2 = 0.500 + 0.250 = \mathbf{0.750}\).

Bezier curve with control point \(\theta_m=(0,-1)\): at \(t=\tfrac{1}{2}\), the curve passes through \((0,0)\) because \(w_1(\tfrac{1}{2})=\tfrac{1}{4}(-1)+0+\tfrac{1}{4}(1)=0\) and \(w_2(\tfrac{1}{2})=\tfrac{1}{4}(1)+\tfrac{1}{2}(-1)+\tfrac{1}{4}(1)=0\).

Bezier midpoint \((0,0)\): \(\mathcal{L}(0,0) = \tfrac{1}{2}(0-0)^2 + \tfrac{1}{4}(0-1)^2 = 0 + 0.250 = \mathbf{0.250}\).

The curved path reduces the maximum barrier from 0.750 to 0.250 — a 3× reduction.

From scratch: quadratic Bezier curve optimisation

import torch
import numpy as np

def bezier_point(theta_a, theta_b, theta_m, t):
    """Quadratic Bezier: (1-t)^2 * A + 2t(1-t) * M + t^2 * B"""
    return (1-t)**2 * theta_a + 2*t*(1-t) * theta_m + t**2 * theta_b

def find_bezier_path(model_a, model_b, train_loader, n_epochs=20, lr=1e-3):
    """
    Find the midpoint theta_m of a low-loss Bezier curve connecting two models.
    Returns the optimised midpoint (the curve is defined by A, M, B).
    """
    theta_a = flatten(model_a)          # flat weight vector
    theta_b = flatten(model_b)
    theta_m = theta_a.clone().requires_grad_(True)  # learnable midpoint

    optimizer = torch.optim.Adam([theta_m], lr=lr)

    for epoch in range(n_epochs):
        for X, y in train_loader:
            t = torch.rand(1).item()    # sample t ~ Uniform[0,1]
            theta_t = bezier_point(theta_a, theta_b, theta_m, t)

            model_t = unflatten(theta_t, model_a)  # reconstruct model
            loss = criterion(model_t(X), y)

            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

    return theta_m.detach()

Weight matching (Git Re-Basin, per-layer greedy)

from scipy.optimize import linear_sum_assignment

def weight_matching(theta_a, theta_b, layers):
    """
    For each layer, find the permutation of theta_b's neurons that
    best aligns with theta_a. Returns the permuted theta_b.
    Uses Hungarian algorithm (linear sum assignment).
    """
    permuted_b = {k: v.clone() for k, v in theta_b.items()}

    for layer_name in layers:
        W_a = theta_a[layer_name]  # shape: [out, in]
        W_b = permuted_b[layer_name]

        # Cost matrix: how well does neuron j of B align with neuron i of A?
        # Use negative inner product as cost
        cost = -W_a @ W_b.T  # [n_out_a, n_out_b]

        # Solve linear sum assignment (Hungarian algorithm)
        row_ind, col_ind = linear_sum_assignment(cost.numpy())

        # Apply permutation: reorder neurons of B to match A
        perm = col_ind  # permutation to apply to B's output neurons
        permuted_b[layer_name] = W_b[perm, :]

        # Also permute the input dimension of the NEXT layer
        # (so the overall function is unchanged)
        next_layer = next_layer_name(layer_name, layers)
        if next_layer:
            permuted_b[next_layer] = permuted_b[next_layer][:, perm]

    return permuted_b

# After alignment, linear interpolation is nearly loss-flat:
# theta_t = (1-t)*theta_a + t*permuted_b  (no barrier!)
Production Gotcha

The layer-wise greedy matching in weight_matching is approximate — it does not guarantee global optimality because permuting layer \(\ell\) changes the cost landscape for layer \(\ell+1\). Ainsworth et al. (2022) propose alternating rounds of matching across all layers until convergence.

Key Takeaways & Related Topics
▼

Summary

  • Linear interpolation crosses barriers: independently trained minima are not linearly mode-connected without alignment.
  • Curved paths work: quadratic Bezier / polygonal chains optimised to minimise expected loss along the path can connect minima while staying near loss = 0.
  • Permutation symmetry is the cause: the barrier is an artifact of neuron-order misalignment, not of genuine landscape complexity.
  • Git Re-Basin resolves it: after Hungarian-algorithm weight matching, the linear path becomes nearly flat, enabling gradient-free model merging.
  • Applications: model merging (combine multiple fine-tunes), loss-valley ensembling (FGE/SWA), transfer learning, and federated learning aggregation.
