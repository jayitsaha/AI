Derivatives: Product, Quotient & Chain Rules

The three workhorse rules for differentiating composite and combined functions — the engine powering neural network backpropagation.
Foundational Lean Intermediate Math & Stats Foundations Single-Variable Calculus Section 2.2
1
Understanding the Concept
▾

A derivative answers one question: how fast is this function changing right now? For simple functions like \(x^2\) or \(\sin x\) you can differentiate directly. But real-world functions are almost always combinations — two functions multiplied together, divided, or nested inside each other. Three rules handle every such case:

Product Rule

When two functions are multiplied: \(h(x)=f(x)\cdot g(x)\). Think of an expanding rectangle — both width and height change simultaneously.

Quotient Rule

When one function is divided by another: \(h(x)=\frac{f(x)}{g(x)}\). Derived directly from the product rule with a reciprocal trick.

Chain Rule

When a function is composed inside another: \(h(x)=f(g(x))\). Rate of change multiplies through each layer — exactly how gradients flow in backprop.

Key Insight

The product rule is the area increment of a rectangle. The chain rule is rate multiplication. These geometric and physical intuitions explain why the formulas look the way they do — and make them impossible to forget.

2
How Each Rule Works — Derivations
▾

Product Rule — The Rectangle Argument

Let \(h(x) = f(x) \cdot g(x)\). Imagine a rectangle with width \(f\) and height \(g\), so area \(= h = fg\). When \(x\) increases by a tiny \(\Delta x\):

  • Width grows by \(\Delta f\), adding a strip of area \(g\,\Delta f\)
  • Height grows by \(\Delta g\), adding a strip of area \(f\,\Delta g\)
  • Corner square \(\Delta f\,\Delta g\) is second-order tiny — vanishes as \(\Delta x \to 0\)

So \(\Delta h \approx g\,\Delta f + f\,\Delta g\). Dividing by \(\Delta x\) and taking the limit:

$$\frac{d}{dx}[f(x)\,g(x)] = f'(x)\,g(x) + f(x)\,g'(x)$$

Mnemonic: "derivative of first times second, plus first times derivative of second."

Quotient Rule — From the Product Rule

Let \(h = f/g\). Rewrite as \(f = h \cdot g\) and differentiate both sides using the product rule:

$$f' = h'\,g + h\,g'$$

Solve for \(h' = \frac{f' - h\,g'}{g} = \frac{f' - \frac{f}{g}\,g'}{g}\). Multiply numerator and denominator by \(g\):

$$\frac{d}{dx}\!\left[\frac{f(x)}{g(x)}\right] = \frac{f'(x)\,g(x) - f(x)\,g'(x)}{[g(x)]^2}$$

Mnemonic: "low d-high minus high d-low, over low squared." Valid only where \(g(x)\neq 0\).

Chain Rule — Rate Multiplication

Let \(h(x) = f(g(x))\). Define \(u = g(x)\) so \(h = f(u)\). As \(x\) changes, \(u\) changes at rate \(g'(x)\). For each unit change in \(u\), \(f\) changes at rate \(f'(u)\). Rates multiply:

$$\frac{dh}{dx} = \frac{df}{du}\cdot\frac{du}{dx} = f'(g(x))\cdot g'(x)$$

The Leibniz form \(\frac{dh}{dx}=\frac{df}{du}\frac{du}{dx}\) makes it look like fractions cancel — a helpful but informal picture. The rigorous proof uses the limit definition and handles the case \(g'(x)=0\) carefully.

Common Mistake

Forgetting to multiply by the inner derivative \(g'(x)\) in the chain rule is the single most common calculus error. E.g., \(\frac{d}{dx}\sin(x^2) = \cos(x^2)\cdot 2x\), NOT just \(\cos(x^2)\).

The Math Behind It — Worked Example & Backprop Connection
▾

Worked Example — Using All Three Rules

Differentiate \(h(x) = \frac{x^2 \cdot \sin(x^2+1)}{e^x}\) at \(x=1\). We apply all three rules.

Step 1 — Quotient Rule outer shell. Let numerator \(N = x^2\sin(x^2+1)\), denominator \(D = e^x\):

$$h'(x) = \frac{N'(x)\cdot e^x - N(x)\cdot e^x}{e^{2x}} = \frac{N'(x) - N(x)}{e^x}$$

Step 2 — Product Rule on \(N = x^2 \cdot \sin(x^2+1)\).

$$N'(x) = 2x\cdot\sin(x^2+1) + x^2\cdot\frac{d}{dx}[\sin(x^2+1)]$$

Step 3 — Chain Rule on \(\sin(x^2+1)\). Outer: \(\sin(\cdot)\), inner: \(x^2+1\):

$$\frac{d}{dx}[\sin(x^2+1)] = \cos(x^2+1)\cdot 2x$$

Step 4 — Assemble.

$$N'(x) = 2x\sin(x^2+1) + 2x^3\cos(x^2+1)$$

Numerical evaluation at \(x=1\): \(x^2+1=2\), \(\sin 2\approx 0.9093\), \(\cos 2\approx -0.4161\), \(e^1\approx 2.7183\).

$$N(1) = 1\cdot\sin(2)\approx 0.9093,\quad N'(1) = 2(0.9093)+2(-0.4161)\approx 0.9864$$
$$h'(1) = \frac{0.9864 - 0.9093}{2.7183} \approx \frac{0.0771}{2.7183}\approx 0.0284$$

Connection to Backpropagation

In a neural network, the loss \(L\) is a composition of many functions: \(L = \ell(a_n(a_{n-1}(\cdots a_1(x)\cdots)))\). To train the network we need \(\frac{\partial L}{\partial w_i}\) for every weight \(w_i\). The chain rule gives the exact recipe:

$$\frac{\partial L}{\partial w_i} = \frac{\partial L}{\partial a_n}\cdot\frac{\partial a_n}{\partial a_{n-1}}\cdots\frac{\partial a_i}{\partial w_i}$$

Backpropagation is nothing more than the chain rule applied efficiently in reverse — starting from the output layer and accumulating products of local Jacobians backward through the network. The product rule appears whenever a layer combines multiple inputs (e.g., attention: query × key). The quotient rule is embedded in softmax's gradient derivation.

Key Invariant

Every gradient in deep learning is a product of partial derivatives chained together by the chain rule. Understanding the chain rule is understanding backpropagation.

Code — From Scratch & Automatic Differentiation
▾

Symbolic differentiation — hand-coded rules in Python

import numpy as np
# Product Rule: (fg)' = f'g + fg'
def product_rule(f, g, df, dg, x):
return df(x) * g(x) + f(x) * dg(x)
# Quotient Rule: (f/g)' = (f'g - fg') / g^2
def quotient_rule(f, g, df, dg, x):
return (df(x) * g(x) - f(x) * dg(x)) / g(x)**2
# Chain Rule: f(g(x))' = f'(g(x)) * g'(x)
def chain_rule(f_prime, g, dg, x):
return f_prime(g(x)) * dg(x)
# --- Worked example: h(x) = x^2 * sin(x^2+1) / exp(x) at x=1 ---
x = 1.0
f = lambda x: x**2 # x^2, f'=2x
df = lambda x: 2*x
s = lambda x: np.sin(x**2+1) # sin(x^2+1), chain: cos(x^2+1)*2x
ds = lambda x: np.cos(x**2+1)*2*x
N = lambda x: f(x)*s(x) # numerator
dN = lambda x: product_rule(f, s, df, ds, x)
D = lambda x: np.exp(x) # denominator
dD = lambda x: np.exp(x)
dh = quotient_rule(N, D, dN, dD, x)
print(f"h'(1) = {dh:.6f}") # → 0.028380
# Verify with numerical finite difference
h = lambda x: N(x)/D(x)
eps = 1e-7
fd = (h(x+eps) - h(x-eps)) / (2*eps)
print(f"Finite diff: {fd:.6f}") # → 0.028380 ✓

Automatic Differentiation (PyTorch) — chain rule at scale

import torch
x = torch.tensor(1.0, requires_grad=True)
h = (x**2 * torch.sin(x**2 + 1)) / torch.exp(x)
h.backward() # chain rule all the way back
print(x.grad) # tensor(0.0284) ✓
# In a neural network layer:
# Each .backward() call applies the chain rule through
# every composed operation that built the computation graph.
Insight

PyTorch's autograd does NOT differentiate symbolically. It records each operation in a computation graph and applies the chain rule numerically during .backward(). Every node stores its local derivative; gradients accumulate via the chain rule from output to input.

Key Takeaways & Connections
▾

Product Rule — area increment argument; applies when two differentiable functions are multiplied. Appears in attention mechanism derivatives (Q·K softmax interaction).

Quotient Rule — derived from product rule; use for rational functions, softmax, normalisation layers. Always verify denominator is non-zero.

Chain Rule — the rule of deep learning. Every gradient in backpropagation is a chain-rule product of local derivatives. The deeper the network, the more terms multiply — this is why vanishing gradients appear (many numbers <1 multiplied together).

Rule Summary

\(\displaystyle (fg)' = f'g + fg'\)  ·  \(\displaystyle \left(\tfrac{f}{g}\right)' = \tfrac{f'g-fg'}{g^2}\)  ·  \(\displaystyle (f\circ g)' = f'(g)\cdot g'\)
