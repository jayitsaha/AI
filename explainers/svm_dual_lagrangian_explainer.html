SVM Dual Formulation via Lagrangian

How the hard-margin SVM primal becomes a kernel-friendly quadratic program through constrained optimisation duality

Advanced Classical ML · SVM Quadratic Programming
1
Understanding the Concept
▾

A Support Vector Machine finds the widest possible street (margin) between two classes of data points. The street width equals \(\frac{2}{\|w\|}\), so maximising margin is the same as minimising \(\|w\|^2\).

The primal problem minimises over the weight vector \(w \in \mathbb{R}^d\) and bias \(b\):

$$\min_{w,b}\;\tfrac{1}{2}\|w\|^2 \quad \text{subject to} \quad y_i(w^\top x_i + b) \geq 1 \;\; \forall i$$

This has \(d+1\) variables (grow with input dimension) and \(n\) inequality constraints. The dual reformulates the same optimum using only \(n\) variables — one per training point — and replaces explicit dot products \(w^\top x\) with inner products \(x_i^\top x_j\), enabling the kernel trick.

Key Insight
At the optimum, only a handful of training points (the support vectors) have non-zero dual variables \(\alpha_i > 0\). Everything else contributes nothing. The dual discovers these automatically.
2
Lagrangian Construction
▾

To handle the inequality constraints we introduce a non-negative multiplier \(\alpha_i \geq 0\) for each constraint and form the Lagrangian:

$$\mathcal{L}(w,b,\alpha) = \frac{1}{2}\|w\|^2 - \sum_{i=1}^n \alpha_i\bigl[y_i(w^\top x_i + b) - 1\bigr]$$

The idea: the Lagrangian equals the primal objective when all constraints are satisfied and equals \(-\infty\) when any constraint is violated (because a violated constraint lets \(\max_\alpha \mathcal{L} \to +\infty\)). So:

$$\min_{w,b}\max_{\alpha \geq 0}\mathcal{L}(w,b,\alpha) \;=\; \text{primal problem}$$

Under Slater's condition (feasibility of a strictly interior point), which the SVM satisfies whenever the data are linearly separable, strong duality holds: we can swap min and max.

$$\min_{w,b}\max_{\alpha \geq 0}\mathcal{L} \;=\; \max_{\alpha \geq 0}\min_{w,b}\mathcal{L}$$
Strong Duality (KKT)
At any saddle point: (1) primal feasibility, (2) dual feasibility \(\alpha_i \geq 0\), (3) complementary slackness \(\alpha_i[y_i(w^\top x_i+b)-1]=0\) for all \(i\).
3
Eliminating w and b — the Dual
▾

For the inner minimisation over \(w, b\) we set partial derivatives of \(\mathcal{L}\) to zero.

Step 1 — Stationarity w.r.t. \(w\)

$$\frac{\partial \mathcal{L}}{\partial w} = w - \sum_{i=1}^n \alpha_i y_i x_i = 0 \quad\Longrightarrow\quad \boxed{w^* = \sum_{i=1}^n \alpha_i y_i x_i}$$

The optimal \(w\) is a linear combination of training inputs, weighted by \(\alpha_i y_i\).

Step 2 — Stationarity w.r.t. \(b\)

$$\frac{\partial \mathcal{L}}{\partial b} = -\sum_{i=1}^n \alpha_i y_i = 0 \quad\Longrightarrow\quad \boxed{\sum_{i=1}^n \alpha_i y_i = 0}$$

This is the balance constraint: positive-class weight equals negative-class weight in the expansion.

Step 3 — Substitute back into \(\mathcal{L}\)

Plug \(w^* = \sum_i \alpha_i y_i x_i\) and use \(\sum_i \alpha_i y_i = 0\):

$$\mathcal{L} = \frac{1}{2}\Bigl\|\sum_i \alpha_i y_i x_i\Bigr\|^2 - \sum_i\alpha_i y_i\underbrace{\Bigl(\sum_j \alpha_j y_j x_j\Bigr)^\top x_i}_{\text{inner product}} + \sum_i \alpha_i - b\underbrace{\sum_i \alpha_i y_i}_{=0}$$

The first two terms combine:

$$\frac{1}{2}\sum_i\sum_j \alpha_i\alpha_j y_i y_j x_i^\top x_j - \sum_i\sum_j \alpha_i\alpha_j y_i y_j x_i^\top x_j + \sum_i \alpha_i = -\frac{1}{2}\sum_i\sum_j \alpha_i\alpha_j y_i y_j x_i^\top x_j + \sum_i\alpha_i$$

So the dual objective (to be maximised over \(\alpha \geq 0\)) is:

$$\boxed{W(\alpha) = \sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \alpha_i\alpha_j y_i y_j\, x_i^\top x_j}$$
The Dual Problem (Hard-Margin SVM)
$$\max_{\alpha}\; W(\alpha) = \sum_i \alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j\, x_i^\top x_j$$ $$\text{subject to}\quad \alpha_i \geq 0\;\forall i,\quad \sum_i \alpha_i y_i = 0$$
Why This Enables the Kernel Trick
Both the dual objective and the prediction rule \(\hat{y}(x) = \text{sgn}\!\bigl(\sum_i \alpha_i y_i x_i^\top x + b\bigr)\) depend on the data only through inner products \(x_i^\top x_j\). Replace these with \(k(x_i, x_j)\) for any positive-semi-definite kernel — instant nonlinear SVM.

Numerical Trace & Key Takeaways
▾

Concrete 2-D Example

Two positive points: \(x_1 = (1,1)^\top, x_2 = (2,2)^\top\); two negative: \(x_3 = (-1,-1)^\top, x_4 = (-2,-2)^\top\). Labels \(y_1=y_2=+1,\; y_3=y_4=-1\).

By symmetry the solution has \(\alpha_1 = \alpha_3 = \alpha\) (the nearest pair are the support vectors) and \(\alpha_2 = \alpha_4 = 0\). The balance constraint: \(\alpha\cdot1 + 0 + \alpha\cdot(-1) + 0 = 0\) ✓.

Dual objective with only \(i,j \in \{1,3\}\):

$$W(\alpha) = 2\alpha - \frac{1}{2}\bigl[\alpha^2(1)(1)(x_1^\top x_1) + 2\alpha^2(1)(-1)(x_1^\top x_3) + \alpha^2(-1)(-1)(x_3^\top x_3)\bigr]$$

With \(x_1^\top x_1 = 2,\; x_1^\top x_3 = -2,\; x_3^\top x_3 = 2\):

$$W(\alpha) = 2\alpha - \frac{1}{2}[2\alpha^2 + 4\alpha^2 + 2\alpha^2] = 2\alpha - 4\alpha^2$$

Setting \(\frac{dW}{d\alpha}=0\): \(2 - 8\alpha = 0 \Rightarrow \alpha^* = \tfrac{1}{4}\).

Recover \(w^* = \tfrac{1}{4}(+1)(1,1)^\top + \tfrac{1}{4}(-1)(-1,-1)^\top = \tfrac{1}{4}(1,1)^\top + \tfrac{1}{4}(1,1)^\top = \tfrac{1}{2}(1,1)^\top\).

Margin \(= \frac{2}{\|w^*\|} = \frac{2}{1/\sqrt{2}} = 2\sqrt{2}\). Bias \(b^*=0\) by symmetry.

Takeaways
  • The dual has \(n\) variables (not \(d\!+\!1\)), so it scales with data count, not dimension — crucial for high-dimensional tasks like text.
  • Sparsity: KKT complementary slackness forces \(\alpha_i = 0\) for non-support-vectors. Only SVs matter at test time.
  • Replacing \(x_i^\top x_j\) with a kernel \(k(x_i, x_j)\) gives a non-linear SVM with no change to the dual solver.
  • Soft-margin SVM adds slack variables; the only change to the dual is the upper bound \(0 \leq \alpha_i \leq C\).
Common Misconception
"The dual is always easier to solve." Not necessarily — the dual QP is \(O(n^2)\) in memory (the Gram matrix \(y_iy_jx_i^\top x_j\)). For very large \(n\), SMO or sub-sampling tricks are needed.
6
From-Scratch Python Code
▾

Solving the dual QP with scipy.optimize.minimize (negative objective, since we maximise):

import numpy as np
from scipy.optimize import minimize
from scipy.optimize import LinearConstraint, Bounds
def svm_dual(X, y):
"""Hard-margin SVM via dual QP."""
n = len(y)
# Gram matrix K[i,j] = y_i * y_j * (x_i . x_j)
K = (y[:, None] * X) @ (y[:, None] * X).T # shape (n,n)
def neg_dual(alpha): # maximise W = minimise -W
return 0.5 * alpha @ K @ alpha - alpha.sum()
def neg_dual_grad(alpha):
return K @ alpha - np.ones(n)
# Constraint: sum(alpha_i * y_i) = 0
cons = {'type': 'eq', 'fun': lambda a: a @ y, 'jac': lambda a: y}
# Box: alpha_i >= 0
bounds = [(0, None)] * n
result = minimize(neg_dual, np.zeros(n), jac=neg_dual_grad,
method='SLSQP', bounds=bounds, constraints=cons)
alpha = result.x
# Support vectors: alpha_i > threshold
sv_mask = alpha > 1e-5
w = (alpha * y) @ X # w = sum alpha_i y_i x_i
b = np.mean(y[sv_mask] - X[sv_mask] @ w) # avg over SVs
return w, b, alpha, sv_mask
# Quick test
X = np.array([[1,1],[2,2],[-1,-1],[-2,-2]], dtype=float)
y = np.array([1, 1, -1, -1], dtype=float)
w, b, alpha, sv = svm_dual(X, y)
# Expected: w ≈ [0.5, 0.5], b ≈ 0, alpha ≈ [0.25, 0, 0.25, 0]
