OLS Derivation — Normal Equations

How setting ∇‖y − Xβ‖² = 0 gives β̂ = (XᵀX)⁻¹Xᵀy, and why it's a geometric projection
Foundational Classical ML Linear Algebra Must Know
1
The One-Line Idea
▼

What is OLS? Ordinary Least Squares finds the coefficient vector \(\hat{\beta}\) that minimises the sum of squared residuals — the squared distances between observed values \(y\) and the model's predictions \(X\hat{\beta}\).

The cost function is simply the squared Euclidean norm of the residual vector:

$$\mathcal{L}(\beta) = \|y - X\beta\|^2 = (y - X\beta)^\top(y - X\beta)$$

Minimising this over \(\beta \in \mathbb{R}^p\) produces the normal equations and the closed-form solution:

$$\hat{\beta} = (X^\top X)^{-1} X^\top y$$
💡 Geometric intuition

\(\hat{y} = X\hat{\beta}\) is the orthogonal projection of \(y\) onto the column space of \(X\). The residual \(e = y - \hat{y}\) is perpendicular to every column of \(X\): \(X^\top e = 0\). This is the deepest reason the formula looks the way it does.

2
Full Derivation — Normal Equations
▼

Step 1: Expand the loss

Expand \(\mathcal{L}(\beta) = (y - X\beta)^\top(y - X\beta)\) using the distributive rule for transposes:

$$\mathcal{L}(\beta) = y^\top y - 2\beta^\top X^\top y + \beta^\top X^\top X \beta$$

The middle term uses \(\beta^\top X^\top y = (X^\top y)^\top \beta = y^\top X\beta\), so both are equal and combine to \(-2\beta^\top X^\top y\).

Step 2: Take the gradient w.r.t. β

Using the matrix calculus identities \(\nabla_\beta (\beta^\top a) = a\) and \(\nabla_\beta (\beta^\top A\beta) = 2A\beta\) (for symmetric \(A\)):

$$\nabla_\beta \mathcal{L}(\beta) = -2 X^\top y + 2 X^\top X \beta$$

Step 3: Set to zero — the Normal Equations

Setting \(\nabla_\beta \mathcal{L} = 0\) and rearranging:

$$X^\top X \,\hat{\beta} = X^\top y \qquad \text{(normal equations)}$$

Step 4: Solve

If \(X\) has full column rank, \(X^\top X\) is symmetric positive-definite and therefore invertible:

$$\hat{\beta} = (X^\top X)^{-1} X^\top y$$
📐 This is a minimum, not a saddle point

The Hessian \(\nabla^2_\beta \mathcal{L} = 2X^\top X\) is positive semi-definite (positive-definite when \(X\) has full column rank), so the critical point is a global minimum. The loss \(\mathcal{L}\) is a convex quadratic.

3
The Geometry: Projection onto col(X)
▼

Think of \(y \in \mathbb{R}^n\) as a point in \(n\)-dimensional space. The column space of \(X\) — written \(\text{col}(X)\) — is a \(p\)-dimensional subplane through the origin. \(X\beta\) can only reach points inside this plane, so we want the point in \(\text{col}(X)\) closest to \(y\).

The closest point is the orthogonal projection \(\hat{y} = X\hat{\beta}\). The projection leaves a residual \(e = y - \hat{y}\) that is perpendicular to the whole plane:

$$X^\top(y - X\hat{\beta}) = 0 \implies X^\top y = X^\top X \hat{\beta}$$

This is precisely the normal equations — they encode the orthogonality condition. Solving them gives the projection matrix:

$$H = X(X^\top X)^{-1}X^\top \quad \Longrightarrow \quad \hat{y} = Hy$$

\(H\) is called the hat matrix. It is symmetric (\(H^\top = H\)) and idempotent (\(H^2 = H\)) — properties of any orthogonal projection.

🔑 Why "normal" equations?

In Latin, normalis means perpendicular. The residual is normal (perpendicular) to the column space of \(X\). That geometric fact is where the name comes from — not from a probability distribution.

Uniqueness

If the columns of \(X\) are linearly independent (full rank), the projection is unique. If not, infinitely many \(\hat{\beta}\) vectors produce the same \(\hat{y}\); we typically pick the minimum-norm solution via the Moore-Penrose pseudoinverse: \(\hat{\beta} = X^+ y\).

When Does the Formula Break Down?
▼
⚠️ Rank-deficiency: X is not full column rank

If columns of \(X\) are linearly dependent (e.g., multicollinearity), \(X^\top X\) is singular and its inverse does not exist. \(\hat{\beta}\) is not unique — there are infinitely many solutions producing the same \(\hat{y}\). Use ridge regression or the pseudoinverse \(X^+ = (X^\top X + \lambda I)^{-1}X^\top\).

⚠️ \(n < p\): more parameters than observations

\(X^\top X\) is at most rank \(n\), so it is singular. OLS is underdetermined. Regularisation (ridge, lasso) is necessary to pick a unique solution.

Numerical practice: never invert explicitly

Computing \((X^\top X)^{-1}\) is numerically unstable. In code, solve the normal equations as a linear system via QR decomposition (NumPy's lstsq) or Cholesky factorisation for better numerical conditioning.

$$X = QR \implies \hat{\beta} = R^{-1}Q^\top y \quad \text{(QR approach, }\mathcal{O}(np^2)\text{)}$$

Gauss-Markov theorem

Under the classical assumptions (linearity, full rank, zero-mean iid errors with constant variance), \(\hat{\beta}_{OLS}\) is the Best Linear Unbiased Estimator (BLUE): no other linear unbiased estimator has smaller variance.

6
Code Trace — From Scratch
▼
import numpy as np
# Data: 5 observations, 1 feature (+ intercept column)
X = np.array([[1, 1.0], [1, 2.0], [1, 3.0], [1, 4.0], [1, 5.0]])
y = np.array([2.1, 3.9, 5.8, 7.6, 10.1])
# Normal equations: (XᵀX)β = Xᵀy
XtX = X.T @ X # 2×2 matrix
Xty = X.T @ y # 2-vector
# Solve via formula (educational only — use lstsq in production)
beta_hat = np.linalg.inv(XtX) @ Xty
print(f"β̂ = {beta_hat}") # [0.14, 1.97]
# Numerically preferred: QR / lstsq
beta_lstsq, _, _, _ = np.linalg.lstsq(X, y, rcond=None)
print(f"β̂ (lstsq) = {beta_lstsq}") # identical
# Fitted values and residuals
y_hat = X @ beta_hat # projection onto col(X)
residuals = y - y_hat # orthogonal to col(X)
print(f"Xᵀe ≈ 0: {X.T @ residuals}") # [~0, ~0]
# Hat matrix H = X(XᵀX)⁻¹Xᵀ
H = X @ np.linalg.inv(XtX) @ X.T # idempotent: H@H == H
print(f"H symmetric: {np.allclose(H, H.T)}") # True
print(f"H idempotent: {np.allclose(H@H, H)}") # True
