Swin Transformer V2

Scaling up Vision Transformers with Post-Norm, Cosine Attention, and Log-Spaced Continuous Position Bias
Deep Learning Computer Vision Large-Scale ViT
1
Understanding Swin V2
▼

What is it? Swin Transformer V2 is an upgraded architecture designed to scale up Vision Transformers (ViTs) to giant capacities (billions of parameters) and ultra-high resolution inputs (e.g., $1536 \times 1536$ pixels). While the original Swin-V1 introduced local windowing and shifted windows to achieve linear computational complexity, it hit severe bottlenecks when scaled up.

The Scaling Bottlenecks: When scaling model depth and parameter count, standard architectures face two critical issues:

  • Training Instability: Deep residual paths cause activation amplitudes to accumulate exponentially, leading to sudden gradient explosions or representation collapse during training.
  • Resolution Transfer Discrepancy: Models pre-trained on low resolution (e.g., $224 \times 224$) perform poorly when fine-tuned on high-resolution images because the relative position coordinate tables cannot extrapolate smoothly to larger window sizes.
💡 Swin V2's Core Pillars

Swin V2 introduces three key innovations to solve these issues: (1) Post-Normalization (Post-Norm) to stabilize deep layers, (2) Scaled Cosine Attention to bound attention values, and (3) Log-Spaced Continuous Position Bias (Log-CPB) to enable smooth resolution scaling.

2
How Swin V2 Works Internally
▼

1. From Pre-Norm to Post-Norm

In Swin-V1 (and typical ViTs), Pre-Normalization is used: LayerNorm is applied *before* the Multi-Head Self-Attention (MSA) and MLP blocks. While this eases gradient flow, the residual connections allow activations to accumulate directly: $x_{l+1} = x_l + \text{MSA}(\text{LN}(x_l))$. In extremely deep networks, this accumulation causes the feature values in later layers to grow exponentially compared to early layers, destabilizing training.

Swin V2 shifts to a modified Post-Norm structure where LayerNorm is placed *after* the residual addition: $x_{l+1} = \text{LN}(x_l + \text{MSA}(x_l))$. This keeps activation scales consistent across all layers, though it requires careful initialization and scaling techniques.

2. Scaled Cosine Attention

Standard self-attention computes similarity via the dot product: $Q K^\top / \sqrt{d}$. In scaled-up models, some token pairs produce extremely large dot products, dominating the softmax distribution and causing representation collapse. Swin V2 replaces this with Scaled Cosine Attention, which computes the cosine similarity between the Query and Key vectors, scaled by a learnable temperature $\tau$:

$$\text{Sim}(q_i, k_j) = \frac{\cos(q_i, k_j)}{\tau} = \frac{q_i^\top k_j}{\|q_i\| \|k_j\| \tau}$$

Because cosine similarity is strictly bounded between $-1$ and $1$, the attention matrix cannot be dominated by a few outlier values, ensuring balanced and stable attention maps.

3. Log-Spaced Continuous Position Bias (Log-CPB)

Instead of using a fixed lookup table for relative position biases (which fails when window sizes change during fine-tuning), Swin V2 uses a small meta-network (a 2-layer MLP) that generates the bias on the fly from relative coordinates. To handle massive window scaling, it maps linear coordinates to a logarithmic space first, drastically reducing the coordinate extrapolation range.

3
Why It Works — The Math
▼

Preventing Dot-Product Explosion

In standard Scaled Dot-Product Attention, assuming the elements of $q_i$ and $k_j$ are independent random variables with zero mean and unit variance, the variance of their dot product is:

$$\operatorname{Var}(q_i^\top k_j) = d$$

As the projection dimension $d$ scales up, the variance increases, leading to extreme values before softmax. Cosine attention completely avoids this dimension-dependent variance because:

$$\left| \frac{q_i^\top k_j}{\|q_i\| \|k_j\|} \right| \le 1 \implies \operatorname{Sim}(q_i, k_j) \in \left[ -\frac{1}{\tau}, \frac{1}{\tau} \right]$$

The learnable parameter $\tau$ is clamped to be at least $0.01$ to prevent extreme scaling.

Logarithmic Coordinate Scaling

When transferring a model from a pre-training window size of $M_{\text{pre}} \times M_{\text{pre}}$ to a fine-tuning size of $M_{\text{fine}} \times M_{\text{fine}}$, the relative coordinate range expands from $[-M_{\text{pre}} + 1, M_{\text{pre}} - 1]$ to $[-M_{\text{fine}} + 1, M_{\text{fine}} - 1]$. For example, scaling from $8 \times 8$ to $32 \times 32$ means the coordinate range expands by $4\times$. Linear extrapolation over this range is highly unstable.

Swin V2 maps the relative coordinates $(\Delta x, \Delta y)$ to log-spaced coordinates $(\hat{\Delta x}, \hat{\Delta y})$:

$$\hat{\Delta x} = \operatorname{sign}(\Delta x) \cdot \ln\left(1 + |\Delta x|\right)$$

By taking the logarithm, a $4\times$ linear coordinate expansion (from $7$ to $31$) is compressed to only a $1.7\times$ expansion (from $\ln(8) \approx 2.08$ to $\ln(32) \approx 3.47$). This makes extrapolation highly stable and accurate.

⚠️ Meta-Network Design

The MLP $\mathcal{M}$ is a simple 2-layer network with a ReLU activation in between. It takes 2D log-spaced coordinates and outputs a single scalar bias value: $B(\Delta x, \Delta y) = \mathcal{M}(\hat{\Delta x}, \hat{\Delta y})$. This MLP is optimized jointly with the main transformer parameters.

Key Takeaways
▼

When to choose Swin V2:

  • Giant Vision Models: When training models with 100M to 3B+ parameters where standard ViTs or Swin V1 suffer from training instability.
  • High-Resolution Downstream Tasks: For tasks requiring large-resolution inputs, such as object detection (COCO), semantic segmentation (ADE20K), or medical imaging.
  • Multi-Modal Pre-training: Swin V2 serves as an excellent visual backbone for large vision-language models (VLMs) due to its stability at scale.

Key Advantages over Swin V1:

  1. Extrapolation Capability: Log-CPB allows a model trained on $8 \times 8$ windows to transfer seamlessly to $32 \times 32$ windows without retraining the position bias parameters from scratch.
  2. Stable Training: The combination of Post-Norm and Scaled Cosine Attention allows deep models to train without gradient or activation explosions.
💡 Summary of Architecture Upgrades

Swin V2 replaces Pre-Norm with Post-Norm, Dot-Product Attention with Scaled Cosine Attention, and Parametric Position Tables with Log-Spaced Continuous Position Bias (Log-CPB).

import torch
import torch.nn as nn
import math
class SwinV2Attention(nn.Module):
def __init__(self, dim, window_size, num_heads):
super().__init__()
self.dim = dim
self.window_size = window_size
self.num_heads = num_heads
self.logit_scale = nn.Parameter(torch.log(10 * torch.ones(num_heads, 1, 1)))
# CPB Meta-Network (MLP)
self.cpb_mlp = nn.Sequential(
nn.Linear(2, 512, bias=True),
nn.ReLU(inplace=True),
nn.Linear(512, num_heads, bias=False)
)
def forward(self, x, mask=None):
B_, N, C = x.shape
# Project Queries, Keys, Values
qkv = self.qkv(x).reshape(B_, N, 3, self.num_heads, C // self.num_heads).permute(2, 0, 3, 1, 4)
q, k, v = qkv[0], qkv[1], qkv[2]
# Scaled Cosine Attention: L2 Normalize Q and K
attn = (F.normalize(q, dim=-1) @ F.normalize(k, dim=-1).transpose(-2, -1))
# Apply learnable scale (1 / tau) clamped to max 100
logit_scale = torch.clamp(self.logit_scale.exp(), max=100)
attn = attn * logit_scale
# Generate Log-Spaced Coordinates & Continuous Bias
relative_coords = self.get_log_relative_coords()
relative_position_bias = self.cpb_mlp(relative_coords)
attn = attn + relative_position_bias
attn = F.softmax(attn, dim=-1)
return (attn @ v)
