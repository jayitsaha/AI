Understanding NP-Completeness
▼

What is it? Complexity theory classifies computational problems by how hard they are — not by how clever your algorithm is, but by the minimum resources any algorithm needs. NP-completeness is a specific class of "hardest" problems in NP: if you could solve one efficiently, you could solve ALL of them efficiently.

Analogy: Imagine a library of crossword puzzles. Some puzzles (class P) you can solve systematically in reasonable time. Others (NP) are hard to solve, but if someone hands you a completed grid you can instantly check it. NP-complete puzzles are the "universal hardest" — they're all secretly the same puzzle in disguise. Crack one, crack them all.

If you remember one thing

NP-complete = NP-hard AND in NP. NP-hard means "at least as hard as everything in NP via polynomial reduction." If you prove a problem is NP-complete, stop searching for an exact polynomial-time algorithm — use approximations, heuristics, or parameterized algorithms instead.

The Four Classes

P — solvable in polynomial time. NP — solution verifiable in polynomial time (but maybe not findable). NP-hard — as hard as anything in NP via poly reduction (may not be in NP). NP-complete — in NP AND NP-hard (the hardest problems in NP). We have \(\mathbf{P} \subseteq \mathbf{NP}\), and the \(\mathbf{P} \neq \mathbf{NP}\) conjecture says this inclusion is strict.

A poly-time reduction from SUBSET-SUM to 3-SAT (schematic) and a verifier for 3-SAT.

def verify_3sat(clauses, assignment):
"""NP verifier: check assignment satisfies all clauses in O(n*k)."""
for clause in clauses: # each clause is list of (var, negated)
satisfied = False
for var, negated in clause:
val = assignment[var]
if negated: val = not val
if val: satisfied = True; break
if not satisfied: return False # clause violated
return True # all clauses satisfied
# Example: (x1 OR ~x2 OR x3) AND (~x1 OR x2 OR x4)
clauses = [[(1,False),(2,True),(3,False)],
[(1,True),(2,False),(4,False)]]
asgn = {1:True, 2:False, 3:True, 4:False}
print(verify_3sat(clauses, asgn)) # True — polynomial verification
def subset_sum_brute(nums, target):
"""O(2^n) exact solver — exponential, NP-complete."""
for r in range(len(nums)+1):
from itertools import combinations
for combo in combinations(nums, r):
if sum(combo) == target: return True, combo
return False, None
print(subset_sum_brute([3,1,1,2,2,1], 5))
# (True, (3, 2)) — found by exhaustive search
def subset_sum_dp(nums, target):
"""Pseudo-poly O(n*W) DP — fast when W is small, still NP-hard in bits."""
dp = {0} # achievable sums
for x in nums:
dp = dp | {s + x for s in dp}
return target in dp
