Multiple Comparisons Problem: Bonferroni, Holm & BH (FDR)

Controlling false positives when running many hypothesis tests simultaneously
Intermediate Statistics Hypothesis Testing O(m log m) — BH needs sort
1
Understanding the Problem
▼

What is it? Every time you run a hypothesis test, you accept a small probability α of a false positive — declaring a result significant when it isn't. But if you run many tests simultaneously, those small probabilities pile up. Run 20 tests at α=0.05 and you have a 64% chance of at least one false positive. Run 1,000 tests (common in genomics or A/B testing) and a false positive is virtually guaranteed.

Analogy: Imagine 1,000 people each flip a fair coin 20 times. Some will get 18+ heads purely by chance. If you declare "this person has telekinesis!" whenever that happens, you'll flag roughly 10 people — all false positives. The multiple comparisons problem is exactly this: the more tests you run, the more "lucky" outcomes appear significant.

If you remember one thing

Running \(m\) independent tests at level \(\alpha\) inflates the family-wise error rate to \(1-(1-\alpha)^m\). At \(m=100\) and \(\alpha=0.05\), FWER = 99.4%. You need a correction. The choice of correction depends on how strictly you need to control errors: Bonferroni (most strict), Holm (same control, more power), or Benjamini-Hochberg (controls a different, weaker error rate — the FDR).

Key Terminology

  • Family of hypotheses: The complete set of \(m\) tests performed simultaneously.
  • FWER (Family-Wise Error Rate): \(P(\text{at least one false rejection})\). Bonferroni and Holm control this.
  • FDR (False Discovery Rate): \(\mathbb{E}[V/R]\) where \(V\) = false rejections, \(R\) = total rejections (0 if \(R=0\)). Benjamini-Hochberg controls this.
  • p-value ordering: All three procedures sort \(p_{(1)} \leq p_{(2)} \leq \cdots \leq p_{(m)}\) first.
Common Context

Genomics: Testing 20,000 genes for differential expression. A/B testing: Running 50 metric variants simultaneously. Feature selection: Testing 500 features in a regression. fMRI: Testing 100,000 voxels for activation. In all these cases, uncorrected testing leads to a flood of false discoveries.

The Three Corrections Explained
▼

1. Bonferroni Correction (1936) — Flat Threshold

The simplest correction: divide \(\alpha\) by the number of tests \(m\). Reject \(H_{(k)}\) if \(p_{(k)} \leq \alpha/m\). For \(m=10\), \(\alpha=0.05\): threshold = \(0.005\). By the Bonferroni inequality \(P(\bigcup A_i) \leq \sum P(A_i)\), this guarantees FWER \(\leq \alpha\) regardless of the dependence structure of the tests.

$$\text{Reject } H_{(k)} \text{ if } p_{(k)} \leq \frac{\alpha}{m}$$

Pro: Simple, ultra-conservative, valid for any dependence. Con: Loses power rapidly as \(m\) grows — at \(m=20{,}000\) (genomics), threshold is \(2.5 \times 10^{-6}\).

2. Holm Step-Down (1979) — Adaptive Threshold

Sort p-values \(p_{(1)} \leq \cdots \leq p_{(m)}\). For each rank \(k = 1, 2, \ldots\), use threshold \(\alpha/(m-k+1)\). Test in order: if \(p_{(k)} \leq \alpha/(m-k+1)\), reject and continue; otherwise, stop and accept all remaining. Holm is uniformly more powerful than Bonferroni while providing the same FWER \(\leq \alpha\) guarantee.

$$\text{Reject } H_{(k)} \text{ if } p_{(j)} \leq \frac{\alpha}{m-j+1} \text{ for all } j \leq k$$

Why better? At rank \(k\), you've already confirmed the first \(k-1\) rejections, so only \(m-k+1\) tests remain "unrejected." The effective family shrinks.

3. Benjamini-Hochberg (1995) — Controls FDR

Sort p-values ascending. Draw the line \(y = k \cdot \alpha/m\) (slope \(\alpha/m\), through origin). Find the largest rank \(K\) such that \(p_{(K)} \leq K \cdot \alpha/m\). Reject \(H_{(1)}, \ldots, H_{(K)}\) — all hypotheses up to and including rank \(K\).

$$K = \max\!\left\{k : p_{(k)} \leq \frac{k \cdot \alpha}{m}\right\}, \quad \text{reject } H_{(1)}, \ldots, H_{(K)}$$

Under independence (or positive regression dependence — PRDS), BH controls FDR \(\leq \alpha \cdot m_0/m \leq \alpha\), where \(m_0\) = number of true nulls. BH is provably more powerful than Bonferroni and Holm when there are many true alternatives.

Key Insight: Why BH Rejects More

Bonferroni and Holm control the probability of any error. BH controls the expected fraction of errors among discoveries. A few false discoveries are tolerable in exploratory settings (genomics, feature mining) if true discoveries are also found efficiently. BH gives you a better signal-to-noise ratio when \(m\) is large.

Why It Works — The Math
▼

Bonferroni Proof (Boole's Inequality)

Let \(A_i\) be the event "falsely reject \(H_i\)" for each true null. Under \(H_i\), \(P(A_i) = \alpha/m\). By the union bound:

$$\text{FWER} = P\!\left(\bigcup_{i \in \mathcal{H}_0} A_i\right) \leq \sum_{i \in \mathcal{H}_0} P(A_i) = m_0 \cdot \frac{\alpha}{m} \leq m \cdot \frac{\alpha}{m} = \alpha$$

No distributional assumptions on dependence — the union bound holds for any joint distribution. This is why Bonferroni is robust but conservative.

Holm Proof Sketch

Let \(m_0\) = true nulls, \(K\) = first rank where Holm stops. For Holm to make a false rejection, it must reject some \(H_i\) that is truly null. At that rank \(k\), we have at least \(m_0\) true nulls remaining among \(m-k+1\) remaining tests. The smallest of \(m_0\) uniform \([0,1]\) variables exceeds \(\alpha/m_0 \geq \alpha/(m-k+1)\) with probability \(1-\alpha\). Hence FWER \(\leq \alpha\). (Full proof uses the closed testing principle.)

Benjamini-Hochberg FDR Proof (Benjamini & Hochberg, 1995)

With \(m_0\) true nulls and \(m-m_0\) true alternatives, p-values under \(H_0\) are uniform \([0,1]\). Define \(V\) = false discoveries, \(R\) = total discoveries. The FDR is:

$$\text{FDR} = \mathbb{E}\!\left[\frac{V}{R} \cdot \mathbf{1}_{R>0}\right]$$

The key insight: when the BH procedure rejects at rank \(K\), the expected number of false rejections among the \(K\) rejections is at most \(K \cdot (m_0/m)\). Since we reject \(K\) hypotheses, FDR \(\leq m_0 \alpha / m \leq \alpha\). Formally (under independence):

$$\text{FDR} = \frac{m_0}{m} \cdot \alpha \leq \alpha$$
The BH Line Geometry

Plot \(p_{(k)}\) on the y-axis vs rank \(k\) on the x-axis. Draw the line \(y = k \cdot \alpha/m\) (passes through origin, slope \(\alpha/m\)). BH finds the last crossing point where the p-value bar dips below the line. All hypotheses to the left of (and including) the last crossing are rejected. This geometric view makes the procedure immediately intuitive.

BH Requires Independence (or PRDS)

The BH FDR ≤ α guarantee holds under independence, or under positive regression dependence on subsets (PRDS). For arbitrary dependence, use the BY (Benjamini-Yekutieli 2001) correction: replace \(\alpha\) with \(\alpha / \sum_{k=1}^m 1/k\). In practice, BH is robust to mild positive correlation (common in genomics) but can be anti-conservative under strong negative correlation.

Real-World Applications

  • Genomics / GWAS: Test 500,000 SNPs. Bonferroni threshold ≈ 10⁻⁷. BH allows many more discoveries — standard practice in differential expression (DESeq2, edgeR use BH).
  • A/B / Multi-Metric Testing: If your dashboard shows 50 metrics per experiment, BH is appropriate for deciding which metrics to investigate further.
  • Feature selection: Run t-tests on 1,000 features. Use BH-adjusted p-values to select features — this controls the expected false discovery rate in your feature set.
  • fMRI neuroimaging: Test 100,000 voxels for activation. Cluster-level FDR or BH on voxel p-values are both standard approaches.
  • Drug discovery / clinical trials: For confirmatory primary endpoints, use Bonferroni or Holm (FWER control is required by FDA guidelines). For exploratory secondary endpoints, BH is acceptable.
Decision Rule

If you must never make a single false claim (clinical primary endpoint, legal, policy) → Bonferroni or Holm. If you're exploring (genomics screen, EDA, feature mining) → BH. Never use uncorrected α when running many simultaneous tests. And never use Bonferroni when Holm is available — Holm is uniformly more powerful with identical FWER control.

Code Implementation
▼

From Scratch (NumPy)

import numpy as np
def bonferroni(p_values, alpha=0.05):
"""Bonferroni correction. Returns mask of rejected hypotheses."""
m = len(p_values)
return np.array(p_values) <= alpha / m
def holm(p_values, alpha=0.05):
"""Holm step-down. Returns boolean reject mask (original order)."""
m = len(p_values)
p = np.array(p_values)
order = np.argsort(p) # sort ascending
p_sorted = p[order]
reject = np.zeros(m, dtype=bool)
for k in range(m):
thresh = alpha / (m - k) # α/(m-k+1), k is 0-indexed
if p_sorted[k] <= thresh:
reject[order[k]] = True
else:
break # stop — remaining are accepted
return reject
def benjamini_hochberg(p_values, alpha=0.05):
"""BH FDR correction. Returns boolean reject mask (original order)."""
m = len(p_values)
p = np.array(p_values)
order = np.argsort(p)
p_sorted = p[order]
# BH thresholds: k*alpha/m for k=1..m
thresholds = (np.arange(1, m+1) * alpha) / m
# Find largest k where p(k) <= k*alpha/m
below = p_sorted <= thresholds
if not below.any():
return np.zeros(m, dtype=bool) # no rejections
last_k = np.where(below)[0].max() # largest qualifying rank (0-indexed)
reject_mask = np.zeros(m, dtype=bool)
reject_mask[order[:last_k+1]] = True # reject all up to last_k
return reject_mask
# Example: m=10 p-values
pvals = [0.001,0.004,0.013,0.021,0.035,0.048,0.069,0.112,0.245,0.380]
print("Bonferroni:", bonferroni(pvals).sum(), "rejections")
print("Holm: ", holm(pvals).sum(), "rejections")
print("BH: ", benjamini_hochberg(pvals).sum(), "rejections")
# Output: Bonferroni: 2, Holm: 2, BH: 3

Production Usage (statsmodels)

from statsmodels.stats.multitest import multipletests
pvals = [0.001,0.004,0.013,0.021,0.035,0.048,0.069,0.112,0.245,0.380]
# Bonferroni
reject_b, pvals_b, _, _ = multipletests(pvals, alpha=0.05, method='bonferroni')
# Holm
reject_h, pvals_h, _, _ = multipletests(pvals, alpha=0.05, method='holm')
# Benjamini-Hochberg (FDR)
reject_bh, pvals_bh, _, _ = multipletests(pvals, alpha=0.05, method='fdr_bh')
# BY (FDR under arbitrary dependence)
reject_by, pvals_by, _, _ = multipletests(pvals, alpha=0.05, method='fdr_by')
# In R: p.adjust(pvals, method="BH") # or "bonferroni", "holm", "BY"
# genomics: Bioconductor's p.adjust() is standard; limma uses BH by default
