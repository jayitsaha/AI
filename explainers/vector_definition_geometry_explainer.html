Understanding Vectors
▼

What is a vector? A vector is an ordered list of numbers that encodes both a magnitude (how big) and a direction (which way). In 2D, writing \(\mathbf{u} = (2,\,1)\) means "move 2 units right and 1 unit up." You can picture it as an arrow starting at the origin and ending at the point \((2,1)\).

Two equivalent views — arrows and coordinates. Geometrically a vector is an arrow in space. Algebraically it is a column (or row) of numbers. Both representations are the same object; we switch between them freely. In \(n\) dimensions, \(\mathbf{x} \in \mathbb{R}^n\) is the column

$$\mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix} \in \mathbb{R}^n$$

Its magnitude (Euclidean length) is \(\|\mathbf{x}\|_2 = \sqrt{x_1^2 + x_2^2 + \cdots + x_n^2}\). Its direction is captured by the unit vector \(\hat{\mathbf{x}} = \mathbf{x}/\|\mathbf{x}\|\).

Everyday analogy. Think of giving someone directions: "Walk 3 blocks east, then 2 blocks north." That instruction is a 2D vector \((3,2)\). A scalar (just a number, like "walk 5 blocks") has magnitude but no direction — that's the key distinction.

💡 If you remember one thing

A vector combines magnitude and direction in a single object. The coordinate tuple \((x_1,\ldots,x_n)\) is just one way to write it; the arrow picture is another. In ML, almost every interesting quantity — a data point, a gradient, a word embedding — is a vector in some high-dimensional space.

Notation conventions

  • Boldface lowercase: \(\mathbf{u}, \mathbf{v}, \mathbf{x}\) — standard for vectors (used throughout linear algebra and ML)
  • Arrow notation: \(\vec{u}\) — common in physics; less frequent in ML literature
  • Column vs row: By default vectors are column vectors; a row vector is the transpose \(\mathbf{u}^\top\)
  • Indexed components: \(u_i\) denotes the \(i\)-th entry of \(\mathbf{u}\); subscripts start at 1 in math, 0 in code
  • Set membership: \(\mathbf{x} \in \mathbb{R}^n\) means \(\mathbf{x}\) is a real-valued \(n\)-dimensional vector

Vector Operations & Properties
▼

Addition — tip-to-tail rule

To add vectors \(\mathbf{u} = (2,1)\) and \(\mathbf{v} = (1,3)\), place \(\mathbf{v}\) so its tail sits at \(\mathbf{u}\)'s tip. The result is the vector from the original origin to \(\mathbf{v}\)'s tip:

$$\mathbf{u} + \mathbf{v} = \begin{bmatrix}2\\1\end{bmatrix} + \begin{bmatrix}1\\3\end{bmatrix} = \begin{bmatrix}3\\4\end{bmatrix}$$

Componentwise: just add the corresponding entries. This is commutative (\(\mathbf{u}+\mathbf{v}=\mathbf{v}+\mathbf{u}\)) and associative.

Scalar multiplication — uniform scaling

Multiplying by scalar \(c \in \mathbb{R}\) stretches (or flips) the arrow without changing its direction (unless \(c < 0\)):

$$2\,\mathbf{u} = 2 \begin{bmatrix}2\\1\end{bmatrix} = \begin{bmatrix}4\\2\end{bmatrix}$$

The magnitude scales by \(|c|\): \(\|c\mathbf{u}\| = |c|\,\|\mathbf{u}\|\). Negative \(c\) flips direction.

Basis vectors and decomposition

Every vector in \(\mathbb{R}^n\) can be written as a linear combination of the standard basis vectors \(\mathbf{e}_1 = (1,0,\ldots,0)^\top\), \(\mathbf{e}_2 = (0,1,0,\ldots,0)^\top\), etc.:

$$\mathbf{v} = \begin{bmatrix}1\\3\end{bmatrix} = 1\cdot\mathbf{e}_1 + 3\cdot\mathbf{e}_2 \quad \text{where } \mathbf{e}_1=\begin{bmatrix}1\\0\end{bmatrix},\;\mathbf{e}_2=\begin{bmatrix}0\\1\end{bmatrix}$$

The coefficients \((1,3)\) are just the components of \(\mathbf{v}\) in the standard basis. Changing the basis is a key idea behind PCA, Fourier analysis, and learned embeddings.

🔑 Key Property — Vector Space Axioms

Vectors live in a vector space: a set closed under addition and scalar multiplication, with a zero vector \(\mathbf{0}\), additive inverses, and eight axioms (commutativity, associativity, distributivity, etc.). Every gradient, embedding, and data point in ML implicitly inherits these axioms.

⚠️ Common Mistake

Vectors are not the same as points — but they are closely related. A point \(P = (2,1)\) specifies a location; the vector \(\mathbf{u}=(2,1)\) specifies a displacement. In practice we identify the position vector with the point, but conceptually a vector can be placed anywhere (it has no fixed origin). This matters when you chain transformations.

The Math: Norms, Dot Products & Angles
▼

Euclidean norm (\(\ell_2\) norm)

The most common measure of a vector's size is the Euclidean norm:

$$\|\mathbf{u}\|_2 = \sqrt{\sum_{i=1}^n u_i^2} = \sqrt{u_1^2 + u_2^2 + \cdots + u_n^2}$$

For \(\mathbf{u}=(2,1)\): \(\|\mathbf{u}\|_2 = \sqrt{4+1} = \sqrt{5} \approx 2.236\). Other norms used in ML:

  • \(\ell_1\) norm (Manhattan): \(\|\mathbf{u}\|_1 = \sum_i |u_i|\). For \(\mathbf{u}=(2,1)\): \(|2|+|1|=3\).
  • \(\ell_\infty\) norm (max): \(\|\mathbf{u}\|_\infty = \max_i |u_i|\). For \(\mathbf{u}=(2,1)\): \(\max(2,1)=2\).
  • \(\ell_p\) norm: \(\|\mathbf{u}\|_p = \bigl(\sum_i |u_i|^p\bigr)^{1/p}\).

Dot product (inner product)

The dot product of \(\mathbf{u},\mathbf{v}\in\mathbb{R}^n\) is the scalar:

$$\mathbf{u} \cdot \mathbf{v} = \mathbf{u}^\top \mathbf{v} = \sum_{i=1}^n u_i v_i$$

For \(\mathbf{u}=(2,1)\) and \(\mathbf{v}=(1,3)\): \(\mathbf{u}\cdot\mathbf{v} = 2\cdot1 + 1\cdot3 = 5\).

Geometric interpretation of the dot product

The dot product has a beautiful geometric form:

$$\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\|\,\|\mathbf{v}\|\cos\theta$$

where \(\theta\) is the angle between \(\mathbf{u}\) and \(\mathbf{v}\). For our vectors: \(\|\mathbf{u}\|=\sqrt{5}\approx2.236\), \(\|\mathbf{v}\|=\sqrt{10}\approx3.162\), \(\mathbf{u}\cdot\mathbf{v}=5\), so:

$$\cos\theta = \frac{5}{\sqrt{5}\cdot\sqrt{10}} = \frac{5}{\sqrt{50}} = \frac{5}{5\sqrt{2}} = \frac{1}{\sqrt{2}} \implies \theta = 45°$$
📐 Three critical cases

• \(\mathbf{u}\cdot\mathbf{v} > 0\): vectors point in similar directions (\(\theta < 90°\))
• \(\mathbf{u}\cdot\mathbf{v} = 0\): vectors are orthogonal / perpendicular (\(\theta = 90°\))
• \(\mathbf{u}\cdot\mathbf{v} < 0\): vectors point in opposite directions (\(\theta > 90°\))

In ML: cosine similarity \(\cos\theta = \frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}\) measures how "aligned" two embedding vectors are — it powers nearest-neighbor search, semantic similarity, and attention scores.

Projection

The scalar projection of \(\mathbf{v}\) onto \(\mathbf{u}\) is how much of \(\mathbf{v}\) lies in the direction of \(\mathbf{u}\):

$$\text{proj}_{\mathbf{u}}\mathbf{v} = \frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|^2}\,\mathbf{u} = \frac{5}{5}\begin{bmatrix}2\\1\end{bmatrix} = \begin{bmatrix}2\\1\end{bmatrix}$$

(In this example the projection of \(\mathbf{v}\) onto \(\mathbf{u}\) happens to equal \(\mathbf{u}\) itself because \(\theta=45°\) and the numbers work out.) Projections underlie least squares regression, PCA, and the attention mechanism.

Vectors in Machine Learning
▼

Machine learning lives in vector spaces. Here are the four canonical roles vectors play in ML:

1. Data points as vectors

A training sample with \(n\) features is a vector \(\mathbf{x} \in \mathbb{R}^n\). A tabular row (age, income, clicks) becomes \(\mathbf{x}=(28,\,55000,\,14)\). An image is a vector of pixel intensities; a document is a vector of word counts (bag of words). The dataset is a collection of \(m\) such vectors, stacked as a matrix \(X \in \mathbb{R}^{m\times n}\).

2. Word embeddings — semantic vectors

Word2Vec and similar models map each word to a dense vector in \(\mathbb{R}^d\) (typically \(d=50\)–\(300\)) such that semantic relationships correspond to vector arithmetic. The famous example with numerically correct values (our simplified 2D version):

$$\mathbf{king} - \mathbf{man} + \mathbf{woman} \approx \mathbf{queen}$$

With \(\mathbf{king}=(3,2)\), \(\mathbf{man}=(2,1)\), \(\mathbf{woman}=(1,3)\): the result is \((2,4)\), which corresponds to the "queen" vector exactly. This works because directions in embedding space encode semantic dimensions (gender axis, royalty axis, etc.).

3. Gradients as vectors

The gradient \(\nabla_\theta \mathcal{L}\) of a loss \(\mathcal{L}\) with respect to parameters \(\theta \in \mathbb{R}^p\) is a vector of partial derivatives:

$$\nabla_\theta \mathcal{L} = \begin{bmatrix}\frac{\partial \mathcal{L}}{\partial \theta_1} \\ \vdots \\ \frac{\partial \mathcal{L}}{\partial \theta_p}\end{bmatrix} \in \mathbb{R}^p$$

SGD moves parameters in the opposite direction of this vector: \(\theta \leftarrow \theta - \eta\,\nabla_\theta\mathcal{L}\). The gradient's direction is the direction of steepest ascent; negating it descends the loss surface.

4. Hidden states and attention as vectors

Every token in a transformer produces a hidden-state vector \(\mathbf{h} \in \mathbb{R}^d\) (e.g., \(d=768\) in BERT-base). The attention score between query \(\mathbf{q}\) and key \(\mathbf{k}\) is essentially a dot product: \(\text{score} = \mathbf{q}^\top\mathbf{k}/\sqrt{d_k}\). The entire attention mechanism is built on the geometry of inner products between vectors.

💡 The ML Unification

Virtually every ML operation reduces to vector/matrix arithmetic: forward passes are matrix-vector products, losses are dot products with label vectors, optimizers follow gradient vectors, and similarity metrics are dot products or cosine similarities. Mastering vectors is mastering ML's computational core.

Key Takeaways & Interview Prep
▼

Summary

  • A vector \(\mathbf{x}\in\mathbb{R}^n\) is an ordered \(n\)-tuple encoding both magnitude \(\|\mathbf{x}\|\) and direction \(\hat{\mathbf{x}}=\mathbf{x}/\|\mathbf{x}\|\).
  • Addition is tip-to-tail; scalar multiplication scales magnitude (and flips direction if negative).
  • The dot product \(\mathbf{u}\cdot\mathbf{v}=\|\mathbf{u}\|\|\mathbf{v}\|\cos\theta\) is the workhorse of similarity measurement.
  • Orthogonality (\(\mathbf{u}\cdot\mathbf{v}=0\)) is the generalization of "perpendicular" to any dimension.
  • In ML: data points, gradients, embeddings, hidden states, and query/key/value vectors are all vectors.

Interview Q&A

Q1 (Easy): What is the difference between a vector and a scalar?

A scalar has only magnitude (e.g., temperature = 23). A vector has both magnitude and direction (e.g., wind velocity = 23 km/h north-east). Formally, scalars are elements of \(\mathbb{R}\); vectors are elements of \(\mathbb{R}^n\) for \(n\geq 1\).

Q2 (Easy): What does it mean for two vectors to be orthogonal?

Their dot product is zero: \(\mathbf{u}\cdot\mathbf{v}=0\). Geometrically they are perpendicular. In ML, orthogonal features carry no linear information about each other; PCA finds an orthogonal basis that maximises explained variance.

Q3 (Medium): Why is cosine similarity preferred over Euclidean distance for comparing embeddings?

Cosine similarity \(\cos\theta=\mathbf{u}\cdot\mathbf{v}/(\|\mathbf{u}\|\|\mathbf{v}\|)\) is scale-invariant — it only measures direction. A document vector and its scaled version have identical cosine similarity to a query. Euclidean distance conflates magnitude and direction, which is problematic when vectors have different lengths for non-semantic reasons (e.g., document length). In recommendation systems and vector databases, cosine similarity (or equivalently, dot product on unit-normalized vectors) is the standard metric.

Q4 (Hard): Why does gradient descent work geometrically?

The gradient \(\nabla_\theta\mathcal{L}\) is a vector in parameter space pointing in the direction of steepest ascent of \(\mathcal{L}\). This follows from the directional derivative formula: \(D_{\mathbf{d}}\mathcal{L}=\nabla\mathcal{L}\cdot\mathbf{d}/\|\mathbf{d}\|\), which is maximised when \(\mathbf{d}\) is parallel to \(\nabla\mathcal{L}\). So moving in the direction \(-\nabla\mathcal{L}\) (steepest descent) decreases \(\mathcal{L}\) fastest, at rate \(\|\nabla\mathcal{L}\|\) per unit step. The update \(\theta\leftarrow\theta-\eta\nabla\mathcal{L}\) follows this direction with step size \(\eta\).
