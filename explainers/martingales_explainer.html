1
Understanding Martingales
▼

What is it? A martingale is a sequence of random variables \((X_0, X_1, X_2, \ldots)\) where your best guess for the next value — given everything you know so far — is exactly the current value. Nothing in your history tells you which way the sequence will drift. It is the mathematical model of a fair game.

Analogy: Imagine you're flipping a fair coin and tracking your running wealth: +$1 for heads, -$1 for tails. At any moment, no matter how many heads or tails you've seen, your expected wealth tomorrow equals your wealth today. Past streaks carry zero predictive power. The martingale condition captures this perfectly.

💡 If you remember one thing

A martingale satisfies \(\mathbb{E}[X_{t+1} \mid \mathcal{F}_t] = X_t\) — the best forecast for the future is the present. Not trending up (supermartingale \(\leq\)), not trending down (submartingale \(\geq\)), but flat on average.

Why it matters: Martingale theory powers financial mathematics (risk-neutral pricing, no-arbitrage), machine learning (gradient noise analysis, convergence proofs), and statistics (sequential hypothesis testing, Wald's identity).

2
The Formal Definition — Three Flavours
▼

Setup: Filtrations and Adapted Processes

Let \((\Omega, \mathcal{F}, \mathbb{P})\) be a probability space. A filtration \(\{\mathcal{F}_t\}_{t\geq 0}\) is an increasing sequence of \(\sigma\)-algebras representing "information accumulated up to time \(t\)". A stochastic process \(\{X_t\}\) is adapted to \(\{\mathcal{F}_t\}\) if \(X_t\) is \(\mathcal{F}_t\)-measurable — you can observe \(X_t\) at time \(t\).

$$\mathcal{F}_0 \subseteq \mathcal{F}_1 \subseteq \mathcal{F}_2 \subseteq \cdots \subseteq \mathcal{F}$$

The Three Conditions

Given an adapted, integrable process \(\{X_t\}\):

  • Martingale: \(\mathbb{E}[X_{t+1} \mid \mathcal{F}_t] = X_t\) — fair game, no drift
  • Submartingale: \(\mathbb{E}[X_{t+1} \mid \mathcal{F}_t] \geq X_t\) — expected to rise (favourable)
  • Supermartingale: \(\mathbb{E}[X_{t+1} \mid \mathcal{F}_t] \leq X_t\) — expected to fall (unfavourable)
🔑 Key Examples

Martingale: Symmetric random walk \(X_t = \sum_{s=1}^t \xi_s\), \(\xi_s \overset{\text{iid}}{\sim} \pm1\) with equal probability.

Supermartingale: Gambler's wealth in a casino where the house has an edge (e.g., winning prob \(p < 0.5\)).

Submartingale: \(|X_t|\) where \(X_t\) is a martingale (by Jensen's inequality, since \(|\cdot|\) is convex).

The Natural Filtration

The most common choice is the natural filtration \(\mathcal{F}_t = \sigma(X_0, X_1, \ldots, X_t)\) — the smallest \(\sigma\)-algebra generated by observations up to time \(t\). The martingale condition then becomes: conditioning on the full history is the same as conditioning only on \(X_t\) (the Markov martingale case), though in general the history matters.

⚠️ Common Confusion

A martingale is not the same as an i.i.d. sequence. Martingale increments \(X_{t+1} - X_t\) have mean zero, but can be dependent (e.g., ARCH models, where variance depends on past values). The martingale condition is purely about the first conditional moment.

Key Theorems — Especially the Optional Stopping Theorem
▼

The Optional Stopping Theorem (OST)

This is the most practically important result. Intuitively: you cannot beat a fair game by choosing a clever time to quit.

Let \(\{X_t\}\) be a martingale and \(\tau\) a stopping time (i.e., \(\{\tau \leq t\} \in \mathcal{F}_t\) for all \(t\) — the decision to stop can only use information available at time \(t\)). Then under regularity conditions:

$$\mathbb{E}[X_\tau] = \mathbb{E}[X_0]$$

Regularity conditions (pick one):

  • \(\tau\) is bounded (\(\tau \leq N\) a.s. for some fixed \(N\))
  • \(\mathbb{E}[\tau] < \infty\) and increments are bounded: \(|X_{t+1} - X_t| \leq C\)
  • \(\{X_{t \wedge \tau}\}\) is uniformly integrable
📐 Numerical Verification (10,000 simulations)

Starting wealth \(X_0 = 100\). Stop when \(X_\tau \geq 120\) or \(X_\tau \leq 80\). Symmetric random walk (\(p=0.5\)).
Fraction hitting 120: 47.2%  |  Fraction hitting 80: 47.1%
Mean \(X_\tau\) = 100.01 ≈ 100 = \(X_0\). ✓

Doob's Convergence Theorem

Any martingale bounded in \(L^1\) (i.e., \(\sup_t \mathbb{E}[|X_t|] < \infty\)) converges almost surely to a finite limit \(X_\infty\). This is the foundation for proving convergence of SGD and many MCMC algorithms.

Doob's \(L^p\) Inequality (Maximal Inequality)

For a non-negative submartingale \(\{X_t\}\) and \(p > 1\):

$$\mathbb{E}\!\left[\sup_{0 \leq t \leq T} X_t^p\right] \leq \left(\frac{p}{p-1}\right)^p \mathbb{E}[X_T^p]$$

This controls how "wild" the sample paths can get in terms of their maximum.

Connection to Fair Pricing (Finance)

The fundamental theorem of asset pricing states: no-arbitrage ⟺ there exists a risk-neutral measure \(\mathbb{Q}\) under which discounted asset prices are martingales. Option prices are expectations of discounted payoffs under \(\mathbb{Q}\):

$$V_0 = \mathbb{E}^\mathbb{Q}\!\left[e^{-rT} V_T\right]$$

Connection to SGD / ML Gradient Noise

In stochastic gradient descent, the gradient noise \(g_t - \nabla L(\theta_t)\) (mini-batch gradient minus true gradient) forms a martingale difference sequence: \(\mathbb{E}[g_t - \nabla L(\theta_t) \mid \theta_t] = 0\). Convergence proofs use the martingale convergence theorem to show that training loss decreases on average.

💡 The Gambler's Ruin Insight

Suppose you start with \$100 and want to reach \$200 before going broke (\$0). By OST: \(\mathbb{E}[X_\tau] = 100\), and \(X_\tau \in \{0, 200\}\). Let \(p\) = prob of reaching \$200. Then \(200p + 0(1-p) = 100\), so \(p = 0.5\). A fair game gives you exactly 50-50 odds regardless of your strategy.

Key Takeaways & When to Use

Martingale Taxonomy

Martingale\(\mathbb{E}[X_{t+1}|\mathcal{F}_t] = X_t\)None (fair)Symmetric RW, stock under risk-neutral measure

When Is This the Right Tool?

  • Finance: Pricing derivatives, proving no-arbitrage, risk-neutral measure construction
  • ML convergence: Showing SGD/MCMC converge via martingale convergence theorem
  • Statistics: Wald's equation, sequential testing (SPRT), confidence sequences
  • Probability: Proving Borel-Cantelli, strong law of large numbers, optional stopping
💡 The OST Bottom Line

No betting strategy on a fair game (no matter how clever: Martingale doubling, Kelly, look-ahead) can change your expected final wealth. The only way to profit is with an information advantage or an edge (\(p > 0.5\)) — not a stopping rule.

Code Trace — Martingales from Scratch
▼
import numpy as np
def simulate_rw(p=0.5, T=20, X0=0, seed=42):
"""Simulate a random walk: +1 w.p. p, -1 w.p. 1-p."""
rng = np.random.default_rng(seed)
steps = rng.choice([1, -1], size=T, p=[p, 1-p])
X = np.concatenate([[X0], X0 + np.cumsum(steps)])
return X
def check_martingale(X, p):
"""E[X_{t+1}|X_t] = X_t + 2p - 1 for binary RW."""
drift = 2*p - 1 # = 0 iff martingale (p=0.5)
expected_drift = np.mean(np.diff(X))
return expected_drift, drift # should be equal
def optional_stopping_theorem(p=0.5, X0=100, lo=80, hi=120, n=10000):
"""Verify E[X_tau] = X0 for bounded stopping time."""
rng = np.random.default_rng(0)
final = []
for _ in range(n):
x = X0
while lo < x < hi: # tau = first exit time
x += rng.choice([1, -1], p=[p, 1-p])
final.append(x)
return np.mean(final) # OST: should be X0 = 100
mart = simulate_rw(p=0.5) # martingale
super_m = simulate_rw(p=0.4) # supermartingale
sub_m = simulate_rw(p=0.6) # submartingale
e_tau = optional_stopping_theorem() # ≈ 100.009
print(f"E[X_tau] = {e_tau:.3f}") # OST verified
