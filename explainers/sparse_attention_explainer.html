Sparse Attention: Local, Strided, BigBird & Longformer

Cutting O(n²) self-attention down to O(n) by choosing carefully which tokens are allowed to look at each other
Advanced Transformers / NLP Long-Context O(n²) → O(n)
1
Understanding Sparse Attention
▼

What is it? Standard self-attention lets every token look at every other token — powerful, but the cost explodes quadratically: double the sequence length and you quadruple the compute and memory. Sparse attention keeps most of that power while only computing a carefully chosen subset of the \(n \times n\) attention pairs, pushing cost toward \(O(n)\).

Analogy: Picture a huge conference where, instead of everyone talking to everyone (exhausting and slow), each person only talks to their immediate neighbors (local), a few people they specifically dial up for periodic updates (strided), and a couple of "town criers" who circulate everything to everyone (global tokens). Nearly the same information spreads through the room, using a fraction of the conversations.

💡 If you remember one thing

Sparse attention masks out most of the \(n^2\) query-key pairs and only computes the ones that matter most — locality, periodic long-range links, and a few global hubs — turning \(O(n^2)\) attention into \(O(n)\) attention.

2
How It Works Internally
▼

Four Building Blocks

Every sparse attention scheme is built from a small vocabulary of connection patterns, mixed and matched: local / sliding window (attend within a fixed radius \(w\) around each position), strided / dilated (attend to every \(s\)-th position, jumping across long ranges cheaply), global tokens (a handful of tokens attend to, and are attended by, everyone), and random (a few random long-range edges per query).

Longformer — Window ∪ Global

Longformer (Beltagy, Peters & Cohan, 2020) unions a sliding window with global attention on a few task-specific tokens (e.g. [CLS], question tokens in QA). Most positions get cheap local context; the tokens that need full visibility get it. Complexity: \(O(n(w+g))\).

BigBird — Window ∪ Global ∪ Random

BigBird (Zaheer et al., NeurIPS 2020) adds \(r\) random edges per query on top of Longformer's pattern. Random edges behave like shortcuts in a small-world graph — with high probability any two tokens are connected through only \(O(\log n)\) hops, so information can still travel across the whole sequence even though each query directly sees only \(O(w+g+r)\) keys.

Design Decision: Why not just use a bigger window?

A bigger window alone still can't propagate information across a long sequence in one layer, and pure local attention has no path for genuinely global dependencies (coreference across a 4,000-word document, say). Mixing window + global + random gives each piece a different job: locality for syntax, global tokens for task signals, random edges for long-range reachability — while total compute stays linear.

🔑 Key Property

Every sparse pattern defines a neighborhood set \(\mathcal{N}(i)\) for each query \(i\); attention is computed and normalized only over \(\mathcal{N}(i)\), so cost is \(O(n\,|\mathcal{N}(i)|)\) instead of \(O(n^2)\).

3
Why It Works — The Math
▼

Masked Attention

$$\text{Attn}(Q,K,V)_i = \sum_{j \in \mathcal{N}(i)} \frac{\exp(q_i \cdot k_j / \sqrt{d})}{\sum_{j' \in \mathcal{N}(i)} \exp(q_i \cdot k_{j'} / \sqrt{d})}\, v_j$$

This is ordinary scaled dot-product attention, except the softmax is taken only over the allowed neighborhood \(\mathcal{N}(i)\) instead of all \(n\) positions — equivalent to adding \(-\infty\) to masked-out logits before the softmax.

FLOP Counting

$$\text{FLOPs}_{\text{dense}} = O(n^2 d) \qquad \text{FLOPs}_{\text{sparse}} = O\!\left(n \cdot \max_i |\mathcal{N}(i)| \cdot d\right)$$

When \(|\mathcal{N}(i)| = k\) is constant (independent of \(n\)) — as with window + global + random patterns — sparse attention is \(O(nkd) = O(nd)\): linear in sequence length.

BigBird's Theoretical Guarantee (Proof Sketch)

Zaheer et al. show that BigBird's attention pattern, viewed as a graph where tokens are nodes and attention links are edges, matches full attention's expressive power under mild conditions: it is a universal approximator of continuous sequence-to-sequence functions and it is Turing-complete. The proof leans on the fact that a sparse graph combining global hubs with random edges has small diameter (a Watts–Strogatz small-world argument) — any pair of nodes can exchange information within \(O(\log n)\) attention layers.

⚠️ Common Misconception

Sparse attention does not mean the model "ignores" most of the sequence. Information about a masked-out token \(j\) can still reach query \(i\) indirectly, through multi-hop paths across layers (local → global → local) or random shortcuts. Sparsity changes the direct connectivity per layer, not what is ultimately reachable across a full network.

🎯 Decision Guide

Short sequences (≤1–2K tokens) → dense attention is simplest and cheaply fused (FlashAttention). Long documents needing a couple of task "anchor" tokens (QA, classification) → Longformer. Very long or highly structured sequences needing strong long-range reachability guarantees → BigBird. Purely local structure (audio, images, adjacent-pixel correlation) → sliding window / dilated attention alone.

When NOT to use sparse attention: if the sequence already fits comfortably in memory with dense attention (a few hundred to ~2K tokens) and latency isn't dominated by the attention matrix, the added implementation complexity and the risk of missing dependencies outside the sparse mask usually aren't worth it — dense attention (optionally FlashAttention-fused) is simpler and exact.

Code Trace — Building Sparse Masks From Scratch
▼
From-scratch: mask construction + masked softmax attention (NumPy)
import numpy as np
def sparse_mask(n, pattern, w=2, s=4, g=2, r=2, seed=0):
"""Build an (n, n) boolean mask: True = attention pair is computed."""
rng = np.random.default_rng(seed)
i = np.arange(n)[:, None] # query index, shape (n, 1)
j = np.arange(n)[None, :] # key index, shape (1, n)
local = np.abs(i - j) <= w # sliding window
strided = (np.abs(i - j) % s) == 0 # every s-th position
glob = (i < g) | (j < g) # global hub rows/cols
rand = np.zeros((n, n), dtype=bool)
for row in range(n): # r random keys per query
cols = rng.integers(0, n, size=r)
rand[row, cols] = True
return {
"dense": np.ones((n, n), dtype=bool),
"local": local,
"strided": strided,
"global": glob,
"longformer": local | glob,
"bigbird": local | glob | rand,
}[pattern]
def masked_attention(Q, K, V, mask):
"""Scaled dot-product attention, restricted to `mask` (n, n) bool."""
d = Q.shape[-1]
scores = Q @ K.T / np.sqrt(d) # (n, n) raw scores
scores = np.where(mask, scores, -np.inf) # mask out disallowed pairs
scores -= scores.max(axis=-1, keepdims=True) # numerical stability
weights = np.exp(scores)
weights /= weights.sum(axis=-1, keepdims=True) # softmax over N(i) only
return weights @ V # (n, d_v)
# FLOPs actually spent vs. dense baseline
mask = sparse_mask(1024, "bigbird", w=3, g=2, r=3)
savings = 1 - mask.sum() / mask.size
print(f"{savings:.1%} of attention pairs skipped") # ~98-99% at n=1024
Production usage: Longformer / BigBird via HuggingFace
from transformers import LongformerModel, LongformerTokenizer
tok = LongformerTokenizer.from_pretrained("allenai/longformer-base-4096")
model = LongformerModel.from_pretrained("allenai/longformer-base-4096")
enc = tok("a long document...", return_tensors="pt")
global_attention_mask = torch.zeros_like(enc["input_ids"])
global_attention_mask[:, 0] = 1 # [CLS] gets global attention
out = model(**enc, global_attention_mask=global_attention_mask)
