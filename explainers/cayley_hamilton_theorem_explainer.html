Cayley-Hamilton Theorem

Every matrix satisfies its own characteristic polynomial — and this unlocks inverses and matrix powers
Intermediate Linear Algebra Special Matrices O(n²) applications
1
Understanding the Theorem
▼

What is it? Every square matrix has a special polynomial called its "characteristic polynomial." The Cayley-Hamilton theorem says: if you plug the matrix itself into that polynomial (instead of a number), you always get the zero matrix. A matrix is, in a sense, a root of its own polynomial.

Analogy: Imagine you measure a person's personality and build a personal "quirk equation" from those measurements. The Cayley-Hamilton theorem says: if you feed that person back into their own quirk equation, everything cancels out to zero. Every entity satisfies its own self-describing equation.

Practical payoff: Once you know \(p(A) = 0\), you can express \(A^{-1}\) and high powers \(A^n\) as linear combinations of lower powers — avoiding expensive matrix multiplications.

💡 If you remember one thing

For an \(n\times n\) matrix \(A\) with characteristic polynomial \(p(\lambda) = \det(A - \lambda I)\), substituting \(\lambda = A\) gives the zero matrix: \(p(A) = \mathbf{0}\). This lets you reduce \(A^k\) to a degree-\((n-1)\) polynomial in \(A\) for any \(k \geq n\).

How It Works Internally
▼

Step 1 — Build the Characteristic Polynomial

For \(A = \begin{bmatrix} 3 & 1 \\ 2 & 4 \end{bmatrix}\), form \(A - \lambda I = \begin{bmatrix} 3-\lambda & 1 \\ 2 & 4-\lambda \end{bmatrix}\). The characteristic polynomial is:

$$p(\lambda) = \det(A - \lambda I) = (3-\lambda)(4-\lambda) - 2 = \lambda^2 - 7\lambda + 10$$

The roots of \(p\) are the eigenvalues: \(\lambda_1 = 2,\; \lambda_2 = 5\). Check: \(p(2) = 4 - 14 + 10 = 0\) ✓, \(p(5) = 25 - 35 + 10 = 0\) ✓.

Step 2 — Substitute the Matrix

Replace \(\lambda\) with \(A\) (and the constant term multiplies \(I\)):

$$p(A) = A^2 - 7A + 10I = \begin{bmatrix}11&7\\14&18\end{bmatrix} - \begin{bmatrix}21&7\\14&28\end{bmatrix} + \begin{bmatrix}10&0\\0&10\end{bmatrix} = \begin{bmatrix}0&0\\0&0\end{bmatrix}$$

Step 3 — Extract the Inverse

From \(A^2 - 7A + 10I = 0\), multiply both sides by \(A^{-1}\):

$$A - 7I + 10A^{-1} = 0 \implies A^{-1} = \frac{1}{10}(7I - A) = \begin{bmatrix}0.4 & -0.1\\ -0.2 & 0.3\end{bmatrix}$$

Step 4 — Reduce High Powers

Since \(A^2 = 7A - 10I\), every higher power reduces by one degree. For \(A^3\):

$$A^3 = A \cdot A^2 = A(7A - 10I) = 7A^2 - 10A = 7(7A-10I) - 10A = 39A - 70I$$
🔑 Key Property

For an \(n \times n\) matrix, any polynomial in \(A\) of degree \(\geq n\) can be reduced to a polynomial of degree at most \(n-1\). This is the minimal polynomial principle underlying Cayley-Hamilton.

3
Why It Works — Proof Sketch
▼

Common Misconception First

⚠️ The Most Common Wrong "Proof"

People write \(p(\lambda) = \det(A - \lambda I)\), then substitute \(\lambda = A\) to get \(\det(A - A) = \det(0) = 0\). This is wrong: \(\lambda\) is a scalar in \(\det(A - \lambda I)\), but \(A\) is a matrix. The determinant of a matrix of matrices is not defined this way — the scalar \(0\) and the zero matrix \(\mathbf{0}\) are different objects.

The Adjugate Proof

Write \(p(\lambda) = \det(\lambda I - A) = \lambda^n - c_{n-1}\lambda^{n-1} - \cdots - c_0\). The key identity is:

$$(\lambda I - A) \cdot \operatorname{adj}(\lambda I - A) = \det(\lambda I - A) \cdot I = p(\lambda) I$$

The adjugate \(\operatorname{adj}(\lambda I - A)\) is a matrix polynomial in \(\lambda\) of degree \(n-1\): write it as \(\lambda^{n-1}B_{n-1} + \cdots + B_0\). Expanding both sides and equating coefficients of \(\lambda^k\) gives \(n+1\) matrix equations. Multiplying each equation by \(A^k\) and summing telescopes to yield \(p(A) = \mathbf{0}\).

Inverse Formula (General \(n\times n\))

From \(p(A) = A^n - c_{n-1}A^{n-1} - \cdots - c_1 A - c_0 I = 0\), if \(c_0 = \det(A) \neq 0\):

$$A^{-1} = \frac{1}{c_0}\bigl(A^{n-1} - c_{n-1}A^{n-2} - \cdots - c_1 I\bigr)$$

For the 2×2 case with \(p(\lambda) = \lambda^2 - \operatorname{tr}(A)\lambda + \det(A)\):

$$A^{-1} = \frac{1}{\det(A)}\bigl(\operatorname{tr}(A)\cdot I - A\bigr)$$

This is exactly the classical formula \(A^{-1} = \frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}\) rewritten.

Applications & Key Takeaways
▼

Computing matrix inverses analytically — Without LU decomposition or Gaussian elimination; express \(A^{-1}\) as a polynomial in \(A\).

Reducing matrix powers — Compute \(A^{100}\) modulo the characteristic polynomial: since \(A^2 \equiv 7A - 10I\), any power reduces to \(\alpha A + \beta I\) (for 2×2). This is far cheaper than repeated matrix multiplication.

Cayley-Hamilton in control theory — The minimal polynomial of the state-transition matrix determines system stability. Cayley-Hamilton guarantees \(A^n\) is a linear combo of lower powers, so you only need \(n\) initial steps to predict all future states.

In ML — Kernel matrix operations, graph neural network propagation (\(k\)-hop = polynomial in adjacency), PCA via covariance matrix, and numerical stability analysis of gradient-descent iteration matrices all invoke Cayley-Hamilton implicitly.

💡 2×2 Summary

For \(A = \begin{bmatrix}a&b\\c&d\end{bmatrix}\): char poly is \(\lambda^2 - (a+d)\lambda + (ad-bc)\), Cayley-Hamilton gives \(A^2 = (a+d)A - (ad-bc)I\), and \(A^{-1} = \frac{1}{ad-bc}\bigl((a+d)I - A\bigr)\). Memorise this — it covers 90% of exam questions.

Code Trace (NumPy)
▼
import numpy as np
# Our matrix
A = np.array([[3., 1.],
[2., 4.]])
# Characteristic polynomial coefficients
tr = np.trace(A) # 7.0 (sum of diagonal)
det = np.linalg.det(A) # 10.0 (ad - bc)
# p(lambda) = lambda^2 - tr*lambda + det
# Verify Cayley-Hamilton: p(A) == 0
A2 = A @ A # [[11,7],[14,18]]
pA = A2 - tr*A + det*np.eye(2) # should be 0
print("p(A) =", np.round(pA, 10)) # [[0,0],[0,0]] ✓
# Inverse via Cayley-Hamilton
A_inv_ch = (1/det) * (tr*np.eye(2) - A) # (7I - A) / 10
print(A_inv_ch) # [[ 0.4 -0.1][-0.2 0.3]]
# A^3 via Cayley-Hamilton (no matrix multiply!)
# A^2 = 7A - 10I => A^3 = 7A^2 - 10A = 39A - 70I
A3_ch = 39*A - 70*np.eye(2) # CH formula
A3_np = np.linalg.matrix_power(A, 3) # reference
print(np.allclose(A3_ch, A3_np)) # True ✓
