1
Understanding Non-informative Priors
▼

What is a prior? In Bayesian inference, before we see any data, we encode our existing beliefs about a parameter \(\theta\) as a prior distribution \(\pi(\theta)\). After observing data, we update to a posterior using Bayes' theorem. The prior shape influences the result — especially with little data.

The problem with "I have no idea": Sometimes we genuinely want the data to speak for itself, with minimal influence from prior assumptions. The natural instinct is to use a flat (uniform) prior: \(\pi(\theta) \propto 1\). But this turns out to be deeply problematic — a prior that is flat in \(\theta\) is NOT flat in any transformed version of \(\theta\). What looks "uninformative" in one parameterization is strongly informative in another.

Analogy: Suppose you say "I'm equally likely to believe the coin's bias \(p\) is anywhere in \([0,1]\)." That's uniform in \(p\). But if instead you parameterize by \(\phi = \log(p/(1-p))\) (log-odds), your "flat" prior on \(p\) becomes a wildly curved, informative prior on \(\phi\). The prior is only flat in one language — reality doesn't care which language you pick.

💡 If you remember one thing

The Jeffreys prior \(\pi(\theta) \propto \sqrt{\mathcal{I}(\theta)}\) — where \(\mathcal{I}(\theta)\) is the Fisher information — is the unique prior that is invariant under reparameterization. For a Bernoulli(\(p\)) likelihood it equals Beta(1/2, 1/2), which is not flat: it concentrates mass near 0 and 1, correctly reflecting that extreme probabilities are more "learnable."

2
How Jeffreys Prior Works
▼

Fisher Information — measuring what data can tell you

The Fisher information \(\mathcal{I}(\theta)\) quantifies how much information a single observation from a likelihood \(p(x|\theta)\) carries about \(\theta\). Formally:

$$\mathcal{I}(\theta) = \mathbb{E}\!\left[\left(\frac{\partial \log p(X|\theta)}{\partial \theta}\right)^2\right] = -\mathbb{E}\!\left[\frac{\partial^2 \log p(X|\theta)}{\partial \theta^2}\right]$$

A high \(\mathcal{I}(\theta)\) means data is very sensitive to small changes in \(\theta\) at that value — the parameter is easy to estimate there. A low value means data can barely distinguish nearby \(\theta\) values.

The Jeffreys prior formula

$$\pi_J(\theta) \propto \sqrt{\mathcal{I}(\theta)}$$

This places more prior mass where Fisher information is high — near parameter values that are easily distinguishable — and less mass where information is low. The intuition: the prior is proportional to the local "resolution" of the parameter.

Key example: Bernoulli likelihood

For \(X \sim \text{Bernoulli}(p)\), \(\log p(X|p) = X \log p + (1-X)\log(1-p)\). The score is \(\frac{\partial}{\partial p}\log p = \frac{X}{p} - \frac{1-X}{1-p}\). Taking expectation of the square:

$$\mathcal{I}(p) = \frac{\mathbb{E}[X]}{p^2} + \frac{1-\mathbb{E}[X]}{(1-p)^2} = \frac{1}{p(1-p)}$$

Therefore the Jeffreys prior is:

$$\pi_J(p) \propto \sqrt{\frac{1}{p(1-p)}} = p^{-1/2}(1-p)^{-1/2} = \text{Beta}\!\left(\tfrac{1}{2}, \tfrac{1}{2}\right)$$
🔑 Reparameterization Invariance

If \(\phi = g(\theta)\) is any smooth 1-1 transformation, and you derive the Jeffreys prior directly for \(\phi\), you get exactly the same result as transforming \(\pi_J(\theta)\) via the Jacobian. No other prior family has this property. This is exactly because Fisher information transforms as \(\mathcal{I}_\phi(\phi) = \mathcal{I}_\theta(\theta)/|g'(\theta)|^2\), so \(\sqrt{\mathcal{I}_\phi} \, |d\phi| = \sqrt{\mathcal{I}_\theta} \, |d\theta|\).

Why flat ≠ uninformative

Consider \(\phi = \arcsin(\sqrt{p})\) (the variance-stabilizing transform for the Bernoulli). A flat prior on \(p\) — \(\text{Beta}(1,1)\) — transforms to density \(\propto |\sin(2\phi)|\) on \(\phi\), which is strongly non-uniform. The Jeffreys prior on \(p = \text{Beta}(1/2,1/2)\) transforms to exactly a uniform density on \(\phi \in [0, \pi/2]\). So Jeffreys is flat in the "natural" (information-geometric) parameterization.

3
Why It Works — The Math
▼

Proof of reparameterization invariance

Let \(\phi = g(\theta)\) with \(g\) invertible and smooth. The Fisher information in terms of \(\phi\) is:

$$\mathcal{I}_\phi(\phi) = \mathcal{I}_\theta\!\left(g^{-1}(\phi)\right) \cdot \left(\frac{d\theta}{d\phi}\right)^2$$

The Jeffreys prior for \(\phi\) is \(\pi_J^\phi(\phi) \propto \sqrt{\mathcal{I}_\phi(\phi)}\). The change-of-variable formula says the induced prior on \(\phi\) from \(\pi_J^\theta(\theta) \propto \sqrt{\mathcal{I}_\theta(\theta)}\) is:

$$\pi^\phi(\phi) = \pi_J^\theta(g^{-1}(\phi)) \cdot \left|\frac{d\theta}{d\phi}\right| \propto \sqrt{\mathcal{I}_\theta(\theta)} \cdot \left|\frac{d\theta}{d\phi}\right| = \sqrt{\mathcal{I}_\theta(\theta) \cdot \left(\frac{d\theta}{d\phi}\right)^2} = \sqrt{\mathcal{I}_\phi(\phi)}$$

This equals \(\pi_J^\phi(\phi)\). The Jeffreys prior is the unique prior (up to normalization) satisfying this. It corresponds to the Riemannian volume element of the Fisher information metric on parameter space.

⚠️ Jeffreys Prior is Often Improper

Many Jeffreys priors do not integrate to a finite value (they are improper). For example, \(\pi(\mu) \propto 1\) on \(\mathbb{R}\) cannot be normalized. This is mathematically fine as long as the posterior is proper (i.e., the likelihood is integrable against the prior). Always verify posterior propriety before using an improper Jeffreys prior.

Weakly informative priors

In practice, fully non-informative priors can cause problems: they may lead to improper posteriors, or to posteriors dominated by pathological likelihood regions. Weakly informative priors — advocated by Gelman, Simpson, and others — are proper priors that incorporate only weak, plausible constraints (e.g., that a probability is not 0.9999 for a rare event). The Half-Normal or \(\text{Normal}^+(0, 1)\) for scale parameters is a canonical example.

💡 Practical Recommendation

For low-dimensional problems, the Jeffreys prior is an excellent default. For hierarchical models or high-dimensional settings, prefer weakly informative priors (e.g., \(\text{Normal}^+(0, \sigma_{prior})\) for scale) that keep the posterior well-behaved. Never use a flat prior on an unbounded parameter without checking that the posterior is proper.

Code — From Scratch & Production

From scratch: Jeffreys prior & posterior for Bernoulli

import numpy as np
from scipy import stats

# ── Fisher information for Bernoulli(p) ──
# I(p) = 1 / [p*(1-p)]
def bernoulli_fisher(p):
    return 1.0 / (p * (1.0 - p))

# ── Jeffreys prior = Beta(1/2, 1/2) ──
jeffreys = stats.beta(0.5, 0.5)

# ── Update: posterior with Jeffreys prior + n Bernoulli observations ──
# Prior: Beta(alpha0=0.5, beta0=0.5)
# Likelihood: Binomial(n, p)  =>  n_heads successes out of n
# Posterior: Beta(alpha0 + n_heads, beta0 + n - n_heads)
def bernoulli_posterior(n_heads, n, a0=0.5, b0=0.5):
    """Returns (alpha_post, beta_post) for Beta posterior."""
    return a0 + n_heads, b0 + (n - n_heads)

# Example: 7 heads out of 10 flips
n_heads, n = 7, 10
a_post, b_post = bernoulli_posterior(n_heads, n)
posterior = stats.beta(a_post, b_post)
print(f"Posterior: Beta({a_post}, {b_post})")
print(f"  MAP estimate: {(a_post-1)/(a_post+b_post-2):.4f}")
print(f"  Mean: {posterior.mean():.4f}  (= {a_post}/{a_post+b_post})")
print(f"  95% CI: [{posterior.ppf(0.025):.4f}, {posterior.ppf(0.975):.4f}]")

# Compare with flat prior Beta(1,1)
a_flat, b_flat = 1 + n_heads, 1 + (n - n_heads)
flat_post = stats.beta(a_flat, b_flat)
print(f"\nFlat prior posterior: Beta({a_flat},{b_flat})")
print(f"  Mean: {flat_post.mean():.4f}")

# ── Reparameterization invariance check ──
# Transform p -> phi = arcsin(sqrt(p))
# Under this map, Jeffreys (Beta(1/2,1/2)) on p => Uniform on phi in [0, pi/2]
p_vals = np.linspace(0.01, 0.99, 1000)
phi_vals = np.arcsin(np.sqrt(p_vals))
jacobian = np.abs(1.0 / (2 * np.sqrt(p_vals * (1 - p_vals))))
jeffreys_pdf_p = jeffreys.pdf(p_vals)
jeffreys_pdf_phi = jeffreys_pdf_p / jacobian  # change of variables

# Should be ~constant = 2/pi
print(f"\nJeffreys prior in phi: mean={jeffreys_pdf_phi.mean():.4f}, "
      f"std={jeffreys_pdf_phi.std():.6f}  (2/pi={2/np.pi:.4f})")

Production: PyMC with weakly informative prior

import pymc as pm
import numpy as np

# 10 coin flips, 7 heads
data = np.array([1,1,0,1,1,0,1,0,1,1])

with pm.Model() as coin_model:
    # Jeffreys prior for Bernoulli parameter
    p = pm.Beta("p", alpha=0.5, beta=0.5)  # Beta(1/2, 1/2) = Jeffreys

    # Likelihood
    obs = pm.Bernoulli("obs", p=p, observed=data)

    # Sample posterior
    trace = pm.sample(2000, tune=1000, return_inferencedata=True, progressbar=False)

import arviz as az
print(az.summary(trace, var_names=["p"]))
