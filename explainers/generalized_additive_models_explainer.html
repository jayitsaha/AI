1
Understanding GAMs
▼

What is it? A Generalized Additive Model (GAM) extends linear regression by replacing each linear term \(\beta_j x_j\) with an arbitrary smooth function \(f_j(x_j)\). The model remains additive — the prediction is a sum of independent per-feature contributions — but each contribution can curve, wiggle, and saturate in any smooth shape the data demands.

Analogy: Think of tuning a stereo equalizer. A linear model is like a single volume knob — one dial controls everything proportionally. A GAM gives you a separate equalizer band for each frequency: each feature gets its own flexible "shape dial" that can boost, cut, or leave unchanged in whatever pattern fits the data — while the final sound is still the sum of all bands.

The core equation:

$$g\!\left(\mathbb{E}[y]\right) = \beta_0 + \sum_{j=1}^{p} f_j(x_j)$$

where \(g(\cdot)\) is a link function (identity for regression, logit for classification), \(\beta_0\) is an intercept, and each \(f_j\) is a smooth, data-driven shape function estimated from the data — typically a spline or low-rank smoother.

💡 If you remember one thing

GAMs trade the linear constraint for smooth nonlinearity while keeping additivity — each feature's effect is visible in isolation as a curve \(f_j(x_j)\), making them as interpretable as linear models yet far more flexible. This is the "sweet spot" between OLS and black-box trees.

2
How GAMs Work Internally
▼

Splines as Shape Functions

Each \(f_j\) is typically represented as a penalized regression spline. A cubic spline with \(K\) knots \(\kappa_1 < \cdots < \kappa_K\) spans a basis of cubic polynomials that join smoothly at the knots. Writing \(f_j(x) = \sum_k b_k(x)\,\gamma_k\) where \(b_k\) are spline basis functions, the fit becomes a standard linear regression in this expanded basis — but with a roughness penalty.

The Penalized Least Squares Objective

For Gaussian response (identity link), GAMs minimize:

$$\underset{\{f_j\}}{\operatorname{minimize}}\;\sum_{i=1}^{n}\!\left(y_i - \beta_0 - \sum_{j=1}^{p} f_j(x_{ij})\right)^{\!2} + \sum_{j=1}^{p} \lambda_j \int \!\left[f_j''(x)\right]^2 dx$$

The \(\lambda_j \int [f_j'']^2\) term penalizes curvature: \(\lambda_j = 0\) allows any shape (interpolation); \(\lambda_j \to \infty\) forces \(f_j\) to be perfectly linear. The smoothing parameters \(\lambda_j\) are tuned by cross-validation or REML (restricted maximum likelihood).

Backfitting Algorithm

The classical fitting algorithm iterates per-feature smoothers until convergence:

  1. Initialize all \(f_j \equiv 0\), set \(\hat{\beta}_0 = \bar{y}\).
  2. For each feature \(j = 1, \ldots, p\):
  3. Compute partial residuals: \(r_{ij} = y_i - \hat{\beta}_0 - \sum_{k \neq j} \hat{f}_k(x_{ik})\)
  4. Update \(\hat{f}_j \leftarrow \operatorname{Smooth}(x_j, r_j)\) and center: \(\hat{f}_j \leftarrow \hat{f}_j - n^{-1}\!\sum_i \hat{f}_j(x_{ij})\)
  5. Repeat until \(\|\hat{f}_j^{\text{new}} - \hat{f}_j^{\text{old}}\|_2 < \varepsilon\) for all \(j\).

Centering at each step is critical: GAMs are only identifiable if each \(f_j\) sums to zero over the data — the intercept absorbs the mean, and partial effects are then interpretable deviations from it.

🔑 Key Property — Identifiability Constraint

Each smooth is centered: \(\sum_{i=1}^{n} f_j(x_{ij}) = 0\). This ensures uniqueness. Without centering, you could add a constant to \(f_1\) and subtract it from \(f_2\) and get the same predictions — infinitely many solutions.

Design Decision: Why Not a Tree or Neural Net?

GAMs maintain main-effects-only additivity deliberately. Trees capture interaction effects by design (splits on feature combinations), making them harder to interpret. GAMs allow interaction terms to be added explicitly (e.g., a tensor-product smooth \(f_{12}(x_1, x_2)\)) only when needed. Modern GAMs (mgcv, PyGAM) support both, keeping the user in control of model complexity.

3
Why It Works — The Math
▼

Spline Basis Representation

Let \(\mathbf{B}_j \in \mathbb{R}^{n \times K_j}\) be the spline design matrix for feature \(j\), where entry \(B_{ij,k} = b_k(x_{ij})\). Then \(f_j(\mathbf{x}_j) = \mathbf{B}_j \boldsymbol{\gamma}_j\). The full GAM in matrix form is:

$$\mathbf{y} = \mathbf{1}\beta_0 + \sum_{j=1}^{p} \mathbf{B}_j \boldsymbol{\gamma}_j + \boldsymbol{\varepsilon}$$

The penalized objective becomes (stacking all bases into \(\tilde{\mathbf{B}} = [\mathbf{B}_1 | \cdots | \mathbf{B}_p]\)):

$$\underset{\boldsymbol{\gamma}}{\operatorname{minimize}}\;\|\mathbf{y} - \tilde{\mathbf{B}}\boldsymbol{\gamma}\|_2^2 + \boldsymbol{\gamma}^\top \mathbf{S}_\lambda \boldsymbol{\gamma}$$

where \(\mathbf{S}_\lambda = \bigoplus_{j} \lambda_j \mathbf{S}_j\) is a block-diagonal penalty matrix. \(\mathbf{S}_j = \int \mathbf{b}_j''(x)\mathbf{b}_j''(x)^\top dx\) is the penalty matrix for smoother \(j\) — precomputable analytically for standard B-spline and thin-plate spline bases.

Closed-Form Solution

Setting the gradient to zero gives a penalized normal equation:

$$\hat{\boldsymbol{\gamma}} = \left(\tilde{\mathbf{B}}^\top\tilde{\mathbf{B}} + \mathbf{S}_\lambda\right)^{-1} \tilde{\mathbf{B}}^\top \mathbf{y}$$

This is ridge regression on the spline basis — the penalty \(\mathbf{S}_\lambda\) shrinks the curvature coefficients toward zero. The effective degrees of freedom (EDF) of smoother \(j\) is \(\operatorname{tr}(\mathbf{H}_j)\) where \(\mathbf{H} = \tilde{\mathbf{B}}(\tilde{\mathbf{B}}^\top\tilde{\mathbf{B}} + \mathbf{S}_\lambda)^{-1}\tilde{\mathbf{B}}^\top\) is the hat matrix.

Selecting \(\lambda\): REML Criterion

The smoothing parameters are chosen by maximizing the restricted marginal log-likelihood (treating \(\boldsymbol{\gamma}\) as random effects with prior \(\boldsymbol{\gamma} \sim \mathcal{N}(\mathbf{0}, \sigma^2 \lambda^{-1}\mathbf{S}^{+})\)):

$$\ell_{\text{REML}}(\lambda, \sigma^2) = -\frac{1}{2}\left[\frac{\|\mathbf{y} - \hat{\mathbf{y}}\|^2}{\sigma^2} + \log|\tilde{\mathbf{B}}^\top\tilde{\mathbf{B}} + \mathbf{S}_\lambda| - \log|\mathbf{S}_\lambda^+| + (n-p)\log\sigma^2\right]$$

REML is preferred over GCV in practice because it is less susceptible to "smoothing parameter underestimation" — it gives wider confidence intervals and better-calibrated uncertainty.

⚠️ Common Pitfall

With only one \(\lambda\) per smoother (isotropic penalty), GAMs cannot simultaneously model sharp transitions and slow trends in the same feature. Adaptive smoothers (e.g., adaptive thin-plate splines) use a spatially varying penalty \(\lambda(x)\) to handle this, at the cost of additional complexity.

5
Key Takeaways
▼

When to use GAMs:

  • Relationships are nonlinear but interpretability is required (clinical risk models, policy analysis)
  • You want to visually audit each feature's effect — the partial effect plots are self-documenting
  • Data volume is moderate (thousands to low millions rows) — spline fitting is O(nK²) per smoother
  • Interaction effects are few and known in advance — add tensor-product smooths selectively

When NOT to use GAMs:

  • High-dimensional input (\(p \gg 100\)) — curse of dimensionality if interactions are implicit
  • Strong interaction structure dominates — tree ensembles (GBDT) will outperform
  • Raw prediction accuracy on complex perception tasks (image, text) — deep nets are superior
💡 The Spectrum

Linear Regression (\(f_j = \beta_j x_j\), EDF=1 each) ⊂ GAM (EDF tuned per smoother) ⊂ GAMP (GAM + pairwise interactions) ⊂ GBDT / Neural Nets (all interactions implicit). Each step buys predictive power at the cost of interpretability.

Code Trace — GAM from Scratch
▼
import numpy as np
from scipy.linalg import solve
# 1. Build cubic spline basis for one feature
def cubic_spline_basis(x, knots):
n, K = len(x), len(knots)
B = np.column_stack([np.ones(n), x, x**2, x**3]
+ [np.maximum(x - k, 0)**3 for k in knots])
return B # shape (n, 4+K)
# 2. Penalty matrix (2nd deriv integral for truncated power basis)
def penalty_matrix(knots):
K = len(knots)
S = np.zeros((4+K, 4+K)) # penalize spline coefficients only
for r in range(K):
for s in range(K):
kmax = max(knots[r], knots[s])
S[4+r, 4+s] = 36*(knots[-1] - kmax) # simplified
return S
# 3. Backfitting: iterate penalized smoothers
def backfitting(X_features, y, lam_list, knots_list, tol=1e-6, max_iter=50):
n, p = X_features.shape
beta0 = y.mean() # intercept = global mean
f_hats = [np.zeros(n)] * p # initialize all smooths to 0
for iteration in range(max_iter):
f_old = [fj.copy() for fj in f_hats]
for j in range(p):
# Partial residuals: all contributions except f_j
r = y - beta0 - sum(f_hats[k] for k in range(p) if k != j)
# Penalized spline fit to partial residuals
B = cubic_spline_basis(X_features[:, j], knots_list[j])
S = penalty_matrix(knots_list[j])
gamma = solve(B.T @ B + lam_list[j]*S, B.T @ r)
f_hats[j] = B @ gamma
f_hats[j] -= f_hats[j].mean() # center!
# Check convergence
if max(np.max(np.abs(f_hats[j]-f_old[j])) for j in range(p)) < tol:
break
return beta0, f_hats
