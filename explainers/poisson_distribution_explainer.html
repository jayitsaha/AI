Understanding the Poisson Distribution
▼

What is it? The Poisson distribution answers the question: "If rare events happen at a known average rate, what is the probability of seeing exactly \(k\) events in a fixed window of time or space?" It models counts of independent occurrences — emails per hour, mutations per chromosome, earthquakes per year.

Analogy: Imagine a very busy intersection where, on average, 3 cars run a red light per hour. Any individual car almost never runs it (low probability), but there are hundreds of cars (large \(n\)). The Poisson distribution tells you: on any given hour, what's the chance you see exactly 0, 1, 2, 5, or 10 violations? The rate \(\lambda = 3\) is what you know; the count \(k\) is the random variable.

If you remember one thing

The Poisson PMF is \(P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}\), with \(\mathbb{E}[X] = \operatorname{Var}(X) = \lambda\). The single parameter \(\lambda\) (the rate) completely describes the distribution — and equals both the mean and the variance.

The Three Conditions (Poisson Postulates)

  • Independence: Events in non-overlapping intervals are independent
  • Stationarity: The average rate \(\lambda\) is constant (proportional to interval length)
  • Non-simultaneity: The probability of two events in the same infinitesimal interval is negligible (rare events)

When these hold, the count of events follows \(\text{Poisson}(\lambda)\). The conditions are violated — and the Poisson fails — when events cluster (e.g., earthquakes triggering aftershocks) or when the rate itself varies.

How It Works — Internal Mechanics
▼

The Binomial → Poisson Limit (The Real Derivation)

Start with \(\text{Binomial}(n, p)\): flip \(n\) coins, each with probability \(p\) of success. If we hold the expected count \(\lambda = np\) fixed while letting \(n \to \infty\) (so \(p = \lambda/n \to 0\)), the binomial PMF converges to the Poisson.

Substituting \(p = \lambda/n\) into the binomial:

$$P(X=k) = \binom{n}{k}\left(\frac{\lambda}{n}\right)^k\left(1 - \frac{\lambda}{n}\right)^{n-k}$$

As \(n \to \infty\):

  • \(\binom{n}{k}/n^k \to 1/k!\) (the combinatorial factor reduces to factorial)
  • \((1 - \lambda/n)^n \to e^{-\lambda}\) (the fundamental definition of \(e\))
  • \((1 - \lambda/n)^{-k} \to 1\) (negligible correction)

Result:

$$P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$$
Key Insight — The Rare Events Intuition

The Poisson is the limit of many trials, each with tiny probability — but where the expected total stays fixed at \(\lambda\). Real-world examples: radioactive decay (billions of atoms, each with tiny decay probability), call center arrivals, web server requests, gene mutations. All share the structure \(n \gg 1, p \ll 1, np = \lambda\).

The PMF at a Glance

For \(\lambda = 3\): \(P(0) \approx 0.050\), \(P(1) \approx 0.149\), \(P(2) \approx 0.224\), \(P(3) \approx 0.224\) (mode), \(P(4) \approx 0.168\), \(P(5) \approx 0.101\). The distribution is right-skewed for small \(\lambda\), becoming more symmetric as \(\lambda\) grows. The mode is at \(\lfloor \lambda \rfloor\) (and also \(\lceil \lambda \rceil - 1\) when \(\lambda\) is an integer).

Common Misconception

The Poisson has infinite support: \(k \in \{0, 1, 2, \ldots\}\). The probability that \(k \geq 20\) for \(\lambda = 3\) is less than \(10^{-7}\), but it is strictly positive. In ML count regression, failing to respect this can lead to using Gaussian approximations that assign probability to negative counts — wrong and dangerous.

Why It Works — The Math
▼

Normalisation: PMF Sums to 1

Verify using the Taylor series for \(e^\lambda\):

$$\sum_{k=0}^{\infty} P(X=k) = \sum_{k=0}^{\infty} \frac{\lambda^k e^{-\lambda}}{k!} = e^{-\lambda} \sum_{k=0}^{\infty} \frac{\lambda^k}{k!} = e^{-\lambda} \cdot e^{\lambda} = 1$$

Mean = λ (Derivation)

$$\mathbb{E}[X] = \sum_{k=0}^{\infty} k \cdot \frac{\lambda^k e^{-\lambda}}{k!} = \lambda e^{-\lambda} \sum_{k=1}^{\infty} \frac{\lambda^{k-1}}{(k-1)!} = \lambda e^{-\lambda} \cdot e^{\lambda} = \lambda$$

Variance = λ (Derivation via Second Moment)

First compute \(\mathbb{E}[X^2] = \mathbb{E}[X(X-1)] + \mathbb{E}[X]\):

$$\mathbb{E}[X(X-1)] = \sum_{k=2}^{\infty} k(k-1) \frac{\lambda^k e^{-\lambda}}{k!} = \lambda^2 e^{-\lambda} \sum_{k=2}^{\infty} \frac{\lambda^{k-2}}{(k-2)!} = \lambda^2$$

Therefore \(\operatorname{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2 = (\lambda^2 + \lambda) - \lambda^2 = \lambda\).

Moment Generating Function

The MGF is \(M_X(t) = e^{\lambda(e^t - 1)}\). This is used to prove the additive property: if \(X \sim \text{Poisson}(\lambda_1)\) and \(Y \sim \text{Poisson}(\lambda_2)\) are independent, then \(X + Y \sim \text{Poisson}(\lambda_1 + \lambda_2)\). Proof: \(M_{X+Y}(t) = M_X(t) \cdot M_Y(t) = e^{(\lambda_1+\lambda_2)(e^t - 1)}\).

Connection to Poisson Process & Exponential Inter-arrivals

If events arrive as a Poisson process with rate \(\mu\) per unit time, then: (1) the count in interval \([0, t]\) is \(\text{Poisson}(\mu t)\); and (2) the waiting time between events is \(\text{Exponential}(\mu)\). These are two sides of the same coin — the Poisson count and exponential inter-arrival times are linked through the continuous-time Poisson process.

Connection to Poisson Regression

In Poisson GLMs for count data, the log-link ensures positivity: \(\log(\mathbb{E}[Y]) = X\beta\), so \(\mathbb{E}[Y] = e^{X\beta}\). The log-likelihood per observation is \(\ell_i = k_i \log(\mu_i) - \mu_i - \log(k_i!)\) where \(\mu_i = e^{X_i\beta}\). The mean = variance constraint (\(\lambda\) determines both) is a strong assumption — real count data often show overdispersion (\(\text{Var} > \text{Mean}\)), motivating the Negative Binomial regression.

Key Takeaways & Comparisons
▼

When to use Poisson:

  • Count data in a fixed interval (time, area, volume) with known average rate
  • Events are independent and rare relative to opportunities
  • Examples: arrivals, defects, mutations, photon counts, word frequencies in NLP

Decision Rule

Use Poisson for count data when mean ≈ variance. Use Negative Binomial when variance > mean (overdispersion — very common in NLP word counts, biological data). Use Binomial when you have a fixed number of trials. If in doubt, test the dispersion statistic \(D = (n-1)s^2/\bar{x}\) and compare to a \(\chi^2\) distribution.

import numpy as np
from scipy import stats
import math
# --- From scratch: Poisson PMF ---
def poisson_pmf(k, lam):
return (lam**k * math.exp(-lam)) / math.factorial(k)
# Verify: P(k=3; lambda=3)
p = poisson_pmf(3, 3.0) # 3^3 * e^{-3} / 3! = 27 * 0.0498 / 6
print(p) # 0.22404 ✓
# --- Scipy production usage ---
dist = stats.poisson(mu=3.0)
dist.pmf(3) # 0.22404
dist.cdf(5) # P(X <= 5) = 0.91608
dist.mean() # 3.0 (= lambda)
dist.var() # 3.0 (= lambda)
dist.rvs(size=1000) # 1000 random samples
