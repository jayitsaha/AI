Parameter Learning: MLE & MAP

Estimating model parameters from data using Maximum Likelihood and Maximum A Posteriori
Foundational Stats Machine Learning O(n) for Bernoulli
1
Understanding Parameter Learning
▼

What is it? In machine learning and statistics, we often assume our data comes from a specific type of probability distribution (e.g., Gaussian, Bernoulli, Poisson), but we don't know the exact values of its parameters (e.g., mean and variance for Gaussian, or probability of success for Bernoulli). Parameter learning is the process of using observed data to estimate these unknown parameters.

Analogy: Imagine you've found a coin and want to know if it's fair. You flip it 100 times and get 60 heads. The "parameter" you're interested in is \(p\), the probability of getting heads. "Parameter learning" is how you use those 100 flips to guess the value of \(p\). Two popular methods for doing this are Maximum Likelihood Estimation (MLE) and Maximum A Posteriori (MAP) estimation.

💡 If you remember one thing

Both MLE and MAP aim to find the parameter values that best explain the observed data. MLE focuses solely on the data's likelihood, while MAP combines the data's likelihood with a "prior belief" about what the parameters should be.

2
How MLE & MAP Work Internally
▼

The Statistical Model and Data

We start with a probabilistic model, say a Bernoulli distribution for coin flips, defined by a parameter \(p\) (probability of heads). Our observed data \(D = \{x_1, x_2, \dots, x_N\}\) are the outcomes of \(N\) flips (e.g., H, T, H, H, ...).

Maximum Likelihood Estimation (MLE)

MLE asks: "Given the observed data \(D\), what parameter value \(\theta\) (e.g., \(p\)) makes this data most probable?" It seeks to maximize the likelihood function \(L(\theta; D) = P(D|\theta)\). This function quantifies how well a specific parameter value \(\theta\) explains the observed data. Often, we maximize the log-likelihood \(\log P(D|\theta)\) instead, as it simplifies calculations (products become sums) and doesn't change the location of the maximum.

🔑 Key Idea: Data-Driven Only

MLE is purely data-driven. It finds the parameter that makes the observed data as likely as possible, without incorporating any prior beliefs or external information about the parameter itself.

Maximum A Posteriori (MAP) Estimation

MAP takes a Bayesian approach. It asks: "Given the observed data \(D\), and our prior beliefs about \(\theta\), what parameter value \(\theta\) is most probable?" It seeks to maximize the posterior probability \(P(\theta|D)\). Using Bayes' theorem, this is proportional to the likelihood times the prior: $$P(\theta|D) \propto P(D|\theta) P(\theta)$$ Here, \(P(\theta)\) is the prior distribution, representing our initial beliefs about \(\theta\) before seeing any data. For example, for a coin bias \(p\), a common prior is the Beta distribution, which can model various beliefs (e.g., that the coin is probably fair, or probably biased towards tails).

⚠️ Prior's Influence

The prior \(P(\theta)\) is crucial for MAP. A strong prior (e.g., believing a coin is almost certainly fair) can "pull" the MAP estimate away from what the data alone suggests, especially with limited data. With infinite data, the likelihood typically overwhelms any reasonable prior, and MLE and MAP converge.

3
Why It Works — The Math
▼

Bernoulli Likelihood

For a sequence of \(N\) independent coin flips, where \(N_H\) are heads and \(N_T\) are tails (\(N_H + N_T = N\)), the likelihood of observing this data given a probability of heads \(p\) is:

$$L(p; D) = P(D|p) = p^{N_H} (1-p)^{N_T}$$

To find the MLE, we maximize this function with respect to \(p\). It's easier to maximize the log-likelihood:

$$\log L(p; D) = N_H \log p + N_T \log (1-p)$$

Taking the derivative with respect to \(p\) and setting it to zero yields the MLE estimate:

$$\frac{d}{dp} \log L(p; D) = \frac{N_H}{p} - \frac{N_T}{1-p} = 0 \implies \hat{p}_{MLE} = \frac{N_H}{N_H + N_T}$$

This is simply the observed frequency of heads, which makes intuitive sense.

Beta Prior & Posterior

For the coin flip problem, a common and mathematically convenient prior for \(p\) (which is between 0 and 1) is the Beta distribution: \(\text{Beta}(p|\alpha, \beta)\). Its probability density function is:

$$P(p) = \frac{p^{\alpha-1}(1-p)^{\beta-1}}{B(\alpha, \beta)}$$

where \(B(\alpha, \beta)\) is the Beta function (a normalizing constant). \(\alpha\) and \(\beta\) are hyperparameters that control the shape of the prior. For example, \(\alpha=1, \beta=1\) gives a uniform prior (all \(p\) values equally likely), while \(\alpha=10, \beta=10\) gives a strong prior belief that \(p\) is around 0.5.

Combining this prior with the likelihood using Bayes' theorem gives the posterior distribution \(P(p|D)\):

$$P(p|D) \propto P(D|p) P(p) \propto p^{N_H}(1-p)^{N_T} \cdot p^{\alpha-1}(1-p)^{\beta-1} = p^{\alpha+N_H-1}(1-p)^{\beta+N_T-1}$$

This is another Beta distribution: \(\text{Beta}(p|\alpha+N_H, \beta+N_T)\). The MAP estimate is the mode of this posterior distribution. For \(\alpha+N_H > 1\) and \(\beta+N_T > 1\), the mode is:

$$\hat{p}_{MAP} = \frac{\alpha+N_H-1}{\alpha+N_H+\beta+N_T-2}$$

Notice how the prior parameters \(\alpha-1\) and \(\beta-1\) act like "pseudocounts" of heads and tails added to the observed data. If \(\alpha=1, \beta=1\) (uniform prior), \(\hat{p}_{MAP}\) simplifies to \(\hat{p}_{MLE}\).

Key Takeaways
▼

MLE vs. MAP: When to use which?

  • MLE: Simpler, purely objective (data-driven). Often preferred when you have a lot of data, or no strong prior beliefs. It's the standard for many machine learning models (e.g., logistic regression, linear regression, neural networks often optimize a likelihood-based loss).
  • MAP: Incorporates prior knowledge, making it valuable when data is scarce or when you want to regularize estimates (a strong prior can prevent overfitting to small datasets). It's a stepping stone towards full Bayesian inference, which considers the entire posterior distribution, not just its mode.

Practical Considerations:

  • Regularization: A common way to think about MAP is that the prior acts as a regularizer. For instance, an L2 prior (Gaussian prior) on weights in linear regression leads to Ridge Regression.
  • Computational Cost: For many models, MLE and MAP estimates can be found by optimizing convex functions, making them computationally efficient. Full Bayesian inference (e.g., MCMC) can be much more expensive.
  • Choice of Prior: Selecting an appropriate prior for MAP can be tricky. An uninformative prior (like uniform, or Jeffreys prior) aims to have minimal impact, letting the data speak for itself. Informative priors require domain expertise.
💡 The "Regularization" Connection

In many cases, maximizing the log-posterior for MAP is equivalent to maximizing the log-likelihood (MLE) plus a regularization term derived from the log-prior. For example, a Gaussian prior on model weights corresponds to L2 regularization (weight decay).

Code Trace (Python / NumPy)
▼
import numpy as np
from scipy.special import beta as beta_func # For normalizing Beta PDF
# --- Data ---
num_heads = 7 # Number of observed heads (N_H)
num_flips = 10 # Total number of flips (N)
num_tails = num_flips - num_heads # N_T
# --- Prior Parameters (for Beta distribution) ---
prior_alpha = 2.0 # α
prior_beta = 2.0 # β
# --- Likelihood Function (for Bernoulli) ---
# P(D|p) = p^(N_H) * (1-p)^(N_T)
def likelihood(p, nh, nt):
# Handle p=0 or p=1 to avoid log(0) issues, though p is usually (0,1)
p = np.clip(p, 1e-9, 1 - 1e-9)
return (p ** nh) * ((1 - p) ** nt)
# --- Prior PDF (Beta distribution) ---
# P(p) = p^(α-1) * (1-p)^(β-1) / B(α,β)
def prior_pdf(p, alpha, beta):
p = np.clip(p, 1e-9, 1 - 1e-9)
# B(alpha, beta) = gamma(alpha)*gamma(beta)/gamma(alpha+beta)
return (p**(alpha - 1) * (1 - p)**(beta - 1)) / beta_func(alpha, beta)
# --- Posterior PDF (also a Beta distribution) ---
# P(p|D) = Beta(p | α+N_H, β+N_T)
def posterior_pdf(p, nh, nt, alpha, beta):
# Posterior parameters are updated with observed counts
post_alpha = alpha + nh
post_beta = beta + nt
return prior_pdf(p, post_alpha, post_beta)
# --- MLE Estimate ---
# p_MLE = N_H / (N_H + N_T)
mle_estimate = num_heads / num_flips
print(f"MLE Estimate: {mle_estimate:.3f}")
# --- MAP Estimate ---
# p_MAP = (α+N_H-1) / (α+N_H+β+N_T-2) (for α,β,α+N_H,β+N_T > 1)
# If any parameter <= 1, mode can be at 0 or 1.
if prior_alpha + num_heads > 1 and prior_beta + num_tails > 1:
map_estimate = (prior_alpha + num_heads - 1) / \
(prior_alpha + num_heads + prior_beta + num_tails - 2)
else: # Handle edge cases where mode is at 0 or 1 or undefined
# Simple fallback: if prior is strong at 0 or 1, MAP might be 0 or 1
# More robust: use optimization or check endpoints
map_estimate = np.nan # Or 0.0 if alpha+nh=1 and beta+nt > 1, etc.
print(f"MAP Estimate: {map_estimate:.3f}")
# Example usage: Evaluate PDFs at a specific p
p_val = 0.5
print(f"Likelihood at p={p_val}: {likelihood(p_val, num_heads, num_tails):.3f}")
print(f"Prior PDF at p={p_val}: {prior_pdf(p_val, prior_alpha, prior_beta):.3f}")
print(f"Posterior PDF at p={p_val}: {posterior_pdf(p_val, num_heads, num_tails, prior_alpha, prior_beta):.3f}")
