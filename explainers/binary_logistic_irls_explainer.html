Understanding Logistic Regression
▼

What is it? Linear regression predicts a continuous number. Logistic regression predicts a probability — the chance that a data point belongs to class 1 (e.g., "is this email spam?"). It squashes a linear score through an S-shaped curve called the sigmoid so the output always lands between 0 and 1.

Analogy: Imagine a doctor reading a blood test result. The raw number (glucose level) can be anything. Logistic regression is like the doctor's mental model: "below 90 → almost certainly healthy, above 200 → almost certainly diabetic, in between → it's complicated." The sigmoid captures exactly that smooth transition from certainty to certainty.

💡 If you remember one thing

Logistic regression maximizes the Bernoulli log-likelihood — equivalently, minimizes the log-loss \(\mathcal{L}(\beta) = -\sum_i [y_i \log p_i + (1-y_i)\log(1-p_i)]\) where \(p_i = \sigma(x_i^\top\beta)\). There is no closed form; IRLS solves it exactly as repeated weighted least squares.

Why logistic and not linear? Linear regression can predict values outside \([0,1]\), making it useless as a probability. The logistic (sigmoid) function \(\sigma(z) = 1/(1+e^{-z})\) guarantees a valid probability for any real-valued linear score \(z = x^\top\beta\).

The Math: MLE & Gradient
▼

The Model

Given features \(x_i \in \mathbb{R}^p\) and binary labels \(y_i \in \{0,1\}\), we model:

$$p_i = P(y_i = 1 \mid x_i) = \sigma(x_i^\top \beta) = \frac{1}{1 + e^{-x_i^\top\beta}}$$

Each observation follows a Bernoulli: \(y_i \sim \text{Bernoulli}(p_i)\). The likelihood of the data is:

$$L(\beta) = \prod_{i=1}^n p_i^{y_i}(1-p_i)^{1-y_i}$$

Log-Likelihood & MLE

Taking the log (for numerical convenience) gives the log-likelihood \(\ell(\beta)\):

$$\ell(\beta) = \sum_{i=1}^n \bigl[y_i \log p_i + (1-y_i)\log(1-p_i)\bigr] = \sum_{i=1}^n \bigl[y_i x_i^\top\beta - \log(1 + e^{x_i^\top\beta})\bigr]$$

MLE maximizes \(\ell(\beta)\), equivalently minimizing the mean log-loss \(-\ell(\beta)/n\).

Gradient (Score)

Differentiating \(\ell\) with respect to \(\beta\) (using \(\partial \sigma(z)/\partial z = \sigma(z)(1-\sigma(z))\)):

$$\nabla_\beta \ell(\beta) = \sum_{i=1}^n (y_i - p_i) x_i = X^\top(y - p)$$

In matrix form with \(p = \sigma(X\beta)\). Setting \(\nabla\ell = 0\) gives the MLE — but there's no closed form (nonlinear in \(\beta\)), so we use numerical optimization.

Hessian (Observed Fisher Information)

The second derivative is always negative-definite (log-likelihood is strictly concave):

$$H = \nabla^2_\beta \ell(\beta) = -X^\top W X \quad \text{where } W = \operatorname{diag}(p_i(1-p_i))$$
🔑 Key Property

The log-likelihood of logistic regression is strictly concave (when \(X\) has full column rank). This means there is a unique global maximum — no local optima to worry about. The Hessian \(-X^\top WX\) is always negative semi-definite.

⚠️ Common Misconception

If the data are perfectly separable (a hyperplane cleanly divides all 0s from all 1s), the MLE does not exist — the likelihood is maximized as \(\|\beta\| \to \infty\). IRLS will diverge. Regularization (L2 / ridge prior) fixes this.

3
IRLS — Newton's Method as Weighted Least Squares
▼

Newton-Raphson Update

Newton's method for maximizing \(\ell\) iterates:

$$\beta^{(t+1)} = \beta^{(t)} - H^{-1}\nabla\ell = \beta^{(t)} + (X^\top W X)^{-1} X^\top(y - p)$$

Rewriting as Weighted Least Squares

Define the working response (adjusted dependent variable):

$$z_i = x_i^\top\beta^{(t)} + \frac{y_i - p_i}{p_i(1-p_i)} = \eta_i + \frac{y_i - p_i}{w_i}$$

Then the Newton step is algebraically equivalent to solving the weighted least squares problem:

$$\beta^{(t+1)} = \underset{\beta}{\operatorname{argmin}}\; \sum_{i=1}^n w_i (z_i - x_i^\top\beta)^2 = (X^\top W X)^{-1} X^\top W z$$

This is IRLS: at each iteration, recompute weights \(W = \text{diag}(p_i(1-p_i))\) and working response \(z\), then solve an ordinary weighted least squares system. The weights change each step because \(p_i\) changes — hence "iteratively reweighted."

📐 IRLS Algorithm

1. Initialize \(\beta^{(0)} = 0\)
2. Compute \(p_i = \sigma(x_i^\top\beta^{(t)})\)
3. Compute weights \(w_i = p_i(1-p_i)\)
4. Compute working response \(z_i = x_i^\top\beta^{(t)} + (y_i - p_i)/w_i\)
5. Solve WLS: \(\beta^{(t+1)} = (X^\top W X)^{-1} X^\top W z\)
6. Check \(\|\nabla\ell\| = \|X^\top(y-p)\| < \epsilon\); if so, stop

Convergence Rate

Because IRLS is Newton's method on a strictly concave objective, it converges quadratically near the optimum — the number of correct decimal places roughly doubles each iteration. In practice 5–10 iterations suffice for double-precision convergence (as seen in our demo above where 5 iterations achieve \(\|\nabla\ell\| < 10^{-4}\)).

💡 Why IRLS Matters

IRLS reduces a nonlinear optimization problem to a sequence of linear solves. Each step leverages highly optimized LAPACK routines for \((X^\top WX)^{-1}\). For small to medium \(p\), this is far faster than gradient descent. IRLS is also the backbone of all Generalized Linear Model (GLM) fitting.

Implementation & Key Takeaways
▼

From-Scratch Implementation (NumPy)

import numpy as np
def sigmoid(z):
return 1 / (1 + np.exp(-np.clip(z, -500, 500))) # clip for stability
def irls_logistic(X, y, max_iter=25, tol=1e-6):
"""Fit logistic regression via IRLS (Newton's method).
X: (n, p) design matrix (include intercept column of 1s)
y: (n,) binary labels 0/1
"""
n, p = X.shape
beta = np.zeros(p) # Initialize β = 0
for t in range(max_iter):
# Step 1: Probabilities
eta = X @ beta
prob = sigmoid(eta) # p_i = σ(xᵢᵀβ)
# Step 2: IRLS weights W = diag(pᵢ(1−pᵢ))
w = np.clip(prob * (1 - prob), 1e-10, None)
# Step 3: Working response z = η + W⁻¹(y − p)
z = eta + (y - prob) / w
# Step 4: Hessian XᵀWX and XᵀWz
XtW = X.T * w # (p, n) broadcast
XtWX = XtW @ X # (p, p) — Hessian
XtWz = XtW @ z # (p,) — target
# Step 5: Solve WLS β_new = (XᵀWX)⁻¹ XᵀWz
beta_new = np.linalg.solve(XtWX, XtWz)
# Step 6: Convergence check on gradient ∇ℓ = Xᵀ(y − p)
grad_norm = np.linalg.norm(X.T @ (y - prob))
beta = beta_new
if grad_norm < tol:
print(f"Converged at iteration {t+1}")
break
return beta
# Usage
X = np.column_stack([np.ones(n), x_feature]) # add intercept
beta = irls_logistic(X, y)
pred_probs = sigmoid(X @ beta)

Key Takeaways

  • MLE = minimize log-loss: The gradient \(\nabla\ell = X^\top(y - p)\) has a beautifully simple form — just the weighted residual.
  • IRLS = Newton's method: Each step solves a weighted least squares problem with weights \(w_i = p_i(1-p_i)\) and working response \(z_i\).
  • Quadratic convergence: Typically 5–10 iterations regardless of dataset size (unlike gradient descent which needs thousands of steps).
  • When to use: Small to medium \(p\) (<10k features), exact second-order convergence needed, GLM framework, or scikit-learn solver='newton-cholesky'.
  • When NOT to use: \(p \gg n\) (matrix \(X^\top WX\) is rank-deficient), perfectly separable data (MLE doesn't exist — add L2 regularization), or very large \(p\) (use L-BFGS or SGD).
