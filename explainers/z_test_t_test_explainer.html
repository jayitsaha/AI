Understanding the Concept
▼

Imagine a doctor testing whether a new drug lowers blood pressure. They measure 20 patients and get an average drop of 8 mmHg. But is that real — or could it be random luck? A hypothesis test puts a number on that question.

The core idea: assume the drug does nothing (the "null hypothesis"). Then ask: how surprising is an 8 mmHg drop if the drug truly does nothing? If it's very surprising (probability < 5%), we reject "nothing happened" and declare the drug effective.

Key Insight

Both the z-test and t-test convert your sample evidence into a single number — the test statistic — and ask where that number lands on a known reference distribution. If it lands in the "unlikely" tail, you reject the null hypothesis.

z-Test vs t-Test — The One Sentence Difference

Use the z-test when the population standard deviation \(\sigma\) is known (rare in practice). Use the t-test when \(\sigma\) is unknown and estimated from data (almost always). The t-distribution has heavier tails to account for the extra uncertainty from estimating \(\sigma\).

Three Practical Variants

  • One-sample: Compare one group's mean to a fixed target (e.g., "is average height = 170 cm?")
  • Two-sample: Compare two independent groups (A/B testing: control vs treatment)
  • Paired: Compare two linked measurements (before/after on the same subject, eliminates individual variability)
If You Remember One Thing

The test statistic \(= \frac{\text{observed difference} - \text{null value}}{\text{standard error}}\). It measures signal-to-noise. Large |test statistic| → reject H₀.

2
How It Works — The Mechanics
▼

The Hypothesis Testing Framework

Every test follows the same five-step recipe:

  1. State H₀ and H₁ — null (no effect) and alternative hypotheses
  2. Choose \(\alpha\) — significance level (typically 0.05). This is the false-positive rate you tolerate.
  3. Compute the test statistic — standardize your sample estimate
  4. Find the p-value — probability of data this extreme if H₀ were true
  5. Decide — if p < α, reject H₀

Why the Normal / t Distribution?

By the Central Limit Theorem, the sample mean \(\bar{x}\) from \(n\) observations (for large \(n\)) is approximately Normal with mean \(\mu\) and standard error \(\sigma/\sqrt{n}\). Standardizing gives:

$$Z = \frac{\bar{x} - \mu_0}{\sigma/\sqrt{n}} \sim N(0,1) \quad \text{(z-test: known } \sigma\text{)}$$

When we replace \(\sigma\) with the sample estimate \(s\), the standardized statistic no longer follows a perfect Normal — it follows a Student's t distribution with \(n-1\) degrees of freedom:

$$T = \frac{\bar{x} - \mu_0}{s/\sqrt{n}} \sim t(n-1) \quad \text{(t-test: unknown } \sigma\text{)}$$
Why Heavier Tails?

The extra uncertainty from estimating \(\sigma\) makes extreme values slightly more probable. With small \(n\), this matters a lot. At \(n=30\), t(29) is nearly indistinguishable from N(0,1). The heavier tails mean critical values are larger: \(t_{0.025,\,df=4} = 2.776\) vs \(z_{0.025} = 1.960\) — harder to reject with small samples.

Two-Sample Welch t-Test

For two independent groups with possibly different variances \(\sigma_1^2 \neq \sigma_2^2\), the Welch test uses:

$$T_W = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{s_1^2/n_1 + s_2^2/n_2}} \sim t(\nu)$$

where the Welch-Satterthwaite degrees of freedom \(\nu\) are:

$$\nu = \frac{\left(\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}\right)^2}{\frac{s_1^4}{n_1^2(n_1-1)} + \frac{s_2^4}{n_2^2(n_2-1)}}$$

Paired t-Test — Reducing Variance

When observations come in pairs (before/after, matched pairs), compute differences \(d_i = x_{i,1} - x_{i,2}\) and run a one-sample t-test on the differences:

$$T_{paired} = \frac{\bar{d}}{s_d/\sqrt{n}} \sim t(n-1)$$

This eliminates between-subject variability, often dramatically increasing power for the same sample size.

The Math — Derivation & Formulas
▼

The p-Value Defined Precisely

For a two-tailed test with observed statistic \(t_{obs}\):

$$p = 2 \cdot P\!\left(T > |t_{obs}|\right) = 2\left(1 - F_{t,\nu}(|t_{obs}|)\right)$$

where \(F_{t,\nu}\) is the CDF of the t-distribution with \(\nu\) degrees of freedom (or the standard Normal CDF for z-tests).

Common Misconception

The p-value is NOT the probability that H₀ is true. It is the probability of observing data this extreme or more extreme, given that H₀ is true. This is a subtle but critical distinction — p = 0.03 does not mean "3% chance the drug doesn't work."

Confidence Interval Connection

A 95% CI and a two-tailed test at \(\alpha=0.05\) are mathematically equivalent. The CI for a one-sample t-test is:

$$\bar{x} \pm t_{\alpha/2,\,n-1} \cdot \frac{s}{\sqrt{n}}$$

If the null value \(\mu_0\) falls outside this interval, the test rejects at the 5% level.

Effect Size — Cohen's d

Statistical significance doesn't imply practical significance. Always report Cohen's d alongside the p-value:

$$d = \frac{\bar{x}_1 - \bar{x}_2}{s_{pooled}}, \quad s_{pooled} = \sqrt{\frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}}$$

Conventions: \(|d|\) = 0.2 small, 0.5 medium, 0.8 large.

Assumptions Required
  • Independence of observations (always)
  • Normality of population (or large \(n\) via CLT)
  • z-test only: \(\sigma\) is known exactly
  • Pooled t-test only: equal variances \(\sigma_1^2 = \sigma_2^2\) — use Welch's instead in practice

Worked Numerical Examples
▼

Example 1 — One-Sample z-Test

Scenario: A factory claims average widget weight = 100g. We sample \(n=30\), get \(\bar{x}=102.5\)g, and know the process SD is \(\sigma=10\)g.

$$z = \frac{102.5 - 100}{10/\sqrt{30}} = \frac{2.5}{1.826} = 1.369$$

Critical value \(z_{0.025} = 1.960\). Since \(1.369 < 1.960\), fail to reject H₀. \(p = 0.171 > 0.05\).

Example 2 — One-Sample t-Test

Scenario: Same claim but \(\sigma\) unknown. Sample \(n=15\), \(\bar{x}=103.2\), \(s=8.4\).

$$t = \frac{103.2 - 100}{8.4/\sqrt{15}} = \frac{3.2}{2.170} = 1.475, \quad df = 14$$

Critical value \(t_{0.025,\,14} = 2.145\). Since \(1.475 < 2.145\), fail to reject H₀. \(p = 0.162\).

Example 3 — Welch Two-Sample t-Test (A/B Test)

Scenario: Control: \(n_1=25, \bar{x}_1=78.3, s_1=12.1\). Treatment: \(n_2=30, \bar{x}_2=71.8, s_2=15.6\).

$$t_W = \frac{78.3 - 71.8}{\sqrt{12.1^2/25 + 15.6^2/30}} = \frac{6.5}{\sqrt{5.855+8.112}} = \frac{6.5}{3.738} = 1.739$$
$$\nu = \frac{(5.855+8.112)^2}{5.855^2/24 + 8.112^2/29} = \frac{195.1}{1.427+2.271} = 52.76$$

Critical value \(t_{0.025,\,52.76} \approx 2.007\). Since \(1.739 < 2.007\), fail to reject. \(p = 0.088\).

Key Takeaways & When to Use What
▼

Decision Guide

SituationTestWhy
\(\sigma\) known, one group vs targetOne-sample zExact under normality
\(\sigma\) unknown, one group vs targetOne-sample tEstimates \(\sigma\) from data
Two independent groups, equal variancePooled two-sample tSlightly more power if assumption holds
Two independent groups, unequal varianceWelch t (default)Robust to heteroscedasticity — always safe
Before/after or matched pairsPaired tRemoves between-subject noise
More than two groupsANOVA / F-testMultiple comparisons inflate Type I error
A/B Testing Connection

Online A/B tests typically use the Welch two-sample t-test (or z-test approximation for large \(n\)) on conversion rates, revenue, or engagement metrics. Always pre-register your hypothesis, set \(\alpha\) and target power (typically 80%), then compute the required sample size before running — don't peek at results mid-experiment.

Three Things to Never Forget

  • Significant \(\neq\) practically important — with \(n=10{,}000\), trivially small effects become significant
  • p-value is not posterior probability — Bayesian credible intervals give what people usually want to know
  • Always check assumptions — Q-Q plots for normality, Levene's test for equal variances
