Isotonic Regression

Fitting a monotone step function with the Pool Adjacent Violators Algorithm

Intermediate Classical ML O(n) Algorithm
1 Understanding Isotonic Regression ▼

Imagine you have noisy data where you know the relationship between your predictor and target must be monotonically non-decreasing — yet the raw observations wiggle up and down due to noise. Isotonic regression finds the best-fitting step function that is guaranteed to be non-decreasing, minimising the sum of squared errors over all such monotone functions.

Staircase analogy: Think of fitting a staircase through noisy data. The stairs may only go up (or stay flat) — never down. Isotonic regression finds the unique staircase that is as close as possible to the observed data, in a least-squares sense.

The Optimization Problem

Given observations \(y_1, y_2, \ldots, y_n\) paired with ordered predictors, we solve:

$$\min_{\hat{y}} \sum_{i=1}^{n}(y_i - \hat{y}_i)^2 \quad \text{subject to} \quad \hat{y}_1 \leq \hat{y}_2 \leq \cdots \leq \hat{y}_n$$

The solution \(\hat{y}\) is a piecewise constant (step) function — consecutive groups of original points are "pooled" together and replaced by their mean.

Key Use Cases

  • Probability calibration: Map a classifier's raw score \(\to\) a true probability. Isotonic regression is a non-parametric alternative to Platt scaling (sigmoid fit), and often more accurate when training data is plentiful.
  • Dose–response curves: Drug concentration should monotonically increase effect.
  • Performance benchmarks: Throughput as a function of resource allocation should be non-decreasing.
  • Survival analysis: Enforce monotone hazard rates.
Key insight: The result is always a piecewise constant function. Points that would violate monotonicity are "pooled" — merged into a single block assigned the block's weighted mean — until the non-decreasing constraint is satisfied everywhere.
2 The PAVA Algorithm (How It Works) ▼

The Pool Adjacent Violators Algorithm (PAVA) solves isotonic regression exactly in \(O(n)\) time. It processes points left to right, maintaining a stack of "blocks" — contiguous groups of points merged to their weighted average.

The Algorithm, Step by Step

  1. Process points from left to right, one at a time.
  2. Each incoming point starts as its own block (mean = its value, weight = 1).
  3. Compare the new block's mean with the previous block's mean on the stack.
  4. If the new block mean < the previous block mean → VIOLATION! Merge the two blocks into one, using a weighted average of their means.
  5. Keep merging backward until monotonicity is restored (or the stack has one block).
  6. After all points are processed, expand each block — every point in a block gets the block's mean as its fitted value.

3 Why It Works (Mathematical Guarantee) ▼

Uniqueness & Optimality

Isotonic regression is a convex quadratic program with linear inequality constraints. The feasible set (all non-decreasing sequences) is a convex cone. The objective is strictly convex. Therefore the solution is unique — there is exactly one optimal step function.

Weighted Isotonic Regression

The weighted version allows different observations to have different influence:

$$\hat{y} = \underset{z:\, z_1 \leq z_2 \leq \cdots \leq z_n}{\arg\min} \sum_{i=1}^{n} w_i(y_i - z_i)^2$$

PAVA handles weights naturally. When merging two adjacent blocks A and B (with means \(\mu_A, \mu_B\) and weights \(w_A, w_B\)):

$$\mu_{AB} = \frac{w_A \mu_A + w_B \mu_B}{w_A + w_B}$$

Connection to Convex Analysis

Projection View
The isotonic fit is the orthogonal projection of \(y\) onto the convex cone of non-decreasing sequences in \(\mathbb{R}^n\).
Geometric View
The solution is the greatest convex minorant (GCM) of the empirical cumulative sum, "inverted" back into value space.
Complexity
PAVA runs in \(O(n)\) time and \(O(n)\) space — optimal for this problem. Each point is pushed and merged at most once.
Duality
Equivalent to a dual problem involving Lagrange multipliers for each monotonicity constraint \(\hat{y}_i \leq \hat{y}_{i+1}\).

Why Each Merge is Locally Optimal

When two adjacent blocks violate monotonicity, their best joint fitted value is always their weighted average. This follows because the derivative of the squared loss within the merged block is zero at the mean — the mean minimises squared error within any fixed group. PAVA exploits this: no global optimization needed, just local greedy merges.

Amortized analysis: Despite the inner while-loop, PAVA is \(O(n)\) total. Each point is added to the stack once and merged (removed) at most once. The total number of operations is bounded by \(2n\).

5 Key Takeaways & When to Use ▼

When to Use Isotonic Regression

  • You know the relationship between predictor and target is monotone (by domain knowledge)
  • You want a non-parametric fit — no assumption about the shape of the curve beyond monotonicity
  • You need to calibrate a classifier's output probabilities without assuming a sigmoid shape
  • You have enough data to support a non-parametric approach (isotonic regression has no smoothing)

Comparison with Alternatives

Method Monotone? Parametric? Smooth? Best for
Isotonic Regression Yes (guaranteed) No No (step function) Calibration, known monotone relationships
Platt Scaling (Sigmoid) Yes Yes (2 params) Yes Small calibration sets, SVM outputs
Monotone Splines Yes (constrained) Semi (basis fns) Yes Smooth monotone trends
Standard Splines Not guaranteed Semi Yes General smooth curves
Linear Regression Not guaranteed Yes Yes Parametric, interpretable models

Key Warnings

Overfitting risk: With small \(n\), isotonic regression can overfit — each point may end up in its own block. Consider Platt scaling or monotone splines for small calibration sets.
No generalization: The step function only defines fitted values at the training \(x\) values. For predictions at new \(x\) values, you need an interpolation rule (e.g., nearest neighbor or linear interpolation between steps). Scikit-learn's IsotonicRegression uses linear interpolation by default.
Practical tip: In sklearn's CalibratedClassifierCV, set method='isotonic' to use isotonic regression for probability calibration. Use method='sigmoid' (Platt) for smaller training sets (<1000 samples).

</> Python Implementation ▼

A from-scratch PAVA implementation, and the equivalent scikit-learn usage:

pava.py 
import numpy as np
from sklearn.isotonic import IsotonicRegression

# ─── From scratch: Pool Adjacent Violators Algorithm ───────────
def pava(y, weights=None):
    """Isotonic regression via PAVA. O(n) time."""
    n = len(y)
    if weights is None:
        weights = np.ones(n)

    # Stack of [mean, weight, start_index, end_index]
    blocks = []

    for i in range(n):
        # New block for current point
        blocks.append([y[i], weights[i], i, i])

        # Merge violating adjacent blocks (pool adjacent violators)
        while len(blocks) > 1 and blocks[-2][0] > blocks[-1][0]:
            prev = blocks.pop(-2)
            curr = blocks[-1]
            # Weighted average of the two merged blocks
            total_w = prev[1] + curr[1]
            new_mean = (prev[0] * prev[1] + curr[0] * curr[1]) / total_w
            blocks[-1] = [new_mean, total_w, prev[2], curr[3]]

    # Expand blocks back to fitted values
    result = np.zeros(n)
    for mean, _, start, end in blocks:
        result[start:end+1] = mean
    return result

# ─── Usage ─────────────────────────────────────────────────────
y = np.array([1.0, 2.5, 1.8, 3.2, 2.9, 4.1])
fitted = pava(y)
print(fitted)
# [1.0, 2.15, 2.15, 3.05, 3.05, 4.1]

# ─── Production: sklearn ────────────────────────────────────────
ir = IsotonicRegression(increasing=True)
x = np.arange(len(y))
ir.fit(x, y)
print(ir.predict(x))
# [1.   2.15 2.15 3.05 3.05 4.1 ]

# ─── Probability calibration example ───────────────────────────

from sklearn.svm import SVC
