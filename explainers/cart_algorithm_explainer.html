CART Algorithm

Classification and Regression Trees — recursive binary splitting with Gini impurity & variance reduction, plus cost-complexity pruning
Intermediate Classical ML · Trees O(n·d·log n) per split
1
Understanding CART
▼

CART — Classification and Regression Trees — is a tree-building algorithm introduced by Breiman, Friedman, Olshen, and Stone in 1984. It builds binary decision trees (every internal node has exactly two children) by repeatedly asking yes/no questions about individual features.

Core Insight

CART turns any prediction task into a sequence of binary choices: "Is feature \(x_j \leq t\)?" At each node it picks the best split — the feature/threshold pair that reduces impurity the most — then recurses on each child. Prediction is the majority class (classification) or mean value (regression) at the leaf.

Think of it as a sorting machine: drop a data point in at the root, and at each node it goes left or right depending on one feature value, until it reaches a leaf that makes the final prediction.

Key Property

Every split is greedy and binary. CART does not look ahead — it picks the locally best split at each node. This makes it fast (polynomial time) but not globally optimal (the best binary tree is NP-hard to find).

How It Works — Splits, Gini & Variance
▼

Classification: Gini Impurity

For a node containing samples from \(K\) classes, let \(\hat{p}_k\) be the fraction of samples in class \(k\). The Gini impurity is:

$$G = \sum_{k=1}^{K} \hat{p}_k (1 - \hat{p}_k) = 1 - \sum_{k=1}^{K} \hat{p}_k^2$$

\(G = 0\) means a pure node (all same class). \(G = 0.5\) for binary classification means a 50/50 mix — maximally impure. CART seeks a split \((j, t)\) that minimises the weighted Gini of the two children:

$$\text{Cost}(j, t) = \frac{n_L}{n} G_L + \frac{n_R}{n} G_R$$

where \(n_L, n_R\) are the child sample counts and \(G_L, G_R\) their Gini impurities.

Regression: Variance Reduction

For regression, "impurity" at a node is the mean squared error of target values \(y_i\) in that node:

$$\text{MSE}_\text{node} = \frac{1}{n}\sum_{i \in \text{node}} (y_i - \bar{y})^2$$

CART splits to maximise variance reduction: \(\text{MSE}_\text{parent} - \tfrac{n_L}{n}\text{MSE}_L - \tfrac{n_R}{n}\text{MSE}_R\). Each leaf predicts \(\bar{y}\) — the mean of its training samples.

Recursive Partitioning

  1. Start with the full training set at the root.
  2. For every feature \(j \in \{1,\ldots,d\}\) and every threshold \(t\) (candidate = midpoint between sorted unique values): compute \(\text{Cost}(j,t)\).
  3. Pick \((j^*, t^*) = \arg\min_{j,t}\,\text{Cost}(j,t)\).
  4. Split: left child gets \(\{x : x_{j^*} \leq t^*\}\), right child gets \(\{x : x_{j^*} > t^*\}\).
  5. Recurse on each child until a stopping criterion: minimum samples in leaf, maximum depth, or zero impurity.

Cost-Complexity Pruning (Weakest-Link)

Growing a full tree overfits. CART prunes with minimal cost-complexity pruning: define the cost of subtree \(T\) rooted at node \(t\) as

$$R_\alpha(T) = R(T) + \alpha \cdot |T|$$

where \(R(T)\) is the total node impurity (sum of weighted Gini/MSE across leaves), \(|T|\) is the number of leaves, and \(\alpha \geq 0\) is the complexity penalty. As \(\alpha\) grows, branches are collapsed. A sequence of nested trees \(T_0 \supset T_1 \supset \cdots \supset T_{\text{root}}\) is generated; the best \(\alpha\) is found by cross-validation.

Common Misconception

Information gain (entropy) and Gini impurity produce nearly identical trees in practice. The main difference: Gini avoids computing logarithms, so it is slightly faster. sklearn's DecisionTreeClassifier uses Gini by default for this reason.

Numerical Trace — Worked Example
▼

Consider 6 samples: \((x_1, y)\) where \(y \in \{A, B\}\):

$$x = [1,2,3,4,5,6], \quad y = [A,A,B,B,B,A]$$

Root node: 3 A's, 3 B's. \(\hat{p}_A = 0.5, \hat{p}_B = 0.5\). Gini = \(1 - (0.5^2 + 0.5^2) = 0.5\).

Try split at \(x \leq 2.5\) (left: \(\{1,2\}\), right: \(\{3,4,5,6\}\)):

  • Left: 2 A, 0 B — \(G_L = 1 - (1^2 + 0^2) = 0\) (pure!)
  • Right: 1 A, 3 B — \(\hat{p}_A=0.25,\hat{p}_B=0.75\) — \(G_R = 1 - (0.0625+0.5625) = 0.375\)
  • Cost = \(\tfrac{2}{6}\cdot 0 + \tfrac{4}{6}\cdot 0.375 = 0.25\)

Try split at \(x \leq 5.5\) (left: \(\{1..5\}\), right: \(\{6\}\)):

  • Left: 2 A, 3 B — \(G_L = 0.48\). Right: 1 A, 0 B — \(G_R = 0\).
  • Cost = \(\tfrac{5}{6}\cdot 0.48 + \tfrac{1}{6}\cdot 0 = 0.40\)

Best split: \(x \leq 2.5\) (cost 0.25). Left leaf predicts A. Right node recurses: \(\{3,4,5,6\}\) → \(1A, 3B\). Best sub-split: \(x \leq 5.5\) gives left = \(\{3,4,5\}\): 0A,3B (pure, predict B), right = \(\{6\}\): 1A (predict A).

Resulting Tree

root: x≤2.5?
├─ YES → Predict A (Gini=0, n=2)
└─ NO → x≤5.5?
   ├─ YES → Predict B (Gini=0, n=3)
   └─ NO → Predict A (Gini=0, n=1)

When to Use CART
  • Need an interpretable, single-model explanation for stakeholders
  • Both classification and regression tasks (one algorithm for both)
  • Base learner inside Random Forest or Gradient Boosting
  • Dataset has mixed feature types (CART handles continuous & categorical natively)
When NOT to Use CART Alone
  • High-dimensional sparse data → linear models generalise better
  • Need smooth decision boundaries → deep trees produce step-function approximations
  • Predictive performance is paramount → use Random Forest or XGBoost
  • Extrapolation required → tree predictions are flat at boundary regions
