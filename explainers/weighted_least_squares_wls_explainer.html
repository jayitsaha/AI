Weighted Least Squares (WLS)

Handling heteroscedastic data by giving each observation a trust-proportional weight
Foundational Statistics Classical ML O(np² + p³)
1
Understanding the Concept
▼

What is this? In ordinary least squares (OLS), every data point counts equally. But what if some observations are noisier than others? WLS solves this by assigning each point a weight — reliable points get high weight, noisy points get low weight.

Analogy: Imagine averaging restaurant ratings. A review from someone who visited 50 times should count more than a one-time visitor. WLS does exactly this — it trusts precise measurements more and noisy ones less.

💡 Key Insight

WLS is OLS on rescaled data. When you weight observation \(i\) by \(w_i\), you're effectively dividing it by its standard deviation — turning a heteroscedastic problem into a homoscedastic one.

$$\hat{\beta}_{WLS} = (X^\top W X)^{-1} X^\top W y \quad \text{where } W = \text{diag}(w_1, \ldots, w_n)$$

Relationship to GLS: WLS is the special case of GLS where the error covariance \(\Omega\) is diagonal. GLS handles correlated errors too; WLS only handles unequal variances (heteroscedasticity).

2
How It Works Internally
▼

The Heteroscedasticity Problem

OLS assumes constant error variance: \(\operatorname{Var}(\varepsilon_i) = \sigma^2\) for all \(i\). When this fails — say \(\operatorname{Var}(\varepsilon_i) = \sigma_i^2\) varies across observations — OLS estimates are still unbiased but no longer efficient. Worse, the standard errors are wrong, making hypothesis tests unreliable.

The WLS Fix: Weight by Precision

If we know (or estimate) each observation's variance \(\sigma_i^2\), set weight \(w_i = 1/\sigma_i^2\). Points with high variance get downweighted; points with low variance get upweighted. The weighted residual sum of squares becomes:

$$S(\beta) = \sum_{i=1}^n w_i (y_i - x_i^\top \beta)^2 = (y - X\beta)^\top W (y - X\beta)$$

Equivalent Interpretation: Rescaled OLS

Define \(\sqrt{W} = \text{diag}(\sqrt{w_1}, \ldots, \sqrt{w_n})\). Let \(y^* = \sqrt{W}\, y\) and \(X^* = \sqrt{W}\, X\). Then:

$$\hat{\beta}_{WLS} = (X^{*\top} X^*)^{-1} X^{*\top} y^* = \text{OLS on } (X^*, y^*)$$

This is why WLS is "OLS on rescaled data." The transformation \(\sqrt{W}\) shrinks noisy rows and amplifies clean ones, producing homoscedastic transformed errors.

⚠️ Common Pitfall

If you get the weights wrong (e.g., use \(w_i = \sigma_i^2\) instead of \(w_i = 1/\sigma_i^2\)), WLS will amplify noisy observations instead of suppressing them — making estimates worse than OLS.

3
The Math Behind It
▼

Derivation

Minimize the weighted sum of squared residuals:

$$S(\beta) = (y - X\beta)^\top W (y - X\beta)$$

Expand:

$$S(\beta) = y^\top W y - 2\beta^\top X^\top W y + \beta^\top X^\top W X \beta$$

Take the gradient and set to zero:

$$\frac{\partial S}{\partial \beta} = -2X^\top W y + 2X^\top W X \beta = 0$$

Solve for \(\beta\):

$$\hat{\beta}_{WLS} = (X^\top W X)^{-1} X^\top W y$$

Properties

Unbiased: \(\mathbb{E}[\hat{\beta}_{WLS}] = \beta\) (same as OLS).

Covariance: \(\operatorname{Var}(\hat{\beta}_{WLS}) = \sigma^2(X^\top W X)^{-1}\) when \(W = \text{diag}(1/\sigma_i^2)\) and errors are independent.

BLUE: WLS is the Best Linear Unbiased Estimator under heteroscedasticity with known variance ratios — it achieves the minimum variance among all linear unbiased estimators.

🔑 When WLS = GLS

WLS is GLS with \(\Omega = \text{diag}(\sigma_1^2, \ldots, \sigma_n^2)\). Since \(\Omega\) is diagonal, \(\Omega^{-1} = W = \text{diag}(1/\sigma_1^2, \ldots, 1/\sigma_n^2)\). No Cholesky decomposition needed — the "square root" is just element-wise.

# OLS (unweighted)
beta_ols = inv(X'X) @ X' @ y
# WLS (weighted)
beta_wls = inv(X'WX) @ X'W @ y
# Rescaled OLS (equivalent to WLS)
sqrtW = diag(sqrt(w))
Xstar = sqrtW @ X
ystar = sqrtW @ y
beta_rescaled = inv(Xstar'Xstar) @ Xstar' @ ystar

Key Takeaways & When to Use
▼
🔑 Decision Guide

Use WLS when: Errors have unequal variances (heteroscedasticity) but are uncorrelated, and you know or can estimate the variance function.

Use GLS instead when: Errors are both heteroscedastic AND correlated (off-diagonal terms in \(\Omega\)).

MethodAssumesWeight MatrixUse When
OLS\(\operatorname{Var}(\varepsilon) = \sigma^2 I\)\(I\) (identity)Errors are i.i.d.
WLS\(\operatorname{Var}(\varepsilon_i) = \sigma_i^2\), uncorrelated\(\text{diag}(1/\sigma_i^2)\)Heteroscedastic, uncorrelated
GLS\(\operatorname{Var}(\varepsilon) = \sigma^2 \Omega\), general\(\Omega^{-1}\)Heteroscedastic + correlated

⚠️ Where Do Weights Come From?

In practice, \(\sigma_i^2\) is rarely known. Common approaches: (1) known from theory (e.g., Poisson: \(\sigma_i^2 \propto \mu_i\)), (2) estimated from residuals of an initial OLS fit, (3) modeled as a function of predictors. Incorrect weights can be worse than no weights.
