Baum-Welch Algorithm

EM for Hidden Markov Models — learning HMM parameters from observations
Advanced Classical ML HMM O(N²T) per iteration
1
Understanding the Concept
▼

A Hidden Markov Model (HMM) describes a system with two layers: a hidden sequence of states \(q_1, q_2, \ldots, q_T\) that evolves according to Markov transitions, and an observed sequence \(o_1, o_2, \ldots, o_T\) emitted probabilistically from each hidden state. Think of it like a broken weather machine behind a wall — you cannot see what the machine is doing, but you can feel whether it's sunny, rainy, or cloudy outside. The HMM tries to infer the hidden machine states from the observations.

The Baum-Welch algorithm solves the learning problem: given only observations, estimate the three parameter matrices \(\lambda = (\pi, A, B)\) — the initial state distribution, the state transition matrix, and the emission probability matrix. It is a specific instantiation of the Expectation-Maximization (EM) algorithm for HMMs.

Core Insight

If you knew the hidden state sequence, parameter estimation would be trivial (count-and-normalize). Since you don't, Baum-Welch computes a soft expectation of state occupancies (E-step), then re-estimates parameters as if those soft counts were real (M-step). This is guaranteed to increase the log-likelihood \(\log P(O|\lambda)\) at every iteration.

The Three HMM Problems

  • Evaluation (Forward algorithm): Given \(\lambda\), compute \(P(O|\lambda)\)
  • Decoding (Viterbi): Given \(\lambda\) and \(O\), find the most likely state path
  • Learning (Baum-Welch): Given \(O\), find \(\lambda^* = \underset{\lambda}{\arg\max}\; P(O|\lambda)\)

Baum-Welch solves problem three via iterative EM: it never uses labeled state sequences.

How It Works — E-step & M-step
▼

E-Step: Forward-Backward Algorithm

The E-step computes two key quantities using the current parameters \(\lambda\):

Forward variable \(\alpha_t(i)\): probability of observing \(o_1, \ldots, o_t\) AND being in state \(i\) at time \(t\):

$$\alpha_t(i) = P(o_1, \ldots, o_t, q_t = i \mid \lambda)$$

Backward variable \(\beta_t(i)\): probability of observing \(o_{t+1}, \ldots, o_T\) given state \(i\) at time \(t\):

$$\beta_t(i) = P(o_{t+1}, \ldots, o_T \mid q_t = i, \lambda)$$

From these, Baum-Welch computes the two posteriors needed for re-estimation:

State occupancy \(\gamma_t(i)\): posterior probability of being in state \(i\) at time \(t\):

$$\gamma_t(i) = \frac{\alpha_t(i)\,\beta_t(i)}{\sum_{j=1}^N \alpha_t(j)\,\beta_t(j)}$$

Transition posterior \(\xi_t(i,j)\): posterior probability of being in state \(i\) at \(t\) and state \(j\) at \(t+1\):

$$\xi_t(i,j) = \frac{\alpha_t(i)\,a_{ij}\,b_j(o_{t+1})\,\beta_{t+1}(j)}{\sum_{i'}\sum_{j'}\alpha_t(i')\,a_{i'j'}\,b_{j'}(o_{t+1})\,\beta_{t+1}(j')}$$

M-Step: Re-estimate Parameters

Using the soft counts from the E-step, update all parameters:

$$\hat{\pi}_i = \gamma_1(i)$$
$$\hat{a}_{ij} = \frac{\sum_{t=1}^{T-1} \xi_t(i,j)}{\sum_{t=1}^{T-1} \gamma_t(i)}$$
$$\hat{b}_j(k) = \frac{\sum_{t:\, o_t = k} \gamma_t(j)}{\sum_{t=1}^T \gamma_t(j)}$$
Numerical Stability

The forward/backward variables decay exponentially with \(T\) — underflow is catastrophic for long sequences. Always work in log-space or use scaling factors \(c_t = \frac{1}{\sum_i \alpha_t(i)}\) so that scaled \(\hat{\alpha}_t(i) = c_t \alpha_t(i)\) stays in \([0,1]\). The log-likelihood is then \(\log P(O|\lambda) = -\sum_t \log c_t\).

3
Why It Works — EM Guarantee & Math
▼

EM Lower Bound Argument

Baum-Welch maximizes \(\log P(O|\lambda)\) by introducing hidden variables \(Q\) (state sequences) and decomposing:

$$\log P(O|\lambda) = \mathcal{Q}(\lambda, \lambda^{\text{old}}) + H(\lambda, \lambda^{\text{old}})$$

where \(\mathcal{Q}\) is the expected complete-data log-likelihood (the EM auxiliary function) and \(H\) is a KL-divergence-like term that is always \(\leq 0\). The M-step maximizes \(\mathcal{Q}\), and by Jensen's inequality this guarantees \(\log P(O|\lambda^{\text{new}}) \geq \log P(O|\lambda^{\text{old}})\).

EM Auxiliary Function (Q-function)

$$\mathcal{Q}(\lambda, \lambda^{\text{old}}) = \sum_Q P(Q|O,\lambda^{\text{old}})\,\log P(O,Q|\lambda)$$

Because \(P(O,Q|\lambda)\) factors over time for HMMs, maximizing \(\mathcal{Q}\) decomposes into three independent maximizations over \(\pi\), \(A\), and \(B\).

Convergence Properties

  • Log-likelihood is monotonically non-decreasing each iteration
  • Converges to a local maximum (not guaranteed global)
  • Initialization matters — random restarts or heuristic init (K-means on emissions) are common
  • Typically converges in 10–100 iterations for moderate-sized problems
  • Convergence criterion: \(|\log P(O|\lambda^{\text{new}}) - \log P(O|\lambda^{\text{old}})| < \epsilon\)
Key Invariant

The forward-backward pass is \(O(N^2 T)\) per iteration (N states, T timesteps). The M-step is \(O(N^2 + NM)\) (M symbols). Total: \(O(N^2 T)\) per EM iteration — tractable for small-to-medium N, T.

Numerical Trace (3-state, T=4)

Let \(N=3\), \(T=4\), observations \(O = [0,1,0,1]\), two emission symbols \(M=2\). With scaled forward:

$$\hat{\alpha}_1(i) = c_1 \cdot \pi_i \cdot b_i(o_1), \quad c_1 = \left(\sum_i \pi_i b_i(o_1)\right)^{-1}$$

With \(\pi = [0.6, 0.3, 0.1]\), \(b_i(0) = [0.5, 0.4, 0.7]\):

\(\alpha'_1 = [0.6{\times}0.5,\; 0.3{\times}0.4,\; 0.1{\times}0.7] = [0.30, 0.12, 0.07]\), sum \(= 0.49\)

\(\hat{\alpha}_1 = [0.612, 0.245, 0.143]\). Scale factor \(c_1 = 1/0.49 \approx 2.04\).

After full forward-backward, \(\gamma_t(i)\) are proper posteriors summing to 1. M-step re-estimates \(A\) by dividing expected transition counts by expected state counts.

From-Scratch Implementation
▼

A minimal, numerically stable Baum-Welch implementation using scaled forward-backward:

import numpy as np
def baum_welch(O, N, M, n_iter=20, tol=1e-6):
"""Baum-Welch EM for discrete-emission HMM."""
T = len(O)
# Random init, row-normalize
pi = np.random.dirichlet(np.ones(N))
A = np.random.dirichlet(np.ones(N), size=N) # N×N
B = np.random.dirichlet(np.ones(M), size=N) # N×M
log_likelihoods = []
for _ in range(n_iter):
# ── E-step: scaled forward ─────────────────
alpha = np.zeros((T, N)); scales = np.zeros(T)
alpha[0] = pi * B[:, O[0]]
scales[0] = alpha[0].sum(); alpha[0] /= scales[0]
for t in range(1, T):
alpha[t] = (alpha[t-1] @ A) * B[:, O[t]]
scales[t] = alpha[t].sum(); alpha[t] /= scales[t]
# ── E-step: scaled backward ─────────────────
beta = np.ones((T, N))
for t in range(T-2, -1, -1):
beta[t] = A @ (B[:, O[t+1]] * beta[t+1])
beta[t] /= scales[t+1] # use same scale
# ── Compute γ and ξ ──────────────────────────
gamma = alpha * beta # T×N, unnorm
gamma /= gamma.sum(axis=1, keepdims=True)
xi = np.zeros((T-1, N, N))
for t in range(T-1):
num = alpha[t][:,None] * A * B[:,O[t+1]] * beta[t+1]
xi[t] = num / num.sum()
# ── M-step ───────────────────────────────────
pi = gamma[0]
A = xi.sum(0) / gamma[:-1].sum(0)[:,None]
for k in range(M):
B[:,k] = gamma[O==k].sum(0) / gamma.sum(0)
ll = -np.log(scales).sum()
log_likelihoods.append(ll)
if len(log_likelihoods)>1 and abs(ll-log_likelihoods[-2])
break
return pi, A, B, log_likelihoods
Production Usage

Use hmmlearn: from hmmlearn import hmm; model = hmm.CategoricalHMM(n_components=3); model.fit(X). For Gaussian emissions: hmm.GaussianHMM. Key hyperparameters: n_components (N states), n_iter, tol. Multiple random restarts recommended to escape local optima.

Key Takeaways & Interview Prep
▼

When to Use Baum-Welch / HMMs

  • Sequential data with latent discrete structure (speech, bioinformatics, NLP POS tagging)
  • No labeled state sequences available (unsupervised)
  • Number of states N is small (up to ~50); scales poorly with N

When NOT to Use

  • Long-range dependencies beyond first-order Markov (use higher-order HMMs or RNNs)
  • Continuous latent space (use Kalman filter / SSMs)
  • Large N — prefer deep sequence models (LSTM, Transformer)
Top Interview Questions

Q: Why does Baum-Welch guarantee monotone log-likelihood increase?
A: It is EM — the M-step maximizes a lower bound (the Q-function) on log P(O|λ). Jensen's inequality ensures the bound is tight at the current parameters, so any improvement in Q is a guaranteed improvement in log P(O|λ).

Q: What does γ_t(i) represent?
A: The posterior probability of being in hidden state i at time t given all observations: \(P(q_t = i | O, \lambda)\). It is computed as α_t(i)β_t(i) normalized.

Q: How do you handle numerical underflow?
A: Scale the forward/backward variables at each timestep by \(c_t = (\sum_i \alpha_t(i))^{-1}\). Log-likelihood = \(-\sum_t \log c_t\). Alternatively, work entirely in log-space with log-sum-exp.

Q: Does Baum-Welch find the global optimum?
A: No — it converges to a local maximum of the marginal likelihood P(O|λ). Use multiple random restarts or supervised initialization from labeled segments.
