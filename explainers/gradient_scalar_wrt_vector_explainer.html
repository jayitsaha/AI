1
Understanding the Gradient
▼

What is it? A scalar function \(f: \mathbb{R}^n \to \mathbb{R}\) takes a vector and outputs a single number (like a loss function or a dot product). The gradient \(\nabla_{\mathbf{x}} f\) is itself a vector that tells you, for each dimension, how much \(f\) increases if you nudge \(\mathbf{x}\) a tiny bit in that direction.

Analogy: Imagine standing on a hilly terrain. Your position is \(\mathbf{x} = (x_1, x_2)\) and the altitude at that point is \(f(\mathbf{x})\). The gradient is like a 2D arrow pointing in the direction of steepest uphill. If you want to roll a ball downhill to find the lowest valley (minimize loss), you go in the negative gradient direction. This is exactly what gradient descent does every iteration.

💡 If you remember one thing

The gradient \(\nabla_{\mathbf{x}} f(\mathbf{x})\) is the direction of steepest ascent. It is perpendicular to the level sets (contour lines) of \(f\). In ML, negating the gradient and taking a small step is gradient descent. Two key identities hold everywhere: $$\nabla_{\mathbf{x}}(\mathbf{a}^\top \mathbf{x}) = \mathbf{a}, \qquad \nabla_{\mathbf{x}}(\mathbf{x}^\top A\mathbf{x}) = (A + A^\top)\mathbf{x}$$

2
Core Mechanics & Layout Conventions
▼

Definition

Let \(\mathbf{x} \in \mathbb{R}^n\) and \(f: \mathbb{R}^n \to \mathbb{R}\). The gradient is the column vector of partial derivatives:

$$\nabla_{\mathbf{x}} f(\mathbf{x}) = \frac{\partial f}{\partial \mathbf{x}} = \begin{bmatrix} \frac{\partial f}{\partial x_1} \\ \frac{\partial f}{\partial x_2} \\ \vdots \\ \frac{\partial f}{\partial x_n} \end{bmatrix} \in \mathbb{R}^n$$

Numerator vs Denominator Layout

A persistent source of confusion: there are two conventions for how to arrange gradients and Jacobians.

ConventionShape of \(\partial f / \partial \mathbf{x}\) (scalar \(f\), vector \(\mathbf{x}\))Used by
Numerator layout (Jacobian form)Row vector \(1 \times n\)Some ML textbooks, numerics
Denominator layout (gradient form)Column vector \(n \times 1\)Most ML/deep learning literature
⚠️ Convention Warning

This explainer uses the denominator layout (gradient = column vector, same shape as \(\mathbf{x}\)). This matches PyTorch's .grad attribute and most ML papers. Mixing conventions mid-derivation is the #1 source of sign/shape errors in backprop derivations.

Why the Gradient is Perpendicular to Level Sets

A level set is the set of points where \(f(\mathbf{x}) = c\) (constant). If you move along a level set, \(f\) does not change, so the directional derivative along that tangent direction is zero. The gradient is zero in any tangent direction to the level set — meaning it must be orthogonal to all such directions, hence perpendicular to the level set itself.

🔑 Key Property

The gradient points in the direction of the steepest ascent. Its magnitude \(\|\nabla f\|\) equals the rate of change in that direction. For any unit vector \(\mathbf{u}\), the directional derivative \(D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}\) is maximized when \(\mathbf{u} = \nabla f / \|\nabla f\|\).

3
Key Gradient Identities (with Derivations)
▼

Identity 1: Linear form \(\nabla(\mathbf{a}^\top \mathbf{x}) = \mathbf{a}\)

Let \(f(\mathbf{x}) = \mathbf{a}^\top \mathbf{x} = \sum_{i=1}^n a_i x_i\). Taking the partial with respect to \(x_j\):

$$\frac{\partial f}{\partial x_j} = a_j \quad \Longrightarrow \quad \nabla_{\mathbf{x}}(\mathbf{a}^\top \mathbf{x}) = \mathbf{a}$$

Intuition: each component of the gradient tells you how fast \(f\) grows in that direction. For a linear function, that rate is just the coefficient \(a_j\). Constant regardless of \(\mathbf{x}\) — the loss surface is a flat hyperplane.

Identity 2: Quadratic form \(\nabla(\mathbf{x}^\top A \mathbf{x}) = (A + A^\top)\mathbf{x}\)

Let \(f(\mathbf{x}) = \mathbf{x}^\top A \mathbf{x} = \sum_{i,j} A_{ij} x_i x_j\). Differentiating with respect to \(x_k\):

$$\frac{\partial}{\partial x_k}\left(\sum_{i,j} A_{ij} x_i x_j\right) = \sum_j A_{kj} x_j + \sum_i A_{ik} x_i = (A\mathbf{x})_k + (A^\top \mathbf{x})_k$$

Collecting in vector form gives:

$$\nabla_{\mathbf{x}}(\mathbf{x}^\top A \mathbf{x}) = A\mathbf{x} + A^\top \mathbf{x} = (A + A^\top)\mathbf{x}$$

When \(A\) is symmetric (\(A = A^\top\)), this simplifies to \(2A\mathbf{x}\) — the matrix-calculus analog of \(d(ax^2)/dx = 2ax\).

Identity 3: Quadratic via scalar OLS loss

The OLS loss \(f(\mathbf{w}) = \|\mathbf{y} - X\mathbf{w}\|^2 = \mathbf{y}^\top\mathbf{y} - 2\mathbf{y}^\top X\mathbf{w} + \mathbf{w}^\top X^\top X \mathbf{w}\). Applying the two identities:

$$\nabla_{\mathbf{w}} f = -2X^\top \mathbf{y} + 2X^\top X \mathbf{w}$$

Setting to zero gives the normal equations \(X^\top X \mathbf{w} = X^\top \mathbf{y}\).

From-Scratch Code: Computing Gradients
▼

Below is a minimal NumPy implementation of the gradient for the two key forms, with numerical verification against finite differences.

import numpy as np
def grad_linear(a, x): # ∇(aᵀx) = a
return a.copy()
def grad_quadratic(A, x): # ∇(xᵀAx) = (A + Aᵀ)x
return (A + A.T) @ x
def grad_ols_loss(X, y, w): # ∇‖y - Xw‖² = -2Xᵀ(y - Xw)
residual = y - X @ w
return -2 * X.T @ residual
def numerical_grad(f, x, h=1e-5): # finite difference check
g = np.zeros_like(x)
for i in range(len(x)):
xp, xm = x.copy(), x.copy()
xp[i] += h; xm[i] -= h
g[i] = (f(xp) - f(xm)) / (2 * h)
return g
# --- Verify linear form ---
a = np.array([2.0, -1.0, 3.0])
x = np.array([1.0, 4.0, -2.0])
g_analytic = grad_linear(a, x) # → [2, -1, 3]
g_numeric = numerical_grad(lambda v: a @ v, x) # should match
assert np.allclose(g_analytic, g_numeric) # ✓

The finite-difference check perturbs each input dimension by ±h and measures the output change — a ground-truth sanity check for any analytic gradient formula.

🔑 PyTorch equivalent

x = torch.tensor([1., 4., -2.], requires_grad=True)
f = (a * x).sum()
f.backward()
x.grad → tensor([2., -1., 3.]) — matches \(\mathbf{a}\) exactly.

Key Takeaways & Connections
▼

Summary: The gradient \(\nabla_{\mathbf{x}} f\) compactly encodes how a scalar output changes with all inputs simultaneously. It is the foundation of every learning algorithm: gradient descent, backpropagation, Newton's method, and natural gradient all consume \(\nabla f\).

Geometric meaning: Gradient arrows are perpendicular to level sets. Moving along a level set costs zero change in \(f\); moving along the gradient direction maximizes the rate of change.

Two identities to memorize:
  • \(\nabla(\mathbf{a}^\top \mathbf{x}) = \mathbf{a}\) — gradient of a dot product is the constant vector.
  • \(\nabla(\mathbf{x}^\top A \mathbf{x}) = (A + A^\top)\mathbf{x}\) — gradient of a quadratic form.

💡 Connections to other topics

• Backpropagation is just repeated gradient computation via the chain rule.
• Gradient descent update: \(\mathbf{x} \leftarrow \mathbf{x} - \eta \nabla f(\mathbf{x})\).
• Jacobian: when \(f\) is vector-valued, the gradient generalises to a matrix \(\partial \mathbf{f} / \partial \mathbf{x}\).
• Hessian: the gradient of the gradient — a matrix of second derivatives used in Newton's method.
