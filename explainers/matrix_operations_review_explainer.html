Understanding Matrix Operations
▼

What are matrices? A matrix is a rectangular grid of numbers — rows and columns. Matrix operations are the rules for combining these grids. They are not exotic abstractions: every time a neural network transforms an input into an output, it performs matrix multiplication under the hood.

Three operations, three roles: Addition merges two matrices element-by-element (think blending two images pixel by pixel). Multiplication composes two transformations — this is the core computation of a neural network layer. Transpose flips a matrix along its diagonal, swapping rows for columns — it appears in gradient computations, attention score scaling, and covariance matrices.

If you remember one thing

Matrix multiplication \(\mathbf{A}\mathbf{B}\) computes the dot product of each row of \(\mathbf{A}\) with each column of \(\mathbf{B}\). The shapes must agree: if \(\mathbf{A}\) is \(m \times k\) and \(\mathbf{B}\) is \(k \times n\), the result \(\mathbf{C}\) is \(m \times n\). In a neural network, this is how \(k\) features are transformed into \(n\) hidden units for all \(m\) data points simultaneously.

The ML Connection

A dense (fully-connected) layer computes \(\mathbf{Y} = \mathbf{X}\mathbf{W}^\top + \mathbf{b}\). Every forward pass, every attention score matrix \(\mathbf{Q}\mathbf{K}^\top\), every gradient update — all reduce to matrix multiplication. Understand matmul and you understand the skeleton of deep learning.

How Each Operation Works
▼

Addition — Elementwise, Same Shape Required

Matrix addition is straightforward: add corresponding entries. Both matrices must have identical shapes. For \(m \times n\) matrices \(\mathbf{A}\) and \(\mathbf{B}\):

$$(\mathbf{A} + \mathbf{B})_{ij} = A_{ij} + B_{ij} \quad \text{for all } i,j$$

Example: \(\mathbf{A} = \begin{bmatrix}1&2\\3&4\end{bmatrix}\), \(\mathbf{B} = \begin{bmatrix}5&6\\7&8\end{bmatrix}\), so \(\mathbf{A}+\mathbf{B} = \begin{bmatrix}6&8\\10&12\end{bmatrix}\). Each position is independent — no row/column interaction.

Multiplication — Row × Column Dot Products

Shape rule: \(\mathbf{A}\) is \(m \times k\), \(\mathbf{B}\) is \(k \times n\) — the inner dimensions must match. Result \(\mathbf{C} = \mathbf{A}\mathbf{B}\) is \(m \times n\). Each output cell \(C_{ij}\) is the dot product of row \(i\) of \(\mathbf{A}\) with column \(j\) of \(\mathbf{B}\):

$$C_{ij} = \sum_{k=1}^{K} A_{ik} \cdot B_{kj}$$

For our \(2\times2\) example: \(C_{00} = 1{\cdot}5 + 2{\cdot}7 = 19\), \(C_{01} = 1{\cdot}6 + 2{\cdot}8 = 22\), \(C_{10} = 3{\cdot}5 + 4{\cdot}7 = 43\), \(C_{11} = 3{\cdot}6 + 4{\cdot}8 = 50\). Note: matmul is NOT commutative — \(\mathbf{A}\mathbf{B} \neq \mathbf{B}\mathbf{A}\) in general.

Transpose — Flip Along the Diagonal

The transpose \(\mathbf{A}^\top\) swaps row index and column index: \((\mathbf{A}^\top)_{ij} = A_{ji}\). A matrix of shape \(m \times n\) becomes \(n \times m\). Geometrically: reflecting the grid across the main diagonal.

$$\mathbf{A} = \begin{bmatrix}1&2\\3&4\end{bmatrix} \implies \mathbf{A}^\top = \begin{bmatrix}1&3\\2&4\end{bmatrix}$$
Key Property: Transpose Reversal

$$(\mathbf{A}\mathbf{B})^\top = \mathbf{B}^\top \mathbf{A}^\top$$

The order reverses. This is crucial in backpropagation: the gradient w.r.t. \(\mathbf{W}\) in a linear layer involves \(\mathbf{X}^\top\), not \(\mathbf{X}\). Verify: for our example, \((\mathbf{A}\mathbf{B})^\top = \begin{bmatrix}19&43\\22&50\end{bmatrix}\) and \(\mathbf{B}^\top\mathbf{A}^\top = \begin{bmatrix}19&43\\22&50\end{bmatrix}\). ✓

Linear Maps & Why Matmul Is Composition
▼

Every matrix encodes a linear map — a function \(f: \mathbb{R}^k \to \mathbb{R}^m\). The \(m \times k\) matrix \(\mathbf{A}\) maps a column vector \(\mathbf{x} \in \mathbb{R}^k\) to \(\mathbf{A}\mathbf{x} \in \mathbb{R}^m\) by taking dot products of \(\mathbf{x}\) with each row of \(\mathbf{A}\).

Matrix multiplication \(\mathbf{C} = \mathbf{A}\mathbf{B}\) is exactly function composition: apply \(\mathbf{B}\) first (map \(\mathbb{R}^n \to \mathbb{R}^k\)), then apply \(\mathbf{A}\) (map \(\mathbb{R}^k \to \mathbb{R}^m\)). The combined transformation \(\mathbf{C}\) maps \(\mathbb{R}^n \to \mathbb{R}^m\) directly.

$$(\mathbf{A}\mathbf{B})\mathbf{x} = \mathbf{A}(\mathbf{B}\mathbf{x}) \quad \text{(associativity — the core property)}$$

A neural network with layers \(\mathbf{W}_1, \mathbf{W}_2, \ldots\) composes linear maps. Without nonlinear activations, all layers collapse to a single matrix product — which is why activations are essential. Each \(\mathbf{W}_\ell \mathbf{x}\) applies one linear transformation in sequence.

Shape Pitfall

The inner dimensions must match for multiplication. \(\mathbf{A}_{m \times k}\,\mathbf{B}_{k \times n}\) — the \(k\) columns of \(\mathbf{A}\) must equal the \(k\) rows of \(\mathbf{B}\). The result shape "outer dimensions" \(m \times n\) is what remains after the inner \(k\) is consumed by the dot products. Memorise: (m×k) · (k×n) = (m×n). This is the most common bug in linear algebra code.

Transpose as Adjoint

The transpose makes the "adjoint" of the linear map: if \(\mathbf{A}\) maps \(\mathbb{R}^k \to \mathbb{R}^m\), then \(\mathbf{A}^\top\) maps \(\mathbb{R}^m \to \mathbb{R}^k\). In ML, if the forward pass is \(\mathbf{y} = \mathbf{A}\mathbf{x}\), the backward pass (gradient w.r.t. \(\mathbf{x}\)) uses \(\mathbf{A}^\top\). This is why the transpose reversal rule \((\mathbf{A}\mathbf{B})^\top = \mathbf{B}^\top\mathbf{A}^\top\) directly gives backpropagation gradients through composed layers.

Key Takeaways & ML Connections
▼

When each operation appears in ML

  • Addition: Bias addition (\(\mathbf{W}\mathbf{x} + \mathbf{b}\)); residual connections (\(\mathbf{x} + F(\mathbf{x})\) in ResNets); gradient accumulation.
  • Matmul: Every dense/linear layer; attention scores \(\mathbf{Q}\mathbf{K}^\top / \sqrt{d_k}\); embedding lookup (a matmul with a one-hot vector); convolutional layers (expressible as matmul via im2col).
  • Transpose: Gradient of a linear layer \(\partial L/\partial \mathbf{X} = \partial L/\partial \mathbf{Y} \cdot \mathbf{W}^\top\); symmetry in covariance matrices; converting between row-vector and column-vector conventions.
Efficiency insight

Matmul of shapes \((m \times k)\cdot(k \times n)\) costs \(O(mkn)\) multiplications. Modern GPUs are optimized for exactly this operation — batched matrix multiplication (BLAS/cuBLAS). Understanding shapes directly predicts training throughput. Larger \(m\) (batch size) amortizes kernel launch overhead; larger \(k\) or \(n\) scales FLOPs.

Three rules to memorize

1. Addition: same shape, elementwise.  2. Matmul shape: \((m\times k)\cdot(k\times n) = (m\times n)\) — inner dims must match.  3. Transpose reversal: \((\mathbf{A}\mathbf{B})^\top = \mathbf{B}^\top \mathbf{A}^\top\).

Code Trace
▼
import numpy as np
# Define two 2×2 matrices
A = np.array([[1, 2],
[3, 4]])
B = np.array([[5, 6],
[7, 8]])
# Matrix Addition — elementwise, shapes must match
C_add = A + B # [[6,8],[10,12]]
# Matrix Multiplication — (2×2)·(2×2) = (2×2)
C_mul = A @ B # [[19,22],[43,50]]
# C_mul[0,0] = A[0,:]·B[:,0] = 1*5 + 2*7 = 19
# C_mul[0,1] = A[0,:]·B[:,1] = 1*6 + 2*8 = 22
# Non-square: (2×3)·(3×2) = (2×2)
M = np.array([[1,2,3],[4,5,6]]) # shape (2,3)
N = np.array([[7,8],[9,10],[11,12]]) # shape (3,2)
MN = M @ N # [[58,64],[139,154]]
# Transpose
A_T = A.T # [[1,3],[2,4]]
# Transpose reversal: (AB)^T == B^T @ A^T
lhs = (A @ B).T # [[19,43],[22,50]]
rhs = B.T @ A.T # [[19,43],[22,50]]
np.allclose(lhs, rhs) # True
# Neural network forward pass
X = np.random.randn(32, 128) # batch=32, features=128
W = np.random.randn(64, 128) # 64 output neurons
Y = X @ W.T # (32×128)·(128×64) = (32×64)
