Variance Reduction via Averaging
The math behind why ensembles work — and what limits them
Intermediate Ensembles Part III · Classical ML Var = ρσ² + (1−ρ)σ²/B
1
Understanding the Concept

What is this? When we train multiple models (called an ensemble) and average their predictions, the noise in each individual model's predictions tends to cancel out. This makes the average much more reliable than any single model — but only up to a point determined by how similar the models are to each other.

Real-world analogy: Imagine asking 100 different people to estimate the temperature outside. If they all looked at the same thermometer (correlated), their answers will all be close to the same wrong value. But if each person looks at a different thermometer in a different part of town (decorrelated), their errors cancel out and the average is nearly perfect.

If you remember one thing
Averaging \(B\) correlated estimators reduces variance to \(\rho\sigma^2 + \frac{1-\rho}{B}\sigma^2\). The first term, \(\rho\sigma^2\), is an irreducible floor — no matter how many models you add, correlated errors stay. Decorrelation (Random Forests) attacks this floor.
The Core Formula
$$\operatorname{Var}\!\left(\bar{X}\right) = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2$$
where \(\rho\) = pairwise correlation between estimators, \(\sigma^2\) = individual variance, \(B\) = number of estimators.
2
How It Works — The Math Unpacked

Let \(X_1, X_2, \ldots, X_B\) be \(B\) estimators, each with mean \(\mu\), variance \(\sigma^2\), and pairwise correlation \(\rho\) (assumed identical for all pairs — the exchangeable assumption).

The sample mean is \(\bar{X} = \frac{1}{B}\sum_{i=1}^B X_i\). Expanding its variance:

$$\operatorname{Var}(\bar{X}) = \frac{1}{B^2}\operatorname{Var}\!\left(\sum_{i=1}^B X_i\right) = \frac{1}{B^2}\left[B\sigma^2 + B(B-1)\rho\sigma^2\right]$$
$$= \frac{\sigma^2}{B} + \frac{(B-1)}{B}\rho\sigma^2 = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2$$

The two terms tell the full story:

  • Irreducible term \(\rho\sigma^2\): persists regardless of \(B\). As \(B\to\infty\), the variance floor is exactly \(\rho\sigma^2\).
  • Reducible term \(\frac{(1-\rho)}{B}\sigma^2\): shrinks to 0 as \(B\to\infty\). This is the "free lunch" from averaging.
Common Misconception
"Adding more trees always helps." True for the reducible term — but if all trees share the same features (correlated), the \(\rho\sigma^2\) floor dominates and more trees give diminishing returns.

Special cases (important to know):

  • \(\rho = 0\) (independent): \(\operatorname{Var}(\bar{X}) = \sigma^2/B\) — full variance reduction, decreases as \(1/B\)
  • \(\rho = 1\) (identical copies): \(\operatorname{Var}(\bar{X}) = \sigma^2\) — no reduction at all
  • \(\rho = 0.5\), \(B\to\infty\): floor = \(0.5\sigma^2\) — only half the variance is ever reducible
3
Why Decorrelation Matters — Random Forests

Bagging (Bootstrap Aggregating) reduces variance by training each tree on a bootstrapped dataset. But the trees still see the same features at each split, so they tend to split on the same strong predictors → high \(\rho\).

Random Forests add random feature subsampling: at each split, only a random subset \(m \ll p\) of features is considered. This forces trees to find different decision boundaries → lower \(\rho\).

$$\Delta\operatorname{Var} = (\rho_{\text{Bagging}} - \rho_{\text{RF}})\,\sigma^2$$

This is the variance reduction delivered purely by decorrelation. The tradeoff: each individual tree may be slightly worse (higher \(\sigma^2\)) because it can't always use the best feature — but the reduction in \(\rho\) more than compensates.

The Random Forest Insight
RF's \(m = \lfloor\sqrt{p}\rfloor\) recommendation (classification) or \(m = p/3\) (regression) is tuned to hit the sweet spot: enough decorrelation to push \(\rho\) down, without so much randomness that individual tree variance \(\sigma^2\) explodes.

Key Takeaways
  • The variance of an average of \(B\) correlated estimators is \(\rho\sigma^2 + \frac{(1-\rho)\sigma^2}{B}\), not \(\sigma^2/B\).
  • As \(B \to \infty\), variance converges to \(\rho\sigma^2\) — the correlation floor, which is irreducible by adding more models.
  • To drive variance toward zero, you must decrease \(\rho\) — this is what Random Forests do via random feature subsampling.
  • Independent ensembles (\(\rho=0\)) achieve the ideal \(\sigma^2/B\) scaling. Perfectly correlated ensembles (\(\rho=1\)) achieve nothing.
  • The bias of the average equals the bias of each individual estimator (averaging does not affect bias).
