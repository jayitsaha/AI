Position-wise Feed-Forward Network (FFN)

Two linear layers with a ReLU in between — applied identically and independently to every token position
Foundational Transformers Deep Learning O(n·d·d_ff)
1
Understanding the Position-wise FFN
▼

What is it? Inside every Transformer block, right after the self-attention sub-layer, sits a small two-layer neural network. It takes each token's vector, blows it up to a wider hidden size, squashes the negative values to zero with ReLU, and projects it back down to the original size. Critically, it does this to every token separately, using the exact same weights for each one — hence "position-wise."

Analogy: Imagine a mailroom where every single letter — regardless of its position in the stack — passes through the identical stamping-and-sorting machine. The machine never looks at the letter next to it; it processes each envelope on its own, using the same fixed set of stamps. Attention is the step where letters get to "read" each other; the FFN is the step where each letter, alone, gets reprocessed by a fixed machine.

💡 If you remember one thing

The FFN is a per-token 2-layer MLP with a nonlinearity, applied with shared weights across all positions and all examples: $$\text{FFN}(x) = \max(0,\, xW_1 + b_1)\,W_2 + b_2$$ Only attention lets tokens exchange information; the FFN never does.

2
How It Works Internally
▼

Two Linear Layers, One Nonlinearity

For a token vector \(x \in \mathbb{R}^{d_{model}}\), the FFN computes \(z = xW_1 + b_1\) where \(W_1 \in \mathbb{R}^{d_{model}\times d_{ff}}\). This expands the representation into a much wider space — in the original Transformer, \(d_{model}=512\) expands to \(d_{ff}=2048\), a 4× expansion. Then ReLU zeroes out every negative entry: \(h = \max(0, z)\). Finally, a second matrix \(W_2 \in \mathbb{R}^{d_{ff}\times d_{model}}\) projects back down: \(y = hW_2 + b_2\).

Numerical Trace (toy dimensions \(d_{model}{=}4,\ d_{ff}{=}16\))

Take a token vector \(x=[0.62,-0.41,0.85,0.13]\). After \(xW_1+b_1\) it becomes a 16-dimensional vector \(z\) with a mix of positive and negative entries. ReLU kills roughly half of them (the sign pattern depends on \(W_1\)), leaving a sparse \(h\). The second matrix then re-combines the surviving 16 "features" back into a 4-dimensional output \(y\), which is added to the residual stream. The interactive walkthrough below computes every one of these numbers live.

Design Decision: Why Two Layers and Not One?

A single linear layer \(xW\) is just a linear map — stacking it on top of attention's linear maps would collapse into one bigger linear map, adding no expressive power. The ReLU in between is what makes the FFN a genuine nonlinear function, letting the network carve piecewise-linear decision regions in representation space. The 4× widen-then-shrink shape is an inverted bottleneck: temporarily over-parameterize to increase capacity, then compress back to keep the residual stream a fixed width.

An Alternative View: Key–Value Memory

Geva et al. (2020) showed each row of \(W_1\) acts like a pattern-detecting "key" — it fires (via ReLU) when the input resembles a stored pattern — and the corresponding row of \(W_2\) is the "value" that gets added to the output when that key fires. Under this view, the FFN sub-layer is a large, differentiable associative memory with \(d_{ff}\) slots, and the position-wise application means every token independently queries the same memory bank.

🔑 Key Property

The FFN is applied with identical weights at every position and is completely sequence-length invariant — mathematically equivalent to two consecutive 1×1 convolutions across the position axis. It never reads a neighboring token's vector.

3
Why It Works — The Math
▼

Forward Pass

For each position \(i\) in the sequence, with \(x_i \in \mathbb{R}^{d_{model}}\):

$$z_i = x_iW_1+b_1 \in \mathbb{R}^{d_{ff}} \qquad h_i=\max(0,z_i) \qquad y_i = h_iW_2+b_2 \in \mathbb{R}^{d_{model}}$$

Stacking all positions into a matrix \(X\in\mathbb{R}^{n\times d_{model}}\), the whole sequence is processed in one batched matrix multiply: \(\text{FFN}(X)=\max(0,XW_1+b_1)W_2+b_2\), with \(W_1,b_1,W_2,b_2\) broadcast identically to every row.

Backward Pass (Gradients)

Given the upstream gradient \(\frac{\partial L}{\partial y}\), backprop through the two linear layers and the ReLU:

$$\frac{\partial L}{\partial W_2}=h^\top\frac{\partial L}{\partial y}\qquad \frac{\partial L}{\partial b_2}=\frac{\partial L}{\partial y}\qquad \frac{\partial L}{\partial h}=\frac{\partial L}{\partial y}W_2^\top$$
$$\frac{\partial L}{\partial z}=\frac{\partial L}{\partial h}\odot \mathbb{1}[z>0]\qquad \frac{\partial L}{\partial W_1}=x^\top\frac{\partial L}{\partial z}\qquad \frac{\partial L}{\partial x}=\frac{\partial L}{\partial z}W_1^\top$$

The ReLU derivative \(\mathbb{1}[z>0]\) is a hard 0/1 gate — this is also why dead ReLUs (a unit that outputs 0 for every input) stop learning: their gradient is permanently zero.

The Position-wise Invariant, Formally

Because \(W_1,b_1,W_2,b_2\) are shared and each row of \(X\) is transformed independently, the Jacobian of the FFN output with respect to the input sequence is block-diagonal:

$$\frac{\partial y_i}{\partial x_j} = 0 \text{ for } i\neq j, \qquad \frac{\partial y_i}{\partial x_i} = \text{diag}(\mathbb{1}[z_i>0])\, W_1^\top \, W_2^\top \text{ (chain rule, dense within a position)}$$

This block-diagonal structure is the mathematical definition of "position-wise": information only mixes within a token's own channels, never across tokens.

⚠️ Common Misconception

"The FFN mixes information across the sequence." False. Only self-attention mixes across positions. The FFN sub-layer is strictly per-token — swap the order of two tokens in the sequence and the FFN output for each token is unchanged (though attention's output would change).

Key Takeaways
▼

Where it lives: Every Transformer encoder/decoder block has exactly one FFN sub-layer, following self-attention, each wrapped in a residual connection and normalization: \(x \leftarrow \text{Norm}(x + \text{FFN}(x))\).

  • Roughly 2/3 of a Transformer's parameters typically live in the FFN sub-layers (\(2\,d_{model}d_{ff}\) weights vs. \(4d_{model}^2\) for attention projections).
  • Modern LLMs often replace ReLU with GELU (BERT, GPT) or gated variants like SwiGLU (LLaMA, PaLM) for smoother gradients and better quality per FLOP.
  • The 4× expansion ratio is an empirical default, not a law — some models use 2.66× (with gating) or up to 8× in sparse Mixture-of-Experts FFNs.
💡 Division of Labor

Attention mixes information across positions (token ↔ token). The FFN mixes information across channels within one position (feature ↔ feature). Stacking these two complementary operations, block after block, is the core Transformer recipe.

Code Trace

import numpy as np
def relu(z):
return np.maximum(0, z)
def position_wise_ffn(x, W1, b1, W2, b2):
# x: (d_model,) W1: (d_model, d_ff) W2: (d_ff, d_model)
z = x @ W1 + b1 # linear 1: expand to d_ff (4x)
h = relu(z) # nonlinearity: kill negatives
y = h @ W2 + b2 # linear 2: project back to d_model
return y
# Applied independently to every position — SAME weights each time
X = np.stack([x_pos1, x_pos2, x_pos3]) # (seq_len, d_model)
Y = np.stack([position_wise_ffn(x, W1, b1, W2, b2) for x in X])
# Equivalent, fully batched (what frameworks actually run):
Y = relu(X @ W1 + b1) @ W2 + b2 # (seq_len, d_model)
