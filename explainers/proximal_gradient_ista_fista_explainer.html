Understanding Proximal Gradient Methods
▼

What is it? Many real-world optimization problems (e.g., LASSO regression, compressed sensing, total-variation denoising) ask you to minimize a sum of two parts: a smooth, differentiable part (easy to differentiate) and a non-smooth, non-differentiable part (like an absolute value or indicator function). Standard gradient descent can't handle the non-smooth piece. Proximal gradient methods solve this by alternating: take a gradient step on the smooth part, then apply the proximal operator on the non-smooth part.

Analogy: Imagine you're rolling a ball down a bumpy hill (the smooth loss surface), but the floor also has sticky patches — regions where the ball snaps to exactly zero (sparsity from L1 regularization). Each iteration: (1) let physics roll the ball a little downhill (gradient step), then (2) snap it to the nearest allowed position (proximal step). FISTA is like giving the ball extra momentum so it overshoots slightly and finds the minimum faster.

💡 If you remember one thing

Proximal gradient = gradient descent on the smooth part + proximal operator on the non-smooth part. For L1 regularization, the proximal operator is soft-thresholding: \(\text{prox}_{\lambda t}(u) = \text{sign}(u)\cdot\max(|u|-\lambda t, 0)\). This is what drives coefficients to exactly zero, producing sparsity. ISTA converges at \(O(1/k)\); FISTA's Nesterov momentum boosts this to \(O(1/k^2)\) — a free quadratic speedup.

🔑 Problem Setup

Minimize \(F(x) = g(x) + h(x)\) where \(g\) is convex and \(L\)-smooth (\(\nabla g\) is \(L\)-Lipschitz), and \(h\) is convex but possibly non-smooth. LASSO: \(g(x) = \frac{1}{2}\|Ax-b\|_2^2\), \(h(x) = \lambda\|x\|_1\).

The Algorithm Internals — ISTA Step by Step
▼

The Proximal Operator — Definition

For a convex function \(h\), the proximal operator with step size \(t\) is:

$$\text{prox}_{th}(v) = \underset{x}{\operatorname{argmin}}\left\{h(x) + \frac{1}{2t}\|x - v\|_2^2\right\}$$

This asks: "starting from \(v\) (the gradient-stepped point), move to the nearest point that trades off minimizing \(h\) against staying close to \(v\)." The \(\frac{1}{2t}\) term is the proximity weight — smaller \(t\) means stay closer to \(v\).

For L1: Soft-Thresholding

When \(h(x) = \lambda\|x\|_1\), the proximal operator decomposes coordinate-wise. For each scalar \(u\):

$$\text{prox}_{\lambda t}(u) = \text{sign}(u)\cdot\max(|u| - \lambda t,\, 0)$$

This is soft-thresholding with threshold \(\tau = \lambda t\). If \(|u| \leq \tau\): the output is exactly 0 (coefficient zeroed = sparsity). If \(|u| > \tau\): the coefficient is shrunk by exactly \(\tau\) toward zero.

ISTA Algorithm (one full iteration)

Given current iterate \(x_k\), step size \(t = 1/L\):

$$x_{k+1} = \text{prox}_{th}\!\left(x_k - t\,\nabla g(x_k)\right)$$
  1. Compute gradient: \(\nabla g(x_k)\) — the gradient of the smooth part.
  2. Gradient step: \(x_{k+\frac{1}{2}} = x_k - t\,\nabla g(x_k)\) — move downhill on \(g\).
  3. Proximal step: \(x_{k+1} = \text{prox}_{th}(x_{k+\frac{1}{2}})\) — apply \(h\)'s proximal operator.

Numerical Trace (2D LASSO)

Problem: \(g(x) = \frac{1}{2}(2x_1-3)^2 + \frac{1}{2}(x_2-1.5)^2\), \(h(x) = 0.5\|x\|_1\), \(L=4\), \(t=0.25\), \(\tau = 0.125\). Starting at \(x_0=(0,0)\):

$$\nabla g(x_0) = [4\cdot0 - 6,\ 0 - 1.5] = [-6,\ -1.5]$$
$$x_{1/2} = [0 + 0.25\cdot 6,\ 0 + 0.25\cdot 1.5] = [1.5,\ 0.375]$$
$$x_1 = \text{ST}([1.5, 0.375],\ 0.125) = [1.375,\ 0.250]$$

The \(x_1\) coordinate hits its optimum \(x_1^* = 1.375\) in one step (strong signal, large Lipschitz ratio). The \(x_2\) coordinate (weaker signal, factor-4 smaller curvature) takes many ISTA steps to converge.

⚠️ Step Size Requirement

ISTA requires step size \(t \leq 1/L\) where \(L\) is the Lipschitz constant of \(\nabla g\) (i.e., \(\|\nabla^2 g\| \leq L\)). For LASSO, \(L = \|A^\top A\|_2 = \lambda_{\max}(A^\top A)\). Too large a step causes divergence; too small causes slow convergence. In practice, use backtracking line search to estimate \(L\) dynamically.

3
FISTA — Nesterov Acceleration & O(1/k²) Rate
▼

The Big Idea: Momentum Without Cost

FISTA (Fast Iterative Shrinkage-Thresholding Algorithm), introduced by Beck & Teboulle (2009), adds a single momentum term to ISTA. This costs almost nothing computationally but improves the convergence rate from \(O(1/k)\) to \(O(1/k^2)\) — an asymptotically free speedup. The key is Nesterov's momentum sequence.

FISTA Algorithm

Maintain two sequences: \(x_k\) (the actual iterates) and \(y_k\) (the "momentum point"). Initialize \(x_0 = y_1\), \(t_1 = 1\):

$$x_{k} = \text{prox}_{th}\!\left(y_k - t\,\nabla g(y_k)\right)$$
$$t_{k+1} = \frac{1 + \sqrt{1 + 4t_k^2}}{2}$$
$$y_{k+1} = x_k + \frac{t_k - 1}{t_{k+1}}\,(x_k - x_{k-1})$$

The momentum coefficient \(\beta_k = (t_k - 1)/t_{k+1}\) grows as \(t_k \approx (k+1)/2\) for large \(k\), so \(\beta_k \to 1\) (pure momentum in the limit). The sequence \(t_k\) satisfies \(t_k^2 - t_{k+1}^2 \leq -t_{k+1}\), which is the algebraic condition needed for the O(1/k²) proof.

Convergence Rates (Formal)

$$\text{ISTA: } F(x_k) - F(x^*) \leq \frac{L\|x_0 - x^*\|_2^2}{2k}$$
$$\text{FISTA: } F(x_k) - F(x^*) \leq \frac{2L\|x_0 - x^*\|_2^2}{(k+1)^2}$$

Both bounds are tight. The improvement is not just constant-factor — it's a genuinely different polynomial rate. For \(k = 100\) iterations: ISTA guarantees error \(\leq C/100\), FISTA guarantees \(\leq 2C/10201 \approx C/5100\) — a 50× speedup.

Numerical Example (k=5)

At k=5 in our 2D LASSO: ISTA error ≈ 0.0282, FISTA error ≈ 0.0060. The momentum point \(y_5\) extrapolates beyond \(x_5\) using \(\beta_5 \approx 0.599\). This overshoot is precisely calibrated by the sequence \(t_k\) to cancel out error at the optimal rate.

📐 Why Nesterov Momentum Works

The proof (Beck & Teboulle 2009) uses a Lyapunov function argument: define \(\phi_k = t_k^2(F(x_k) - F(x^*))\). FISTA's design ensures \(\phi_k\) is non-increasing, while the quadratic growth of \(t_k \sim k/2\) forces \(F(x_k) - F(x^*) \leq \phi_k / t_k^2 \to 0\) at rate \(O(1/k^2)\). The momentum sequence \(t_k\) is the exact algebraic key that makes this telescope.

Key Takeaways & When to Use
▼

When to Use Proximal Gradient / FISTA

  • LASSO / Elastic Net: large-scale regression with L1 or L1+L2 penalty — default choice.
  • Compressed sensing: recover sparse signals from few measurements (\(h = \lambda\|x\|_1\)).
  • Total Variation denoising: \(h(x) = \lambda\|\nabla x\|_1\) (prox via Chambolle's algorithm).
  • Matrix factorization with nuclear norm: \(h = \lambda\|X\|_*\) (prox = soft SVD threshold).
  • Any problem where \(h\) has a closed-form prox but \(\nabla h\) is infinite/undefined.

Quick Comparison

Method Rate Complexity/iter Handles non-smooth?
Gradient descent O(1/k) O(nd) No
ISTA O(1/k) O(nd) + prox Yes (prox)
FISTA O(1/k²) O(nd) + prox Yes (prox)
ADMM O(1/k) O(nd) + linear solve Yes (distributed)
Subgradient O(1/√k) O(nd) Yes (slow)
🎯 Decision Rule

Use FISTA whenever you can compute the proximal operator of \(h\) in closed form and need accuracy — it's almost always better than ISTA at no extra cost. Use ADMM when the problem is separable or distributed. Use subgradient only as a last resort when no prox is available.

From-Scratch Code Trace
▼

From-scratch NumPy implementation of both ISTA and FISTA for the general composite problem \(F = g + h\) with L1 regularization (LASSO). Step through active lines in the info trace below.

import numpy as np
def soft_threshold(x, tau):
"""Proximal operator for lambda*||x||_1 — applied coordinate-wise."""
return np.sign(x) * np.maximum(np.abs(x) - tau, 0.0)
def ista(A, b, lam, n_iter=200, tol=1e-8):
"""ISTA for LASSO: min 0.5||Ax-b||^2 + lam*||x||_1"""
L = np.linalg.norm(A, ord=2) ** 2 # Lipschitz constant = sigma_max(A)^2
t = 1.0 / L # step size
tau = lam * t # soft-threshold parameter
x = np.zeros(A.shape[1]) # initialize at 0
for _ in range(n_iter):
grad = A.T @ (A @ x - b) # gradient of g(x) = 0.5||Ax-b||^2
x_new = soft_threshold(x - t * grad, tau) # gradient + prox step
if np.linalg.norm(x_new - x) < tol: break # convergence check
x = x_new
return x
def fista(A, b, lam, n_iter=200, tol=1e-8):
"""FISTA (Beck & Teboulle 2009): O(1/k^2) convergence for LASSO"""
L = np.linalg.norm(A, ord=2) ** 2
t = 1.0 / L
tau = lam * t
x = np.zeros(A.shape[1]) # current iterate
y = x.copy() # momentum point (starts = x)
t_k = 1.0 # Nesterov sequence (t_1 = 1)
for _ in range(n_iter):
grad_y = A.T @ (A @ y - b) # gradient at momentum point y
x_new = soft_threshold(y - t * grad_y, tau) # prox step from y
t_new = (1 + np.sqrt(1 + 4 * t_k**2)) / 2 # update Nesterov seq
beta = (t_k - 1) / t_new # momentum coefficient
y_new = x_new + beta * (x_new - x) # momentum extrapolation
if np.linalg.norm(x_new - x) < tol: break
x, y, t_k = x_new, y_new, t_new
return x
Key Lines
Line 8: Lipschitz constant via largest singular value of A. This is exact for quadratic g(x).
Line 13: Gradient of the smooth part only — \(\nabla g = A^\top(Ax - b)\). Never differentiate h.
Line 14: Both gradient descent (on g) and proximal step (on h) happen atomically in one line.
Lines 30–32: FISTA's three extra lines vs ISTA: update \(t_k\), compute \(\beta_k\), extrapolate \(y_{k+1}\). Cost: 2 floats + vector add.
