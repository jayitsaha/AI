Occam's Razor & Model Complexity

Prefer the simplest model that fits the data

01 The Core Idea ▾

Occam's Razor, attributed to the 14th-century friar William of Ockham, is a principle of parsimony: among all hypotheses that explain the observed data equally well, prefer the simplest one. In machine learning, "hypotheses" are models, and "simplest" means fewest parameters, lowest VC dimension, or shortest description length.

A classic analogy: if you hear hoof prints on a trail, you should infer horses — not zebras. Both explain the sound, but horses are the simpler, more probable explanation in most contexts. Introducing a zebra hypothesis requires extra complexity that is not justified by evidence.

Key Insight: Simplicity is not just elegance — it is a probabilistic prior. Simpler models occupy less hypothesis space and are thus more likely a priori. A model with fewer degrees of freedom is easier to falsify, and its explanatory power is therefore more meaningful when it succeeds.

In practice, this translates into a fundamental tension: complex models can memorize training data perfectly, but they generalize poorly. Simple models may underfit, missing genuine structure. Occam's razor provides a principled guide for where to land on this spectrum.

02 Bayesian Occam & Minimum Description Length ▾

1. Bayesian Occam's Razor

Under a complexity-penalizing prior \(P(\mathcal{H})\), Bayes' theorem gives us the posterior over model classes:

$$P(\mathcal{H} | \mathcal{D}) \propto P(\mathcal{D} | \mathcal{H}) \cdot P(\mathcal{H})$$

The term \(P(\mathcal{D} | \mathcal{H})\) is the marginal likelihood (model evidence), obtained by integrating over all parameter settings:

$$P(\mathcal{D} | \mathcal{H}) = \int P(\mathcal{D} | \theta, \mathcal{H}) \, P(\theta | \mathcal{H}) \, d\theta$$

A complex model spreads its probability mass thinly across a huge parameter space. It may achieve high likelihood at the optimum \(\hat{\theta}\), but the integral is dominated by the vast wasteland of poor-fitting parameter settings. A simpler model concentrates probability mass where it matters and wins on evidence — unless the complex model fits dramatically better.

2. Minimum Description Length (MDL)

MDL, due to Rissanen, formalizes Occam's razor via information theory. The best model is the one that yields the shortest two-part code — encoding both the model and the data given the model:

$$L_{\text{total}} = L(\mathcal{D} | \mathcal{H}) + L(\mathcal{H})$$

By Shannon's theorem, description length equals \(-\log_2 P\), so minimizing \(L_{\text{total}}\) is equivalent to maximizing \(\log P(\mathcal{D}|\mathcal{H}) + \log P(\mathcal{H})\), which is exactly maximizing the log posterior. MDL and Bayesian model selection are therefore two sides of the same coin.

Warning: Occam's razor does NOT say "the simplest model is always best." It says prefer simplicity all else being equal. If a more complex model fits significantly better, it may still win — both the evidence integral and the MDL code length will reflect this. The razor is a tiebreaker weighted toward simplicity, not a veto on complexity.
03 Overfitting as an Occam Violation ▾

A polynomial of degree 15 can pass exactly through 10 training points with zero residual error. This looks impressive — until you plot it between the points. The curve oscillates wildly, assigning near-zero probability to any unseen data. This is an Occam violation: the model chose a needlessly complex hypothesis from an astronomically large hypothesis class when a far simpler one would explain the data just as well (or nearly so).

The bias-variance decomposition quantifies this mathematically. For any estimator \(\hat{f}\) and squared loss:

$$\mathbb{E}\left[(y - \hat{f}(x))^2\right] = \text{Bias}^2[\hat{f}] + \text{Var}[\hat{f}] + \sigma^2$$

High-degree polynomials → low bias (can represent almost any function) → high variance (sensitive to each training point) → poor generalization. The irreducible noise \(\sigma^2\) cannot be reduced regardless of model complexity.

Model Selection Criteria as Operational Occam: AIC and BIC add an explicit penalty term \(\lambda \cdot k\) (where \(k\) = number of parameters) to the negative log-likelihood, operationalizing Occam's razor directly:
  • AIC: \(-2\ln\hat{L} + 2k\) — penalizes each parameter equally
  • BIC: \(-2\ln\hat{L} + k\ln n\) — penalizes more heavily as the dataset grows, consistent with Bayesian model selection

L1 regularization (Lasso) produces sparse models by driving irrelevant coefficients to exactly zero — selecting the minimal relevant feature set. L2 (Ridge) shrinks all coefficients toward zero, similarly encoding a simplicity prior. Both are direct algorithmic embodiments of Occam's razor.

05 Key Takeaways ▾
  • Simpler models have stronger inductive bias = stronger prior = fewer bits needed to describe them. The prior encodes Occam's preference before any data is seen.
  • Occam's razor is not dogma — it is a probabilistic inference tool. The marginal likelihood and MDL both quantify the tradeoff between fit and complexity automatically.
  • Practical manifestations include: L1/L2 regularization, cross-validation model selection, information criteria (AIC, BIC, WAIC), and Bayesian model comparison via Bayes factors.
  • The Bias-Variance tradeoff is the empirical face of Occam's razor: simplicity trades increased bias for reduced variance, and the optimal balance is the Occam optimum.
  • Related frameworks: No Free Lunch theorem (no model is universally best, so prior knowledge = Occam structure matters), PAC learning (sample complexity depends on hypothesis class size), and VC dimension (a measure of hypothesis class complexity).
  • In deep learning, implicit Occam regularization arises from SGD's preference for flat minima, dropout, early stopping, and weight decay — the razor is always operative, even when not explicitly invoked.
