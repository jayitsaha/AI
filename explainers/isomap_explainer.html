Isomap

Geodesic distances & k-nearest-neighbour graph — unrolling curved manifolds with shortest paths
Intermediate Unsupervised Learning Dimensionality Reduction O(n² log n + n³)
1
Understanding the Concept
▾

Isomap is a non-linear dimensionality reduction algorithm that preserves the intrinsic geometry of data lying on a curved manifold. The core insight: straight-line (Euclidean) distance between two points on a curved surface is misleading — it cuts through empty space rather than following the surface. The correct distance is the geodesic distance, measured along the manifold itself.

💡 The Key Analogy

Think of two cities on opposite sides of a mountain range. The straight-line (Euclidean) distance cuts through rock. The real travel distance (geodesic) follows roads over mountain passes. Isomap measures travel distances, not crow-fly distances.

Isomap approximates geodesic distances by building a k-nearest-neighbour (k-NN) graph over the data. Within each neighbourhood, Euclidean distances are valid (the manifold is locally flat). Dijkstra's or Floyd-Warshall shortest-path algorithm then stitches these local hops into global geodesic distances. Finally, Classical MDS (Multidimensional Scaling) embeds all points in a low-dimensional Euclidean space that best preserves those geodesic distances.

🔑 One-Line Summary

Isomap = k-NN graph + shortest-path geodesics + MDS → the true low-dimensional structure that PCA and Euclidean-distance methods miss on curved manifolds.

The classic demonstration is the Swiss roll: a 2D rectangle wrapped into a 3D spiral. PCA projects it into a 2D oval (smearing distant manifold points together). Isomap unrolls it perfectly back to the rectangle because geodesic distances along the roll's surface correctly separate points.

How It Works Internally
▾

Step 1 — Build the k-NN Graph

For each of the \(n\) data points \(\mathbf{x}_i \in \mathbb{R}^D\), find the \(k\) nearest neighbours by Euclidean distance. Connect \(\mathbf{x}_i \to \mathbf{x}_j\) with edge weight \(\|\mathbf{x}_i - \mathbf{x}_j\|_2\). The result is a sparse weighted graph \(G = (V, E)\). The hyper-parameter \(k\) controls the trade-off: too small → disconnected graph; too large → shortcuts across manifold folds.

Step 2 — Shortest-Path Geodesic Distances

Run all-pairs shortest paths on \(G\). The geodesic distance matrix \(D_G \in \mathbb{R}^{n \times n}\) is defined as:

$$d_G(i, j) = \min_{\text{paths } p: i \to j} \sum_{(u,v) \in p} \|\mathbf{x}_u - \mathbf{x}_v\|_2$$

For small \(n\), Floyd-Warshall runs in \(O(n^3)\). For large \(n\), Dijkstra from each node runs in \(O(n(|E| + n \log n))\). Points not connected to the main component remain at \(\infty\) — a sign that \(k\) is too small.

Step 3 — Classical MDS on \(D_G\)

Double-centre \(D_G^{(2)}\) (the matrix of squared geodesic distances) to form the gram matrix:

$$B = -\tfrac{1}{2} H D_G^{(2)} H, \quad H = I - \tfrac{1}{n}\mathbf{1}\mathbf{1}^\top$$

Compute the eigendecomposition \(B = V \Lambda V^\top\). Retain the top \(d\) positive eigenvalues \(\lambda_1 \ge \cdots \ge \lambda_d > 0\). The \(d\)-dimensional embedding is:

$$Y = V_d \Lambda_d^{1/2} \in \mathbb{R}^{n \times d}$$
⚠️ Design Decision: k vs ε neighbourhoods

Isomap also admits ε-ball graphs (connect if distance < ε). k-NN graphs are more robust to non-uniform sampling density; ε-balls are more principled geometrically. In practice, k-NN is preferred because it guarantees every point has exactly k neighbours.

The Math Behind It
▾

Let the data \(\{{\mathbf{x}_i}\}_{i=1}^n \subset \mathbb{R}^D\) lie on a smooth \(d\)-dimensional Riemannian manifold \(\mathcal{M}\) isometrically embeddable in \(\mathbb{R}^D\). The geodesic distance between two points \(p, q \in \mathcal{M}\) is:

$$d_{\mathcal{M}}(p,q) = \inf_{\gamma} \int_0^1 \|\gamma'(t)\|_2 \, dt$$

where \(\gamma: [0,1] \to \mathcal{M}\) is a smooth curve with \(\gamma(0)=p\), \(\gamma(1)=q\).

MDS Optimisation Objective

Classical MDS finds \(Y = [\mathbf{y}_1, \ldots, \mathbf{y}_n]^\top \in \mathbb{R}^{n \times d}\) minimising the strain:

$$\text{Strain}(Y) = \left\| B - Y Y^\top \right\|_F$$

where \(B\) is the double-centred squared-distance matrix. The solution is closed-form: retain the top \(d\) eigenvectors of \(B\).

Convergence Guarantee

Tenenbaum et al. (2000) proved: as \(n \to \infty\) and \(k \sim O(\log n)\), the graph geodesic \(d_G(i,j) \to d_{\mathcal{M}}(\mathbf{x}_i, \mathbf{x}_j)\) uniformly on compact manifolds. The recovery is asymptotically exact for isometrically embeddable manifolds.

📐 Key Equations Summary

k-NN adjacency: \(w_{ij} = \|\mathbf{x}_i - \mathbf{x}_j\|_2\) if \(j \in \text{kNN}(i)\), else \(\infty\)
Geodesic matrix: \(D_G = \text{ShortestPaths}(W)\)
Centering matrix: \(H = I_n - \tfrac{1}{n}\mathbf{1}\mathbf{1}^\top\)
Gram matrix: \(B = -\tfrac{1}{2} H D_G^{\odot 2} H\)
Embedding: \(Y = V_d \Lambda_d^{1/2}\) where \(B = V \Lambda V^\top\)

Complexity

k-NN construction: \(O(Dn^2)\) brute force, \(O(Dn \log n)\) with KD-trees. All-pairs shortest paths: \(O(n^3)\) Floyd-Warshall or \(O(kn^2 \log n)\) Dijkstra. Eigendecomposition of \(B\): \(O(n^3)\) full, \(O(n^2 d)\) with LAPACK's partial routines. Total dominant cost: \(\boldsymbol{O(n^3)}\).

From-Scratch Code
▾
import numpy as np from scipy.sparse.csgraph import shortest_path from scipy.spatial.distance import cdist def isomap(X, n_components=2, n_neighbors=10): """Isomap from scratch. X: (n_samples, n_features).""" n = X.shape[0] # Step 1: Build k-NN graph (weight = Euclidean distance) D_euc = cdist(X, X) # (n, n) pairwise distances W = np.full((n, n), np.inf) # infinity = no edge for i in range(n): nn_idx = np.argsort(D_euc[i])[1:n_neighbors+1] # exclude self W[i, nn_idx] = D_euc[i, nn_idx] # directed; symmetrize below W = np.minimum(W, W.T) # undirected symmetric graph # Step 2: All-pairs shortest paths (geodesic distances) D_geo = shortest_path(W, method='D', directed=False) # Dijkstra # D_geo[i,j] = geodesic distance on manifold (or inf if disconnected) # Step 3: Classical MDS on D_geo D2 = D_geo ** 2 # squared distance matrix H = np.eye(n) - np.ones((n,n)) / n # centering matrix B = -0.5 * H @ D2 @ H # double-center: gram matrix # Eigendecomposition (B is symmetric positive semi-definite if manifold is flat) eigvals, eigvecs = np.linalg.eigh(B) # sorted ascending eigvals = eigvals[::-1]; eigvecs = eigvecs[:, ::-1] # descending # Keep top d positive eigenvalues pos = eigvals[:n_components] Y = eigvecs[:, :n_components] * np.sqrt(np.maximum(pos, 0)) return Y # (n, d) embedding

Key Takeaways & When to Use
▾

✅ Use Isomap When
  • Data lies on an isometrically embeddable manifold (no folding back on itself)
  • You need to preserve global geometry (unlike t-SNE/UMAP which distort global structure)
  • Dataset is small/medium (< 10k points — \(O(n^3)\) is a bottleneck)
  • You want a principled, theoretically-grounded reduction
⚠️ Avoid Isomap When
  • Manifold has holes or handles — geodesics can detour wildly
  • Data is noisy — graph shortcuts corrupt geodesics
  • You need to embed new (out-of-sample) points — Isomap has no natural projection formula
  • \(n > 10\text{k}\) — use Landmark Isomap or UMAP instead
