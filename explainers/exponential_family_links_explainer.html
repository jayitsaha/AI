Understanding the Exponential Family
▼

What is it? Many statistical distributions — Normal, Bernoulli (coin flip), Poisson (event counts), Gamma (waiting times) — look completely different on the surface. The exponential family is a unified mathematical template that shows all these distributions are secretly the same shape, just with different parameters. A Generalized Linear Model (GLM) harnesses this fact: instead of building separate regression models for each outcome type, you get one framework that works for all of them.

Analogy: Think of a USB-C port. Many different devices (phones, laptops, cameras) have different internal designs, but they all communicate through the same plug standard. The exponential family is that plug standard for probability distributions. The link function is the cable that connects your linear regression formula \(\eta = x^\top\beta\) to the mean \(\mu\) of whichever distribution you're using.

💡 If you remember one thing

Every exponential family distribution has the form \(f(y;\theta,\phi) = \exp\!\left(\frac{y\theta - b(\theta)}{a(\phi)} + c(y,\phi)\right)\). The function \(b(\theta)\) is the cumulant generator: its first derivative gives the mean \(\mu = b'(\theta)\) and its second derivative gives the variance function \(V(\mu) = b''(\theta)\), so one function encodes all distributional moments.

The Four Key Players

Normal
\(b(\theta) = \theta^2/2\)
Mean: \(\mu = \theta\)
Var: \(\sigma^2\) (constant)
Bernoulli / Logistic
\(b(\theta) = \log(1+e^\theta)\)
Mean: \(\mu = \sigma(\theta)\)
Var: \(\mu(1-\mu)\)
Poisson
\(b(\theta) = e^\theta\)
Mean: \(\mu = e^\theta\)
Var: \(\mu\)
Gamma
\(b(\theta) = -\log(-\theta)\)
Mean: \(\mu = -1/\theta\)
Var: \(\mu^2\phi\)

Link Functions & the GLM Structure
▼

Three Components of a GLM

A GLM has exactly three parts: (1) a random component — the response \(y\) follows an exponential family distribution; (2) a systematic component — the linear predictor \(\eta = x^\top\beta\) is a linear combination of the covariates; (3) a link function \(g\) that connects them: \(g(\mu) = \eta\).

$$g(\mu) = \eta = x^\top\beta \qquad \Longleftrightarrow \qquad \mu = g^{-1}(\eta)$$

The link function must map the valid range of \(\mu\) onto all of \(\mathbb{R}\) (because \(\eta\) is unconstrained). For a probability \(\mu \in (0,1)\), we need a function from \((0,1) \to \mathbb{R}\); for a count \(\mu > 0\), we need \((0,\infty) \to \mathbb{R}\).

Why Not Just Use OLS Everywhere?

Three reasons. First, linear regression can predict probabilities outside \([0,1]\) or negative counts — GLMs prevent this structurally. Second, variance in OLS is assumed constant; real outcomes have variance that scales with the mean (counts: \(\text{Var} \propto \mu\); proportions: \(\text{Var} \propto \mu(1-\mu)\)). Third, the link function makes the systematic component genuinely linear on the right scale (e.g., log-linear for multiplicative effects).

Common Link Functions

You can use any valid link for any exponential family distribution, but the canonical link arises naturally from the distribution's own structure (detailed in Card 3). Common choices:

🔑 Key Property

The canonical link is special: when you use it, the sufficient statistic for \(\beta\) is simply \(X^\top y\) — the same as in ordinary regression. This makes the score equations (Fisher scoring) the most tractable and guarantees that the information matrix has the simplest form \(X^\top W X\) where \(W = \operatorname{diag}(w_i)\) are observation weights.

The Math — Mean, Variance, and Canonical Links
▼

Deriving Mean and Variance from \(b(\theta)\)

Let \(\ell(\theta) = \log f(y;\theta,\phi) = \frac{y\theta - b(\theta)}{a(\phi)} + c(y,\phi)\). Score equations give \(\mathbb{E}[\partial\ell/\partial\theta] = 0\), which yields:

$$\mathbb{E}[Y] = \mu = b'(\theta)$$

Differentiating again and using \(\mathbb{E}[\partial^2\ell/\partial\theta^2] + \mathbb{E}[(\partial\ell/\partial\theta)^2] = 0\) (the information identity):

$$\operatorname{Var}(Y) = b''(\theta)\cdot a(\phi)$$

This is profound: a single scalar function \(b(\theta)\) encodes both the mean via its first derivative and the variance via its second derivative. The dispersion \(a(\phi)\) scales the variance but does not affect \(\mu\).

Why the Canonical Link is \(\theta(\mu)\)

The canonical link is defined as the function \(g\) such that \(g(\mu) = \theta\), the natural parameter. Since \(\mu = b'(\theta)\), the canonical link is the inverse function of \(b'\):

$$g_{\text{canonical}}(\mu) = \theta(\mu) = (b')^{-1}(\mu)$$

Worked Example — Bernoulli

For Bernoulli: \(b(\theta) = \log(1+e^\theta)\).

Step 1 — Mean: \(\mu = b'(\theta) = \frac{e^\theta}{1+e^\theta} = \sigma(\theta)\) (sigmoid). ✓

Step 2 — Variance: \(b''(\theta) = \sigma(\theta)(1-\sigma(\theta)) = \mu(1-\mu)\). ✓

Step 3 — Canonical link: invert \(\mu = \frac{e^\theta}{1+e^\theta}\) to get \(\theta = \log\frac{\mu}{1-\mu}\) — this is exactly the logit function. ✓

Numerical check (\(\theta = 0.5\)): \(\mu = e^{0.5}/(1+e^{0.5}) \approx 0.6225\), \(b''(0.5) = 0.6225 \times 0.3775 \approx 0.2350 = \mu(1-\mu)\). Verified above.

Variance Functions \(V(\mu)\)

Because \(b''(\theta) = V(\mu)\) (as a function of the mean), the variance function tells you how variance scales with the mean — crucial for model adequacy:

$$V(\mu) = \begin{cases} 1 & \text{Normal (constant)} \\ \mu(1-\mu) & \text{Bernoulli (bell-shaped in } \mu) \\ \mu & \text{Poisson (linear)} \\ \mu^2 & \text{Gamma (quadratic)} \end{cases}$$
⚠️ Common Pitfall

Using a non-canonical link does not make the model wrong — it changes the shape of the fitted curve and the interpretation of \(\beta\). Canonical links often give simpler score equations and more interpretable coefficients (e.g., log-odds ratios for logistic regression), but the probit link (for Bernoulli) or identity link (for Poisson) are sometimes more natural scientifically.

IRLS — How GLMs Are Fitted

GLMs are fitted by Iteratively Reweighted Least Squares (IRLS). At each iteration, form a working response \(z_i = \hat{\eta}_i + (y_i - \hat{\mu}_i)\,g'(\hat{\mu}_i)\) and weights \(w_i = 1/[V(\hat{\mu}_i)\,g'(\hat{\mu}_i)^2]\), then solve the weighted least squares problem \(\hat{\beta} = (X^\top W X)^{-1} X^\top W z\). This converges to the MLE under mild conditions. When using the canonical link, \(g'(\mu) = 1/V(\mu)\), so \(w_i = V(\hat\mu_i)\) and the update is simplest.

From Scratch — NumPy GLM Building Blocks

import numpy as np
# ── Cumulant functions b(theta) ───────────────────────────────────
def b_normal(theta): return 0.5 * theta**2 # b'=theta=mu, b''=1
def b_bernoulli(theta): return np.log1p(np.exp(theta)) # numerically stable
def b_poisson(theta): return np.exp(theta) # b'=b''=e^theta
def b_gamma(theta): return -np.log(-theta) # theta<0 required
# ── Mean: mu = b'(theta) ─────────────────────────────────────────
def mu_normal(theta): return theta
def mu_bernoulli(theta): return np.exp(theta) / (1 + np.exp(theta)) # sigmoid
def mu_poisson(theta): return np.exp(theta)
def mu_gamma(theta): return -1.0 / theta
# ── Variance function V(mu) = b''(theta) ─────────────────────────
def V_normal(mu): return np.ones_like(mu) # constant
def V_bernoulli(mu): return mu * (1 - mu) # max at mu=0.5
def V_poisson(mu): return mu # linear
def V_gamma(mu): return mu**2 # quadratic
# ── Canonical link functions g(mu) = theta(mu) ───────────────────
def link_normal(mu): return mu # identity
def link_bernoulli(mu): return np.log(mu/(1-mu)) # logit
def link_poisson(mu): return np.log(mu) # log
def link_gamma(mu): return -1.0/mu # reciprocal
# ── IRLS: fit a GLM with canonical link ──────────────────────────
def irls_canonical(X, y, mu_fn, V_fn, link_fn, n_iter=20, tol=1e-8):
"""Iteratively Reweighted Least Squares for canonical-link GLMs."""
n, p = X.shape
beta = np.zeros(p) # initialize coefficients
for _ in range(n_iter):
eta = X @ beta # linear predictor
mu = mu_fn(eta) # fitted means
W = np.diag(V_fn(mu)) # IRLS weight matrix
z = eta + (y - mu) / V_fn(mu) # working response
Xw = W @ X # weighted design
beta_new = np.linalg.lstsq(Xw, W @ z, rcond=None)[0]
if np.linalg.norm(beta_new - beta) < tol: break
beta = beta_new
return beta
# ── Verify: Poisson GLM on toy data ──────────────────────────────
np.random.seed(42)
X = np.column_stack([np.ones(50), np.linspace(0, 2, 50)])
beta_true = [0.5, 1.2]
y = np.random.poisson(np.exp(X @ beta_true))
beta_hat = irls_canonical(X, y, mu_poisson, V_poisson, link_poisson)
print(f"True: {beta_true}, Estimated: {beta_hat.round(3)}") # ≈ [0.5, 1.2]

Production — statsmodels GLM

import statsmodels.api as sm
import numpy as np
# Logistic regression (Binomial family, canonical logit link)
X = sm.add_constant(np.random.randn(200, 3))
y_binary = (np.random.rand(200) > 0.5).astype(int)
logit_model = sm.GLM(y_binary, X, family=sm.families.Binomial()).fit()
print(logit_model.summary())
# Output: log-odds coefficients; exp(coef) gives odds ratios
# Poisson regression (log link — canonical)
y_counts = np.random.poisson(3, size=200)
poisson_model = sm.GLM(y_counts, X, family=sm.families.Poisson()).fit()
# exp(coef) = multiplicative rate ratio
# Gamma regression (log link, non-canonical but often preferred)
y_pos = np.abs(np.random.randn(200)) + 0.1
gamma_log = sm.GLM(y_pos, X,
family=sm.families.Gamma(link=sm.families.links.Log())).fit()
# ⚠️ Canonical Gamma link is reciprocal (1/mu); log link more interpretable
# scikit-learn: only Gaussian, Bernoulli, Poisson supported
from sklearn.linear_model import PoissonRegressor
sk_poisson = PoissonRegressor(alpha=0.1).fit(X[:, 1:], y_counts)
# alpha = L2 regularisation on beta; uses log link internally
⚠️ Common Gotcha

In statsmodels, the default Gamma family uses the inverse (reciprocal) canonical link. In most applied work, the log link is preferred for Gamma because \(\exp(\beta_j)\) is a multiplicative effect on the mean, which is easier to interpret. Always specify the link explicitly: family=sm.families.Gamma(link=sm.families.links.Log()).

Key Takeaways & Interview Tips
▼

When to use each distribution:

  • Normal + identity link: Continuous, unbounded response, approximately symmetric errors (OLS)
  • Bernoulli + logit link: Binary outcomes (0/1), click-through rate, disease presence
  • Poisson + log link: Non-negative integer counts, especially when mean ≈ variance
  • Gamma + log link: Positive, right-skewed continuous outcomes (insurance claims, survival times, prices)

Key interview questions and answers:

  • Q: What is the canonical link for Poisson? A: The log link. The natural parameter is \(\theta = \log\mu\), so \(\eta = \log\mu\) and \(\mu = e^\eta\).
  • Q: Why is the logit the canonical link for Bernoulli? A: Because inverting \(\mu = e^\theta/(1+e^\theta)\) gives \(\theta = \log[\mu/(1-\mu)]\) — the log-odds.
  • Q: What does \(b''(\theta)\) represent? A: The variance function \(V(\mu)\); it tells you how variance grows with the mean.
  • Q: What is IRLS? A: The standard MLE fitting algorithm for GLMs — iteratively solve weighted least squares using current \(\hat\mu\) as weights. Equivalent to Fisher scoring.
  • Q: Can you use a non-canonical link? A: Yes. The model is still valid; you lose some computational simplicity and the sufficient statistic is no longer \(X^\top y\), but interpretation may be more natural (e.g., log link for Gamma gives multiplicative effects).
🔑 The Unifying Insight

Every GLM fits by minimizing a member of the deviance family — the GLM analogue of least-squares loss. For Normal, deviance = RSS. For Bernoulli, deviance = cross-entropy. For Poisson, deviance = Poisson log-likelihood ratio. All derive from the same exponential family log-likelihood template via \(\ell \propto y\theta - b(\theta)\).
