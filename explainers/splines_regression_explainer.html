1
Understanding Splines
▼

What is a spline? A spline is a piecewise polynomial — instead of fitting one big polynomial to all your data (which tends to wiggle wildly), you fit smaller, simpler polynomials on sub-intervals and stitch them together at special join points called knots. The stitching is done carefully so the pieces look seamless: the curve is continuous, and depending on the spline type, the first and second derivatives match at each knot too.

Analogy: Think of a flexible metal ruler (a draughtsman's spline) held in place by weights at a few points. Between weights it follows a smooth curve, and at each weight the curve bends seamlessly. The weights are the knots. A linear spline is like a connect-the-dots with straight lines. A cubic spline bends the ruler smoothly. A B-spline lets you control the ruler locally — moving one weight only affects the nearby curve.

💡 If you remember one thing

Splines trade global polynomial power for local flexibility. Knots split the domain into intervals; the order of the polynomial controls smoothness. A natural cubic spline enforces \(S''=0\) at the boundaries so the fit stays linear beyond the data range.

Four Spline Families at a Glance

  • Linear spline (C⁰): Piecewise linear; continuous but corners at knots.
  • Cubic spline (C²): Piecewise cubic; continuous through second derivative. Needs 2 extra boundary conditions.
  • Natural cubic spline: Cubic spline with \(S''=0\) at the two boundary knots — the curve extrapolates linearly.
  • B-spline: A basis representation for splines with compact support — each basis function is non-zero only over a few intervals. The curve is a weighted sum of these local bump functions.

How Splines Work Internally
▼

Knots and Intervals

Place \(K\) interior knots \(\xi_1 < \xi_2 < \cdots < \xi_K\) inside the domain \([a,b]\). This splits the x-axis into \(K+1\) intervals. On each interval \([\xi_k, \xi_{k+1}]\) you fit a polynomial of degree \(d\). For a cubic spline, \(d=3\).

Smoothness Constraints

At each interior knot, the left-hand and right-hand polynomials must agree in value and in their first \(d-1\) derivatives. For cubic splines this is continuity of \(S, S', S''\). Each smoothness constraint removes one free parameter, so a cubic spline has \(4(K+1) - 3K = K + 4\) free parameters in total.

🔑 Degrees of Freedom

A cubic spline with \(K\) interior knots has \(K + 4\) degrees of freedom. Adding 2 natural boundary conditions (\(S''=0\) at each end) reduces this to \(K + 2\) — exactly the dimension of the natural cubic spline basis.

B-Spline Basis — Local Support

Any spline can be written as a linear combination of B-spline basis functions \(B_{k,d}(x)\). These are defined recursively (Cox–de Boor formula). The key property: \(B_{k,d}(x) > 0\) only on the span of \(d+1\) consecutive knots. Moving a single coefficient only deforms a local region of the curve — unlike a global polynomial or even the truncated power basis for ordinary cubic splines.

⚠️ Knot Placement Matters

Too few knots → underfitting (the model can't follow the data's curvature). Too many knots → overfitting. Common strategies: evenly-spaced quantiles of \(x\), or choosing knots by cross-validation.

The Math — Construction & Basis
▼

Natural Cubic Spline via Tridiagonal System

Given data \((x_0,y_0),\ldots,(x_n,y_n)\) with \(h_i = x_{i+1}-x_i\), define \(M_i = S''(x_i)\). The continuity of \(S'\) at interior knots gives:

$$h_{i-1}M_{i-1} + 2(h_{i-1}+h_i)M_i + h_i M_{i+1} = 3\!\left(\frac{y_{i+1}-y_i}{h_i} - \frac{y_i-y_{i-1}}{h_{i-1}}\right), \quad i=1,\ldots,n-1$$

Natural boundary conditions add \(M_0 = 0\) and \(M_n = 0\), yielding a symmetric positive-definite tridiagonal linear system — solvable in \(O(n)\) time. Once all \(M_i\) are known, each cubic piece is:

$$S_i(x) = y_i + b_i(x-x_i) + M_i\frac{(x-x_i)^2}{2} + \frac{M_{i+1}-M_i}{6h_i}(x-x_i)^3$$

where \(b_i = \frac{y_{i+1}-y_i}{h_i} - \frac{h_i}{3}(2M_i+M_{i+1})\).

B-Spline Basis (Cox–de Boor Recursion)

Given an extended knot sequence \(\tau_0 \le \tau_1 \le \cdots\), define degree-0 basis functions:

$$B_{k,0}(x) = \begin{cases}1 & \tau_k \le x < \tau_{k+1}\\ 0 & \text{otherwise}\end{cases}$$

and for degree \(d \ge 1\):

$$B_{k,d}(x) = \frac{x - \tau_k}{\tau_{k+d}-\tau_k}\,B_{k,d-1}(x) + \frac{\tau_{k+d+1}-x}{\tau_{k+d+1}-\tau_{k+1}}\,B_{k+1,d-1}(x)$$

The spline curve is then \(S(x) = \sum_k c_k B_{k,d}(x)\), where coefficients \(c_k\) are found by least-squares. The B-spline basis forms a partition of unity: \(\sum_k B_{k,d}(x) = 1\) everywhere.

📐 Partition of Unity

B-spline basis functions sum to 1 at every point: \(\sum_k B_{k,d}(x) = 1\). This means the curve is a convex combination of control points when all coefficients are equal — it lies within the convex hull of the control polygon.

Key Takeaways & When to Use
▼

Hierarchy of smoothness:

  • Linear spline — C⁰: fit is continuous, derivative jumps at knots. Use for piecewise-linear trends.
  • Cubic spline — C²: visually smooth, requires 2 boundary conditions (not-a-knot, clamped, or natural).
  • Natural cubic spline — C² + zero curvature at ends. Best default for regression; reduces boundary artefacts.
  • B-splines — Compact support; numerically stable; the standard basis for smooth regression and GAMs.

When to use splines instead of polynomials:

  • Data has local structure (different curvature in different regions).
  • Runge's phenomenon makes high-degree global polynomials unstable.
  • You want to add smoothness as a regularisation term (penalised splines / thin-plate splines).
💡 In Practice

Use scipy.interpolate.CubicSpline or patsy.bs() / mgcv in R for regression splines. Penalised B-splines (P-splines) add a roughness penalty \(\lambda \int [S''(x)]^2 dx\) to control smoothness automatically via cross-validation.

Code Trace — Natural Cubic Spline
▼
import numpy as np
# Knots / data points (natural cubic spline interpolates exactly)
x = np.array([0., 1., 2., 3.]) # knot x-positions
y = np.array([0., 1., 0., 1.]) # knot y-values
h = np.diff(x) # h = [1, 1, 1]
# Build tridiagonal system for second derivatives M_i
n = len(x) - 1 # 3 intervals
A = np.zeros((n+1, n+1))
A[0,0] = 1; A[n,n] = 1 # natural BC: M_0=M_n=0
for i in range(1, n):
A[i,i-1]=h[i-1]; A[i,i]=2*(h[i-1]+h[i]); A[i,i+1]=h[i]
# RHS: finite difference of slopes
rhs = np.zeros(n+1)
for i in range(1, n):
rhs[i] = 3*((y[i+1]-y[i])/h[i] - (y[i]-y[i-1])/h[i-1])
# Solve → M = [0., -2., 2., 0.]
M = np.linalg.solve(A, rhs) # O(n) with Thomas algorithm
# Cubic coefficients on each piece [x_i, x_{i+1}]
for i in range(n):
a = y[i]
b = (y[i+1]-y[i])/h[i] - h[i]*(2*M[i]+M[i+1])/3
c = M[i] / 2
d = (M[i+1]-M[i]) / (6*h[i])
# S_i(x) = a + b*(x-xi) + c*(x-xi)^2 + d*(x-xi)^3
