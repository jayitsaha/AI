Linear-Chain CRF

Conditional Random Field for Sequence Labeling — discriminative, globally normalized
Advanced Classical ML Sequence Modeling O(T·K²) inference
1
Understanding the Concept

A Linear-Chain CRF is a discriminative probabilistic model for labeling sequences. Given an input sequence \(\mathbf{x} = (x_1, \ldots, x_T)\) (e.g., words in a sentence), it outputs a joint distribution over label sequences \(\mathbf{y} = (y_1, \ldots, y_T)\) (e.g., POS tags or NER tags), modelling \(P(\mathbf{y} \mid \mathbf{x})\) directly.

Unlike a Naive Bayes or HMM, a CRF never models \(P(\mathbf{x})\). It instead learns a score for every possible label sequence and converts scores to probabilities via a global normalizer called the partition function \(Z(\mathbf{x})\).

Key Concept

A linear-chain CRF defines: $$P(\mathbf{y} \mid \mathbf{x}) = \frac{1}{Z(\mathbf{x})} \exp\!\Bigl(\sum_{t=1}^{T} \sum_k \lambda_k\, f_k(y_{t-1}, y_t, \mathbf{x}, t)\Bigr)$$ where \(f_k\) are feature functions, \(\lambda_k\) are learned weights, and \(Z(\mathbf{x}) = \sum_{\mathbf{y}'} \exp(\cdots)\) is the partition function summing over all possible label sequences.

Real-World Analogy

Imagine grading an essay by reading each word in context of its neighbors and assigning a grammar role. A plain per-word classifier would grade each word independently and might tag "New" as an adjective even when followed by "York" (which signals a proper noun pair). A CRF "sees" the whole labeling at once and says: "Globally, the sequence B-ORG → I-ORG scores much higher than ADJ → NNP, so I prefer that."

If You Remember One Thing

A CRF is a log-linear model with a global normalization that lets it capture arbitrary overlapping features of the whole input while making predictions that are globally consistent across the sequence.

How It Works — Internal Mechanisms

Feature Functions

Feature functions \(f_k(y_{t-1}, y_t, \mathbf{x}, t)\) return real values (often 0/1 indicators). Examples:

  • Transition feature: f(y_{t-1}=B-PER, y_t=I-PER, x, t) = 1 — adjacent labels are a valid BIO pair
  • Observation feature: f(y_{t-1}, y_t=NN, x, t) = 1 if x_t ends in "-tion"
  • Contextual feature: f(y_t=NNP, x, t) = 1 if x_{t-1} = "President"

The score of a complete label sequence is the sum of all weighted feature activations: $$\text{score}(\mathbf{y}, \mathbf{x}) = \sum_{t=1}^{T} \mathbf{w}^\top \mathbf{f}(y_{t-1}, y_t, \mathbf{x}, t) = \sum_{t=1}^T \psi_t(y_{t-1}, y_t)$$ where \(\psi_t(y_{t-1}, y_t)\) is shorthand for the local potential at position \(t\).

Forward-Backward Algorithm (Computing Z and Marginals)

Naively summing over all \(K^T\) sequences is exponential. The linear-chain structure enables dynamic programming:

$$\alpha_t(y) = \sum_{y'} \alpha_{t-1}(y') \cdot \exp\!\bigl(\psi_t(y', y)\bigr)$$

The partition function is \(Z(\mathbf{x}) = \sum_y \alpha_T(y)\), computed in \(O(T K^2)\). Backward messages \(\beta_t(y)\) give marginals \(P(y_t, y_{t+1} \mid \mathbf{x})\).

Viterbi Decoding (Argmax)

At test time, find the highest-scoring sequence: $$\hat{\mathbf{y}} = \underset{\mathbf{y}}{\arg\max}\; P(\mathbf{y} \mid \mathbf{x}) = \underset{\mathbf{y}}{\arg\max}\; \text{score}(\mathbf{y}, \mathbf{x})$$ Replace \(\sum\) with \(\max\) in the DP recurrence — same \(O(TK^2)\) complexity.

Training: Maximize Log-Likelihood

Given labeled data \(\{(\mathbf{x}^{(i)}, \mathbf{y}^{(i)})\}\), we maximize: $$\mathcal{L}(\mathbf{w}) = \sum_i \Bigl[\text{score}(\mathbf{y}^{(i)}, \mathbf{x}^{(i)}) - \log Z(\mathbf{x}^{(i)})\Bigr] - \frac{\|\mathbf{w}\|^2}{2\sigma^2}$$ The gradient decomposes as empirical counts minus model-expected counts: $$\frac{\partial \mathcal{L}}{\partial w_k} = \sum_i \Bigl[\underbrace{\sum_t f_k(y_{t-1}^{(i)}, y_t^{(i)}, \mathbf{x}^{(i)}, t)}_{\text{empirical}} - \underbrace{\sum_t \mathbb{E}_{P}[f_k]}_{\text{model expected}}\Bigr]$$ The model-expected counts are computed via forward-backward. The objective is convex in \(\mathbf{w}\).

Common Mistake

Locally-normalized models (like MEMMs) suffer from the label bias problem: states with fewer transitions absorb all probability mass. CRFs avoid this entirely because normalization is global across the whole sequence.

The Math — Key Formulas & Derivations
CRF Distribution
$$P(\mathbf{y} \mid \mathbf{x};\mathbf{w}) = \frac{\exp\!\Bigl(\displaystyle\sum_{t=1}^T \mathbf{w}^\top \mathbf{f}(y_{t-1}, y_t, \mathbf{x}, t)\Bigr)}{Z(\mathbf{x};\mathbf{w})}$$
$$Z(\mathbf{x};\mathbf{w}) = \sum_{\mathbf{y}' \in \mathcal{Y}^T} \exp\!\Bigl(\sum_{t=1}^T \mathbf{w}^\top \mathbf{f}(y'_{t-1}, y'_t, \mathbf{x}, t)\Bigr)$$

Log-Likelihood & Its Gradient

Log-probability for one example:

$$\ell(\mathbf{w}) = \underbrace{\sum_{t=1}^T \mathbf{w}^\top \mathbf{f}(y_{t-1}, y_t, \mathbf{x}, t)}_{\text{numerator (score)}} - \underbrace{\log Z(\mathbf{x};\mathbf{w})}_{\text{log partition}}$$

Gradient w.r.t. weight \(w_k\):

$$\frac{\partial \ell}{\partial w_k} = \underbrace{\sum_{t} f_k(y_{t-1}, y_t, \mathbf{x}, t)}_{\text{gold counts}} - \underbrace{\sum_{t}\sum_{y', y} P(y_{t-1}{=}y', y_t{=}y \mid \mathbf{x})\, f_k(y', y, \mathbf{x}, t)}_{\text{model expected counts}}$$

The second term uses edge marginals \(P(y_{t-1}, y_t \mid \mathbf{x})\) from forward-backward — no approximation needed.

Numerical Trace (Tiny Example)

Sentence: "Paris is beautiful", tags: \(K = 3\) → {B-LOC, O, ADJ}. Suppose one feature per bigram tag pair. Let score matrix (log potentials) at each position be:

$$\psi_1 = \begin{bmatrix} 2.1 & -\infty & -\infty \\ -\infty & 0.5 & 0.8 \\ -\infty & 0.3 & 0.1 \end{bmatrix}$$

Forward pass (log-space): \(\log\alpha_1(\text{B-LOC}) = 2.1\),\; \(\log\alpha_1(O) = 0.5\),\; \(\log\alpha_1(\text{ADJ}) = 0.3\). At \(t=2\):

$$\log\alpha_2(y) = \text{logsumexp}_{y'}\!\bigl(\log\alpha_1(y') + \psi_2(y', y)\bigr)$$

\(\log Z = \text{logsumexp}(\log\alpha_T)\). Viterbi uses \(\max\) instead of logsumexp. Gradient: gold counts from \((\text{B-LOC, O, ADJ})\) path minus model expected counts from marginals.

Convexity Guarantee

The CRF log-likelihood is concave in \(\mathbf{w}\) (log-partition is convex; score is linear → negated log-partition + linear = concave). L-BFGS converges to the global optimum. No local minima problem (unlike neural nets).

Key Takeaways & When to Use

Use CRF when:

  • Labels are interdependent (BIO schemes, POS constraints)
  • You have rich, hand-crafted features (morphology, gazetteers)
  • Dataset is small-to-medium and interpretability matters
  • You need a convex objective with global optimum guarantee

Avoid CRF when:

  • Labels are independent per token (softmax per position suffices)
  • You need deep representation learning — use BiLSTM-CRF or BERT+CRF instead
  • Sequence is extremely long — O(TK²) becomes expensive for large K

Related Topics

  • HMM — generative predecessor (models P(x,y)); CRF avoids independence assumptions
  • MEMM — locally normalized; suffers label bias; CRF fixes this
  • BiLSTM-CRF — replaces hand features with neural emissions; CRF layer on top
  • Structured SVM — margin-based alternative with same inference machinery
The CRF Legacy

Lafferty et al. (2001) CRFs dominated NER/POS for a decade. Modern systems still use a CRF output layer on top of BERT/RoBERTa to enforce label-transition constraints — the viterbi/forward-backward machinery is unchanged.
