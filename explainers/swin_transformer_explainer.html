Swin Transformer

Hierarchical Vision Transformer with Shifted Windows
Foundational Computer Vision Deep Learning O(N) complexity
1
Understanding Swin Transformer
▼

What is it? Swin Transformer is a powerful deep learning architecture for computer vision tasks like image classification, object detection, and segmentation. It builds upon the success of the original Transformer model (originally for NLP) but adapts it efficiently for images.

The Problem with Vision Transformers (ViT): The original ViT treats an image as a sequence of fixed-size patches, applying self-attention globally. This leads to quadratic complexity with respect to the number of patches (image size), making it computationally expensive for high-resolution images. It also lacks a built-in hierarchy, which is crucial for capturing multi-scale image features.

Swin's Solution: Swin Transformer tackles these issues with two key innovations:

  1. Hierarchical Feature Maps: It builds feature maps at different scales, similar to Convolutional Neural Networks (CNNs), allowing it to capture both fine-grained details and global context.
  2. Shifted Window Self-Attention: Instead of global attention, Swin computes self-attention within local, non-overlapping windows. To allow cross-window connections, it then shifts these windows in successive layers.

💡 If you remember one thing

Swin Transformer achieves linear complexity with respect to image size by using windowed self-attention and a hierarchical structure, enabling efficient processing of high-resolution images.

How Swin Works Internally
▼

Stage-wise Hierarchical Structure

Swin builds feature maps in stages. Each stage starts with a patch merging layer that reduces the spatial resolution and increases the channel dimension. Within each stage, multiple Swin Transformer blocks are applied. This hierarchical design allows the model to learn representations at different scales.

Example: For a 224x224 image, the initial patch embedding might create 56x56 "tokens" (4x4 patches). Stage 1 operates on this. Patch merging then reduces it to 28x28 (Stage 2), then 14x14 (Stage 3), and finally 7x7 (Stage 4), with increasing channel dimensions.

Swin Transformer Block

A Swin Transformer block consists of two main components:

  1. Windowed Multi-Head Self-Attention (W-MSA): Self-attention is computed *only* within local windows. If the window size is M×M, the complexity is linear in M², not the global image size.
  2. Shifted Window Multi-Head Self-Attention (SW-MSA): In the next block, the windows are shifted. This allows information to flow between windows from the previous layer, effectively enabling cross-window connections without the quadratic cost of global attention.

These blocks also include Layer Normalization and MLP layers, standard components in Transformer architectures.

🔑 Key Innovation: Shifted Windows

The key idea is that by shifting the windows in alternating blocks (regular windowing then shifted windowing), every patch can interact with every other patch across layers, while maintaining local computation within each block. This balances efficiency and effective receptive field growth.

The Math Behind Swin
▼

Patch Partition and Embedding

An input image \(I \in \mathbb{R}^{H \times W \times 3}\) is divided into non-overlapping patches of size \(P \times P\). Each patch is flattened into a vector, and then projected into an embedding dimension \(C\) using a linear layer. This results in \(N = \frac{H}{P} \times \frac{W}{P}\) tokens, forming an initial feature map \(X_0 \in \mathbb{R}^{N \times C}\) or spatially \(X_0 \in \mathbb{R}^{\frac{H}{P} \times \frac{W}{P} \times C}\).

Windowed Self-Attention (W-MSA)

For a feature map of size \(h \times w \times c\), divided into non-overlapping windows of size \(M \times M\), the self-attention is computed within each window. For a query \(Q\), key \(K\), and value \(V\), the standard attention is:

$$ \operatorname{Attention}(Q, K, V) = \operatorname{Softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$

In W-MSA, this is applied independently to each window. If there are \(W_{num} = \frac{h}{M} \times \frac{w}{M}\) windows, each of size \(M^2\), the computation is localized. The complexity per window is \(O(M^4)\), and total complexity is \(O(W_{num} \cdot M^4) = O(h \cdot w \cdot M^2)\).

Shifted Window Self-Attention (SW-MSA)

To enable cross-window communication, the windows are shifted by \((M/2, M/2)\) pixels. This requires efficient implementation using cyclic shifts (or masking). The key is that for a \(L \times L\) feature map and window size \(M \times M\), the W-MSA and SW-MSA blocks alternate. This ensures that over two consecutive blocks, each patch can attend to all other patches within its local neighborhood effectively.

The complexity remains \(O(h \cdot w \cdot M^2)\), which is linear in the number of pixels \(h \cdot w\) if \(M\) is fixed.

🧮 Complexity Analysis

Let \(N\) be the number of patches (image size). Global attention is \(O(N^2)\). Swin's W-MSA/SW-MSA complexity is \(O(N \cdot M^2)\) where \(M\) is the window size. Since \(M \ll N\), this is much more efficient. The hierarchical structure further reduces complexity by operating on smaller feature maps in later stages.

Key Takeaways
▼

Efficiency: Swin Transformer's primary advantage is its computational efficiency. By using local windowed attention and a hierarchical structure, it scales linearly with image size, making it suitable for high-resolution images and large datasets.

Effectiveness: Despite its efficiency, Swin Transformer achieves state-of-the-art results across various vision tasks. The shifted window mechanism effectively captures long-range dependencies, while the hierarchical design allows for multi-scale feature learning.

Flexibility: Swin can be used as a general-purpose backbone for a wide range of vision tasks, from image classification to dense prediction tasks like semantic segmentation and object detection.

Comparison to ViT: While ViT uses global self-attention leading to quadratic complexity, Swin uses windowed and shifted-window attention for linear complexity. Swin's hierarchical structure also provides inductive biases (like translation equivariance) that are beneficial for vision tasks.

💡 Hierarchy Matters

The hierarchical design, mimicking CNNs, is crucial. It allows the model to build rich representations from local details to global context, which is fundamental for understanding visual information.
