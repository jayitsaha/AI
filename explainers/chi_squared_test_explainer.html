Understanding the Chi-Squared Test
▼

What is it? The chi-squared (\(\chi^2\)) test is a statistical tool for deciding whether the counts you observe match the counts you expected. You compare what actually happened to what would happen by chance, cell by cell, and ask: "Is the total discrepancy too large to be coincidence?"

Two flavours: (1) Goodness of Fit — one categorical variable: do the observed proportions match a specified distribution? e.g., Is this die fair? (2) Test of Independence — two categorical variables in a cross-table: are they related? e.g., Does coffee drinking affect sleep quality?

Analogy: Imagine pouring 100 ping-pong balls into 6 equal buckets. By chance you expect ~16.7 per bucket, but you actually get [18, 22, 13, 17, 20, 10]. The chi-squared test is like a referee saying: "Are these deviations from 16.7 just fluky, or is something rigged?" It does so by squaring each deviation (so over and under both count), dividing by expected (so big buckets' deviations aren't over-penalised), and summing.

💡 If you remember one thing

The test statistic \(\chi^2 = \sum \frac{(O-E)^2}{E}\) measures normalised total squared deviation from expectation. Under \(H_0\), it follows a \(\chi^2\) distribution with \(k-1\) (GoF) or \((r-1)(c-1)\) (independence) degrees of freedom.

2
How It Works Internally
▼

Step 1 — Compute Expected Counts

Goodness of Fit: Under \(H_0\), the expected count for category \(i\) is \(E_i = n \cdot p_i\), where \(p_i\) is the hypothesised probability. For a fair 6-sided die with 100 rolls: \(E_i = 100 \times \tfrac{1}{6} \approx 16.667\) for all \(i\).

Test of Independence: For a two-way \(r \times c\) table, if the row and column variables are independent, then \(P(\text{row }i, \text{col }j) = P(\text{row }i) \cdot P(\text{col }j)\). Estimating from marginals: \(E_{ij} = \frac{R_i \cdot C_j}{N}\), where \(R_i\) is the \(i\)-th row total, \(C_j\) is the \(j\)-th column total, and \(N\) is the grand total.

Step 2 — Compute the Test Statistic

$$\chi^2 = \sum_{\text{all cells}} \frac{(O - E)^2}{E}$$

Each term \(\frac{(O-E)^2}{E}\) is the squared standardised residual for one cell. Squaring ensures both surpluses and deficits contribute positively. Dividing by \(E\) normalises: a deviation of 5 from \(E=10\) is more alarming than from \(E=1000\).

Step 3 — Degrees of Freedom

The null distribution depends on how many free cells there are:

  • GoF with \(k\) categories: \(df = k - 1\) (one constraint: totals must sum to \(n\))
  • Independence with \(r\) rows and \(c\) columns: \(df = (r-1)(c-1)\) (marginals fixed by data)

Step 4 — Compare to the χ² Distribution

Under \(H_0\), the test statistic follows \(\chi^2(df)\). The p-value is the tail probability \(P(\chi^2_{df} > \chi^2_\text{obs})\). Reject \(H_0\) if \(p < \alpha\) (e.g., 0.05), or equivalently if \(\chi^2_\text{obs} > \chi^2_{\alpha, df}\) (the critical value).

🔑 Key Property

The \(\chi^2\) distribution with \(df\) degrees of freedom is the distribution of \(Z_1^2 + \cdots + Z_{df}^2\) where each \(Z_i \sim \mathcal{N}(0,1)\) independently. Each standardised cell residual \((O_i - E_i)/\sqrt{E_i} \approx \mathcal{N}(0,1)\) under \(H_0\), so summing their squares gives the \(\chi^2\) statistic — this is why the null distribution is exactly \(\chi^2\).

Numerical Trace — Dice Example

Faces [1–6], observed: [18, 22, 13, 17, 20, 10], expected: 16.667 each.

$$\chi^2 = \frac{(18-16.667)^2}{16.667} + \frac{(22-16.667)^2}{16.667} + \frac{(13-16.667)^2}{16.667} + \frac{(17-16.667)^2}{16.667} + \frac{(20-16.667)^2}{16.667} + \frac{(10-16.667)^2}{16.667}$$
$$= 0.107 + 1.707 + 0.807 + 0.007 + 0.667 + 2.667 = 5.960$$

With \(df=5\) and \(\chi^2_{0.05,5} = 11.071\): since \(5.960 < 11.071\), \(p=0.310\), we fail to reject — no significant evidence of a loaded die.

3
The Math — Derivation & Distribution
▼

Why Does Σ(O−E)²/E Follow a χ² Distribution?

The key insight: if counts come from a multinomial distribution under \(H_0\), then for large \(n\), the individual standardised residuals \(Z_i = (O_i - E_i)/\sqrt{E_i}\) are approximately independent standard normal. Their sum of squares follows \(\chi^2\). Formally, this is a consequence of the Central Limit Theorem applied to multinomial counts.

Precisely: under \(H_0\), for \(k\) categories with expected counts \(E_i = n p_i\):

$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i} \xrightarrow{d} \chi^2(k-1) \quad \text{as } n \to \infty$$

The \(k-1\) (not \(k\)) is because counts satisfy the constraint \(\sum O_i = n\), removing one degree of freedom.

The χ²(df) Distribution

If \(Z_1, \ldots, Z_d \overset{\text{iid}}{\sim} \mathcal{N}(0,1)\), then \(\sum_{i=1}^d Z_i^2 \sim \chi^2(d)\). Its PDF is:

$$f(x; d) = \frac{x^{d/2-1} e^{-x/2}}{2^{d/2} \,\Gamma(d/2)}, \quad x > 0$$

Properties: mean \(= d\), variance \(= 2d\), mode \(= \max(d-2, 0)\). As \(d\) grows, the distribution shifts right and becomes more symmetric (by CLT, it approaches \(\mathcal{N}(d, 2d)\)).

Pearson's Correction for Independence

For a contingency table, the marginal totals are fixed by the observed data (not preset by the researcher). This imposes \((r-1)+(c-1)\) additional constraints beyond the grand total, leaving \(df = rc - 1 - (r-1) - (c-1) = (r-1)(c-1)\).

📐 Formula Summary

GoF: \(\chi^2 = \sum_{i=1}^{k}\frac{(O_i-E_i)^2}{E_i}\), \(\;df=k-1\), \(\;E_i = n p_{i,0}\)

Independence: \(\chi^2 = \sum_{i,j}\frac{(O_{ij}-E_{ij})^2}{E_{ij}}\), \(\;df=(r-1)(c-1)\), \(\;E_{ij}=\frac{R_i C_j}{N}\)

⚠️ Assumptions & Limitations

The \(\chi^2\) approximation requires expected cell counts ≥ 5 for each cell. If any cell has \(E_{ij} < 5\), use Fisher's Exact Test (GoF / 2×2) or collapse categories. Also: observations must be independent — the test breaks down for paired or clustered data. Finally, it detects association, not causation.

5
Key Takeaways & When to Use
▼

Use the chi-squared test when:

  • Your data are counts / frequencies (not continuous measurements)
  • GoF: checking if observed proportions match a theoretical distribution (uniform, Poisson, Hardy-Weinberg, etc.)
  • Independence: testing whether two categorical variables are related in a cross-tabulation
  • All expected cell counts are ≥ 5 (if not, use Fisher's Exact Test)

Do NOT use when:

  • Outcomes are continuous — use t-test, ANOVA, Pearson correlation
  • Observations are paired or matched — use McNemar's test
  • Expected counts are too small (< 5 in any cell) — use Fisher's Exact Test
  • You want to measure strength of association (use Cramér's V or odds ratio instead)

💡 Cramér's V — Measuring Effect Size

The p-value tells you if an association is real, not how strong it is. Use Cramér's V: \(V = \sqrt{\chi^2 / (N \cdot \min(r-1, c-1))}\). Ranges 0–1. For the coffee/sleep example: \(V = \sqrt{19.144/(200 \times 1)} \approx 0.31\) — a moderate effect.

Code Trace
▼
import numpy as np
from scipy import stats
# ── GOODNESS OF FIT ──
observed = np.array([18, 22, 13, 17, 20, 10]) # 100 dice rolls
expected = np.full(6, 100/6) # uniform: 16.667 each
chi2 = np.sum((observed - expected)**2 / expected)
# chi2 = 5.9600, df = k-1 = 5
p_gof = 1 - stats.chi2.cdf(chi2, df=5) # p = 0.3101 → fail to reject
# ── INDEPENDENCE TEST ──
ct = np.array([[40, 30, 20],
[20, 40, 50]]) # rows=Sleep, cols=Coffee
chi2_ind, p_ind, dof, expected_ct = stats.chi2_contingency(ct)
# chi2 = 19.1438, df = (2-1)*(3-1) = 2, p = 0.0001 → reject H0
# ── EXPECTED CELL FORMULA ──
row_totals = ct.sum(axis=1, keepdims=True) # [90, 110]
col_totals = ct.sum(axis=0, keepdims=True) # [60, 70, 70]
E = row_totals @ col_totals / ct.sum() # outer product / N
# E[0,0] = 90*60/200 = 27.0
