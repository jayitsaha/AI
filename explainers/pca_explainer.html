1
Understanding PCA
▼

What is it? PCA finds the directions in feature space along which data varies the most, then projects the data onto a lower-dimensional subspace spanned by those directions. It compresses a dataset with many correlated features into fewer uncorrelated principal components while preserving as much variance (information) as possible.

Analogy: Imagine photographing a 3D sculpture. If you photograph it straight-on, you lose depth. But if you find the viewing angle that shows the most shape detail — the widest spread, the richest silhouette — that's what PCA does. It rotates the coordinate system to align the first axis with the direction of maximum variance, the second axis with the next most variable direction orthogonal to the first, and so on.

💡 If you remember one thing

PCA finds the orthogonal axes of maximum variance: these are the eigenvectors of the covariance matrix (equivalently, the right singular vectors of the mean-centered data matrix \(X\)). Project onto the top-\(k\) to compress. The fraction of total variance captured by component \(i\) is \(\lambda_i / \sum_j \lambda_j\).

2
How PCA Works — Two Equivalent Methods
▼

Step 0: Center the data

Subtract the column mean: \(\tilde{X} = X - \mathbf{1}\bar{x}^\top\) where \(\bar{x}_j = \frac{1}{n}\sum_i X_{ij}\). Centering is mandatory — PCA measures variance around the mean, not the origin. Scaling (dividing by std) is optional but recommended when features have different units.

Method A — Covariance Matrix Eigenvectors

Compute the \(d \times d\) sample covariance matrix:

$$\Sigma = \frac{1}{n-1}\tilde{X}^\top \tilde{X}$$

Eigen-decompose: \(\Sigma = V \Lambda V^\top\) where columns of \(V = [v_1, \ldots, v_d]\) are eigenvectors (principal axes) and \(\Lambda = \operatorname{diag}(\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_d \geq 0)\) contains eigenvalues. The \(k\)-dimensional projection is \(Z = \tilde{X} V_k\) where \(V_k\) contains the top-\(k\) eigenvectors.

Cost: \(O(nd^2 + d^3)\). Good when \(n \gg d\) (many samples, few features).

Method B — SVD of Centered Data (preferred)

Decompose the centered matrix directly:

$$\tilde{X} = U \Sigma_{\text{sv}} V^\top, \quad U \in \mathbb{R}^{n \times r},\ \Sigma_{\text{sv}} \in \mathbb{R}^{r \times r},\ V \in \mathbb{R}^{d \times r}$$

The right singular vectors \(V\) are identical to the eigenvectors of the covariance matrix. The singular values relate to eigenvalues by \(\sigma_i^2 = (n-1)\lambda_i\). Scores (projections): \(Z = U\Sigma_{\text{sv}} = \tilde{X}V\).

Why prefer SVD? Numerically stabler — avoids squaring the condition number of \(\tilde{X}\). When \(n \ll d\), use the economy SVD: cost \(O(n^2 d)\) instead of \(O(d^3)\). Randomized SVD further reduces cost to \(O(ndk)\) for top-\(k\) components.

🔑 Key Equivalence

Covariance eigenvectors = right singular vectors of \(\tilde{X}\). Both give the same principal components. The covariance path is intuitive; the SVD path is numerically superior. sklearn.decomposition.PCA uses truncated SVD internally.

3
Explained Variance, Scree Plot & Biplot
▼

Explained Variance Ratio

The total variance in the centered data equals the sum of all eigenvalues \(\sum_{i=1}^d \lambda_i = \operatorname{tr}(\Sigma)\). Component \(i\) explains a fraction:

$$\text{EVR}_i = \frac{\lambda_i}{\sum_{j=1}^d \lambda_j}$$

The cumulative explained variance (CEV) tells you how many components to keep. A common heuristic: keep enough components to capture 90–95% CEV.

Scree Plot

A bar or line plot of eigenvalues \(\lambda_i\) vs component index \(i\), in decreasing order. The "elbow" — where the curve bends sharply — indicates the natural cutoff. Beyond the elbow, additional components add little variance. The name comes from the scree (rubble) at the base of a mountain: after the steep slope, you reach diminishing returns.

⚠️ Scree Plot Pitfall

The elbow is often ambiguous. Parallel Analysis (compare eigenvalues to random data) or cross-validated reconstruction error gives a more principled \(k\) selection. Never use the scree plot alone for high-stakes dimensionality decisions.

Biplot

A biplot overlays two kinds of information in the same PC1 vs PC2 plane: (1) scores — the projected data points \(z_i = \tilde{x}_i^\top V_2\) — and (2) loadings — arrows for each original feature \(j\) with direction proportional to \(v_j = [V_{j1}, V_{j2}]\) and length proportional to the feature's contribution. Features with long, similar-direction arrows are positively correlated. Features with opposite-direction arrows are negatively correlated. Features at 90° are uncorrelated.

∑ Formula Reference

Scores (row \(i\)): \(z_i = \tilde{X}_i V_k \in \mathbb{R}^k\)
Loading vector (feature \(j\)): column \(j\) of \(V_k^\top \in \mathbb{R}^{k \times d}\)
Reconstruction: \(\hat{X}_i = z_i V_k^\top + \bar{x}^\top\)
Reconstruction error: \(\|\tilde{X} - \tilde{X} V_k V_k^\top\|_F^2 = \sum_{i=k+1}^d \lambda_i\)

Key Takeaways & When to Use PCA
▼

When to use PCA:

  • Exploratory analysis — visualize high-dimensional data in 2D/3D
  • Remove multicollinearity before linear regression
  • Speed up downstream models (fewer features = faster)
  • Noise reduction (discard low-variance components that capture noise)
  • Compression: images, spectra, gene expression matrices

When NOT to use PCA:

  • Non-linear structure — use UMAP, t-SNE, or kernel PCA instead
  • When interpretability of original features is required (PCs are linear combinations, hard to interpret)
  • Sparse high-dimensional data (text/bags-of-words) — truncated SVD / LSA instead
  • Class separability is the goal — use LDA (supervised) instead
💡 PCA vs alternatives

PCA (linear, global variance) → Kernel PCA (non-linear, kernel trick) → t-SNE (non-linear, local structure, non-parametric) → UMAP (non-linear, local+global, parametric option). Use PCA first — fast, interpretable, exact. Escalate only if linear is insufficient.

Code — From Scratch & Production
▼

From Scratch (NumPy)

import numpy as np
def pca_cov(X, k):
"""PCA via covariance matrix eigenvectors."""
n = X.shape[0]
X_c = X - X.mean(axis=0) # center (mandatory)
Sigma = (X_c.T @ X_c) / (n - 1) # d×d covariance matrix
eigvals, eigvecs = np.linalg.eigh(Sigma) # eigh: symmetric
idx = np.argsort(eigvals)[::-1] # sort descending
eigvals, eigvecs = eigvals[idx], eigvecs[:, idx]
V_k = eigvecs[:, :k] # top-k eigenvectors (d×k)
Z = X_c @ V_k # scores (n×k)
evr = eigvals / eigvals.sum() # explained variance ratio
return Z, V_k, evr
def pca_svd(X, k):
"""PCA via SVD — numerically preferred."""
X_c = X - X.mean(axis=0)
U, s, Vt = np.linalg.svd(X_c, full_matrices=False)
# singular values → eigenvalues: lambda_i = s_i^2 / (n-1)
eigvals = s**2 / (X.shape[0] - 1)
V_k = Vt[:k].T # right singular vecs (d×k)
Z = X_c @ V_k # scores (n×k)
evr = eigvals / eigvals.sum()
return Z, V_k, evr
# Production: sklearn
from sklearn.decomposition import PCA
pca = PCA(n_components=2, svd_solver='full')
Z = pca.fit_transform(X) # scores
print(pca.explained_variance_ratio_) # EVR per component
print(pca.components_) # V_k.T (k×d loadings)
