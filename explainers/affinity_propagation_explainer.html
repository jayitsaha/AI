Affinity Propagation

Message-passing clustering — no K required, exemplars emerge from the data
Intermediate Unsupervised Learning Clustering O(n² · iter)
1
Understanding the Concept
▾

Affinity Propagation is a clustering algorithm that finds a set of exemplars — real data points that best represent their cluster — without you ever specifying how many clusters you want. Instead of randomly initialising K centres (like K-Means does), every data point simultaneously considers itself a candidate exemplar and negotiates with all other points via messages.

Think of it like a committee election held by postal vote. Every person (data point) sends a ballot to every candidate saying "I think you'd make a good representative" — weighted by how similar they are. Every candidate replies with "I'm willing to stand, and here's how many people already back me." After many rounds of voting, a stable set of representatives (exemplars) and their districts (clusters) naturally emerges from consensus.

💡 If you remember one thing

Affinity Propagation passes two types of messages iteratively — responsibility r(i,k) (point i tells candidate k how good it is) and availability a(i,k) (candidate k tells point i how available it is) — until the sum \(r(i,k)+a(i,k)\) converges and each point elects its exemplar.

The algorithm was introduced by Brendan Frey and Delbert Dueck at the University of Toronto in Science (2007). It works on any similarity matrix (not just Euclidean distances), automatically determines the number of clusters from a single preference parameter, and guarantees that every chosen exemplar is an actual input point.

How It Works — Message Passing
▾

The algorithm operates on an \(N \times N\) similarity matrix \(S\) where \(s(i,k)\) measures how well point \(k\) would serve as the exemplar for point \(i\). Negative squared Euclidean distance \(s(i,k) = -\|x_i - x_k\|^2\) is the most common choice. The diagonal \(s(k,k)\) is the preference — higher values make more clusters.

Two Alternating Messages

Responsibility r(i,k) — sent from data point \(i\) to candidate exemplar \(k\). It encodes how well-suited \(k\) is to be the exemplar for \(i\), relative to all competing candidates. A large positive value means \(k\) is \(i\)'s best option with no strong competitor.

$$r(i,k) \leftarrow s(i,k) - \max_{k' \neq k}\bigl[a(i,k') + s(i,k')\bigr]$$

Availability a(i,k) — sent from candidate \(k\) back to point \(i\). It reflects how appropriate it would be for \(k\) to be an exemplar, given the positive responsibilities \(k\) receives from all other points. The self-availability \(a(k,k)\) accumulates endorsements from every point that wants \(k\) as its exemplar.

$$a(i,k) \leftarrow \min\!\Bigl(0,\; r(k,k) + \sum_{i' \neq i,\, i' \neq k} \max(0, r(i',k))\Bigr)$$
$$a(k,k) \leftarrow \sum_{i' \neq k} \max(0, r(i',k))$$

Damping for Stability

To prevent oscillations, each update is damped by mixing with the previous value at rate \(\lambda \in [0.5, 1)\):

$$r_{t+1}(i,k) = \lambda \cdot r_t(i,k) + (1-\lambda) \cdot r_{\text{new}}(i,k)$$

Convergence Decision

After messages stabilise, each point \(i\) elects its exemplar as the candidate maximising the combined criterion:

$$k^*(i) = \underset{k}{\operatorname{argmax}}\bigl[a(i,k) + r(i,k)\bigr]$$

Points for which \(k^*(i) = i\) (they elect themselves) become exemplars. All other points join the cluster of their elected exemplar.

⚠️ Key design choice

The preference \(s(k,k)\) directly controls cluster count: set to the minimum similarity for fewer clusters, to the median for a moderate number, or to a custom value for domain-guided output. Unlike K-Means, you never pick K directly — but you must still tune preference.

3
The Mathematics
▾

Affinity Propagation can be derived as max-product belief propagation on a factor graph. Define the net cluster quality objective we want to maximise:

$$\mathcal{S}(\mathbf{c}) = \sum_{i=1}^N s\bigl(i,\, c_i\bigr)$$

subject to the constraint that every point \(i\) whose exemplar is \(k\) must have \(k\) also choosing itself as its own exemplar: if \(c_i = k\) then \(c_k = k\). This constraint prevents "phantom" exemplars that are not themselves cluster centres.

Factor Graph Formulation

Introduce binary indicator variables \(I_{ik} \in \{0,1\}\) where \(I_{ik}=1\) iff point \(i\) chooses \(k\) as exemplar. The constraint factor for each candidate \(k\) is:

$$f_k(I_{1k}, I_{2k}, \ldots, I_{Nk}) = \begin{cases} 1 & \text{if } I_{kk}=1 \text{ whenever any } I_{ik}=1 \\ 0 & \text{otherwise}\end{cases}$$

Max-sum message passing (log-domain version of max-product) on this factor graph yields exactly the responsibility and availability update rules.

Convergence Guarantee

Key Property

With damping \(\lambda \in [0.5,1)\) the messages are guaranteed to converge to a fixed point of the update equations. However, this fixed point need not be the global optimum of \(\mathcal{S}\) — it is a local stationary solution. In practice, multiple random-preference restarts improve solution quality.

Complexity

Each iteration requires computing all \(O(N^2)\) responsibility and availability values — so each sweep is \(O(N^2)\). With \(T\) iterations total, the complexity is \(O(N^2 T)\) in time and \(O(N^2)\) in memory (for storing \(S\), \(R\), \(A\)). This quadratic scaling is the main limitation for large datasets; sparse variants restrict messages to a \(K\)-nearest-neighbour graph to achieve \(O(NK \cdot T)\).

Numerical Trace (3 points, 2 iterations)

With \(N=3\), \(S = \begin{bmatrix}-0 & -25 & -100 \\ -25 & 0 & -49 \\ -100 & -49 & 0\end{bmatrix}\), preference \(p = -49\) on diag, \(\lambda=0.5\):

Iter 1 — Responsibility update for r(0,0):

$$r(0,0) \leftarrow s(0,0) - \max_{k \neq 0}[a(0,k)+s(0,k)] = -49 - \max[-25, -100] = -49-(-25) = -24$$

Iter 1 — Availability update for a(0,0) (self):

$$a(0,0) \leftarrow \sum_{i \neq 0}\max(0,r(i,0)) = \max(0,-25)+\max(0,-100) = 0$$

After iteration 1 the criterion \(a(0,0)+r(0,0) = 0 + (-24) = -24\) vs \(a(1,1)+r(1,1)\) which rises, correctly identifying point 1 as the emerging exemplar for a cluster containing points 1 and 2.

Sklearn Usage

from sklearn.cluster import AffinityPropagation
import numpy as np

X = np.array([[1,2],[1.5,1.8],[5,8],[8,8],[1,0.6],[9,11]])

ap = AffinityPropagation(
    damping=0.5,          # λ: 0.5–0.9, higher = more stable but slower
    preference=None,      # None → median similarity (auto)
    max_iter=200,
    convergence_iter=15,  # stop if labels unchanged for 15 iters
    random_state=42
)
ap.fit(X)
print("Exemplar indices:", ap.cluster_centers_indices_)
print("Labels:", ap.labels_)

When to Use

  • Dataset is small-to-medium (N ≤ 5,000) and you want interpretable exemplars
  • You have a meaningful pairwise similarity (not just Euclidean) — e.g. sequence alignment, graph edit distance
  • You genuinely don't know K and want the data to decide

When Not to Use

  • N > 10,000 — quadratic memory and time become prohibitive
  • You need probabilistic cluster assignments or soft memberships
  • Cluster boundaries are highly non-convex (prefer DBSCAN or spectral)
