1
Understanding the Concept
▾

What is this? A Markov chain is a mathematical model for a system that randomly jumps between a set of states over time. The key rule: where you go next depends only on where you are now, never on how you got there. This "memoryless" property is called the Markov property.

Real-world analogy: Imagine weather that follows three states: Sunny, Cloudy, and Rainy. Each morning the weather might change — but today's forecast depends only on today's weather, not last week's. A 70% chance of staying sunny, 20% chance of going cloudy, 10% chance of rain. Over many days, despite starting sunny every Monday, the weather settles into a long-run pattern — that's the stationary distribution.

💡 If You Remember One Thing

A Markov chain is fully described by a transition matrix \(P\) where \(P_{ij}\) = probability of going from state \(i\) to state \(j\). Multiply any starting distribution by \(P\) repeatedly and it converges to the unique stationary distribution \(\pi\) satisfying \(\pi P = \pi\).

Why it matters for ML: Markov chains are the mathematical backbone of Markov Chain Monte Carlo (MCMC) — the workhorse of Bayesian inference. Every time a researcher samples from a posterior distribution using Metropolis-Hastings or Gibbs sampling, they're running a carefully constructed Markov chain whose stationary distribution is the target posterior.

🔑 The Four Core Ideas

Transition matrix: \(P_{ij}\) = probability of state \(i \to j\); rows sum to 1.
Stationary distribution: \(\pi\) satisfying \(\pi = \pi P\); the long-run frequency.
Ergodicity: guarantees the chain eventually visits every state and forgets its start.
Detailed balance: \(\pi_i P_{ij} = \pi_j P_{ji}\) — a sufficient condition for reversibility, used in MCMC design.

2
How It Works Internally
▾

The Transition Matrix

For a chain with \(n\) states, the transition matrix \(P\) is an \(n \times n\) matrix where each entry \(P_{ij} \geq 0\) and every row sums to 1 (it's a stochastic matrix). For our weather example with states {Sunny=0, Cloudy=1, Rainy=2}:

$$P = \begin{bmatrix} 0.7 & 0.2 & 0.1 \\ 0.3 & 0.4 & 0.3 \\ 0.2 & 0.3 & 0.5 \end{bmatrix}$$

Row 0 says: from Sunny, go to Sunny with prob 0.7, Cloudy with 0.2, Rainy with 0.1.

Distribution Evolution: \(\pi_{t+1} = \pi_t P\)

If \(\pi_t\) is a row vector of probabilities over states at time \(t\), then the distribution at time \(t+1\) is \(\pi_{t+1} = \pi_t P\). After \(t\) steps from any start: \(\pi_t = \pi_0 P^t\).

Starting from pure Sunny state \(\pi_0 = [1, 0, 0]\), after one step: \(\pi_1 = [0.7, 0.2, 0.1]\). After many steps the distribution converges to \(\pi \approx [0.457, 0.283, 0.261]\) regardless of starting point.

Finding the Stationary Distribution

The stationary distribution \(\pi\) satisfies \(\pi P = \pi\). Rearranging: \(\pi(P - I) = 0\). This is an eigenvector equation — \(\pi\) is the left eigenvector of \(P\) corresponding to eigenvalue 1. Solving:

  • Set up the linear system \(\pi P = \pi\) plus the normalization constraint \(\sum_i \pi_i = 1\)
  • Or: find the left null space of \((P - I)\) — guaranteed to exist because every stochastic matrix has eigenvalue 1
  • Or: simply iterate \(\pi_{t+1} = \pi_t P\) until convergence (power iteration)

Ergodicity: When Does Convergence Happen?

Not every Markov chain converges to a unique stationary distribution. For guaranteed convergence, the chain must be:

  • Irreducible: every state is reachable from every other state (the graph is strongly connected)
  • Aperiodic: the chain doesn't oscillate in fixed cycles (greatest common divisor of return times = 1)

A chain satisfying both is called ergodic (or regular). The ergodic theorem then guarantees: (1) a unique stationary distribution \(\pi\) exists, (2) the time-average of any function along a path equals its expectation under \(\pi\), (3) convergence is independent of starting state.

Detailed Balance (Reversibility)

A chain satisfies detailed balance with respect to \(\pi\) if for all pairs of states \(i, j\):

$$\pi_i P_{ij} = \pi_j P_{ji}$$

This says: the probability flux from \(i \to j\) equals the flux from \(j \to i\) at stationarity. A chain satisfying detailed balance is reversible — it looks the same whether you run time forward or backward. Detailed balance is a sufficient but not necessary condition for \(\pi\) to be stationary. This is crucial for MCMC: the Metropolis-Hastings algorithm deliberately constructs a chain that satisfies detailed balance with the target distribution as \(\pi\).

⚠️ Common Misconception

The stationary distribution is NOT the same as the most visited state. It describes the long-run fraction of time spent in each state — which may be far from uniform even if all states are reachable. Also, detailed balance implies stationarity, but a chain CAN have a stationary distribution without satisfying detailed balance (e.g., a cycle 1→2→3→1 with uniform \(\pi\)).

3
The Mathematics
▾

Formal Definition

A sequence of random variables \(\{X_0, X_1, X_2, \ldots\}\) on state space \(\mathcal{S}\) is a Markov chain if it satisfies the Markov property:

$$P(X_{t+1} = j \mid X_t = i,\, X_{t-1},\ldots,X_0) = P(X_{t+1} = j \mid X_t = i) = P_{ij}$$

The transition matrix \(P\) is stochastic: \(P_{ij} \geq 0\) for all \(i,j\), and \(\sum_j P_{ij} = 1\) for all \(i\).

Chapman-Kolmogorov Equations

The \(t\)-step transition probabilities satisfy:

$$P^{(t)}_{ij} = P(X_{t+n} = j \mid X_n = i) = (P^t)_{ij}$$

So the \(t\)-step transition matrix is literally \(P\) raised to the \(t\)-th power. For our weather chain: \(P^{10}\) has nearly identical rows \(\approx [0.457, 0.283, 0.261]\) — the chain has essentially "mixed" by step 10.

Stationary Distribution: Derivation

\(\pi\) is a stationary distribution if and only if it solves:

$$\pi P = \pi, \quad \sum_{i} \pi_i = 1, \quad \pi_i \geq 0 \;\forall i$$

Equivalently, \(\pi\) is the left eigenvector of \(P\) for eigenvalue 1. For an ergodic chain this solution is unique. The Perron-Frobenius theorem guarantees that every non-negative irreducible matrix has a unique maximal eigenvalue (here = 1) with a strictly positive eigenvector.

Convergence Rate: The Spectral Gap

Let \(\lambda_1 = 1 \geq |\lambda_2| \geq \cdots \geq |\lambda_n|\) be the eigenvalues of \(P\). The spectral gap is \(\delta = 1 - |\lambda_2|\). The mixing time (time to get close to stationary) scales as:

$$\|P^t_{i,\cdot} - \pi\|_{TV} \leq |\lambda_2|^t \cdot C$$

For our weather chain: \(|\lambda_2| \approx 0.473\), spectral gap \(\approx 0.527\). After 10 steps, error bound is \(0.473^{10} \approx 0.00059\) — essentially converged. A larger spectral gap means faster mixing.

Detailed Balance: Proof that It Implies Stationarity

Suppose \(\pi_i P_{ij} = \pi_j P_{ji}\) for all \(i, j\). Then summing over \(i\):

$$\sum_i \pi_i P_{ij} = \sum_i \pi_j P_{ji} = \pi_j \sum_i P_{ji} = \pi_j \cdot 1 = \pi_j$$

So \((\pi P)_j = \pi_j\), confirming \(\pi P = \pi\). The converse fails: stationarity does not imply detailed balance (cyclic chains are a counterexample).

📐 Key Formulas Summary

\(\pi_{t+1} = \pi_t P\) — one-step distribution update
\(\pi = \pi P\) — stationary distribution condition
\(\pi_i P_{ij} = \pi_j P_{ji}\) — detailed balance (reversibility)
\(\delta = 1 - |\lambda_2|\) — spectral gap (mixing speed)

Code Implementation
▾

From Scratch (NumPy)

import numpy as np
# ── 3-state weather Markov chain ────────────────────────────────────────
# States: 0=Sunny, 1=Cloudy, 2=Rainy
P = np.array([
[0.7, 0.2, 0.1], # from Sunny: 70% stay, 20% cloud, 10% rain
[0.3, 0.4, 0.3], # from Cloudy
[0.2, 0.3, 0.5], # from Rainy
]) # each row sums to 1 → stochastic matrix
# ── Stationary distribution via eigendecomposition ──────────────────────
eigenvalues, eigenvectors = np.linalg.eig(P.T) # left eigenvectors of P
idx = np.argmin(np.abs(eigenvalues - 1.0)) # eigenvalue = 1
pi = eigenvectors[:, idx].real
pi = pi / pi.sum() # normalize → probability vector
# Result: pi ≈ [0.4565, 0.2826, 0.2609]
# ── Verify: pi @ P = pi ─────────────────────────────────────────────────
assert np.allclose(pi @ P, pi), "Not stationary!"
# ── Simulate distribution evolution ─────────────────────────────────────
pi_t = np.array([1.0, 0.0, 0.0]) # start: certainty in Sunny
for t in range(15):
pi_t = pi_t @ P # pi_{t+1} = pi_t * P
tv = 0.5 * np.sum(np.abs(pi_t - pi)) # total variation distance
if t < 5 or tv < 0.001: print(f"t={t+1}: {pi_t.round(4)}, TV={tv:.4f}")
# ── Check detailed balance ────────────────────────────────────────────────
def check_detailed_balance(pi, P, tol=1e-9):
n = len(pi)
for i in range(n):
for j in range(i+1, n):
if not np.isclose(pi[i]*P[i,j], pi[j]*P[j,i], atol=tol):
return False
return True
print("DB satisfied:", check_detailed_balance(pi, P)) # False for weather
# ── Mixing time estimate (spectral gap) ──────────────────────────────────
eigvals = np.sort(np.abs(np.linalg.eigvals(P)))[::-1]
lambda2 = eigvals[1] # second-largest |eigenvalue|
spectral_gap = 1 - lambda2 # ≈ 0.527
mixing_time_eps = np.ceil(np.log(1/0.01) / np.log(1/lambda2)) # steps for ε=0.01
print(f"Spectral gap: {spectral_gap:.4f}, ~{int(mixing_time_eps)} steps for ε=0.01")

Production: Scipy & PyMC (MCMC)

# ── Stationary dist via linear system (more numerically stable) ─────────
from scipy.linalg import solve
import numpy as np
def stationary_distribution(P):
n = P.shape[0]
# Solve: pi (P - I) = 0, sum(pi) = 1
A = (P.T - np.eye(n)) # system matrix
A[-1] = 1.0 # replace last row with normalization
b = np.zeros(n); b[-1] = 1.0 # rhs: pi sums to 1
return solve(A, b) # returns pi
pi = stationary_distribution(P)
print(pi) # [0.4565, 0.2826, 0.2609]
# ── Bayesian inference with MCMC (PyMC) ─────────────────────────────────
import pymc as pm
import numpy as np
observed = np.array([2.1, 1.9, 2.3, 2.0, 2.4]) # some data
with pm.Model() as model:
mu = pm.Normal("mu", mu=0, sigma=10) # prior
sigma = pm.HalfNormal("sigma", sigma=1) # prior
obs = pm.Normal("obs", mu=mu, sigma=sigma, observed=observed)
# PyMC runs NUTS (gradient-based MCMC) — a reversible Markov chain
# whose stationary distribution IS the posterior p(mu,sigma | data)
trace = pm.sample(2000, tune=1000, cores=1) # draws from posterior
# The key: NUTS satisfies detailed balance → ergodic → converges to posterior
💡 Key Insight for MCMC

Metropolis-Hastings and NUTS work by constructing a Markov chain with detailed balance with respect to the target posterior \(\pi\). Because the chain is ergodic, it converges to \(\pi\) from any starting point — no need to know the normalizing constant! This is why MCMC can sample from unnormalized distributions like \(p(\theta | \text{data}) \propto p(\text{data}|\theta)\, p(\theta)\).

When to Use Each Concept

  • Transition matrix analysis: Any finite-state sequential process (NLP language models, text generation, DNA sequences, page-rank)
  • Stationary distribution: Long-run behavior, Google PageRank (\(P\) = web link matrix, \(\pi\) = page importance), steady-state queuing theory
  • Ergodicity: When you need to trust that time-average = space-average — required for MCMC correctness guarantees
  • Detailed balance: MCMC design — Metropolis-Hastings, Gibbs sampling, Hamiltonian Monte Carlo all exploit this to sample from intractable posteriors

Related Topics

  • Prerequisites: Basic probability (conditional probability, Bayes rule), linear algebra (eigenvectors, matrix multiplication)
  • Builds to: MCMC methods (Metropolis-Hastings, Gibbs, HMC/NUTS), Hidden Markov Models (HMMs), Markov Decision Processes (MDPs/RL), Bayesian inference, PageRank
  • Key papers: Metropolis et al. (1953), Hastings (1970) — the foundational MCMC papers that use Markov chains + detailed balance to sample from posteriors
🔗 Connection to Deep Learning

Character-level language models (pre-transformer) are essentially high-order Markov chains. The Transformer's attention mechanism can be interpreted as a learned transition matrix over token positions. In reinforcement learning, the environment is modeled as a Markov Decision Process (MDP) — states + actions + transition probabilities + rewards — the direct extension of Markov chains with decisions.
