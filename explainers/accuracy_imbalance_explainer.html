Accuracy, When It Fails

Class Imbalance — why 99% accuracy can mean a useless model, and which metrics to trust instead
Foundational Classical ML · Evaluation Must Know
1
Understanding the Concept
▾

Accuracy = fraction of correct predictions. It sounds perfect — but it secretly rewards doing nothing when data is skewed.

The Accuracy Paradox

A dataset with 9,900 negatives and 100 positives lets a model that always predicts negative score 99.0% accuracy while catching zero positives. The metric looks great; the model is completely useless.

Real-world analogy: Imagine a hospital where 99% of patients are healthy. A doctor who refuses to diagnose any disease correctly identifies 99% of patients — but every sick person goes home untreated. That 99% score is a lie about the doctor's competence.

If You Remember One Thing

When classes are imbalanced, a trivial majority-class classifier maximises accuracy. Use Balanced Accuracy, Precision-Recall AUC, or MCC — they expose useless models that accuracy hides.

Why does this happen mathematically?

Accuracy averages performance across all classes weighted by their frequency. With 99% negatives, the denominator is dominated by negatives, so correctly classifying negatives contributes almost everything to the score — positives are drowned out.

Metric Definitions

$$\text{Accuracy} = \frac{TP + TN}{TP+TN+FP+FN}$$

$$\text{Precision} = \frac{TP}{TP+FP} \qquad \text{Recall} = \frac{TP}{TP+FN}$$

$$\text{F1} = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision}+\text{Recall}}$$

$$\text{Balanced Accuracy} = \frac{1}{2}\!\left(\frac{TP}{TP+FN} + \frac{TN}{TN+FP}\right)$$

$$\text{MCC} = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

Why Precision is Undefined

Precision \(= TP / (TP+FP)\). When the model never predicts positive, \(TP = FP = 0\), so the denominator is 0 — division by zero. Sklearn returns 0 with a warning. This is another signal the model is broken.

Why Each Robust Metric Works
▾

Balanced Accuracy

$$\text{Balanced Accuracy} = \frac{1}{2}\left(\frac{TP}{TP+FN} + \frac{TN}{TN+FP}\right) = \frac{\text{Sensitivity} + \text{Specificity}}{2}$$

It averages per-class recall, so each class contributes equally regardless of size. A random classifier scores exactly 0.5, a perfect classifier scores 1.0, and our all-negative classifier scores exactly 0.5 — random.

MCC — Matthews Correlation Coefficient

$$\text{MCC} = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

MCC is a Pearson correlation between observed and predicted labels. It ranges from \(-1\) (perfect anti-correlation) through \(0\) (random) to \(+1\) (perfect). It uses all four confusion matrix cells simultaneously and is invariant under class label swapping. Many researchers consider MCC the single most informative binary metric.

Precision-Recall AUC

The PR curve plots Precision (y-axis) vs Recall (x-axis) as the decision threshold sweeps from 0 to 1. For a random classifier, PR-AUC ≈ class prevalence \(p\) (not 0.5 like ROC-AUC). For our 1% dataset:

$$\text{PR-AUC}_{\text{random}} \approx p = 0.01 \qquad \text{PR-AUC}_{\text{perfect}} = 1.0$$

This makes PR-AUC much harder to game on skewed data — a baseline model starts near the floor, not at 50%.

ROC-AUC Can Also Mislead on Imbalanced Data

ROC-AUC measures the probability that a random positive ranks above a random negative. It can look high (e.g. 0.75) even when precision at the operating threshold is catastrophically low, because it ignores the class imbalance entirely. Always pair ROC-AUC with PR-AUC on skewed data.

Decision Rule

If prevalence < 10%: drop raw accuracy, report Balanced Accuracy + PR-AUC + MCC as your primary trio. Always state the baseline (random MCC=0, random PR-AUC≈prevalence).
