Understanding MGFs & Characteristic Functions
▼

What is this? A moment generating function (MGF) is a special kind of average that encodes all the moments of a random variable — its mean, variance, skewness, kurtosis — in a single function. The characteristic function does the same thing but always exists, even when the MGF does not.

Analogy: Think of a random variable as a song. The moments (mean, variance, …) are individual notes. The MGF is like a recording of the entire song — if you have it, you can recover every note. The characteristic function is an even more reliable recording format that works for every song, including very noisy or heavy-tailed ones that would distort a standard recorder.

💡 If you remember one thing

The MGF is \(M(t) = \mathbb{E}[e^{tX}]\). Its \(k\)-th derivative evaluated at \(t=0\) gives the \(k\)-th moment: \(M^{(k)}(0) = \mathbb{E}[X^k]\). And for independent \(X, Y\), \(M_{X+Y}(t) = M_X(t)\cdot M_Y(t)\) — which is the key to proving the Central Limit Theorem.

Why it matters for ML/Stats: MGFs and characteristic functions are the core tools for proving the CLT (the theoretical foundation of why averages are approximately Normal), deriving distributions of sums of random variables, and characterizing distributions uniquely. Every time you rely on Gaussian approximations, you are using their consequences.

Internals: Moments from Derivatives
▼

The MGF Definition

For a random variable \(X\), the MGF is defined as:

$$M_X(t) = \mathbb{E}[e^{tX}] = \int_{-\infty}^{\infty} e^{tx} f(x)\,dx \quad \text{(continuous case)}$$

The MGF exists (is finite) for \(t\) in some open interval around 0. This is not guaranteed — heavy-tailed distributions like Cauchy or Pareto have no MGF.

Extracting Moments via Differentiation

The magic: differentiate under the expectation sign. The \(k\)-th derivative of \(e^{tX}\) with respect to \(t\) is \(X^k e^{tX}\). Setting \(t=0\):

$$\frac{d^k}{dt^k} M_X(t)\Big|_{t=0} = \mathbb{E}\!\left[X^k e^{0}\right] = \mathbb{E}[X^k]$$

Numerical Trace — Standard Normal

For \(X \sim \mathcal{N}(0,1)\), the MGF is \(M(t) = e^{t^2/2}\) (derived below). Let us read off all moments numerically:

📐 Moment Extraction Trace

\(M(t) = e^{t^2/2}\)
\(M'(t) = t\,e^{t^2/2}\)  →  \(M'(0) = 0 = \mathbb{E}[X]\) ✓
\(M''(t) = (1+t^2)\,e^{t^2/2}\)  →  \(M''(0) = 1 = \mathbb{E}[X^2]\) ✓
\(M'''(t) = (3t+t^3)\,e^{t^2/2}\)  →  \(M'''(0) = 0 = \mathbb{E}[X^3]\) ✓
\(M^{(4)}(0) = 3 = \mathbb{E}[X^4]\)  (kurtosis \(= 3\sigma^4 = 3\)) ✓

The Characteristic Function — Always Exists

Replace the real parameter \(t\) with an imaginary one \(it\) (where \(i = \sqrt{-1}\)):

$$\varphi_X(t) = \mathbb{E}[e^{itX}] = \int_{-\infty}^{\infty} e^{itx} f(x)\,dx$$

This is exactly the Fourier transform of the density \(f\). Because \(|e^{itX}| = 1\) for all real \(t\) and \(X\), the expectation is bounded: \(|\varphi_X(t)| \le \mathbb{E}[|e^{itX}|] = 1\). So the characteristic function exists for every distribution, even Cauchy.

Independence → Product Rule (Key for CLT)

If \(X\) and \(Y\) are independent, then \(e^{t(X+Y)} = e^{tX} \cdot e^{tY}\) and by independence of expectations:

$$M_{X+Y}(t) = \mathbb{E}[e^{t(X+Y)}] = \mathbb{E}[e^{tX}]\cdot\mathbb{E}[e^{tY}] = M_X(t)\cdot M_Y(t)$$

The same holds for characteristic functions: \(\varphi_{X+Y}(t) = \varphi_X(t)\cdot\varphi_Y(t)\). This multiplicative property is the backbone of the CLT proof.

🔑 Key Property

An MGF uniquely determines the distribution whenever it exists in a neighbourhood of 0. Two distributions are identical if and only if they have the same MGF (or characteristic function). This is the uniqueness theorem — the reason MGF arguments are valid proofs.

The Math: Derivations & CLT Proof Sketch
▼

Deriving the Gaussian MGF

Let \(X \sim \mathcal{N}(\mu, \sigma^2)\). We want \(M(t) = \mathbb{E}[e^{tX}]\).

$$M(t) = \int_{-\infty}^{\infty} e^{tx} \cdot \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}} dx$$

Combine the exponents and complete the square in \(x\):

$$tx - \frac{(x-\mu)^2}{2\sigma^2} = -\frac{1}{2\sigma^2}\Bigl[(x - (\mu + \sigma^2 t))^2 - \sigma^4 t^2 - 2\mu\sigma^2 t\Bigr]$$

The \(x\)-dependent term integrates to 1 (it is a Gaussian pdf). The remaining constant factor is:

$$M(t) = \exp\!\left(\mu t + \frac{\sigma^2 t^2}{2}\right)$$

For \(\mathcal{N}(0,1)\): \(M(t) = e^{t^2/2}\). Numerical check: \(M(1) = e^{0.5} \approx 1.6487\) ✓

Poisson MGF

For \(X \sim \text{Poisson}(\lambda)\), \(P(X=k) = e^{-\lambda}\lambda^k/k!\):

$$M(t) = \mathbb{E}[e^{tX}] = \sum_{k=0}^{\infty} e^{tk} \cdot \frac{e^{-\lambda}\lambda^k}{k!} = e^{-\lambda} \sum_{k=0}^{\infty} \frac{(\lambda e^t)^k}{k!} = e^{-\lambda} e^{\lambda e^t}$$
$$M(t) = \exp\!\bigl(\lambda(e^t - 1)\bigr)$$

Numerical check: \(\lambda=3, t=0.5\): \(M(0.5) = e^{3(e^{0.5}-1)} = e^{3(1.6487-1)} = e^{1.946} \approx 7.002\) ✓

CLT Proof Sketch via Characteristic Functions

Let \(X_1, \ldots, X_n\) be i.i.d. with mean 0, variance \(\sigma^2\). Define the standardised sum \(S_n = \frac{1}{\sigma\sqrt{n}}\sum_{i=1}^n X_i\). We want to show \(S_n \xrightarrow{d} \mathcal{N}(0,1)\).

Step 1 — Characteristic function of \(S_n\). By independence and scaling:

$$\varphi_{S_n}(t) = \left[\varphi_X\!\left(\frac{t}{\sigma\sqrt{n}}\right)\right]^n$$

Step 2 — Taylor expand \(\varphi_X\) near 0. Using \(\mathbb{E}[X]=0\), \(\mathbb{E}[X^2]=\sigma^2\):

$$\varphi_X(s) = 1 + is\,\mathbb{E}[X] - \frac{s^2}{2}\mathbb{E}[X^2] + O(s^3) = 1 - \frac{\sigma^2 s^2}{2} + O(s^3)$$

Step 3 — Substitute \(s = t/(\sigma\sqrt{n})\):

$$\varphi_X\!\left(\frac{t}{\sigma\sqrt{n}}\right) = 1 - \frac{t^2}{2n} + O\!\left(n^{-3/2}\right)$$

Step 4 — Take the \(n\)-th power and use \(\lim_{n\to\infty}(1+a/n)^n = e^a\):

$$\varphi_{S_n}(t) = \left[1 - \frac{t^2}{2n} + O(n^{-3/2})\right]^n \xrightarrow{n\to\infty} e^{-t^2/2}$$

Step 5 — Recognise the limit. \(e^{-t^2/2}\) is the characteristic function of \(\mathcal{N}(0,1)\). By the Lévy continuity theorem, pointwise convergence of characteristic functions implies convergence in distribution:

$$S_n \xrightarrow{d} \mathcal{N}(0,1)$$
⚠️ Common Misconception

The MGF version of this proof requires the MGF to exist in a neighbourhood of 0, which rules out heavy-tailed distributions. The characteristic function proof above is completely general — it works for any distribution with finite mean and variance, including those with no MGF (e.g., Cauchy fails even the variance condition).

Uniqueness Theorem (statement)

If two random variables \(X\) and \(Y\) have the same MGF \(M(t)\) for all \(t\) in some open interval \((-h, h)\), then \(X\) and \(Y\) have the same distribution. Equivalently: if their characteristic functions agree for all \(t \in \mathbb{R}\), their CDFs agree. This makes MGF / CF arguments rigorous proofs, not just analogies.

From Scratch — Python (NumPy)

import numpy as np
from scipy.integrate import quad
# ── MGF via numerical integration ──────────────────────────────────
def mgf_numerical(t, samples):
"""M(t) = E[e^{tX}] estimated from samples."""
return np.mean(np.exp(t * samples))
# ── Analytical MGF for N(mu, sigma^2) ──────────────────────────────
def mgf_normal(t, mu=0, sigma=1):
"""Closed-form: M(t) = exp(mu*t + sigma^2*t^2/2)"""
return np.exp(mu * t + 0.5 * sigma**2 * t**2)
# ── Extract k-th moment via numerical differentiation ──────────────
def moment_from_mgf(k, mgf_fn, h=1e-3):
"""Central finite differences for k-th derivative at t=0."""
# Uses generalised finite difference formula
coeff = np.array([(-1)**(k-j) * _binom(k, j) for j in range(k+1)])
pts = np.array([mgf_fn((j - k/2) * h) for j in range(k+1)])
return np.dot(coeff, pts) / h**k
def _binom(n, k):
from math import comb; return comb(n, k)
# ── Verify: N(0,1) moments ─────────────────────────────────────────
rng = np.random.default_rng(42)
X = rng.standard_normal(100_000)
print(f"E[X] sample={X.mean():.4f} MGF-deriv={moment_from_mgf(1, mgf_normal):.4f}")
print(f"E[X²] sample={np.mean(X**2):.4f} MGF-deriv={moment_from_mgf(2, mgf_normal):.4f}")
print(f"E[X⁴] sample={np.mean(X**4):.4f} MGF-deriv={moment_from_mgf(4, mgf_normal):.4f}")
# Output: E[X]=0, E[X²]=1, E[X⁴]≈3 ✓
# ── Characteristic function (complex) ──────────────────────────────
def char_fn(t, samples):
"""φ(t) = E[e^{itX}] = E[cos(tX)] + i*E[sin(tX)]"""
return np.mean(np.exp(1j * t * samples))
# |φ(t)| <= 1 always; for N(0,1) φ(t) = exp(-t²/2)
t_vals = np.array([0, 0.5, 1.0, 2.0])
for tv in t_vals:
cf_sample = abs(char_fn(tv, X))
cf_exact = np.exp(-tv**2 / 2)
print(f"t={tv}: |φ_sample|={cf_sample:.4f} |φ_exact|={cf_exact:.4f}")

Production Usage — SciPy

from scipy import stats
import numpy as np
# scipy.stats distributions expose .moment(k) and .stats()
dist = stats.norm(loc=0, scale=1)
print(dist.moment(1)) # 0.0 (mean)
print(dist.moment(2)) # 1.0 (second moment = variance when mean=0)
print(dist.moment(4)) # 3.0 (fourth moment)
# MGF for common distributions via moment-matching
# For sums of independents: MGFs multiply
def mgf_sum_normals(t, mu_list, sigma_list):
"""MGF of sum of independent Normals = product of individual MGFs"""
return np.prod([mgf_normal(t, mu, sig) for mu, sig in zip(mu_list, sigma_list)])
# ⚠️ Gotcha: MGF may not exist — always check domain
# Cauchy dist has NO finite moments and NO MGF
cauchy = stats.cauchy()
samples = cauchy.rvs(10_000)
print(np.mean(np.exp(0.01 * samples))) # likely inf or huge — MGF doesn't exist
⚠️ Gotcha: Domain of the MGF

The MGF of a Log-Normal distribution exists only for \(t \le 0\), not for any \(t > 0\). Use the characteristic function (always well-defined) for such distributions. In ML, heavy-tailed loss distributions (e.g., gradient noise with power-law tails) are exactly where this matters.

When to Use Which

🎯 Decision Guide
  • Distribution has light/medium tails (Normal, Poisson, Exponential) → MGF — closed form, easy differentiation
  • Distribution may be heavy-tailed (Cauchy, stable) or CLT proof → Characteristic function
  • Want cumulants (excess kurtosis, standardised skewness) → CGF
  • Sums of random variables → multiply MGFs (or CFs), then invert
  • Tail probability / large deviations → use CGF with Legendre–Fenchel transform

Key Takeaways

  • MGF packs all moments into one function; \(k\)-th moment = \(k\)-th derivative at 0.
  • Independence turns sums into products — algebraically simple but statistically powerful.
  • Characteristic function is the universal version: exists for every distribution, same product rule, underpins the rigorous CLT.
  • The CLT is proved in 5 lines using characteristic functions: Taylor expand → raise to \(n\)-th power → apply \((1+x/n)^n \to e^x\) → recognize \(e^{-t^2/2}\) → invoke Lévy continuity theorem.
  • Uniqueness theorem makes these tools logically tight: identical MGF = identical distribution.
🔗 Connections to ML

The CLT (proved via characteristic functions) justifies why mini-batch gradient noise is often approximated as Gaussian. The cumulant generating function appears in PAC-Bayes bounds and large deviation theory for generalization. Characteristic functions are used in kernel methods (Bochner's theorem: a positive definite kernel is the Fourier transform of a non-negative measure).
