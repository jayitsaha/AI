Expected Calibration Error (ECE)

Quantifying the gap between model confidence and actual accuracy — the reliability diagram's weighted penalty
Intermediate Classical ML Calibration O(N log N)
1
Understanding ECE
▾

A classifier outputs a probability — say, 85% confident this email is spam. But does "85% confident" actually mean the model is right 85% of the time? ECE measures exactly this mismatch.

💡 The Core Intuition

Group all predictions by their confidence score (into bins). In each bin, compare the average confidence to the average accuracy. ECE is the weighted average of these gaps — weighted by how many predictions fall in each bin.

Real-world analogy: Imagine a weather forecaster who says "70% chance of rain" on 100 different days. If it only rained on 50 of those days, the forecaster is overconfident. ECE is like measuring how often the forecaster's stated confidence matches reality — across all their confidence levels.

📐 The Formula
$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$

\(M\) = number of bins, \(|B_m|\) = number of samples in bin \(m\), \(N\) = total samples, \(\text{acc}(B_m)\) = fraction correct in bin, \(\text{conf}(B_m)\) = mean predicted confidence in bin.

⚠️ If You Remember One Thing

A perfectly calibrated model has ECE = 0. Every gap bar in the reliability diagram is zero — confidence matches accuracy at every level. In practice, modern deep neural networks are severely overconfident (high ECE) unless post-hoc calibration (Platt scaling, temperature scaling) is applied.

2
How It Works — Binning Mechanics
▾

Step-by-Step Computation

1. Collect predictions. For each of \(N\) samples, record the model's maximum predicted probability \(\hat{p}_i\) and whether it was correct \(y_i \in \{0,1\}\).

2. Partition into bins. Divide \([0,1]\) into \(M\) equal-width intervals (typically \(M=10\), each of width 0.1). Assign sample \(i\) to bin \(B_m\) if \(\hat{p}_i \in \left(\frac{m-1}{M}, \frac{m}{M}\right]\).

3. Compute per-bin statistics. For each non-empty bin \(B_m\):

$$\text{acc}(B_m) = \frac{1}{|B_m|} \sum_{i \in B_m} \mathbf{1}[\hat{y}_i = y_i], \quad \text{conf}(B_m) = \frac{1}{|B_m|} \sum_{i \in B_m} \hat{p}_i$$

4. Compute the weighted gap. Weight each bin's absolute gap by its relative size \(|B_m|/N\) and sum:

$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$

MCE — Maximum Calibration Error

While ECE averages gaps, MCE takes the worst-case bin — useful when you care about reliability at the extremes:

$$\text{MCE} = \max_{m \in \{1,\ldots,M\}} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$
⚠️ Binning Sensitivity

ECE is not a fixed-point metric — it depends on \(M\). With \(M=10\) bins many papers use: sparse high-confidence predictions and dense low-confidence ones get lumped together. Adaptive (equal-mass) binning assigns roughly equal \(|B_m|\) to each bin, reducing variance from empty bins. The ECE value can change substantially (±5%) when switching from uniform to adaptive binning on the same model.

✅ Overconfidence vs. Underconfidence

When \(\text{conf}(B_m) > \text{acc}(B_m)\): the model is overconfident (gap bar above diagonal). When \(\text{conf}(B_m) < \text{acc}(B_m)\): underconfident (gap bar below diagonal). Modern DNNs are almost always overconfident without calibration.

Mathematical Properties & Variants
▾

Connection to Expected Value

ECE estimates the population-level quantity:

$$\text{ECE} = \mathbb{E}_{\hat{p}}\left[ \left| \mathbb{P}(Y=1 \mid \hat{p}) - \hat{p} \right| \right]$$

where the expectation is taken over the distribution of predicted probabilities. Perfect calibration means \(\mathbb{P}(Y=1 \mid \hat{p}=p) = p\) for all \(p \in [0,1]\).

Equal-Mass vs. Equal-Width Binning

PropertyEqual-Width (uniform)Equal-Mass (adaptive)

Classwise ECE (for multi-class)

For a \(K\)-class classifier, compute ECE independently for each class \(k\) treating it as one-vs-rest, then average:

$$\text{CECE} = \frac{1}{K} \sum_{k=1}^{K} \text{ECE}_k$$

Reliability Diagram Interpretation

The reliability diagram plots \(\text{acc}(B_m)\) (y-axis) vs. \(\text{conf}(B_m)\) (x-axis) for each bin. The diagonal \(y=x\) represents perfect calibration. The area between bars and the diagonal — when weighted by bin mass — is ECE.

📐 Numerical Example

Suppose \(N=1000\), \(M=10\) bins. Bin 8 (confidence ≈ 0.75–0.85): 150 samples, 90 correct. Then \(\text{acc}(B_8) = 90/150 = 0.60\), \(\text{conf}(B_8) \approx 0.80\), gap \(= 0.20\), weighted contribution \(= (150/1000) \times 0.20 = 0.030\). Summing all 10 bins gives ECE.

✅ When to Use ECE

Use ECE when you need to verify that a model's confidence scores can be trusted as probabilities — e.g., medical diagnosis (does "90% confident" mean 90%?), fraud detection, or any risk-based decision system. Always pair ECE with a reliability diagram for interpretation.

🚫 ECE Pitfalls

1. ECE is binning-dependent — always report M. 2. ECE only measures the top class confidence, not the full probability vector (use Brier Score for the latter). 3. A model can have low ECE but be inaccurate — calibration ≠ accuracy. 4. Empty bins (no predictions in a range) are silently skipped, distorting the average.
