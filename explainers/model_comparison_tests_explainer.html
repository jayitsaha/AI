Understanding the Problem

You trained model A and model B. On your 10-fold CV, A beats B by 1.2 accuracy points. Is that real, or is it noise? Statistical hypothesis tests let you quantify whether the difference is larger than what chance alone would produce.

Core Question

Given a vector of per-fold (or per-example) performance differences \(\mathbf{d} = [d_1, \dots, d_k]\), can we reject the null hypothesis \(H_0: \mathbb{E}[d]=0\)?

Four tests address this — each with different assumptions about the distribution, the data, and the comparison protocol:

If you remember one thing

The naive paired t-test on k-fold CV scores is anti-conservative (rejects too often) because the folds share training data, violating independence. Dietterich's 5×2cv test was specifically designed to fix this.

How Each Test Works Internally

A. Paired t-test on CV fold scores

Given \(k\) folds with per-fold differences \(d_i = \text{acc}_i^A - \text{acc}_i^B\):

$$\bar{d} = \frac{1}{k}\sum_{i=1}^k d_i, \qquad s_d^2 = \frac{1}{k-1}\sum_{i=1}^k(d_i - \bar{d})^2$$
$$t = \frac{\bar{d}}{s_d/\sqrt{k}} \sim t_{k-1} \quad \text{under } H_0$$

Reject \(H_0\) if \(|t| > t_{k-1,\,\alpha/2}\). Standard assumption: \(d_i \stackrel{\text{iid}}{\sim} \mathcal{N}(\mu, \sigma^2)\). Problem: fold scores share training data — they are not iid.

B. Wilcoxon Signed-Rank Test

Rank-based, no normality assumption. Steps:

  • Compute \(d_i = \text{score}_i^A - \text{score}_i^B\). Drop ties (\(d_i=0\)).
  • Rank \(|d_i|\) from 1 to \(k'\) (handle ties by averaging ranks).
  • Compute \(W^+ = \sum_{\{i:d_i>0\}} R_i\) and \(W^- = \sum_{\{i:d_i<0\}} R_i\).
  • Test statistic \(W = \min(W^+, W^-)\). For \(k'\ge 10\), use normal approximation:
$$z = \frac{W - \mu_W}{\sigma_W}, \quad \mu_W = \frac{k'(k'+1)}{4}, \quad \sigma_W = \sqrt{\frac{k'(k'+1)(2k'+1)}{24}}$$

Only cells \(b\) (A right, B wrong) and \(c\) (A wrong, B right) carry information. Under \(H_0\): \(b\) and \(c\) are equally likely.

$$\chi^2 = \frac{(|b-c|-1)^2}{b+c} \sim \chi^2_1 \quad \text{(with continuity correction)}$$

For small \(b+c < 25\), use exact binomial: \(b \sim \text{Binomial}(b+c,\, 0.5)\).

D. Dietterich's 5×2 CV Paired t-test

Run 5 independent trials. Each trial: randomly split data into two equal halves (fold 1, fold 2). Train A and B on fold 1, test on fold 2, and vice versa. Record differences:

$$p_i^{(j)} = \text{acc}_{i,j}^A - \text{acc}_{i,j}^B, \quad i=1,\dots,5,\; j=1,2$$

Within trial \(i\), compute mean and variance:

$$\bar{p}_i = \frac{p_i^{(1)} + p_i^{(2)}}{2}, \qquad s_i^2 = \left(p_i^{(1)} - \bar{p}_i\right)^2 + \left(p_i^{(2)} - \bar{p}_i\right)^2$$

Test statistic (only numerator uses trial 1's first fold to avoid bias):

$$t = \frac{p_1^{(1)}}{\sqrt{\frac{1}{5}\sum_{i=1}^5 s_i^2}} \sim t_5 \quad \text{under } H_0$$

Five degrees of freedom from 5 independent variance estimates. This correctly accounts for the correlated nature of the folds.

Why 5×2 and not more folds?

Each trial must be statistically independent (separate random splits). Using 2 folds per trial is the minimal design that lets you estimate within-trial variance. Dietterich showed via simulation that 5 trials with df=5 controls Type I error near the nominal α=0.05 level, whereas naive 10-fold paired t often reaches 0.10–0.25.

Significance vs Noise — What Can Go Wrong

Even correct tests can mislead. Here's the landscape of failure modes:

Type I Error (False Positive) — "We found a difference that doesn't exist"

The naive 10-fold paired t-test inflates Type I error because folds share ~90% of training data → their errors are correlated → the denominator \(s_d/\sqrt{k}\) underestimates variance → \(t\) is too large. Dietterich (1998) showed empirical Type I rates of 0.09–0.27 at nominal α=0.05.

Type II Error (False Negative) — "We missed a real difference"

The 5×2 test, while conservative in Type I, has lower power than the naive paired t because it only uses 10 data points (5×2) vs. the full \(n\) used k times. For small effect sizes or small datasets, the test may not reject even when A genuinely beats B.

Critical Anti-Pattern

Running multiple tests (paired t AND Wilcoxon AND McNemar) and reporting only the one that gives p<0.05 is p-hacking. Choose your test before seeing the results, based on the experimental design and distributional assumptions.

Effect Size — Statistical vs Practical Significance

A test can be significant (\(p = 0.003\)) yet practically meaningless (\(\Delta\text{acc} = 0.03\%\)). Always report Cohen's d alongside the p-value:

$$d = \frac{\bar{d}}{s_d}$$

Benchmarks: \(d\approx 0.2\) small, \(d\approx 0.5\) medium, \(d\geq 0.8\) large. For classification accuracy, even d=0.2 may be operationally significant depending on the domain.

Key Takeaways
Summary
  • The naive paired t-test on CV folds is anti-conservative — use it only as a quick screen.
  • Dietterich's 5×2 cv t-test is the gold standard for CV-based comparisons.
  • McNemar's test is optimal when you have fixed per-example predictions from both models.
  • Wilcoxon is your fallback when normality is doubtful and you can't run 5×2.
  • Always report effect size (Cohen's d or accuracy delta) alongside the p-value.
  • A statistically significant difference may be practically negligible — and vice versa.
