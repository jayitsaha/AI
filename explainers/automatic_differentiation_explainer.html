Understanding Automatic Differentiation
▼

What is it? Automatic differentiation (AD) is a technique to compute exact derivatives of any computer program — not symbolic math, not finite differences, but exact numerical derivatives by applying the chain rule mechanically to every arithmetic operation. All modern deep learning frameworks (PyTorch, JAX, TensorFlow) are built on it.

Analogy: Imagine a long assembly line where each station transforms a part. A quality inspector can walk the line forward (noting how each station's output changes when the input jitters slightly) or walk backward (starting from the final defect and tracing which upstream station is responsible). Forward mode inspects one input's influence on all outputs. Reverse mode inspects all inputs' influence on one output — perfect for a single loss.

💡 If you remember one thing

Forward mode costs 1 pass per input (\(O(n)\) passes for \(n\) inputs). Reverse mode costs 1 pass per output (\(O(m)\) passes for \(m\) outputs). Neural nets have millions of inputs and one scalar loss, so reverse mode (backprop) requires exactly 1 backward pass regardless of model size.

Three ways to compute derivatives

  • Symbolic differentiation — manipulate expressions algebraically (Mathematica). Exact but can cause expression swell.
  • Numerical differentiation — finite differences \(\frac{f(x+h)-f(x)}{h}\). Simple but \(O(n)\) function evaluations + numerical error.
  • Automatic differentiation — track derivatives alongside values through a computation graph. Exact, efficient, composable with all control flow.

How AD Works Internally
▼

The Computational Graph

Every function is decomposed into a directed acyclic graph (DAG) of primitive operations (add, multiply, sin, exp, …). For \(f = \sin(x_1) + x_1 x_2\) with \(x_1=0.5,\, x_2=1.5\):

$$v_1 = x_1 = 0.5, \quad v_2 = x_2 = 1.5, \quad v_3 = \sin(v_1) \approx 0.4794, \quad v_4 = v_1 \cdot v_2 = 0.75, \quad f = v_3 + v_4 \approx 1.2294$$

Forward Mode — Dual Numbers / Tangents

Augment each variable with a tangent (dot) that tracks how it changes w.r.t. one chosen input. Seed \(\dot{x}_1 = 1, \dot{x}_2 = 0\) to compute \(\partial f / \partial x_1\). Propagate using the chain rule:

$$\dot{v}_3 = \cos(v_1)\cdot\dot{v}_1 = \cos(0.5)\cdot 1 \approx 0.8776, \quad \dot{v}_4 = x_2\dot{v}_1 + x_1\dot{v}_2 = 1.5, \quad \dot{f} = \dot{v}_3 + \dot{v}_4 \approx 2.3776$$

To also get \(\partial f/\partial x_2\), you must run a second forward pass with seed \(\dot{x}_1=0, \dot{x}_2=1\), yielding \(\dot{f}=0.5\). Cost: one forward pass per input.

Reverse Mode — Adjoints / Backpropagation

First, run a forward pass storing all intermediate values (the "tape"). Then seed \(\bar{f}=1\) and propagate adjoints \(\bar{v}_i = \partial f/\partial v_i\) backward through the graph:

$$\bar{v}_3 = \bar{f}\cdot 1 = 1, \quad \bar{v}_4 = \bar{f}\cdot 1 = 1$$
$$\bar{x}_1 = \bar{v}_3\cdot\cos(v_1) + \bar{v}_4\cdot x_2 = 0.8776 + 1.5 = 2.3776, \quad \bar{x}_2 = \bar{v}_4\cdot x_1 = 0.5$$

Both \(\partial f/\partial x_1\) and \(\partial f/\partial x_2\) emerge in one backward pass.

🔑 Key Property — The FLOP/Memory Trade-off

For a function \(f:\mathbb{R}^n \to \mathbb{R}^m\):
Forward mode: \(m\) outputs at once per pass → need \(n\) passes for full Jacobian. Ideal when \(n \ll m\).
Reverse mode: \(n\) inputs at once per pass → need \(m\) passes for full Jacobian. Ideal when \(m \ll n\).
Deep learning: \(n \sim 10^8\) parameters, \(m=1\) (scalar loss). Reverse mode wins by \(10^8\times\).

The Mathematics — Chain Rule in Two Directions
▼

The Chain Rule as Matrix Multiplication

The Jacobian of \(f = g \circ h\) is \(J_f = J_g \cdot J_h\). AD avoids forming the full Jacobian and instead computes Jacobian-vector products (forward) or vector-Jacobian products (reverse):

$$\text{Forward (JVP):}\quad J\mathbf{v} = \frac{\partial f}{\partial x}\mathbf{v}, \quad \text{Reverse (VJP):}\quad \mathbf{u}^\top J = \mathbf{u}^\top \frac{\partial f}{\partial x}$$

Dual Numbers Formalism (Forward Mode)

Define dual numbers \(\epsilon\) with \(\epsilon^2 = 0\). Then \(f(x+\dot{x}\epsilon) = f(x) + f'(x)\dot{x}\epsilon\). Every primitive op propagates the tangent automatically:

$$\sin(a+\dot{a}\epsilon) = \sin(a) + \cos(a)\dot{a}\epsilon, \quad (a+\dot{a}\epsilon)(b+\dot{b}\epsilon) = ab + (a\dot{b}+b\dot{a})\epsilon$$

Reverse Mode — The Adjoint Equation

The adjoint \(\bar{v}_i \triangleq \partial f / \partial v_i\) satisfies the reverse recurrence. If \(v_j\) depends on \(v_i\) via \(v_j = \phi(v_i)\):

$$\bar{v}_i = \sum_{j:\, v_i \to v_j} \bar{v}_j \cdot \frac{\partial v_j}{\partial v_i}$$

This is exactly the backpropagation rule. The sum handles the case where a variable fans out to multiple nodes (e.g., \(x_1\) appears in both \(\sin(x_1)\) and \(x_1 x_2\)).

⚠️ Common Misconception

AD is not symbolic differentiation and not finite differences. It computes the exact derivative at a specific numerical point by applying the chain rule to primitive operations. No step size \(h\) is involved, so there is no truncation error or cancellation error.

Key Takeaways & When to Use Each Mode
▼

Decision Rule

🔑 Forward vs Reverse — The Rule

Let \(f: \mathbb{R}^n \to \mathbb{R}^m\). Use forward mode when \(n \leq m\) (fewer inputs than outputs). Use reverse mode when \(m \leq n\) (fewer outputs than inputs). Neural network training: \(n = 10^6\text{–}10^{10}\) parameters, \(m = 1\) loss → always reverse.

Forward mode shines when:

  • Computing directional derivatives \(J\mathbf{v}\) (e.g., Hessian-vector products)
  • Functions with few inputs: sensitivity analysis, uncertainty propagation
  • Online/streaming computation where you can't store a tape
  • Physics simulations differentiating w.r.t. 1–2 physical parameters

Reverse mode shines when:

  • Any ML model training (backprop IS reverse mode AD)
  • Optimizing cost functions over many parameters
  • Adjoint-based PDE-constrained optimization
  • Sensitivity analysis of many inputs to one output
⚠️ Memory Trade-off of Reverse Mode

Reverse mode must store all intermediate primal values (the "tape" or "Wengert list") during the forward pass to use in the backward pass. Memory cost is \(O(T)\) where \(T\) is the number of primitive ops. Gradient checkpointing recomputes parts of the forward pass during backprop, trading FLOPS for memory.

💡 Connection to PyTorch

PyTorch's autograd builds the computation graph dynamically ("define-by-run"). Each tensor tracks its creator operation. Calling .backward() traverses the graph in reverse topological order, accumulating gradients via .grad. JAX uses functional transformations: jax.jvp for forward mode (JVP), jax.vjp or jax.grad for reverse mode (VJP).

Code Trace — From Scratch in NumPy
▼
import numpy as np
x1, x2 = 0.5, 1.5
# ── PRIMAL (forward values) ──────────────────
v1 = x1 # 0.5
v2 = x2 # 1.5
v3 = np.sin(v1) # 0.479426
v4 = v1 * v2 # 0.750000
f = v3 + v4 # 1.229426
# ── FORWARD MODE: df/dx1 (seed x1dot=1) ─────
v1d = 1.0 # seed
v2d = 0.0
v3d = np.cos(v1) * v1d # 0.877583
v4d = x2 * v1d + x1 * v2d # 1.500000
fd = v3d + v4d # 2.377583 = df/dx1
# ── FORWARD MODE: df/dx2 (seed x2dot=1) ─────
v1d2 = 0.0; v2d2 = 1.0 # new seed
v3d2 = np.cos(v1) * v1d2 # 0.0
v4d2 = x2*v1d2 + x1*v2d2 # 0.5
fd2 = v3d2 + v4d2 # 0.5 = df/dx2
# ── REVERSE MODE: both gradients in 1 pass ──
f_bar = 1.0 # seed = df/df
v3_bar = f_bar * 1 # df/dv3 = 1
v4_bar = f_bar * 1 # df/dv4 = 1
x1_bar = v3_bar*np.cos(v1) + v4_bar*x2 # 2.377583
x2_bar = v4_bar * x1 # 0.5
print(x1_bar, x2_bar) # [2.3776, 0.5000]
