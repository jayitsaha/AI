Graph Types: Undirected, Directed, Weighted, Bipartite & DAG

Five fundamental graph structures — their properties, maths, and ML roles
Intermediate Discrete Math Graph Theory Foundational for GNNs
1
Understanding Graph Types
▼

What is a graph? A graph \(G = (V, E)\) is a mathematical structure with a set of vertices (nodes) \(V\) and a set of edges \(E\) connecting pairs of vertices. The key question in any graph problem is: what information do the edges carry? That choice defines the graph type.

Analogy: Think of a city's road map. An undirected graph is like streets where you can drive both ways — the connection is symmetric. A directed graph adds one-way streets. A weighted graph attaches travel times to each road. A bipartite graph is a map with two zones (residential vs commercial) where roads only cross zones. A DAG is a delivery-route network where every delivery only moves forward — no circular routes exist.

💡 If you remember one thing

Each graph type is a restriction or augmentation of the basic \(G=(V,E)\) definition: directions turn edges into ordered pairs, weights attach scalars, bipartiteness partitions vertices, and DAGs forbid cycles while enforcing a topological order. Every ML graph (knowledge graph, computation graph, user-item matrix) maps onto exactly one of these types.

2
Five Graph Types — Properties & Structure
▼

1. Undirected Graph

Edges are unordered pairs: \(\{u,v\} = \{v,u\}\). The degree \(\deg(v)\) counts how many edges touch vertex \(v\). The Handshaking Lemma is the central identity:

$$\sum_{v \in V} \deg(v) = 2|E|$$

Numerically: a 5-node graph with edges \(\{0,1\},\{0,2\},\{1,2\},\{1,3\},\{2,4\},\{3,4\}\) has degree sequence \([2,3,3,2,2]\) summing to \(12 = 2 \times 6\). The adjacency matrix \(A\) is symmetric: \(A_{ij}=A_{ji}\).

2. Directed Graph (Digraph)

Edges are ordered pairs: \((u,v)\neq(v,u)\). Each vertex has both an in-degree \(\deg^-(v)\) and an out-degree \(\deg^+(v)\):

$$\sum_{v \in V} \deg^+(v) = \sum_{v \in V} \deg^-(v) = |E|$$

The adjacency matrix is generally asymmetric. Strong connectivity matters: vertex \(u\) can reach \(v\) AND \(v\) can reach \(u\). Tarjan's algorithm finds strongly connected components in \(O(V+E)\).

3. Weighted Graph

A weight function \(w: E \to \mathbb{R}\) attaches a scalar to each edge. Often represents cost, distance, or similarity. Dijkstra's algorithm finds shortest paths in \(O((V+E)\log V)\) for non-negative weights. The weighted adjacency matrix has \(A_{ij} = w(i,j)\) (or \(0\) if no edge), and the Laplacian generalises to:

$$L_{ij} = \begin{cases} \sum_{k} w(i,k) & \text{if } i=j \\ -w(i,j) & \text{if } (i,j)\in E \\ 0 & \text{otherwise} \end{cases}$$

4. Bipartite Graph

Vertex set splits into two disjoint parts \(V = U \cup W\) with \(U \cap W = \emptyset\), and every edge connects a vertex in \(U\) to one in \(W\) — no edges within a part. A graph is bipartite iff it contains no odd-length cycle. The biadjacency matrix \(B \in \mathbb{R}^{|U|\times|W|}\) has \(B_{ij}=1\) if user \(i\) interacts with item \(j\) — the core structure of collaborative filtering.

5. Directed Acyclic Graph (DAG)

A directed graph with no directed cycle. By the absence of cycles, vertices can be ordered so all edges point "forward" — this is called a topological ordering. Kahn's algorithm computes it using in-degree queues in \(O(V+E)\). A key invariant:

$$\text{DAG has a topological order} \iff \text{no directed cycle exists}$$

The neural network computation graph is a DAG: inputs are sources (in-degree 0), loss is the sink (out-degree 0), and backprop is reverse topological traversal.

🔑 Key Property — Adjacency Spectrum

The eigenvalues of the adjacency matrix \(A\) reveal structure: for an undirected graph the spectrum is real and symmetric; for bipartite graphs the spectrum is symmetric around zero (\(\lambda_i = -\lambda_{n-i}\)); for DAGs the matrix is nilpotent (all eigenvalues zero after topological relabeling).

Why It Works — Math & ML Connections
▼

Graph Laplacian & Spectral Theory

The unnormalised Laplacian \(L = D - A\) (degree matrix minus adjacency) is positive semi-definite for any undirected graph. Its smallest eigenvalue is always zero (with eigenvector \(\mathbf{1}\)), and the number of zero eigenvalues equals the number of connected components. The Fiedler value (second-smallest eigenvalue \(\lambda_2\)) measures algebraic connectivity — it is zero iff the graph is disconnected.

$$\mathbf{x}^\top L \mathbf{x} = \sum_{(i,j)\in E} (x_i - x_j)^2 \geq 0$$

ML Role of Each Type

  • Undirected: Social networks, molecular graphs, citation graphs. GNN message-passing aggregates neighbour features symmetrically.
  • Directed: Web hyperlinks (PageRank), Twitter follower graphs, causal graphs. The direction encodes asymmetric influence.
  • Weighted: Knowledge graph relation scores, attention matrices in Transformers (attention weight = edge weight in a complete directed weighted graph), similarity graphs for spectral clustering.
  • Bipartite: User-item recommendation (matrix factorisation implicitly factorises the biadjacency matrix \(B \approx UV^\top\)). Also heterogeneous graphs in drug-target interaction.
  • DAG: Computational graphs (PyTorch autograd), Bayesian networks (no directed cycles = conditional independence structure), scheduling problems, topological feature propagation in tree-LSTM.
📐 Adjacency Matrix Properties by Type

Undirected: \(A = A^\top\), spectrum real.
Directed: \(A\) generally asymmetric.
Weighted: \(A_{ij} = w_{ij} \in \mathbb{R}\).
Bipartite: \(A = \begin{bmatrix} 0 & B \\ B^\top & 0 \end{bmatrix}\), spectrum symmetric about 0.
DAG: after topo-sort relabeling, \(A\) is strictly upper-triangular (\(A^k = 0\) for \(k \geq |V|\)).

⚠️ Common Misconception

A tree is a special undirected graph (connected, acyclic, \(|E|=|V|-1\)) — it is NOT a DAG unless you root it and orient edges away from the root. Similarly, a DAG is not necessarily a tree: multiple parents per node are allowed.

Interview Questions

  • Q: How do you detect a cycle in a directed graph? — DFS with three colours (white/grey/black); a grey-to-grey back-edge indicates a cycle. For undirected graphs, a grey-to-grey edge not to the parent node suffices.
  • Q: Why is the computation graph a DAG and not just a directed graph? — Backpropagation requires a topological ordering to compute gradients in reverse; a cycle would make this impossible (the gradient of \(x\) would depend on itself).
  • Q: How does matrix factorisation relate to bipartite graphs? — The rating matrix \(R\) is the biadjacency matrix of the user-item bipartite graph. Factorising \(R \approx UV^\top\) learns low-dimensional embeddings for both partitions.
  • Q: What makes GNNs sensitive to graph type? — Standard GNN message-passing assumes undirected edges (symmetric aggregation). Directed graphs need asymmetric aggregators; weighted graphs need attention coefficients; DAGs allow layer-by-layer propagation.
