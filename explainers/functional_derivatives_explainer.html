What Is a Functional Derivative?
▼

Ordinary calculus asks: "How does a number change when we tweak another number?" Variational calculus asks a more ambitious question: "How does a scalar output change when we tweak an entire function?"

A functional is a map from a function space to the reals. Write it as \(J[f]\) — the square brackets signal that the argument is a function, not a point. The canonical form is an integral functional:

$$J[f] = \int_a^b L\!\left(x,\, f(x),\, f'(x)\right) dx$$

where \(L\) is the Lagrangian (or integrand kernel), a function of the independent variable \(x\), the function value \(f(x)\), and the slope \(f'(x)\).

Analogy — GPS Routing

Ordinary calculus finds the best number (e.g., speed on a fixed road). Variational calculus finds the best entire route — the function \(f\) that minimises total travel time. Every possible road shape is a candidate; the functional assigns a cost to each one.

The functional derivative \(\dfrac{\delta J}{\delta f(x)}\) is the analogue of a partial derivative: it measures the infinitesimal change in \(J\) when we poke the function at a single point \(x\). Formally, if we perturb \(f \to f + \varepsilon\,\eta\) for an arbitrary test function \(\eta\) (with \(\eta(a)=\eta(b)=0\)), then

$$\frac{d}{d\varepsilon}\bigg|_{\varepsilon=0} J[f + \varepsilon\,\eta] = \int_a^b \frac{\delta J}{\delta f(x)}\,\eta(x)\,dx$$

This is the Gâteaux derivative of \(J\) in the direction \(\eta\). Setting \(\delta J = 0\) for all admissible \(\eta\) gives the Euler–Lagrange equation, the fundamental optimality condition of variational calculus.

One sentence

The functional derivative \(\delta J/\delta f(x)\) tells you in which direction to "push" the function \(f\) at each point to decrease \(J\) — it is the gradient of a scalar in infinite-dimensional function space.

2
Deriving the Euler–Lagrange Equation
▼

Setup: Perturb the Function

Let \(f^*\) be the unknown minimiser of \(J[f] = \int_a^b L(x, f, f')\,dx\). For any smooth test function \(\eta\) with \(\eta(a) = \eta(b) = 0\) (so perturbations vanish at the boundary), define the one-parameter family

$$f_\varepsilon(x) = f^*(x) + \varepsilon\,\eta(x)$$

Then \(\Phi(\varepsilon) \equiv J[f_\varepsilon]\) is an ordinary function of the real number \(\varepsilon\), and \(\varepsilon = 0\) is a minimum, so \(\Phi'(0) = 0\).

Step 1 — Differentiate Under the Integral

$$\Phi'(\varepsilon) = \frac{d}{d\varepsilon}\int_a^b L(x, f^*+\varepsilon\eta,\, f^{*\prime}+\varepsilon\eta')\,dx = \int_a^b \left(\frac{\partial L}{\partial f}\,\eta + \frac{\partial L}{\partial f'}\,\eta'\right)dx$$

Step 2 — Integrate by Parts (the key step)

The second term contains \(\eta'\). Integrate by parts: \(\displaystyle\int_a^b \frac{\partial L}{\partial f'}\,\eta'\,dx = \left[\frac{\partial L}{\partial f'}\,\eta\right]_a^b - \int_a^b \frac{d}{dx}\!\left(\frac{\partial L}{\partial f'}\right)\eta\,dx\). The boundary term vanishes because \(\eta(a)=\eta(b)=0\).

Step 3 — Apply the Fundamental Lemma

Collecting terms, \(\Phi'(0) = 0\) becomes

$$\int_a^b \left[\frac{\partial L}{\partial f} - \frac{d}{dx}\frac{\partial L}{\partial f'}\right]\eta(x)\,dx = 0 \quad \forall\,\eta$$

By the fundamental lemma of calculus of variations (du Bois-Reymond, 1879), if an integral against every smooth \(\eta\) is zero, the bracket must be identically zero. This yields the Euler–Lagrange equation:

$$\boxed{\frac{\partial L}{\partial f} - \frac{d}{dx}\frac{\partial L}{\partial f'} = 0}$$

The functional derivative is exactly the left-hand side:

$$\frac{\delta J}{\delta f(x)} = \frac{\partial L}{\partial f} - \frac{d}{dx}\frac{\partial L}{\partial f'}$$

Example: Shortest Path in the Plane

The arc length of a curve \(f(x)\) from \(x=a\) to \(x=b\) is \(J[f] = \int_a^b \sqrt{1 + f'(x)^2}\,dx\). Here \(L = \sqrt{1+f'^2}\), so \(\partial L/\partial f = 0\) and \(\partial L/\partial f' = f'/\sqrt{1+f'^2}\). The Euler–Lagrange equation gives

$$\frac{d}{dx}\!\left[\frac{f'}{\sqrt{1+f'^2}}\right] = 0 \implies f' = \text{const} \implies f(x) = ax + b$$

The shortest path between two points is a straight line — confirmed by variational calculus. Numerically: \(J[\text{straight line}] = \sqrt{2} \approx 1.4142\); any perturbation increases length (verified: at \(\varepsilon=\pm0.5\), \(J \approx 1.4293\)).

Boundary Conditions Matter

The derivation requires \(\eta(a)=\eta(b)=0\) (Dirichlet BCs). For free endpoints (natural BCs), the boundary term \([\partial L/\partial f'\cdot\eta]_a^b\) does NOT vanish and yields additional transversality conditions: \(\partial L/\partial f'\big|_{x=a,b} = 0\).

ML Applications & Entropy
▼

1. Empirical Risk as a Functional

In machine learning, given data distribution \(p(x,y)\), the squared-loss risk functional is

$$J[f] = \mathbb{E}_{p}\!\left[(f(x) - y)^2\right] = \int\!\int (f(x)-y)^2\,p(x,y)\,dx\,dy$$

Treating this as a functional in \(f\) and computing the functional derivative:

$$\frac{\delta J}{\delta f(x)} = 2\int (f(x) - y)\,p(y|x)\,p(x)\,dy = 2\,p(x)\!\left[f(x) - \mathbb{E}[y|x]\right]$$

Setting \(\delta J/\delta f(x) = 0\) at every \(x\) gives \(f^*(x) = \mathbb{E}[y|x]\) — the conditional expectation is the pointwise minimiser of squared loss. This is not just a statistical fact; it follows directly from the calculus of variations.

2. Regularised (Sobolev) Functional

Adding a smoothness penalty \(\lambda\int f'(x)^2\,dx\) gives

$$J[f] = \int \left[(f(x)-y(x))^2 + \lambda\,f'(x)^2\right]p(x)\,dx$$

Here \(L = (f-y)^2 p + \lambda (f')^2 p\), so \(\partial L/\partial f = 2(f-y)p\) and \(\partial L/\partial f' = 2\lambda f' p\). The Euler–Lagrange equation (with constant \(p\)) becomes

$$2(f-y)p - 2\lambda p\,f'' = 0 \implies f - \lambda f'' = y$$

This is a second-order ODE for the optimal \(f\). Spline smoothing solves exactly this system: the natural cubic spline is the minimiser of this functional over piecewise-cubic functions.

3. Maximum Entropy — Optimising a Distribution

The differential entropy functional over probability densities is \(H[p] = -\int p(x)\log p(x)\,dx\). Maximising \(H\) subject to \(\int p\,dx = 1\) uses a Lagrange multiplier \(\mu\):

$$\frac{\delta}{\delta p(x)}\!\left[-\int p\log p\,dx - \mu\!\int p\,dx\right] = -(1 + \log p(x)) - \mu = 0$$
$$\implies p(x) = e^{-(1+\mu)} = \text{const}$$

The maximum-entropy distribution (unconstrained domain) is uniform. With mean and variance constraints (add Lagrange multipliers \(\mu_1, \mu_2\)), the same method recovers the Gaussian as the maximum-entropy distribution with fixed mean and variance.

The Unifying Pattern

Across ML: (1) write the objective as \(J[f]\) or \(J[p]\); (2) compute \(\delta J/\delta f\) using the Euler–Lagrange template; (3) set to zero → ODE or algebraic condition for \(f^*\). This handles ERM, GANs (discriminator optimal policy), information-theoretic bounds, and variational inference all within one framework.

4. Variational Inference — ELBO as a Functional

In variational Bayes, we maximise the ELBO \(\mathcal{L}[q] = \mathbb{E}_q[\log p(x,z)] - \mathbb{E}_q[\log q(z)]\) over distributions \(q(z)\). Taking \(\delta \mathcal{L}/\delta q(z) = 0\) gives the mean-field fixed-point equations used in coordinate ascent VI. Functional derivatives are the engine behind "optimal \(q\)" derivations.

Code Implementation
▼
import numpy as np
from scipy.integrate import quad
# ── 1. Functional evaluation (arc length) ────────────────────────────────
def arc_length(f_prime_fn, a=0, b=1):
"""J[f] = ∫ sqrt(1 + f'²) dx (arc-length functional)."""
integrand = lambda x: np.sqrt(1 + f_prime_fn(x)**2)
val, _ = quad(integrand, a, b)
return val
# Straight line f(x)=x: f'=1 everywhere
J_opt = arc_length(lambda x: 1.0) # → 1.41421356 (= √2)
# Perturbed path: f_ε(x) = x + ε·x(1-x), f_ε' = 1 + ε(1-2x)
def J_perturbed(eps):
return arc_length(lambda x: 1.0 + eps*(1 - 2*x))
print(f"J[straight line] = {J_opt:.6f}") # 1.414214
for eps in [-0.5, -0.2, 0.0, 0.2, 0.5]:
print(f" ε={eps:+.1f}: J={J_perturbed(eps):.6f}")
# ε=±0.5 → 1.429347 (always ≥ J_opt, confirming global minimum)
# ── 2. Functional derivative via finite differences ──────────────────────
def functional_derivative_fd(J_fn, f_vals, x_grid, x0, h=1e-5):
"""δJ/δf(x0) ≈ [J[f+h·δ_{x0}] - J[f]] / h (Dirac spike perturbation)."""
idx = np.argmin(np.abs(x_grid - x0))
f_pert = f_vals.copy(); f_pert[idx] += h
return (J_fn(f_pert) - J_fn(f_vals)) / h
# ── 3. Euler-Lagrange residual check ─────────────────────────────────────
x = np.linspace(0, 1, 500)
f = x.copy() # candidate: straight line
fp = np.gradient(f, x) # f' ≈ 1 everywhere
EL = np.gradient(fp / np.sqrt(1 + fp**2), x) # d/dx[∂L/∂f']
print(f"Max |E-L residual|: {np.max(np.abs(EL)):.2e}") # ~1e-14 (zero)
# ── 4. Optimal density via functional derivative (entropy) ────────────────
def entropy(p_vals, x_grid): # H[p] = -∫ p log p dx
safe_p = np.maximum(p_vals, 1e-300)
return -np.trapezoid(safe_p * np.log(safe_p), x_grid)
x_dom = np.linspace(0, 1, 1000)
p_uniform = np.ones_like(x_dom) # uniform: H = log(1) = 0... wait
p_uniform /= np.trapezoid(p_uniform, x_dom) # normalise → p=1 on [0,1]
H_max = entropy(p_uniform, x_dom)
print(f"Entropy of uniform on [0,1]: {H_max:.6f}") # → 0.0 (log 1 = 0 ✓)

Key Takeaways & Connections
▼

Gradient vs Functional Derivative: For \(f:\mathbb{R}^n\to\mathbb{R}\), the gradient \(\nabla f\) lives in \(\mathbb{R}^n\). For \(J:C^2[a,b]\to\mathbb{R}\), the functional derivative \(\delta J/\delta f\) lives in the dual of the function space — it is itself a function, telling you how much \(J\) responds to a poke at each \(x\).

Connections to Other Topics

Lagrangian mechanics: \(L(t,q,\dot q)\) is the kinetic minus potential energy; E-L gives Newton's second law. Optimal control (Pontryagin): extends to controlled systems with state constraints. Gaussian processes: the RKHS norm is a functional whose minimum (Representer Theorem) gives the GP posterior mean. Deep learning: "neural tangent kernel" analysis uses functional derivatives of infinite-width network outputs.

When to Use Functional Derivatives

  • Deriving the Bayes-optimal predictor for any loss (set \(\delta \text{Risk}/\delta f = 0\))
  • Proving that spline interpolation solves a regularised functional minimisation
  • Deriving mean-field equations in variational Bayes / VI
  • Deriving the optimal discriminator in GANs (Jensen–Shannon divergence minimisation)
  • Physics-informed neural networks (PINNs) — residuals from E-L appear in the loss
Quick Reference — Functional Derivative Formula

For \(J[f] = \int L(x, f, f')\,dx\):   \(\dfrac{\delta J}{\delta f(x)} = \dfrac{\partial L}{\partial f} - \dfrac{d}{dx}\dfrac{\partial L}{\partial f'}\).   For \(J[f] = \int L(x,f)\,dx\) (no derivative term):   \(\dfrac{\delta J}{\delta f(x)} = \dfrac{\partial L}{\partial f}\) directly.
