Continuous Random Variables: PDF & CDF

Probability as area, the running integral, and why P(X = x) = 0

1
Understanding Continuous Random Variables
▼

What is a continuous random variable? A random variable \(X\) is continuous when it can take any value in an interval — not just whole numbers or a finite list. Think of the exact height of a randomly chosen person, the time until a radioactive atom decays, or the temperature at noon tomorrow. There are infinitely many possible outcomes.

Analogy: Imagine pouring water onto a long table. You can't say "how much water landed exactly on the 30 cm mark" — the answer is zero because the mark has no width. But you can ask "how much water landed between 28 cm and 32 cm?" That region has a definite width, so it catches a definite amount. A continuous distribution works exactly this way: the density (water per centimetre) is what the PDF captures, and probability is the area under that density curve.

💡 If You Remember One Thing

For a continuous random variable, probability = area under the PDF curve. The PDF itself is a density — it can exceed 1 — but the total area under it always equals 1. The CDF is the running total of that area from \(-\infty\) to \(x\), and \(f(x) = F'(x)\): the PDF is the derivative of the CDF.

2
PDF and CDF — Internal Mechanics
▼

The Probability Density Function (PDF)

The PDF \(f(x)\) does NOT give probabilities directly. It gives probability per unit of \(x\) — a density. To get a probability, integrate over an interval:

$$P(a < X < b) = \int_a^b f(x)\, dx$$

Two properties must hold: \(f(x) \ge 0\) for all \(x\), and the total area must be 1:

$$\int_{-\infty}^{\infty} f(x)\, dx = 1$$

Because it is a density, \(f(x)\) CAN exceed 1 — what matters is that the area (integral) equals 1. For example, a uniform distribution on \([0, 0.5]\) has \(f(x) = 2\) everywhere on that interval.

The Cumulative Distribution Function (CDF)

The CDF \(F(x)\) gives the probability that \(X\) falls at or below \(x\):

$$F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)\, dt$$

The CDF is the running integral of the PDF. It starts at 0 (as \(x \to -\infty\)) and climbs monotonically to 1 (as \(x \to +\infty\)). Every probability question becomes subtraction:

$$P(a < X \le b) = F(b) - F(a)$$

The PDF–CDF Duality

By the Fundamental Theorem of Calculus, differentiating the CDF gives back the PDF:

$$f(x) = \frac{dF}{dx} = F'(x)$$
🔑 Key Property

PDF and CDF are two views of the same object. The PDF is the "slope" of the CDF at each point. Where the CDF rises steeply, the PDF is tall (high density of outcomes). Where the CDF is flat, the PDF is near zero (outcomes are rare there).

Why P(X = x) = 0 for Any Single Point

Integration over a single point yields zero: \(\int_x^x f(t)\,dt = 0\). There is no width, so no area, so no probability. This is not a quirk — it is the defining feature of continuous distributions. You can assign probability to intervals, but never to individual points. This also means \(P(X < x) = P(X \le x) = F(x)\); the \(<\) vs \(\le\) distinction is irrelevant for continuous variables.

⚠️ Common Mistake

Students sometimes confuse \(f(x)\) (a density, can be any non-negative number) with \(P(X=x)\) (always zero for continuous RVs). Seeing \(f(0) = 0.3989\) for a standard normal does NOT mean "there's a 39.89% chance X equals 0." It means the density is 0.3989 at that point; the probability of landing in a small interval \([0, 0 + \epsilon]\) is approximately \(0.3989 \cdot \epsilon\).

The 68-95-99.7 rule follows from integrating the PDF:

$$P(-1 < X < 1) = F(1) - F(-1) = 0.8413 - 0.1587 = 0.6827$$

PDF is the Derivative of CDF

Numerically verify: using finite differences at \(x = 0\):

$$\frac{F(0.001) - F(-0.001)}{0.002} \approx \frac{0.50040 - 0.49960}{0.002} = \frac{0.00080}{0.002} = 0.3989 = f(0)\checkmark$$

Expected Value and Variance

For a continuous RV with PDF \(f\):

$$\mathbb{E}[X] = \int_{-\infty}^{\infty} x\, f(x)\, dx, \qquad \operatorname{Var}(X) = \int_{-\infty}^{\infty} (x - \mu)^2 f(x)\, dx$$

These replace the discrete sums \(\sum x_i p_i\) and \(\sum (x_i - \mu)^2 p_i\) from discrete probability.

∫ Core Identities

\(P(a < X < b) = \int_a^b f(x)\,dx = F(b) - F(a)\)
\(f(x) = F'(x)\quad\) (PDF = derivative of CDF)
\(P(X = x) = 0\quad\) for any single point
\(\int_{-\infty}^{\infty} f(x)\,dx = 1\quad\) (normalization)

Key Takeaways
▼

The core mental model:

  • PDF = density (height of the curve). Integrate it to get probability.
  • CDF = running integral of PDF from \(-\infty\) to \(x\). Always in \([0,1]\).
  • P(X = x) = 0 for any exact point — probability lives in intervals.
  • Any non-negative function integrating to 1 is a valid PDF.

Common distributions and their PDFs:

  • Normal \(\mathcal{N}(\mu, \sigma^2)\): bell curve, symmetric, used everywhere
  • Uniform \(\text{Uniform}(a,b)\): flat PDF \(f(x)=1/(b-a)\) on \([a,b]\)
  • Exponential \(\text{Exp}(\lambda)\): \(f(x)=\lambda e^{-\lambda x}\), memoryless waiting times
  • Beta \(\text{Beta}(\alpha,\beta)\): flexible on \([0,1]\), used as prior for probabilities
💡 Connecting to Discrete Distributions

In discrete distributions, the PMF gives actual probabilities \(P(X=k)\), and the CDF is a sum \(F(x)=\sum_{k\le x}P(X=k)\). The continuous analogue replaces sums with integrals and point probabilities with density. Everything else — expected value, variance, CDF — transfers directly with \(\Sigma \to \int\).

Code Trace — NumPy / SciPy
▼
import numpy as np
from scipy import stats
# Define a standard normal X ~ N(0, 1)
X = stats.norm(loc=0, scale=1) # mu=0, sigma=1
# PDF: density at a point (NOT a probability)
f0 = X.pdf(0) # 0.3989 (density, can exceed 1)
f1 = X.pdf(1) # 0.2420
# CDF: P(X <= x) = running integral of PDF
F0 = X.cdf(0) # 0.5000 (by symmetry)
F1 = X.cdf(1) # 0.8413
Fn1 = X.cdf(-1) # 0.1587
# P(a < X < b) = CDF(b) - CDF(a)
prob = X.cdf(1) - X.cdf(-1) # 0.6827 (68.27% rule)
# P(X = x) = 0 for any exact x (continuous)
from scipy.integrate import quad
point_prob, _ = quad(X.pdf, 0, 0) # 0.0 exactly
# PDF = derivative of CDF (finite difference verification)
dx = 1e-5
approx_pdf = (X.cdf(0+dx) - X.cdf(0-dx)) / (2*dx) # 0.3989
print(abs(approx_pdf - X.pdf(0)) < 1e-8) # True
# Inverse CDF (quantile function)
median = X.ppf(0.5) # 0.0 (50th percentile)
q95 = X.ppf(0.95) # 1.645
