Understanding Significance Tests
▼

What is this? After fitting a regression model \(y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \varepsilon\), you get estimated coefficients \(\hat{\beta}_j\). But are they real signals, or could they just be noise? Significance tests answer: "Is this coefficient's effect distinguishable from zero?" and "Does the entire model explain anything at all?"

Analogy: Imagine you're judging whether a new fertilizer brand actually improves crop yield. You run an experiment and get a 5% yield increase — but your measuring instrument is noisy. The t-test on each coefficient is like asking: "Is this 5% bigger than what random noise alone could produce?" The F-test is asking: "Is ANY of the treatment or soil type variation real, taken all together?"

💡 If you remember one thing

Each coefficient's t-statistic is \(t_j = \hat{\beta}_j / \text{SE}(\hat{\beta}_j)\) — the estimate divided by its uncertainty. Large \(|t_j|\) means the signal is many standard errors away from zero, making it implausible that \(\beta_j = 0\). The F-test checks if any predictor helps by comparing the full model to an intercept-only baseline.

How the Tests Work — The Mechanics
▼

The Per-Coefficient t-test

Under the Gauss-Markov assumptions with Gaussian errors \(\varepsilon \sim \mathcal{N}(0, \sigma^2 I)\), the OLS estimator satisfies \(\hat{\beta} \sim \mathcal{N}(\beta, \sigma^2 (X^\top X)^{-1})\). So the \(j\)-th coefficient:

$$\hat{\beta}_j \sim \mathcal{N}(\beta_j,\; \sigma^2 [(X^\top X)^{-1}]_{jj})$$

We don't know \(\sigma^2\), so we estimate it from the residuals: \(\hat{\sigma}^2 = \text{RSS}/(n-p)\) where \(n\) is observations, \(p = k+1\) is the number of parameters (predictors plus intercept), and RSS \(= \|y - X\hat{\beta}\|^2\). The plug-in standard error is:

$$\text{SE}(\hat{\beta}_j) = \hat{\sigma}\sqrt{[(X^\top X)^{-1}]_{jj}}$$

The null hypothesis is \(H_0: \beta_j = 0\) (predictor \(j\) has no linear effect). The test statistic:

$$t_j = \frac{\hat{\beta}_j}{\text{SE}(\hat{\beta}_j)} \;\overset{H_0}{\sim}\; t_{n-p}$$

Under \(H_0\), \(t_j\) follows a Student's t-distribution with \(n-p\) degrees of freedom. We reject \(H_0\) if \(|t_j| > t_{\alpha/2,\, n-p}\). The two-tailed p-value is \(2 \cdot P(T \geq |t_j|)\) where \(T \sim t_{n-p}\).

The Overall F-test

The F-test compares the full model (all \(k\) predictors) against the null model (intercept only, predicting \(\bar{y}\) everywhere). It partitions the total variation:

$$\underbrace{\sum(y_i - \bar{y})^2}_{\text{SST}} = \underbrace{\sum(\hat{y}_i - \bar{y})^2}_{\text{SSR (explained)}} + \underbrace{\sum(y_i - \hat{y}_i)^2}_{\text{RSS (residual)}}$$

The F-statistic is the ratio of mean explained variance to mean residual variance:

$$F = \frac{\text{SSR}/k}{\text{RSS}/(n-p)} = \frac{\text{Mean Explained Variance}}{\text{Mean Residual Variance}} \;\overset{H_0}{\sim}\; F_{k,\, n-p}$$

Under \(H_0: \beta_1 = \beta_2 = \cdots = \beta_k = 0\), the F-statistic follows an F-distribution. Large F means the model explains far more variance than noise alone — the predictors collectively matter.

🔑 Key Connection

With a single predictor \((k=1)\), the F-test and the t-test on that predictor are identical: \(F = t^2\). With multiple predictors, the F-test is a joint test — a feature could be individually insignificant (large p-value in t-test) but still contribute when tested jointly, or vice versa.

⚠️ Critical Pitfall

The t-tests test each coefficient conditional on all others in the model. Adding or removing a predictor changes all the t-stats. A predictor that seems significant alone may become insignificant in the presence of a correlated predictor (multicollinearity). Never interpret t-stats in isolation from model context.

Why It Works — The Math
▼

Deriving the t-test from First Principles

Start with \(\hat{\beta} = (X^\top X)^{-1} X^\top y\). Since \(y = X\beta + \varepsilon\) and \(\varepsilon \sim \mathcal{N}(0,\sigma^2 I)\):

$$\hat{\beta} - \beta = (X^\top X)^{-1} X^\top \varepsilon \;\sim\; \mathcal{N}\!\left(0,\; \sigma^2 (X^\top X)^{-1}\right)$$

For the \(j\)-th coefficient: \((\hat{\beta}_j - \beta_j)/\sigma\sqrt{c_{jj}} \sim \mathcal{N}(0,1)\) where \(c_{jj} = [(X^\top X)^{-1}]_{jj}\). Since \(\sigma\) is unknown, replace it with \(\hat{\sigma}\). Crucially, RSS/\(\sigma^2\) is independent of \(\hat{\beta}\) and \(\text{RSS}/\sigma^2 \sim \chi^2_{n-p}\). By definition of the t-distribution (normal divided by independent \(\sqrt{\chi^2/\text{df}}\)):

$$\frac{\hat{\beta}_j - \beta_j}{\hat{\sigma}\sqrt{c_{jj}}} = \frac{\hat{\beta}_j - \beta_j}{\text{SE}(\hat{\beta}_j)} \;\sim\; t_{n-p}$$

Under \(H_0: \beta_j = 0\), this simplifies to \(t_j = \hat{\beta}_j / \text{SE}(\hat{\beta}_j) \sim t_{n-p}\).

Deriving the F-test: Two Equivalent Formulations

Formulation 1 — Variance ratio: Under \(H_0: \beta_1 = \cdots = \beta_k = 0\) (all slopes are zero):

$$\frac{\text{SSR}/\sigma^2}{\chi^2_k} \perp \!\!\! \perp \frac{\text{RSS}/\sigma^2}{\chi^2_{n-p}} \implies F = \frac{\text{SSR}/k}{\text{RSS}/(n-p)} \sim F_{k,\, n-p}$$

Formulation 2 — Likelihood Ratio: Under Gaussian errors, \(-2\log\Lambda = n\log(\text{RSS}_\text{null}/\text{RSS}_\text{full})\). For finite \(n\), the exact pivot is the F-statistic — the LRT and F-test are equivalent under normality.

Confidence Intervals

Inverting the t-test gives the \((1-\alpha)\) confidence interval for \(\beta_j\):

$$\hat{\beta}_j \;\pm\; t_{\alpha/2,\, n-p} \cdot \text{SE}(\hat{\beta}_j)$$

A feature is significant at level \(\alpha\) if and only if the CI excludes zero.

Numerical Trace (n=20, k=2 predictors)

Using our example: \(n=20\), \(p=3\), \(\text{df}_\text{res}=17\), \(\hat{\sigma}=1.388\).

For x₁: \(\hat{\beta}_1 = 2.039\), \(\text{SE} = 0.144\), so \(t = 2.039/0.144 = 14.17\). Critical value at α=0.05: \(t_{0.025,17} = \pm 2.110\). Since \(14.17 \gg 2.110\), reject \(H_0\). p-value \(= 2 \times P(T_{17} \geq 14.17) \approx 7.6\times 10^{-11}\).

For the F-test: \(\text{SSR} = 1008.34\), \(\text{RSS} = 32.74\). \(F = (1008.34/2)/(32.74/17) = 504.17/1.926 = 261.78\). Critical value: \(F_{0.05, 2, 17} = 3.59\). Since \(261.78 \gg 3.59\), reject \(H_0\) jointly.

📐 R² and the F-test

There is an algebraic identity: \(F = \dfrac{R^2/k}{(1-R^2)/(n-p)}\). So the F-test is equivalent to testing whether R² is significantly greater than zero. In our example: \(F = (0.969/2)/((1-0.969)/17) = 261.8\). R² and F move together.

Key Takeaways & Common Traps
▼

What each test tells you

  • t-test on β̂ⱼ: Is predictor \(j\)'s effect distinguishable from zero, given the other predictors are in the model?
  • F-test: Do all the predictors together explain significantly more variance than just using the mean \(\bar{y}\)?
  • Confidence interval: A range of plausible true values for \(\beta_j\); significant ↔ CI excludes 0.

The "stars" on the regression table

Standard notation: p < 0.001 = ***, p < 0.01 = **, p < 0.05 = *, p < 0.1 = ·, p ≥ 0.1 = ns (not significant).

🚨 Do Not Confuse

Statistical significance ≠ practical significance. With \(n=100{,}000\) observations, even a coefficient of \(0.0001\) might get p < 0.001. Always look at the coefficient magnitude and confidence interval, not just the p-value. Similarly, a high R² does not mean individual predictors are significant — you can have R² = 0.99 with no individual t-stat > 2.

When F-test and t-tests conflict

  • F significant, all t's not: Classic sign of severe multicollinearity — predictors are collectively informative but individually redundant.
  • Some t's significant, F not: Rare; can happen with very few observations.
  • F not significant: Don't trust any t-test stars — you may be chasing noise (multiple testing issue).

import numpy as np
from scipy.stats import t as t_dist, f as f_dist
# Design matrix: intercept + x1 + x2
X = np.column_stack([np.ones(n), x1, x2]) # shape (n, p=3)
n, p = X.shape # n=20, p=3, k=2 predictors
# OLS solution
XtX_inv = np.linalg.inv(X.T @ X) # (p x p) matrix
beta_hat = XtX_inv @ X.T @ y # [3.472, 2.039, -1.153]
# Residual variance estimate
residuals = y - X @ beta_hat # shape (n,)
RSS = residuals @ residuals # 32.74
s2 = RSS / (n - p) # 1.926 (df_res = 17)
# Standard errors of coefficients
SE = np.sqrt(s2 * np.diag(XtX_inv)) # [1.255, 0.144, 0.210]
# Per-coefficient t-tests
t_stats = beta_hat / SE # [2.766, 14.173, -5.488]
p_vals = 2 * (1 - t_dist.cdf(np.abs(t_stats), df=n-p))
t_crit = t_dist.ppf(0.975, df=n-p) # ±2.110 for alpha=0.05
CI = np.column_stack([beta_hat - t_crit*SE, beta_hat + t_crit*SE])
# Overall F-test
y_bar = np.mean(y)
SST = np.sum((y - y_bar)**2) # 1041.08
SSR = SST - RSS # 1008.34 (explained)
k = p - 1 # number of slope predictors
F_stat = (SSR / k) / (RSS / (n - p)) # 261.78
p_F = 1 - f_dist.cdf(F_stat, dfn=k, dfd=n-p) # ~0 (essentially zero)
R2 = SSR / SST # 0.969
adj_R2 = 1 - (RSS/(n-p)) / (SST/(n-1)) # 0.965
