Sigmoid Function & Linear Decision Boundary

How logistic regression maps any real number to a probability and draws a line between classes
Foundational Classical ML Classification Must Know
1
Understanding the Concept
▼

The sigmoid function is the mathematical engine inside logistic regression. It takes any real number \(z\) — which could range from \(-\infty\) to \(+\infty\) — and squashes it into the open interval \((0, 1)\). That output can then be interpreted as a probability.

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

In logistic regression, \(z\) is not arbitrary — it is a linear combination of features: \(z = \mathbf{w}^\top \mathbf{x} + b\), where \(\mathbf{w}\) are the learned weights, \(\mathbf{x}\) is the input feature vector, and \(b\) is the bias. So the predicted class probability is:

$$\hat{p} = \sigma(\mathbf{w}^\top \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^\top \mathbf{x} + b)}}$$
Key Insight

The decision boundary is exactly where \(z = 0\), i.e., where \(\hat{p} = 0.5\). In 2D with features \(x_1, x_2\), that means the equation \(w_1 x_1 + w_2 x_2 + b = 0\) — a straight line. Points farther from this line get probabilities closer to 0 or 1.

Analogy: Think of the sigmoid as a volume dial on a radio. The raw signal \(z\) can be any loudness, but the dial only shows values between 0% and 100%. The decision boundary is the exact midpoint at 50% — the threshold where you flip from class 0 to class 1.

The One Property to Remember

\(\sigma(z) \geq 0.5\) if and only if \(z \geq 0\). The decision boundary in feature space is always a hyperplane (line in 2D, plane in 3D). Logistic regression is a linear classifier.

2
How It Works — Internal Mechanism
▼

Step 1: Compute the Linear Score \(z\)

For a 2D example with features \(x_1, x_2\), weights \(w_1 = 1.5, w_2 = -1.0\), and bias \(b = -0.5\):

$$z = w_1 x_1 + w_2 x_2 + b = 1.5 x_1 + (-1.0) x_2 + (-0.5)$$

This is a dot product: each feature is scaled by its weight and summed. \(z\) can be any real number — positive means the point leans toward class 1, negative toward class 0.

Step 2: Apply the Sigmoid to Get \(\hat{p}\)

The sigmoid "squashes" \(z\) into \((0,1)\). The exponential \(e^{-z}\) grows very large when \(z \ll 0\) (making \(\sigma \approx 0\)) and shrinks to 0 when \(z \gg 0\) (making \(\sigma \approx 1\)):

$$\hat{p} = \sigma(z) = \frac{1}{1+e^{-z}}$$

Numerical Trace with Real Points

Using \(w_1=1.5,\; w_2=-1.0,\; b=-0.5\):

Point A = (2, 1): z = 1.5(2) + (-1.0)(1) + (-0.5) = 1.5 → σ = 0.8176 → class 1
Point B = (1, 2): z = 1.5(1) + (-1.0)(2) + (-0.5) = -1.0 → σ = 0.2689 → class 0
Point C = (1, 0): z = 1.5(1) + (-1.0)(0) + (-0.5) = 1.0 → σ = 0.7311 → class 1
Point D = (0, 2): z = 1.5(0) + (-1.0)(2) + (-0.5) = -2.5 → σ = 0.0759 → class 0
Boundary: z=0 → 1.5x₁ - x₂ - 0.5 = 0 → x₂ = 1.5x₁ - 0.5

Step 3: Decision Rule

$$\hat{y} = \begin{cases} 1 & \text{if } \hat{p} \geq 0.5 \iff z \geq 0 \\ 0 & \text{if } \hat{p} < 0.5 \iff z < 0 \end{cases}$$
Common Misconception

The sigmoid output is a model probability, not a calibrated real-world probability. A raw logistic regression can be overconfident or underconfident. Platt scaling or isotonic regression can calibrate these outputs for better probability estimates.

3
The Mathematics — Derivation & Loss
▼

Why Sigmoid? The Probabilistic Argument

Assume the log-odds ratio (logit) is linear in the features:

$$\log\frac{p}{1-p} = \mathbf{w}^\top \mathbf{x} + b = z$$

Solving for \(p\) directly yields the sigmoid:

$$p = \frac{e^z}{1+e^z} = \frac{1}{1+e^{-z}} = \sigma(z)$$

This is not an arbitrary choice — it is the canonical link function for Bernoulli-distributed outputs in the Generalized Linear Model (GLM) framework.

Binary Cross-Entropy Loss

Given \(n\) training examples \(\{(\mathbf{x}_i, y_i)\}\) with \(y_i \in \{0,1\}\), the negative log-likelihood is:

$$\mathcal{L}(\mathbf{w}, b) = -\frac{1}{n}\sum_{i=1}^{n}\bigl[y_i \log \hat{p}_i + (1-y_i)\log(1-\hat{p}_i)\bigr]$$

This is convex in \(\mathbf{w}\) and \(b\), so gradient descent finds the global minimum (no local optima).

Gradient of the Loss — Elegant Cancellation

First, note the sigmoid derivative: \(\sigma'(z) = \sigma(z)(1-\sigma(z))\). Applying the chain rule:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{w}} = \frac{1}{n}\sum_{i=1}^{n}(\hat{p}_i - y_i)\,\mathbf{x}_i, \qquad \frac{\partial \mathcal{L}}{\partial b} = \frac{1}{n}\sum_{i=1}^{n}(\hat{p}_i - y_i)$$

The gradient is simply the average prediction error \((\hat{p}_i - y_i)\) weighted by the features — a remarkably clean form. The sigmoid derivative \(\sigma'(z)\) cancels with a term in the loss, leaving this simple expression.

Decision Boundary Geometry

The boundary is the set of points where \(\hat{p} = 0.5\), i.e., \(z = 0\):

$$\{\mathbf{x} : \mathbf{w}^\top \mathbf{x} + b = 0\}$$

In \(\mathbb{R}^2\) this is a line; in \(\mathbb{R}^d\) it is a \((d-1)\)-dimensional hyperplane. The vector \(\mathbf{w}\) is perpendicular to this hyperplane, and \(|b|/\|\mathbf{w}\|\) is the signed distance from the origin to the boundary.

Key Formulas

Sigmoid: \(\sigma(z) = 1/(1+e^{-z})\), range \((0,1)\)

Derivative: \(\sigma'(z) = \sigma(z)(1-\sigma(z))\), max \(= 0.25\) at \(z=0\)

Boundary: \(\mathbf{w}^\top\mathbf{x}+b=0\); distance from origin \(= |b|/\|\mathbf{w}\|_2\)

Key Takeaways & When to Use
▼
  • Sigmoid squashes: Any real \(z\) maps to \((0,1)\) — interpretable as a probability.
  • Linear decision boundary: Logistic regression can only separate classes that are linearly separable in feature space. The boundary is always a hyperplane.
  • Distance encodes confidence: Points far from the boundary get probabilities near 0 or 1. Points near the boundary are uncertain (\(\hat{p} \approx 0.5\)).
  • Convex loss: Binary cross-entropy is convex → gradient descent finds the global optimum, no random restarts needed.
  • Gradient elegance: \(\partial\mathcal{L}/\partial\mathbf{w} = \frac{1}{n}\sum(\hat{p}_i - y_i)\mathbf{x}_i\) — the update is just the average error times the feature.
When to Use Logistic Regression
  • Binary classification with interpretability needs
  • Baseline model before trying nonlinear methods
  • When features are already well-engineered or data is linearly separable
  • When calibrated probabilities matter (e.g., medical risk scores)
Limitations
  • Cannot learn XOR or any non-linearly-separable pattern without feature engineering
  • Sensitive to outliers (outliers shift the boundary significantly)
  • Assumes a linear log-odds relationship between features and outcome

Related topics: Softmax (multiclass extension), SVM (different boundary criterion), Neural networks (stacked sigmoids = nonlinear boundaries), Regularization (L1/L2 for logistic regression).
