Understanding Overdispersion
▼

What is it? When you want to predict counts — number of hospital visits, daily website clicks, insurance claims, crimes per neighborhood — you naturally reach for Poisson regression. Poisson regression has one strict assumption: the variance equals the mean. Real count data almost always violates this. The variance is often much larger than the mean — a phenomenon called overdispersion. Negative Binomial (NB) regression fixes this by adding one extra parameter \(\alpha\) (the dispersion parameter) that lets variance grow faster than the mean.

Analogy: Imagine counting how many customers enter a coffee shop each hour. On average it's 10/hour. Poisson says: the spread (standard deviation) should be \(\sqrt{10} \approx 3.16\). But if some hours see 0 customers and other hours see 50 (because of rain, events nearby, etc.) the actual spread is far higher. The Poisson model is confidently wrong. NB regression says: "I'll allow an extra source of randomness — the true arrival rate itself fluctuates hour to hour" — and it models that extra variance explicitly.

💡 If you remember one thing

Negative binomial regression adds a dispersion parameter \(\alpha\) so that \(\operatorname{Var}(Y) = \mu + \alpha\mu^2\). When \(\alpha = 0\) it reduces exactly to Poisson. The bigger \(\alpha\), the fatter the tails and the higher the probability of extreme counts.

Why Overdispersion Matters

If you fit a Poisson model to overdispersed data, the estimated standard errors are too small — you'll report false precision. p-values will be artificially tiny, and confidence intervals will be too narrow. You may conclude a covariate is significant when it is not. NB regression correctly inflates the standard errors to account for the extra variance.

⚠️ A Common Mistake

Always test for overdispersion before choosing Poisson vs NB. A simple check: if the sample variance is much larger than the sample mean for your response variable, overdispersion is present. A formal test (Cameron & Trivedi's dispersion test, or the likelihood-ratio test comparing Poisson to NB) confirms it.

The Gamma-Poisson Mixture
▼

The Core Idea: Two Levels of Randomness

Negative binomial regression is best understood as a Gamma-Poisson mixture. Instead of a single fixed rate \(\mu\), we imagine each observation's rate \(\lambda_i\) is itself drawn from a Gamma distribution centered on \(\mu\). Then the count \(Y_i\) is drawn from Poisson(\(\lambda_i\)). Marginalizing out \(\lambda_i\) gives the Negative Binomial distribution.

Formally: if \(\lambda \sim \text{Gamma}(r, r/\mu)\) (shape \(r = 1/\alpha\), rate \(r/\mu\)), then:

$$Y \mid \lambda \sim \text{Poisson}(\lambda) \quad \Longrightarrow \quad Y \sim \text{NegBin}(\mu, \alpha)$$

The Gamma distribution injects subject-level heterogeneity — some individuals have inherently higher rates, others lower, and we are accounting for this latent variation. This is why NB handles overdispersion naturally.

The Variance-Mean Relationship

After integrating out the Gamma mixing distribution, the marginal variance is:

$$\operatorname{Var}(Y) = \mu + \alpha \mu^2$$
  • \(\alpha = 0\): reduces to Poisson — \(\text{Var} = \mu\)
  • \(\alpha > 0\): extra quadratic term — variance grows faster than mean
  • Large \(\alpha\): heavy tails — many zeros and extreme counts

From PMF to Regression

In negative binomial regression, the mean \(\mu_i\) depends on covariates \(x_i\) through a log link:

$$\log(\mu_i) = x_i^\top \beta \quad \Longleftrightarrow \quad \mu_i = \exp(x_i^\top \beta)$$

The dispersion parameter \(\alpha\) is estimated jointly with \(\beta\) by maximum likelihood. The log link ensures \(\mu_i > 0\) for all \(x_i\), which is required for count data.

🔑 Key Property — NB Parameterizations

There are two NB parameterizations. NB1: \(\text{Var} = \mu(1 + \alpha)\) — linear in \(\mu\). NB2 (most common): \(\text{Var} = \mu + \alpha\mu^2\) — quadratic in \(\mu\). statsmodels and R's MASS use NB2 by default. The shape parameter is \(r = 1/\alpha\); smaller \(r\) means more dispersion.

The Mathematics — PMF, MLE & Dispersion
▼

The Negative Binomial PMF

Using the mean-dispersion parameterization (NB2), with \(\mu > 0\) and \(r = 1/\alpha > 0\):

$$P(Y = k \mid \mu, r) = \binom{k + r - 1}{k} \left(\frac{r}{r+\mu}\right)^r \left(\frac{\mu}{r+\mu}\right)^k, \quad k = 0, 1, 2, \ldots$$

where \(p = r/(r+\mu)\) is the success probability. As \(r \to \infty\) (i.e., \(\alpha \to 0\)), this PMF converges to the Poisson(\(\mu\)) PMF — a key identity to know for interviews.

Log-Likelihood and MLE

The log-likelihood for a sample \((y_i, x_i)_{i=1}^n\) with \(\mu_i = \exp(x_i^\top \beta)\) and shared dispersion \(\alpha\) is:

$$\ell(\beta, \alpha) = \sum_{i=1}^n \left[ \log \Gamma(y_i + r) - \log \Gamma(r) - \log(y_i!) + r \log\!\left(\frac{r}{r+\mu_i}\right) + y_i \log\!\left(\frac{\mu_i}{r+\mu_i}\right) \right]$$

where \(r = 1/\alpha\). This is maximized numerically (Newton-Raphson or BFGS) because no closed-form solution exists for \(\hat{\alpha}\). The score equations for \(\beta\) resemble weighted Poisson GLM equations with weights depending on \(\alpha\).

Score for \(\beta\) and Sandwich Variance

The gradient of \(\ell\) with respect to \(\beta\) is:

$$\frac{\partial \ell}{\partial \beta} = \sum_{i=1}^n \frac{y_i - \mu_i}{1 + \alpha \mu_i}\, x_i = 0$$

Notice the denominator \(1 + \alpha\mu_i\): when \(\alpha = 0\) this is exactly the Poisson score. As \(\alpha\) increases, observations with large \(\mu_i\) get downweighted — intuitively, highly variable observations carry less information per unit.

📐 Key Formula — Variance Function

\(\operatorname{Var}(Y \mid x) = \mu + \alpha \mu^2 = \mu(1 + \alpha\mu)\)

The variance function in the GLM sense is \(V(\mu) = \mu + \alpha\mu^2\). The dispersion parameter \(\alpha\) is estimated as a free parameter, unlike in Poisson where it is fixed at 0. Test \(H_0: \alpha = 0\) with a likelihood-ratio test to detect overdispersion.

Dispersion Test (Cameron & Trivedi, 1990)

Fit a Poisson model. Regress \((y_i - \hat{\mu}_i)^2 - y_i\) on \(\hat{\mu}_i^2\) (without intercept). If the coefficient is significantly positive, NB2 is preferred. Equivalently, the LRT statistic \(-2(\ell_{\text{Poi}} - \ell_{\text{NB}})\) follows a 50:50 mix of \(\chi^2_0\) and \(\chi^2_1\) under \(H_0: \alpha = 0\).

🚫 Underdispersion

NB handles overdispersion (\(\text{Var} > \mu\)) but NOT underdispersion (\(\text{Var} < \mu\)). For underdispersion, consider Conway-Maxwell-Poisson or a double-Poisson model. Zero-inflation (excess zeros) requires Zero-Inflated Poisson or ZINB — a different problem from simple overdispersion.

From Scratch — NB Log-Likelihood in NumPy

import numpy as np
from scipy.special import gammaln
from scipy.optimize import minimize
def nb_log_pmf(y, mu, alpha):
"""NB2 log-PMF: Var(Y) = mu + alpha*mu^2, r = 1/alpha."""
r = 1.0 / alpha
# log C(y+r-1, y) = log Gamma(y+r) - log Gamma(r) - log Gamma(y+1)
log_binom = gammaln(y + r) - gammaln(r) - gammaln(y + 1)
log_p_part = r * np.log(r / (r + mu))
log_q_part = y * np.log(mu / (r + mu))
return log_binom + log_p_part + log_q_part
def neg_log_likelihood(params, X, y):
"""NB2 regression negative log-likelihood."""
beta = params[:-1]
log_alpha = params[-1] # optimize in log-space → alpha > 0
alpha = np.exp(log_alpha)
mu = np.exp(X @ beta) # log link
return -np.sum(nb_log_pmf(y, mu, alpha))
def fit_nb2(X, y):
"""Fit NB2 regression by MLE via L-BFGS-B."""
n_features = X.shape[1]
init = np.zeros(n_features + 1) # beta=0, log_alpha=0 (alpha=1)
result = minimize(neg_log_likelihood, init, args=(X, y),
method='L-BFGS-B', options={'maxiter': 500})
beta_hat = result.x[:-1]
alpha_hat = np.exp(result.x[-1])
return beta_hat, alpha_hat

Production — statsmodels

import statsmodels.api as sm
import statsmodels.formula.api as smf
# Formula API (preferred — handles intercept automatically)
model = smf.negativebinomial('visits ~ age + income + chronic', data=df)
result = model.fit(method='newton', disp=False)
print(result.summary())
# Key output fields
print('alpha (dispersion):', result.params['alpha']) # NB2 alpha
print('IRR:', np.exp(result.params)) # Incidence Rate Ratios
# Test overdispersion: LRT Poisson vs NB
poi = smf.poisson('visits ~ age + income + chronic', data=df).fit(disp=False)
LRT = -2 * (poi.llf - result.llf) # chi-sq with 1 dof
from scipy.stats import chi2
p_val = 0.5 * chi2.sf(LRT, 1) # mixture distribution under H0
print(f'LRT={LRT:.2f}, p={p_val:.4f}') # p<0.05 → prefer NB
⚠️ Gotchas

1. statsmodels' alpha is \(1/r\), matching NB2 convention above. R's MASS::glm.nb reports theta = r = 1/alpha — the inverse.

2. Always check convergence with result.mle_retvals — NB optimization is sometimes sensitive to starting values on highly overdispersed data.

3. Coefficient interpretation: \(e^{\beta_j}\) is the Incidence Rate Ratio (IRR) — a unit increase in \(x_j\) multiplies the expected count by \(e^{\beta_j}\).

When to Use Negative Binomial Regression

  • Response variable is a non-negative integer (count data)
  • Sample variance noticeably exceeds sample mean
  • LRT or dispersion test rejects Poisson in favor of NB
  • Domain has natural heterogeneity (different baseline rates per subject)

When NOT to Use

  • Data has underdispersion (Var < μ) — NB cannot model this
  • Counts are bounded (e.g., out of N trials) — use Binomial/Beta-Binomial
  • Extremely heavy zero inflation — use ZINB (Zero-Inflated NB) instead
  • Continuous non-negative response — use log-normal or Gamma GLM
🎯 Decision Rule

Start with Poisson → compute Cameron & Trivedi dispersion test → if p < 0.05, fit NB → check for excess zeros → if present, consider ZINB. The parameter \(\hat{\alpha}\) tells you the magnitude of overdispersion: \(\hat{\alpha} < 0.1\) is mild, \(\hat{\alpha} > 1\) is severe.
