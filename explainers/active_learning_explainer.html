Active Learning

Querying the Most Informative Unlabeled Points

1 — Understanding Active Learning

Standard supervised learning requires all labels upfront — you collect a dataset, label every point, then train. This is expensive when labeling requires expert time (medical imaging, legal documents, rare-event annotation).

Active learning flips the process: start with a small labeled pool and a large unlabeled pool, then choose which points to ask the oracle to label next. The learner is active rather than passive — it drives its own data collection.

PASSIVE LEARNING
Label everything → train once → deploy. Wastes budget on obvious examples.
ACTIVE LEARNING
Label a few → train → query most informative → repeat. Focus budget on hard cases.

Real-world analogy: A student who asks the teacher only the questions they are most confused about learns faster than one who re-reads what they already know. The oracle (human annotator) is the teacher; the model is the student.

The active learning loop repeats until a labeling budget \(B\) is exhausted:

  1. Train model \(M\) on current labeled set \(\mathcal{L}\)
  2. Use query strategy to score all unlabeled points in \(\mathcal{U}\)
  3. Select the highest-scoring point(s) \(x^*\)
  4. Ask oracle for label \(y^*\), move \((x^*, y^*)\) from \(\mathcal{U}\) to \(\mathcal{L}\)
  5. Repeat from step 1
Key Insight
With the right query strategy, 100 labeled examples can outperform 1000 random labels. The selection of which points to label matters more than the total count.
2 — Four Query Strategies
Strategy 1
Uncertainty Sampling
Query the point the model is least confident about. Three variants:
  • Least Confidence: \(x^* = \arg\max (1 - P(\hat{y}\mid x))\)
  • Margin: \(x^* = \arg\min (P(\hat{y}_1\mid x) - P(\hat{y}_2\mid x))\)
  • Entropy: \(x^* = \arg\max H(x)\)
Strategy 2
Query-by-Committee (QbC)
Train a committee of \(C\) diverse models; query where they disagree most. Vote entropy:
  • \(x^* = \arg\max \left(-\sum_k \tfrac{V(y_k)}{C}\log\tfrac{V(y_k)}{C}\right)\)
  • More robust than single-model uncertainty
Strategy 3
Expected Model Change
Query the point that would cause the largest model update (largest expected gradient length) if labeled:
  • \(x^* = \arg\max \mathbb{E}_{y}\left[\|\nabla_\theta \mathcal{L}\|\right]\)
  • Principled but requires \(O(n)\) gradient computations
Strategy 4
Batch-Mode Active Learning
Select \(B\) points simultaneously that are both informative AND diverse to avoid redundant queries:
  • Greedy submodular maximization
  • Avoids clustered, redundant queries near boundary
When to Use Each Strategy
Use Uncertainty Sampling for speed. Use QbC for robustness. Use EMC when you want principled gradient-based selection. Use Batch Mode when you must label multiple points per round (parallelism, human teams).
3 — The Math

Entropy (Uncertainty Sampling)

Shannon entropy measures the uncertainty in a probability distribution over \(K\) classes. Higher entropy = more confused = better query candidate.

$$H(x) = -\sum_{k=1}^{K} P(y_k \mid x)\, \log_2 P(y_k \mid x)$$

Margin Sampling

The margin between the top-2 class probabilities. A small margin means the model is torn between two classes — a more targeted signal than entropy.

$$x^* = \arg\min_x \left[ P(\hat{y}_1 \mid x) - P(\hat{y}_2 \mid x) \right]$$

QbC Vote Entropy

With \(C\) committee members, let \(V(y_k)\) = number of members predicting class \(k\). High vote entropy means committee members disagree.

$$x^* = \arg\max_x \left( -\sum_k \frac{V(y_k)}{C} \log \frac{V(y_k)}{C} \right)$$

Expected Model Change (Binary Case)

For logistic regression, the expected gradient length is proportional to the model's uncertainty \(p(1-p)\), which is maximized at the decision boundary.

$$\text{EMC}(x) \propto \mathbb{E}_{y}\left[\|\nabla_\theta \ell(x, y)\|\right] \approx \sigma(x)\,(1 - \sigma(x))\,\|x\|$$
Geometric Intuition
All uncertainty-based strategies tend to select points near the decision boundary, where the model is most confused. The key difference is how they measure "confusion" — single model vs. committee, probability vs. gradient.

5 — Key Takeaways
  • ★Active learning shines when labeling is expensive. Medical imaging, legal annotation, expensive experiments — when each label costs money or time.
  • 1Uncertainty Sampling: Fast, simple, easy to implement. Ignores data density — may over-query outliers.
  • 2Query-by-Committee: More robust, ensemble-based. Requires training and maintaining multiple models.
  • 3Expected Model Change: Principled, gradient-based. Expensive — requires \(O(n)\) forward/backward passes per cycle.
  • 4Batch Mode: Avoids redundancy by selecting diverse subsets. Essential for parallel annotation pipelines.
  • →Related paradigms: Semi-supervised learning, self-training, label propagation, and data programming (Snorkel) all reduce labeling cost via different mechanisms.
The Exploration–Exploitation Tradeoff
Pure uncertainty sampling is exploitation: always query near the current boundary. Adding a density term or diversity constraint introduces exploration, querying informative regions even if not near the current boundary. The best strategies balance both.
