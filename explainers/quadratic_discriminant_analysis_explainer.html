Quadratic Discriminant Analysis (QDA)

Each class gets its own covariance — a curved decision boundary emerges
Intermediate Classical ML Classification O(Kp²) params
1
Understanding QDA
▼

What is it? Quadratic Discriminant Analysis (QDA) is a classification algorithm that models each class as a Gaussian cloud. Unlike its simpler cousin LDA, QDA allows each class to have its own shape and orientation — its own covariance matrix \(\Sigma_k\). Because the covariance matrices differ, the decision boundary between classes becomes a quadratic curve (an ellipse, parabola, or hyperbola), not a straight line.

Analogy: Imagine two piles of confetti on a table. LDA assumes both piles are the same shape (maybe both round), and just draws a straight line between them. QDA notices that one pile is round and spread wide, while the other is elongated and tilted — and draws a curved boundary that fits these different shapes. More flexibility, more accurate boundaries — but more data needed to pin down each pile's shape.

💡 If you remember one thing

QDA gives every class \(k\) its own covariance matrix \(\Sigma_k\). The log-posterior score is $$\delta_k(x) = -\tfrac{1}{2}\log|\Sigma_k| - \tfrac{1}{2}(x-\mu_k)^\top \Sigma_k^{-1}(x-\mu_k) + \log\pi_k$$ Because \(\Sigma_k\) differs across classes, the boundary \(\delta_k(x) = \delta_j(x)\) is quadratic in \(x\).

2
How QDA Works Internally
▼

The Generative Model

QDA is a generative classifier. It models the class-conditional densities as multivariate Gaussians:

$$p(x \mid y=k) = \frac{1}{(2\pi)^{p/2}|\Sigma_k|^{1/2}} \exp\!\left(-\tfrac{1}{2}(x-\mu_k)^\top \Sigma_k^{-1}(x-\mu_k)\right)$$

where \(\mu_k\) is the class mean, \(\Sigma_k\) is the class-specific covariance, and \(p\) is the number of features. Via Bayes' theorem, the posterior is \(p(y=k \mid x) \propto p(x \mid y=k)\,\pi_k\).

Training: Estimate Parameters Per Class

Given \(n_k\) training points in class \(k\) (out of \(n\) total):

$$\hat{\pi}_k = \frac{n_k}{n}, \quad \hat{\mu}_k = \frac{1}{n_k}\sum_{i: y_i=k} x_i, \quad \hat{\Sigma}_k = \frac{1}{n_k - 1}\sum_{i: y_i=k}(x_i - \hat{\mu}_k)(x_i - \hat{\mu}_k)^\top$$

Each class gets its own covariance estimate. For \(K\) classes and \(p\) features, this requires \(K \cdot p(p+1)/2\) covariance parameters — much more than LDA's single pooled \(\Sigma\).

Prediction: Compute the Discriminant Score

Taking the log-posterior (dropping constants shared across classes), the quadratic discriminant function is:

$$\delta_k(x) = -\tfrac{1}{2}\log|\hat{\Sigma}_k| - \tfrac{1}{2}(x-\hat{\mu}_k)^\top \hat{\Sigma}_k^{-1}(x-\hat{\mu}_k) + \log\hat{\pi}_k$$

Assign \(\hat{y} = \arg\max_k \delta_k(x)\). The first term penalizes high-volume (spread-out) classes; the second is the Mahalanobis distance squared from \(x\) to class \(k\); the third adjusts for class imbalance.

Why the Boundary is Quadratic

For two classes \(j, k\), the boundary satisfies \(\delta_k(x) = \delta_j(x)\). This expands to:

$$x^\top(\hat{\Sigma}_j^{-1} - \hat{\Sigma}_k^{-1})x + 2(\hat{\mu}_k^\top\hat{\Sigma}_k^{-1} - \hat{\mu}_j^\top\hat{\Sigma}_j^{-1})x + c = 0$$

The leading \(x^\top A\, x\) term (a quadratic form) exists precisely because \(\hat{\Sigma}_j^{-1} \neq \hat{\Sigma}_k^{-1}\). In LDA, \(\Sigma_j = \Sigma_k = \Sigma\) so this term cancels — leaving a linear (hyperplane) boundary.

🔑 Key Insight

The quadratic boundary is not a design choice — it is the inevitable consequence of allowing per-class covariances. If you force \(\Sigma_k = \Sigma\) (LDA), the quadratic term vanishes and you get a line. QDA is strictly more general.

Why It Works — The Math
▼

Numerical Trace: Two Classes in 2D

Using our worked example with equal class priors \(\pi_0 = \pi_1 = 0.5\):

  • Class 0: \(\hat{\mu}_0 = [-1, 0]^\top\), \(\hat{\Sigma}_0 = \begin{bmatrix}0.8 & 0.3\\0.3 & 0.8\end{bmatrix}\), \(\det(\hat{\Sigma}_0) = 0.55\)
  • Class 1: \(\hat{\mu}_1 = [2, 1]^\top\), \(\hat{\Sigma}_1 = \begin{bmatrix}1.5 & -0.7\\-0.7 & 0.5\end{bmatrix}\), \(\det(\hat{\Sigma}_1) = 0.26\)

Classifying \(x = [0.5, 0.5]^\top\):

$$\delta_0(x) = -\tfrac{1}{2}\ln(0.55) - \tfrac{1}{2}(x - \mu_0)^\top \hat{\Sigma}_0^{-1}(x - \mu_0) + \ln(0.5) = -1.803$$
$$\delta_1(x) = -\tfrac{1}{2}\ln(0.26) - \tfrac{1}{2}(x - \mu_1)^\top \hat{\Sigma}_1^{-1}(x - \mu_1) + \ln(0.5) = -4.924$$

Since \(\delta_0 > \delta_1\), predict class 0. Class 0 is closer in the Mahalanobis sense, and though its covariance is smaller in volume penalty, the point sits much closer to \(\mu_0\).

Bias–Variance Trade-off vs LDA

LDA estimates \(\frac{p(p+1)}{2}\) pooled covariance parameters. QDA estimates \(K \cdot \frac{p(p+1)}{2}\). For \(p=2, K=2\): LDA has 3 parameters, QDA has 6. For \(p=100\): LDA has 5,050, QDA has 10,100. This makes QDA high-variance in small samples:

⚠️ Rule of Thumb

You need at least \(n_k > p\) samples per class for QDA's covariance estimate to be non-singular. In practice, aim for \(n_k \gg p\) (e.g., \(5p\) to \(10p\)). With small samples, regularized DA (RDA) interpolates between LDA and QDA.

Connection to Mahalanobis Distance

The Mahalanobis distance from \(x\) to class \(k\) is \(D_k^2(x) = (x - \mu_k)^\top \Sigma_k^{-1}(x - \mu_k)\). QDA classifies by choosing the class with smallest \(D_k^2(x)\), adjusted for class volume \(|\Sigma_k|\) and prior \(\pi_k\). This generalizes Euclidean nearest-centroid: when \(\Sigma_k = I\), Mahalanobis reduces to Euclidean.

🎯 Decision Guide

Use LDA when classes have similar covariance or sample size is small relative to features. Use QDA when you have enough data per class (\(n_k \gg p\)) and classes clearly have different shapes. Use RDA when unsure — tune \(\alpha\) by cross-validation to interpolate.

6
Key Takeaways
▼

Summary: QDA is a probabilistic classifier that models each class as a Gaussian with its own covariance matrix. This produces a quadratic (curved) decision boundary that can capture classes with different shapes and orientations — something LDA's straight line cannot do.

When to use QDA:

  • Classes have visually different scatter shapes or orientations
  • You have enough per-class samples: \(n_k > 5p\) is a reasonable minimum
  • The Gaussian class-conditional assumption is plausible (check Q-Q plots per class)
  • Features are continuous and correlated within classes

When NOT to use QDA:

  • High-dimensional features (\(p\) is large): too many covariance parameters — use LDA or shrinkage
  • Small sample sizes: covariance estimates are unreliable — use LDA or RDA
  • Data is clearly non-Gaussian: use SVM, kernel methods, or tree-based classifiers
  • You need exact probability calibration: QDA posteriors can be miscalibrated without Platt scaling
