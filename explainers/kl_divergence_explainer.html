Understanding KL Divergence
▼

What is it? KL divergence measures how different one probability distribution is from another — specifically, how many extra bits (or nats) you waste if you use an approximate distribution \(q\) when the true distribution is \(p\). It is the "extra coding cost of the wrong model."

Analogy: Imagine designing an optimal Morse-code alphabet for English letter frequencies \(p\). If you optimise for English, you spend exactly \(H(p)\) bits per letter on average. If you use an alphabet optimised for French (\(q\)), you waste an extra \(D_{\mathrm{KL}}(p\|q)\) bits per letter. The total cost — cross-entropy \(H(p,q)\) — equals \(H(p) + D_{\mathrm{KL}}(p\|q)\). Crucially, the waste is asymmetric: using an English code for French is a different mismatch from using a French code for English.

Crucial twist: KL divergence is not symmetric. \(D_{\mathrm{KL}}(p\|q)\) asks "how does \(q\) fail relative to \(p\)?" and \(D_{\mathrm{KL}}(q\|p)\) asks the reverse. These answer different questions and lead to fundamentally different optimisation behaviours in ML.

If you remember one thing

\(D_{\mathrm{KL}}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)} \geq 0\), with equality iff \(p=q\). It is not symmetric: forward KL \((p\|q)\) is mean-seeking — \(q\) must spread to cover all of \(p\). Reverse KL \((q\|p)\) is mode-seeking — \(q\) collapses to one mode of \(p\). Cross-entropy = entropy + forward KL: \(H(p,q) = H(p) + D_{\mathrm{KL}}(p\|q)\).

How KL Divergence Works Internally
▼

The Formula

For discrete distributions \(p\) and \(q\) over alphabet \(\mathcal{X}\):

$$D_{\mathrm{KL}}(p \| q) = \sum_{x \in \mathcal{X}} p(x) \log \frac{p(x)}{q(x)}$$

For continuous densities: \(D_{\mathrm{KL}}(p \| q) = \int p(x)\log\frac{p(x)}{q(x)}\,dx\). Convention: \(0 \log 0 = 0\) and \(p(x)\log\frac{p(x)}{0} = +\infty\) — if \(q\) assigns zero probability to an event that \(p\) gives positive probability, the divergence is infinite. This is the support constraint.

Each Term's Role

Each term \(p(x)\log\frac{p(x)}{q(x)}\) answers: "under the true distribution \(p\), how surprised am I if I coded using \(q\) instead of the optimal \(p\) code?" The term is positive when \(q(x) < p(x)\) (model underestimates this event), negative when \(q(x) > p(x)\) (model over-allocates bits here). The weighted average with weights \(p(x)\) is always non-negative.

The Cross-Entropy Identity

$$H(p,q) = -\sum_x p(x)\log q(x) = \underbrace{-\sum_x p(x)\log p(x)}_{H(p)} + \underbrace{\sum_x p(x)\log\frac{p(x)}{q(x)}}_{D_{\mathrm{KL}}(p\|q)}$$

This decomposition reveals why minimising cross-entropy in neural network training is equivalent to minimising forward KL: \(H(p)\) is constant w.r.t. model parameters \(\theta\), so \(\arg\min_\theta H(p,q_\theta) = \arg\min_\theta D_{\mathrm{KL}}(p\|q_\theta)\).

Key Property: Non-negativity (Gibbs' Inequality)

By Jensen's inequality applied to the strictly convex \(-\log\): \(D_{\mathrm{KL}}(p\|q) \geq 0\), with equality iff \(p = q\) almost everywhere. This is the information-theoretic bedrock: you can never do better than coding with the true distribution.

3
The Math — Proof of Non-negativity & Asymmetry
▼

Proof of Non-negativity via Jensen's Inequality

Since \(-\log\) is strictly convex, Jensen's inequality gives \(\mathbb{E}[-\log X] \geq -\log(\mathbb{E}[X])\). Apply to \(X = q(x)/p(x)\):

$$D_{\mathrm{KL}}(p\|q) = -\sum_x p(x)\log\frac{q(x)}{p(x)} \;\geq\; -\log\!\left(\sum_x p(x)\cdot\frac{q(x)}{p(x)}\right) = -\log\!\underbrace{\sum_x q(x)}_{=1} = 0$$

Equality holds iff \(q(x)/p(x)\) is constant \(p\)-almost everywhere, which forces \(p = q\).

Why the Two Directions Behave Differently

$$D_{\mathrm{KL}}(p\|q) = \mathbb{E}_{x\sim p}\!\left[\log\frac{p(x)}{q(x)}\right] \qquad D_{\mathrm{KL}}(q\|p) = \mathbb{E}_{x\sim q}\!\left[\log\frac{q(x)}{p(x)}\right]$$

The forward KL (\(p\|q\)) averages under \(p\) — it is infinite whenever \(q(x)=0\) for some \(x\) where \(p(x)>0\). This forces \(q\) to cover every mode of \(p\): if \(p\) is bimodal, the minimising \(q\) spreads to cover both modes (mass-covering / mean-seeking behaviour).

The reverse KL (\(q\|p\)) averages under \(q\) — if \(q(x)\approx 0\) somewhere, that region contributes nothing. So \(q\) can freely ignore modes of \(p\) it doesn't occupy; it concentrates on whichever mode gives the lowest \(D_{\mathrm{KL}}\) (zero-forcing / mode-seeking behaviour).

Numerical Example (5-bin discrete, verified with NumPy)

Let \(p = [0.05, 0.60, 0.25, 0.07, 0.03]\) (peaked at bin 1), \(q = [0.10, 0.20, 0.40, 0.20, 0.10]\) (broad):

$$D_{\mathrm{KL}}(p\|q) = 0.3974 \;\text{nats}, \quad D_{\mathrm{KL}}(q\|p) = 0.3680 \;\text{nats}$$

They differ by \(\approx 0.029\) nats. The forward KL is larger because \(p\) is peakier: bin 1 alone contributes \(0.60 \times \log(0.60/0.20) \approx 0.66\) nats — large, because \(q\) heavily under-represents this mode. The cross-entropy: \(H(p) + D_{\mathrm{KL}}(p\|q) = 1.0942 + 0.3974 = 1.4916 = H(p,q)\) ✓.

KL is Not a Metric

KL divergence is neither symmetric nor does it satisfy the triangle inequality — it is a divergence, not a distance. The Jensen–Shannon divergence \(\mathrm{JSD}(p\|q) = \tfrac{1}{2}D_{\mathrm{KL}}(p\|m) + \tfrac{1}{2}D_{\mathrm{KL}}(q\|m)\) where \(m = \tfrac{1}{2}(p+q)\) is symmetric and bounded in \([0,\log 2]\). Its square root is a true metric and appears in GAN theory.

Key Takeaways & ML Applications
▼

Two Directions, Two Behaviours

  • Forward KL \(D_{\mathrm{KL}}(p\|q)\) — mean-seeking / mass-covering: \(q\) must assign non-zero probability everywhere \(p\) does, or pay infinite cost. Used in MLE and cross-entropy training: the model must explain every data point. If \(p\) is bimodal, the optimal \(q\) spans both modes.
  • Reverse KL \(D_{\mathrm{KL}}(q\|p)\) — mode-seeking / zero-forcing: \(q\) avoids regions where \(p\) is small (the penalty for \(q\) being large where \(p\) is small is large). Used in variational inference and VAE ELBOs: the approximate posterior collapses onto a single mode of the true posterior.

Cross-entropy training = minimising forward KL

For one-hot labels \(p\) (Dirac), \(H(p) = 0\), so cross-entropy loss = \(D_{\mathrm{KL}}(p\|q_\theta)\). Minimising cross-entropy IS minimising KL divergence — they're the same objective.

VAE ELBO

The Evidence Lower Bound decomposes as: \(\mathcal{L} = \mathbb{E}_{q_\phi}[\log p(x|z)] - D_{\mathrm{KL}}(q_\phi(z|x)\|p(z))\). The KL term is reverse KL, regularising the encoder posterior toward the prior \(p(z) = \mathcal{N}(0,I)\). For Gaussians this has the closed form: \(-\tfrac{1}{2}\sum_j(1 + \log\sigma_j^2 - \mu_j^2 - \sigma_j^2)\).

The Three Faces of KL in Deep Learning

Cross-entropy training: forward KL, must cover all data. Variational inference / VAEs: reverse KL in ELBO, posterior collapses to a mode. Knowledge distillation: forward KL on teacher soft outputs, student must match full distribution — not just argmax. GAN equilibrium: generator minimises JSD \(\approx \tfrac{1}{2}D_{\mathrm{KL}}(p_r\|m) + \tfrac{1}{2}D_{\mathrm{KL}}(p_g\|m)\), a symmetric variant.

Code Trace

import numpy as np
# Two discrete distributions over 5 bins
p = np.array([0.05, 0.60, 0.25, 0.07, 0.03]) # peaked at bin 1
q = np.array([0.10, 0.20, 0.40, 0.20, 0.10]) # broader, centred at bin 2
# Forward KL: D_KL(p || q) — expectation under p
kl_fwd = np.sum(p * np.log(p / q)) # 0.3974 nats
# Reverse KL: D_KL(q || p) — expectation under q
kl_rev = np.sum(q * np.log(q / p)) # 0.3680 nats
# Asymmetry confirmed
assert not np.isclose(kl_fwd, kl_rev) # True — differ by 0.0294
# Cross-entropy decomposition: H(p,q) = H(p) + KL(p||q)
H_p = -np.sum(p * np.log(p)) # 1.0942 nats
H_pq = -np.sum(p * np.log(q)) # 1.4916 nats
assert np.isclose(H_pq, H_p + kl_fwd) # True ✓
# VAE ELBO: closed-form KL for Gaussians
def kl_gaussian(mu, log_var):
"""D_KL(N(mu,sigma^2) || N(0,1)) — closed form (nats)."""
return -0.5 * np.sum(1 + log_var - mu**2 - np.exp(log_var))
mu = np.array([0.5, -0.3])
log_var = np.array([-0.2, 0.1])
print(kl_gaussian(mu, log_var)) # 0.1820 nats
