KL Divergence (Relative Entropy)

The extra bits paid for using the wrong distribution — and why it's always non-negative
Intermediate Information Theory Probabilistic ML O(n) compute
1
Understanding KL Divergence
▼

What is it? KL divergence (Kullback-Leibler divergence), also called relative entropy, measures how different one probability distribution \(p\) is from another \(q\). Specifically, it measures the extra information cost you pay when you use \(q\) as a code instead of the true distribution \(p\).

Analogy — the wrong codebook: Suppose you're compressing messages from a weather station. The true distribution of outcomes is \(p\) (e.g., 70% sunny, 30% rainy). If you design your compression code assuming \(q\) (e.g., 50/50), your code will be suboptimal. KL divergence \(D_{KL}(p \| q)\) tells you exactly how many extra bits per message you waste by using the wrong codebook \(q\) instead of the optimal one for \(p\).

If you remember one thing

\(D_{KL}(p \| q) = \sum_x p(x)\log\frac{p(x)}{q(x)}\) is the extra bits paid when coding \(p\)-distributed data with a \(q\)-optimal codebook. It equals zero if and only if \(p = q\) everywhere, and is always \(\geq 0\) — using the wrong distribution can never save bits.

Key properties at a glance:

  • Non-negative: \(D_{KL}(p \| q) \geq 0\), with equality iff \(p = q\) a.e. (Gibbs' inequality)
  • Asymmetric: \(D_{KL}(p \| q) \neq D_{KL}(q \| p)\) in general — "forward" vs "reverse" KL
  • Not a metric: violates symmetry and triangle inequality
  • Decomposition: \(D_{KL}(p \| q) = H(p, q) - H(p)\) — cross-entropy minus entropy

How KL Divergence Works Internally
▼

The Definition

For discrete distributions \(p\) and \(q\) over the same alphabet \(\mathcal{X}\):

$$D_{KL}(p \| q) = \sum_{x \in \mathcal{X}} p(x) \log \frac{p(x)}{q(x)}$$

For continuous distributions:

$$D_{KL}(p \| q) = \int_{-\infty}^{\infty} p(x) \log \frac{p(x)}{q(x)}\, dx$$

Convention: \(0 \cdot \log(0/q) = 0\) and \(p \cdot \log(p/0) = +\infty\) (if \(p > 0\)).

Interpreting Each Term

Rewrite the sum as:

$$D_{KL}(p \| q) = \sum_x p(x)\bigl[\log p(x) - \log q(x)\bigr] = -H(p) + H(p, q)$$

where \(H(p) = -\sum_x p(x)\log p(x)\) is the entropy of \(p\) (optimal coding length under \(p\)) and \(H(p,q) = -\sum_x p(x)\log q(x)\) is the cross-entropy (average coding length under \(q\) when the truth is \(p\)). KL divergence is therefore the excess coding cost: cross-entropy minus entropy.

Why It's Asymmetric — Forward vs Reverse KL

The two directions have radically different behaviors when fitting a simpler distribution \(q\) to a complex \(p\):

  • Forward KL \(D_{KL}(p \| q)\): forces \(q\) to cover all modes of \(p\) (mass-covering). Where \(p > 0\), \(q\) must also be \(> 0\) or the divergence explodes. Used in MLE and VAE encoders.
  • Reverse KL \(D_{KL}(q \| p)\): forces \(q\) to concentrate on one mode of \(p\) (mode-seeking). If \(q > 0\) where \(p = 0\), the divergence penalizes this heavily. Used in VI (ELBO maximization) and expectation propagation.
Design Decision: Which Direction to Minimize?

Variational Inference minimizes \(D_{KL}(q \| p)\) (reverse KL), making the approximate posterior \(q\) mode-seeking — it commits to one region of the true posterior. VAE encoders push \(D_{KL}(q_\phi(z|x) \| p(z))\) toward zero as part of the ELBO. Meanwhile, cross-entropy training of classifiers implicitly minimizes \(D_{KL}(p_{\text{data}} \| p_{\theta})\) over the model parameters.

Numerical Trace: \(p = [0.3, 0.7]\), \(q = [0.7, 0.3]\)

Step through the computation term by term:

  • \(x=0\): \(0.3 \cdot \log(0.3/0.7) = 0.3 \cdot \log(0.4286) = 0.3 \cdot (-0.8473) = -0.2542\) nats
  • \(x=1\): \(0.7 \cdot \log(0.7/0.3) = 0.7 \cdot \log(2.3333) = 0.7 \cdot 0.8473 = 0.5931\) nats
  • \(D_{KL}(p\|q) = -0.2542 + 0.5931 = \mathbf{0.3389}\) nats
  • Reverse: \(D_{KL}(q\|p) = 0.7\cdot\log(0.7/0.3) + 0.3\cdot\log(0.3/0.7) = 0.5931 - 0.2542 = \mathbf{0.3389}\)... wait — by symmetry of this particular example it matches. Try \(p=[0.1,0.9], q=[0.9,0.1]\):
  • \(D_{KL}(p\|q) = 0.1\cdot\log(0.1/0.9)+0.9\cdot\log(0.9/0.1) = 0.1\cdot(-2.197)+0.9\cdot(2.197) = -0.2197+1.977 = \mathbf{1.758}\) nats
  • \(D_{KL}(q\|p) = 0.9\cdot\log(0.9/0.1)+0.1\cdot\log(0.1/0.9) = \mathbf{1.758}\) nats — symmetric for this balanced case.
  • True asymmetry: try \(p=[0.1,0.9], q=[0.3,0.7]\): \(D_{KL}(p\|q)=0.1163\), \(D_{KL}(q\|p)=0.1537\) — now they differ.
Common Pitfall

KL divergence is defined only when \(q(x) > 0\) wherever \(p(x) > 0\) (absolute continuity). If \(q\) puts zero mass anywhere that \(p\) puts positive mass, \(D_{KL}(p\|q) = +\infty\). Always check support compatibility before computing.

3
Why It's Always ≥ 0 — Gibbs' Inequality
▼

Gibbs' Inequality — Proof via Jensen's Inequality

We want to show \(D_{KL}(p \| q) \geq 0\) with equality iff \(p = q\).

Key tool: \(\log\) is a strictly concave function, so by Jensen's inequality, \(\mathbb{E}[\log X] \leq \log \mathbb{E}[X]\) for a random variable \(X\).

$$D_{KL}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = -\sum_x p(x) \log \frac{q(x)}{p(x)}$$

Now apply Jensen's inequality to the concave function \(\log\), with \(X = q(x)/p(x)\) under measure \(p\):

$$-\sum_x p(x) \log \frac{q(x)}{p(x)} \geq -\log\!\left(\sum_x p(x) \cdot \frac{q(x)}{p(x)}\right) = -\log\!\left(\sum_x q(x)\right) = -\log(1) = 0$$

Therefore \(D_{KL}(p \| q) \geq 0\). Equality holds when \(q(x)/p(x) = \text{const}\) for all \(x\) where \(p(x)>0\). Since both sum to 1, the constant must be 1, i.e., \(p = q\). \(\blacksquare\)

Alternative Proof via \(\log x \leq x - 1\)

A direct inequality: \(\ln x \leq x - 1\) for all \(x > 0\), with equality iff \(x = 1\).

$$-D_{KL}(p\|q) = \sum_x p(x)\log\frac{q(x)}{p(x)} \leq \sum_x p(x)\!\left(\frac{q(x)}{p(x)} - 1\right) = \sum_x q(x) - \sum_x p(x) = 1 - 1 = 0$$

So \(D_{KL}(p\|q) \geq 0\). Equality when \(q(x)/p(x) = 1\) everywhere, i.e., \(p = q\). \(\blacksquare\)

Three Ways to See Non-Negativity

1. Coding theory: You can never do better than the optimal code — the optimal code for \(p\) achieves \(H(p)\) bits; any other codebook \(q\) costs at least \(H(p)\) bits, so cross-entropy \(H(p,q) \geq H(p)\).
2. Jensen: Concavity of \(\log\) gives \(\mathbb{E}_p[\log(q/p)] \leq \log \mathbb{E}_p[q/p] = \log 1 = 0\).
3. Inequality \(\log x \leq x-1\): Apply pointwise and sum over the distribution.

Relationship to Mutual Information

Mutual information is a KL divergence between the joint and the product of marginals:

$$I(X;Y) = D_{KL}(p(x,y) \| p(x)p(y)) = \mathbb{E}_{x,y}\!\left[\log\frac{p(x,y)}{p(x)p(y)}\right]$$

Non-negativity of KL directly implies \(I(X;Y) \geq 0\), i.e., knowing one variable can only reduce (or maintain) uncertainty about the other — never increase it.

Key Takeaways & Connections
▼

When KL divergence appears in ML:

  • VAE (Variational Autoencoder) ELBO: The ELBO is \(\mathcal{L} = \mathbb{E}_{q_\phi}[\log p_\theta(x|z)] - D_{KL}(q_\phi(z|x)\|p(z))\). Maximizing ELBO = minimizing KL from approximate posterior to prior.
  • Cross-entropy loss in classification: Minimizing \(H(p_{\text{data}}, p_\theta)\) over \(\theta\) is equivalent to minimizing \(D_{KL}(p_{\text{data}}\|p_\theta)\) since \(H(p_{\text{data}})\) is constant w.r.t. \(\theta\).
  • Variational Inference: Mean-field VI minimizes \(D_{KL}(q\|p)\) (reverse KL) via coordinate ascent on ELBO.
  • Knowledge Distillation: The distillation loss is \(D_{KL}(p_{\text{teacher}}\|p_{\text{student}})\) — train the student to match the teacher's soft labels.
  • Reinforcement Learning (PPO/TRPO): KL constraints prevent policy updates from moving too far from the old policy: \(D_{KL}(\pi_{\text{old}}\|\pi_{\text{new}}) \leq \delta\).
The Central Hierarchy

Entropy \(H(p)\) = average surprise under \(p\). Cross-entropy \(H(p,q)\) = average surprise when using \(q\) but truth is \(p\). KL Divergence \(D_{KL}(p\|q) = H(p,q) - H(p)\) = the surplus. Minimizing cross-entropy (ML training) is the same as minimizing KL from data to model.

When NOT to use KL as a loss:

  • When distributions have different supports — KL is infinite. Use Jensen-Shannon (symmetric, bounded) or Wasserstein distance.
  • When you need a true metric — KL violates symmetry and the triangle inequality.
  • When \(q\) might assign zero probability — numerically add \(\varepsilon\) or use label smoothing.

Code Trace
▼
import numpy as np
def kl_divergence(p, q, eps=1e-12):
"""D_KL(p||q) in nats. p and q are probability arrays."""
p, q = np.asarray(p, float), np.asarray(q, float)
# Clip q to avoid log(0) — never clip p (zero p contributes 0)
q = np.clip(q, eps, None)
mask = p > 0
return np.sum(p[mask] * np.log(p[mask] / q[mask]))
p = np.array([0.3, 0.7])
q = np.array([0.7, 0.3])
kl_pq = kl_divergence(p, q) # 0.3389 nats
kl_qp = kl_divergence(q, p) # 0.3389 nats (symmetric here)
p2 = np.array([0.1, 0.9])
q2 = np.array([0.3, 0.7])
kl_p2q2 = kl_divergence(p2, q2) # 0.1163 nats
kl_q2p2 = kl_divergence(q2, p2) # 0.1537 nats — DIFFERENT
# Cross-entropy decomposition:
H_p = -np.sum(p * np.log(p)) # entropy
H_pq = -np.sum(p * np.log(q)) # cross-entropy
assert abs(H_pq - H_p - kl_pq) < 1e-9 # H(p,q) = H(p) + D_KL(p||q)
# PyTorch: F.kl_div expects LOG-PROBABILITIES for input (q)
import torch, torch.nn.functional as F
log_q = torch.log(torch.tensor(q))
p_t = torch.tensor(p)
loss = F.kl_div(log_q, p_t, reduction='sum') # D_KL(p||q)
# ⚠️ reduction='batchmean' for training (divides by batch size)
