1
Understanding the Problem
▼

What is the problem? K-Nearest Neighbours (KNN) classifies a test point by majority vote among its K closest training neighbours. The single most important hyper-parameter is K itself. Choose it too small and the model memorises noise; choose it too large and it ignores local structure entirely.

Analogy. Imagine asking your K nearest neighbours for their opinion on a restaurant. If K = 1 you get one person's quirky taste — fast but unreliable. If K = everyone in the city, you drown in generic consensus that ignores that you live next to a great noodle strip. The right K balances neighbourhood size against signal quality.

💡 If you remember one thing

K controls the bias–variance trade-off: small K → low bias / high variance (overfit); large K → high bias / low variance (underfit). Choose K by minimising the cross-validation error — the resulting "U-shaped" curve has an elbow that is the sweet spot. Always prefer odd K to avoid tie votes in binary classification.

Why not just use accuracy on training data?

With K = 1, training accuracy is always 100%: every point is its own nearest neighbour and votes for itself. This is useless — we need a held-out estimate of generalisation error. Cross-validation provides an honest estimate without wasting data.

Bias–Variance Trade-off in KNN
▼

Formal Decomposition

For a point \(\mathbf{x}\), the KNN regression estimate is \(\hat{f}(\mathbf{x}) = \frac{1}{K}\sum_{i \in \mathcal{N}_K(\mathbf{x})} y_i\). The expected mean-squared error decomposes as:

$$\mathbb{E}\left[(y - \hat{f}(\mathbf{x}))^2\right] = \underbrace{\sigma^2_{\varepsilon}}_{\text{irreducible}} + \underbrace{\left(f(\mathbf{x}) - \mathbb{E}[\hat{f}(\mathbf{x})]\right)^2}_{\text{Bias}^2} + \underbrace{\operatorname{Var}(\hat{f}(\mathbf{x}))}_{\text{Variance}}$$

How K moves the needle

K valueBiasVarianceDecision boundaryGeneralisation
K = 1LowVery highJagged, traces every pointPoor (overfit)
K = 5–15ModerateModerateSmooth, captures structureBest (sweet spot)
K → nVery highNear zeroFlat — always majority classPoor (underfit)

Why does variance fall with K? The KNN estimator averages \(K\) labels, each with variance \(\sigma^2\). By the law of large numbers:

$$\operatorname{Var}\!\left(\hat{f}_K(\mathbf{x})\right) = \frac{\sigma^2}{K}$$

Doubling K halves the variance — but the neighbourhood grows and may cross the true decision boundary, introducing bias.

🔑 Key Insight

There is a U-shaped curve of generalisation error vs K. The minimum of this curve is the optimal K*. The "elbow method" finds this minimum graphically; cross-validation computes it numerically.

Odd K for binary classification

With an even K and two classes, ties are possible (e.g., 2 votes each with K = 4). Choosing odd K guarantees a unique majority. More generally, choose K not divisible by the number of classes to avoid systematic ties. In multiclass settings, consider weighted voting: neighbour at distance \(d\) contributes \(1/d\) votes.

⚠️ Common Pitfall

Normalising features before computing distances is mandatory. If one feature spans 0–10,000 and another spans 0–1, KNN will effectively ignore the small-scale feature. Always apply StandardScaler (zero mean, unit variance) or MinMaxScaler before running KNN.

3
The Math — Cross-Validation & Elbow
▼

Leave-One-Out Cross-Validation (LOO-CV)

The gold standard for small datasets. For each training point \(i\), train on all other \(n-1\) points and predict on point \(i\). The LOO-CV error for a given K is:

$$\text{CV}_{LOO}(K) = \frac{1}{n} \sum_{i=1}^{n} \mathbf{1}\!\left[\hat{y}^{(-i)}_K(\mathbf{x}_i) \neq y_i\right]$$

where \(\hat{y}^{(-i)}_K\) is the KNN prediction using the model trained without point \(i\). This is an almost unbiased estimator of test error, but has high variance across different training sets.

k-Fold Cross-Validation (practical alternative)

Split the data into \(k\) folds (typically \(k=5\) or \(k=10\)). For each fold, train on the remaining \(k-1\) folds, predict on the held-out fold:

$$\text{CV}_{k\text{-fold}}(K) = \frac{1}{k} \sum_{j=1}^{k} \text{Err}_j(K)$$

where \(\text{Err}_j\) is the error on fold \(j\). Much cheaper than LOO-CV (\(O(k \cdot n \cdot d)\) vs \(O(n^2 \cdot d)\)) with comparable bias and lower variance.

The Elbow Method

Plot \(\text{CV}(K)\) against \(K\). The curve is U-shaped: high error at \(K=1\) (overfit), falling to a minimum, then rising again (underfit). The optimal \(K^*\) is:

$$K^* = \underset{K \in \{1,3,5,\ldots\}}{\operatorname{argmin}}\; \text{CV}(K)$$

In our example (80 points, two overlapping Gaussians, 10% label noise): minimum 5-fold CV error occurs at K = 13–15 (≈ 16.9%), confirming the elbow. The "rule of thumb" \(K \approx \sqrt{n}\) gives \(\sqrt{80} \approx 9\) — in the right neighbourhood.

∑ Key Formula

Rule of thumb: start search at \(K \approx \sqrt{n}\). The elbow is the K where decreasing K further no longer substantially reduces CV error. In noisy settings, prefer the one-standard-error rule: choose the largest K whose CV error is within 1 SE of the minimum — this trades a tiny amount of accuracy for a smoother, more robust boundary.

Practical Rules & Code

From-scratch cross-validated KNN

import numpy as np
from collections import Counter
def knn_predict(X_train, y_train, X_test, k):
"""KNN prediction: O(n_train * n_test * d) brute-force."""
preds = []
for x in X_test:
# Euclidean distances to all training points
dists = np.linalg.norm(X_train - x, axis=1)
# Indices of K nearest neighbours
nn_idx = np.argsort(dists)[:k]
# Majority vote (tie → lowest class label)
votes = Counter(y_train[nn_idx])
preds.append(max(votes, key=lambda c: (votes[c], -c)))
return np.array(preds)
def cv_error(X, y, k, n_folds=5, seed=0):
"""k-fold cross-validated error for KNN with a given K."""
rng = np.random.default_rng(seed)
idx = rng.permutation(len(X))
folds = np.array_split(idx, n_folds)
errors = []
for f in range(n_folds):
val = folds[f]
train = np.concatenate([folds[i] for i in range(n_folds) if i != f])
preds = knn_predict(X[train], y[train], X[val], k)
errors.append(np.mean(preds != y[val]))
return np.mean(errors)
def find_best_k(X, y, k_range=range(1, 32, 2), n_folds=5):
"""Sweep odd K values and return the elbow (minimum CV error)."""
cv_errors = {k: cv_error(X, y, k, n_folds) for k in k_range}
best_k = min(cv_errors, key=cv_errors.get)
return best_k, cv_errors

Production: scikit-learn GridSearchCV

from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import GridSearchCV
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
# Always scale features before KNN
pipe = Pipeline([
('scaler', StandardScaler()),
('knn', KNeighborsClassifier(metric='minkowski', p=2))
])
param_grid = {
'knn__n_neighbors': list(range(1, 32, 2)), # odd K only
'knn__weights': ['uniform', 'distance'] # try distance-weighted
}
gs = GridSearchCV(pipe, param_grid, cv=5, scoring='accuracy', n_jobs=-1)
gs.fit(X_train, y_train)
print(f"Best K: {gs.best_params_['knn__n_neighbors']}")
print(f"CV Accuracy: {gs.best_score_:.3f}")
# ⚠️ Gotcha: weights='distance' can help when classes are imbalanced
# ⚠️ Gotcha: use n_jobs=-1 — KNN CV is embarrassingly parallel
⚠️ One-Standard-Error Rule

If the CV curve is flat near the minimum, prefer the largest K within one SE of the minimum error. This gives a smoother boundary at minimal accuracy cost, and is more stable across different training samples:
se = std(fold_errors) / sqrt(n_folds)
Choose the largest K with CV error ≤ min_error + se.

6
Key Takeaways
▼

When to use cross-validation for K:

  • Always — never pick K by inspecting training accuracy
  • Use LOO-CV for small datasets (n < 200); 5- or 10-fold otherwise
  • Search only odd K values in binary classification to avoid ties
  • Start search at \(K \approx \sqrt{n}\) and sweep ±50%

When NOT to rely on KNN:

  • High-dimensional data (d > 20): distances become meaningless — "curse of dimensionality"
  • Large n (n > 100k): prediction is O(n·d) per query — use KD-tree or ball-tree, or switch to SVM/Random Forest
  • Very imbalanced classes: majority voting fails — use weighted KNN or oversample minority class
💡 The One-Line Mental Model

K = 1 draws a boundary that memorises. K = n draws a boundary that ignores. The best K sits at the bottom of the U-shaped CV error curve. Use cross-validation to find it, always pick odd K, and always scale your features first.
