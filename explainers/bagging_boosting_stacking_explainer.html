Bagging vs Boosting vs Stacking

Three ensemble strategies that combine weak learners into powerful predictors — each with a distinct philosophy on variance, bias, and model diversity.

Intermediate Classical ML · Ensembles Must Know
1
Understanding the Concept
▾

Ensemble methods build a strong learner by combining many weak learners. The three dominant strategies differ in how they train and combine those learners.

The Intuition

Bagging trains models in parallel on random data subsets — like asking 100 doctors each trained on different patients to vote. Disagreement cancels out, reducing variance.
Boosting trains models sequentially, each one correcting the mistakes of the previous — like a student who reviews only wrong answers after each test. Errors are progressively eliminated, reducing bias.
Stacking trains diverse models and then learns how to combine them with a meta-learner — like a judge who has watched many specialists and learned whose opinion to trust for which type of case.

The key insight: Bagging and Boosting address different sources of error (variance vs bias); Stacking is agnostic — it delegates the combination strategy to another model.

If You Remember One Thing

Bagging = parallel + ↓ variance (Random Forest). Boosting = sequential + ↓ bias (XGBoost). Stacking = meta-learner combining diverse models.

2
How Each Method Works Internally
▾

Bagging (Bootstrap Aggregating) — Breiman 1996

  1. Draw \(B\) bootstrap samples \(D_1, \ldots, D_B\) from training data \(D\) (sampling with replacement, same size \(n\)).
  2. Train a base learner \(h_b\) independently on each \(D_b\).
  3. Aggregate: for regression average outputs; for classification majority vote.
$$\hat{f}_{bag}(x) = \frac{1}{B} \sum_{b=1}^{B} h_b(x)$$

Because each \(D_b\) is a random resample, the learners are decorrelated. Averaging decorrelated predictors reduces variance without increasing bias — the variance of the mean drops as \(1/B\) (for uncorrelated models), or more precisely:

$$\operatorname{Var}\!\left(\bar{h}\right) = \rho \sigma^2 + \frac{1-\rho}{B}\sigma^2$$

where \(\rho\) is the pairwise correlation between learners. Random Forest further reduces \(\rho\) by sub-sampling features at each split.

Boosting (AdaBoost / Gradient Boosting) — Freund & Schapire 1997 / Friedman 2001

  1. Initialise weights \(w_i = 1/n\) for all samples.
  2. Fit weak learner \(h_m\) to current weighted dataset.
  3. Compute error \(\epsilon_m\) and learner weight \(\alpha_m = \frac{1}{2}\ln\!\left(\frac{1-\epsilon_m}{\epsilon_m}\right)\).
  4. Upweight misclassified samples: \(w_i \leftarrow w_i \exp(\alpha_m y_i h_m(x_i))\), re-normalise.
  5. Repeat for \(M\) rounds. Final: \(H(x) = \text{sign}\!\left(\sum_{m=1}^{M}\alpha_m h_m(x)\right)\).

Gradient Boosting generalises this: learner \(m\) fits the negative gradient of the loss, making boosting a gradient descent in function space.

$$F_m(x) = F_{m-1}(x) + \nu \cdot h_m(x) \qquad h_m \approx -\nabla_F \mathcal{L}(y, F_{m-1}(x))$$

Stacking (Stacked Generalisation) — Wolpert 1992

  1. Split data into \(K\) folds. Train \(L\) diverse base learners on out-of-fold data, collect their predictions \(z_{i\ell}\) for each sample.
  2. Construct a new feature matrix \(Z \in \mathbb{R}^{n \times L}\) from these out-of-fold predictions.
  3. Train a meta-learner \(g\) on \(Z\) to predict \(y\). At test time: \(\hat{y} = g(h_1(x), h_2(x), \ldots, h_L(x))\).
Critical: Why Out-of-Fold Predictions?

If base learners see the training targets while generating meta-features, the meta-learner learns from leaked predictions. Cross-validation at Level 0 ensures the meta-learner trains on honest (unseen-target) predictions.

3
The Math — Bias–Variance Decomposition
▾

Every predictor's expected squared error decomposes as:

$$\mathbb{E}\!\left[(y - \hat{f}(x))^2\right] = \underbrace{\sigma^2}_{\text{irreducible}} + \underbrace{\operatorname{Bias}^2(\hat{f})}_{\text{systematic error}} + \underbrace{\operatorname{Var}(\hat{f})}_{\text{sensitivity to data}}$$

Why Bagging reduces variance. Let \(h_1,\ldots,h_B\) be identically distributed (not independent) with \(\operatorname{Var}(h_b) = \sigma^2\) and pairwise correlation \(\rho\). Then:

$$\operatorname{Var}\!\left(\frac{1}{B}\sum_b h_b\right) = \rho\sigma^2 + \frac{1-\rho}{B}\sigma^2 \xrightarrow{B\to\infty} \rho\sigma^2$$

Averaging does not reduce bias, but pushes variance toward \(\rho\sigma^2\). Bias of the ensemble equals the bias of any single learner.

Why Boosting reduces bias. Each round fits residuals \(r_i = -\partial\mathcal{L}/\partial F(x_i)\). After \(M\) rounds, the training residuals contract multiplicatively. For AdaBoost with exponential loss, the training error satisfies:

$$\text{Train Error} \leq \prod_{m=1}^{M} 2\sqrt{\epsilon_m(1-\epsilon_m)} = \exp\!\left(-2\sum_{m=1}^{M}\gamma_m^2\right)$$

where \(\gamma_m = 0.5 - \epsilon_m > 0\) is the edge of the weak learner. Training error vanishes exponentially — bias is systematically driven down. The risk is overfitting (variance grows with \(M\)).

Stacking — no single bias–variance story. The meta-learner \(g\) can be any model. If \(g\) is a linear regression, the result is a constrained combination that can potentially achieve lower generalisation error than either bagging or boosting alone, by exploiting each base model's region of competence.

Numerical Example — Bagging Variance Reduction

5 learners, each with \(\sigma^2 = 1\), correlation \(\rho = 0.3\):
Simple average variance \(= 0.3 \times 1 + \frac{0.7}{5} \times 1 = 0.3 + 0.14 = 0.44\).
Uncorrelated case: \(\frac{1}{5} = 0.20\). Correlated case: floor is \(\rho\sigma^2 = 0.30\).
Adding more models helps only until \(\rho\sigma^2\) — de-correlation (feature subsampling) is what drives the rest down.

Decision Guide

Use Bagging when your base model has high variance (e.g., deep decision trees) and you want stability and can parallelise training.
Use Boosting when your base model has high bias (e.g., shallow trees / stumps) and you want maximum predictive accuracy with careful regularisation.
Use Stacking in competition settings or when you have diverse model types (tree-based, linear, NN) and want to let a meta-learner discover the optimal blend.

  • Random Forest = Bagging + random feature subsets at each split (reduces \(\rho\))
  • XGBoost/LightGBM/CatBoost = Gradient Boosting with regularisation, column subsampling
  • Stacking in sklearn: StackingClassifier / StackingRegressor
6
Key Takeaways & Interview Tips
▾
  • Bias–variance is the core story: Bagging attacks variance, Boosting attacks bias, Stacking attacks both indirectly.
  • Random Forest is bagging + feature sub-sampling; the key hyperparameter is max_features (controls \(\rho\)).
  • Boosting can overfit — early stopping, learning rate, and max depth are critical regularisers.
  • Stacking requires cross-validation at Level 0 to avoid leakage; out-of-fold predictions are the correct approach.
  • Diversity is essential for all ensembles — identical models cannot improve on each other regardless of combination rule.
Common Interview Trap

"Does bagging reduce bias?" — No. It leaves bias unchanged and only reduces variance. Interviewers frequently test this. Similarly, boosting can increase variance as \(M\) grows, which is why regularisation (learning rate, subsampling) is mandatory in practice.
